## s03p04 세 가게가 나란히
> 가운데 가게가 양다리다. 칸막이·저울·소시지는 왼쪽(세균)과 같고, 실패는 오른쪽(진핵)과 같다. 그리고 차양의 가지 하나만 자기 것이다 — 기출은 이 「어느 쪽을 닮았나」를 정면으로 묻는다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 가게 셋이 한 줄로 — 왼쪽·가운데·오른쪽 | 왼쪽이 세균, 가운데가 고세균, 오른쪽이 진핵이다. 셋이 똑같이 생겼고 다른 곳만 뜻을 나른다 | 0 |  |
| 1 | 왼쪽·가운데는 칸막이 없는 한 칸 · 오른쪽만 안이 기둥으로 방 셋으로 나뉘었고, 주인은 가운데 방에 있다 | 핵막과 막성 소기관 — 세균 없음 / 고세균 없음 / 진핵 있음. 주인이 있는 가운데 방이 핵이다. 고세균에 칸막이가 없어서 원핵생물로 묶인다 | 11 |  |
| 2 | 저울 — 왼쪽과 가운데는 같은 작은 저울, 오른쪽만 큰 저울 | 리보솜 — 세균 70S(50+30) / 고세균 70S / 진핵 80S(60+40). 고세균이 세균과 같은 쪽이다. ★ 저울이 곧 S 다 — S(스베드베리)는 원심분리로 무게·크기를 달아 붙인 수라, 작은 저울 둘이 70, 큰 저울 하나가 80이다 | 5 |  |
| 3 | 실패 — 가운데와 오른쪽에만 있고, 왼쪽에는 실이 그냥 엉켜 있다 · 오른쪽 가게의 실패는 주인과 같은 가운데 방, 계산대 위 주인 앞에 놓였다 | 히스톤 — 세균 없음 / 고세균 있음 / 진핵 있음. 실을 감아 정리해 주는 것이 히스톤이고, 고세균이 진핵을 닮은 대표 항목이다 ★ 진핵에서 실패가 주인이 있는 가운데 방(핵)에 있는 것도 요점이다 — 히스톤은 핵 안에서 DNA를 감는다. 곁방(미토콘드리아 같은 소기관)에 두면 틀린다 — 미토콘드리아 DNA에는 히스톤이 없다 | 5 |  |
| 4 | 한 줄에 꿴 소시지 — 왼쪽과 가운데에만 · 오른쪽은 낱개로 따로 걸렸다 | 오페론 — 세균 있음 / 고세균 있음 / 진핵 없음. 여럿을 한 줄에 꿰어 한꺼번에 켜고 끄는 것이 오페론이고, 이것은 고세균이 세균과 같은 쪽이다 | 5 |  |
| 5 | 차양의 줄무늬 — 가운데 것만 가지가 갈라진다 | 막지질 — 세균과 진핵은 에스테르 결합에 곧은 사슬, 고세균만 에테르 결합에 가지 친 곁사슬이다. 여섯 중 고세균만의 것은 이것 하나다 | 5 |  |
| 6 | 가게 주인 — 왼쪽 사람만 끝이 F자로 꺾인 장대를 들었다 | 번역 개시 아미노산 — 세균만 fMet(포르밀메티오닌), 고세균·진핵은 Met. 포르밀기가 F자 장대다 ★ 2026-08-25 납작모자를 F자 장대로 바꿨다 — 「모자」는 5′ 캡 전용이라 _심볼예약 을 깨고 있었고, s10p01b·s19p01 은 같은 f 를 이미 F자 장대로 그리고 있었다. 이제 덱 전체가 한 기호를 쓴다 | 4 |  |
