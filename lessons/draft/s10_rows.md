# s10 번역 억제제 공장 — 17 유전자의 발현 — 번역


## s10p01 리보솜 좌석
> 리보솜을 위아래 크기가 다른 두 블록으로 그린 이유는 다음 패널에서 자물쇠를 층별로 나눠 걸기 위해서다. 벨트 위 세 자리는 오른쪽부터 입장·연결·퇴장 순서다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 블록을 관통해 좌우로 지나는 겹줄 레일 | mRNA — 리보솜이 이 띠를 훑으며 코돈을 읽는다(A자리 쪽이 3′) | 1 |  |
| 1 | 아래 블록보다 확실히 큰 위 블록 | 30S(작은) / 50S(큰) 소단위 — 원핵 70S, 진핵은 40S+60S=80S | 1 |  |
| 2 | 오른쪽에서 구슬 들고 도착 | A자리 — 아미노아실 tRNA 입장 | 2 |  |
| 3 | 오른쪽 인부가 멘 황갈색 배낭 — 열린 옆주머니에서 쪼개진(다 쓴) 동전 둘이 떨어진다 | 아미노아실-tRNA 합성효소가 ATP를 써서 아미노산을 tRNA에 실어 보냈다(ATP→AMP+PPi) ★ 쪼개진 동전이 이미 쓴 에너지다 — 싣느라 들어오기 전에 썼고, ATP 가 AMP 까지 쪼개지니 고에너지 결합 둘만큼이다(동전 둘) ★ 가운데에서 붙이는 사람은 배낭도 동전도 없다 — 펩타이드 결합 자체에는 ATP·GTP를 따로 쓰지 않는다. 에너지는 들어올 때 이미 메고 온 것이다 | 6 |  |
| 4 | 가운데 사람이 제 사슬 끝을 오른쪽 사람이 쥔 구슬에 넘겨 잇는다 — 가운데 사람 손엔 낱구슬이 없다 | P자리 — 펩타이드 결합이 만들어진다. ★ 구슬이 사슬로 오는 게 아니라 사슬이 구슬로 간다 — P자리 tRNA 에 달린 사슬 전체가 A자리 아미노산으로 옮겨 간다(펩티딜 전이). 「새 아미노산이 P자리 사슬 끝에 붙는다」는 오답이다. 결합 뒤 사슬은 A자리 tRNA 에 달려 있고, 자리옮김으로 그 tRNA 가 P 로 옮겨 앉는다(곁판 s10p01c) | 1 |  |
| 5 | 왼쪽에서 빈손으로 퇴장 | E자리 — tRNA 방출 | 1 |  |
| 6 | 머리 모양이 서로 다른 열쇠 셋이 놋쇠빛 자물쇠 하나의 같은 열쇠구멍에 | 요동가설 — 안티코돈 1번이 이노신이면 코돈 3번의 A·U·C 모두와 짝짓는다 ⚠ 이 자물쇠는 놋쇠빛이고 열쇠가 딸려 있다 — 덱의 약물·독물 자물쇠는 밝은 금색이고 열쇠가 없이 기계에 채워져 있다. 둘은 열쇠로 갈린다 — 이 자물쇠엔 열쇠가 셋이나 꽂혀 있다 | 6 |  |
| 7 | ★ 오른쪽에서 들고 들어오고 · 가운데서 사슬을 넘겨 잇고 · 왼쪽으로 빈손으로 나간다 | A(들어옴) → P(펩타이드 보유) → E(나감). 자리 이름을 외우지 말고 사람이 하는 일로 읽는다 | 1 |  |

## s10p01b 두 개찰구 — 훑는 쪽, 곧장 앉는 쪽
> ★ 위 칸에는 모자가 있고 아래 칸에는 없다 — 그 하나가 나머지를 다 만든다. 모자가 있으면 붙잡고 훑어야 하고(점선), 모자가 없으면 빛나는 간판에 곧장 내려앉는다. 멈추는 자리에 쭈그려 춤추는 코사크가 있는 것이 코작 서열이고, 아래 사람이 든 F자 장대가 fMet다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | ★ 위 칸 왼쪽 끝에는 겨자색 중산모가 있고, 아래 칸 왼쪽 끝은 맨 띠뿐이다 | 진핵 mRNA에는 앞머리에 5′ 캡이 있고 원핵 mRNA에는 없다 — 이 하나가 개시 방식을 통째로 가른다 | 0 |  |
| 1 | 위 칸 — 모자에서 오른쪽으로 점선이 뻗고, 청록 상자에서 지시봉이 내려와 띠를 짚는다 | 작은 소단위체가 5′ 캡에 먼저 붙은 뒤 띠를 따라 훑어 내려가며 개시 AUG를 찾는다 — 이 훑는 과정이 스캐닝이다 | 1 |  |
| 2 | ★ 위 칸 — 점선이 끝나는 자리에 팔짱 끼고 한 다리를 찬 채 쭈그린 코사크가 서 있다 | 코작(Kozak) 서열. 스캐닝하던 소단위체가 아무 AUG에서나 멈추지 않고, 개시 AUG 둘레의 최적 서열을 만나야 멈춘다. 코사크가 곧 코작이다 | 1 |  |
| 3 | ★ 아래 칸 — 띠 가운데에 사방으로 빛살이 뻗는 판이 박혀 있고, 상자가 그 위에 곧장 내리꽂혀 앉는다 · 점선이 없다 | 샤인-달가노 서열. shine이 곧 「빛난다」이다. 원핵은 훑지 않고 이 서열에 직접 결합한다 — 16S rRNA가 그것을 알아본다 | 0 |  |
| 4 | ★ 아래 사람은 끝이 F자로 꺾인 장대를 짚었고, 위 사람은 두 손이 비어 있다 | 세균의 개시 아미노산은 fMet(포르밀메티오닌)이고 진핵은 Met다. 고세균도 Met라서 f가 붙는 것은 세균뿐이다 | 2 |  |
| 5 | ★ 두 칸을 나란히 보면 — 위는 모자 → 훑기 → 코사크, 아래는 빛나는 간판에 곧장 | 진핵은 5′캡에 붙어 스캐닝하고 첫 아미노산이 Met, 원핵은 샤인-달가노에 직접 결합하고 첫 아미노산이 fMet이다 | 3 |  |
| 6 | 두 칸 모두 청록 상자(작은 소단위체)만 띠에 닿아 있고, 같은 청록의 큰 돔(큰 소단위체)은 밧줄에 매달려 아직 떠 있다 — 상자는 목적지 표시가 아니라 띠에 … | 리보솜의 작은 소단위체가 mRNA와 결합한다. 큰 소단위체는 개시 자리가 정해진 뒤에 얹힌다 | 1 |  |

## s10p02 억제제 자물쇠
> 자물쇠가 걸린 층 위치가 곧 표적이다. 작은 층이면 30S, 큰 층이면 50S. 이음매를 걸친 큰 자물쇠 하나만 양쪽에 다 작용하고, 멀리 떨어진 다른 기계는 진핵 전용이다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 청록 돔(위층)과 청록 상자(아래층)로 된 공장 건물 자체 | 공장 두 층 = 70S 리보솜 (작은 30S + 큰 50S) | 2 |  |
| 1 | 아래 상자 옆면(왼쪽 면) — 열쇠구멍이 넷(주사위 눈처럼 보이는 네 구멍 = 테트라) 뚫린 자물쇠 | 테트라사이클린. 테트라(tetra)가 넷이다. 30S의 A자리를 막아 아미노아실-tRNA가 못 들어온다 | 1 |  |
| 2 | 아래 상자 앞면 — 열쇠구멍이 세로가 아니라 옆으로 누운 자물쇠(열쇠를 잘못 읽는다 = 오독), 고리는 밧줄처럼 꼬인 쇠(strepto = 꼬임) | 스트렙토마이신. 구멍이 누웠으니 열쇠를 잘못 읽는다 — 30S에 붙어 오독(misreading)을 일으킨다. strepto는 「꼬였다」는 뜻이다 | 1 |  |
| 3 | 위 돔 왼쪽 — 염소빛 황록색 자물쇠 | 클로람페니콜. 이름 앞의 「클로르」가 염소(鹽素)이고 염소는 황록색 기체다. 50S의 펩티딜 전이효소(리보자임)를 막는다 | 1 |  |
| 4 | 위 돔 오른쪽 — 붉은 자물쇠 | 에리트로마이신. erythro가 그리스어로 「붉다」이다. 50S에서 전좌(translocation)를 막는다 | 0 |  |
| 5 | 두 층 이음매의 큰 자물쇠 — 가짜 열쇠가 꽂힌 채 부러져 있고, 똑같은 자물쇠가 오른쪽 진핵 기계에도 하나 걸려 있다 | 푸로마이신. 아미노아실-tRNA 유사체로 위장해 A자리에 들어가 사슬을 조기 종결시킨다. 위장이라 원핵·진핵 양쪽에 다 듣는다 | 0 |  |
| 6 | 혼자만 공장 밖 오른쪽 기계의 고리에 걸린 평범한 금색 자물쇠(열쇠가 꽂혀 있지 않은 쪽 — 열쇠 꽂힌 쌍둥이 자물쇠는 6행) | 디프테리아 독소 — 진핵 전용이라 70S 공장에 안 걸린다. 진핵의 신장인자를 ADP 리보실화해 멈춘다(콜레라 G단백질과 짝) | 0 |  |
