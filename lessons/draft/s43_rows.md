# s43 담장 있는 공장, 없는 공장 — 17 유전자의 발현 — 원핵과 진핵


## s43p01 담장 있는 공장, 없는 공장
> ★ 담장이 있느냐 없느냐 하나가 나머지를 다 만든다. 담장이 핵막이고 뚫린 둥근 구멍이 핵공이다 — s11p04와 같은 표식이다. ★ 타탄 무늬 깔개가 TATA 상자이고, 삼각 깃발이 σ(시그마) 인자다.

|---|---|---|---|---|

## s43p02 담장 안 손질대
> 담장 안에서 하는 손질은 셋이다 — 앞머리에 모자, 꼬리에 술, 가운데를 잘라 잇기. ★ 청록은 이어져 나가고(엑손), 회색은 올가미로 묶여 안에 남는다(인트론) — 이름이 곧 행선지다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 작업대 왼쪽 끝 — 띠의 앞머리에 작은 모자를 씌우는 사람 | 5′ 캡. 모자가 곧 이름이다. 하는 일이 둘이다 — 분해를 막고, 밖에서 읽는 쪽이 먼저 잡는 손잡이가 된다. 진핵 번역 개시에서 작은 소단위체가 맨 먼저 붙는 자리가 여기다 | 6 |  |
| 1 | 작업대 오른쪽 끝 — 띠의 꼬리에 똑같은 술을 여러 가닥 매다는 사람 | poly-A 꼬리. 여러 가닥인 것이 poly다. 안정성을 높이고 핵 밖으로 나가는 것과 번역을 돕는다 | 9 |  |
| 2 | 가운데 — 다섯 사람이 팔짱을 껴 한 덩어리가 되어 가위질한다 | 스플라이소좀. 자르는 것은 한 사람이 아니라 단백질과 작은 RNA가 모인 한 복합체이고, 그 snRNP가 다섯 종이라 다섯이 붙어 있다 | 3 |  |
| 3 | 띠에 청록과 회색이 번갈아 있고, 가위는 회색만 자른다 | 청록이 엑손(최종 mRNA에 남아 번역되는 구간), 회색이 인트론(전사는 되지만 번역되지 않고 제거되는 구간)이다. 잘라 내고 남은 것을 잇는 것이 스플라이싱이다 | 6 |  |
| 4 | ★ 잘린 회색 토막은 올가미 매듭으로 묶여 담장 안 통에 남는다 · 거기에는 모자도 술도 없다 | 인트론이 빠질 때 라리아트(lariat, 올가미) 고리가 생긴다 — 이름이 곧 올가미다. 잘린 인트론이 곧바로 분해되는 것은 캡도 꼬리도 없어 보호받지 못하기 때문이다 | 3 |  |
| 5 | ★ 이어 붙인 것은 청록만 한 줄로 남아 담장 구멍으로 나간다 · 나가는 띠의 앞끝엔 작업대 왼쪽 사람이 씌우던 그 모자가, 뒤끝엔 오른쪽 사람이 매다는 그 술이… | ★ 엑손은 나가고(ex-) 인트론은 안에 남는다(in-). 이름이 곧 행선지다 — 둘을 바꿔 놓은 선지가 이 단원 최다 오답인데, 이 한 줄이면 갈린다 ★ 나가는 띠에 모자와 술이 다 붙어 있다 — 손질이 끝난 것만 나간다. 잘린 회색 토막(5행)에 모자도 술도 없는 것과 갈린다 | 0 |  |
| 6 | 작업대 위의 띠는 길고, 구멍으로 나가는 띠는 짧다 | 실제 유전자가 암호화 구간보다 훨씬 긴 것은 인트론이 많이 끼어 있기 때문이다 | 1 |  |
| 7 | ★ 담장 안에서 하는 손질은 모두 셋이다 — 앞머리 모자 · 꼬리 술 · 가운데 잘라 잇기 | 진핵 전사 후 RNA 가공 3가지: 5′ 캡 · poly-A 꼬리 · 스플라이싱. 전부 담장 안에서 끝나고, 끝나야 나간다 | 3 |  |

## s43p03 같은 원본, 다른 완성품
> 원본 띠는 맨 위 하나뿐인데 선반 아래로 연장이 둘 내려온다 — 둘 다 ○로 시작해 ☆로 끝나고 가운데 한 조각만 다른데, 하나는 파는 삽이고 하나는 뜨는 국자다. ★ 조각을 고르는 것이 선택적 스플라이싱이고, 조각 하나가 곧 도메인이다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | ★ 선반은 셋인데 회색이 섞인 원본 띠는 맨 위 하나뿐이다 · 인부가 위를 가리키고 아래로 쓸어내린다 | 아래 둘은 새로 만든 것이 아니라 같은 원본에서 내려온 것이다. 유전자는 하나인데 완성품이 여럿 — 이것이 선택적 스플라이싱이다 | 0 |  |
| 1 | 가운데 선반은 ○ △ ☆ 셋이고 끝에 연장 하나(둥근 나무 손잡이 + 민 나무 자루 + 납작한 쇠 날) · 아래 선반은 ○ □ ☆ 셋이고 끝에 연장 하나(같은 손… | 선택적 RNA 스플라이싱: 하나의 유전자에서 엑손 조합을 달리해 여러 폴리펩타이드를 만드는 것. DNA가 달라진 것이 아니라 자를 자리를 달리 잡은 것이다 — 그래서 가위가 맨 위 선반에만 놓여 있다 | 1 |  |
| 2 | ★ 둘 다 ○로 시작해 ☆로 끝나는데 가운데 한 조각만 다르다 — 연장 둘도 똑같이 생겼다: 둥근 나무 손잡이와 납작한 쇠 날은 같고 가운데 자루 한 마디만 다르… | 도메인: 단백질 안에서 특정 기능을 담당하는 구조적 단위. 조각 하나가 기능 하나를 맡기에 가운데 부품만 갈아 끼워도 하는 일이 통째로 바뀐다 | 2 |  |
| 3 | 맨 위 띠에서 청록 조각들 사이에 회색이 길게 벌어져 있다 · 가위는 그 위에 놓여 있다 | 인트론이 엑손 사이 거리를 늘려 놓는다. 사이가 넓으면 가위가 들어갈 자리도 넓다 — 유전자에서도 그만큼 교차(재조합)가 일어날 확률이 높아져 엑손 셔플링이 쉬워진다 | 2 |  |
| 4 | ★ 원본은 하나인데 선반 아래로 연장이 둘 나온다 | 유전자 수보다 훨씬 다양한 단백질이 만들어진다. 사람이 적은 유전자 수로도 복잡한 몸을 갖는 큰 까닭이 선택적 스플라이싱이다 | 3 |  |
