# s07 호르몬 본사 빌딩 — 41·45 내분비


## s07p01 옥상과 두 경로
> 뇌하수체에서 호르몬이 나가는 길을 문맥(혈관)이냐 축삭이냐로 갈랐다. 전엽은 혈관으로 방출호르몬을 받아 스스로 합성해 내보내고, 후엽은 시상하부에서 만든 것을 축삭으로 받아 저장했다 내보낼 뿐이다.

| # | 소품(그림) | 사실 | 카드 | 과 |

## s07p03 갑상선 층
> 갑상선의 핵심은 내보낼 때와 쓸 때가 다르다는 것이다. 많이 나가는 쪽이 활성형이 아니라, 표적에서 한 조각 떼어내야 비로소 힘을 쓴다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 벽 바깥에 걸쳐 있는 수영장 | 콜로이드 — 세포 밖에 저장한다 | 0 |  |
| 1 | 결정을 붓는 트럭 | 요오드 | 1 |  |
| 2 | 2×2로 박힌 둥근 버튼 넷 · 그 방 천장에서 나온 팔이 줄을 쥐고 흰 자갈 바구니를 위로 끌어올린다 — 그 곁에 위를 가리키는 굵은 화살표 | 부갑상선 4개 · 부갑상선호르몬이 혈중 칼슘을 올린다. 이 덱에서 자갈은 언제나 Ca²⁺다(s16p02b 예약) ★ 화살표 둘이 반대로 선 것이 곧 길항이다 — 이 방의 바구니는 올라가고(부갑상선), 오른쪽 아래 갑상선 쪽 바구니는 내려간다(칼시토닌). 기출은 이 둘을 바꿔 낸다 ★ 부갑상선이 만지는 것은 자갈뿐이다 — 결정(요오드)도 수영장(콜로이드)도 건드리지 않으니 혈당과는 아무 상관이… | 4 |  |
| 3 | 위층 왼쪽 — 코트 없이 바로 망치질하는 인부 · 곁의 결정 넷 단 코트 입은 사람(T4 포장)과 달리 포장을 벗은 활성형 | T3 — 활성형 | 3 |  |

## s07p04 부신과 로비
> 부신은 겉과 속이 완전히 다른 장기다. 겉껍질은 스테로이드를 만들어 천천히 오래 작용하고, 속은 신경 자극에 즉시 반응한다. 층으로 그려야 이 이질성이 보인다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 구불구불한 호스로 천천히 오는 세 층 · 바깥에 늘어진 호스 끝은 놋쇠 마개다 — 전선이 아니다 | 부신피질은 ACTH라는 호르몬 신호를 받아 느리게 작동한다 | 0 |  |
| 1 | 맨 위층 — 쓰러진 소금통에서 흰 알갱이가 쏟아졌고, 인부가 솔로 그것을 쓸어 도로 통에 담고 있다 | 알도스테론 — Salt (사구대). ★ 알갱이를 도로 담는 것이 곧 이름이다 — 알도스테론. 그리고 하는 일도 그림 그대로다 — Na⁺를 도로 거둬들인다(재흡수). 쏟는 것이 아니라 담는 쪽인 것이 요점이다 | 5 |  |
| 2 | 가운데 층 — 층층 케이크 옆에 케이크만 한 코르크 마개가 서 있다 | 코르티솔 — Sugar (다발대). ★ 코르크가 곧 이름이다 — 코르티솔. 게다가 코르크(cork)와 코르텍스(cortex, 겉껍질·피질)는 같은 뿌리라, 이 마개 하나가 「부신피질」까지 나른다. 케이크가 당(糖)이다 | 3 |  |
| 3 | 아래층 — 빨간 하트 옆에 작은 양철 로봇 인형이 서 있다 (네모 머리에 안테나) | 안드로겐 — Sex (망상대). ★ 로봇이 곧 이름이다 — 안드로이드. 하트가 성(性)이고, 부신에서 나오는 것은 약한 남성호르몬이라 정소에서 나오는 것과는 세기가 다르다 | 1 |  |
| 4 | 호스와 달리 곧게 뻗어 세 층을 건너뛰고 지하로 직통하는 굵은 검은 전선 케이블 | 부신수질은 신경 자극을 직접 받는다. 구불구불한 호스(호르몬)와 곧은 케이블(신경)이 형태부터 다르다 ★ 덱의 문법 그대로다 — 물 호스·수도관은 피(호르몬)가 오는 길, 검은 전선은 신경이다(s07p01) | 2 |  |
| 5 | 케이블을 잡아당기자 드럼통의 뚜껑이 한꺼번에 터져 날아감 | 에피네프린·노르에피네프린이 즉시 분비된다. ★ 뚜껑이 터진 드럼통이 이 덱의 에피네프린이다 — 9-1c 전화국 창구 앞에 손님으로 서 있고, 혈당 마을 「올리는 손은 넷」에서 넷째 홈통 위에 서서 포도를 솟구쳐 낸다. ★ 터진다는 것이 급할 때 한꺼번에 쏟아 낸다는 뜻이다 — 같은 드럼통에서 나온 것이 수용체에 따라 심장·기관지·혈관에서 다른 반응을 낸다 | 3 |  |
| 6 | 옥상에서 유일하게 케이블이 없는 시계 | 송과선은 뇌하수체 조절을 받지 않는다 | 0 |  |
| 7 | 옥상 하늘의 해 | 송과선은 빛을 따른다 | 1 |  |
| 8 | 지붕 위 — 케이블 없는 시계 왼쪽에 놓인 그물무늬 멜론 하나 | 멜라토닌 — 멜론이 곧 이름이다. 곁의 시계가 생체리듬·수면 조절을, 하늘의 해가 빛을 나르고(밤에 분비가 는다). 뜻은 시계와 해가 지고 이름만 이 멜론이 진다 | 1 |  |
