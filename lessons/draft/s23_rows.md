## s23p01 문 세 개의 상태
> 셋째 문이 열려 있으면서 동시에 막혀 있는 게 핵심이다. 닫힌 것(휴지)과 다르다. 안쪽 마개가 물리적으로 구멍을 막고 있어 아무리 세게 밀어도 안 되는데, 그것이 절대 불응기의 정체다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 굳게 닫힌 문 | Na⁺ 채널 휴지 상태 | 7 |  |
| 1 | 활짝 열려 사람이 우리 쪽으로 밀려듦 — 문 위 벽시계는 12시 정각 | 활성 상태 — 탈분극. ★ Na⁺ 는 들어온다(벽 이쪽 = 세포 안) | 4 |  |
| 2 | 열려 있는데 안쪽 마개가 막음 | 불활성 상태 — 문이 닫힌 것과 다르다 | 4 |  |
| 3 | 밀어도 꿈쩍 않는 사람 | 절대 불응기 — 아무리 센 자극도 새 활동전위를 못 만든다 | 9 |  |
| 4 | 벽시계가 2시를 가리키는 둥근 아치 — 칼을 든 요리사들이 등을 보이며 벽 너머로 걸어 나간다 | 지연 정류성 K⁺(칼) 채널 — 재분극. ★ Na⁺ 무리는 우리 쪽으로 들어오고 K⁺ 는 등을 보이며 나간다 — 같은 벽에서 방향이 반대다. ★ 둘째 문 위 12시, 아치 위 2시 — Na⁺ 문보다 늦게 열린다 | 6 |  |

## s23p02 아세틸콜린 수용체 두 종류
> 두 창구의 차이는 뒤에 문이 있는가다. 레버 바로 뒤에 문이 있으면 이온이 직결로 흐르고, 문이 없으면 주자가 먼 방까지 가야 한다. 먼 방이 둘인 것은 표적 조직이 둘이라는 뜻이다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 똑같이 생긴 둥근 열쇠가 양쪽 열쇠구멍에 하나씩 꽂혀 있다 | 같은 아세틸콜린인데 결과가 갈린다 — 정하는 것은 수용체다 | 1 |  |
| 1 | 왼쪽 — 슬롯이 문에 직접 달려 그 자리에서 열림 · 열린 창살 곁으로 흰 소금 결정이 쏟아져 든다 · 그 바닥에 열린 담뱃갑 하나 | 니코틴성 nAChR — 리간드개폐 이온채널 직결, 즉각 반응 ★ 쏟아져 드는 것이 흰 소금(Na⁺)이다 — nAChR 은 양이온 통로이고 탈분극을 만드는 것은 주로 Na⁺ 유입이다. 자갈(Ca²⁺)이 아니다 | 3 |  |
| 2 | 불끈 선 근육 팔 | 골격근 신경근접합 — 니코틴성이 있는 두 자리 중 하나 | 0 |  |
| 3 | 왼쪽 아래 — 같은 직결 문 장면이 한 번 더. 근육 팔은 없고, 대신 두 번째 사람이 제 열쇠로 제 문을 연다 | 자율신경절 — 절전이 낸 ACh가 절후의 니코틴 수용체를 연다 | 0 |  |
| 4 | 오른쪽 — 열쇠구멍판이 맨 벽에 홀로 붙어 뒤에 문이 없다 · 복도가 끝에서 둘로 갈라짐 · 그 앞 바닥에 붉은 갓에 흰 점이 박힌 버섯 하나 | 무스카린성 mAChR — GPCR 경유(2차 전령), 느리고 길다 | 1 |  |
| 5 | 복도를 달리는, 둥근 원반을 든 주자 | 2차 전령이 먼 표적까지 달려간다 — 직결이 아니다 | 0 |  |
| 6 | 손으로 붙잡아 늦추는 진자 — 그 손은 손가락 둘만 곧게 펴서 공을 눌러 세운다 | M2 — 심박 감소 | 0 |  |
| 7 | 손이 목을 쥐어짜는 물자루 + 떨어지는 물방울 — 그 손은 손가락 셋으로 쥔다 | M3 — 평활근 수축 · 샘 분비 촉진 | 0 |  |

## s23p03 아드레날린 수용체 격자
> 2×2 자리가 곧 이름이다. 왼쪽 열이 α, 오른쪽 열이 β이고, 칸마다 선반 위의 흰 알(α)·개어 둔 흰 베(β)와 그 개수(1·2)가 이름을 그대로 나른다. 각 칸의 동작이 그 수용체의 작용이다. 옆 패널의 진자를 늦추던 것과 여기서 빠르게 하는 것이 부교감과 교감의 길항이다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 2×2 격자 틀 자체 (왼쪽 열 α · 오른쪽 열 β) · 칸마다 벽 높이 작은 선반 하나 — 왼쪽 열 선반엔 흰 알, 오른쪽 열 선반엔 개어 둔 흰 베 · 윗줄… | 네 칸 모두 교감 절후의 노르에피네프린 수용체 ★ 이름은 선반 위 물건이 나른다 — 알이면 α(알파 → 알), 베면 β(베타 → 베), 하나면 1, 둘이면 2. 덱 글자사전 그대로다(s49p01 창턱의 알·베, s14p02 굵은 관 발치의 알·베와 같은 물건) | 3 |  |
| 1 | 좌상 — 굵은 관을 띠로 조임 · 선반에 흰 알 하나(α₁) | α₁ — 혈관 평활근 수축 (같은 평활근도 β₂는 이완) | 1 |  |
| 2 | 좌하 — 자기 입을 막고 확성기는 방치 · 선반에 흰 알 둘(α₂) | α₂ — 신경 말단에 붙어 자기 분비를 줄인다(음성 피드백) | 0 |  |
| 3 | 우상 — 크랭크로 진자를 빠르게 · 선반에 개어 둔 흰 베 하나(β₁) | β₁ — 심박 증가 | 2 |  |
| 4 | 우하 — 접힌 관을 벌리개로 펼침 · 선반에 개어 둔 흰 베 둘(β₂) | β₂ — 기관지 확장·평활근 이완 (교감 흥분 때 숨관이 넓어지는 칸) | 1 |  |
