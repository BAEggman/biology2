## s22p01 세포 세 종류
> 세 건물의 차이는 벽 두께와 사람 유무다. 벽이 두꺼운데 아무도 없으면 죽은 세포다. 오른쪽 두 관도 같은 원리인데, 사람이 없는 관은 물관이고 머리 없이 앉아 있는 관은 체관요소다.

|---|---|---|---|---|
| 0 | 얇고 고른 벽 + 사는 사람 | 유조직 — 살아 있고 1차벽만 | 2 |  |
| 1 | 모서리만 두꺼운 벽 + 사는 사람 | 후각조직 — 살아 있고 모서리가 두꺼운 1차벽 | 3 |  |
| 2 | 두꺼운 석벽에 균열, 안이 텅 빔 | 후벽조직 — 죽은 세포, 리그닌 2차벽 단단한 지지가 일이라 석세포(sclereid)와 섬유(fiber) 두 모양으로 나온다 — 벽이 두꺼운데 사람이 없는 것이 「죽어서야 제 일을 한다」이다 | 3 |  |
| 3 | 끝벽이 없고 아무도 없는 넓은 관 | 물관 — 죽은 빈 관 | 3 |  |

| 5 | 옆방의 조수 — 체관요소 셋 모두 곁에 옆방이 하나씩 붙었다 | 반세포 — 체관요소마다 하나씩 붙는다 | 2 |  |

|---|---|---|---|---|

| 1 | 아파트 문을 열고 집 안을 질러가는 길 — 문이 하나같이 장식 없는 심플한 민짜다 | 심플라스트 경로 | 2 |  |

## s22p02b 자루를 실으면 물이 따라 든다
> ★ 당이 아니라 물이 압력을 만든다. 자루를 밀어 넣자 옆 도랑 물이 쇠살문으로 빨려 들고, 그래서 왼쪽 끝이 항아리처럼 빵빵해진다. 오른쪽은 자루를 내려 가늘다. 그 굵기 차이가 곧 압력차이고, 자루는 굵은 쪽에서 가는 쪽으로 밀려간다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | ★ 왼쪽 — 큰 잎 아래에서 인부들이 자루를 관 속으로 힘껏 밀어 넣는다 | 공급원(source)은 다 자란 잎이다 — 제 몫보다 많이 만들어 내보내는 쪽. 밀어 넣는 힘이 곧 능동수송이다. 당은 저절로 체관에 들어가지 않는다 | 2 |  |
| 1 | ★ 자루가 들어가자 옆 도랑 물이 관 밑의 쇠살문으로 빨려 든다 · 물길의 화살표는 모두 관 쪽을 향한다 — 짐이 실려 진해진 관이 물을 끌어들이는 것 | 당이 실리면 체관 속이 진해져 용질 퍼텐셜이 낮아진다. 낮아진 만큼 물이 삼투로 들어온다 — ★ 당은 물을 부르는 미끼이지 미는 힘이 아니다 | 2 |  |
| 2 | ★ 왼쪽 끝이 항아리처럼 빵빵하게 부풀어 자루와 물로 꽉 찼다 | 들어찬 물이 압력을 올린다. 체관이 양압인 까닭이 이것이다 — 위에서 잡아당기는 물관의 음압과 정반대다 | 2 |  |
| 3 | 오른쪽 — 인부들이 자루를 꺼내 비운다 | 당 하역. 받는 쪽에서는 당을 내려 쓰거나 쌓아 둔다 | 1 |  |
| 4 | ★ 오른쪽 관은 왼쪽 항아리처럼 부풀지 않고 가늘다 — 끝까지 같은 굵기로 가다 둥글게 막혔다(관 끝으로 쏟는 것이 아니라 옆구리로 내린다) | 하역하면 물도 따라 빠져 압력이 내려간다 — 하역이 압력을 올린다고 쓰면 틀린다 | 1 |  |
| 5 | ★ 자루가 부푼 쪽에서 가는 쪽으로 밀려간다 — 관의 굵기 차이가 곧 압력차다 | 압류설(pressure-flow hypothesis). 적재 → 용질 퍼텐셜↓ → 물 유입 → 압력↑ → 압력차를 따라 수용부로 흐름 → 하역 → 압력↓. 이 한 바퀴가 체관 수송의 기작이다 | 3 |  |
| 6 | ★ 받는 통이 넷 — 굵은 뿌리 다발 · 붉은 열매 · 울퉁불퉁한 덩이줄기 · 아주 작은 새싹 잎 · 자루가 그 위로 쏟아져 나온다 | 수용부(sink)는 뿌리 · 열매 · 어린 잎 · 덩이줄기다 — 당을 쓰거나 저장하는 쪽. 셋만 외우면 어린 잎에 걸린다 | 1 |  |
| 7 | ★ 왼쪽 큰 잎과 오른쪽 작은 잎이 같은 모양이다 | 같은 잎인데 다 자란 것은 주고 어린 것은 받는다. 공급원·수용부는 자리 이름이 아니라 역할 이름이라 봄의 덩이줄기처럼 뒤바뀔 수도 있다 | 1 |  |

## s22p03 뿌리혹과 균근
> 뿌리혹은 양쪽이 신호를 주고받은 뒤 생긴다. 한쪽만 부르는 게 아니라 서로 확인한다. 혹 안 인부의 밀폐 헬멧은 질소고정효소가 산소를 만나면 망가지기 때문이다.
