# s34 씨앗 공방 — 38 속씨식물 생식


## s34p01 위층 — 꽃가루 작업대
> 꽃밥 속을 공방의 위층으로 잡았다. 소포 더미를 올려다보는 큰 사람이 소포자모세포, 소포 더미에 앉은 작은 사람 넷이 소포자다. 같은 층 작업대의 알갱이 속은 머리는 셋인데 세포는 둘이다 — 외투 하나에 머리 둘이 아직 안 갈라진 생식세포다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 빈손으로 소포 더미를 올려다보는 훨씬 큰 사람 | 소포자모세포(microsporocyte, 2n)가 감수분열에 들어간다. 빈손인 것은 자기 몫이 남지 않기 때문이다 ★ 이 방을 왼쪽에서 오른쪽으로 읽으면 계보가 한 줄이다 — 소포자모세포(2n) → 소포자(n) 4개 → 화분립 → 생식세포 → 정자 2개 | 2 |  |
| 1 | 소포 더미 위에 앉은 작은 사람 넷 — 맨 위 소포에 셋, 아래 소포에 하나 · 소포는 다 성하다 | 감수분열 산물은 소포자(microspore, n) 4개. 세는 것은 소포가 아니라 사람이다. 넷이 다 사는 것이 배낭(대포자 1개만 생존)과 갈리는 자리다 ★ 소포가 곧 이름이다 — 소포자 | 5 |  |
| 2 | 알갱이 속 — 몸은 둘이다: 관을 멘 하나 · 외투 하나에 머리 둘(단추를 끝까지 채운 외투에서 머리 둘이 나란히 나온다) | 소포자가 체세포분열 한 번 → 세포는 둘(관세포 + 생식세포) = 수배우체. 외투 하나에 머리 둘인 것은 생식세포가 아직 정세포 둘로 안 갈라졌다는 뜻이다 | 7 |  |
| 3 | 겉이 오톨도톨한 두꺼운 껍질이 통째로 벗겨져 옆에 놓임 | 화분벽. 2세포(수배우체)에 이 벽까지 씌운 것이 화분립(pollen grain)이다 | 2 |  |
| 4 | 어깨에 멘 긴 속 빈 관 | 관세포(tube cell) → 화분관. 이름이 곧 물건이다 — 정자를 만드는 쪽이 아니다 | 3 |  |
| 5 | 맨 오른쪽 — 얼굴도 옷도 똑같은 작은 둘(큰 사람과 같은 붉은 조끼이지만 키가 작다) — 외투 속 머리 둘(3행)이 갈라져 나온 정자 둘이지, 큰 사람의 분신이… | 생식세포(generative cell)가 수분한 뒤 체세포분열 → 정자 2개. 하나가 갈라진 것이라 둘이 똑같다 — 화분관을 만드는 쪽이 아니다 | 4 |  |

## s34p02 아래층 — 배낭 방
> 위층에서 내려오면 씨방 속 밑씨다. 이 방이 암배우체(배낭)이고, 문이 하나뿐이라 방 전체에 좌표가 생긴다 — 문 쪽에 셋, 가운데 바구니에 둘, 문 반대편 벽에 셋. 기출이 묻는 것은 거의 다 「어느 쪽이냐」다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 아치를 두 겹으로 두른 돌벽, 왼쪽 끝에 난 좁은 문 하나 | 밑씨를 감싸는 주피 2겹(→ 나중에 종피)과 그 틈인 주공(珠孔, micropyle = 작은 문). 문이 하나뿐인 것이 이 방의 좌표축이다 | 2 |  |
| 1 | 왼쪽 끝의 대포 넷 — 셋은 검게 타 주저앉았고 하나만 온전히 서 있다 | 대포자모세포(2n) 감수분열 → 대포자 4개, 보통 1개만 생존하고 3개는 퇴화. 위층 소포자가 넷 다 사는 것과 정반대다 ★ 대포가 곧 이름이다 — 대포자. 소포자(소포)가 넷 다 사는 것과 정반대로, 여기서는 하나만 산다 ★ 이 방의 계보도 한 줄이다 — 대포자모세포(2n) → 대포자 4개(1개만 생존) → 체세포분열 3회 → 8핵 7세포의 배낭. 넷 중 셋이 타 버린 것이 그 시작이다 | 10 |  |
| 2 | 문 바로 안쪽 — 걸상에 앉은 청록 옷 하나를 양옆 회색 옷 둘이 무릎 꿇고 떠받든다. 하나는 쟁반을 받쳐 들고, 하나는 팔을 뻗어 문 쪽 길을 가리킨다 | 주공 쪽에 난세포 1 + 조세포 2. 손짓하는 둘이 조세포(助細胞)로, 문 쪽으로 화분관을 유인·유도한다 ★ 도울 조(助)가 곧 동작이다 — 무릎 꿇고 시중드는 둘이 조세포, 가만히 앉은 하나가 난세포다 ★ 옷 색이 곧 답이다 — 34-3 과 같은 규칙으로 이 공방의 청록 옷은 난세포이고 이 방에서 그 하나뿐이다. 조세포·반족세포는 회색이다 | 3 |  |
| 3 | 큰 바구니 하나에 나란히 앉은 겨자색 옷 둘 | 중앙세포는 하나인데 그 안에 극핵이 둘 — 8핵인데 세포가 7인 이유가 이 바구니다. 배젖이 3n인 이유(정자 n + 극핵 n + 극핵 n)도 여기서 나온다 ★ 겨자색이 극핵이다. 수정 전이라 이 방에는 붉은 옷(정자)이 아직 없다 — 34-3 에서 붉은 옷 하나가 이 바구니로 들어가 앉아 셋이 된다 | 7 |  |
| 4 | 문에서 가장 먼 벽에 등을 붙이고 앉은 회색 옷 셋 — 둘은 통나무 위, 하나는 통나무 끝에, 셋 다 맨발 | 반족세포(反足細胞, antipodal) 3개 — 주공 반대편. 앉은 자리가 갈려도 셋은 각각 다른 세포다. 기능은 미상이고 수정에 참여하지 않는다 (BM하 #1024 영남대) ★ 반족(反足)은 자리다 — 문(주공)의 정반대 끝에 붙어 있다 | 2 |  |

## s34p03 화분관 길 — 두 곳으로 갈라진다
> 위층 관이 여기까지 내려왔다. 정자 둘이 서로 다른 두 곳으로 간다 — 하나는 문 쪽 난세포와 손을 맞잡아 2n이 되고, 하나는 바구니로 들어가 앉아 3n이 된다. 이 방에서 붉은 옷은 정자뿐이다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 벽을 가로질러 뚫린 네모난 구멍 하나 — 관 위아래로 빈 곳이 보인다 | 화분관은 주피를 뚫고 들어오는 것이 아니라 이미 나 있는 주공(珠孔)으로 들어온다. 아래층에서 좌표축이 되었던 그 문이다 | 0 |  |
| 1 | 관 바깥 끝 — 얕은 접시 위에 앉은 오톨도톨한 알갱이 | 수분(受粉)은 화분립이 암술머리에 닿는 것까지다. 화분관은 거기서 자라 나와 암술대를 지나 내려온다 — 수분과 수정은 다른 사건이다 | 3 |  |
| 2 | 문 안쪽 회색 옷 둘 — 하나는 팔을 들어 관을 불러들이고, 하나는 그 곁에 쓰러져 있다 | 조세포 2개가 화학물질로 화분관을 유인한다. 관이 도착하면 조세포 하나가 죽고 그 자리가 정자 2개가 나올 통로가 된다 | 0 |  |
| 3 | 이 방에서 붉은 옷을 입은 사람은 딱 둘 — 하나는 문 쪽에, 하나는 바구니 안에 | 정자 2개. 예비가 아니라 서로 다른 두 곳으로 간다 (BM하 #1023 삼육대) | 1 |  |
| 4 | ★ 문 쪽 붉은 옷 하나가 가만히 선 청록 옷과 두 손을 맞잡음 — 이 방에서 청록 옷은 이 여자 하나뿐이다 | 정자(n) + 난세포(n) → 접합자 2n → 배. 난세포가 받는 정자는 하나뿐이다. 청록은 이 덱에서 늘 난세포다 | 3 |  |
| 5 | 바구니 안이 셋이 됨 — 겨자색 둘에 붉은 옷 하나가 들어가 앉았다 | 겨자색 둘이 극핵이다. 정자 n + 극핵 n + 극핵 n → 배젖 3n. 종자에서 3n인 것은 배젖 하나뿐이다 | 4 |  |
| 6 | 먼 오른쪽 벽에 앉은 회색 옷 셋 — 아무것도 하지 않는다 | 수정에 참여하는 것은 난세포와 극핵 2개뿐이다. 조세포도 반족세포도 참여하지 않는다 | 1 |  |

## s34p04 종자 창고 — 갈라 보면 셋이다
> 수정이 끝난 밑씨를 갈라 보면 셋이다 — 두 겹 가죽 = 종피(2n) · 아이 = 배(2n) · 겨자색 자루 = 배젖(3n). 가운데 껍질은 떡이 둘에 자루가 하나도 없고(쌍자엽), 오른쪽 껍질은 떡이 하나에 자루가 셋 남았다(단자엽).

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 왼쪽 — 두 겹 가죽으로 싸서 끈으로 묶은 껍질 — 위 꼭지 곁에서 바깥 갈색 가죽이 젖혀져 그 밑의 밝은 속 가죽이 보인다. 갈라 놓은 둘과 크기도 모양도 같다 | 종자는 밑씨가 통째로 자란 것이다. 겉을 싼 두 겹이 종피(種皮) — 아래층 방의 주피 2겹이 그대로 굳은 것이라 모체의 몸, 곧 2n이다 | 3 |  |
| 1 | 갈라 놓은 껍질 안에 앉은 아이 — 청록 윗도리에 붉은 바지 | 배(胚). 청록(난세포)과 붉은색(정자)이 한 몸에 있는 것이 곧 접합자 2n이다. 아이가 껍질 밖이 아니라 안에 있는 것이 「배는 종자의 일부」라는 뜻이다 | 1 |  |
| 2 | 가운데 껍질 — 흰 떡 두 장, 그 밖에는 텅 비었다 | 쌍자엽 종자. 자엽(떡잎)이 2개이고 배젖을 흡수해 자엽에 저장한다 — 그래서 자루가 하나도 안 남았다 (콩) | 4 |  |
| 3 | 오른쪽 껍질 — 흰 떡 한 장, 그 뒤로 겨자색 자루 셋이 껍질을 채우고 있다 | 단자엽 종자. 자엽이 1개(scutellum)이고 배젖을 그대로 남긴다 — 그래서 자루가 남아 있다 (옥수수) | 4 |  |
| 4 | 자루가 하나도 둘도 아니고 셋인 것 | 배젖(胚乳)이다. 겨자색은 아래층 바구니(극핵)에서 그대로 온 색이고 셋인 것은 정자 n + 극핵 n + 극핵 n = 3n이라서다 | 3 |  |
| 5 | 바닥 통의 물에 잠겨 부푼 껍질 — 아래로 굵은 뿌리 하나만 나왔고 위로는 아무것도 없다 | 발아: 흡수(imbibition)로 부풀고 → 유근이 먼저 아래로 → 그 다음 떡잎. 위가 비어 있는 것이 곧 순서다 | 4 |  |

## s34p05 검문소 — 닮았으면 못 들어온다
> 암술머리에 검문소가 있다. 문지기와 같은 모자를 쓴 것만 막고, 다른 모자는 그냥 지나간다 — 자가불화합성은 낯선 것이 아니라 자기를 거부한다. 왼쪽 문지기는 껍질 속 사람의 모자를, 오른쪽 문지기는 껍질 위에 얹힌 모자를 본다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 문지기 둘이 나란히 쓴 뾰족한 고깔모자 — 이 모자가 이 문의 기준이다 | 암술 쪽이 들고 있는 S 대립유전자. 옷이 돌색인 것은 차단하는 것이 배낭이 아니라 암술머리·암술대의 모체(2n) 조직이기 때문이다 | 0 |  |
| 1 | 가운데 — 납작한 모자를 쓴 하나만 아무도 안 막고 문을 지나간다 | 자가불화합성은 자기 화분을 거부해 타가수정을 강제하는 장치다. 표가 다르면 통과한다 | 1 |  |
| 2 | 막히는 쪽이 낯선 쪽이 아니라 문지기와 닮은 쪽이다 — 이 판에 동물 면역(낯선 쪽을 막는 쪽)은 안 그려져 있다 · 견줌은 말로만 | 식물 자가불화합성은 자기(自己)를 거부하고, 동물 면역은 비자기를 거부한다 — 정확히 반대다 | 4 |  |
| 3 | 왼쪽 — 껍질이 열려 속 사람이 문지기와 똑같은 고깔모자를 썼고, 문지기가 그 모자를 손가락으로 가리킨다 | 배우체형(gametophytic). 화분 자신의 반수체 S 대립유전자가 차단을 결정한다 | 2 |  |
| 4 | 오른쪽 — 껍질이 닫혔고 고깔모자가 껍질 위에 얹혀 있다. 창으로 보이는 속 사람은 납작한 모자인데도 막힌다 | 포자체형(sporophytic). 화분벽에 묻은 포자체(2n) 조직의 S 산물이 차단을 결정한다 — 속이 달라도 껍질이 같으면 막힌다 | 2 |  |

## s34p06 접붙이기 마당 — 열매는 위가 정한다
> 굵고 검은 밑둥 하나에 흰 가지 둘을 끈으로 감아 붙였더니 한 나무에서 사과와 배가 같이 난다. 밑둥에는 열매가 하나도 없다 — 열매를 정하는 것은 아래(대목)가 아니라 위(접수)다.

| # | 소품(그림) | 사실 | 카드 | 과 |
|---|---|---|---|---|
| 0 | 굵고 검은 밑둥 하나에 끈으로 감아 붙인 흰 가지 둘 | 접목(grafting) = 대목(臺木, stock — 뿌리를 대는 아래) + 접수(接穗, scion — 붙이는 위 가지). 감은 끈이 이음매다 | 1 |  |
| 1 | 왼쪽 접수에는 붉은 사과, 오른쪽 접수에는 노란 배. 밑둥에는 열매도 잎도 하나 없다 | 한 나무에서 서로 다른 열매가 난다. 아래가 같은데 위가 다르면 열매가 다르다는 뜻이다 | 0 |  |
| 2 | 뒤의 작은 나무 둘 — 왼쪽은 사과, 오른쪽은 배를 달았고 각각 가지 끝이 여럿 하얗게 잘려 있다 | 접수를 떼어 온 나무다. 큰 나무의 열매가 이 나무들의 열매와 같다 — 열매의 질은 접수(scion)의 유전자가 결정한다. 대목은 뿌리와 병저항을 댈 뿐이다 | 1 |  |
| 3 | 화분에 꽂은 잘린 가지 — 묻힌 끝이 울퉁불퉁하게 부풀었고 거기서만 뿌리가 난다 | 꺾꽂이(cutting). 상처 끝에 캘러스(callus)가 생기고 거기서 뿌리가 난다. 가지의 다른 데서는 나지 않는다 | 1 |  |
| 4 | 그 혹이 따로 붙인 알뿌리가 아니라 가지 자신이 부푼 것이다 | 캘러스는 미분화 전능세포 덩이다. 식물 세포가 흔히 전능성(totipotency)을 가져 한 조각이 완전한 개체가 된다 | 1 |  |
