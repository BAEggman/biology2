## 1. 덱 문법(이어 쓴 것 · 새로 정한 것)
- 【짚 다발을 끼운 은빛 쇠 고리】 = 코헤신 — 춤판 짚단(두 다발 = 자매)의 팔 고리가 끊겨 C 자 조각으로 튐(후기 I) · 허리 고리만 남음(→ L48g).
- 【헛간 벽에 박힌 검은 쇠고리(밧줄이 나옴)】 = 극 · 삼밧줄 = 방추사 — 춤판 왼쪽 기둥 · 오른쪽 벽. 굴렁쇠 = 그 쇠고리가 양쪽으로 굴러가는 중(중심체 이동).
- 돔 천막 = 핵 — 앞을 잘라 낸 커다란 천막 안에서 전기 I(혼례) · 오른쪽 옆구리가 찢겨 이동기.
- 새로: 남색 짚단(검은 실크해트 신랑) = 아버지 쪽 · 하늘색 짚단(흰 면사포 신부) = 어머니 쪽(옛 s47p01 의 짙은 · 옅은 실). 엮은 짚 띠 = 접합사(【지퍼】는 DNA 라 쓰지 않음). 이발사의 끝 바꿔 꽂기 = 교차. A 자 + 꼭대기 X = 키아즈마. 외바퀴 수레 = 이동기. 줄다리기 = 방추장치가 당김. 판자 칸막이 + 뚜껑 문 = 세포질분열 · 딸세포 둘(아래층 = 감수 II).
- ⚠ 판자 칸막이는 L48b 창고의 공중 널빤지(식물 세포판)와 꼴 · 자리를 달리했다 — 이쪽은 바닥 앞 가장자리에서 들어오는 낮은 울(「방이 둘로」만 나른다). 동물 · 식물 가르기는 L48b.
- ⚠ 독립 분리의 동전 던지기는 쓰지 않는다(금화 · 동전 = ATP) → L48g 짚 제비뽑기. 큰 쌍(남색 왼쪽) · 작은 쌍(하늘색 왼쪽)을 일부러 반대로 세웠다(방향은 쌍마다 따로).
