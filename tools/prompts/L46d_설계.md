# L46d 꽃밭 물 대기와 흰 배수관 — 혈압 조절 · 모세혈관 교환 · 림프 (2026-11-11 · 새 과 ① 43 수송 첫 장)

## 왜
43장 부모 카드 중 혈압 조절(H0-91 ~ 103 · 285) · 모세혈관(H0-117 ~ 127) · 림프(H0-128 ~ 141) 37장이 어느 과에도 없었다(계획 G3 「꽃밭 물 대기와 흰 실개천」). 심장 집 세계(L46a 집 · L46b 뒤뜰 · L46c 부엌)의 뒤뜰을 한 장 더 잇는다 — L46b 가 「세 호스」(동맥 · 모세 · 정맥)의 꼴이었다면 L46d 는 「물을 어떻게 나누고 · 어디서 새고 · 누가 거두나」다.

## 이야기(틀)
작은 나무집(심장)이 진홍 호스로 물을 내보내 뒤뜰 꽃밭에 댄다. 갈래(세동맥)마다 굵기를 바꾸는 사람이 있고, 꽃밭의 가는 실관(모세혈관)은 입구의 입술(전 괄약근)이 물을 들이고 · 앞머리에서 새고(정수압) · 끝에서 앨범이 빨아들인다(알부민 · 교질삼투압). 다 못 거둔 물은 웅덩이로 고이고, 흙 속 흰 배수관(림프관)이 거둬 거름 탱크(림프절)를 지나 회청 호스(대정맥)로 합쳐 집으로 돌린다. 돌아오는 길은 오르막 — 판막 문과 종아리(제2의 심장)가 민다.

## 약속(덱 그대로 + 이 과)
- 덱: 나무집 · 노란 반달 = 심장 · 반달판막(L46a) · 진홍 / 회청 호스 = 동맥 / 정맥(L46b) · 바늘 압력계 = 혈압 · 유턴 금지 문 = 판막 · 입 달린 꽃이 흰 방울을 삼킴 = 조직과의 교환(L46b) · 밝은(흰) 방울 = O₂ · 알약꼴 초록 세균 = 세균 · 장난감 병정 = T 세포(L01d) · 흰 길 = 림프(L12b · L12e).
- 이 과(예약에 새로 적음): 비틀어 짜는 사내 = 엔도텔린(비「틀린」 → 텔린 · 수축) · 노 젓는 사람 = NO(노 · 이완 — 뒤의 근육 헬스장 평활근도 같은 사람) · 들썩이는 집 = 심박수 ↑ · 높은 걸상 위 졸졸 + 어지러운 정원사 / 누운 정원사 = 중력 · 눕힘 · 종아리의 나무집 문신 = 제2의 심장(이 세계의 심장 집 · 【빨간 하트】는 Sex 전용이라 하트를 쓰지 않음) · 실관 입구의 입술 = 전 괄약근(오므림 = 닫음) · 불붙은 성냥 = 히스타민(예약에 「불붙은 성냥은 히스타민 쪽」이라 미리 적혀 있었다) · 비눗방울에 싸인 큰 공 = 소낭 수송 · 사진 앨범 = 알부민(앨범 ↔ 알부민 — 종이가 물을 빨아들임) · 흰 배수관 = 림프관(끝 막힘 · 꽃잎 날개 구멍) · 매듭 + 퉁퉁 부은 다리 = 림프 막힘 → 부종 · 부푼 금속 거름 탱크 = 림프절.
- ⚠ 피한 것: 호스를 졸라맨 끈(TGF · L17) → 비틀기 · A 자 접이 사다리(【_글자모양사전】 A) → 높은 걸상 · 흰 알(α — 알 · 감 · 베, 뒤의 헤모글로빈 그림이 씀) → 앨범 · 나무 통(히스톤) · 콩 모양 통(L46c 미토콘드리아) → 금속 거름 탱크 · 꽃 도장 · 붉은 도장 없음.
