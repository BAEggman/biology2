## 약속 · 고리
- 덱 그대로: 섬 = 이자섬 · 개어 둔 흰 베 = β · 치켜든 주사기 = 인슐린 · 포도 = 포도당 · 수조 물높이 = 혈당 · 초록 띠 = 정상 구간 · **조끼 입은 사람 = T 세포**(s13p03 — 단추는 세어지게 그리지 않는다: CD4 · CD8 예약) · 노란 기름 덩이 = 지방.
- 새로: **제 섬 사람(조끼) 셋이 망치로 β 집을 부숨 = 자가면역** · **문손잡이 자리의 빈 구멍 = 인슐린 수용체 · 신호 경로 고장(저항성)** · **문 앞에 못 들어가고 쌓인 포도 = 고혈당** · **난로에서 타는 노란 기름 덩이 = 포도당 대신 지방을 땔감으로** · **넘친 포도가 흘러 나가는 돌 도랑 = 요당**.
- ⚠ 모자 금지(옛 판의 「납작모자」는 5′ 캡 예약과 부딪혀 「조끼만」으로 바꿈).
