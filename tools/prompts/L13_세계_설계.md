## 세계의 문법
- **성 = 몸.** 회색 돌 성벽 = 피부 · 점막(첫 장벽) — 붉은 벽돌 담(= 막 · 핵막)과 재료로 가른다. 성벽의 무너진 틈 = 장벽을 넘은 자리. 안뜰 = 조직. 오른쪽 깊은 곳의 내성(둥근 돌탑) = 적응 면역의 병영.
- **그림은 성 안에서 본다**(성벽이 위쪽 띠). 침입자는 틈으로 들어온다.
- 침입자 = 배지 없는 것: 화난 초록 알약 세균(꼬리 하나 = 편모 — 【웃는 초록 알약 세균】의 표정 문법) · 망토 두른 사람 + 흰 종이 두루마리(바이러스 — L03b).
- 주민(자기 세포) = 가슴에 붉은 꽃 배지(옛 s13p03 의 MHC I 배지 — 「자기」의 표지).
- **흰 옷 경비 = 백혈구**(L46e): 파리채 = 호중구 · 커다란 입의 둥근 흰 덩이 = 대식세포 · 작은 덩이(둥근 창 하나) = 단핵구 · 뚱뚱한 경비 + 불붙은 성냥 = 비만세포(히스타민) · 흰 옷 궁수 = NK(배지 없는 자만 쏜다 — 옛 s13p03#4. 초록 옷 · 깃 모자의 옛 궁수는 알려진 옛이야기 인물을 닮아 흰 옷 경비로).
- **장난감 병정 = T 세포** · 조끼 단추 넷씩 두 줄 = CD8(세포독성) · 한 줄 넷 = CD4(도움) · **장난감 벌 = B 세포** · 깃발 = 항체(옛 s13p01 · p02).
- 톨게이트 초소(Toll-like) = TLR · 초소의 수배 전단 = PAMP(공통 무늬). 전단의 그림: 꼬리(플라젤린) · 꽃 도장 없는 금빛 밧줄 토막(비메틸화 CpG DNA — 꽃 도장 = 메틸화 · 밧줄 = L01 의 DNA) · 두 겹 두루마리(dsRNA).
- 봉화(성벽 위 불 바구니) = 염증 · 열 · 인터폰 = 인터페론 · 도랑 셋 → 저수지(보 洑) → 물줄기 = 보체(옛 s13p03#0 · #1) — 구멍은 **침입자의 몸**에 뚫는다(옛 판은 성벽에 뚫었다 — 성벽은 제 몸이라 뜻이 어긋난다).
- ⚠ 피할 것: 투구 · 칼 · 창 · 방패의 병사(【로마 병정 투구 + 칼】 = ROMK · 【둥근 나무 방패】 = NADPH) · 모래시계는 4형 과민(옛 s13p02)의 몫 · 빨강 하양 줄무늬 차단기(L12f 식욕) → 초소의 가로대는 민 나무 · 끈적한 점액(믹소) · 금관악기 · 동전(ATP — 통행료를 동전으로 그리지 않는다) · 왕관(코로나).
