## 왜
L01a ~ c 는 볼티모어 군(배의 모양)을 가르지만 군 안의 가족 · 병(IV 군 폴리오 · 리노 · HAV / 황열 · 뎅기 · 지카 · HCV · V 군 볼거리 · VI 군 HIV · HTLV-1 · I 군 EBV · VII 군 HBV)과 종양 바이러스(I0-69)가 그림에 없었다(GPT 추가 감사 §2). 세 장에 더 싣지 않고(과적) 같은 항구에 한 장을 더 지었다.

## 약속(덱 그대로 + 이 과)
- 덱(L01a ~ c): 크림빛 창고 두루마리 = mRNA · 돌판 수 = mRNA 까지 걸음 · 금빛 꼰 밧줄 = dsDNA(외겹 = ssDNA) · 흰 종이 리본 = RNA · 작고 밋밋한 배 = 피코르나 · 노란 깃발 = 플라비 · 뒤집힌 배 = (−)RNA · 파라솔 = 파라믹소 · 반점 담요 = 홍역 · 거꾸로 댄 배 = 레트로 · 리본 → 밧줄 작업대 = 역전사 · 나비 = 파필로마 · 붉은 벽돌 건물 = 간 · 글자 꼴 물건(A 사다리 · B · C 갈고리).
- 이 과(예약에 새로 적음): 배 앞에 선 승객 = 그 무리의 바이러스 · 병 · 작은 검은 게 = 암 · 장난감 병정 = T 세포(부서짐 = HIV · 똑같은 떼 = HTLV-1) · 붉은 벽돌 인형집 = 간(A형 · C형 간염) · 통째로 벽돌로 쌓은 배 + B 돛 = B형 간염 · 한 토막만 외겹인 밧줄 = 틈 난 dsDNA · 돌판 두 장 = 두 걸음(틈 메우기 → 전사).
