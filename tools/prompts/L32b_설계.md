# L32b 「먹구름 낀 세 날 — 시럽 바퀴 · 구멍 난 담 · 봉한 넷째 집」 — 저해제와 짝풀림제 (2026-11-08 · 갈아엎기 74호)

> s32 둘째 과 — s32u01 행 13~20(8행 · 카드 10 · B1-142 셋 겹침) → 정거장 10. 장소: L32a 와 **같은 담장**의 먹구름 낀 다른 날 셋을 틀선으로 나눈 세 칸(덱 규칙 #118 「틀선 칸 = 같은 장면의 다른 날」). 왼 칸 = 시럽 바퀴(올리고마이신) · 가운데 칸 = 도깨비 드릴 구멍(DNP 짝풀림제) · 오른 칸 = 해골 미장이가 봉한 넷째 집(시안화물 · CO · 아자이드).
> 한 장면에 셋을 다 두면 결과가 서로 부딪힌다(구멍으로 새는데 물이 언덕처럼 솟을 수 없다) — 그래서 날을 가른다.

## 약속 · 고리(덱 그대로 + 새것)
- 덱 그대로(L32a): 붉은 벽돌 담장 = 내막 · 지붕 근육 팔 = H⁺ 펌프 · 담장 뒤 물 높이 = 기울기 · 돌 아치 + 물레방아 = ATP 합성효소 · 동전 쟁반 = ATP(빈 쟁반 = 0 · L31b) · 바위 수레(Q) · 상자 수레(cyt c) · 노란 공 = 전자 · 흰 방울 머리 = O₂ · 가득 찬 둥근 양동이 = NADH(L31c 양동이 탑과 같은 꼴).
- **금색 자물쇠 = 약물 · 독물**(덱 예약) — 막는 약 둘(올리고마이신 · 시안화물)에만 · 구멍(짝풀림제)에는 없다.
- 새로: **올리고당 시럽 = 올리고마이신**(시럽이 날개를 아치에 붙임 = 합성효소 자체를 막음) · **민머리 요리사**(모자 없음 — 모자는 5′ 캡 예약) · **붉은 도깨비의 손드릴 구멍 = 짝풀림제(DNP)** — 구멍은 아치가 아니라 **벽돌(막)**에 · 김 + 달아오른 테 = 열 · **해골 미장이 = 독(시안화물)** — 넷째 집 문을 벽돌로 봉함 = 복합체 IV 차단 · **돌로 굳은 수레 · 팔 = 전부 멈춤 · 운반체가 짐(전자)을 실은 채 = 환원 상태로 정체**.
