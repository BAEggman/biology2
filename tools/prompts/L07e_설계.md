# L07e 「관제탑이 파이프로 내려보내는 셋 — 가는 관이 덧문을 내린다」 — 시상하부 방출호르몬 셋과 음성 피드백 (2026-11-08 · 갈아엎기 66호)

> s07 다섯째 과 — 덱 데이터상 s48 묶음에 든 s07p05(5행 · 카드 9) → 정거장 7. 과 ID 는 내용대로 L07e(scene s07 · L19h 와 같은 처리). 장소: L07a 호르몬 본사 빌딩의 윗부분을 당겨 본 것 — 옥상 관제탑(시상하부) · 그 곁에서 위층으로 내려가는 굵은 파란 물 파이프(문맥 · 앞을 갈라 속을 보임) · 위층 창구(전엽 · 나비 접시 = TSH 창구) · 빌딩 바깥 오른쪽 벽을 타고 아래에서 올라오는 가는 붉은 관(되돌이 길).
> 옛 판의 「덧문 하나」를 둘로 — 파이프 입구 덧문(TRH)과 위층 나비 창구의 셔터(TSH). 카드 Q0-25 가 「음성 피드백으로 TRH · TSH 억제」를 같이 묻기 때문이다.

## 약속 · 고리
- 옥상 관제탑 관제사 = 시상하부(L07a) · 굵은 파란 물 파이프 = 문맥(L07a) · 위층 창구 = 전엽(L07b 일곱 창구).
- **똑같이 생긴 흰 낙하산 셋 = 방출호르몬(-RH)** — 놓아 내려보낸다 = 방출(release) · 낙하산이 똑같다 = 이름 끝이 같다 · 매달린 짐 = 앞 글자(표적).
- 나비 접시 = 갑상샘(→ TRH · 위층 나비 창구 = TSH · L07b) · 세 층 케이크 = 부신 피질(→ CRH · ACTH · L07b · L07d) · 리본으로 묶은 달걀 둘 = 생식샘(→ GnRH · 하나의 지시가 FSH · LH 둘을 켠다 · L07b 의 컵 속 달걀 둘).
- 빌딩 밖 아래에서 따로 올라오는 가는 붉은 관 = 되돌이 길(표적샘 호르몬이 온몸의 피를 돌아온다 · 내려간 길을 거꾸로 오지 않는다) · 관 속 보라 결정 = 요오드 든 갑상샘 호르몬(L07c 의 보라 결정).
- 가는 관 두 갈래가 덧문 둘을 반쯤 내리누름 = 음성 피드백 — T3 · T4 가 TRH(관제탑)와 TSH(위층 창구)를 함께 억제 · 반쯤 = 끄는 것이 아니라 줄인다(양이 줄면 다시 들린다).
