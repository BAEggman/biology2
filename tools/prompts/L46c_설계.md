# L46c 「부엌 식탁의 가라앉힌 유리병과 붉은 원반 — 당구 치는 적혈구」 — 혈장 · 세포성 요소 · 적혈구 (2026-11-08 · 갈아엎기 83호)

> s46 셋째(마지막) 과 — s46p04(가라앉힌 시험관 · 5행 · 카드 9) → 정거장 6. 장소: 부엌 나무 식탁(앞에서 본 꼴) — 왼쪽 긴 유리병(가라앉아 세 층으로 갈린 피) · 가운데 가운데가 옴폭한 붉은 원반들(하나는 모로 서서 아령 옆모습) · 오른쪽 얼굴 달린 붉은 원반 — 어깨 너머로 내던진 작은 돔 천막(핵) · 콩 모양 통 둘(미토콘드리아)이 뒤에 떨어지고, 저는 당구공을 쳐 금화 둘 · 창밖의 해(해 + 당구 = 해당).
> 「시험관」은 s38p02(메셀슨 띠 시험관 · 선반) 몫이라 **긴 유리병**으로 그린다.

## 약속 · 고리
- 덱 그대로: **돔 천막(안에 보라 공) = 핵**(L48a · 천막 = 핵막 · 보라 공 = 인) · **콩 모양 통(안쪽 주름) = 미토콘드리아**(L19e · L19g) · **당구 = 해당과정**(L31a 해 뜨는 당구장 — 해 + 당구) · **금화 = ATP**(언제나) · **흰 방울 = O₂** · **가운데 옴폭한 붉은 원반 = 적혈구**(L46b 모세혈관 토막 안).
- 새로: **가라앉아 칼로 자른 듯 갈린 세 층 = 혈장 · 백혈구 + 혈소판 · 적혈구** · **유리병 허리의 검은 선 아래까지 내려온 노란 층 = 혈장이 절반 넘음(약 55 %)** · **선처럼 얇은 흰 띠 = 백혈구 · 혈소판(얇은 것 = 적혈구가 압도적)** · **구멍 안 뚫린 도넛 · 모로 선 아령 옆모습 = 양면오목원반(표면적↑ → 기체 교환 빠름)** · **원반에 매달린 흰 방울 = 산소 운반** · **내던져 굴러가는 천막 · 콩 통 = 핵 · 미토콘드리아 없음** · **당구공을 쳐 금화 둘 · 흰 방울엔 손대지 않음 = 무산소 해당과정으로만 ATP**.
- 피할 것: 시험관 · 선반(s38 메셀슨) → 긴 유리병 · 사람이 멘 자루(배수성 n · 2n) → 몸에 매달린 방울 · 접시 · 쟁반(lacZ 우유 접시 · 칼모듈린 쟁반) → 식탁 위에 바로 · 눈금 자(s17 바사 렉타) → 선 하나 · 맥주잔(L31c 효모) · 모자.
