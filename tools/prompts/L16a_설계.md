# L16a 「전화 교환국의 창구 셋」 — 세포막 수용체 · 세포내 수용체 (2026-11-08 · 갈아엎기 1호)

> s16 「전화국」(9 세포의 신호 교환 · 31행 · 카드 162)의 첫 과. s16p01 창구 세 개 + s16p01c 손님이 오기 전 을 한 과로 — 수용체 꼴 넷(막 셋 + 세포내 하나) · 리간드 예 · 리간드 전/후 · 3단계. 2차 전령(s16p02 · p02b)은 L16b, RTK 아래 줄(p01b)은 L16c.
> 테마: **전화 교환국** — 「신호 교환」의 교환(switchboard · 교환원). 창구 너머(위쪽 · 거리) = 세포 밖, 창구 벽 = 세포막, 홀 안 = 세포 안. 장소 뜻은 이 하나뿐.

## 덱 약속 그대로 · 새 고리
- 그대로: 둥근 금화 = ATP(#8) · **짙은 회색 네모 칩 = GTP**(G단백질 · s31 숙시닐CoA 와 같은 물건) · 도장 = 인산화(#100 — 여기선 **열쇠 모양 도장** = 키나아제가 찍는 인산화) · 열쇠 = 키나아제(L31a).
- 새 고리(이 과에서 세움): **이온 음료 자판기 = 이온통로 수용체**(이온) · **뱀이 벽을 일곱 번 꿰는 창구 = GPCR**(7회 막 관통) · **지게꾼 = G단백질**(지게 = G · 등에 진 것을 내려놓고 다시 지는 것이 GDP↔GTP) · **타이 맨 둘 = RTK**(타이 = 티로신 · 둘이 등을 맞대야 찍는다 = 이합체) · **기름 범벅 손님 = 지용성 리간드**(벽을 그냥 통과) · **서류 캐비닛 = 핵(DNA)** · **종 = 반응**.
- 리간드 예: 담배 = 니코틴성 ACh(이온통로) · 등불 = 빛, 향수병 = 냄새(GPCR — 에피네프린도 이 창구 · L16b 에서) · 묘목 = 생장인자(RTK).
