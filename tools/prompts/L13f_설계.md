## 2. 이야기 — 한 장면 한 사건

L13e 에서 별 세균에 맞는 벌만 골라져 불어났다. 그 벌들이 오늘 성 안 둥근 탑(내성)에서 **깃발 연대 다섯으로 나뉘어 출정**한다.
가까이서 보니 깃발 하나하나가 **Y 자**다(L46c · L53a 의 「하늘색 Y자 집게」 = 면역글로불린과 같은 꼴 — 세계마다 물건 하나).

- 깃발 천(갈래 끝) = 가변부위(V · N 말단 · 항원결정부위에 붙음 — L13e 「깃발 천 = V」 그대로)
- 깃대(밑동) = 불변부위(C · C 말단 — 연대(종류)와 하는 일을 가른다 · 흰 덩이가 잡는 손잡이)
- 연대마다 깃대 밑동이 다르다 — 지팡이 손잡이(G · 「지」) · 다섯이 밑동끼리 이은 별 바퀴 + 두 봉우리 쇠 장식(M) · 둘을 잇는 J 자 고리 + A 자 사다리(A · J 사슬) · 뚱보 경비 배에 거꾸로 꽂힘 + 세 갈래 갈퀴(E) · 아무것도 안 하는 벌의 D 자 명찰(D) — 【_글자모양사전】 그대로.

## 3. 정거장(13)
s1 큰 Y 깃발을 넷이 든다(큰 벌 둘의 긴 장대 = 중쇄 · 작은 벌 둘의 짧은 장대 = 경쇄) — IM-039
s2 두 갈래 끝의 별 깃발 천이 세균 머리의 별 돌기를 집음(가변 · N 말단 · 결합) · 맨 손잡이(불변 · C 말단) — IM-040 · 041
s3 탑 벽에 기대 하품하는 D 자 명찰 벌 — IgD(B 세포 표면 수용체 · 하는 일이 안 보임) — src #4
s4 가장 큰 무리 = 지팡이 손잡이 깃발 + 깃발이 꽉 찬 진홍 호스의 둥근 창 — IgG 혈청 최다 — IM-048(src #1 · IM-083 drop)
s5 임신부 배의 둥근 유리창으로 깃발을 밀어 넣고 아기가 받음 — IgG 태반 통과 · 수동면역 — IM-044
s6 뚱보 경비 배에 거꾸로 꽂힌 깃발 둘을 꽃가루 공이 잇자 성냥이 확 — IgE · 비만세포 · 히스타민(성냥은 경비의 것 — 깃발의 일이 아님) — src #3(IM-053 · 046 · 092 · 093)
s7 세 갈래 갈퀴로 벌레를 성벽 틈으로 밀어냄 — IgE 기생충 — IM-046
s8 다섯 Y 가 밑동끼리 이은 별 바퀴(갈래 끝 열) + 두 봉우리 쇠 장식 · 끝마다 세균이 엉겨 붙음 — IgM 5량체 · 응집 — IM-047(src #0)
s9 바퀴가 저수지의 보(판자)를 들이받아 물이 터지고 세균 배에 구멍 — 보체 고전경로 · MAC — IM-045 · 052
s10 샘가 — A 자 사다리 위 쌍둥이 벌의 이음 깃발(J 자 고리) · 우는 아이 눈물 속 작은 이음 깃발 — IgA 분비 이량체 · 점막(호스 속은 홑 깃발 — 혈액 IgA 는 단량체) — IM-042 · 043(src #2)
s11 갈래 끝이 손에 빼곡히 붙어 창턱을 못 잡는 보라 망토 — 중화 — IM-050
s12 세균에 거꾸로 붙은 깃발의 깃대를 쥐고 삼키는 흰 덩이 — 옵소닌화(Fc 를 잡음) — IM-051
s13 깃발투성이인데도 멀쩡히 춤추는 세균 — 항체는 직접 죽이지 않는다 — IM-049

## 4. 그림 길
- S1(카본 높음 · 출연진 그림을 올려 장면 통째): S1a 는 출연진 그림이 안 붙은 채 가서(업로드 뒤 메뉴를 눌러 입력이 끊김) 세균을 가시 공(바이러스 꼴)으로 그렸다 → 버림. **S1b**(출연진 붙음 — 알약 세균 · 어두운 두건 · 흰 모자 경비가 세계 그대로) = 바탕.
- 구역 편집(오림은 모두 base0 = S1b 2048 에서 · 16:9 · 붙이기 전에 `colormatch.py` 로 Gemini 그림의 빛깔을 오림에 맞춤 — 벽 · 창 안쪽 같은 넓은 맨바닥이 살짝 달라 상자 둘레에 네모 얼룩이 졌다):

| 이름 | 고친 것 | 비고 |
|---|---|---|

## 6. 배운 것
- **작은 Y(항체)의 방향은 곧은 선으로는 못 나른다** — 갈래(V)가 몸에 닿게 그려도 독자는 「곧은 쪽이 몸에 박힌 가시 · 안테나」로 읽는다(세 번 · 크기 · 굵기 · 끝 모양을 바꿔도). 팔 끝이 안으로 굽은 **집게**로 그리자 바로 「집게가 몸을 물고 막대가 바깥」으로 읽혔다(`L13f_ylib.claw_y`). 집게 곁 작은 세모 천은 「가시」로 읽힌다 — 뺀다.
- **박힌 것**(비만세포에 붙은 IgE)은 깃대를 윤곽 안까지 그린 뒤 몸을 다시 덮으면(가림) 「꽂힘」으로 읽힌다.
- Gemini 는 「갈래 끝으로 붙고 깃대가 바깥」 · 「깃대 쪽부터 핀처럼」을 둘 다 핀(깃대를 꽂음)으로 그렸다 — 방향이 곧 뜻인 작은 물건은 처음부터 PIL 로.
- 넓은 맨바닥(탑 벽 · 창 안)이 있는 오림은 Gemini 그림의 빛깔이 2 ~ 5 % 달라 상자 둘레가 네모 얼룩으로 남는다 → `colormatch.py`(바뀌지 않은 픽셀로 채널별 a·x+b) 뒤에 붙인다. 문턱 6(상자째)로 붙일 때는 상자끼리 겹치게.
- 같은 채팅 덧붙임은 틀을 지킨다(ZA3 · ZE2c · ZF2 · ZH2 · ZI2 · ZJ2 모두 정합 그대로).
