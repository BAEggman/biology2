## 그림의 문법 (배치 = 개념 지도)
- **아래 = 음식의 길(왼쪽 → 오른쪽)**: 큰 돌 머리의 입 → 머리 뒤쪽 목 방(인두) → 노란 미끄럼 관(식도) → 큰 강철 통(위 · L12a) → 쇠살문(유문) → 돌 운하(십이지장 · L12b). 이 한 줄이 소화관.
- **길 곁 = 부속샘 넷**: 입천장의 쇠 주둥이 셋(침샘) · 섬 뜬 연못의 둥근 돌 수반(췌장 — 홈통 둘 = 외분비 · 섬 = 이자섬) · 붉은 벽돌 곳간(간) · 초록 관의 초록 주머니(담낭).
- **호르몬 = 흰 봉투 · 피 = 붉은 물길**(L16d 문법). 길목마다 선 초병이 「제 발밑에 음식이 왔을 때만」 봉투를 띄운다 = 단계적 활성. 누가 받는지는 자리(바로 곁)로 읽는다.
- **되돌아가는 고리**: 붉은 물길은 오른쪽 끝에서 붉은 관이 되어 올라가 그림 맨 위를 따라 돌 머리 꼭대기의 관제탑(포만중추 · 시상하부 — L07e 의 그 관제탑)으로 든다(흰 꺾쇠 = L07e#6 의 문법). 관제탑의 검은 전선(신경)이 입 앞의 차단기(식욕)를 올리고 내린다 → 음식의 길(아래 · 오른쪽으로) + 소식의 길(위 · 왼쪽으로)이 한 바퀴.
- **당기는 줄 = 억제**(L49a 소마토스타틴의 고삐): 쇠살문에 건 줄 셋 = 엔테로가스트론.

## 물건 · 약속 (새로 세운 것 ★ — 예약 18 새로 · 17 덧붙임 · `reserve_L12f.py` 437 → 455)
- ★ **속을 갈라 보인 큰 돌 머리(옆얼굴)** = 입 · 인두. 흰 돌 이빨 = 기계적 소화 · 분홍 혀 · 윗턱 위 콧길의 흰 바람 · 목 방에서 바람은 고리 진 회색 관(기관 — L46f)으로, 빵 덩이는 ★ **노란 미끄럼 관**(식도)으로.
- ★ **밀 이삭 레이스 앞치마 일꾼의 가위 + 흰 실에 꿴 포도알 줄** = 아밀레이스(밀 + 레이스) · 녹말 → 두 알 토막(엿당) · 가윗날 사이 물방울 = 가수분해.
- ★ **쇠 주둥이 밑의 물방울 · 흰 네모 알갱이 · 금 간 초록 알약 세균 · 분홍 막대사탕** = 침(물 · 염 · 라이소자임 · 점액성 당단백질).
- ★ **철모 · 방독면 병사** = 가스트린(G세포) — ★ 반죽 덩이에 밀려 불룩 휜 통 벽 = 위벽이 늘어남. 곁의 불붙은 성냥 ↑(ECL 히스타민) · 누운 주황 배턴 ↓(D 소마토스타틴).
- ★ **「쉿」 요원**(검은 정장 · 선글라스) = 세크레틴(S세포) — 초록 물(산성 유미즙) 둑 → 연못의 왼쪽 홈통이 흰 분필(HCO₃⁻)을 → 물이 맑아짐.
- ★ **기둥 위 감시 카메라** = CCK(씨씨) — 노란 기름 웅덩이(지방)를 비춤 → 드립 주전자 인부(췌장 소화효소) · ★ 띠에 졸린 초록 주머니(담낭 → 담즙).
- ★ **쇠살문의 고리에 묶인 갈색 줄 셋**(요원의 몸통 · 카메라 기둥 · ★ 국방색 지프 = GIP) = 엔테로가스트론이 위를 늦춤. ★ 운하 바닥 밑 지그재그 검은 전선 = 장신경계.
- ★ **돌 머리 꼭대기의 관제탑 + 맨 위의 붉은 관** = 포만중추가 소화계 신호를 통합. ★ **빨강 하양 차단기 + 빵 수레** = 식욕.
- ★ **빈 그릇 · 숟가락의 초록 도깨비** = 그렐린(그르렁 · 통 위 = 위 · 빈 그릇 = 식전 · 차단기 ↑) / ★ **Y 쌍둥이** = PYY(운하 둑 = 소장) / ★ **랩 씌우는 노란 공 사람** = 렙틴(지방조직) / 섬의 주사기 든 사람 = 인슐린 — 뒤의 셋이 차단기 ↓.
- **기괴함**: 속을 가른 돌 머리 안에서 일하는 레이스 앞치마 일꾼 · 머리 꼭대기의 관제탑 · 통 위의 방독면 병사와 도깨비 · 둑에서 「쉿」 하는 요원 · 기름 웅덩이를 감시하는 카메라 · 쇠살문을 끄는 지프 · 노란 공 사람의 랩.
- ⚠ 피한 것: 신호등(방실결절) → 차단기 · 끈적한 점액(믹소) → 막대사탕 · 가스 불 · 버너(브루너샘) → 방독면 · 나무 수문(유전자 흐름) → 쇠창살 문 · 손에서 손으로 건네는 봉투(내인자) → 봉투는 붉은 물길로만 · 깔때기 · 수평 저울 · 은빛 돔 덮개 · 전화기 · 알려진 영화 캐릭터 꼴(도깨비 · 요원).
