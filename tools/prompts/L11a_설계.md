# L11a 「지퍼 공사장의 분기점」 — DNA 복제 분기점 · 대장균 개시 순서 (2026-11-08 · 갈아엎기 29호)

> s11(16 핵산과 유전 — 복제와 수복 · 6판 56행 · 카드 91)을 네 과로: **a 분기점 + 이름 자리**(p01 11행 + p01b 7행 · 카드 40) · b 중합효소 계보(p02 · 17) · c 수복 3종(p03 · 16) · d 담장 안팎 + 선로의 끝(p04 + p05 · 18).
> 이 과: 13 정거장. 장소: 공사장 — 오른쪽에서 들어오는 닫힌 지퍼가 가운데 분기점에서 위 · 아래 띠로 갈라져 왼쪽으로. 사람들은 오른쪽부터 에이스(DnaA) → 스패너(자이레이스) → 빗자루 멘 지퍼 끄는 사람(헬리케이스 DnaB) → 쐐기 든 둘(SSB) → 지팡이 짚은 프라이팬 요리사(프라이메이스 DnaG) · 위 띠 긴 판자 하나 + 도르래 줄 · 아래 띠 짧은 판자 다섯 + 용접공.

## 약속 · 고리(옛 그대로 · p01b 의 이름 물건을 p01 의 인물에 직접 달았다)
- 닫힌 지퍼 = 어버이 이중나선 · 분필 동그라미(이빨 성김) + 에이스 카드 = DnaA · 복제기점(AT 많아 약함) · 지퍼 손잡이 끄는 사람 + 어깨의 빗자루(비) = 헬리케이스 DnaB · 나무 메 + 쐐기 든 둘 = SSB(둘 = SS · 붙잡음 = B) · 꼬인 뭉치의 스패너 = 자이레이스(분기점 앞쪽) · 프라이팬 + 지팡이 = 프라이메이스 DnaG · 쇠못 = RNA 프라이머(나무가 아님 → 나중에 뽑음) · 판자는 못 박힌 뭉툭한 끝 → 뾰족한 끝으로 자람 = 5′→3′ · 띠를 두 번 감은 줄 + 도르래 = 활주 클램프 · 위 띠 긴 판자 하나 = 선도가닥 · 아래 띠 짧은 판자 다섯 = 지연가닥 · 오카자키 · 용접 불꽃 + 라이터 = 라이게이스 · 오른쪽부터 선 차례 = 개시 순서 A → B → SSB → G.
