# L17b 「장터 모퉁이 — 낫과 밧줄」 — 사구체곁장치 · 레닌-안지오텐신-알도스테론 · ANP (2026-11-08 · 갈아엎기 5호)

> s17 둘째 과 — s17u01 모퉁이(행 1~8 · 카드 5) + 시험 단골(ACE · 안지오텐신 II 의 네 효과 · 레닌 분비 자극 · ANP). 같은 장소(콩팥 강가 장터)의 **모퉁이**.

## 약속 · 고리
- 그대로(s17u01): 알갱이 주머니 = 과립세포 · 낫 = 레닌(자르는 효소) · 늘어진 밧줄 → 팽팽한 토막 = 안지오텐시노겐 → 안지오텐신(텐션) · 창 안 촘촘 검은 털 = 치밀반 · 졸라맨 끈 = TGF · 삼베 그물 = 간질세포(메운다) · 큰 열쇠 = 알도스테론(s17u03) · 흰 쇠 V자 이음쇠 = ADH(s17u02 · u03) · 둥근 관 = 핏줄 · 네모 관 = 오줌길.
- 새 고리: **허파 모자 + 스페이드 한 장 카드(에이스) = ACE(폐)** · **고깔모자 쓰고 자루 위에 앉은 사람 = 부신(콩팥 위의 모자)** · **심장 모양 물풍선 = ANP(심방)**.
