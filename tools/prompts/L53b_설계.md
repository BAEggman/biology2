# L53b 바닷속 버터 부교 ② 저절로 드는 문 — 선택적 투과 · 확산 · 삼투 · 통로와 운반체 (2026-11-13 · 8장 38 · 정거장 13 · 세계 s53 의 b)

## 왜
사용자: 「커버 안된 카드부터 만들어보자」(2026-11-13). L53a(42장)에 이어 같은 버터 띠의 둘째 그림 — 계획 G1 「부교 성벽 ② 저절로 드는 문」의 38장(전부 그림 없음). 수동수송 한 묶음: 무엇이 그냥 지나고 · 무엇이 못 지나며 · 못 지나는 것은 어떤 문으로 지나는가.

## 그림의 문법 (개념 지도가 곧 배치)
- **왼쪽 → 오른쪽 = 교과서의 차례**: 맨 틈(단순확산) → 통로 → 운반체 → 개폐성 통로 → (맨 끝) 동전 펌프(능동수송과 견주기).
- **위 물 = 세포 밖 · 아래 물 = 세포 안**(L53a 그대로). 손님은 늘 **빽빽한 쪽에서 드문 쪽으로** — 위 물엔 흰 방울(O₂) · 포도(포도당) · 사과(과당) · 흰 소금 자루(Na⁺)가, 아래 물엔 어두운 방울(CO₂) · 은빛 칼(K⁺)이 많다. 거스르는 것은 맨 오른쪽 펌프 하나.
- **동전(ATP)이 없다**: 징수원은 졸고 동전함은 비었다. 동전은 펌프 밑에만.
- **구슬 기둥 = 막단백질**(L53a) — 틈(통로) · 회전문(운반체) · 쇠살 문(개폐) · 놋쇠 펌프 상자.

## 물건 · 약속
- **흰 방울 ↓ · 어두운 방울 ↑** = O₂ · CO₂ 의 단순확산(【밝은 방울】 · 【어두운 방울】) — 같은 틈에서 서로 반대로 = 물질마다 제 기울기.
- **길게 늘어져 흘러내리는 노란 기름방울** = 비극성 소수성 분자(이중층에 녹음) · **금빛 고리 넷 봉인의 흰 봉투** = 스테로이드 호르몬(봉투 = 호르몬 L16d · 고리 넷 = 스테로이드) — L53a 의 우편함 기둥을 거치지 않는다.
- **땀 흘리는 파란 물방울**(물은 느림) · **튕기는 포도**(극성 친수성) · **물방울들이 끌어안은 흰 소금 자루**(수화껍질로 커진 이온).
- **나무 판자 벽 + 해바라기 + 사과 · 포도 더미로 몰리는 물방울** = 삼투 · 세포벽 · 팽압. 식물세포 = 나무(L48b · L14a). 띠 바로 밖(위)의 판자 = 세포벽 · 납작 눌린 부표 머리 둘 = 팽압 · 꼿꼿한 해바라기 = 지지.
- **조는 징수원 + 빈 놋쇠 동전함** = 수동수송은 에너지 0 · 그가 앉은 틈 기둥이 단순확산(왼쪽) / 촉진확산(오른쪽)의 경계.
- **늘 열린 좁은 틈 + 한 줄로 오르는 칼** = 통로단백질 · K⁺ 누출 통로(L23a#1 과 같은 뜻).
- **회전문**(놋쇠 굽은 벽 두 짝 사이의 유리 문짝) = 운반단백질 — 문짝이 늘 가로막아 위아래가 함께 뚫리지 않는다(결합 → 모양 변화). **곧은 문짝 한 장 + 웃는 붉은 원반(적혈구)** = GLUT1 · **별 꼴 날개 다섯 + 사과** = GLUT5 — 문짝 수가 번호. 문 위의 긴 포도 줄 = 포화 · 붉은 원반이 사과를 밀어냄 = 특이성(캠벨의 그 예 — 적혈구 포도당 운반체는 과당도 거부).
- **손을 맞잡은 포도와 흰 소금 자루** = SGLT(Na⁺ 공수송 — L17a 의 짝) — 문은 L53c.
- **쇠살 문 둘**: 노란 번개 맞은 문으로 칼이 솟음 = 전압 개폐 K⁺ 통로(신경세포 · L23a 칼 아치) / 주먹이 꽂아 쥔 놋쇠 열쇠 + 쏟아져 드는 소금 = 화학(리간드) 개폐(L23b#1).
- **놋쇠 펌프 상자** = 【동전 투입구 크랭크 펌프】 — 동전은 아래(세포 안)에서 ↑ · 소금 줄기는 자루가 여섯인 위 물로(역행). L53c 의 주인공.
- **기괴함**: 물방울들에게 끌어안겨 뚱뚱해진 소금 자루 · 땀 흘리며 낀 물방울 · 부표 머리를 납작 누른 해바라기 화분 벽 · 기둥 꼭대기에서 코 방울 부는 징수원 · 사과를 밀어내는 웃는 적혈구 · 손잡고 선 포도와 소금 자루 · 번개 맞은 쇠살 문 · 팔 없는 주먹의 열쇠.
- ⚠ 피한 것: 물레방아 꼴(ATP 합성효소 — 회전문은 유리 문짝 · 물줄기 없음) · 수면 모자 · 나방(빈 지갑 = ATP 바닥) · 문지기(억제자) 낱말 · 포도송이(글리코젠) · 삼투 더미의 소금 자루(Na⁺ 는 밖).
