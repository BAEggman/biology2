## 약속 · 고리
- 덱 그대로: 판자 가위표 = 막힘(쪽문 = 전자전달계로 가는 문 · 커튼 문은 열림 — 막힌 것은 피루브산 문이 아님) · 가득 찬 양동이 탑 = NADH 쌓임 · 빈 양동이 = NAD⁺ · 당구대 = 해당과정(L31a) · 반환구 동전 둘 = 순 2 ATP · 뒤집은 주머니 + 나방 = 빈털터리(발효 ATP 0) · 보랏빛 각뿔 = 젖산 · 연기 방울 먼저 = CO₂ 먼저(알코올 발효) · 붉은 벽돌 이층집 = 간 · 붉은 정육면체 = 포도당 · 꼬리 쫓는 개 = 코리(꼬리) 회로.
- 새로: 먹구름 밤 = 산소 없음(해 뜨는 당구장의 반대) · 근육 선수 = 근육(백근 젖산) · 양조장 + 맥주잔 = 효모 · 에탄올.
