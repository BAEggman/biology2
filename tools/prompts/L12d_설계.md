# L12d 「문 안쪽 조제실 — 달걀이 삼킨 손」 — 비타민 B7 · B6 · B1(TPP) · B5 (조효소의 일 · 결핍) (2026-11-08 · 갈아엎기 72호)

> s12 넷째 과 — s12p05(7행 · 카드 14) → 정거장 7. 장소: 회장 문(L12c) 안쪽의 긴 실내 조제실 — 왼쪽부터 양철 차양 작업대(B7) · 넥타이 작업대(B1) · 피리 작업대(B6) · 통 셋(B5).
> **탄소 = 벽돌 한 장**으로 묶는다(옛 판의 「사슬 끝 벽돌 한 장」을 넓힘): B7 은 벽돌 셋에 한 장을 더 붙이고(카복실화 · 피루브산 3 → 옥살아세트산 4) · B1 은 벽돌 한 장을 떼어 던져 연기 방울이 된다(탈탄산 · CO₂ = L31b 의 「연기 꼬리 단 어두운 방울」). B5 의 통마다 묶인 큰 종이 꼬리표 = CoA(L31b 의 꼬리표).
> 옛 판의 「B6 가 꼬리표를 옮긴다」는 꼬리표가 CoA 로 이미 쓰여 **작은 파란 공이 피리 가락에 접시에서 접시로 뛴다**로 바꿈(아미노기 전이).

## 약속 · 고리
- 양철(틴) 차양에서 실내에 비 = 비오틴(비 + 틴) · 빗방울 일곱 = B7 · 벽돌 셋에 넷째를 붙이는 두 손 = 카복실화(탄소 하나 붙이기 · 피루브산 카복실화효소 — 당신생) · 지방 · 글리코젠 · 아미노산 합성 조효소.
- 깨진 날달걀 흰자가 그 두 손을 덮어 굳힘 + 흰자 속 금색 자물쇠 = 아비딘이 비오틴을 붙잡아 못 쓰게(약 · 막음의 금색 자물쇠) · 결핍 = 피부 이상 · 신경근육 질환.
- 넥타이 = 티아민(B1) · 벽돌 한 장을 떼어 던지자 연기 방울 = 탈탄산(CO₂ 제거 · TPP).
- 구멍 여섯 피리 = 피리독신(B6 · PLP) · 피리 가락에 작은 파란 공이 접시에서 접시로 = 아미노기 전이(아미노산 대사) · 바닥만 남은 붉은 병 = 빈혈 · 저절로 떠는 양철 컵 = 경련 · 과민반응.
- 똑같은 통이 선반 · 바닥 · 저쪽 세 곳에 = 판토텐산(pantos = 어디에나) · 통에 기댄 판자 다섯 = 판토(판자) + B5 · 통마다 큰 종이 꼬리표 = 조효소 A(CoA · L31b) · 통 곁 가시 덩굴 감긴 빈 장화 + 늘어진 빈 자루 = 손발 저림 · 무감각 · 피로(어디에나 있어 결핍은 드물다).
