## 약속 · 고리(옛 그대로 + 이번에 더한 것)
- 엄지로 눌러 굴 난 반죽 공 = 낭배(굴 = 원장 · 입구 = 원구) · 잘린 면 파랑 · 빨강 · 노랑 = 외 · 중 · 내배엽 · 파란 끈 → 가죽 + 혹 달린 대롱 = 외피 + 신경관(뇌) · 빨간 끈 → 팔뚝 + 연장 상자 = 근육 + 대부분 기관 · 노란 끈 → 굴 안벽 + 곁주머니 둘(잎 · 처진 자루) = 소화관 내벽 + 폐 · 간 · 겹 둘뿐인 작은 공 = 2배엽(자포 · 유즐) · 조리법 카드 넷(덩이 → 넷 금 → 빈 껍질 → 눌린 굴) = 접합자 → 난할 → 포배 → 낭배 · 어긋난 공 쌓기 = 나선난할 · 곧은 쌓기 = 방사난할 · 덜 된 덩어리 = 결정 · 온전한 작은 공 = 부정(쌍둥이) · 갈라진 붉은 덩이 = 분열체강 · 벽에서 떨어지는 주머니 셋 = 장체강.
- **더한 것(bizarreness · 편 가르기)**: 거대한 빵집 엄지가 굴 입구 밖에서 가리킨다(누른 손이 그림에 있다) · 팔뚝이 작업대에서 불끈 솟아 있다(몸 없는 팔) · 왼 쟁반 귀퉁이 달팽이(연체 = 선구) · 오른 쟁반 귀퉁이 불가사리(극피 = 후구) — 글자 없이 어느 쟁반이 어느 편인지 박는다(p05 세 간판 · 별 간판과 같은 약속).
