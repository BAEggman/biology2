# L49a 「호수 위 섬의 네 집과 유리 수조 — 붓는 홈통 넷, 떠내는 손 하나」 — 이자섬 세포 · 혈당을 올리고 내리는 호르몬 (2026-11-08 · 갈아엎기 75호)

## 약속 · 고리(덱 그대로)
- 물에 뜬 섬 = 이자섬(islet · insula → 인슐린) · 동글동글한 포도 = 포도당(⚠ 낱말은 「포도」만 — 「포도알」은 α 고리 「알」과 겹친다) · 유리 수조 물높이 = 혈당 · 초록 띠 = 정상 구간.
- 흰 알 = α · 개어 둔 흰 베 = β · 삼각 모자 = δ · 사슬 = F(PP · 펩타이드) — 왼쪽부터 α · β · δ · F · 크기 = 비율(β 가장 큼 약 70% · α 약 20% · δ 약 5% · F 가장 적음 — 차례와 크기가 어긋난다).
- 곤봉 + 포도 = 글루카곤(올림) · 치켜든 주사기 = 인슐린(내림 · 유일) · 놓인 배턴 = 소마토스타틴(든 배턴 = GH) · 고삐 두 가닥 = 둘 다 억제.
- 코르크 마개 = 코르티솔 · 근육 선수(L31c) + 구슬 꿴 줄(단백질) → 낱 구슬(아미노산) → 작은 붉은 벽돌 오두막(간) → 포도 = 당신생 · 든 배턴 주자 = GH · 뚜껑 터진 드럼통 = 에피네프린.
- ⚠ 모자는 δ 삼각 모자 하나만(다른 사람 모자는 5′ 캡으로 읽힌 적이 있다).
