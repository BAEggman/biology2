## 그림의 문법 (L10a 와 같은 크림빛 바탕 · 침목 없는 겹줄 레일 = mRNA · 왼쪽 끝 겨자색 중산모 = 5′)
- **레일 위(왼 → 오 = 5′ → 3′)**: 창 셋 달린 객차가 줄지어 섰다 — **객차 한 대 = 코돈 · 창 셋 = 염기 셋 · 창의 빛깔 넷 = 염기 넷(초록 A · 파랑 U · 빨강 G · 노랑 C)**. ① 맨 앞 객차 지붕의 **월계관 쓴 황제 아우구(AUG)스투스**가 팔을 뻗어 오른쪽을 가리킨다(개시 · 창 = 초록 · 파랑 · 빨강). ② 가운데 **보라 정거장(리보솜)**이 객차 한 대를 품었고, 안에 **흰 수염 팔순 할아버지(tRNA — 이 세계에서 좌석의 사람 = tRNA)**: 허리를 세우고 다리를 뻗어 앉은 몸 = **L 자(3차원)** · 한 손의 종이(종이 = RNA)에 그린 **세 잎 클로버(2차원)** · 번쩍 든 팔(팔 → 팔순 → 80) 손가락 끝에 **갈고리 · 갈고리 · 접이 사다리(C · C · A — 글자모양사전)**와 구슬 하나(3′ 말단) · 발끝의 **세 이빨 열쇠(L10a — 안티코돈)**가 아래 객차의 창 셋에 닿는다 · 입가 말풍선 「빛깔 네모 셋 → 구슬 하나」(번역자). ③ 레일 끝 차막이 앞 세 객차 지붕에 **나무판(L10a — 방출 인자 = 종결)을 든 셋 — 발레리나(우아아 = UAA) · 비명 지르는 사람(우악 = UAG) · 원시인(우가 = UGA)**.
- **앞마당 왼쪽 = 도색장**: 받침대에 올린 객차의 맨 창 셋 · 붓 든 칠장이 · **페인트 통 넷**(창마다 넷 중 하나 → 4 × 4 × 4) · 이젤의 **체스판 64칸**(금빛 구슬 61 + 나무판 3 — 칸 수가 곧 숫자 · L50a 의 25칸 깔개와 같은 수법).
- **앞마당 오른쪽 = 다 꿰어진 사슬의 행선지**: 갈림길 **이정표**(화살판 셋마다 빛깔 다른 구슬 — 빨강 = 막사 · 파랑 = 손님채 · 초록 = 꼬투리) · **짐꾼**이 다 꿰어진 구슬 사슬(앞 끝 파랑)을 어깨에 메고 **콩 모양 손님채(L52a — 미토콘드리아)**로 간다(번역이 끝난 뒤) · 멀리 작은 **카키 막사(L48d — 소포체)** 지붕엔 보라 짝이 올라앉아 사슬을 넣는 중(번역 도중 — 견줄 짝).

## 덱의 약속 (다시 쓰는 것 · 피할 것)
레일 = mRNA · 겨자색 중산모 = 5′ · 보라 정거장 = 리보솜 · 좌석의 맨머리 사람 = tRNA · 구슬 = 아미노산 · 세 이빨 열쇠 = 안티코돈 · 나무판 = 방출 인자(종결) · 종이 = RNA · C 자 갈고리 = C · A 자 접이 사다리 = A · 콩 모양 손님채(안쪽 빨간 주름 커튼) = 미토콘드리아 · 지붕의 초록 꼬투리 = 엽록체 · 카키 천 막사 + 지붕의 보라 짝 = 조면소포체 · 사슬 앞 끝의 빨간 구슬 = 신호서열 · 칸 수 = 숫자(25칸 깔개).
⚠ 피할 것: 지팡이(DnaG) → 할아버지는 지팡이 없음 · 왕관(코로나) · 로마 투구 + 칼(ROMK) → 황제는 월계관 · 맨손 · 깃발(σ · 플라비) · 호루라기(화학수용기) → 황제는 팔만 뻗음 · 곤봉(글루카곤) → 원시인은 맨손 · 헤드셋(관제사 = 뇌) → 통역은 말풍선으로 · 창의 빛깔을 초록 · 노랑 · 빨강 순으로 두지 않는다(신호등 = 방실결절) → U = 파랑 · 객차는 구슬을 싣지 않는다(구슬은 tRNA 가 든다 — L10a).

## 남은 것
- 갈고리 둘 + 사다리는 처음 보는 눈에 글자 「C C A」 로 읽힌다 — 뜻한 바(갈고리 = C · 접이 사다리 = A).

- 레일 끝 차막이는 「빈 팻말 · 신호기」로도 읽힌다 · 바탕의 언덕 선.
