# L17a 「콩팥 강가 장터 — 거르는 강」 — 여과 장벽 · 네 걸음 · 배 셋(청소율) · 근위세뇨관 짐꾼 (2026-11-08 · 갈아엎기 4호)

> s17(44 배설계 · 59행 · 카드 160)의 첫 과. s17u01 「거르는 강과 장터」에서 모퉁이(사구체곁장치 → L17b)와 좌판(질소 노폐물 → L17c)을 뺀 나머지 — 강머리(여과) · 배 셋 · 둑의 짐꾼. 시험 단골 둘을 더함(Na⁺-K⁺ 펌프 구동력 · 포도당 수송 최대치 초과 = 당뇨).
> 테마: **콩팥 강가 장터** — 콩 자루와 팥 자루를 파는 장터(콩 + 팥 = 콩팥). 장소 뜻: **강 = 세뇨관(오줌길) · 둑 = 세포 · 좌판 뒷문 너머 = 혈액**. 네 걸음은 강 따라 왼쪽 → 오른쪽.

## 약속 · 고리
- 그대로: 둥근 금화 = ATP · 소금 자루 = Na⁺ · 포도 궤짝 = 포도당(s17u01) · 뒷문 = 기저외측막(덱 전체) · 하마 = PAH · 통나무 = 이눌린 · 빈 배 = 포도당 · 가시 그물 = 기저막 음전하 · 말뚝 위 가랑이 = 족세포 슬릿 · 호스 뭉치 = 사구체.
- 새 고리: **콩 · 팥 자루 = 콩팥(장소 이름)** · **널다리에 남은 궤짝 더미 = 수송 최대치(Tm) 초과 → 당뇨**.
