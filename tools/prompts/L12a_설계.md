# L12a 「커다란 위 통과 십이지장 작업대 — 붓고 · 자르고 · 켜고」 — 위샘 세포와 단백질 · 지방 분해효소 (2026-11-08 · 갈아엎기 69호)

> s12 첫 과 — s12p01(위 · 7행 · 카드 6) + s12p03(효소 절단 · 5행 · 카드 4) → 정거장 13. 장소: 앞을 잘라 낸 커다란 강철 통(위 — 바탕은 J 자가 아닌 둥근 통으로 나옴) — 그 오른쪽 아래에서 오른쪽으로 뻗은 넓은 관(십이지장) 속 작업대 둘. 위에서 붓는 것(위샘 세포) → 통 속에서 자르는 것(펩신) → 관으로 넘어가 자르고 켜는 것(이자 효소).
> 옛 두 판(s12p01 위 · s12p03 효소 절단)은 「콜라 병 = 펩시노겐 → 펩신」으로 이미 이어져 있다. 한 장에 두면 그 이음이 물건 하나로 선다.

## 약속 · 고리(옛 그대로 + 새것 하나)
- 하반신이 흰 그리스 기둥인 인부 = 주세포(主 = 기둥) · 초록 유리 콜라 병의 걸쭉한 반죽 = 펩시노겐(펩시 → 펩신 · 비활성) · 하반신이 붉은 벽돌인 인부 = 벽세포 · 민짜 흙 항아리의 맑은 액 = HCl(H⁺ · Cl⁻) — 병이냐 항아리냐로 두 세포가 갈린다.
- 벽돌 인부가 내미는 흰 봉투 = 내인자 · 받는 사람의 코끝만 코발트빛 = B12(코발라민 · 덱 예약 — 코끝만) · 회장 문으로 달려 간다(L12c 에서 다시 만난다).
- 통 바깥벽의 놋쇠 수도꼭지가 거품을 붉은 관(피)으로 = 알칼리성 조조(HCO₃⁻ 가 혈액으로).
- 송아지 + 굳은 우유 = 레닌(키모신 · 어린 포유류의 카세인 응고).
- 검은 탄산 병 = 펩신(초록 병이 켜진 것) · 향이 피어오르는 보라 마름모 = 방향족 아미노산(덱 예약) · 마름모의 왼쪽(N 말단 쪽)을 자른다.
- 구스넥 드립 주전자 = 트립신(덱 예약) · 쌀밥 공기 = 라이신(라이스) · **아르헨티나 국기 = 아르기닌(Arg — 새 고리)** · 그 오른쪽(C 말단 쪽)을 자른다.
- 기모노 + 같은 드립 주전자 = 키모트립신 · 마름모의 오른쪽(C 말단) — 펩신과 같은 마름모, 반대쪽.
- 열쇠 꽂힌 회색 상자 = 엔테로펩티데이스 → 케이블이 트립신 허리로만 → 트립신 허리에서 둘째 케이블이 키모트립신으로 = 트립신이 나머지를 켠다(마스터 스위치).
- 기름 웅덩이에 가장자리를 담그는 큰 쟁반 = 라이페이스(판) · 쟁반을 함께 미는 콜리 = 콜리페이스.
