# L23b 「똑같은 열쇠 둘 — 문에 박힌 열쇠구멍과 맨 벽의 열쇠구멍」 — 아세틸콜린 수용체(니코틴성 · 무스카린성) (2026-11-08 · 갈아엎기 79호)

> s23 둘째 과 — s23p02(8행 · 카드 4 + 겹침) → 정거장 8. 장소: 기둥 하나로 왼쪽 · 오른쪽을 가른 건물 안. 왼쪽 = 창살문 두 층(열쇠구멍이 **문에 바로** 박혀 돌리면 그 자리에서 열림 = 이온통로 직결) · 오른쪽 = **맨 벽**에 열쇠구멍판만(뒤에 문이 없다 = GPCR) → 긴 복도를 달리는 지게꾼(G단백질) → 끝에서 둘로 갈라진 복도(진자 · 물자루).
> 같은 열쇠(ACh)인데 결과가 갈리는 것은 열쇠구멍(수용체)이다 — 이 과의 첫 문장.

## 약속 · 고리
- 덱 그대로: 흰 소금 = Na⁺(자루 · 결정) · 열린 담뱃갑 = 니코틴 · 붉은 갓 흰 점 버섯 = 무스카린 · **손가락 둘로 진자를 세움 = M2(심박 감소) · 손가락 셋으로 물자루를 쥠 = M3(평활근 수축 · 샘 분비)**(⚠ 숫자는 손가락으로만 · 다른 손은 주먹으로) · 근육 팔 = 골격근 · 지게꾼 = G단백질(L16a) · 짙은 회색 네모 칩 = GTP.
- 새로: **똑같은 둥근 놋쇠 열쇠 둘 = 아세틸콜린** · **문에 박힌 열쇠구멍 = 이온통로 직결(LGIC)** · **맨 벽의 열쇠구멍판(뒤에 문 없음) = GPCR** · **아래층 창살문을 제 열쇠로 여는 사람 = 자율신경절(절전 → 절후 니코틴성)** · **갈라진 복도 = 2차 전령이 여러 표적으로 · 느리고 길다**.
