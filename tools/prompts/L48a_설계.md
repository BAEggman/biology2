# L48a 「다섯 칸 헛간 — 천막이 무너졌다가 다시 선다」 — 유사분열 다섯 단계 (2026-11-08 · 갈아엎기 63호)

> s48 첫 과 — s48p01(10행 · 카드 10) → 정거장 11(틀 + 10). 장소: 앞벽을 잘라 낸 긴 나무 헛간 — 굵은 칸막이로 다섯 칸 · 칸마다 양쪽 벽 가운데 높이에 검은 쇠고리 하나씩(= 두 극). 칸마다 같은 세 가지가 다른 꼴로 — 둥근 천막(핵막) · 가위표 짚단(복제된 염색체 · 금빛 하나 + 초록 하나) · 쇠고리에서 나온 밧줄(방추사).
> 옛 판은 「나무 상자 다섯 칸 · 굵은 막대」였다. 과에서는 L19h 의 **가위표 짚단**(잘록한 허리 = 중심절 · 허리의 걸쇠 = 동원체 · 밧줄 = 방추사)을 그대로 이어 쓴다 — 같은 물건이 같은 뜻으로 과를 건너간다. 「다섯 칸」= 다섯 토막이라는 옛 약속(s47p01 과 같은 꼴)은 헛간 다섯 칸이 잇는다.

## 약속 · 고리
- 다섯 칸을 왼쪽부터 = 전기 · 전중기 · 중기 · 후기 · 말기(차례).
- 둥근 천막 = 핵막 · 천막 속 바람 빠진 보라 공 = 인(핵소체 · L48c 의 「천막 안의 공」과 같은 물건).
- **묶인 가위표 짚단 = 응축된(복제된) 염색체** · **묶이지 않은 짚 가닥 = 풀린 염색질** — 응축 = 짚을 단으로 묶는다 · 풀림 = 단을 푼다.
- 짚단 색 둘(금빛 · 초록) = 서로 다른 염색체 두 개 — 후기에 양쪽 벽이 금빛 하나 · 초록 하나씩 받는 것이 「딸세포가 같은 벌을 받는다」.
- 쇠고리 = 극 · 밧줄 = 방추사(미세소관) · 밧줄이 짚단 허리 걸쇠에 걸림 = 동원체 부착(L19h) · 양쪽에서 하나씩 = 양극 부착.
- 흰 점선 = 중기판(가상의 평면 · 물건 위로 그어짐) · 세발 받침 상자 사진기 = 핵형 분석(중기 사진을 찍어 늘어놓는다).
- 갈라진 짚단 넷 = 자매염색분체가 각각 염색체로 세어진다(수 2배) · V 꼴로 허리가 앞장서 끌려감 = 동원체 미세소관이 짧아지며 끌어감.
- 조각을 기운 새 천막 두 채 = 핵막 재형성(옛 핵막 조각에서 다시 짓는다 · 핵 둘) · 쇠고리에 밧줄 없음 = 방추사 사라짐.
- 이름 고리: 유사분열의 유사(有絲) = 「실이 있는」 분열(그리스말 mitos = 실) — 쇠고리에서 나오는 밧줄이 그 실이다.
