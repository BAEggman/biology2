# L32a 「맑은 날 담장의 펌프집 넷 — 노란 공은 줄을 타고 · 물은 담을 넘고 · 동전은 물레방아에서」 — 전자전달계 · 화학삼투 (2026-11-08 · 갈아엎기 73호)

> s32 첫 과 — s32u01 행 0~12(13행 · 카드 39) → 정거장 14. 장소: L31b 안뜰 뒷담의 쪽문을 지나면 나오는 긴 붉은 벽돌 담장(내막 — s33p03 「붉은 벽돌 담장 = 미토콘드리아」 그대로) · 앞마당(기질 · 마른 모래) · 담장 뒤 바다(막간공간 · 담장 꼭대기까지 찬 물 = H⁺). 담장에 박힌 나무 펌프집 넷(I · II · III · IV) · 오른쪽 끝 돌 아치 하나 + 물레방아(ATP 합성효소).
> 옛 판 s32u01 은 큰 장면(맑은 날) + 오른쪽 세로 세 칸(먹구름 낀 다른 날 셋)이 한 장이었다. 한 그림에 세 칸까지 넣으면 칸 하나가 손바닥만 해져 석상 · 양동이 기둥 · 자물쇠가 안 읽힌다 → 맑은 날(L32a)과 먹구름 세 날(L32b) 둘로.

## 약속 · 고리(덱 그대로 + 새것)
- 덱 그대로: 붉은 벽돌 담장 = 미토콘드리아(내막) · 가득 찬 둥근 금속 양동이 = NADH · 빈 양동이 = NAD⁺ · 네모 양동이 = FADH₂(L31b) · 동전 = ATP · 흰 둥근 방울 = O₂(L31a 창의 흰 방울) · 돌 아치 + 물레방아 = ATP 합성효소(s32u01 · L45c) · 노란 공 = 전자(s45u02 · L45c) · 담장 뒤 물 높이 = 기울기의 크기.
- ⚠ 펌프집은 **나무 판잣집**이다 — 붉은 벽돌 **건물**은 간 예약(L12b 곳간). 물을 퍼 던지는 것은 **나무 퍼개**(금속 양동이는 NAD 전용 · 국자는 퍼옥시좀 예약).
- ⚠ 병은 **붉은 밀랍**으로 봉한다 — 코르크 마개는 코르티솔 예약.
- 새로(이 과): **지붕을 뚫고 솟은 근육 팔 = H⁺ 펌프**(I · III · IV) · **빈 셔츠 소매 = 펌프 없음**(II) · **문 모양 = 받는 짐**(동그란 문 = 둥근 양동이 = NADH → I · 네모 문 = 네모 양동이 = FADH₂ → II) · **레일 수레 = 이동 운반체**(돌 = 비단백질 유비퀴논 · 나무 상자 = 단백질 cyt c) · **Y 자로 합치는 레일 = 두 길이 Q 에서 합류** · **노란 공이 수레를 타고 집에서 집으로 = 전자 전달** · **소용돌이 = 물이 빠질 데가 아치 하나뿐** · **개구리처럼 뛰는 물방울 둘 = 2H⁺**.
