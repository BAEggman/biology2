## 약속 · 고리
- 덱 그대로: **돔 천막(문 열림 · 안에 보라 공) = 핵**(L48a 천막 = 핵막 · 보라 공 = 인 · L46c) · **흙빛 갈색 버섯(점 · 고리 없음) = 담자균**(L05a 다섯째 집) · **빵 덩이 = 접합균(빵곰팡이)**(L05a 둘째 집).
- 새로: **산울타리로 나뉜 칸 = 세포(격벽으로 나뉜 균사 마디)** · **파란 천막 / 노란 천막 = 서로 다른 짝짓기형의 반수체 핵** · **칸마다 천막 하나 = n — 캠핑장의 대부분 = 반수체 우세** · **두 캠퍼가 칸 사이 산울타리를 뽑는다 · 천막은 제자리 = 원형질융합(세포질만)** · **한 칸에 파랑 · 노랑 천막 둘(따로) = 이핵 · 쌍이면 2핵(n+n) ≠ 2n** · **짝 칸 줄이 언덕을 넘어 길게 · 버섯 대까지 = 담자균은 n+n 이 길다 · 버섯 = 2핵균사의 자실체** · **가장 작은 칸에서 지퍼로 하나 된 줄무늬 큰 천막 + 번쩍 = 핵융합(2n 접합자 · 유일한 2배체)** · **곧바로 터져 낙하산 단 작은 천막 넷(파랑 둘 · 노랑 둘) = 감수분열 → 반수체 포자** · **빵 옆 산울타리 없는 긴 땅에 천막이 줄줄이 = 격벽 없는 다핵균사(접합균)**.
- 피할 것: 사람이 멘 자루 · 배낭(#배수성) · 모자 · 시계(시간은 왼쪽 → 오른쪽 길로) · 가위(#PDE — 울타리는 손으로 뽑는다) · A자 텐트(#PKA — 돔 천막만) · 포도(#포도당).
- 말로 꼭: 「천막 둘 ≠ 2n」 — 두 핵이 한 칸에 있어도 합쳐지기 전까지는 n+n 이다.
