# L17f 「집합관 수갱과 창을 다는 방」 — 집합관 · ADH · 요소 · 바사 렉타 · 두 틀선 칸 (2026-11-08 · 갈아엎기 9호)

> s17 여섯째(마지막) 과 — s17u03 행 6~20 · 카드 ≈ 35. 둑(주세포 · 사이세포)은 L17e 에.
> 장소 뜻: 둑 위 운하 = 피질 집합관 · 수갱 = 수질 집합관(내려갈수록 깊은 수질) · 수갱 바깥 껍질 = 간질 · 방 = 주세포 한 칸(왼 벽 = 관강막 · 맞은편 돌벽 = 기저외측막) · 구리관 = 핏줄.

## 약속 · 고리(옛 s17u03 그대로)
- 소금 껍질 쐐기 + 누런 요 = NaCl + 요소(수질 기울기) · 맨 아래 문의 누런 가루 = 요소 재순환 · 흰 쇠 V(볼트 셋) = ADH(V2 는 기저외측 → 바깥면에 꽂힘) · 물실이 옆으로 = 간질이 당긴다 · 항아리 = 최종 오줌 · 수레의 창틀 끼우기 = AQP2 삽입(창틀 둘 = 2) · 회 굳은 창 셋 · 넷 = AQP3 · AQP4 · 격자 넉 쪽 = 4량체 · 물방울 한 줄 · 유리 구 셋 화살 구리관 = 바사 렉타 역류교환 · 따로 선 역청 토막 기계 = 굵은 상행각이 기울기를 만든다 · 틀선 칸 둘 = 다른 날(ADH 없음 · 루프 이뇨제).
