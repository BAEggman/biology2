# L04d 「절지 갑옷 가게 — 네 칸 진열장」 — 절지동물 (2026-11-08 · 갈아엎기 26호)

> s04 넷째 과 — s04p04 절지 갑옷 가게(8행 · 카드 14) → 정거장 10. 장소: 갑옷 가게 안 — 2×2 진열장(왼쪽 위 갑각 · 오른쪽 위 곤충 · 왼쪽 아래 협각 · 오른쪽 아래 노래기 + 지네) · 가운데 받침대의 갑옷 한 벌(겹비늘 · 마디 리벳).

## 약속 · 고리(옛 그대로)
- 가재 껍질 같은 겹비늘 = 키틴 외골격(균류 세포벽과 같은 재료) · 팔꿈치 · 무릎 · 발목의 검은 쇠 리벳 = 관절지 · 투구의 더듬이 넷(둘 위 · 둘 앞) + 물통 = 갑각류(더듬이 2쌍 · 물) · 더듬이 둘 머리 위로만 = 곤충(1쌍 · 다리 3쌍) · 맨들맨들 투구 + 입 앞 엄니 한 쌍 = 협각류 · 허리의 황동빛 가는 관 다발 → 붉은 웅덩이 = 말피기관(곤충 + 거미 · 갑각류 없음) · 다리 빽빽 + 풀 + 짧은 더듬이 = 노래기(마디당 2쌍 · 초식) · 다리 성김 + 갈고리 독발톱 + 고기 + 긴 더듬이 = 지네(1쌍 · 육식). 진열장을 왼쪽 위부터 Z 자로 읽으면 더듬이 2 → 1 → 0.
