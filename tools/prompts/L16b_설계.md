# L16b 「2차 캠프장」 — 2차 전령 (2026-11-08 · 갈아엎기 2호)

> s16 둘째 과 — s16p02(고리 창구 · cAMP) + s16p02b(피자 작업대 · IP₃ · DAG · Ca²⁺) 8행 · 카드 76, 거기에 시험 단골 셋(에피네프린 → 글리코겐 분해 · 콜레라 독소 · 세포질 Ca²⁺ 낮게 유지)을 더함.
> 테마: **2차 캠프장** — 「2차 전령」의 2차(1차는 교환국 창구 · 2차는 안에서 이어지는 자리) + **캠프 = cAMP**. 장소 뜻 없음(캠프장은 세포 안 어딘가).

## 덱 약속 그대로 · 새 고리
- 그대로: 둥근 금화 = ATP → **구부린 금화 고리 = cAMP**(동전을 구부린 것 — ATP 에서 나온다 · 고리 = cyclic) · 짙은 회색 네모 칩 = GTP · 지게꾼 = G단백질(L16a) · 열쇠 = 키나아제 · **피자 = PIP₂ · 구멍 셋 조각 = IP₃ · 닭 = DAG · 자갈 = Ca²⁺**(옛 s16p02b 소리 고리 그대로) · 뚜껑 터진 드럼통 = 에피네프린(s07 · s49) · 포도 = 포도당(s49).
- 새 고리: **열쇠 걸린 A자 텐트 = PKA** · **C자 피자 커터 = 인지질분해효소 C** · **C자로 굽은 열쇠 = PKC** · **소포 상자 = 소포체** · **콜라 범벅 지게꾼 = 콜레라 독소에 걸린 G단백질**(콜라 ≈ 콜레라) · 가위 = PDE(고리를 자른다).
