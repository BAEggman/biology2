## 세계 · 약속
새 세계 「언덕 위 관찰소」(scene s52). 왼쪽 = 들여다보는 도구(현미경 탑) · 가운데 = 갈아서 돌리는 도구(믹서 + 회전그네) · 오른쪽 = 그렇게 갈라낸 미토콘드리아를 집 한 채로 키운 손님채와 그 내력(세포내 공생). 도구 → 분획 → 미토콘드리아 → 기원 순으로 왼쪽에서 오른쪽으로 읽는다.
- **진핵세포 모형** = 탁자의 큰 투명 공: 크림색 돔 천막 = 핵(【돔 천막】) · 천막과 껍질 사이의 물 = 세포질 · 문 달린 껍질 = 원형질막(흰 화살 + 흰 방울 = 들임 · 검은 화살 + 어두운 방울 = 내보냄). 접시 넷(아메바 · 갈색 버섯 · 청개구리 · 새싹) = 진핵 네 생물군.
- **크기**: 연노랑 알약 세균 ≈ 공 속 빨간 콩(미토콘드리아) · 투명 공은 훨씬 큼. 자(【눈금 자】 = 바사 렉타)는 쓰지 않았다.
- **S/V** = 분홍 물감 쟁반의 젤리 공(한천 덩이 실험): 큰 공은 겉 테만 물들고 속이 하얗다. 정육면체는 탄소 수 예약이라 공으로.
- **현미경**: 하얀 탑(등불의 넓은 물결빛 = 빛 · 긴 파장) / 검은 기둥(노란 작은 공 줄기 = 전자 · 덱의 전자 = 노란 작은 공). 화면 둘 — 번진 빨간 얼룩 하나(돋보기를 대도 하나 = 배율 ≠ 분해능) / 또렷한 체리 둘(가까운 두 점을 가름).
- **SEM / TEM**: 금칠(도금)한 털북숭이 공 + 지그재그로 훑는 빛 = 겉(3차원 표면) / 팽팽한 줄로 얇게 썬 한 장을 노란 공 줄기가 꿰뚫음 = 속(절편 투과). 칼(= K) 대신 줄로 썬다.
- **세포분획**: 믹서 = 균질화 · 차양 달린 회전그네의 유리관 = 원심분리(관이 바깥으로 날리며 무거운 것이 바닥으로). 그네 셋이 차례로 빨라지고 관 바닥 앙금이 차례 — 크림색 천막(핵) → 빨간 콩 + 초록 꼬투리(미토콘드리아 · 엽록체) → 카키 천 조각 + 보라 덩이(마이크로솜). 앙금은 모두 덱의 그 물건(천막 · 주름 콩 · L45a 꼬투리 · L48d 막사 천 · 보라 리보솜).
- **미토콘드리아 = 주름 커튼 손님채**(덱 표지 【안쪽 주름 = 미토콘드리아】): 크림색 겉벽(외막) · 겉벽을 꿰뚫은 짧은 관(포린 — 둥근 구멍은 핵공이라 피함) · 빨간 주름 커튼(내막 · 크리스타) · 안방(기질)의 일꾼(효소) · 금빛 끈 고리(DNA — L37b 「통 없는 맨 끈의 이음매 없는 고리」) · 보라 오뚝이(리보솜). 통풍구로 흰 방울(O₂)이 들고 홈통에서 금 동전(ATP)이 쏟아진다.
- **세포내 공생 = 손님을 들인 주모**: 크림색 한복 주모 = 숙주(초기 진핵세포) · 빨간 알약 손님 = 삼켜진 호기성 세균. 주모가 제 숄로 손님을 감싼다 → 손님은 제 빨간 외투(세균 막) 위에 숄(숙주 막)을 한 겹 더 = **이중막** — 손님채의 빨간 커튼 + 크림색 겉벽과 같은 빛이라 구조가 곧 내력이다. 손님은 동전(ATP)으로 방값을 낸다. 막걸리 = 마걸리스.
- **조상 둘**: 맨 흰 알(α — 【알 · 감 · 베】)을 들고 흰 방울을 들이마시는 빨간 손님 = 호기성 α-프로테오박테리아 / 청록(남빛) 손님이 햇볕 받는 지붕 위 초록 꼬투리(엽록체)로 = 남세균. 나무 오두막 = 식물세포.
- **기괴함**: 접시 위 청개구리 · 믹서 속 세포 · 금칠당하는 털북숭이 · 햄처럼 썰리는 세포 · 흐릿해질 만큼 도는 그네 · 땀 흘리며 춤추는 세포와 퍼질러 자는 세포 · 알약 손님을 숄로 싸는 주모 · 사다리 타는 청록 알약.
- ⚠ 피한 것: 눈금 자 · 정육면체 · 붉은 렌즈 · 놋쇠 스코프 · 대포(전자총 대신 줄기) · 칼 · 시험관 선반 · 세 층 유리병 · 세탁기 드럼 · 주전자 · 국자 · 표주박(국자꼴) · 여행 가방 · 자루 · 수면 모자 · 달리는 사람 · 역도 선수 · 초록 피부 사람 · 담장의 둥근 구멍.
