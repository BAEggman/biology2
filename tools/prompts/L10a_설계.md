# L10a 「한 레일 위 보라 정거장 셋 — 들고 들어오고 · 넘겨 잇고 · 빈손으로 나간다」 — 리보솜 세 자리와 번역 세 걸음 (2026-11-08 · 갈아엎기 68호)

> s10 첫 과 — s10p01(8행 · 카드 19) + 덱 데이터상 s48 묶음에 든 s10p01c(4행 · 카드 3) → 정거장 12. s10 묶음(번역)은 계획표 28번째지만, s48 의 마지막 남은 판(s10p01c)이 s10p01 의 세 자리 위에서만 서므로 같이 세운다. 나머지 s10p01b(개시 — 진핵 · 원핵) · s10p02(억제제 자물쇠)는 L10b · L10c 로 s10 차례에.
> 장소: 왼쪽 끝에 겨자색 중산모(5′ 캡)가 앉은 긴 겹줄 레일(mRNA) 하나 · 그 위에 똑같은 보라 정거장 셋(리보솜 · 위 큰 돔 = 큰 단위체 · 아래 작은 상자 = 작은 단위체 · 돔 앞을 갈라 좌석 셋 — 오른쪽 A · 가운데 P · 왼쪽 E). 왼쪽 정거장 = 개시 · 가운데 = 신장 · 오른쪽 = 종결 — 한 mRNA 에 여러 리보솜이 줄지어 읽는 폴리솜 꼴이고, 3′ 쪽으로 갈수록 사슬이 길다(1 → 5 → 10 구슬).

## 약속 · 고리
- 겹줄 레일 = mRNA · 왼쪽 끝 겨자색 중산모 = 5′ 캡(덱 예약 「모자」) · 정거장은 오른쪽(3′)으로 간다 = 5′ → 3′ 로 읽는다.
- 보라 정거장 = 리보솜(L48c 의 보라 짝을 크게) · 위 큰 돔 = 큰 단위체 · 아래 작은 상자 = 작은 단위체(레일을 문다) — 원핵 70S = 50S + 30S · 진핵 80S = 60S + 40S(S 는 더하지 않는다).
- 맨머리 사람 = tRNA(덱 약속 · 모자 금지) · 손의 구슬 하나 = 아미노산 · 구슬 사슬 = 폴리펩타이드(L48c).
- 좌석 셋 = 오른쪽 A(들고 들어온다) · 가운데 P(사슬을 쥐고 넘긴다) · 왼쪽 E(빈손으로 나간다).
- 정거장 옆 자판기 = 아미노아실-tRNA 합성효소 · 동전 = ATP(덱 예약) · 바닥의 쪼개진 동전 반쪽 둘 = ATP → AMP + PPi(고에너지 결합 둘) · 구슬 받은 사람 = 충전된 tRNA.
- 오른쪽 사람의 세 이빨 열쇠 = 안티코돈 · 레일 판의 열쇠구멍 = 코돈 · 끝 이빨만 빨간 고무 = 셋째 자리 요동(이노신이면 U · C · A).
- 돔 천장에서 내려온 보라 집게가 잇는 자리를 누름 = 펩티딜 전이효소는 큰 단위체의 rRNA(리보자임) · 가운데 사람은 동전 · 배낭 없음 = 펩타이드 결합에 따로 에너지 안 씀.
- 왼쪽 정거장: 가운데 좌석에 위에서 곧장 떨어져 앉음 · 오른쪽 좌석 빔 = 개시 tRNA 는 P 에 · 오른쪽 정거장: 오른쪽 좌석에 사람 아닌 나무판 = 방출 인자 · 사슬이 손에서 풀려 떨어짐 = 방출.
