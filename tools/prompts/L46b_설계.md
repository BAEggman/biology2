## 약속 · 고리
- 덱 그대로: 작은 나무집 + 노란 반달 문 = 심장(L46a) · 진홍 = 산소 많은 피 · 회청 = 산소 적은 피 · 유턴 금지 표지판 = 판막의 역류 방지(L46a) · 흰 방울 = O₂ · 연기 꼬리 단 어두운 방울 = CO₂ · 그물 = 기저막(L17a 의 가시 그물과 한 집안 — 이것은 가시 없는 가는 그물) · 호스 = 혈관(s17u01 수입세동맥).
- 새로: **고무 겹이 서넛인 두꺼운 벽 · 좁은 속 · 불룩 = 동맥(높은 압력 · 탄력)** · **얇은 벽 · 헐렁한 속 · 집 쪽으로만 젖혀지는 작은 문 셋 = 정맥과 판막** · **풀밭에 썰어 세운 토막 셋 = 단면**(진홍 겹겹 두꺼운 벽 · 작은 구멍 / 회청 얇은 벽 · 큰 구멍 / 분홍 한 겹 고리 + 겉 그물 = 내피 + 기저막 · 속을 꽉 채운 옴폭한 붉은 원반 = 내경이 적혈구 하나) · **입 달린 꽃 = 조직 — 흰 방울을 삼키고 어두운 방울을 뱉는다(교환)** · **부채 = 총 단면적(그림에서 가장 넓다)** · **실관에 거꾸로 매달린 나무늘보 = 가장 느린 혈류** · **압력계 바늘 셋 = 혈압 동 > 모 > 정** · **속도선 많음 · 조금 · 나무늘보 = 속도 동 > 정 > 모**.
- 피할 것: 달팽이(L04 연체 = 선구) → 나무늘보 · 코일 스프링(#티틴) → 고무 겹 · 국화(단일식물) → 둥근 민 꽃 · 돋보기(s11 「찾는다」) → 썰어 세운 토막 · 칼(L23a K⁺) → 토막만(칼 없이) · 맥주잔(L31c 효모) · 초승달(#80 CAM) → 반달 · 모자.
