# L36b 「한 바퀴 도는 마당」 — 세대교번 · 배우자(체세포분열) vs 포자(감수분열) (2026-11-08 · 갈아엎기 38호)

> s36 둘째 과 — s36p02 한 바퀴 도는 마당(8행 · 카드 31) → 정거장 9. 장소: 낮은 담장 앞 네 칸 — 첫째 칸(자루 하나가 도구 없이 둘로) · 둘째 칸(손 맞대고 자루 둘) · 셋째 칸(깔때기 · 주둥이 넷 · 두꺼운 껍질) · 넷째 칸(깨진 껍질 · 혼자 선 하나) · 머리 위 밧줄이 오른끝에서 왼끝으로 되돌아와 담장에 매임.

## 약속 · 고리(옛 그대로)
- 자루 한 개 = n · 두 개 = 2n(L36a 와 같은 표식) · 되돌아오는 밧줄 = 세대교번 한 바퀴 · 도구 없이 둘로 갈라짐 = 체세포분열로 배우자(이미 n) · 손 맞댐 + 자루 둘 함께 = 수정(n + n = 2n · 씨앗 공방의 손) · 깔때기 + 주둥이 넷 = 감수분열(2n 하나 → n 넷 · 이 마당의 유일한 반 가르기) · 몸을 감싼 두꺼운 껍질 = 스포로폴레닌 벽(건조 보호 · 파생형질) · 깨진 껍질 + 혼자 선 하나 = 포자는 융합 없이 혼자 배우체로.
