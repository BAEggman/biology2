- **버터 띠 = 세포막**. L50b 산장 선반의 버터(【녹아 흐르는 버터 / 얼어 고드름 달린 버터】 = 막 유동성)를 바닷속을 가로지르는 띠로 키웠다. 옆에서 본 단면 — 띠 위 밝은 물 = 세포 밖 · 아래 짙은 물 = 세포 안. 왼쪽 끝은 얼고(고드름) 오른쪽 끝은 햇살에 녹는다 → 온도가 그림의 가로축.
- **부표 사람 = 인지질**. 줄무늬 둥근 머리(친수성)는 물에 · 긴 두 다리(소수성 꼬리 둘)는 버터 속에 = 양친매성이 생김새 그대로. 두 줄 = 이중층 · 윗줄 빨간 머리 / 아랫줄 파란 머리 = 비대칭. 곧은 다리 = 포화(빽빽 · 얼어붙음) · 꺾인 무릎 = 불포화(틈 · 얼음 곁에서도 떨림 선) · 짧은 다리 = 짧은 꼬리.
- **구슬 기둥 = 막단백질**(덱: 구슬 사슬 = 단백질). 띠에 박힘 = 내재 · 띠를 끝까지 꿰뚫음 = 막관통 · 띠 속에서만 감긴 사슬 + 맨 흰 알(α) = 소수성 α나선 · 파란 머리에 사슬로 매달린 구슬 공 = 주변부.
- **기능 여섯(수활전인결부)** = 기둥마다 단 물건: 뚫린 굴(수송) · 작업대 일꾼(효소) · 우편함 + 켜진 등(신호전달 — L16d 봉투 · 우편함) · 막대사탕 다발 + 이웃의 하늘색 Y 집게(인식 · 면역글로불린 — L46c) · 큰 회색 대갈못으로 이웃 부교의 기둥과 이어짐(결합 — L14a 대갈못) · 밧줄 그물 + 살구색 구슬 줄(ECM · 미세섬유 부착 — L14b).
- **콜레스테롤** = 다리 사이에 낀 금빛 타일(【금빛 고리 넷 덩이】 문장). 꺾인 다리 쪽 = 옆걸음을 막음 · 언 쪽 타일 둘레만 노랗게 안 얼었다 = 고체화 방지 → 완충이 한눈에.
- **플립페이스** = 주황 오리발(flipper) 잠수부가 파란 머리 부표 사람을 들고 아랫줄로(굽은 화살).

- **막대사탕**(당 — L48d) = 기둥에 꽂히면 당단백질 · 부표 머리에 꽂히면 당지질 · 윗줄에만(세포 바깥 면).
- **기괴함**: 몸통 없이 머리와 다리뿐인 부표 사람 · 그 줄에 낀 소 · 돼지 머리 · 버터 속을 걷는 오리발 잠수부 · 얼음덩이에 갇혀 떠는 일꾼 · 녹아 흐르는 버터에 쓰러지는 기둥 · 사탕을 집는 Y 집게.
