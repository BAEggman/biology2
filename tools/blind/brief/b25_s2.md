# 블라인드 테스트 2단계 — 이름을 준 뒤 다시 보기 (묶음 b25)

이제 판마다 **그 그림이 가르치려는 개념의 이름 목록**을 준다(순서는 섞었다). 그리고 이 덱이 **모든 판에서 같은 뜻으로 쓰는 물건 약속**도 준다.
같은 그림을 다시 보고, 개념마다 **그림의 어느 물건이 그것을 나르는지** 가리켜라. 잇는 고리(소리 / 모양 / 글자 / 뜻 / 자리 / 개수)도 한 마디.
어느 물건도 그 개념을 나르지 못하면 「못 찾음」이라고 솔직히 적어라 — 억지로 끼워 맞추지 마라.
개념 하나에 물건이 둘 이상이면 다 적어라. 물건 하나가 개념 둘을 나르면 그것도 적어라.

결과: `/tmp/b2/tools/blind/out/<pid>.s2.json`
```json
{"pid":"…","map":[{"concept":"개념 이름(준 그대로)","obj":"그림의 물건 또는 못 찾음","link":"소리/모양/글자/뜻/자리/개수 + 한 마디","sure":"높음/중간/낮음"}]}
```
파일을 다 쓴 뒤 마지막 답으로 「2단계 끝」만 적어라.

## s36p01 「누가 업고 있나」
- 그림: /tmp/b2/tools/blind/png/s36p01.png
- 개념 목록:
1. 종자식물은 포자체 우세에 더해 배우체가 미세해지고 포자체 조직에 영양을 의존한다
2. 관속조직(목부·사부)이 있으면 키가 커진다
3. 배우체 축소의 흐름 그 자체다
4. 종자식물은 화분이 바람·동물로 운반되고(연) 화분관이 정자를 배우체에게 직접 전
5. 배우체는 n, 포자체는 2n이다
6. 땅에 붙은 실은 뿌리가 아니라 헛뿌리다
7. 관속식물은 포자체(2n)가 우세하다
8. 왼쪽이 선태식물, 가운데가 비종자 관속식물(석송류·양치류), 오른쪽이 종자식물이
9. 선태식물은 배우체(n)가 우세하고 포자체(2n)가 배우체에 영양을 의존한다
10. 선태·양치는 정자가 물 속을 헤엄쳐 난자에게 가야 한다

## s19p02m 「걸쇠 하나가 비면 아무도 못 간다」
- 그림: /tmp/b2/tools/blind/png/s19p02m.png
- 개념 목록:
1. 아직 방추사가 붙지 않은 「텅 빈 동원체」에 결합해 대기 신호를 보내는 단백질이
