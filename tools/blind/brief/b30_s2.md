# 블라인드 테스트 2단계 — 이름을 준 뒤 다시 보기 (묶음 b30)

이제 판마다 **그 그림이 가르치려는 개념의 이름 목록**을 준다(순서는 섞었다). 그리고 이 덱이 **모든 판에서 같은 뜻으로 쓰는 물건 약속**도 준다.
같은 그림을 다시 보고, 개념마다 **그림의 어느 물건이 그것을 나르는지** 가리켜라. 잇는 고리(소리 / 모양 / 글자 / 뜻 / 자리 / 개수)도 한 마디.
어느 물건도 그 개념을 나르지 못하면 「못 찾음」이라고 솔직히 적어라 — 억지로 끼워 맞추지 마라.
개념 하나에 물건이 둘 이상이면 다 적어라. 물건 하나가 개념 둘을 나르면 그것도 적어라.

결과: `/tmp/b2/tools/blind/out/<pid>.s2.json`
```json
{"pid":"…","map":[{"concept":"개념 이름(준 그대로)","obj":"그림의 물건 또는 못 찾음","link":"소리/모양/글자/뜻/자리/개수 + 한 마디","sure":"높음/중간/낮음"}]}
```
파일을 다 쓴 뒤 마지막 답으로 「2단계 끝」만 적어라.

## s48p01 「천막이 무너졌다가 다시 선다」
- 그림: /tmp/b2/tools/blind/png/s48p01.png
- 개념 목록:
1. 체세포분열(유사분열)은 다섯 단계
2. 염색질이 응축되어 염색체가 나타나기 시작하는 때가 전기다.
3. 중기판(metaphase plate)이란 염색체가 배열되는 가상의 중앙 평면이다
4. 후기다.
5. 염색체가 세포의 중앙(적도면)에 배열되는 때가 중기다.
6. 이 차례가 그대로 전기 → 전중기 → 중기 → 후기 → 말기다.
7. 염색체가 다시 염색질로 풀리고 핵막이 재형성되는 때가 말기다.
8. 방추사가 형성되기 시작하는 때가 전기다.
9. 핵막이 완전히 소실되고 방추사가 동원체에 결합하는 때가 전중기다.
10. 핵막과 인이 사라지기 시작하는 때가 전기다.
