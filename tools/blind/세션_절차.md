# 그릴 때마다 블라인드 1세션 — 「복원이 되는가」 (2026-10-13 신설)

> 사용자 지시(그대로): 「매번 그릴 때마다 블라인드테스트를 1세션 실행해보고 복원이 되는지 검증도 해보자」
> → 판을 새로 그리거나 고칠 때마다, 그 판에 대해 **처음 보는 판독자** 둘이 그림에서 사실표를 **복원**하는지 잰다.
> 못 복원한 행은 고치고(그림 또는 글), **고친 뒤 새 판독자로 다시 잰다**. 같은 판독자에게 다시 보이면 기억이 섞인다.

## 왜 README 의 3단계와 다른가
- 예전 1단계는 **단원명 · 판 제목**을 줬다 → cold 가 제목 덕을 봤다(지시서 2026-09-11 R2).
  여기서는 **그림만** 준다. 판 표제어를 그림에서 읽어 내는지가 통합판의 목적(한 단원이 한 장에서 한눈에)이기 때문이다.
- 단계를 셋으로 나눠 **실제 학생의 순서**를 흉내 낸다:
  1. **생판**(그림만) → `cold` — 처음 보는 사람에게도 읽히는가
  2. **덱 약속표**(`reservations.md`)를 준 뒤 → `warm` — 덱을 배우고 온 학생이 이 판에서 사실을 **복원**하는가 ← **합격 잣대**
  3. **개념 이름 목록**(섞어서)을 준 뒤 → `cued` — 이름을 들으면 그림에서 되찾는가(Sketchy 가 실제로 기대는 것)
- 채점자는 따로(Opus). 「약속표 덕」「이름 목록이 흘림」「배경지식으로 맞힘」을 note 에 밝힌다.

## 절차 바뀜 — 2026-11-02 (b137 부터) · 2단계에 「까닭」을 묻는다

## 잣대 바꿈 — 2026-11-04 · 닻 판 대조 · 판 표제어 = 단원 줄기
> 사용자 선택(그대로): 「닻 판 대조로 바꿈 (권장)」 · 「단원 줄기가 서면 Y (권장)」
- **warm — 닻 판 대조**: 채점자 하나가 새 판과 닻 판(채택판의 판독 — 지금은 s45u01 · b141, `tools/blind/anchor/s45u01_b141/`)을 같은 잣대 · 같은 채점 메모로 함께 매긴다. 새 판 두 독자의 warm 평균이 닻 두 독자의 평균보다 **2 행**(사실 행 수가 다르면 그만큼의 %p) 넘게 낮지 않으면 통과. 90% 는 참고로만.
- **판 표제어 — 단원 줄기**: 1순위가 그 판의 단원 줄기를 세우면 Y. 하위 갈래는 구역 표제어가 따로 잰다(겹쳐 재지 않는다). 줄기는 `--trunk` 로 준다.
- 도구: `setup_session.py --anchor tools/blind/anchor/<pid>_<batch> --trunk "<단원 줄기>" [--memo <판 채점 메모 파일>]` — 닻의 그림 · 정답표 · 그때 약속표 · 학생 답을 작업폴더 `anchor/` 에 복사하고, 채점 지시에 닻 절 · 표준 채점 메모(틀 행 · 구역 쪼개기 · ★ · ⚠ · 정답표 전체 · 손질 자국) · 까닭 효과 · 판정 칸을 넣는다(b140 · b141 때 손으로 붙이던 것).
- 닻 폴더는 그때의 그림 · 정답표 · 약속표를 얼려 둔다(채택판이 나중에 다시 그려져도 닻은 그대로). 독자 물음이나 약속표가 크게 바뀌면 닻을 새로 읽힌다.
- 두 독자가 다 못한 행은 **고칠 자리 목록**으로 적는다 — 통과를 막는 문이 아니다(닻도 같은 잣대에서 두 독자가 다 못한 행이 있다).
- 첫 적용: s45u02 b140 판독을 닻과 함께 다시 채점(새 독자 없음) → 판 표제어 Y · Y(줄기) · 구역 4/4 · 4/4 · warm 13 · 13 대 닻 16 · 18(−4.0 행) → **통과 N**. 보관 `out/s45u02_판독/b140/닻대조/`.

## 합격 기준
> 2026-11-04 부터(위 「잣대 바꿈」). 그 전에 채택한 판은 그때 기준(warm ≥ 90% · 판 표제어 = 주제)으로 채택된 그대로 둔다.
- 판 표제어 1순위가 그 판의 **단원 줄기**를 세운다 — 1·2단계 둘 다
- 구역(통합판)마다 표제어가 맞는다
- **사실 warm — 닻 판 대조**: 같은 채점자가 함께 매긴 닻 판(s45u01 · b141 판독)의 두 독자 평균보다 2 행 넘게 낮지 않다(틀 행 제외) — 90% · cued 는 참고로 함께 적는다
- 두 판독자가 **다 못한 행**(warm ≠ Y)은 고칠 자리 목록으로 — 다음 손질의 1순위. 한 사람만 못한 행은 note 를 읽고 판단한다.

## 하는 법
```
python3 tools/blind/setup_session.py <pid> <batch> <작업폴더>      # 그림 · 약속표 · 섞은 이름 목록 · 프롬프트 넷을 작업폴더에
#  통합판(2026-11-04 부터): --unified --topic "<판 정답>" --trunk "<단원 줄기>" --zones "<구역=표제어; …>" --anchor tools/blind/anchor/s45u01_b141 [--memo <판 채점 메모>]
```
1. 판독자 A · B — `Agent(general-purpose, model=sonnet)` 둘을 **동시에** `prompt_stage1_A.txt` · `_B.txt` 로.
2. 둘 다 끝나면 `SendMessage` 로 `prompt_stage2.txt`(폴더 이름만 A/B 로) → 끝나면 `prompt_stage3.txt`.
3. 채점자 — `Agent(general-purpose, model=opus)` 에 `prompt_grader.txt`.
   결과: `tools/blind/out/<pid>.json`(A, 표준 꼴 — report.js 가 읽는다) · `<pid>.B.json` · `<pid>.통합판독.json`.
4. 끝나면 판독자 답과 채점을 `tools/blind/out/<pid>_판독/<batch>/` 로 옮겨 남긴다(다음 재검이 out/ 를 덮으므로).
5. 고칠 자리 → 고침 → **새 묶음 번호로** 1부터 다시(판독자는 새로 띄운다).
