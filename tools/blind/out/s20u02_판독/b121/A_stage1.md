# 1단계 생판 — s20u02 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위 **옥신과 식물의 굴성(굴광성·굴지성)** — 85%
- 2순위 **굴광성 실험의 역사(다윈→보이센옌센→웬트, 옥신의 발견)** — 10%
- 근거: 창 한 곳에서 오는 파란 빛, 줄기 끝마다 달린 '눈', 끝을 가리고·자르고·막는 여섯 가지 처리, 노란 알갱이가 그늘 쪽에만 몰린 큰 단면 식물, 눕힌 화분에서 위로 휜 줄기와 아래로 휜 뿌리.

## ② 구역별 읽기 (왼쪽부터 4구역)

### 구역1 창 + 왼쪽 탁자 3그루 — **다윈의 실험: 빛을 받는 곳은 줄기 끝**
1. 창(파란 유리 6칸)+파란 빛줄기+바닥의 창 모양 빛무늬 = 한쪽 옆에서만 오는 빛, 단방향 자극 (자리).
2. 빛이 파랑 = 굴광성에 듣는 빛은 청색광 (색, 확신 중간).
3. 식물1, 처리 없음: 눈과 줄기가 창 쪽으로 굽음 = 정(+)굴광성, 대조군 (뜻).
4. 식물2, 눈 위에 끈으로 묶은 검은 천주머니: 곧게 섬 = 끝을 가리면 안 굽는다, 빛 감지부는 끝 (자리).
5. 식물3, 눈은 드러내고 아랫줄기에 검은 테이프: 그래도 굽음 = 굽는 곳이 빛을 못 봐도 되고 끝에서 아래로 무언가 전달됨 (자리).
6. '눈' = 줄기(초엽) 끝이 빛을 본다, 눈이 창 쪽을 향함(식물6만 정면) (뜻).
- 덧붙임: 세 식물은 같은 탁자·같은 빛 아래 처리만 달라 비교실험 설계(대조군+처리군)로 읽힘. 휜 것은 1·3, 곧은 것은 2.

### 구역2 가운데 탁자 3그루 + 누운 눈 — **보이센옌센·웬트: 끝의 신호는 통과하는 물질**
1. 식물4, 끝 토막과 줄기 사이의 반투명 노란 큐브(한천/젤라틴 1개): 끼워도 창 쪽으로 굽음 = 신호가 블록을 통과하는 화학물질 (모양·뜻).
2. 식물5, 끝이 잘린 그루터기(고리 단면): 곧게 서서 안 굽음 = 끝이 없으면 굽지 않음, 끝이 신호의 근원 (자리).
3. 탁자 위에 누운 눈 1개 = 떼어낸 끝, 식물5의 것으로 보임 (자리).
4. 식물6, 눈 바로 밑을 가로지른 얇은 투명 팔각판(운모): 곧게 섬 = 물질이 못 지나가면 굽지 않음 → 신호는 화학물질 (모양·뜻).
- 덧붙임: 4와 1이 짝(통과하는 블록 대 못 통과하는 판), 휜 것은 4, 곧은 것은 5·6. 잘린 단면이 속 빈 고리라 초엽처럼 관 모양.

### 구역3 큰 식물(바닥의 큰 화분, 속을 보인 단면) — **콜로드니-웬트: 옥신이 그늘 쪽에 몰려 세포를 늘림**
1. 노란 옥수수알 모양 알갱이 25개 = 옥신(IAA) (소리 옥수수~옥신, 모양; 25의 뜻은 모름).
2. 알갱이가 빛 반대(그늘) 쪽 가장자리에만 한 줄 = 옥신이 그늘 쪽으로 몰림, 측방 이동 (자리).
3. 줄이 눈 뒤에서 흙선까지 이어짐 = 끝에서 만들어 아래로 이동, 극성 수송 (자리).
4. 그늘 쪽 세포는 긴 칸 1열, 빛 쪽은 작은 정사각 칸 2열 = 옥신 쪽 세포가 더 길게 자람 (모양).
5. 줄기가 창 쪽으로 활처럼 굽고 눈이 창을 봄 = 그늘 쪽이 더 자라 빛 쪽으로 굽음 (뜻).

### 구역4 오른쪽 방, 눕힌 투명 화분 — **굴지성: 줄기는 음(−), 뿌리는 양(+), 평형석**
1. 화분을 눕혔고 방에 창이 없음 = 중력만이 자극 (자리).
2. 초록 줄기가 입구로 나와 위로 굽음 = 음(−)굴지성 (뜻).
3. 줄기 알갱이 약 25개와 긴 세포가 아래쪽 = 아래쪽 옥신이 많아 신장 촉진 → 위로 굽음 (자리·모양).
4. 크림색 뿌리가 흙 속에서 아래로 굽어 컵으로 = 양(+)굴지성 (뜻).
5. 뿌리 알갱이(약 16개, 작음)도 아래쪽 = 같은 옥신이 뿌리에서는 아래쪽 신장을 억제, 뿌리가 더 민감 (뜻, 확신 중간).
6. 뿌리 끝이 든 작은 컵 바닥의 검은 공 5개 = 평형석(아밀로플라스트)이 가라앉아 중력 감지, 컵은 뿌리골무(근관)의 균형세포 (모양·뜻).

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이어 붙인 흔적
- 모름: 창 6칸(2×3), 알갱이 개수 25·25·약16과 공 5의 숫자 뜻, 알갱이 뾰족한 끝이 세포 쪽을 향하는 뜻, 컵 벽의 물방울 점, 큰 식물 세포 2+1열의 구성.
- 구조: 두 칸(왼쪽 방 = 빛 / 오른쪽 방 = 중력), 왼쪽 방의 눈은 6개(식물1·3·4·6, 누운 눈, 큰 식물), 탁자 2개에 화분 3+3.
- 어색: 오른쪽 방 줄기는 눈 없는 매끈한 끝(빛이 없는 방이라서?), 큰 식물만 바닥에 크게 섬(확대 설명용), 뿌리 알갱이가 훨씬 작음.
- 헷갈림: 한천(웬트)과 젤라틴(보이센옌센) 블록 구분 불가, 식물2(끝 가림)와 식물3(아랫줄기 가림)의 검정 처리, 투명판이 운모인지 유리인지, 누운 눈이 어느 식물 것인지.
- 이어 붙임: 큰 식물과 화분 오른쪽 둘레의 흰 후광(오려 붙인 가장자리), 오른쪽 화분 테두리 구간에서 뿌리의 베이지 띠가 알갱이 없이 끊겼다 줄기에서 다시 시작.

## ④ 한 문장
한쪽에서 오는 빛을 줄기 끝이 감지해 만든 옥신이 그늘 쪽으로 몰려 그쪽 세포를 늘려 줄기가 빛 쪽으로 굽고(굴광성), 눕히면 옥신이 아래쪽에 쌓여 줄기는 위로(−)·뿌리는 아래로(+) 굽는다(굴지성).
