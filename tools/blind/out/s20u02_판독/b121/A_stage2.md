# 2단계 — 약속표로 다시 읽기 (s20u02)

## 판정
약속표로 더 잘 풀림(1단계의 약함·모름 중 7곳 풀리고 6곳 남음). 풀린 것: #13 옥수수 알갱이=옥신, #122 눈=포토트로핀, #125 파란 창·빛줄기=청색광, #123·#124 골무+회색 낟알=뿌리골무+평형석, #126 같은 화분 줄지어 하나씩 다름=대조 실험, #118 틀선 칸=다른 조건. 안 풀린 것(약속표에 없어 끼우지 않음): 노란 큐브, 투명판, 검은 주머니·테이프, 개수들. 비슷해 보여도 쓰지 않은 것: #4 자갈, #16 어두운 방울, #119 물방울, #151 격자창 개수, #1 모자.

## ① 판 표제어
- 1순위 **굴성: 굴광성과 굴지성(청색광·포토트로핀·옥신·평형석)** — 90% ↻ (85→90, 포토트로핀·평형석이 약속으로 확정되어 옥신 중심에서 굴성 중심으로)
- 2순위 **굴광성: 청색광 수용과 옥신 재분배, 다윈·보이센옌센·웬트 실험** — 7% ↻

## ② 구역별 (왼쪽부터 4구역)

### 구역1 창 + 왼쪽 탁자 3그루 — **굴광성: 청색광을 받는 자리는 눈(줄기 끝)**
1. ↻ 파란 유리창 + 파란 빛줄기(벽의 가는 사선들) + 바닥의 창 모양 푸른 무늬 = 청색광 (#125; 1단계 '확신 중간' → 확정).
2. 빛이 창 한쪽에서만 옴 = 단방향 자극 (자리).
3. ↻ 눈(하늘색 홍채의 흰 눈알) = 청색광 수용체 포토트로핀, 빛을 받는 자리 (#122; 1단계 '약한 암시' → 확정). 줄기 끝에 달림 = 받는 자리는 끝.
4. ↻ 같은 화분이 줄지어 하나씩만 다름 = 한 가지만 바꾼 대조 실험 (#126; 1단계는 덧붙임 → 사실로 셈).
5. 식물1(처리 없음): 눈이 창을 보고 창 쪽으로 굽음 = 정굴광성, 대조.
6. 식물2(눈 위에 끈 묶은 검은 천주머니): 곧음 = 눈을 가리면 안 굽는다.
7. 식물3(눈은 열고 아랫줄기에 검은 테이프): 굽음 = 줄기가 빛을 못 봐도 눈이 받으면 굽는다.

### 구역2 가운데 탁자 3그루 + 누운 눈 — **눈에서 내려오는 신호: 통과하면 굽고 막으면 안 굽는다**
1. 식물4(눈 토막과 줄기 사이 반투명 노란 큐브): 굽음 = 블록을 통과하는 물질 (한천/젤라틴 구분은 약속표에 없음).
2. 식물5(눈 없이 잘린 그루터기, 속 빈 고리 단면): 곧음 = 눈이 없으면 굽지 않음.
3. ↻ 탁자 위에 누운 눈 = 떼어낸 포토트로핀 자리, 식물5의 것으로 보임.
4. 식물6(눈 밑을 가른 얇은 투명 팔각판): 곧음 = 못 지나가게 막으면 굽지 않음 (운모/유리는 약속표에 없음).

### 구역3 큰 식물(속을 보인 단면) — **옥신이 그늘 쪽에 쏠려 세포를 늘림**
1. ↻ 옥수수 알갱이 25개 = 옥신 (#13; 1단계는 소리·모양 근거 → 약속 근거로 확정).
2. ↻ 알갱이가 그늘 쪽에만 한 줄 = '한쪽에 몰리면 그쪽에 옥신이 많다' (#13 그대로).
3. 줄이 눈 뒤에서 흙선까지 아래로 = 극성 수송 (#13의 '아래로만 흘러내림'과 같은 방향).
4. 그늘 쪽 긴 세포 1열, 빛 쪽 작은 정사각 세포 2열 = 옥신 쪽 세포가 더 길어짐 (모양; 약속표에 없는 내 읽기).
5. 줄기가 창 쪽으로 활처럼 굽고 눈이 창을 봄 = 그늘 쪽이 더 자라 빛 쪽으로 굽음.

### 구역4 오른쪽 방, 눕힌 투명 화분 — **굴지성: 줄기는 위(−), 뿌리는 아래(+), 뿌리골무의 평형석**
1. ↻ 틀선으로 떼어 낸 칸 = 같은 장면의 다른 조건 (#118): 빠진 것 = 창·빛줄기·눈·탁자들, 더해진 것 = 눕힌 화분·골무 → 빛 없이 중력만 자극 (1단계는 '창 없음'만 읽음).
2. 초록 줄기가 입구로 나와 위로 굽음 = 음(−)굴지성.
3. 줄기 알갱이 약 25개와 긴 세포가 아래쪽 = 아래쪽 옥신이 많아 신장 → 위로.
4. 크림색 뿌리가 흙 속에서 아래로 굽어 골무로 = 양(+)굴지성.
5. 뿌리 알갱이(약 16개) 아래쪽 = 같은 옥신이 뿌리에서는 아래쪽 신장을 억제 (내 읽기; 약속은 '쏠림=많음'까지).
6. ↻ 뿌리 끝에 씌운 오목한 점무늬 컵 = 바느질 골무 = 뿌리골무(근관) (#123; 1단계 '균형세포'를 근관 전체로 정정, 벽의 점은 골무 무늬로 풀림).
7. ↻ 골무 바닥에 가라앉은 짙은 회색 낟알 5개 = 평형석(녹말체) (#124).

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이어 붙인 흔적
- ↻ 풀림: 알갱이 뾰족한 끝 = 옥수수 알 꼭지(뜻 없음), 뿌리 알갱이·줄기가 가는 것 = 칸 속 축소판이라 뜻 없음(#118), 오른쪽 줄기에 눈이 없는 것 = 빛 없는 칸에서 빠진 것, 컵 벽의 점 = 골무 무늬.
- 남은 모름: 큐브(한천/젤라틴), 투명판(운모/유리), 검은 주머니·테이프(차광으로 읽음), 알갱이 25·25·약16과 공 5와 창 6칸의 숫자, 세포 2+1열, 눈이 정면인 식물6.
- 헷갈림: 회색 공 대 자갈(#4)·어두운 방울(#16) — 매끈한 둥근 낟알이 골무 바닥에 가라앉아 평형석으로 갈림.
- 이어 붙임(그대로): 큰 식물·화분 둘레의 흰 후광, 오른쪽 화분 테두리에서 뿌리 알갱이 줄이 베이지 띠로 끊겼다 줄기에서 다시 시작.

## ④ 한 문장
청색광을 눈(포토트로핀)이 받는 줄기 끝에서 옥수수 알갱이(옥신)가 그늘 쪽으로 쏠려 그쪽 세포가 길어져 줄기가 빛 쪽으로 굽고(굴광성), 눕히면 뿌리골무 속 평형석이 가라앉아 중력을 알리고 알갱이가 아래쪽에 쏠려 줄기는 위로·뿌리는 아래로 굽는다(굴지성).
