# stage1 — 생판 (s20u02, 2048x868, 두 방을 이은 통합판)

## ① 판 전체 표제어
- **1순위: 옥신(auxin)과 식물의 굴성 — 굴광성·굴중성** (90%)
- **2순위: 옥신의 발견 실험(다윈, 보이센옌센, 웬트)과 옥신의 작용(극성 이동, 세포 신장)** (45%)
- 근거: 노란 옥수수알 줄(소리: 옥수수, 옥신)이 모든 식물에 달려 있다. 왼쪽 방은 창 한쪽에서 오는 푸른 빛, 오른쪽 방은 창이 없고 화분을 눕혔다(중력만).

## ② 구역별 (왼쪽부터)

### 구역1 — 창문·빛줄기 + 책상1(화분 3): **다윈 실험 — 빛은 끝(눈)이 받는다**
1. 창(6칸)·푸른 빛줄기·바닥의 창무늬·화분 그림자가 오른쪽으로 눕는다: 빛이 왼쪽 한 방향에서만 온다 [자리]
2. 빛도 눈동자도 푸른색: 굴광성에 듣는 빛은 청색광, 수용체 포토트로핀 [색, 확신 중]
3. 눈 = 빛을 감지하는 줄기 끝(어린잎집 끝) [뜻]
4. 화분1(손 안 댐): 눈이 창을 보고 왼쪽으로 휨 = 양성 굴광성, 대조 [자리]
5. 화분2: 끈으로 묶은 검은 천주머니가 눈을 덮음 → 곧게 섬 = 끝을 가리면 안 굽는다 [모양]
6. 화분3: 눈은 내놓고 검은 테이프가 아래 줄기를 감음 → 그래도 굽음 = 감지는 끝, 굽는 곳은 아래 [자리]

### 구역2 — 책상2(화분 3 + 책상 위 누운 눈): **보이센옌센 — 끝에서 내려오는 확산성 화학 신호**
1. 화분5: 눈 없는 그루터기가 곧게 섬, 잘린 눈은 책상에 누움 = 끝을 떼면 안 굽는다 [모양]
2. 화분4: 눈과 그루터기 사이에 노란 반투명 정육면체(젤라틴/한천 블록) → 그래도 왼쪽으로 굽음 = 물질이 확산으로 통과 [자리]
3. 화분6: 눈 바로 밑을 가로지른 얇은 투명 판(운모 추정) → 곧게 섬, 눈은 정면 = 불투과막이 신호를 막는다 [자리]
4. 셋을 겹치면 신호는 끝에서 아래로 내려가는 이동성 화학물질 [뜻]

### 구역3 — 바닥의 거대 식물: **옥신의 그늘 쪽 이동 → 그늘 쪽 신장 → 빛 쪽 굽음 (콜로드니-웬트)**
1. 노란 옥수수알 = 옥신 [소리: 옥수수, 옥신 / 모양]
2. 알 25개가 오른쪽(빛 반대) 가장자리 한 줄에만 = 그늘 쪽에 옥신 집중 [자리·개수]
3. 알 줄이 눈 바로 밑 끝에서 시작해 밑동까지 = 끝에서 만들어져 아래로만 흐름(극성 이동) [자리]
4. 알 쪽 세포는 길쭉한 세로칸, 반대쪽은 작은 정사각칸 3줄 = 옥신이 세포 신장을 촉진 [모양]
5. 눈이 창을 보고 윗부분이 크게 왼쪽으로 휨 = 결과는 빛 쪽 굽음 [모양]
6. 오른쪽은 빛이 사라져 크림색 벽 = 그늘 쪽 [자리]

### 구역4 — 오른쪽 방 왼쪽, 눕힌 투명 화분 속 뿌리·컵: **뿌리의 양성 굴중성 — 평형석**
1. 창 없는 방 + 눕힌 화분 = 빛 없이 중력만 자극 [자리]
2. 흙 속 크림색 뿌리가 아래로 꺾여 컵으로 = 양성 굴중성 [모양]
3. 알 16개가 뿌리 아래(안쪽) 가장자리에 = 옥신이 아래쪽에 모임 [자리·개수]
4. 같은 쏠림인데 뿌리는 아래로 굽음 = 뿌리에선 옥신이 신장을 억제 [뜻]
5. 뿌리 끝을 덮은 투명 골무 모양 컵 = 뿌리골무(근관), 평형세포 [모양]
6. 컵 바닥에 검은 공 5개 = 평형석(녹말체)이 중력 쪽으로 가라앉음 [모양·개수]

### 구역5 — 오른쪽 방 오른쪽, 입구 밖 줄기: **줄기의 음성 굴중성**
1. 화분 밖 줄기가 수평으로 나왔다가 위로 휨 = 음성 굴중성 [모양]
2. 알 약 26개가 아래쪽(중력 쪽)에만 = 옥신이 아래로 이동 [자리·개수]
3. 아래쪽 세포 길쭉, 위쪽 작은 칸 = 줄기는 아래가 더 자라 위로 휨 [모양]
4. 눈 없는 매끈한 끝 캡 경계 아래에서 알 줄이 시작 = 끝에서 공급 [자리, 확신 하]

## ③ 잔결
- 뜻 모를 것: 컵 벽의 하얀 점(물방울?), 알 끝의 흰 뾰족 꼭지, 뿌리 중간의 굵은 크림색 마디(유리 벽 통과 표현? 하배축?)
- 어색: 화분3 테이프가 밑동은 비우고 가운데만 덮음, 오른쪽 줄기 끝에 눈이 없음, 거대 식물만 속이 보이는 단면
- 헷갈림: 블록(통과)과 판(차단), 검은 주머니(끝)와 테이프(아래), 같은 알 위치인데 줄기는 촉진·뿌리는 억제, 누운 눈이 화분5 것인지
- 이음 흔적: 두 방 사이 틈과 반대쪽 모서리, 거대 식물·오른쪽 줄기·뿌리에 흰 윤곽과 다른 선 굵기, 푸른 빛층이 거대 식물 앞에서 갑자기 사라지고 희미한 대각선

## ④ 한 문장
끝에서 만든 옥신(옥수수알)이 빛·중력 반대쪽으로 쏠리면 줄기는 그쪽이 길어져 빛 쪽·위로 굽고 뿌리는 억제되어 아래로 굽는다. 그 신호가 끝에서 내려오는 화학물질임은 다윈·보이센옌센 실험이 보여 준다.
