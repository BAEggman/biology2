# stage2 — 약속표로 다시 읽기 (s20u02, ↻ = 1단계와 달라진 곳)

## 약속 판정 (정직)
- 맞아떨어진 약속 7개: #13 옥수수 알갱이=옥신(몰린 쪽에 옥신 많다) · #122 파란 홍채 눈알=포토트로핀(빛을 받는 자리) · #125 파란 유리창·빛줄기=청색광 · #123 바느질 골무=뿌리골무 · #124 골무 속 짙은 회색 낟알=평형석 · #126 같은 화분 줄·하나씩만 다름=대조 실험 · #118 틀선 칸=같은 장면의 다른 조건.
- 판정: 줄거리·표제어 불변. 1단계의 짐작을 확정하고 확신도를 올린 쪽이 대부분이며, 새로 풀린 것은 컵 벽의 점무늬, 줄기에 눈이 없는 까닭, 개수(5·25·26·16)가 뜻 없다는 점뿐이다.
- 약속 밖(1단계 읽기 그대로): 젤라틴 블록 · 운모 판 · 검은 주머니와 테이프 · 잘린 눈 · 세포 칸 모양. 검은 주머니는 사람 모자도 5′ 캡(#1)도 아니라서 약속에 끼우지 않았다.

## ① 판 전체 표제어
- **1순위: 굴성 — 굴광성(청색광·포토트로핀·옥신 재분배)과 굴중성(평형석·뿌리골무)** (93%) ↻ 이름 구체화, 90에서 93
- **2순위: 옥신의 발견 실험(다윈, 보이센옌센)과 옥신의 작용** (35%) ↻ 45에서 35
- 근거: 파란 창·눈알·골무·평형석은 굴성 어휘, 옥수수알이 두 칸을 잇는다.

## ② 구역별 (왼쪽부터)

### 구역1 — 창 + 책상1: **다윈 실험 — 빛을 받는 자리는 끝(눈)**
1. ↻ 파란 유리창(6칸) · 파란 빛줄기 · 바닥의 창무늬 = 청색광, 왼쪽에서만 [#125 확정, 1단계는 확신 중]
2. ↻ 파란 홍채 눈알 = 청색광 수용체 포토트로핀, 빛을 받는 자리는 줄기 끝 [#122, 1단계 2·3번을 하나로]
3. ↻ 같은 화분이 줄지어 하나씩만 다름 = 한 가지만 바꾼 대조 실험, 화분1이 무처리 [#126 신규]
4. 화분1: 눈이 창을 보고 굽음 = 양성 굴광성
5. 화분2: 검은 천주머니가 눈을 덮음 → 곧음 = 수용체를 가리면 안 굽는다
6. 화분3: 눈은 두고 아래만 검은 테이프 → 굽음 = 빛은 끝에서 받고 굽는 곳은 아래

### 구역2 — 책상2: **보이센옌센 — 눈에서 내려오는 확산성 화학 신호**
1. 화분5: 눈을 뗀 그루터기는 곧음, 눈은 책상에 누움 = 눈을 떼면 안 굽는다
2. 화분4: 눈과 그루터기 사이 노란 반투명 블록(젤라틴/한천) → 굽음 = 물질이 통과
3. 화분6: 눈 밑의 얇은 투명 판(운모) → 곧음, 눈 정면 = 불투과막이 막음
4. 셋을 합치면 신호는 눈에서 아래로 가는 이동성 화학물질
- ↻ 관찰(수 안 셈): 이 줄 여섯 그루엔 옥수수알이 없다 — 신호의 정체(옥신)는 구역3에서 드러나는 짜임(확신 하).

### 구역3 — 거대 식물: **옥신의 그늘 쪽 이동 → 그늘 쪽 신장 → 빛 쪽 굽음**
1. ↻ 옥수수 알갱이 = 옥신 [#13 확정, 1단계는 소리 추정]
2. ↻ 알 25개가 오른쪽(빛 반대) 한 줄에만 = 몰린 쪽에 옥신이 많다 [#13, 개수 25는 뜻 없음]
3. 알 줄이 눈 밑 끝에서 밑동까지 = 끝에서 아래로(극성 수송) [자리, 확신 중]
4. 알 쪽 세포는 길쭉, 반대쪽은 작은 정사각 = 옥신이 신장 촉진 [모양, 약속 밖]
5. ↻ 눈(수용체)이 파란 빛 쪽을 보고 윗부분이 왼쪽으로 굽음 = 굴광성의 결과 [#122·#125]
6. 오른쪽은 파란 빛이 안 닿는 크림 벽 = 그늘 쪽

### 구역4 — 오른쪽 칸 왼쪽, 눕힌 화분 속 뿌리·골무: **뿌리의 양성 굴중성 — 뿌리골무 속 평형석**
1. ↻ 틀선 칸: 파란 창과 눈이 빠지고 화분이 눕혀짐 = 같은 식물의 다른 조건, 빛 없이 중력만 [#118·#125]
2. 뿌리가 아래로 꺾여 골무로 = 양성 굴중성
3. 알 16개가 뿌리 아래쪽 = 아래쪽에 옥신 많음 [#13]
4. 같은 쏠림인데 뿌리는 아래로 굽음 = 고농도 억제(#13 시든 잡초와 같은 결)
5. ↻ 바느질 골무가 뿌리 끝을 덮음 = 뿌리골무, 벽의 하얀 점은 골무의 오목점으로 풀림 [#123, 모양·자리]
6. ↻ 골무 바닥에 가라앉은 짙은 회색 둥근 낟알 5개 = 평형석(녹말체), CO₂ 방울 아님 [#124, 개수 5는 뜻 없음]

### 구역5 — 오른쪽 칸 오른쪽, 입구 밖 줄기: **줄기의 음성 굴중성**
1. 수평으로 나와 위로 굽음 = 음성 굴중성
2. 알 26개가 아래쪽에만 = 아래쪽에 옥신 많음 [#13]
3. 아래쪽 세포 길쭉 = 줄기는 아래가 더 자라 위로 굽음
4. ↻ 눈 없는 매끈한 끝 = 청색광 수용체를 안 쓰는 칸(빛이 아니라 중력) [#122의 부재 + #118, 1단계는 모름]
5. 알 줄이 끝 캡 선 밑에서 시작 = 끝에서 공급 [자리, 확신 하]

## ③ 잔결
- 풀림: 컵 점무늬, 줄기에 눈 없음, 개수 무의미.
- 그대로: 블록(통과)과 판(차단), 검은 주머니(끝)와 테이프(아래), 같은 알 위치에서 줄기 촉진·뿌리 억제, 알 끝의 흰 꼭지, 유리 벽을 지나는 굵은 크림 마디(연결 표현으로 읽음).
- ↻ 이음 흔적 보강: 크림 뿌리가 유리 벽에서 끊기고 찢긴 가장자리의 줄기 조각이 따로 붙음, 두 칸 사이 틈, 파란 빛층이 거대 식물 앞에서 사라짐.

## ④ 한 문장 ↻
파란 빛을 받는 눈(포토트로핀)은 끝에 있고, 끝에서 내려온 옥신(옥수수알)이 그늘·아래쪽에 몰리면 줄기는 그쪽이 길어져 빛 쪽·위로 굽고 뿌리는 억제되어 아래로 굽으며, 뿌리골무 속 평형석이 중력을 알린다.
