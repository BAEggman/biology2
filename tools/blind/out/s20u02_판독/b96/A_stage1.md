# stage1 생판 읽기 (s20u02, 2048x868, 두 칸 만화식 판)

## ① 판 전체 표제어
- 1순위 **굴성(굴광성·굴중성)과 옥신** - 확신 70%
- 2순위 **식물 호르몬 옥신의 작용(굴광성 실험사 포함)** - 확신 20%
- 근거: 눈 달린 줄기가 창(빛) 쪽으로 굽는 실험들, 옥수수 알이 한쪽에 몰린 줄기 단면, 눕힌 화분에서 줄기는 위로 뿌리는 아래로 굽는 장면. 남은 10%는 식물의 환경 반응 일반/광수용체.

## ② 구역 (왼쪽부터 4구역)

### 구역1 (창문 + 왼쪽 탁자 3화분) - **다윈식 굴광성 실험: 빛을 감지하는 곳은 줄기 끝**
1. 왼쪽 벽 창문(6칸)과 파란 빛줄기 하나: 빛이 한쪽 옆에서만 옴(단방향 광) - 자리/뜻
2. 빛줄기·창·눈동자가 모두 파랑: 청색광(수용체 포토트로핀)일 가능성 - 색, 약 40%
3. 줄기 끝의 눈알: 빛을 보는 곳 = 줄기 끝(초엽 끝) - 모양/뜻
4. 1번 맨 줄기: 눈이 창을 보며 창 쪽으로 굽음 = 양성 굴광성(대조) - 방향
5. 2번: 눈을 검은 천 주머니(끈으로 묶음)로 덮음, 곧게 섬 = 끝을 가리면 굽지 않음 - 모양/뜻
6. 3번: 눈은 내놓고 줄기 아랫부분만 검은 테이프, 그래도 굽음(감광=끝, 굽는 곳=아래) - 자리. 단 눈이 창 반대쪽을 봄.
→ 읽힌 사실 6개

### 구역2 (오른쪽 탁자 3화분 + 떨어진 눈 1) - **보이센-옌센식: 신호는 끝에서 내려오는 화학물질**
1. 4번: 잘린 줄기 두 토막 사이에 투명 큐브(젤라틴/한천 조각, 얼음조각처럼 생김), 눈이 창 쪽으로 굽음 = 투과성 블록을 물질이 통과 - 모양/뜻
2. 5번: 눈 없는 맨 줄기(잘린 단면 고리) + 탁자 위에 떨어진 눈 1개 = 끝 제거, 굽지 않음 - 모양/자리
3. 6번: 눈과 줄기 사이에 낀 회색 돌판(운모), 눈이 곧게 섬 = 불투과 판이 물질 이동을 막음 - 모양/뜻
모름: 떨어진 눈이 5번과 별개 역할(한천 블록에 물질을 모으는 웬트식?)인지.
→ 읽힌 사실 3개

### 구역3 (큰 화분의 키 큰 식물) - **옥신의 그늘쪽 이동 → 그쪽 세포 신장 → 빛 쪽으로 굽음**
1. 노란 옥수수 알 = 옥신 - 소리(옥수수↔옥신)/모양
2. 알이 눈 바로 아래에서 시작해 줄기 아래까지 한 줄 = 옥신은 끝에서 만들어져 아래로 이동 - 자리
3. 알 25개가 창 반대쪽(휜 바깥쪽)에만 몰림 = 그늘쪽 옥신 축적 - 자리/개수(25 자체의 뜻은 모름)
4. 알 곁은 길쭉한 세포 한 줄, 창 쪽은 작은 정사각 세포 두 줄 = 옥신 쪽 세포가 길게 늘어남(신장) - 모양
5. 눈이 창을 보며 줄기가 창 쪽으로 휨 = 그늘쪽이 더 자라 빛 쪽으로 굽음 - 방향
→ 읽힌 사실 5개

### 구역4 (눕힌 투명 화분, 창 없는 방) - **굴중성: 줄기 음성·뿌리 양성, 옥신과 평형석**
1. 눕힌 화분, 창·빛줄기 없음: 빛 없이 중력만으로 반응 - 자리/뜻
2. 줄기가 흙에서 나와 위로 꺾여 오름 = 음성 굴중성 - 방향
3. 줄기 아래쪽(휜 바깥쪽)에 알 25개 + 긴 세포 = 아래쪽 옥신 증가, 아래쪽 신장, 위로 휨 - 자리/개수/모양
4. 뿌리(크림색, 흙 속)가 아래로 굽어 컵 속으로 = 양성 굴중성 - 방향
5. 뿌리 아래쪽(안쪽 곡면)에도 알 15개: 같은 아래쪽 옥신이 뿌리에서는 신장을 억제(아래쪽이 덜 자람) - 자리/개수(추론)
6. 점무늬 컵(골무 모양)에 뿌리 끝이 들어감 = 뿌리골무(근관) - 소리(골무)/모양
7. 컵 바닥에 가라앉은 검은 공 5개 = 평형석(아밀로플라스트) 침강, 중력 감지 - 자리/뜻(5의 뜻은 모름)
→ 읽힌 사실 7개

## ③ 뜻 모를·어색한·헷갈리는·이어 붙인 흔적
- 어색: 3번 화분의 눈이 창 반대(오른쪽)를 봄. 굽는 방향이 빛 쪽이 아니라서 구역1의 6번 사실 방향이 의심스러움.
- 어색: 4~6번 화분의 눈은 빛줄기 윗경계 밖(빛 안 받는 자리)인데 4번은 창 쪽으로 굽음.
- 이어 붙인 흔적: 큰 식물 뒤 연한 민트색 세로띠. 경계가 자로 잰 듯 수직이고 이 구역만 벽색이 다름. 두 방을 가른 칸막이는 만화식 분할이라 의도로 보임.
- 헷갈림: 알이 깎은 연필 끝처럼도 보임(옥수수 알 vs 연필). 투명 큐브가 얼음/유리/젤라틴 중 무엇인지. 돌판이 받침대(접시)처럼도 보임. 검은 주머니(끝)와 검은 테이프(아래)를 서로 바꿔 읽을 위험.
- 모름: 창 6칸, 알 개수(25·25·15), 공 5개, 키 큰 식물만 바닥의 큰 화분인 이유, 오른쪽 방 줄기 끝에 눈이 없는 이유(빛이 아니라 중력이라서?).

## ④ 한 문장
줄기 끝이 느낀 자극(빛·중력)에 따라 옥신이 그늘쪽·아래쪽으로 몰려 그쪽 세포를 늘이므로, 줄기는 빛 쪽·위로 굽고 뿌리는(옥신이 신장을 억제하고 중력은 평형석이 감지) 아래로 굽는다 = 굴성.
