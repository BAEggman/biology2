# stage2 약속 적용 재독 (s20u02) - 달라진 곳은 ↻

## ① 판 전체 표제어
- 1순위 **굴성(굴광성·굴중성)** - 80% ↻(70→80). 눈알(122)·골무(123)·회색 낟알(124)이 모두 '빛·중력을 받는 자리'를 나르고, 옥신의 본 무대(지퍼 줄기·시든 잡초)는 약속표 주석상 s20u01이라 이 판은 옥신 자체보다 옥신이 만드는 굴성 쪽이다.
- 2순위 **옥신의 작용(굴광성 실험사 포함)** - 12% ↻(20→12)

## ② 구역 (4구역 그대로)

### 구역1 (창 + 왼쪽 탁자 3화분) - **다윈식 가림 실험: 빛을 받는 자리(눈)는 줄기 끝**
1. 왼쪽 벽 창(6칸)·빛줄기 하나: 한쪽 옆에서만 오는 빛, 해 뜬 정상 장면(118의 '해 뜬 날이 정상'과 짝) - 자리/뜻
2. ↻ 하늘색 홍채의 흰 눈알 = 청색광 수용체 포토트로핀, 빛을 받는 자리(122), 줄기 끝에 달림. 1단계의 '청색 40%'와 '눈=끝'을 이 하나로 합쳐 확정. 창·빛줄기의 파랑은 약속표에 없어 별도 사실로 안 셈
3. 1번 맨 줄기: 눈이 창을 보며 창 쪽으로 굽음 = 양성 굴광성(대조) - 방향
4. 2번: 눈(수용체)을 검은 천 주머니로 덮음, 곧게 섬 - 모양/뜻
5. 3번: 눈은 내놓고 아랫줄기만 검은 테이프, 굽음(단 눈이 창 반대쪽을 봄) - 자리
→ 읽힌 사실 5개 ↻(6→5, 2번 합침)

### 구역2 (오른쪽 탁자 3화분 + 떨어진 눈 1) - **보이센-옌센식: 신호는 끝에서 내려오는 화학물질**
1. 4번: 잘린 두 토막 사이 투명 큐브(젤라틴/한천 블록), 굽음 = 물질이 블록을 통과 - 모양/뜻
2. 5번: 눈 없는 그루터기 + 떨어진 눈 1 = 끝 제거, 굽지 않음 - 모양/자리
3. ↻ 6번: 눈은 멀쩡한데 눈과 줄기 사이에 회색 돌판(운모), 곧게 섬 = 수용체가 있어도 전달이 막히면 반응 없음 - 모양/뜻
큐브·돌판은 약속표에 없어 자체 읽기. 모름: 떨어진 눈의 별도 역할.
→ 읽힌 사실 3개

### 구역3 (큰 화분의 키 큰 식물) - **옥신의 그늘쪽 이동 → 그쪽 세포 신장 → 빛 쪽으로 굽음**
1. ↻ 옥수수 알 = 옥신(13). 1단계는 소리 추정이었고 이제 확정
2. ↻ 알이 눈 바로 아래에서 시작해 아래로만 한 줄 = 극성 수송(13의 '꼭대기에서 아래로만 흘러내림'과 같은 꼴)
3. 알 25개가 창 반대쪽(휜 바깥쪽)에만 = 그늘쪽 옥신 축적 - 자리/개수(25의 뜻은 모름)
4. 알 곁 긴 세포 한 줄 vs 창 쪽 작은 세포 두 줄 = 옥신 쪽 신장 - 모양
5. 눈이 창을 보며 줄기가 창 쪽으로 휨 = 굴광성 - 방향
→ 읽힌 사실 5개 (119의 H⁺ 물방울은 이 판에 없음: 산성 성장은 이 판의 사실이 아님)

### 구역4 (눕힌 투명 화분, 창 없는 칸) - **굴중성: 줄기 음성·뿌리 양성, 옥신과 평형석**
1. ↻ 오른쪽 칸 = 틀선으로 떼어 낸 '다른 조건' 칸(118): 왼쪽(해 뜬 정상)과 달리 창·빛줄기 없음 + 화분 눕힘 = 빛 없이 중력만. 큰 장면 안의 칸이 아니라 나란한 두 칸이라 꼴이 완전히 같지는 않음(적용 70%)
2. 줄기가 흙에서 나와 위로 꺾임 = 음성 굴중성 - 방향
3. 줄기 아래쪽 알 25개 + 긴 세포 = 아래쪽 옥신, 아래쪽 신장, 위로 휨 - 자리/개수
4. 뿌리가 아래로 굽어 컵 속으로 = 양성 굴중성 - 방향
5. ↻ 뿌리 아래쪽 알 15개 = 같은 옥신이 뿌리에선 고농도 억제(13의 '알갱이 더미=고농도 억제' 어휘), 아래쪽이 덜 자라 아래로 굽음. 1단계 '추론'에서 승격
6. ↻ 점무늬 컵 = 바느질 골무 = 뿌리골무(123) 확정
7. ↻ 골무 속에 가라앉은 짙은 회색 낟알 5개 = 평형석(124) 확정. 5의 뜻은 모름
→ 읽힌 사실 7개 (+미산입 추론 1: ↻ 줄기 끝에 눈이 없음 = 눈이 '빛을 받는 자리'(122)이고 이 칸은 빛 없는 조건(118)이라 눈이 필요 없는 장면, 60%)

## ③ 모름·어색·헷갈림·이어 붙임
- 어색(불변): 3번 화분 눈이 창 반대쪽을 봄. 눈이 수용체인 줄 알아도 풀리지 않음. 빛줄기 윗경계가 직선이라 눈이 띠 안에 든 것은 1번뿐(3·4·6번·큰 식물 눈은 띠 밖).
- 이어 붙임(불변): 큰 식물 뒤 민트 세로띠, 경계가 수직. 틀선이 없어 118로 설명 안 됨.
- ↻ 해소: 알이 연필 끝처럼 보이던 것은 옥수수 알(13)로 정리.
- ↻ 약속 이웃 어휘와의 혼동, 모두 불채택: 눈알 얹은 돌판은 트로피(29, 근육 트로포-)·모듈 쟁반(22), 검은 테이프는 검은 가스 파이프(36), 검은 주머니는 모자(1), 회색 낟알은 자갈(4)·어두운 방울(16).
- 여전히 모름: 창 6칸, 알 개수(25·25·15), 낟알 5, 큰 식물이 바닥의 큰 화분인 이유, 떨어진 눈의 별도 역할, 민트 띠.

## ④ 한 문장 ↻
청색광 수용체(눈)가 빛을 받거나 뿌리골무 속 평형석이 중력을 느끼면 옥신(옥수수 알)이 그늘쪽·아래쪽에 몰려, 줄기는 그쪽이 길어져 빛 쪽·위로, 뿌리는 그쪽이 억제돼 아래로 굽는다 = 굴성.

## 판정
약속은 새 사실을 더하기보다 1단계 추정 4건(알·눈·골무·낟알)을 확정하고 오른쪽 칸의 정체(118)를 풀었다. 개수·이어 붙임·3번 방향은 그대로이고, 큐브·돌판·검은 가림막은 약속표에 없어 자체 읽기로 남는다. 약속의 이웃 어휘(트로피·가스 파이프·자갈)는 오독 후보로 비친다.
