# stage1 — 생판 (그림만 보고)

## ① 판 전체 표제어
- 1순위: **옥신(auxin)과 굴성 — 굴광성·굴지성** (다윈 → 보이센옌센 → 웬트 실험 흐름 + 옥신 재분배·세포 신장) — 확신도 88%
- 2순위: **식물 호르몬 총론(옥신 중심)** — 7% (그림이 옥신 한 가지에만 집중해 총론일 가능성은 낮음)
- 나머지 5%: 광수용체 · 식물의 환경 반응 일반
- 구성: 왼쪽 칸(창 있는 방: 작은 식물 6그루 + 큰 식물 1)과 오른쪽 칸(창 없는 방: 누운 화분 1)의 두 컷. 글자·화살표는 없음.

## ② 구역 (왼쪽 → 오른쪽)
**구역1 — 한쪽 창의 푸른 빛과 굴광성** (왼쪽 벽 창문 + 1번 식물)
- 창문(6칸) 한 곳에서만 빛이 듦 → 단방향 빛이 굴광성 자극 (자리·개수)
- 푸른 빛줄기, 바닥의 푸른 얼룩 → 굴광성에 듣는 빛은 청색광(포토트로핀) (색)
- 식물 끝의 눈알 → 끝(자엽초 첨단)이 빛을 보는 곳, 눈이 창을 향함 (모양)
- 1번: 아무 처리 없이 창 쪽으로 굽음 → 양성 굴광성, 대조군 (뜻)
- 작은 식물 6그루(탁자 2개 × 화분 3) = 처리를 달리한 6가지 비교 (개수)

**구역2 — 다윈: 빛은 끝에서 받는다** (왼쪽 탁자 2·3번)
- 2번: 끈으로 묶은 검은 주머니가 끝을 가림 → 곧게 섬 = 끝을 가리면 안 굽는다 (모양·뜻)
- 3번: 끝은 드러내고 아랫줄기만 검은 띠(5~6줄 감김) → 그래도 굽고 눈이 창을 봄 = 감지는 끝, 굽는 곳은 끝 아래 (자리)
- 둘 다 검정 = 불투명, 빛 차단 (색)

**구역3 — 보이센옌센·웬트: 내려가는 것은 물질** (오른쪽 탁자 4·5·6번 + 잘린 끝)
- 4번: 투명한 노란 젤라틴(한천) 덩어리 위에 끝을 얹음 → 아래 줄기가 창 쪽으로 굽음 = 화학물질이 젤라틴을 통과 (모양·뜻)
- 5번: 끝이 잘려 눈알+단면이 탁자 위에 누움, 줄기는 맨 막대로 곧음 = 끝이 신호 물질의 근원 (자리)
- 6번: 눈 아래 줄기를 가로지른 얇은 투명판(운모) → 눈은 정면, 줄기 곧음 = 불투과 장벽이 이동을 막음 (모양)
- 젤라틴은 통과·판은 차단의 대비 = 신호의 정체는 확산하는 물질 (뜻)

**구역4 — 큰 식물 단면: 옥신의 그늘쪽 이동과 세포 신장** (큰 화분)
- 노란 옥수수 알 한 줄(25개) = 옥신 (모양·소리 옥수수↔옥신)
- 알이 빛 반대쪽(그늘쪽) 가장자리에만 몰림 = 옥신이 그늘쪽으로 이동·축적 (자리)
- 알이 눈 바로 밑부터 흙까지 이어짐 = 끝에서 만들어져 아래로 극성 이동 (자리·개수)
- 그늘쪽 긴 세포 한 열(약 10개) vs 빛쪽 작은 네모 세포 두 열 → 옥신이 세포 신장을 촉진, 그늘쪽이 더 자라 빛 쪽으로 굽음 (모양)

**구역5 — 굴지성: 누운 화분, 줄기는 위로·뿌리는 아래로** (오른쪽 칸)
- 투명 화분이 옆으로 누움, 창도 눈도 없음 → 빛 없이 중력만 자극 (자리). 한 모종이 입구 쪽으로 줄기를, 흙 속 아래로 뿌리를 내민 단면
- 줄기(위로 굽음): 알(약 26개)이 아래쪽 바깥 굽이 + 긴 세포 → 아래가 더 자라 위로 = 음성 굴지성 (모양)
- 뿌리(아래로 굽음): 알(약 16개)이 아래쪽 안쪽 굽이 → 같은 옥신이 뿌리에서는 아래쪽 신장을 억제 = 양성 굴지성, 기관별 반응 차이 (자리; 억제는 배치로 추정)
- 뿌리 끝을 덮은 골무 = 뿌리골무(root cap) (소리·모양)
- 골무 바닥에 가라앉은 검은 공 5개 = 평형석(아밀로플라스트)이 중력 방향으로 침강 (모양·개수)

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이은 흔적
- 큰 식물이 푸른 빛줄기 밖(흰 벽)에 서 있음 — 확대 모형인지 그늘 표시인지 불명. 단면의 긴 세포가 아래로 갈수록 더 길어지는 것도 의도 불명.
- 오른쪽 칸 줄기 끝에는 눈이 없음(왼쪽 칸 눈 6개) — 빛과 무관하다는 표시로 추정, 확신 낮음.
- 투명판은 유리/운모/비닐 구별 불가, 다윈의 투명 캡 실험과도 헷갈림. 젤라틴 덩어리는 얼음·각설탕으로도 보이고 한천/젤라틴 구분 불가.
- 노란 알은 연필심·캔디콘으로도 보임(옥수수 알로 판단). 골무의 점무늬는 유리컵·시험관으로 오독 가능.
- 잘린 끝이 4번·5번 중 누구 것인지 모호(단면이 5번을 향해 5번으로 판단).
- 개수(알 25·약 26·약 16, 창 6칸, 띠 5~6줄)는 세었으나 숫자 자체에 뜻이 있는지는 불명. 검은 공 5개만 '여러 개가 가라앉음'으로 읽음.
- 이은 흔적: 좌우 두 칸이 각자 테두리·다른 방(2컷 합성). 큰 식물 화분이 오른쪽 탁자 모서리와 겹치고 탁자 끝에서 화분 테두리로 가는 가는 회색 사선이 남음. 큰 식물·누운 줄기의 정밀 단면 화풍이 작은 식물과 달라 확대 삽입처럼 보임. 푸른 빛줄기 안에 희미한 대각선.

## ④ 한 문장
빛이나 중력을 받은 식물 끝에서 옥신이 한쪽(그늘쪽·아래쪽)으로 몰리고, 줄기는 그쪽 세포가 더 길어지고 뿌리는 억제돼 굽는다 — 그래서 줄기는 빛·위로, 뿌리는 아래로 향한다.
