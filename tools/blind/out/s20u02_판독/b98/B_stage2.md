# stage2 — 약속표로 다시 읽기 (s20u02.png) · ↻ = 1단계와 달라진 곳

## 판정
약속표로 더 잘 풀린다. 1단계에서 [중]·[하]이던 알=옥신(13), 컵=뿌리골무(123), 파란 빛(125), 파란 눈(122)이 확정됐고, 대조 실험(126)·틀선 칸(118)은 새로 읽혔다. 검은 주머니·검은 띠·젤리 큐브·투명 판·잘린 눈알은 약속표에 없어 1단계 읽기를 그대로 둔다(억지로 끼우지 않음). 1단계 오판은 하나: 오른쪽 틀을 이은 흔적으로 본 것.

## ① 판 전체 표제어 ↻
- 1순위 **굴성(굴광성·굴지성): 옥신이 한쪽으로 쏠려 굽는다** — 확신 90% ↻(85→90, 문구를 굴성 중심으로)
- 2순위 **옥신의 발견 실험과 작용(세포 신장)** — 확신 6% ↻(10→6)
- 근거: 파란 창빛(125) → 눈알(포토트로핀 122) → 알(옥신 13)이 그늘 쪽 한 줄 → 굽음. 오른쪽은 틀선 칸(118) 속 눕힌 화분 → 골무(123)·낟알(124).

## ② 구역 (왼쪽부터 4구역)
### 구역1 창 + 첫째 탁자 — **청색광을 눈알(포토트로핀)이 받는다, 대조 실험 ①**
1. ↻ 파란 유리창 + 파란 빛줄기 = 청색광(125), 한쪽에서 오는 빛. 바닥의 파란 네모 빛무늬도 같은 빛(색·자리)[상]
2. ↻ 하늘색 홍채의 흰 눈알 = 포토트로핀, 빛을 받는 자리(122). 줄기 끝마다 하나(모양·자리)[상]
3. ↻ 같은 화분이 줄지어 하나씩만 다름 = 한 가지만 바꾼 대조 실험(126)(자리)[상]
4. 맨 왼쪽(처리 없음): 눈알이 창을 향해 굽음 = 굴광성, 비교 기준(자리·모양)[상]
5. 눈알 위에 끈으로 묶은 검은 주머니, 줄기 곧음 = 눈알이 빛을 못 받으면 안 굽는다(모양·자리)[상]
6. 가운데만 검은 띠, 눈알은 드러나 굽음 = 빛 받는 자리(끝)와 굽는 자리(아래)가 다르다(자리)[중]

### 구역2 둘째 탁자 — **눈알에서 몸통으로 내려가는 신호, 대조 실험 ②**
1. ↻ 같은 화분 줄이 이어짐: 첫째와 합쳐 6그루 한 줄. 큰 화분은 줄 밖(126)(자리)[상]
2. 젤리 큐브를 눈알과 몸통 사이에 끼워도 굽음 = 신호는 통과(모양·자리)[중]
3. 눈알이 떨어져 누운 끝 없는 줄기: 곧음 = 빛 받는 자리를 떼면 안 굽는다(자리·뜻)[상]
4. 눈알 밑 얇은 투명 판: 눈알은 정면, 줄기 곧음 = 신호가 막힘(모양·자리)[중]

### 구역3 큰 식물 — **옥신의 그늘 쪽 쏠림과 세포 신장**
1. 줄기를 세로로 열어 속을 확대해 보임 = 핵심 기작(자리)[상]
2. ↻ 옥수수 알 = 옥신(13): 오른쪽(창 반대, 그늘 쪽) 한 줄에만 몰림 = 그쪽에 옥신이 많다(소리·자리)[상]
3. 알 쪽 세포는 길쭉, 창 쪽은 작은 정사각 = 옥신 많은 쪽이 길어진다(모양)[상]
4. 줄기와 눈알이 창 쪽으로 휨 = 그늘 쪽이 더 자라 빛 쪽으로 굽는다(모양)[상]
5. 알이 눈알 바로 밑에서 시작해 아래로 = 옥신이 끝에서 내려간다(자리)[중]

### 구역4 오른쪽 틀 — **굴지성: 평형석과 아래쪽 옥신, 줄기는 위로·뿌리는 아래로**
1. ↻ 틀선으로 떼어 낸 칸 = 같은 장면의 다른 조건(118): 창 없는 방 + 눕힌 화분. 같은 식물(같은 알·세포 격자)(자리)[상]
2. ↻ 줄기 끝에 눈알 없음 = 포토트로핀과 무관, 곧 중력 자극(자리)[상]
3. 눕힌 투명 화분 = 중력 방향이 바뀜(뜻)[상]
4. 줄기가 입구 밖에서 위로 굽음 = 음성 굴지성(자리)[상]
5. ↻ 알(옥신)이 줄기·뿌리 모두 아래쪽 한 줄(13) = 아래쪽에 옥신이 많다(자리)[상]
6. 줄기는 아래쪽 세포만 길쭉 = 줄기에선 옥신 많은 쪽이 자라 위로(모양)[상]
7. 뿌리는 아래로 굽고 알이 굽은 안쪽 = 뿌리에선 옥신 많은 쪽이 억제돼 양성 굴지성(자리)[중]
8. ↻ 바느질 골무(점무늬 컵) = 뿌리골무(123), 뿌리 끝이 들어감(소리·모양)[상]
9. ↻ 골무 바닥에 가라앉은 짙은 회색 낟알 5개 = 평형석(124). 자갈(Ca²⁺)·어두운 방울(CO₂)과 다름(모양·자리)[상]

## ③ 풀리지 않은 것 · 헷갈림 · 흔적 ↻
- 약속표 밖(1단계 읽기 유지): 검은 주머니·검은 띠·젤리 큐브·투명 판·잘린 눈알. 주머니는 5′ 캡 중산모가 아니고, 띠는 어깨띠(Wee1)가 아님(사람이 없음). 두 검정 덮개는 끝 대 가운데로만 갈림.
- 골무의 점무늬는 골무 무늬로 보며 물방울(H⁺, 119)과 갈림[중].
- 큰 식물은 알이 눈알 밑 오목한 쪽까지 올라가 그늘 쪽 위치가 흐리고, 푸른 빛이 바랜 자리라 빛 방향 단서가 약함.
- ↻ 개수(알 25·26·15, 창살 6, 화분 8)는 약속표에 개수 약속이 없어 뜻 없음.
- ↻ 오른쪽 틀은 118로 풀려 흔적 아님. 남은 흔적: 둘째 탁자 3그루의 누런 줄기·굵은 외곽선, 큰 식물 뒤 희미한 세로 이음선, 둘째 탁자 오른쪽 모서리 찢김.

## ④ 한 문장 ↻
한쪽에서 온 청색광을 눈알(포토트로핀)이 받으면 옥신(옥수수 알)이 그늘 쪽으로 쏠려 그쪽이 길어져 빛 쪽으로 굽고, 눕히면 평형석(골무 속 낟알)이 가라앉은 아래쪽에 옥신이 몰려 줄기는 위로·뿌리는 아래로 굽는다.
