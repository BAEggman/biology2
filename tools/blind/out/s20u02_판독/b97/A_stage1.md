# stage1 생판 (s20u02.png)

## ① 판 전체 표제어
- **1순위: 옥신(auxin)과 식물의 굴성 — 굴광성·굴지성** (90%)
- **2순위: 식물 호르몬·식물의 환경 자극 반응(신호전달)** (55%)
- 근거: 눈알 달린 줄기(끝이 빛을 봄), 창 하나(한쪽 빛), 끝 가림·밑동 가림·끝 제거·투명 블록·투명 판(다윈~보이센옌센 실험 세트), 한쪽에 몰린 노란 알과 늘어난 세포, 오른쪽 방은 눕힌 화분(중력).
- 틀이 둘: 왼쪽 방=빛, 오른쪽 방=중력. 둘 다 같은 노란 알(옥신)이 나온다.

## ② 구역별 (왼쪽 → 오른쪽)

### 구역1 창가 첫 탁자 — **다윈의 굴광성 실험(빛은 줄기 끝이 받는다)**
- 창(짙은 파랑 6칸)+파란 빛줄기·벽: 한쪽 옆에서만 오는 빛 = 굴광성의 자극. 파랑=청색광/포토트로핀일 수 있음(추정). 근거: 자리/모양.
- 눈알: 줄기(자엽초) 끝의 빛 감지부. 눈동자는 모두 창 쪽. 근거: 뜻/자리. 왼쪽 방 눈은 보이는 것 6개(식물1·3·4·6, 큰 식물, 떨어진 눈)+주머니 속 1개, 오른쪽 방은 0개.
- 화분 3개(처리 3가지):
 - 맨 줄기: 윗부분이 창 쪽으로 굽음 = 대조, 양의 굴광성.
 - 끝에 검은 천주머니(끈 묶음): 곧게 섬 → 끝을 가리면 안 굽는다 = 빛 감지는 끝. 근거: 뜻/자리.
 - 밑동에 검은 슬리브: 끝은 노출, 창 쪽으로 굽음 → 아래가 어두워도 굽는다 = 끝의 신호가 아래로 전달. 근거: 자리.
- 읽힌 사실 7개: 단방향 빛, 청색광(추정), 눈=끝, 대조 굽음, 끝 가림=직립, 밑동 가림=굽음, 신호의 하향 전달.

### 구역2 둘째 탁자 — **보이센옌센 실험 + 끝 제거(탈두)**
- 줄기가 잘리고 그 사이에 투명 정육면체(얼음 같음=젤라틴/한천 블록): 두 토막 사이가 떨어져 있어도 위쪽이 굽음 → 물에 녹는 화학물질이 통과. 근거: 모양/뜻.
- 눈이 잘려 탁자에 누워 있고 그루터기는 곧게: 끝 제거 → 안 굽음(끝=신호의 근원). 근거: 자리/동작.
- 눈 바로 아래를 가로지르는 얇은 투명 판(가장자리 점·흰 얼룩=운모 조각 같음): 눈이 정면, 곧게 → 불투과 장벽이 전달을 막음. 근거: 모양/뜻.
- 블록(통과·굽음) 대 판(차단·직립)의 짝 대비. 읽힌 사실 6개.

### 구역3 큰 화분 — **옥신의 측방 이동과 세포 신장 차이(콜로드니–웬트)**
- 탁자가 아니라 바닥의 큰 화분. 줄기를 세로로 쪼갠 확대 단면, 큰 눈(껍질 후드에 반쯤 덮임)이 창을 보며 크게 굽음 = 알·세포가 보이는 내부 설명도.
- 노란 옥수수 알 모양 알갱이 약 25개(±1)가 창 반대(그늘·바깥)쪽에 한 줄로 몰림 = 옥신이 그늘쪽에 모임. 근거: 소리(옥수수≈옥신)/자리/개수. 뾰족한 흰 꼬리는 안쪽.
- 그늘쪽: 길쭉한 직사각 세포 1열(늘어남). 빛쪽: 작은 정사각 세포 2열(덜 늘어남) → 그늘쪽이 더 자라 빛 쪽으로 굽음. 위쪽(끝) 세포는 아주 작고 아래로 갈수록 길다.
- 읽힌 사실 6개.

### 구역4 오른쪽 방 — **굴지성: 평형석과 옥신, 줄기(−)·뿌리(+)**
- 창도 눈도 없는 방, 눕힌 투명 화분(흙): 자극=중력, 빛 무관. 근거: 자리/뜻.
- 줄기(입구 밖, 초록; 끝은 눈 없이 매끈): 위로 굽음 = 음의 굴지성. 노란 알 약 26개가 아랫면에 한 줄, 아랫면 쪽 세포가 길쭉 → 아랫면이 더 늘어남.
- 뿌리(흙 속, 크림색): 아래로 굽어 컵으로 = 양의 굴지성. 알 약 16개가 아랫(안쪽)면: 같은 옥신인데 뿌리는 신장 억제 → 기관 따라 반대 반응.
- 점무늬 투명 컵(골무 모양; 소리: 골무=뿌리골무)에 회색 구슬 5개가 바닥에 가라앉음 = 근관 평형석(전분립)의 침강 = 중력 감지. 근거: 소리/모양/개수.
- 읽힌 사실 9개.

## ③ 모호·어색·이음 흔적
- 뜻 모를 것: 노란 알이 옥신인지 H+(산성 생장)인지, 얼음인지 젤라틴인지, 창 6칸·구슬 5개·알 25/26/16개의 수 의미(셈은 했으나 뜻은 모름), 큰 눈의 껍질 후드.
- 헷갈림: 검은 것 둘(끝/밑동), 투명한 것 둘(블록/판), 줄기·뿌리 모두 알이 아랫면인데 결과 반대, 안 굽는 두 그루(끝 없음/전달 차단)의 이유가 다름.
- 이음: 파란 벽·빛줄기가 사각 레이어(큰 식물 왼쪽 계단형 직선 가장자리), 빛줄기 윗 경계 톱니 흰 테두리, 방 모서리 이중선, 식물 4~6·블록·판 후광, 오른쪽 뿌리 중간의 폭 넓은 크림 띠(줄기와 뿌리가 안 이어짐), 틀 2개.

## ④ 한 문장
