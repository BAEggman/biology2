# stage2 덱 약속 적용 재독 (s20u02.png)
판정: 약속표로 더 잘 풀린다. #13 옥수수 알갱이, #122 눈알, #123 골무, #124 회색 낟알이 이 판에 정확히 걸린다. 방향·구역 나눔은 1단계와 같고, 「추정→확정」과 「의심 해소」가 대부분이다. 표에 없는 물건은 추정으로 둔다. (↻ = 1단계와 달라진 곳)

## ① 판 전체 표제어
- **1순위: 옥신의 비대칭 분포로 굽는 굴성 — 굴광성·굴지성** (93%) ↻ 90→93, 표현을 #13의 「비대칭 분포」로 바꿈
- **2순위: 식물 호르몬(옥신)의 작용과 환경 자극 반응** (60%) ↻ 55→60
- 근거: 눈알(포토트로핀)이 왼쪽 방의 자극(옆빛)을, 눕힌 화분이 오른쪽 방의 자극(중력)을 연다. 갈라 본 줄기·누운 줄기·뿌리 세 곳의 한쪽 안벽에만 줄지은 알갱이가 판을 꿰는 실이다.
- 틀 둘: 왼쪽=빛, 오른쪽=중력. ↻ #118(틀선 칸=같은 장면의 다른 조건)로도 읽히나 칸 밖 큰 장면이 따로 없어 확정하지 않는다.

## ② 구역별
### 구역1 창가 첫 탁자 — **포토트로핀(눈)과 다윈의 굴광성 실험** ↻ 표제어에 포토트로핀 추가
1. 창+파란 빛줄기: 한쪽 옆에서만 오는 빛 = 굴광성 자극 (자리, 표에 없음)
2. 파랑 = 청색광(추정; 눈의 파란 홍채와 같은 색)
3. ↻ 눈알 = 포토트로핀, 청색광 수용체 (#122, 모양). 눈동자는 모두 창 쪽. 눈은 왼쪽 방 6개+주머니 속 1개, 오른쪽 방 0개
4. ↻ 눈의 자리 = 줄기 끝 = 빛을 받는 자리 (자리)
5. 맨 줄기: 윗부분이 창 쪽으로 굽음 = 대조, 양성 굴광성
6. 눈을 검은 천주머니로 가림 → 곧게 섬 = 수용체를 가리면 안 굽는다
7. 눈은 열고 밑동만 검은 슬리브 → 굽음 = 수용은 끝에서 하면 충분
8. 끝에서 아래로 신호가 전달된다(6·7의 합). 읽힌 사실 8개 ↻ 7→8

### 구역2 둘째 탁자 — **보이센옌센 실험과 끝(눈) 제거**
1. 줄기 중간에 투명 정육면체 블록(젤라틴/한천 추정)이 끼어도 굽음 → 블록은 통과 (모양/뜻)
2. 블록 속 두 토막이 떨어져 있어도 굽음 = 녹는 화학물질이 건너감
3. 눈이 잘린 그루터기는 곧게 → 눈(끝) 없으면 안 굽는다
4. 잘린 눈이 탁자에 누움 = 수용·신호원인 끝이 분리됨
5. 눈 아래를 가로지르는 얇은 투명 판(운모 추정): 곧게 섬 = 차단 (모양/뜻)
6. ↻ 눈(수용체)이 멀쩡해도 전달이 막히면 안 굽는다 = 수용만으로는 부족. 읽힌 사실 6개

### 구역3 바닥의 큰 화분 — **갈라 본 줄기의 옥신 비대칭 분포와 세포 신장**
1. ↻ 옥수수 알갱이 = 옥신 (#13, 소리 옥수수≈옥신). 약 25개
2. 알갱이가 한쪽 안벽(창 반대·그늘쪽)에만 줄지음 = 옥신 몰림 (자리)
3. ↻ 몰린 쪽 세포는 길쭉 = 줄기는 몰린 쪽이 길어진다 (#13)
4. 빛쪽 세포는 작은 정사각 2열 = 덜 자람
5. 그늘쪽이 더 길어 줄기가 창 쪽으로 굽음 = 굴광성
6. 큰 눈이 창을 봄 = 포토트로핀이 끝에서 빛을 받음. 읽힌 사실 6개

### 구역4 오른쪽 방 — **굴지성: 누운 줄기·뿌리의 옥신과 뿌리골무의 평형석**
1. 창도 눈도 없는 방 + 눕힌 투명 화분 = 자극은 중력, 빛 무관
2. 누운 줄기 끝이 위로 굽음 = 음성 굴지성
3. 줄기 알갱이(약 26개)가 아랫면에만 = 옥신이 아래에 몰림
4. ↻ 몰린 아랫면 세포 길쭉 → 몰린 쪽이 길어져 위로 (#13)
5. 뿌리(흙 속)가 아래로 굽어 골무로 = 양성 굴지성
6. ↻ 뿌리 알갱이(약 16개)도 아랫면 → 몰린 쪽이 덜 자라 아래로 (#13) = 같은 옥신, 줄기와 반대
7. ↻ 바느질 골무 = 뿌리골무(근관) (#123, 소리·모양)
8. ↻ 골무 속 짙은 회색 낟알 5개 = 평형석(녹말체) (#124). 둥근 알이라 CO₂ 방울·자갈(Ca²⁺)·GTP 칩과 갈린다
9. 낟알이 골무 바닥에 가라앉음 = 중력 감지. 읽힌 사실 9개

## ③ 모호·어색·이음 흔적
- ↻ 풀린 것: 노란 알이 H⁺인가 → 옥신 확정(H⁺는 #119 물방울 꼴인데 이 판에 물방울이 없다). 눈·골무·낟알 이름도 표로 확정.
- 여전히 모름(표에 없음): 투명 블록(얼음/젤라틴/한천), 투명 판(운모/유리), 검은 주머니·슬리브(차광으로 읽음; 슬리브는 #36 검은 가스 파이프와 닮았으나 카스파리대 장면이 아니라 끼우지 않음), 파란 빛줄기·창 6칸, 큰 눈의 껍질 후드, 알 개수 25/26/16·낟알 5(개수 약속 없음 → 의미 없는 「많음」).
- 헷갈림: 검은 것 둘(끝/밑동), 투명한 것 둘(블록/판), 줄기·뿌리 모두 알이 아랫면(#13의 길어진다/덜 자란다로 해소), 안 굽는 두 그루(눈 없음/전달 차단).
- 이음: 파란 벽·빛줄기 사각 레이어(큰 식물 왼쪽 계단형 직선·톱니 흰 테두리·방 모서리 이중선), 식물 4~6·블록·판 후광, 첫 탁자 회색/둘째 탁자 갈색, 오른쪽 뿌리 중간의 폭 넓은 크림 띠(유리 테두리를 지나는 부분이나 이음새처럼 보임).

## ④ 한 문장 ↻
눈(포토트로핀)이 옆빛을 받으면 옥수수 알(옥신)이 한쪽 안벽에 몰려, 줄기는 몰린 쪽이 길어져 빛 쪽·위로, 뿌리는 몰린 쪽이 덜 자라 아래로 굽고, 골무의 평형석이 중력을 알린다.
