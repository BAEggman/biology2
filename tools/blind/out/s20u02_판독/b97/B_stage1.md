# stage1 — 생판 (s20u02.png, 사전 정보 없음)

## ① 판 전체 표제어
- 1순위 **옥신(auxin)과 굴성 — 굴광성(초엽 실험)·굴중성(굴지성)** — 확신도 85%
- 2순위 **식물 호르몬·식물의 환경 신호 반응(총론)** — 확신도 10%
- 근거: 눈알 달린 휜 줄기(초엽·줄기 끝=감지부), 왼쪽 창에서 오는 한쪽 빛, 줄기에 줄지은 노란 옥수수 알(옥수수≈옥신, 소리), 옆으로 누운 화분(중력 자극). 빛과 중력 두 자극 모두 "끝에서 감지 → 알(옥신)이 한쪽으로 몰림 → 세포 신장 차이 → 굽음"으로 묶인다.

## ② 구역 (왼쪽 → 오른쪽, 4구역)

**구역1 — 창 + 첫 탁자 3화분: 다윈식 굴광성 실험(빛은 끝에서 감지)**
- 왼쪽 벽의 창 + 사선으로 쏟아지는 푸른 빛줄기: 한쪽(좌측) 단방향 빛이 자극(자리). 푸른색은 청색광(굴광성 유효광·포토트로핀)일 수 있음(색, 추정). 창살 6칸은 모름.
- 화분1(아무것도 안 함): 눈알이 창을 보고 줄기가 빛 쪽으로 굽음 = 정상 초엽의 양성 굴광성, 대조군(자리). 눈알 = 끝(빛 감지부)(모양).
- 화분2: 눈알(끝)에 끈 묶은 까만 천주머니 → 줄기가 곧게 섬 = 끝을 가리면(불투명 덮개) 안 굽는다(뜻).
- 화분3: 눈알은 드러내고 아랫줄기만 까만 테이프로 감음 → 끝이 빛 쪽으로 굽음 = 아랫부분을 가려도 굽는다, 감지는 끝(자리).
- 개수: 화분 3 = 처치 3(대조·끝 가림·아래 가림).

**구역2 — 두 번째 탁자 3화분 + 잘린 끝: 보이센-옌센식 절단·삽입 실험(이동하는 화학 신호)**
- 화분4: 끝을 자른 틈에 얼음 같은 투명 큐브(젤라틴 블록 추정)를 끼웠는데도 끝은 창 쪽으로 굽음 = 신호가 젤라틴을 통과하는 확산성 화학물질(뜻·모양).
- 화분5: 끝이 잘려 나간 줄기(단면에 속 빈 고리), 잘린 눈알 달린 끝은 탁자 위에 누움 → 줄기는 곧고 안 굽음 = 끝 없으면 반응 없음, 끝이 감지·신호 공급(뜻·자리).
- 화분6: 눈알 바로 밑 줄기를 가로지르는 6각형 얇은 투명판(운모 mica 추정) → 눈알이 곧게 위 = 불투과 장벽이 신호의 하향 이동을 막음(뜻·모양).
- 화분4 큐브(통과)와 화분6 판(차단)은 같은 "끼워 넣기"의 대비.

**구역3 — 바닥의 큰 화분, 절개된 큰 줄기: 옥신의 측면 이동과 그늘쪽 세포 신장(콜로드니-웬트)**
- 맨 위 큰 눈알(끝)이 창을 보고 줄기는 빛 쪽으로 크게 굽음 = 굴광성(자리).
- 절개 단면: 창 반대쪽(그늘진 쪽)에 노란 옥수수 알 한 줄(25개) = 옥신이 그늘쪽에 몰림(옥수수≈옥신, 자리). 25의 뜻은 모름.
- 알 바로 옆 세포는 길쭉한 긴 세포, 창 쪽은 작은 정사각 세포 두 줄 → 그늘쪽 세포가 더 길게 신장(모양).
- 알 줄이 눈 밑에서 시작해 토양선까지 내려옴 → 끝에서 아래 신장대로 옥신 이동(자리). 큰 크기 = 구역1·2 결과의 "원인판".

**구역4 — 오른쪽 방(창 없음), 옆으로 누운 투명 화분: 굴중성(굴지성)**
- 창 없는 빈 방 + 눕힌 화분 → 자극은 빛이 아니라 중력(자리).
- 줄기(초록, 눈알 없음): 위로 휨 = 음성 굴중성. 알 26개가 아래쪽(바깥 볼록면), 위쪽은 작은 정사각 세포 → 아래쪽 옥신이 신장 촉진(자리·모양).
- 뿌리(흙속 크림색): 아래로 휨 = 양성 굴중성. 알 16개가 아래쪽(오목면) → 같은 아래쪽 옥신이 뿌리에선 신장 억제 = 줄기·뿌리의 옥신 감수성 차(자리).
- 뿌리 끝에 꽂힌 작은 유리컵 + 바닥에 쌓인 검은 구슬 5개: 컵=뿌리골무(근관), 구슬=평형석(전분립·아밀로플라스트)이 중력 방향으로 가라앉아 감지(모양·뜻).

## ③ 잔결
- 뜻 모를 것: 투명 큐브(젤라틴? 얼음?)와 6각 판(운모? 유리?)의 정체, 푸른 빛이 청색광을 뜻하는지, 창살 6칸·알 개수(25/26/16)·구슬 5개의 뜻, 컵 표면의 물방울 같은 점.
- 어색한 것: 오른쪽 줄기엔 눈알이 없음(빛 무관 표시?), 뿌리-줄기 이음부는 유리 테두리 구간에서 알 없는 평평한 크림 띠로 끊기고 줄기는 들쭉날쭉한 단면으로 시작, 큰 식물이 천장선을 넘음.
- 헷갈리는 것: 까만 주머니(끝, 안 굽음) ↔ 까만 테이프(아랫줄기, 굽음) / 투명 큐브(통과) ↔ 투명 판(차단) / 잘린 끝 ↔ 남은 줄기 / 알이 같은 아래쪽인데 줄기는 촉진, 뿌리는 억제.
- 이어 붙인 흔적: 푸른 빛 층이 직사각 판처럼 직선 가장자리로 천장·벽 밖까지 번짐, 3번 화분 목 옆의 허연 직사각 얼룩, 왼쪽 벽 아래 푸른 조각의 거친 경계, 눈알 흰자가 배경색을 그대로 비춤(투명 컷아웃), 6각 판의 들쭉날쭉한 가장자리, 큐브 속 줄기 토막만 색이 선명한 초록, 두 방(패널)이 따로 그려져 붙은 구성.

## ④ 한 문장
