# 1단계 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- **1순위: 세포호흡(포도당 이화) — 해당과정 → 피루브산 산화 → TCA 회로, 산소가 없으면 발효** (확신 85%)
- **2순위: 산소 유무에 따른 피루브산의 운명(호기호흡 대 발효)과 NAD+/NADH·ATP 수지** (확신 8%)
- 근거: 붉은 정육면체(6C)가 기계에 먹혀 붉은 피라미드(3C) 2개로 나옴 / 동전 투입 2·수확 4 / 물양동이 나르는 사람들 / 검은 방울(CO2) / 도는 원반 / 먹구름 아래 발효.

## ② 구역별 (왼쪽부터 4구역)
### 구역1 맨 왼쪽 들판·이빨 기계 — **해당과정(세포질): 포도당 → 피루브산 2, ATP 순 2, NADH 2**
1. 붉은 정육면체 1개를 사람이 기계 입에 밀어 넣음 = 포도당 6탄당(모양: 6면체). 입의 이빨 = 쪼갬(6C→3C+3C). 막 없는 들판 = 세포질.
2. 놋쇠 굴뚝 2개에 동전이 1개씩 꽂힘 = ATP 2개 투자(소모) (개수 2).
3. 컨베이어로 나오는 붉은 피라미드 2개 = 피루브산 2분자(3탄당) (개수·모양).
4. 땅의 4칸 쟁반의 동전 4개 = 총 ATP 4 생성(기질수준 인산화) → 4−2 = 순 2 (개수).
5. 도장 든 작업자가 피라미드에 붉은 사각 자국을 찍음 = 인산기 첨가(인산화) [중].
6. 물이 튀는 찬 양동이 1 + 다른 작업자 곁의 빈 양동이 1 = NAD+ → NADH(물=전자), 포도당당 NADH 2 [중].
7. 피라미드에서 떼는 동전 + 손에 든 동전 = 피루브산 단계의 ATP 직접 생성(기질수준 인산화) (개수 2) [중].
8. 맑은 해 + 공중 거품 10개(오른쪽으로 갈수록 성기다 먹구름 앞에서 끊김) = 산소가 있는 환경(호기) [중~낮음].

### 구역2 벽 입구(경비·돌림문·가위) — **피루브산의 미토콘드리아 유입과 산화적 탈카복실화 → 아세틸 CoA**
1. 벽 = 미토콘드리아 막(마당 = 기질), 문 = 통로 [중].
2. 문의 경비가 붉은 피라미드를 들고 검사 = 피루브산은 수송체를 거쳐야 막을 지남(자리).
3. 큰 가위 든 남자 + 꼭대기가 잘린 피라미드 + 위에서 떨어지는 검은 방울·연기 1개 = 탈카복실화, CO2 1개 방출, 3C→2C (개수 1).
4. 끈으로 매단 꼬리표 달린 작은 붉은 조각 = 아세틸 CoA(2C+CoA) (뜻: 꼬리표 = CoA).
5. 물양동이 들고 걷는 남자 1명 = NADH 1개 생성 (개수 1).
6. 빈 4칸 쟁반 = ATP 0 [낮음]. 돌림문(팔 3~4개)을 끙끙 미는 머리카락 있는 남자 + 바닥의 곡선 화살표 = 모름(후보: 한 방향 비가역 반응 / ATP 합성효소 회전).

### 구역3 가운데 큰 회전 원반 — **TCA 회로(시트르산 회로, 기질)**
1. 가장자리에 동작선이 있는 돌아가는 원반 = 회로(순환) 경로.
2. 높은 굴뚝 2개, 각각 검은 공+연기 = CO2 2개 방출 (개수 2).
3. 꼭지 달린 작은 정육면체 → 화살표 → 큰 정육면체 = 옥살로아세트산(4C)+아세틸(2C) → 시트르산(6C).
4. 원반 위에 따로 누운 꼬리표 = CoA 분리·재사용.
5. 둘레에서 물양동이 든 사람 3명 = NADH 3개 (개수 3).
6. 무릎 꿇고 중간 크기 정육면체를 만지는 사람 = 4C 옥살로아세트산 재생 [중]; 큐브 크기 = 탄소 수(6→5→4) [중].
7. 뚜껑 단지 10개 = 중간체·단계 [낮음; 정설 8단계와 안 맞음].
8. 모름: 그가 흔드는 남청색 판(FADH2/GTP?), 뒷벽 선반 위에서 양동이를 든 남자(FADH2? 막에 박힌 숙신산 탈수소효소?), 뒷벽의 닫힌 작은 문, 원반 중앙의 작은 구멍.

### 구역4 오른쪽 먹구름 아래 — **무산소: 전자전달 차단, 발효(젖산·알코올), NAD+ 재생, 코리 회로**
1. 먹구름, 해·거품 없음 = 산소 부족(구역1 대비).
2. 판자를 X로 박은 문 = 산소 필요한 전자전달계가 막힘 [중].
3. 문 앞에 쌓인 찬 양동이 더미(약 15~20) = NADH 적체(개수 많음).
4. 양동이를 쏟아 보라 피라미드에 붓는 사람 = 젖산 발효, 붉은 피루브산 → 보라 젖산, NADH → NAD+ (색).
5. 붉은 피라미드 위 검은 방울 + 물 붓는 나비넥타이 사람 = 알코올 발효, 탈카복실화 CO2 1 + NADH로 환원 [중].
6. 작은 기계 입에 양동이를 밀어 넣는 사람 = NAD+가 해당과정으로 되돌아감.
7. 기계 선반의 동전 2개 = 발효의 순 ATP 2 (개수 2).
8. 보라 피라미드 2개를 실은 수레 → 집 = 젖산이 간으로, 문 앞 작은 붉은 큐브 = 새 포도당(코리 회로, 포도당신생) [중].
9. 원 그리며 도는 개 = 순환(코리 회로 말장난?) [낮음].

## ③ 뜻 모를·어색한·헷갈리는·이어 붙인 흔적
- 돌림문·바닥 화살표·빈 쟁반 / 선반 위 남자 / 닫힌 작은 문 / 남청색 판 / 개: 정체 불확실. 바닥의 작은 고리·점은 자갈 질감.
- 헷갈림: 피라미드 4종(온전한 붉은 것, 꼭대기 잘린 것, 꼬리표 붙은 조각, 보라색), 큐브 크기 여러 개, 양동이 찬 것/빈 것(물 = NADH인지 H2O인지), 동전이 네 곳(굴뚝 2·쟁반 4·손/피라미드 2·선반 2)이라 투자·총생산·순이득이 섞임, 검은 방울(물방울형)과 검은 공(굴뚝) 둘 다 CO2로 보임, 문 3개(열림·닫힘·판자).
- 이어 붙인 흔적: 왼쪽 들판(낮은 시점)과 가운데 벽 마당(내려다본 시점)이 벽 기둥에서 갑자기 만남(하늘은 이어짐). 오른쪽 작은 기계는 왼쪽 큰 기계의 축소 복제(굴뚝에 동전·슬롯 없음). 뒷벽이 오른쪽 기둥에서 꺾여 두 겹처럼 보임. 오른쪽 끝에서 집·구름이 프레임에 잘림.

## ④ 한 문장
포도당(6C)은 세포질에서 피루브산 2(ATP 순 2, NADH 2)가 되고, 산소가 있으면 미토콘드리아에서 CO2를 잃고 아세틸 CoA로 TCA 회로에 들어가 CO2 2·NADH 3 등을 내며, 산소가 없으면 NADH를 되돌려 NAD+를 살리는 발효로 해당과정만 돌린다.
