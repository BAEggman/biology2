# 2단계 — 약속표를 쥐고 다시 읽음 (↻ = 1단계와 달라진 곳)

**판정**: 약속표로 훨씬 잘 풀린다. 풀린 것: 선반 일꾼(네모 양동이)·쪽문(#174)·어두운 네모 칩(#101)·꼬리표(#172)·도장(#100)·판자 문(#144). ↻정정 셋: 선반 일꾼은 H⁺ 기울기가 아니라 FADH₂, 전자전달 본체(근육 팔·아치·물높이)는 이 판에 없음, 집은 간 표지 아님(#93). 표에 없어 장면 논리로만 읽은 것: 경비원·개찰구·이빨 입 기계. (1단계의 일부 조각은 화면이 빠져 큰 그림으로 읽었음 — 이번에 재확인.)

## ① 표제어
- 1순위 **세포호흡 총론(해당과정→아세틸CoA→TCA→전자전달 입구, 무산소 발효·코리 회로)** 90%
- 2순위 **포도당 대사: 호기 대 혐기 경로** 7%

## ②·⑤ 구역별 (사실 → 까닭)
### 구역1 **해당과정** (담 밖 풀밭)
1. 해 + 밝은 방울 10(굵은 7·잔 3, 먹구름 쪽엔 0) = O₂ 있음(#17·#118) → 까닭: 해(좌)↔먹구름(우)로 맞서고 방울이 오른쪽으로 사라져 산소 유무가 갈림. 10과 크기 차는 까닭 모름.
2. 큰 블록 1을 안아 이빨 입에 밀어 넣음 = 포도당 6C(#171) → 까닭: 블록이 각뿔·쐐기보다 크고 입을 채움. 들어가는 1 ↔ 나오는 각뿔 2(크기·개수)로 6→3+3.
3. 굴뚝 둘 꼭대기 투입구에 동전 1씩 = ATP 2 투자(#8) → 까닭: 동전이 위에서 '꽂혀 들어가는' 자세, 아래 상자엔 '담긴' 4 — 투입 2↔산출 4로 순 2.
4. 컨베이어 각뿔 2 = 3C 2분자 → 까닭: 같은 크기·빛깔 둘을 나란히 = 반으로 갈려 똑같은 것 둘.
5. 민 붉은 도장, 앞 각뿔에 겹사각 자국 = 인산화(#100) → 까닭: 자국은 앞 각뿔에만, 뒤 각뿔엔 동전이 붙음 — 자국↔동전 대비.
6. 각뿔 밑에서 양동이로 흘러드는 물줄기 + 가득 양동이 = NADH(#102) → 까닭: 물이 각뿔에서 통으로 흐름 = 받아 가는 방향. 곁의 빈 통과 가득/빈 대비.
7. 빈 양동이 = NAD⁺ → 까닭: 같은 통이 가득한 통 곁에 비어 놓임(짝 대비).
8. 일꾼이 동전을 각뿔 면에 붙이고 다른 손엔 치켜듦 = 기질수준 ATP 생성 → 까닭: 동전이 각뿔에 '붙는' 동작 = 중간체에서 동전이 생김.
9. 풀밭 4칸 상자, 칸마다 동전 1 = ATP 4(총) → 까닭: 칸 4×동전 1로 '넷'을 세게 함. 굴뚝 2와 견주면 4−2=2.

### 구역2 **피루브산 수송 + 아세틸CoA(PDH)** (문 안 마당 입구)
1. 경비원이 작은 각뿔 하나를 듦 = 3C만 통과(장면 논리) → 까닭: 손엔 큐브가 아니라 각뿔 — 문 밖 큐브↔문 안 각뿔. 모자는 #1대로 무의미.
2. 회전 개찰구를 힘껏 미는 남자 + 바닥 굽은 화살표(→) = 한 번에 하나, 한 방향 수송 → 까닭: 팔이 돌아야 하나씩 지남. 동전 투입구 없음 — 투입구 달린 Na⁺-K⁺ 펌프(#148)와 대비해 ATP 직접 안 씀(추정).
3. 윗면이 평평하게 잘린 큰 각뿔 + 가위 든 일꾼 = 탈카르복실화 → 까닭: 3C 각뿔의 위가 잘려 땅의 작은 쐐기(2C)와 견줌. 남은 몸통의 뜻은 까닭 모름.
4. 잘린 자리 위 검은 방울 1 + 연기 = CO₂ 1(#16) → 까닭: 개수 1 = 탄소 하나, 각뿔 바로 위 허공 = 막 떨어짐.
5. 쐐기 + 끈 묶은 꼬리표 = 아세틸CoA(#171·172) → 까닭: 꼬리표가 쐐기에 '달려 한 몸' ↔ 3구역 홀로 놓인 꼬리표.
6. 걷는 일꾼의 가득 양동이 1 = NADH 1 → 까닭: 가위질 곁에서 통 하나를 들고 오른쪽 마당 안으로 감 = 하나 나와 운반됨.
7. 개찰구 곁 빈 4칸 상자 = 이 단계 직접 ATP 0 → 까닭: 풀밭의 가득 찬 상자와 같은 상자를 비워 둠(나란히+빔).

### 구역3 **TCA 회로** (마당 돌림판)
1. 도는 원반(속도선·볼트) = 회로 → 까닭: 원이라 끝이 처음에 이어짐, 속도선 = 계속 돎.
2. 작은 블록(위에 쐐기) → 굽은 화살표 → 큰 블록 = OAA4+아세틸2→시트르산6(#171) → 까닭: 작→큰으로 커지고 쐐기가 얹혀 4+2=6.
3. 원반 위 홀로 놓인 꼬리표 = 떨어진 CoA(#172) → 까닭: 쐐기에 달렸던 것이 쐐기 없이 따로(붙음↔떨어짐).
4. 굴뚝 2 + 검은 공 2 = CO₂ 2 → 까닭: 개수 2, 구역2의 방울 1과 견줌. 두 공의 크기 차는 까닭 모름.
5. 가득 둥근 양동이 일꾼 셋 = NADH 3 → 까닭: 같은 사람·같은 통 셋 나란히 = '셋'.
6. 무릎 꿇고 중간 블록 + 어두운 네모 칩을 터는 일꾼 = GTP 1(#101) → 까닭: 칩이 동전(둥글·금색)과 달리 네모·어두움 = ATP와 갈림. 블록이 큰 블록보다 작음 = 탄소 줄어듦(5냐 4냐는 모름).
7. ↻벽 선반 위 일꾼의 네모 양동이(가득) = FADH₂ 1(#102) → 까닭: 네모 통이 둥근 통 셋과 하나만 다름. 바닥이 아닌 벽 선반에 선 까닭은 그림만으론 모름.

### 구역4 **NADH·FADH₂의 길** ↻(전자전달 본체 없음)
1. 뒷담 밑동의 작은 나무 쪽문(#174) → 까닭: 작고 밑동이라 통 하나씩 드나드는 길. 구역5 큰 문(판자 가위표)과 견주면 이쪽은 판자 없음.

### 구역5 **무산소 발효(NAD⁺ 재생)** (먹구름 아래)
1. 먹구름, 방울 없음 = 산소 없음 → 까닭: 해와 맞섬. 구름 아래에서만 문이 막히고 통이 쌓임.
2. 판자 가위표 친 문 = 이 길은 쓰지 않음(#144, 약 자물쇠 아님) → 까닭: 문은 멀쩡하고 널빤지 둘만 X = 부서짐이 아니라 '안 씀'.
3. 문 앞 가득 양동이 더미(16~18) = NADH 축적 → 까닭: 같은 통을 높이 쌓음 = 비워지지 못함. 마당의 한 사람 한 통과 개수 대비.
4. 빨간 각뿔 위 검은 방울 + 물 붓는 일꾼 = CO₂ 떼고 통 비움(알코올 발효로 읽음, 에탄올 물건은 표에 없어 추정) → 까닭: 방울이 각뿔 위에서 떨어짐, 각뿔은 빨강 그대로 모서리만 깎임.
5. 통을 비우자 각뿔이 보라로 물듦 = 젖산 발효 → 까닭: 3C 모양 그대로 색만 변함 = 골격 그대로 환원(위 각뿔과 하나만 다름).
6. 작은 기계가 빈 통을 삼킴 + 선반 동전 2 = NAD⁺ 되돌려 해당과정 지속, ATP 2 → 까닭: 같은 이빨·리벳의 작은 기계 = 같은 해당과정. 굴뚝에 투입구·동전 없고 선반에 동전 2 — 구역1과 견주면 '순 2'(추정).

### 구역6 **코리 회로** (오른쪽 길·집·개)
1. 수레의 보라 각뿔 2 = 젖산 2 → 까닭: 수레 = 옮김, 둘 = 피루브산 2몫.
2. 집 문 앞 큐브 1 = 포도당 → 까닭: 수레의 각뿔 2(3+3)↔큐브 1(6) — 구역1의 큐브 1→각뿔 2를 거꾸로(좌우 맞섬).
3. ↻집은 간 표지 아님(#93) → 까닭: 수레가 가고 큐브가 나오는 문으로만 읽힘.
4. 제 꼬리를 쫓는 개 = 코리 회로(#173) → 까닭: 소리(꼬리=코리) + 빙글빙글=회로, 곡선 속도선.

## ③ 모름·어색
- 모름: 통 10개(하나만 다른 통 없음 → #126 아님), 가운데 어두운 타원 고리, 바닥 고리 8, 선반 기둥 2, 집 창 둘, 머리카락 있는 둘(경비원·개찰구 남자).
- 어색: 중간 블록의 탄소 수, 구역1의 가득 통이 하나뿐, 오른쪽 담의 단차(이어 붙인 흔적). ↻작은 기계는 붙임이 아니라 일부러 다시 그린 해당과정 기계.

## ④ 한 문장
포도당(큐브 6C)은 ATP 2를 넣고 각뿔 둘이 되어 ATP 4·NADH를 남기고, 산소가 있으면 문을 지나 CO₂ 하나를 떼고 CoA 꼬리표 쐐기가 되어 돌림판(CO₂ 2·NADH 3·FADH₂ 1·GTP 1)을 돌며 가득 양동이를 쪽문(전자전달)으로 보내지만, 산소가 없으면 그 길이 판자로 막혀 통이 쌓이니 통을 비워 해당과정만 잇고 젖산은 수레로 실어 포도당으로 되돌린다(코리).
