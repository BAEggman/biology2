# 1단계 — 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위 **세포호흡 (포도당 이화: 해당과정 → 피루브산 산화 → TCA 회로 → 전자전달·산화적 인산화, 산소 없으면 발효)** — 80%
- 2순위 **포도당 대사 총론 (호기 vs 혐기 경로, ATP·NADH 수지, 발효와 Cori 회로)** — 12%
- 근거: 큐브(6C)→피라미드(3C)→작은 조각(2C), 동전=ATP, 물양동이=NADH, 검은 방울=CO2, 벽 안마당=미토콘드리아, 하늘 방울=O2, 먹구름=무산소.

## ② 구역별 (왼쪽부터)
### 구역1 — **해당과정** (햇빛 든 벽 밖 초원 = 세포질)
① 큰 빨간 정육면체를 입에 넣는 일꾼 = 포도당 6C (모양·크기) ② 이빨 달린 기계 = 6C를 쪼개는 효소계 (동작) ③ 굴뚝 2개, 슬롯에 동전 1개씩 = ATP 2개 투자 (개수) ④ 컨베이어 위 빨간 피라미드 2개 = 피루브산 2분자, 3C (개수·모양) ⑤ 스탬프로 찍은 겹사각 도장 = 인산기(PEP류) (모양) ⑥ 도장 쪽에서 양동이로 흘러드는 물 = H2O 방출 또는 NADH (뜻, 불확실) ⑦ 피라미드에 붙은 동전·일꾼이 든 동전 = 기질수준 인산화로 ATP 생성 (뜻) ⑧ 앞 4칸 상자의 동전 4개 = ATP 총 4, 순 2 (개수) ⑨ 물 튀는 양동이 1 + 빈 양동이 1 = NADH / NAD+ (뜻, 불확실). → 9개

### 구역2 — **피루브산 수송 + 산화적 탈카르복실화(아세틸-CoA 생성)** (벽 왼쪽 문)
① 벽 = 미토콘드리아 막 (자리) ② 문 앞 제복 경비원이 작은 빨간 피라미드를 확인 = 피루브산은 수송체를 통해서만 통과 (뜻) ③ 밀어 도는 회전문 + 바닥 오른쪽 화살표 = 일방향(세포질→기질) 수송 (모양·동작) ④ 가위 든 일꾼 + 꼭대기가 잘린 큰 피라미드 = 탈카르복실화, 3C→2C (동작) ⑤ 떨어지는 검은 물방울 + 연기 1개 = CO2 1분자 (모양·개수) ⑥ 끈으로 꼬리표를 맨 작은 붉은 조각 = 아세틸(2C)+CoA (모양) ⑦ 물양동이 들고 걷는 일꾼 1명 = NADH 1개 (개수) ⑧ 빈 4칸 상자 = ATP 0 (개수, 불확실). → 8개

### 구역3 — **TCA 회로** (가운데 회전 원반)
① 롤러 위에서 도는 원반 = 회로(순환) (모양) ② 모자 쓴 작은 큐브 → 굽은 화살표 → 큰 큐브 = 옥살아세트산(4C)+아세틸(2C) → 시트르산(6C) (모양·크기) ③ 원반 위 빈 꼬리표 = CoA 방출 (모양) ④ 굴뚝 2개 + 검은 공 2개 = CO2 2분자/회전 (개수) ⑤ 물양동이 든 일꾼 3명 = NADH 3개 (개수) ⑥ 무릎 꿇고 큐브를 만지며 어두운 납작판을 터는 일꾼 = FADH2 1개(숙신산 단계) (뜻, 불확실) ⑦ 큐브가 큰 것 > 무릎 큐브 > 작은 큐브 = 탄소 6→5→4 (크기). 가장자리 뚜껑 통 10개는 모름. → 7개

### 구역4 — **전자전달계·산화적 인산화** (벽 위 선반, 작은 문, 하늘) — 확신 낮음
① 높은 선반 위에서 양동이를 든 일꾼 = 막 한쪽에 고인 H+ 기울기(위치에너지) (자리·뜻) ② 벽 아래 작은 문 = H+ 통로, ATP 합성효소 (자리, 불확실) ③ 하늘의 투명한 방울 10개(먹구름 쪽엔 없음) = O2, 최종 전자수용체 (모양·자리). 선반 위 기둥 2개는 모름. → 3개

### 구역5 — **무산소 발효 (NAD+ 재생)** (먹구름 아래)
① 먹구름 = 산소 없음 (자리) ② 판자를 X로 박은 문 = 전자전달계 차단 (모양) ③ 문 앞에 쌓인 양동이 더미(16~18개) = NADH 축적, NAD+ 고갈 (개수) ④ 작은 기계 + 일꾼이 빈 양동이를 입에 넣음 = NAD+를 해당과정에 되돌림 (동작) ⑤ 기계 선반 위 동전 2개 = ATP 순 2 (개수) ⑥ 양동이 물을 부어 빨강→보라가 되는 피라미드 = 젖산 발효(피루브산+NADH→젖산+NAD+) (동작·색) ⑦ 빨간 피라미드 위 검은 방울·긴 연기 + 물 붓는 나비넥타이 일꾼 = 알코올 발효, CO2 방출 (모양, 불확실). → 7개

### 구역6 — **Cori 회로** (맨 오른쪽 길·집·개)
① 수레 속 보라 피라미드 2개 = 젖산 운반 (개수·색) ② 벽돌집 = 간 (자리) ③ 집 문 앞 빨간 큐브 1개 = 간에서 만든 포도당이 되돌아옴 (모양·동작) ④ 제자리에서 빙글빙글 도는 개 = "코리/콜리" 소리 + 회로 (소리·동작). → 4개

## ③ 뜻 모를 것 · 어색한 것 · 이어 붙인 흔적
- 벽 위 선반의 일꾼·기둥 2개, 벽 아래 작은 닫힌 문은 전자전달계로 추정할 뿐 확정 못 함(판자 문과의 짝도 헷갈림).
- 원반의 통 10개(중간체 8개와 안 맞음, 1회전 ATP 10?), 가운데 타원 고리, 어두운 납작판, TCA에 GTP 동전이 안 보임.
- 회전문 옆 빈 4칸 상자(왼쪽 동전 상자와 짝), 바닥에 흩어진 작은 고리 8~9개는 뜻 불명.
- 같은 빨간 피라미드가 피루브산/PEP/발효 기질로 반복, 양동이가 NADH·NAD+·H2O로 겹침.
- 이어 붙인 흔적: 오른쪽 작은 기계는 왼쪽 기계의 축소 재사용, 오른쪽은 벽 기둥에서 시점이 꺾이고 색조가 다름. 머리카락 있는 인물(경비원·회전문 남자)은 대머리 일꾼과 결이 다름.

## ④ 한 문장
포도당(큐브)은 세포질에서 피루브산 2개와 순 ATP 2개가 되고, 산소가 있으면 문지기를 지나 미토콘드리아에서 CO2를 떼며 TCA 원반을 돌아 NADH·FADH2로 전자전달 ATP를 크게 만들지만, 산소가 없으면(먹구름) 문이 막혀 NADH가 쌓이므로 발효로 NAD+를 되살려 해당과정만 잇고 젖산은 간에서 포도당으로 되돌린다(Cori).
