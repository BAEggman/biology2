# 2단계 (약속표 어휘로 다시 읽음) ↻ = 1단계와 달라진 곳

## 판정
약속으로 더 잘 풀림. 풀린 것: 회색 네모 칩=GTP(#101) · 네모 양동이=FAD(#102) · 뒷담 쪽문=전자전달계 길(#174) · 가위표 판자=쓰지 않음(#144) · 꼬리 쫓는 개=코리 회로(#173) · 민 도장=인산화(#100) · 블록·각뿔·쐐기=탄소 수(#171·172) · 방울=O₂/CO₂(#17·16). 약속표에 없어 모름: 돌림문·경비·단지 10개. 꼴이 겹쳐 보류: 4칸 쟁반(#22 모듈 쟁반이나 동전이 담겨 칼모듈린 아님), 수레(#109 상자 수레=cyt c이나 젖산을 실음), 집(#93 홀로 선 간인지 담장에 붙은 집인지).

## ① 표제어
- **1순위: 세포호흡 — 해당과정 → 피루브산 산화 → TCA 회로 → (산소 없으면) 발효·코리 회로; 전자전달계는 쪽문으로만 암시** ↻ 90%
- **2순위: 산소 유무에 따른 NADH 처리(호기 대 발효)와 NAD⁺ 재생** 6%

## ② 구역별 사실 + ⑤ 까닭 ([ ] = 까닭이 기댄 단서)
### 구역1 맨 왼쪽 들판 — **해당과정(세포질)**
1. 큰 블록 1을 이빨 기계 입에 밀어 넣음 = 포도당(6C) 쪼개짐 6→3+3. → 까닭: [크기] 입구 큰 블록 1 ↔ 출구 작은 각뿔 2를 견줘 한 덩이가 둘로 갈라짐.
2. 굴뚝 2개에 꽂힌 동전 = ATP 2 소모(#8). → 까닭: [동작·개수] 동전이 구멍으로 들어감=쓰는 쪽, 기계 위(입력 쪽)에 둘.
3. 컨베이어의 각뿔 2 = 피루브산 2(3C, #171). → 까닭: [개수·크기] 같은 각뿔 둘 나란히=포도당 하나당 둘, 블록보다 작음=탄소 적음.
4. 땅의 쟁반 동전 4 = 총 ATP 4(순 2). → 까닭: [개수·자리] 칸마다 하나라 개수가 곧 양, 굴뚝의 2를 뺀 값이 순 2, 나오는 쪽 땅에 놓임.
5. ↻ 민 도장 자국 = 인산화(#100). → 까닭: [대비] 자국은 왼쪽 각뿔에만, 오른쪽엔 동전 — 순서대로 「인산 붙음 → ATP로 떨어짐」.
6. ↻ 물 튀는 가득 양동이 ↔ 곁의 빈 양동이 = NADH ↔ NAD⁺(#102). → 까닭: [대비·동작] 같은 양동이를 가득/텅으로 맞세움, 튀는 물=채워지는 중(환원); 양동이가 하나뿐이라 NADH '2'는 안 읽힘(까닭 모름).
7. 각뿔에서 떼는 동전 + 든 동전 = 기질수준 인산화. → 까닭: [대비] 구멍에 들어가는 동전(굴뚝) ↔ 각뿔 몸에서 나오는 동전.
8. ↻ 해 + 왼쪽~가운데 하늘의 밝은 방울 10 = O₂ 있음(#17; 틀선 칸이 없어 해는 판의 뜻 그대로 #118). → 까닭: [자리·대비] 방울이 오른쪽 먹구름 하늘엔 없음; 10개의 뜻은 까닭 모름.

### 구역2 벽 입구 — **피루브산 유입과 산화적 탈카복실화 → 아세틸 CoA**
1. 담장 한 겹 + 열린 문 하나 = 막과 통로(#116 담장=막). → 까닭: [자리] 풀 들판과 모래 마당을 가르고 문 하나만 뚫림=정해진 길로만 건넘.
2. 문턱 경비가 온전한 각뿔을 듦 = 피루브산이 수송체를 거쳐 입장(경비는 약속표 없음). → 까닭: [자리·대비] 꼭대기 멀쩡한 각뿔=아직 3C(가위질 전), 문→가위→원반 순으로 늘어섬.
3. 가위 + 꼭대기 잘린 각뿔 + 떨어지는 검은 방울 1 = 탈카복실화, CO₂ 1(#16), 3C→2C. → 까닭: [동작·개수] 자른 자리 위로 방울이 떨어짐=잘린 것이 CO₂, 방울 하나=하나.
4. 끈으로 꼬리표를 맨 작은 쐐기 = 아세틸 CoA(#172). → 까닭: [크기·동작] 쐐기 작음=2C, 꼬리표를 끈으로 묶음(#170 한 몸)=CoA 붙음; 구역3의 풀린 꼬리표와 붙음↔떨어짐.
5. 가득 양동이 들고 원반 쪽으로 걷는 사람 1 = NADH 1. → 까닭: [자리·개수] 가위 곁을 지나 마당으로=이 단계의 산출물, 한 사람=하나.
6. 빈 4칸 쟁반 = ATP 0 [낮음]. → 까닭: [비어 있음] 구역1의 4동전 쟁반과 같은 소품을 비워 둠=이 단계엔 ATP 없음.
(모름) 돌림문(팔 3~4개)을 힘주어 미는 머리카락 있는 남자 + 바닥 곡선 화살표 → 까닭 모름: 「한 방향·힘듦」 같으나 무슨 사실인지 못 읽음.

### 구역3 가운데 원반 — **TCA 회로(기질)**
1. 도는 원반 = 회로. → 까닭: [모양·동작] 둥글어 끝이 처음으로 이어짐, 가장자리 동작선=계속 도는 중.
2. 굴뚝 2 + 검은 공 2 = CO₂ 2(한 바퀴). → 까닭: [개수·자리] 연기와 솟는 공=배출, 굴뚝을 원반 앞에 따로 세움=밖으로 내보냄; 두 공의 크기 차이는 까닭 모름.
3. 작은 블록+쐐기 → 큰 블록(4C+2C→6C). → 까닭: [크기·동작] 작은 4·큰 6(#171), 쐐기를 얹자 커짐, 화살표가 작은→큰.
4. 큰 블록 곁에 풀려 누운 꼬리표 = CoA 분리. → 까닭: [대비] 구역2에선 쐐기에 묶였던 꼬리표가 홀로 누움=아세틸을 넘기고 풀려남.
5. 둘레의 가득 양동이 든 사람 3 = NADH 3. → 까닭: [개수·자리] 같은 가득 양동이 든 사람이 셋=개수가 양, 원반 바깥에서 내보냄(구역2의 1과 합쳐 4).
6. ↻ 무릎 꿇은 사람의 중간 블록 = 5C(α-케토글루타르산 꼴). → 까닭: [크기] 폭을 재니 큰 40 : 이것 30 : 작은 24 — 4와 6 사이라 5, 도는 동안 한 칸씩 줆.
7. ↻ 그가 흔드는 짙은 회색 네모 칩 = GTP 1(#101). → 까닭: [모양·색] 둥근 금동전(ATP)과 모양·색을 달리해 다른 것임을 알림, 칩 하나=한 바퀴에 1.
8. ↻ 뒷벽 선반 위 사람의 네모 가득 양동이 = FADH₂ 1(#102). → 까닭: [모양·자리] 둥근 양동이(NADH)와 달리 네모 하나=FAD; 막(담장)에 붙은 선반=막에 박힌 숙신산 탈수소효소 꼴(내 추정).
9. ↻ 뒷담 밑동의 닫힌 작은 쪽문 = NADH·FADH₂가 전자전달계로 가는 길(#174). → 까닭: [대비] 닫혔어도 판자로 막히진 않음 ↔ 구역4의 가위표 문=산소 있을 땐 쓰는 길.
(모름) 뚜껑 단지 10개(8단계와 안 맞음) · 원반 가운데 작은 구멍 → 까닭 모름: 같은 단지가 일정 간격이라 「같은 종류의 단계」까지만 읽힘.

### 구역4 오른쪽 먹구름 아래 — **무산소: 발효·NAD⁺ 재생·코리 회로**
1. 먹구름 + 해·방울 없음 = 산소 없음. → 까닭: [대비·자리] 구역1 하늘(해·방울)과 좌우로 맞세움, 하늘이 오른쪽으로 갈수록 어두워짐.
2. ↻ 가위표 판자 문 = 전자전달계 길을 쓰지 않음(#144). → 까닭: [대비] 구역3의 쪽문과 같은 문이 판자로 막힘, 산소 없는 쪽에 놓임.
3. 문 앞에 쌓인 가득 양동이 더미(약 15~20) = NADH 적체. → 까닭: [개수·대비] 구역3에선 한 명씩 들고 나가던 양동이가 막힌 문 앞에 쌓임=못 내보낸 NADH.
4. 양동이 쏟는 사람 + 붉은→보라 각뿔 + 푸른 불꽃 = 젖산 발효, NADH→NAD⁺. → 까닭: [빛깔·동작] 각뿔 빛깔이 바뀜=다른 물질, 양동이를 비움=NADH가 NAD⁺로, 물 닿는 자리 불꽃=전자를 넘김.
5. 쏟는 사람 + 붉은 각뿔 위 검은 방울 = 알코올 발효, CO₂ 1. → 까닭: [대비] 같은 붓는 동작 한 쌍에서 방울 유무·각뿔 빛깔만 다름=두 발효를 가름; 나비넥타이는 까닭 모름.
6. 작은 이빨 기계 입에 빈 양동이를 넣는 사람 = NAD⁺가 해당과정으로 복귀. → 까닭: [크기·동작] 구역1의 큰 기계와 같은 입을 작게=같은 해당과정, 빈 양동이를 넣음=공급.
7. 기계 선반의 동전 2 = 순 ATP 2. → 까닭: [개수·대비] 구역1 쟁반 4보다 적음=순이득; 굴뚝에 동전 투입구가 없는 것은 까닭 모름.
8. 보라 각뿔 2 실은 수레 → 집 = 젖산이 간으로. → 까닭: [자리·개수] 수레가 집 쪽으로, 각뿔 2=젖산 2.
9. 집 문간의 작은 붉은 블록 = 새 포도당. → 까닭: [자리] 문 밖으로 나와 있음; 크기가 작은 까닭은 모름(6C 규칙과 안 맞음).
10. ↻ 꼬리 쫓아 도는 개 = 코리 회로(#173). → 까닭: [동작] 몸을 감싼 원형 동작선=회로, 젖산→집→포도당 장면 곁에 놓임.

## ③ 남은 것
뜻 모름: 돌림문·화살표 / 경비 / 단지 10 / 선반의 뜻 / 문간 블록 크기 / 나비넥타이 / 작은 기계 왼쪽의 빈 선반 / 굴뚝 투입구 없음. 헷갈림: 각뿔 4종, 동전 네 곳(투자·총생산·순), 문 3개. 이어 붙임: 1단계와 같음(들판↔벽 마당 시점 차, 작은 기계는 큰 기계의 축소, 뒷벽 꺾임).

## ④ 한 문장
포도당(블록 6C)은 세포질에서 각뿔 둘로 쪼개지며 ATP를 2 쓰고 4 얻고, 산소가 있으면 벽 문을 지나 가위에 CO₂를 잃고 꼬리표 쐐기(아세틸 CoA)로 원반(TCA)에서 CO₂·NADH·FADH₂·GTP를 내며 양동이가 쪽문(전자전달계)으로 가고, 산소가 없으면 그 문이 막혀 양동이를 쏟는 발효로 NAD⁺를 되살려 해당과정을 잇고 젖산은 간을 거쳐 코리 회로로 돈다.
