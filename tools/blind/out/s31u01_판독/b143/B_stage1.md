# 생판 판독 (stage1) — 그림만 보고

## ① 판 전체 표제어
- 1순위 **세포 호흡과 발효 (해당과정 → 피루브산 산화 → 시트르산 회로 → 산화적 인산화, 막히면 발효)** 확신 72%
- 2순위 **미토콘드리아의 구조와 기능 (막 수송·기질 반응·ATP 합성)** 확신 12%

## ② 구역별 (왼쪽부터)
**구역1 풀밭·상어 화로 = 해당과정(세포질)** 읽힌 7
1. 큰 빨간 정육면체를 안고 입에 밀어 넣음 = 포도당 6C (모양·크기)
2. 이빨 달린 화로, 벽 밖 풀밭 = 해당(당 쪼개기)이 세포질에서 (뜻·자리)
3. 컨베이어의 빨간 피라미드 2 = 피루브산 2분자 3C×2 (모양·개수)
4. 굴뚝 2개에 금화 1씩 = ATP 2 (투자 2 또는 순 2) (개수)
5. 칸막이 상자 금화 4 = ATP 4 생성 (4−2=순 2) (개수)
6. 파란 옷 남자가 피라미드 금화를 떼어 듦 = 기질수준 인산화 (동작)
7. 땀 흘리는 성난 남자·물양동이·물줄기 = NAD+→NADH 2 또는 투자 단계 고생 (뜻, 불확실)
- 모름: 해(‘해당’ 말놀이?), 하늘 비눗방울 11개(왼쪽~가운데만; O2? CO2?), 이빨 위6~7·아래3

**구역2 벽 문·경비·가위 = 피루브산 수송·산화(→아세틸 CoA)** 읽힌 8
1. 벽 = 미토콘드리아 막, 문 = 통로 (자리)
2. 제복 경비병이 3C 피라미드를 들고 문 안쪽 = 수송 단백질 (뜻)
3. 가위 든 사내 = 탈탄산(잘라냄) (뜻)
4. 검은 물방울+연기 1 = CO2 1분자 (모양·개수)
5. 윗면 잘린 큰 피라미드 = 3C→2C (모양)
6. 끈 묶인 꼬리표 달린 작은 피라미드 = 아세틸 CoA (꼬리표=CoA)
7. 양동이 들고 원판 쪽으로 걷는 사내 = NADH 1 (뜻)
8. 굽은 회색 화살표 = 회로 쪽 진행 (자리)
- 모름: 나선 기둥(4고리+ㄱ자 봉; 회전문? 보조인자 4?)

**구역3 중앙 원판 = 시트르산 회로** 읽힌 7
1. 볼트 박힌 큰 원판+속도선 = 도는 순환 회로 (모양)
2. 작은 큐브+얹은 피라미드 →(분홍 화살표)→ 큰 큐브 = OAA 4C+아세틸 2C→시트르산 6C (크기)
3. 원판 위 빈 꼬리표 = 떨어진 CoA (자리)
4. 무릎 꿇고 중간 큐브에서 검은 조각 털어냄 = 탈탄산 6→5→4C (동작)
5. 연기·검은 공 원통 2 = CO2 2/회전 (개수)
6. 원판 둘레 양동이 든 사람 3 = NADH 3 (개수)
7. 벽 선반 위 양동이 사내 1 = FADH2 1, 막 결합 효소 (자리·개수, 추정)
- 모름: 볼트 17(가려진 2 포함), 중앙 구멍, 철제 받침, 뒷벽 작은 닫힌 문, GTP 1개(금화) 못 찾음

**구역4 먹구름·막힌 문·작은 화로 = 산소 없음 → 발효** 읽힌 9
1. 물레방아(벽에 반쯤) = ATP 합성효소, H+ 흐름 (모양, 추정)
2. 먹구름·비 = 산소 없음/물 (뜻, 약함)
3. X자 판자 막힌 문+양동이 더미(15~20) = 전자전달 차단→NADH 축적 (자리)
4. 작은 화로 굴뚝 2, 선반 금화 2 = 발효는 해당과정뿐, 순 ATP 2 (개수)
5. 양동이를 화로 창에 넣는 사내 = NAD+ 재생 (동작)
6. 보라 피라미드에 물 붓기 = 피루브산+NADH→젖산 (빨강+파랑=보라)
7. 연기 방울 밑, 물줄기에 귀퉁이 깎인 빨간 피라미드 = 알코올 발효(CO2 이탈) (모양)
8. 수레의 보라 피라미드 2 = 젖산 2분자, 간으로 (개수)
9. 끝 창고+빨간 큐브(속도선) = 간의 포도당 재합성, 코리 회로? (추정)
- 모름: 원 그리며 도는 개

## ③ 어색·헷갈림·이음
- 뜻 모를 물건: 나선 기둥(4고리), 볼트 17, 원판 중앙 구멍, 비눗방울 11(대2·중6·소3), 해, 개, 끝 창고의 큐브, 뒷벽의 작은 닫힌 문, 이빨 수.
- 날씨 대비: 왼쪽 맑은 해 → 오른쪽 폭풍·비. 좌→우로 ‘산소 있음→없음’을 암시하는 듯하나 확신 낮음.
- 헷갈림: 빨간 피라미드 7곳, 큐브 4/5/6C 모두 크기 차뿐; 검은 CO2가 방울·공 두 꼴; 양동이=NADH인지 FADH2인지; 막힌 문이 ‘산소 없음’인지 ‘피드백 억제’인지.
- 어색: 금화가 굴뚝에 꽂힘, 선반 사내만 벽 높이, 빈 이름표 2장(글씨 없음), 벽 밑에 글씨 같은 낙서 2곳(읽히지 않음).
- 이음: 뚜렷한 선 없음. 벽 끝(x≈640)·기둥(x≈1590)에서 장면이 바뀜; 회색 큰 화살표만 덧그린 느낌.

## ④ 한 문장
포도당(6C)이 해당과정에서 쪼개져 ATP를 조금 내고, 피루브산이 막을 지나 CO2를 잃고 아세틸 CoA가 되어 회로에서 CO2·NADH·FADH2를 내며, 이 운반체로 산소가 ATP를 만들지만 산소가 막히면 NADH를 젖산·에탄올 발효로 털어 NAD+를 되살린다.
