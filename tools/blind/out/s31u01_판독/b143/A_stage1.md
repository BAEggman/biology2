# 1단계 생판 읽기 (s31u01)

## ① 판 표제어
- 1순위 **세포호흡(해당 → 피루브산 산화 → TCA 회로 → 전자전달·산화적 인산화)** 75%
- 2순위 **ATP 생성·에너지 대사(기질수준 vs 산화적 인산화)** 12% (그 밖 **미토콘드리아·화학삼투** 5%)
- 근거: 6면 큐브 1개가 피라미드 2개로 쪼개짐(6C→3C×2), 동전(ATP)이 곳곳(굴뚝 2·상자 4·작은 기계 선반 2), 검은 공·방울(탄소=CO2)이 가위 곁 1·원통 2, 꼬리표(CoA)가 붙었다 떨어짐, 보라 피라미드(전자운반체)와 물(양동이·비·물레방아)이 오른쪽에 몰림.
- 해·거품은 광합성 쪽으로도 읽히나, CoA 꼬리표·CO2 공·회로 원반이 호흡을 가리켜 2순위로 돌림.

## ② 구역별 읽기 (여섯 구역)

### 구역1 벽 밖 풀밭: **해당과정(포도당 → 피루브산)**
- 사람이 빨간 큐브 1개를 상어 입 기계에 밀어 넣음 = 포도당 6탄당 1분자 (모양 6면·자리 입구), 이빨 입 = 당을 썰어 쪼갬, 해당(解糖) (뜻)
- 컨베이어에 나온 빨간 피라미드 2개 = 피루브산 2분자, 3C×2 (개수)
- 굴뚝 끝에 선 동전 2개 = ATP 2(순생성 또는 투자), 4칸 나무상자의 동전 4개 = ATP 총 4 생성 (개수)
- 파란 셔츠 사람이 피라미드 면에 동전을 직접 붙임(손에 1개 더) = 기질수준 인산화 (동작)
- 땀 뻘뻘 사람이 물통 물을 피라미드에 뿌림, 해, 거품 11개(굴뚝 곁 1개 포함) = 물·열·O2? 약함

### 구역2 왼쪽 벽의 문~가위: **피루브산 수송·산화(→ 아세틸-CoA)**
- 벽의 문 + 제복 경비원이 피라미드를 쥠 = 피루브산이 막의 문을 통과 (자리·뜻)
- 가위 = 탈카복실화 (뜻), 검은 방울 1개(연기 한 가닥) = CO2 1분자, 3C→2C (개수 1)
- 윗부분이 잘려 납작한 피라미드 = 2C 아세틸, 끈으로 꼬리표를 맨 작은 피라미드 = 아세틸-CoA (모양·뜻)
- 바닥의 굵은 회색 화살표 = 진행 방향(안쪽·회로로) (자리). 문 곁 나선 기둥(고리 4) = 모름

### 구역3 큰 원반: **TCA 회로**
- 볼트(16~18개) 달린 원반 + 가장자리 속도선 = 돌아서 제자리로 오는 회로 (모양·동작)
- 모자(작은 피라미드) 쓴 작은 큐브 → 빨간 화살표 → 큰 큐브 = 4C+2C → 6C 구연산 (모양)
- 원반에 떨어진 빈 꼬리표(속도선) = CoA 분리·재사용 (모양)
- 원통 2개마다 검은 공 달린 연기 = CO2 2분자(한 바퀴 2) (개수)
- 무릎 꿇은 사람이 큐브를 옮기며 회색 카드를 털어냄, 큐브 크기 차 = 산화·탄소 감소? 약함

### 구역4 뒷벽 위: **H+ 농도 기울기·ATP 합성효소**
- 높은 선반 위 물통 든 사람 = 한쪽에 높게 고인 H+ (자리·뜻)
- 벽 위 물레방아 = 회전하는 ATP 합성효소 (모양·동작). 벽 = 막. 작은 닫힌 문 = 모름

### 구역5 오른쪽 칸 위: **물 생성·차단**
- 먹구름과 비 = 물 생성(O2 환원) (모양)
- 널빤지 X로 막힌 문 + 양동이 더미(13개 이상) = 막힘·축적, 약함
- 검은 방울 떨어지는 빨간 피라미드에 물 붓는 사람(모서리가 톱니처럼 파임) = 모름

### 구역6 오른쪽 칸 아래: **전자운반체 → 산화적 인산화**
- 보라 피라미드 = NADH·FADH2 (색), 손수레 속 보라 2개 = NADH 2 (개수), 물 닿으면 붉은 기운 섞임 = 산화? 약함
- 작은 청록 기계(굴뚝 2, 창에 양동이 투입) → 선반 위 동전 2개 = ATP 합성 (모양·개수)
- 몸에 선이 도는 개 = 모름

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이어 붙인 흔적
- 모름: 나선 기둥(고리 4+굽은 손잡이, 회전문?), 원반 가운데 구멍, 회색 카드, 개(입 벌리고 도는 선), 작은 집 문턱의 빨간 큐브(속도선), 뒷벽 작은 문, 상어 이빨 수(위 6·아래 3~4).
- 어색: 벽 위 선반의 사람, 벽 뒤 물레방아, 오른쪽에만 내리는 비, 허공에서 떨어지는 검은 방울.
- 헷갈림: 빨간 큐브·빨간 피라미드·보라 피라미드, 검은 공 vs 방울, 동전이 네 곳(굴뚝·상자·손·선반), 양동이 든 사람 9명, 꼬리표 둘(끈 맨 것·떨어진 것).
- 이어 붙인 흔적: 작업복 색이 갈색(왼쪽·가운데)과 회청색(오른쪽 칸+가운데 2명)으로 갈림, 벽이 단 지는 곳부터 다른 칸처럼 보임, 하늘이 왼쪽 크림·오른쪽 먹구름.

## ④ 한 문장
포도당이 쪼개져 ATP를 남기고 피루브산이 되며, CO2를 잃고 CoA를 단 아세틸로 TCA 원반을 돌아 CO2 2개와 전자운반체를 내놓고, 그 전자가 끝에서 물과 대량의 ATP(물레방아)가 된다.
