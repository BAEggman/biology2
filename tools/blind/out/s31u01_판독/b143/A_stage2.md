# 2단계 약속표 판독 (s31u01)

## ① 판 표제어 ↻
- 1순위 **세포호흡 — 포도당 분해(해당과정 · 피루브산 산화 · TCA 회로) + 산소 없을 때의 발효 · 코리 회로** 72% ↻ 1단계는 전자전달·산화적 인산화를 중심으로 읽었으나, 이 판에서 전자전달은 쪽문·물레방아로 예고만 된다.
- 2순위 **산소 유무에 따른 포도당 대사의 갈림길(호기 호흡 vs 혐기 발효)** 15% (그 밖 **세포호흡 전체** 8%)
- 판정: 약속표로 더 잘 풀린다. 모름 8→3, 정정 3곳(보라 피라미드 · 선반의 물통 · 구름과 비), 개수가 뜻을 얻음(양동이 4+1, 동전 2·4·2).

## ② 구역 (왼쪽부터 여섯 · 줄마다 「→ 까닭」이 ⑤)

### 구역1 풀밭: **해당과정(포도당 → 피루브산 2, ATP·NADH)**
- 빨간 큐브 1을 상어 입 기계에 밀어 넣음 = 포도당 6C(#171) → 까닭: 그림에서 가장 큰 빨간 물건(컨베이어 피라미드 너비의 약 1.7배)이라 탄소 최다, 이빨 입 = 쪼갬
- 컨베이어 피라미드 2 = 피루브산 3C×2 → 까닭: 같은 크기·색을 나란히 둠 = 반반(6=3+3), 큐브 1(큼)이 피라미드 2(작음)로 개수만 늘고 크기는 줆
- 굴뚝 끝 동전 2 = ATP 순생성 2(#8) → 까닭: 기계 한 대 전체의 산출이라 굴뚝에 하나씩 세움, 상자 4와 손 2를 견주면 4−2=2(추정)
- 4칸 상자 동전 4 = ATP 총 4 ↻ → 까닭: 칸 넷에 하나씩이라 개수를 눈으로 셈, 굴뚝(2)보다 많음 = 총량이 순량보다 큼
- 파란 사람의 동전 2(손 1 + 피라미드 면 1) = 3C 단계에서 ATP를 직접 주고받음 ↻ → 까닭: 동전이 손을 거쳐 피라미드 면에 곧장 닿음(효소 없이 물질끼리), 피라미드마다 2 × 2 = 상자 4(추정)
- 땀 흘리는 사람의 가득 찬 물통 1 = NADH(#102) ↻ → 까닭: 물이 피라미드 면의 꼭지에서 통으로 쏟아져 듦(H를 빼 담는 방향, 방향은 추정), 두 피라미드 사이에 놓임, 땀의 뜻은 까닭 모름
- 해와 밝은 방울 11 = 산소 있는 맑은 날(#17) ↻ → 까닭: 오른쪽 먹구름·비와 좌우로 맞섬, 해만의 뜻은 '해당' 소리일 수 있으나 추정

### 구역2 문~가위: **피루브산 수송 · 산화(→ 아세틸 CoA)**
- 담의 문 + 경비원이 피라미드를 쥠 = 3C만 막을 통과(운반체는 추정) → 까닭: 큐브는 담 밖 풀밭에서 쪼개지고 피라미드만 안뜰로 들어옴(자리 대비), 문이 하나뿐
- 가위로 윗부분이 잘려 평평한 피라미드 + 검은 방울 1 = 3C→2C, CO2 1(#16) → 까닭: 잘린 조각이 방울 1개, 평평한 윗면을 컨베이어의 뾰족한 피라미드와 견줘 하나 줄었음을 읽음
- 끈으로 꼬리표를 맨 작은 쐐기 = 아세틸 CoA(#172) ↻ → 까닭: 쐐기는 피라미드보다 작아 2C, 꼬리표가 '매여' 있음 ↔ 원반 위 홀로 놓인 꼬리표(붙음 vs 떨어짐)
- 가득 찬 양동이를 들고 걷는 사람 1 = NADH 1 ↻ → 까닭: 걷는 동작 = 만들어져 다음으로 옮겨 감, 원반 둘레 3과 개수를 견줌
- 바닥의 굵은 회색 화살표 = 진행 방향 → 까닭: 문에서 원반 쪽으로 휘어 오름(순서), 약속표에 없는 물건

### 구역3 큰 원반: **TCA 회로**
- 볼트 둘린 원반 + 속도선 = 돌아서 제자리로 오는 회로 → 까닭: 둥근 판과 가장자리 속도선 = 회전, 한 판 위에 앞뒤 단계가 같이 놓임(볼트 17~18은 까닭 모름)
- 모자(쐐기) 쓴 작은 블록 → 화살표 → 큰 블록 = 4C+2C → 6C(구연산) ↻ → 까닭: 블록 크기가 탄소 수(#171), 쐐기가 문 앞 쐐기와 같은 꼴 = 그것이 들어옴, 화살표가 합치는 방향
- 큰 블록 곁에 홀로 놓인 빈 꼬리표 = CoA가 떨어져 재사용 ↻ → 까닭: 매이지 않고 놓임(비어 있음)
- 원통 2개의 검은 공 2 = CO2 2 → 까닭: 같은 굴뚝을 나란히 = 같은 일이 두 번, 원반 바깥으로 나옴 = 회로 밖으로 빠짐, 공 크기 차는 까닭 모름
- 무릎 꿇은 사람이 큐브를 쥐고 회색 네모 칩을 털어냄 = GTP 1(#101) ↻ → 까닭: 칩이 네모(동전의 둥긂과 갈림) = ATP 아님, 털어내는 동작과 속도선 = 떨어져 나옴, 큐브는 4와 6 사이(5C 후보, 확정 못함)
- 원반 곁에 선 사람 셋의 둥근 양동이 3 = NADH 3 ↻ → 까닭: 가득 찬 둥근 양동이를 사람마다 하나씩(개수 3), 앞 단계의 1과 합쳐 4

### 구역4 뒷벽: **담(막) 너머 전자전달계로**
- 벽 선반 위 사람 + 네모꼴 양동이 1 = FADH2 1(#102 네모=FAD, 추정) ↻ 1단계 'H+ 농도'를 정정 → 까닭: 모두 바닥인데 혼자 벽에 붙은 선반 위, 양동이 모양이 둥글지 않음, 왜 벽인가는 까닭 모름
- 담 밑동의 작은 나무 쪽문 = NADH·FADH2가 전자전달계로 가는 길(#174) ↻ → 까닭: 안뜰에서 담 너머로 가는 길, 오른쪽의 판자 친 문과 견줘 이쪽은 열려 있음
- 담 뒤 물레방아 = ATP 합성효소(#116) → 까닭: 담 너머에 솟음, 아치와 물 흐름이 없어 돌지 않음 = 다음 판 예고(추정)

### 구역5 오른쪽 위: **산소 없음 — NADH 정체 · 알코올 발효**
- 먹구름과 비 = 산소 없음 ↻ 1단계 '물 생성'을 정정 → 까닭: 왼쪽 하늘은 해·밝은 방울인데 오른쪽엔 구름·비뿐(방울 없음), 틀선 칸이 없어 해·구름이 판의 뜻 그대로(#118)
- 널빤지 X로 막힌 문 = 쓰지 않는다(#144) = 전자전달 길 막힘 ↻ → 까닭: 뒷벽 쪽문과 같은 꼴인데 이쪽만 판자(하나만 다름)
- 문 앞 가득 찬 양동이 더미 13+ = NADH 정체 ↻ → 까닭: 왼쪽은 한 사람이 하나씩 옮기는데 여기는 쌓이기만 함
- 피라미드 + 검은 방울 + 물 붓는 사람 = 알코올 발효(CO2 방출 + NADH 환원, 추정) ↻ → 까닭: 방울이 위에 떠 있고 물이 닿은 모서리가 뜯김, 아래 보라 장면(방울 없음)과 하나만 다름

### 구역6 오른쪽 아래: **젖산 발효 · 코리 회로**
- 빨간 피라미드에 물을 붓자 보라로 변함 = 젖산 발효(피루브산 + NADH → 젖산, 추정) ↻ 1단계 'NADH·FADH2'를 정정 → 까닭: 빨강 + 파란 물 = 보라(색 섞임), CO2 방울 없음
- 수레의 보라 피라미드 2 → 집 문턱의 큐브 1 = 젖산 2 → 포도당 1(집은 #93 단서로 간 아님) ↻ → 까닭: 개수 2→1, 각뿔→큐브, 풀밭의 1→2의 거꾸로(수레가 집 쪽으로 간다는 것은 추정)
- 꼬리 쫓는 개 = 코리 회로(#173) ↻ → 까닭: 빙글빙글 = 회로, 꼬리 = 코리
- 작은 청록 기계에 양동이를 밀어 넣으면 선반에 동전 2(굴뚝은 빔) = 소량 ATP(낮은 확신) ↻ → 까닭: 큰 기계의 축소판인데 동전 자리만 굴뚝에서 선반으로 바뀜, 뜻은 까닭 모름

## ③ 잔결
- 모름: 거치대(고리 4, 모두 비어 있음), 원반 가운데 구멍, 상어 이빨 수(위 6 · 아래 3~4) · 약함 유지: 해의 정확한 뜻
- 약속표에 없어 그림 그대로만: 상어 입 · 컨베이어 · 경비원(모자는 #1로 뜻 없음) · 수레 · 집
- 작업복 색(갈색 6 / 회청색 9)은 구역과 어긋나 의도 불분명
- 어색: 허공의 검은 방울, 벽 위 선반의 사람, 물 없는 물레방아

## ④ 한 문장
포도당이 풀밭에서 둘로 쪼개져 ATP·NADH를 내고, 산소가 있으면 문을 지나 CO2를 잃고 CoA를 단 아세틸로 TCA 원반을 돌며 CO2 2·NADH 3·FADH2 1·GTP 1을 내어 담 뒤 전자전달계로 보내고, 산소가 없으면 NADH가 쌓여 피루브산에 부어 발효로 NAD⁺를 되살리며 젖산은 포도당으로 돌아간다.
