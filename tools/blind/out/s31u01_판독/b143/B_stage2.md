# 2단계 — 약속표로 다시 읽기 (stage2)

## ① 판 전체 표제어 ↻
- 1순위 **세포 호흡 — 포도당의 분해: 해당과정 → 피루브산 산화 → 시트르산 회로 (+산소 없으면 발효·코리 회로)** 88% (1단계 72%)
- 2순위 **NADH·FADH₂ 양동이의 행방 — 전자전달계 입구와 NAD⁺ 재생** 7%
- 판정: 약속표로 훨씬 잘 풀림(양동이·꼬리표·회색 칩·큐브 크기·쪽문·개·방울); 간(#93)·물레방아 아치(#116)만 1단계 추정을 깎음.

## ② 구역별 — 사실 → 까닭
공통: 하늘의 밝은 방울 11 = O₂(#17) — 구역1 위 6·구역2 위 3·구역3 위 2·구역4 0 → 까닭: 오른쪽으로 갈수록 줄어 폭풍 구간에서 0 = 산소 「있다→없다」 대비; 11 자체는 까닭 모름.

**구역1 풀밭의 이빨 화로 = 해당과정(세포질)** 7
1. 큰 빨간 큐브를 안아 입에 밀어 넣음 = 포도당 6C (크기) → 까닭: 블록은 클수록 탄소가 많다(#171); 출구의 작은 피라미드 둘과 크기로 견줘 「하나가 둘로 쪼개짐」.
2. 이빨 화로 · 담 밖 풀밭 = 해당(뜻) · 세포질(자리) → 까닭: 이빨이 깨물어 쪼갬; 담 안 모래마당과 맞서 담 바깥 = 막 밖.
3. 굴뚝에 꽂힌 동전 2 = ATP 2 투자 (개수) ↻ → 까닭: 투입구에 넣은 모양 = 쓰는 쪽; 쟁반 4와 견줘 4−2 = 순 2.
4. 벨트의 피라미드 2 = 피루브산 2 (3C×2) → 까닭: 각뿔 = 3C, 6 = 3+3 이라 개수 2; 둘이 나란히 — 왼쪽 물 뽑기 · 오른쪽 동전 떼기(앞뒤 단계).
5. 땀 흘리는 사람이 피라미드에서 물을 뽑아 양동이를 채움 = NAD⁺→NADH (동작) ↻ → 까닭: 물줄기가 피라미드→양동이로 흐름(수소·전자 이동), 가득 = NADH(#102); 찡그린 얼굴은 까닭 모름.
6. 푸른 셔츠 사람이 동전 1을 들고 피라미드 면의 동전 1을 쥠 = 기질수준 인산화 (동작) → 까닭: 동전이 피라미드에 직접 붙어 손으로 뗌(담·물레방아 불필요); 피라미드당 2 ×2 = 4.
7. 칸막이 쟁반의 동전 4 = ATP 4 생성 (개수) → 까닭: 2×2 칸마다 하나; 굴뚝 2와 개수로 견줘 순 2.

**구역2 담의 문·경비병·가위 = 피루브산 수송과 산화** 7
1. 담의 문 + 문간에서 3C 피라미드를 쥔 경비병 = 피루브산이 막을 지나 들어옴 (자리) → 까닭: 문 하나를 경비병이 지킴(선택적 수송); 풀밭(밖) ↔ 모래마당(안) 대비.
2. 가위 든 사내 = 탈탄산(잘라 냄) (뜻) → 까닭: 칼(K)이 아니라 가위 = 하나를 떼어 냄; 날이 피라미드 꼭대기를 겨눔.
3. 검은 방울+연기 1 = CO₂ 1 (모양·개수) → 까닭: 어두운 방울 = CO₂(#16); 하나 — 구역3의 둘과 견줌.
4. 윗면 잘린 피라미드 = 3C→2C (모양) → 까닭: 경비병 손의 온전한 각뿔과 견줘 꼭대기가 낮아짐.
5. 끈으로 큰 꼬리표를 맨 작은 쐐기 = 아세틸 CoA (모양) ↻ → 까닭: 쐐기 = 2C · 꼬리표 = CoA(#172); 여기선 끈으로 「붙어」 있음 ↔ 구역3에선 「홀로」 누움.
6. 가득 찬 둥근 양동이를 들고 걷는 사내 1 = NADH 1 (개수·동작) → 까닭: 가득 = NADH, 한 사람 하나; 원판 쪽으로 걸어감.
7. 바닥의 굽은 회색 화살표 = 다음 단계로 이어짐 (자리) → 까닭: 문과 원판 사이 바닥에서 방향을 가리킴.

**구역3 볼트 원판 = 시트르산 회로** 10
1. 볼트 둘린 큰 원판+속도선 = 회로 (모양) → 까닭: 제자리에서 돌며 처음(작은 큐브)으로 돌아옴.
2. 작은 큐브+쐐기 → 큰 큐브 = 4C+2C→6C (크기) → 까닭: 블록 폭이 약 18 : 28; 분홍 화살표가 합침을 가리킴.
3. 원판에 홀로 누운 큰 꼬리표 = 떨어져 나온 CoA (자리) ↻ → 까닭: 구역2에서 쐐기에 매였던 꼬리표가 합쳐진 뒤 풀림(붙음↔홀로).
4. 큐브 3종의 폭 18 : 22 : 28 ≈ 4 : 5 : 6 = 6C→5C→4C (크기) ↻ → 까닭: 크기 차가 곧 탄소 수; 6→4 에 굴뚝 둘(잃은 2)과 맞음.
5. 굴뚝 2+연기·검은 공 2 = CO₂ 2 (개수) → 까닭: 어두운 공 = CO₂; 둘(구역2의 하나와 견줌).
6. 무릎 꿇은 사람이 회색 네모 칩 1을 털어냄 = GTP 1 (모양) ↻ (1단계는 탈탄산으로 오독) → 까닭: 둥근 동전(ATP)과 맞선 네모 회색 칩(#101); 한 개.
7. 가득 찬 둥근 양동이를 든 사람 3 = NADH 3 (개수) → 까닭: 가득 = NADH; 셋이 원판 둘레에서 쪽문 쪽에 섬.
8. 벽 선반 위에서 네모 양동이를 든 사람 1 = FADH₂ 1 · 막에 붙은 효소 (모양·자리) ↻ → 까닭: 둥근 양동이 사이에서 하나만 모양이 다름(네모 = FAD, #102); 벽(막)에 붙은 선반.
9. 뒷담 밑동의 널빤지 없는 작은 나무 쪽문 = NADH·FADH₂ 가 전자전달계로 가는 길 (자리) ↻ → 까닭: 양동이 든 사람이 문 앞 마당에 섬, 문이 말끔함 ↔ 구역4의 막힌 문.
10. 담 너머로 윗부분만 보이는 물레방아 = ATP 합성효소 (추정) ↻ → 까닭: 담(막) 뒤의 바퀴 = 다음 판 예고; 돌 아치는 이 면에 없음.

**구역4 먹구름·막힌 문·작은 화로 = 산소 없을 때: 발효와 젖산의 행방** 10
1. 먹구름·비·O₂ 방울 0 = 산소 없음 (날씨·개수) ↻ → 까닭: 왼쪽의 해·방울과 「있다↔없다」로 맞섬; 비 자체의 뜻은 까닭 모름.
2. 널빤지 둘을 X 로 친 쪽문 = 전자전달계를 쓰지 않음 (#144·#174) ↻ → 까닭: 구역3 쪽문과 같은 문에 가위표만 더해짐(하나만 다름).
3. 문 앞에 쌓인 가득 찬 양동이 약 20 = NADH 쌓임·NAD⁺ 부족 (개수) ↻ → 까닭: 빈 통이 하나도 없고 전부 가득; 문이 막혀 비울 데가 없음.
4. 작은 화로+선반의 동전 2(굴뚝은 빔) = 해당만으로 순 ATP 2 → 까닭: 구역1(굴뚝 2 투자·쟁반 4)에서 투자를 뺀 순이익만 남음; 이빨 입·물레방아 없음.
5. 빈 양동이를 화로 창에 되돌려 넣는 사람 = NAD⁺ 재생 → 해당 지속 (동작) ↻ → 까닭: 비어 있음 = NAD⁺(#102)가 기계(해당) 안으로 돌아감 = 발효의 목적.
6. 물을 맞아 보라색이 된 피라미드, 검은 방울 없음 = 젖산 발효 (빛깔) → 까닭: 빨강+파란 물 = 보라(환원); 크기 그대로 = 3C 유지.
7. 물을 맞아 모서리가 깎인 빨간 피라미드 + 곁의 검은 방울 = 알코올 발효 (모양) ↻ → 까닭: 같은 물 붓기에서 검은 방울(CO₂) 유무만 다름; 깎임 = 탄소 이탈.
8. 수레의 보라 피라미드 2 = 젖산 2분자를 실어 냄 (개수) → 까닭: 포도당 1 → 피루브산 2; 수레 = 운반.
9. 제 꼬리를 쫓아 도는 개 = 코리 회로 (소리·동작) ↻ → 까닭: 꼬리→코리, 빙글빙글 = 회로; 둘레의 원형 속도선.
10. 문간의 빨간 큐브(속도선) = 포도당 6C (추정) ↻ (1단계 「간」 철회) → 까닭: 큐브 = 6C; 집은 담에 붙은 작은 집이라 간 아님(#93) — 까닭 약함.

## ③ 어색·헷갈림·이음 ↻
- 풀린 것: 개(#173) · 쪽문(#174) · 회색 칩(#101) · 빈 이름표(#172) · 하늘 방울(#17) · 양동이 모양(#102).
- 아직 모름(약속표에 없어 억지로 끼우지 않음): 4고리 철제 기둥+ㄱ자 봉(구역2) · 원판 중앙 타원 구멍 · 볼트 17 · 선반 양끝 공머리 기둥 2 · 해(「해당」 소리 추정뿐) · 비 · 땀·튄 물방울(#119 H⁺? 낮음).
- 헷갈림: 회색 네모 칩(GTP) ↔ 검은 공(CO₂); 네모 ↔ 둥근 양동이; 빨강 ↔ 보라 피라미드.
- 이음: 뚜렷한 선 없음; x≈1600 에서 담이 꺾이며 하늘이 맑음→폭풍으로 바뀜; 회색 큰 화살표만 덧그린 듯.

## ④ 한 문장
포도당(6C)은 담 밖에서 3C 둘로 쪼개져 순 ATP 2·NADH 를 내고, 담 안에서 CO₂ 를 잃어 아세틸 CoA 가 되어 시트르산 회로에서 CO₂ 2·NADH 3·FADH₂ 1·GTP 1 을 내며, 가득 찬 양동이는 쪽문으로 전자전달계에 넘기되 문이 막히면 발효로 비워 NAD⁺ 를 되살리고 젖산은 코리 회로로 돌려보낸다.
