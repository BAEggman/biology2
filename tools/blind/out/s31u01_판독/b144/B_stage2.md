# 2단계 — 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳)

## 판정
약속으로 더 잘 풀린다. 읽힌 사실 25→27개, 오독 3곳 교정, 모름 6곳 해결. 일부러 안 끼운 것: 경비 모자(1번: 뜻 없음) · 회전문 톱니(147번은 벽에 박힌 기계라 자리가 다름) · 가위(3번은 낫이라 직접 약속 없음) · 해(118번: 틀선 칸이 없는 판이라 '다른 날'이 아니고 구체 뜻은 안 적힘).

## ① 표제어
- **세포호흡: 해당과정 → 피루브산 산화 → TCA 회로 → 무산소 발효(+코리 회로)** — 1순위 88% ↻(65→88)
- **산소 유무에 따른 포도당 대사(호기 대 혐기 · NAD⁺ 재생)** — 2순위 8%
- 전자전달·ATP 합성효소는 이 판에 없다. 쪽문(174번)만 그리로 가는 길로 보인다.

## ②+⑤ 구역별 사실과 까닭
### 구역1 **해당과정** (담장 밖 들판 · 7개)
1. 큰 붉은 큐브(6C 포도당, 171번)를 상어 입 기계가 삼킴 → 까닭: 큐브가 판에서 가장 큰 블록인데 옆문 컨베이어엔 작은 각뿔 둘 — 크기·개수 맞섬이 6→3+3(쪼갬). 이빨은 '쪼갠다'로 짐작할 뿐.
2. 컨베이어 붉은 각뿔 2개(3C 피루브산) → 까닭: 큐브와 같은 붉은색이 '같은 탄소가 갈라짐'을, 개수 2가 포도당당 2를 나름. 컨베이어 끝이 구역2 담장 문에 닿음.
3. 굴뚝 2개에 코인이 위에서 꽂힘(떨어짐 선) = ATP 2 투입(8·148번) → 까닭: 기계 위에서 '들어가는' 방향이라 소비. 개수 2는 상자 4와 견줘 순이득을 셈.
4. 4칸 나무 상자의 코인 4 = ATP 4 생산, 순 2 ↻ → 까닭: 굴뚝 2 ↔ 상자 4의 개수 견줌. 같은 상자를 구역2에서 비워 '찬 ↔ 빈' 대비.
5. 침착한 일꾼이 코인 하나를 들고 하나는 각뿔 옆면에서 떼어 냄 = 기질수준 인산화 → 까닭: 코인이 손과 각뿔 면 사이라 '각뿔에서 뗀다'. 손의 2개가 상자 4와 맞는지는 추정.
6. 땀 흘리는 일꾼이 솔로 각뿔을 문지르고 그 물줄기가 가득 찬 금속 양동이로 넘침, 옆 일꾼 곁 양동이는 빔 = NAD⁺→NADH(+H⁺ 물, 102·119번) ↻ → 까닭: 가득/빔을 나란히 둔 '하나만 다름'이 환원 전후. 물줄기가 각뿔→양동이로 향함. 땀·찡그림은 까닭 약함.
7. 해와 밝은 방울 10개 = O₂ 있음(17번) ↻ → 까닭: 오른쪽으로 갈수록 뜸하다 폭풍 앞에서 끊겨 구역4 하늘과 맞섬. 해는 맑음의 짝일 뿐 뜻 모름, 10개의 수도 모름.

### 구역2 **피루브산 산화** (담장 문 안 · 5개)
1. 문간의 제복 경비원이 각뿔 1개를 안음, 문 밖은 풀빛 = 피루브산이 막(담장)의 문을 지남 → 까닭: 컨베이어 끝이 문에 닿은 자리, 하나씩 안겨 '한 번에 하나'. 경비원=수송체는 약속표에 없는 추정.
2. 가위 든 일꾼 곁 꼭대기 잘린 각뿔 + 그 위 검은 방울 1개(연기) = 3C→2C, CO₂ 1(16번) ↻확정 → 까닭: 잘려 평평한 꼭대기와 방울이 위아래로 겹침. 방울 1 = 피루브산당 1.
3. 땅의 작은 쐐기에 끈으로 묶인 큰 꼬리표 = 아세틸-CoA(171·172번) → 까닭: 쐐기가 각뿔보다 훨씬 작고(3→2), 꼬리표가 '묶임' — 구역3에서 홀로 놓임과 맞섬.
4. 뒤에서 가득 찬 둥근 양동이를 들고 걷는 사람 1명 = NADH 1 ↻ → 까닭: 물높이가 보이는 가득, 1명 = 피루브산당 1. 걸음은 구역3 쪽. 멀고 작게 그린 까닭은 모름.
5. 텅 빈 4칸 나무 상자 = ATP 직접 생산 없음 → 까닭: 구역1 상자와 같은 모양에서 코인만 없음.
- 3팔 회전문+톱니+바닥의 한 방향 화살표: 까닭 모름 ↻(1단계 'ATP 합성효소' 철회 — 116번은 돌 아치+물레방아).

### 구역3 **TCA 회로** (안뜰 원반 · 8개)
1. 둘레에 나사 원통 17개 안팎, 속도선·중앙 타원 구멍·퍼지는 연한 줄의 둥근 원반 = 도는 회로 → 까닭: 원 = 처음으로 돌아옴, 속도선 = 회전. 나사 수와 중앙 구멍은 모름.
2. 쐐기 얹은 작은 큐브 → 화살표 → 큰 큐브 = 4C+2C→6C ↻ → 까닭: 구역2와 같은 쐐기가 얹히고 오른쪽 블록이 더 큼(크기 맞섬).
3. 큰 큐브 곁에 홀로 놓인 꼬리표 = CoA 떨어짐 ↻ → 까닭: 구역2 '묶임' ↔ 여기 '풀림'.
4. 받침 위 연기 파이프 2개에 검은 공이 뜸 = CO₂ 2 ↻ → 까닭: 개수 2 ↔ 구역2의 1. 무릎 꿇은 사람의 큐브는 큰 큐브보다 작아(4~5쯤) 탄소 잃음.
5. 원반 곁 가득 찬 둥근 양동이를 든 사람 3명 = NADH 3 → 까닭: 같은 양동이·같은 자세를 나란히 세워 개수 3.
6. 무릎 꿇은 사람이 흔드는 짙은 회색 네모 칩 = GTP 1(101번) ↻(1단계 오독 교정) → 까닭: 둥근 동전이 아닌 네모·회색 = 다른 인산 화폐. 흔드는 선 = 방금 만듦.
7. 뒷벽 선반 위 사람이 두 손으로 받친 모난 양동이(물 보임) = FADH₂ 1(102번 네모) ↻(1단계 오독 교정) → 까닭: 모양만 둥근 양동이와 다름. 벽(막)에 붙은 자리는 막 효소와 맞을 듯하나 근거 없음. 선반 말뚝 2개는 모름.
8. 뒷벽 밑 돌 틀의 작은 나무 쪽문, 널빤지 없음 = 가득 찬 양동이가 전자전달계로 가는 길(174번) ↻ → 까닭: 가득 찬 양동이가 모인 마당의 뒷담이라 자리가 맞고, 구역4 같은 문은 막혀 '열린 길 ↔ 막힌 길'.

### 구역4 **무산소 발효와 코리 회로** (폭풍 아래 · 7개)
1. 검은 폭풍 구름, 밝은 방울 없음 = O₂ 없음 → 까닭: 왼쪽 맑은 하늘+방울과 좌우로 맞섬.
2. 쪽문의 널빤지 가위표(144번 '쓰지 않는다') + 앞에 쌓인 가득 찬 양동이 약 18개 = 전자전달 길이 막혀 NADH 쌓임 ↻ → 까닭: 구역3의 같은 문 하나만 막힘. 사람당 하나이던 양동이가 더미로 불어남 = 정체(많음이 뜻).
3. 가득 찬 양동이를 붉은 각뿔에 붓는 일꾼 + 곁의 검은 방울 1 = CO₂ 나오는 발효(에탄올 쪽, 약속표 아닌 지식으로 식별) → 까닭: 가득→쏟아 비움 = NADH→NAD⁺. 방울이 곁에 있어 젖산 쪽(없음)과 맞섬.
4. 앞쪽 일꾼이 붓는 물에 각뿔이 보라로 번지고 방울 없음 = 젖산 발효(CO₂ 없음) → 까닭: 같은 '비우는' 동작에 방울만 없음(하나만 다름). 붉음+푸름=보라로 다른 물질. 크기 그대로 = 3C 유지.
5. 보라 각뿔 2개를 수레로 개집 쪽에 밀고 감 = 젖산 운반 → 까닭: 수레 속 각뿔이 젖산과 같은 보라. 2개는 구역1 각뿔 2와 같은 수(추정).
6. 제 꼬리를 쫓아 도는 개(173번) + 개집 앞 작은 붉은 큐브 = 코리 회로(젖산→간→포도당) ↻ → 까닭: 원형 선과 꼬리 무는 모양 = 출발점으로 돌아옴. 큐브가 문 앞 = 간이 내놓음. 개집=간은 93번 '홀로 선 건물' 조건이 애매한 추정.
7. 작은 상어 기계: 굴뚝 빔, 일꾼이 둥근 통을 입에 밀어 넣음, 선반에 코인 2 = NAD⁺ 되먹임, 해당과정만 돌아 순 ATP 2 → 까닭: 구역1 기계를 줄여 '상자 4 → 선반 2'로 견줌. 통이 빈지는 안 보임. 굴뚝이 빈 까닭은 모름.

## ③ 의문
- 모름: 회전문·나사 17개·중앙 구멍·선반 말뚝·바닥의 작은 고리·붉은 나비넥타이·땀.
- 헷갈림: 코인(ATP)↔네모 칩(GTP), 둥근↔네모 양동이, 검은 방울 4곳(1·2·1), 각뿔 색(붉음 피루브산 · 보라 젖산).
- 이음: 오른쪽 끝 틀의 흰 틈·어긋난 선(개집 잘림). 118번 틀선 칸은 이 판에 없어 해당 없음.

## ④ 한 문장
포도당(6C 큐브)은 세포질에서 피루브산 둘로 쪼개져 순 ATP 2와 NADH를 내고, 산소가 있으면 문을 지나 CO₂ 하나를 떼고 꼬리표 단 아세틸이 되어 TCA 원반에서 CO₂ 2·NADH 3·FADH₂ 1·GTP 1을 낸 뒤 가득 찬 양동이가 쪽문으로 전자전달계에 가지만, 산소가 없으면 그 문이 막혀 쌓인 NADH를 각뿔에 쏟아 NAD⁺를 되살리는 발효(에탄올 CO₂ 나옴 · 젖산 안 나옴)로 해당과정만 돌리고 젖산은 코리 회로로 간에 간다.
