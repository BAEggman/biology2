# 1단계 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- **세포호흡 (해당과정 → 피루브산 산화 → TCA 회로 → 전자전달·ATP 합성 + 무산소 발효)** — 1순위, 확신 65%
- **산소 유무에 따른 포도당 대사 (호기 호흡 대 발효)** — 2순위, 확신 20%
- 버린 후보: 광합성(해·방울은 있으나 잎·초록·엽록체 없음). 에너지 화폐(ATP·NADH) 수지 약 10%.
- 근거: 6면 큐브 하나가 피라미드 2개로 쪼개짐, 코인(ATP) 넣기 2·얻기 4, 가위+검은 방울+꼬리표, 도는 원반+연기 파이프 2개, 물 양동이(수소 운반체), 폭풍 아래 보라 피라미드 수레와 맴도는 개.

## ② 구역 (왼쪽부터 4구역)
### 구역1: 벽 없는 들판 — **해당과정(세포질)**
1. 붉은 큐브(6면 = 6탄당 포도당)를 상어 입 기계가 삼킴 — 모양·개수
2. 출구 컨베이어에 붉은 피라미드 2개 = 피루브산 2분자(3C) — 소리(피라미드~피루브산)·개수
3. 굴뚝 2개에 코인 2개가 꽂혀 내려감(줄이 코인 위) = 투자기 ATP 2 소모 — 개수·동작
4. 4칸 상자에 코인 4개 = ATP 4 생성(총), 순 2 — 개수
5. 침착한 일꾼이 코인 하나는 들고 하나는 피라미드에 댐 = 기질수준 인산화(중간 확신) — 동작
6. 땀 흘리는 일꾼이 물 양동이 물로 피라미드를 문지름, 양동이 둘(찬 것 1·빈 것 1) = NAD+ → NADH(낮음) — 뜻·개수
7. 해(긴 살 8·짧은 살 8), 하늘 방울 10개(오른쪽으로 갈수록 끊김) = 모름(산소? 에너지 근원?)

### 구역2: 담장 문~가위~회전문 — **피루브산 수송과 산화(아세틸-CoA 생성)**
1. 문턱의 경비원이 피라미드 1개를 듦, 문 밖은 들판 = 피루브산이 막의 문(수송체)으로 들어감 — 자리·뜻
2. 가위 든 사람 + 윗면이 잘린 피라미드 + 검은 방울(연기) = 탈카르복실화로 CO2 1개 떨굼(3C→2C) — 모양·뜻
3. 작은 피라미드에 끈으로 묶인 빈 꼬리표 = 아세틸-CoA(2C+CoA) — 모양·뜻
4. 양동이 들고 걷는 사람 1명 = NADH 1(낮음) — 개수
5. 3팔 회전문+톱니바퀴+휘는 화살표+빈 4칸 상자 = ATP 합성효소(회전 촉매, 3팔=β 3)로 보임(낮음) — 모양·동작

### 구역3: 회전 원반 — **TCA 회로**
1. 둥근 원반, 가장자리에 회전선, 나사 원통 17~18개(가려져 못 셈) = 순환 회로 — 모양
2. 작은 큐브(위에 작은 지붕) → 화살표 → 큰 큐브 = 4C+2C → 6C 시트르산 — 모양·크기
3. 큐브 옆 빈 꼬리표 = CoA 방출 — 모양
4. 연기 파이프 2개, 위로 뜨는 검은 공 2개 = CO2 2분자 — 개수
5. 원반 곁 양동이 든 사람 3명 = NADH 3 — 개수
6. 무릎 꿇은 사람이 큐브를 잡고 어두운 판을 털음 = FADH2 1 또는 4C 산 재생(낮음) — 동작
7. 벽 선반 위 양동이 든 사람 = 높은 곳의 H+(막간 쪽 기울기?)(낮음) — 자리

### 구역4: 폭풍 구름 아래 오른쪽 — **무산소 발효와 코리 회로**
1. 검은 폭풍 구름(왼쪽은 해와 방울) = 산소 없음 — 자리
2. 판자 X로 막힌 문 + 양동이 약 18~20개 더미 = 전자전달 막힘, NADH 쌓임 — 뜻·개수
3. 붉은 피라미드 + 검은 방울 + 물 붓기 = 알코올 발효(CO2 방출·NAD+ 재생)(중간)
4. 보라 피라미드에 물 붓기 = 젖산 발효(피루브산 환원)(중간) — 색
5. 수레의 보라 피라미드 2~3개 = 젖산을 간으로 운반 — 동작
6. 개집 + 문 앞 작은 붉은 큐브 + 맴도는 개 = 코리 회로(젖산→간→포도당) — 소리·동작
7. 작은 상어 입 기계에 양동이 투입, 선반 코인 2개, 굴뚝 비어 있음 = NAD+ 공급받아 해당과정만 돌려 순 ATP 2 — 개수

## ③ 의문
- 뜻 모름: 선반 양끝 말뚝 2개, 원반 중앙의 타원 구멍, 어두운 판, 뒷벽의 작은 닫힌 문, 바닥의 작은 고리 8개, 해와 방울의 정확한 뜻.
- 헷갈림: 코인이 네 곳(굴뚝 2·상자 4·일꾼 손 2·선반 2), 양동이가 너무 많음(NADH·H+·물 구분 안 됨), 붉은 피라미드가 5종(컨베이어·경비원·가위 밑·꼬리표·오른쪽), 검은 방울 4곳(CO2 맞는지).
- 이음 흔적: 오른쪽 끝 틀에 흰 틈과 어긋난 선, 개집이 틀에 잘림, 가장자리에 작은 회색 조각, 오른쪽 뒷벽이 더 칙칙함, 작은 상어 기계는 큰 것의 축소 복제.

## ④ 한 문장
포도당(6C)은 해당과정에서 피루브산 2개와 순 ATP 2개가 되고, 산소가 있으면 문을 지나 CO2를 떼어 TCA 회로와 전자전달로 ATP를 더 만들며, 산소가 없으면(폭풍) 젖산·에탄올 발효로 NAD+를 되살려 해당과정만 돌린다.
