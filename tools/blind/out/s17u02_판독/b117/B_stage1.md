# stage1 생판 (s17u02)

## ① 판 표제어
- 1순위 **신장 세뇨관의 부위별 물·이온 수송 (헨레고리 하행지·상행지~원위세뇨관, 수송체·이뇨제)** 65%
- 2순위 **역류 증폭·오줌 농축/희석(삼투 기울기)** 20%
- 그 밖 **PTH와 Ca2+·인산 항상성** 8%, **이차 능동수송·Na+/K+ ATPase** 7%
- 근거: 한 가닥 청록 관(물+흰 점=용질)이 U자로 꺾였다 오른쪽 문으로 빠짐. 점은 내려갈수록 촘촘, 오른쪽은 옅고 거의 없음. 하행부엔 구멍, 상행부엔 기계, 끝엔 펌프.

## ② 구역 (왼→오른)
**구역1 근위부(시작부): 포도당·Na+** — 선반·첫 수평관·왼쪽 방
- 포도 상자 1 = 포도당 (소리, 80%)
- 흰 가루 포대 1 = Na+ (뜻·같은 포대가 반복, 75%)
- 모름: 성냥개비 4(인→인산염? 40%), 뜰채 그물+물방울 4(거름? 30%), 벽의 X자 나무(뒤에 흰 금속판 2)

**구역2 하행지: 물만 빠져 농축** — 관 정면·양옆 벽
- 구멍 14개 안팎+물줄기 10여 가닥(좌4·정면4~5·우3) = 물 통로(아쿠아포린), 물 투과성 높음 (모양·뜻, 70%)
- 물줄기엔 점이 없고 점은 관에 남음 = 용질 불투과 (모양, 55%)
- 내려갈수록 점이 촘촘 = 삼투농도 상승 (모양, 65%)
- U자 바닥이 가장 촘촘 = 말단 최고 농도 (자리, 60%)
- 모름: 구리 U자관+눈금자(삼투압 눈금/직행혈관? 35%), 4구 램프 상자(끈 연결; 부갑상선 4개? 25%)

**구역3 상행지: 얇은 곳 수동, 굵은 곳 NKCC2·ROMK**
- 아래는 가늘고 위는 굵음 = 얇은/굵은 상행지 (모양, 60%); 올라갈수록 점·색 옅음 = 희석 (65%)
- 손 2개 = 수동(手=수, 소리·뜻 55%); 떨어진 알갱이→소금 더미 1 = NaCl이 빠져 간질에 쌓임 (60%)
- 기어 3개 기계 = 공동수송체 NKCC2 (모양·뜻, 70%)
- 포대 1 = Na+ 1 / 칼 1 = K+ 1 (소리 칼→칼륨) / 염소 2마리 = Cl− 2 (소리·개수) → 1:1:2 (75·70·80%)
- 노란 자물쇠가 손잡이를 잠금 = 억제, 루프 이뇨제 (뜻, 55%)
- 로마 병사 = ROMK (소리 Roman+K, 65%); 칼을 벽에 꽂음 = K+가 관강으로 되샘, 재순환 (동작, 50%)
- 모름: 옆 창의 알갱이·▶(세포 사이 경로 양이온? 35%), 병사 발치 판자, 벽 T자 못 약 30개(펌프? 35%)

**구역4 원위세뇨관: NCC·티아지드**
- 기어 3개 기계 = NCC (70%); 포대 1 = Na+ 1, 염소 1 = Cl− 1 (개수, 75%)
- 자물쇠 = 억제 (60%); 티백 = 티아지드 (소리, 70%)
- 관액이 옅고 점 거의 없음 = 희석액, 물 불투과 (모양, 60%)
- 모름: 벽 X자 나무에 가려진 칼 1 (NCC엔 K+ 없음? 35%), 바구니 회색 돌 6+물방울 3 (Ca2+·PTH? 25%)

**구역5 맨 오른쪽: 펌프 Na+/K+ 3:2**
- 소화전형 펌프 = Na+/K+ ATPase (모양, 60%); 벨트로 구역4 기계와 연결 = 펌프가 만든 Na+ 기울기로 구동, 이차 능동수송 (55%)
- 문 안 구리관에서 포대 3 낙하 = Na+ 3, 칼 2 = K+ 2 (개수, 60%)
- 모름: 구리관 의미, 홈통의 옅은 물

## ③ 이상한 것
- 뜻 모름: 4구 램프 상자와 그물-상자-바구니를 잇는 끈(한 신호가 근위부와 원위부 두 곳을 함께 조절하는 듯, PTH·호르몬? 20%), 성냥 4, X 2개(막힘 표시? 20%), 검은 T자 못(펌프·접합? 35%), 병사 발치 판자, 구리관 2곳(혈관? 25%).
- 개수 장부: 포대 6(선반 1·경사로 2·문 3)+바닥 소금 더미 1, 칼 5, 염소 3(2+1), 자물쇠 2, 티백 1, 기어 6(3+3), 손 2, 성냥 4, 램프 4, 회색 돌 6, 물방울(그물 4·바구니 3).
- 헷갈림: 칼 5자루(병사 손·경사로·벽·문 앞 2)가 다 K+인지; 같은 기어 기계 2대·자물쇠 2개는 얹힌 포대·칼·염소 수와 티백으로만 구분; 포대(Na+ 1)·소금 더미(NaCl)·흰 점(용질) 구분; 물줄기 두 종류(곧게 떨어짐/활처럼 나감).
- 이은 흔적: 병사 발치 판자(파란 테두리·주황 번짐), 문 앞 칼 2(계단 가장자리·얼룩), T자 못(픽셀형), 옆 창의 흰 알갱이·호, 그물 손잡이 위 테두리 끊김, 끈(선 질감 다름), 노란 자물쇠·돔·물방울(벡터풍).

## ④ 한 문장
하행지에서 물이 삼투로 빠져 진해지고, 상행지에서 NaCl이 빠져(얇은 곳 수동, 굵은 곳 NKCC2 1:1:2+ROMK) 묽어지며, 원위부 NCC가 Na·Cl을 더 걷고 펌프(3Na:2K)가 이를 구동하는데, 루프·티아지드 이뇨제가 각각을 잠근다.
