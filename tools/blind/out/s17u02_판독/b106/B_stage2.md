# 2단계 약속 어휘로 다시 읽기 (↻ = 1단계와 달라진 곳)

## 판정
약속으로 더 잘 풀린다. 1단계 「모름·약함」이던 X판 둘, 성냥, 구슬판, 가는 줄, 바구니 돌, 자물쇠 둘이 이름을 얻었다. 거꾸로 약속이 1단계 읽기를 바로잡은 곳: 눈금자 · 구슬판(사구체→부갑상선) · 톱니 기계(능동→공동수송체) · 바구니(Ca+Mg→Ca) · T자국(못→역청). 약속표에 없어 소리·개수로만 읽은 것은 억지로 끼우지 않았다.

## ① 판 전체 표제어
- 1순위 **헨레고리 대향류 증폭과 원위세뇨관의 부위별 수송 (이뇨제·PTH 작용점 포함)** — 78% ↻(70→78)
- 2순위 **이뇨제(푸로세미드·티아지드)와 호르몬(ADH·PTH)의 세뇨관 조절** — 15% ↻(20→15)

## ② 구역별
### 구역1 **하행각 — 늘 열린 물길로 물만 빠짐, ADH와 무관**
1. 맨 구멍 약 14개 + 쏟아지는 물줄기 = 늘 열린 물길(아쿠아포린, 호르몬 무관) [약속]
2. 물빛·흰 결정이 위 옅음→U턴 쪽 짙음 = 관 속 농도 상승 [약속]
3. 결정은 구멍으로 안 샘 = 용질 비투과 [모양]
4. ↻ X판+흰 V자 이음쇠 = ADH(V2)를 여기서는 쓰지 않는다 [약속 둘] (1단계: 모름)
5. ↻ 불 안 붙은 빨간 성냥 4개 = 인산 [약속] (1단계: 등장성?)
6. 바닥 웅덩이 = 빠진 물이 간질로 [자리]
7. ↻ 줄 묶인 닫힌 문+고리: 뒷문(기저외측막)+PTH 줄을 이은 읽기 — 인산이 못 나가 오줌으로(45%). '닫힘·고리'는 약속표 밖. 1단계의 '고리=헨레고리' 철회

### 구역2 **바사 렉타(기울기를 지키기만)와 부갑상선**
1. ↻ 곧게 내려가 U자로 되올라오는 구리 둥근 관 = 바사 렉타(역류교환) [약속] (55→90%)
2. ↻ 눈금자 = 바사 렉타 표지일 뿐, 기울기 눈금 아님 [약속] (1단계 정정)
3. 둥근 관(핏줄) 대 네모 관(세뇨관), U턴에서 닿되 안 이어짐 [약속]
4. ↻ 2×2 같은 색 둥근 버튼 4개 판 = 부갑상선 [약속] (1단계: 사구체 → 정정)
5. ↻ 판 밑을 지나는 가는 줄 = PTH가 하는 일: 왼쪽은 문고리 줄(인산), 오른쪽은 바구니 줄(Ca²⁺) [약속]
6. U턴 점이 가장 빽빽 = 가장 짙은 곳 [약속]

### 구역3 **상행각 — 물 불투과, 얇은 곳 수동 · 굵은 곳 NKCC2와 ROMK**
1. ↻ 이음매마다 새까만 역청(T자국 약 20) = 물 불투과 [약속] (1단계: 못)
2. 벽 틈에서 나온 편 손바닥 2개 + 저절로 흘러내리는 소금 = 수동수송 [약속]
3. 소금 더미 = 수질 간질의 짙은 NaCl [자리, 약속표 밖]
4. ↻ 벽에 박힌 톱니 기계(동전 없음) = 공동수송체 [약속] (1단계: 능동수송)
5. 경사판 자루 1+칼 1+염소 2 = Na⁺1·K⁺1·Cl⁻2 [약속+소리; 염소는 약속표 밖, 개수가 맞아 유지]
6. 로마 투구 병정+칼 = ROMK, K⁺ 되돌림 [약속] (80→95%)
7. ↻ 크랭크에 걸린 금색 자물쇠 = 푸로세미드(루프 이뇨제)가 막음 [약속] (40→90%)
8. ↻ 관 틈 바구니의 자갈 6~7 = Ca²⁺(Mg 아님) 세포사이 재흡수 [약속] (1단계: Ca·Mg)
9. 관 폭 계단식 확대 = 얇은→굵은 [모양, 약속표 밖]
10. 위로 갈수록 옅은 물빛 = 농도 낮아짐 [약속]

### 구역4 **원위세뇨관 — NCC(티아지드 차단)와 뒷문의 Na⁺/K⁺ 펌프**
1. 가로관의 아주 연한 물빛 = 가장 묽음 [약속]
2. 톱니 기계 + 경사판 자루 1+염소 1 = NCC(Na⁺·Cl⁻) [약속+소리]
3. ↻ 자물쇠에 매단 티백 = 티아지드가 NCC를 막음 [약속] (65→90%)
4. ↻ X판+못에 걸린 칼 = K⁺는 NCC에서 쓰지 않는다 [약속 둘] (1단계: 모름)
5. ↻ 열린 뒷문(기저외측막): 소금 자루 3 밖, 칼 2 안 [약속]
6. ↻ 동전 투입구 달린 크랭크 펌프 = Na⁺/K⁺ 펌프, 동전=ATP를 씀 [약속] (1단계: 손펌프, 동전 투입구는 놓쳤음)

## ③ 남은 것
- 약속표 밖: 염소, 소금 더미, 관 폭 계단, 닫힌 문의 줄·고리, 벽돌→밋밋한 벽 배경, 수로의 물. 성냥 4·자갈 6~7의 개수 뜻도 표에 없어 읽지 않음.
- 해소: 구리관 오른쪽 다리 끊김(눈금자 밑으로 되올라옴), 맨 위 갈색 줄(PTH 줄), X판 둘.
- 이은 흔적(1단계 그대로): 배경 x≈870, 상행각 가로 이음선 2곳, 가로관 세로 이음선, 오른쪽 그림체 차이.

## ④ 한 문장
하행각은 늘 열린 물길로 물만 빠져 진해지고, 상행각은 물을 막은 채 얇은 곳은 수동으로 굵은 곳은 NKCC2(푸로세미드 차단)와 ROMK로 소금을 퍼내며 PTH가 Ca²⁺를 끌어내고, 바사 렉타는 그 기울기를 지키기만 하고, 원위세뇨관은 NCC(티아지드 차단, K 안 씀)로 더 묽게 하되 구동력은 뒷문 Na⁺/K⁺ 펌프(3 밖·2 안, ATP)가 댄다.
