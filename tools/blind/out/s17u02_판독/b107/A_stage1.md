## ① 판 전체 표제어
- 1순위 **콩팥 세뇨관의 부위별 물·이온 수송 — 헨레고리 역류증폭 + 공동수송체 + 이뇨제 작용점** (80%)
- 2순위 **삼투조절과 배설 — 콩팥의 오줌 농축·희석** (12%)
- 근거: 굵은 관 한 줄이 왼쪽 위에서 시작해 내려가고(구멍 뚫린 벽) U자로 꺾였다가 올라가(핀 박힌 벽, 기계) 오른쪽 위로 뻗음. 물색도 진한 청록·점 많음(U 바닥) → 투명·점 없음(오른쪽 위)으로 변해 농도 변화를 보여줌. 칼=칼륨, 염소(山羊)=Cl, 소금자루=Na 같은 소리 말놀이가 반복됨.

## ② 구역별 (왼쪽부터)
**구역1 (x≈25–470, 벽돌방+선반) — 하행지: 물만 빠져 농축(삼투) · 근위부 재흡수**
- 구멍 약 14개(앞면 8·좌벽 3·우벽 3), 물줄기가 솟아 바닥 웅덩이로 = 물 투과성 높음, 수분만 간질로 [뜻·개수]
- 흰 점(용질)이 아래로 갈수록 촘촘 = 용질은 못 나가 농도↑ [모양·자리]
- 빠진 물이 모이는 방 바닥 웅덩이 = 간질로 이동한 물 [자리]
- 선반의 포도 상자 = 포도당(근위부 재흡수) [소리]
- 소금 자루 = Na⁺ [소리·모양]
- 성냥 4개 = 인(P·인산) 추정 [뜻], 4의 뜻은 모름
- 그물(빈 채 물방울 뚝뚝, 줄이 가운데 상자로 이어짐) = 모름
- X자 나무에 붙은 물 안 나오는 수도꼭지 = 모름(조절·능동 물길 없음?)

**구역2 (x≈470–890, 벽돌 간질) — 수질 간질: 삼투 기울기 · 직세동맥**
- 구리 U자관이 헨레고리 안쪽에 나란히 = 직세동맥(U자 혈관, 역류교환) [모양·자리]
- 눈금자(숫자 없음) = 농도 기울기 눈금? 추정
- 벽돌벽 = 고삼투 간질 추정
- 네모 상자(둥근 단추 4, 양옆 줄이 그물·돌바구니로) = 부갑상샘 4개→PTH(인산 재흡수↓, Ca²⁺ 재흡수↑) 추정 40% [개수]
- 아래 U 굽이 = 점이 가장 촘촘, 오른쪽으로 갈수록 성김 = 꼭짓점이 최고농도 [자리]

**구역3 (x≈890–1500, 상행지) — 물은 막고 NaCl만 뺌 (얇은 곳 수동 · 두꺼운 곳 NKCC2 능동)**
- 관벽 양쪽 검은 T자 못 각 9~10개 = 물 안 새는 벽(밀착) 추정
- 얇은 부분: 손 2개(손바닥 위, 알갱이 전달) → 소금더미 1 = NaCl 수동(手) 이탈, 간질에 쌓임 [소리·뜻]
- 관이 계단식으로 넓어짐 = 얇은→두꺼운 상행지 [모양]
- 톱니바퀴 3개 기계+크랭크 = 공동·능동수송체 NKCC2
- 비탈: 소금자루 1·칼 1·염소 2 = Na⁺1·K⁺1·Cl⁻2 [소리·개수]
- 로마 병사가 칼을 관벽 홈에 꽂음 = ROMK(K⁺ 재순환) [소리 로마+K]
- 크랭크에 걸린 자물쇠 = 루프이뇨제가 NKCC2 차단 [뜻]
- 위로 갈수록 점이 사라지고 물이 맑아짐 = 희석 구간 [자리]
- 병사 발치 돌석판 3칸(Ca²⁺·Mg²⁺ 세포 사이 이동?), 기계 옆 갈색 네모 홈(관 안 입구?) = 모름

**구역4 (x≈1500–2048, 원위부) — 원위세뇨관: NCC(티아지드) · Na⁺/K⁺ 펌프**
- 벽걸이 칼을 X 나무로 덮음 = K⁺는 안 나름(NCC엔 K 없음) 추정
- 톱니 기계+비탈: 소금자루 1·염소 1 = NCC(Na⁺·Cl⁻ 1:1) [개수]
- 자물쇠+티백 = 티아지드가 NCC 차단 [소리]
- 벨트로 기계에 이어진 검은 펌프 = Na⁺/K⁺-ATPase가 구동력 제공(2차 능동) 추정
- 검은 문에서 쏟아지는 자루 3 + 문틀에 꽂힌 칼 2 = Na⁺ 3 밖·K⁺ 2 안(3:2) [개수]
- 돌 약 6개 든 바구니(물방울 3) = Ca²⁺ 재흡수(PTH 줄) 추정
- 위 파이프의 투명하고 묽은 물 = 희석된 저장성 액 [모양]
- 오른끝 경사 물길 = 모름(집합관?)

## ④ 한 문장
세뇨관은 구간마다 벽이 달라서, 하행지는 물만 빼 농축하고 상행지는 물은 막고 염만 빼 희석하며(두꺼운 곳 NKCC2 1Na·1K·2Cl, ROMK), 원위부는 NCC로 NaCl을 더 빼는데 루프·티아지드 이뇨제가 각 기계에 자물쇠를 건다.
