# 2단계 — 약속표로 다시 읽기 (s17u02)

판정: 약속표로 훨씬 잘 풀림. 1단계의 4구역 틀은 그대로, 「모름」 6물건이 풀리고 「추정」 대부분이 확정됨. 표 밖 물건은 끼우지 않음. [#번호]는 약속표 줄.

## ① 판 전체 표제어
- 1순위 **콩팥 세뇨관의 구간별 물·이온 수송 — 역류증폭·공동수송체·이뇨제·PTH 작용** (88%) ↻ 80→88
- 2순위 **삼투조절과 배설 — 오줌 농축·희석** (8%)
- 근거: 네모 나무틀 관 = 오줌길(세뇨관), 둥근 구리관 = 핏줄 [#133]. 물빛과 흰 결정의 짙기 = 관 속 농도 [#145]. 약속 물건(상자·뜰채·펌프·자물쇠·티백·X)이 전부 신장 쪽.

## ② 구역별
**구역1 (좌) — 하행지·근위부: 늘 열린 물길, ADH 안 씀, PTH가 인산 재흡수↓**
- 맨 구멍에서 쏟아지는 가는 물줄기 = 늘 열린 물길(아쿠아포린, 호르몬 무관) [#146] ↻ 「삼투로 물 빠짐」을 정밀화
- V자 이음쇠에 널빤지 가위표 = ADH(V2)를 여기선 안 씀 [#7·#144] ↻ 모름→풀림
- 아래로 갈수록 짙은 물빛·촘촘한 결정 = 농도↑ [#145]
- 포도 = 포도당 [#90], 소금자루 1 = Na⁺ 1 [#111]
- 성냥개비 = 인(산) [#142] ↻ 추정→확정
- 줄에 들린 빈 뜰채가 물만 떨굼 = PTH가 인산을 건지지 않음(재흡수↓) [#140] ↻ 모름→풀림
- 바닥 웅덩이 = 빠진 물이 간질로(표 밖, 자리 읽기)

**구역2 (중) — 바사 렉타 · 부갑상선**
- 굽은 네모 관 사이로 곧게 내려갔다 되올라오는 구리 둥근 관 + 곁 눈금자 = 바사 렉타 [#6·#77·#133] ↻ 눈금자는 농도 눈금이 아니라 바사 렉타 표지, 기울기는 만들지 않고 지키기만(역류교환)
- 2×2 둥근 버튼 넷 상자 = 부갑상선 [#139] ↻ 40%→확정. 양옆 줄 = PTH가 하는 일(왼쪽 뜰채·오른쪽 바구니) [#139·#140]
- U 굽이에 결정 최다 = 꼭짓점 최고농도 [#145]
- 벽돌 벽 = 표 밖(간질 추정)

**구역3 (중~우) — 상행지: 물 불투과, 얇은 곳 수동, 두꺼운 곳 NKCC2·ROMK**
- 구멍 없이 이음매마다 새까만 T자 = 역청 메운 벽, 물 불투과 [#146] ↻ 추정→확정
- 벽 틈에서 편 손바닥 2개, 결정이 저절로 흘러내림 = 도구 없는 수동수송(얇은 곳) [#147]. 소금더미는 표 밖
- 톱니 기계 = 공동수송체, 동전 안 씀 [#147]
- 비탈 자루 1·칼 1·염소 2 = Na⁺1·K⁺1·Cl⁻2 [#111·#3]. 염소는 표 밖, 소리(염소=Cl)로 읽음
- 로마 투구 + 칼을 벽 홈에 = ROMK [#141] ↻ 확정
- 금색 자물쇠 = 루프 이뇨제(푸로세미드)가 막음 [#2] ↻ 확정
- 관이 계단식으로 넓어짐(표 밖), 위로 갈수록 결정↓·물빛 옅음 = 희석 [#145]
- 돌석판 3칸, 갈색 네모 홈 = 모름 유지(자갈은 둥근 알갱이, 과립세포 주머니는 알갱이 가득이라 어느 쪽도 아님)

**구역4 (우) — 원위부: NCC·티아지드·Na⁺-K⁺ 펌프·PTH(Ca²⁺)**
- 못에 걸고 가위표 친 칼 = K⁺ 여기선 안 씀 [#144] ↻ 추정→확정
- 톱니 기계 + 비탈 자루 1·염소 1 = NCC(Na⁺·Cl⁻ 1:1) [#147·#111]
- 자물쇠 + 티백 = 티아지드가 막음 [#143·#2]
- 동전 투입구 크랭크 펌프 = Na⁺-K⁺ 펌프(ATP), 벨트 = 펌프가 기계에 힘을 댐 [#148·#147] ↻ 확정
- 검은 문 = 뒷문(기저외측막) [#134]: 자루 3 밖·칼 2 안 = 3:2 ↻
- 가득 찬 자갈 바구니가 들리고 물방울 = PTH가 Ca²⁺를 건져 올림(재흡수↑), 방금 꺼냄 [#4·#140] ↻ 확정
- 위 파이프의 투명한 묽은 물 = 희석 [#145]
- 경사 물길 = 모름(뒷문 밖 혈액 쪽? 둥근 관이 아니라 보류)

## ③ 남은 것·흔적
- 모름: 돌석판 3, 갈색 홈, 경사 물길, 벽돌·소금더미·염소는 표 밖. 성냥 4개·톱니 3개·T 개수는 뜻 없음으로 봄
- 헷갈림: 칼 5개(병사·비탈·벽걸이·문틀 2), 자루 6개(선반 1·비탈 각 1·문 3), 자물쇠 2개(티백 단 쪽만 티아지드)
- 이음 흔적: x≈892 벽돌→회벽, x≈1556 위 파이프 이음, U관 밑 지운 얼룩. 약속 물건(상자·뜰채·바구니·줄·T·자물쇠·펌프)은 스티커풍 후가공

## ④ 한 문장
세뇨관은 구간마다 벽이 달라, 하행지는 늘 열린 구멍(ADH 무관)으로 물만 빼 농축하고 상행지는 이음매를 막아 물은 못 지나게 하며 염만 빼내는데(손=수동, 기계=NKCC2 1Na·1K·2Cl, 로마 병정=ROMK, 자물쇠=루프 이뇨제), 원위부는 NCC(티아지드)와 3:2 펌프로 더 빼고, 부갑상선 줄은 인산 재흡수를 줄이고 Ca²⁺ 재흡수를 늘리며, 바사 렉타는 기울기를 지킨다.
