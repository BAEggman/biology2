# stage2 — 약속표로 다시 읽기 (s32u01.png, ↻ = 1단계와 달라진 곳)

## ⓪ 약속표 판정
- 직접 걸린 약속: 동전=ATP, 금색 자물쇠=약물·독물, 밝은 방울=O₂, 금속 양동이=NAD⁺/NADH(가득=NADH), 올리고당 시럽=올리고마이신, 밀랍 봉인=완성된 물 병, 석상 사람=환원된 채 멈춘 전달자, 붉은 도깨비+손드릴=DNP, 해골 미장이=시안화물·CO, 근육 팔=펌프 I·III·IV / 빈 셔츠 소매=II.
- 판정: 약속으로 확실히 더 잘 풀린다. 구역2~5는 물건 거의 전부에 이름이 붙고, 1단계 「모름」 하나(양동이 탑)가 풀렸다. 구역1은 팔·소매만 약속이고 수레·상자·빗장·빈손 남자는 약속표 밖이라 1단계 읽기를 그대로 둔다.
- 겹침 주의(끼우지 않음): 붉은 벽돌 건물=간, 왕복 궤도=바사 렉타, 자갈=Ca²⁺, 갈라진 땅과 마른 바람=건조 스트레스, 놋쇠 못 개수=히스톤(s37p01). 이 판의 붉은 벽돌 막사·담장, 레일, 바윗돌, 갈라진 땅, 지붕 못과 모양이 겹치지만 이 판 맥락(내막·사슬)과 뜻이 안 맞는다.

## ① 판 전체의 표제어
- 1순위 **산화적 인산화 — 전자전달계 + 화학삼투 ATP 합성, 저해제·짝풀림제 포함** (확신 93%) ↻88→93
- 2순위 **세포호흡의 에너지 수확(ATP 생산 전반)** (확신 4%)

## ② 구역
### 구역1 (x 40~880) **전자전달계: 복합체 I~IV와 H⁺ 펌프**
1. 담장 = 내막, 물 = H⁺, 벽 너머 바다 = 막간공간의 높은 H⁺ ↻약속(106·108)으로 확정
2. 막사 4채 = 복합체 I·II·III·IV (개수 4)
3. 지붕의 근육 팔 3개가 홈통으로 물을 담장 너머로 = H⁺ 펌프 I·III·IV (개수 3) ↻약속 108과 일치
4. 둘째 막사의 빈 셔츠 소매 = 펌프하지 않는 II (1단계 「늘어진 소매」가 약속어로 확정). 추론: NADH 경로 펌프 3곳, FADH₂ 경로 2곳
5. 상자를 안은 짐꾼 2명이 I·II 두 입구로 = 전자 상자가 들어오는 입구 2곳 ↻후퇴: NADH는 금속 양동이로 그리는 약속이라 상자가 NADH/FADH₂라고 단정 못 함
6. 바윗돌 수레(II·III 사이) = CoQ, 7. 상자 수레(III·IV 사이) = cyt c (둘 다 약속표 밖, 추정)
8. 넷째 막사 문간 남자가 수레 상자를 받으려 손 내밂 = cyt c→IV, 순서 I/II→Q→III→c→IV
→ 읽힌 사실 8개 (약속 확정 3, 추정 5)

### 구역2 (x 880~1010) **산소 → 물**
1. 상자를 안은 흰 풍선 머리 남자 = 밝은 방울 = O₂, 사슬 끝에서 전자를 받음 ↻1단계 「풍선=기체」를 방울 어휘로 확정
2. 물방울 2개 = 만들어지는 물(2H₂O, 확신 낮음)
3. 붉은 밀랍 봉인 병 속 물 = 완성된 물 H₂O ↻약속 104 (코르크=코르티솔 아님)
→ 읽힌 사실 3개

### 구역3 (x 1010~1340) **ATP 합성효소와 화학삼투**
1. 아치에 박혀 도는 물레방아 = ATP 합성효소 ↻약속 103이 물레방아=ATP 합성효소를 명시
2. 물(H⁺)이 담장 아치를 지나 방아를 돌림 = 기울기를 따라 막간→기질로 되흐름
3. 쏟아지는 동전 더미 = ATP ↻약속 8
4. 팔은 물을 올림(펌프), 방아는 물이 내려옴(합성) = 방향 대비
→ 읽힌 사실 4개

### 구역4 (x 1290~1650) **사슬 끝 차단(시안화물·CO)**
1. 해골 미장이 = 시안화물·CO ↻약속 107
2. 흙손·벽돌로 봉한 문간 = 사슬 끝(IV) 봉쇄 ↻
3. 금색 자물쇠 = 약물·독물(저해제) ↻약속 2
4. 문간 앞에 줄 선 석상 사람 4명 = 환원된 채 멈춘 전달자 4 ↻1단계 「회색 남자」가 약속어로 확정
5. 금속 양동이 탑(약 10개, 맨 위 가득, 흘러내린 자국, 밑 웅덩이) = NADH가 재산화 못 되고 쌓임 ↻1단계 「모름」이 약속 102로 풀림(확신 중간: 포개진 빈 양동이=NAD⁺일 가능성 남음)
→ 읽힌 사실 5개 ↻4→5

### 구역5 (x 1480~2020) **ATP 합성효소 저해(올리고마이신)와 짝풀림(DNP)**
1. 요리사가 단지에서 붓는 금빛 끈적 시럽 = 올리고마이신 ↻소리 추정이 약속 103으로 확정
2. 시럽과 금색 자물쇠가 걸린 둘째 물레방아 = ATP 합성효소를 직접 막음
3. 붉은 도깨비+손드릴 = 짝풀림제 DNP ↻1단계 「UCP1류」 철회(약속표엔 DNP만)
4. 담장에 뚫린 구멍 3개(물줄기 2) = H⁺가 새는 길 ↻약속 106
5. 시뻘건 벽돌과 김 3줄기 = 에너지가 열로 (약속표 밖, 추정)
→ 읽힌 사실 5개

## ③ 남은 것·헷갈림·이어 붙인 흔적
- 여전히 모름: 둘째 막사 지붕의 못 4개, 빗장 문, 셋째 막사 앞 빈손 남자, 해, 폭풍·큰 파도 3·벽 위로 넘치는 물 2곳, 갈라진 땅, 양동이 개수(약 10)의 뜻, 방아 살 6~8.
- 해골 오른손 연장은 칼(K)이 아니라 미장 끌·망치로 보여 K로 읽지 않는다.
- 이어 붙인 흔적: 변동 없음. 금화 더미 오른쪽이 x≈1365에서 세로 직선으로 잘리고 옆이 평평한 크림색 사각(약 155×145px).

## ④ 한 문장
전자가 복합체 I→IV를 거쳐 O₂에 닿으며 H⁺를 담장 너머로 퍼 올려 만든 기울기가 ATP 합성효소(물레방아)를 돌려 ATP 동전을 쏟는데, 시안화물·올리고마이신은 길과 방아를 잠그고 DNP는 담장에 구멍을 내 ATP 없이 열만 낸다.
