# stage1 — 생판 읽기 (s32u01.png, 2048×868, 좌표는 원본 px)

## ① 판 전체의 표제어
- 1순위 **산화적 인산화 — 전자전달계(복합체 I~IV) + 화학삼투 ATP 합성, 저해제·짝풀림제 포함** (확신 88%)
- 2순위 **세포호흡의 에너지 수확 단계(미토콘드리아 ATP 생산 전반)** (확신 8%)
- 근거: 벽 하나를 사이에 둔 바다(물 높이 차), 벽에 박힌 막사 4채와 물 퍼 올리는 팔 3개, 물레방아가 금화를 쏟음, 해골·자물쇠·드릴 악마(독·잠김·구멍).

## ② 구역 (왼쪽부터)

### 구역1 (x 40~880) **전자전달계: 복합체 I~IV와 H+ 펌프**
1. 벽 = 막, 벽 너머 바다 = H+가 높게 찬 막간공간, 사람이 걷는 앞쪽 땅 = 기질 (뜻·자리)
2. 벽돌 막사 4채 = 복합체 I·II·III·IV (개수 4, 순서)
3. 지붕에서 솟아 물을 퍼 바다로 던지는 팔 3개 = H+ 펌프 I·III·IV (개수 3, 뜻)
4. 둘째 막사만 팔 대신 늘어진 소매 = 복합체 II는 H+를 안 퍼냄 (모양·개수 차이). 추론: NADH 경로는 펌프 3곳, FADH2는 II로 들어가 2곳
5. 첫째·둘째 막사로 상자를 안고 들어가는 남자 2명 = NADH→I, FADH2→II 전자 투입 (개수 2, 자리)
6. 레일 위 바윗돌 수레(II와 III 사이) = 유비퀴논(CoQ), 둥글고 무거운 지용성 이동 운반체 (모양·자리)
7. 레일 위 상자 실은 수레(III와 IV 사이) = 시토크롬 c, 수용성 이동 운반체 (자리)
8. 넷째 막사 문간 남자가 수레의 상자를 받으려 두 손을 내밂 = cyt c→복합체 IV 전달, 순서 I/II→Q→III→cyt c→IV (동작·자리)
- 약한 읽기(세지 않음): 둘째 막사 지붕의 둥근 못 4개(II 소단위 4개?), 빗장 걸린 나무문, 셋째 막사 앞 빈손 남자, 해(정상 가동?)
→ 읽힌 사실 8개

### 구역2 (x 880~1010) **산소 → 물: 최종 전자수용체**
1. 상자를 안은 풍선 머리 남자 = O2(풍선=기체)가 사슬 끝(IV 다음)에서 전자를 받음 (모양·자리)
2. 곁의 물방울 2개 = 물 생성(O2+4e-+4H+→2H2O) (개수 2, 확신 낮음)
3. 붉은 밀랍 병 속의 물 = 산물 H2O (뜻)
→ 읽힌 사실 3개

### 구역3 (x 1010~1340) **ATP 합성효소와 화학삼투**
1. 벽 아치에 박혀 도는 물레방아 = ATP 합성효소(F0F1), 막을 관통하는 회전 효소 (모양·자리)
2. 바다 쪽에서 아치로 쏟아져 방아를 돌리는 물 = H+가 기울기를 따라 막간→기질로 되돌아 흐름 (뜻)
3. 방아에서 쏟아지는 금화 더미 = ATP, 기질 쪽에 쌓임 (뜻·자리)
4. 팔은 물을 올리고(에너지 소모) 방아는 물이 내려옴(기울기 소모) = 펌프와 합성의 방향 대비 (대비)
- 방아 살 6~8개는 물에 가려 불확실 → 모름
→ 읽힌 사실 4개

### 구역4 (x 1290~1650) **전자전달 저해(복합체 IV, 시안화물·CO류)**
1. 해골 = 독·사망 (모양)
2. 해골의 흙손 + 벽돌로 메워진 문 = 입구 봉쇄, IV의 O2 결합자리 막음 (모양·뜻)
3. 문에 채운 자물쇠 = 결합해 차단 유지 (모양)
4. 문 쪽으로 줄 선 회색 남자 4명(각자 상자) = 전자가 못 넘어가 운반체가 줄줄이 밀려 환원 정체 (개수 4, 색)
- 양동이 탑 약 10개(위 양동이에 물, 밑에 웅덩이) → 모름
→ 읽힌 사실 4개

### 구역5 (x 1480~2020) **ATP 합성효소 저해(올리고마이신류)와 짝풀림(DNP·UCP1류)**
1. 허브 축에 자물쇠가 걸린 둘째 물레방아 = ATP 합성효소 잠김(F0 통로 차단) (모양)
2. 호박색 끈끈한 시럽 항아리를 붓는 앞치마 남자 = 올리고당→올리고마이신 (소리, 확신 중간)
3. 전동 드릴로 석벽에 구멍 뚫는 붉은 악마 = 짝풀림제, 막에 H+ 새는 구멍 (뜻)
4. 뚫린 구멍 3개(2개는 물줄기 분출) = H+ 누출 (개수 3)
5. 시뻘겋게 단 벽돌과 김 3줄기 = 에너지가 ATP 대신 열로 (모양·개수)
- 갈라진 땅, 폭풍 구름·큰 파도 3개·벽 위로 넘쳐 흐르는 물 2곳 = 기울기 과잉인지 누출인지 불확실
→ 읽힌 사실 5개

## ③ 이상한 것·헷갈리는 것·이어 붙인 흔적
- 뜻 모름: 양동이 탑(약 10개, 몸통에 W 자국), 갈라진 땅, 빗장 문, 셋째 막사 앞 빈손 남자, 둘째 막사 지붕 못 4개, 해.
- 헷갈림: 풍선 머리가 O2인지 다른 뜻인지. 시럽이 올리고당 소리인지 기질 과잉(꿀)인지. 폭풍과 넘치는 물이 H+ 과잉인지 누출인지. 회색 남자 4명이 복합체 4개인지 전자 4개인지. 양동이 탑이 누출 통로인지.
- 같은 물건 반복: 물레방아 2개(왼쪽 정상 가동, 오른쪽 잠김)를 같은 효소의 정상·저해로 읽음.
- 이어 붙인 흔적: 금화 더미 오른쪽 끝이 x≈1365에서 세로 직선으로 잘리고, 그 오른쪽 약 155×145px(y 592~735)가 질감 없는 평평한 크림색 사각. 해골·양동이·회색 줄 구역의 무채색 색감은 의도적 탈색으로 보이나 다른 그림 같기도 함. 넷째 회색 남자는 석조 건물 뒤에 머리만 걸침.

## ④ 한 문장
전자가 복합체 I→IV를 거쳐 O2에 이르며 H+를 막 너머로 퍼 올려 만든 기울기가 ATP 합성효소(물레방아)를 돌려 ATP를 만들고, 저해제는 길목과 방아를 잠그며 짝풀림제는 벽에 구멍을 내어 ATP 없이 열만 낸다.
