# stage2 덱 약속으로 다시 읽기 (s32u01)

## 판정
약속표가 이 판을 훨씬 잘 푼다(예). 이 판에 걸린 약속은 2·8·17·102~109 이고, 102~109 여덟 항이 전부 이 그림에 나온다. 읽힌 29개 중 22개가 표로 확정, 7개는 표 밖(1단계 추론 유지). 1단계 「모름·약함」 6개 중 3개가 풀림. 표에 없는 물건은 끼우지 않았다. 「↻」 = 1단계와 달라진 곳.

## ① 판 표제어 ↻
- 1순위 **산화적 인산화: 전자전달계·화학삼투(ATP 합성효소)와 억제제·짝풀림제** 95% ↻ (85에서 올림. 광합성 어휘인 루비스코 스코프·NADPH 방패·포르피린 액자가 하나도 없음)
- 2순위 **전자전달 억제제·짝풀림제(시안화물·올리고마이신·DNP) 단원** 3% ↻ (광합성 6%는 폐기)

## ② 구역 ([표N] = 약속표 N번으로 확정, [표 밖] = 표에 없어 추론)
**구역1 복합체 I (읽힌 4)**
1. 지붕에서 솟은 근육 팔이 홈통으로 담장 너머에 물을 퍼 올림 = H+ 펌프 [표108] ↻ 확정
2. 둥근 금속 양동이 가득 = NADH, 둥근 구멍이 그 입구 [표102] ↻ 모양 추정이 확정
3. 금지 표지의 네모 양동이 = FAD(H2) 거절, FADH2 는 II 로 [표102 네모=FAD] ↻
4. 담장=막, 바다가 더 높음 = H+ 기울기 [표 밖]. 해는 표에 없어 모름 유지

**구역2 복합체 II (읽힌 3)**
1. 팔 대신 늘어진 빈 셔츠 소매(소맷부리 단추) = 펌프 없음 0 [표108] ↻ 확정
2. 네모 양동이+사각 창 = FADH2 가 II 로 [표102] ↻
3. 양동이에 물이 가득 = 환원형(가득=NADH 꼴) [표102]

**구역3 복합체 III와 Q (읽힌 2)**
1. 팔 = III 도 H+ 펌프 [표108]
2. 레일 수레에 실려 건물에 안 붙고 구르는 둥근 바위 = 유비퀴논 Q, 돌=비단백질 운반체 [표109] ↻ 확정. 큰 문: 모름 유지

**구역4 복합체 IV와 산소 (읽힌 6)**
1. 팔 = IV 도 H+ 펌프 [표108]. 펌프 팔은 I·III·IV
2. 상자 수레(III~IV 사이) = 시토크롬 c [표109] ↻ 자리 추정이 확정
3. 문 안 남자가 상자를 건넴 = IV 가 전자를 O2 로 [표 밖]
4. 흰 풍선 머리 = 밝은 방울 O2 [표17 변형]
5. 붉은 밀랍으로 봉한 병 속 물 = 완성된 물 H2O [표104] ↻ 모름이 풀림. 근거: 병 모양·붉은 밀랍·물이 문장과 일치, 자리도 산소 발치(생성물)
6. 점선 화살표(웅덩이→풍선)+물방울 2 = 미완성 물(H+)이 O2 에 붙어 병의 물이 됨 [표 밖] ↻ 1단계의 '물 2분자 생성'을 고침(완성된 물은 병)

**구역5 ATP 합성효소 (읽힌 4)**
1. 아치 안 물레방아를 H+ 물이 돌림 = F0 회전 [표 밖]
2. 아치 위 소용돌이 = H+ 입구 [표 밖]
3. 금화 = ATP [표8] ↻ 확정
4. 금화 더미와 바닥의 금화 = ATP 대량, 개수 불명 [표8]. 물 쟁반: 모름 유지

**구역6 시안화물 차단·정체 (읽힌 4)**
1. 해골 미장이가 흙손·벽돌로 문간을 봉함 = 시안화물·CO [표107] ↻
2. 문 옆 금색 자물쇠 = 통로·효소를 막는 독 [표2] ↻
3. 돌빛 석상 사람 3 = 멈춰 선 전달자, 환원된 채 정체 [표105] ↻ 약함이 풀림. 근거: 회색 사람이 상자를 든 채 굳음, 봉한 문 바로 앞 자리
4. 6단 금속 양동이 탑이 넘침 = NADH 가득 쌓임 [표102 가득=NADH] ↻ 뜻이 풀림. 6 은 표에 없어 모름

**구역7 올리고마이신·짝풀림 (읽힌 6)**
1. 폭풍+솟은 거대 파도+5번째 팔 = 합성효소가 막혀 H+ 기울기 극대 [팔만 표108, 나머지 표 밖]
2. 끈적한 금빛 시럽 항아리를 붓는 앞치마 남자+금색 자물쇠 채운 굳은 바퀴 = 올리고마이신, 합성효소 차단 [표103·표2] ↻ 말장난 추정이 확정
3. 붉은 도깨비+손드릴 = 짝풀림제 DNP [표106] ↻
4. 기둥의 구멍 3(2 개통, 1 뚫는 중)+새는 물줄기 = H+ 누출, 구멍엔 자물쇠 없음 [표2] ↻
5. 불꽃·김 = ATP 대신 열 [표 밖]
6. 이쪽엔 금화 없음 = ATP 중단 [표8 반대]

## ③ 의문·어색·이음 ↻
- 안 풀림(표 밖): 해, 소용돌이, 물레방아(표엔 동전=ATP 뿐), 물 쟁반, 큰 문, 점선 방향, 개수 6·3·3·2, 5번째 팔(펌프 팔 4 대 복합체 3).
- 약속 충돌: 표93 붉은 벽돌 건물=간 이 이 판의 붉은 벽돌 집·담장(막·복합체)과 겹침. 간으로는 읽지 않았으나 독자가 오독할 소지. 표49 알=α 는 달걀꼴 흰 머리와 닮았으나 표17 방울로 읽음. 질그릇 항아리(표102 물 그릇)는 여기선 시럽 항아리.
- 이음: 1단계와 같음. 큰 파도 모서리의 작은 네모 자국뿐.

## ④ 한 문장 ↻
담장(막)에서 근육 팔(I·III·IV, II 는 빈 소매)이 H+ 를 퍼 올리고, 둥근 양동이 NADH 와 네모 양동이 FADH2 의 전자가 Q 바위·cyt c 수레를 거쳐 풍선(O2)에 닿아 밀랍 병의 물이 되며, 돌아오는 H+ 가 물레방아를 돌려 금화(ATP)를 쏟지만, 자물쇠 달린 독(시안화물 해골·올리고마이신 시럽)은 길과 바퀴를 막아 석상 정체와 NADH 적체를 만들고 도깨비 드릴(DNP)은 막에 구멍을 내 ATP 대신 열을 낸다.
