# 1단계 생판 (s32u01, 그림만 보고)

## ① 판 표제어
- 1순위 **산화적 인산화 (전자전달계 + 화학삼투 + ATP 합성효소)** 88%
- 2순위 **호흡 억제제·탈공액제 (미토콘드리아 독)** 8% (그 밖: 막 수송 펌프, 광인산화 각 2%)
- 근거: 벽 한 줄에 칸 4개가 왼→오로 이어지고 칸마다 물을 퍼 올리는 팔, 가운데 물레방아→금화, 오른쪽에 해골·악마·자물쇠.
- 큰 틀: 벽=막, 벽 너머 바다=막 사이 공간(H+ 고농도), 앞마당=기질. 물을 바다로 퍼 올리고 아치로 되돌려 흘린다 [자리·뜻].

## ② 구역 (x는 2000폭 기준)
**구역1 (40–520) 복합체 I·II: 입구와 펌프 유무**
- 칸1(둥근 구멍+팔): 팔이 홈통으로 물을 바다에 쏟음 = I이 H+ 퍼 올림 [동작]
- 양동이 든 남자 → 칸1 = NADH가 전자를 I에 공급 [모양·뜻, 70%]
- 손잡이 달린 네모 통 든 남자 → 칸2 창 = FADH2가 II로 따로 입장 [모양·자리, 65%]
- 칸2 지붕에 팔 대신 축 늘어진 천 소매 = II는 H+ 펌프 안 함 [모양, 75%]
- 칸 4개 중 팔 3개 = 펌프는 I·III·IV 셋 [개수]
- 모름: 해(광선 16=긴 8+짧은 8), 칸1 위 「양동이 금지」 표지(로테논류? NADH 막 투과 불가?)

**구역2 (520–890) 복합체 III·IV와 이동 운반체**
- 바위 실은 수레(레일) = 유비퀴논 Q, 막 속 이동 운반체 I·II→III [모양·자리, 60%]
- 상자 실은 수레 = 시토크롬 c, III→IV [자리, 60%] (바위/상자 구분은 순서로만 추정)
- 칸3 팔 = III 펌프, 칸4 팔 = IV 펌프 [동작]
- 칸4 문에서 남자가 상자를 풍선 인간에게 건넴 = IV가 전자를 O2에 인계 [동작]
- 레일 한 줄 = 왼→오 전자 흐름 순서 [자리]

**구역3 (890–1290) O2와 ATP 합성효소: 화학삼투**
- 풍선 머리 사람이 상자 받음 = O2(기체), 최종 전자 수용체 [모양·뜻]
- 발치 물병(붉은 봉랍) = 산물 H2O [모양, 70%]
- 점선 화살표(웅덩이→풍선 인간) = 기질 H+가 O2 환원에 쓰임 [뜻, 40%, 못 셈]
- 벽 아치 속 물레방아: 바다 물이 높이차로 흘러 바퀴를 돌림 = H+가 기울기 따라 ATP 합성효소 통과·회전 [모양·자리]
- 쏟아지는 금화+쟁반 더미 = ATP, 개수 세기 불가(더미) [뜻]
- 바다 소용돌이 = 아치로 빨려드는 구동력 [모양, 50%]

**구역4 (1290–1600 윗줄) 전자전달 차단: 시안화물류**
- 해골 = 치명적 독(시안화물·CO) [뜻, 65%]
- 벽돌로 막고 자물쇠 채운 문 + 흙손·붉은 벽돌 = 마지막 문(IV) 봉쇄, 전자 O2 못 감 [모양·뜻, 60%]
- 상자 든 회색 사람 3(둘 보임+굴뚝 뒤 머리 하나) = 막혀서 줄 선 전자·상류 환원 적체 [개수, 50%]
- 모름: 양동이 6개 탑이 넘침(NADH 적체? 30%)

**구역5 (1370–1600 아랫줄) 탈공액제: H+ 누출과 열**
- 붉은 악마 = 해로운 약물(DNP류) [뜻, 70%]
- 드릴로 벽에 구멍 3개(둘 완성, 하나 뚫는 중) = 막에 H+ 새는 길 [동작·개수]
- 구멍마다 불꽃·김, 물줄기 2가 쟁반으로 = 물레방아 우회 누출, 에너지가 ATP 대신 열 [모양]

**구역6 (1580–2000) ATP 합성효소 억제: 올리고마이신**
- 제빵사가 꿀 시럽 항아리를 바퀴에 부음 = 「올리고(당)」+마이신 [소리, 45%]
- 바퀴 축 자물쇠, 꿀로 끈적임 = 회전·통로 잠금 [뜻]
- 이 바퀴엔 금화 없음 = ATP 합성 중단 [모양]
- 바퀴 뒤 물이 막혀 고임 = H+ 못 통과 [모양]
- 굴뚝 팔이 큰 고리 물줄기, 큰 파도, 먹구름 = 펌프 계속·기울기 급등? [모양, 40%, 못 셈]

## ③ 어색·모름·헷갈림·이음
- 모름: 해, 금지 표지, 양동이 탑 6, 회색 사람 이유, 4번째 팔(펌프 3과 불일치).
- 헷갈림: 물이 3역(양성자 바다·NADH 양동이·산물 물병), 상자가 4곳(수레·건넴·회색 줄 등) 같은 뜻인지.
- 이음: 눈·열 차분 모두 이음선 못 찾음. 해·금지 표지·점선 화살표는 평면 아이콘이라 덧붙인 듯. 하늘은 중앙(아치)부터 먹구름.

## ④ 한 문장
NADH·FADH2의 전자가 복합체 I→(Q)→III→(c)→IV를 거쳐 O2로 갈 때 I·III·IV가 퍼 올린 양성자(물)가 ATP 합성효소(물레방아)를 돌려 ATP(금화)를 만들고, 시안화물은 문을 막고 올리고마이신은 바퀴를 잠그며 탈공액제는 벽에 구멍을 내 ATP 대신 열을 낸다.
