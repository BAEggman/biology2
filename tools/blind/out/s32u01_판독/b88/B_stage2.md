# 2단계 약속 적용 (s32u01) — ↻ = 1단계와 달라진 곳, [번호] = 약속표 줄

## 판정
약속표가 더 잘 풀었다. 이 판 전용 약속(양동이·바위/상자 수레·석상·물병·시럽·도깨비 드릴·해골 미장이·근육 팔/빈 소매·자물쇠·동전)이 1단계 추정을 거의 그대로 확정했고 뒤집힌 읽기는 없다(상자=전자 자체→cyt c라는 결만 바로잡음). 새로 풀림 ↻ 회색 사람, 양동이 탑, 입구 모양. 약속표에 없는 물건은 억지로 끼우지 않았다.

## ① 판 표제어
- 1순위 **산화적 인산화 (전자전달계 + 화학삼투 + ATP 합성효소, 억제제·짝풀림제 포함)** 96% ↻(88→96, 전용 약속 8개가 이 판에 겹침)
- 2순위 **호흡 억제제·짝풀림제 (미토콘드리아 독)** 3% ↻(8→3)

## ② 구역
**구역1 (40–520) 복합체 I·II: 전자 입구와 펌프 유무**
- 칸1 근육 팔이 홈통으로 물을 담장 너머 바다로 = H+ 펌프(I) [108]
- ↻가득 찬 둥근 금속 양동이 → 둥근 구멍 = NADH → I [102] 70→95
- ↻네모 양동이 → 네모 창 = FAD(H2) → II [102] 65→95. 입구 모양이 짐 모양과 맞음(둥근↔둥근, 네모↔네모)
- ↻칸2 지붕의 빈 셔츠 소매 = II는 H+ 펌프 없음 [108] 75→95
- 칸 4개 중 팔 3개 = 펌프는 I·III·IV [개수]
- ↻칸1 위 금지 표지가 네모 양동이처럼 보임 = FAD는 I로 못 들어감? 45%, 표지는 약속표에 없어 미확정
- 모름: 해(광선 16). 약속표에 없음. 날씨 분위기(정상↔독)로만 추정

**구역2 (520–890) 복합체 III·IV와 이동 운반체**
- ↻둥근 바위 실은 레일 수레 = 유비퀴논 Q, 건물에 안 붙고 구르는 이동 운반체 [109] 60→95
- ↻바위 = 비단백질(ETC 유일) [109] 신규
- ↻상자 수레 = 시토크롬 c [109]. 상자는 전자 자체가 아니라 cyt c
- 칸3 팔 = III 펌프, 칸4 팔 = IV 펌프 [108]
- 칸4 문 남자가 상자를 풍선 인간에게 건넴 = IV가 O2로 인계
- 레일 순서 = I·II→Q→III→c→IV

**구역3 (890–1290) O2와 ATP 합성효소**
- 풍선 머리 = 밝은 방울 O2, 최종 수용체 [17]
- ↻붉은 밀랍 물병 = 완성된 H2O [104] 70→95
- ↻담장 너머 바다 = 막 사이 공간, 높이차 = 기울기 [108]
- 아치 속 물레방아가 동전을 쏟음 = ATP 합성효소 [8] ↻오른쪽 자물쇠 바퀴와 짝이 맞아 확정
- 동전 더미 = ATP, 개수 불가 [8]
- 소용돌이 50%, 점선 화살표 40%: 약속표에 없어 미확정

**구역4 (1290–1600 윗줄) 시안화물·CO 차단**
- ↻해골 미장이(흙손·벽돌로 봉한 문간) = 시안화물·CO [107] 65→95
- ↻금색 자물쇠 달린 막힌 문 = 잠그는 독, IV 봉쇄 → 전자가 O2에 못 감 [2]
- ↻석상 3(둘+굴뚝 뒤 머리) = 멈춰 선 전달자, 환원된 채 정체 [105] 50→95
- ↻가득 찬 금속 양동이 탑 6이 넘침 = NADH 적체 [102] 30→70. 개수 6의 뜻은 모름

**구역5 (1370–1600 아랫줄) 짝풀림제**
- ↻붉은 도깨비 + 손드릴 = 짝풀림제 DNP [106] 70→95
- ↻벽 구멍 3개, 자물쇠 없음 = 구멍 내는 약(막는 약과 대비) [2], 물줄기 2가 쟁반으로 = H+ 누출
- 구멍마다 불꽃·김 = 에너지가 ATP 대신 열

**구역6 (1580–2000) ATP 합성효소 억제**
- ↻올리고당 시럽 붓는 제빵사 = 올리고마이신 [103] 45→95
- ↻바퀴 축 금색 자물쇠 = 잠금 [2], 금화 없음 = ATP 합성 중단, 바퀴 뒤 물 고임 = H+ 못 통과
- ↻굴뚝 팔 = H+ 펌프, 큰 호로 쉼 없이 퍼 올림 [108]. 큰 파도·먹구름은 약속표 없음, 넷째 팔은 펌프 3 규칙과 안 맞아 미해결

## ③ 어색·모름·헷갈림·이음
- 놓쳤던 것 ↻: 금색 자물쇠가 둘(문=시안화물, 바퀴=올리고마이신, 같은 모양이라 자리로만 구분), 물 쟁반(누출수 받이).
- 헷갈림: 붉은 벽돌 칸·담장은 「붉은 벽돌 건물=간」[93]과 겹치나 간으로 안 읽음. 조끼 단추[39]·흰 셔츠 칼라[71]·바닥 돌점[4]·쟁반[22]도 읽지 않음. 상자가 수레·건넴·석상 손에 반복.
- 이음: 이음선 못 찾음. 해·표지·점선 화살표는 평면 아이콘.

## ④ 한 문장
가득 찬 둥근 양동이(NADH)와 네모 양동이(FAD)의 전자가 복합체 I·II→바위 Q→III→상자 cyt c→IV를 거쳐 O2로 갈 때 근육 팔 I·III·IV(II는 빈 소매)가 퍼 올린 물이 물레방아(ATP 합성효소)를 돌려 동전(ATP)을 쏟고, 해골 미장이(시안화물)는 문을 막아 석상 전달자와 NADH를 쌓으며 올리고당 시럽·자물쇠(올리고마이신)는 바퀴를 잠그고 도깨비 드릴(DNP)은 벽에 구멍을 내 ATP 대신 열을 낸다.
