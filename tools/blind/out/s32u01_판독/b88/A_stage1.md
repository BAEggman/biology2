# stage1 생판 (s32u01, 그림만 보고)

## ① 판 표제어
- 1순위 **산화적 인산화: 전자전달계(복합체 I~IV)와 화학삼투(ATP 합성효소)** 확신 85%
- 2순위 **광합성 명반응의 전자전달·광인산화(엽록체)** 6% (해가 있고 막 위 펌프·물레방아가 같아서. 그러나 NADH/FADH2 양동이·산소 풍선·복합체 II 빈 소매는 호흡 쪽)
- 오른쪽 절반의 중심: **전자전달 억제제·짝풀림제(올리고마이신, 시안화물, DNP/UCP1)**

## ② 구역 (왼쪽부터). 약속: 벽=막, 벽 너머 바다=반대 구획의 높은 H+, 물=H+, 상자=전자
**구역1 복합체 I (x30~300)** 읽힌 4
1. 팔+나무 국자가 물을 벽 너머 바다로 퍼 올림 = H+ 펌프, 에너지 써서 기울기 거슬러 (뜻·동작)
2. 둥근 구멍+둥근 양동이(물 가득) = NADH 입구, 모양 맞춤 (모양)
3. 금지 표지: 사각 양동이에 빨간 사선 = I 은 FADH2 를 받지 않음 (모양)
4. 바다가 벽보다 높음 = 막 사이 농도 기울기 (자리). 해: 모름(정상 상태?)

**구역2 복합체 II (x300~520)** 읽힌 3
1. 지붕에 팔 대신 늘어진 빈 소매 = II 는 H+ 를 못 퍼냄, 0개 (개수)
2. 사각 창+사각 양동이 든 사람 = FADH2 가 II(숙신산 탈수소효소)로 (모양)
3. 양동이 속 물 = 전자·H 를 실은 환원 운반체 (뜻)

**구역3 복합체 III와 Q (x520~700)** 읽힌 2
1. 팔 = III 도 H+ 펌프 (뜻)
2. 레일 위 수레의 둥근 돌, 문 앞 = 유비퀴논 Q: 막 속을 옆으로 오가며 I·II 에서 III 로 (자리·모양 'Q'). 큰 문: 모름

**구역4 복합체 IV와 산소 (x700~1000)** 읽힌 5
1. 팔 = IV 도 H+ 펌프 (뜻). 펌프 팔은 I·III·IV 3개
2. 상자 실은 수레(III~IV 사이) = 시토크롬 c, III 에서 IV 로 (자리)
3. 문 안 남자가 허리 숙여 상자를 건넴 = IV 가 전자를 산소에 넘김 (동작)
4. 흰 풍선 머리 = 산소 O2, 최종 전자수용체 (모양)
5. 점선 화살표+물방울 2개 = 물 2분자 생성 (개수 2). 밀봉 병 속 물: 모름(생성수?)

**구역5 ATP 합성효소 (x1000~1300)** 읽힌 4
1. 아치 안 물레방아를 물이 돌림 = F0 회전, H+ 가 기울기 따라 막 통과 (뜻)
2. 아치 위 바다의 소용돌이 = H+ 가 이 입구로 빨려듦 (자리)
3. 금화 = ATP (뜻)
4. 금화 더미 = ATP 대량 생산, 개수는 못 셈 (개수). 물 쟁반: 모름

**구역6 차단·정체 (x1290~1560)** 읽힌 4, 모두 추정
1. 해골이 흙손·벽돌로 문을 막음 = 독으로 전자 통로 차단→사망, 시안화물/CO 류 (뜻)
2. 금빛 자물쇠 = 억제 (모양)
3. 양동이 6단 탑이 넘침 = 상류 운반체 적체 또는 단계별 에너지 방출 (개수 6, 약함)
4. 회색 석상 3명이 상자 든 채 정지 = 멈춘 전자 운반체 (뜻, 약함)

**구역7 억제제·짝풀림 (x1560~2000)** 읽힌 6
1. 폭풍+솟은 거대한 파도+팔의 안간힘 = H+ 기울기 극대, 합성효소 막혀 H+ 쌓임 (자리)
2. 시럽 항아리 붓는 앞치마 남자+자물쇠 채워 굳은 바퀴 = ATP 합성효소 억제, 올리고마이신('올리고당' 말장난 추정) (소리)
3. 악마가 드릴로 기둥에 구멍 = 짝풀림제 DNP (뜻)
4. 구멍 3개(2개 개통, 1개 뚫는 중)+물줄기 = H+ 가 합성효소를 우회해 샘 (개수 3)
5. 불꽃·김 = ATP 대신 열, UCP1 갈색지방 (뜻)
6. 이쪽엔 금화 없음 = ATP 생성 감소 (자리)

## ③ 의문·어색·이음
- 모름: 밀봉 병, 물 쟁반, 해, 큰 문. 약함: 6단 탑, 석상 3명(셋째는 머리만).
- 팔 4개(집 1·3·4·5)인데 복합체는 3개(I·III·IV): 집5 의 팔이 헷갈림(IV 를 다시 그린 것인지, 억제 상황의 같은 펌프인지 모름). 물줄기 굵기는 첫째>셋째>넷째로 보이나 4:4:2 같은 수치 뜻인지는 불확실.
- 점선 화살촉이 사람 쪽이라 방향 애매(물이 산소로 들어가는지, 산소에서 물이 나오는지). Q·cyt c 수레 배정은 두 집 사이 자리로 추정. 사각/둥근 양동이를 NADH/FADH2 에 짝짓는 것도 모양 추정.
- 확신 순서: 팔=펌프, 빈 소매=II, 풍선=산소, 물레방아·금화=ATP 합성 (높음) > 양동이 모양 짝, Q·cyt c 수레, 악마=짝풀림 (중) > 해골 문, 올리고당 말장난, 6단 탑, 석상 (낮음).
- 이음: 뚜렷한 접합선 없음. 오른쪽 거대 파도 왼쪽 모서리에 작은 네모 자국(보정 흔적 가능), 붉은 벽돌에서 회색 석벽으로 재질 전환, 사람·병 가장자리 흰 테두리는 모든 인물 공통이라 합성 아님.

## ④ 한 문장
전자(상자)가 NADH/FADH2→Q→시토크롬 c→산소로 흐르며 복합체 I·III·IV 의 팔(II 는 빈 소매)이 H+ 를 퍼 올리고, 그 H+ 가 ATP 합성효소(물레방아)를 돌려 ATP(금화)를 만들지만, 시안화물·올리고마이신으로 막히거나 DNP 로 구멍이 나면 ATP 대신 정체와 열이 난다.
