# 2단계 재판독 — s32u01 (약속표 어휘로 다시 봄, ↻ = 1단계와 달라진 곳)

## 판정
약속표로 훨씬 잘 풀린다. 올리고마이신·시안화물·DNP·NAD/FAD·ATP·H+ 펌프·H2O·정체 전달자가 한 판에 다 있다. 뼈대는 그대로, 1단계의 추정 여럿이 확정되고 「모름」이던 금지 표지·석상·양동이 탑이 풀렸다.

## ① 판 전체 표제어
- **1순위: 산화적 인산화 (전자전달계 + 화학삼투 + 시안화물·DNP·올리고마이신) — 95%** ↻(90→95)
- **2순위: 세포호흡 후반부(미토콘드리아 에너지 대사 전체) — 3%** ↻(6→3)
- 큰 틀 유지: 담 = 내막, 바다 = 막간(H+), 모래 = 기질, 상자 = 전자.

## ② 구역별 읽기
**구역1 [4칸 상자집 + 레일] 전자전달계 복합체 I~IV·산소** (12개)
1. ↻ 가득 찬 둥근 금속 양동이 = NADH → 둥근 구멍 = 복합체 I (#102, 상)
2. ↻ 네모 양동이 = FAD(H2) → 네모 창 = 복합체 II (#102, 상)
3. ↻ 금지 표지 = 네모(FAD) 양동이에 빗금: FAD는 복합체 I로 못 들어감 (#102로 읽음, 중; 1단계 「모름」)
4. ↻ 지붕에서 솟은 팔 3개(I·III·IV) + 2번째 칸 빈 셔츠 소매 = II는 펌프 없음 (#108, 상)
5. ↻ 팔이 홈통으로 물을 담장 너머 바다로 = H+ 펌프, 기질→막간 (#108, 상)
6. 돌덩이 수레(2·3칸 사이) = CoQ (약속 밖, 자리, 중하)
7. 상자 수레(3·4칸 사이) = cyt c (약속 밖, 자리, 중하)
8. 레일 한 줄 = 전자 순서 I·II→Q→III→c→IV (약속 밖, 중)
9. 4번째 칸에서 상자를 건네는 사람 = IV가 전자를 산소에 넘김 (중)
10. ↻ 흰 방울 머리 = 밝은 방울 O2 (#17, 중상)
11. ↻ 점선 화살표 + 물방울 2개 = H+ 2개가 산소로 소모 (덧붙인 표시, 중)
12. ↻ 붉은 밀랍 물병 = 완성된 물 H2O (#104, 상)

**구역2 [돌아치 물레방아 + 동전 쟁반] 화학삼투·ATP 합성** (5개)
1. 물레방아 1개 = ATP 합성효소 (약속 밖, 뜻으로 읽음, 상)
2. 바다→바퀴→모래로 떨어지는 물 = H+ 기울기 역류가 바퀴를 돌림 (상)
3. 바다 소용돌이 = 막간 H+ 위치에너지가 빠지는 길 (약속 밖, 중)
4. ↻ 쏟아져 쌓인 둥근 동전 = ATP (#8, 상)
5. 바퀴가 돌 때만 동전 = H+ 흐름과 ATP 합성이 짝지어짐 (중)

**구역3 [해골 + 막힌 문 + 석상 + 양동이 탑] 시안화물·CO 중독** (4개)
1. ↻ 흙손·벽돌로 문간을 봉하는 해골 미장이 = 시안화물·CO, 복합체 IV 차단 (#107, 상)
2. ↻ 금색 자물쇠 = 막는 독 (#2, 상)
3. ↻ 돌로 굳은 사람 3명 = 멈춰 선 전달자(환원된 채 정체) (#105, 상; 3의 뜻은 모름)
4. ↻ 가득 찬 금속 양동이 6개 탑이 넘침 = NADH 쌓임 (#102, 중상; 6의 뜻은 모름)

**구역4 [도깨비 + 드릴 + 구멍 난 기둥] 짝풀림제 DNP** (4개)
1. ↻ 붉은 도깨비 + 손드릴 = DNP (#106, 상)
2. ↻ 구멍 3개(2 완성 + 1 작업 중), 자물쇠 없음 = 막는 약이 아니라 구멍 내는 약 (#2, 상)
3. 구멍 물줄기가 동전 없는 물 쟁반으로 = H+가 합성효소를 건너뛰고 새어 ATP 못 만듦 (중)
4. 구멍의 불꽃·김 = 열로 빠짐 (중상; 1단계의 UCP1 후보는 약속표 밖이라 철회 ↻)

**구역5 [잠긴 물레방아 + 제빵사 + 맨 오른쪽 팔] 올리고마이신** (4개)
1. ↻ 자물쇠 채운 바퀴, 동전 없음 = ATP 합성효소 차단 (#2, 상)
2. ↻ 끈적한 금빛 시럽 = 올리고마이신 (#103, 상; 1단계는 소리 추정 중)
3. ↻ 막힌 바퀴 뒤 아치에 갇힌 짙은 물 = H+가 못 내려가 정체 (중; 1단계에서 놓침)
4. 맨 오른쪽 팔(H+ 펌프)이 계속 퍼 올리고 바다 끝에 물 언덕 = 기울기 상승 (#108, 중하)

## ③ 뜻 모를 것·어색한 것·헷갈리는 것·이음
- 약속 밖이라 억지로 안 끼움: 두 수레·레일(CoQ·cyt c 배정은 자리 추정), 소용돌이, 물 언덕, 먹구름, 해, 쟁반 둘, 제빵사, 석상 3·양동이 6·구멍 3의 개수.
- 겹쳐 보였으나 안 쓴 약속: 붉은 벽돌 = 간(#93, 건물 아닌 담·기둥이고 간 얘기 없음) · 레일 = 왕복 궤도(#6, 콩팥 아님) · 돌덩이 = 자갈 Ca2+(#4, 한 덩이 큰 돌) · 궤짝 = P450(#48, 빈 전자 상자) · 조끼 단추 = CD4·8(#39, 의상) · 나무 바퀴 = 방패 NADPH(#113, 물레방아).
- 맨 오른쪽 팔은 4칸 밖의 또 하나라 펌프를 4개로 오독하기 쉬움.
- 이음 ↻: 점선 화살표·물방울 2개만 수채 질감과 달리 깨끗한 벡터풍 = 덧붙인 흔적(1단계 놓침). 하늘·담·바다는 연속, 맨 오른쪽 담만 붉은 벽돌→회색 돌.

## ④ 한 문장
↻ 가득한 NADH·FAD 양동이의 전자(상자)가 I·II→Q→III→c→IV→O2(방울)로 흐르며 팔(H+ 펌프)이 물을 담 밖으로 퍼내고, 되돌아오는 물이 바퀴(ATP 합성효소)를 돌려 동전(ATP)을 만들며, 자물쇠 독(시안화물·올리고마이신)은 길과 바퀴를 막고 도깨비(DNP)는 구멍으로 열만 낸다.
