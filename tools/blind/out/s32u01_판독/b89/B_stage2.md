# 덱 2단계 (s32u01, 약속표 읽은 뒤) — 달라진 곳 ↻

판정: 표가 1단계를 뒤집지 않고 「모름·약함」을 걷어 냄. 단 표 #93이 s32u01을 「세포호흡 담장」이라 직접 말해 표제어 확신 상승엔 그 몫이 섞임.

## ① 표제어
- 1순위 **세포호흡의 전자전달계와 산화적 인산화(화학삼투)** — 95% ↻(85)
- 2순위 **화학삼투(H+ 기울기)와 ATP 합성효소·저해제** — 4%
- 근거: 담장=막·펌프집 4채=복합체 I–IV(#93), 팔=H+ 펌프(#108), 아치+물레방아=ATP 합성효소(#116), 동전=ATP(#8), 틀 칸 3개=다른 날(#118).

## ② 구역 (#=약속표 번호)
**구역1 (집 1·2) — 복합체 I·II: NADH·FAD 공급, 펌프 유무**
1. ↻ 담장=막, 붙은 펌프집 4채=복합체 I–IV (#93, 개수 4)
2. 지붕에서 솟은 팔이 홈통으로 담장 너머로=H+ 펌프, 1호집 (#108)
3. ↻ 가득 찬 금속 양동이→둥근 입구=NADH (#102)
4. ↻ 네모 양동이→2호집 창=FAD (#102)
5. ↻ 2호집 위 빈 셔츠 소매(장갑 아님)=II 펌프 없음 → 팔 3개(I·III·IV) (#108)
6. ↻ 짐이 거치는 팔 수: NADH 3(≈10 H+)·FAD 2(≈6 H+) (#108, 추론)
7. ↻ 금지 표지: 표에 없음. 금색 자물쇠가 아니니 막는 약(로테논)은 아님(#2), 네모 통이면 「FAD는 I 불가」(약함)
해=표에 없음, 모름.

**구역2 (집 3·4, 선로) — Q·cyt c → III·IV → O2 → 물**
1. ↻ 레일 수레의 둥근 바위(II–III 사이)=Q (#109)
2. ↻ 돌은 단백질 아님=유일한 비단백질 운반체 (#109)
3. ↻ 상자 수레(III–IV 사이)=시토크롬 c (#109)
4. 3·4호집 팔=III·IV 펌프 (#108)
5. 풍선머리=O2 최종 전자수용체 (표에 직접 없음, 밝은 방울=O2 #17 결)
6. 푸른 셔츠 일꾼이 상자를 풍선머리에게=IV가 전자를 O2로 (표에 없음)
7. ↻ 붉은 밀랍 물병=완성된 물 H2O (#104, 1단계 모름 해소)
8. 점선 화살표+물방울 2=O2+H+→물 (표에 없음)
(1단계 「팔 굵기 4·4·2」 폐기: 표는 팔 개수로 H+ 양을 정함)

**구역3 (수문) — ATP 합성효소와 H+ 기울기**
1. 담장 뒤 바다=막간공간, 앞 땅=기질, 팔이 땅→바다=기울기 거슬러 (#93, #108)
2. ↻ 담장 밑동의 돌 아치 하나+물레방아=ATP 합성효소, H+가 돌아오는 유일한 길 (#116)
3. ↻ 쏟아진 둥근 금동전=ATP (#8; 회색 네모 칩 GTP 없음 #101)
4. ↻ 담장 뒤 물 높이=H+ 기울기 크기, 정상 기준 (#117)
5. 소용돌이=아치로 빠지는 H+(?) — 표에 없음, 아치 막힌 칸엔 없음이 근거(약)
해·바퀴살 수=모름.

**구역4 (우상 칸) — 올리고마이신**
1. ↻ 항아리에서 붓는 끈적한 금빛 시럽=올리고마이신 (#103, 소리 올리고당)
2. ↻ 물레방아 축의 금색 자물쇠=막는 약, 효소를 잠금 (#2)
3. 시럽·자물쇠로 아치 정지, 물·동전 없음=ATP 합성 중단 (#116, #8)
4. ↻ 바다가 불룩=물 높이 ↑ 기울기 최대 (#117)
5. ↻ 먹구름 칸=같은 장면의 다른 날 (#118)

**구역5 (우중 칸) — 짝풀림제 DNP**
1. ↻ 붉은 도깨비+손드릴=DNP (#106, UCP1 폐기)
2. ↻ 담장 새 구멍 3개에서 물이 샘=H+ 누출 (#116, 개수 3)
3. ↻ 자물쇠 없음=구멍 내는 약 (#2)
4. ↻ 진동선 달고 힘껏 퍼 넘기는 팔=더 빨리 도는 펌프 (#108)
5. ↻ 바다 낮고 얕음=기울기 소실 (#117)
6. 빈 쟁반=ATP 없음 (#8)
7. 구멍마다 불·김=열 (표에 없음)

**구역6 (우하 칸) — 시안화물·CO**
1. ↻ 해골 미장이(흙손·벽돌)=시안화물·CO (#107)
2. ↻ 봉한 문의 금색 자물쇠·빗장=막는 독, 4호집=IV (#2)
3. 풍선머리가 문밖에서 빈손=O2 있어도 못 씀 (표에 없음)
4. ↻ 돌로 굳은 팔=멈춘 펌프 (#105)
5. ↻ 상자 든 석상 2명=멈춰 선 전달자(cyt c), 환원된 채 정체 (#105, 개수 2)
6. ↻ 가득 찬 금속 양동이 4개 쌓임=NADH 가득 정체 (#102, 개수 4)

## ③ 이상한 것
- ↻ 풀린 것: 물병, 소매(장갑 아님), 바위·상자 짝, 시럽, 도깨비, 석상, 자물쇠↔구멍 규칙, 틀 칸=다른 날(이어 붙임이 아니라 의도된 구성).
- 남은 모름(표에 없어 끼우지 않음): 해(16줄기), 소용돌이, 금지 표지, 풍선머리·푸른 셔츠 일꾼, 점선 화살표, 3호집 무인, 2호집 위 작은 마개, 선로 방향.
- 구분점: 붉은 밀랍(물)↔코르크(코르티솔), 자물쇠(막는 약)↔구멍(짝풀림), 둥근 동전(ATP)↔회색 칩(GTP, 없음).
- 잔흔: 큰 판 우상단 모서리 흰 조각(사소).

## ④ 한 문장
NADH·FAD의 전자가 Q·cyt c로 III·IV를 거쳐 O2에 닿아 물이 되고 지난 팔 수만큼 H+가 담장 뒤에 쌓여 아치 물레방아(ATP 합성효소)를 돌려 ATP 동전을 쏟으며, 다른 날 세 칸은 아치를 잠그는 올리고마이신(물 더 쌓임)·담장에 구멍 내는 DNP(물 새고 열, 동전 없음)·IV를 봉하는 시안화물(전달자 석상)이다.
