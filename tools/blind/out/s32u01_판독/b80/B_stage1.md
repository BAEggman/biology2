# 1단계 생판 기록 (s32u01)

열람: 원본 그림 1장 + 내가 잘라 만든 조각만. 사전 정보 없음.

## ① 판 전체 표제어
- 1순위 **산화적 인산화 — 전자전달계와 화학삼투(ATP 합성효소)**. 억제제·짝풀림제까지 한 장에 묶음. 확신 85%
- 2순위 **세포호흡 후반부(미토콘드리아 ATP 생성)**. 확신 10% (해 때문에 광인산화도 스쳤으나 O2가 물이 되는 장면이 있어 5% 미만)
- 큰 은유: 벽 = 댐(막), 바다 = H+ 저수지, 팔 = 펌프, 수차 = 터빈, 금화 = ATP.

## ② 구역 (왼쪽 → 오른쪽, 원본 x픽셀 대략)

**구역1 (40~890) 전자전달계 복합체 I~IV와 H+ 펌프**
- 벽돌 벽 = 내막(H+ 못 지나감), 벽 너머 바다 = 막간공간(H+ 고농도), 앞 마당 = 기질 (뜻·자리)
- 근육 팔 3개가 마당 물을 퍼 바다로 던짐 = 복합체 I·III·IV가 에너지를 써서 H+ 능동 펌프 (개수·뜻)
- 둘째 집 지붕의 축 처진 빈 소매 = 복합체 II는 펌프 안 함 (자리·개수)
- 집 4채, 입구가 둥근 구멍 → 네모 창 → 문 → 문 = 복합체 I→II→III→IV 순서 (개수·자리)
- 둥근 양동이 남자 → 둥근 구멍 = NADH가 I로 (모양)
- 네모 양동이 남자 → 네모 창 = FADH2(숙신산)가 II로 (모양)
- 바위 실은 수레(II·III 사이 레일) = 유비퀴논 CoQ, 막 속 이동 운반체 (자리, 추정)
- 상자 실은 수레(III·IV 사이) = 사이토크롬 c (자리, 추정)
- 해 = 모름 (정상 상태 배경? 에너지 원천?)

**구역2 (890~1020) 산소: 최종 전자수용체, 물 생성**
- 풍선 머리 남자 = O2 (모양: 기체)
- 넷째 집 대머리 남자가 상자를 건넴 = 복합체 IV가 전자를 O2로 (자리·동작)
- 물방울 2개 = O2 1분자 + 4e- + 4H+ → H2O 2분자 (개수)
- 바닥 물병 = 최종 산물 물 (뜻)

**구역3 (1020~1320) 화학삼투: ATP 합성효소**
- 벽 아치 속 나무 수차 = ATP 합성효소 F0F1, 돌아가는 효소 (모양·동작)
- 바다에서 마당으로 쏟아져 수차를 돌리는 물 = H+가 농도 기울기 따라 되돌아옴 (뜻)
- 금화 더미(수백 개, 튀어 오름) = ATP 대량 생산 (뜻)
- 아치 = 막을 관통하는 F0 통로 (자리, 약함)

**구역4 (1320~1760) 전자전달 억제제: 시안화물·CO (복합체 IV)**
- 해골 = 치명적 독 CN-·CO·N3- (뜻)
- 벽돌로 메워진 문 + 금색 자물쇠 = 복합체 IV 차단, 전자 통로 폐쇄 (모양)
- 해골의 흙손 = 문을 벽돌로 막아 버림, 결합해 막음 (모양)
- 회색 사람 4명 줄(상자 든 3명 + 머리만 보이는 1명) = 전자 흐름 정지, 앞단 정체 (개수·색, 약함)
- 양동이 탑(약 10개, 물 넘침) = 모름 (NADH 쌓임? NADH 1분자당 H+ 10개?)

**구역5 (1390~1680, 아래쪽) 짝풀림제: H+ 누출과 열 (DNP·UCP1)**
- 빨간 악마 = 짝풀림제, 열 (뜻·색)
- 전동 드릴로 벽에 구멍 = 막에 H+ 통로를 뚫음 (동작)
- 구멍 3개에서 새는 물줄기 = 수차를 안 거치고 H+ 샘, ATP 없음 (개수)
- 붉게 단 벽돌 + 김 3줄기 = 에너지가 열로 (색·모양)
- 쟁반 = 모름 (누수 물받이)

**구역6 (1660~2040) ATP 합성효소 억제제: 올리고마이신**
- 시럽 붓는 흰 앞치마 남자 = 올리고마이신 (소리: 올리고당 시럽)
- 꿀로 엉킨 수차 = ATP 합성효소 F0 차단 (모양)
- 축의 금색 자물쇠 = 회전 정지 (모양)
- 위쪽 폭풍 먹구름 + 솟은 물결 = 출구가 막히면 H+ 기울기가 과도하게 쌓여 전자전달도 멈춤 (자리, 약함)

## ③ 뜻 모를 것 · 어색한 것 · 헷갈림 · 이음새
- 모름: 해, 양동이 탑, 회색 4명의 정확한 뜻, 쟁반, 구멍·김 3개의 수, 해골이 다른 손에 쥔 가는 막대.
- 어색: 빈 소매. 넷째 집은 팔과 남자가 함께 있음. 회색 넷째 사람이 석조 건물 뒤에 반쯤 가림. 첫째 팔은 물을 오른쪽, 둘·셋째는 왼쪽으로 쏟음.
- 헷갈림: 금화(ATP)와 꿀(억제), 수차 2개(정상/잠김), 자물쇠 2개(문/축), 해골(억제제)과 악마(짝풀림제), 양동이 물이 NADH인지 H+인지, 상자가 전자인지.
- 이음새: 뚜렷한 접합선 없음. 하늘이 맑음 → 폭풍으로 서서히 바뀌고, 왼쪽 벽돌 벽과 오른쪽 회색 석조 건물의 재질이 바뀜.

## ④ 한 문장
복합체 I·III·IV(팔 3개)가 H+를 벽 너머로 퍼 올리고(II는 안 함) O2가 전자를 받아 물이 되며, 되돌아오는 H+가 ATP 합성효소(수차)를 돌려 ATP(금화)를 만드는데, 독(해골)과 올리고마이신(시럽)은 이 흐름을 막고 짝풀림제(악마)는 새게 해 열로 날려 버린다.
