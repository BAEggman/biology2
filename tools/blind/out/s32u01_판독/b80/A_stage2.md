# 2단계 약속표 판독 (s32u01) - 약속 어휘로 다시 보기 (↻ = 1단계와 달라진 곳)

## 판정
이 판에 걸리는 약속: #2 금색 자물쇠, #8 동전, #17 밝은 방울, #102~#108 (양동이·시럽·밀랍병·석상·도깨비·해골 미장이·근육 팔). 큰 줄기는 1단계와 같고, 약속은 (a) 「모름」 2개를 풀고 (b) 추정 8개를 확정하며 (c) 「자물쇠 유무 = 막는 약 대 구멍 내는 약」 구분을 새로 준다. 약속이 없는 해·두 수레·물레방아·돔·구름은 그대로 추정/모름. 이 판 맥락상 끼우지 않은 겹침: 붉은 벽돌(#93 간), 돌덩이(#4 자갈), 레일(#6 왕복 궤도), 해골의 작은 도구(#3 칼).

## ① 판 전체 표제어
- 1순위 **산화적 인산화 (전자전달계·화학삼투·ATP 합성효소 + 저해제·짝풀림제)** - 92% ↻ (85 -> 92: #102~108 이 모두 이 단원 어휘)
- 2순위 **세포호흡 후반부 (호흡 사슬 단계)** - 5% ↻ (광인산화·막 수송 후보는 NADH·FAD 양동이, 올리고마이신, DNP 로 사실상 배제)

## ② 구역별 (왼쪽 -> 오른쪽)

### 구역1 **전자전달계 복합체 I~IV와 H+ 펌핑 (NADH·FAD 입력)** - 9
- 담 = 내막, 너머 바다 = 막간공간 (#108 「담장 너머로」)
- 지붕 달린 칸 4개 = 복합체 I~IV (개수)
- 근육 팔 3개 = H+ 펌프 (I·III·IV) (#108)
- ↻ 둘째 칸 지붕에서 솟은 천 = 「빈 셔츠 소매」 (소맷단 단추까지 확인): 복합체 II 는 펌프 없음 (#108). 1단계 추정 확정
- ↻ 둥근 금속 양동이(가득) = NADH -> 둥근 구멍(I) (#102)
- ↻ 네모 양동이 = FAD(H2) -> 네모 창(II) (#102 「네모 양동이 = FAD」)
- 돌덩이 수레·상자 수레 = Q·cyt c (약속 없음, 칸 사이 자리로만 추정)
- 레일 = 전달 순서
- 해(광선 16줄): 약속표에 없음, 모름 유지

### 구역2 **최종 전자수용체 O2 -> 완성된 물** - 4
- 풍선 머리 = 밝은 방울 O2 (#17)
- 문간 남자가 상자를 건넴: 복합체 IV -> O2 전자 전달
- ↻ 붉은 밀랍 물병 = 완성된 물 H2O (#104). 1단계 「모름」 해결
- ↻ 상자 위 물방울 2개: 완성된 물은 병이므로 1단계의 「H2O 2분자」를 정정, 물이 되기 전 재료(H+)로 읽음. 2의 뜻은 불확실

### 구역3 **ATP 합성효소와 화학삼투** - 4
- ↻ 금화 = ATP (#8) 확정, 더미가 큼 = 대량 생산
- 아치 구멍으로 쏟아지는 물 = H+ 가 합성효소로만 복귀
- 도는 물레방아 = 회전 촉매 (약속 없음, 모양). 바퀴살 약 8개

### 구역4 **시안화물·CO 저해와 전자 정체** - 5
- ↻ 해골 미장이(흙손) = 시안화물·CO (#107)
- ↻ 벽돌로 봉한 문간 = 전자가 O2 로 가는 길 차단
- ↻ 금색 자물쇠 = 막는 약·독 (#2)
- ↻ 석상 사람 4명 = 멈춰 선 전달자, 환원된 채 정체 (#105)
- 양동이 탑(약 10개) = NADH 적체 (#102 + 추정, 가득/빈 판별은 어려움)

### 구역5 **짝풀림제 DNP (구멍 -> 열)** - 4
- ↻ 붉은 도깨비+손드릴 = DNP (#106)
- 벽돌 구멍 = H+ 누출, 합성효소 우회
- 붉게 달궈진 벽돌+김 = ATP 대신 열
- ↻ 자물쇠 없음 = 구멍 내는 약 (#2), 막는 약과 구별. 새로 읽힌 사실
- 구멍 3개·쟁반: 모름

### 구역6 **올리고마이신과 H+ 기울기 축적** - 5
- ↻ 올리고당 시럽 항아리 = 올리고마이신 (#103), 소리 추정 확정
- ↻ 시럽 엉킨 바퀴+축의 금색 자물쇠 = F0 를 막는 약 (#2)
- 말라붙은 아치 = H+ 복귀 차단
- 물 돔 = 막간공간 H+ 축적 (약속 없음, 추정)
- 먹구름 = 전기적 기울기 (약속 없음, 추정)

## ③ 의문·어색함
- 풀린 것: 밀랍병, 빈 소매. 확정된 것: 시럽, 석상, 해골, 도깨비, 양동이, 동전, 자물쇠
- 여전히 모름: 해, 두 수레의 정체, 구멍 3개와 쟁반, 해골 오른손의 작은 도구(칼날 안 보여 K 로 읽지 않음), 지붕의 작은 둥근 뚜껑, 물방울 2개의 수
- 헷갈릴 위험: 붉은 벽돌 = 간 약속과 겹침, 자물쇠 두 개는 서로 다른 약, 문간 남자가 주는지 받는지 모호
- 이음매: 선명한 붙임선 없음. 하늘이 x 약 1040 에서 먹구름으로 급변, 오른쪽 돌 건물은 덧댄 듯 재질이 어긋남

## ④ 한 문장
근육 팔이 담 너머로 퍼 올린 물(H+)이 물레방아(ATP 합성효소)를 돌려야만 동전(ATP)이 쏟아지는데, 해골 미장이(시안화물)와 올리고당 시럽(올리고마이신)은 자물쇠로 문과 바퀴를 막고, 도깨비(DNP)는 담에 구멍을 내 동전 대신 열만 낸다.
