# 2단계 덱 약속 재판독 (s32u01)

열람: 그림 + 내 조각 + 약속표.md만 (A/ · grader/ · labels · prompt_* · /tmp/b2 안 열었음). 「↻」 = 1단계와 달라진 곳.

## 판정
약속으로 더 잘 풀린다. 약속 102·103·104·105·106·107·108과 8·2가 이 판 물건 대부분을 확정했고, 1단계의 「모름」·「추정」 5개가 풀렸다. 반대로 약속표의 닮은 항목 몇 개(붉은 벽돌 건물 = 간 등)는 이 판에 적용하면 오독이 된다.

## ① 판 전체 표제어
- 1순위 **산화적 인산화 — 전자전달계·화학삼투(ATP 합성효소), 막는 독·짝풀림제 포함** 93% ↻(85→93)
- 2순위 **세포호흡 후반부(미토콘드리아 ATP 생성)** 5% ↻(10→5)
- 근거: 금속 양동이(NAD/FAD) · 올리고당 시럽 · 밀랍 물병 · 석상 · 도깨비 드릴 · 해골 미장이 · 근육 팔이 한 판에 몰려 있음.

## ② 구역 (왼쪽 → 오른쪽)

**구역1 (40~890) 전자전달계 복합체 I~IV와 H+ 펌프**
- 벽돌 담장 = 막, 담장 너머 바다 = 막간공간, 마당 = 기질. 약속108의 「물을 담장 너머로」가 담장 = 막, 물 = H+를 받쳐 줌 ↻ 확정
- 지붕에서 솟은 근육 팔 3개가 홈통으로 물을 퍼 던짐 = H+ 펌프 3개 = I·III·IV (약속108, 개수)
- 둘째 집 지붕의 빈 셔츠 소매 = 펌프 없음 = 복합체 II (약속108, 자리)
- 집 4채 = I→II→III→IV 순서 (개수·자리, 약속 없음)
- 둥근 금속 양동이(가득) → 둥근 구멍 = NADH가 I로 (약속102, 모양) ↻ 양동이 물은 H+가 아니라 NADH
- 네모 양동이(가득) → 네모 창 = FADH2가 II로 (약속102 「네모 양동이 = FAD」) ↻ 근거 보강
- 바위 수레(II·III 사이) = CoQ, 상자 수레(III·IV 사이) = 사이토크롬 c (자리, 약속 없음, 추정 유지). 바위는 자갈이 아니어서 Ca2+ 약속 미적용
- 해 = 모름 (약속 없음. 맑은 하늘이 정상 구간을 알리는 배경일 수 있음)

**구역2 (890~1020) 산소와 물**
- 풍선 머리 = O2 (밝은 방울의 큰 꼴, 약속17) ↻ 근거 보강
- 넷째 집 대머리 남자가 상자를 건넴 = 복합체 IV가 전자를 O2로 (자리·동작)
- 물방울 2개 = O2 1 + 4e- + 4H+ → H2O 2 (개수)
- 붉은 밀랍으로 봉한 작은 물병 = 완성된 물 H2O (약속104) ↻ 추정 → 확정

**구역3 (1020~1320) 화학삼투: ATP 합성효소**
- 아치 속 수차 = ATP 합성효소 F0F1, 돌아가는 효소 (모양·동작)
- 수차를 돌리며 쏟아지는 물 = H+가 기울기 따라 되돌아옴 (뜻)
- 금화 더미 = ATP (약속8, 둥근 동전 = ATP) ↻ 확정
- 아치 = F0 통로 (자리, 약함)

**구역4 (1320~1760) 전자전달 억제제: 시안화물·CO**
- 해골 미장이(흙손 · 벽돌로 봉한 문간) = 시안화물·CO (약속107) ↻ N3- 삭제
- 문간의 금색 자물쇠 = 막는 독, 복합체 IV 봉쇄 (약속2)
- 돌로 굳은 석상 4명(상자 든 3 + 머리만 1) = 멈춰 선 전달자, 환원된 채 정체 (약속105) ↻ 모름 → 해소. 4라는 수의 뜻은 못 읽음
- 금속 양동이 탑(10개 안팎, 맨 위에 물, 밑에 웅덩이) = NADH가 가득 쌓여 넘침, NAD+로 못 돌아옴 (약속102 가득 = NADH) ↻ 모름 → 부분 해소. 10의 뜻은 모름

**구역5 (1390~1680, 아래) 짝풀림제: H+ 누출과 열**
- 붉은 작은 도깨비 + 손드릴 = 짝풀림제 DNP (약속106) ↻ UCP1 삭제
- 드릴로 낸 구멍 3개 = 막에 낸 H+ 통로. 자물쇠가 없음 = 막는 약이 아니라 구멍 내는 약 (약속2 대비) ↻
- 구멍에서 새는 물줄기 = 수차를 우회한 H+ 누출, ATP 없음 (개수·뜻)
- 붉게 단 벽돌 + 김 = 에너지가 열로 (색·모양)

**구역6 (1660~2040) ATP 합성효소 억제제: 올리고마이신**
- 끈적한 금빛 시럽을 붓는 흰 앞치마 남자 = 올리고마이신 (약속103) ↻ 소리 추정 → 확정
- 시럽에 엉킨 수차 = ATP 합성효소 F0 차단 (모양)
- 축에 채운 금색 자물쇠 = 막는 약 (약속2), 회전 정지
- 위쪽 폭풍 + 솟은 물결 = 출구가 막히면 H+ 기울기가 과도해져 전자전달도 멈춤 (약속 없음, 약함)

## ③ 모름 · 어색 · 헷갈림 · 이음새
- 아직 모름: 쟁반(모듈 쟁반 = 칼모듈린과 닮았으나 모듈 없음, 미적용), 구멍·김 3개의 수, 폭풍·물결, 수레 2개, 탑의 10, 해골이 다른 손에 쥔 칼 같은 가는 날(약속3 「칼 = K」이면 KCN? 미장 연장일 수도).
- 약속이 헷갈리게 하는 곳 ↻: 붉은 벽돌 건물 = 간(이 판의 벽돌 집 4채·담장), 왕복 궤도 = 바사 렉타(이 판의 레일), 궤짝 = P450(상자에 과일 없음), 드립 주전자 = 트립신(시럽 단지).
- 어색: 빈 소매, 넷째 집에 팔과 남자 동시, 넷째 석상 반쯤 가림. 이음새는 뚜렷한 접합선 없음.

## ④ 한 문장
복합체 I·III·IV(팔 3개)가 H+를 담장 너머로 퍼 올리고(II는 안 함) O2가 전자를 받아 물이 되며, 되돌아오는 H+가 ATP 합성효소(수차)를 돌려 ATP(동전)를 만든다. 시안화물(해골)·올리고마이신(시럽)은 막아서 전달자를 석상처럼 굳히고, 짝풀림제(도깨비)는 구멍을 내 열로 날린다. ↻ 석상·NADH 탑 추가
