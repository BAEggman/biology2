# 1단계 생판 판독 (s32u01) - 그림만 보고

## ① 판 전체 표제어
- 1순위 **산화적 인산화 (전자전달계 -> 양성자 기울기 -> ATP 합성효소, 저해제·짝풀림제 포함)** - 확신 85%
- 2순위 **화학삼투·양성자 구동력 (막 수송 관점)** - 확신 8% (광인산화 등 잡음 7%)
- 근거: 담 한 장(막), 네 칸(복합체 4), 팔 셋(펌프 3), 레일 수레 둘(이동 운반체 2), 풍선 머리+물방울(O2 -> 물), 물레방아+금화(ATP 합성효소), 해골·악마·꿀(저해제·짝풀림제)이 모두 호흡 사슬 이야기에 맞는다.

## ② 구역별 (왼쪽 -> 오른쪽)

### 구역1 (x 40-870) **전자전달계 복합체 I~IV와 H+ 펌핑**
- 벽돌 담 너머 바다: 담 = 내막, 바다 = 막간공간(H+ 고임), 마당 = 기질 (자리)
- 벽돌 칸 4개: 복합체 I·II·III·IV (개수)
- 근육 팔 3개가 홈통으로 물을 퍼 바다로: I·III·IV 만 H+ 능동 펌핑 (개수·동작). 물줄기 굵기 첫째 >> 둘째 > 셋째(대략 4:2:1)는 H+ 수 차이일 수 있으나 불확실
- 둘째 칸은 팔 없이 늘어진 천 양말/빈 소매: 복합체 II 는 펌핑 안 함 (모양)
- 둥근 양동이 남자 -> 둥근 구멍: NADH -> 복합체 I (모양 맞춤)
- 네모 양동이 남자 -> 네모 창: FADH2 -> 복합체 II (모양 맞춤)
- 돌덩이 수레(칸2~3 사이): 유비퀴논 Q, I·II -> III (자리, 추정)
- 나무상자 수레(칸3~4 사이): 시토크롬 c, III -> IV (자리, 추정)
- 레일: 전자는 정해진 순서로 이동 (뜻) => 읽힌 사실 9
- 해(광선 16줄): 모름

### 구역2 (x 870-1000) **최종 전자수용체 O2 -> H2O**
- 풍선 머리 남자: O2, 마지막 전자 수용체 (모양)
- 칸4 문에서 허리 굽혀 상자를 건네는 남자: 복합체 IV 가 O2 에 전자를 넘김 (자리)
- 상자 위 물방울 2개: 물 생성, O2 1분자당 H2O 2분자 (개수)
- 붉은 밀랍 마개 물병: 모름 => 읽힌 사실 3

### 구역3 (x 1000-1300) **ATP 합성효소와 화학삼투**
- 아치 구멍으로 바다 -> 마당에 쏟아지는 물: H+ 가 기울기를 따라 ATP 합성효소로만 복귀 (자리)
- 도는 물레방아: 회전하는 F0 -> 회전 촉매 (모양). 바퀴살 약 8개(가려짐), 소단위 수인지는 불확실
- 금화: ATP (ADP+Pi) (뜻)
- 금화 산더미: 산화적 인산화가 ATP 대부분 생산 (양, 추정) => 읽힌 사실 4

### 구역4 (x 1290-1700, 위 띠) **전자전달 저해제와 전자 정체 (시안화물·CO류)**
- 해골: 독 (뜻), 복합체 IV 저해제 추정
- 벽돌로 메운 문: 전자가 O2 로 가는 통로 봉쇄 (모양)
- 문틀 자물쇠: 단단한 결합·잠금 (뜻, 추정)
- 회색 석상 같은 사람 4명(상자 듦): 환원된 운반체의 정체 (개수 4, 추정)
- 양동이 탑 약 10개: NADH 계통 환원형 적체 (추정, 개수 부정확) => 읽힌 사실 5
- 흙손·해골의 작은 칼: 모름

### 구역5 (x 1470-1650, 아래) **짝풀림 (양성자 누출 -> 열)**
- 붉은 악마: 짝풀림제(DNP·UCP1 계열) (소리·뜻)
- 전동 드릴로 벽돌에 구멍: 내막에 H+ 샘, 합성효소 우회 (뜻)
- 붉게 달궈진 벽돌+김, 쟁반으로 튀는 물줄기: 에너지가 ATP 대신 열로 (뜻) => 읽힌 사실 3
- 구멍 3개, 쟁반: 모름

### 구역6 (x 1630-1990) **올리고마이신(ATP 합성효소 F0 저해)과 양성자 기울기 축적**
- 항아리의 끈적한 꿀: 올리고당 -> 올리고마이신 (소리)
- 꿀 엉킨 바퀴+축 자물쇠: F0 막힘, 회전·ATP 합성 정지 (모양)
- 말라붙은 아치: H+ 복귀 차단 (뜻)
- 바다 위 거대한 물 돔: 막간공간 H+ 축적, 전자전달 감속 (뜻)
- 먹구름: 전기적 기울기(막전위) (추정) => 읽힌 사실 5

## ③ 의문·어색함
- 모름: 해(호흡판에 왜 해? 광합성 암시인지, 맑음(정상) 대 먹구름(저해) 대비인지), 둘째 칸 양말(양말·빈 소매·깔때기?), 붉은 밀랍병, 해골의 칼
- 헷갈림: 돌덩이/상자 중 Q·cyt c 는 위치로만 추정. 자물쇠 두 개(문틀/바퀴 축)와 물레방아 두 대(정상/꿀)는 서로 다른 저해 지점. 문 앞 남자가 상자를 주는지 받는지 방향 모호
- 이음매: 선명한 붙임선은 없다. 하늘이 x 약 1040 에서 먹구름으로 급변, 오른쪽 회색 돌 건물은 벽돌 담 앞에 덧댄 듯 재질·원근이 어긋남, 회색 사람들은 채도가 떨어져 따로 붙인 느낌

## ④ 한 문장
전자가 네 칸을 지나며 퍼 올린 H+(물)가 막 너머에 고이고, 이것이 ATP 합성효소(물레방아)로만 돌아올 때 ATP(금화)가 만들어지니, 문을 막거나(시안화물) 바퀴를 막거나(올리고마이신) 벽에 구멍을 내면(짝풀림) ATP 합성은 멈추거나 열로만 샌다.
