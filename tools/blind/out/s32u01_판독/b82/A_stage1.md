# 1단계 생판 판독 (s32u01, 그림만 보고)

## ① 판 표제어
- 1순위 **산화적 인산화(미토콘드리아 전자전달계 + 화학삼투 + ATP 합성효소, 저해제·짝풀림 포함)** 88%
- 2순위 **세포호흡 후반부(전자전달 → ATP 생성)** 7%. 해가 있어 엽록체 명반응도 스쳤으나 양말·펌프팔 3개·끝자리 풍선은 미토콘드리아 쪽.
- 1순위 근거: 칸 4개(팔 3+양말 1)가 일렬, 이동 수레 2대, 줄 끝에 풍선(O2), 이어 물레방아→금화(ATP), 뒤에 자물쇠·해골·드릴 악마(저해제·짝풀림).
- 무대: 방파제=내막, 바다=막간공간(H+ 많음), 모래마당=기질. 해(맑음) 쪽=정상, 먹구름 쪽=저해·짝풀림(약).

## ② 구역 (왼→오, x는 원본 좌표)
**구역1 복합체 I·II 입구 (x40~540)**
1. 둥근 구멍 칸+양동이 사람 = NADH→복합체 I (자리·동작, '나르다'~NADH 소리는 약)
2. 네모 창 칸+네모 물통 사람 = FADH2→복합체 II (모양·자리)
3. 둘째 칸 지붕의 양말 = 석신산 탈수소효소 = II (소리 sock~succinate)
4. 둘째 칸만 근육팔 없음 = II는 H+ 펌프 안 함 (개수 팔3/칸4)
5. 첫 칸 근육팔이 물받이로 물을 벽 너머로 퍼냄 = I은 H+를 기질→막간공간으로 펌프 (뜻)

**구역2 이동 전달체·복합체 III·IV (x520~900)**
1. 돌덩이 수레(칸2·3 사이) = CoQ, I·II→III (자리·모양)
2. 상자 수레(칸3·4 사이) = 시토크롬 c, III→IV (자리). 수레 2대 = 전달체 2종 (개수)
3. 칸3 근육팔 = III의 H+ 펌프 (뜻)
4. 칸4 근육팔 = IV의 H+ 펌프 (뜻)
5. 팔 총 3개(I·III·IV): FADH2 경로는 팔 2개만 통과 → NADH보다 ATP 적음 (개수, 추론)
6. 푸른 셔츠 남자가 문 앞에서 상자를 건넴 = IV가 cyt c 전자를 O2로 (자리·동작)

**구역3 최종 전자수용체 O2 → H2O (x890~1030)**
1. 풍선 머리 사람 = O2, 사슬 맨끝 (모양·자리)
2. 상자 위 물방울 2개 = O2 1분자→H2O 2분자 (개수)
3. 상자를 받는 동작 = 전자를 받아 환원 (동작)
4. 점선 호(물방울→웅덩이) = 기질의 H+가 물 생성에 소비 (뜻, 약)

**구역4 화학삼투·ATP 합성효소 (x1030~1400)**
1. 벽 아치를 빠져나오는 물 = H+가 기울기 따라 막간→기질로 ATP 합성효소 통과 (뜻·자리)
2. 물레방아 = 회전하는 F0F1 (모양)
3. 쏟아지는 금화 더미 = ATP (뜻, 수백 개라 셀 수 없음)
4. 물이 돌려야 금화가 나옴 = H+ 흐름과 ATP 합성의 짝지음 (뜻)

**구역5 복합체 IV 저해(시안화물·CO류) (x1300~1720)**
1. 벽돌로 막힌 문 = IV 봉쇄 (모양)
2. 자물쇠 = 저해제 결합 (모양·뜻)
3. 해골+흙손+벽돌 = 치명적 독 (뜻)
4. 회색 사람 4명이 상자 들고 문 쪽으로 줄섬 = 전자·운반체 정체 (개수 4, 약)
5. 양동이 탑 약 10개 = 못 쓴 NADH·FADH2 누적? (모양, 약)

**구역6 짝풀림 (x1390~1620)**
1. 악마+전동드릴 = 짝풀림제(DNP류) (뜻)
2. 뚫린 구멍 3개(분출 2, 뚫는 중 1) = 막의 H+ 누출 통로 (개수)
3. 구멍의 물줄기가 쟁반으로 = ATP 합성효소를 우회해 기질로 샘 (뜻)
4. 붉게 달아오른 벽+김 = ATP 대신 열 (모양)

**구역7 올리고마이신, ATP 합성효소 봉쇄 (x1620~2000)**
1. 자물쇠 채운 이중 테 바퀴 = ATP 합성효소(F0) 봉쇄 (모양)
2. 단지에서 쏟는 금빛 끈적액 = 올리고마이신 (올리브유? 소리는 약)
3. 바퀴 곁에 금화 없음 = ATP 합성 정지 (자리)
4. 위쪽 물 돔+먹구름 = 막간공간 H+ 기울기 과축적 (뜻, 약)

## ③ 모름·어색·헷갈림·이은 흔적
- 봉인 물병(적랍, 풍선 사람 발치), 점선 호의 방향 = 모름.
- 양동이 탑(약 10개, V/W 각인 6개쯤)의 뜻은 추정일 뿐, 각인은 모름.
- 해·먹구름·물 돔이 정상/교란을 가른다는 읽기는 약함.
- 돌 수레와 상자 수레 중 어느 쪽이 CoQ인지 헷갈림(자리로만 판단).
- 물레방아 2개(왼쪽 작동/오른쪽 잠김) 혼동 소지. 오른쪽만 이중 테.
- 팔마다 물줄기 크기가 달라 H+ 수(4·4·2)와 대응하는지 불명.
- 이은 흔적 없음. 한 장면이고 하늘만 x≈1000에서 맑음→폭풍.

## ④ 한 문장
방파제(내막)의 복합체 I–IV가 전자를 O2까지 넘기며 H+(물)를 바다(막간공간)로 퍼 올려 만든 기울기가 물레방아(ATP 합성효소)를 돌려 금화(ATP)를 쏟게 하지만, 저해제는 문·바퀴를 잠그고 짝풀림제는 구멍을 뚫어 금화 대신 열만 낸다.
