# stage1 — 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위 **전자전달계와 산화적 인산화(화학삼투)** — 85%
- 2순위 **산화적 인산화의 저해·탈공역(공역 조절, 열 발생)** — 10% (그 밖: 막 능동수송 일반 3%, 세포호흡 총론 2%)
- 뼈대: 벽돌 방벽 = 막, 바다(높은 쪽) = 막간공간의 H+, 해변 = 기질. 레일 따라 부스 4개 = 복합체 I·II·III·IV, 팔 = 펌프, 물레방아 + 금화 = ATP 합성.

## ② 구역별 읽기 (왼쪽부터 7구역, x는 원본 2048 기준 대략)

### 구역1 (x 40~310) **복합체 I — NADH 투입과 첫 펌프**
1. 첫째 부스 = 복합체 I (자리: 레일 맨 앞)
2. 근육 팔이 홈통으로 물을 벽 너머 바다로 퍼 올림 = H+ 펌프, 농도를 거슬러 올리는 능동 (동작·뜻)
3. 둥근 구멍 앞 둥근 양동이 든 사람 = NADH가 I에 전자를 넣음 (모양 짝)
- 해(광선 16줄): 모름. 맑은 날씨 = 정상 작동의 대비로 추정.

### 구역2 (x 310~640) **복합체 II + 유비퀴논(Q)**
1. 팔 대신 늘어진 빈 소매 = II는 H+를 안 퍼 올림 (모양·뜻)
2. 네모 창 + 네모 양동이(고리 손잡이) = FADH2(숙신산)가 II로 (모양 짝)
3. 레일 위 돌덩이 수레, II·III 사이 = Q, I·II의 전자를 III로 나르는 막 속 이동 운반체 (자리·모양, 큐볼 = Q 말놀이)

### 구역3 (x 520~830) **복합체 III + 사이토크롬 c**
1. 셋째 부스에 팔 = III도 H+ 펌프 (뜻)
2. 레일 위 나무 상자 수레, III·IV 사이 = cyt c (crate = c, 자리), 전자를 IV로 나름
- 비어 있는 큰 문: 모름.

### 구역4 (x 710~1030) **복합체 IV — 산소가 전자를 받아 물이 됨**
1. 넷째 부스 팔 = IV도 펌프. 펌프 팔 3개(I·III·IV), 안 펌프 1개(II) (개수)
2. 푸른 셔츠 사람이 문턱에서 허리 굽혀 상자를 건넴 = IV가 전자를 O2에 넘김 (동작)
3. 흰 풍선 머리 사람 = O2, 기체·최종 전자수용체 (모양)
4. 상자 위 물방울 2개 = H2O, O2 1분자당 2분자 (개수)
- 물 든 병(붉은 밀랍), 점선 궤적: 모름.

### 구역5 (x 1030~1470) **화학삼투 — ATP 합성효소**
1. 방벽 = 내막, 바다 = 막간공간(H+ 많음), 해변 = 기질 (자리)
2. 아치 속 물레방아 = ATP 합성효소(F0F1), 돌아가는 회전효소 (모양)
3. 바다 물이 바퀴 위로 쏟아져 내림 = H+가 기울기 따라 되돌아 흐름 (동작)
4. 바퀴 옆으로 쏟아져 쌓이는 금화 = ATP (뜻)

### 구역6 (x 1330~1725) **전자전달 저해 — 독이 길을 막아 정체**
1. 해골 = 독, 사이안화물·CO류 (뜻)
2. 해골이 흙손·벽돌로 문을 쌓아 막고 자물쇠 = 복합체 차단, IV로 추정 (동작)
3. 상자 든 회색 사람 3명 + 머리만 보이는 1명 = 4, 굳어 선 줄 = 상류 운반체의 전자 정체, 환원 상태 (색·자세·개수)
- 포개진 양동이 탑(9~10개): 모름. NADH 정체로 추정.

### 구역7 (x 1500~2010) **ATP 합성효소 저해(올리고마이신)와 탈공역(열)**
1. 제빵사가 꿀을 붓고 바퀴 축에 자물쇠 = 올리고마이신이 F0를 막음 (소리 올리고당·동작)
2. 악마 + 전동 드릴 + 벽 구멍 3개 = 탈공역제(DNP·UCP1), 막에 구멍 (뜻·개수)
3. 구멍 물줄기가 금화 없는 둘째 쟁반으로 = ATP 없이 기울기만 소실 (자리)
4. 붉게 단 벽돌 + 김 2줄 = 열 발생 (색·개수)
5. 먹구름과 하늘로 솟은 물 언덕 = 막간공간 H+ 과축적, 호흡 정지로 추정 (모양)

## ③ 걸리는 것
- 뜻 모름: 해, 병, 점선(풍선 사람에서 웅덩이로, 작은 방울 1), 양동이 탑, 빈 큰 문, 벽돌 문이 IV인지 ATP/ADP 교환문인지.
- 어색: 몸 없이 팔뚝만 솟은 팔, 얼굴 없는 풍선 머리, 석상 같은 회색 4명, 비현실 크기의 물 언덕, 쟁반 2개가 맞붙음, 대머리 남자 5명이 서로 닮음.
- 헷갈림: 물레방아 2개(작동 / 막힘)는 같은 물건의 정상·저해 쌍. 금화와 꿀이 모두 황금색. 자물쇠 2개는 대상이 다름(문 / 바퀴). 돌덩이 수레 대 상자 수레(Q 대 c). 상자가 3종(수레 · 풍선 사람 · 회색 줄).
- 이음 흔적: 하늘이 맑음에서 폭풍으로 매끈히 이어져 칼 같은 이음선은 없음. 벽·바다 연속. 오른쪽 앞의 회색 석벽(꿀 바퀴)만 재질이 달라 별도 소판을 얹은 느낌. 레일은 구역4에서 끝남. 소판 4개(복합체 열 / ATP 합성 / 전자전달 저해 / ATP 합성 저해·탈공역)를 한 풍경에 묶은 인상.

## ④ 한 문장
전자가 I→Q→III→c→IV로 내려가며 세 곳(II 제외)에서 H+를 바다로 퍼 올리고 산소가 물이 되며, 그 기울기가 물레방아(ATP 합성효소)를 돌려 ATP(금화)를 만들되 독·꿀·구멍이 끼면 ATP 대신 정체나 열만 남는다.
