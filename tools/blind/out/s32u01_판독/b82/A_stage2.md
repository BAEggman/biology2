# 2단계 약속표 판독 (s32u01) — ↻ = 1단계와 달라진 곳

## ① 판 표제어
- 1순위 **산화적 인산화(전자전달계 + 화학삼투 + ATP 합성효소, 저해제·짝풀림 포함)** 96% ↻88→96
- 2순위 **세포호흡 후반부(전자전달→ATP 생성)** 2%
- 판정: 약속표로 더 잘 풀림. 양동이·근육 팔/빈 소매·동전·물병·해골 미장이·도깨비 드릴·올리고당 시럽·석상이 모두 표와 맞아 오른쪽 절반은 거의 확정. 수레·돌덩이·상자·물레방아·해·물 돔은 표에 없어 1단계 추정 그대로(억지로 끼우지 않음).

## ② 구역 (x는 원본 좌표)
**구역1 복합체 I·II 입구 (x40~540)**
1. 가득 찬 둥근 금속 양동이 사람 → 둥근 구멍 칸 = NADH→복합체 I (약속 가득=NADH, 모양 둥근 통↔둥근 구멍) ↻근거 확정
2. 네모 양동이 사람 → 네모 창 칸 = FADH2→복합체 II (약속 네모=FAD, 모양 짝) ↻근거 확정
3. 첫 칸 근육 팔이 홈통으로 담장 너머에 물을 쏟음 = I의 H+ 펌프 (약속) ↻확정
4. 둘째 칸 지붕의 빈 셔츠 소매(끝에 단추) = II는 펌프 없음 (약속) ↻양말=석신산 풀이는 오독, 폐기

**구역2 이동 전달체·복합체 III·IV (x520~900)**
1. 돌덩이 수레(칸2·3 사이) = CoQ 추정, I·II→III (자리, 표에 없음)
2. 상자 수레(칸3·4 사이) = 시토크롬 c 추정, III→IV (자리, 표에 없음)
3. 칸3 근육 팔 = III의 H+ 펌프 (약속)
4. 칸4 근육 팔 = IV의 H+ 펌프 (약속)
5. 팔 3개+빈 소매 1개 = 펌프는 I·III·IV뿐, FADH2는 팔 2개만 통과해 ATP 덜 만듦 (개수, 추론)
6. 푸른 셔츠 전달자가 문 앞에서 상자를 건넴 = IV가 전자를 O2로 (자리·동작)

**구역3 최종 전자수용체 O2 → H2O (x890~1030)**
1. 풍선 머리 사람 = O2 (밝은 방울=O2와 같은 계열, 사슬 끝 자리) ↻근거 보강
2. 상자를 받는 동작 = 전자를 받아 환원 (동작)
3. 상자 위 물방울 2개, 점선으로 기질 웅덩이와 이어짐 = 기질 H+가 O2 환원에 소비 (뜻) ↻H2O 2분자에서 H+로 고침
4. 발치의 붉은 밀랍 봉인 물병 = 완성된 물 H2O (약속) ↻모름→풀림

**구역4 화학삼투·ATP 합성효소 (x1030~1400)**
1. 벽 아치를 지나 쏟아지는 물 = H+가 기울기 따라 막간→기질 (뜻·자리)
2. 물레방아 = 회전하는 ATP 합성효소 (모양, 표에 없음)
3. 쏟아지는 금화 더미 = ATP (약속 동전, 수백 개라 셀 수 없음) ↻확정
4. 물이 돌려야 금화가 나옴 = H+ 흐름과 ATP 합성의 짝지음 (뜻)

**구역5 복합체 IV 저해(시안화물·CO)와 정체 (x1300~1720)**
1. 벽돌로 봉한 문간 = IV 봉쇄 (약속 해골 미장이) ↻
2. 해골 미장이(흙손·벽돌) = 시안화물·CO (약속) ↻확정
3. 문간의 금색 자물쇠 = 막는 약·독 (약속) ↻
4. 석상 4명이 상자 든 채 줄섬 = 멈춰 선 전달자, 환원된 채 정체 (약속, 개수 4) ↻약→확정
5. 금속 양동이 탑 약 10개, 맨 위 통만 물이 보이고 밑에 웅덩이 = NADH가 넘치게 쌓임 (약속 가득=NADH, 중) ↻모름→중

**구역6 짝풀림 (x1390~1620)**
1. 붉은 작은 도깨비+손드릴 = 짝풀림제 DNP (약속) ↻확정
2. 뚫린 구멍 3개(분출 2, 뚫는 중 1) = 막의 H+ 누출 통로, 자물쇠 없음이 약속과 맞음 (개수)
3. 구멍 물줄기가 쟁반으로 = ATP 합성효소를 거치지 않고 샘 (뜻)
4. 붉게 달아오른 벽+김 = ATP 대신 열 (모양, 표에 없음)

**구역7 올리고마이신 (x1620~2000)**
1. 자물쇠 채운 이중 테 바퀴 = ATP 합성효소(F0) 봉쇄 (약속 자물쇠)
2. 단지에서 쏟는 끈적한 금빛 시럽 = 올리고마이신 (약속 올리고당 시럽) ↻올리브유 풀이 폐기
3. 바퀴 곁에 동전 없음 = ATP 합성 정지 (약속 동전, 자리)
4. 위쪽 물 돔+먹구름 = 막간공간 H+ 과축적 (뜻, 표에 없어 약)

## ③ 남은 모름·헷갈림
- 표에 없음: 레일 수레, 물레방아, 해·먹구름·돔, 열·김, 쟁반, 탑의 V/W 각인.
- 표와 겹쳐 보이나 안 쓴 것: 붉은 벽돌=간(여기선 막·복합체), 단일 돌덩이=자갈 Ca²⁺(Ca 문맥 없음), 레일=왕복 궤도(직선 단선이라 아님), 조끼=CD4·CD8(면역 문맥 없음).
- 탑은 NADH 누적(약속 양동이) 대 H+ 새는 파이프(맨 위가 바다 수위, 밑에 웅덩이) 사이에서 앞쪽을 택함. 점선 호의 방향은 H+ 소비로 읽되 약함. 이은 흔적 없음.

## ④ 한 문장
NADH(가득 양동이)·FADH2(네모 양동이)가 복합체 I·II로 들어가 전자가 O2(풍선)에서 물병(H2O)이 되는 동안 근육 팔이 H+를 담장 너머로 퍼 올리고, 그 H+가 물레방아(ATP 합성효소)를 돌려 동전(ATP)을 쏟지만, 해골 미장이(시안화물)와 올리고당 시럽(올리고마이신)은 막고 드릴 도깨비(DNP)는 구멍으로 새게 해 동전 대신 열만 낸다.
