# stage2 — 덱 약속으로 다시 읽음 (↻ = 1단계와 달라진 곳)

## 판정
약속표는 이 그림의 물건 약 10개에 이름을 붙여 주고, 1단계와 부딪히는 곳은 없다. 담장·부스·수레·풍선 사람·물레방아는 표에 없어 1단계 읽기를 유지한다. 결론: 표로 더 잘 풀린다(모름 5개 해소, 읽힌 사실 24→27개). 구조는 안 바뀌고 확신만 오른다.

## ① 판 전체 표제어
- 1순위 **전자전달계와 산화적 인산화(화학삼투)** — 95% ↻ 85에서 상승 (표 102·108·8·103·107·106행이 모두 이 단원 어휘)
- 2순위 **산화적 인산화의 저해제·짝풀림제** — 3% ↻ 10에서 하락 (표가 판 전체를 호흡 연쇄로 묶음)
- 뼈대 유지: 담장 = 내막, 바다 = 막간공간(H⁺ 많음), 해변 = 기질. 표 108행의 「담장 너머로」가 뒷받침.

## ② 구역별 (7구역, 경계는 1단계와 같음)

### 구역1 **복합체 I — NADH와 첫 H⁺ 펌프**
1. 첫째 부스 = I (자리, 표 밖)
2. 지붕의 근육 팔이 홈통으로 담장 너머에 물을 붓기 = H⁺ 펌프 (표 108행)
3. 둥근 구멍 앞, 가득 찬 둥근 금속 양동이 = NADH (표 102행 + 모양 짝) ↻ 가득 = NADH로 확정
- 해: 표에 없음, 모름.

### 구역2 **복합체 II(FAD, 펌프 없음) + 유비퀴논(Q)**
1. 빈 셔츠 소매 = 펌프 없음 (표 108행) ↻ 「늘어진 천」이 표 이름으로 확정
2. 가득 찬 네모 양동이 = FAD(H₂) (표 102행 + 네모 창)
3. 레일 위 돌덩이 수레(II·III 사이) = Q (자리·큐볼 말놀이, 표 밖)

### 구역3 **복합체 III + 사이토크롬 c**
1. 근육 팔 = III도 펌프 (표 108행)
2. 레일 위 상자 수레(III·IV 사이) = cyt c (crate = c, 표 밖)
- 빈 큰 문: 여전히 모름.

### 구역4 **복합체 IV — 산소와 완성된 물**
1. 근육 팔 = IV 펌프. 팔 3(I·III·IV) 대 빈 소매 1(II) (표 + 개수)
2. 푸른 셔츠 사람이 상자를 건넴 = IV가 전자를 O₂에 (동작, 표 밖)
3. 흰 풍선 머리 = O₂ (표 밖. 「밝은 방울 = O₂」와 같은 밝은 기체 계열이라 지지되나 확정 못 함)
4. 상자 위 물방울 2개 = H₂O 2분자 (개수, 표 밖)
5. ↻ 붉은 밀랍으로 봉한 물병 = 완성된 물 (표 104행). 1단계의 「모름」 해소

### 구역5 **화학삼투 — ATP 합성효소와 ATP**
1. 담장 = 내막, 바다 = 막간공간, 해변 = 기질 (자리)
2. 아치 속 물레방아 = ATP 합성효소, 회전 (모양, 표 밖)
3. 바다 물이 바퀴로 쏟아짐 = H⁺가 기울기 따라 되돌아옴 (동작)
4. 넘치도록 쌓인 금빛 동전 = ATP (표 8행)

### 구역6 **시안화물·CO 저해와 정체**
1. ↻ 해골 미장이(흙손·벽돌로 문간 봉함) = 시안화물·CO (표 107행). 1단계의 「ATP/ADP 교환문일 수도」 폐기
2. ↻ 문간의 금색 자물쇠 = 막는 독 (표 2행). 새로 셈
3. ↻ 돌로 굳은 회색 석상 4명(상자 3 + 머리만 1) = 멈춰 선 전달자, 환원된 채 정체 (표 105행)
4. ↻ 양동이 탑(9~10개, 맨 위 가득, 밑에 물 번짐) = NAD 계열 금속 양동이 (표 102행). 가득·넘침이므로 NADH 쌓임으로 추정

### 구역7 **올리고마이신과 짝풀림제(열)**
1. ↻ 끈적한 금빛 올리고당 시럽을 붓는 제빵사 = 올리고마이신 (표 103행). 1단계 말놀이가 확정
2. ↻ 바퀴 축의 금색 자물쇠 = 막는 약 (표 2행). 새로 셈
3. ↻ 붉은 도깨비 + 손드릴 = 짝풀림제 DNP (표 106행). 1단계의 UCP1은 표 근거가 없어 뺌. 자물쇠 없음 = 「구멍 내는 약」(표 2행)과 일치
4. 구멍 3개 물줄기가 동전 없는 둘째 쟁반으로 = ATP 없이 기울기 소실 (표 밖)
5. 붉게 단 벽돌 + 김 2줄 = 열 (표 밖)
6. 먹구름과 물 언덕 = H⁺ 과축적, 추정 (표 밖)

## ③ 걸리는 것
- 풀림: 물병, 석상, 문간, 올리고당, 양동이 탑, 자물쇠 2개.
- 여전히 모름: 해, 점선(풍선 사람에서 웅덩이로), 빈 큰 문, 푸른 셔츠 사람의 정체, 물 언덕, 쟁반 2개.
- 표에 걸리나 적용 안 함: 붉은 벽돌 건물 = 간(담장·부스일 뿐, 간 맥락 없음). 자갈 = Ca²⁺(바닥 잔돌은 질감, 돌덩이는 자갈 아님). 조끼 단추(단추 줄 없음). 모듈 쟁반(구획 없음). 흰 셔츠 칼라(그냥 옷).
- 불안한 겹침: 표 6행 「왕복 궤도 = 바사 렉타 전용」. 레일은 콩팥 단서가 없고 수레가 뜻을 나르므로 이동로로만 읽었으나 전용 약속과 겹침.
- 이음 흔적: 1단계와 같음. 하늘은 매끈히 이어지고 오른쪽 앞 회색 석벽만 별도 소판 느낌.

## ④ 한 문장
금속 양동이(NADH·FAD)의 전자가 I·II→Q→III→c→IV로 내려가며 근육 팔(I·III·IV)이 H⁺를 담장 너머로 올려 두고, 그 기울기가 물레방아를 돌려 동전(ATP)을 만들되 시안화물·올리고마이신·짝풀림제가 끼면 정체·쌓임·열만 남는다.
