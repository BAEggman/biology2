# 1단계 생판 읽기 — 통합판 s32u01 (그림만 보고, 사전 정보 없음)

## ① 판 전체의 표제어
- 1순위 **산화적 인산화 — 전자전달계 + 화학삼투(ATP 합성효소), 저해제·탈공액제 포함** 85%
- 2순위 **세포호흡(에너지대사) 단원 전반** 10% (그 밖에 **엽록체 광인산화** 3% — 해·물·O2 풍선 때문에 잠깐 의심했으나 NADH/FADH2 두 입구와 독·탈공액 장면이 호흡을 가리킴)
- 큰 틀: 벽돌벽 = 내막, 벽 너머 바다 = 막간공간(H+ 고농도), 사람이 걷는 모래땅 = 기질.

## ② 구역별 (왼쪽 → 오른쪽)

### 구역1 **복합체 I–IV와 H+ 퍼올림** (원본 x≈40–900, 확신 90%)
- 벽돌 부스 4칸 = 복합체 I·II·III·IV (개수·자리)
- 근육 팔 3개(1·3·4번 부스)가 나무통으로 물을 벽 너머 바다로 퍼 던짐 = I·III·IV가 H+를 기질→막간으로 능동적으로 퍼올림 (개수·동작). 물줄기가 오른쪽으로 갈수록 가늘다 = IV가 적게(4·4·2?) — 불확실.
- 2번 부스: 팔 없이 꺾여 늘어진 헝겊 통 = 복합체 II는 H+를 안 퍼올림 (모양·자리)
- 둥근 양동이 든 남자 → 둥근 구멍(1번) = NADH가 I로 전자 공급 (뜻·자리)
- 네모 양동이(+렌치) 든 남자 → 네모 창(2번) = FADH2(숙신산)가 II로 (자리). 렌치는 모름.
- 레일 위 돌공 수레(2·3번 사이) = 유비퀴논(CoQ), 상자 수레(3·4번 사이) = 시토크롬 c: 복합체 사이를 오가는 이동 운반체 (자리·모양)
- 해(광선 16갈래): 모름 — 맑음 = 정상 상태 신호로 추정.
→ 읽힌 사실 9개

### 구역2 **O2 = 최종 전자수용체, 물 생성** (x≈810–1020, 확신 85%)
- 풍선 머리 남자 = O2 (뜻: 풍선 = 공기)
- 4번 부스 문에서 몸을 내밀어 상자를 건네는 대머리 남자 = 복합체 IV가 전자를 O2에 전달 (동작·자리)
- 상자 위 물방울 2개 = O2 + 4e− + 4H+ → 2H2O (개수)
- 발치의 병(빨간 밀랍 마개, 물): 모름(생성된 물? 저장?)
→ 읽힌 사실 3개

### 구역3 **ATP 합성효소(화학삼투)** (x≈1020–1330, 확신 90%)
- 돌 아치(벽의 구멍)로 바다 물이 쏟아져 물레방아를 돌림 = H+가 농도기울기를 따라 ATP 합성효소(F0 채널)로만 되돌아옴 (자리·동작)
- 물레방아 = 회전하는 효소(F0 회전 → F1) (모양)
- 바퀴에서 쏟아져 쟁반에 쌓이는 금화 = ATP (뜻). 개수는 수백 — 못 셈.
- 물 흐름이 펌프와 반대(내리막) = 퍼올린 에너지를 되돌려 받아 일함 (뜻)
→ 읽힌 사실 4개

### 구역4 **전자전달 저해(독)** (x≈1300–1700 위쪽, 확신 70%)
- 해골 = 독: 시안화물·CO 등 전자전달계 억제제 (뜻). 어느 복합체인지는 안 읽힘(IV 추정).
- 벽돌로 메우고 자물쇠 채운 문 + 흙손·벽돌 = 전자 흐름 봉쇄 (모양·동작)
- 회색 석상 같은 남자 4명이 상자 들고 줄 섬(3명 + 머리만 보이는 1) = 막혀 정체된 전자/운반체 (추정; 4 = 4e−?)
- 회색 양동이 탑(약 9~10개): 모름(NADH 쌓임? 추정)
→ 읽힌 사실 3개

### 구역5 **탈공액 — 열** (x≈1450–1700 아래쪽, 확신 80%)
- 빨간 악마 + 전동드릴 = 탈공액제(DNP·UCP1) (뜻: 막을 뚫는 장난꾼)
- 달궈진 빨간 벽돌에 구멍 3개, 구멍마다 가는 물줄기 = H+가 합성효소를 우회해 새어듦 (개수·모양)
- 김(3가닥) 오르는 물쟁반 + 달궈진 벽돌 = 에너지가 ATP 대신 열로 (뜻)
- 산소 소비 증가 여부는 그림에 없음.
→ 읽힌 사실 4개

### 구역6 **ATP 합성효소 억제 — 올리고마이신** (x≈1650–2010, 확신 75%)
- 앞치마 남자가 항아리의 끈끈한 누런 시럽을 바퀴에 붓는다 = 올리고당(시럽) ≈ 올리고마이신 (소리)
- 시럽이 바퀴와 아치를 이어 붙이고 축에 자물쇠 = ATP 합성효소(F0) 정지 (모양)
- 물 흐름·금화 없음 = ATP 생산 중단 (자리)
- 오른쪽 먹구름 + 벽 너머 물 돔 = H+가 돌아올 길이 막혀 막간에 쌓인 기울기 (추정)
→ 읽힌 사실 4개

## ③ 뜻 모를 것 · 어색한 것 · 헷갈림 · 이음
- 모름: 병, 렌치, 해 광선 16개(긴 8 + 짧은 8), 양동이 탑 개수, 회색 4명이 가는 방향.
- 헷갈림: 돌공/상자 중 어느 쪽이 CoQ이고 cyt c인지는 자리로만 정함. 자물쇠가 두 곳(문·바퀴)이라 어느 것이 어느 억제제인지는 해골 vs 시럽으로만 가름. 둘째 부스의 꺾인 통이 "없는 펌프"인지 단순 굴뚝인지 애매.
- 이음: 접합선은 못 찾음(열·행 색 단절 검사도 없음). 하늘이 x≈1040 부근부터 맑음→폭풍으로 부드럽게 바뀔 뿐. 벽돌벽→돌 아치→돌집으로 재질이 바뀌는 건 구역 구분으로 보임.

## ④ 한 문장
NADH·FADH2의 전자가 I–IV를 지나 O2에서 물이 되는 동안 I·III·IV가 H+를 퍼올려 만든 기울기가 ATP 합성효소로 되돌아오며 ATP를 만들고, 독(전자전달 차단)·올리고마이신(합성효소 차단)·탈공액제(H+ 누출 → 열)는 이 사슬의 서로 다른 고리를 끊는다.
