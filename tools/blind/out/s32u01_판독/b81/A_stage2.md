# 2단계 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳)

## 판정
약속표로 **더 잘 풀린다.** 1단계에서 확신이 낮거나 모름이던 해골·시럽·자물쇠·물병·회색 줄·도깨비는 확정, 양동이 탑은 뜻이 뒤집힘. 반대로 상자·수레·물레방아·태양·돔·폭풍은 표에 없어 1단계 추정 그대로이며, 억지로 약속에 끼우지 않았다.

## ① 판 전체 표제어
- **1순위 산화적 인산화 — 전자전달계·화학삼투·ATP 합성효소, 시안화물·올리고마이신·DNP 장면 포함** (95%) ↻ 85→95. NADH·FAD·ATP·완성된 물·세 가지 억제/짝풀림이 모두 표에 있어 광인산화 가능성은 사라짐
- **2순위 화학삼투(양성자 기울기로 ATP 합성)** (4%) ↻ 10→4

## ② 구역별 (약속 = 표에 있음 / 추정 = 표 밖)
**구역1 전자전달계 복합체 I~IV**
- 담장 = 막, 담장 너머 바다 = 막간 H+ 쪽 [추정; 표도 「담장 너머」를 씀]
- 상자 4개 = 복합체 I~IV, 좌→우 [추정]
- ↻ 지붕에서 솟은 근육 팔 3개가 홈통으로 물을 담장 너머로 = H+ 펌프 I·III·IV [약속]
- ↻ 2번 상자의 빈 셔츠 소매 = 펌프 없음 → 복합체 II [약속]
- ↻ 가득 찬 둥근 금속 양동이를 둥근 구멍으로 = NADH → I [약속]
- ↻ 네모 양동이를 네모 창으로 = FAD(가득이면 FADH2) → II [약속]
- 바위 수레 = CoQ, 상자 수레 = 시토크롬 c [추정, 자리]. 상자는 석상·풍선 사람의 것과 같은 꼴이라 전자 짐으로 읽음
- 모름: 태양, 팔 물줄기 굵기(첫째만 굵음), 레일, 2번 상자 위 작은 고리

**구역2 산소 → 물**
- 풍선 머리 사람 = O2 [표의 「밝은 방울=O2」와 같은 꼴, 반약속]
- ↻ 붉은 밀랍 물병 = 완성된 물 H2O [약속; 1단계 모름이 풀림]
- ↻ 상자 위 물방울 2개 = H+ 2개 쪽(물=H+ 약속의 연장, 병이 이미 「완성된 물」이므로). 1단계의 「물 2분자」는 약화
- 문에서 몸을 내밀어 상자를 건네는 대머리 남자 = 복합체 IV가 전자를 O2에 넘김 [추정]

**구역3 화학삼투·ATP 합성효소**
- 물레방아 = ATP 합성효소, 담의 아치 = 막 관통 H+ 통로 [추정]
- 바다 물이 아치로 쏟아져 바퀴를 돌림 = H+가 기울기 따라 복귀 [추정+물=H+]
- ↻ 금화 = ATP [약속 확정], 큰 더미와 흩어진 30개 안팎 = 대량 생산

**구역4 시안화물·CO로 막힘 → 정체**
- ↻ 해골 미장이 + 벽돌로 봉한 문간 = 시안화물·CO [약속; 40%→확정]
- ↻ 금색 자물쇠 = 막는 독 [약속]
- ↻ 석상 사람 4명(3 + 반쯤 가린 1)이 돌로 굳은 상자를 든 채 줄 섬 = 환원된 채 멈춘 전달자 [약속]
- ↻ 양동이 10개 탑, 맨 위 가득, 바닥에 물웅덩이 = NADH가 쌓여 넘침 [약속]. 1단계의 「H+ 10」은 철회. 10의 뜻(포도당당 NADH 10?)은 표 밖

**구역5 짝풀림제**
- ↻ 붉은 도깨비 + 손드릴 = DNP [약속]
- 구멍 3개(2개 이미 샘, 1개 뚫는 중), 자물쇠 없음 = 구멍 내는 약 [약속과 일치]
- 물줄기 = ATP 합성효소를 거치지 않는 H+ 누출, 붉은 벽과 김 = 열 [추정]. 모름: 물받이

**구역6 올리고마이신**
- ↻ 올리고당 시럽을 바퀴에 붓는 사람 = 올리고마이신 [약속; 1단계 「올리브유 소리」는 근거가 틀렸음]
- ↻ 바퀴 축의 금색 자물쇠 = 막는 약 [약속] → 멈춘 ATP 합성효소
- 푸른 돔, 폭풍 구름 = 기울기 과축적, 이상 상태 [추정, 낮음]

## ③ 남은 것·새로 보인 것
- 모름: 태양, 돔, 폭풍, 물받이, 레일, 수레의 바위, 10의 뜻, 물방울 2개의 정확한 뜻
- 표와 겹쳐도 끼우지 않음: 붉은 벽돌(간), 레일(왕복 궤도), 바닥 알갱이·바위(자갈 Ca2+), 조끼(단추 줄·개수 없음), 바다의 돔(돔 건물=뇌 아님). 이음매는 여전히 없음
- ↻ 새로 보임: 석상이 든 상자도 돌 질감(짐째 굳음). 양동이 탑 맨 위 물과 바닥 웅덩이. 구멍 물줄기 세기가 위>가운데>아래(뚫는 중)로 달라 구멍이 늘수록 새는 양이 늘어남(추정). 시럽은 바퀴살 사이와 바닥 웅덩이 2곳으로 흘러 끈적하게 막힘. 금화는 쟁반 옆면으로도 흘러내림
- 약속 의존도: 표가 직접 준 것 12개(근육 팔, 빈 소매, 금속 양동이, 네모 양동이, 동전, 물병, 석상, 해골 미장이, 도깨비+드릴, 올리고당 시럽, 자물쇠 2). 표 밖 추정으로 남은 것은 담·상자·수레·물레방아·아치·대머리 남자·풍선 사람·물방울·붉은 벽·김. 약속이 없었다면 오른쪽 반은 40% 이하로 남았을 것

## ④ 한 문장
NADH·FAD의 전자가 사슬을 타고 O2에 닿아 물이 완성되는 동안 H+가 막 너머로 퍼 올려져 기울기가 되고, 그 기울기가 ATP(동전)를 만들지만, 시안화물·올리고마이신이 막고 DNP가 구멍을 내면 ATP가 끊기고 전달자는 석상처럼 멈춘다.
