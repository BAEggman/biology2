# 1단계 생판 (그림만 보고, 사전 정보 없음)

## ① 판 전체 표제어
- **1순위 산화적 인산화 — 전자전달계(복합체 I~IV)·화학삼투·ATP 합성효소, 저해제·탈공역제 포함** (85%)
- **2순위 화학삼투(양성자 기울기로 ATP 합성)** (10%) — 태양과 산소 풍선 때문에 광인산화(명반응)로 읽을 여지가 아주 조금 있으나, 탈공역·저해 장면이 많아 낮게 봄
- 읽는 틀: 벽돌 담 = 막, 담 너머 바다 = 고농도 H+ 쪽, 모래땅 = 기질 쪽. 왼쪽은 맑음(정상), 오른쪽은 폭풍(방해)
- 결정적 근거: 상자 4개 중 팔이 3개(II만 없음), 물통 든 사람 2, 레일 위 수레 2, 물레방아→금화, 구멍 뚫는 악마. 글자·숫자 표지는 그림 어디에도 없음

## ② 구역별 읽기 (x는 원본 픽셀)

**구역1 전자전달계 복합체 I~IV (x 40~900)**
- 담과 바다: 바다 수위가 담보다 높다 = 막 건너 H+ 기울기 [뜻·자리]
- 상자 4개 = 복합체 I~IV, 좌→우 순서 [개수 4]
- 상자에서 솟은 팔 3개가 홈통으로 물을 담 너머로 퍼 올림 = I·III·IV의 H+ 능동 펌핑 [동작·개수 3]
- 2번 상자만 팔 없이 빈 소매 = 복합체 II는 H+를 펌프하지 않음 [자리·개수]
- 물통 든 사람 2 = 전자 공급 2종, NADH→I(둥근 통·둥근 구멍), FADH2→II(네모 통·네모 창) [모양·개수 2]
- 바위 실은 수레 = CoQ(유비퀴논) I·II→III [자리, 확신 낮음]
- 나무 상자 실은 수레 = 시토크롬 c III→IV [자리, 확신 낮음]
- 모름: 태양(에너지? 정상 가동?), 첫 팔의 물줄기만 유독 굵음(4·4·2 암시?), 2번 상자 위 작은 고리

**구역2 산소, 최종 전자 수용체 (x 900~1030)**
- 풍선 머리 사람 = O2(기체, 사슬 끝) [모양·자리]
- 상자 위 물방울 2개 = 물 2분자 (O2 1분자→H2O 2분자) [개수]
- 문에서 몸을 내밀어 상자를 건네받는 대머리 남자 = 복합체 IV가 전자를 O2에 넘김 [동작]
- 모름: 붉은 밀랍 봉인 물병(산물 H2O?)

**구역3 화학삼투 — ATP 합성효소 (x 1030~1450)**
- 물레방아 = ATP 합성효소(F0F1), 돌아가는 회전 효소 [모양·동작]
- 담에 뚫린 아치 = 막을 관통하는 H+ 통로(F0) [자리]
- 바다 물이 아치로 쏟아져 바퀴를 돌림 = H+가 기울기를 따라 막간→기질로 복귀(화학삼투) [동작]
- 바퀴에서 튀는 금화, 큰 더미 = ATP 대량 생산 [뜻·개수 많음]

**구역4 전자전달 차단 (x 1330~1720, 뒤쪽 담)**
- 해골 = 치명적 독 → 전자전달 저해제(시안화물·CO 계열?, 40%) [뜻]
- 흙손+벽돌, 이미 벽돌로 막힌 문 + 자물쇠 = 통로 차단 [동작·뜻]
- 회색으로 굳은 사람 4명(1명은 반쯤 가림), 상자를 들고 줄 섬 = 막힌 앞에서 정체된 전달체? [개수 4, 확신 낮음]
- 양동이 10개 탑, 맨 위에 물 가득 = NADH 1분자당 펌프된 H+ 10개(4+4+2)? [개수 10, 확신 낮음]

**구역5 탈공역 (x 1390~1690, 앞쪽)**
- 악마 = 탈공역제(DNP·UCP1 계열) [뜻]
- 드릴로 구멍 뚫기, 구멍 3개(2개는 이미 샘, 1개 뚫는 중) = 막을 새게 함 [동작·개수 3]
- 구멍의 물줄기가 물받이로 = ATP 합성효소를 거치지 않는 H+ 흐름 [뜻]
- 붉게 달아오른 벽 + 김 = 열 발생 [뜻]
- 모름: 물받이의 정확한 용도

**구역6 ATP 합성효소 저해 (x 1680~2000)**
- 두 번째 물레방아(돌벽) = ATP 합성효소, 멈춘 상태 [모양]
- 항아리의 끈적한 호박색 액체를 바퀴에 부음 = 올리고마이신(올리브유 항아리 소리?) [소리·뜻, 확신 낮음]
- 바퀴 축 자물쇠 = F0 봉쇄 [뜻]
- 바다 위 푸른 돔 = 기울기 과축적, 폭풍 구름 = 이상 상태 [뜻]

## ③ 뜻 모를 것·어색함·헷갈림·이음매
- 뜻 모를 것: 물병, 태양(긴 줄기 8 + 짧은 줄기 8), 10개 탑, 회색 줄, 돔, 물받이
- 어색함: 팔만 상자에서 솟음, 풍선 머리, 같은 대머리 남자가 5번 나옴, 바다가 담보다 높은데 물을 담 너머로 퍼 올림(역방향 일 = 능동수송으로 읽음)
- 손에 든 것: 둥근 물통, 네모 물통, 홈통(팔 3), 나무 상자(풍선 사람·회색 사람 3), 흙손과 벽돌(해골), 드릴(악마), 항아리(요리사 차림 남자)
- 바닥의 작은 것: 흩어진 금화 30개 안팎, 호박색 웅덩이 2곳, 조약돌, 붉은 병. 선반·벽걸이는 없고 벽에 붙은 것은 자물쇠 하나뿐
- 헷갈림: 상자 3·4는 둘 다 '문'이라 수레 순서로만 구분. 바위/상자 중 어느 쪽이 CoQ인지. 물레방아 2개, 자물쇠 2개, 악역 3(해골·악마·항아리 남자)이 어느 억제제인지
- 이음매: 하늘·바다·담이 끊김 없이 이어짐. 하늘만 x≈1040~1100에서 맑음→폭풍으로 부드럽게 바뀜(의도된 장면 전환으로 읽음). 뚜렷한 이어 붙임 흔적은 못 찾음

## ④ 한 문장
전자가 사슬을 타고 내려가며 H+를 막 너머로 퍼 올려 기울기를 만들고(복합체 I·III·IV), 그 기울기가 ATP 합성효소를 돌려 ATP를 만들되, 독·구멍·잠금이 이 흐름을 끊거나 새게 한다.
