# 2단계 — 약속표 어휘로 다시 읽기 (s32u01)

## 판정
약속표는 1단계를 뒤집지 않고 **확정·구체화**했다. 크게 풀린 곳은 오른쪽 절반(저해제·짝풀림제)과 병·빈 소매·석상·양동이 구분. 표 밖이라 안 풀린 곳은 부스·수레·풍선·물레방아·해·먹구름·물 돔(1단계의 자리·모양 추정 그대로). 읽힌 사실 27 → 32개. 표가 뒷받침하지 않는 1단계 곁가지(UCP1, 광인산화, 석상 4=4e−)는 접었다.

## ① 판 표제어
- ↻ 1순위 **산화적 인산화 — 전자전달계·화학삼투 + 저해제(시안화물·CO, 올리고마이신) + 짝풀림제(DNP)** 85 → 97%
- ↻ 2순위 **세포호흡(에너지대사) 단원 전반** 10 → 3%. 광인산화 후보는 버림 — 쓰인 약속 2·8·102–108이 모두 호흡 어휘.

## ② 구역별 (근거 = 약속표 번호)
### 구역1 **복합체 I–IV와 H+ 퍼올림** 90→93% · 9개(그대로)
- 담장 = 내막, 바다 = 퍼올린 H+ 쪽(108 "담장 너머로"), 부스 4칸 = 복합체 4(개수·자리, 표 밖).
- 지붕에서 솟은 근육 팔 3개 + 홈통 = H+ 펌프 I·III·IV (108 ✓).
- ↻ 2번 부스의 꺾인 통 = 빈 셔츠 소매(끝동 단추) = 복합체 II 펌프 없음 (108). 1단계 "애매" 해소.
- 둥근 금속 양동이(가득) = NADH → I (102 ✓). ↻ 네모 양동이 = FAD(H2) → II (102). 렌치로 본 것은 양동이 철사 손잡이 — 의미 없음.
- 돌공 수레 = CoQ, 상자 수레 = cyt c: 표 밖, 자리로만 추정(그대로). 해(광선 16)는 표 밖, 모름.

### 구역2 **O2 → 물** 85→88% · 3→4개
- 풍선 머리 = O2 (17 "밝은 방울" 계열일 수 있으나 풍선이 방울인지 표에 없어 확정 안 함). 문4 남자가 상자 건넴 = IV가 O2에 전자 전달(자리). 청록 물방울 2 = 만들어지는 물 2분자(어두운 방울 CO2(16)는 아님).
- ↻ 붉은 밀랍 병 = 완성된 물(104) — 모름 → 풀림. 코르크(26)와는 밀랍으로 갈림.

### 구역3 **ATP 합성효소(화학삼투)** 90% · 4개(그대로)
- 아치의 물 + 물레방아 = H+ 되돌아옴 + 합성효소(표 밖, 모양). 내리막 흐름 = 기울기 에너지 회수.
- 금화 = ATP (8 ✓ 확정). 회색 네모 칩(GTP 101)이 아님.

### 구역4 **시안화물·CO — 전자전달 저해와 정체** 70→92% · 3→5개
- ↻ 해골 미장이 = 시안화물·CO (107). ↻ 흙손·벽돌로 봉한 문간 = 전자 흐름 봉쇄(복합체 IV 차단, 교과서 연결).
- ↻ 금색 자물쇠 = 막는 약·독 (2) — 통로를 잠금.
- ↻ 석상 4명 = 멈춰 선 전달자, 환원된 채 정체 (105). 4의 뜻은 모름.
- ↻ 금속 양동이 탑(약 10개, 맨 위에 물이 찼고 바닥에 웅덩이) = NADH가 쌓임(102+105; 추정). 모름 → 추정.

### 구역5 **짝풀림제(DNP)** 80→95% · 4→5개
- 도깨비 + 손드릴 = DNP (106 ✓). 달궈진 벽돌 3개·구멍 3·가는 물줄기 = 막에 구멍 + H+ 누출, 김 = 열.
- ↻ 자물쇠가 없다 = 막는 약이 아니라 구멍 내는 약 (2).

### 구역6 **올리고마이신 — ATP 합성효소 억제** 75→93% · 4→5개
- ↻ 끈적한 금빛 시럽 = 올리고당 = 올리고마이신 (103; 1단계 소리 풀이와 일치).
- ↻ 바퀴 축의 금색 자물쇠 = 막는 약(2). 시럽이 바퀴·아치에 엉겨 합성효소(F0) 정지, 물·동전 없음 = ATP 중단.
- 먹구름 + 물 돔 = H+ 기울기 쌓임: 표 밖, 추정 그대로.

## ③ 모름 · 헷갈림 · 이음
- ↻ 풀림: 병, 빈 소매, 석상, 렌치(손잡이), 자물쇠 짝(해골↔문 · 시럽↔바퀴 · 도깨비는 없음).
- 아직 모름(표 밖): 해, 먹구름, 물 돔, 돌공·상자·레일의 정체, 물방울 2·석상 4·양동이 약 10의 개수 뜻(포도당당 NADH 10과 우연히 맞을 수 있으나 표에 개수 규칙 없음), 물줄기 굵기(4·4·2?).
- 일부러 안 끼움(표와 겹치나 맥락 다름): 붉은 벽돌(간 93), 레일(왕복 궤도 6), 궤짝(P450 48, 사과·오이·공 없음), 자갈(4)≠돌공, 돔 건물(뇌 94)≠물 돔, 조끼(39)=의상.
- 이음: 접합선 못 찾음(1단계와 같음).

## ④ 한 문장
가득 찬 양동이(NADH·FAD)의 전자가 팔 3개가 H+를 담장 너머로 퍼올리는 복합체 I–IV를 지나 O2에서 물이 되고, 되돌아오는 H+가 물레방아를 돌려 동전(ATP)을 찍어낸다. 해골(시안화물·CO)과 시럽(올리고마이신)은 자물쇠로 흐름을 막고, 도깨비(DNP)는 구멍을 뚫어 동전 대신 열을 낸다.
