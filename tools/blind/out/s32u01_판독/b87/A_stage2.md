# stage2 — 약속표를 읽고 다시 (↻ = 1단계와 달라진 곳)

## 판정
약속으로 **더 잘 풀린다**. 큰 틀(표제어·7구역)은 그대로이고, 1단계의 「모름·추정」 여럿이 확정되며, 금지 표지와 자물쇠의 읽기가 바뀐다. 약속표에 없는 물건(해·먹구름·소용돌이·파도·물레방아와 아치·점선 화살표·굽힌 사람·물받이)은 끼워 맞추지 않고 1단계의 자리·모양·동작 읽기를 유지한다.

## ① 표제어
- 1순위 **산화적 인산화 — 전자전달계·화학삼투·저해제·짝풀림제** — 96% ↻(90→96)
- 2순위 **세포호흡의 전자전달계 단계** — 3% ↻(7→3)
- 뼈대 그대로: 벽돌 담=막, 바다=막간 공간, 마당=기질. 팔이 담 너머로 퍼 올리는 물=H⁺(#108).

## ② 구역별 (#=약속표 번호)
**구역1 복합체 I·II — NADH·FAD 입구, 펌프 있음/없음**
- 둥근 창 부스+근육 팔 = I, H⁺ 펌프 (#108)
- ↻ 가득 찬 둥근 금속 양동이 사람 = NADH (#102) — 「양동이=H⁺ 공급」 대안 폐기
- 네모 창 부스 = II (자리)
- ↻ 팔 대신 빈 셔츠 소매 = 펌프 없음 (#108) — 「모름·양말」 풀림
- ↻ 네모 양동이 사람 = FAD(FADH₂), I를 건너뜀 (#102)
- ↻ 금지 표지 속 양동이도 네모 = 「FAD 통 금지」로 판독. 표지는 약속표에 없어 뜻 미확정(후보: FAD가 II 효소에 붙박이)
- 해: 약속 없음, 모름 유지

**구역2 Q·시토크롬 c와 복합체 III·IV**
- ↻ 레일 수레의 둥근 바위 = Q, 돌=비단백질 운반체 (#109)
- 문 부스+팔 = III 펌프, 문 부스+팔 = IV 펌프 (#108)
- ↻ 상자 수레 = cyt c (#109)
- ↻ 수레는 건물에 안 붙고 구름 = 이동성 전달체 (#109)
- 펌프 팔은 I·III·IV 3개, II만 없음. 물줄기 I≥III>IV (4·4·2?) 약함
- 굽힌 사람이 상자를 건넴 = IV→O₂ 전자 (동작)

**구역3 O₂ → 완성된 물**
- 풍선 머리 = O₂ (모양·자리). #17 「밝은 방울=O₂」와 같은 계열로 보이나 풍선 머리 사람은 약속표에 없어 확정은 아님
- 받은 상자 = 전자. 점선 화살표 = 웅덩이의 H⁺가 O₂로 들어가 2H₂O (뜻)
- ↻ 붉은 밀랍 물병 = 완성된 H₂O (#104) — 펌프의 「물=H⁺」과 갈림

**구역4 화학삼투 — ATP 합성효소**
- 소용돌이 = H⁺ 기울기가 아치로 끌어당김. 돌 아치+물레방아 = ATP 합성효소. 물이 바퀴를 돌림 (모양·동작)
- ↻ 쏟아지는 동전 = ATP (#8)
- 동전·물 모두 마당(기질) 쪽 = ATP는 기질에서 합성, H⁺ 복귀 (자리)

**구역5 전자전달 저해 — 시안화물·CO**
- ↻ 해골 미장이(흙손·벽돌로 봉한 문) = 시안화물·CO (#107) — CN⁻냐 CO냐 구별 불필요
- ↻ 금색 자물쇠 = 「막는 약」 표지 (#2)
- ↻ 석상 3명 = 환원된 채 정체한 전달자 (#105)
- ↻ 가득 찬 금속 양동이 6개 탑이 넘침 = NADH 쌓임 (#102). 6은 모름

**구역6 짝풀림제**
- ↻ 도깨비+손드릴 = DNP (#106)
- 구멍 3개(둘 뚫림, 하나 작업 중)와 물줄기 = H⁺ 누출. 불꽃·김 = 열. 동전 없는 물받이 = ATP 안 만듦
- ↻ 자물쇠 없음 = 막는 약이 아니라 구멍 내는 약 (#2)

**구역7 ATP 합성효소 저해 — 올리고마이신**
- ↻ 금빛 올리고당 시럽을 쏟는 사람 = 올리고마이신 (#103) — 「ADP 부족」 대안 폐기
- 시럽 엉킨 바퀴 = 회전 정지. ↻ 바퀴 축의 자물쇠 = 막는 약 (#2)
- 바퀴 뒤 물 가득+거대한 파도 = H⁺ 기울기 축적 (자리). 넷째 팔의 높은 호 = 기울기가 높아도 펌프 계속 (#108, 약함)

## ③ 잔결
- 풀림: 빈 소매·Q/cyt c 짝·NADH/FAD 통·시럽·석상·해골·물병·동전·자물쇠 둘.
- 안 풀림: 해·먹구름·소용돌이·파도, 통 6개·석상 3명·바퀴살 8개·물방울 2개의 개수, 표지의 뜻, 둘째 사람이 네모 통을 든 채 지나는 모순.
- 새로 본 것: 표지 속 양동이의 네모 모양, 부스 지붕 위 작은 고리(뜻 모름), 바닥에 고인 시럽 웅덩이 2곳.
- 충돌 점검(안 끼움): 붉은 벽돌(#93 간)은 막·부스 재료, 레일은 #109의 수레 길(#6 바사 렉타 아님), 바닥 잔 점은 질감(#4 자갈 아님), 금빛 시럽은 #103(#55 점액 아님).
- 이음매: 없음. 해만 납작해 얹은 듯.

## ④ 한 문장
NADH(둥근 양동이)·FAD(네모 양동이)의 전자가 Q(바위)→III→cyt c(상자)→IV를 거쳐 O₂에서 완성된 물이 되는 동안 I·III·IV(근육 팔)만 H⁺를 퍼 올려 만든 기울기가 ATP 합성효소(물레방아)를 돌려 동전(ATP)을 쏟게 하고, 시안화물·CO(해골)와 올리고마이신(시럽)은 자물쇠로 막아 전달자를 석상처럼 정체시키거나 기울기만 쌓으며, 짝풀림제(도깨비)는 구멍을 내 ATP 없이 열만 낸다.
