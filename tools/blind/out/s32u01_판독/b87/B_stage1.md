# 생판 stage1 — s32u01 (그림만 보고)

## ① 판 표제어
- 1순위 **산화적 인산화 (전자전달계 + 화학삼투 ATP 합성 + 저해제·탈공역제)** — 88%
- 2순위 **세포호흡 후반부, 미토콘드리아 ATP 생성 총정리** — 8%
- 근거: 벽돌 벽 하나를 두고 바다(높음)/마당(낮음) = 막 양쪽 H⁺ 기울기 (벽=내막, 바다=막간공간, 마당=기질). 벽 속 팔이 물을 바다로 퍼올림 = H⁺ 펌프. 물레방아+금화 = ATP 합성효소. 풍선머리+물병 = O₂→H₂O. 집 4채·팔 4·물레방아 2. 레일이 첫 집에서 넷째 집까지 이어짐 = 전자 경로(I→IV 순서).

## ② 구역 (왼→오)
**구역1 복합체 I — NADH 입구** 읽힌 3
- 첫 집의 둥근 구멍 = 복합체 I (자리: 첫째 / 모양)
- 둥근 양동이 나르는 남자 = NADH가 전자 공급 (뜻: 물통=환원력 / 둥근 통↔둥근 구멍)
- 지붕의 팔이 물을 바다로 쏟음, 물줄기 가장 굵음 = H⁺ 펌프, 4개? (뜻 / 굵기, 낮음)
- 해 = 모름 (오른쪽 폭풍과 짝 → '정상' 추정)

**구역2 복합체 II — FADH₂, 펌프 없음** 읽힌 4
- 둘째 집의 네모 창 = 복합체 II (자리 / 입구 모양이 I과 다름)
- 네모 양동이 든 남자(옷 다름) = FADH₂가 I을 건너뛰고 II로 (모양)
- 팔 대신 늘어진 양말 같은 관 = H⁺ 안 퍼올림 (뜻; sock≈succinate 소리 추정)
- 양동이 금지 표지(네모 양동이에 ✕) = 펌프 없음 재강조, 또는 FADH₂는 I 불가 (뜻)

**구역3 복합체 III + CoQ** 읽힌 3
- 셋째 집의 문 = 복합체 III (bc₁) (자리)
- 팔(물줄기 중간) = H⁺ 펌프, 4개? (굵기, 낮음)
- 레일 수레 위 둥근 돌 = CoQ, 이동 운반체 I·II→III (자리: II·III 사이 / 수레=이동, 돌=지용성)

**구역4 복합체 IV + 사이토크롬 c + O₂→H₂O** 읽힌 7
- 넷째 집의 문 = 복합체 IV (자리)
- 팔(물줄기 가장 가늘다) = H⁺ 펌프, 2개? (굵기, 낮음)
- 수레 위 나무 상자(crate) = 사이토크롬 c, III→IV, 1e⁻씩 (소리 c / 자리)
- 문에서 몸 내밀어 상자 건네는 파란 셔츠 남자 = IV가 전자를 O₂에 넘김 (동작)
- 머리가 풍선인 남자 = O₂, 최종 전자 수용체 (모양: 기체)
- 가슴으로 향하는 파란 점선 화살표 + 물방울 2 = 기질 H⁺ 2개 합류 → 물 (개수)
- 발치 물병 = 산물 H₂O (뜻)

**구역5 ATP 합성효소 — 화학삼투** 읽힌 4
- 돌 아치 속 물레방아 = ATP 합성효소(F₀ 회전자) (모양)
- 바다에서 쏟아져 바퀴를 돌리는 물 = H⁺가 기울기 따라 막간→기질로 F₀ 통과 (뜻)
- 아치 위 바다의 소용돌이 = H⁺가 구멍으로 빨려듦 (모양, 방향)
- 바퀴에서 튀어 쟁반에 쌓이는 금화 = ATP (ADP+Pi), 양 많음 (뜻 / 셀 수 없음)

**구역6 전자전달 저해 — 시안화물·CO (복합체 IV)** 읽힌 5
- 해골 = 독 중독·사망 (뜻)
- 흙손+벽돌로 문을 막는 동작(문 안이 벽돌) = IV 차단 (동작)
- 문의 자물쇠 = 저해제 결합, 잠금 (모양)
- 회색으로 굳은 남자 3명이 상자 든 채 줄섬 = 전자 전달체가 전자를 못 넘겨 환원 상태로 정체 (개수 3 / 색)
- 넘쳐흐르는 양동이 탑 6개 = 상류(NADH) 적체 (개수 6, 낮음)

**구역7 탈공역제 — DNP·UCP1 열 발생** 읽힌 5
- 붉은 악마 + 전동드릴 = 탈공역제 DNP (뜻 / 모양)
- 기둥에 난 구멍 3개(둘은 분출, 하나는 뚫는 중) = 막 투과성↑ (개수 3)
- 구멍에서 뿜는 물줄기 = H⁺가 합성효소를 우회해 새어 돌아감 (뜻)
- 구멍의 불꽃·김 = 열로 소실, 갈색지방 UCP1 (뜻)
- 금화 없는 물 쟁반 = 새어 나온 H⁺는 ATP를 못 만듦 (자리: 금화 쟁반 옆 대비)

**구역8 ATP 합성효소 저해 — 올리고마이신, 호흡조절** 읽힌 6
- 자물쇠 채운 둘째 물레방아 = F₀ 차단 (모양)
- 꿀 쏟는 앞치마 남자 = 올리고마이신 (소리: 올리고당, 중간)
- 바퀴 뒤에 고인 파란 물 = H⁺ 정체 (뜻)
- 기둥 위 넷째 팔의 거대한 아치 물줄기 = 막혀도 퍼올림 → 기울기 극대, 이윽고 전자전달 정지(호흡조절) (뜻, 낮음)
- 뒤에 솟은 해일 = 기울기 과대 (모양)
- 먹구름 = 저해·탈공역 구역의 비정상 (해와 대비)

## ③ 의문·어색·이음
- 해: 용도 불명. 꿀 항아리 남자: 올리고마이신인지 ATP 과잉(금화색)인지 헷갈림.
- 상자가 세 번 쓰임(cyt c 수레, 풍선 남자가 받는 전자, 회색 3인) — 구분 필요.
- 숫자 뜻 불명: 양동이 6, 회색 3, 구멍 3. 팔 4개 중 넷째만 집이 아니라 기둥 위 — 복합체가 아닌 별개?
- 표지가 I·II 사이에 걸려 어느 집 것인지 모호. 물레방아 둘(작동/잠김)이 같은 효소의 두 상태인지.
- 이음선은 안 보임. 다만 오른쪽만 돌벽·폭풍으로 바뀌어 '정상 | 비정상' 두 장면이 이어진 듯함.

## ④ 한 문장
복합체 I·III·IV가 전자 에너지로 H⁺를 막 너머로 퍼올려 만든 기울기가 ATP 합성효소를 돌려 ATP를 만들고(전자는 끝내 O₂→H₂O), 저해제(시안화물·올리고마이신)는 흐름을 막고 탈공역제는 열로 새게 한다.
