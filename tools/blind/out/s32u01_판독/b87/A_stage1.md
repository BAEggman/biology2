# stage1 — 생판 (그림만 보고 · 사전 정보 없음)

## ① 판 전체의 표제어
- 1순위 **산화적 인산화 — 전자전달계(복합체 I~IV)·화학삼투·ATP 합성효소·저해제·짝풀림제** — 확신 90%
- 2순위 **세포호흡의 전자전달계 단계(미토콘드리아의 ATP 생성 일반)** — 확신 7%
- 무대 뼈대: 붉은 벽돌 담 = 미토콘드리아 내막(자리·뜻), 담 너머 바다 = 막간 공간(H⁺ 높음), 모래 마당 = 기질(H⁺ 낮음). 팔이 홈통으로 마당 물을 바다로 퍼 올림 = 양성자 펌프(동작). 바다가 아치로 빠져 물레방아를 돌리고 동전이 쏟아짐 = H⁺ 기울기로 ATP 합성(뜻). 왼쪽은 해, 오른쪽은 먹구름 = 정상 대 억제·이상(자리).

## ② 구역별 읽기 (왼쪽→오른쪽, 괄호 = 근거)
**구역1 복합체 I·II — 전자 진입과 펌프 유무**
- 둥근 창 부스 + 팔 1개 = 복합체 I, H⁺ 펌프 (자리 첫째·동작)
- 둥근 큰 양동이(물) 든 사람 = NADH가 I에 전자 공급 (뜻)
- 네모 창 부스 = 복합체 II (자리 둘째). 팔 대신 늘어진 빈 천 소매 = H⁺ 펌프 없음 (개수)
- '양동이 금지' 표지 = II는 물(H⁺)을 못 퍼 올림 (뜻; NADH 불가로도 읽힘)
- 네모난 작은 양동이 사람 = FADH₂, I를 건너뛰고 II로 (모양)
- 해: 모름 (정상 상태의 대비로 추정)

**구역2 이동 전달체 Q·시토크롬 c와 복합체 III·IV**
- 레일 위 돌덩이 수레 = 유비퀴논 Q, I·II→III 운반, 막 속 이동 (자리·모양)
- 문 부스 + 팔 = 복합체 III, 펌프 (자리·동작)
- 레일 위 나무상자 수레 = 시토크롬 c, III→IV 운반 (자리)
- 문 부스 + 팔 = 복합체 IV, 펌프 (자리·동작)
- 펌프 팔은 I·III·IV 3개, II만 없음. 물줄기 크기 I≥III>IV (4·4·2?) (개수·약함)
- 레일 = 전자가 I·II→Q→III→c→IV 순서로 흐름 (뜻)
- 허리 굽혀 상자를 건네는 사람 = IV가 전자를 O₂에 넘김 (동작)

**구역3 O₂ — 최종 전자 수용체와 물 생성**
- 풍선 머리 사람 = O₂ (모양)
- 건네받은 상자 = 전자 (동작)
- 점선 화살표(마당 물웅덩이→가슴) = 기질의 H⁺가 O₂ 환원에 쓰임, O₂+4e⁻+4H⁺→2H₂O (뜻; 물방울 2개 = 2H₂O? 약함)
- 발치 물병 = 산물 H₂O (모양)

**구역4 화학삼투 — ATP 합성효소(복합체 V)**
- 바다 소용돌이 = 막간 공간 H⁺ 기울기(양성자 구동력)가 아치로 끌어당김 (모양)
- 돌 아치 + 물레방아 = 막에 박힌 ATP 합성효소 (자리)
- 물이 바퀴를 돌림 = H⁺ 흐름이 회전을 일으킴 (동작)
- 동전 쏟아짐 = ATP (뜻)
- 동전도 물도 담 앞 마당으로 떨어짐 = ATP는 기질 쪽 합성, H⁺는 기질로 복귀 (자리)

**구역5 전자전달 저해 — 시안화물·CO(복합체 IV 차단)**
- 해골 = 독 (모양·뜻)
- 흙손과 벽돌로 막은 문 = 전자 통로(IV→O₂) 차단 (동작)
- 자물쇠 = 단단한 결합·억제 (뜻)
- 회색 사람 3명이 상자 든 채 줄 섬 = 전자·전달체가 환원 상태로 정체 (개수)
- 6개 쌓여 넘치는 물통 탑 = NADH·FADH₂ 쌓임, NAD⁺ 고갈 (개수·약함)

**구역6 짝풀림제 — H⁺ 누출과 열**
- 악마 + 전동 드릴 = 짝풀림제(DNP·UCP1 계열) (뜻)
- 구멍 3개(둘은 뚫림, 하나는 작업 중) = 막에 생긴 누출 통로 (개수)
- 구멍에서 나온 물줄기 = H⁺가 합성효소를 우회해 샘 (동작)
- 불꽃 2곳과 김 2줄 = 에너지가 열로 (모양)
- 물줄기가 동전 없는 물받이로 = ATP는 안 만들어짐 (자리)

**구역7 ATP 합성효소 저해제 — 올리고마이신 계열**
- 꿀단지 든 사람 = F₀ 통로를 막는 저해제 (뜻)
- 꿀이 엉킨 바퀴 + 자물쇠 = 회전 정지 (모양)
- 바퀴 뒤 물이 가득, 뒤 바다에 거대한 물결 = H⁺ 기울기 축적 (자리)
- 넷째 팔이 큰 호를 그리며 계속 퍼 올림 = 펌프는 계속하다 결국 멈춤? (약함)

## ③ 잔결
- 뜻 모름: 늘어진 천 소매(양말 같음), 해, 물통 6개, 회색 3명, 바퀴살 8개, 점선 위 물방울 2개.
- 어색: 금지 표지 옆에서 양동이를 든 둘째 사람. 넷째 팔만 부스 없이 담 끝에서 솟음.
- 헷갈림: 돌↔상자의 Q·cyt c 짝은 자리로만 정함. 양동이가 NADH인지 H⁺인지. 해골이 CN⁻인지 CO인지. 꿀이 올리고마이신인지 ADP 부족인지. 넷째 팔이 짝풀림 과속인지 저해 후 기울기 폭증인지.
- 이음매: 뚜렷하지 않음(하늘·바다 연속). 해만 가는 선으로 납작해 얹은 듯.

## ④ 한 문장
전자가 I(·II)→Q→III→c→IV를 거쳐 O₂에서 물이 될 때 I·III·IV가 H⁺를 퍼 올려 만든 기울기가 ATP 합성효소를 돌려 ATP를 만들고, 전달계가 막히거나 합성효소가 막히거나 막이 새면 ATP는 줄고 열이나 정체만 남는다.
