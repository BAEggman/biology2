# 생판 1단계 (s32u01) — 그림만 보고 읽음

## ① 판 전체 표제어
- 1순위 **산화적 인산화: 미토콘드리아 전자전달계(복합체 I~IV)와 화학삼투 ATP 합성** — 85%
- 2순위 **화학삼투·양성자 구동력과 ATP 합성효소(F0F1)** — 10%
- 근거: 담=막, 바다=H+ 많은 쪽, 팔=펌프, 문 4개=복합체 4개, 물레방아→금화=ATP. 태양 때문에 광합성 명반응을 잠깐 의심했으나 O2 풍선·물병이 호흡 쪽이라 접음.

## ② 구역별 (주판 = 구역1~5, 우측 소판 3장 = 구역6~8)
**구역1 복합체 I: NADH 입구·H+ 펌프** (읽힌 3, 모름 1)
- 근육 팔이 구유로 담 너머 바다로 물을 퍼 올림 = 전자 흐름의 힘으로 H+를 역농도로 펌프(동작·자리).
- 둥근 문 + 둥근 양동이 든 사람 = NADH가 전자를 복합체 I에 건넴(모양 짝).
- 문 위 금지 표지(사각 양동이에 빗금) = 사각 통(FADH2)은 I로 못 들어감(모양, 확신 낮음).
- 태양(긴 살 8+짧은 살 8) = 모름(에너지?).

**구역2 복합체 II: FADH2 입구, 펌프 없음** (읽힌 2, 모름 1)
- 팔 없는 빈 셔츠 소매 = II는 H+를 안 퍼냄(4개 중 유일, 모양·뜻).
- 네모난 창 + 사각 양동이 든 사람 = FADH2가 II로(석신산 탈수소효소)(모양 짝).
- 하필 셔츠인 까닭(FAD?) 모름.

**구역3 이동 운반체 CoQ → 복합체 III** (읽힌 3)
- 선로 = 막 안 전자 이동로.
- 돌덩이 실은 수레 1대 = CoQ(유비퀴논)가 I·II의 전자를 III으로(자리: 2·3번 사이).
- 셋째 팔 = III도 펌프(팔 3 = I·III·IV).

**구역4 시토크롬 c → 복합체 IV → O2 → H2O** (읽힌 6)
- 나무 상자 실은 수레 1대 = 시토크롬 c가 III→IV로 전자 운반(자리: 3·4번 사이).
- 넷째 팔 = IV도 펌프(물줄기 굵기 I>III>IV, H+ 수 차이 암시?는 불확실).
- 4번 문에서 상자를 건네는 사람 = IV(시토크롬 c 산화효소)가 전자를 O2에 넘김.
- 풍선 머리 사람 = O2, 최종 전자 수용체(모양: 기체=풍선).
- 파란 점선 화살표 + 물방울 = O2가 전자·H+를 받아 물이 됨.
- 붉은 봉인 물병 1개 = 생성물 H2O(대사수). 봉인의 뜻은 모름.

**구역5 화학삼투: H+ 기울기 → ATP 합성효소 → ATP** (읽힌 5)
- 바다가 담 안쪽보다 높음 = 막사이공간 H+ 고농도(양성자 기울기).
- 소용돌이 1개 = H+가 한 통로(F0)로 빨려 듦.
- 아치 속 물레방아 = ATP 합성효소(F0F1), 흐름에 회전(살 약 8, 가려져 불확실).
- 물이 내리막으로 쏟아짐 = H+가 기울기 따라 수동으로 되돌아옴.
- 금화 더미(3~4줄기로 쏟아짐) = ATP.

**구역6 ATP 합성효소 억제(올리고마이신형)** (읽힌 4)
- 자물쇠 채운 물레방아 = 합성효소 차단.
- 항아리에서 쏟는 끈적한 황금 액체 = 억제제(약물)가 달라붙어 막음. 요리사 차림은 모름.
- 바다가 불룩 솟음 = H+ 기울기 과잉 축적.
- 물도 금화도 없음 = ATP 중단(전자전달도 곧 멈춤).

**구역7 탈공역(DNP·UCP1형): 열만 나고 ATP 없음** (읽힌 5)
- 악마가 드릴로 담에 구멍을 뚫음 = 막을 새게 하는 탈공역제/열생성 단백질.
- 구멍 3개에서 물이 샘 = H+가 합성효소를 거치지 않고 누출.
- 구멍마다 불꽃·김 = 에너지가 열로 방출(발열).
- 빈 쟁반 = ATP 없음.
- 팔이 진동선과 함께 계속 퍼냄 = 전자전달·O2 소비는 계속.

**구역8 복합체 IV 차단(시안화물·CO형): 사슬 정체·사망** (읽힌 6)
- 해골 인부가 벽돌·흙손으로 문을 막고 자물쇠+빗장 = IV 억제 독, 치사.
- 풍선머리(O2)가 문 앞에서 양손 벌림 = O2가 있어도 못 씀.
- 돌로 굳은 두 사람(상자) = 운반체가 전자 낀 채 정체.
- 쌓인 양동이 4개 = NADH 재산화 안 돼 쌓임.
- 굳은 팔 = 펌프 정지. 잔잔한 바다 = 기울기 소멸.

## ③ 뜻 모를 것 · 어색한 것 · 헷갈리는 것 · 이어 붙인 흔적
- 모름: 태양, 금지 표지 속 통의 모양, 붉은 봉인 물병, 셔츠.
- 헷갈림: 돌 수레와 상자 수레 중 어느 쪽이 CoQ인지(자리로만 추정), 점선 화살촉이 상자 쪽인지 웅덩이 쪽인지, 대머리 남자 셋이 닮음.
- 이어 붙인 흔적: 우측 소판 3장은 검은 테두리·크림 여백으로 분리, 하늘이 먹구름(주판은 맑음), 화질 결이 살짝 다름 = 별도 장면을 이어 붙임.

## ④ 한 문장
복합체 I·III·IV가 전자를 O2까지 흘리며 H+를 퍼 올려 만든 기울기가 물레방아(ATP 합성효소)를 돌려 금화(ATP)를 만드니, 합성효소 차단·탈공역·복합체 IV 차단은 이 흐름을 각각 다른 곳에서 망친다.
