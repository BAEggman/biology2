# 1단계 생판 (그림만 보고)

## ① 판 전체 표제어
- 1순위: **산화적 인산화 — 미토콘드리아 전자전달계와 화학삼투(양성자 기울기로 ATP 합성효소가 ATP 생산), 그리고 그 교란(ATP 합성효소 저해·탈공액·복합체 IV 독)** (90%)
- 2순위: **광합성 명반응의 광인산화(틸라코이드 전자전달 + 화학삼투)** (5%) — 해와 펌프·물레방아가 닮았으나, 해골·악마·풍선 O2 가 호흡 쪽을 가리킴.
- 큰 근거: 담장 = 막, 바다(높음) vs 모래(낮음) = 기울기, 칸 4개(팔 3 + 셔츠 1), 레일 위 수레 2, 풍선 = O2, 물레방아 + 금화 = ATP 합성효소 + ATP.

## ② 구역별 (왼쪽 → 오른쪽: 큰 판 5구역 + 오른쪽 작은 판 3개)
**구역1 복합체 I — NADH 입구(사슬의 첫 칸)** — 4개
- 팔이 나무 홈통 물을 담장 너머 바다로 끼얹음 = H+ 펌프, 모래(기질)→바다(막간) 거슬러 퍼올림 (모양·뜻)
- 물줄기가 굵음 = 많은 H+ (4개라는 건 추정) (개수)
- 둥근 구멍 + 둥근 물통을 안은 남자 = NADH 가 들어와 전자를 줌 (모양·자리)
- 앞선 남자 = 사슬의 맨 앞 (자리). 금지(양동이 X) 표지·해는 모름.

**구역2 복합체 II — FADH2 입구** — 3개
- 셔츠만 있고 팔(근육) 없음 = 이 복합체는 H+ 를 안 퍼올림 (모양·뜻)
- 네모 창 + 손잡이 달린 네모 물통 남자 = FADH2 가 여기로, 1번 팔을 건너뜀 (모양·자리)
- 두 번째 칸 = 복합체 II (자리)

**구역3 복합체 III + 돌공 수레** — 3개
- 팔 = H+ 펌프 (뜻)
- 돌공 수레 = 유비퀴논(CoQ), I·II 에서 III 로 전자를 나르는 이동 운반체 (자리·모양; 큐볼 소리 연상?)
- 레일 = 막 안에서 옆으로 움직임 (뜻)

**구역4 복합체 IV + 시토크롬 c + O2** — 7개
- 팔 = H+ 펌프, 물줄기 가늘음 = 적게(2개?) (개수 추정)
- 나무상자 수레 = 시토크롬 c, III→IV 이동 운반체 (자리)
- 문 안 남자 = 복합체 IV, 상자(전자)를 풍선에게 넘김 (동작)
- 풍선 머리 = O2, 사슬 맨 끝 최종 전자수용체 (모양·자리)
- 풍선 남자의 상자 = 전달된 전자
- 모래 웅덩이→상자로 가는 파선 화살표 = 기질 H+ 가 O2 환원에 소모 (뜻)
- 병의 물 = 생성물 H2O (모양)

**구역5 화학삼투 — ATP 합성효소** — 6개
- 바다가 모래보다 높음 = 막간공간 H+ 고농도·기울기 (자리)
- 벽돌 담장 = 내막, H+ 못 지나감 (뜻)
- 소용돌이 = H+ 가 기울기 따라 좁은 통로로 (모양)
- 아치 속 물레방아 = ATP 합성효소, 물이 돌림 (바퀴살 8개 뜻은 모름)
- 쏟아지는 금화 = ATP (모양)
- 모래로 쏟아진 물 = H+ 가 기질로 복귀 (자리)

**구역6 (오른쪽 위) ATP 합성효소 저해** — 4개
- 끈적한 노란 시럽 범벅(올리고당 시럽→올리고마이신? 소리 추정) = F0 를 막음
- 바퀴 자물쇠 = 회전 정지
- 담장 위로 부푼 큰 물결 = 기울기 과포화, 펌프도 멈춤
- 항아리 든 남자 = 억제제 주입자

**구역7 (오른쪽 가운데) 탈공액** — 5개
- 악마 + 전동드릴 = 탈공액제(DNP·UCP 류)
- 담장 구멍 3개 = H+ 가 ATP 합성효소를 건너뛰고 샘 (개수)
- 불꽃·김 = 열 발생
- 빈 쟁반 = ATP 없음
- 진동선 낀 팔이 계속 퍼올림 = 전자전달·O2 소비 지속

**구역8 (오른쪽 아래) 복합체 IV 차단 독** — 6개
- 해골 + 벽돌·흙손으로 문을 막고 자물쇠 = 시안화물·CO·아지드로 IV 봉쇄, 치명적
- 돌로 굳은 팔 = 펌핑 정지
- 돌이 된 남자 2명(상자) = 상류 운반체(CoQ·시토크롬 c)가 환원된 채 정체 (개수 2)
- 쌓인 양동이 4개 = NADH·FADH2 산화 못 되고 쌓임 (4의 뜻은 모름)
- 빈손의 풍선 신사 = O2 를 못 씀
- 잔잔한 바다 = 펌프 멈춤

## ③ 모름 · 어색 · 헷갈림 · 이은 흔적
- 모름: 금지 양동이 표지(추정: 손잡이 네모 통 FADH2 는 I 로 못 들어옴), 해(큰 판만 맑음, 작은 판은 흐림→정상 vs 이상), 바퀴살 8개, 병의 붉은 밀랍, 흰 구름·갈매기.
- 헷갈림: 돌공·상자 중 어느 쪽이 CoQ 인지(문 앞 자리로 판단), 문 안 남자가 상자를 주는지 받는지.
- 어색: 파선 화살표만 수채 그림과 달리 도해식 평면 선(나중에 덧댄 느낌), 풍선 머리.
- 이은 흔적: 큰 판 1개 + 작은 판 3개가 각자 검은 틀로 갈라져 있고 하늘도 맑음/흐림/먹구름으로 달라 따로 그려 붙인 판. 작은 판 1은 아치 둘레가 돌 덧댐 모양, 판 3의 풍선 인물은 조끼가 아닌 양복. 큰 판 안쪽 이음선은 못 찾음(틀 모서리의 어긋남은 큰 판과 작은 판 모두 같아 이음 증거 아님).

## ④ 한 문장
전자가 복합체 I→III→IV 를 따라 O2 로 내려오며 퍼올린 H+ 기울기가 물레방아(ATP 합성효소)를 돌려 ATP 를 찍어내고, 물레방아를 막거나·담장에 구멍을 내거나·마지막 문을 막으면 ATP 공장이 멈춘다.
