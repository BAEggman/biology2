# 2단계 (약속표로 다시 봄) — 달라진 곳은 ↻

## 판정
약속표로 **더 잘 풀린다.** 큰 줄거리(산화적 인산화)는 1단계도 맞았고, 약속표는 확정·정밀화를 했다: 모름이던 해·시럽·물 높이·소용돌이·금지 표지가 풀리고 사실 38→42개. 안 풀린 것은 억지로 안 끼웠다.

## ① 판 전체 표제어
- 1순위: **산화적 인산화 — 전자전달계 + 화학삼투(ATP 합성효소), 정상 조건 큰 장면 + 다른 조건 3칸(올리고마이신 · 짝풀림제 DNP · 시안화물/CO)** (97%) ↻ 90→97
- 2순위: **화학삼투·ATP 합성효소만의 판** (2%) ↻ 광합성(5%)은 버림: 밝은 방울 머리=O2, 해골 미장이, 도깨비+손드릴이 호흡을 못박음.

## ② 구역별 ([#]=약속표 번호)
**구역1 복합체 I — NADH 입구** — 5개 ↻
- 근육 팔+홈통 = H+ 펌프 (뜻 #108)
- 가득 찬 둥근 금속 양동이 = NADH ↻ 확정 (모양 #102)
- 이 짐이 거칠 팔 3개(I·III·IV) = H+ 많음 ↻ 새로 읽음 (개수 #108)
- 해 뜬 맑은 날 = 정상 조건 ↻ 모름→풀림 (#118)
- 금지 표지 ↻ 표지는 약속표에 없으나, 그림 속 양동이가 손잡이 달린 네모꼴 = FAD → 「FAD 는 I 로 못 들어감」(둥근 구멍은 둥근 양동이용). 확신 65%.

**구역2 복합체 II — FAD** — 3개
- 빈 셔츠 소매 = 펌프 없음 ↻ 확정 (#108)
- 네모 양동이 = FAD, 네모 창에 맞음 ↻ (#102)
- 거칠 팔 2개(III·IV)뿐 = NADH 보다 H+ 적음 ↻ (#108)

**구역3 복합체 III + 유비퀴논** — 4개 ↻
- 팔 = 펌프
- 레일 위 둥근 바위 = Q ↻ 확정 (#109). 큐볼 소리 연상은 철회
- 돌 = 비단백질 운반체 ↻ 새로 읽음 (#109)
- 건물에 안 붙고 레일을 구름 = 막을 떠다님 (#109)

**구역4 복합체 IV + 시토크롬 c + O2·H2O** — 7개
- 팔 = 펌프
- 상자 수레 = 시토크롬 c(단백질) ↻ 확정 (#109)
- 문 안 남자 = 복합체 IV가 상자를 넘김 (약속표 없음)
- 밝은 방울 머리 = O2 ↻ 확정 (#17)
- 그가 받은 상자 = 전달된 전자 (추정)
- 웅덩이→상자 파선 화살표 = 기질 H+ 소모 (약속표 없음, 추정)
- 붉은 밀랍 물병 = 완성된 H2O ↻ 확정 (#104)

**구역5 ATP 합성효소·화학삼투** — 6개
- 돌 아치 하나+물레방아 = ATP 합성효소 (#116)
- 소용돌이 = 물이 돌아올 길이 이 아치뿐 ↻ 풀림 (#116)
- 동전 수북 = ATP 많음 (#8)
- 담장 뒤 물 높이 = H+ 기울기 크기 ↻ (#117)
- 담장 = 막, 쏟아진 물이 모래로 = H+ 가 기질로 복귀 (#116)

**구역6 올리고마이신 날** — 4개
- 끈적한 금빛 시럽 = 올리고마이신 ↻ 추정→확정 (#103)
- 금색 자물쇠 = 막는 약 ↻ (#2)
- 치솟은 물결 = 기울기 최대 ↻ (#117)
- 항아리 든 남자 = 약 붓는 이 (약속표 없음)

**구역7 짝풀림제(DNP) 날** — 7개 ↻
- 도깨비+손드릴 = DNP (#106)
- 담장 구멍 = 짝풀림 (#116). 구멍 3개의 수는 모름
- 자물쇠 없음 = 구멍 내는 약 ↻ (#2)
- 진동선·두 줄 물보라 팔 = 더 빨리 도는 펌프 ↻ (#108)
- 빈 쟁반 = ATP 없음 (#8)
- 낮은 바다 = 기울기 작음 ↻ (#117)
- 불꽃·김 = 열 (약속표 없음)

**구역8 시안화물·CO 날** — 6개
- 해골 미장이+벽돌 봉한 문 = 시안화물·CO (#107)
- 금색 자물쇠 = 막는 약 (#2)
- 돌 팔 = 멈춘 펌프, 석상 2명 = 멈춘 전달자 (#105)
- 가득 찬 금속 양동이 4개 = NADH 쌓임 ↻ (FADH2 는 빠짐, #102)
- 빈손 O2 신사 = O2 못 씀 (#17)

## ③ 남은 모름 · 이은 흔적
- 여전히 모름(약속표에 없음): 파선 화살표, 문 안 남자, 바퀴살 8·구멍 3·양동이 4·석상 2의 수, 불꽃·김, 항아리 든 남자, 판 1 아치의 돌 덧댐.
- ↻ 틀선 칸은 이은 흔적이 아니라 「같은 장면의 다른 날」 약속(#118). 판 3 인물의 양복은 그림 차이로 남음.
- ↻ 정정: 큐볼 연상 철회, 쌓인 양동이는 NADH 뿐, 2순위 광합성 폐기. 쟁반은 큰 장면(수북)과 판 2(빔)에만 있고 판 1·3 에는 안 보임 — ATP 없음의 생략으로 추정(약속표 없음).
- 약속표에 없어 끼우지 않은 것: 금지 표지 자체, 파선 화살표, 문 안 남자, 불꽃·김, 구름·갈매기 흔적.

## ④ 한 문장 ↻
맑은 날엔 NADH(팔 3개)·FAD(팔 2개)의 전자가 Q·시토크롬 c 를 타고 O2 로 내려가며 퍼올린 H+ 가 돌 아치 물레방아로만 돌아오며 동전(ATP)을 찍고, 올리고마이신은 물레방아를 잠그고 DNP 는 담장에 구멍을 내며 시안화물은 마지막 문을 막는다.
