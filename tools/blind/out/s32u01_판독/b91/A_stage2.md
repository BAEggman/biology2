# 2단계 약속 적용 (s32u01) — ↻ 달라지거나 새로 읽힘 · ＝ 1단계와 같고 약속이 뒷받침 · [번호] 약속표 줄

## ① 판 전체 표제어
- 1순위 **산화적 인산화: 전자전달계·화학삼투(ATP 합성효소)·저해제·짝풀림제** — 97% ↻(85→97)
- 2순위 **화학삼투·양성자 구동력과 ATP 합성효소** — 3% ↻(10→3)
- 판정: 약속표로 더 잘 풀림. 줄거리는 1단계가 이미 맞았고(＝ 다수), 「모름」 6개가 풀리고, 팔 개수=H+ 양·물 높이=기울기·구멍/자물쇠 구분이 새로 읽힘.

## ② 구역별 (주판 구역1~5, 틀선 소판 구역6~8)
**구역1 복합체 I: NADH 입구·펌프** (읽힌 5)
- ＝ 지붕에서 솟은 근육 팔이 홈통으로 담장 너머로 물을 퍼 넘김 = H+ 펌프[108].
- ＝ 가득 찬 둥근 금속 양동이 = NADH[102].
- ↻ 해 뜬 맑은 하늘 = 정상 조건[118] (1단계 모름).
- ＝ 금지 표지의 네모 양동이 = FAD는 I에 안 들어감(표 밖 표지, [102]+빗금 해석, 확신 중간).
- ↻ NADH 짐이 거치는 팔 3개(I·III·IV) = H+ 많이[108] (1단계 못 봄).

**구역2 복합체 II: FAD 입구·펌프 없음** (읽힌 3)
- ↻ 빈 셔츠 소매 = 그냥 「펌프 없음」[108] (1단계 「셔츠=FAD?」 의문 해소).
- ＝ 네모 양동이 든 사람·네모 창 = FAD(FADH2)[102].
- ↻ FAD 짐은 팔 2개(III·IV)만 거침 = NADH보다 H+·ATP 적음[108].

**구역3 유비퀴논 Q → 복합체 III** (읽힌 3)
- ↻ 레일 수레의 둥근 바위 = Q, 비단백질이며 건물에 안 붙고 막을 구름[109] (1단계는 자리만으로 읽음).
- ＝ 선로 = 운반체의 길(표 밖, 왕복 궤도 아님).
- ＝ 셋째 팔 = III 펌프.

**구역4 시토크롬 c → 복합체 IV → O2 → 물** (읽힌 6)
- ↻ 상자 수레 = cyt c, 단백질이라 바위와 갈림[109] (1단계는 자리만).
- ＝ 넷째 팔 = IV 펌프(펌프 팔 3 = I·III·IV).
- ＝ 머리가 밝은 방울인 사람 = O2[17] (풍선=밝은 방울).
- ＝ 문에서 상자를 건네는 사람 = IV가 전자를 O2에 넘김(표 밖).
- ＝ 점선 화살표·물방울 = H+가 전자와 함께 O2에 합류(표 밖, 방향 불확실).
- ↻ 붉은 밀랍 물병 = 완성된 물[104] (1단계 「봉인 모름」 해소).

**구역5 화학삼투: 기울기·ATP 합성효소·ATP** (읽힌 5)
- ＝ 담장 밑동의 돌 아치 하나 + 물레방아 = ATP 합성효소[116].
- ↻ 소용돌이 = 돌아올 길이 아치뿐이라 휘감겨 듦[116] (1단계는 「F0 입구」 추정).
- ＝ 담장 뒤 물 높이 = H+ 기울기 크기[117].
- ＝ 금 동전 = ATP[8].
- ＝ 물이 내리막으로 돌아옴 = H+ 수동 이동.

**구역6 소판1 올리고마이신** (읽힌 5)
- ↻ 끈적한 금빛 시럽 = 올리고마이신[103] (1단계 「억제제」).
- ＝ 금색 자물쇠 = 막는 약·독[2], 물레방아가 잠김.
- ＝ 바다가 불룩 = 기울기 최대[117].
- ＝ 물도 동전도 없음 = ATP 0.
- ↻ 틀선 칸 = 같은 장면의 다른 날[118] (1단계 「이어 붙임」 정정). 항아리·요리사는 표 밖.

**구역7 소판2 짝풀림제 DNP** (읽힌 6)
- ↻ 붉은 작은 도깨비 + 손드릴 = DNP[106] (1단계 「UCP1형」 추정 → DNP).
- ↻ 담장의 다른 구멍 3개 = 짝풀림제[116], 자물쇠 없음[2] (구멍/자물쇠 구분).
- ＝ 구멍마다 불꽃·김 = 열(표 밖).
- ＝ 빈 쟁반 = ATP 없음.
- ↻ 진동선 달고 힘껏 퍼 넘기는 팔 = 더 빨리 도는 펌프[108].
- ↻ 바다가 소판1·3보다 낮음 = 기울기 작음[117] (1단계 못 봄, 원근 탓에 확신 중간).

**구역8 소판3 시안화물·CO** (읽힌 7)
- ＝ 해골 미장이(흙손·벽돌로 봉한 문간) = 시안화물·CO[107].
- ＝ 금색 자물쇠·빗장 = 막는 독[2].
- ＝ 석상 사람 2(상자) = 환원된 채 멈춘 전달자[105].
- ＝ 굳은 팔 = 멈춘 펌프[105].
- ＝ 밝은 방울 사람이 양손 벌림 = O2 있어도 못 씀.
- ＝ 쌓인 가득 찬 금속 양동이 4개 = NADH 쌓임[102].
- ↻ 잔잔한 바다 = 퍼 올림 없음(높이는 정상급이라 기울기 신호 약함)[117].

## ③ 풀림 · 아직 모름 · 끼우지 않은 것
- 풀림: 태양(정상 조건), 셔츠, 물병 봉인, 돌·상자 수레의 짝, 소용돌이, 우측 3칸 = 이어 붙임이 아니라 「다른 날」 틀선[118].
- 아직 모름(표 밖): 금지 표지, 점선 방향, 항아리·요리사, 태양 살 16개, 둥근 문·네모 창, 불꽃·김.
- 끼우지 않음: 모래 잔돌(자갈 아님), 단추 없는 조끼(CD4·CD8 아님), 담장 붙은 벽돌 부스(간 아님), 붉은 밀랍(코르크 아님).

## ④ 한 문장
맑은 날에는 NADH(팔 3개)·FAD(팔 2개)의 전자가 펌프를 거쳐 O2에 닿아 물이 되고 담장 뒤에 쌓인 H+가 돌 아치 물레방아로만 돌아오며 동전(ATP)을 쏟지만, 다른 날에는 올리고마이신이 물레방아를 잠가 물만 쌓고, DNP가 담장에 구멍을 내 열만 내며, 시안화물이 IV의 문을 봉해 모두를 돌로 굳힌다.
