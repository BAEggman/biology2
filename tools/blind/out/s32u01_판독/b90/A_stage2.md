# stage2 — 약속표 어휘로 다시 읽기 (s32u01)

## 판정
약속표로 **더 잘 풀린다.** 모름→확 2건(해·물병), 추→확 10건, 새로 4건. 확→추 2건(허리 숙인 일꾼·상자 받음), 철회 3건(분사 굵기 4:4:2 · UCP1 · 「이어 붙인 흔적」). 약속에 없는 물건은 끼우지 않고 ③에 모았다.

## ① 판 전체 표제어
- 1순위 **산화적 인산화 — 전자전달계(I~IV)·화학삼투·ATP 합성효소와 그 이상 조건(억제제·짝풀림제)** (96%) ↻ 88→96
- 2순위 **화학삼투와 ATP 합성효소(양성자 기울기)** (3%) ↻ 8→3
- 근거: 양동이 둘(102)·바위/상자 수레(109)·밝은 방울 사람(17)·팔과 빈 소매(108)·아치+물레방아(116)·수위(117)·틀선 칸(118)이 한 장에서 맞물린다. 본판=정상의 날, 틀 세 칸=다른 날.

## ② 구역별 (확/추 · ↻=1단계와 달라짐)

**구역1 정상의 날 — 복합체 I·II와 전자 투입** (본판 왼쪽, 8개)
1. ↻ 해 뜬 맑은 날 = 정상 조건, 틀 밖 큰 장면 (118) 모름→확
2. 담장에 붙은 작은 벽돌 집 4채 = 복합체 I–IV (93: 간 아님) 확
3. 가득 찬 금속 양동이 → 둥근 구멍 = NADH → I (102) 확
4. 가득 찬 네모 양동이 → 네모 창 = FAD(H₂) → II (102) 확
5. 1번 위 금지 표지(네모 양동이 ✕) = I은 FAD 불가 — 약속 밖, 네모=FAD로 읽음 추
6. 지붕에서 솟아 홈통으로 물을 담장 너머로 붓는 팔 = H⁺ 펌프 (108) 확
7. 2번의 빈 셔츠 소매 = 펌프 없음 (108) 확
8. ↻ 짐이 거치는 팔 수: NADH 3(I·III·IV) > FAD 2(III·IV) = H⁺ 양·ATP 수율 차 (108) 새로 확

**구역2 이동 운반체와 III·IV** (본판 가운데, 6개)
1. ↻ 레일 수레의 둥근 바위 = 유비퀴논 Q — 집에 안 붙고 구른다 (109) 추→확
2. ↻ 레일 상자 수레 = 시토크롬 c (109) 추→확
3. ↻ 구르는 수레 = 복합체에 안 붙은 이동성 운반체 (109) 추→확
4. ↻ 3번 팔 = III의 H⁺ 펌프 (108) 확 — 분사 굵기로 4개 읽던 것 철회
5. ↻ 4번 팔 = IV의 H⁺ 펌프 (108) 확 — 2개 읽던 것 철회
6. ↻ 허리 숙인 일꾼이 풍선머리와 상자를 주고받음 = IV→O₂ 전자 인계 — 약속 밖 확→추

**구역3 산소와 완성된 물** (본판 가운데-오른쪽, 4개)
1. 머리가 통째로 밝은 방울인 사람 = O₂ (17) 확
2. ↻ 상자를 안음 = 사슬 끝에서 전자를 받음 — 약속 밖 확→추
3. ↻ 점선 화살+물방울 2 = O₂+4e⁻+4H⁺→2H₂O (개수는 약속 밖) 추
4. ↻ 붉은 밀랍으로 봉한 물병 = 완성된 물 H₂O (104) 모름→확

**구역4 H⁺ 기울기와 ATP 합성효소** (본판 오른쪽, 5개)
1. 담장=막, 담장 뒤 물 높이 = H⁺ 기울기 크기, 정상 수위 (117) 확
2. 담장 밑동 돌 아치 하나 + 물레방아 = ATP 합성효소, 물(H⁺)이 아치를 지나며 바퀴를 돌린다 (116) 확
3. ↻ 아치 뒤 소용돌이 = 돌아오는 길이 이 아치뿐이라 (116) 추→확
4. ↻ 담장에 다른 구멍 없음 = 정상, 짝풀림 아님 (116) 새로 확
5. 둥근 금화 더미 = ATP (8·101) 확

**구역5 합성효소 억제 — 올리고마이신** (우상 틀, 5개)
1. 바퀴 중심의 금색 자물쇠 = 막는 약·독 (2) 확
2. ↻ 항아리로 붓는 끈적한 금빛 시럽 = 올리고마이신 (103) 추→확
3. 동전 없음 = ATP 합성 0 확
4. ↻ 담장 뒤 물이 큰 파도로 솟음 = 기울기가 커짐 (117) 추→확
5. ↻ 소용돌이 없음 = 아치 길이 막혀 H⁺ 못 돌아옴 새로 추

**구역6 짝풀림 — DNP** (우중 틀, 7개)
1. ↻ 붉은 작은 도깨비 + 손드릴 = 짝풀림제 DNP (106) 확 (UCP1 철회)
2. 담장의 다른 구멍 3개 = 합성효소를 거치지 않는 H⁺ 누출 (116) 확
3. ↻ 자물쇠 없음 = 막는 약이 아니라 구멍 내는 약 (2) 새로 확
4. 구멍의 불꽃·김 = 열 발생 (약속 밖, 그림 그대로) 확
5. 빈 쟁반 = 동전(ATP) 없음 확
6. ↻ 속도선 그린 힘껏 퍼 넘기는 팔 = 더 빨리 도는 펌프 (108) 추→확
7. ↻ 낮은 수위 = 기울기 작음 (117) 추→확

**구역7 전자전달 억제 — 시안화물·CO** (우하 틀, 5개)
1. 해골 미장이(흙손·벽돌로 봉한 문) + 금색 자물쇠 = 시안화물·CO, IV 차단 (107·2) 확
2. ↻ 돌로 굳은 석상 2명(상자 안음) = 멈춘 전달자, 환원된 채 정체 (105) 추→확
3. 돌로 굳은 근육 팔 = 멈춘 펌프 (105) 확
4. ↻ 쌓인 가득 찬 금속 양동이 = NADH가 쌓임 (102) 추→확 (개수 4는 모름)
5. 밝은 방울 사람이 손만 벌림 = O₂ 있어도 못 씀 확

## ③ 잔결
- 약속 밖이라 그대로 둠: 금지 표지, 불꽃·김, 허리 숙인 일꾼, 물방울 2·구멍 3·양동이 4·햇살 16줄의 개수, 두 상자 모양 차이, 칸 없는 민 쟁반(「모듈 쟁반」에 안 끼움), 분사 굵기 차.
- 해당 없어 안 끼움: 붉은 벽돌 건물=간(93)은 담장에 붙은 집이라, 자갈=Ca²⁺(4)는 큰 바위라서.
- ↻ 「이어 붙인 흔적」 철회: 틀선 세 칸은 다른 날(118), 본판 안쪽엔 이음매 없음.
- 남은 헷갈림: 우하 바다 수위가 정상과 같아 117로는 읽을 것이 없다.

## ④ 한 문장
정상의 날엔 NADH·FAD의 짐이 팔(I·III·IV, II는 빈 소매)을 거치며 H⁺를 담장 너머로 퍼 올리고(NADH가 팔 3개로 더 많이), 쌓인 높이가 아치 하나의 물레방아(ATP 합성효소)로만 돌아오며 금화(ATP)를 쏟고 O₂가 마지막 짐을 받아 완성된 물이 되며, 다른 날엔 올리고마이신·시안화물이 길을 막고 DNP는 담장에 구멍을 내 ATP 대신 열만 낸다.
