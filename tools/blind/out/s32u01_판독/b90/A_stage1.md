# stage1 — 생판 (s32u01, 그림만 보고)

## ① 판 전체 표제어
- 1순위 **산화적 인산화 — 전자전달계(복합체 I~IV)와 화학삼투에 의한 ATP 합성** (88%)
- 2순위 **화학삼투: 양성자 기울기와 ATP 합성효소(억제제·짝풀림제 포함)** (8%)
- 근거: 벽 하나를 사이에 둔 바다(높은 쪽)와 작업장, 물을 퍼 올리는 팔 3개 + 빈 소매 1개, 물레방아→금화, 오른쪽 세 컷은 "고장 사례". 글자는 전혀 없음. 호흡 쪽이라 본 단서는 둥근 통/네모 통 두 종류와 II의 빈 소매.

## ② 구역별 (확=근거 분명 / 추=추정)

**구역1 복합체 I·II — NADH·FADH2 투입, 펌프 유무** (본판 왼쪽, 6개)
1. 부스 4칸이 한 줄 = 복합체 I–IV 사슬 (개수·자리) 확
2. 둥근 양동이→둥근 구멍 = NADH→I (모양 맞춤) 확
3. 네모 물통→네모 창 = FADH2→II (모양 맞춤) 확
4. 1번 부스 위 금지 표지(네모 통에 ✕) = I은 NADH 전용, FADH2 불가 (뜻) 추
5. 근육 팔이 물을 퍼 벽 너머 바다에 붓는다 = I이 H+을 기울기 거슬러 막간공간으로 능동 펌프 (동작) 확
6. 2번 부스는 팔 없는 빈 셔츠 = II는 H+ 펌프 안 함 (개수 0) 확

**구역2 이동 운반체(Q·cyt c)와 III·IV** (본판 가운데, 6개)
1. 수레 위 둥근 돌 = 유비퀴논(CoQ), I·II→III (자리 2·3번 사이, 모양 Q볼·단단) 추
2. 수레 위 나무 상자 = 시토크롬 c, III→IV (자리 3·4번 사이, 소리 c=crate) 추
3. 레일·수레 = 막을 따라 오가는 이동성 운반체 (뜻) 추
4. 3번 팔 = III의 H+ 펌프 (분사 굵기 I>III>IV, III은 4개 추정) 확
5. 4번 팔 = IV의 H+ 펌프 (분사 가장 가늚, 2개 추정) 확
6. 4번 문에서 허리 숙인 일꾼이 상자를 풍선머리와 주고받음 = IV→O2 전자 인계 (동작) 확

**구역3 산소와 물 생성** (본판 가운데-오른쪽, 3개)
1. 풍선 머리 = O2(기체), 사슬 맨 끝 = 최종 전자수용체 (모양·자리) 확
2. 상자를 안은 풍선머리 = 전자를 받음 확
3. 물웅덩이→풍선머리 점선 화살 + 물방울 2개 = O2+4e⁻+4H⁺→2H2O (개수 2) 확
- 밀랍 봉인 병 속 물 = 「모름」 (산물 H2O 정도로만 짐작)

**구역4 양성자 기울기와 ATP 합성효소** (본판 오른쪽, 5개)
1. 벽 = 내막(H+ 불투과), 벽 너머 높은 바다 = 막간공간 H+ 고농도 (자리) 확
2. 바다의 소용돌이 = 양성자 구동력이 한 곳(아치)으로 쏠림 추
3. 아치 속 물레방아 = ATP 합성효소(F0F1), 물이 돌린다 (모양) 확
4. 물이 높은 곳→낮은 곳으로 흘러내림 = H+이 농도 기울기 따라 합성효소로 기질에 복귀 (뜻) 확
5. 쏟아져 쌓이는 금화 = ATP (에너지 화폐) 확

**구역5 ATP 합성효소 억제 (올리고마이신형)** (우상, 4개)
1. 바퀴 중심 자물쇠 + 끈적한 꿀 = F0 통로·회전 차단 확
2. 동전 없음 = ATP 합성 0 확
3. 벽 위로 솟은 큰 파도 = 막간 H+ 과축적 → 전자전달 정체(호흡 조절) 추
4. 항아리 붓는 아저씨 = 외부 억제제 투여 (약 이름은 모름, 올리고마이신 추정) 추

**구역6 짝풀림 (DNP·UCP1형)** (우중, 6개)
1. 악마 + 전동 드릴 = 짝풀림제, 막에 인위적 구멍 확
2. 벽에 구멍 3개에서 물이 샘 = 합성효소를 거치지 않는 H+ 누출 (개수 3) 확
3. 구멍의 불꽃·김 = 에너지가 열로 방출(체온↑, 갈색지방) 확
4. 빈 쟁반 = ATP 합성 감소 확
5. 팔은 속도선까지 그리며 계속 퍼 올림 = 전자전달·O2 소비 지속·증가 추
6. 먹구름·낮은 수위 = 기울기 소실 추

**구역7 전자전달 억제 (복합체 IV, CN⁻·CO형)** (우하, 5개)
1. 해골 석공(벽돌·흙손)이 4번 문을 벽돌+자물쇠로 봉함 = IV 차단 독물(시안화물·CO), 치명적 확
2. 돌로 굳은 사람 2명·상자 2개 = 상류 운반체 정체(환원형) 추
3. 쌓인 양동이 4개 = NADH 축적 추
4. 돌로 굳은 팔 = 펌프 정지 → 기울기·ATP 없음 확
5. 정장 풍선머리가 손만 벌림 = O2가 있어도 못 씀 확

## ③ 잔결
- 뜻 모를 것: 해(햇살 16줄: 긴 8+짧은 8, 맑은 상태 표지 정도) / 밀랍 병 속 물 / 쟁반(ADP+Pi 자리?) / 바퀴살 8·금화 수 / 양동이 4
- 어색: 벽을 뚫고 솟은 팔, 머리 없는 셔츠, 풍선 머리, 같은 O2 사람이 우하 컷에서는 정장, 수레 위 상자(X 버팀)와 풍선머리가 든 상자(걸쇠)의 생김새가 다름
- 헷갈림: 돌↔상자 중 어느 쪽이 Q·cyt c인지(순서로만 판정), 팔 둘 중 III·IV 구분(분사 굵기뿐), 금지 표지가 "네모 통만" 금지인지 "통 전부" 금지인지, 우하 양동이 4의 뜻, 병이 O2 쪽인지 물 쪽인지
- 이어 붙인 흔적: 본판 1 + 우측 3컷의 4컷 콜라주(검은 테두리·흰 안쪽 여백). 우측 컷은 본판 소품(벽·부스·팔·쟁반·물레방아·풍선머리)을 재사용. 본판은 맑은 하늘+해, 우측은 먹구름·회색 하늘(정상 대 이상). 본판 안쪽은 이음매 없음.

## ④ 한 문장
벽(내막) 양쪽의 양성자 기울기를 전자전달계의 팔(I·III·IV는 펌프, II는 아님)이 만들고, 그 기울기가 물레방아(ATP 합성효소)를 돌려 금화(ATP)를 만들며 산소가 마지막 전자를 받아 물이 되고, 합성효소나 IV를 막으면 멈추고 막에 구멍(짝풀림)을 내면 ATP 대신 열만 난다.
