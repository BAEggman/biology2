# stage2 — 약속표로 다시 읽기 (s32u01)

## ① 판 전체의 표제어
- 1순위 **산화적 인산화 — 전자전달계 + 화학삼투 ATP 합성(+ 억제제·짝풀림제)** : 96% ↻(90→96)
- 2순위 **화학삼투(양성자 기울기와 ATP 합성효소)** : 3% ↻(6→3)
- 판정: 약속 102~108·2·8이 이 판의 어휘와 그대로 맞는다. 1단계 읽기는 뒤집히지 않고 「추정」이 「확정」으로 올라갔으며, 모름이던 병·석상·양동이 탑·큰 팔이 풀렸다. 약속이 도운 곳은 구역1·2·5·7·8·9, 도움이 없던 곳은 구역3(수레)·6(물레방아)·소용돌이·해. 틀: 담장 = 내막, 담장 뒤 바다 = 막간 공간, 앞마당 = 기질.

## ② 구역별 (↻ = 1단계와 달라짐)
**구역1 복합체 I — NADH 입구** (4)
- 첫 건물·둥근 구멍 = 복합체 I
- ↻ 둥근 금속 양동이 가득 = NADH (102), 든 남자가 전자 공급
- 지붕의 근육 팔이 물을 담장 너머로 = H+ 펌프 (108 확정)
- ↻ 금지 표지의 네모 양동이 = FAD (102)는 복합체 I로 못 들어감

**구역2 복합체 II — FAD 입구** (3)
- 둘째 건물·네모 창 = 복합체 II
- ↻ 네모 양동이 가득 = FADH2 (102)
- ↻ 빈 셔츠 소매 = 펌프 없음 (108 확정)

**구역3 복합체 III + 이동 전달체** (4)
- 셋째 건물의 팔 = H+ 펌프
- 돌덩이 수레(I·II→III) = CoQ, 상자 수레(III→IV) = 시토크롬 c — 약속표에 없어 자리로만 읽음(상자는 crate~c 소리 연상, 추정)
- 수레 2대 = 이동 전달체 2종

**구역4 복합체 IV** (3)
- 넷째 건물의 팔 = H+ 펌프
- 문간 남자가 상자를 풍선머리에게 건넴 = 전자를 O2로
- 팔 3 + 빈 소매 1 = I·III·IV만 펌프

**구역5 산소 → 물** (5)
- 풍선머리 = O2 (밝은 방울 17과 같은 계열 같으나 풍선 머리는 약속표 밖)
- 상자를 받음 = 전자
- ↻ 물방울 2개 = H+ 2개로 고침 (화살이 기질 웅덩이에서 옴; 1단계는 H2O)
- 점선 화살 = 기질 H+ 소모
- ↻ 붉은 밀랍 병 = 완성된 물 H2O (104) — 모름 해소

**구역6 ATP 합성효소** (5)
- 소용돌이 = H+가 기울기 따라 내려감
- 담장 아치의 물레방아 = ATP 합성효소 (약속표 없음, 모양)
- 물이 바다→앞마당 = 막간→기질
- 둥근 금화 = ATP (8; 회색 네모 칩 = GTP 101과 다름)
- 금화 더미 = ATP 대량

**구역7 시안화물·CO** (4)
- ↻ 해골 미장이(흙손·벽돌·봉한 문간) = 시안화물·CO (107)
- ↻ 금색 자물쇠 = 막는 독 (2) → 전자 통로 차단
- ↻ 석상 3 = 멈춰 선 전달자, 환원된 채 정체 (105)
- ↻ 가득 찬 양동이 탑 6 = NADH 적체 (102)

**구역8 짝풀림제** (6)
- ↻ 붉은 도깨비 + 손드릴 = DNP (106)
- 구멍 3 = H+ 누수
- ↻ 자물쇠 없음 = 막는 약이 아니라 구멍 내는 약 (2)
- 불꽃·김 = 열
- 구멍 물줄기→쟁반 = ATP 합성효소 우회
- 쟁반에 금화 없음 = ATP 안 만듦

**구역9 올리고마이신** (4)
- ↻ 올리고당 시럽 = 올리고마이신 (103; 꿀/기름 혼동 해소)
- 바퀴 축 금색 자물쇠 = 막는 약, 회전 정지
- 바퀴 뒤 가득 찬 물 = H+ 쌓임
- ↻ 큰 팔 = H+ 펌프 (108). 큰 파도·먹구름은 기울기 과다로 추정, 올리고마이신인지 짝풀림(호흡 증가)인지 구분 못함

## ③ 모름·어색함·겹침·이어 붙임
- 여전히 모름: 해(광선 16), 먹구름·큰 파도, 소용돌이 세부, 물 쟁반, 레일, 표지판 자리.
- 약속과 겹쳐 조심: 붉은 벽돌 건물(93 = 간)이 복합체 4채·담장과 겹침 — 간 맥락이 없어 간으로 안 읽음(약속을 외운 독자는 걸릴 수 있음). 돌덩이(4 자갈 = Ca2+), 레일(6 왕복 궤도), 궤짝(48 = 사과·오이·공 든 것만), 흙손(3 칼), 쟁반(22 모듈 쟁반), 자물쇠 색·열쇠구멍(74 = s10p02 전용)도 이 판 맥락이 달라 약속으로 안 읽음.
- 잘 짜인 곳: 자물쇠 있음(시안화물·올리고마이신 = 막는 약) 대 없음(구멍 = DNP)이 한눈에 갈리고, 약 이름은 해골·시럽·도깨비가 따로 알려 준다.
- 이어 붙인 흔적: 풍선머리 남자·상자·병 둘레 흰 후광, 점선 화살·물방울의 평면 벡터풍, 오른쪽 벽돌→돌벽 경계(변함 없음).

## ④ 한 문장
금속 양동이(NADH·FAD)의 전자가 복합체 I·II로 들어가 I·III·IV의 근육 팔이 H+를 담장 너머로 퍼 올려 만든 기울기가 물레방아를 돌려 동전(ATP)을 쏟고 전자는 끝에서 O2와 H+를 만나 물병(H2O)이 되며, 해골 미장이(시안화물)·올리고당 시럽(올리고마이신)은 자물쇠로 길을 잠그고 도깨비 드릴(DNP)은 자물쇠 없이 구멍을 뚫어 동전 대신 열을 낸다.
