# stage1 — 생판 (s32u01, 그림만 보고)

## ① 판 전체의 표제어
- 1순위 **산화적 인산화 — 전자전달계 + 화학삼투 ATP 합성(+ 억제제·짝풀림제)** : 90%
- 2순위 **화학삼투(양성자 기울기와 ATP 합성효소)** : 6%
- 읽는 틀: 벽 = 미토콘드리아 내막, 벽 뒤 바다 = 막간 공간(H+ 높음), 앞마당 = 기질. 왼쪽 맑은 해 = 정상 호흡, 오른쪽 먹구름 = 독·짝풀림 상태로 보임.

## ② 구역별 (왼쪽부터)
**구역1 복합체 I — NADH 입구** (4)
- 첫 건물·둥근 구멍 = 복합체 I (자리: 첫째, 모양: 둥근 입구)
- 둥근 양동이 든 남자 = NADH가 전자를 건넴 (양동이가 구멍과 같은 모양)
- 건물 위 근육 팔이 벽 너머 바다로 물을 쏟음 = H+ 펌프, 기질→막간 (동작; 물줄기가 셋 중 가장 굵어 H+ 수가 많다는 뜻일 수 있음, 추정)
- 금지 표지(네모 양동이에 X) = FADH2는 복합체 I로 못 들어감 (뜻)

**구역2 복합체 II — FADH2 입구** (3)
- 둘째 건물·네모 창 = 복합체 II
- 네모 양동이 든 남자 = FADH2가 전자를 건넴 (모양)
- 팔 대신 축 늘어진 헝겊 소매 = 복합체 II는 H+를 펌프하지 않음 (모양·뜻)

**구역3 복합체 III + 이동 전달체** (4)
- 셋째 건물의 팔 = 복합체 III도 H+ 펌프
- 돌덩이 실은 수레(I·II→III 구간) = CoQ(유비퀴논)
- 상자 실은 수레(III→IV 구간) = 시토크롬 c
- 수레 2대 = 이동성 전달체 2종 (개수)

**구역4 복합체 IV** (3)
- 넷째 건물의 팔 = 복합체 IV도 H+ 펌프 (물줄기가 가장 가늘어 보임, 추정)
- 문간 푸른 셔츠 남자가 상자를 풍선머리에게 건넴 = 전자를 O2로 넘김 (동작)
- 펌프 팔 3 + 소매 1 = I·III·IV만 펌프, II는 아님 (개수)

**구역5 산소 → 물** (4, 병은 모름)
- 얼굴 없는 풍선머리 = O2, 최종 전자 수용체 (모양: 기체=풍선)
- 상자를 받아 안음 = 전자를 받음
- 물방울 2개 = 산물 H2O (개수)
- 점선 화살(바닥 물웅덩이→가슴) = 기질의 H+가 물 만드는 데 쓰임
- 붉은 밀랍 병 = 모름

**구역6 ATP 합성효소** (5)
- 바다의 소용돌이 = 기울기를 따라 H+가 막을 통해 흘러내림 (모양)
- 벽 아치에 박힌 물레방아 = ATP 합성효소(F0 회전·F1 촉매) (모양·뜻)
- 물이 바다→앞마당으로 쏟아져 바퀴가 돎 = 양성자 구동력, 막간→기질 (방향)
- 쏟아지는 금화 = ATP (돈 = 에너지 화폐)
- 쟁반 가득한 금화 더미 = ATP 대량 생성 (개수는 못 셈)

**구역7 복합체 IV 억제 독 (시안화물·CO류)** (4)
- 해골 = 치명적 독 (뜻)
- 벽돌로 막고 자물쇠 채운 문, 흙손·벽돌 든 해골 = 전자 통로 완전 차단
- 회색 사람 3명이 상자 든 채 줄섬 = 전자 정체
- 넘치는 양동이 탑(6개) = NADH 등 환원형 운반체 적체 (추정)

**구역8 짝풀림제** (5)
- 붉은 악마 + 전동 드릴 = 짝풀림제(DNP류), 일부러 구멍 뚫음
- 벽 구멍 3개 = 막의 H+ 누수 경로
- 불꽃·김 = 열 발생
- 구멍 물줄기가 쟁반으로 = ATP 합성효소 우회, 기울기 소실
- 쟁반엔 물뿐 금화 없음 = ATP는 안 만들어짐

**구역9 ATP 합성효소 억제 (올리고마이신)** (3)
- 앞치마 남자가 항아리의 황금 점액을 바퀴에 부음 = 올리고마이신 (소리 '올리고' 연상, 추정)
- 바퀴 축의 자물쇠, 엉겨 붙은 점액, 바퀴 뒤에 가득 찬 어두운 물 = 회전 정지, ATP 합성 중단, H+가 못 빠져 쌓임
- 큰 팔·솟은 파도·먹구름 = 막힌 뒤 기울기 과다 (추정)

## ③ 뜻 모를 것 · 어색한 것 · 이어 붙인 흔적
- 모름: 병(붉은 밀랍, 맑은 액체 — 대사수? 독?), 해(광선 16개, 왜 해인지), 양동이 탑 6의 정확한 뜻, 회색 인물 3(왜 회색), 오른쪽 큰 팔이 4번째 펌프인지, 두 번째 물 쟁반, 레일 자체(막 속 이동 길로 읽었으나 근거 약함), 펌프 팔 물줄기 굵기 차이가 H+ 개수(4·4·2)인지.
- 헷갈림: 돌=CoQ·상자=시토크롬 c는 자리만 근거(상자는 전자 상자와 같은 모양); 자물쇠가 두 군데(문, 바퀴)라 어느 독이 어느 효소를 막는지 섞임; 황금 액체가 꿀인지 기름인지; 표지판이 I 쪽 금지인지 II 쪽인지.
- 이어 붙인 흔적: 풍선머리 남자·상자·병 둘레의 흰 후광(오려 붙임), 점선 화살·물방울은 평면 벡터풍, 오른쪽 벽이 벽돌에서 돌벽으로 바뀜(경계), 벽 윗단의 꼬인 줄무늬(소용돌이 아래, 불확실).

## ④ 한 문장
NADH·FADH2의 전자가 복합체 I→IV를 지나 산소에서 물이 되는 동안 I·III·IV가 H+를 막간으로 퍼 올려 만든 기울기가 ATP 합성효소를 돌려 ATP를 만들고, 시안화물류·올리고마이신은 이 흐름을 막으며 짝풀림제는 기울기를 새게 해 ATP 대신 열을 만든다.
