# stage2 · s32u01 (약속표 적용 재독 · ↻ = 1단계와 달라진 곳)

## 판정
약속표로 더 잘 풀린다. 오른쪽 절반(시안화물·짝풀림제·올리고마이신)과 소매·양동이·물병·석상이 확정됐다. 구조물(수레·물레방아·소용돌이)과 날씨는 약속표에 없어 1단계 읽기 그대로다. 1단계 「모름」 11개 중 2개 풀림(소매·물병), 3개 절반 풀림(양동이 탑·석상·어느 복합체).

## ① 판 전체 표제어
- 1순위 **산화적 인산화(전자전달계·ATP 합성효소 + 이를 깨는 약: 시안화물·CO, 짝풀림제, 올리고마이신)** 94% ↻(88→94)
- 2순위 **전자전달계와 화학삼투(양성자 구동력)** 55% ↻(60→55)
- 근거: 근육 팔=H+ 펌프, 동전=ATP, 밝은 방울=O2, 물병=H2O, 해골 미장이=시안화물·CO, 도깨비+손드릴=짝풀림제, 금빛 시럽=올리고마이신이 약속표 그대로 나온다.

## ② 구역별 (왼쪽부터)
**구역1 복합체 I·II: 전자 입구·펌프 유무** (6개)
1. 담장=내막, 바다=막간공간, 앞 모래=기질 [자리, ↻ 「물을 담장 너머로」 약속으로 뒷받침]
2. 지붕에서 솟은 근육 팔+홈통=H+ 펌프, 굴뚝1=I [약속]
3. ↻ 가득 찬 둥근 금속 양동이=NADH, I로 입력 [약속]
4. ↻ 빈 셔츠 소매(소맷단 단추 보임)=펌프 없음, 굴뚝2=II [약속, 1단계 모름 해결]
5. ↻ 네모 양동이=FAD(H2), 네모 창=II로 입력 [약속]
6. 금지표지(네모 양동이 X, 굴뚝1 벽)=네모(FAD)는 둥근 구멍(I)에 안 맞아 우회 [모양, 추정. 표지는 약속표에 없음]
모름: 해.

**구역2 복합체 III·IV와 이동성 운반체** (5개)
1~2. 굴뚝3·4 팔=III·IV도 H+ 펌프 [약속]
3. 굴뚝 4개=복합체 I–IV, 팔 3 대 소매 1=펌프 복합체 3개 [개수]
4. 철길 위 바위 수레(II·III 사이)=조효소 Q [자리, 약속표에 없음]
5. 철길 위 나무상자 수레(III·IV 사이)=시토크롬 c [소리 c·자리, 약속표에 없음]
모름: 물줄기 굵기(I>III>IV).

**구역3 최종 전자수용체 O2 → H2O** (5개)
1. ↻ 밝은 방울 머리=O2 [약속]
2. IV 문의 남자가 상자를 건넴=전자 IV→O2 [동작]
3. 가슴 물방울 2개=2 H2O [개수]
4. 점선 화살표(기질 웅덩이→가슴)=H+는 기질에서 소모 [뜻·자리]
5. ↻ 붉은 밀랍 물병=완성된 H2O [약속, 1단계 추정 확정]

**구역4 ATP 합성효소(화학삼투)** (5개)
1. 아치 물레방아로 바다 물이 쏟아져 앞마당으로=H+가 기울기 따라 효소를 통과 [동작]
2. 바퀴 회전=회전 촉매 [모양]
3. ↻ 동전=ATP, 쟁반에 쌓임(기질 쪽) [약속]
4. 소용돌이=H+가 입구로 쏠림 [모양]
5. 벽은 막고 아치로만=H+는 효소 통로로만 [자리]

**구역5 시안화물·CO(복합체 IV 저해)** (5개)
1. ↻ 해골 미장이=시안화물·CO [약속]
2. 벽돌로 봉한 문간=전자 통로 차단 [약속·동작]
3. ↻ 금색 자물쇠=통로를 잠그는 약·독 [약속]
4. ↻ 석상 3명=멈춰 선 전달자, 환원된 채 정체 [약속]
5. ↻ 가득 차 넘치는 금속 양동이 탑=NADH 쌓임 [약속, 1단계 모름 해결, 6은 여전히 모름]

**구역6 짝풀림제(DNP)** (6개)
1. ↻ 붉은 도깨비+손드릴=짝풀림제(DNP) [약속, UCP1은 철회]
2. 드릴로 담장(막)에 구멍, 자물쇠 없음=막는 약이 아니라 새게 하는 약 [약속]
3. 구멍에서 물이 앞마당으로=H+가 효소를 우회해 샘 [동작]
4. 불꽃·김=열 [모양]
5. 물만 담긴 쟁반=ATP 못 만듦 [자리]
6. 같은 기둥 위 팔 풀가동+폭풍=사슬 가속 [추정]

**구역7 올리고마이신** (5개)
1. ↻ 금빛 끈적 시럽 항아리=올리고마이신 [약속]
2. ↻ 축의 금색 자물쇠=효소를 잠가 막음 [약속]
3. 시럽에 엉긴 바퀴 정지=회전 정지 [동작]
4. 바퀴 속에 갇힌 물=H+ 통과 못 해 기울기 정체 [뜻]
5. 금화 없음=ATP 합성 중지 [자리]

## ③ 모름 · 어색 · 헷갈림 · 이은 흔적
- 아직 모름: 해, 폭풍·큰 파도, 소용돌이, 금지표지, 개수(구멍 3·양동이 6·석상 3), 5번째 팔(펌프 팔 4 대 복합체 3).
- 약속표에 있어도 끼우지 않음: 바위≠자갈(Ca2+), 철길≠왕복 궤도(바사 렉타), 붉은 벽돌 굴뚝≠벽돌 건물(간), 닫힌 상자≠과일 궤짝(P450), 조끼에 단추 줄 없음(CD4·CD8 아님).
- 헷갈림: 파란 물이 H+·NADH·H2O·새는 물을 다 나름. 자물쇠 2개는 같아서 약 종류는 곁의 인물(해골·시럽)이 가름.
- 이은 흔적: 하늘 맑음→폭풍, 벽돌→돌벽, 대머리 얼굴 반복. 뚜렷한 이음매 없음.

## ④ 한 문장
근육 팔이 NADH·FAD의 전자로 물(H+)을 담장 너머로 퍼 올려 만든 기울기가 바퀴를 돌려 동전(ATP)을 쏟고 O2는 끝에 물이 되는데, 시안화물·CO와 올리고마이신은 잠가서, 짝풀림제는 구멍을 내서 이를 깬다.
