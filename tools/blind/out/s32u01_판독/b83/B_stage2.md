# 2단계 약속표 적용 판독 (s32u01.png)

판정: 약속표로 더 잘 풀린다(뼈대 유지, 병·석상·시럽·해골·도깨비·팔/소매·양동이가 확정). 약속표에 없는 것은 끼우지 않았다.

## ① 판 전체 표제어
- 1순위 **산화적 인산화 — 전자전달계·화학삼투·ATP 합성효소·저해제·짝풀림제** 96% ↻(88→96) 근거: NAD/FAD 양동이 #102, 올리고마이신 #103, DNP #106, 시안화물 #107이 한 판에 모임.
- 2순위 **세포호흡 총괄(미토콘드리아 ATP 생성)** 3% ↻(광합성 7% 폐기: NAD·올리고마이신이 광합성과 안 맞음).

## ② 구역별 (7구역)
### 구역1 (x≈40–520) **복합체 I·II — NADH·FAD 공급과 H⁺ 펌프**
- 둥근 금속 양동이(가득) = NADH. 근거: #102 ↻확정
- 집1 둥근 구멍 + 팔 = 복합체 I(양동이와 모양 짝). 근거: 모양
- 네모 양동이(가득) = FAD(H₂), 네모 창 = II. 근거: #102 ↻확정
- 지붕의 근육 팔 3개(물을 담장 너머로) = H⁺ 펌프 I·III·IV. 근거: #108 ↻확정
- 집2 빈 셔츠 소매(커프스 단추) = 펌프 없음. 근거: #108 ↻확정
- 벽돌 벽 = 내막. 근거: 뜻(약속표 없음)
- 벽 뒤 바다 = 막간공간(H⁺ 고농도). 근거: 자리(약속표 없음)
- 집 4채 = 복합체 4개. 근거: 개수(벽돌 건물=간 #93은 안 씀)
- 해(광선 8+8) = 모름.

### 구역2 (x≈500–900) **이동성 운반체 Q·cyt c와 복합체 III·IV**
- 집3 팔 = III의 H⁺ 펌프. 근거: #108 ↻확정
- 집4 팔 = IV의 H⁺ 펌프. 근거: #108 ↻확정
- 돌공 수레(II·III 사이) = Q 추정. 근거: 자리(큰 공이라 자갈 #4 아님)
- 상자 수레(III·IV 사이) = cyt c 추정. 근거: 자리·소리(crate=c)
- 철로 = 막 면 이동 추정. 근거: 모양(직선이라 왕복 궤도 #6 아님)
- 파란 셔츠 남자(문에서 물방울을 건넴) = IV가 물을 만듦. 근거: 동작
- 팔마다 물줄기 굵기 다름 = 모름.

### 구역3 (x≈880–1010) **O₂ → 완성된 H₂O**
- 풍선 머리 = 밝은 방울 O₂. 근거: #17 ↻보강
- 붉은 밀랍 병(맑은 물) = 완성된 물 H₂O. 근거: #104 ↻(모름→풀림, 코르크=코르티솔 아님)
- 상자 = 전자 짐 추정. 근거: 자리(같은 상자 5개, 석상 #105와 묶임 ↻)
- 물방울 2개 = 만들어지는 H₂O 2분자 추정. 근거: 개수(H⁺일 여지, 약속표로 안 갈림)
- 점선 호 = 모름.

### 구역4 (x≈1000–1260) **화학삼투 — ATP 합성효소와 ATP**
- 동전 = ATP. 근거: #8 ↻확정(둥글어 GTP 네모 칩 #101 아님)
- 아치 속 물레방아 = ATP 합성효소. 근거: 모양(올리고마이신 자물쇠와 같은 틀 ↻보강)
- 물이 바퀴를 돌려 동전이 쏟아짐 = H⁺ 흐름→ATP 합성. 근거: 뜻
- 소용돌이 = 막간 H⁺가 기울기 따라 빠짐(추정). 근거: 모양
- 바퀴 밑 웅덩이 = 기질(추정). 근거: 자리

### 구역5 (x≈1260–1640) **전자전달 차단 — 시안화물·CO**
- 해골 미장이(흙손·벽돌) = 시안화물·CO. 근거: #107 ↻확정
- 벽돌로 봉한 문간 = 통로(복합체 IV) 봉쇄. 근거: #107
- 금색 자물쇠 = 막는 독. 근거: #2 ↻확정
- 회색 석상 3명(상자 듦) = 멈춰 선 전달자(환원된 채 정체). 근거: #105 ↻확정(3의 뜻은 모름)
- 양동이 탑 10여 개 = NAD⁺/NADH #102. 맨 위 물·바닥 웅덩이(NADH)와 포개진 빈 양동이(NAD⁺)로 갈려 보류 ↻

### 구역6 (x≈1440–1700) **짝풀림 — 도깨비+손드릴(DNP)**
- 붉은 도깨비+손드릴 = 짝풀림제 DNP. 근거: #106 ↻확정
- 자물쇠 없음 = 구멍 내는 약. 근거: #2 주석 ↻새로 읽힘
- 벽 구멍 3개 = 막 구멍. 근거: 개수(3의 뜻은 모름)
- 구멍에서 물줄기 2 = H⁺ 누수. 근거: 모양
- 수증기 2 + 붉게 달궈진 돌 = 열 발생(추정). 근거: 모양
- 물 쟁반(동전 없음) = ATP 없이 물만(추정). 근거: 자리

### 구역7 (x≈1620–2000) **ATP 합성효소 저해 — 올리고마이신**
- 끈적한 금빛 시럽 = 올리고마이신. 근거: #103 ↻('올리브유 소리' 오독 수정)
- 바퀴 축의 금색 자물쇠 = 막는 약. 근거: #2 (시럽과 같은 뜻의 이중 부호)
- 돌 건물 물레방아 = ATP 합성효소(구역4와 같은 틀). 근거: 모양
- 동전 없음 = ATP 0. 근거: 자리
- 항아리를 붓는 제빵사 = 억제제 투입(추정). 근거: 동작
- 높은 호를 던지는 4번째 팔 = H⁺ 펌프. 근거: #108 ↻(폭풍·거대 파도·붉은 밑동은 모름)

## ③ 안 풀린 것
해, 소용돌이, 폭풍·거대 파도, 점선 호, 물방울 2의 정체, 양동이 탑·석상의 개수는 약속표로도 모름. 조끼 인물(#39)·양동이의 V 고리(#7)는 안 씀. 이어 붙인 흔적: 세로 이음 없이 한 장면으로 이어짐.

## ④ 한 문장
NADH·FAD 양동이의 전자가 복합체를 지나 O₂를 완성된 물로 만들며 팔(H⁺ 펌프)이 세운 기울기가 물레방아(ATP 합성효소)를 돌려 동전(ATP)을 만들되, 해골·올리고마이신은 막고 도깨비는 열만 낸다.
