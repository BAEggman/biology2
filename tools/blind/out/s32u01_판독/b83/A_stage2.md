# 2단계 — 약속표로 다시 읽기 (s32u01) · ↻ = 1단계와 달라진 곳

## ① 판 전체 표제어
- 1순위 **산화적 인산화: 전자전달계·화학삼투(H⁺ 구배→ATP 합성효소)·저해제(시안화물·CO, 올리고마이신)·짝풀림제(DNP)** — 92% ↻(85→92)
- 2순위 **세포호흡 말단 단계(미토콘드리아 에너지 전환)** — 5%
- 판정: 약속으로 더 잘 풀림. 모름이던 병·석상·도깨비·해골·시럽이 전부 풀렸고, 큰 틀은 그대로, 오독 1건만 정정. 약속에 없는 해·바위·상자·레일·물레방아·소용돌이·폭풍은 억지로 끼우지 않고 자리 논리로만 읽음.

## ② 구역별 (왼쪽부터)
**구역1 — 복합체 I·II: 전자 공여체 투입과 H⁺ 펌프 (읽힌 6)**
1. 담·바다·모래 = 내막·막간공간·기질 (약속 없음, 자리)
2. 지붕에서 솟은 근육 팔+홈통 = H⁺ 펌프 (약속108) ↻추정→확정
3. 집 4채 = 복합체 I–IV (개수, 약속 없음)
4. 팔 3개와 집 2의 빈 셔츠 소매 = I·III·IV만 펌프, II는 펌프 없음 (약속108) ↻소매 확정. 물줄기는 집1>집3>집4로 굵어 보임(4:4:2 암시? 약함)
5. 둥근 금속 양동이(가득)+둥근 구멍 = NADH→I (약속102) ↻
6. 네모 양동이+네모 창 = FAD(H₂)→II (약속102) ↻
- 해: 약속에 없음, 여전히 모름.

**구역2 — 이동 운반체, 복합체 III·IV, O₂→H₂O (읽힌 7)**
1. 바위 수레(집 2~3 사이) = Q (약속 없음, 자리 추정)
2. 상자 수레(집 3~4 사이) = 시토크롬 c (약속 없음, 자리 추정)
3. 레일 = 전자의 길. 「왕복 궤도=바사 렉타」와 닮았으나 신장 요소가 없어 안 끼움
4. 집 4 문의 남자가 상자를 풍선 남자에게 = IV가 전자를 O₂로
5. 풍선 머리 = 밝은 방울 = O₂ (약속17) ↻
6. 붉은 밀랍 물병 = 완성된 H₂O (약속104) ↻모름→해결, 코르크(코르티솔)와 다름
7. 물방울 2개+점선 = 기질 H⁺가 e⁻·O₂와 만나 물이 됨 ↻1단계 「물 2분자」 정정(완성된 물은 병이므로 물방울은 반응물 H⁺, 60%)

**구역3 — ATP 합성효소·화학삼투 (읽힌 5)**
1. 아치 속 물레방아 = ATP 합성효소 (약속 없음, 모양)
2. 소용돌이 = 막간공간 H⁺ 낙하구
3. 물이 바퀴를 돌려 기질로 = H⁺ 복귀가 회전 구동
4. 금화 = ATP (약속8) ↻확정, 바퀴 아래에서만 나옴 = 공액
5. 바퀴 밑 웅덩이 = 기질 H⁺ 풀

**구역4 — 시안화물·CO 차단 (읽힌 6)**
1. 해골 미장이(흙손·벽돌) = 시안화물·CO (약속107) ↻확정, ADP/ATP 교환체 가설 폐기
2. 벽돌로 봉한 문간 = 복합체 IV 폐쇄
3. 금색 자물쇠 = 막는 독 (약속2) ↻
4. 석상 3명 = 멈춰 선 전달자, 환원된 채 정체 (약속105) ↻
5. 석상이 든 상자 3개 = 실린 전자 짐이 정체 (약속 없음, 추정)
6. 양동이 탑 약 10개(맨 위만 가득) = NADH 쌓임, NAD⁺ 고갈 (약속102) ↻

**구역5 — 짝풀림제 DNP (읽힌 5)**
1. 붉은 도깨비+손드릴 = DNP (약속106) ↻확정
2. 드릴 구멍 3개(물줄기 2+뚫는 중 1) = 막 구멍, H⁺ 누출. 자물쇠 없음이 약속2와 맞음 ↻
3. 샌 물이 금화 없는 물통으로 = 구배 소실, ATP 없음
4. 붉게 단 벽돌+수증기 2줄 = 열
5. 위의 4번째 펌프 팔(약속108)이 큰 원으로 던짐 = 전자전달 가속 또는 계속 펌프 ↻팔 확정, 뜻 두 갈래

**구역6 — 올리고마이신, ATP 합성효소 봉쇄 (읽힌 6)**
1. 돌 아치 속 두 번째 물레방아 = ATP 합성효소
2. 끈적한 금빛 시럽 = 올리고당 시럽 = 올리고마이신 (약속103) ↻
3. 축의 금색 자물쇠 = 막는 약, 회전 잠금 (약속2) ↻
4. 앞치마 남자+질그릇 단지 = 약 투여. 단지 속은 물이 아니라 시럽
5. 이 바퀴엔 물도 금화도 없음 = ATP 합성 중단
6. 폭풍·큰 파도 = H⁺ 구배 폭증, 펌프 팔은 계속 던짐

## ③ 남은 것·겹침·흔적
- 남은 모름: 해, 바위·상자의 확정 근거, 양동이 10개의 뜻(포도당당 NADH 10 가능), 소용돌이·폭풍·파도(상식 읽기).
- 약속과 겹쳐 보이나 안 끼움: 붉은 벽돌(간은 건물, 여기는 담·초소), 바위(자갈=Ca²⁺ 아님), 궤짝(P450은 과일이 듦), 조끼(단추 줄 없음), 바닥 점점(자갈 아님).
- 헷갈림: 올리고마이신 바퀴와 DNP 구멍이 한 돌 성문에 섞임.
- 이은 흔적: 돌 성문이 벽돌 담에 덧댄 듯. 하늘은 매끈히 이어짐. 글자 없음.

## ④ 한 문장
내막 앞에서 NADH·FAD가 전자를 넣으면 펌프 팔이 H⁺를 담 너머로 퍼 올리고 O₂는 물이 되며, 그 H⁺가 물레방아로 돌아오며 ATP(금화)를 만드는데, 시안화물(해골)·올리고마이신(시럽)은 막고 DNP(도깨비)는 구멍을 내 열만 낸다.
