# 1단계 생판 — s32u01 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **산화적 인산화: 전자전달계(복합체 I–IV)와 화학삼투(H⁺ 구배 → ATP 합성효소), 저해제·짝풀림제** — 85%
- 2순위 **세포호흡 말단 단계(미토콘드리아 에너지 전환)** — 10% (같은 판을 더 넓게 부른 이름)
- 탈락 후보 **광합성 명반응** 3% (해가 있으나, 팔 3개+팔 없는 집 1채와 양동이 2종 투입이 호흡 쪽)
- 큰 틀: 벽돌 담 = 내막, 담 뒤 바다 = 막간공간(H⁺ 고농도), 앞 모래 = 기질. 팔이 바닷물을 퍼 담 너머로 던짐 = H⁺ 펌프. 물이 물레방아로 되돌아 흐르며 금화(ATP)를 쏟음.

## ② 구역별 (왼쪽부터)
**구역1 — 복합체 I·II: 전자 공여체 투입과 H⁺ 펌프 (읽힌 6)**
1. 담·바다·모래 배치 = 내막·막간공간·기질 (자리)
2. 팔이 물을 퍼 던짐 = H⁺ 능동 펌프, 기질→막간 (동작)
3. 집 4채 = 복합체 I–IV (개수)
4. 팔 3개(집 1·3·4), 집 2만 팔 없이 늘어진 소매 = I·III·IV만 펌프, II는 안 함 (개수·자리)
5. 둥근 구멍+둥근 양동이 = NADH→I (모양)
6. 네모 창+네모 양동이 = FADH₂→II, 일꾼 2명 = 공여체 2종 (모양·개수)
- 해: 모름.

**구역2 — 이동 운반체와 복합체 III·IV, O₂→H₂O (읽힌 7)**
1. 바위 수레(집 2~3 사이) = 유비퀴논 Q, I·II→III (자리)
2. 상자 수레(집 3~4 사이) = 시토크롬 c, III→IV (자리)
3. 레일 = 막 위 전자의 길 (모양)
4. 집 4 문에서 허리 숙여 상자를 건네는 남자 = IV가 전자를 O₂에 넘김 (동작)
5. 풍선 머리 남자 = O₂, 최종 전자수용체 (모양)
6. 상자 위 물방울 2개 = H₂O 2분자 (개수)
7. 웅덩이→풍선→물방울 점선 = 기질 H⁺가 물이 되는 데 쓰임 (자리)
- 빨간 밀랍 병: 모름.

**구역3 — ATP 합성효소·화학삼투 (읽힌 5)**
1. 아치 속 물레방아 = ATP 합성효소 F₀F₁ (모양)
2. 위쪽 소용돌이 = 막간공간 H⁺가 한 곳으로 빨려 내려옴 (모양)
3. 물이 바퀴를 돌려 기질 쪽으로 쏟아짐 = H⁺ 하강 흐름이 회전을 구동 (동작)
4. 금화 분수·더미(수백 개, 셀 수 없음) = ATP, 바퀴 아래에서만 나옴 = 공액 (뜻·자리)
5. 바퀴 밑 웅덩이 = 기질로 돌아온 H⁺ (자리)

**구역4 — 전자전달 차단 독, 시안화물·CO형 (읽힌 5)**
1. 해골 = 독 (모양)
2. 벽돌로 메워진 문+자물쇠 = 복합체 IV 폐쇄, 전자가 O₂로 못 감 (뜻)
3. 흙손·벽돌 든 해골 = 억제제가 직접 결합해 막음 (동작)
4. 석상처럼 회색인 남자 3명과 상자 3개 = 운반체가 환원형으로 정체, 줄 섬 (개수)
5. 양동이 탑 약 10개 = NADH 등이 산화되지 못하고 쌓임 (개수)

**구역5 — 짝풀림제, DNP·UCP1형 (읽힌 5)**
1. 붉은 악마 = 짝풀림제 (모양)
2. 드릴 구멍 3개(물줄기 2+뚫는 중 1) = 막에 H⁺ 누출구 (개수)
3. 샌 물이 금화 없는 물통으로 = 구배 소실, ATP 없음 (동작)
4. 달아오른 벽돌과 수증기 2줄 = 에너지가 열로 (모양)
5. 위쪽 팔이 큰 원을 그리며 더 세게 던짐 = 전자전달·O₂ 소비 가속 (동작, 해석 70%)

**구역6 — ATP 합성효소 저해제, 올리고마이신형 (읽힌 6)**
1. 돌 아치 속 두 번째 물레방아 = ATP 합성효소 (모양)
2. 꿀을 부어 엉킴 = 억제제가 F₀에 붙어 막음 (뜻)
3. 축의 자물쇠 = 회전 잠금 (모양)
4. 앞치마 남자 = 저해제를 가하는 쪽 (동작)
5. 이 바퀴엔 물도 금화도 없음 = ATP 합성 중단 (자리)
6. 폭풍·거대 파도 = H⁺ 구배 폭증, 전자전달 되먹임 억제 (뜻, 해석 70%)

## ③ 뜻 모를 것·어색한 것·헷갈리는 것·이은 흔적
- 모름: 해(광선 16줄, 정상/폭풍 대비인지 광합성 암시인지), 빨간 밀랍 병(ADP·Pi 병인지 독 병인지), 집 2 지붕의 작은 볼트 구멍, 양동이 탑의 V자 흠.
- 헷갈림: 해골 문이 집 4와 별개로 담 한가운데에 있음 → 복합체 IV 차단인지 ADP/ATP 교환체 차단인지. 회색 상자와 수레 상자와 풍선 남자 상자가 같은 상자라 시토크롬 c인지 ATP인지.
- 어색: 억제제(꿀) 옆인데 팔이 가장 세게 던짐(짝풀림과 올리고마이신이 한 성문에 섞임). 오른쪽 바퀴가 겹바퀴처럼 이중 테.
- 이은 흔적: 오른쪽 돌 성문이 붉은 벽돌 담 앞에 덧댄 듯(재질·색 다름, 팔이 돌 윗면 틈에서 솟음). 하늘은 맑음에서 폭풍으로 매끈히 이어져 칸 선은 없음. 글자 없음.

## ④ 한 문장
내막이라는 담 앞에서 전자가 레일을 따라 산소까지 흐르며 H⁺를 담 너머로 퍼 올리고, 그 H⁺가 물레방아(ATP 합성효소)로 되돌아오며 ATP를 만드는데, 독·구멍·꿀이 이 흐름을 끊거나 새게 한다.
