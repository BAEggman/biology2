# stage1 — 생판 (s32u01, 그림만 보고)

## ① 판 표제어
- 1순위 **산화적 인산화 — 전자전달계(복합체 I–IV)와 화학삼투 ATP 합성** 90%
- 2순위 **광인산화(엽록체 광반응의 전자전달·화학삼투)** 5% — 해 하나 때문에 남김
- 공통 읽기: 벽=내막, 벽 너머 바다=막간 공간(H+ 높음), 모래 바닥=기질(낮음). 근거: 팔 3+빈 소매 1(I·III·IV 펌프, II 는 안 함) · 양동이 2 · 레일 운반체 2 · 풍선 머리+물방울 2 · 수차+금화 · 오른쪽 3컷(억제·짝풀림)

## ② 구역 (왼→오: 본판 6 + 오른쪽 세로 3컷)
**구역1 복합체 I — NADH 가 전자를 내리는 첫 펌프**
- 팔 1, 큰 구유·가장 굵은 물줄기 → H+ 를 벽 너머 높은 바다로 퍼올림 = I 은 펌프 [동작·굵기; 4H+ 는 약한 추정]
- 큰 둥근 양동이 든 남자 → 둥근 해치 → NADH 가 전자 공여 [뜻·자리]
- 금지 표지(양동이에 사선) 1: 모름 (로테논류 I 억제? NADH 막 통과 불가?)
- 해 1(광선 16: 긴 8+짧은 8): 모름

**구역2 복합체 II — H+ 펌프 안 함, FADH2 입구**
- 머리·손 없는 빈 셔츠 소매 1(구유 없음) → II 는 H+ 를 안 퍼올림 [모양·뜻]
- 네모 창 + 더 작은 네모 양동이 남자 → FADH2 가 I 을 건너뛰고 II 로 전자 공여 [크기·자리]

**구역3 Q(유비퀴논) → 복합체 III**
- 돌공 1 + 레일 수레 → Q: 막 속을 오가는 지용성 이동 운반체, I·II→III [뜻·자리; Q=큐볼 소리]
- 셋째 집 팔 1(중간 줄기) → III 가 H+ 펌프 [동작]
- 빈 문: 모름

**구역4 시토크롬 c → 복합체 IV**
- 상자 1 + 수레 → cyt c: 수용성 이동 운반체, III→IV [자리; c=crate 소리]
- 넷째 집 팔 1(가장 가는 줄기) → IV 가 H+ 펌프(2H+ 추정) [굵기]
- 파란 셔츠 남자 1(문 안에서 상자를 건넴) → IV 가 전자를 O2 에 넘김 [동작]

**구역5 O2 — 최종 전자수용체, 물 생성**
- 풍선 머리 사람 1(둥근 흰 'O') → 산소 [모양·소리]
- 상자를 안아 받음 → 전자를 받는 최종 수용체 [동작]
- 물방울 2 → H2O 2분자(O2+4e−+4H+→2H2O) [개수]
- 점선 화살표(바닥 웅덩이→가슴) → 기질 쪽 H+ 가 소비되어 물이 됨 [방향·자리]
- 병(붉은 밀랍 마개, 물 반쯤) 1: 모름 (독·억제제? 대사수?)

**구역6 ATP 합성효소 — 화학삼투**
- 벽 위로 솟은 바다 → 막간 공간의 H+ 고농도(기울기) [자리·높이]
- 소용돌이 1 → 양성자 구동력(H+ 가 문으로 쏠림) [모양]
- 벽을 뚫은 아치 문 1 → F0 H+ 통로 [자리]
- 수차 1(바큇살 약 8) → H+ 흐름으로 도는 F1 [동작]
- 금화 더미(수십 개) → ATP 다량 생성 [개수·뜻]
- 쟁반 1, 쟁반 밖 금화 약 30: 모름

**구역7 (우상) ATP 합성효소 억제 — 올리고마이신**
- 수차 중심 자물쇠 1 → 합성효소 잠김 [모양]
- 항아리의 황금 시럽 + 흰 앞치마 아저씨 1 → 올리고마이신 [소리: 올리고당]
- 크게 부푼 바다 → H+ 기울기 과축적, 전자전달 정체 [모양]
- 쟁반·금화 없음 → ATP 중단 [개수 0]

**구역8 (우중) 짝풀림 — 양성자 누출·열**
- 빨간 악마 1(뿔 2) + 드릴 → 짝풀림제 DNP [소리: D=Devil/Drill]
- 벽 구멍 3(물 쏟아짐) → 막에 H+ 누출 통로, 합성효소 우회 [뜻; 3 의 의미는 모름]
- 구멍마다 불꽃·김 → 열 발생 [모양]
- 팔이 계속 움직임(운동선) → 전자전달은 지속·가속 [동작]
- 빈 쟁반 → ATP 감소 [개수 0]

**구역9 (우하) 복합체 IV 억제 — 시안화물·CO**
- 해골 1(흙손+벽돌) → 독(시안화물) [뜻]
- 벽돌·빗장·자물쇠 1 로 막힌 문 → IV 봉쇄 [모양]
- 정장 풍선 머리 1, 손 벌림 → O2 를 못 씀 [동작]
- 돌이 된 팔·빈 구유 → 펌프 정지 [모양]
- 돌로 굳은 남자 2(상자 각 1) → 상류 운반체 정체(환원) [개수]
- 쌓인 양동이 4 → NADH·FADH2 산화 못 되고 적체 [개수]

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이음
- 모름: 금지 표지, 해, 병, 쟁반 밖 금화, 셋째 집 빈 문, 구름 1.
- 어색: 얼굴 없는 풍선 머리, 팔만 나온 집, 벽보다 높은 바다(의도로 봄), 점선 화살표 방향(웅덩이→가슴, 확신 낮음).
- 헷갈림: 돌공=Q/상자=cyt c 가 맞는지(풍선 사람도 같은 상자를 듦 → 상자=전자?), 큰 통=NADH/작은 통=FADH2 인지, 파란 셔츠 남자=IV 인지 cyt c 인지, 구멍 3·양동이 4·물줄기 굵기가 개수 뜻인지.
- 이음: 본판 1 + 오른쪽 작은 컷 3(검은 테두리 4개, 하늘 어둡고 흐림, 풍선 사람 옷이 조끼→정장). 본판 안 이음선은 못 찾음. 해·물방울·점선 화살표·금지 표지는 납작한 아이콘 느낌으로 펜화 위에 덧입힌 듯.

## ④ 한 문장
NADH·FADH2 의 전자가 I·III·IV(팔 3, II 는 빈 소매)의 펌프를 돌려 바다(막간)에 H+ 를 쌓고, 그 H+ 가 수차(ATP 합성효소)를 지나며 금화(ATP)를 만든다 — 합성효소 억제·짝풀림·IV 차단은 이 흐름을 끊는다.
