# stage2 — 약속표로 다시 읽기 (s32u01)

**판정**: 약속으로 더 잘 풀린다. 판·구역 표제어는 그대로(변동 0), 읽힌 사실 33→38. 모름→확정 2(해·병), 추측→약속 근거 확정 8(올리고당 시럽·Q·cyt c·양동이 둘·자물쇠·도깨비·해골·석상), 교정 4(↻), 남은 모름은 ③. 약속이 헷갈리게 한 것은 없다(간·자갈·왕복 궤도·코르크와 겹쳐 보이나 약속표 단서로 제외).

## ① 판 표제어
- 1순위 **산화적 인산화 — 전자전달계(복합체 I–IV)와 화학삼투 ATP 합성(+올리고마이신·짝풀림·시안화물)** 95%
- 2순위 **세포호흡(미토콘드리아 호흡) 전체** 3%
- ↻ 2순위 교체: 광인산화 철회 — 해는 광합성 단서가 아니라 '해 뜬 맑은 날=정상'[118]. 담장=막[116], 집=담장에 붙은 작은 벽돌 집(간 아님[93]).

## ② 구역
**구역1 복합체 I — NADH 짐의 출발**
- 가득 찬 크고 둥근 금속 양동이 = NADH [102]
- 지붕에서 솟은 근육 팔+홈통 = H+ 펌프 [108]
- ↻ 짐이 거치는 팔 3(집1·3·4) = 퍼내는 H+ 가장 많음(≈10). 1단계 '물줄기 굵기=4H+' 폐기
- ↻ 해 = 정상 조건 [118] (1단계 모름)
- 금지 표지(양동이에 사선): 약속표에 없음 → 모름 유지

**구역2 복합체 II — 펌프 없음**
- 빈 셔츠 소매 = 펌프 없음 [108]
- ↻ 가득 찬 네모 양동이 = FAD(H2) [102] (크기 추정 → 확정)
- ↻ 짐이 거치는 팔 2(집3·4) = H+ 더 적음(≈6)

**구역3 Q → 복합체 III**
- ↻ 레일 수레의 둥근 바위 = Q [109]; 돌 = 비단백질(유일), 건물에 안 붙고 구름 = 막을 떠다님. 놓쳤던 단선 레일 = 이 수레의 길
- 셋째 집 팔 = III 펌프 [108]; 빈 문: 모름

**구역4 시토크롬 c → 복합체 IV**
- ↻ 상자 수레 = cyt c(단백질) [109] — 돌공/상자 헷갈림 해소
- 넷째 집 팔 = IV 펌프
- 파란 셔츠 남자(약속표에 없음)가 짐(상자)을 O2 에 건넴 = IV 가 전자를 O2 로

**구역5 O2 · 물**
- 밝은 방울 머리 사람 = O2 [17]; 짐을 받아 안음 = 최종 전자 수용체
- ↻ 붉은 밀랍 병 = 완성된 물(H2O) [104] (1단계 모름)
- ↻ 물방울 2+점선 화살표(웅덩이→가슴) = 돌아온 물(H+)이 O2 로 가서 물이 됨. 1단계 'H2O 2분자'에서 변경(완성된 물은 병). 놓쳤던 웅덩이 = 아치로 돌아온 H+ 가 기질에 고임. 2 의 뜻은 모름

**구역6 ATP 합성효소**
- 담장 밑동 돌 아치 1+물레방아 = ATP 합성효소 [116]
- ↻ 아치가 H+ 귀환의 유일한 길 → 아치 뒤 바다가 소용돌이로 휘감김 (1단계 '양성자 구동력')
- 담장 뒤 물의 높이 = H+ 기울기 크기 [117], 정상(높음)
- 둥근 금화 더미 = ATP [8] (네모 칩=GTP 아님); 담장=막이라 H+ 는 아치로만 통과
- 쟁반·쟁반 밖 금화 약 30: 모름

**구역7 (우상) 올리고마이신**
- ↻ 금색 자물쇠 = 막는 약·독 [2]
- ↻ 올리고당 시럽 = 올리고마이신 [103] (1단계 소리 추측 확정)
- 크게 부푼 바다 = 기울기 커짐 [117]
- 수차 정지·동전 없음 = ATP 중단. 요리사는 약속표에 없음

**구역8 (우중) 짝풀림**
- 붉은 도깨비+손드릴 = 짝풀림제 DNP [106]
- ↻ 담장에 새로 뚫린 구멍 3(자물쇠 없음) = 짝풀림 [116·2]
- ↻ 운동선 팔 = 더 빨리 도는 펌프 [108]
- ↻ 낮은 바다 = 기울기 작아짐 [117]
- 빈 쟁반 = ATP 없음. 불꽃·김 = 열(상식 읽기, 약속표 없음)

**구역9 (우하) 시안화물·CO**
- 해골 미장이(흙손·벽돌로 봉한 문간) = 시안화물·CO [107]
- ↻ 금색 자물쇠 = 막는 약·독 [2]
- ↻ 돌로 굳은 팔 = 멈춘 펌프, 석상 사람 2 = 멈춰 선 전달자(환원 정체) [105]
- 밝은 방울 머리 사람이 문밖에서 손 벌림 = O2 를 못 씀
- ↻ 쌓인 양동이 4(물 보임) = NADH 가득 정체 [102]. 바다 높이는 정상과 비슷해 읽을 것 없음

## ③ 남은 모름 · 헷갈림 · 이음
- 모름(약속표에 없음): 금지 표지, 구름 1, 쟁반 밖 금화, 셋째 집 빈 문, 집 입구 모양(해치·창·문), 구멍 3·양동이 4·물방울 2 의 수, 바닥 잔돌(자갈=Ca²⁺ 로 끼우지 않음)
- ↻ 이음: 오른쪽 3칸은 이음 흔적이 아니라 '다른 날(조건)' 칸 [118]. 하늘이 어둡고 옷이 바뀐 것도 의도
- 헷갈림: 돌공/상자·큰 통/네모 통은 해소. 파란 셔츠 남자=IV 일꾼인지 cyt c 인지는 미해결

## ④ 한 문장
NADH(가득 양동이)·FAD 의 짐이 팔 3·2 개를 거치며 H+ 를 담장 너머로 퍼 올려 바다(기울기)를 쌓고, 그 물이 돌아오는 유일한 길인 아치의 물레방아(ATP 합성효소)가 동전(ATP)을 찍어 낸다. O2 사람이 짐을 받아 물(병)을 만들며, 올리고마이신(자물쇠·시럽)·DNP(구멍)·시안화물(해골)은 이 흐름을 막거나 새게 한다.
