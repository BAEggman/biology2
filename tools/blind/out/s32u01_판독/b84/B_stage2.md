# stage2 — 약속표로 다시 읽음 (↻ = 1단계와 달라진 곳)

## 판정
약속표가 핵심 물건 11개(자물쇠 2 · 동전 · 금속/네모 양동이 · 올리고당 시럽 · 밀랍 물병 · 석상 · 도깨비+드릴 · 해골 미장이 · 근육 팔/빈 소매)의 이름표를 확정·정정해 줘서 더 잘 풀린다. 판 표제어는 그대로. 표에 없는 물건(해 · 소용돌이 · 물레방아 · 큰 물 언덕 · 돌/상자 수레 · 풍선 · 점선 호)은 1단계 읽기를 두고 약속에 끼우지 않음.

## ① 판 전체 표제어
- 1순위: **산화적 인산화 — 전자전달계 + 화학삼투(ATP 합성), 억제제·짝풀림제 포함** (96%) ↻90→96
- 2순위: **화학삼투 — H+ 기울기와 ATP 합성효소** (3%)
- 근거: 약속 101~108(ATP 동전 · NADH/FAD 양동이 · 올리고마이신 · 완성된 물 · 정체한 전달자 · DNP · 시안화물 · H+ 펌프)이 한 묶음으로 전부 등장.

## ② 구역별 (7구역, 나눔은 1단계와 같음)
**구역1 · 복합체 I·II 입구** — 읽힌 7개 ↻6→7
1. 벽돌집 4채 = 복합체 4개 (개수; 표에 없음)
2. ↻ 집1: 둥근 창 + 물 가득한 금속 양동이 = I + NADH (약속 102)
3. ↻ 집1 지붕의 거대한 근육 팔(홈통으로 물을 담장 너머로) = H+ 펌프 (약속 108)
4. ↻ 집2: 네모 창 + 네모 양동이 = II + FAD(H2) (약속 102)
5. ↻ 집2 지붕의 「양말」은 빈 셔츠 소매(끝에 단추) = 펌프 없음 (약속 108)
6. ↻ 금지 표지판(네모 양동이에 사선) = I은 FAD 불가, NADH 전용. 근거: 약속 102 + 지지대가 집1에 걸림 + 네모 양동이는 집2로 가니 집2 금지일 수 없음
7. 담/바다/길 = 내막/막간/기질 (자리; 표에 없음)
- 모름 유지: 해

**구역2 · 이동 운반체와 복합체 III·IV** — 읽힌 6개
1. 수레의 둥근 돌 = Q (표에 없음; 자리·무게)
2. 수레의 상자 = cyt c (표에 없음; 자리)
3. ↻ 집3·집4 지붕의 근육 팔 = III·IV의 H+ 펌프 (약속 108). 팔 3개 + 빈 소매 1개
4. ↻ 문간 남자가 상자를 건넴 = 전달자가 IV에서 전자를 넘김 (약속 105: 석상 = 멈춘 「전달자」)
5. 세 팔의 물줄기 굵음 → 가늚 = 복합체별 H+ 양 (양; 추정)
6. 물을 담장 너머로 쏟음 = 기울기 거스르는 능동 수송 (약속 108)

**구역3 · 최종 전자수용체 O2와 물** — 읽힌 4개 ↻3→4
1. 풍선 머리 남자 = O2 (약속 17 「밝은 방울」과 같은 꼴, 같은 물건은 아님)
2. 상자(전자)를 받음 = IV에서 전자 수용
3. ↻ 붉은 밀랍 물병 = 완성된 물 H2O (약속 104; 1단계 「모름」이 풀림)
4. ↻ 상자를 타고 흐르는 물방울 2개 = 완성 전의 물, 병과 짝 (추정: 약속 104가 「완성된」 물을 따로 둠)
- 모름 유지: 점선 호(방울과 같은 청록, 끝이 웅덩이 — 방향 불명)

**구역4 · 화학삼투 — 물레방아와 금동전** — 읽힌 5개
1. 소용돌이 = H+이 빠져나가는 입구 (표에 없음)
2. 아치 속 물레방아 = ATP 합성효소 (표에 없음; 뜻)
3. 물이 바다 → 길로 쏟아짐 = H+ 기울기 방향
4. ↻ 둥근 금동전 = ATP (약속 8; 회색 네모 칩이면 GTP라 갈림)
5. 금동전 더미가 큼 = ATP 대량 생산 (양)
- 모름 유지: 바퀴살 8개

**구역5 · 전자전달 억제 — 시안화물·CO** — 읽힌 5개 ↻4→5
1. ↻ 해골 미장이(흙손 + 벽돌) = 시안화물·CO (약속 107; 「아지드」는 표에 없어 뺌)
2. ↻ 벽돌로 봉한 문간 = IV의 통로 차단 (약속 107 + 집4 문과 같은 모양)
3. ↻ 문 옆 금색 자물쇠 = 막는 독 (약속 2)
4. ↻ 석상 3명(상자 든 채 줄 섬) = 멈춘 전달자, 환원된 채 정체 (약속 105; 개수 3)
5. ↻ 금속 양동이 탑 = NAD+/NADH 풀 (약속 102). 맨 위만 가득 → NADH가 NAD+로 못 돌아옴(추정). 6개의 뜻은 모름

**구역6 · 짝풀림 — 구멍(H+ 누출)과 열** — 읽힌 5개 ↻4→5
1. ↻ 붉은 작은 도깨비 + 손드릴 = 짝풀림제 DNP (약속 106; 1단계의 UCP1은 표에 없어 뺌)
2. ↻ 벽돌 기둥에 구멍 3개, 자물쇠 없음 = 구멍 내는 약 (약속 2 끝 문장)
3. 새는 물줄기 = H+이 합성효소를 거치지 않고 샘
4. 불꽃과 김 = 열 (표에 없음)
5. ↻ 기둥 위 4번째 근육 팔 = H+ 펌프가 계속 가동 (약속 108로 확정, 「활발」은 추정)

**구역7 · ATP 합성효소 억제 — 올리고마이신** — 읽힌 4개
1. ↻ 금빛 시럽 = 올리고당 시럽 = 올리고마이신 (약속 103; 1단계 「올리브유」 정정)
2. ↻ 바퀴 축의 금색 자물쇠 = 효소를 잠그는 약 (약속 2)
3. 매끈한 큰 물 언덕 = 갇힌 H+ 기울기 (표에 없음)
4. 금동전·쏟아지는 물이 없음 = ATP 0 (구역4와 대조)

## ③ 모름 · 어색 · 헷갈림 · 이음새
- 여전히 모름: 해(광선 긴 8 + 짧은 8), 점선 호, 바퀴살 8개, 양동이 6개, 앞치마 사람(시럽을 붓는 행위자로만 읽음)
- 어색: 4번째 팔만 집 없이 기둥 위(약속은 「지붕에서 솟은」) — 펌프임은 확실, 어느 복합체인지는 모름
- 약속 충돌 위험(여기선 모두 해당 없음 판정): 붉은 벽돌 건물 = 간(여기 벽돌 부스·담은 막 구조물) · 궤짝 = P450(속이 빔) · 끈적한 점액 = 믹소(금빛 시럽) · 자갈 = Ca2+(큰 돌 하나) · 왕복 궤도 = 바사 렉타(콩팥 요소 없음) · 질그릇 단지 = 물 그릇(여기선 시럽이 뜻)
- 헷갈림: 자물쇠 둘(문 = 시안화물 / 바퀴 = 올리고마이신)은 걸린 대상으로 가름. 큰 물 언덕은 구역7의 것이지 구멍 뚫린 구역6의 것이 아님
- 이음새: 1단계와 같음(이어 붙임 없음, 담이 벽돌 → 석조로 바뀜)

## ④ 한 문장
NADH(금속 양동이)·FAD(네모 양동이)의 전자가 I(II) → Q → III → cyt c → IV → O2(풍선)로 흘러 물(밀랍 병)이 되고, 그 힘으로 근육 팔이 퍼 올린 H+ 기울기가 물레방아(ATP 합성효소)를 돌려 금동전(ATP)을 쏟게 하며, 해골 미장이(시안화물)·도깨비(DNP)·올리고당 시럽(올리고마이신)은 각각 길을 막고, 기울기를 열로 새게 하고, 바퀴를 잠가 ATP를 멈춘다.
