# stage1 — 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위: **산화적 인산화 — 미토콘드리아 전자전달계와 화학삼투(ATP 합성효소), 억제제·탈공액제 포함** (90%)
- 2순위: **화학삼투 — H+ 농도 기울기(양성자 구동력)와 ATP 합성효소** (6%. 엽록체 광인산화 비교판일 가능성은 2% 안팎)
- 큰 틀: 벽돌 담 = 막, 담 너머 바다 = H+ 고농도 쪽(막간), 모래 길 = 반대쪽(기질). 팔이 물을 담 너머로 퍼 올림 = 기울기를 거스르는 H+ 펌프. 물레방아 + 금화 = H+이 흘러내리며 ATP를 만듦. 왼쪽 맑음 = 정상 가동, 오른쪽 먹구름 = 억제·이상 상태.

## ② 구역별 읽기 (왼쪽부터 7구역)
**구역1 · 복합체 I·II 입구 (NADH·FADH2, II는 펌프 안 함)** — 읽힌 6개
1. 벽돌집 4채 = 전자전달 복합체 4개 (개수)
2. 집1: 둥근 창 + 둥근 양동이 든 남자 = I에 NADH가 전자를 넣음 (모양 일치·첫 자리)
3. 집1 지붕의 근육 팔이 홈통 물을 담 너머로 쏟음 = H+ 펌프, 에너지 소모 (동작·뜻)
4. 집2: 네모 창 + 네모 양동이 = II에 FADH2가 들어감 (모양 일치·둘째 자리)
5. 집2 지붕에 팔 대신 축 처진 양말(빈 소매) = II는 H+을 못 퍼 올림. 팔은 왼쪽에 3개뿐 (뜻·개수)
6. 담/바다/길 = 내막/막간/기질 (자리)
- 모름: 해(긴 광선 8 + 짧은 광선 8), 금지 표지판(네모 양동이에 사선; "FADH2는 I에 못 들어간다" 또는 "II는 펌프 금지" 중 하나로 추정)

**구역2 · 이동 운반체(Q·cyt c)와 복합체 III·IV** — 읽힌 6개
1. 레일 위 수레의 둥근 돌 = 유비퀴논(CoQ), II와 III 사이의 지용성 이동 운반체 (자리·무게, 보통 확신)
2. 레일 위 수레의 나무 상자 = 시토크롬 c, III와 IV 사이 (자리, 보통 확신)
3. 집3(문 + 팔) = III, 펌프함 (3번째 자리·팔 있음)
4. 집4(문 + 팔, 문간 남자가 상자를 건넴) = IV(시토크롬 c 산화효소), 마지막으로 전자를 넘김·펌프함
5. 세 팔의 물줄기가 왼쪽 굵음 → 오른쪽 가늚 = 복합체마다 퍼 올리는 H+ 양이 다름 (I 많고 IV 적음, 양)
6. 물을 바다로 쏟는 동작 = 기울기 역행 수송이라 에너지가 듦 (뜻)

**구역3 · 최종 전자수용체 O2와 물 생성** — 읽힌 3개
1. 풍선 머리 남자 = 산소 O2 (기체 = 풍선, 사슬의 맨 끝 자리)
2. 상자(전자)를 문간 남자에게서 받음 = IV에서 O2가 전자를 받음 (동작)
3. 상자 위 물방울 2개 = H2O 생성 (2 H2O, 개수)
- 모름: 어깨에서 웅덩이로 가는 점선 호, 빨간 밀랍 마개의 물병 (생성수일 수도)

**구역4 · 화학삼투 — 물레방아(ATP 합성효소)와 금화(ATP)** — 읽힌 5개
1. 바다의 소용돌이 = H+이 기울기를 따라 빠져 내려가는 입구 (모양)
2. 담의 아치 속 물레방아 = ATP 합성효소 F0F1, 물이 흘러야 돎 (뜻)
3. 물이 바다 쪽에서 길 쪽으로 쏟아짐 = H+이 막간에서 기질로 이동 (자리·방향)
4. 튀어나오는 금화 = ATP (에너지 화폐), 바퀴가 돌 때 생산 (뜻)
5. 금화 더미가 아주 큼 = ATP 대부분을 여기서 만듦 (양)
- 모름: 바퀴살 8개의 뜻

**구역5 · 전자전달 억제 — 시안화물·CO (복합체 IV 차단)** — 읽힌 4개
1. 해골 = 독(CN−, CO), 사망 (모양)
2. 벽돌로 메워지고 자물쇠 잠긴 문 = 통로(복합체 IV의 문) 차단 (집4 문과 같은 모양)
3. 해골의 흙손·벽돌 = 억제제가 붙어 길을 막는 동작
4. 회색으로 굳은 남자 3명이 상자를 든 채 줄 섬 = 상류 전달체가 전자를 못 넘기고 정체 (색·개수 3)
- 모름: 양동이 6개 탑(해골 옆, 맨 위 양동이에 물)

**구역6 · 탈공액 — 막에 구멍(H+ 누출)과 열 (DNP·UCP1)** — 읽힌 4개
1. 악마 + 전동 드릴 = 막에 구멍을 내는 탈공액제 (동작·모양)
2. 벽돌 기둥(막)의 구멍 3개 (개수)
3. 구멍에서 새는 물줄기 = H+이 ATP 합성효소를 거치지 않고 샘 (기울기 소실)
4. 불꽃과 김 = 에너지가 열로 방출 (뜻)
- 추정(미계수): 기둥 위 4번째 팔의 거대한 물 포물선 = 전자전달·펌프는 계속, 오히려 활발

**구역7 · ATP 합성효소 억제 — 올리고마이신 (F0 차단)** — 읽힌 4개
1. 기름 범벅 + 축에 자물쇠가 걸린 바퀴(돌 아치) = ATP 합성효소가 멈춤 (구역4와 대조)
2. 항아리의 끈적한 노란 기름 = 올리고마이신 (소리: 올리브유 ≈ 올리고)
3. 바다 위 매끈한 큰 물 언덕 = 못 빠져나간 H+이 쌓인 기울기 (모양·자리)
4. 금화·쏟아지는 물이 없음 = ATP 생성 0 (대조)

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이음새
- 뜻 모름: 해, 점선 호, 물병, 바퀴살 8개, 양동이 탑 6개, 앞치마 사람이 누구인지(항아리를 든 사람)
- 어색: 팔이 4개인데 집은 4채·펌프 복합체는 3개. 4번째 팔은 집 없이 기둥 위에 섬.
- 헷갈림: ① 표지판의 대상(집1 지지대에 걸렸으나 집2 앞) ② 상자가 여러 곳에 쓰임(수레·풍선 남자·회색 남자 3명 — cyt c인지 전자인지) ③ 양동이(남자)와 나무 홈통(팔) ④ 물레방아가 둘 ⑤ 파도 언덕(기울기 쌓임)이 구멍 뚫린 구역(기울기 소실)과 같은 하늘 아래라 모순처럼 보임
- 이음새: 뚜렷한 이어 붙임 없음(수평선·담 벽돌 줄·하늘이 끊김 없이 이어지고 맑음 → 먹구름으로 서서히 바뀜). 다만 오른쪽 끝에서 담이 붉은 벽돌 → 회색 석조로 바뀌어 구역7이 증축처럼 보임. 글자는 없음.

## ④ 한 문장
NADH·FADH2의 전자가 I(II)→Q→III→cyt c→IV→O2(물)로 흐르며 I·III·IV가 H+을 퍼 올려 만든 기울기가 ATP 합성효소를 돌려 ATP를 만들고, 전자전달 차단·합성효소 차단·탈공액은 이 연결을 끊거나 열로 낭비시킨다.
