# stage1 생판 (s45u01.png)

## ① 판 표제어
- **1순위: 광합성 탄소 고정 반응 — 캘빈 회로·광호흡·C4·CAM (C3/C4/CAM 비교)** 90%
- **2순위: 광호흡(Rubisco 산소화)과 그 회피 전략 C4·CAM** 6% (그 밖 광합성 전반 3%)
- 그림 안의 약속(마디를 세어야 읽힘): 줄무늬 막대의 마디 수 = 탄소 수(2·3·4·5), 검은 방울·검은 캡 = CO2의 탄소, 흰 구슬 = O2, 금화 = ATP, 루비 렌즈 망원경 = Rubisco(ruby+scope).

## ② 구역 (왼쪽부터 4구역)
### 구역1 큰 집 — **캘빈 회로(고정·환원·재생)** · 10개
1. 루비 렌즈 망원경 = Rubisco (소리: ruby+scope)
2. 렌즈에 경첩으로 붙은 5마디 막대 = RuBP 5탄당 (개수 5)
3. 검은 방울 3개(공중 2, 막대 끝 1) = CO2 3분자, 3회전 (색·개수)
4. 탁자 위 부러진 막대: 3마디 + (2마디+검은 캡) = 5C+CO2 → 6C가 3C 둘로, 3-PGA 2분자 (개수)
5. 방패 든 남자 + 금화 1 = 환원에 ATP·NADPH 소모 (동작; 방패=NADPH는 추정)
6. 햇빛 드는 벽감의 금화 바구니 + 방패 2 = 명반응이 대는 ATP·NADPH (자리: 빛줄기)
7. 시험관 꽂이 6칸에 3마디 막대 5 + 빈 칸 1 = G3P 6분자 중 5 재순환 (개수)
8. 검은 아치 구멍으로 드는 3마디 막대(널판 경사) = 6번째 G3P 1분자만 순생산으로 이탈 (자리)
9. 소년이 안은 5마디 막대 3 + 금화 3 = G3P 5(15C)→RuBP 3(15C) 재생, ATP 3 (개수)
10. 소년이 속도선 그으며 망원경 쪽으로 걸음 = 재생 RuBP가 Rubisco로 복귀, 순환 (동작)

### 구역2 3칸 별채 — **광호흡(엽록체→퍼옥시좀→미토콘드리아)** · 9개
1. 칸 3개 = 세포소기관 3곳이 차례로 (개수 3)
2. 칸1 같은 루비 망원경 + 5마디 막대 끝 흰 구슬 1 = Rubisco가 CO2 대신 O2를 물음, 산소화 (색)
3. 칸1 벽 동전 투입구에 금화 낙하 = ATP 소모, 에너지 낭비 (동작)
4. 칸1 터진 자루에서 쏟아진 보라 알 8 = 새는 포도당(소리: 포도→포도당), 추정 (개수 8)
5. 칸2 거품 가득 나무통 + 국자 = 퍼옥시좀 H2O2·카탈레이스 거품, 추정 (모양)
6. 칸2 바닥 2마디 막대 = 2C 글리콜산→글리신 (개수; 옆 바닥 구멍은 모름)
7. 칸3 주름 접힌 몸통의 철제 난로 = 미토콘드리아 크리스타 (모양)
8. 굴뚝 연기 + 꼭대기 검은 방울 1 = 글리신 2→세린+CO2 1, 탄소 손실 (색·개수)
9. 칸3 바닥 2마디 막대 = 글리신 2C (개수)

### 구역3 담쟁이 오두막 — **C4 식물(공간 분리: 엽육→유관속초 CO2 농축)** · 10개
1. 담쟁이 덮인 집 안의 금고형 상자 = 엽육(바깥)·유관속초(안) 이중 구조 (자리)
2. 지붕 밑 끈 2개로 묶인 회색 관 5개 = 관다발 (소리: bundle)
3. 상자 안 검은 빗방울 약 20 = CO2 고농도 (색·수)
4. 상자 속 망원경 + 5마디 막대 끝 검은 방울 = 유관속초에서만 Rubisco·캘빈 (자리)
5. 상자 밖 흰 거품 약 15 = O2는 못 들어옴, 광호흡 억제 (색, 추정)
6. 땀 닦는 남자 + 큰 해 = 고온·강한 빛 적응 또는 ATP 비용 (표정, 모호)
7. 빨간 U자 자석 = PEP 카르복실화효소, CO2를 끌어당김 (뜻; Mg 가능성)
8. 자석 끝 막대 3마디 + 검은 캡 = PEP 3C + CO2 → OAA 4C (개수)
9. 상자 벽 틈을 통과하는 4C 막대(검은 캡이 안쪽) = 말산이 원형질연락사로 들어가 CO2 방출 (자리)
10. 풀밭 3마디 막대 + 금화 1 = 피루브산 3C가 ATP로 PEP 재생 (개수)

### 구역4 2층 탑 — **CAM 식물(시간 분리: 밤 고정·낮 캘빈)** · 9개
1. 윗층 초승달·별 창 = 밤 (모양)
2. 초록 콩 2개 벌어진 사이로 검은 방울 3 = 공변세포, 기공 열림, 밤 CO2 흡수 (모양·개수)
3. 무릎 꿇은 남자 + 자석 + 검은 캡 막대 = 밤에 PEPC가 CO2 고정 (뜻)
4. 장작더미 3마디 막대 7~8 = PEP 재료(전분 분해) (개수)
5. 큰 항아리 속 막대 6 = 말산 4C를 액포에 저장 (개수)
6. 사다리 = 밤→낮 이동? (모름)
7. 아랫층 해 창 + 맞붙은 콩 2 = 낮, 기공 닫힘 (모양)
8. 쓰러진 항아리에서 쏟아지는 막대와 검은 방울 3~4 = 낮에 말산이 CO2로 풀림 (동작)
9. 망원경 + 5마디 막대는 아랫층에만 = 낮에 Rubisco·캘빈, 빛 필요 (자리)

## ③ 걸리는 것
- 뜻 모름: 칸1·2 왼쪽 벽의 얇은 회색 유리판, 칸2 바닥 구멍, 칸1 벤치 앞 연청회색 작은 방울, 사다리, 방패의 정체, 금화·방패·보라 알의 짝.
- 어색: 밤에 기공이 열리고 낮에 닫힘(일반 식물과 반대, 의도로 보임) / 밤층에는 망원경이 없음.
- 헷갈림: 검은 캡 vs 검은 방울(둘 다 CO2), 흰 구슬 vs 연청회색 방울, 3마디(3C) vs 3마디+캡(4C), 자석=PEPC인지 Mg인지, 같은 망원경 4곳이 장소마다 뜻이 다름.
- 이음 흔적: 건물 4덩이가 밝은 땅 틈과 각자 그림자로 떨어져 붙은 듯하나 하늘·햇무리는 연속 — 약함. 글자는 없음.

## ④ 한 문장
Rubisco가 RuBP(5C)에 CO2를 붙여 3C 둘로 쪼개는 캘빈 회로는 O2가 끼면 광호흡으로 탄소를 잃으므로, C4는 엽육 PEPC로 CO2를 4C로 잡아 유관속초에 농축(공간)하고 CAM은 밤에 말산으로 모았다가 낮에 풀어 쓴다(시간).
