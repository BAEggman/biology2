# 1단계 생판 (s45u01.png)

## ① 판 전체 표제어
- 1순위 **광합성 탄소고정 반응: 캘빈 회로 · 광호흡 · C4 · CAM** (85%)
- 2순위 **C3·C4·CAM 식물의 환경 적응(고온·건조에서 CO2 확보 전략)** (10%)
- 읽는 열쇠(그림 전체에서 일관): 적색 렌즈 망원경 = Rubisco, 막대 마디 수 = 탄소 수(5=RuBP, 3, 4, 2), 짙은 물방울 = CO2, 흰 구슬·기포 = O2, 금화 = ATP, 방패 = NADPH, 자석 = PEP 카르복실화효소.

## ② 구역별 (왼쪽부터 4구역)

### 구역1 큰 방: **캘빈 회로(C3 탄소고정 3단계)**
1. 작업대 끝 적색 렌즈 망원경 = Rubisco (모양/자리)
2. 렌즈에 걸친 5마디 막대 = RuBP 5탄당 (개수)
3. 짙은 물방울 3개(낙하 2 + 막대 끝 1) = CO2 3분자 = 3회전 (개수/색)
4. 작업대에 부러진 2토막(3+3마디, 한 토막 끝 짙은 마디) = 6C 중간체가 3PGA 2분자로 분해(5+1=3+3), 짙은 마디 = CO2 유래 탄소 (개수)
5. 방패 든 남자 + 토막 위 금화 1 = 환원: 3PGA + ATP + NADPH → G3P (동작)
6. 창가 금화 바구니 + 방패 2 + 빛줄기 = 명반응이 ATP·NADPH를 공급 (자리/개수)
7. 시험관 꽂이 6칸 = 3마디 막대 5 + 빈 칸 1: G3P 6분자 중 5 재순환, 1 순생산 (개수)
8. 판 위로 검은 구멍을 향하는 3마디 막대 1 = 순생산 G3P가 회로 밖으로 (자리/개수)
9. 걷는 남자의 5마디 막대 3 + 금화 3 = RuBP 3분자 재생에 ATP 3 (개수)
10. 햇빛(창) = 명반응 의존 (뜻)
→ 10개

### 구역2 작은 방 3칸: **광호흡(엽록체 → 퍼옥시좀 → 미토콘드리아)**
- 방A(엽록체): 같은 망원경 + 5마디 막대 끝에 흰 구슬 = Rubisco가 CO2 대신 O2를 붙임(산소화) (색/자리); 금화가 투입구로 떨어짐 = ATP 소모 (뜻); 찢긴 자루에서 쏟아진 보라 포도 8알 = 포도당(수확량) 손실(추정, 약함)
- 방B(퍼옥시좀): 거품 가득한 통 + 국자 = H2O2 분해(카탈레이스)로 O2 거품 (모양); 2마디 막대 = 2탄소 글리콜산 (개수); 바닥 구멍 = 모름
- 방C(미토콘드리아): 아코디언 주름 난로 = 내막 크리스타 (모양); 연통 밖 연기 + 짙은 방울 = CO2 방출 (자리); 2마디 막대 = 글리신 2C, 2분자 → 세린 + CO2 (개수)
- 세 칸이 한 줄 = 세 소기관 협업 (자리)
→ 9개

### 구역3 담쟁이 집: **C4 식물 (엽육 → 유관속초, 공간적 분리)**
1. 담쟁이 바깥 + 두꺼운 벽 안방 = 엽육세포 바깥 / 유관속초 안쪽 (자리)
2. 지붕 뚫는 관 묶음 5~6개, 띠 2 = 유관속 (모양/개수)
3. 자석 = PEP 카르복실화효소 (CO2 친화력 높고 O2 무반응) (뜻)
4. 자석에 붙은 4마디 막대(짙은 1 + 3) = PEP 3C + CO2 → OAA 4C (개수)
5. 안방 벽 틈(덮개)으로 들어가는 4마디 막대 = 4C산(말산)이 유관속초로 이동 (자리)
6. 안방의 짙은 물방울 비 약 25~30 = 탈카르복실화로 CO2 농축 (개수/색)
7. 안방의 망원경 + 5마디 막대 + CO2 방울 = Rubisco는 유관속초에서 캘빈 회로 (자리)
8. 바닥 3마디 막대 + 금화 = 피루브산 → PEP 재생에 ATP (개수)
9. 흰 기포 약 20개 전부 안방 밖, 안은 0 = 유관속초는 O2 낮아 광호흡 억제 (자리)
10. 땀 닦는 남자 + 큰 태양 = 고온·강광·건조에 유리 (뜻)
→ 10개

### 구역4 탑: **CAM 식물 (밤 고정 · 낮 방출, 시간적 분리)**
1. 윗층 달·별 = 밤 (자리)
2. 벌어진 두 콩(공변세포) 사이로 짙은 방울 3 = 밤에 기공 열림, CO2 유입 (개수)
3. 자석 남자 + 항아리 = PEP 카르복실화효소가 CO2를 4C산으로 고정해 액포에 저장 (동작)
4. 항아리 속 막대 5, 끝마다 짙은 방울 = 4C산 저장 (개수)
5. 바닥의 짧은 막대 더미 약 6 = PEP 재료(전분 분해) (추정)
6. 사다리 = 밤에서 낮으로 시간 이동 (자리)
7. 아래층 해 + 맞닿은 두 콩 = 낮 기공 닫힘, 수분 보존 (모양)
8. 쓰러진 항아리 + 짙은 방울 4 = 말산 방출 → CO2 (개수)
9. 망원경 + 5마디 막대 = 낮 캘빈 회로 (자리)
10. 한 건물 위아래 = 시간 분리 (C4는 공간 분리) (자리)
→ 10개

## ③ 뜻 모를 것 · 어색한 것 · 헷갈리는 것
- 모름: 검은 구멍(G3P 막대 도착점), 포도 자루 8알, 방B 바닥 구멍, 막대 한쪽 끝 작은 고리(인산기?), 렌즈 둘레 호선, 방패 총 3개(창 2 + 손 1)의 수 뜻.
- 헷갈림: 짙은 방울을 CO2로 읽었으나 물(땀·증산) 가능성; 자석이 PEP 카르복실화효소인지 펌프인지; 항아리가 액포인지 단순 저장인지.
- 어색: 안방 지붕 아래 실내 비, 바깥 한낮 태양 + 탑 윗층만 밤(의도된 대비로 보임).
- 이어 붙인 흔적: 없음. 하늘·바닥 연속, 큰 지붕이 작은 방 지붕으로 이어짐.

## ④ 한 문장
Rubisco는 CO2를 만나면 캘빈 회로로 당을 만들지만 O2를 만나면 광호흡으로 손해를 보므로, 더운 건조 환경에서는 C4(공간 분리)·CAM(시간 분리)이 Rubisco 주변 CO2를 높여 이를 피한다.
