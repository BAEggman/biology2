# stage1 — 생판 (그림만 보고 읽은 것)

## ① 판 전체 표제어
- 1순위: **광합성 탄소 반응 — 캘빈 회로(C3)·광호흡·C4·CAM** (75%)
- 2순위: **광호흡과 C4·CAM 보완 전략(고온·건조 적응)** (10%)
- 판을 꿰는 규칙: 크림·갈색 줄무늬 막대의 마디 수 = 탄소 수(5마디 RuBP, 3마디 3C). 붉은(루비) 렌즈 망원경 = 루비-스코프 = Rubisco [소리]. 금화 = ATP. 회색 방울 = CO2(탄소색). 흰 구슬·흰 방울 = O2.

## ② 구역별
**구역1 큰 작업방 — 캘빈 회로(고정→환원→재생)** [읽힌 13]
- 망원경 렌즈에 막대 끝이 꽂힘: RuBP가 Rubisco에 결합 [소리·자리]. 둘레 회색 방울 3개 = CO2 3분자(3바퀴=G3P 1개) [개수]
- 작업대의 부러진 막대 3+3: 6C 중간체가 3-PGA 2분자로 쪼개짐 [뜻]. 한쪽 끝 진회색 원통 = 새로 붙은 탄소, 얹힌 금화 = ATP 인산화
- 햇살 드는 창 + 금화 바구니(약 15) + 방패 2개: 명반응 산물 ATP·NADPH 공급 [자리]. 방패 = NADPH는 추정
- 방패에 망치질하는 남자: 환원 단계(ATP·NADPH 소모) [뜻, 추정]
- 6칸 시험관 선반(5칸에 3마디 막대, 1칸 빔): G3P 6분자 중 5개 재순환·1개 순생산 [개수 6=5+1]
- 5마디 막대 3개를 안고 가는 남자: RuBP 3분자 재생(5 G3P 15C → 3×5C) [개수 3]. 막대 끝 금색 타원 = 인산
- 판자에 기댄 4마디 막대 = 4C 중간체(추정). 쥐구멍·판자 = 모름

**구역2 첫째 좁은 방 — 광호흡① 엽록체(Rubisco 산소화)** [읽힌 3]
- 5마디 막대 + 망원경 접점에 흰 구슬 1개: CO2(회색) 대신 O2(흰색)가 RuBP와 반응 → 3-PGA + 2-포스포글리콜산 [색·뜻]
- 벽 틈에 떨어지는 금화 1개: ATP 소모(광호흡은 에너지 낭비)
- 쏟아진 보라 구슬(약 8)·기운 자루: 모름(NH3? Pi?)

**구역3 둘째 좁은 방 — 광호흡② 퍼옥시좀** [읽힌 3]
- 흰 거품 가득한 통 + 국자: H2O2를 카탈레이스가 분해해 O2 거품 [모양·색]. 바닥 배수구 = 물(추정). 바닥 3마디 막대 = 3C 산물(추정)

**구역4 셋째 좁은 방 — 광호흡③ 미토콘드리아** [읽힌 4]
- 주철 난로 = 미토콘드리아(연소=호흡). 주름 연통(약 10겹) = 크리스타 [모양]. 굴뚝 연기 + 회색 방울 1개 = CO2 방출(글리신 2→세린+CO2, 탄소 손실). 바닥 2마디 막대 = 글리신 2C(추정)

**구역5 해 아래 정원 오두막 — C4 식물** [읽힌 10]
- 큰 해 + 땀 닦는 남자: 강광·고온·건조에 적응 [뜻]
- 우거진 식물 = 엽육세포, 두꺼운 돌 방 = 관다발초세포 [자리·모양]
- 방 안 소나기(회색 방울 약 25) = CO2 농축 [개수]. 지붕 쪽 파이프 5개 = 모름(관다발? CO2 펌프?)
- 벽 틈으로 들어오는 작은 막대 + 김: 4C산이 들어와 CO2 방출
- 방 안 망원경 + 5마디 막대 + 큰 회색 방울: 관다발초세포의 Rubisco가 CO2 고정(O2 없음)
- 방 밖 흰 방울(약 17) = O2는 엽육 쪽
- 남자 손의 3마디(금색 마디, 끝 방울) = PEP+CO2(추정). 바닥 막대+금화 = PEP 재생에 ATP(추정)

**구역6 탑 — CAM 식물(밤/낮)** [읽힌 10]
- 위층 밤(초승달·별): 밤에 기공 열림. 콩팥 모양 초록 2개 사이 틈 + 방울 3 = 공변세포·열린 기공, CO2 유입 [모양·개수]
- 무릎 꿇고 막대를 항아리에 꽂는 남자, 막대 더미(약 6), 항아리(막대 6, 방울 붙음): 밤에 CO2를 4C산(말산)으로 만들어 액포(항아리)에 저장
- 아래층 낮(해): 땅콩 모양 2개 맞붙음 = 닫힌 기공
- 쓰러진 항아리에서 쏟아지는 막대 + 방울 3: 말산 방출 → CO2
- 망원경 + 5마디 막대 + 회색 화살촉: 방출된 CO2로 Rubisco가 캘빈 회로
- 사다리: 밤→낮 시간 분리(추정)

## ③ 뜻 모를 것·어색함·헷갈림·이은 흔적
- 모름: 방패의 정체(NADPH? 회로?), 보라 구슬 자루, 쥐구멍, 판자, 파이프 5개, 탑의 문·좁은 창.
- 헷갈림: 회색 방울이 CO2인지 물인지(굴뚝·비·탑); 콩팥(강낭콩)·땅콩 모양이 신장·땅콩으로 읽힐 위험(공변세포); 금화(ATP)와 막대 위 금색 타원(인산); 왼벽 막대만 갈색 시작; 둘째 방 3마디·셋째 방 2마디(순서 뒤바뀐 듯); 거품 통이 퍼옥시좀인지 녹말·설탕 저장인지; 난로가 미토콘드리아인지 고온 요인인지; 큰 방과 좁은 방 3개가 한 지붕이라 같은 묶음인지 불명.
- 환경 기울기: 왼쪽 푸른 하늘·초록 방 → 오른쪽 노란 하늘·모래(고온·건조).
- 이은 흔적: 탑 아래층 사다리 발 밑 밝은 직사각 패치 2곳, 둘째 방 바닥 밑 번진 이중 먹선.

## ④ 한 문장
회색=CO2·흰색=O2·마디=탄소로 읽으면, 보통(C3)은 Rubisco가 RuBP에 CO2를 붙이는 캘빈 회로로 돌지만 고온·건조에선 O2가 끼어들어 광호흡으로 낭비하므로, 식물은 CO2를 공간(C4)·시간(CAM)으로 따로 모아 이를 피한다.
