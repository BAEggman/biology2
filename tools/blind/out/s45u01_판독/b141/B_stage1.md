# stage1 — 생판(그림만 보고)

## ① 판 전체
- 1순위 **광합성 탄소 반응: 캘빈 회로·광호흡·C4·CAM** (85%) / 2순위 **C3·C4·CAM 탄소 고정 경로 비교** (10%)
- 근거: 네 구역에 루비 망원경(효소)·줄무늬 막대(탄소 뼈대, 한 칸=C 1)·회색 방울(CO2)·금화(ATP)가 되풀이되고, 해·달·콩팥 모양 두 세포(공변세포)가 나온다.

## ② 구역별 (왼쪽→오른쪽)

### 구역1 큰 작업장 — **캘빈 회로(고정·환원·재생)** [10개]
- 루비 렌즈 망원경 1 = 루비스코 (소리 루비↔Rubisco)
- 5칸 막대 = RuBP (개수 5)
- 회색 방울 3 = CO2 3분자 (개수; 회색은 판 전체에서 CO2)
- 탁자의 부러진 3칸 막대 2토막 = 6C가 쪼개진 3-PGA 2, 한 토막 끝 회색 칸 = CO2 유래 탄소 (개수, 찢긴 모양)
- 금화 2(토막마다 1) = ATP, 창턱 바구니 = 명반응 공급
- 방패 = NADPH(추정), 회색 끝에 눌러 환원, 창턱에 2장
- 창문 + 주황 빛줄기 = 명반응, 초록 방 = 기질
- 랙 6칸: 3칸 막대(G3P) 5 + 빈 컵 1 (개수)
- 3칸 막대가 벽의 검은 구멍으로 나감 = 순생산 G3P 1 배출
- 소년이 멘 5칸 막대 3 + 금화 3 = 재생(G3P 5→RuBP 3, ATP 3), 망원경 쪽으로 걸어 회로가 닫힘

### 구역2 세 칸 곁방 — **광호흡(엽록체→퍼옥시솜→미토콘드리아)** [9개, 모름 1]
- 방 3칸 = 소기관 3 (개수, 자리)
- 칸1 망원경 + 5칸 막대 끝의 흰 진주알 1 = O2가 붙는 루비스코 산소화 (구역1은 회색, 여기는 흰색)
- 칸1 선반의 회색 방울 1 = CO2가 적어 O2에 밀림
- 칸1 벽 동전 투입구 = ATP 소모, 낭비 경로 (뜻)
- 칸2 넘치는 흰 거품 통 = 퍼옥시솜 H2O2를 카탈레이스가 분해(O2 거품) (모양)
- 칸2 바닥 2칸 막대 = 글라이콜산·글리옥실산 2C (개수 2)
- 칸3 주철 난로(주름 몸통, 아코디언 관) = 미토콘드리아(크리스타) (모양)
- 칸3 굴뚝 연기 + 회색 방울 1 = CO2 방출(글리신 2→세린+CO2+NH3) (자리: 지붕 밖)
- 칸3 바닥 2칸 막대 = 글리신 2C
- 모름: 칸1 찢어진 자루의 보라 포도알 8 (NH3? 인산?)

### 구역3 해 아래 작은 집 — **C4 식물(공간 분리: 엽육→유관속초)** [11개]
- 큰 흰 해 + 땀 닦는 남자 = 고온·강광·건조, 기공 닫힘 (뜻)
- 금고를 두른 초록 덩굴 = 엽육세포(크란츠 고리)
- 두꺼운 금고 = 유관속초세포 (자리, 두꺼운 벽)
- 금고를 관통해 끈 2줄로 묶인 파이프 5~6 = 유관속 (bundle; 개수)
- 붉은 말굽자석 = PEP 카복실화효소 (CO2에 끌림, O2는 안 붙음)
- 회색 캡 + 3칸 = 4칸 막대 = 옥살아세트산·말산 4C = PEP(3C)+CO2 (개수 4, 이름 C4)
- 금고 벽 경첩 문틈을 지나는 4칸 막대, 점선 통로 = 원형질연락사로 말산 이동
- 금고 안 회색 방울 약 20 = CO2 농축(탈카복실화)
- 금고 안 망원경 + 5칸 막대 + 회색 방울 = 유관속초의 캘빈 회로
- 흰 방울(O2): 바깥 열 개 넘고 금고 안 2 = 안쪽 O2 낮음, 광호흡 억제
- 금고 밖 바닥 3칸 막대 + 금화 1 = 3C→PEP 재생에 ATP, 엽육으로 회수

### 구역4 2층 탑 — **CAM(시간 분리: 밤 고정, 낮 환원)** [9개]
- 위층 밤 / 아래층 낮 = 시간 분리 (자리)
- 초승달·별 + 콩팥 두 세포가 크게 벌어짐 = 기공 열림, 회색 방울 3 낙하 = 밤에 CO2 흡수 (개수 3)
- 무릎 꿇은 남자가 말굽자석으로 회색 캡 막대 잡음 = PEPC의 CO2 고정
- 점토 항아리 = 액포, 회색 방울 달린 막대 약 6 = 말산 저장
- 바닥에 쌓인 3칸 막대 약 7 = PEP 재료(녹말 분해)
- 아래층 해 그린 창 + 맞붙은 콩팥 두 세포 = 낮, 기공 닫힘
- 쓰러진 항아리에서 쏟아지는 막대 2 + 회색 방울 3 = 말산이 나와 CO2 방출
- 망원경 + 5칸 막대 + 회색 조각 = 낮의 루비스코·캘빈 회로
- 사다리 = 밤→낮을 잇는 시간 이동

## ③ 어색·헷갈림·이어 붙임
- 뜻 모를 것: 보라 포도알 8, 동전 투입구의 정확한 뜻, 칸1·2의 얇고 키 큰 판자, 배수구 구멍, 방패의 정체, 막대 끝 고리(인산? 방향표?)
- 어색: 첫 막대 윗끝이 렌즈에서 가늘어지고 점선 흔적(덧붙인 듯). 구역1 랙 위 벽에 직사각형으로 톤이 다른 자국과 가는 세로 금(지우고 덧칠한 흔적?)
- 헷갈림: 회색 방울(CO2)↔물방울, 흰 알·흰 방울·흰 거품(O2 계열), 막대 칸 수 5·4·3·2, 자석이 C4와 CAM에 둘 다 나옴, 금화↔반짝임
- 이어 붙임: 하늘·땅은 한 파노라마. 막대·금화·자석·방울은 윤곽이 또렷한 스티커처럼 배경에 얹힘

## ④ 한 문장
C3의 캘빈 회로(CO2 3→G3P 6 중 1만 순생산, 5로 RuBP 3 재생)는 루비스코가 O2도 받아 광호흡이라는 낭비를 낳으므로, 덥고 건조한 곳의 식물은 C4(공간 분리)와 CAM(시간 분리)으로 CO2를 먼저 모아 루비스코 둘레 농도를 높인다.
