# stage2 — 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳)

## 판정
- 풀린 것: 포도(#90 = 포도당; 1단계 모름) · 방패(#114 = NADPH 확정) · 반짝임(#161) · 마디 규칙(#159) · 거품·국자(#160·#163) · 초승달(#80) · 자석(#162) · 해·창(#118).
- 고친 것: 칸2 흰 거품은 O2가 아니라 H2O2 자체. 「초록 방 = 기질」은 삭제(기질 = 술 깔개 #164, 이 판에 없음). 명반응 항목(#164·#167·#168)이 이 판에 하나도 없음 = 탄소 반응 판. 판 이름은 그대로, 읽힘은 한 단계 나아짐.

## ① 판 전체
- 1순위 **광합성 탄소 반응: 캘빈 회로·광호흡·C4·CAM** (90%) / 2순위 **C3·C4·CAM 탄소 고정 경로 비교** (7%)

## ② 구역별 + ⑤ 까닭

### 구역1 큰 작업장 — **캘빈 회로(고정·환원·재생)** [10개]
1. 루비 스코프(#34) = 루비스코 → 까닭: 렌즈는 막대 끝에 닿고 뒤끝은 탁자 위 토막을 향함, 점선 호 = 작동 중
2. 5칸 막대(#159) = RuBP → 까닭: 칸 수 = 탄소 수, 소년이 멘 막대와 같은 5칸 = 돌아 되돌아옴
3. 어두운 방울 3(#16) = CO2 → 까닭: 허공에서 내려와 막대 끝에 붙음, 3은 소년 막대 3·랙 6칸(3×2)과 맞물림
4. 부러진 3칸 토막 둘 = 3-PGA → 까닭: 5칸 + 어두운 방울 1 = 6이 찢겨 3+3 = 불안정, 어두운 칸은 한 토막에만
5. 금화 2(#8) = ATP → 까닭: 토막 둘에 금화 둘, 하나씩 곁에
6. ↻ 방패(#114) = NADPH + 반짝임(#161) → 까닭: 첫 토막엔 금화만, 둘째엔 금화 + 방패 + 반짝임 = 금화 → 방패 순으로 환원(순서는 추정)
7. ↻ 창·빛줄기(#118) + 창턱 금화·방패 2 = 빛이 대는 ATP·NADPH → 까닭: 빛줄기가 방패 든 남자와 토막에 닿고 금화 수북 ↔ 방패 둘 = 금화를 더 씀
8. 랙 6칸 = G3P 5 + 빈 컵 1 → 까닭: 같은 컵 여섯 중 하나만 빔(하나만 다름), 막대 5엔 반짝임 = 여섯 중 하나 나가고 다섯 남음
9. 검은 구멍으로 나가는 3칸 막대 = 순생산 1 → 까닭: 빈 컵 곁에서 한 개만 사라짐; 구멍이 검은 까닭 모름
10. 소년의 5칸 막대 3 + 금화 3 = 재생 → 까닭: 3×5 = 랙에 남은 3칸 5개(15), 금화는 막대 끝마다 하나, 스코프 쪽으로 걸어 = 되돌아 닫힘

### 구역2 세 칸 곁방 — **광호흡(엽록체→퍼옥시솜→미토콘드리아)** [9개]
1. 같은 틀의 좁은 방 3칸 = 소기관 셋(추정) → 까닭: 칸마다 큰 물건 하나만 선 같은 방이 나란함 = 차례로 거침
2. 칸1 막대 끝 밝은 방울(#17) = O2 → 까닭: 구역1에서 어두운 방울이 붙던 자리에 밝은 방울(하나만 다름) = O2가 CO2 자리를 차지
3. 칸1 선반의 어두운 방울 1 = CO2 → 까닭: 붙지 못하고 비켜 떨어짐 = 밀림
4. ↻ 칸1 동전 투입구 = ATP를 씀 → 까닭: 금화가 떨어져 들어가는 동작(구역1은 쌓인 쪽); 어느 단계인지는 까닭 모름
5. ↻ 칸1 보라 포도 8(#90) = 포도당 → 까닭: 덧댄 낡은 자루에서 쏟아져 흩어짐 = 새는 포도당(추정), 하필 O2 붙는 칸; 8은 까닭 모름
6. ↻ 칸2 고운 거품(#160) + 국자(#163) = H2O2·퍼옥시솜 → 까닭: 둥근 알 아닌 거품이 넘쳐 국자·배수구로 = 생겨서 치워지는 곳
7. 칸2·3 바닥의 2칸 막대 = 탄소 2 → 까닭: 5·3칸보다 짧음 = 줄어든 조각; 두 막대 고리 쪽 색이 반대인 까닭 모름
8. 칸3 난로·아코디언 = 태워 내보내는 곳(추정) → 까닭: 굴뚝이 지붕을 뚫고 나감 = 안에서 밖으로; 약속표에 없음
9. 굴뚝의 어두운 방울 1 + 연기 = CO2 방출 → 까닭: 지붕 밖 허공으로 나감 = 구역1(밖→안)과 반대; 수 1은 모름

### 구역3 해 아래 작은 집 — **C4 식물(공간 분리: 엽육→유관속초)** [11개]
1. 큰 해(#118) + 땀 = 강한 빛·더위 → 까닭: 해가 하늘을 채울 만큼 큼(구역4 창 속 해는 작은 원), 이마 닦는 동작 = 더워 힘든 환경
2. 금고를 두른 덩굴 = 엽육세포 → 까닭: 금고 양옆을 에워싸 고리를 이룸(약속표에 없음)
3. 두꺼운 금고 = 유관속초(약속표 밖) → 까닭: 벽 안 어두운 방울 약 20 ↔ 집 밖 1 = 벽이 높은 농도를 가둠
4. 끈 두 줄로 묶은 파이프 5~6 = 유관속(약속표 밖) → 까닭: 묶음이 금고 지붕을 뚫고 안까지 = 금고가 감쌈; 5~6은 모름
5. ↻ 붉은 자석(#162) = PEPC → 까닭: 막대 끝 어두운 캡을 붙들고 흰 방울은 호선·불꽃과 함께 튕겨 나감 = CO2만 붙이고 O2는 거부
6. 4칸 막대(캡 + 3칸) = 4탄소 → 까닭: 바닥 3칸 막대에 어두운 캡 하나가 붙음(#159) = 3+1
7. 문틈 통과 막대 + 점선 = 안으로 이동 → 까닭: 두꺼운 벽의 작은 경첩 문틈을 한 개씩, 캡이 안쪽
8. 금고 안 어두운 방울 약 20 = CO2 농축 → 까닭: 같은 크기 방울이 구역1(3)·구역2(1)보다 압도적이고 캡 끝에서 떨어짐
9. 금고 안 스코프 + 5칸 + 어두운 방울 = 캘빈 회로 → 까닭: 구역1과 같은 장면, 스코프는 안에만 자석은 밖에만 = 두 효소가 안팎으로 갈림
10. ↻ 흰 방울 안 2 / 밖 열 넘음 = O2 → 까닭: 안팎 개수 대비 + 집 밖으로 새어 나감 = O2는 바깥에 많음
11. 금고 밖 바닥 3칸 막대 + 금화 1 → 까닭: 캡 떨어진 3칸이 문 밖에 눕고 금화 얹힘 = 되돌아와 3탄소로 되살아나는 데 ATP; 4칸 ↔ 3칸 대비

### 구역4 2층 탑 — **CAM(시간 분리: 밤 고정, 낮 환원)** [9개]
1. ↻ 초승달(#80) = CAM, 위층 밤 / 아래층 해 창(#118) → 까닭: 달 창 위층 ↔ 해 창 아래층이 위아래로 맞섬 = 같은 식물의 밤·낮(층은 칸막이, 다른 날 아님)
2. 위층 콩팥 둘(#14) 벌어짐 + 어두운 방울 3 낙하 → 까닭: 벌어진 틈으로 방울 셋이 항아리로 = 밤에 기공 열려 CO2 들어옴
3. 무릎 꿇은 남자 + 자석 + 캡 막대 = PEPC → 까닭: 막대 끝에 어두운 방울을 붙이는 동작, 곁 더미에서 한 개씩
4. 항아리 속 막대 약 6, 끝마다 어두운 방울 = 저장(그릇은 약속표 밖) → 까닭: 위층 항아리는 가득 ↔ 아래층은 쓰러져 쏟아짐 = 밤에 채우고 낮에 비움
5. 위층 3칸 막대 더미 약 7 = 재료(추정) → 까닭: 장작처럼 수북, 아래층엔 없음
6. 아래층 맞붙은 콩팥 = 기공 닫힘 → 까닭: 틈이 가늘고 방울이 안 들어옴(위층과 대비)
7. 쓰러진 항아리의 막대 2 + 어두운 방울 3 = CO2 방출 → 까닭: 들어온 방울 3 ↔ 쏟아진 방울 3(수 같음), 아가리가 스코프 쪽
8. 아래층 스코프 + 5칸 + 어두운 조각 = 낮의 캘빈 회로 → 까닭: 스코프는 아래층에만, 자석은 위층에만 = 두 효소가 밤낮으로 갈림
9. 사다리 → 까닭: 위층 바닥에서 쓰러진 항아리 앞까지 이어짐 = 위의 것이 아래로(암시); 분명한 까닭 모름

## ③ 안 풀린 것 · 어색 · 헷갈림
- 모름: 난로·아코디언, 막대 끝 고리(막대마다 일정치 않음), 검은 구멍, 칸1·2의 얇은 판자, 포도 8, 구역4 스코프만 점선 호 없음, 파이프 5~6.
- 어색: 첫 막대 윗끝(가늘고 점선 — 덧붙인 듯), 구역1 랙 위 벽의 직사각형 톤 차이.
- 헷갈림: 어두운 방울(CO2)↔물방울, 밝은 알(O2)↔고운 거품(H2O2), 칸 수 5·4·3·2, 자석(PEPC)↔스코프(루비스코)는 다른 효소, 금화↔반짝임. 소품은 스티커처럼 얹힘.

## ④ 한 문장
C3의 캘빈 회로(CO2 3 → G3P 6 중 1만 순생산)는 루비스코가 O2도 받아 광호흡이라는 낭비를 낳으므로, 덥고 건조한 곳의 식물은 자석(PEPC)으로 CO2를 먼저 모아 안팎(C4)이나 밤낮(CAM)으로 나눠 루비스코 곁의 CO2를 높인다.
