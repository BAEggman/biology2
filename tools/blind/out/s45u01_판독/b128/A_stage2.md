# 2단계 약속표 적용 — s45u01 (↻ = 1단계와 달라진 곳)

## 판정
약속표는 「재료」를 풀어 준다: 동전=ATP(#8), 방패=NADPH(#114), 어두운 방울=CO2(#16), 밝은 방울=O2(#17), 루비 스코프=루비스코(#34), 초승달=CAM(#80), 콩팥 모양 둘=공변세포(#14), 포도=포도당(#90), 소복한 흰 거품=H2O2(#160), 마디=탄소·막대에 붙은 어두운 방울도 탄소(#159), 반짝임=환원된 것(#161). 구역1·4는 거의 약속어로 읽힌다. 「장소·장치」(난로·굴뚝·국자·바닥 구멍·관 5개·흰 상자·항아리·사다리·땀 흘리는 남자·큰 해)는 약속표에 없어 1단계 추정 그대로이며 끼우지 않았다. 이 판에 없는 약속: #18 갈라진 땅·마른 바람(바닥은 맨 모래), #17 밝은 방울 머리 사람, #118 틀선 칸. #126(줄지은 소품 중 하나만 다름)은 빈 컵 1칸과 겹치나 5+1 개수로 읽음.

## ① 판 표제어
- 1순위 **광합성 탄소 반응: 탄소 고정 경로 총정리(캘빈 회로·광호흡·C4·CAM)** — 90% ↻(85→90, 루비스코·CAM·탄소 막대가 약속으로 확정)
- 2순위 **루비스코의 CO2 고정·O2 반응과 C4·CAM의 CO2 농축 전략 비교** — 55%

## ② 구역별
### 구역1 큰 작업실 — **캘빈 회로(고정→환원→RuBP 재생)** — 13개
1. 루비 스코프 = 루비스코 (소리·#34)
2. 어두운 방울 3 = CO2 3분자 (#16·개수)
3. 5마디 막대 = RuBP 5C (#159)
4. ↻ 막대 끝에 붙은 어두운 방울 = 탄소 하나 → 5+1 = 6C 중간체
5. 탁자의 부러진 3마디 토막 2 = 3-PGA 2 (6→3+3), 주둥이 앞 속도선 ↻ 새로 봄
6. ↻ 한 토막의 남색 마디 = CO2 유래 탄소 (추정→확정)
7. ↻ 창가 동전 바구니 = ATP (인산 아님)
8. ↻ 창가 방패 2 = NADPH (약함→확정)
9. 방패·동전을 쓰는 남자 = 환원(3-PGA→G3P)
10. ↻ 시험관대 6칸 중 반짝이는 3마디 막대 5 = 환원된 G3P 5 재순환
11. ↻ 빈 칸 1 + 구멍으로 나가는 반짝이는 막대 1 = 순생산 G3P 1
12. 5마디 막대 3 + 동전 3(반짝임 없음) = RuBP 3 재생, ATP 3
13. 운반꾼이 곁방으로 감 = 순환·연결 (추정)

### 구역2 세 칸 곁방 — **광호흡(RuBP 산소화→글리콜산 경로)** — 10개
1. 칸 3개 = 엽록체·퍼옥시좀·미토콘드리아 (추정)
2. 칸A 루비스코에 5마디 막대 + 밝은 방울 1 = RuBP + O2, 어두운 방울이 안 붙음 (#17·#159)
3. 칸A 벤치 모서리 연한 어두운 방울 1 = CO2 적음 (추정)
4. ↻ 칸A 떨어지는 동전 = ATP 소모 (인산 해석 폐기)
5. ↻ 칸A 쏟아진 포도 8 = 포도당 손실 (모름→풀림, 쏟아짐 뜻은 추정)
6. ↻ 칸B 통의 소복한 고운 거품 = H2O2 (O2 추정 정정)
7. 칸B 2마디 막대 = 2C (글리콜산·글리옥실산)
8. 칸C 굴뚝 위 어두운 방울 1 + 연기 = CO2 방출
9. 칸C 2마디 막대 = 글리신 2C
10. 칸C 주름 난로 = 미토콘드리아 (추정)

### 구역3 해 아래 초록 집 — **C4 식물(엽육 고정→유관속초 CO2 농축)** — 9개
1. 큰 해 + 땀 닦는 남자 = 고온·강광·건조 (뜻, 약속 밖)
2. 덤불 = 엽육세포, 흰 상자 = 유관속초세포 (자리)
3. 끈 2개로 묶인 관 5개 = 관다발 (모양·개수)
4. ↻ 상자 안 어두운 방울 약 20 = CO2 농축 (#16)
5. 상자 안 루비스코 + 5마디 막대 + 끝에 붙은 방울 = RuBP + CO2
6. ↻ 밝은 방울(O2)은 상자 밖에만 = 안은 O2 낮아 광호흡 억제 (방울 뜻 확정, 자리 해석은 추정)
7. ↻ 남색 끝 4마디 막대 2 = 3C + CO2 탄소 1 = 4C산 운반 (#159)
8. 문틈 경첩 구멍 = 원형질연락사 (약함)
9. 바닥 3마디 막대 + 동전 = 탈탄산 뒤 3C 복귀, ATP로 PEP 재생

### 구역4 2층 탑 — **CAM 식물(시간 분리)** — 11개
1. ↻ 초승달·별의 윗방 = CAM의 밤 (#80)
2. 해 비친 아랫방 = 낮
3. ↻ 윗방 콩팥 모양 둘 벌어짐 = 공변세포 열림 (#14)
4. 틈 사이 어두운 방울 3 = CO2 흡수
5. 아랫방 콩팥 모양 둘 맞붙음 = 닫힘
6. 항아리 = 액포 (모양, 약속 밖)
7. ↻ 항아리 속 막대 6 = 3마디 + 끝의 어두운 방울 = 4C 말산 (#159)
8. 무릎 꿇고 막대를 넣는 남자 = PEP + CO2 → 말산 저장
9. 바닥 3마디 막대 더미 7쯤(반짝임 없음) = 3C 재료 PEP (추정)
10. 쓰러진 항아리의 막대·어두운 방울 3 = 낮 말산 방출·탈탄산 → CO2
11. 5마디 막대 + 루비스코 = 낮 캘빈 회로

## ③ 남은 모름·헷갈림·이은 흔적
- 약속표 밖: 난로 · 국자 · 칸B 바닥 구멍 · 구역1 검은 구멍(출구 추정) · 관 5개 · 사다리 · 막대 끝 고리 · 칸A에 떨어지는 남색 조각+동전(탄소 1과 ATP의 낭비? 모름).
- ↻ 해소: 둥근 방울(CO2·O2)과 소복한 거품(H2O2)이 갈림. 구역3 상자 안 방울은 어두운 색이라 빗물이 아니라 CO2.
- 이은 흔적(그대로): 구역1 맨 왼쪽 스코프·탁자 둘레 점선 윤곽, 구역3 바닥 막대 오른쪽 번진 끝.

## ④ 한 문장
루비스코는 RuBP에 CO2를 붙여 ATP·NADPH로 포도당 쪽 G3P를 만들지만 O2를 붙이면 광호흡으로 낭비하니, C4는 CO2를 유관속초에 모으고 CAM은 밤에 말산으로 저장해 낮에 쓴다.
