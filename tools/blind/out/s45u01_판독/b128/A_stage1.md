# 1단계 생판 — s45u01 (그림만 보고 읽음)

## ① 판 표제어
- 1순위 **광합성 탄소 반응: 탄소 고정 경로 총정리(캘빈 회로·광호흡·C4·CAM)** — 확신 85%
- 2순위 **루비스코의 CO2 고정과 O2 반응, 이를 보완하는 C4·CAM 전략** — 확신 55%

판 안에서 스스로 정리된 약속: 루비 렌즈 황동 망원경 = 루비스코(소리 "루비"), 줄무늬 막대 = 탄소 골격(마디 1개 = C 1개, 5·3·4·2마디가 구역마다 일관), 회색 방울 = CO2, 노란 동전 = 인산/ATP, 흰 구슬·거품 = O2, 남색 마디 = CO2에서 새로 붙은 탄소(추정).

## ② 구역별 (왼쪽부터 4구역)

### 구역1 큰 작업실 — **캘빈 회로(고정→환원→RuBP 재생)** — 12개
1. 루비 망원경 = 루비스코 (소리)
2. 망원경으로 드는 회색 방울 3 = CO2 3분자 (개수)
3. 망원경 눈에 물린 5마디 막대 = RuBP(5C) (개수)
4. 탁자 위 부러진 3마디 토막 2 = 6C 중간체가 3-PGA 2분자로 쪼개짐 (모양·개수)
5. 한 토막 끝의 남색 마디 = CO2 유래 새 탄소 (색, 추정)
6. 창가 햇살 속 동전 바구니(수북) = 명반응이 대는 ATP (자리·뜻)
7. 창가 방패 2 = NADPH (뜻, 약함)
8. 방패 가운데를 손보는 남자(곁에 동전·토막) = 환원: 3-PGA→G3P, ATP·NADPH 소모 (동작)
9. 시험관대 6칸 중 3마디 막대 5 = G3P 5분자는 회로에 남음 (개수)
10. 빈 칸 1 + 검은 구멍으로 빠지는 3마디 막대 1 = 6개 중 1개만 순생산 (개수·자리)
11. 5마디 막대 3개·동전 3개를 안은 운반꾼 = G3P 5(15C)→RuBP 3(15C) 재생, ATP 3 (개수)
12. 운반꾼이 오른쪽 곁방으로 걸어감 = RuBP가 다시 루비스코로(순환) (동작, 추정)

### 구역2 세 칸 곁방 — **광호흡(RuBP 산소화→글리콜산 경로)** — 8개
1. 칸 3개 = 엽록체·퍼옥시좀·미토콘드리아 3곳 (개수, 추정)
2. 칸A 망원경에 5마디 막대 + 흰 구슬 1 = RuBP + O2 산소화 (모양)
3. 칸A 벤치 모서리의 연한 회색 방울 1 = CO2는 적고 O2가 많은 조건 (개수, 추정)
4. 칸B 흰 거품 양동이 = 퍼옥시좀 H2O2 분해 거품(O2) (모양, 추정)
5. 칸B 2마디 막대 = 2C(글리콜산·글리옥실산) (개수)
6. 칸C 주름진 난로 = 미토콘드리아(크리스타 주름) (모양, 추정)
7. 칸C 굴뚝 위 회색 방울 1 + 연기 = 글리신 탈탄산으로 CO2(·NH3) 손실 (모양)
8. 칸C 2마디 막대 = 글리신 2C (개수)
모름: 자주색 열매 8알 쏟아진 자루, 칸A 천장에서 떨어지는 동전 붙은 남색 조각, 칸B 바닥 구멍.

### 구역3 해 아래 초록 집 — **C4 식물(엽육 고정→유관속초 CO2 농축)** — 9개
1. 큰 해 + 땀 닦는 남자 = 고온·강광·건조 (뜻)
2. 바깥 덤불 = 엽육세포, 안의 흰 상자 = 유관속초세포 (자리)
3. 끈 2개로 묶인 관 5개 = 관다발 (모양·개수)
4. 상자 안 회색 방울 약 20 = CO2 농축 (개수)
5. 상자 안 망원경 + 5마디 막대 = 유관속초에서 루비스코·캘빈 (모양)
6. 흰 구슬(O2)은 상자 밖에만 = 유관속초 O2 낮음, 광호흡 억제 (자리, 추정)
7. 남색 끝 4마디 막대 2(문틈·남자 손) = CO2 실은 4C산(OAA·말산) 운반 (개수·색)
8. 문틈 경첩 구멍 통과 = 원형질연락사 (자리, 약함)
9. 바닥 3마디 막대 + 동전 1 + 흐린 끝 = 탈탄산 뒤 3C 복귀, ATP로 PEP 재생 (개수)

### 구역4 2층 탑 — **CAM 식물(시간 분리: 밤 흡수·낮 이용)** — 10개
1. 윗방 밤(달·별) / 아랫방 낮(해) = 시간 분리 (자리)
2. 윗방 콩 2개 벌어짐 = 밤에 기공 열림 (모양)
3. 틈 사이 회색 방울 3 = CO2 흡수 (개수)
4. 항아리 = 액포(유기산 저장) (모양)
5. 항아리 속 막대 6, 끝마다 방울 = 밤에 쌓인 4C 말산 (개수)
6. 무릎 꿇고 막대를 넣는 남자 = PEP+CO2→OAA→말산 저장 (동작)
7. 바닥 통나무 더미 7쯤 = 전분 분해로 PEP 공급 (모양, 추정)
8. 아랫방 콩 2개 맞붙음 = 낮에 기공 닫힘 (모양)
9. 쓰러진 항아리에서 막대·회색 방울 3 쏟아짐 = 낮에 말산 방출·탈탄산 → CO2 (모양·개수)
10. 5마디 막대 + 망원경 = 낮 캘빈 회로 (개수)
모름: 사다리, 왼쪽 문과 가는 창.

## ③ 어색·헷갈림·이은 흔적
- 자주색 열매 8알은 뜻 모름. 막대 끝의 작은 고리(인산 자리?)도 모름.
- 회색 방울을 CO2로 읽었으나 구역3 상자 안은 빗물·증산처럼도 보여 물과 혼동될 수 있음.
- 흰 것 3종(구슬·거품·떠다니는 거품방울)이 모두 O2인지 불확실. 동전도 ATP·인산·PEP 재생에 섞여 쓰임.
- 운반꾼이 구역1 왼쪽 루비스코가 아니라 곁방으로 향함(회로 복귀인지 광호흡 연결인지).
- 이은 흔적: 구역1 맨 왼쪽 망원경·탁자 둘레의 점선 윤곽, 구역3 바닥 막대 오른쪽의 번진 끝.

## ④ 한 문장
루비스코는 CO2를 고정해 캘빈 회로를 돌리지만 O2도 붙여 광호흡으로 낭비하므로, C4(공간 분리)와 CAM(시간 분리)은 CO2를 농축해 이를 피한다.
