# 2단계 (약속표 어휘로 같은 그림 다시 읽기)

## ① 판 전체 표제어
- 1순위 **광합성 탄소 고정(암)반응 — 캘빈 회로·광호흡·C4·CAM** (90%) ↻88→90: 루비스코(#34)·초승달=CAM(#80)·어두운 방울=CO2(#16)·밝은 방울=O2(#17)·마디 막대=탄소(#159)가 한 판에서 맞물림
- 2순위 **광합성 전반(명반응 산물 ATP·NADPH → 암반응)** (6%)
- 판정: 약속으로 더 잘 풀린다. ↻확정: 방패·반짝이·포도·초승달·흰 거품·방울 두 종. ↻철회: 「관 끝 고리=인산」(인산은 성냥개비 #142, 이 판엔 없다 → 고리는 모름)

## ② 구역별 (6구역 그대로)
**구역1 큰 작업실 — 캘빈 회로(C3): 고정→환원→재생**
- 루비스코 망원경 1대 (#34)
- 5마디 막대+끝에 붙은 어두운 방울 1 = 6탄소 중간체 ↻(#159 붙은 방울도 탄소 1)
- 어두운 방울 3(공중 2+붙은 1) = CO2 3 (#16)
- 두 동강 3+3(회색 마개=붙은 방울) = 3-PGA 2 ↻(#159)
- 동전 = ATP (#8): 쪼갠 관 옆 1·소년 3·창가 약 12
- 방패 = NADPH ↻확정(#114): 작업대 1+창 2, 3의 뜻은 모름
- 방패 손질하는 남자 = 환원 단계(동전·방패를 받음) (동작)
- 반짝이는 막대 = 환원된 것 ↻모름→풀림(#161): 틀 5+기댄 1 = G3P 6
- 틀 6칸 = 5 재생+1 순생산 (개수) / 쥐구멍 = 그 1개 탈출 (자리)
- 소년: 5마디 3+동전 3 = RuBP 3·ATP 3 (개수)
- 창가 바구니+방패 2 = ATP·NADPH 쌓인 곳 / 빛줄기는 해 뜬 정상 날 배경(#118) ↻약화
- 남자의 작은 연장: 모름

**구역2 곁채 첫 칸 — 광호흡① 엽록체**
- 루비스코+5마디 막대 (#34·#159)
- 막대 끝 밝은 방울 1 = O2 ↻확정(#17): CO2 대신 O2를 잡음
- 동전 투입구로 떨어지는 동전 1 = ATP 소모 ↻(#8·#148 투입구 어휘)
- 터진 자루의 포도 8 = 포도당 ↻확정(#90), 샘=손실, 8은 모름
- 벤치 밑 연회색 작은 방울 1: 새로 봄, 모름

**구역3 곁채 가운데 칸 — 광호흡② 퍼옥시좀**
- 통에 소복한 고운 흰 거품 = H2O2 ↻확정(#160, 낱낱 둥근 방울 O2와 갈림)
- 2마디 막대 = 2탄소 (#159)
- 국자·바닥 구멍: 약속표에도 없어 모름

**구역4 곁채 셋째 칸 — 광호흡③ 미토콘드리아**
- 주름 기둥 난로: 약속표에 없음, 미토콘드리아 추정 유지(연통은 #36 가스 파이프 아님: 난로에 붙은 연통)
- 연기+어두운 방울 1 = CO2 방출 ↻(#16)
- 2마디 막대 = 2탄소 (#159)

**구역5 햇빛 집 — C4: 엽육 고정→유관속초 CO2 농축**
- 큰 해+땀 닦는 남자: 약속표에 없음, 고온·강광 추정(#18 갈라진 땅은 없다)
- 잎=엽육 / 돌 상자=유관속초 / 끈 2줄 관 5개=유관속: 모두 약속표에 없는 추정
- 상자 안 어두운 방울 십수 개 = CO2 농축 ↻(#16)
- 상자 안 루비스코+5마디+붙은 방울 = 6탄소 ↻
- 어두운 마개+3마디 = 4탄소 막대 2(남자 손·벽 틈) ↻(#159)
- 벽 틈 문: 엽육→유관속초 이동 추정
- 바닥 3마디 막대+동전 = 피루브산+ATP→PEP (#8)
- 집 밖 밝은 방울 약 15(↻다시 셈)·상자 안 0 = O2 ↻(#17), 광호흡 억제

**구역6 2층 탑 — CAM: 밤 고정·저장, 낮 방출**
- 위층 초승달 = CAM ↻(#80)
- 아래층 해 창 = 낮(정상 날 #118)
- 벌어진 콩팥 모양 2 = 공변세포 열림 ↻확정(#14)
- 어두운 방울 3 = 밤 CO2 3 흡수 (#16)
- 항아리(그릇)에 어두운 방울 붙은 3마디 막대(4탄소)를 담는 남자 = 말산 저장, 항아리=액포 추정 ↻(#159·#102 끝말)
- 맞닿은 콩팥 모양 2 = 공변세포 닫힘 (#14)
- 쓰러진 항아리+어두운 방울 3~4 = CO2 방출 (#16)
- 낮 루비스코+5마디+붙은 방울 = 6탄소 ↻

## ③ 잔결
- 모름: 방패 3·포도 8의 개수, 국자·구멍, 난로, 관 끝 고리, 렌즈 둘레 호, 세움판 3, 남자 연장, 사다리. 끼워 보다 버린 약속: #36 연통·#126 시험관 틀·#118 칸막이·#81 흰 구슬·#37 핀 막대.
- 어색: 소년이 오른쪽으로 걷는다. ↻신규 이음새 의심: 햇빛 집 바닥 3마디 막대 오른끝이 뭉개져 풀에 녹음, 상자 안 관 밑의 어두운 얼룩.
- 곁채 3칸=광호흡 읽기 ↻65→80%(H2O2 #160가 퍼옥시좀을 받침).

## ④ 한 문장 ↻
루비스코가 어두운 방울(CO2)을 잡아 마디 막대(탄소)를 늘리고 동전(ATP)·방패(NADPH)로 환원해 포도당을 만들지만, 밝은 방울(O2)이 끼면 광호흡으로 새므로 식물은 CO2를 공간(C4)·시간(초승달 CAM)으로 나눠 농축한다.
