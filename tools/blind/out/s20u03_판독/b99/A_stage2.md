# 2단계 약속표로 다시 읽기 (s20u03) — ↻ = 1단계와 달라진 곳

## ① 판 전체 표제어
- **1순위: ↻ 식물의 환경 반응 — 광수용체(피토크롬·청색광)·광주기성·생체시계·건조 스트레스** 확신 55%
- **2순위: ↻ 식물의 빛 반응(광주기성과 광수용체)** 확신 25% (1단계와 순서를 맞바꿈)
- 판정: 약속표가 구역4·5를 거의 다 풀었다(콩팥 모양 둘=공변세포 한 쌍, 회중시계=생체시계, 어두운·밝은 방울=CO₂·O₂, 루비 스코프=루비스코, 파란 유리알=청색광 수용체, 파란 빛줄기=청색광, 갈라진 땅=건조 스트레스, 틀선 칸=같은 장면의 다른 날). 오른쪽에 빛이 아닌 건조 스트레스가 확인돼 더 넓은 쪽을 1순위로 올렸다. 구역1~3의 물건은 약속표에 항목이 없어 1단계 읽기를 유지하고, 대조 실험(#126)만 새로 적용했다.

## ② 구역별 (5구역)
### 구역1. 밤의 길이를 재는 타이머(임계 암기) — 유지
- 모래시계 1, 검은 모래 = 밤을 재는 타이머. ↻ 회중시계(=생체시계)와 다른 물건이므로 반복 주기가 아니라 밤 한 번의 길이로 읽는다.
- 별 박힌 밤하늘 = 밤, 오른쪽으로 갈수록 별이 줄어 낮이 됨(↻ 별 감소=새벽) = 하루 낮밤 주기.
- 돌탑 = 표에 없음, 모름 유지.

### 구역2. 단일식물·장일식물과 야간 중단 — ↻ 대조 실험 틀
- ↻ 같은 화분·같은 띠 4칸이 하나씩만 다르다(#126): 좌상→우상은 밤 길이만, 좌상→좌하는 섬광만, 좌하→우하는 식물 종류만 → 결과(개화/봉오리)의 원인은 그 하나.
- 노란 판=낮, 검은 띠=밤(색).
- 좌상: 긴 밤(띠 약 3/4) + 국화 활짝 1·봉오리 2 = 단일식물은 긴 밤에 개화.
- 우상: 짧은 밤(약 1/4) + 봉오리 3 = 개화 못 함.
- 좌하: 긴 밤 중간쯤 빨간 섬광 1 + 봉오리 3 = 야간 중단(적색광)이 단일식물 개화를 막음.
- 우하: 같은 섬광 + 분홍 꽃 약 7 = 장일식물은 밤이 끊겨 짧아지면 개화(추정 80%).
- 편지 봉투 + 점선 화살표(잎→줄기→꽃) = 개화 신호(플로리겐)가 잎에서 꽃눈으로 이동.
- 노랑 국화 vs 분홍 다른 종 = 단일·장일 두 유형.

### 구역3. 피토크롬 적색광↔원적색광 가역 스위치(상추 종자 발아) — 유지
- 켜진 붉은 전구 + 싹 튼 씨앗 = 적색광은 발아 촉진(Pr→Pfr).
- 검은 전구(열기선 3) + 안 튼 씨앗 = 원적색광은 억제(검정=눈에 안 보임, 추정 75%).
- 가운데 스위치 1 = 광가역(오가는 전환). 상추 봉지 = 상추 종자(광발아).
- 팻말 [검|빨]→발아, [빨|검]→미발아 = 마지막 빛이 결정. 흙 위 씨앗 = 빛 필요(추정).
- 전구·스위치·봉지·팻말은 약속표에 없어 억지로 끼우지 않음.

### 구역4. ↻ 기공 열림(정상): 청색광→공변세포→CO₂ 입·O₂ 출→루비스코
- 콩팥 모양 둘 + 열린 틈 = 공변세포 한 쌍이 연 기공(#14).
- ↻ 파란 유리알 2(공변세포마다 1) = 청색광 수용체(포토트로핀), 빛을 받는 자리(#122) — 1단계 모름 해결.
- ↻ 파란 빛줄기 3줄 안팎 = 청색광(#125) — '빛'에서 '청색광'으로 구체화.
- ↻ 어두운 방울 약 25개(대각선 11+틈 4+속 9+렌즈 1) = CO₂ 유입(#16), 아래 화살표 1.
- ↻ 밝은 방울 약 25개 + 위 화살표 1 = O₂ 방출(#17).
- ↻ 루비 렌즈 놋쇠 스코프 = 루비스코(#34): 렌즈 발톱이 CO₂ 방울 1개를 붙잡음 = CO₂ 고정 — 1단계 모름 해결.
- ↻ 회중시계 = 생체시계(#15): 기공 개폐에 시계가 관여(50→90%).
- ↻ 큰 장면(해 뜬 맑은 날, 젖은 흙+웅덩이 3)이 정상(#118).

### 구역5. ↻ 건조 스트레스로 기공 닫힘(틀선 칸 = 다른 날)
- ↻ 굵은 틀선 칸 = 같은 장면의 다른 날·다른 조건(#118).
- ↻ 갈라진 땅 = 건조 스트레스(#18). 1단계 'ABA?'는 철회(갓 쓴 아비·셔터가 없다).
- 맞닿은 콩팥 모양 둘 = 공변세포 한 쌍이 기공을 닫음.
- ↻ 밝은 방울 약 30개가 속을 채움 = O₂ 축적, 어두운 방울 0 = CO₂ 차단.
- ↻ 루비스코 렌즈가 O₂ 방울에 맞닿아 분홍빛이 번짐 = CO₂ 대신 O₂와 반응(광호흡, 추정 65%).
- ↻ 시계 2시·파란 빛줄기·파란 유리알이 구역4와 같고 땅만 다름 = 한 가지(건조)만 바꾼 대조.

## ③ 남은 것
- ↻ 풀림: 푸른 구슬, 루비 망원경, 흰 구슬, 어두운 방울, 시계, 구역5의 검은 구분선(이음새가 아니라 틀선), 갈라진 땅.
- 남은 모름: 돌탑, 검은 모래(약속 없음), 검은 전구(추정), 스위치 올림·내림, 공변세포의 분홍 이중 테두리, 구역5 큐브의 갈색 테두리.
- 헷갈림: 검정·빨강이 구역1~3에서 서로 다른 뜻으로 겹침(약속 없음).
- 이음새: x≈953·1274 직선과 구역2의 사각 붙임은 약속과 무관한 제작 흔적으로 유지.

## ④ 한 문장 ↻
한 가지씩 바꿔 보면, 식물은 밤의 길이와 마지막 빛의 색(피토크롬)으로 개화·발아를 정하고, 낮에는 청색광을 받은 공변세포가 기공을 열어 CO₂를 들이고 O₂를 내보내 루비스코를 일하게 하지만, 같은 시각(생체시계)에도 건조 스트레스가 오면 기공이 닫혀 CO₂는 막히고 O₂가 쌓인다.
