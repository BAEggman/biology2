# 2단계 — 약속표로 다시 읽음 (↻ = 1단계와 달라진 곳)

## 판정
약속표가 크게 푼 곳은 구역4·5(공변세포·회중시계·파란 구슬·빛줄기·방울·루비스코·틀선)와 판 전체 윤곽이다. 구역1~3의 핵심 소품(모래시계·붉은/검은 전구·붉은 섬광·편지봉투·스위치·팻말)은 약속표에 없어 1단계 읽기를 그대로 둔다(억지로 끼우지 않음). 구역2·3에는 #126(대조 실험)만 새로 적용된다.

## ① 판 전체
- **1순위: 식물의 빛 반응(광수용체) — 광주기성·피토크롬·청색광·생체시계·기공 조절** — 55% ↻(40→55)
- **2순위: 식물의 환경 반응(빛 + 건조 스트레스)** — 20% ↻(2순위 교체: 시간 측정 → 환경 반응)
- 근거: 파란 구슬(#122)·붉은/검은 전구 = 광수용체, 회중시계(#15) = 생체시계, 갈라진 땅(#18) = 건조 → 오른쪽 큐브가 앞 세 구역과 한 단원이 되는 이유가 풀림(1단계 약점 해소).

## ② 구역별
**구역1 돌기둥·모래시계 — 임계 암기(밤 길이)를 재는 타이머** (약속표 밖)
- 모래시계 = 연속된 밤의 길이 재기 [뜻] ↻ 회중시계(생체시계)와 다른 물건이라 '일주기 진동'이 아니라 '간격 재기'로 가름
- 검은 모래 = 밤·어둠 [색] / 별 하늘 → 낮 하늘 = 하루 흐름 [자리]
- 돌기둥 = 모름(표에 없음) → 3개

**구역2 회색 벽 — 광주기성 + ↻ 대조 실험(#126)**
- ↻ 같은 화분 2×2에 하나씩만 다름 = 한 가지만 바꾼 대조 실험(원인: 띠의 밤 길이 / 붉은 섬광 / 식물 종) [개수]
- 띠 노랑·검정 = 낮·밤(검정 약 73% vs 27%) / 좌상 긴 밤 + 활짝 핀 국화 = 단일식물은 긴 밤에 개화 / 우상 짧은 밤 + 녹색 봉오리 = 개화 못함
- 좌하 긴 밤 + 붉은 섬광(살 12) + 봉오리 = 야간 중단이 단일식물 개화 억제 / 우하 같은 섬광 + 분홍 꽃 = 장일식물은 개화 / 빨강 = 적색광이 효과적
- 편지봉투 1개 + 점선(잎→줄기→꽃) = 플로리겐 이동 → 8개

**구역3 나무판 — 피토크롬: 적색광(R)↔원적색광(FR) 가역, 상추 종자 발아**
- ↻ 같은 화분·선반 둘, 위의 전구만 다름 = 대조 실험(#126)
- 빨간 전구(살 13) = R / 검은 전구 + 열기 3줄 = FR(눈에 안 보이는 빛) / 양상추 봉투 = 광발아 종자
- 싹(떡잎 2장) = R 촉진 / 씨앗 그대로 = FR 억제 / 스위치 = R⇄FR 되돌림 / 팻말 2개(검→빨, 빨→검) = 마지막 빛이 결정 → 8개
- 스위치는 #45(청록 상자·D자 고리)와 달라 DHP 로 읽지 않음

**구역4 왼쪽 큐브 — 맑은 날(정상): 기공 열림, 청색광·생체시계, CO₂ 유입·O₂ 방출, 루비스코** ↻
- 콩팥 모양 둘이 벌어짐 = 공변세포 한 쌍·기공 열림 [#14] / 파란 구슬 2개 = 청색광 수용체(포토트로핀) [#122] ↻ 모름→풀림 / 연파란 빛줄기 3~4줄이 공변세포로 = 청색광 [#125] ↻ '햇살'→청색광
- 어두운 방울 줄(밖 약 11 → 구멍 → 안 약 9) = CO₂ 유입 [#16] ↻ 70%→확정 / 밝은 방울 약 25 = O₂ 방출 [#17] ↻ 수증기 가능성 버림
- 루비빛 렌즈 놋쇠 스코프 = 루비스코 [#34], 렌즈에 붙은 어두운 방울 = CO₂ 고정 ↻ 소리 추정→확정
- 회중시계 2시 = 생체시계 [#15] ↻ 모름→풀림 / 젖은 흙·푸른 웅덩이 3 = 물 충분(자갈=Ca²⁺ 아님: 물빛·광택) / 칸 밖 큰 장면 = 정상 [#118] → 9개

**구역5 오른쪽 큐브 — 틀선 칸(다른 날): 건조 스트레스 → 기공 닫힘** ↻
- 틀선 칸 = 같은 장면의 다른 날 [#118] ↻ 이음 흔적→틀선 / 갈라진 마른 땅 = 건조 스트레스 [#18] / 공변세포 둘 맞붙음 = 기공 닫힘 [#14]
- 파란 구슬·연한 빛줄기는 그대로 = 청색광이 와도 건조가 이겨 닫힘(65%) ↻ / 어두운 방울 0 = CO₂ 끊김 [#16]
- 잎 속을 채운 밝은 방울 = O₂ 축적 [#17] ↻ 수증기·말산 가능성 버림 / 루비스코 렌즈가 밝은 방울에 닿음 = O₂ 와 반응, 광호흡(60%) [#34]
- 회중시계 같은 2시 = 시각은 같고 건조만 다름 [#15·#126] ↻ → 8개

## ③ 모름·헷갈림·이음
- 풀림 ↻: 회중시계·파란 구슬·빛줄기·어두운/밝은 방울·루비스코·갈라진 땅·가운데 검은 세로선(틀선).
- 아직 모름: 돌기둥, 띠 끝의 못 구멍, 화분의 은색 고리, 모래시계·전구·팻말·편지봉투의 약속(표에 없음 — 모양·뜻 추정).
- 그림에 없음: 초승달(#80 CAM)·갓 쓴 아비(#19 ABA)·롤 셔터(#120)가 없어 CAM·ABA·셔터로 읽지 않음. 구역3 씨앗은 손바닥이 없어 종자 휴면(#20)이 아님. 검은 팻말 = 어둠 아닌 FR.
- 이음: 벽|나무판, 나무판|큐브, 4화분 타일 가장자리는 여전히 이음. 두 큐브 사이 선만 틀선.

## ④ 한 문장
식물은 밤의 길이와 적색/원적색광으로 때를 읽고, 맑은 날엔 청색광·생체시계로 기공을 열어 CO₂를 들이고 O₂를 내보내지만, 같은 빛·같은 시각이라도 건조한 날엔 기공이 닫혀 CO₂가 끊기고 O₂가 쌓인다.
