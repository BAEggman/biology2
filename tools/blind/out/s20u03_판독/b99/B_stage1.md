# 생판 stage1 — s20u03 (그림만 보고 읽음)

## ① 판 전체 표제어
- **1순위: 식물의 빛 반응 — 광주기성·피토크롬(+기공 개폐·광호흡)** — 확신 40%
- **2순위: 식물의 시간 측정(밤 길이·생체시계·일주기)** — 확신 20%
- (참고 3순위: 식물의 환경 스트레스 — 건조·기공 폐쇄 10%)
- 근거: 모래시계·밤→낮 하늘·회중시계 2개 = 시간, 빨강/검정 전구·붉은 섬광 = 빛의 파장, 국화·상추 싹 = 반응. 약점: 오른쪽 두 큐브(루비 망원경·흰 구슬)는 광합성 쪽이라 앞 세 구역과 한 단원인 이유가 불확실.

## ② 구역별 (왼쪽부터 5구역; 구역1·2는 같은 벽·하늘 바탕, 구역4·5는 전/후 한 쌍)
**구역1 돌기둥·모래시계(별 하늘) — 임계 암기(밤 길이)를 재는 타이머**
- 모래시계 1개 = 연속된 밤의 길이를 재는 도구 [뜻/모양]
- 검은 모래(흰 점 박힘) = 어둠·밤 [색]
- 하늘이 왼쪽 별밤 → 오른쪽 낮으로 변함 = 밤→낮 하루 흐름 [자리]
- 돌기둥·둥근 창 = 모름 → 읽힌 사실 3

**구역2 회색 벽 2×2 화분 — 광주기성: 단일식물·장일식물, 야간 중단, 플로리겐**
- 화분 4개, 노랑+검정 띠 = 낮·밤 길이 (검정 비율 좌상 약 73%, 우상 약 27%) [자리/개수]
- 좌상: 긴 밤 + 노란 국화 활짝(꽃 3송이) = 단일식물은 긴 밤에 개화 [뜻]
- 우상: 짧은 밤 + 녹색 봉오리 3개 = 밤이 짧으면 개화 못함
- 좌하: 긴 밤 한가운데 빨간 섬광(살 12) + 녹색 봉오리 = 야간 중단은 단일식물 개화 억제(밤이 '연속'이어야 함)
- 우하: 같은 섬광 + 분홍 꽃 핌(다른 종) = 장일식물은 야간 중단에 개화 [자리]
- 섬광이 빨강 = 중단에 효과적인 빛은 적색광 [색]
- 편지봉투 1개 + 점선 화살표(잎→줄기→꽃) = 플로리겐(개화 신호)이 잎에서 꽃으로 이동 [뜻/자리] → 7

**구역3 나무판 — 피토크롬: 적색광(R)↔원적색광(FR) 가역, 상추 종자 발아**
- 켜진 빨간 전구(살 13) = R [색]
- 검은 전구 + 열기 3줄 = FR(눈에 안 보이는 빛, 열) [뜻]
- 양상추 그림 봉투 1개 = 광발아 종자(상추) [모양]
- 빨간 전구 아래 싹(떡잎 2장) = R이 발아 촉진 / 검은 전구 아래 씨앗 그대로 = FR이 억제 [자리]
- 스위치 1개 = R⇄FR 되돌림(Pr⇄Pfr) [뜻]
- 팻말 2개: 검→빨(발아), 빨→검(미발아) = 마지막에 쬔 빛이 결정 [자리] → 7

**구역4 왼쪽 큐브 — 기공 열림: CO2 유입·O2 방출, 루비스코의 CO2 고정**
- 큐브(옆면 잎맥) = 잎, 절단면 = 잎 속 빈 공간, 사선 햇살·밝은 유리벽 = 낮(빛 있음) [모양/자리]
- 콩팥형 2개가 벌어짐 = 공변세포 2개, 기공 열림 [모양]
- 검은 방울 줄(밖 약 11 → 구멍 → 안 약 9) + 아래 화살표 = CO2 유입 (70%) [뜻]
- 흰 방울 약 25 + 위 화살표 = O2(또는 수증기) 방출 [뜻]
- 루비 박힌 망원경 1개 = 루비스코(ruby+scope), 렌즈의 검은 방울 = CO2 고정 (65%) [소리]
- 젖은 흙·물웅덩이 3개 = 물 충분 [뜻] → 6

**구역5 오른쪽 큐브 — 기공 닫힘(건조): O2 축적·루비스코 광호흡**
- 공변세포 2개가 맞붙음 = 기공 닫힘 [모양]
- 갈라진 마른 땅 = 가뭄 → 기공 닫음(수분 보존) [뜻]
- 잎 속을 꽉 채운 흰 구슬 = 갇힌 O2 (수증기일 수도, 55%) [모양]
- 검은 방울 0개 = CO2 못 들어옴 [개수]
- 망원경 렌즈가 흰 구슬에 닿음 = 루비스코가 O2와 반응(광호흡, 55%) [자리] → 5

## ③ 모름·어색·헷갈림·이음
- 모름: 돌기둥(한계·임계 표지석? 근거 약함), 노란 띠 왼쪽 끝의 못 구멍, 화분의 은색 고리, 파란 구슬(공변세포마다 1개, 두 큐브 같은 크기: 물? 청색광? 핵?), 회중시계(두 큐브 모두 2시 정각: 같은 시각 비교? 생체시계?).
- 헷갈림: 흰 구슬 = O2/수증기/말산(CAM)? 검은 방울 = CO2/물? 붉은 렌즈 망원경 = 루비스코(소리) vs 원적색(遠赤, 뜻)? 검은 팻말 = 어둠이 아니라 FR(검은 전구와 짝으로 판단).
- 이음: 벽|나무판(x≈932), 나무판|큐브(≈1245), 두 큐브 사이 검은 세로선(≈1648); 4화분의 직사각 타일 가장자리(대비를 올리면 보임); 나무판 팻말 윗쪽 가로 색 이음; 오른쪽 큐브는 단면 모양·바닥·창틀 화풍이 왼쪽과 다름.

## ④ 한 문장
식물은 연속된 밤의 길이와 적색/원적색광의 마지막 노출로 때를 읽어 개화·발아를 정하고, 낮에 열린 기공으로 CO2를 들이되 건조하면 닫아 O2가 쌓인다.
