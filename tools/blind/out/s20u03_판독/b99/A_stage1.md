# 1단계 생판 읽기 (s20u03, 그림만 보고)

## ① 판 전체 표제어
- **1순위: 식물의 빛 반응 — 광주기성·피토크롬을 중심으로, 기공(청색광)·생물시계까지** 확신 55%
- **2순위: 식물의 환경 신호 반응(빛·물·시간 → 개화·발아·기공 조절)** 확신 25%
- 근거: 왼쪽 밤하늘이 오른쪽 낮으로 이어지는 한 온실, 시계류 3개(모래시계 1·회중시계 2), 밤 길이 띠와 붉은 섬광, 붉은/검은 전구와 상추씨, 공변세포 한 쌍(기공). 오른쪽 두 기공 구역의 단원 소속이 가장 불확실하다.

## ② 구역별 (왼쪽→오른쪽 5구역)
### 구역1. **밤의 길이를 재는 타이머(임계 암기)** — 돌탑·모래시계·밤하늘
- 모래시계 1개, 모래가 검다 = 모양(모래=시간)+색(검정=어둠): 식물이 재는 것은 낮이 아니라 밤(암기)의 길이, 일정 길이 이상이어야 반응(임계 암기).
- 별 박힌 밤하늘 = 자리: 밤. 하늘이 왼쪽 밤→오른쪽 낮으로 번짐 = 자리: 하루 낮밤 주기(광주기).
- 모래시계를 둥근 창에 품은 돌탑(벽돌 기둥) = 모름(추정: 고정된 문턱 '임계', 또는 시계탑).

### 구역2. **단일식물·장일식물과 야간 중단** — 벽의 2×2 화분 4칸
- 노란 판=낮, 검은 띠=밤(색). 띠 길이로 밤 길이를 비교(자리).
- 좌상: 긴 밤(검은 띠 약 3/4) + 활짝 핀 노란 국화 1·봉오리 2 = 단일식물은 긴 밤에 개화(개수).
- 우상: 짧은 밤(검은 칸 약 1/4) + 녹색 봉오리 3 = 단일식물은 밤이 짧으면 개화 못 함.
- 좌하: 긴 밤 한가운데 빨간 섬광 1줄(야간 중단) + 봉오리 3 = 밤을 끊으면(적색광) 단일식물 개화 억제 → 연속된 암기가 관건(자리).
- 우하: 같은 섬광 + 분홍 꽃 약 7송이(다른 종) = 장일식물은 밤이 끊겨 짧아지면 개화(뜻, 추정 80%).
- 좌상의 편지 봉투와 점선 화살표(잎→줄기→꽃) = 개화 신호(플로리겐)가 잎에서 만들어져 위 꽃눈으로 이동(뜻: 편지=메시지, 자리: 잎→꼭대기).
- 노랑 국화 vs 분홍 다른 종 = 단일/장일 두 유형의 구분.

### 구역3. **피토크롬: 적색광↔원적색광 가역 스위치(상추 종자 발아)** — 나무판
- 켜진 붉은 전구 + 싹 튼 씨앗(떡잎 2, 껍질 갈라짐) = 적색광이 발아 촉진(Pr→Pfr 활성형)(색/뜻).
- 검은 전구(열기 물결선 3) + 싹 안 튼 씨앗 = 눈에 안 보이는 원적색광(검정=안 보임)은 발아 억제, Pfr→Pr(추정 75%).
- 가운데 벽 스위치 1개 = 두 형태 사이를 오가는 가역 전환(모양/뜻).
- 상추 그림 씨앗봉지 1 = 상추 종자(광발아 종자)(뜻).
- 팻말 2개: [검|빨] 마지막이 빨강 → 발아, [빨|검] 마지막이 검정 → 미발아 = 마지막에 받은 빛이 결정(자리/순서).
- 씨앗이 흙 위에 노출 = 발아에 빛이 필요(자리, 추정).

### 구역4. **기공 열림 — 낮·빛·젖은 흙에서 기체 교환**
- 신장형 공변세포 2개 + 사이의 어두운 틈 = 기공 열림(모양/개수).
- 짙은 물방울 11개(+작은 점 1)가 대각선으로 틈에 들어오고 아래 화살표 1, 잎 속에서도 약 9개 낙하 = CO2 유입(색·방향, 70%).
- 흰 거품 약 25개 + 위쪽 화살표 1 = O2(+수증기) 방출(70%).
- 푸른 햇살 줄기 3줄 안팎 = 빛이 개구를 유도(자리). 젖은 흙+웅덩이 3 = 물 충분.
- 회중시계(2시) = 시계 → 생물시계/일주기(뜻 50%).
- 망원경+루비 렌즈에 물방울 1 = 모름(후보: 루비+스코프 소리=루비스코, CO2 감지기, 원적색광 말장난). 푸른 구슬 2 = 모름(청색광 수용체? K+·물?).

### 구역5. **기공 닫힘 — 같은 시각(2시)인데 가뭄**
- 맞닿은 공변세포 2개, 틈 없음 = 기공 닫힘(모양).
- 갈라진 마른 땅 + 갈색 잎 가장자리 = 물 부족(가뭄) → 닫힘(ABA?)(뜻 65%).
- 흰 구슬 약 30개가 속을 가득 채움 = 못 나가고 갇힌 기체(O2/수증기, 정체 모름).
- 회중시계가 구역4와 똑같이 2시 = 시각이 아니라 물이 변수(추정).
- 망원경 렌즈에 물방울 없이 흰 구슬만 닿음 = 모름(광호흡?). 푸른 구슬 2 = 모름.

## ④ 한 문장
식물은 낮이 아니라 끊기지 않은 밤의 길이를 재어 꽃피우고(단일·장일, 야간 중단, 개화 신호), 그 빛 감지는 적색·원적색광으로 되돌려지는 피토크롬 스위치(마지막 빛이 결정)가 맡으며, 낮의 빛·물 조건에 따라 기공이 열리고 닫혀 기체 교환이 달라진다.
