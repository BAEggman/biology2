# stage2 — 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳)

## 판정
약속표는 구역4·5를 크게 풀었고(#14 #15 #16 #17 #18 #34 #118 #122 #125), 구역3은 확정·보강(#127), 구역2는 구조만 보탰다(#126). 구역1(모래시계·시계판·돌기둥)은 약속표에 없어 1단계 그대로다. 억지로 안 끼운 것: 돌기둥(#93은 붉은 건물만), 벽 스위치(#45는 청록 상자+D고리), 판마다 놋쇠 구멍 1개(#23은 s37p01 전용), 흙 위 씨앗(#20은 묻고 눌린 씨앗만). 하늘에 초승달(#80)은 없다.

## ① 판 전체 표제어
- 1순위 **식물의 빛 반응과 기공 조절 — 광주기성·피토크롬·청색광(포토트로핀)·생체시계·건조 스트레스(광호흡)** : 65% ↻(55→65)
- 2순위 **식물의 환경 반응(빛·물 신호전달)** : 20%
- 하늘이 밤→새벽→한낮으로 흐르고 맨 오른쪽 틀선 칸만 '다른 날'이다 ↻

## ② 구역별 (5구역 유지)

### 구역1 벽돌 기둥 + 모래시계 : **밤(암기) 길이를 재는 타이머** (약속 밖 — 그대로)
- 모래시계 = 시간 길이 타이머, 별하늘 아래라 낮이 아니라 밤의 길이 (뜻·자리)
- 검은 모래 + 별점 = 밤·어둠 (색·모양)
- 시계판 눈금 12개 = 시계·하루 주기 (회중시계 #15와 같은 계열인지는 모름, 안 끼움)
- 돌기둥 = 모름
→ 읽힌 사실 3개

### 구역2 회색 벽 4판 : **광주기성 — 한 가지씩만 바꾼 대조 실험(#126)**
1. 노란 판 + 검은 띠 = 낮·밤, 띠 길이 = 밤 길이 (길이)
2. 판 넷 ↻ = 이웃끼리 하나씩만 다른 대조: 위 두 판은 밤 길이만, 왼쪽 두 판은 섬광만, 아래 두 판은 식물 종만 다르다 (#126)
3. 국화 + 긴 밤 → 만개(+봉오리 2) = 단일식물은 긴 밤에 핀다
4. 국화 + 짧은 밤 → 봉오리 3 = 밤이 짧으면 안 핀다, 원인은 밤 길이
5. 국화 + 긴 밤 + 섬광 → 봉오리 3 = 어둠이 끊기면 안 핀다, 원인은 끊김
6. 분홍 꽃(종 다름) + 긴 밤 + 섬광 → 핌 = 장일식물은 반대로 핀다
7. 빨간 섬광 ↻ = 적색광(#127) — 밤을 끊는 데 적색광이 듣는다, 구역3과 연결
8. 편지 + 점선 화살표(잎→줄기→꽃) = 개화 신호가 잎에서 꽃으로 (약속 밖, 뜻)
→ 읽힌 사실 8개

### 구역3 나무판 : **피토크롬 — 적색광은 Pfr를 켜고 원적색광은 되돌린다(상추 씨앗)**
1. 붉게 켜진 전구 ↻ = 적색광 660nm, 피토크롬을 활성형 Pfr로 켠다 (#127)
2. 열만 내는 새까만 전구 ↻ = 근적외(원적색)광 730nm, Pfr→Pr (#127)
3. 붉은 전구 아래 싹 = 발아
4. 검은 전구 아래 씨앗 그대로 = 발아 안 함
5. 간판 둘(검정→빨강 / 빨강→검정) = 마지막에 받은 빛이 결정 (순서)
6. 벽 스위치 = 켜고 끄는 가역 스위치 (약속 밖, '켠다·되돌린다' 어휘와 맞음)
7. 상추 봉지 = 상추씨(빛 필요 종자)
8. 같은 화분·선반·간판틀에 전구만 다름 ↻ = 한 가지만 바꾼 대조 (#126)
→ 읽힌 사실 8개

### 구역4 큰 장면의 잎 큐브 : **정상(맑은 날) — 청색광·생체시계로 기공 열림, CO2 들고 O2 나감, 루비스코 CO2 고정**
1. 콩팥 모양 둘 + 틈 = 공변세포 한 쌍, 열린 기공 (#14)
2. 분홍 안쪽 테두리 = 기공 쪽 벽이 두껍다 (약속 밖)
3. 파란 빛줄기 ↻ = 청색광 (#125, 확신 상승)
4. 파란 유리알 2개 ↻ = 포토트로핀, 공변세포가 빛을 받는 자리 (#122, 「모름」이 풀림)
5. 어두운 방울 줄(바깥 약 11) + 아래 화살표 ↻ = CO2 유입 (#16)
6. 밝은 방울(약 25) + 위 화살표 ↻ = O2 방출 (#17, 수증기가 아님)
7. 루비빛 렌즈 놋쇠 스코프가 어두운 방울을 쥠 ↻ = 루비스코가 CO2 고정 (#34, 60→95%)
8. 회중시계 = 생체시계, 2시 정각 (#15)
9. 젖은 흙 + 웅덩이 3 = 물 충분, #18의 반대 (자리·개수)
→ 읽힌 사실 9개

### 구역5 틀선 칸 : **'다른 날' = 건조한 날 — 기공 닫힘, O2 쌓임, 루비스코가 O2를 잡음(광호흡)**
1. 틀선으로 떼어 낸 칸 ↻ = 같은 장면의 다른 날·조건 (#118, 1단계의 '이음 흔적'이 아니라 약속된 틀)
2. 맞붙은 쭈글쭈글한 공변세포 = 기공 닫힘·팽압 상실
3. 갈라진 땅 + 먼지·바람선 ↻ = 건조 스트레스 (#18)
4. 밝은 방울 약 30개 빽빽 ↻ = O2 축적 (#17)
5. 스코프가 밝은 방울을 쥠(분홍빛 번짐) ↻ = 루비스코가 O2 결합 = 광호흡
6. 어두운 방울이 없다 ↻ = CO2 유입 차단 (빠진 것)
7. 파란 빛줄기·유리알·시계는 그대로 = 청색광 신호가 있어도 건조가 이겨 닫힌다 (안 바뀐 것)
→ 읽힌 사실 7개

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이음
- 모름: 돌기둥, 시계판 12눈금, 모래시계, 편지·스위치·상추 봉지·간판(뜻으로만 읽음), 분홍 안쪽 테두리, 2시의 뜻(두 칸이 같아 변수는 아님).
- 어색: 구역2 화분이 띠 끝을 가림, 분홍 식물에 장일 표시 없음. 구역5 큐브의 크기·기울기는 #118상 뜻 없음 ↻.
- 헷갈림: 붉은색은 적색광(#127)이나 루비 렌즈는 스코프에 낀 것만 루비스코(#34). 검정은 밤(띠)·원적색(전구)·CO2(방울)로 모양이 갈린다. 파랑은 빛줄기(청색광)·유리알(수용체)·웅덩이(물).
- 이음: 4|5는 이음이 아니라 틀선 칸 ↻. 구역2 식물은 흰 테두리로 오려 붙인 듯, 국화 3그루는 복사.

## ④ 한 문장 ↻
밤 길이와 적색/원적색 스위치(피토크롬)로 개화·발아를 정하고, 한낮엔 청색광 수용체와 생체시계로 기공을 열어 CO2를 들이지만, 건조한 날엔 기공이 닫혀 CO2가 끊기고 O2가 쌓여 루비스코가 O2를 잡는 광호흡이 된다.
