# stage1 — 생판 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **식물의 빛 반응 — 광주기성·피토크롬(+기공·광호흡)** : 55%
- 2순위 **식물의 환경 반응·신호전달(빛·시간·물: 생체시계, 기공 조절)** : 25%
- 하늘이 왼쪽 밤(별) → 가운데 새벽 → 오른쪽 한낮(파란 햇빛)으로 이어진다. 하루의 흐름 위에 개념을 세운 판.

## ② 구역별 (왼쪽부터 5구역)

### 구역1 벽돌 기둥 + 모래시계 : **밤(암기) 길이를 재는 타이머**
- 모래시계 = 시간 '길이'를 재는 도구, 별하늘 아래에 있으니 낮이 아니라 밤의 길이를 잰다 (뜻·자리)
- 검은 모래 + 하얀 별점 = 밤·어둠 (색·모양)
- 시계판 눈금 고리 12개 = 시계·하루 주기 (개수; 12h/24h 중 무엇인지는 모름)
- 돌기둥 자체의 뜻 = 모름 (임계·한계?)
→ 읽힌 사실 3개

### 구역2 회색 벽의 4개 판 : **광주기성 실험 — 단일·장일식물, 야간 중단, 개화 신호**
1. 노란 판 + 검은 띠 = 하루 중 낮(노랑)·밤(검정), 띠 길이 = 밤 길이 (모양·길이)
2. 판 4개 = 4가지 조건 (개수)
3. 국화 + 긴 검은 띠 → 노란 꽃 만개(+봉오리 2) = 단일식물은 긴 밤에 핀다 (결과)
4. 국화 + 짧은 검은 네모 → 초록 봉오리 3개 = 밤이 짧으면 안 핀다 (결과)
5. 국화 + 긴 띠 + 빨간 섬광 → 봉오리 3개 = 밤 한가운데 빛으로 어둠을 끊으면 개화 억제, 연속된 밤이 관건 (자리)
6. 분홍 꽃 식물 + 긴 띠 + 섬광 → 핌 = 장일식물은 밤을 끊으면 핀다 (결과)
7. 빨간 섬광 = 적색광이 야간 중단에 듣는다, 구역3 피토크롬과 연결 (색)
8. 편지 봉투 + 점선 화살표(잎→줄기→꽃) = 개화 신호(플로리겐)가 잎에서 만들어져 줄기로 꽃에 간다 (뜻·방향)
→ 읽힌 사실 8개

### 구역3 나무판 : **피토크롬 — 적색/원적색 가역 스위치(상추 씨앗 발아)**
1. 붉게 켜진 전구 = 적색광 R, 약 660nm (색)
2. 검은 전구 + 열기 물결 = 원적색광 FR, 약 730nm, 눈에 안 보이고 적외선에 가깝다 (색·모양)
3. 붉은 전구 아래 싹튼 모종 = R → 발아 촉진 (자리)
4. 검은 전구 아래 그대로인 씨앗 = FR → 발아 억제 (자리)
5. 간판 둘(검정→빨강 / 빨강→검정) = 마지막에 쪼인 빛이 결과를 정한다, 순서가 중요 (순서)
6. 벽 스위치 = 켰다 껐다 되돌리는 Pr⇄Pfr 전환 (뜻)
7. 상추 그림 씨앗봉지 = 재료는 상추씨, 빛 필요 종자 (모양)
→ 읽힌 사실 7개

### 구역4 잎맥 큐브(기공 열림) : **기공 열림 — CO2 유입, Rubisco 고정**
1. 잎맥 큐브 = 잎, 윗면 콩팥모양 2개 + 틈 = 공변세포 2개와 열린 기공 (모양·개수)
2. 분홍 안쪽 테두리 = 기공 쪽 세포벽이 두껍다 (모양)
3. 파란 빛줄기 = 햇빛 중 청색광이 기공을 연다 (색, 약한 확신)
4. 검은 물방울 줄(바깥 약 11개) + 아래 화살표 = CO2가 들어온다 (방향·색)
5. 흰 방울 약 25개 + 위 화살표 = O2(또는 수증기)가 나간다 (방향; 둘 중 모름)
6. 루비 렌즈 망원경이 발톱으로 검은 방울을 쥠 = 루비+스코프 → Rubisco가 CO2를 잡는다 (소리, 약 60%)
7. 회중시계 2시 정각 = 하루 중 시각·생체시계 (뜻)
8. 젖은 흙 + 웅덩이 3개 = 물이 충분 (자리·개수)
→ 읽힌 사실 8개 (파란 구슬 2개는 모름)

### 구역5 이음선 건너 큐브(기공 닫힘) : **기공 닫힘 — 가뭄, O2 축적, 광호흡**
1. 맞붙어 쭈글쭈글한 공변세포, 틈 없음 = 기공 닫힘·팽압 상실 (모양)
2. 갈라진 마른 땅 + 먼지·바람선 = 가뭄·건조 고온 (자리)
3. 큐브 속 흰 구슬 약 30개 빽빽 = 못 나가고 쌓인 O2 (개수)
4. 같은 망원경 발톱이 흰 방울을 쥠(분홍빛 번짐) = Rubisco가 CO2 대신 O2를 잡는다 = 광호흡 (소리·자리)
5. 구역4와 똑같은 2시 시계 = 시각은 같고 물 상태만 다르다 (비교)
6. 햇빛·파란 구슬은 그대로 = 빛이 있어도 가뭄이면 닫힌다 (자리)
→ 읽힌 사실 6개

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이음
- 모름: 돌기둥, 시계 12눈금의 뜻, 파란 구슬 2개(청색광 수용체? 팽압? 두 구역에서 크기 불변), 스위치 레버 위치, 2시의 뜻, 구역5 먼지 구름 5개.
- 어색: 구역2 화분이 판 오른쪽 끝을 가려 밤의 총길이가 안 보인다. 임계 밤 길이를 표시한 눈금이 없다. 분홍 식물은 장일식물이라는 표시 없이 결과로만 추정. 편지 봉투는 만개한 국화 한 그루에만 있다.
- 헷갈림: 검정이 밤(1·2), 원적색(3), CO2(4)로 세 번 쓰였다. 빨강은 적색광(2·3)·루비 렌즈·분홍 세포벽. 흰 방울이 O2인지 수증기인지. 시계가 모래시계(1)와 회중시계(4·5) 두 종류. 파랑이 청색광·구슬·웅덩이 세 곳.
- 이음 흔적: 구역4|5 사이 크림색 이중선, 창살·바닥 질감 불연속, 5의 큐브는 기울고 화풍이 다르다. 구역2 식물은 흰 테두리로 오려 붙인 듯, 국화 3그루는 같은 그림 복사. 나무판 윗변이 직선으로 덧댄 판. 밤→낮 하늘 그라데이션이 구역1~4를 한 장면으로 묶는다.

## ④ 한 문장
식물은 밤의 길이(연속 암기)와 적색/원적색 빛 스위치(피토크롬)로 때를 읽어 꽃과 발아를 정하고, 한낮 가뭄에는 기공이 닫혀 CO2는 끊기고 O2가 쌓여 Rubisco가 O2를 잡는 광호흡이 일어난다.
