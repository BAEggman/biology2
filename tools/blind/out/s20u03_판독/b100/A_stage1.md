# stage1 생판 독해 (그림 s20u03, 사전 정보 없음)

## ① 판 전체 표제어
- 1순위: **식물의 빛 반응과 환경 신호 — 광주기성·피토크롬·기공 개폐** (확신 60%)
- 2순위: **식물의 생체시계(일주기 리듬)와 광수용체 — 시간 읽기** (확신 20%)
- 근거: 하늘이 왼쪽 밤(별)에서 가운데 새벽, 오른쪽 한낮으로 이어짐(자리). 시간 도구(모래시계 1, 회중시계 2)가 반복됨. 붉은색·검은색·푸른색 빛이 구역마다 다른 뜻으로 쓰임.

## ② 구역별 (5구역)
### 구역1 돌기둥+모래시계 — **밤의 길이를 재는 타이머(임계 암기)**
1. 모래시계 1개 = 시간을 재는 장치(뜻).
2. 모래가 검고 흰 별점이 박힘 = 재는 것은 낮이 아니라 밤, 곧 암기(색·밤하늘 자리).
3. 12눈금 시계 문자판 안에 박힘 = 하루 주기, 생체시계(개수 12).
4. 돌기둥 = 모름(고정된 기준값=임계값? 추정).

### 구역2 회색 벽, 노란 슬롯 4칸+화분 4개 — **광주기성: 단일·장일식물, 야간 중단, 플로리겐**
1. 노란 슬롯 1칸 = 하루, 검은 막대 = 밤의 길이(모양·자리).
2. 좌상: 긴 밤+국화 만개(활짝 1, 봉오리 2) = 단일식물은 긴 밤에 개화.
3. 우상: 짧은 밤(작은 검은 네모)+초록 봉오리 = 밤이 임계 암기보다 짧으면 단일식물 불개화.
4. 좌하: 긴 밤 한가운데 붉은 섬광 1번+불개화 = 야간 중단이 단일식물 개화를 막음. 연속된 밤이 결정(자리).
5. 우하: 같은 긴 밤+붉은 섬광+분홍 꽃 만발(다른 종) = 장일식물은 야간 중단으로 개화.
6. 섬광이 붉음 = 적색광이 야간 중단에 효과적(색, 구역3과 연결).
7. 좌상 잎의 편지 봉투 1개+점선 화살표 3개가 줄기 따라 꽃으로 = 플로리겐(잎에서 만들어져 체관으로 꽃눈에 전달)(뜻: 편지=전령).

### 구역3 나무판 — **피토크롬: 적색광/원적색광 광가역성, 상추 종자 발아**
1. 빨간 전구(켜짐, 광선 13줄)+싹튼 화분(떡잎 2, 갈라진 껍질) = 적색광이 발아 촉진(Pr→Pfr)(색).
2. 검은 전구(열기선 3줄)+싹 안 튼 씨앗 = 눈에 안 보이는 원적색광이 발아 억제(Pfr→Pr)(색·열선).
3. 가운데 토글 스위치 1개 = 켰다 껐다 되돌리는 광가역성(뜻).
4. 상추 씨앗 봉투 1개 = 광발아 종자인 상추(모양).
5. 팻말 2개: 검정→빨강은 발아, 빨강→검정은 불발아 = 마지막에 쪼인 빛이 결정(왼→오른쪽 순서 자리).

### 구역4 열린 기공, 낮, 젖은 흙 — **기공 열림: 청색광·CO2 흡수·루비스코·생체시계**
1. 잎 모양 정육면체 위 공변세포 2개가 틈을 둘러쌈, 틈 열림 = 팽압 올라 기공 개방(개수 2).
2. 푸른 빛줄기 약 3줄 = 청색광이 기공을 엶(색).
3. 짙은 방울 바깥 약 11+안쪽 약 10개가 안으로 = CO2 유입(색·화살표 방향).
4. 흰 거품 약 20개+흰 화살표 밖으로 = O2·수증기 방출, 증산(방향).
5. 루비 달린 망원경 1개, 발톱이 짙은 방울 1개를 쥠 = 루비스코의 CO2 고정(소리: 루비+스코프).
6. 회중시계 2시 = 낮, 기공의 일주기 리듬(모양).
7. 젖은 흙+물웅덩이 3개 = 물 충분(자리).

### 구역5 닫힌 기공, 가뭄 — **기공 닫힘: 물 스트레스(가뭄)와 광호흡**
1. 공변세포 2개가 쭈글쭈글 맞붙어 틈 없음 = 팽압을 잃고 기공 닫힘(모양).
2. 갈라진 마른 땅+먼지 5덩이+바람줄 = 가뭄(자리). ABA는 그림에 직접 없음.
3. 같은 2시 시계·같은 푸른 빛 = 시간과 빛이 같아도 물 부족이 우선(개수·자리 대응).
4. 잎 속 흰 구슬 약 30개 빽빽 = 닫혀서 못 나간 O2(또는 수증기) 축적(개수).
5. 루비 끝이 흰 구슬에 닿고 짙은 방울이 없음 = CO2 차단, 루비스코가 O2를 잡는 광호흡(자리).

## ③ 잔결
- 뜻 모름: 돌기둥, 슬롯 왼쪽 끝 작은 구멍, 화분의 회색 고리, 공변세포 속 파란 구슬 2개(액포·K+·청색광수용체 중?), 분홍 테두리(세포벽?).
- 헷갈림: 검정이 밤(슬롯)과 원적색광(전구·팻말) 두 뜻. 붉음이 적색광·섬광·루비 세 가지. 짙은 방울은 CO2인지 물인지. 흰 거품은 O2인지 수증기인지. 망원경은 루비스코인지 피토크롬인지.
- 이어 붙인 흔적: 구역4와 5 사이 굵은 검은 세로선(하늘·땅이 갑자기 바뀜). 구역2 오른쪽 두 칸은 배경 톤이 살짝 달라 대비를 올리면 네모 패치 경계가 보임. 붉은 섬광 두 칸은 섬광 부분이 밝은 노란 사각 패치로 덧붙음.

## ④ 한 문장
식물은 빛의 색과 밤의 길이, 시간을 읽어 꽃피우기·발아·기공 여닫기를 정하고, 물이 모자라면 기공을 닫는다.
