# stage2 — 약속표로 다시 읽기 (s20u03) · 「↻」 = 1단계와 달라진 곳

## 판정
약속표로 구역3·4·5는 뚜렷이 더 잘 풀림(모름 6건 해소, 추정 4건 확정, 오독 2건 철회). 구역1·2는 표에 해당 물건이 거의 없어 1단계 읽기를 유지하고 「대조 실험」 약속으로 구조만 보강. 표에 없는 모래시계·편지봉투·스위치·상추 봉지·간판은 억지로 끼우지 않음.

## ① 판 표제어
- 1순위 **식물의 환경 반응 — 광수용체(피토크롬·청색광)·광주기성·생체시계, 건조 스트레스에 의한 기공 닫힘** (72%) ↻ 55→72
- 2순위 **광주기성과 피토크롬(빛으로 개화·발아 조절)** (12%)
- 참고 **기공 개폐와 가스 교환** (8%)
↻ 근거: 청색광 수용체(파란 유리알), 적색광·근적외광 전구, 회중시계(생체시계), 갈라진 땅(건조 스트레스), 루비스코가 모두 약속표 어휘로 한 판에 모임. 1단계 2순위 '생체시계'는 회중시계가 확정돼 1순위에 흡수.

## ② 구역
**구역1 — 모래시계: 밤 길이를 재는 타이머** (변화 거의 없음)
- 모래시계=시간 재는 타이머, 검은 모래+별=어둠, 위는 밤하늘.
- ↻ 점검: 밤하늘에 초승달(CAM) 없음, 별뿐. 12눈금 틀·돌기둥은 모름 유지(모래시계는 표에 없고 회중시계와는 다른 물건).
→ 읽힘 3

**구역2 — 노란 레일 4칸: 광주기와 개화**
- 1단계 8개 유지(레일=하루 띠, 긴 밤+개화, 편지봉투=플로리겐, 짧은 밤+비개화, 섬광+비개화, 장일식물 개화, 국화 3+분홍 1, 핵심=밤 길이).
- ↻ 「한 가지만 바꾼 대조 실험」: 좌상↔우상=밤 길이만, 좌상↔좌하=번쩍임만, 좌하↔우하=식물 종만 다름 → 결과의 원인이 하나씩 갈림.
- 빨간 번쩍임은 표에 같은 물건이 없음. 같은 빨강=적색광 색 약속과 이어 R 섬광으로 읽음(추정). 은색 고리·레일 구멍은 모름 유지.
→ 읽힘 9

**구역3 — 나무판: 피토크롬 적색광/근적외광 가역**
- ↻ 붉게 켜진 전구 = 적색광(660nm): 피토크롬을 활성형 Pfr로 켠다 → 싹 튼 상추.
- ↻ 새까만 전구+물결선 3 = 빛 대신 열만 내는 근적외광(730nm): Pfr를 Pr로 되돌린다 → 안 튼 씨앗. 물결선(열)의 뜻 풀림.
- 간판 2: 마지막 빛이 결정. 상추 봉지=광발아 종자. 스위치=켜기·되돌리기 비유(표의 '켠다·되돌린다'와 맞으나 물건은 표 밖, 추정).
- ↻ 같은 화분·선반·간판이 나란하고 전구만 다름 = 대조 실험. 나무판은 코르크가 아닌 매끈한 널빤지.
→ 읽힘 6

**구역4 — 큐브1(젖은 땅, 해 뜬 맑은 날=정상): 기공 열림**
- ↻ 콩팥 모양 둘 = 공변세포 한 쌍, 틈 열림 = 기공 열림(확정).
- ↻ 파란 구슬 각 1(2) = 청색광 수용체(포토트로핀, 빛 받는 자리), 푸른 빛줄기 2 = 청색광(1단계 '불확실' 해소).
- ↻ 어두운 방울 = CO2: 대각선 11 + 틈 2 + 잎 속 약 8 + 렌즈 위 1, 안으로 들어옴(확정).
- ↻ 밝은 방울 약 20 + 흰 화살표 1 = O2가 나감(1단계 '수증기' 후보 철회).
- ↻ 루비빛 렌즈 놋쇠 스코프 = 루비스코(확정), 렌즈에 맺힌 방울 = CO2 고정.
- ↻ 회중시계(2시) = 생체시계(확정).
- 젖은 흙+웅덩이 3 = 물 충분(자갈=Ca²⁺로는 안 읽음: 구덩이에 하늘빛이 비침).
→ 읽힘 8

**구역5 — 큐브2(틀선 칸=같은 장면의 다른 날): 건조 스트레스로 기공 닫힘**
- ↻ 틀선으로 떼어 낸 칸 = 같은 장면의 다른 날·다른 조건. x≈1650 세로선은 이음 흔적이 아니라 칸 경계.
- ↻ 갈라진 땅+마른 바람(먼지 5, 속도선) = 건조 스트레스. 1단계 'ABA' 철회: 갓 쓴 늙은 아비가 이 판에 없음.
- 공변세포 쌍이 주름져 맞붙음 = 기공 닫힘.
- ↻ 어두운 방울 0 = CO2 못 들어옴. 밝은 방울 약 30이 속을 채움 = O2 갇힘. 루비스코가 O2에 둘러싸임 = 광호흡 쪽(귀결, 추정).
- ↻ 파란 구슬·푸른 빛줄기·2시 시계가 큐브1과 같음 = 청색광·생체시계는 그대로인데 닫힘 → 원인은 건조.
→ 읽힘 7

## ③ 모름·어색·이음
- ↻ 풀림: 회중시계, 파란 구슬, 흰 공(O2), 망원경(루비스코), 물결선, x≈1650 선(칸 경계).
- 남음: 시계판 12눈금, 은색 고리, 레일 구멍, 모래시계·편지봉투·스위치·상추 봉지(표 밖), 빨간 번쩍임의 모양.
- 헷갈림: 빨강 셋(섬광·전구·간판)·검정 셋(밤 띠·근적외 전구·간판 칸)이 구역마다 뜻이 다름.
- 이음: 벽 4칸 사각 패치, 식물의 흰 오려낸 테두리, 섬광 주변 레일 가장자리 색 끊김은 그대로.
- 점검: 갓 쓴 아비(ABA)·칼(K)·자갈(Ca²⁺)·초승달(CAM)·옥수수 알갱이(옥신) 등 인접 약속물은 이 판에 없음.

## ④ 한 문장
식물은 낮이 아닌 밤의 길이와 적색광/근적외광(피토크롬)으로 개화·발아를 정하고, 같은 청색광·같은 시각(생체시계)이어도 건조 스트레스가 오면 기공이 닫혀 CO2는 막히고 O2가 쌓여 루비스코가 곤란해진다.
