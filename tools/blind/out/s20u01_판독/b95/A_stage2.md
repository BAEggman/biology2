# 2단계 — 약속표로 다시 본 s20u01 (↻ = 1단계와 달라진 곳)

## 판정
약속표가 크게 풀어 줌. 121줄 중 이 판에 걸린 줄: 13·119(구역1), 64(구역2), 37(구역3), 38(구역4), 121(구역5), 19·20·21·18·120(구역6), 1번(갓은 ABA 전용). 1단계에서 갈렸던 옥신/지베렐린 짝, 솔, 흙더미 소속, 노인의 뜻이 한꺼번에 풀렸고 1단계 최상 후보는 모두 살아남음. 틀린 곳은 분무기와 시소의 뜻 두 군데. 표 밖 물건은 끼우지 않음(정은 칼=K 아님, 받침돌은 자갈=Ca²⁺ 아님).

## ① 판 전체 표제어
- **식물 호르몬(옥신·시토키닌·지베렐린·브라시노스테로이드·에틸렌·아브시스산)** — 1순위 ↻ 90→98%. 표가 구역마다 호르몬 이름을 못 박음.
- **식물의 환경 반응·스트레스 신호전달** — 2순위 1%.

## ② 구역 (경계는 1단계와 같음)
**구역1 사다리 남자 + 지퍼 옥수수 = 옥신 ↻ 45→96% (지베렐린 대안 버림) — 읽힌 5개**
- ↻ 옥수수 알갱이 = 옥신 그 자체(표 13). 1단계는 '옥수수~옥신' 말장난으로만 읽음
- 지퍼 열린 줄기 속 알갱이 = 줄기 속 옥신
- 꼭대기 자루에서 지퍼 틈을 따라 약 10알이 아래로만 = 극성 수송 (그대로)
- 잎겨드랑이 지퍼로 잠긴 꼬투리 3 = 곁눈이 눌림, 정단우성 (그대로, 이제 근거 있음)
- ↻ 사다리 아래 알갱이 더미에 파묻힌 시든 풀 = 고농도 억제(합성 옥신 2,4-D 제초제). 모름이 풀림: 더미=고농도, 풀이 시듦
- ↻ 분무기 물방울 = H⁺(표 119) → 지퍼 틈(세포벽)이 열림 = 산성 성장·세포 신장. 1단계 '합성 호르몬(2,4-D?)'은 틀림
- 사다리·분무하는 남자: 표 밖, 뜻 안 붙임

**구역2 토끼 가족 + 화분 = 시토키닌 ↻ 98% — 읽힌 4개**
- 토끼 = 시토키닌(표 64, 소리도 맞음)
- ↻ 초록 롤러로 칠한 잎 1장만 초록, 안 칠한 곁잎 1장은 노랑 = 노화 지연. 1단계 모름(롤러의 뜻)이 풀림
- 새끼 2 = 세포분열 촉진
- 긴 곁가지 1 = 곁눈 촉진

**구역3 망치·정 남자 + 지렛대 + 웃자란 화분 = 지베렐린 ↻ 45→95% (옥신 대안 버림) — 읽힌 3개**
- ↻ 받침돌에 걸친 널 = 지렛대 = 지베렐린(표 37). 1단계 '시소=균형·길항? 기울기?'는 틀림: 시소가 아니라 이름을 나르는 지렛대
- 지렛대 끝에 들려 오른 웃자란 화분 식물 = 줄기 신장 (그대로)
- 망치·정으로 쪼개진 씨(2쪽)에서 새싹 = 휴면 타파·발아 (표 밖, 지베렐린 일반 지식으로 읽음)

**구역4 솔 든 남자 + 키 큰 식물 2그루 = 브라시노스테로이드 ↻ 40→95% (접촉형태형성·살리실산 대안 버림) — 읽힌 2개**
- 나무 토막에 털 박힌 솔 = BR(표 38)
- ↻ 솔 든 사람 뒤의 약 두 배 크고 곧은 외줄기 = BR의 일(줄기 신장, 곧고 튼튼). '그냥 신장'에서 한정됨
- 오른쪽 여러 줄기 작은 덤불: 표 밖, 비교 기준으로만 봄

(중앙 열린 유리문: 표에 없음, 경계로만 봄)

**구역5 토마토 든 남자 + 보라 구름 = 에틸렌 ↻ 98% — 읽힌 5개**
- 연보라 구름 = 에틸렌(표 121)
- ↻ 구름이 손에 든 익은 토마토에서 흘러나옴 = 익은 열매가 내보냄(자기촉매). 1단계 '닿음?'이 확정
- ↻ 구름 안 열매 4(빨강·분홍)만 익고 구름 밖 아래 1은 초록 = 숙성
- 노란 잎 3 = 낙엽(탈리)
- 발치의 짧고 굵고 옆으로 누운 말린 싹 = 삼중반응 (그대로). 곧은 싹은 표 밖, 대조

**구역6 갓 쓴 노인 + 셔터 = 아브시스산(ABA) ↻ 98% — 읽힌 5개**
- ↻ 갓 쓴 늙은 아비 = ABA, '아바' 소리(표 19). 노화 아님 — 1단계의 '노화?' 곁가지 삭제
- 셔터를 내림 = 기공 닫힘(표 120)
- ↻ 갈라진 땅 위 쓰러진 마른 풀 ↔ 빳빳이 선 셔터 잎 = 건조 스트레스와 ABA의 건조 내성(표 18)
- ↻ 흙에 묻고 손바닥으로 누른 씨 = 종자 휴면(표 20). 흙더미 소속이 구역6으로 확정
- 구두 밑에 깔린 모종 = 생장 억제(표 21)

## ③ 풀림 / 아직 모름 / 이음
- 풀림: 시든 풀 두 포기(구역1 = 고농도 옥신, 구역6 = 가뭄) 구분, 분무기, 시소, 솔, 흙더미, 노인, 롤러, 구름의 출처.
- 아직 모름(표 밖): 사다리, 망치·정·씨 그 자체, 열린 문, 곧은 싹, 오른쪽 덤불, 같은 얼굴 대머리 정원사 4명(뜻 없는 일꾼으로 봄), 개수(10·3·2·5)가 번호 약속인지.
- 이음 흔적은 그대로: 갓·머리·옥수수·씨 가장자리의 흰 테, 중앙 문에서 박공이 따로 시작.

## ④ 한 문장
식물 호르몬은 소품 하나가 일 하나를 나른다 — 알갱이 옥신(극성 수송·정단우성·산성 성장), 토끼 시토키닌(분열·노화 지연·곁눈), 지렛대 지베렐린(신장·발아), 솔 BR(신장), 보라 구름 에틸렌(숙성·낙엽·삼중반응), 갓 쓴 아비 ABA(기공 닫기·휴면·생장 억제·건조 내성). 문 왼쪽 넷은 자라게, 오른쪽 둘은 익히고 닫고 재운다.
