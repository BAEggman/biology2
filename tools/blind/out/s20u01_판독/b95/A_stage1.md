# 1단계 생판 — s20u01 (그림만 보고)

## ① 판 전체 표제어
- **식물 호르몬(종류별 작용)** — 1순위, 확신 90%. 온실 한 칸에 호르몬 6가지가 한 칸씩 무대로 늘어섬. 같은 대머리 정원사가 4번, 토끼·노인이 소품 겸 주인공. 기체 구름(에틸렌), 셔터(기공), 갈라진 땅이 결정적 단서.
- **식물의 환경 반응·스트레스 신호전달** — 2순위, 6%. (굴성·접촉·가뭄 반응으로 읽는 길)

## ② 구역 (왼쪽→오른쪽, 원본 px 대략)
**구역1 (x30–530) 사다리 남자 + 지퍼 옥수수 = 옥신 45% / 대안 지베렐린 40% — 읽힌 5개**
- 옥수수 = 소리(옥수수~옥신)
- 줄기·껍질이 지퍼로 열림 = 세포벽 느슨 → 세포 신장(산성 성장), 모양
- 이삭 알갱이 약 10알이 줄기 옆을 따라 아래로만 떨어짐 = 위→아래 극성 이동, 동작
- 지퍼로 꼭 닫힌 꼬투리 3개(잎겨드랑이) = 곁눈이 눌림, 정단우세, 개수
- 분무기 안개 = 밖에서 뿌리는 합성 호르몬(2,4-D류?), 약함
- 모름: 사다리(키? 위아래?), 알갱이 더미 위 축 처진 풀 싹(잎 3: 키다리병? 제초제?)

**구역2 (x410–670) 토끼 가족 + 화분 = 시토키닌 — 읽힌 4개**
- 토끼 = 소리(시-토키-닌~토끼)
- 새끼 2마리가 마주 봄(어미 합 3) = 세포 분열·딸세포 2개, 개수
- 초록 롤러로 칠한 잎만 진초록, 옆 잎 1장은 노랑 = 노화 지연, 색
- 길게 뻗은 곁가지 1개 = 곁눈 생장(정단우세 완화), 자리
- 모름: 롤러가 '바르기'(외부 처리)인지

**구역3 (x650–980) 망치·정 남자 + 시소 + 웃자란 화분 = 지베렐린 45% / 대안 옥신 30% — 읽힌 3개**
- 망치+정으로 딱딱한 씨(2쪽) 깨니 새싹 = 휴면 타파·발아, 동작
- 가늘고 길게 웃자란 줄기(마디 길고 작은 잎 약 8) = 줄기 신장·추대, 모양
- 시소(널빤지+돌 받침) = 균형·길항(GA↔ABA?) 또는 기울기(굴중성?) — 헷갈림
- 모름: 바닥 부스러기 3점

**구역4 (x950–1260) 솔 든 남자 + 키 큰 식물 2그루 = 브라시노스테로이드 40% / 대안 접촉형태형성 20% — 읽힌 2개**
- 솔(브러시) = 소리(브러시~브라시노)
- 천장까지 닿는 외줄기 식물 = 줄기·세포 신장
- 모름: 밑동 줄기 4~5개 덤불(분지? 왜성? 대조?), 솔질의 뜻

(중앙 열린 유리문 x1270–1370 = 경계. 왼쪽 4구역은 자라게 하는 쪽, 오른쪽 2구역은 익히고 닫고 재우는 쪽.)

**구역5 (x1430–1750) 토마토 든 남자 + 보라 구름 = 에틸렌 — 읽힌 5개**
- 보라 구름 = 기체 호르몬
- 토마토 5개(초록→분홍→빨강) + 손에 든 1개 = 과일 숙성, 개수·색
- 익은 열매에 구름이 닿음 = 이웃을 익히는 양성 되먹임?, 약함
- 노란 잎 3장 = 노화·낙엽(탈리), 개수
- 곧은 싹 vs 갈고리처럼 말린 굵은 싹 = 삼중 반응(신장 억제·비대·수평 생장), 모양

**구역6 (x1690–2040) 갓 쓴 노인 + 셔터 = 아브시스산(ABA) — 읽힌 5개**
- 큰 잎에 내려온 롤 셔터를 쥠 = 기공 닫힘(물 스트레스), 동작
- 흙더미(산) 속 씨앗 위에 손 = 종자 휴면, 자리
- 새싹을 밟은 신발 = 생장·발아 억제
- 갈라진 마른 땅 + 시든 갈색 풀(마른 잎 4) = 가뭄 스트레스
- 노인 = 소리(아브~아버지?), 약함

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이음
- 지퍼 꼬투리 3개, 분무기 내용물, 사다리, 알갱이 더미 풀 싹, 시소, 솔, 두 식물 대조, 열린 문은 뜻이 갈림. 구역4는 살리실산·스트리고락톤 가능성도 남음.
- 대머리 정원사가 4번 같은 얼굴이라 호르몬 구분은 소품에만 의존. 노인만 한복 화풍이라 튐.
- 흙더미(속 씨앗)가 구역5·6 사이에 걸쳐 소속 불명(삼중 반응의 흙 압력 vs 휴면). 구역3·4도 식물이 맞닿음.
- 이음 흔적: 노인 갓·사다리 남자 머리·옥수수·씨 가장자리에 얇은 흰 테(오려 붙인 스티커 느낌). 중앙 문에서 지붕 박공이 따로 시작해 두 장을 이은 듯.

## 확신 요약
- 단단함: 구역2 시토키닌(토끼 소리+분열+노화 지연), 구역5 에틸렌(기체 구름+숙성+삼중 반응), 구역6 ABA(셔터+휴면+가뭄).
- 갈림: 구역1과 3의 옥신/지베렐린 짝은 바뀔 수 있음(구역1: 극성 이동·정단우세 소품이 옥신 쪽, 키·사다리는 지베렐린 쪽; 구역3: 발아·웃자람은 지베렐린 쪽, 기울어진 화분·망치는 옥신 쪽). 구역4는 소리 말장난 한 가닥에 기댐.
- 숫자 소품: 3(꼬투리·토끼·노란 잎), 5(토마토), 2(새끼 토끼·씨 쪽·식물).

## ④ 한 문장
식물 호르몬은 종류마다 일이 달라서, 옥신은 위에서 아래로 흘러 신장·정단우세를, 시토키닌은 분열·노화 지연·곁눈을, 지베렐린은 발아·줄기 신장을, 에틸렌은 기체로 숙성·낙엽을, ABA는 기공을 닫고 휴면·생장 억제를 맡는다.
