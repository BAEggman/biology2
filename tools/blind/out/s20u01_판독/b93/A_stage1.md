# 1단계 생판 — s20u01 (그림만 보고 읽음)

## ① 판 전체 표제어
- **식물 호르몬(옥신·지베렐린·시토키닌·에틸렌·아브시스산)** — 1순위 80%. 온실 한 채에서 작업자·토끼·노인이 호르몬 하나씩 맡아 시연하는 구성이고, 토마토 숙성·기공 셔터·휴면 씨앗이 호르몬 효과의 전형이라서.
- **식물의 환경 반응·스트레스 생리(굴성·접촉형태형성·기공·휴면)** — 2순위 10%. 솔질·시소·가뭄 땅 때문.
- 유리문을 경계로 왼쪽은 '키우고 나누는' 쪽, 오른쪽은 '익히고 떨구고 닫는' 쪽으로 갈리는 인상.

## ② 구역 (왼쪽부터 6구역. 괄호는 근거, 확신 40% 미만은 「모름」 처리)
**구역1 — 옥신 40% (지베렐린 30%)** 옥수수≈옥신(소리). 분무 장면.
- 사다리가 필요한 거대 옥수수 1그루 → 줄기 신장·키 성장 (뜻/크기)
- 사다리 남자가 분무기 1개로 뿌림 → 호르몬을 외부에서 처리·살포 (뜻)
- 줄기의 지퍼, 위쪽만 열려 알곡이 부풀어 나옴 → 모름(세포벽 풀림=산 성장? 낮음)
- 꼭대기에서 아래로 떨어지는 알갱이 약 8개 → 모름(위→아래 극성 이동? 낮음)
- 땅의 알갱이 더미 1개 + 시든 싹 1개 → 모름(고농도 억제? 낮음). 사다리 5단 → 모름

**구역2 — 시토키닌 65%**
- 토끼(시토'키'닌≈토끼) → 호르몬 이름 (소리)
- 새끼 토끼 2마리가 마주 봄(+어미 1) → 세포분열·세포질 분열 촉진, 1→2 (개수/뜻)
- 어미가 초록 페인트 롤러로 칠한 잎은 짙은 녹색, 옆 잎 1장은 노랗게 변함 → 노화 지연·푸름 유지 (뜻/색)
- 화분 줄기에서 옆으로 길게 뻗은 곁가지 1개 → 곁눈 생장 촉진·정단우세 완화 (모양/자리)
- 화분 → 모름

**구역3 — 지베렐린(종자 발아·휴면 타파) 45% (옥신 20%)**
- 망치+끌로 단단한 씨앗 1개를 쪼갬 → 딱딱한 종피·휴면을 깸 (뜻)
- 갈라진 두 쪽 사이로 난 싹 1개 → 발아 (자리; 두 쪽=떡잎 2 가능)
- 시소(받침돌 1, 남자 무릎이 한쪽을 눌러 화분 쪽이 올라감) → 모름(균형·비율?)
- 시소 위 화분의 가늘고 긴 싹 1개, 밑이 휘어 위로 섬 → 모름(웃자람인지 굴중성인지)

**구역4 — 접촉형태형성 35% / 브라시노스테로이드 30%**
- 솔 1개로 잎을 문지르는 남자 → 접촉 자극 (뜻; 솔≈브러시≈브라시노 소리는 낮음)
- 솔질한 식물은 남자 키 정도, 뒤의 건드리지 않은 식물은 약 1.5배 → 접촉하면 신장 억제·작아짐 (크기/자리)
- 큰 식물 밑동의 줄기 4~5개 → 모름

**구역5 — 에틸렌 85%**
- 식물을 감싼 보라색 구름 1개 → 기체 호르몬 (모양)
- 식물 위 토마토 5개(초록 1·주황 1·분홍 2·빨강 1) + 손에 든 빨강 1개 → 과일 숙성 촉진 (개수/색)
- 구름 바로 밖의 초록 토마토 1개 → 기체가 닿아야 익음 (자리)
- 든 토마토에서 구름으로 이어진 연기 → 익은 열매가 에틸렌을 내 이웃을 익힘(양성 되먹임) (자리)
- 떨어지는 노란 잎 2장 → 낙엽(탈리) 촉진 (개수)
- 새싹 2개, 곧은 1 + 갈고리처럼 꺾인 1 → 삼중 반응 (모양/개수)

**구역6 — 아브시스산(ABA) 70%**
- 갓 쓴 노인 1명 → 아브(아버지)·노화/쉼 (소리/뜻, 낮음)
- 큰 잎 위 롤 셔터를 손으로 끝까지 내림 → 기공 닫힘 (뜻/모양)
- 흙무덤 단면 속 씨앗 1개를 손으로 누름 → 종자 휴면 유지·발아 억제 (자리/뜻)
- 갈라진 땅 → 가뭄·수분 스트레스 (모양)
- 화분 속 작은 새싹 약 3개 → 모름

집계(확신 40% 이상만 셈): 구역1 2개 · 구역2 4개 · 구역3 2개 · 구역4 2개 · 구역5 6개 · 구역6 4개, 합 20개. 오른쪽(에틸렌·ABA)이 왼쪽보다 선명하게 읽힘.

## ③ 뜻 모를 것 · 어색한 것 · 헷갈리는 것 · 이은 흔적
- 지퍼 옥수수: 이삭 위에서 다시 줄기가 올라 꼭대기에 작은 이삭이 또 있음, 의도 불명. 알갱이 더미에서 난 시든 싹도 불명. 시소도 불명. 화분 3개(토끼 화분·시소 화분·노인 화분)가 각기 다른 일을 하는 듯하나 이유 불명.
- 옥신이냐 지베렐린이냐: 구역1(옥수수·분무)과 구역3(쪼갠 씨앗·긴 싹)에 둘이 나뉘어 들어갔을 것 같으나 어느 쪽이 어느 쪽인지는 반반. 구역4는 6번째 호르몬(브라시노스테로이드?)인지 환경 반응(접촉)인지 미정.
- 헷갈림: 시든 싹(구역1)과 갈고리 새싹(구역5), 노란 잎 2종(시토키닌의 노화 vs 에틸렌의 낙엽), 흙 속 씨앗(휴면)과 쪼갠 씨앗(발아), 롤러가 병처럼도 보임, 솔질 쪽이 결과인지 큰 식물이 결과인지.
- 이음새: 열린 유리문 자리(가로 약 1190~1360)에서 지붕 구조·원근이 바뀌어 두 장을 이은 듯. 노인만 화풍이 달라 합성한 느낌. 작업자 4명이 복제처럼 똑같음. 구역2·3은 곁가지와 시소 때문에 경계가 붙어 있음.

## ④ 한 문장
식물 호르몬은 종류마다 일이 달라서, 옥신·지베렐린은 키와 발아를, 시토키닌은 분열과 노화 지연을, 에틸렌은 숙성·낙엽을, ABA는 기공 닫기·휴면을 맡는다.
