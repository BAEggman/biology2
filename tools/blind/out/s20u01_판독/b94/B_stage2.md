# 2단계 약속 대조 읽기 (s20u01) — ↻ = 1단계와 달라진 곳

## ① 판 전체 표제어
- 1순위 **식물 호르몬(옥신·시토키닌·지베렐린·브라시노스테로이드·에틸렌·ABA)** 95% ↻(85→95). 약속표에 이 판 전용 풀이가 구역마다 하나씩 있어 여섯 무리와 1:1로 맞음.
- 2순위 **식물의 환경 스트레스 반응·생장 조절(기공·휴면·건조 내성)** 3%.
- 판정: 약속으로 확실히 더 잘 풀림. 1단계 추정이 거의 확정되고 「모름」 5개(지퍼·알 더미·시소와 돌·솔·갓)가 풀림. 틀렸던 읽기 셋: 옥수수 소리 풀이(→ 알갱이가 옥신), 시소=균형·길항(→ 받침돌 지렛대=지베렐린), 노인=노화 상징(→ 갓 쓴 아비=ABA).
- 읽힌 사실 수 5·4·4·2·5·5 (1단계 5·4·3·2·5·5). 수는 구역3만 +1이지만, 1단계에서 추정으로 센 것이 표 근거로 확정되어 믿음이 달라짐. 표에 없는 물건(망치·끌·깨진 씨앗, 사다리)은 일반 지식 읽기로만 남음.

## ② 구역 (왼쪽부터 6구역)
**구역1 옥신** (옥수수·사다리 사람)
- ↻ 옥수수 알갱이 = 옥신(#13). 이름표는 줄기가 아니라 알갱이.
- ↻ 꼭대기 자루에서 지퍼 틈으로 아래로만 떨어지는 알갱이(약 10알) = 극성 수송.
- ↻ 분무기 물방울 = H⁺(#119), 지퍼 틈 = 세포벽 → 열림 = 벽 느슨·세포 신장(산성 생장). 추정이 확정.
- ↻ 사다리 아래 알갱이 더미에 파묻힌 시든 잡초 = 고농도 억제(1단계 모름 → 풀림).
- 지퍼 열린 줄기 속 알갱이 = 줄기 안의 옥신. 사다리와 사람은 무대 소품.

**구역2 시토키닌** (토끼·화분)
- ↻ 흙바닥에 앉은 토끼 = 시토키닌(#64). 1단계는 소리 추정.
- 새끼 토끼 2마리 = 세포분열 촉진.
- 초록 롤러로 칠한 초록 잎 ↔ 안 칠한 노란 잎 = 노화 지연. 표는 「반쪽 초록 잎」, 내 눈엔 통째로 칠한 잎 1장과 노란 잎 1장의 대비.
- 화분의 긴 곁가지 = 곁눈 촉진.

**구역3 지베렐린** (망치·씨앗·시소)
- ↻ 받침돌에 걸친 지렛대 = 지베렐린(#37). 「시소·돌 모름」이 풀리고 균형·길항 읽기는 버림.
- 지렛대 끝에 들려 올라간 가늘고 긴 식물 = 줄기 신장.
- 망치·끌로 깨진 씨앗 = 휴면 해제, 틈의 싹 = 발아. 표에 없는 물건이라 일반 지식 읽기이며, 구역6의 「눌러 묻은 씨앗=휴면」과 짝으로 읽힘.

**구역4 브라시노스테로이드** (솔·큰 식물)
- ↻ 솔 = 브라시노스테로이드(#38). 1단계 소리 추정이 확정.
- ↻ 솔이 닿은 두 배 크고 곧은 줄기 = 그 호르몬이 하는 일(줄기 신장).
- 보류(세지 않음): 곁의 작고 빽빽한 식물(대조?), 아랫잎이 남은 것(낙엽 지연?).

**구역5 에틸렌** (토마토·구름)
- 연보라 기체 구름 = 에틸렌(#121).
- 구름 안 열매만 익음(빨강·분홍 4) 대 구름 밖 초록 1 = 숙성 촉진.
- 사람이 든 익은 열매에서 구름이 나옴 = 익은 열매가 내보냄(자기촉매).
- 구름 안 노란 잎 3장 = 낙엽.
- 포기 발치의 곧은 싹 대 짧고 굵고 누운 초록 고리 = 삼중반응.

**구역6 ABA** (아비·셔터·흙더미)
- ↻ 갓 쓴 늙은 아비 = ABA(#19, #1). 갓 「모름」이 풀리고 노화 상징 읽기는 버림.
- ↻ 한 손이 잎의 롤 셔터를 내림 = 기공 닫힘(#120).
- ↻ 한 손이 누른 흙더미 속 씨앗 = 종자 휴면(#20).
- ↻ 구두 밑에 깔린 모종 = 생장 억제(#21).
- ↻ 갈라진 땅 위 말라 쓰러진 풀 ↔ 빳빳이 선 셔터 잎 = 건조 스트레스 대 ABA의 건조 내성(#18). 마른 바람은 따로 못 찾음.

## ③ 남은 모름·헷갈림·이음
- 표에 없어 끼우지 않은 것: 사다리, 분무기 든 사람, 망치와 끌(끌은 칼과 닮았으나 K⁺로 읽지 않음), 시소 위 꿇어앉은 사람, 바닥의 검은 선(마른 호스? 뿌리?). 같은 대머리 작업복 사람 4명은 모자가 없어 뜻 없는 일꾼.
- 헷갈림: 시든 풀 둘(알 더미 속=고농도 억제, 갈라진 땅 위=가뭄), 싹 셋(깨진 씨앗=발아, 누운 싹=삼중반응, 눌린 싹=생장 억제), 노란 잎 둘(초록 칠 곁=노화 지연, 구름 속=낙엽). 자리로만 갈림. 구역 경계도 겹침.
- 이음: 가운데 열린 유리문과 기둥이 좌(키우는 쪽)·우(익히고 재우는 쪽)를 가름(표 근거 없음). 눈에 띄는 접합선 없음. 틀선 칸 없음(#118 해당 없음).

## ④ 한 문장
옥신은 꼭대기에서 아래로만 흘러 H⁺로 세포벽을 풀어 키우고(많으면 억제), 시토키닌은 나누고 푸르게 하며 곁눈을 틔우고, 지베렐린은 지렛대로 키를 들어 올리고, 브라시노스테로이드는 줄기를 곧고 크게 하며, 에틸렌은 기체로 열매를 익히고 잎을 떨구고 싹을 눕히고, ABA는 기공 셔터를 내려 가뭄을 견디고 씨앗을 재우고 싹을 누른다.
