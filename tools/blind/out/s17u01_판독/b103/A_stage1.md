# 1단계 생판 (s17u01, 그림만 보고)

## ① 판 전체 표제어
- 1순위 **배설계: 신장(네프론)의 오줌 생성 - 여과·재흡수·분비, 레닌 장치, 질소노폐물** (70%). 수로가 세뇨관 관강으로 읽힌다. 짐을 뭍으로 지고 오르면 재흡수, 뭍에서 배로 실으면 분비.
- 2순위 **세포막 수송(공동수송·삼투)** (12%). 포도+소금 짐, 문, 널다리가 막수송으로도 읽힌다.

## ② 구역 (왼쪽부터, 원본 x좌표)
### 구역1 (0-650) **사구체 여과 + 곁사구체장치(레닌·치밀반)**
- 위에서 내려오는 굵은 푸른 관 = 수입세동맥, 굵어서 압력이 높다 (자리·굵기)
- 관 속 점박이 구슬 = 곁사구체세포의 레닌 과립 (모양: 점=과립)
- 낫 = 레닌 (소리: 레닌의 낫, 뜻: 자름)
- 낫에 끊기는 바닥 밧줄 = 안지오텐시노젠이 잘려 안지오텐신 I (동작)
- 관 중간 매듭 = 수입세동맥 수축, 되먹임 (동작)
- 매듭에서 솔 상자로 이어진 밧줄 = 치밀반이 보내는 신호 (자리)
- 나무 덕트 속 검고 빽빽한 솔 + 흰 반짝임 = 치밀반이 NaCl 감지 (모양: 빽빽=dense)
- 엉킨 푸른 호스 뭉치 = 사구체 모세혈관 뭉치 (모양)
- 호스에서 쏟아지는 물줄기 약 12줄 = 여과액 (동작·개수)
- 그물 더미 = 여과막이 크기로 거름 (뜻)
- 호스 위로 닿는 구리 기둥 = 수출세동맥, 더 가늘다 (자리, 낮음)
- 못 2개 = 모름 (ACE 가능성만)

### 구역2 (650-1100, 위·가운데) **근위세뇨관 재흡수: Na+-포도당 공동수송**
- 자주색 포도 상자 = 포도당 (소리)
- 소금 자루 = Na+ (뜻)
- 둘이 짐을 함께 지고 널다리를 오르는 남자들 = 공동수송 (동작)
- 한 남자는 소금 2 + 포도 1, 다른 남자는 소금 1 + 포도 1 = Na+:포도당 2:1(SGLT1), 1:1(SGLT2) (개수)
- 널다리 = 운반체 단백질 (모양)
- 짐을 다 내려 빈 배(널다리에 밧줄로 묶임) = 포도당이 관강에 안 남음, 전량 재흡수 (자리, 추정)
- 가판대 포도 상자(오른쪽 3, 왼쪽 약 4)와 소금 자루(오른쪽 3) = 개수만 보이고 뜻은 모름

### 구역3 (630-1130, 수면) **울타리·성게·두 말뚝 남자 - 대부분 모름**
- 성게 4마리가 화살표 따라 왼쪽으로 튐 = 가시 이온 H+ 또는 K+ 분비? (모양, 낮음)
- 뾰족 울타리(말뚝 20여 개, 가로대 2줄) = 장벽? 모름
- 두 말뚝에 다리를 크게 벌리고 선 남자 = 모름 (두 갈래 사이를 잇는 자세, 인산 완충? 추측뿐)

### 구역4 (1100-1550) **포도당의 문(GLUT) + 통나무 배**
- 어두운 문으로 포도만 들고 들어가는 남자 = 촉진확산 GLUT, 소금 없음 (동작·뜻)
- 통나무 약 12개 실은 빠른 배 = 여과만 되고 그대로 나가는 물질(이눌린)? (낮음)

### 구역5 (1545-2040, 위) **질소 노폐물 3종: 암모니아·요소·요산**
- 어항 속 물고기 + 김 = 암모니아, 어류, 기체처럼 휘발 (뜻)
- 그 아래 넘치는 큰 항아리 = 물이 아주 많이 필요 (자리)
- 개구리 + 노란 이불(요) = 요소 (소리·뜻)
- 이불 앞 동전 3개 = 합성에 ATP 3 (개수)
- 중간 항아리 = 물 중간 (자리)
- 알 속 병아리 + 흰 이불 더미 = 조류 요산, 알 속에 하얗게 쌓임 (뜻)
- 금화 약 20 = 합성 에너지 최대 (개수)
- 찻잔 물방울 하나 = 물 거의 불필요 (개수)

### 구역6 (1500-2040, 아래) **통과 하마 배**
- 널판으로 통을 굴려 배에 싣는 남자 = 분비(혈액쪽에서 관강으로)? (동작, 낮음)
- 하마 = hippurate(PAH)? 소리, 낮음. 통 약 10개 = 모름
- 세 배의 짐: 빈 배 0 < 통나무 약 12 < 통 약 10 + 하마. 늘어나는 순서라 청소율 비교일 수도 있으나 확신 낮음.

## ③ 어색·헷갈림·이은 흔적
- 모름: 구리 기둥, 못 2개, 울타리, 말뚝 남자, 성게 4, 통 약 10.
- 헷갈림: 구슬 vs 호스 뭉치(어느 쪽이 사구체), 낫=Na vs 레닌, 성게=H+ vs K+, 하마=hypo vs hippurate.
- 어색: 하마가 통 위에 앉음, 큰 항아리 물이 널판으로 흐름, 호스 끝이 없는데 물이 쏟아짐.
- 흔적: 솔 상자 속 털은 노이즈 같은 합성, 동전 3개·찻잔 물방울·병아리·성게 화살표는 스티커처럼 평평, 구리 기둥이 이음매처럼 전체 높이를 가름, 왼쪽은 번진 수채풍이고 오른쪽은 또렷한 만화풍.

## ④ 한 문장
사구체에서 걸러져 수로로 쏟아진 물에서 포도당·Na+는 뭍으로 되지고 오르고, 일부는 배로 실려 나가며, 레닌-치밀반 장치가 압력을 맞추고, 동물마다 질소 쓰레기를 암모니아·요소·요산으로 다르게 내보낸다.
