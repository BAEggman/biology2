# stage2 약속표 어휘로 다시 읽기 (s17u01) — ↻ 1단계와 달라진 곳 · [n] 약속표 줄 번호

## 판정
약속으로 훨씬 더 잘 풀린다. 구역1의 1단계 「모름」(낫·밧줄·못·말뚝 위 사람·울타리와 성게)이 [3][128~130]으로 풀렸고 그물·솔털 오독은 고쳤다. 구역4는 하마가 풀렸다. 구역2·3은 방향 그대로 약속이 확정만 했다. 안 풀린 것은 ③에 남겼다.

## ① 판 전체 표제어
- 1순위 **배설계 — 콩팥(네프론)의 구조와 오줌 생성: 사구체 여과막·사구체옆장치(레닌–안지오텐신)·재흡수·분비·질소 노폐물** (85%) ↻ 70→85
- 2순위 **동물의 질소 노폐물과 삼투조절(배설 방식 비교)** (10%) ↻ 20→10

## ② 구역별 읽기 (괄호는 확신도)
### 구역1 왼쪽 구석+호스 아래 물가 **사구체 여과막과 사구체옆장치·레닌–안지오텐신** (80%) ↻ 표제어 바뀜
1. 실뭉치 호스 1 + 물줄기 약 11 → 사구체와 여과액 [132] (90%)
2. 푸른 천 둥근 관(호스로 들어감) → 핏줄, 들어오는 관 [133] (80%) ↻
3. 그 관 허리를 조인 가는 끈 1(끝이 상자 창 속으로) → 들어오는 관을 조이는 되먹임 신호 [128 비고] (75%) ↻
4. ㄴ자로 꺾인 나무 네모 관 → 세뇨관, 막힌 끝이 푸른 관에 닿되 안 이어짐 [133] (80%) ↻
5. 창 속 촘촘한 검은 털 → 촘촘함=치밀반 [4 비고] (70%) ↻ 솔가장자리에서 고침
6. 구겨 넣은 삼베 그물 → 사구체간질세포(메운다) [131] (80%) ↻ 여과막에서 고침
7. 낫 1 → 자르기만 하는 효소=레닌 [3] (70%) ↻
8. 땅에 늘어진 긴 밧줄 → -오겐(안지오텐시노겐) [128] (75%) ↻
9. 쇠말뚝 둘 사이 팽팽한 밧줄 토막(낫이 끊은 자리 하나) → 안지오텐신 I [128] (75%) ↻
10. 가시 철 울타리에 되튕기는 가시 공(성게) 4 → 같은 전하끼리 반발, 크기 아닌 전하로 막음 [129] (75%) ↻ 4의 뜻은 모름
11. 두 말뚝에 발 올리고 다리 벌린 사람의 가랑이 → 여과 슬릿 [130] (70%) ↻
12. 관벽 불룩한 구슬 알갱이 덩어리(낫 자루가 기댐) → 약속 없음, 레닌 알갱이를 가진 사구체옆세포 추정 (40%)
13. 구리빛 가는 둥근 관 1(호스 뒤에서 위로) → 핏줄 [133], 더 가늘어 나가는 핏줄 후보 (35%) ↻

### 구역2 가운데 부두 **근위세뇨관 재흡수: Na⁺–포도당 공동수송과 뒷문(기저외측막)** (75%)
1. 포도 → 포도당 [90] (85%)
2. 소금 자루 → Na⁺ [111 비고] (85%)
3. 소금과 포도를 함께 지고 오르막 널판을 오르는 두 사람 → 공동수송, 농도를 거슬러 끌어올림 (60%)
4. 앞사람 소금 2자루+포도 1상자 / 뒷사람 1+1 → Na⁺ 대 포도당 2:1과 1:1 (45%)
5. 열린 뒷문 어두운 안으로 포도만 안고 들어가는 사람 1 → 기저외측막, 세포에서 혈액 쪽으로 나가는 문 [134] (65%) ↻ 부두=세포, 수로=관 안으로 읽힘
6. 빈 노 젓는 배(계류 밧줄) → 짐을 다 내림=완전 재흡수 (35%)
7. 통나무 배(통나무 약 12, 긴 물결) → 그대로 빠르게 통과(이눌린류?) (25%)
- 모름: 가판대 2의 개수

### 구역3 오른쪽 위 선반 **질소 노폐물 3형, 물 필요량, ATP 비용** (80%)
1. 어항 물고기 1, 김 3줄 → 암모니아(어류, 휘발·독성) (70%)
2. 개구리 1 + 노란 이불 → 요(이불)=요소·요산 [9], 양서류라 요소 (70%) ↻
3. 알 속 오리새끼가 앉은 흰 접힌 이불 더미 → 요 [9], 알이라 요산(불용성 고체) (75%)
4. 금화 0 / 3 / 약 16 → 동전=ATP [8], 합성 비용 암모니아<요소<요산 (75%) ↻ 에너지에서 ATP로
5. 항아리 셋(넘치는 큰 것 / 가득 찬 작은 것 / 한 방울 찻잔) → 물 그릇=질그릇 항아리 [102 비고], 필요한 물 암모니아>요소>요산 (65%)
- 모름: 알 왼쪽 모래 무더기

### 구역4 오른쪽 아래 **PAH 분비** (60%) ↻ 「분비? 통 더 얹기」에서
1. 하마 1 → PAH [41] (80%) ↻ 모름에서 풀림
2. 판자 위에서 통 1을 통 약 10 실린 하마 배에 더 얹는 사람 → 부두(혈액 쪽)에서 수로(관 안)로 더 보탬=분비 (55%)
- 모름: 통의 뜻과 개수

## ③ 뜻 모를 · 어색 · 헷갈림 · 이어 붙인 흔적
- 약속표로도 모름: 구슬 알갱이 덩어리, 배 3척과 통, 성게 4·통나무 12·물줄기 11의 개수, 가판대, 모래 무더기, 상자 앞면 못 1([23]은 s37p01 전용이라 안 읽음).
- 못 찾은 약속: [2] 금색 자물쇠(문 손잡이는 둥근 고리뿐), [7], [33], [43].
- 약속으로 갈린 헷갈림: 둥근 관·네모 관 [133], 실뭉치·삼베 그물 [132·131], 낫·칼 [3], 밧줄 셋(-오겐 / 안지오텐신 / 되먹임 끈) [128].
- 정정 ↻: 1단계 「의족 같은 발」은 널판 위 모서리의 계류 말뚝이 발과 겹친 것이다.
- 이어 붙인 흔적(유지): 선반의 개구리·금화 3·알 속 오리·물고기가 아이콘풍 합성처럼 보임, 솔털 조각 잡음 질감, 알 왼쪽 반투명 얼룩, 맨 왼쪽 관을 가로지르는 가로 이음선 1줄, 하마 배가 오른쪽 틀에서 잘림.

## ④ 한 문장
사구체는 전하와 슬릿으로 큰 분자를 막고 걸러 내고, 사구체옆장치는 레닌(낫)이 안지오텐신(밧줄)을 만들어 압력을 맞추며, 세뇨관은 포도당을 Na⁺와 함께 되찾아 뒷문으로 보내고 PAH는 더 얹어 내보내고, 동물은 질소 노폐물을 암모니아·요소·요산(요, 동전=ATP)으로 달리 버린다.
