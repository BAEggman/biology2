# stage1 — 생판 (그림만 보고, 좌표는 원본 2048px 기준)

## ① 판 전체 표제어
- **배설계(신장): 오줌 생성(여과·재흡수·분비)과 질소노폐물** — 1순위 80%
- **체액·삼투조절(항상성, 레닌 조절 포함)** — 2순위 12%
- 근거: 한 줄기 관(동맥→뭉치→동맥), 뭉치에서 새는 물, 짐을 배↔뭍으로 나르는 시장, 선반 3칸(물고기·개구리·알).

## ② 구역 (왼→오)
**구역1 (x25~570, 위·가운데) — 사구체옆장치·수입/수출세동맥: 레닌과 되먹임** (대안 **헨레고리 역류** 20%)
- 회색 천 관 + 아래 화살표 2 = 수입세동맥(굵고 말랑, 혈액 유입) — 자리·화살표
- 구리관 + 위 화살표 2 = 수출세동맥(가늘고 단단, 유출) — 굵기 대비
- 관 허리를 묶은 매듭줄 = 수입세동맥 수축 → GFR 감소 — 모양
- 매듭줄이 나무상자 틈새로 이어짐 = 세뇨관→사구체 되먹임 신호 — 자리
- 두 관 사이의 나무 L자 관 = 원위세뇨관 — 자리
- 틈새의 검은 촘촘한 솔 + 흰 결정(약 13) = 치밀반(dense), NaCl 감지 — 소리·모양
- 관 벽의 불룩 주머니 속 구슬 수십 개 = 사구체옆세포 과립 — 모양
- 낫이 주머니에 꽂혀 구슬을 쏟음 = 레닌 분비(낫→레닌) — 소리
- 삼베 그물 덩이 = 메산지움(mesh)? — 약함
- 놋쇠 고리(구리관 아래) = 수출세동맥 수축 → GFR 증가? — 모름 쪽
→ 읽힌 사실 9

**구역2 (x380~1000, 아래) — 사구체 여과와 여과막**
- 호스 한 뭉치(두 동맥 사이) = 사구체 — 모양
- 뭉치 아래로 새는 물줄기 약 12 = 압력으로 물·작은 용질 여과 — 동작
- 석벽 안 초록 물 = 보먼주머니/여과액 — 자리
- 가시 울타리, 가로살 3줄 = 여과막(내피·기저막·족세포 틈새) — 개수
- 갈색 가시공 4개가 튕겨 화살표로 되돌아감 = 알부민·혈구 등 큰 분자는 못 나가고 혈액에 남음 — 모양(알밤≈알부민)
- 두 말뚝 위에 다리 벌린 남자 = 족세포 발돌기, 다리 사이 = 여과틈새 — 자세
→ 읽힌 사실 7

**구역3 (x620~1340, 위·부두) — 근위세뇨관 재흡수: Na+·포도당 공동수송**
- 포도 상자(왼 가판 4, 오른 가판 3) = 포도당 — 소리(포도→포도당)
- 소금 자루(가판 아래 3) = Na+ — 뜻
- 배→뭍으로 오르는 판자 다리 = 공동수송체 통로, 방향 = 재흡수 — 자리
- 자루 2 + 상자 1을 진 사람 = Na+ 2 : 포도당 1 — 개수
- 자루 1 + 상자 1을 든 사람 = Na+ 1 : 포도당 1 — 개수
- 포도 상자만 들고 어두운 문으로 드는 사람 = 포도당 단독 촉진확산(혈액 쪽) — 동작
- 판자 끝에 묶인 빈 배 = 포도당·Na+가 다 되찾겨 소변엔 없음 — 자리
→ 읽힌 사실 7

**구역4 (x1220~2000, 아래) — 청소율과 분비: 이눌린(GFR)·PAH**
- 통나무 배가 물결을 가르며 짐 변동 없이 통과 = 여과만 되는 물질, 청소율=GFR — 동작
- 술통 약 9개 + 하마 = PAH(하마→마뇨산), 청소율≈신혈장유량 — 소리
- 뭍에서 판자로 통을 굴려 배에 더 실음 = 분비(혈액→세뇨관), 재흡수와 방향 반대 — 동작
- 만재로 가라앉은 배 = 한 번 통과로 대부분 제거 — 모양
→ 읽힌 사실 4

**구역5 (x1520~1960, 위·선반) — 질소노폐물: 암모니아·요소·요산**
- 수조 + 물고기 = 암모니아, 수생동물 — 뜻
- 김 3가닥 = NH3(수소 3), 휘발·독성 큼 — 개수
- 넘치는 큰 항아리 = 물을 가장 많이 씀 — 크기
- 개구리 + 노란 이불(요) + 소쿠리 = 요소(양서류·포유류) — 소리
- 중간 항아리 = 물 중간 — 크기
- 동전 3 = 요소 합성 ATP 3 — 개수
- 알 속 병아리 = 조류·파충류 알 — 모양
- 흰 이불(요) 더미(산) = 요산, 불용성 고체 — 소리
- 찻잔의 물방울 1 = 물 거의 안 씀 — 크기
- 동전 더미 = 에너지 최대 소모 — 개수
- 수조 칸에 동전 없음 = 에너지 최소 — 빈자리
→ 읽힌 사실 11

## ③ 이상한 것
- 뜻 모를 것: 바닥 밧줄(틀 밖에서 들어와 못 2개에 묶임) · 놋쇠 고리 · 삼베 그물 · 문 안의 어둠 · 계류 말뚝 · 둥근 소쿠리 · 하마.
- 어색: 관이 U자로 휘어 헨레고리처럼도 보임 · 낫이 주머니에 꽂힘 · 하마가 술통 위 · 같은 얼굴 남자 5명.
- 헷갈림: 회색관(수입세동맥↔하행각)·구리관(수출세동맥↔상행각)·호스 뭉치(사구체↔나선세뇨관)·통나무배↔술통배·노란 이불(요소)↔흰 더미(요산)·가시공(알부민↔혈구).
- 이어 붙인 흔적: 왼쪽 벽 지평선에 관 양옆으로 블록 모양 흐린 유령(지운 자국) — 오른쪽 벽엔 없음 · 왼쪽(관·호스)은 짙은 회화풍, 오른쪽(시장·선반)은 매끈한 평면풍 · 바닥 석재가 x≈560에서 황갈 판석→회색 절석으로 바뀜 · 물빛은 연속.

## ④ 한 문장
신장은 사구체에서 큰 것을 막고 거르고(레닌이 그 양을 되먹임 조절), 세뇨관에서 포도당·Na+는 되찾고 일부는 더 얹어 오줌을 만들며, 질소노폐물은 암모니아→요소→요산 순으로 물은 덜 쓰고 에너지는 더 쓴다.
