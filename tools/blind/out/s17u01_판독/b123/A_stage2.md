# stage2 — 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳, #번호 = 약속표)

## 판정
약속표로 더 잘 풀린다. 「모름」이던 바닥 밧줄·쇠말뚝(#128), 둥근 소쿠리(#136)가 풀렸고, 하마(#41)·세 척의 배(#135)는 짐작에서 확정으로, 가시 울타리의 뜻은 크기에서 전하로 고쳐졌다(#129). 약속에 없어 그대로 모름: 놋쇠 고리, 계류 말뚝, 첫 배의 가로장 3, 가판대 상자 4+3·소금 자루 3, 하마 배의 통 약 9.

## ① 판 전체
- **배설계(콩팥): 사구체 여과·재흡수·분비(청소율)·질소노폐물, 그리고 레닌-안지오텐신의 시작** — 1순위 90%
- **체액·혈압 조절(RAAS·삼투조절)** — 2순위 6%
- ↻ 1단계 구역1의 대안 **헨레고리 역류**는 버림: 눈금 자·유리 구 셋(#6·#152)이 없고, 둥근 관의 화살은 들어오는/나가는 관(#133).

## ② 구역 (왼→오)
**구역1 (x25~570) — 사구체옆장치와 레닌-안지오텐신의 시작**
- 회색 둥근 관 ↓↓ = 들어오는 관(수입세동맥) · 구리 둥근 관 ↑↑ = 나가는 관(수출세동맥) (#133)
- 가는 끈이 들어오는 관을 졸라맴 = 되먹임 신호 (#128) ↻ 확정
- 나무 네모 관(오줌길)의 막힌 끝이 회색 관에 닿되 안 이어짐 = 원위세뇨관 접촉 (#133) ↻
- 촘촘한 검은 털 = 치밀반 (#4) · 흰 결정 약 13 = 관 속 NaCl 짙기 (#145) ↻
- 부푼 주머니에 크림 알갱이 가득 = 과립세포 (#137) · 아가리의 낫 = 레닌, 자르기만 하는 효소 (#3) ↻ 「낫→Lenin」 소리 근거는 폐기
- ↻ 땅에 늘어져 끝이 잘린 긴 삼밧줄 = 안지오텐시노젠, 쇠말뚝 둘 사이 팽팽한 토막 = 안지오텐신 I(끊긴 자리 하나) (#128) — 낫 날이 잘린 자리 위에 놓임
- 삼베 그물 = 메산지움 (#131) ↻ 약함→확정
→ 읽힌 사실 11

**구역2 (x380~1000, 아래) — 사구체 여과: 전하 장벽과 여과 슬릿**
- 엉킨 호스 뭉치 + 새는 물줄기 약 12 = 사구체와 여과액 (#132)
- 물이 떨어지는 운하 = 관 속, 둑 따라 땅 위 = 겉질 구간 (#134·#158) ↻ 새로 더함
- 가시 울타리 = 같은 전하의 가시 그물, 가시공 4 = 음전하 단백질(알부민)이 튕겨 되돌아감 (#129·#138) ↻ 크기→전하, 가로살 3줄 뜻은 버림
- 말뚝 위 다리 벌린 사람의 가랑이 = 여과 슬릿 (#130) ↻ 족세포 발돌기→슬릿
→ 읽힌 사실 6

**구역3 (x620~1340, 위) — 근위세뇨관 포도당 재흡수: SGLT1·SGLT2·GLUT2**
- 포도 = 포도당 (#90) · 흰 소금 자루 = Na⁺ (#111, 배수성 아님)
- 자루 둘 + 궤짝 = SGLT1(관 뒤쪽·남은 것까지 꽉), 자루 하나 + 궤짝 = SGLT2(관 앞쪽·많이·느슨) (#111) ↻ 이름 배정
- 수로와 맞붙은 널빤지 다리 = 관강막 (#134) ↻
- 어두운 뒷문으로 궤짝만 안고 나감 = 기저외측막의 GLUT2 (#134) ↻
- 텅 빈 배 = 전부 되찾음 (#135) ↻
→ 읽힌 사실 7

**구역4 (x1220~2000, 아래) — 청소율의 세 유형: 이눌린(GFR)·PAH(RPF)**
- 통나무 그대로 떠내려가는 배 = 여과만, 이눌린, GFR의 잣대 (#135) ↻ 확정
- 하마 = PAH (#41) ↻ 확정
- 더 실린 배 + 뭍에서 통을 굴려 얹음 = 분비(더 버림), 한 번에 거의 다 실려 나가니 RPF의 잣대 (#135)
- 배에 남아 흘러가는 짐 = 오줌으로 나가는 양 (#135) ↻
→ 읽힌 사실 5 (세 배가 한 묶음)

**구역5 (x1520~1960, 위·선반) — 질소노폐물: 암모니아·요소·요산**
- 뚜껑·그릇 없이 오르는 김 = 암모니아, 너무 독해 못 가둠 (#136) ↻ · 수조 속 물고기 = 수생
- 뚜껑 반쯤 젖힌 바구니에 덮인 노란 요 = 요소, 얼마간 가둠 (#136·#9) ↻ 「소쿠리 모름」 해소
- 알 속 병아리 밑의 흰 요 더미 = 요산 (#9)
- 동전 = ATP (#8): 수조 칸 0 · 개구리 3 · 알 곁 더미 ↻ 확정
- 항아리 물높이(#153): 넘치는 큰 항아리 · 중간 항아리 · 찻잔의 물방울 1 = 물을 많이→적게
→ 읽힌 사실 12 (김 3가닥=NH₃·개구리=양서류는 약속 밖 곁다리)

## ③ 이상한 것
- 풀린 것: 밧줄 둘 · 소쿠리 · 문 안의 어둠(뒷문) · 삼베 그물 · 낫 · 하마.
- 약속에 없어 모름: 놋쇠 고리 · 계류 말뚝 · 가로장 3 · 상자 4+3/자루 3 · 통 약 9 · 바닥 알갱이 약 17의 수.
- 끼우지 않은 후보: 검은 털(#38 솔 — 든 솔 아님) · 흰 결정(#78 다이아몬드 — 떨어지지 않음) · 술통(#98 — 뚜껑 멀쩡) · 알(#62 오카리나 — 진짜 알) · 상자 못 1(#139 — 버튼 넷 아님) · 호스 뭉치(#43 — 붉은 웅덩이 없음).
- 이어 붙인 흔적(1단계 그대로): 왼쪽 벽 지평선의 블록 모양 유령, 왼쪽 회화풍/오른쪽 평면풍, x≈560 바닥 석재 변화(구리관이 이음매를 가림).

## ④ 한 문장
콩팥은 사구체에서 음전하·슬릿 장벽으로 알부민을 막고 거르며(레닌이 되먹임으로 조절), 세뇨관에서 SGLT·GLUT2로 포도당을 되찾고 일부는 분비하여 청소율 세 유형(이눌린·전부 재흡수·PAH)이 생기며, 질소노폐물은 암모니아→요소→요산 순으로 물은 덜·ATP는 더 쓴다.
