# 1단계 생판 읽기 (s17u01, 그림만 보고)

## ① 판 전체 표제어
- **1순위: 배설계 — 신장(콩팥)의 오줌 생성(여과·재흡수·분비)과 질소 노폐물** — 확신도 75%
- **2순위: 항상성 — 체액·삼투·혈압 조절(RAAS·ADH)** — 확신도 12%
- 참고: **막수송(공동수송·촉진확산)** 5% — 가운데 시장 구역만 설명함.
- 근거: 실뭉치+물줄기(사구체), 가시 울타리(여과막), 포도+소금 운반(공동수송), 3칸 선반(암모니아·요소·요산), 배 3척(청소율?).

## ② 구역별 읽기 (왼쪽부터 6구역, 괄호는 근거와 확신)
**구역1 (x 0~620) 사구체와 방사구체 장치(JGA)**
1. 회색 호스 뭉치 = 사구체 (모양·뜻: 얽힌 실뭉치, 80%)
2. 뭉치 밑으로 쏟아지는 물줄기 약 12줄 = 여과액(원뇨)이 혈관 밖으로 빠짐 (뜻 75%, 12는 뜻 모름)
3. 위에서 내려와 뭉치로 이어지는 파란 자루관 = 수입세동맥 (자리 55%)
4. 그 목을 묶은 밧줄 = 조임·수축 (뜻 40%)
5. 관벽 속 구멍 송송한 진주알 = 레닌 과립을 가진 JG세포 (모양 40%; 대안: 유창 모세혈관)
6. 노란 L자 관의 창 속 검은 빽빽한 솔털 = 치밀반(빽빽·짙음) 또는 솔가장자리 (모양 40%)
7. 밧줄이 이 창과 파란 관 매듭을 이음 = 세뇨관→수입세동맥 되먹임 (자리 40%)
8. 삼베 그물 더미 = 그물(라시스·메산지움 또는 모세혈관망) (뜻 40%)
9. 뭉치에서 위로 빠지는 구리색 기둥 = 수출세동맥 (자리·색 35%)
- 모름(세지 않음): 낫(Na 소리? 또는 ANP), 밧줄+못 2개.

**구역2 (x 620~1130, 아래) 사구체 여과막**
1. 가시 달린 철망 울타리 = 여과막·기저막, 그물눈 크기로 거름 (뜻 70%)
2. 밤송이(성게) 4개가 울타리에 막혀 튕김(화살표) = 큰 입자(혈구·단백질)는 못 지나 혈액에 남음 (뜻 65%, 4는 뜻 모름)
3. 두 말뚝에 다리 벌리고 선 남자 = 족세포의 발돌기와 여과 틈 (소리 '발'+자세 60%)
4. 물은 울타리를 지나 반대편 물길로 감 = 작은 분자만 통과 (자리 60%)
- 울타리 위 가시: 모름(음전하 장벽?).

**구역3 (x 680~1330, 위 시장·부두) 근위세뇨관 재흡수(Na+-포도당 공동수송)**
1. 포도 상자 = 포도당 (소리 85%)
2. 흰 가루 자루 = 소금 Na+ (모양 70%)
3. 두 남자가 포도와 소금을 함께 들고 판자 하나로 부두를 오름 = 공동수송, 같은 방향 (뜻 70%)
4. 남자 A: 소금 자루 2 + 포도 1상자 = Na+ 2 : 포도당 1 (개수 35%)
5. 문 속으로 포도만 들고 들어가는 남자 = Na+ 없이 포도당이 혈액 쪽으로 나감, GLUT2 (뜻 45%)
6. 판자 아래 빈 배 = 포도당 전부 재흡수, 소변엔 0 (뜻 40%)
7. 돌벽 = 세뇨관 상피·막 (자리 35%). 재고(포도 4+3상자, 자루 3+3)는 개수 뜻 모름.

**구역4 (x 1220~1540, 물길 가운데) 통나무 쾌속선**
1. 통나무 약 10개를 싣고 내리지도 더 싣지도 않고 질주 = 여과만 되고 재흡수·분비 없는 물질(이눌린→GFR?) (뜻 30%)

**구역5 (x 1540~2000, 위 선반) 질소 노폐물과 물·에너지 비용**
1. 수족관 물고기 = 암모니아 (뜻 75%)
2. 김 3줄 = NH3 기체·독성 (개수 50%)
3. 개구리 + 노란 누비 이불(요) = 요소 (소리 '요소'+양서류 65%)
4. 알 속 병아리 + 하얀 침구 더미(요+산) = 요산, 알 속에 쌓임 (소리+자리 65%)
5. 동전 0 / 3 / 약 16 = 합성에 드는 에너지, 암모니아<요소<요산 (개수 55%)
6. 항아리 3개(넘치는 큰 것/반쯤 찬 단지/한 방울 찻잔) = 내보낼 때 드는 물, 암모니아>요소>요산 (모양·자리 65%)

**구역6 (x 1500~2048, 아래 오른쪽) 하마와 통 실은 배**
1. 판자로 통을 계속 굴려 싣는 남자 + 통 약 10개 위의 하마 = 모름. 후보: 하마=hippurate(PAH, 근위세뇨관 분비) 40% / 하마=hypo(시상하부)→ADH 25% / 포유류→요소 15%.

## ③ 걸리는 것
- 뜻 모를 물건: 낫, 밧줄+못 2개, 구리 기둥, 삼베 그물, 통나무 배, 하마+통, 문 속 어두운 방, 머리에 손 얹고 선 남자 A(포화·대기?).
- 어색한 것: 검은 솔털 창(질감이 달라 오려 붙인 듯, 흰 점), 개구리·동전 3개·병아리 창·수족관 물고기는 납작한 스티커 느낌, 달걀 왼쪽 갈색 얼룩, 파란 관 양옆 벽의 회색 번짐(지운 글자 자국 같음).
- 헷갈림: 흰 자루(소금 vs 요산), 노란 이불 vs 하얀 침구, 솔털(솔가장자리 vs 치밀반), 파란 관(수입세동맥 vs 헨레고리), 배 3척(빈 배·통나무·하마)이 청소율 비교인지.
- 이어 붙인 흔적: 뚜렷한 이음선은 못 찾음. 왼쪽 부두(갈색 포석)와 시장(회색 포장) 바닥색이 다르고, 위의 후붙임 조각들이 있음.

## ④ 한 문장
콩팥은 사구체에서 크기로 걸러(여과) 세뇨관에서 포도당·Na+를 되찾고(재흡수) 일부는 더 실어 내보내며(분비), 동물은 질소 노폐물을 암모니아·요소·요산 중 물이 부족할수록 에너지를 더 쓰는 쪽으로 처리한다.
