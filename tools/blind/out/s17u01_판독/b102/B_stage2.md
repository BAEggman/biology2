# 2단계 — 약속표로 다시 읽기 (s17u01)

판정: 약속표로 더 잘 풀린다. 큰 틀(배설·신장)은 그대로이고, 왼쪽 구역(사구체·JGA)과 하마·가시 공·가랑이가 약속으로 확정되거나 고쳐졌다. 약속표에 없는 물건(진주알·구리 기둥·널다리·문·빈 배·통나무 배·통·병 모양 말뚝)은 끼우지 않고 추정/모름으로 둔다. 약속표의 V자 이음쇠·금색 자물쇠·왕복 궤도·눈금 자·알도스테론의 '통'은 이 그림에서 못 찾았다(금색 점 탐색에도 동전·이불·병아리뿐) — 다른 판용으로 본다.

## ① 판 전체 표제어
- ↻ 1순위 **배설계 — 신장의 오줌 생성(여과·재흡수·분비)과 질소 노폐물 3종** 85% (1단계 75%)
- ↻ 2순위 **사구체 여과와 그 조절(JGA: 레닌–안지오텐신, 세뇨관사구 되먹임)** 8% (1단계 2순위 삼투조절은 하마가 ADH가 아니라 PAH로 풀려 폐기)
- 근거: 사구체와 여과액(#132) · 여과 장벽(#129~131) · 안지오텐신 사슬(#128) · 하마=PAH(#41) · 요·동전(#9·#8) · 포도·소금 자루(#90·#111)

## ② 구역별

### 구역1 (x 0~590) — ↻ **사구체와 사구체옆장치(JGA)** (대안 '보먼주머니+근위세뇨관' 폐기)
1. ↻ 엉킨 관 뭉치 = 사구체 — #132 (1단계엔 55% 추정)
2. ↻ 그 밑 물줄기(≈12, 개수 뜻 없음) = 여과액 — #132
3. ↻ 위에서 들어오는 굵은 푸른 관 = 구심성 세동맥 — #128 '들어오는 관'
4. ↻ 그 목을 졸라맨 가는 끈(나무 관 틈에서 옴) = 되먹임 신호(TGF) — #128
5. ↻ ㄴ자 나무 관 창 속 촘촘한 짧은 털 = 치밀반(macula densa) — #4 '촘촘함이 뜻' (솔가장자리 대안 폐기, 솔 #38은 자루 달린 솔)
6. ↻ 낫 = 레닌(자르기만 하는 효소) — #3 (칼 아님)
7. 낫 자루가 꽂힌 구멍 숭숭한 진주알 = 사구체옆세포(레닌 저장) — 약속표 없음, 자리로 추정
8. ↻ 땅에 늘어져 낫에 잘린 긴 밧줄 = 안지오텐시노겐(-오겐) — #128
9. ↻ 쇠말뚝 두 개 사이 팽팽한 짧은 토막 = 안지오텐신(텐션) — #128 (1단계 '못 2개 모름' 해소)
10. ↻ 관 사이 틈을 메운 구겨 넣은 삼베 그물 = 사구체간질세포(메산지움) — #131
모름: 가는 구리 기둥(날세동맥? 약속표 없음)

### 구역2 (x 600~1000) — ↻ **여과막: 전하 장벽과 여과 슬릿**
1. ↻ 가시 그물 울타리 = 전하로 막는 벽 — #129 (1단계 '크기·전하'를 '전하'로 교정)
2. ↻ 가시 돋은 공(4개) = 같은 음전하의 큰 분자 — #129, 4개의 수는 모름
3. ↻ 공이 튕겨 사구체 쪽으로 되돌아감(화살표) = 같은 전하끼리 반발, 혈액에 남음 — #129
4. ↻ 말뚝 위에 다리를 벌린 남자의 가랑이 틈 = 여과 슬릿 — #130 (1단계 '발세포' 폐기: 사람이 아니라 틈이 뜻)

### 구역3 (x 680~1500, 위) — **근위세뇨관 재흡수: Na⁺–포도당 공동수송**
1. 포도 = 포도당 — #90 확정
2. 흰 소금이 보이는 자루 = Na⁺ — #111 확정(배수성 자루 아님)
3. 두 사람 모두 포도 1상자 + 소금 2자루를 함께 짐 = Na⁺ 2 : 포도당 1 공동수송 — 개수
4. 캄캄한 문으로 포도만 들고 들어가는 사람 = 세포→혈액 포도당만(Na⁺ 안 따라감) — 추정
5. 짐을 다 내린 빈 배 = 포도당 전부 재흡수 — 추정
6. 석축 담장 = 막(#116 '담장=막' 어법), 널다리 = 수송체 — 약속표 밖 추정

### 구역4 (x 1220~1500) — ↻ **통나무 배** (헨레고리 가설 폐기)
1. 통나무 배의 물결 꼬리를 거꾸로 이으면 두 말뚝 사이 틈으로 간다 = 슬릿을 막힘없이 지나 서지 않고 끝까지 가는 물질(이눌린 추정) — 약속표 없음, 추정

### 구역5 (x 1510~2000, 위) — **질소 노폐물 3종: 암모니아·요소·요산**
1. 어항 속 물고기 + 김 = 암모니아 — 문맥 추정
2. 노란 요(이불) 덮은 소쿠리 + 개구리 = 요소 — #9 요, 짝은 양서류
3. 알 속 병아리가 앉은 접힌 요 더미 = 요산 — #9 요, 짝은 조류
4. 동전 물고기 0 / 개구리 3(덧붙인 흔적) / 알 곁 더미 약 16 = ATP 비용 암모니아<요소<요산 — #8 확정
5. 큰 항아리(넘침) / 작은 단지 / 한 방울 찻잔 = 필요한 물 — #102 '물 그릇=질그릇', 크기 추정

### 구역6 (x 1480~2000, 아래) — ↻ **PAH 하마와 분비** (1단계 'ADH?' 폐기)
1. ↻ 하마 = PAH — #41 확정
2. ↻ 판자로 통을 실어 보내는 남자 + 통 약 10개 실은 배 = PAH가 혈액 쪽 부두에서 관강으로 분비되어 실려 나감 — 추정('통'은 약속표 밖)

## ③ 모름·어색·헷갈림·흔적
- 모름: 가는 구리 기둥, 진주알 정체, 가시 공 4개·물줄기 12·통 10의 수, 병 모양 말뚝, 통나무 정체.
- 헷갈림: 촘촘한 털(#4) vs 자루 솔(#38), 낫(#3) vs 칼, 하마(PAH) vs 해마, 통(#33 알도스테론) vs 물 그릇, 소금 자루(#111) vs 배수성 자루. 소쿠리=요소는 내 말장난.
- 흔적: 털 조각(선명한 덧칠), 개구리 앞 동전 3개(덧붙임), 알 옆 갈색 얼룩(지움), 푸른 관 아래 가로 이음선.

## ④ 한 문장
신장은 사구체에서 전하와 슬릿으로 거른 여과액을(JGA의 레닌·되먹임이 조절) 세뇨관에서 Na⁺와 포도당은 거두고 PAH는 더 실어 내보내며, 남는 질소 노폐물은 암모니아·요소·요산 순으로 물은 덜, ATP는 더 들여 버린다.
