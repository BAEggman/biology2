# 1단계 생판 — s17u01 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **배설계: 신장의 오줌 생성(사구체 여과·세뇨관 재흡수)과 질소 노폐물 3종** — 75%
- 2순위 **삼투조절·수분 평형(ADH·아쿠아포린)** — 12% (3순위 **막수송: 공동수송·촉진확산** 8%)
- 근거: 오른쪽 선반 세 칸(물고기·개구리·알) + 물동이 크기 3단 + 동전 개수 = 질소 노폐물 3종이라 배설 단원이 거의 확정. 왼쪽 = 신장 구조, 가운데 = 재흡수.

## ② 구역별 (왼쪽부터 6구역)

### 구역1 (x 0~590, 왼쪽 기슭) — **사구체(실뭉치)와 사구체옆장치(JGA)** [대안 **보먼주머니+근위세뇨관**]
1. 똘똘 감긴 푸른 호스 뭉치 = 사구체(glomerulus=작은 실뭉치, 모양·뜻 55%) / 대안 근위곡세뇨관('곡'=꼬임)
2. 호스 밑으로 쏟아지는 물줄기 약 12(굵은 9+가는 3, 정확치 않음) = 여과액이 빠져나옴(대안: 물 재흡수) — 동작·개수
3. 위로 길게 뻗은 굵고 부드러운 푸른 관 = 들세동맥(구심성, 굵음) — 모양·자리
4. 관의 목을 묶은 매듭 + 줄이 나무 상자 틈 솔까지 연결 = 치밀반 신호로 들세동맥이 조임(세뇨관-사구체 되먹임) — 자리·연결 35%
5. 관 벽에 박힌 구멍 숭숭한 진주알 = 사구체옆세포 과립(레닌) / 대안 보먼주머니 속 사구체(구멍=창) — 모양
6. 낫(자루가 진주에 꽂히고 날이 밧줄을 자름) = 레닌(자르는 효소) — 뜻·자리 35%
7. 잘린 땅바닥 밧줄(긴 쪽·못 2개에 묶인 짧은 쪽) = 안지오텐시노겐→안지오텐신Ⅰ 절단 — 30%, 못 2개는 모름
8. ㄴ자 나무 관 틈의 빽빽한 검은 털 = 치밀반(macula densa; 대안 솔가장자리) — 모양 45%
9. 세 구조물 사이 삼각 자리의 헝클어진 삼베 그물 = 메산지움(라시스=그물)/모세혈관망 — 30%
모름: 가는 구리 기둥(날세동맥? 단순 기둥), 땅 위 밧줄 고리.

### 구역2 (x 600~1000, 물웅덩이·울타리) — **여과막(여과 장벽): 크기·전하 선택**
1. 촘촘한 그물 울타리(위에 가시) = 틈새막·기저막, 작은 것만 통과 — 모양
2. 가시 돋친 밤송이 4개가 부딪혀 튕겨 호스 쪽으로 되돌아감(화살표) = 단백질·혈구 등 큰(음전하) 분자는 여과 안 되고 혈액에 남음 — 동작. 4개의 뜻은 모름
3. 두 기둥에 한 발씩 걸치고 선 남자 = 발세포(podocyte, 발) — 소리·뜻 55%
4. 두 기둥 사이 간격 = 여과 틈새 — 자리

### 구역3 (x 680~1500 위쪽, 시장·널다리·문) — **근위세뇨관 재흡수: Na+·포도당 공동수송과 촉진확산**
1. 포도 = 포도당 — 소리
2. 소금 자루 = Na+ — 뜻
3. 두 남자 모두 포도 1상자 + 소금 2자루를 함께 짐 = 공동수송(symport), Na+ 2 : 포도당 1 — 개수
4. 널다리 한 가닥 = 수송체 통로, 일방향(배→부두) — 모양
5. 짐을 다 내린 빈 배 = 관강에 포도당 안 남음(100% 재흡수) — 상태
6. 캄캄한 문 안으로 포도만 들고 들어가는 대머리 = 세포→혈액으로 포도당만(GLUT, Na+는 안 따라감) — 동작
7. 오른쪽 가판대 포도 3상자·소금 3자루 = 모름

### 구역4 (x 1220~1500, 가운데 수면) — **통나무 배(질주)** — 모름
- 통나무를 싣고 물살을 가르는 배: 헨레고리(log≈loop)이거나 재흡수 없이 지나가는 물질로 추정, 20% 미만이라 읽힌 것으로 안 침.

### 구역5 (x 1510~2000 위, 선반·물동이) — **질소 노폐물 3종: 암모니아·요소·요산**
1. 어항 속 물고기 + 김 = 암모니아(수생, 독성 강, 휘발) — 자리·모양
2. 소쿠리에 덮은 노란 이불(요) + 개구리 = 요소(요+소쿠리, 양서류·포유류) — 소리
3. 알 속 병아리가 앉은 접힌 흰 이불 더미(요+산) = 요산(조류·파충류, 고체 결정) — 소리
4. 물동이: 넘치는 큰 항아리 / 작은 단지 / 한 방울 찻잔 = 필요한 물 암모니아≫요소>요산 — 크기
5. 동전: 물고기 0 / 개구리 3 / 알 곁 더미 약 16 = 합성 에너지(ATP) 암모니아<요소<요산 — 개수

### 구역6 (x 1480~2000 아래, 판자·하마 배) — **수분 조절(ADH?)** 
1. 통을 판자로 나르는 남자 + 통 약 10개(앞5·뒤5) 위에 앉은 하마 = 물(수분) 조절 추정(하마≈hypo-/시상하부, 통=ADH·아쿠아포린). 25% — 1개만 침.

## ③ 모를 것·어색한 것·헷갈림·이어 붙인 흔적
- 모름: 낫·못 2개·구리 기둥·통나무 배·하마와 통·밤송이 4개의 숫자·판자 끝 옆 병 모양 말뚝.
- 어색: 하마가 통 위에 앉은 쪽배, 기둥 걸친 남자, 항구에 낫.
- 헷갈림: 푸른 관·호스(혈관?세뇨관?), 통과 항아리(둘 다 물그릇), 배 3척(빈 배·통나무 배·통 배), 하마와 해마.
- 흔적: 나무 상자의 솔 털(선명한 덧칠, 흰 점), 개구리 앞 동전 3개(화풍 다르게 선명), 알 옆 갈색 얼룩(지운 자국), 푸른 관·그물 아래 가로 이음선(y≈600).

## ④ 한 문장
신장은 사구체에서 큰 분자를 남기고 거른 뒤(왼쪽), 세뇨관에서 Na+와 함께 포도당을 도로 거두고(가운데), 질소 노폐물은 동물에 따라 암모니아·요소·요산으로 물과 에너지를 달리 들여 버린다(오른쪽).
