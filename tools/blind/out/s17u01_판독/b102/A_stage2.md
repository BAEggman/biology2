# 2단계 약속표로 다시 읽기 (s17u01) — ↻ = 1단계와 달라진 곳

## 판정
약속표로 훨씬 잘 풀린다. 「모름」이던 낫·밧줄+못 2개·하마가 풀렸고 틀린 읽기 셋(크기로 거름·솔가장자리·족세포)을 고쳤다. 약속표에 없는 물건은 추정으로만 남겼다.

## ① 판 전체 표제어
- **1순위: 배설계 — 신장(네프론)의 구조와 기능: 여과·재흡수·분비·청소율, 방사구체 장치(되먹임·레닌-안지오텐신), 질소 노폐물** — 85% ↻(75→85)
- **2순위: 삼투조절과 체액 항상성(RAAS 포함)** — 7% ↻(12→7)
- 근거: #128~#132 사구체 한 벌, #41 하마=PAH, #8 동전=ATP, #9 요, #90 포도, #111 소금 자루.

## ② 구역별 읽기 (왼쪽부터 6구역, #=약속표 번호)
**구역1 (x 0~620) 사구체 혈관극: 방사구체 장치와 레닌-안지오텐신** — 13개
1. 회색 호스 뭉치 = 사구체 (#132)
2. 밑으로 쏟아지는 물줄기 약 12줄 = 여과액 (#132)
3. 파란 자루관 = 들어오는 관, 수입세동맥 (#128, 75%)
4. ↻ 그 목을 졸라맨 가는 끈 = 들어오는 관을 조이는 되먹임 신호 (#128, 80%)
5. ↻ 끈의 다른 끝이 노란 관의 털 창으로 = 신호가 나오는 곳
6. ↻ 창 속 촘촘히 돋은 짧은 털 = 촘촘함이 뜻, 치밀반 (#4, 70%); 솔가장자리 폐기
7. 노란 L자 관 = 치밀반이 붙은 원위세뇨관 (자리, 55%)
8. ↻ 관들 사이 빈틈에 구겨 넣은 삼베 그물 = 사구체간질세포 (#131, 80%)
9. ↻ 낫 = 자르기만 하는 효소, 레닌 (#3, 80%); 1단계 「Na 소리?」
10. ↻ 땅에 늘어진 긴 밧줄 = -오겐, 안지오텐시노겐 (#128, 80%)
11. ↻ 못 2개 사이 팽팽한 밧줄 토막 = 안지오텐신 (#128, 80%); 못 2=Ⅱ는 가설 20%
12. 낫이 닿은 관벽의 구멍 송송 진주알 = 레닌 쌓은 JG세포 (약속표 없음, 45%)
13. 구리색 기둥 = 나가는 관, 수출세동맥 (약속표 없음, 50%)

**구역2 (x 620~1130, 아래) 사구체 여과막: 전하 장벽과 여과 슬릿** — 4개
1. ↻ 가시 그물 울타리 = 전하로 막는 장벽 (#129, 80%); 1단계 「크기」
2. ↻ 가시 공 4개가 튕겨 호스 쪽으로 되돌아감 = 같은 전하끼리 반발 (#129); 4는 뜻 모름
3. ↻ 두 말뚝 위에 다리 벌린 사람의 가랑이 = 여과 슬릿, 그 틈으로만 지남 (#130, 85%); 1단계 「족세포」
4. 물줄기는 울타리를 지나 건너편 물길로 = 물·작은 용질 통과 (60%)

**구역3 (x 680~1330, 위 시장·부두) 근위세뇨관 재흡수: Na⁺-포도당 공동수송** — 7개
1. 포도 = 포도당 (#90, 90%)
2. 흰 소금이 보이는 자루 = Na⁺ (#111, 85%); 자루 수는 배수성이 아님
3. 두 남자가 포도와 소금을 함께 들고 판자 하나로 담장을 넘음 = 공동수송 (75%)
4. 남자 A 소금 2 + 포도 1상자 = Na⁺ 2 : 포도당 1 (개수, 45%)
5. 문 속으로 소금 없이 포도만 = 포도당만 지나는 통로, GLUT2? (약속표 없음, 40%)
6. 판자 밑 빈 배 = 포도당 전부 재흡수, 청소율 0 (45%)
7. ↻ 돌벽 = 담장 = 막 (약속표 어휘, 60%)

**구역4 (x 1220~1540) 통나무 쾌속선** — 1개
1. 통나무 약 10개를 싣고 내리지도 더 싣지도 않고 질주 = 걸러진 그대로 나가는 물질(이눌린, 청소율=GFR) (약속표 없음) ↻ 30→50%: 하마=PAH로 배 3척 비교가 단단해짐

**구역5 (x 1540~2000, 위 선반) 질소 노폐물: 암모니아·요소·요산** — 6개
1. ↻ 동전 0 / 3 / 약 16 = ATP (#8, 85%); 3은 요소 회로의 ATP 3과 맞음
2. 노란 요(이불) + 개구리 = 요소 (#9, 75%)
3. 하얀 요(이불) 더미 + 알 속 병아리 = 요산 (#9, 75%)
4. 항아리 3개(넘침/반쯤/한 방울 찻잔) = 물 그릇(#102), 물 필요량 암모니아>요소>요산 (65%)
5. 수족관 물고기 = 암모니아 (약속표 없음, 65%)
6. 김 3줄 = NH₃ 기체 (약속표 없음, 45%)

**구역6 (x 1500~2048, 아래) 하마와 통 실은 배** — 3개
1. ↻ 하마 = PAH (#41, 90%); 1단계 「후보 40%」
2. 판자로 통을 계속 굴려 싣는 남자 = 혈액 쪽에서 관강(배)으로 더 실어 줌, 분비 (약속표 없음, 55%)
3. 짐이 불어 무거운 배 = PAH 청소율이 가장 큼 (약속표 없음, 45%)

## ③ 걸리는 것
- 여전히 모름: 통나무 배, 진주알, 문, 구리 기둥, 물고기·김·개구리·병아리, 통, 남자 A의 손동작; 배 3척=청소율 비교는 가설 55%.
- 약속표엔 있으나 안 보임: 금색 자물쇠, 알도스테론, ADH(V자), 바사 렉타, 말피기관. 배 1의 가로판 둘이 <꼴로 꺾였으나 원근 같아 V자에 끼우지 않음.
- 어색: 검은 털 창(오려 붙인 듯), 개구리·동전·병아리 창·물고기 선화(납작한 스티커), 달걀 왼쪽 갈색 얼룩, 파란 관 옆 벽의 회색 번짐. 이음선은 못 찾음(왼쪽 부두 갈색 포석 ↔ 시장 회색 포장만 다름).

## ④ 한 문장
콩팥은 사구체에서 전하와 슬릿으로 걸러 낸 여과액에서 포도당을 Na⁺와 함께 되찾고 PAH는 더 실어 내보내며, 치밀반의 되먹임과 레닌→안지오텐신으로 사구체 혈류를 다스리고, 질소 노폐물은 암모니아→요소(ATP 3)→요산(ATP 많이)으로 갈수록 물을 덜 쓰는 대신 ATP를 더 쓴다.
