# stage1 — 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위 **삼투조절과 배설 (질소 노폐물 3형 + 신장의 재흡수)** — 60%
- 2순위 **신장(네프론)의 여과·재흡수와 ADH 물 조절** — 20%
- 밀려난 후보: **세포막 물질수송(공동수송·삼투)** 8%, **체온조절·에너지 비용** 7%
- 근거: 오른쪽 선반의 칸 순서(어항·개구리·알)와 그 아래 그릇 순서(넘침·반쯤·한 방울)와 동전 수(0·3·약16)가 한 줄로 짝지어 있다 → 암모니아·요소·요산. 가운데는 소금+포도를 함께 나르는 사람들(Na⁺·포도당), 왼쪽은 관과 물줄기(배설관).

## ② 구역별 (왼쪽 → 오른쪽), 근거는 괄호
**구역1 (x 0~620) 배설관 구조** — 위에서 세 관(회색 천 관 · 노란 나무 덕트 · 구리관)이 내려옴
1. 회색 관 팽대부 속 구멍 숭숭한 진주 공 = 사구체를 감싼 보먼주머니 (모양·자리, 구멍=여과)
2. 같은 관이 U자로 꺾임 = 헨레고리 (모양)
3. 호스 뭉치(꼬인 관) = 곡세뇨관 (모양; 사구체일 수도 — 헷갈림)
4. 뭉치에서 쏟아지는 물줄기 약 12 = 여과·재흡수·오줌 생성 (뜻)
5. 구리 직관 + 황동 이음쇠로 뭉치에 합류 = 집합관 (모양·자리)
모름: 관 중간 밧줄 조임, 낫, 못 2개+바닥 밧줄 고리, 나무 L덕트의 어두운 창, 그물 더미. (대안 읽기: 무척추 배설기관 — 납작한 나무=편형동물 원신관, 천 관=지렁이 후신관, 마디 달린 구리관=곤충 말피기관. 25%)

**구역2 (x 600~1000, 물가) 삼투순응·협염성**
1. 성게 4마리 = 해수와 같이 가는 삼투순응자 (소리·뜻; 개수 4는 모름)
2. 창끝 울타리(약 20) + 튕겨 돌아가는 화살표 = 범위를 못 넘는 협염성 (뜻·동작)
3. 두 말뚝(2)에 다리 벌려 선 남자 = 광염성·삼투조절자 (모양)

**구역3 (x 660~1340, 위쪽 부두 시장) Na⁺–포도당 공동수송**
1. 포도 상자 = 포도당 (소리 '포도당')
2. 흰 소금 자루 = Na⁺ (뜻)
3. 회색 셔츠 남자: 포도 1 + 소금 2 = Na⁺2 : 포도당1, SGLT1형 (개수)
4. 베이지 셔츠 남자: 포도 1 + 소금 1 = 1:1, SGLT2형 (개수)
5. 둘이 같은 판자를 함께 오름 = 같은 방향 공동수송 (동작)
6. 문 안으로 포도만 들고 들어가는 대머리 남자 = 포도당 단독 촉진확산 GLUT (동작·자리)
모름: 가판대 재고(포도 상자 4+3, 소금 3자루), 빈 거룻배(널판 3).

**구역4 (x 1200~1500, 수로 중앙)** 표제어 모름 — 통나무 약 12를 실은 배가 혼자 빠르게 물결을 끌고 감. 읽힌 것 없음.

**구역5 (x 1500~2000, 위 오른쪽) 질소 노폐물 3형**
1. 어항 물고기 + 김 3줄 = 암모니아 (수생, 독성·휘발)
2. 그 아래 철철 넘치는 큰 항아리 = 암모니아는 물을 많이 써 희석 (자리)
3. 개구리 = 요소 (양서류)
4. 개구리 발밑 동전 3 = 요소 합성에 ATP 소모, 중간 (개수)
5. 가운데 반쯤 찬 작은 항아리 = 요소는 물 중간 (자리)
6. 알 + 병아리 + 흰 방석 더미 = 요산, 조류·파충류, 알 속 흰 침전 (모양)
7. 알 옆 동전 더미 약 16 = 요산이 에너지를 가장 많이 씀 (개수)
8. 알 아래 빈 찻잔 + 한 방울 = 요산은 물이 거의 안 듦 (자리·개수)
모름: 바구니·노란 담요.

**구역6 (x 1480~2048, 아래 오른쪽) 호르몬 물조절? (약 25~35%)**
1. 하마 = 시상하부 (소리 hippo≈hypo)
2. 하마 밑 통 약 10(+판자 위 1) = 저장된 ADH 소포
3. 판자로 통을 끌어올리는 남자 = 소포가 막으로 이동·삽입, 물 재흡수

## ③ 뜻 모를 것 · 어색한 것 · 이어 붙인 흔적
- 낫(자루가 진주 쪽), 못 2개+밧줄, 그물, 통나무 배: 뜻 모름.
- 나무 덕트 창의 어두운 패치: 가장자리가 털처럼 곤두선 세로줄에 흰 점, 화풍이 달라 붙여 넣은 느낌. 밧줄이 거기로 이어짐.
- 개구리 발밑 노란 육각 동전 3: 선명한 클립아트, 흰 테두리 → 이어 붙임. 알 속 균열 창·병아리·방석도 합성 느낌.
- 헷갈림: 호스 뭉치가 사구체인지 곡세뇨관인지, 세 관이 무엇의 짝인지, 하마의 정체, 통이 올라가는지 내려가는지. 하마 배는 오른쪽 틀에서 잘림.

- 센 것(의미 불명 포함): 성게 4, 말뚝 2, 창끝 약 20, 코일 물줄기 약 12, 사람 5(회색·베이지·대머리·말뚝·판자), 포도 상자(가판대 4+3, 운반 2), 소금 자루(가판대 3, 운반 3), 김 3줄, 동전 3 / 약 16, 통 약 10+1, 통나무 약 12, 거룻배 널판 3, 못 2.

## ④ 한 문장
물고기·개구리·새는 암모니아→요소→요산으로 갈수록 물은 덜 쓰고 에너지는 더 쓰며, 신장에서는 Na⁺와 포도당이 짝지어 되돌아오고 호르몬이 물 재흡수를 조절하며, 성게 같은 해양동물은 바닷물에 맞춰 사는 삼투순응자다.
