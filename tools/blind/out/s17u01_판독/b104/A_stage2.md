# stage2 - 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳, [번호] = 약속표 줄)

## 정직한 판정
약속표로 훨씬 잘 풀린다. 1단계 「모름」 구역(자루-관·낫 / 통나무 배·말뚝 남자 / 하마·통)이 모두 풀려 읽힌 사실이 19→31개. 약속표 없이는 못 푼 것: 낫=레닌, 말뚝 위 남자=슬릿, 가시 공=전하 반발, 하마=PAH, 자루 수=Na+ 수. 1단계가 틀리게 읽은 것: 그물, 성게, 구리관, 솔.

## ① 판 전체 표제어
- **1순위: 배설계 - 콩팥의 오줌 생성·조절(여과·재흡수·분비·청소율, JG 장치·레닌-안지오텐신)과 질소 노폐물** (88%) ↻ 60→88
- **2순위: 삼투조절·체액 항상성** (6%)

## ② 구역별 (왼쪽부터)
**구역1 JG 장치·레닌-안지오텐신 (맨 왼쪽)** - 7개 ↻ 모름→풀림
- ↻ 파란 자루 = 둥근 관 = 핏줄, 들어오는 관(수입세동맥) [133]. 가는 새끼줄로 졸라맴 = 들어오는 관을 조이는 되먹임 신호(세뇨관사구 되먹임) [128].
- ↻ 네모 나무 관(오줌길)의 막힌 끝이 자루에 닿되 안 이어짐 [133]. 그 안쪽 촘촘한 털 = 치밀반(촘촘함이 뜻) [4] (1단계 '솔가장자리'에서 바뀜, 65%). 줄 끝이 털에 닿음.
- ↻ 굽은 낫 = 자르기만 하는 효소 = 레닌 [3·128]. 땅에 처진 긴 밧줄 = 안지오텐시노젠, 두 쇠말뚝 사이 팽팽한 토막 = 안지오텐신(끊긴 자리 하나 = I) [128].
- 진주(자루 불룩한 창, 점 박힘)는 약속표에 없음. 낫 자루가 닿는 자리라 JG 세포의 렌닌 알갱이로 추정(낮음, 세지 않음).

**구역2 사구체 여과와 여과 장벽 (구리관·호스·그물·울타리·말뚝)** - 6개
- 엉킨 호스 뭉치 = 사구체, 밑으로 쏟아지는 약 10줄 물 = 여과액 [132] (1단계와 같음).
- ↻ 삼베 그물 = 사구체간질세포(메운다) [131] (1단계 '기저막'은 오독).
- ↻ 가시 공(성게 4)이 가시 울타리에 튕김 = 같은 전하끼리 반발, 크기가 아니라 전하로 막음(알부민) [129] (1단계 '크기'는 오독).
- ↻ 말뚝 위에 다리 벌린 남자의 가랑이 = 여과 슬릿 [130].
- ↻ 구리관 = 둥근 관 = 핏줄, 사구체에서 나가는 관(날세동맥)으로 읽음 [133] (1단계 '수입'과 뒤바뀜, 중하). 황동 이음쇠는 약속표에 없음(V자 아님).

**구역3 근위세뇨관 재흡수(포도당·Na+ 공동수송) (시장·널빤지·문)** - 6개
- 포도 = 포도당 [90]. 소금 자루 = Na+, 멘 자루 수 = 함께 들어가는 Na+ 수 [111].
- ↻ 널빤지 위 남자 A: 자루 2 + 포도 1을 꽉 끌어안음 = 2 Na+:1 포도당 고친화(SGLT1) / 남자 B: 자루 1 + 포도 1을 옆구리에 낌 = 1:1 저친화(SGLT2) [111]. A 뒤 자루 2개가 멘 것인지 바닥인지는 모호.
- ↻ 어두운 문 = 뒷문(기저외측막), 포도 상자만 든 남자 = Na+ 없이 포도당이 혈액 쪽으로(GLUT) [134].
- ↻ 널빤지 밑 빈 배 = 전부 되찾음(오줌에 포도당 없음) [135].

**구역4 청소율·분비 (통나무 배·하마 배)** - 4개 ↻ 모름→풀림
- 강 위 같은 배 셋 = 청소율 세 유형 [135]: 통나무 배(짐 그대로 떠내려감) = 여과만, 빈 배(구역3) = 전부 되찾음, 짐을 더 싣는 하마 배 = 더 버림(분비).
- ↻ 하마 = PAH [41]. 통을 굴려 싣는 남자 = 「더 실림」(분비). 배에 남아 흘러가는 짐 = 오줌으로 나가는 양 [135].

**구역5 질소 노폐물 3종(암모니아·요소·요산) (선반 3칸)** - 8개
- 뚜껑 없는 어항의 김+물고기 = 암모니아, ↻ 휘발성이 아니라 너무 독해 가두지 못하고 곧장 흘림 [136]. 넘치는 큰 항아리 = 물 아주 많이.
- 개구리+노란 요 = 요소 [9]. 단지 = 물 중간. ↻ 동전 3 = ATP 3 [8].
- 알 속 병아리+흰 요 더미 = 요산 [9]. ↻ 동전 약 16 = ATP 많이 [8]. 찻잔 = 물 거의 안 씀.
- 칸 셋이 나란하고 하나씩만 다름 [126]: 암모니아→요소→요산, 독성↓·물↓·ATP↑.

## ③ 약속표에 없음·남은 의문·이어 붙인 흔적
- 약속표에 없어 억지로 안 끼움: 진주, 황동 이음쇠, 널빤지, 가판대 상자 4+3·자루, 통나무·통 개수, 성게 4의 개수.
- 흔적(1단계 그대로): 솔 상자 패치, 그물 밑 수평 이음선, 금화 3·알 속 병아리 오려 붙인 느낌, 위로 잘린 세 관.
- 헷갈림: 구리관(나가는)·자루(들어오는) 방향, 털 = 치밀반 vs 솔가장자리.

## ④ 한 문장
핏줄 뭉치(사구체)에서 전하·슬릿 장벽을 지난 여과액이 강(세뇨관)으로 나가 쓸 것(포도당·Na+)은 되찾고 더 버릴 것은 싣고 가며, JG 장치가 레닌-안지오텐신과 되먹임으로 이를 조절하고, 질소 노폐물은 종류마다 물·ATP 값이 다르다.
