# stage2 — 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳, 괄호 숫자 = 약속표 줄)

## ① 판 전체 표제어
- 1순위 **콩팥(신장)의 기능 — 사구체 여과·재흡수·분비·청소율, 질소 노폐물까지** 75% ↻ (1단계 1순위 '삼투조절과 배설')
- 2순위 **질소 노폐물과 배설계 개관** 15% (그 밖 삼투조절 5%, 레닌–안지오텐신계 5%)
- 판정: 약속으로 훨씬 잘 풀린다. 1단계 읽힌 25개 중 약 15개만 살고(시장·선반), 왼쪽 덩어리·울타리·하마 쪽 약 10개는 틀렸다. 대신 새로 풀린 것이 약 10개. 삼투순응·협염성·시상하부/ADH·헨레고리 읽기는 버린다.

## ② 구역별
**구역1 (x 0~620) 사구체·방사구체장치·렌닌** ↻ 5개→10개
1. 회색 둥근 관 = 핏줄, 들어오는 관(133) ↻ U자 휨은 헨레고리가 아니라 사구체로 드는 길
2. 그 관을 졸라맨 가는 끈 = 들어오는 관을 조이는 되먹임 신호(128) ↻
3. 나무 L자 네모 관 = 오줌길, 막힌 끝이 둥근 관에 닿되 안 이어짐(133) ↻
4. 그 창 속 촘촘한 짧은 털의 어두운 판 = 치밀반(4 '촘촘함이 뜻') ↻ 끈이 이 창으로 이어짐
5. 구겨 넣은 삼베 그물 = 사구체간질세포(131) ↻
6. 엉킨 호스 뭉치 + 물줄기 약 12 = 사구체와 여과액(132) ↻ '곡세뇨관' 정정
7. 구리 둥근 관 = 핏줄, 사구체에서 나가는 쪽(133, 65%) ↻ '집합관' 정정
8. 낫 = 자르기만 하는 효소, 렌닌(3) ↻
9. 땅에 늘어진 긴 삼밧줄 = 안지오텐시노겐(128) ↻
10. 쇠말뚝 둘 사이 팽팽한 토막 = 안지오텐신 I, 끊긴 자리 하나(말뚝은 번호 아님)(128) ↻
약속표에 없어 안 끼움: 점 박힌 진주 팽대부(수입관 벽·낫 옆 → 렌닌 과립 추정 40%), 황동 이음쇠(열쇠구멍 없어 자물쇠 아님).

**구역2 (x 600~1000, 물가) 사구체 여과 장벽** ↻ 삼투순응 폐기
1. 가시 공 4개가 가시 울타리에 튕겨 되돌아감 = 같은 전하끼리 반발, 크기가 아니라 전하로 막음(129) ↻ 성게 아님
2. 두 말뚝 위 다리 벌린 남자의 가랑이 = 여과 슬릿(130) ↻
(공 4·말뚝 2·창끝 약 20의 개수 뜻은 모름)

**구역3 (x 660~1340, 위 부두) Na⁺–포도당 공동수송과 뒷문** — 6개 유지
1. 포도 = 포도당(90) 2. 소금 자루 수 = 함께 드는 Na⁺ 수(111)
3. 회색 셔츠: 소금 2 + 포도를 꽉 끌어안음 = 2:1 고친화 SGLT1 ↻ 고친화 뜻 추가
4. 베이지 셔츠: 소금 1 + 포도를 한 팔에 느슨히 = 1:1 SGLT2
5. 둘이 한 판자를 같은 방향으로 = 공동수송
6. 문으로 포도만 들고 드는 대머리 = 뒷문 = 기저외측막으로 나감(134), Na⁺ 없이 GLUT2 ↻
가판대 재고(포도 4+3, 소금 3)는 모름.

**구역4 (x 680~1500, 수로 중앙) 청소율 세 유형 중 둘(135)** ↻ 모름→2개
1. 짐을 다 내려 텅 빈 거룻배 = 전부 되찾음(포도당)
2. 통나무를 실은 채 혼자 떠내려가는 배 = 짐 그대로 = 여과만(이눌린형, 청소율=GFR)

**구역5 (x 1500~2000, 위 오른쪽) 질소 노폐물 3형** — 8개→10개
1. 어항 물고기 + 뚜껑 없는 김 = 암모니아, 독해서 곧장 흘림(136) ↻ 2. 넘치는 큰 항아리 = 물 많이
3. 개구리 = 양서류 4. 노란 요 = 요소(9) ↻ 5. 동전 3 = ATP 3(8) ↻ 6. 반쯤 찬 항아리 = 물 중간
7. 알·병아리 = 새 8. 알 속 흰 요 더미 = 요산(9) ↻ 9. 동전 더미 약 16 = ATP 많이 10. 빈 찻잔+한 방울 = 물 거의 안 듦

**구역6 (x 1480~2048, 아래 오른쪽) PAH 분비** ↻ 호르몬 읽기 폐기
1. 하마 = PAH(41) ↻ 시상하부 아님 2. 통 약 10을 가장 많이 실은 배 = 더 실림 = 분비(135) ↻
3. 판자 위에서 통을 배 쪽으로 내리는 남자 = 분비로 짐 얹기(방향은 자세로 추정 60%) ↻

## ③ 모름 · 어색 · 헷갈림 · 이어 붙임
- 약속표에 없는 것: 진주 팽대부, 황동 이음쇠, 판자·석벽·거룻배 말뚝, 개구리·바구니·알·병아리의 정체, 판자 위 통의 방향. 가판대 재고도 모름.
- 알(알=α 후크)·삼베(베=β 후크)는 이 판에서 쓸 자리가 안 보여 안 셈.
- 이어 붙임: 덕트 창의 털 선 어두운 패치(약속의 '촘촘한 털'을 넣은 소품), 개구리 발밑 클립아트 동전 3(ATP 수를 못 박은 패치), 알 속 창·요 더미. 하마 배는 틀에서 잘려 통 수 불확실.

## ④ 한 문장
콩팥은 사구체에서 전하와 슬릿으로 거른 여과액에서 포도당을 Na⁺와 함께(SGLT 2:1·1:1) 되찾아 뒷문으로 내보내고, 여과만 되는 짐·다 되찾는 짐·분비로 더 실리는 짐(PAH)이 오줌 양을 가르며, 렌닌이 안지오텐시노겐을 끊어 안지오텐신 I 을 만들고 치밀반이 들어오는 관을 조이는데, 질소는 물고기(암모니아)–개구리(요소, ATP 3)–새(요산, 물 거의 안 씀) 순으로 버린다.
