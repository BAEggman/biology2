# 2단계 약속표 재판독 — s17u01 (↻ = 1단계와 달라진 곳)

판정: 약속표로 훨씬 잘 풀린다. 1단계 「모름」(낫·밧줄·못·가시 공·울타리·기둥 위 사람·통나무 배·하마)이 거의 다 약속 하나씩으로 풀렸고, 1단계의 솔가장자리·헨레고리·H⁺ 가시 공·ADH 하마 같은 짐작은 뒤집혔다. 구역 수(6)는 같다.

## ① 판 전체 표제어
- **1순위: 콩팥(신장)의 구조와 기능 — JG 장치(레닌)·사구체 여과·재흡수·분비(청소율)·질소 노폐물** (88%) ↻ 근거가 '네프론 일렬 배열'에서 '약속표 항목 다수 일치'로 바뀜
- **2순위: 사구체 여과와 청소율(GFR·RPF) 중심 판** (6%) ↻ 1단계 2순위 '막 수송'은 버림
- 근거: 실뭉치+물줄기(사구체·여과액), 가시 그물+가시 공, 말뚝 위 가랑이(슬릿), 같은 배 셋(청소율), 알갱이 주머니+낫(레닌), 요·동전·김·항아리가 모두 약속표 항목.

## ② 구역별 판독 (왼→오른)
**구역1 · JG 장치와 레닌(x0~590)**
- 파란 둥근 관 = 핏줄, 수입세동맥 (#133) ↻
- 관 벽이 부풀어 만든 주머니에 가득 비친 작은 크림빛 알갱이 = 과립세포 (#137) ↻ (1단계: 사구체 구슬 덩이)
- 그 아가리에서 나온 자루 달린 굽은 낫 = 레닌, 자르기만 하는 효소 (#3·#137) ↻ 모름→풀림
- 땅에 늘어진 긴 삼밧줄 = 안지오텐시노겐(-오겐) (#128) ↻
- 낫이 한 번 끊어 두 쇠말뚝 사이에 팽팽한 토막 = 안지오텐신 I (끊긴 자리 하나=I, 말뚝 둘은 번호 아님) (#128) ↻ 모름→풀림
- 관을 졸라맨 가는 끈 = 들어오는 관을 조이는 되먹임 신호 (#128) ↻ (1단계: 세동맥 수축)
- 네모 나무 관 = 오줌길(세뇨관), 막힌 끝이 파란 관에 닿되 안 이어짐 (#133) ↻
- 그 안쪽 벽의 촘촘한 짧은 털 = 치밀반 (자갈·Ca²⁺ 아님, 촘촘함이 뜻) (#4) ↻ 솔가장자리 버림
- 구겨 넣은 삼베 그물 = 사구체간질세포(메산지움) (#131) ↻
- 구리 둥근 관 = 핏줄, 수출세동맥 (#133) ↻ 집합관 버림. 놋쇠 이음쇠·U자 굽이는 약속표에 없어 뜻 안 읽음.

**구역2 · 사구체와 여과 장벽(x360~1130, 아래)**
- 엉킨 호스 뭉치 = 사구체, 그 밑 물줄기 약 12줄 = 여과액 (#132) ↻ 곡세뇨관 버림
- 가시 울타리(가시 그물) = 같은 전하끼리 반발로 막음 (#129) ↻
- 가시 공 4개 = 음전하 단백질(알부민), 울타리에 튕겨 되돌아감 (#138) ↻ H⁺ 버림
- 두 말뚝 위에 다리를 벌린 사람의 가랑이 = 여과 슬릿, 그 틈으로만 지남 (#130) ↻ 모름→풀림

**구역3 · 포도당 재흡수(x660~1500, 위)**
- 포도 = 포도당 (#90), 흰 소금 자루 = Na⁺ (#111), 같이 나름 = 공동수송
- 앞사람: 소금 2자루+포도 1상자, 상자를 두 팔로 꽉 끌어안음 = SGLT1(2:1, 고친화) (#111) ↻ 고친화 추가
- 뒷사람: 소금 1자루+포도 1상자, 한 팔로 헐겁게 = SGLT2(1:1, 저친화) (#111) ↻
- 짐 내린 빈 배 = 텅 빔, 전부 되찾음(포도당 청소율 0) (#135) ↻
- 어두운 뒷문으로 포도만 들고 나감 = 기저외측막, Na⁺ 없이 (#134) ↻
- 널판 오르막 = 기울기 거스름은 약속표 밖 해석이라 세지 않음.

**구역4 · 통나무 배(x1220~1530)**
- 통나무 짐이 그대로 떠내려가는 배 = 여과만, 이눌린(GFR 잣대) (#135) ↻ 모름→풀림, pH 버림
- 배에 남아 흘러가는 짐 = 오줌으로 나가는 양 (#135)

**구역5 · 선반+항아리(x1510~1960, 위)**
- 물고기 = 암모니아, 뚜껑 없이 오르는 김 = 너무 독해 가두지 못하고 곧장 흘림 (#136) ↻
- 개구리 + 노란 요(이불) = 요소 (#9), 동전 3 = ATP 3 (#8) ↻
- 알+병아리+접힌 흰 요 = 요산 (#9), 동전 더미 약 16~17 = ATP 많이 (#8) ↻ 금화→ATP
- 물고기 칸 동전 0 = ATP 불필요
- 항아리 물높이(넘침·가득·컵 한 방울) = 나오는 양 (#153) ↻

**구역6 · 하마 배(x1470~2000, 아래)**
- 하마 = PAH (#41) ↻ 시상하부·ADH 버림
- 더 실린 배 = 더 버림(분비) (#135) ↻
- 널판으로 통을 굴려 보태는 사람 = 분비로 짐이 더해짐 ↻

## ③ 아직 모름 · 어색 · 헷갈림
- 약속표에 없어 안 읽음: 놋쇠 이음쇠, U자 굽이, 계선주·보트 속 쇠사슬 기둥, 빈 배의 가로장 3, 노점 상자·자루 수(4+3, 3), 김 3가닥, 수족관 구석 얼룩, 바구니, 찻잔(질그릇 아님), 대머리, 초록 물빛.
- 헷갈림: 가는 끈(되먹임)과 굵은 밧줄(안지오텐신) 구별, 알이 α 후크일 가능성(병아리가 있어 조류로 읽음).
- 흔적: 좌상단 벽의 번진 얼룩, 치밀반 위 흰 잡티, 계선주가 뒷사람 발목에 겹침.

## ④ 한 문장
콩팥은 사구체에서 크기와 전하로 피를 걸러 여과액을 만들고(JG 장치가 레닌으로 압력과 혈압을 살핀다), 포도당·Na⁺는 운반체로 되찾고 일부는 더 내보내며(청소율로 가늠), 질소 노폐물은 물과 ATP를 얼마나 쓸 수 있느냐에 따라 암모니아·요소·요산으로 내보낸다.
