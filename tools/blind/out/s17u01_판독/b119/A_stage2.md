# stage2 약속표로 다시 읽기 (s17u01) — ↻ = 1단계와 달라진 곳

## 판정
약속표로 훨씬 잘 풀린다. 1단계 「모름」 6개(허리 밧줄·말뚝 둘·말뚝 남자·하마·통나무 배·낫)가 풀렸고, 틀리거나 비튼 읽기 3개(그물·솔털·성게 이유)를 고쳤다. 약속표에 있어도 이 판에 안 보이는 것(금색 자물쇠 #2·V자 #7·동전 펌프 #148·아쿠아포린 구멍 #146)은 끼우지 않았다.

## ① 판 전체 표제어
- **1순위: 배설계 — 신장의 구조와 소변 생성(사구체 여과·세뇨관 재흡수·분비·청소율), JG장치의 레닌-안지오텐신, 질소 노폐물** (확신 85%) ↻60→85
- **2순위: 소변 생성 1단계 — 사구체 여과와 근위세뇨관 재흡수·분비** (8%) ↻삼투조절에서 교체
- 근거: 사구체(#132)·레닌 낫(#137)·하마 PAH(#41)·배 셋(#135)·요 이불(#9)이 모두 신장·배설 약속.

## ② 구역별 (왼→오른)
**구역1 맨 왼쪽 — 사구체와 JG장치(레닌-안지오텐신·되먹임)** (읽힌 12) ↻
- 엉킨 호스 뭉치 = 사구체, 밑 물줄기 10여 가닥 = 여과액(#132)
- 굵은 파란 둥근 관 = 들어오는 핏줄(수입세동맥), 허리를 졸라맨 가는 밧줄 = 그 관을 조이는 되먹임 신호(#128·#133) ↻모름→풀림
- 'ㄴ' 네모 나무 관 = 세뇨관, 끝이 둥근 관에 닿기만 함 = 닿되 안 이어짐(#133) ↻
- 그 속 촘촘한 검은 털 = 「촘촘함이 뜻」(#4) → 치밀반(솔가장자리 가능성 남김), 밧줄 끝이 털에 닿음 = 신호의 출발 ↻1단계 솔가장자리 정정
- 관 벽 불룩 주머니의 크림 알갱이 = 과립세포, 그 아가리의 낫 = 레닌, 새는 구슬 = 과립 방출(#137·#3) ↻추정→확정
- 땅에 처진 긴 밧줄 = 안지오텐시노겐, 낫이 끊어 말뚝 둘 사이에 팽팽한 토막 = 안지오텐신 Ⅰ(말뚝 둘은 번호 아님, 끊긴 자리 하나=Ⅰ)(#128) ↻모름→풀림
- 삼베 그물 = 사구체간질세포(메산지움, 「메운다」, #131) ↻모세혈관망 정정
- 구리 둥근 관 = 핏줄(수출 쪽 추정)

**구역2 물 속 — 사구체 여과 장벽(전하·슬릿)** (읽힌 4) ↻
- 가시 공 4 = 음전하 단백질(알부민, #138), 가시 울타리에 튕김 = 같은 전하끼리 반발, 크기가 아니라 전하로 막음(#129) ↻1단계 「큰 입자」 정정
- 말뚝 위 남자의 가랑이 = 여과 슬릿(#130) ↻모름→풀림
- 호스 물은 창살·가랑이 틈으로만 통과

**구역3 시장·널다리 — 근위세뇨관 재흡수(공동수송)** (읽힌 7)
- 포도 = 포도당(#90), 흰 소금 자루 = Na⁺, 자루 수 = 함께 들어가는 Na⁺ 수(#111) ↻
- 앞 남자 자루2+상자1 = 2:1, 뒤 남자 자루1+상자1 = 1:1(SGLT1·2 이름은 내 추정)
- 짐을 묶어 함께 나름 = 공동수송, 동전 없음 = ATP 직접 안 씀(#147) ↻
- 부두 건물 = 한 방(세포), 수로 쪽 벽·널다리 = 관강막(#134, 추정) ↻
- 짐 다 내린 빈 배 = 전부 되찾음(#135) ↻
- 가판 상자 4+3·자루 3 = 모름 유지

**구역4 어두운 문 — 기저외측막** (읽힌 2)
- 뒷문 = 기저외측막(세포→혈액, #134) ↻
- 포도만 혼자 들고 나감 = 포도당 단독 이동(GLUT 촉진확산, 추정)

**구역5 선반 3칸·그릇 3개 — 질소 노폐물 3종** (읽힌 6)
- 수조 물고기 + 뚜껑·그릇 없이 오르는 김 = 암모니아, 너무 독해 가두지 못하고 곧장 흘림(#136) ↻
- 개구리 + 이불 바구니 = 요소, 알 속 병아리 + 접힌 이불 더미 = 요산(요 #9) ↻확정
- 금화 0·3·약 17 = ATP 비용(#8) ↻확정
- 항아리 물높이 넘침 > 반 > 찻잔 = 관 끝에서 나오는 양(#153) ↻
- 열린 수조 → 뚜껑 열린 바구니 → 닫힌 알 = 가둘 수 있는 정도(추정)

**구역6 통나무 배·통 굴리기·하마 배 — 청소율 3유형** (읽힌 5)
- 통나무 배 = 여과만(이눌린, GFR 잣대)(#135) ↻확정
- 통·하마 배 = 더 실림 = 분비, 하마 = PAH(#41) ↻확정
- 널빤지로 통을 굴려 내림 = 분비(혈액→관)
- 배에 남아 흘러가는 짐 = 오줌으로 나가는 양(배설)

## ③ 모름·어색·헷갈림·이은 흔적
- 모름 유지: 황동 고리(자물쇠 아님), 구리관의 정확한 역할, 가판 상자·자루 개수, 배 안 꺾인 가로널 셋(V 아님).
- 약속표 밖 추정: SGLT1·2 이름, 오르막=능동수송, GLUT, 찻잔.
- 이은 흔적: U자 안쪽 y≈600 수평 절단, 솔털 위 하얀 점, 뒤 남자 오른발 밑 회색 기둥.

## ④ 한 문장
사구체가 전하와 슬릿으로 알부민은 막고 거른 여과액에서 근위세뇨관이 Na⁺와 함께 포도당을 되찾거나 더 분비해 청소율이 갈리고(이눌린·포도당·PAH), 레닌-안지오텐신·되먹임이 그 압을 지키며, 질소 노폐물은 독성·물·ATP 비용에 따라 암모니아·요소·요산으로 나간다.
