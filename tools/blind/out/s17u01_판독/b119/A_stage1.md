# stage1 생판 읽기 (그림 s17u01, 그림만 보고)

## ① 판 전체 표제어
- **1순위: 배설계 — 신장(네프론)의 소변 생성(여과·재흡수·분비)과 질소 노폐물 배설** (확신 60%)
- **2순위: 삼투조절·체액 항상성(레닌-안지오텐신·ADH, 수분·염 균형)** (확신 15%)
- 밀린 후보: 막수송 단독(SGLT·GLUT) 10%, 소화·흡수 5%.
- 근거: 사구체 같은 호스 뭉치와 새는 물줄기, 솔·그물, 포도+소금을 나르는 부두, 선반의 물고기·개구리·알과 물그릇 3개. 남자 5명이 각기 다른 운반(여과·공동수송 둘·문·분비)을 맡은 듯.

## ② 구역별 (왼쪽 → 오른쪽)
**구역1 맨 왼쪽 배관 — 사구체·수입/수출세동맥·레닌** (읽힌 8)
- 꼬인 호스 뭉치 = 사구체(실뭉치, 모양). 밑으로 새는 물줄기 10여 가닥 = 여과(뜻·개수).
- 굵은 파란 관(위→U자→뭉치) = 수입세동맥, 가는 구리관+황동 고리(뭉치에서 위로 나감) = 수출세동맥. 넓게 들어와 좁게 나감 = 사구체압 유지(굵기·자리, 추정).
- 'ㄴ'자 나무 통 속 검은 솔털 = 근위세뇨관 솔가장자리(모양).
- 삼베 그물 = 세뇨관주위모세혈관(구리관 옆, 모양·자리).
- 파란 관 불룩 주머니(창으로 속이 보임)의 크림 구슬 + 나무 주둥이에서 새는 구슬 약 15 + 낫 = JG세포의 레닌 과립 분비('낫'=Lenin=renin, 소리, 추정).
- 땅의 굵은 밧줄 끝을 낫이 자름, 잘린 토막 = 안지오텐시노겐→안지오텐신Ⅰ(뜻, 추정).
- 모름: 파란 관 허리를 묶은 밧줄(줄 끝이 솔 상자 털에 닿음), 말뚝 2개+가는 줄.

**구역2 물 속 울타리 — 사구체 여과막** (읽힌 3)
- 뾰족한 쇠 울타리 = 여과 장벽(모양·자리).
- 성게 4마리가 울타리에 튕겨 되돌아감(화살표) = 큰 입자(단백질·혈구)는 여과 안 됨(뜻·개수).
- 호스 물은 창살 사이로 지나감 = 물·작은 용질은 통과(자리).
- 모름: 두 말뚝에 다리 벌리고 선 남자(발세포? 수입·수출 사이?).

**구역3 시장·널다리 — 근위세뇨관 재흡수, Na⁺-포도당 공동수송** (읽힌 6)
- 보라 포도 = 포도당(소리 포도→포도당), 흰 소금 자루 = Na⁺(뜻).
- 둘을 함께 들고 널다리를 올라 부두로 = 공동수송, 오르막 = 농도 거슬러(2차 능동수송, 자리).
- 앞 남자 자루2+상자1 = Na⁺2:포도당1(SGLT1), 뒤 남자 자루1+상자1 = 1:1(SGLT2)(개수, 추정).
- 짐을 다 내려 빈, 말뚝에 묶인 배 = 포도당 전부 재흡수(추정).
- 모름: 가판 포도 상자(4+3)·소금 자루 3의 개수 뜻.

**구역4 어두운 문 — 포도당 촉진확산(GLUT)** (읽힌 2)
- 문 = 통로, 소금 없이 포도 상자만 든 남자가 혼자 들어감 = 포도당 단독 촉진확산(뜻·자리).
- 안이 캄캄함 = 세포 안/혈액 쪽(추정).

**구역5 선반 3칸·그릇 3개 — 질소 노폐물 3종** (읽힌 6)
- 김 나는 수조 속 물고기 = 암모니아(수생, 독성 크고 휘발·물 많이 필요).
- 개구리 + 노란 이불 바구니(이불 '요'+소쿠리 '소') + 금화 3 = 요소.
- 알 속 병아리가 앉은 접힌 흰 이불 더미('요'+'산') + 금화 약 17 = 요산(알 = 조류·파충류).
- 항아리 큰(넘침) > 작은 > 찻잔 = 필요한 물 양 암모니아 > 요소 > 요산.
- 금화 0 < 3 < 17 = 합성 에너지 비용 증가.
- 왼→오른 = 수생→양서류→육상 알, 서식지와 대응(자리).

**구역6 아래 오른쪽 — 분비와 청소율** (읽힌 3, 모두 추정)
- 통나무 배(싣지도 내리지도 않고 항적 남기며 지나감) = 여과만 되고 재흡수·분비 없는 물질(이눌린→GFR).
- 널빤지로 통을 굴려 내리는 남자 = 분비(혈액→세뇨관 내강).
- 통 9~10개와 하마가 오른 무거운 배 = 분비로 가장 많이 실림. 하마 = hippuric/PAH(마뇨산) 또는 ADH(hippo~hypothalamus), 약함.

## ③ 모름·어색·헷갈림·이은 흔적
- 파란 관 허리 밧줄 묶음(끝이 솔 털에 닿음), 말뚝 2개+가는 줄, 두 말뚝 위 남자: 뜻 모름.
- 하마가 PAH인지 ADH인지, 호스 뭉치가 사구체인지 곡세뇨관인지 헷갈림. 배 3척(빈 배·통나무 배·통+하마 배)의 청소율 가설은 약함.
- 개수(가판 상자 4+3, 자루 3, 통 9~10, 통나무 약 12, 구슬 약 15)가 뜻인지 장식인지 가리지 못함.
- 뒤 남자 오른발 아래 작은 회색 기둥, 솔털 위 하얀 반짝이 점: 합성 잡티 같음.
- U자 안쪽 y≈600에서 그물이 수평 직선으로 잘려 포석으로 바뀜(이은 흔적). 파란 관·구리관·나무 통 셋 다 위로 잘려 화면 밖으로 이어짐.
- 수조 바닥 오른쪽 작은 회색 형상(수초? 모름).

## ④ 한 문장
사구체가 큰 것은 막고 물·작은 용질만 여과하면 세뇨관이 포도당·Na⁺는 되찾고 일부는 분비하며, 질소 노폐물은 서식지의 물 사정에 따라 암모니아·요소·요산으로 내보낸다.
