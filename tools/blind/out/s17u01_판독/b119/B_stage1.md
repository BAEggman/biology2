# 1단계 생판 판독 — s17u01 (사전정보 없음)

## ① 판 전체 표제어
- **1순위: 배설 — 신장(네프론)의 오줌 생성(여과·재흡수·분비)과 질소 노폐물** (확신 70%)
- **2순위: 막 수송 — 공동수송·역수송·삼투와 수분 조절** (확신 12%)
- 근거: 선반 세 칸(물고기·개구리·알)의 금화 0·3·약 15개와 항아리 3개(넘침·가득·한 방울 컵)가 '암모니아<요소<요산(에너지), 물 필요량은 반대'라는 비교표를 닮았고, 왼쪽 장치는 솔·U자관·곡관의 네프론 배열, 가운데는 포도와 소금을 함께 나르는 공동수송이다.

## ② 구역별 판독 (왼→오른)
**구역1 · 좌측 배관 장치(x0~660) — 네프론 구조(여과→세뇨관→집합관)**
- 푸른 관 옆구리 창 속 구슬 덩이 = 사구체·보먼주머니, 걸러지는 작은 물질 (모양·뜻, 중)
- 관 위쪽을 조인 밧줄(위는 부풀고 아래는 처짐) = 세동맥 수축으로 여과압 조절 (뜻, 하)
- 솔 달린 나무 덕트(밧줄이 이어줌) = 솔가장자리(미세융모), 근위세뇨관 (소리 '솔'·모양, 중상)
- 삼베 그물 더미 = 크기로 거르는 여과막 또는 모세혈관망 (모양, 중하)
- 푸른 관의 U자 굽이 = 헨레고리 (모양, 중)
- 똘똘 뭉친 호스 = 곡세뇨관 (모양, 중)
- 구리 직관+놋쇠 이음 = 집합관(곧은 관·합류) (자리, 하)
- 호스 밑 물줄기 약 12줄 = 오줌으로 나가는 물 (개수, 중하)
- 모름: 구슬 구멍에 꽂힌 낫(낫≈나트륨·ANP? 초승달?), 바닥의 밧줄+못 2개

**구역2 · 울타리·가시공·기둥 위 사람(x560~1130, 아래) — 분비·역수송(추정)**
- 창끝 가시 울타리(윗가시 약 20) = 막(상피) 경계 (뜻, 하)
- 밤송이/성게 같은 가시 공 4개 + 튀는 호선·화살표 = 가시(산) H+ 등 이온이 울타리를 넘어 호스(관강) 쪽으로 분비 (모양·자리, 하)
- 두 기둥에 다리를 벌려 선 사람 = 반대 방향 교환 운반체(역수송)? (모양, 하)

**구역3 · 노점·짐꾼·문(x660~1500, 위) — 포도당·Na+ 공동수송(재흡수)**
- 포도 상자 = 포도당(포도糖) (소리·뜻, 상)
- 흰 소금 자루 = Na+ (뜻, 상)
- 두 사람이 포도+소금을 같은 방향으로 함께 나름 = 공동수송 (동작, 상)
- 앞사람 소금 2자루+포도 1상자, 뒷사람 1:1 = Na+:포도당 2:1(SGLT1)·1:1(SGLT2) (개수, 중)
- 널판 오르막 = 농도 기울기를 거슬러 에너지 쓰는 2차 능동수송 (자리, 중)
- 짐 내린 빈 보트 = 포도당이 모두 재흡수되어 오줌엔 없음 (뜻, 중하)
- 어두운 문으로 포도 상자만 들고 드는 대머리 = 포도당만 촉진확산(GLUT)으로 혈액 쪽에 나감, Na+은 따로 (자리, 중하)

**구역4 · 통나무 보트(x1220~1530) — 모름(pH?)**
- 통나무 약 11개를 싣고 물살 일으키는 배 = 후보: log→pH=−log[H+](옆 가시공=H+), 에너지 쓰는 능동수송, 비버 (소리, 하)

**구역5 · 선반+항아리(x1510~1960, 위) — 질소 노폐물 3종**
- 수족관 물고기 = 어류 → 암모니아 (뜻, 상)
- 수족관 김 3가닥 = 암모니아의 휘발성·독성 (모양, 하)
- 개구리 = 양서류 → 요소 (뜻, 중)
- 개구리 곁 노란 이불(요) = 요소 (소리 '요', 중하)
- 알 속 병아리가 흰 접힌 이불(요) 위 = 조류 → 요산, 흰 불용성 결정 (뜻·소리, 중상)
- 금화 0(물고기)·3(개구리)·약 15(알) = 합성 에너지 비용 암모니아<요소<요산 (개수, 중상)
- 항아리 큰 넘침·작은 가득·컵 한 방울 = 필요한 물 암모니아≫요소>요산 (개수·자리, 중상)
- 껍질 있는 알 = 육상 양막란, 물 절약 = 요산 (뜻, 중)

**구역6 · 널판 통·하마 보트(x1470~2000, 아래) — 수분 조절(ADH?)**
- 하마 = 하이포(히포)~시상하부(ADH) 또는 반수생 동물 (소리, 하)
- 보트 위 통 약 10개 = 물(수분)의 저장·재흡수, 술통이면 알코올=ADH 억제 (뜻, 하)
- 널판 내리막으로 굴리는 통 1개 = 에너지 없이 수동 이동(오르막 짐꾼과 대비) (자리, 하)

## ③ 뜻 모를 것 · 어색한 것 · 헷갈리는 것 · 흔적
- 모름: 낫과 쏟아지는 구슬, 바닥의 밧줄·못, 구리관·놋쇠 이음의 뜻, 기둥 두 개의 뜻, 통나무 보트.
- 헷갈림: 가시 공이 성게(삼투순응?)인지 밤송이(H+?)인지, 울타리를 넘는 방향. 하마가 시상하부인지 반수생 포유류인지. 노란 이불·흰 이불이 같은 '요' 말장난이라 요소·요산 구분이 불안. 노점의 상자·자루 수(4+3, 3)에 뜻이 있는지.
- 어색함: 뒷사람 발목에 계선주(말뚝)가 겹침, 왼쪽 아래 땅의 쓸데없이 긴 밧줄.
- 이어 붙인 흔적: 좌상단 벽의 번진 얼룩, 솔 위의 하얀 잡티, 왼쪽 장치(선 굵고 선명)와 오른쪽 선반·하마(부드러움)의 질감 차이. 뚜렷한 단절선은 못 찾음.

## ④ 한 문장
신장은 혈액을 걸러 포도당·Na+·물을 운반체로 되찾아 오고, 남은 질소 노폐물은 물이 풍부하면 암모니아, 중간이면 요소, 물이 귀하면 에너지를 더 들여 요산으로 내보낸다.
