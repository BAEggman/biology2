# 2단계 — 약속표로 다시 읽기 (s17u01) · 「↻」=1단계에서 달라진 곳

## ① 판 전체 표제어
- 1순위: **콩팥(신장)의 오줌 생성 — 사구체 여과·세뇨관 재흡수/분비·청소율 + 질소 노폐물** (85%) 「↻」 50→85
- 2순위: **사구체옆장치와 레닌–안지오텐신(여과 조절)** (6%) 「↻」 '막수송' 폐기
- 판정: 약속으로 더 잘 풀린다. 모름이던 낫·크림 주머니·그물·가시 공·기둥 남자·배 셋·하마가 모두 풀림. 그림에 없는 것: ADH(V자 이음쇠), 바사 렉타(눈금 자·유리 구).

## ② 구역별 (왼→오)
**구역1 [x0–590] 사구체와 사구체옆장치**
- 파란 둥근 관=핏줄(들어오는 관) · 구리 둥근 관=핏줄(나가는 관, 추정) [#133]
- 둥근 관 허리의 가는 밧줄=관을 조이는 되먹임 신호 [#128]
- 불룩한 주머니+크림빛 알갱이=과립세포, 아가리의 낫=레닌(칼 아님) [#137·#3] 「↻」 모름→풀림
- 바닥의 길게 처진 밧줄=안지오텐시노겐, 두 말뚝 사이 팽팽한 토막=안지오텐신 I(끊긴 자리 하나) [#128] 「↻」
- 나무 네모 관=세뇨관, 닫힌 끝이 파란 관에 닿기만 함 [#133] · 그 속 촘촘한 털=치밀반 [#4, 추정] 「↻」 솔가장자리 정정
- 삼베 그물=사구체간질세포(메운다) [#131] 「↻」 모세혈관망 정정
- 실뭉치 호스+물줄기 약 12=사구체와 여과액 [#132]
→ 읽힌 11

**구역2 [x590–1050 위] 부두·천막1·짐꾼 둘 — 포도당·Na⁺ 재흡수**
- 포도 상자(천막1 셋)=포도당 [#90]; 흰 소금이 보이는 자루=Na⁺, 자루 수=함께 드는 Na⁺ 수 [#111]
- 짐꾼A 소금2+포도1을 두 팔로 꽉 안음=2:1 고친화, 짐꾼B 소금1+포도1을 한 팔로 느슨히=1:1 저친화 [#111] 「↻」 친화도 추가
- 빈 배=전부 되찾음(포도당 청소율 0) [#135] 「↻」 모름→풀림
→ 읽힌 6 (항구 물=오줌길 추정 포함)

**구역3 [x600–1150 아래] 철책·가시 공·기둥 남자 — 여과 장벽**
- 가시 공 4=음전하 단백질(알부민) [#138]; 가시 철책에 튕겨 되돌아가는 화살표=전하 반발(크기 아님) [#129]
- 말뚝 두 개 위 다리 벌린 남자의 가랑이=여과 슬릿 [#130] 「↻」 H⁺·삼투순응자 폐기
→ 읽힌 3

**구역4 [x1040–1510] 뒷문·천막2·통나무 배**
- 등 보이며 열린 문으로 나가는 사람=뒷문(기저외측막), 든 것은 포도뿐=Na⁺ 없이 포도당만 [#134·#90] 「↻」 '문맥' 폐기
- 통나무 배(물보라)=여과만 되고 그대로 떠내려감=이눌린(GFR 잣대) [#135] 「↻」
- 모름: 천막2의 포도3·소금3 재고, 문 안의 어둠
→ 읽힌 3

**구역5 [x1510–2000 위] 선반 셋+그릇 셋 — 질소 노폐물**
- 뚜껑 없는 수조의 물고기+오르는 김=암모니아(독해서 가두지 못함) [#136]
- 개구리+덮개 씌운 바구니의 노란 이불=요소(얼마간 가둠), 알 속 오리+흰 이불=요산 [#136·#9] 「↻」 '요' 소리 확정
- 금화=ATP: 개구리 3, 알 곁 약 17 [#8]
- 항아리(넘침)>단지>찻잔=관 끝에서 나오는 오줌의 양 [#153]
→ 읽힌 5

**구역6 [x1480–2048 아래] 하마 배**
- 하마=PAH [#41]; 짐이 더 실린 배=더 버림(분비) [#135]; 판자로 통을 더 굴려 넣는 사람=분비로 짐이 더해짐(추정) 「↻」 시상하부·ADH 폐기
→ 읽힌 3

## 1단계 대비 정정·추가
- 틀렸던 것: 솔가장자리·진주=영양소 → 치밀반(촘촘함이 뜻) / 파란 주머니=보먼주머니 → 과립세포 주머니 / 낫=Na⁺·K⁺ 소리 → 레닌 / 성게=H⁺ → 알부민 / 하마=시상하부 → PAH / 문=문맥 → 뒷문 / 통 10개=ADH 소낭 → 분비의 짐.
- 놓쳤다가 보인 것: 나무 관이 파란 관에 닿기만 하고 이어지지 않음, 되먹임 밧줄이 치밀반 털까지 닿음, 말뚝 둘 사이 밧줄 토막, 짐꾼의 안는 정도, 바구니 덮개.
- 유지: 표제어(콩팥), 질소 노폐물 3종(물↔ATP 맞바꿈), Na⁺ 자루 2:1·1:1.

## ③ 잔결
- 아직 모름: 치밀반 털 위 흰 구슬 8알(구슬=아미노산 약속과 모양 다름), 구리관·호스 놋쇠 이음, S자 굽이, 천막 재고 수, 통나무 약 12·통 약 10의 개수 뜻.
- 약속과 다른 점: 부두는 널빤지가 아니라 돌벽(관강막 약속 불확실), 놋쇠 못·놋쇠 이음은 이 판엔 쓰이지 않는 듯.
- 이어 붙인 흔적: 그물 밑 y≈593–598·x≈255–420 수평 이음선 그대로. 새로 보임: x≈600에서 선 굵기·질감이 바뀜(왼쪽이 굵고 촘촘).

## ④ 한 문장
사구체가 크기·전하·슬릿으로 걸러 낸 여과액에서 세뇨관이 포도당을 Na⁺와 함께 되찾고 일부는 더 얹어 버리며, 그 차이를 청소율(이눌린·포도당·PAH)로 재고, 질소 노폐물은 암모니아→요소→요산으로 물을 아끼는 만큼 ATP가 든다.
