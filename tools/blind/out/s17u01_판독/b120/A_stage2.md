# Stage 2 — 약속표로 다시 본 판 (「↻」 = 1단계와 달라진 곳)

**판정**: 약속으로 훨씬 잘 풀린다. 1단계 「모름」이던 왼쪽 세 가닥 관·낫·밧줄·그물·두 말뚝 남자·통나무 배·하마가 모두 풀렸고, 구역3·6의 큰 줄거리는 1단계가 맞았다. 틀린 곳: 울타리를 「크기」로 읽은 것, 구리관=수입으로 읽은 것.

## ① 판 전체 표제어
- **1순위: 배설 — 신장 겉질(사구체 여과 · 근위세뇨관 재흡수 · 분비 · 청소율 · JG 장치의 레닌-안지오텐신)과 질소 노폐물** — 85% ↻(70→85; 땅 위 운하=겉질 #158)
- **2순위: 신장(네프론)의 구조와 기능 일반** — 10%
- 생식·발생 오독 여지는 사라짐.

## ② 구역 (6구역 유지, 근거는 약속표 번호)
**구역1 JG 장치와 레닌-안지오텐신** ↻(1단계 「배설기관 비교」 25% 폐기)
- 둥근 파란 천관 = 핏줄, 들어오는 관(수입 세동맥) #133; 가는 끈 매듭 = 그 관을 조이는 되먹임 신호 #128주
- 네모 나무 덕트 = 오줌길(세뇨관), 막힌 끝이 둥근 관에 닿되 안 이어짐 #133
- 덕트 속 촘촘한 검은 털 = 치밀반(자갈 Ca²⁺ 아님, 촘촘함이 뜻) #4 ↻; 끈이 매듭에서 털까지 이어짐 = 신호 길
- 부푼 주머니 속 크림빛 알갱이 = 과립세포 #137 ↻; 그 아가리의 낫 = 레닌(자르기만 하는 효소) #137·#3 ↻
- 바닥에 늘어진 긴 밧줄 = 안지오텐시노겐, 끊겨 두 말뚝 사이에 팽팽한 토막 = 안지오텐신 I(끊긴 자리 하나) #128 ↻
- 구겨 넣은 삼베 그물 = 사구체간질세포(메운다) #131 ↻
- 약속표에 없음: 털 위 흰 구슬 8개(관 속 NaCl 농도 같으나 미확정, #145 꼴)
읽힌 사실 9

**구역2 사구체 여과 장벽 — 전하와 슬릿** ↻(크기→전하)
- 뭉친 호스 = 사구체, 아래 물줄기 = 여과액 #132
- 가시 울타리에 가시 공 4가 튕겨 되돌아감 = 같은 음전하끼리 반발, 크기가 아님 · 공 = 알부민 #129·#138 ↻
- 말뚝 위 다리 벌린 남자의 가랑이 = 여과 슬릿(그 틈으로만 지남) #130 ↻
- 파란 관이 호스로 들어감 = 수입 세동맥→사구체; 가는 구리관 = 수출 세동맥 추정 ↻(1단계 구리관=수입 뒤집힘)
읽힌 사실 7

**구역3 근위세뇨관 재흡수 — 포도당·Na⁺ 공동수송**
- 포도 = 포도당 #90; 흰 가루 자루 = Na⁺, 자루 수 = 함께 가는 Na⁺ 수 #111
- 앞 짐꾼: 자루 2 + 상자를 꽉 끌어안음 = 2:1 고친화; 뒤 짐꾼: 자루 1 + 상자 느슨 = 1:1 #111 ↻(개수에 근거 생김)
- 건널판 = 관강막 쪽 통로(반쯤) #134; 어두운 문 = 뒷문 = 기저외측막, 포도만 들고 Na⁺ 없이 나감 #134 ↻
- 묶인 빈 배 = 전부 되찾음(포도당 청소율 0) #135; 땅 위 운하 = 겉질 #158 ↻
읽힌 사실 8

**구역4 통나무 배 — 여과만(이눌린, GFR 의 잣대)** ↻(모름→풀림)
- 짐(통나무)이 그대로 떠내려감 #135; 흘러가는 짐 = 오줌으로 나가는 양
읽힌 사실 2

**구역5 하마 배 — 분비(PAH)** ↻(「물·ADH?」 폐기)
- 하마 = PAH #41; 짐이 더 실린 배 + 통을 더 싣는 남자 = 더 버림(분비) #135
읽힌 사실 2

**구역6 질소 노폐물 3종** (1단계 확정, 근거 보강)
- 열린 수족관의 김 = 너무 독해 가두지 못하고 곧장 흘림 = 암모니아 #136; 큰 항아리 넘침 = 많은 오줌 #153; 동전 0 = ATP 안 듦 #8
- 바구니(뚜껑 반쯤 젖힘) + 노란 요(이불) = 요소, 얼마간 가둬 둠 #9·#136; 동전 3 · 작은 항아리 = ATP·오줌 중간
- 알 속 병아리 + 흰 접힌 요 = 요산 #9; 동전 더미 = ATP 최대; 찻잔 = 오줌 최소
읽힌 사실 10

## ③ 못 푼 것 · 헷갈림 · 이음
- 약속표에 없어 끼우지 않음: 구리관 끝 황동 이음쇠, 털 위 흰 구슬 8, 천막·가판 상자(왼 4·오른 3)·가판 소금 자루 3, 통 9~10 · 통나무 11~12 · 물줄기 11, 계류 말뚝, 찻잔 물방울.
- 해소된 헷갈림: 낫≠칼(K) #3 · 촘촘한 털≠자갈(Ca²⁺) #4 · 가는 끈≠굵은 밧줄 #128 · 둥근 관(핏줄)↔네모 관(세뇨관) #133 · 소금 자루 수 = Na⁺ 수(배수성 아님) #111 · 이불 = 요 #9.
- 남은 어색: 가판 소금 자루 3이 Na⁺-K⁺ 펌프의 「소금 셋」(#148)과 같은 꼴이나 펌프가 없다. 하마가 통 위에 앉은 것은 이름 소리(PAH)로 풀림.
- 이음 흔적(그대로): 왼쪽 위 지평선 부근 흐린 얼룩, 그물 아랫끝의 수평 절단선, 왼쪽(굵은 선)과 나머지의 화풍 차이.

## ④ 한 문장
겉질(땅 위 운하)에서 사구체는 음전하 그물과 슬릿으로 알부민을 막고 거른 것을, 근위세뇨관이 포도당을 Na⁺ 와 함께 되찾아 청소율이 이눌린(여과만)·포도당(0)·PAH(분비 더함)로 갈리며, 치밀반-과립세포(레닌→안지오텐신)가 이를 되먹임하고, 남는 질소는 암모니아→요소→요산으로 물은 덜·ATP 는 더 쓴다.
