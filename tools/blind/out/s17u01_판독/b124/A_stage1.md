# 1단계 생판 (그림만 보고)

## ① 판 전체 표제어
- **1순위 배설(콩팥 네프론의 오줌 생성+질소 노폐물)** 85% / **2순위 삼투조절·체액 항상성(레닌·ADH 등 호르몬)** 10%
- 근거: 호스 뭉치에서 물이 샘(여과), 짐 나르는 장터(재흡수), 선반 3칸+물그릇 3개(질소 노폐물 3종), 항구의 물길(체액). 나머지 5%는 막수송 일반.

## ② 구역 (왼쪽부터 5구역, 괄호 안은 근거)
구역별 확신도: 구역4 약 85%(소리·자리·개수가 겹쳐 확실), 구역2 약 60%, 구역1 약 45%(구조는 보이나 호르몬 쪽은 추정), 구역3·5 약 25~35%(표제어부터 갈림).
### 구역1 왼쪽 관 더미 — **사구체·방사구체장치** (읽힌 7)
1. 굵은 푸른 천 관+↓↓2 = 수입세동맥 (굵기·방향)
2. 가는 구리관+↑↑2+황동 이음쇠 = 수출세동맥 (굵기차)
3. 호스 뭉치 = 사구체, 絲球=실뭉치 (뜻)
4. 뭉치 밑으로 새는 물줄기 약 12 = 여과 (모양·개수)
5. 노란 L덕트 끝의 빽빽한 검은 솔+흰 결정 12 = 치밀반, NaCl 감지 (모양·자리: 두 혈관 사이)
6. 푸른 관을 조인 매듭 밧줄이 덕트로 이어짐 = 되먹임(수입세동맥 수축) (자리)
7. 진주 가득한 주머니, 구멍서 쏟아짐 = 과립세포의 레닌 과립 방출 (모양)
- 추정(미산입): 낫이 땅의 긴 밧줄 끝을 자름 = 레닌이 안지오텐시노젠 절단(30%); 삼베 그물 = 사구간질세포(30%)

### 구역2 장터·부두·문 — **재흡수: Na+–포도당 공동수송** (읽힌 6)
1. 보라 포도 상자 = 포도당 (소리)
2. 흰 가루 소금 포대 = Na+ (뜻)
3. 앞 남자: 소금 2포대+포도 1상자 = 2:1 (개수)
4. 뒤 남자: 소금 1포대+포도 1상자 = 1:1 (개수)
5. 둘이 한 널다리로 같은 방향 = 공동수송, 2차 능동 (동작)
6. 대머리 남자가 포도만 들고 어두운 문으로 = 포도당만 촉진확산(혈액 쪽) (동작·자리)
- 추정: 빈 배 = 도착지(혈관); 진열대 포도 4+3상자·소금 3포대 = 여과액에 풍부

### 구역3 아래 운하 — **여과 장벽** (읽힌 3)
1. 가시 철책 = 여과막, 틈보다 큰 것 차단 (모양)
2. 가시공 4 = 혈구·단백질 (모양·개수); 대안: K+·H+ 분비
3. 공이 철책에서 튕겨 물줄기 쪽(←) = 못 지나감 (동작)
- 모름: 기둥 두 개 위에 다리 벌린 남자(발세포? 펌프?), 달리는 통나무 배(통+나무→Na+ 통로? 20%)

### 구역4 오른쪽 위 선반+그릇 — **질소 노폐물 3종** (읽힌 12)
1. 어항 물고기1+올챙이1 = 암모니아, 수생 (자리)
2. 어항 위 김 3줄 = 독성·휘발 (모양)
3. 넘쳐 고이는 큰 항아리 = 물이 가장 많이 필요 (크기)
4. 강아지·개구리·상어 칸 = 요소 (자리)
5. 노란 이불 = 요(尿)→요소 (소리)
6. 동전 3 = 요소 합성 ATP (개수)
7. 중간 단지 = 물 중간 (크기)
8. 올챙이→개구리 = 변태 때 암모니아→요소 (자리)
9. 알 속 병아리·도마뱀·딱정벌레 = 요산(조류·파충류·곤충) (자리)
10. 흰 이불 더미 = 요산, 흰 불용성 (소리·모양)
11. 금화 더미 17+ = ATP 최대 (개수)
12. 찻잔 한 방울 = 물 최소 (크기)
- 세 칸: 동전 0<3<17+, 그릇 대>중>소 → 에너지↑ 물↓ 반비례

### 구역5 오른쪽 아래 하마 배 — **삼투 농도·저장액(추정)** (읽힌 3)
1. 하마≈hippo≈hypo = 저(低) (소리)
2. 통 약 10+굴러 내리는 1 = 물, '통'≈tonic (소리·뜻)
3. 경사로로 통을 굴려 싣는 남자 = 기울기 따라 이동 (동작)
- 대안: 통 = 아쿠아포린 소낭, 남자 = ADH 신호(물 재흡수)

## ③ 모름·어색·헷갈림·이은 흔적
- 모름: 못 2개+짧은 밧줄, 황동 이음쇠, 기둥 위 남자, 통나무 배, 빈 배(가로판 3), 부두 모서리 남자 발 옆 작은 병, 어두운 문 안쪽
- 헷갈림: 가시공↔철책 가시가 닮음; 흰 것 3종(소금 포대·결정·이불 더미)이 각각 다른 뜻; 배 3척(빈 배·통나무 배·통 배)의 역할; 상어 1/2마리(머리·꼬리가 이불 양쪽); 물그릇 4종(항아리·단지·찻잔·통); 어항 김이 독성인지 따뜻함인지
- 이음: 화풍 단절(만화풍 선반 / 사실풍 사람 / 해칭풍 관·삼베 / 두꺼운 채색 하마); 화살표 4·흰 결정·동전 3은 평면 벡터로 얹힘; 푸른 관·구리관·덕트가 위로 잘려 큰 구조의 일부로 보임
- 방향 메모: 물줄기 ↓, 공 ←(철책→물줄기), 통나무 배 →, 짐꾼은 부두→배(아래로), 통도 부두→배

## ④ 한 문장
콩팥은 피를 사구체에서 거르고(여과) 포도당·Na+는 되가져오며(재흡수) 질소 노폐물(암모니아→요소→요산)은 물 사정에 맞춰 내보내고, 호르몬이 물·염분 양을 맞춘다.
