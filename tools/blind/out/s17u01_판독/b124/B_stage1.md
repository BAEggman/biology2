# 1단계 생판 읽기 — s17u01 (그림만 보고)

확신 표기: [상] 70% 이상 · [중] 40~70% · [하] 15~40% · 그 아래는 「모름」

## ① 판 전체 표제어
- 1순위 **배설계: 콩팥(네프론)의 여과·재흡수·분비 + 질소 노폐물** — 70%
- 2순위 **삼투조절·체액(물·염) 항상성(ADH 포함)** — 15%
- 근거: 오른쪽 선반의 칸 3개 · 물그릇 3개(넘치는 큰 항아리 / 작은 항아리 / 물방울 1개 그려진 찻잔) · 동물 8종이 '질소 노폐물 3종 + 물 사용량 + 에너지 값'으로 또렷이 읽힌다. 왼쪽은 굵은 관 → 호스 뭉치 → 가는 관(사구체·세동맥꼴), 가운데는 포도·소금을 배에서 부두로 옮기는 재흡수꼴이다.

## ② 구역별 (왼쪽부터)
**구역1. 사구체·세동맥(여과)** — 맨 왼쪽 관·호스·상자
- 굵은 파란 천관(아래 화살표 2) ↔ 가는 구리관(위 화살표 2): 들어오는 쪽은 굵고 나가는 쪽은 가늘다 = 구심성·원심성 세동맥, 압력 유지 [중] (굵기·방향)
- 호스를 둥글게 감은 뭉치 1개 = 사구체(絲球, 실뭉치) [중] (모양·소리)
- 뭉치 밑으로 운하에 떨어지는 물줄기 약 11줄 = 압력 여과 [중] (뜻) — 여과인지 재흡수인지 방향은 갈림
- 밧줄 1가닥이 관을 조이고 줄이 상자로 이어짐 = 세동맥 수축 조절 신호 [하] (자리)
- 상자 속 검은 솔 위 흰 결정 약 12개 = 치밀반(dense=빽빽·검정)의 NaCl 감지? [하]
- 관 속 구슬 수백 개, 마개 구멍에서 20여 개가 쏟아짐 + 낫 1자루 = 레닌 과립 방출과 '자르는' 효소? [하]
- 삼베 그물 1더미 = 메산지움(mesh)? [하]

**구역2. 여과막(울타리·가시공)** — 호스 오른쪽 운하
- 가시 울타리, 가로대 3겹 = 3겹 선택적 장벽 [중] (모양·개수)
- 밤송이 가시공 4개가 울타리에서 튕겨 호스 쪽으로 되돌아가는 곡선 화살표 = 큰·음전하 입자(단백질·혈구)는 걸러지지 않고 혈액에 남음 [중] (동작) — H+·K+ 분비일 수도
- 기둥 2개에 다리 벌리고 선 사람 1명 = 발세포(podocyte)의 발, 사이 틈 = 여과틈새 [하]

**구역3. 재흡수(포도당·Na+)** — 시장·부두
- 포도 = 포도당 [상] (소리) / 흰 가루 자루 = 소금·Na+ [중] (모양)
- 한 사람은 어깨에 소금 자루 + 팔에 포도 상자, 다른 사람은 포도 상자를 안고 판자를 오르며 뒤에 소금 자루 2개 = 소금과 포도가 한 짝으로 이동, Na+-포도당 공동수송 [중] (개수 2·동작)
- 판자 1장 = 운반체 통로(포화?) [하], 빈 배 1척 = 포도당이 남지 않음(100% 재흡수) [하]
- 포도 상자 10(가게 4 + 탁자 3 + 든 것 3), 소금 자루 6, 천막 2: 개수 뜻은 모름. 어두운 문 속으로 포도 상자를 들고 들어가는 사람 1명 = 모름

**구역4. 짐배 둘(통나무·하마)** — 가운데 오른쪽 운하
- 통나무 10여 개를 싣고 물결을 가르는 배 = 모름(그냥 지나가는 물질?)
- 하마가 통 약 10개 위에 앉은 배 + 판자로 통을 내려보내는 사람 1명 = '물 먹는 하마'(물 재흡수·ADH) / hippo=히푸르산(분비) / hippo=시상하부 — 셋 중 못 고름

**구역5. 질소 노폐물 3종** — 오른쪽 선반
- 칸 3개 = 암모니아·요소·요산 [상]
- 왼칸: 물고기 1·올챙이 1, 김 3줄, 앞에 넘치는 큰 항아리 = 암모니아(수생, 독성 최대, 물 최다, 휘발) [상]
- 가운데: 강아지(포유류)·개구리·상어(연골어류), 노란 이불(요→요소, 소리), 작은 항아리, 노란 동전 3개 = 요소(독성·물·에너지 모두 중간) [상]
- 오른칸: 알 속 병아리(조류)·도마뱀·딱정벌레(곤충), 알 속 흰 이불 더미(불용성 결정을 알 안에 저장), 물방울 1개 그려진 찻잔, 금화 약 16개 = 요산(물 최소, 에너지 최고) [상]

## ③ 뜻 모를 것 · 어색한 것 · 헷갈림 · 이어 붙인 흔적
- 모름: 낫·구슬 주머니·못 2개와 바닥 밧줄, 삼베 그물, 통나무 배, 하마, 어두운 방.
- 헷갈림: 호스 물줄기가 여과(혈액→관)인지 재흡수(관→혈액)인지, 초록 운하가 혈액인지 오줌인지, 흰 가루가 소금인지 요소인지(선반의 흰 덩어리와 겹침), 노랑 3종(이불·병아리·금화).
- 이어 붙인 흔적: 굵은 화살표 4개는 납작한 벡터라 덧입힌 듯(곡선 화살표 1개는 얇은 손선). 동전 3개·작은 항아리·찻잔은 흰 테두리가 둘러 스티커 같음. 그물 아래 U자 안쪽에 직사각 보정 자국과 들쭉날쭉한 검은 선. 선반 속 동물은 하마·사람과 크기 비율이 어긋남. 맨 왼쪽은 먹선이 굵고 질감이 빽빽, 가운데는 선이 가늘고 깔끔.

## ④ 한 문장
콩팥은 혈액을 압력으로 거르고(여과), 포도당·소금은 거의 되찾고(재흡수) 일부는 더 내보내며(분비), 남은 질소 노폐물은 사는 곳에 따라 물을 많이 쓰는 암모니아에서 물을 아끼는 요산까지 달리 버린다.
