# 2단계 약속표로 다시 읽기 — s17u01

판정: 약속표로 훨씬 더 잘 풀린다. 1단계 「모름」·[하]이던 낫·구슬 주머니·밧줄·그물·상자 속 솔·통나무 배·하마·문·가랑이가 약속으로 풀렸다. 1단계 [중] 이상은 대체로 맞았고, 틀린 두 곳(가시공을 '큰 입자·혈구'로 본 것, 굵기 차를 뜻으로 본 것)은 바로잡았다. 읽힌 사실 19개 → 37개. 표에 없는 물건은 끼우지 않았다(③). ↻ = 1단계와 달라진 곳, #n = 약속표 번호.

## ① 판 전체 표제어
- 1순위 **배설계 — 콩팥의 여과·재흡수·분비(청소율) + 질소 노폐물 3종** — 88% ↻(70→88)
- 2순위 **삼투조절·체액 항상성(RAAS·ADH 포함)** — 7% ↻(15→7)
- 근거: 선반은 1단계 그대로(#9 요 · #8 동전 · #136 김 · #153 항아리), 왼쪽은 사구체와 JG 장치(#128 · #131~133 · #137), 가운데는 재흡수(#111 · #134), 짐배 셋은 청소율(#135).

## ② 구역별 (읽힌 사실 수: 1단계 → 2단계)
**구역1. 사구체와 JG 장치(여과·레닌·되먹임)** 3 → 12
- 파란 둥근 관 ↓ = 들어오는 핏줄(구심성), 구리 둥근 관 ↑ = 나가는 핏줄(원심성) (#133 둥근 관 = 핏줄 · 몸의 화살 = 흐르는 쪽). 굵기 차는 표에 없어 뜻으로 안 씀 ↻
- 엉킨 호스 뭉치 + 밑의 물줄기 = 사구체와 여과액 (#132) ↻
- 삼베 그물 = 사구체간질세포 (#131 「메운다」: 관 사이 빈틈을 메움) ↻
- 크림빛 알갱이 가득 부푼 주머니 = 과립세포, 그 아가리에서 나온 낫 = 레닌 (#137 · #3 낫 = 자르기만 하는 효소) ↻
- 땅에 늘어진 긴 밧줄 = 안지오텐시노겐, 두 쇠말뚝 사이 팽팽한 토막 = 안지오텐신 I (끊긴 자리 하나, 말뚝 둘은 번호 아님) (#128). 밧줄이 낫 날 밑을 지나 올 풀린 채 끊긴 것이 근거 ↻ 모름→풀림
- 관을 졸라맨 가는 끈 = 들어오는 관을 조이는 되먹임 신호 (#128 끝말) ↻
- 둥근 관에 닿되 안 이어지는 네모 나무 관의 상자 = 오줌길이 사구체 곁을 지남 (#133) · 속의 촘촘한 검은 털 = 촘촘함 = 치밀반 (#4) · 흰 결정 약 12개 = 관 속 NaCl 짙음 (#145) → 짙으면 끈이 조여 여과 감소 ↻

**구역2. 여과 장벽(전하 반발 · 슬릿)** 2 → 4
- 가시 그물(울타리) + 가시 공 4개 = 음전하 단백질(알부민)이 같은 전하 그물에 튕겨 되돌아감, 크기가 아니라 전하로 막음 (#129 · #138) ↻ 1단계의 '큰 입자·혈구'는 틀림
- 말뚝 위에 다리 벌린 사람의 가랑이 = 여과 슬릿 (#130) ↻ '발세포'→슬릿

**구역3. 근위세뇨관 재흡수(SGLT · GLUT2)** 3 → 6
- 포도 = 포도당 (#90), 흰 소금이 보이는 자루 = Na⁺ (#111)
- 자루와 궤짝을 함께 진 짐꾼 = 공동수송. 어깨에 자루 1 = SGLT2(앞쪽·많이·느슨히), 등에 자루 2 = SGLT1(뒤쪽·남은 것까지 꽉) (#111) ↻ 자루 수가 뜻
- 자루 없이 궤짝만 안고 뒷벽의 문으로 = GLUT2(촉진 확산), 뒷문 = 기저외측막 (#134) ↻ 모름→풀림

**구역4. 청소율 세 유형(짐배 셋)** 0 → 5
- 강 위 같은 배 셋 = 청소율 세 유형 (#135) ↻
- 통나무를 실은 채 그대로 달리는 배 = 이눌린(여과만, GFR 잣대) ↻ 모름→풀림
- 텅 빈 배 = 전부 되찾음(포도당) ↻
- 하마 = PAH (#41), 통을 더 실음 = 분비, 청소율이 RPF 잣대 ↻ 1단계 후보 셋 중 둘째가 맞음

**구역5. 질소 노폐물 3종** 11 → 10
- 칸 3 = 암모니아·요소·요산. 요(이불) = 요소·요산: 노란 이불 = 요소, 알 속 흰 이불 = 요산 (#9)
- 물고기·올챙이 / 강아지·개구리·상어 / 병아리·도마뱀·딱정벌레 = 칸마다 사는 동물(표에 없어 실물 그대로 읽음)
- 뚜껑·그릇 없이 오르는 김 = 너무 독해 가두지 못하고 곧장 흘림(암모니아) (#136) ↻ '휘발'→'독성'
- 뚜껑 반쯤 젖힌 바구니에 덮어 둔 강아지 = 얼마간 가둬 둠(요소) (#136) ↻
- 동전 = ATP (#8): 0 → 3 → 약 16 ↻ '에너지'→ATP
- 항아리 > 작은 항아리 > 찻잔 물방울 = 나오는 물의 양 (#153)

## ③ 남은 것
- 표에 없어 뜻 없음으로 둔 것: 놋쇠 이음쇠, 천막 2, 가게의 궤짝 7·자루 3(표는 멘 자루만 센다), 판자 1장, 물줄기 11, 말뚝·못 개수. 운하 쪽 돌 둑을 관강막으로 읽을 수도 있으나 표의 '널빤지 벽'이 아니라 셈에서 뺌.
- 헷갈림: 구리관은 구리 왕복관(#6 · #152)과 재질이 같으나 눈금 자·유리 구가 없어 나가는 핏줄로만 읽음.
- 이어 붙인 흔적: 굵은 화살 4개·곡선 화살·동전 3개·작은 항아리·찻잔은 납작하거나 흰 테두리라 약속 부호를 덧붙인 것으로 읽힘. 그물 아래 직사각 보정 자국은 그대로.

## ④ 한 문장 ↻
콩팥은 들어온 혈액을 사구체에서 전하·슬릿 장벽으로 거르고(JG 장치가 레닌·되먹임으로 조절), 근위세뇨관이 포도당을 SGLT·GLUT2로 되찾으며 PAH는 더 내보내(청소율), 남은 질소 노폐물은 암모니아·요소·요산으로 버린다.
