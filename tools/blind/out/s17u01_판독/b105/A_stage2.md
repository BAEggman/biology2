# 2단계 약속 어휘로 다시 읽기 (s17u01)

**판정** 약속으로 훨씬 잘 풀림. 1단계 「모름」 7곳(혹·낫, 검은 털, L자 상자, 바닥 밧줄·못, 가시 울타리, 두 기둥 남자, 통나무 배)이 풀리고, 막연하거나 틀렸던 6곳(성게, 밧줄 묶음, 그물, 하마, 빈 배, 문)을 고침. 구역3·5의 큰 틀은 그대로 확정. 약속표에 없는 물건은 끼우지 않음. 번호는 약속표 줄.

## ① 판 표제어
- 1순위 **배설계: 콩팥(신장)의 오줌 생성 — 사구체 여과·재흡수·분비·청소율, 방사구체 장치(레닌), 질소노폐물** 90% ↻(75%)
- 2순위 **방사구체 장치와 레닌–안지오텐신계(혈압·체액 조절)** 6%
- 근거: 132 사구체, 137 레닌, 135 배 셋(청소율), 41 하마=PAH, 111 소금자루=Na⁺ 수, 9 요·8 동전.

## ② 구역
**구역1 왼쪽 파이프 섬 — 방사구체 장치(JGA)·사구체·레닌 방출** ↻(사구체 여과?)
- 엉킨 호스 코일 + 밑으로 떨어지는 물줄기 약 11 = 사구체와 여과액 (132, 그대로 확정)
- 둥근 관 = 핏줄(133): 파란 관 = 들어오는 핏줄, 코일에서 나가는 구리관 = 나가는 핏줄 ↻
- 나무 네모 관(L자) = 세뇨관, 막힌 끝이 파란 관에 닿기만 함(133 닿되 안 이어짐) ↻
- 그 속 벽에 촘촘히 돋은 검은 털 = 치밀반(4 촘촘함) ↻ 모름→풀림, '이어 붙인 얼룩' 의심 철회
- 치밀반에서 나와 파란 관을 졸라맨 가는 끈 = 들어오는 관을 조이는 되먹임(128) ↻ 수출→수입
- 관 벽 주머니에 가득한 크림빛 알갱이 = 과립세포(137), 그 아가리의 낫 = 레닌(137·3) ↻ 2개
- 낫 끝에 닿은 땅의 긴 삼밧줄 = 안지오텐시노겐, 두 못 사이 팽팽한 토막 = 안지오텐신 I(128, 끊긴 자리 하나) ↻ 2개
- 구겨 넣은 삼베 그물 = 사구체간질세포(131 메운다) ↻ 여과막→메산지움
→ 읽힌 10개

**구역2 가시 울타리·가시 공·두 기둥 위 남자 — 여과막: 전하 장벽과 여과 슬릿** ↻(삼투순응?)
- 가시 공 4 = 음전하 단백질(알부민, 138) ↻ 성게 아님
- 가시 울타리에 튕겨 되돌아감 = 같은 전하 반발, 크기가 아닌 전하(129) ↻
- 말뚝 위 다리 벌린 사람의 가랑이 = 여과 슬릿(130) ↻
→ 읽힌 3개

**구역3 부두 시장 — 포도당 재흡수: Na⁺–포도당 공동수송(SGLT1·2)**
- 포도 = 포도당(90), 소금 자루 = Na⁺(111), 함께 나름 = 공동수송
- 널빤지 위 남자 소금2·포도1, 두 팔로 꽉 안음 = 2:1 고친화(SGLT1) ↻ 개수 확정
- 선 남자 소금1·포도1, 한 팔로 느슨 = 1:1 저친화(SGLT2) ↻
- 어두운 문으로 포도만(소금 0) = 뒷문 = 기저외측막(134) ↻
- 텅 빈 배 = 전부 되찾음(135) ↻ 운반체→청소율 0
→ 읽힌 7개

**구역4 통나무 배 — 이눌린 청소율(GFR)** ↻(모름)
- 짐 그대로 떠내려감 = 여과만 = 이눌린(135), 같은 강의 배 셋 = 청소율 세 유형, 흘러가는 짐 = 배설량
→ 읽힌 3개

**구역5 선반·물그릇 3개 — 질소노폐물 3종** (그대로 확정)
- 김 나는 어항 물고기 = 암모니아, 뚜껑 없이 오르는 김 = 독해서 곧장 흘림(136) ↻ 의미 구체화
- 큰 항아리 넘침 = 물 매우 많이, 작은 항아리 = 중간, 찻잔 물방울 1 = 거의 없음(102)
- 개구리 + 노란 요 = 요소(9) ↻ 소리 추정→확정, 동전 3 = ATP 3(8)
- 알 속 병아리 + 접힌 흰 요 더미 = 요산(9), 동전 더미 약 17 = ATP 가장 많이(8)
- 오른쪽 칸일수록 물↓·ATP↑
→ 읽힌 11개

**구역6 하마 배 — PAH와 분비** ↻(ADH?)
- 하마 = PAH(41), 짐을 더 실은 배 = 더 버림(135), 남자가 통을 부두에서 배로 내려 실음 = 분비 동작(추정)
→ 읽힌 3개

## ③ 남은 것
- 1단계에서 놓쳤던 것 ↻: 끈이 치밀반 틈에서 나와 파란 관 목으로 이어진다는 점(1단계는 상자까지만 봄), 낫 끝에서 잘린 밧줄 끝, 두 남자의 팔 모양(꽉 안음/느슨), 통을 부두에서 배 쪽으로 내려 싣는 방향(1단계는 끌어올린다고 봄).
- 덜 확실한 읽기: 치밀반(약속은 '촘촘함'만 말함, 끈과 자리로 보강 — 중간~높음), 고친화/저친화 짝짓기(중간), 통 싣는 남자 = 분비(중간), 구리관 = 나가는 핏줄(중간).
- 약속표에 없어 읽지 않음: 구리관·황동 이음쇠(재질), 왕골 바구니, 가판대 포도 7상자·소금 3자루, 통 약 10개, 볼라드, 찻잔 재질, 천막.
- 어긋남: '같은 배 셋'인데 배 모양이 서로 다름. ADH(V자 이음쇠)·알도스테론은 이 그림에서 못 찾아 1단계 ADH 추정 폐기. 파란 관 U자부 가로 이음선·벽 얼룩은 그대로.

## ④ 한 문장
혈액은 사구체에서 크기(슬릿)와 전하(알부민 반발)로 걸러지고 방사구체 장치가 레닌·되먹임으로 이를 맞추며, 걸러진 포도당은 Na⁺와 함께 되찾고 PAH는 더 버리는데 이를 이눌린·포도당·PAH 청소율로 재며, 질소노폐물은 암모니아→요소→요산 순으로 물은 덜·ATP는 더 쓴다.
