# stage1 — 생판 읽기 (그림만 보고)

## ① 판 전체 표제어
- 1순위: **신장(콩팥)의 기능 — 사구체 여과·세뇨관 재흡수/분비·청소율·JG장치·질소 노폐물 (배설계)** — 확신 80%
- 2순위: **체액·혈압 항상성 (레닌-안지오텐신계·삼투조절)** — 확신 10%
- 근거: 포도(=포도당)+소금(=Na+) 공동수송, 호스 뭉치(사구체), 낫(레닌), 암모니아·요소·요산 3칸, 배 3척(청소율).

## ② 구역별 읽기 (왼쪽부터)
**구역1 (x0~360) 사구체옆장치·레닌-안지오텐신계** — 7개
- 굵은 파란 관(위에서 뭉치로 이어짐) = 수입세동맥 [모양·자리, 추정]
- 관의 불룩한 칸 속 흰 알갱이 수백 개 = JG(방사구체)세포의 레닌 과립 [모양]
- 그 칸에 꽂힌 낫 + 쏟아지는 알갱이 = 레닌(Lenin→낫) 분비 [소리]
- 낫이 끊은 굵은 밧줄(한끝은 그림 밖) = 안지오텐시노겐→안지오텐신Ⅰ 토막 [뜻·모양]
- 관 허리를 졸라맨 가는 끈 1줄 = 혈관 수축(안지오텐신Ⅱ/세뇨관-사구체 되먹임) [뜻]
- 끈이 가 닿는 L자 나무관 창 속 검고 빽빽한 털 = 치밀반(macula densa, 원위세뇨관 벽, Na+/Cl- 감지) [뜻: 점+빽빽]
- 관·상자·뭉치 사이에 쌓인 그물 = 사구체외 메산지움(lacis=그물) 세포 [소리·자리]
- 말뚝 2개+밧줄: 모름(ACE?)

**구역2 (x360~960 아래) 사구체 여과와 여과막** — 6개
- 호스를 둘둘 만 뭉치 = 사구체(모세혈관 얽힘) [모양]
- 뭉치 위의 가는 구리관 vs 굵은 파란 관 = 수출세동맥이 더 가늘어 압력↑ [굵기, 추정]
- 뭉치 밑으로 새는 물줄기 약 12가닥 = 압력으로 걸러지는 여과액(원뇨) [개수·모양]
- 가시 철책(가로대 3) = 여과막(기저막: 크기·음전하 장벽) [모양]
- 철책에 튕겨 뭉치 쪽(왼쪽)으로 되돌아가는 성게 4마리 = 알부민 등 큰 단백질·혈구는 여과 안 됨 [모양·방향]
- 두 기둥에 다리 벌려 선 남자 = 발세포 발돌기 사이 여과 틈 [자리, 자신 낮음]

**구역3 (x660~1500 위·가운데) 근위세뇨관 재흡수 — Na+·포도당 공동수송** — 7개
- 포도 상자 = 포도당(포도당=포도+당) [소리·뜻]
- 소금 자루 = Na+ [뜻]
- 앞 남자: 소금 2자루+포도 1상자 = SGLT1(2Na+:1포도당) [개수]
- 뒤 남자: 소금 1자루+포도 1상자 = SGLT2(1:1) [개수]
- 배→좁은 판자→부두 = 관강→상피세포로 이동(재흡수), 판자=운반체 [동작]
- 짐 내린 빈 배(좌판 3) = 포도당 전량 재흡수, 소변엔 없음 [모양]
- 어두운 문 안으로 포도 상자만 들고 가는 남자 = 세포→혈액 GLUT2(소금 없이 촉진확산) [동작]

**구역4 (x1200~2048 아래) 청소율·분비 — 이눌린 vs PAH** — 5개
- 통나무 배(통나무 약 12), 물보라 내며 안 서고 지나감 = 이눌린: 여과만, 재흡수·분비 없음 → GFR [동작]
- 하마 = hippurate, PAH [소리]
- 통 약 10개 가득 실은 배 = 여과+분비로 거의 전량 배설 → 청소율 최대(신혈장유량) [개수]
- 판자에서 통을 굴려 싣는 사람 = 근위세뇨관 능동 분비(혈액→관강) [동작]
- 빈 배<통나무 배<하마 배 짐 순서 = 청소율 비교 [배열, 추정]

**구역5 (x1500~2000 위) 질소 노폐물 3종** — 6개
- 수족관+물고기+김 3줄 = 암모니아(독성·수생동물·물 아주 많이) [모양]
- 칸 밑 그릇 3: 넘치는 큰 항아리>반쯤 찬 작은 항아리>찻잔 한 방울 = 쓰는 물 암모니아>요소>요산 [개수·자리]
- 개구리+노란 이불(요)+소쿠리 = 요소(양서류·포유류) [소리: 요+소쿠리]
- 개구리 발치 동전 3 = 요소 합성 에너지 중간 [개수]
- 알 속 병아리+접힌 흰 이불 더미(요+산) = 요산(조류·파충류, 불용성 고체, 알 속 저장) [소리·뜻]
- 알 옆 동전 더미 약 18 = 요산 합성 에너지 최대 [개수]

## ③ 모름·어색·헷갈림·이음 흔적
- 모름: 기둥 위 남자의 정확한 뜻, 말뚝 2개, 놋쇠 이음쇠, 성게가 하필 4마리인 이유, 가게 포도 상자(4+3)·소금 3의 수, 하마(PAH 아니면 hypo-?).
- 헷갈림: 구리관·파란 관 중 어느 쪽이 수입/수출인지, 빈 배 vs 통나무 배, 노란 이불과 흰 이불(둘 다 '요').
- 이음 흔적: 왼쪽 파란 관 y≈600에 희미한 가로 이음선; 나무 상자 창 속 검은 털 조각은 가장자리 들쭉날쭉+반짝점으로 오려 붙인 듯; 선반 물고기·개구리·병아리·동전·이불은 납작한 스티커풍; 왼쪽 위 벽에 안개 같은 얼룩(지운 흔적?).

## ④ 한 문장
혈액이 사구체에서 크기별로 걸러진 뒤 세뇨관에서 포도당·Na+는 되돌려지고(재흡수) 일부는 더 실려 나가며(분비), 이를 레닌계가 조절하고, 남는 질소 노폐물은 동물마다 암모니아·요소·요산으로 다르다.
