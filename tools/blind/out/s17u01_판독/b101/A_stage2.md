# 2단계 덱 약속으로 다시 읽기 — s17u01 (「↻」= 1단계와 달라진 곳)

## ① 판 전체 표제어
- 1순위 **배설계 — 신장(네프론)의 여과·재흡수·분비·청소율, 레닌-안지오텐신, 질소 노폐물** (90%) ↻ 80→90
- 2순위 **항상성 — 체액·혈압·삼투조절** (6%)
- 판정: 약속으로 더 잘 풀린다. 하마·요·동전·포도·소금 자루·팽팽/늘어진 줄이 약속과 그대로 맞고, 어긋난 것은 없다. 다만 구역2와 그물·파이프는 약속표에 없어 그대로 모름.

## ② 구역 (왼→오)
**구역1 (x0–600) JG장치·레닌-안지오텐신계 + 근위세뇨관**
- 푸른 천 관 = 수입세동맥→사구체→세뇨관 줄기 (자리)
- ↻ 바닥의 길게 늘어진 밧줄 = 안지오텐시노겐(늘어진 줄 = −오겐 전구체)
- ↻ 낫이 밧줄을 1번 자름 = 레닌 (칼은 K 전용이라 낫을 쓴 듯, 추정)
- ↻ 잘려서 짧고 팽팽한 토막이 못 2개에 묶임 = 안지오텐신(텐션); 못 2개 = II 꼴(개수=번호, 40%)
- ↻ 관을 조인 팽팽한 매듭 줄 = 안지오텐신의 혈관 수축
- 불룩한 창 속 흰 점박이 공 = 사구체(구멍) 또는 JG 과립 (50%)
- 노란 L홈통 = 원위세뇨관; 끝 상자 속 검은 알갱이 = 치밀반 (55%). ↻ 대안: 알도스테론(약속 '알갱이를 쓸어 도로 통에 담기'와 닮았으나 쓸어 담는 동작이 없어 20%, 억지로 안 끼움)
- 납작 코일 + 물줄기 약 12가닥 = 근위곡세뇨관 물 재흡수
- 모름: 그물 더미; 구리 파이프(이음쇠는 V자가 아니고 눈금도 없어 ADH·바사 렉타 약속과 안 맞음) ↻

**구역2 (x600–1130 아랫줄) 사구체 여과막 (알부민 차단)**
- 가시 얹은 촘촘한 울타리 = 크기·전하로 거르는 막 (담장=막 약속과 같은 결)
- ↻ 밤송이 4개가 튕겨 나옴 = 알부민 (알밤↔알부민 소리, 45%)
- 모름: 두 기둥에 다리 벌려 선 남자(발세포? 25%)

**구역3 (x660–1500 윗줄 + 비탈·빈 배) 포도당·Na⁺ 재흡수 SGLT/GLUT**
- ↻ 동글동글한 포도 = 포도당 (약속)
- ↻ 흰 소금이 보이는 자루 = Na⁺ (약속; 자루 개수=배수성 규칙은 소금이 보이므로 해당 없음)
- 짐꾼 2명: 각자 포도 상자 1 + 소금 자루 2(아래 사람 둘째 자루는 반쯤 가림) = Na⁺ 2 : 포도당 1 공동수송
- 문간 남자: 포도 상자 1만 = GLUT 촉진확산
- ↻ 부두 돌벽 = 막, 비탈 = 통로
- 모름: 빈 배, 가판 상자·자루 개수(3+1/3, 1/3)의 뜻

**구역4 (x1210–1980 아랫줄) 청소율·분비: PAH**
- ↻ 하마 = PAH (약속, 90%) ← 1단계 45%
- 하마 배의 통 약 10개 + 부두 남자가 통 1개를 더 굴려 싣기 = 여과된 뒤 분비로 더 얹힘
- 통나무 약 12개 실은 빠른 배 = 걸러져 그대로 나가는 물질(이눌린→GFR, 속도), 약속표 밖 40%
- ↻ 대안 ADH-아쿠아포린은 V자 이음쇠가 없어 버림

**구역5 (x1510–1960 윗줄) 질소 노폐물 3형**
- 수조 물고기 1 = 암모니아; 김 3줄 = NH₃ 휘발·독성 (40%)
- ↻ 물 그릇 셋 = 큰 항아리(넘침) → 단지 → 찻잔(방울 1): 물 필요량 많음→중간→거의 없음 (약속: 물 그릇은 항아리·단지)
- ↻ 요(이불) 둘 = 요소·요산 (약속). 개구리 곁 노란 요 = 요소, 알 속 흰 요 = 요산; 색 구분은 약속에 없어 동물·그릇 크기로 가름
- 알 속 병아리 = 조류·파충류 (알에 갇혀 불용성 결정으로 저장)
- ↻ 금화 약 30 = ATP (약속) — 요산 합성에 가장 많이 듦
- 좌→우 = 독성↓ · 물↓ · ATP↑

## ③ 모름 · 어색 · 헷갈림 · 흔적
- ↻ 약속표에 있으나 이 판에서 못 찾은 신장 약속: 금색 자물쇠(푸로세미드), V자 이음쇠(ADH), 눈금 자·왕복 궤도(바사 렉타), 알갱이 쓸어 담기(알도스테론), 말피기관, 칼(K), 자갈(Ca). 이 판에 안 실렸거나 내가 못 본 것.
- 모름: 그물, 구리 파이프, 두 기둥의 남자, 빈 배, 통나무 배.
- ↻ 헷갈림: 팽팽한 줄 약속과 겹치는 줄이 셋(매듭 줄·못 토막·빈 배 계류줄). 앞의 둘은 안지오텐신, 계류줄은 소품으로 봄. 알(α 후크)과 요산 알이 겹침. 얇은 갈색 줄과 굵은 크림 줄이 다름.
- 어색: 짐꾼이 시장→빈 배로 내려가 재흡수/분비 방향이 흐림.
- 흔적: 코일 한가운데 가로 이음선(원본 y≈600).

## ④ 한 문장
신장은 여과막(알부민 차단)으로 거른 뒤 포도당·Na⁺(포도·소금)를 SGLT/GLUT로 되찾고, PAH(하마)는 분비까지 되어 청소율로 기능을 재며, 레닌이 안지오텐시노겐을 잘라 안지오텐신(팽팽한 줄)이 혈관을 조이고, 동물은 노폐물을 암모니아(물↑)·요소·요산(요, ATP↑)으로 골라 버린다.
