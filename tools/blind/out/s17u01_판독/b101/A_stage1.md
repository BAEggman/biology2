# 1단계 생판 — s17u01 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **배설계 — 신장(네프론)의 오줌 생성·조절과 질소 노폐물** (80%)
- 2순위 **항상성 — 삼투조절·체액·혈압 조절(레닌-안지오텐신)** (12%)
- 이유: 왼쪽 관·사구체·코일, 낫·밧줄, 포도·소금 짐꾼, 오른쪽 선반의 물고기·개구리·알과 항아리 3개가 모두 "몸이 물·염·노폐물을 거르고 되찾고 버린다"로 모인다. 항구(물길+부두+시장)는 한 무대.

## ② 구역 (왼→오)
**구역1 (x0–600) JG장치·레닌-안지오텐신 + 근위세뇨관**
- 푸른 천 관이 프레임 위에서 내려와 불룩한 곳을 지나 코일로 이어짐 = 세동맥→사구체→세뇨관 줄기 (자리)
- 관을 묶은 밧줄 매듭 1개 = 수입세동맥 수축(GFR↓) (모양)
- 매듭 아래 불룩한 창 속 흰 점박이 공 = 사구체(구멍 많은 모세혈관 뭉치) 또는 JG세포 레닌 과립 (모양, 50%)
- 노란 L자 나무 홈통이 위에서 내려와 관 곁에 닿음 = 원위세뇨관이 사구체 곁으로 되돌아옴 (자리)
- 홈통 끝 상자 속 검고 촘촘한 알갱이 = 치밀반(dense) (뜻)
- 매듭과 상자를 잇는 밧줄 1가닥 = 치밀반이 NaCl을 재어 수입세동맥을 조이는 되먹임 (모양)
- 낫이 바닥의 긴 밧줄을 1번 자름 = 레닌이 안지오텐시노겐을 잘라 안지오텐신 I (뜻)
- 잘린 짧은 토막이 못 2개에 묶여 관 밑동에 닿음 = ACE→안지오텐신 II가 혈관을 조임 (개수 2, 40%)
- 납작한 나선 코일 + 물줄기 약 12가닥 = 근위곡세뇨관, 물이 새어 나가는 재흡수 (모양)
- 모름: 구겨진 그물 더미(모세혈관 그물?), 구리 파이프(위 프레임~물가: 수출세동맥/집합관?)

**구역2 (x600–1130 아랫줄) 여과 장벽 (선택적 통과)**
- 가시 얹힌 촘촘한 그물 울타리 = 크기·전하로 거르는 막 (모양)
- 밤송이 4개가 울타리에 부딪혀 왼쪽으로 튕김(화살표) = 큰·음전하 단백질·혈구는 못 지나감 (개수 4, 40%)
- 모름: 두 기둥을 딛고 다리 벌려 선 남자(괄약근 2개? 입·출 세동맥?), 울타리 앞 웅덩이

**구역3 (x660–1500 윗줄 + 비탈·빈 배) 포도당·Na⁺ 재흡수: SGLT/GLUT**
- 포도 = 포도당(소리), 소금 = Na⁺(뜻)
- 짐꾼 2명 각자 포도 상자 1 + 소금 자루 2(아래 사람의 둘째 자루는 반쯤 가림) = Na⁺ 2 : 포도당 1 공동수송 SGLT, 2차 능동수송 (개수)
- 문간 남자는 포도 상자 1만, 소금 0 = GLUT 촉진확산, 에너지 불필요 (개수)
- 가판: 포도 상자 3+3(+밑 1), 소금 자루 1+3 = 기질 풍부(개수의 뜻은 모름)
- 비탈을 내려가 빈 배로 = 막을 건너는 통로 (방향이 재흡수와 반대 같아 헷갈림)

**구역4 (x1210–1980 아랫줄) 청소율·분비 (낮은 확신)**
- 통나무 약 12개 실은 배가 물살을 가르며 빠르게 = 걸러져 그대로 나가는 물질(이눌린→GFR, 속도) (뜻, 40%)
- 하마 + 통 약 10개 = 마뇨산 PAH(河馬↔馬尿酸, 소리), 여과+분비로 한 번에 비워짐 (45%)
- 부두 남자가 통 1개를 널빤지로 굴려 하마 배에 더 실음 = 세뇨관으로의 분비 (뜻)
- 대안: 통 = 아쿠아포린(ADH 물 재흡수) (30%)

**구역5 (x1510–1960 윗줄) 질소 노폐물 3형**
- 수조 속 물고기 1마리 = 암모니아(수생); 수조 위 김 3줄 = NH₃ 휘발·독성 (40%)
- 넘치는 큰 항아리 = 암모니아는 물이 가장 많이 듦 (크기)
- 개구리 + 노란 누비이불(요) 덮은 통 = 요소(소리 요, 양서류·포유류) (60%); 중간 항아리 = 물 중간
- 알 속 병아리 + 흰 누비이불(요)이 뾰족한 받침(산?) 위 = 요산, 조류·파충류, 알 속 불용성 결정으로 저장 (소리·뜻)
- 알 곁 금화 약 30개 = 요산 합성에 에너지 가장 많이 (개수)
- 찻잔 + 물방울 1개 = 물 거의 안 씀 (크기)
- 좌→우 = 독성↓ · 물↓ · 에너지↑ (자리)

## ③ 모름 · 어색 · 헷갈림 · 이어 붙인 흔적
- 모름: 그물 더미, 구리 파이프, 두 기둥의 남자, 빈 배, 통나무 배.
- 어색: 짐꾼이 시장에서 빈 배 쪽으로 내려감(재흡수라면 거꾸로여야). 큰 항아리 물이 부두 가장자리로 흘러 하마 배 비탈로 이어져 보임.
- 헷갈림: 밧줄이 둘(매듭·되먹임 밧줄 / 낫이 자른 밧줄); 누비이불이 둘(노랑·하양); '통'이 둘(개구리 곁 통 / 하마 배 통).
- 이어 붙인 흔적: 코일 한가운데를 가로지르는 곧은 가로 이음선(원본 y≈600), 윤곽선이 어긋남. 왼쪽 관·그물의 먹선이 더 굵고 거칠어 오른쪽과 결이 다름. 선반(물고기·개구리·알)은 부두 시장 위에 얹힌 듯함.

## ④ 한 문장
신장은 혈액을 걸러(여과) 포도당·Na⁺·물은 되찾고(재흡수) 필요 없는 것은 더 내보내며(분비), JG장치(레닌-안지오텐신)가 이를 조절하고, 동물은 질소 노폐물을 물 많이 드는 암모니아에서 물 아끼는 요산까지 환경에 맞게 골라 버린다.
