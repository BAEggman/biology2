# stage2 - s17u03 약속표로 다시 읽음 (↻ = 1단계와 달라진 곳, #=약속 번호)

판정: 약속표로 훨씬 잘 풀린다. 1단계 「모름」 대부분이 풀리고 오독 넷(사구체·렌치·삽입판2·구리관)을 고쳤다. 큰 틀(신장·오줌 농축·ADH)은 유지. 약속표에 없는 것은 끼우지 않았다.

## ① 판 표제어 ↻
- 1순위 **집합관과 오줌 농축: ADH(V·아쿠아포린)·알도스테론(주세포)·사이세포(산/염기)·바깥 소금 기울기·요소·바사 렉타** (85%) ↻ 65에서 올림, 요붕증은 「다른 날」 칸으로 내림
- 2순위 **헨레고리·바사 렉타 대향류 기울기** (8%)

## ② 구역별 (7구역 ↻ 윗줄을 둘로 쪼갬)
**구역1 윗줄 왼쪽 패** 표제어 **주세포: 알도스테론이 와야 소금을 건지고 K+를 내보냄** ↻
1. 체 든 소년이 알갱이를 걸러 흰 소금 보이는 자루에 담음 = Na+ 건져 들임, 알갱이를 도로=알도스테론 (#33·#111) ↻ 사구체 철회
2. 체의 쇠사슬과 바닥의 검은 쇠자물쇠 = 멀리서 신호가 와야 풀림 (#149) ↻
3. 먼지 망토·진흙 장화 소년의 큰 열쇠 1 = 다른 샘(부신)에서 온 것 (#149) ↻ 렌치 철회
4. 로마 투구+칼을 물(관강)에 꽂음 = ROMK, K+ 분비 (#141·#3) ↻ 약에서 확실로
5. 사슬 곁 파란 방울 3 = 방금 물에서 건짐 (#140, 약, 3은 모름) ↻

**구역2 윗줄 가운데 패** 표제어 **사이세포: α는 산(H+), β는 염기(HCO3-)를 쏟음** ↻
1. 흰 알 1(곁에 레몬) = α 사이세포 (#49·#154) ↻
2. 레몬 6조각 = 산 H+ (#154)
3. 흰 베 두루마리 1(곁에 분필) = β 사이세포 (#49·#154) ↻
4. 상자에서 쏟아지는 흰 분필 약 15 = 염기 HCO3- (#154) ↻
5. 두 패가 한 관의 둑에 나란히 = 같은 벽의 다른 세포 (#156) ↻

**구역3 삽입판1** 표제어 **ADH가 오지 않은 날** ↻
1. 틀선 칸 = 같은 장면의 다른 날 (#118) ↻
2. 속 빈 V 홈 2 = 오지 않은 날, 물길 자리 1+가루 문 자리 1 (#7) ↻
3. 관 속 물이 위아래 모두 옅음 = 농축 안 됨 (#145)
4. 소금 더미 그대로 = 소금 퍼내기·기울기는 정상 (#150)
5. 넘치는 항아리 = 오줌량 많음 (#153)
6. 요 반쯤 묻힘 = 요소 (#9)
7. 가루 문 자리를 흰 소금이 덮고 물실도 없음 = 닫힌 문 (#155) ↻

**구역4 삽입판2** 표제어 **푸로세미드(루프 이뇨제)가 소금 퍼내기를 막은 날** ↻ 신성 요붕증 철회
1. 금색 자물쇠 1이 톱니 기계 손잡이에 = 막는 약 (#2) ↻
2. 소금 더미 없음 = 바깥 기울기 소실 (#157)
3. V 2 꽂혀 있음 = ADH는 왔는데도 못 농축 (#7) ↻
4. 옅은 물 + 넘치는 항아리 = 묽은 오줌 많음 (#145·#153)
5. 요가 벽에 걸려 비어 있음 = 요소가 맴돌 자리 없음 (#9·#155, 약)
6. 가루 문에서 노란 가루만 샘 (#155, 약)

**구역5 중앙** 표제어 **굵은 상행각이 만든 소금 껍질 위에서 집합관이 ADH로 농축** ↻
1. 역청 이음매 나무통 + 벽의 톱니 기계(기어 3) = 물은 못 내보내고 소금만 퍼내는 구간 (#157·#146·#147) ↻
2. 퍼낸 소금이 이웃 관 바깥 껍질로, 위 얇고 아래 두꺼움 = 깊을수록 짜짐 (#150) ↻
3. 네모 관(오줌길)의 물빛 위 옅음에서 아래 진함 = 관 속 농도 (#133·#145)
4. 벽에서 껍질로 빨려 드는 가는 파란 물실 1 = 바깥이 당겨 나가는 물 (#150) ↻
5. 큰 V 둘 = ADH, 위는 물길·아래는 가루 문 (#7) ↻
6. 맨 아래 작은 문의 누런 가루가 요로 배어듦 = 가장 깊은 곳에서만 요소가 나가 맴돎 (#155·#9) ↻
7. 깔때기·가는 줄기·속 빈 항아리 = 오줌량 적음 (#153)
8. 통 속 얇은 물 = 못 빠져나감 (약)

**구역6 오른쪽 방** 표제어 **주세포 한 칸: 아쿠아포린 창과 Na+-K+ 펌프** ↻
1. 관 벽에 붙은 방 = 소금 건지고 칼 꽂는 패의 식구 (#156) ↻
2. 널빤지 벽 = 관강막, 열린 뒷문 = 기저외측막 (#134) ↻ 문 해소(약)
3. 회 바른 붙박이 창 윗줄 3·아랫줄 4 = 늘 있는 길 AQP3·4 (#151, 중) ↻ 넷째 창 가림 철회
4. 수레로 와 끼워지는 창 2(손 1·수레 1) = 와야 끼워지는 AQP2 (#151) ↻
5. 네 쪽 창을 한 줄씩 지나는 청록 물방울 4줄 = 넷이 모인 한 길 (#151) ↻
6. 창 곁 작은 V 1 = ADH가 와야 열리는 길 (#7)
7. 동전 투입구 크랭크 펌프 = Na+-K+ 펌프(ATP) (#148·#8) ↻ 모름 해소 (소금 셋·칼 둘은 안 보임)
8. 물방울이 둥근 관(핏줄)으로 = 되찾은 물 (#133) ↻
9. 방 밑 소금 껍질 (#150)

**구역7 구리관** 표제어 **바사 렉타: 기울기를 지키기만 하는 역류교환** ↻ 헨레고리 철회
1. 둥근 구리관 둘(왕복) + 눈금 자 1 = 바사 렉타 (#6·#77) ↻
2. 둥근 관 = 핏줄 (#133)
3. 유리 구 셋 맑음-뿌옇음(맨 아래 결정)-맑음 = 내려가며 받고 올라오며 도로 놓음 (#152) ↻
4. 만들지 않고 지키기만 함 (#6) ↻

## ③ 모름·어색·이은 흔적
- 약속표에 없어 모름: 왼쪽 거품 급류, 레몬 6·분필 약 15·기어 3의 개수, 깔때기 양쪽 나무판, 병사 파문 2겹, 오른쪽 소금 껍질의 S자 허리. 바닥 낟알은 자갈 아닌 소금알로 봄.
- 헷갈림: 열린 문이 뒷문인지 통로인지, 창 번호 읽기(3·4·2).
- 이은 흔적: 윗줄 x≈1190 이음선과 가운데 패 물 패치, 수직관 속 연한 직사각 덧댐, 구리관 굵기 차, 방 바닥 패치와 셋째 창 아래 남은 갈색 틀 조각, 삽입판1 문 자리 흰 직사각 덮개 ↻, 오려 붙인 인물·V·자물쇠·동전.

## ④ 한 문장
오줌이 진해지려면 굵은 상행각이 퍼낸 바깥 소금 기울기와 ADH(V)가 둘 다 와야 하고(하나 빠진 날은 항아리가 넘침), 같은 관 벽에서 주세포는 알도스테론으로 소금을 건지며 K+를 내보내고 사이세포는 산·염기를 쏟는다.
