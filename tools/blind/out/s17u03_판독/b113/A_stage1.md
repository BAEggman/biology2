# stage1 - s17u03 생판 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위 **신장(콩팥)의 오줌 농축: 수질 삼투 기울기 + ADH(항이뇨호르몬) -> 물 재흡수 / 요붕증** (65%)
- 2순위 **삼투조절·수분 항상성(막을 통한 물 이동: 아쿠아포린·능동수송)** (15%)
- 그 밖: 효소 반응속도(V) 8%, 산염기 완충 4%
- 근거: 항아리(~항이뇨), V(바소프레신), 위->아래로 진해지는 수직관, 소금 더미, 창문=물 통로, 아래서 만나는 U자 관.

## ② 구역별 (왼쪽 끝 기준 6구역)

**구역1 위 수로 띠와 선반 (x 30~1190, 윗줄)** 표제어 **세뇨관을 따라 일어나는 일: 여과(사구체->보먼주머니)·재흡수·분비**
1. 체(sieve) 든 소년 + 쇠사슬 + 끝의 검은 고리/공 = 사슬+구+체 = 사구체 -> 여과 (소리·모양, 중상)
2. 체를 빠져나온 흰 가루가 자루로 = 작은 용질만 여과, 자루 = 보먼주머니 (뜻, 중)
3. 맨 왼쪽 거품 낀 급류 = 높은 압력으로 걸러짐 (모양, 약)
4. 렌치 든 외투 소년 = 렌치~레닌? 사구체 곁이라 방사구체세포? (소리, 약)
5. 로마 병사가 칼을 물에 꽂아 파문 2겹 = 칼~칼륨(K+) 분비? (소리, 약)
6. 레몬 6조각(반쪽 5+통 1, 둘은 물속에서 튐) = 신맛=산(H+) 분비? (뜻, 약)
7. 달걀 1(물에 안 들어감) = 알부민은 안 걸러짐? 또는 hen+레몬=헨레? (소리, 약)
- 모름: 사슬의 파란 방울 3, 두루마리 1, 상자에서 쏟아지는 흰 막대 약 15(낙하 4)

**구역2 삽입판1 (x 130~440)** 표제어 **중추성 요붕증: ADH 없음**
1. 속이 비치는 유령 V 2개 = ADH(바소프레신) 없음 (모양·개수)
2. 항아리가 넘쳐 바닥에 물웅덩이 = 묽은 오줌 다량(다뇨)=요붕증 (뜻)
3. 관 전체가 옅은 청록 = 농축 안 됨 (모양)
4. 소금 더미는 멀쩡 = 기울기·펌프는 정상 (자리)
5. 자물쇠 없음 = 펌프 작동 (뜻)
6. 노란 누비 방석(요) 반쯤 소금에 묻힘 = 요소가 기울기에 한몫 (소리 요=尿素)

**구역3 삽입판2 (x 475~780)** 표제어 **펌프가 잠겨 기울기 없음(신성 요붕증 또는 루프이뇨제형)**
1. 크랭크 곁 금색 자물쇠 1 = 펌프 차단 (뜻)
2. 소금 더미 전혀 없음 = 삼투 기울기 소실 (자리)
3. V 2개가 진짜 모양 = ADH는 충분 (개수)
4. 항아리 넘침·튐 = 다뇨 (뜻)
5. 방석이 벽에 걸려 안 쓰임 = 요소 기울기도 없음 (자리)

**구역4 중앙 장치 (x 830~1270)** 표제어 **헨레고리 대향류 증폭과 오줌 농축**
1. 톱니바퀴 3 + 손잡이 1 + 홈통 = 능동수송 펌프가 소금을 퍼냄 (모양)
2. 흰 소금 더미 = NaCl로 수질 간질액이 고삼투 (뜻)
3. 더미가 아래로 갈수록 두껍고 넓음 = 깊을수록 진함 (자리)
4. 나무통(안 새는) 속 얇은 물 = 상행지는 물 불투과·묽어짐 (모양, 약)
5. 투명 수직관: 위 옅음->아래 진한 청록 = 하행지는 물이 빠지며 농축 (모양)
6. 더미 쪽으로 새는 파란 물결선 1 = 삼투로 물 이동 (모양)
7. 노란 누비 방석 1 = 요소 (소리 요)
8. 벽의 작은 문 + 노란 가루 = 요소 수송체 (모양, 약)
9. 큰 V 2 (하나는 더미 꼭대기 높이, 하나는 깔때기 곁) = ADH가 집합관에 작용 (소리)
10. 깔때기 -> 가는 줄기 -> 항아리 1 = 소량의 진한 오줌 (모양)

**구역5 오른쪽 방 (x 1270~1640)** 표제어 **ADH -> 아쿠아포린 삽입 -> 집합관 물 재흡수**
1. 남자 1명이 벽에 창문을 끼움 = 창=물 통로(아쿠아포린) 삽입, ADH 작용 (뜻)
2. 바퀴 2짜리 손수레에 창문 1 = 소낭으로 운반 (뜻, 약)
3. 뒷벽 창문 7개(윗줄 3+아랫줄 4, 윗줄 넷째는 잘려 가려짐) = 막의 아쿠아포린 다수 (개수)
4. 오른쪽 아래 창 위 작은 v 1 = ADH 신호 (소리)
5. 그 창에서 오른쪽 관으로 가는 물방울 4줄(줄당 약 19) = 물이 세포를 지나 혈관으로 (모양)
6. 방 밑으로 쏟아지는 흰 소금 = 수질의 고삼투 (자리)
- 모름: 검은 손펌프 + 위의 노란 구슬, 열린 문

**구역6 맨 오른쪽 구리관 (x 1650~1800)** 표제어 **수질 삼투압 기울기(300->1200)와 직세혈관 U자**
1. 구리관 2개가 아래 구에서 합쳐짐 = 헨레고리·직세혈관 U자 (모양·개수)
2. 유리구 3(작->중->큼) = 깊이별 농도 증가 (자리)
3. 맨 아래 구에만 소금 결정 = 가장 진함 (뜻)
4. 눈금자 1 = 깊이/긴 고리일수록 더 농축 (뜻, 약)

## ③ 모를 것·어색한 것·이은 흔적
- 달걀·두루마리·막대 상자·렌치·로마 병사가 나르는 사실을 모름.
- V가 ADH인지 속도 v인지 헷갈림. 삽입판2의 자물쇠가 펌프 차단인지 수용체 불응인지 헷갈림. 노란 방석이 요소(요)인지 완충(쿠션)인지 헷갈림.
- 삽입판1만 V가 반투명, 나무통 위 물도 본판에만 있음. 오른쪽 소금 더미가 모래시계처럼 S자로 꼬임.
- 이은 흔적: 윗줄 x≈1190 수직 이음선과 직사각 물 패치, 수직관 속 연한 직사각 덧댐, 구리관 위·아래 굵기 달라짐, 방 바닥의 직사각 패치와 잘린 넷째 창, 인물·레몬·V·자물쇠·물방울은 스티커처럼 오려 붙인 느낌.

## ④ 한 문장
오줌이 진해지려면 수질의 소금·요소 기울기(펌프)와 ADH(V)가 둘 다 있어야 하고, 하나라도 빠지면 항아리가 넘치는 묽은 오줌(요붕증)이 된다.
