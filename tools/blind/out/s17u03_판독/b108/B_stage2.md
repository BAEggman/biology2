# 2단계 약속표로 다시 읽기 (s17u03) — 「↻」는 1단계와 달라진 곳

## ① 판 전체 표제어
- **1순위: 집합관의 기능(알도스테론·ADH 조절, 주세포·개재세포 수송, 수질 기울기와 요 농축)** — 90% ↻(1단계 60%, '요 농축'만 보던 것이 집합관 전체로 넓어짐)
- **2순위: 요 농축 기전(대향류 증폭·요소 재순환·직세혈관)** — 6%
- 판정: 약속으로 훨씬 잘 풀린다. 「모름」 5건(병사·막대·휴지·문·체크)이 풀렸고 오독 5묶음(체=여과, 달걀·레몬=여과 선택성, U자관=헨레고리, 기계=능동펌프, 항아리=방광)이 바로잡혔다. 맞았던 것: V=ADH, 이불, 쪽문, 물실, 소금 껍질, 물빛, 창, 펌프.

## ② 구역(왼쪽부터)
**구역1 수로 상류 — 주세포: 알도스테론·ROMK [5]** ↻(표제어 '여과(체)')
1. 네모 나무 수로 = 세뇨관 관강(#133).
2. 체로 알갱이(흰 소금 자루=Na⁺)를 건져 자루에 담는 사람 = 알도스테론, Na⁺ 재흡수(#33·#111) ↻ '여과' 오독.
3. 체에 감긴 쇠사슬의 검은 쇠자물쇠 = 호르몬이 와야 풀리는 일(#149).
4. 먼지 망토·진흙 장화 나그네의 큰 열쇠 = 멀리 다른 샘(부신피질 등)에서 온 신호(#149) ↻ '수용체 열쇠'에서 좁힘.
5. 로마 투구+칼(칼끝이 물에) = ROMK, K⁺를 관강으로(#141·#3) ↻ 모름→풀림.

**구역2 액자① — ADH 없는 날 [5]**
1. 틀선 칸 = 같은 장면의 다른 날, 큰 장면이 정상(#118).
2. V자 이음쇠·쪽문·물실이 사라짐 = ADH 없음(#7), 바뀐 것은 그 하나(#126).
3. 소금 껍질·요 이불·돌아가는 톱니 기계는 그대로 = 기울기는 있음(#150·#9·#147).
4. 옅은 물빛 = 관 속 농도 낮음(#145).
5. 굵은 줄기·넘치는 항아리 = 관 끝에서 나오는 양 많음(#153) ↻ '방광·다뇨'를 '양'으로.

**구역3 액자② — 루프 이뇨제를 쓴 날 [5]**
1. 금색 자물쇠가 톱니 기계에 = 공동수송체를 막는 약, 푸로세미드형(#2·#147) ↻ '펌프 억제'→약.
2. 소금 껍질 없음·이불은 벽에 걸림 = 기울기 소실(#150·#9).
3. V자 이음쇠 있음 = ADH는 있음(#7).
4. 옅은 물빛(#145). 5. 넘치는 항아리(#153) = ADH가 있어도 묽고 많음.

**구역4 수로 중류 — 개재세포: H⁺·HCO₃⁻ 분비 [5]** ↻(표제어 '여과 선택성')
1. 흰 알 = α(#49). 2. 노란 레몬 = 산 H⁺(#154) → α개재세포.
3. 흰 베 두루마리 = β(#49). 4. 흰 분필 토막 = 염기 HCO₃⁻(#154) → β개재세포 ↻ 휴지·막대 모름이 풀림.
5. 물로 떨어짐 = 관강으로 분비.

**구역5 가운데 기계·물기둥·항아리 — 수질 기울기와 ADH의 요 농축 [9]**
1. 이음매마다 새까만 역청을 메운 나무 상자 = 물 불투과 벽(#146) ↻ 새로 읽음.
2. 벽에 박힌 톱니 기계(동전 없음) = 짐을 묶어 나르는 공동수송체(#147) ↻ '능동 펌프'.
3. 위는 얇고 아래로 두꺼운 흰 소금 껍질 = 깊을수록 짜지는 관 바깥(#150).
4. 아래쪽을 덮은 노란 요 이불 = 요소(#9).
5. 한 자리에만 뚫린 작은 문에서 누런 가루가 이불로 배어듦 = 요소가 나가는 한 자리(#155).
6. 흰 블록 V = ADH(#7).
7. 관 벽에서 나와 소금 껍질에 빨려 드는 파란 물실 = 바깥이 당겨 나가는 물(#150).
8. 위는 옅고 아래는 진한 청록 물 = 내려갈수록 농도 ↑(#145).
9. 가는 줄기·속 빈 항아리 = 관 끝 양 적음(#153) ↻ '방광'.

**구역6 방 — 아쿠아포린·기저외측막·Na⁺-K⁺ 펌프 [8]**
1. 십자가 유리를 넉 쪽으로 가른 창 + 쪽마다 한 줄 청록 물방울 = 넷이 모인 하나의 길(#151) ↻ 4량체 확정.
2. 회 바른 붙박이 창 위 3 = AQP3. 3. 아래 4 = AQP4(늘 있는 것, #151).
4. 수레에 실려 와 지금 끼우는 창 둘(남자 손 1+수레 1) = AQP2, ADH가 와야 끼워짐(#151).
5. 열린 뒷문 = 기저외측막(#134) ↻ 모름→풀림.
6. 벽의 얇은 흰 체크(관 꼴 V) = V자 이음쇠 = V2 수용체(#7) ↻ 모름→풀림.
7. 동전 투입구 달린 크랭크 펌프 = Na⁺-K⁺ 펌프, ATP 사용(#148; 소금 셋·칼 둘은 안 그려짐).
8. 방 밑 소금 껍질 = 바깥 소금(#150).

**구역7 구리 왕복관·눈금 자 — 바사 렉타 [4]** ↻(표제어 '헨레고리')
1. 둥근 구리관이 홀로 곧게 내려갔다 되올라옴 = 직세혈관, 둥근 관=핏줄(#6·#133).
2. 곁의 눈금 자 = 바사 렉타(#77).
3. 유리 구 셋(맑음→뿌옇음→맑음) = 내려가며 받고 올라오며 도로 놓음(#152) ↻ '삼투농도 눈금' 오독.
4. 실어 내는 것이 없다 = 기울기를 만들지 않고 지키기만(#6).

## ③ 풀리지 않은 것·어색함·헷갈림·이은 흔적
- 끝내 모름(표에 없음): 깔때기 곁 작은 흰 레버(눕힌 V꼴, V와 함께 나타남), 수로 시작 상자의 흰 거품, 칼끝 곁 가는 실. 알갱이·고리·레몬·분필·톱니·눈금의 개수는 센다는 약속이 없어 뜻을 두지 않음. 표의 티백·자갈·성냥·하마는 이 판에 없음.
- 어색: 지하실의 누비 이불, 방 밖 벽의 펌프, 방 바닥선에서 잘려 쏟아지는 껍질.
- 헷갈림: 금 자물쇠(약) vs 검은 자물쇠(호르몬), 흰 V 셋(굵은 V·얇은 체크·눕힌 레버), 노란 것 셋(레몬 H⁺·이불 요소·금 자물쇠 약), 둥근 구리관(핏줄) vs 네모 나무관(세뇨관).
- 이은 흔적: 액자 테두리, V 뒤 직사각 나무판, 방 밑 껍질의 직선 윗변, 옅은/진한 물의 수평 경계.

## ④ 한 문장
집합관에서는 먼 샘의 열쇠(알도스테론·ADH)가 와야 Na⁺와 물이 건져지고(K⁺·H⁺·HCO₃⁻는 관강으로 내보냄), 오줌이 진해지려면 톱니 기계가 쌓은 소금 껍질(+요소 이불)과 ADH로 열린 물길이 함께 있어야 하며 직세혈관은 그 기울기를 지키기만 한다.
