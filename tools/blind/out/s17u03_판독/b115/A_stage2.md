# stage2 약속표로 다시 읽기 (s17u03)

## 판정
약속으로 훨씬 잘 풀림. 큰 틀(콩팥·농축·ADH)은 그대로, 「모름」 대부분이 풀리고 오독 3곳(체·구리관·쇠띠)을 고침(↻). 약속에 없는 것은 모름으로 둠. (약N = 약속표 N번)

## ① 판 전체 표제어
- 1순위 **원위세뇨관~집합관의 조절과 오줌 농축 (주세포·사이세포, 알도스테론·ADH, 수질 기울기·요소 재순환·직세혈관)** 85% ↻(45→85)
- 2순위 **오줌의 농축·희석 (역류증폭·삼투조절)** 10%
- 근거: V=ADH(약7), 금색 자물쇠=막는 약(약2), 요=요소(약9), 눈금 자 왕복관=직세혈관(약6), 틀선 칸=다른 날(약118), 항아리 물높이=나오는 양(약153).

## ② 구역별 (왼→오른)
**구역1 선반 왼쪽 세 사람 — 주세포: 알도스테론(Na+ 되찾기)·K+ 내보내기 (약156)** ↻
- 체로 알갱이를 건져 도로 자루에 담는 남자 = 알도스테론 (약33) ↻(여과→알도스테론)
- 흰 소금 보이는 자루 1 = Na+ (약111 꼴, 1은 추정)
- 체에 감긴 쇠사슬 + 검은 자물쇠 = 먼 데서 신호가 와야 풀리는 일 (약149) ↻
- 먼지 망토·진흙 장화 소년 + 큰 열쇠 = 먼 샘에서 온 호르몬, 고리가 열린 날 (약149) ↻
- 사슬에서 떨어지는 물방울 = 방금 건져 올림 = 재흡수 늘림 (약140) ↻
- 로마 투구 + 곧은 칼을 물에 꽂음 = ROMK, K+를 관강으로 (약141·3) ↻

**구역2 왼쪽 아래 액자 두 장 — 같은 장면의 다른 날(대조) (약118·126)**
- 틀선 칸 = 다른 조건, 칸 밖 큰 장면이 정상 ↻
- 액자1: V 자리가 점선 빈 꽂이 = ADH 오지 않은 날 (약7) ↻
- 액자1: 물빛 옅고 굵은 줄기, 넘치는 항아리 = 묽은 오줌 다량 (약145·153)
- 액자2: 톱니 기계 손잡이 자리의 금색 자물쇠 = 막는 약(루프 이뇨제) (약2) ↻
- 액자2: 소금 껍질 없음 = 기울기 소실, V는 실선인데도 묽음 ↻
- 같은 항아리·기둥에 하나씩만 다름 = 한 가지만 바꾼 대조 (약126) ↻

**구역3 선반 가운데 물건 — 사이세포: 산 쏟는 α형 / 염기 쏟는 β형 (약156)** ↻
- 노란 레몬(6조각, 2조각 물에 닿음) = 산 H+ (약154)
- 흰 알(달걀 1) 곁의 레몬 = α형 (알=α, 약49·154) ↻
- 흰 베(두루마리) = β (약49) ↻
- 베 곁 상자에서 쏟아지는 흰 분필 토막 = 염기 HCO3− (약154) ↻
- 서로 다른 두 패 = 같은 벽의 다른 세포 종류 (약156) ↻

**구역4 가운데 큰 장면 — 수질: 소금 껍질 기울기·ADH 길·요소 재순환**
- 검은 역청 띠로 이은 통 + 톱니 기계 = 물은 못 내보내고 소금만 퍼내는 상행각 굵은 구간 (약157·146) ↻(쇠띠→역청)
- 톱니 3 = 소금 셋을 묶어 나르는 공동수송체 (약147·157)
- 널을 타고 나가는 알갱이 → 이웃 관 바깥의 소금 껍질 (약157)
- 껍질 위 얇고 아래 두꺼움 = 깊을수록 짠 바깥 (약150)
- 파란 물실 타원 = 바깥이 당겨 나가는 물 (약150) ↻
- 수갱 물빛 위 옅고 아래 짙음 = 관 속 농도 (약145)
- V 위 = ADH가 와야 열리는 물길 (약7)
- V 아래 + 맨 아래 쪽문 = ADH가 와야 열리는 요소 문 (약7·155) ↻
- 노란 요 + 문에서 배는 누런 가루 = 요소, 가장 깊은 자리에서만 (약9·155) ↻
- 바닥의 누런 가루 자취 = 왼쪽 앞 장 고리로 돌아와 맴돎(재순환) (약155) ↻
- 깔때기·가는 줄기·속 빈 항아리 = 나오는 양 적음 (약153)

**구역5 오른쪽 방 — 주세포 한 칸 (약156)** ↻
- 관과 맞붙은 널빤지 벽 = 관강막 (약134) ↻
- 뒷문 = 기저외측막 (약134) ↻
- 손수레로 와 지금 끼우는 창틀 둘(손 1 + 수레 1) = 와야 끼워지는 AQP2 (약151) ↻
- 회 바른 붙박이 창 윗줄 3 = AQP3 (약151) ↻
- 회 바른 붙박이 창 아랫줄 4 = AQP4 (약151) ↻
- 유리 넉 쪽 + 쪽마다 한 줄 청록 물방울 = 넷이 모인 하나의 길 (약151) ↻
- V = ADH(V2), 핏줄 쪽 벽에 꽂힘 (약7)
- 동전 얹은 크랭크 손펌프 = Na+-K+ 펌프 (약148·8) ↻

**구역6 맨 오른쪽 — 직세혈관: 기울기를 지키기만 (약6·77)** ↻
- 곧게 내려가고 되오르는 구리 왕복관 + 눈금 자 = 직세혈관 ↻(헨레고리→직세혈관)
- 유리 구 셋(맑음→뿌옇음→맑음) = 내려가며 받고 올라오며 도로 놓음 (약152) ↻
- 구 속 흰 결정·물빛 = 깊을수록 농도 짙음 (약145)

## ③ 모름·이음
- 약속표에 없어 모름: 물방울 개수 3, 칼 곁 풀잎, 자루 곁 흰 홈통, 방 아래 두 번째 껍질의 자리 뜻, 톱니 기계 크랭크, 막대·레몬 개수.
- 어색: 칼이 주사침처럼도 보임(투구+곧은 날이라 칼), 금색 자물쇠 고리가 반쯤 열린 듯함.
- 이음 흔적(1단계와 같음): x≈1190 수로 이음, 레몬~상자 패치, 물기둥 위 직사각, 방 펌프·문 둘레 잔상, 액자 둘, 오른쪽 위 벽 x≈1830.

## ④ 한 문장
위 수로에서 주세포(알도스테론이 Na+를 건지고 ROMK가 K+를 내보냄)와 사이세포(산·염기를 쏟음)를 거친 관액이, 소금 펌프가 만든 깊을수록 짠 껍질 곁을 내려갈 때 ADH(V)가 와서 물길(AQP2)과 요소 문을 열어야 진한 오줌이 조금 나오고, V가 안 오거나 펌프를 약으로 막으면 묽은 오줌이 넘친다.
