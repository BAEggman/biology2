# stage2 — 약속표로 다시 읽기 (「↻」= 1단계와 달라진 곳)

## 판정
약속표로 **훨씬 잘 풀린다.** 모름이던 병사·나그네·검은 자물쇠·이불·V·창 개수·기둥 띠·펌프가 풀렸고, 구역6은 1단계 오독(헨레고리)을 바로잡았다. 끝내 안 풀림(약속표에 없음): 톱니 3, 레몬 6, 물방울 4의 개수, 홈통·깔때기.

## ① 판 표제어
- **1순위: 신장의 소변 농축·희석 — 상행지 NaCl 수송 → 수질 기울기 → 집합관 ADH·요소·아쿠아포린, 바사 렉타가 기울기 보존** (75%) 「↻」확신↑
- **2순위: 원위부(주세포·개재세포)의 이온·산염기·호르몬 조절** (15%) 「↻」

## ② 구역 (왼→오)
**구역1 · 왼쪽 위 둑 — 먼 호르몬이 풀어 주는 Na⁺ 길 + ROMK** 「↻」
1. 소금 체를 건져 올리는 사람 + 소금 자루 1 = Na⁺ 재흡수 (뜻·모양; 자루 수의 뜻은 불확실)
2. 「↻」 체에 감긴 쇠사슬의 검은 쇠자물쇠 + 열쇠 든 나그네(먼지 망토·진흙 장화) = 먼 곳 호르몬이 와야 풀리는 일 (#149 · 금색 자물쇠=약과 다름)
3. 「↻」 로마 투구 + 곧은 칼을 꽂는 병정 = ROMK(K⁺를 관강으로 내보냄) (소리·모양, #141·#3)
4. 청록 물방울 4 = 방금 건진 물(#140) — 개수 뜻 「모름」

**구역2 · 비교 컷 2장 — 대조: ADH 없음 vs 루프이뇨제, 둘 다 묽은 소변 다량** 「↻」
1. 「↻」 틀선 칸 = 같은 장면의 다른 조건, 큰 그림이 정상 (#118)
2. 컷1: V 없음 → 물실·문 없음, 옅은 물, 넘치는 항아리 = ADH 없으면 농축 못함 (#7·#153)
3. 「↻」 컷2: 금색 자물쇠 걸린 톱니 기계 = 루프이뇨제(푸로세미드)가 NKCC2를 막음 (#2·#147)
4. 컷2: 소금 껍질 없음·이불은 바닥에 = 수질 기울기(NaCl·요소) 소실 (#150·#9)
5. 컷2: V가 있어도 넘침 = 기울기가 없으면 ADH도 소용없다

**구역3 · 둑 가운데 — 집합관 개재세포 α·β** 「↻」(1단계 「모름」→풀림)
1. 「↻」 흰 알 + 곁의 레몬 = α형이 H⁺(산) 분비 (알=α #49·#154)
2. 「↻」 베(옷감) 말이 + 곁의 흰 분필 토막(상자에서 쏟아짐) = β형이 HCO₃⁻(염기) 분비
3. 둑 → 강으로 떨어짐 = 관강으로 분비 (자리). 레몬 6조각의 개수는 「모름」

**구역4 · 큰 수직관 — 상행지가 쌓은 기울기 + ADH·요소로 농축뇨**
1. 「↻」 역청 띠 기둥 = 물 불투과 벽(상행지) (#146)
2. 「↻」 벽에 박힌 톱니 기계 + 홈통의 소금 = 공동수송체(NKCC2)가 NaCl을 바깥으로 (#147)
3. 「↻」 관 바깥 소금 껍질(위 얇고 아래 두꺼움) = 깊을수록 짠 수질 (#150)
4. 「↻」 굵은 V 옆, 벽에서 껍질로 빨려 드는 물실 = ADH가 연 길로 바깥이 물을 당김
5. 물기둥 옅음→진함 = 관 속 농도 증가 (#145)
6. 「↻」 한 자리 작은 문 + 누런 가루 → 누런 요 + 얇은 V = ADH로 말단에서만 요소가 수질로 (#155·#9)
7. 깔때기→가는 진한 줄기→속 빈 항아리 = 소량 농축뇨 (#153)
8. 네모 나무 관 = 세뇨관(#133)

**구역5 · 방 — 주세포: AQP2·3·4, V2, Na⁺-K⁺ 펌프** 「↻」
1. 4칸 창 = 아쿠아포린(넷이 모인 길) (#151)
2. 「↻」 손수레로 와 널벽(관강막)에 끼워지는 창 2 = AQP2, ADH가 와야 끼움
3. 「↻」 회 바른 붙박이 위 3 = AQP3
4. 「↻」 붙박이 아래 4 = AQP4 (뒷벽 = 기저외측막)
5. 「↻」 뒷벽의 V = ADH·V2 수용체
6. 「↻」 동전 얹은 크랭크 펌프 = Na⁺-K⁺ 펌프(ATP) (#148·#8)
7. 「↻」 뒷문 = 기저외측막 (#134)
8. 창마다 한 줄 지나는 청록 점 = 물 통과

**구역6 · 구리 U관 + 눈금 자 — 바사 렉타** 「↻」정정(헨레고리 아님)
1. 홀로 곧게 내려갔다 오르는 둥근 관 = 바사 렉타(핏줄, #6·#133)
2. 눈금 자 = 바사 렉타 (recta=곧다, #77)
3. 구 3(맑음→뿌옇음→맑음) = 내려가며 받고 올라오며 도로 놓음, 기울기 보존 (#152)

## ③ 잔여
- 뜻 「모름」: 톱니 3·레몬 6·물방울 4의 개수, 깔때기 널 2, 방 뒤 작은 창
- 헷갈림: 금색(약) vs 검은 자물쇠(열쇠), 둥근 구리관 vs 네모 나무관, 붙박이 창 vs 끼우는 창, 요 vs 소금 껍질
- 이어 붙임: 둑 스티커 점선, 둑 사각 패치 2, 물기둥 사각 패치, 방 안 수레·문·펌프 패치

## ④ 한 문장
상행지의 NaCl 수송과 요소가 수질을 짜게 쌓으면, ADH(V)가 집합관 막에 AQP2를 끼워 물을 빼내 진한 소변이 조금 나오고, 바사 렉타는 그 기울기를 지키며 개재세포는 H⁺·HCO₃⁻를 가른다.
