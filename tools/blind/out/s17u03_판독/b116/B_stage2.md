# stage2 약속 적용 — s17u03 (「↻」= 1단계와 달라진 곳)

## ① 판 전체 표제어 ↻
- 1순위 **집합관: 주세포·사이세포와 ADH(V)로 오줌 농축(수질 소금·요소 기울기)** — 80%
- 2순위 **수질 삼투기울기·요소 재순환·바사 렉타 역류교환** — 12%
- 판정: 약속으로 훨씬 잘 풀린다. 1단계 「효소」는 통째로 틀림 — V는 속도가 아니라 ADH(#7), 창은 효소가 아니라 아쿠아포린(#151), 방석은 저해제가 아니라 요(#9), 톱니 기계는 효소가 아니라 공동수송체(#147). 네모 관=오줌길, 둥근 구리관=핏줄(#133). 맞았던 것: 액자=다른 조건, 물빛 진함=농도, 금색 자물쇠=막는 것, 창·펌프=수송 쪽.

## ② 구역 (↻ 선반을 두 패로, 액자를 「다른 날」로 다시 나눔 · #번호는 약속표)
**구역1 선반 왼 패 — 주세포: 알도스테론·ENaC·ROMK** ↻
- 체로 물속 가루를 건져 자루에 담는 소년 = ENaC 로 소금(Na⁺) 재흡수(체=통로; #149·#33) ↻ 「전이효소」 폐기
- 체에 감긴 검은 쇠자물쇠가 열려 발치에 놓임 = 먼 데서 온 것이 와서 풀린 일(금색 약 자물쇠와 다름) ↻
- 먼지 망토·진흙 장화 나그네의 큰 열쇠 = 알도스테론(먼 곳에서 옴; #149) ↻ 「모름」 해소
- 가득 든 체+사슬 끝 물방울 3 = 건져 올림=재흡수 늘림, 방금 꺼냄(#140) ↻
- 로마 투구 병정+칼을 물에 꽂음 = ROMK, K⁺ 를 관강으로(#141·#3) ↻ 「가수분해」 폐기

**구역2 선반 오른 패 — 사이세포: α·β 의 산·염기 분비** ↻
- 흰 달걀(알=α) 곁에서 물에 떨어지는 레몬 6조각 = α: H⁺ 분비(#154·#49) ↻
- 흰 베(β) 곁 상자가 쏟는 흰 분필 십여 토막 = β: HCO₃⁻ 분비(#154) ↻
- 두 패가 한 관의 둑에 따로 섬 = 한 벽의 다른 세포 종류(#156) ↻
- 둑 위 수로 = 겉질 구간, 옅은 물빛 = 묽은 관액(#158·#145) ↻

**구역3 액자① — ADH 가 오지 않은 날** ↻ (1단계 「경쟁적 저해」)
- V 두 자리가 윤곽뿐인 빈 꽂이 = 오지 않은 날(#7) ↻
- 물실(파란 꼬불선)이 없음 = 물길이 안 열림(#7·#150) ↻
- 넘치는 항아리+옅은 물 = 오줌 많고 묽음(#153·#145) ↻
- 소금 껍질과 방석은 그대로 = 달라진 것은 ADH 뿐(#118) ↻

**구역4 액자② — 루프 이뇨제로 막은 날** ↻ (1단계 「비경쟁적 저해」)
- 금색 자물쇠가 톱니 기계 크랭크에 걸림 = 막는 약·푸로세미드(#2·#147) ↻
- 소금 가루·껍질이 없음 = 소금을 못 퍼내 기울기가 사라짐(#157·#150) ↻
- V 가 채워졌는데도 항아리가 넘침 = ADH 는 왔으나 물을 못 당김(#7·#153) ↻
- 방석이 벽에 걸림 = 요가 깔릴 껍질이 없음 하(#9) ↻

**구역5 중앙 큰 장면 — 정상(해 뜬 날): 수질 기울기와 ADH 길** ↻
- 역청 이음매 통(물 불투과)+톱니 기계 = 굵은 상행각의 소금만 퍼내는 구간(#146·#157·#147) ↻ 「효소」 폐기
- 홈통의 흰 가루 더미, 위 얇고 아래 두꺼움 = 관 바깥 소금 껍질, 깊을수록 짠 수질(#150) ↻
- 껍질 아래 켜에 깔린 노란 방석 = 요(#9·#150) ↻ 「경쟁적 저해제」 폐기
- 맨 아래 쪽문의 노란 가루가 방석에 배고 바닥으로 왼쪽 앞 장 고리에 돌아감 = 요소 재순환(#155) ↻
- 큰 V 둘 = ADH — 물실 곁 하나, 요소 문 곁 하나, 바깥 벽에 꽂힘(#7) ↻ 「Vmax」 폐기
- 관 벽→껍질로 빨려 드는 꼬불 물실 = 바깥이 당겨 나가는 물(#150) ↻ 「모름」 해소
- 수로→수직관 = 겉질→속질, 아래로 짙은 청록 = 농도 상승(#158·#145) ↻
- 좁은 깔때기+가는 줄기+속 빈 항아리 = 적고 진한 오줌(#153) ↻

**구역6 오른쪽 방 — 주세포 한 칸: ADH→아쿠아포린2** ↻
- 방 = 관 벽에 붙은 앞 패(주세포) 한 칸; 널빤지 왼벽=관강막, 뒷벽·뒷문=기저외측막(#156·#134) ↻
- 수레의 창+지금 다는 창 = 2 → AQP2, 와야 끼워짐(#151) ↻ 「효소 농도」 폐기
- 회 바른 붙박이 창, 윗줄 3=AQP3·아랫줄 4=AQP4(개수=번호; #151) ↻
- 청록 물방울 4줄(76)이 유리 쪽마다 한 줄로 창을 지나 오른쪽 관으로 = 넷이 모인 물길(#151) ↻
- 오른벽 작은 v = V2 수용체, 핏줄 쪽 벽(#7) ↻
- 동전 투입구 크랭크 펌프+금빛 동전 = Na⁺-K⁺ 펌프·ATP(#148·#8) ↻ 「모름」 해소
- 방 아래 오른쪽 흰 더미 = 이쪽 바깥 소금 껍질(#150) 하 ↻

**구역7 구리관·유리구·눈금자 — 바사 렉타** ↻
- 둥근 구리 왕복관+눈금자 = 직세혈관(#6·#77) ↻
- 유리 구 3(맑음→뿌옇고 흰 결정→맑음) = 내려가며 받고 올라오며 도로 놓음(#152) ↻
- 다리 화살 ↓4·↑4 = 피 흐르는 쪽(#152) ↻
- 창의 물이 내려가는 쪽 다리로 듦 = 받는 곳(그림) ↻

## ③ 남은 것·약속표에 없는 것
- 톱니 3개·레몬 6·분필 수·물방울 76 은 개수 규칙이 약속표에 없어 모름(창 2·3·4 만 번호). 오른쪽 소금 더미에 방석이 없는 까닭, 펌프 뒤 희미한 사각 조각, 틀 모서리의 점눈금은 모름. 이음 흔적(맨 위 수로 x≈1165 세로선, 깔때기 물 직사각 패치)은 그대로이나 창 둘레 울퉁불퉁은 이음이 아니라 「회」(#151) ↻

## ④ 한 문장 ↻
집합관은 둑의 두 세포(주세포: 알도스테론이 체(ENaC)를 열어 소금을 건지고 칼(ROMK)로 칼륨을 내보냄 / 사이세포: 산·염기를 쏟음)와, ADH(V)가 와야 열리는 아쿠아포린 창·요소 문으로 수질의 소금·요소 껍질에 물을 빼앗겨 적고 진한 오줌을 만들고, ADH 가 안 오거나(액자①) 루프 이뇨제가 소금 기계를 잠그면(액자②) 오줌이 넘친다.
