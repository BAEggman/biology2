## ② 구역 (왼→오)
**구역1 상단 수로 선반 — 효소의 6분류(추정)**
- 키로 흰 가루를 자루에 옮겨 붓는 소년 → 전이효소(기를 옮김; 뜻) 중
- 같은 소년의 쇠사슬+열린 검은 자물쇠, 사슬 끝 물방울 3개 → 연결효소(결합, 물 방출; 모양·개수) 중하
- 외투 소년이 든 검은 고리·열쇠 → 열쇠-자물쇠 특이성? 하
- 칼을 물에 꽂은 로마병사(칼날 절반 잠김, 물결 고리 1) → 가수분해(물로 자름; 뜻) 중
- 레몬 6조각(낙하 4+첨벙 2) → 산·pH 또는 산화환원 하 / 달걀 1개 → 단백질 변성(열)? 하
- 펴진 부분+말린 부분이 한 장인 돗자리 → 이성질화(같은 물건, 모양만 바뀜; 모양) 중하
- 엎어진 상자에서 쏟아지는 흰 막대 십여 개 → 분해효소(물 없이 떼어냄; 뜻) 하

**구역2 왼쪽 액자① — 경쟁적 저해**
- 노란 방석이 가루 더미에 반쯤 묻힘 → 경쟁적 저해제는 기질이 많으면 밀려남(자리·뜻) 중
- 가루가 계속 떨어져 더미가 큼 → 반응 진행, Vmax는 그대로(뜻) 중
- 윤곽뿐인 연한 V 2개 → 아직 못 채운 겉보기 속도(모양) 하
- 크랭크 손잡이가 비어 있음 → 알로스테릭 자리는 빔(자리) 중하 / 넘치는 항아리 → 모름

**구역3 왼쪽 액자② — 비경쟁적(알로스테릭) 저해**
- 금빛 자물쇠가 크랭크 자리에 걸림 → 활성부위 아닌 곳에 결합(자리) 중
- 가루·더미 전혀 없음 → Vmax 자체가 낮아져 기질을 더해도 회복 안 됨(뜻) 중
- 방석이 벽에 걸려 놀고 있음 → 경쟁적 저해제는 없다는 대조(자리) 중하
- 굵은 흰 V 2개, 쪽문에서 새는 노란 가루 → 모름

**구역4 중앙 큰 장면 — Vmax·포화(미카엘리스-멘텐)**
- 방앗간(통+톱니 3+크랭크+홈통) = 효소(모양·뜻) 중상
- 윗 통의 물 = 기질 S(자리) 중하 / 흰 가루 더미 = 생성물 P, 더미 크기 = 생성량·속도(뜻) 중
- 큰 V 2개 = Vmax(크기) 중하 / 물기둥→좁은 깔때기→항아리 = 기질 공급과 병목·포화(모양) 중하
- 방석이 가루에 파묻힘+노란 가루가 바닥 왼쪽으로 옅어짐 = 기질 폭증으로 경쟁적 저해를 이김, 저해제는 가역적(자리) 하
- 맨 위 수로가 꺾여 내려오는 물 = 기질 흐름(자리) 중하
- 타르 띠, 쪽문, 가루에 스민 파란 꼬불선 → 모름

**구역5 오른쪽 방 — 효소·기질 농도와 속도**

## ④ 한 문장
방앗간(효소)이 물(기질)을 가루(생성물)로 바꾸는 속도 V는 기질·효소 양에 따라 포화(Vmax)에 이르고, 방석(자리 다툼)은 기질로 이기지만 자물쇠(다른 자리)는 못 이긴다.
