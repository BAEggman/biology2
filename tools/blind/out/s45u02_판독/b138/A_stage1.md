# stage1 생판 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **엽록체와 광합성 색소 — 빛 흡수(잎→엽록체→색소→스펙트럼)** 70%
- 2순위 **광계: 안테나 색소→반응중심(명반응의 시작)** 15% (그 밖 **엥겔만 실험·작용 스펙트럼** 10%)

## ② 구역 (왼쪽부터 4구역, [ ]는 근거)
### 구역1 **잎의 단면 구조** (7개)
- 큐브 단면 = 광합성 장소 중 잎 속 [모양]
- 맨 윗줄 납작·투명 세포 + 얇은 갈색 막 = 상부 표피 + 큐티클 [자리]
- 키 큰 기둥 세포 약 10개, 초록 점 빽빽 = 책상(울타리)조직, 엽록체 최다 [모양·개수]
- 둥글고 성긴 3~4층 세포 + 빈틈 = 해면조직, 공기 틈 [모양]
- 세포 속 초록 타원 점 = 엽록체 [모양]
- 띠 두른 파이프 다발, 단면 5개, 파란 물 = 관다발(엽맥)의 물관이 물 공급 [뜻·개수]
- 맨 아랫줄 납작 세포 = 하부 표피(기공은 안 보임) [자리]

### 구역2 **엽록체의 구조** (9개)
- 달걀 + 껍질 2겹 = 이중막(외막·내막) [모양·개수 2]
- 회색 빈 바닥 = 스트로마 [자리]
- 팬케이크 더미 6개 = 그라나, 접시 1장 = 틸라코이드 [모양·개수 6]
- 더미 사이 납작한 선반 = 스트로마 라멜라 [모양]
- 접시 앞 보라 점 3열 = 막에 박힌 광계(엽록소 복합체) [색]
- 맨 위 더미의 열린 검은 구멍 = 틸라코이드 내강 [모양]
- 흰 공 3(구멍 위·두 껍질 사이 납작 덩이·껍질 밖) = 물 분해로 생긴 O₂가 내강→스트로마→막 사이→밖으로 [자리·개수 3]
- 황동 망원경 + 루비 렌즈 = 루비스코 [소리]
- 거기 붙은 5마디 막대 = RuBP(5탄당), 스트로마 = 캘빈회로 [개수 5, 추정]

### 구역3 **광합성 색소(엽록소 a·b, 카로티노이드)와 광계(안테나→반응중심)** (13개)
- 초록 방석 = 틸라코이드 막, 꼬리 4개가 박힘 [자리·개수]
- 사각 보라 머리 + 가운데 은회색 구 = 엽록소 고리 + 중심 Mg [모양]
- 긴 꼬리 = 피톨 꼬리(소수성, 막 고정) [모양]
- 왼쪽 큰 사람, 가슴 Y + 흰 공 3개 = 엽록소 a, 메틸기 -CH₃ [개수 3]
- 오른쪽 큰 사람, 가슴 포크 = 엽록소 b, 포르밀기 -CHO [소리]
- 머리 줄무늬 7칸: a는 보라·파랑·빨강, b는 파랑·청록·주황이 진함 = 흡수 봉우리가 다름 [뜻·개수 7]
- 초록 빛이 V자로 튕김 = 초록은 반사 [모양]
- 당근 사람, 머리 잎에 보라·청록 빛 = 카로티노이드(β-카로틴), 청자~청록 흡수 [소리·모양]
- 흰 기둥 빛을 망토로 받음 = 과잉 빛 소산(광보호) [뜻, 추정]
- 노란 물결선 3개 = 안테나 3종(a·당근·b)에서 반응중심으로 공명 에너지 전달 [개수 3]
- 가운데 작은 두 사람(가슴 Y, 줄무늬 없는 머리) = 반응중심 엽록소 a 쌍 [개수 2]
- 그릇 + 노란 공, 손 맞잡음 = 1차 전자 수용체가 들뜬 전자를 받음 [뜻]
- 점선 → 빛나는 공 + 열 물결 3 = 에너지가 열·형광으로 빠짐? [추정]

### 구역4 **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 엽록소 d·f** (10개)
- 위에서 온 흰 기둥 빛 → 프리즘 = 백색광은 여러 파장 혼합 [모양]
- 무지개 띠, 보라(좌)→빨강(우) = 가시광선 파장 순서 [자리]
- 식탁 위 마디 있는 초록 실 = 실 모양 조류 [모양]
- 올리브색 막대 알갱이 = 호기성 세균, 산소 쪽으로 모임 [뜻]
- 무리가 보라~파랑 끝과 빨강 끝에 큼, 초록·노랑엔 몇 마리 = 작용 스펙트럼 봉우리 [개수]
- 흰 거품 = O₂, 보라 8·청록 3·초록 1·주황 3·빨강 약 10 = 광합성량 [개수]
- 식탁 앞 네모 9칸 + 당근: 보라·파랑·빨강 = a, 청록·주황(작은 포크 표시) = b, 당근 = 카로티노이드 → 흡수 스펙트럼이 작용 스펙트럼과 겹침 [뜻]
- 흰 칸 4개 = 초록·노랑대는 흡수 약함 [개수 4]
- 붉은 안개 속 d, f 글자 사람 둘 = 엽록소 d·f [글자·개수 2]
- 안개 = 700 nm 너머 원적색광 흡수 [자리]

## ③ 잔결
- 뜻 모름: 관다발의 갈색 띠 2개와 파이프 밑 물방울 1, 망원경의 회청 방울, 방석 위 빛나는 공·점선·열 물결
- 어색: 잎에 기공(공변세포)이 없음. 보라 네모 모티프가 머리·그라나 점·식탁 칸 3곳에 쓰여 헷갈림. a·b 큰 사람은 가슴 기호로만 구분됨. 청록 막대가 b와 당근 둘로 갈림
- 이음새: 엽록체 좌하 그라나 오른쪽의 평평한 직사각 회색 패치(윤곽이 잘림), 오른쪽 큰 사람 빛줄기 둘레의 희미한 윤곽선 잔재, 프리즘 앞 흰 기둥이 하늘색이 바뀌는 선(왼 크림 | 오른 청회)을 가림, 수채풍 붉은 안개와 d·f는 앞 구역과 질감이 다름, 선명한 벡터풍 점·칩·망원경·노란 공은 얹은 듯

## ④ 한 문장
잎 속 엽록체의 틸라코이드 막에서 엽록소 a·b와 카로티노이드가 청자색·적색 빛을 흡수(초록은 반사)해 반응중심으로 에너지를 모아 전자를 내보내며, 이 흡수 스펙트럼이 광합성 작용 스펙트럼(엥겔만)과 맞는다.
