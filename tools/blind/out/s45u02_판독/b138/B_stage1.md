# 1단계 생판 — s45u02 (사전 정보 없이 그림만 보고)

## ① 판 전체 표제어
- 1순위 **광합성 색소와 광계(엽록소 a·b, 카로티노이드, 안테나+반응중심, 흡수·작용 스펙트럼)** — 65%
- 2순위 **엽록체 구조와 광합성 장소(잎→엽록체→틸라코이드, O2 방출)** — 20%
- 짜임: 잎(기관) → 엽록체(세포소기관) → 색소·광계(분자) → 스펙트럼 실험(확인) 순으로 왼쪽에서 오른쪽.

## ② 구역별 (왼쪽부터 4구역)

### 구역1 **잎의 단면 구조(엽육·엽맥)** — 읽힌 6
1. 맨 위 얇은 갈색 띠 = 큐티클(자리).
2. 위·아래 맨 바깥 줄의 옅은 세포, 초록 알갱이 없음 = 표피(엽록체 없음, 빛 통과). 윗줄 6개 안팎.
3. 위쪽 세로 기둥 세포 10개 안팎, 알갱이 빽빽 = 울타리조직(엽록체 최다, 빛 받는 쪽).
4. 아래쪽 둥근 세포가 성기게 쌓여 빈틈 = 해면조직(엽록체 적음, 세포 간극 기체 교환).
5. 세포 속 초록 타원 알갱이 = 엽록체(모양).
6. 은색 파이프 5개 묶음, 끝마다 파란 물, 갈색 띠 2개 = 엽맥(관다발)의 물관, 광합성 원료 물 운반(뜻). 5·2의 뜻은 모름. 기공·공변세포는 없음.

### 구역2 **엽록체 구조와 O2 방출** — 읽힌 8
1. 달걀 껍질이 두 겹 띠 + 어두운 사이 틈 = 이중막(외막·내막, 막 사이 공간)(모양, 2).
2. 동전 더미 6개 = 그라나, 낱장 원반 = 틸라코이드(더미당 3~8장).
3. 더미를 잇는 납작한 초록 선반 = 스트로마 라멜라(자리).
4. 원반 옆면 보라 네모(더미마다 3줄) = 틸라코이드 막에 박힌 광계·색소 복합체(구역3 머리와 같은 모양).
5. 더미 밖 회색 바닥 = 스트로마(암반응 자리).
6. 망원경(scope)+빨간 보석(ruby) = 루비스코(소리), 스트로마에서 CO2 고정.
7. 5마디 줄무늬 막대 = 5탄당 RuBP(개수 5, 약함).
8. 맨 위 그라나의 열린 어두운 구멍(내강) → 흰 진주 → 막 사이에 낀 납작 진주 → 밖에 뜬 진주, 3개 = 내강(물 분해 자리)에서 생긴 O2가 이중막을 지나 방출.

### 구역3 **광합성 색소와 광계(안테나+반응중심)** — 읽힌 13
1. 사람 4명의 보라 네모 머리+은회색 공 = 포르피린 고리+Mg(금속색) = 엽록소 분자.
2. 긴 꼬리 4개 = 피톨 꼬리(소수성), 쿠션(막)에 꽂힘.
3. 왼쪽 큰 사람 가슴 Y+흰 점 3개 = 메틸기 -CH3 → 엽록소 a(개수 3).
4. 오른쪽 큰 사람 가슴 포크(날 4) = 포르밀기 -CHO(소리) → 엽록소 b.
5. 머리창 줄무늬: a는 보라·파랑·빨강, b는 파랑·청록·주황이 진하고 나머지 옅음 = 흡수 스펙트럼(a 청자+적색, b 청+주황, 서로 보완).
6. 머리에서 위로 튕기는 초록 V선 2개 = 녹색광 반사 → 잎이 초록.
7. 7색 무지개 빔 2줄 = 백색광이 안테나 색소로 입사.
8. 주황 당근 = 카로틴(카로티노이드)(소리·모양).
9. 보라+청록 빔이 당근 머리로 = 청자~청록 흡수.
10. 망토로 흰 강한 빛을 받아 번짐 = 과잉 빛 소산·광보호(망토=보호자, 추정).
11. 노란 꼬불선 3개(큰 사람 2, 당근 1 → 작은 사람) = 공명 에너지 전달, 안테나→반응중심(개수 3).
12. 작은 두 사람(줄무늬 없음, Y 둘, 손잡음) = 반응중심 엽록소 a 한 쌍(특수 쌍, 개수 2).
13. 그릇 속 노란 공을 건넴 = 들뜬 전자(e⁻)를 1차 전자수용체(그릇)에 전달.

### 구역4 **흡수·작용 스펙트럼(엥겔만)과 원적색광 엽록소 d·f** — 읽힌 10
1. 흰 빛기둥→프리즘→보라~빨강 7색 띠 = 백색광 분광(개수 7).
2. 벤치 위 마디 진 초록 줄 = 실 모양 조류(해캄류).
3. 갈색 막대·알갱이 = 호기성 세균(산소 많은 곳으로 모임).
4. 세균 위 흰 방울 = O2 발생.
5. 보라~파랑 끝·빨강 끝에 큰 더미 2곳, 나머지 색은 몇 마리 = 작용 스펙트럼 최대가 청자·적색.
6. 벤치 밑 네모 10개 중 색 채움 5(보라·파랑·청록·주황·빨강), 흰 채움 4, 당근 1 = 색별 흡수 여부(흰 = 초록·노랑 비흡수).
7. 청록·주황 네모 옆 미니 포크 = 엽록소 b의 흡수대.
8. 청록 아래 미니 당근 = 카로티노이드의 흡수대.
9. 오른쪽 붉은 안개 = 빨강 너머 원적색광(가시광선 밖).
10. 안개 속 d·f 글자 두 사람(빨간 창+은색 공) = 엽록소 d·f는 원적색광 흡수(f가 더 깊이 = 더 긴 파장, 약함).

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 붙인 흔적
- 모름: 파이프 5개·띠 2개, 막대 끝 고리, 망원경 옆 회색-파란 물방울(CO2? 물?), 회색 깔개, 구슬 둘레 푸른 테, 벤치 밑 흰 네모 4개, 보라 네모 줄 수 차이(2~7줄).
- 헷갈림: 김 나며 빛나는 노란 공(전자 에너지 방출? ATP?), 쿠션(= 틸라코이드 막?), 흰 진주(O2 vs H⁺), 작은 사람과 큰 a 사람 둘 다 Y, 보라 네모(광계 vs 엽록소).
- 어색: 작은 두 사람이 쿠션 뒤 가장자리에 하반신 가려짐, 파이프 다발이 블록 밖으로 삐져나옴, 중앙 흰 기둥이 망토 앞에서 흐려짐, d는 반투명.
- 붙인 흔적: 스트로마 오른쪽 회색 직사각 패치(직선 가장자리, 지운 자리?), 균일한 보라 네모·Y·포크·당근 아이콘·d·f 글자·노란 꼬불선·흰 방울·초록 V선은 손그림 위 벡터 스티커 질감.

## ④ 한 문장
잎 속 엽록체의 틸라코이드 막에서 엽록소 a·b와 카로티노이드가 청자색·적색 빛(초록은 반사)을 흡수해 에너지를 반응중심 엽록소 a 한 쌍에 모으고 전자를 내보내며 물이 분해돼 O2가 나오는데, 이는 엥겔만 실험의 세균 분포로 확인되고 원적색광은 엽록소 d·f가 맡는다.
