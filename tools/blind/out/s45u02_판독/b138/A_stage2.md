# stage2 약속표 적용 (그림 + 약속표만 열람)

판정: 약속표가 구역2·3을 확실히 더 풀었다(스트로마 · 루비스코+막대+CO₂ · 메틸/포르밀 · 틸라코이드/그라나/루멘 · 포르피린-Mg · O₂). 구역1·4, 당근·프리즘·세균·전자 공은 약속표 밖이라 그림 읽기 그대로. 틀선 칸이 없어 #118 미적용.

## ① 판 전체
- 1순위 **엽록체와 광합성 색소 — 빛 흡수(잎→엽록체→틸라코이드→색소→스펙트럼)** 80% ↻(70→80)
- 2순위 **광합성의 두 단계와 자리(명반응=틸라코이드 · 탄소 고정=스트로마)** 10% ↻(광계 2순위는 5%로 내림)

## ② 구역 (↻ = 1단계와 달라짐)
### 구역1 **잎의 단면 구조** (5개)
1. 윗줄 납작·투명 세포+갈색 막 = 상부 표피+큐티클 → 까닭: 아래엔 있는 초록 점이 없음(비어 있음)=광합성 않는 겉, 투명=빛 통과
2. 기둥 세포 약 10개·점 빽빽 = 책상조직(점=엽록체) → 까닭: 해면보다 점이 훨씬 많고 빛 쪽 맨 위에 틈 없이 섬=광합성 최다
3. 둥근 세포 3~4층+빈틈 = 해면조직 → 까닭: 기둥과 달리 둥글어 틈이 남·점 적음·아래=기체가 다니는 층
4. 띠 두른 파이프 5개+파란 물 = 관다발(물관), 물 공급 → 까닭: 물 찬 관을 한 다발로 두 층 사이에 박음=엽육에 물 대는 길(5·띠 2는 까닭 모름)
5. ↻ 맨 아랫줄 납작 세포 = 하부 표피(기공 없음) → 까닭: 윗줄과 대칭인 겉, 콩팥 모양 둘·롤 셔터(#14·#120)가 없어 기공은 이 판 몫이 아님

### 구역2 **엽록체의 구조와 스트로마의 루비스코** (9개)
1. 달걀+껍질 2겹 = 이중막 → 까닭: 껍질이 두 겹 포개지고 사이가 비어 보임=막 2장+막 사이 공간
2. ↻ 바닥의 술 달린 얇은 회색 깔개 = 스트로마(#164) → 까닭: 그라나는 선반에 뜨고 깔개만 바닥에 펴 깔림=그라나 바깥 바닥 (1단계: 빈 속 전체)
3. ↻ 팬케이크 포갠 더미 6 = 그라나, 접시 1장 = 틸라코이드(#167) → 까닭: 접시를 포개 쌓음=막이 쌓임, 여러 더미=grana 복수(6은 까닭 모름)
4. 더미 사이 납작 선반 = 스트로마 라멜라(약속표 밖) → 까닭: 더미끼리 같은 초록 판으로 이어짐=쌓인 막끼리 연결
5. ↻ 접시 겉 보라 네모+점 3열 = 막에 박힌 엽록소(#81) → 까닭: 구역3 머리와 같은 액자를 작게 줄 세움=엽록소가 막에 박힘
6. ↻ 맨 위 접시의 열린 어두운 속 = 루멘(#167) → 까닭: 다른 접시는 닫혔는데 이것만 속이 열림=속 빈 공간, 그 위에 O₂ 방울
7. ↻ 밝은 방울 3(열린 속 위·껍질 사이 납작·껍질 밖) = O₂(#17) → 까닭: 같은 방울이 한 칸씩 위로 옮김=루멘→막 사이→밖으로 나감
8. ↻ 루비빛 놋쇠 스코프 = 루비스코(#34) → 까닭: 깔개 위에 섬=스트로마에서 일함, 렌즈가 막대 끝에 닿음=기질을 붙듦
9. ↻ 두 빛깔 5마디 막대+어두운 방울 = RuBP 5탄소+CO₂ 1(#159·#16) → 까닭: 마디·방울 하나가 탄소 하나=5+1, 방울이 막대 끝에 붙음=고정 중(아래 고리는 모름)

### 구역3 **틸라코이드막의 색소(엽록소 a·b, 카로티노이드)와 광계: 안테나→반응중심** (12개)
1. ↻ 초록 방석 = 틸라코이드, 겉천 = 막(#167) → 까닭: 속 빈 납작 쿠션 위에 서고 꼬리가 박힘=색소는 막에 박혀 있음
2. ↻ 보라 네모 머리+은구 = 포르피린 고리+Mg(#81) → 까닭: 몸통·꼬리 대비 머리만 보라 액자, 빛줄기가 머리로 들어감
3. 긴 꼬리 4 = 피톨 꼬리(약속표 밖) → 까닭: 엽록소 넷만 꼬리가 있고 당근엔 없음, 끝이 방석에 닿음=막에 고정
4. ↻ 왼쪽 큰 사람 가슴 세 갈래 가지 = 메틸 → 엽록소 a(#165) → 까닭: 두 큰 사람이 키·자세·꼬리가 같고 가슴만 다름=곁가지 하나 차이, 갈래 셋=수소 셋
5. ↻ 오른쪽 큰 사람 가슴 포크 = 포르밀 → 엽록소 b(#166) → 까닭: 같은 자리 메틸이 포크로 바뀜=b는 그 자리가 CHO
6. 머리 줄무늬 7칸, a 보라·파랑·빨강 / b 파랑·청록·주황이 진함 → 까닭: 같은 창에 진한 칸만 다르고 그 색 줄기만 들어감=흡수 색이 달라 서로 메움
7. 초록 줄기가 V자로 튕김 = 초록 반사 → 까닭: 다른 색은 들어가는데 초록만 되튀어 오름=흡수 안 함
8. 당근+보라·청록 줄기 = 카로티노이드(약속표 밖) → 까닭: 주황·꼬리 없음·가슴 기호 없음=엽록소 아님, 청자~청록만 들어감
9. 흰 기둥 빛을 망토로 받음 = 과잉 빛 막이(광보호, 추정) → 까닭: 번진 센 빛이 망토에서 사라지고 망토가 엽록소 a 쪽을 가림
10. 노란 물결선 3 = 공명 에너지 전달 → 까닭: 큰 셋에서 가운데 둘로 모임=에너지가 모임(왼쪽 작은 이 둘·오른쪽 하나인 까닭은 모름)
11. 작은 두 사람(가슴 메틸) = 반응중심 엽록소 a 쌍 → 까닭: 머리 창이 비고 빛줄기가 안 닿음·손 맞잡음=전달된 에너지를 받는 쌍
12. 그릇+노란 공 = 1차 전자 수용체가 전자를 받음 → 까닭: 한쪽이 공을 놓고 한쪽이 그릇을 받침=받는 자가 따로 있음(약속표 밖)

### 구역4 **빛의 색과 흡수·작용 스펙트럼(엥겔만 실험), 원적색 엽록소 d·f** (8개)
1. 흰 기둥→프리즘→7색 띠, 보라(가까이·급히 꺾임)→빨강(멀리·곧음) → 까닭: 한 줄 흰빛이 갈리고 짧은 파장일수록 크게 꺾이는 순서가 자리로 읽힘
2. 식탁 위 마디 초록 실 = 실 모양 조류 → 까닭: 한 줄이 띠 전체를 가로지름=같은 개체에 색만 바꿔 비춤
3. 올리브 막대 세균, 보라끝·빨강끝 큰 무리·초록노랑 몇 마리 = 작용 스펙트럼 → 까닭: 양 끝 높고 가운데 빈 대비, 편모=움직여 O₂로 모임
4. 흰 방울(#17) 보라 8·청록 3·초록노랑 1·주황 3·빨강 약 10 = O₂ 양 → 까닭: 개수가 무리 크기와 같이 오르내림=광합성 세기
5. ↻ 식탁 앞 자줏빛 칩 9칸 = 색별 흡수(#81·#126·#166) → 까닭: 칩 틀은 같고 창 색만 다름=바뀐 것은 빛 색 하나, 보라·파랑·빨강 a / 청록·주황은 작은 포크=b / 당근=카로티노이드
6. 흰 창 칩 4 = 초록·노랑 흡수 안 함 → 까닭: 같은 칩인데 창이 비고 위 거품·세균도 적음
7. ↻ 청록 막대 둘·주황 막대 하나(띠→칩·당근) = a 빈 곳을 b·카로티노이드가 메움 → 까닭: 막대가 b 칩·당근으로만 내려오고 그 자리 거품이 3개씩 작게 솟음
8. 빨강 끝 너머 붉은 안개 속 d·f 글자 사람 = 엽록소 d·f 원적색 → 까닭: 빨강 띠 끝 바로 밖·창이 어두운 붉음=더 긴 파장, f가 더 깊이 섬(추정), d 반투명은 모름

## ③ 잔결
- 모름: 관다발 띠 2·물방울 1, 막대 아래 고리, 햇살 달린 공·점선·열 물결 3(전자·열은 약속표에 없음), d 반투명. ↻ 회청 방울은 CO₂(#16)로 풀림.
- 헷갈림: 파이프 속 파란 구슬은 #122와 닮았으나 물로 읽음(#36 검은 가스 파이프도 아님). 보라 네모 3곳은 #81 하나로 풀림.
- 이음새(그대로): 엽록체 좌하 그라나 오른쪽 직사각 회색 패치(윤곽 잘림) · 오른쪽 큰 사람 빛줄기 둘레 희미한 윤곽선 · 프리즘 쪽 흰 기둥이 하늘색 바뀌는 선(왼 크림|오른 청회)을 덮음 · 수채풍 붉은 안개.

## ④ 한 문장 ↻
틸라코이드막의 엽록소 a·b(메틸↔포르밀 곁가지 하나 차이)와 카로티노이드가 서로 다른 색을 흡수(초록은 반사)해 에너지를 반응중심 a 쌍에 모아 전자를 내고, 그 흡수 색이 엥겔만 작용 스펙트럼과 맞으며, 탄소 고정(루비스코)은 스트로마가 따로 맡는다.
