# stage2 — 덱 약속으로 다시 읽기 (↻ = 1단계와 달라진 곳)

## ① 판 전체 표제어
- 1순위 **광합성 개관과 광합성 색소(엽록체 구조·엽록소 a/b·카로티노이드·흡수/작용 스펙트럼)** 70% ↻ 이름에 '개관' 보탬, 60→70
- 2순위 **광계의 빛 포획(안테나 색소→반응중심 에너지·전자 전달)** 20% ↻ 25→20
- ↻ 근거 보탬: 약속 물건 중 ATP 동전·NADPH 방패·NAD 양동이·기공 셔터가 판 어디에도 없다 = 명반응 산물·기공 단계가 아니라 '빛을 받는 쪽'까지. 반면 루비스코·탄소 막대·O₂ 방울이 엽록체에 있어 개관 성격.

## ② 구역별 (왼→오)
**구역1 잎 단면 — 엽육조직과 관다발** (6개, 약속 물건 없음 → 1단계 유지)
1. 맨 위 납작 투명 세포줄+갈색 막 = 위표피+큐티클
2. 길쭉한 기둥 세포 10개 안팎, 초록 알갱이 빽빽 = 책상조직
3. 둥글고 틈 많고 알갱이 적은 세포 = 해면조직
4. 속 빈 은빛 파이프 5개+갈색 띠 2개 = 관다발(소리·개수; 말총 관 다발#43과 달라 약속 아님)
5. 맨 아래 납작 세포줄 = 아래표피. ↻ 콩팥 둘·롤 셔터가 없음 = 기공을 안 다룸이 확정
6. 세포 속 초록 타원 = 엽록체

**구역2 엽록체 — 이중막·그라나·스트로마, O₂, 루비스코** (8개)
1. 달걀 껍질 2겹 = 이중막(개수·모양)
2. 팬케이크 더미 6개(더미당 6~7장) = 그라나
3. 더미 사이 납작 선반 = 스트로마 라멜라(표에 없음, 모양)
4. 맨 위 더미의 어두운 입 = 틸라코이드 내강
5. ↻ 밝은 방울 3개(내강→껍질 사이→바깥) = O₂ 확정(#17)
6. 루비빛 놋쇠 스코프 = 루비스코 확정(#34, 소리 추정과 일치)
7. ↻ 양 끝 술 달린 회색 깔개(담 안 바닥) = 스트로마(#164) — 1단계 '미확정'→확정. 루비스코가 그 위에 앉음
8. ↻ 마디 5(갈·흰 번갈아)+붙은 어두운 방울 = 탄소 5+CO₂ 1=6(#159·#16) → RuBP+CO₂→6탄소 중간체 확정. 끝 고리는 여전히 모름

**구역3 방석 위 무대 — 색소와 에너지 전달** (12개)
1. 방석 = 틸라코이드 막(표에 없음, 꼬리가 박힘)
2. ↻ 자주 액자+은빛 구슬 = 포르피린+Mg(#81) — 머리 13개(큰2·작은2·네모7·안개2) 모두 같은 틀
3. 긴 꼬리 = 피톨 꼬리(표에 없음). 당근엔 틀·꼬리 없음
4. ↻ 가슴 세 갈래+흰 알 셋 = 메틸기 CH₃(#165) → 왼쪽 큰 인물 = 엽록소 a 확정
5. ↻ 가슴 4갈래 포크 = 포르밀기 CHO(#166) → 오른쪽 큰 인물 = 엽록소 b 확정(a·b 차이=곁사슬)
6. 렌즈색=받는 빛색. ↻ 파란 줄기=청색광(#125)은 a의 파란 렌즈로, 청록 줄기는 b의 청록 렌즈로
7. 초록 V = 초록빛 되튐(표에 없음)
8. 당근 = 카로티노이드(소리), 보라·청록빛
9. 망토에 닿는 흰 빔 = 햇살 그대로, 광보호/포획 모호
10. 노랑 물결선 3개 = 에너지 전달(표에 없음)
11. ↻ 작은 둘의 Y=CH₃ → 반응중심 엽록소 a 쌍 확정
12. 사발+노란 구슬 = 전자→수용체(구슬이라 ATP 동전 아님)

**구역4 프리즘·벤치·붉은 안개 — 흡수·작용 스펙트럼** (8개)
1. 흰 빛기둥(햇살=글자 그대로#118)→프리즘 = 백색광 분산
2. 보라(왼)→빨강(오른) 무지개
3. 마디 초록 실 = 사상 녹조류
4. 세균 더미: 보라·파랑 아래, 빨강 아래 수십, 초록·노랑 아래 거의 없음 = 엥겔만, 작용스펙트럼
5. ↻ 밝은 방울(왼7·오른8·가운데 2+2) = O₂ 확정(#17)
6. ↻ 같은 포르피린 네모 7개가 줄지어 렌즈색만 다름 = 한 가지만 바꾼 대조 실험(#126) → 흡수는 보라·파랑·빨강, 나머지 4개 흰 렌즈
7. 네 번째 네모 위 초록 V = 초록은 안 받음
8. 붉은 안개·유령 인물 2 = 표에 없음. ↻ 머리=포르피린이니 엽록소류, 렌즈 붉음=적색광. 표식·꼬리 없음, 정체(red drop/두 광계)는 낮은 확신

## ③ 판정
- 약속표가 더 잘 풀었다: 모름·추정이던 8곳(Y·포크·깔개·막대+방울·방울 색·머리·파란 줄기·네모 7줄)을 확정. 이은 흔적의 흰 반달은 초승달(CAM)이 아니라 수직으로 잘린 방울 조각.
- 풀린 쪽은 '분자 신원'(a/b, 루비스코, 스트로마, O₂, CO₂, 포르피린-Mg)이고, '과정'(에너지 전달·전자·분산·엥겔만)은 약속이 아니라 그림의 뜻으로 읽는다.
- 표에 없어 1단계 유지: 당근·망토·물결선·사발·방석·꼬리·프리즘·벤치·안개.
- 여전히 모름: 막대 끝 고리, 안개 속 인물이 유령처럼 흐린 까닭.

## ④ 한 문장 ↻
포르피린-Mg 엽록소 a(CH₃)·b(CHO)와 카로티노이드가 파장별로 빛을 받아(초록은 되튐) 에너지를 반응중심 a 쌍으로 모아 O₂를 내고, 스트로마의 루비스코는 RuBP+CO₂를 6탄소로 잇는다. 스펙트럼은 청·적에서 높다.
