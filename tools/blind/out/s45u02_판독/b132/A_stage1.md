# 생판 판독 (s45u02.png, 사전정보 없이 그림만 봄)

## ① 판 전체 표제어
- 1순위 **광합성: 장소(잎·엽록체)와 광합성 색소·빛 흡수(스펙트럼)** 65% — 왼→오로 잎 → 엽록체 → 색소 분자 → 흡수·작용 스펙트럼으로 좁혀 들어감.
- 2순위 **명반응의 빛 포획(광계: 안테나 색소 → 반응중심)** 20%.

## ② 구역 (왼→오 4구역. 우측 붉은 안개 부분은 5번째 구역일 수도 있음)

### 구역1 **잎의 단면 구조(엽육·관다발)** — 7개
1. 층층 3D 블록 = 잎 단면, 광합성은 엽록체 든 잎 세포에서 (모양)
2. 맨 위 납작·투명 세포 한 줄(약 5칸)+갈색 얇은 띠 = 위 표피+각피, 엽록체 없이 빛 통과 (자리)
3. 그 밑 길쭉 기둥 세포 약 10개, 초록 타원 점 빽빽 = 울타리(책상)조직, 엽록체 최다 (모양·개수)
4. 아래쪽 둥글고 듬성한 세포, 점 적고 틈 있음 = 해면조직, 틈은 기체 교환로 (모양)
5. 맨 밑 납작 세포 줄 = 아래 표피. 기공·공변세포는 안 그려짐 → 모름
6. 두 층 사이를 가로지르는 은빛 속 빈 파이프 5개(왼끝 구멍 5) = 관다발의 물관, 물(재료) 공급 (뜻·개수)
7. 파이프를 묶은 갈색 띠 2개 = 유관속초 또는 리그닌 (약한 추정)

### 구역2 **엽록체 구조(이중막·그라나·스트로마·O₂)** — 10개
1. 속이 보이게 자른 달걀 = 엽록체 (모양)
2. 껍질이 두 겹, 사이에 짙은 띠 = 외막·내막 이중막, 개수 2 (개수)
3. 안쪽 동전 더미 6개(왼3·오3), 각 6~7장 = 그라나(틸라코이드 쌓임) (모양·개수)
4. 더미를 잇는 납작 선반 = 스트로마 라멜라(그라나 간 틸라코이드) (모양)
5. 꼭대기 더미 윗면이 열려 어두운 속 = 틸라코이드 내강 (모양)
6. 흰 구슬 3개: 내강 → 두 막 사이에 눌림 → 밖으로 = 물 분해 O₂가 내강에서 생겨 엽록체 밖으로 (자리·동작·개수)
7. 더미 바깥 빈 공간·바닥 회색 깔개 = 스트로마(기질) (자리)
8. 놋쇠 망원경, 붉은 보석 접안 = 루비스코(루비+스코프) (소리)
9. 망원경에 기댄 5마디 막대 = RuBP 5탄당 (개수; 흰 마디 2=인산?)
10. 접안에 닿는 파란 물방울 = CO₂(추정) → 스트로마에서 CO₂ 고정, 캘빈 회로 (뜻·자리)

### 구역3 **광합성 색소와 집광(엽록소 a·b, 카로티노이드 → 반응중심)** — 12개
1. 네모 머리틀+가운데 은구슬 = 엽록소의 포르피린 고리+중심 Mg, 전 구역에 반복 (모양)
2. 긴 꼬리 4개가 쿠션에 박힘 = 피톨 꼬리, 막에 고정 (모양·개수)
3. 초록 쿠션 = 틸라코이드 막 (자리; 구역2 디스크와 같은 모양)
4. 왼쪽 큰 인물, 가슴 Y+흰 점 3 = 메틸기 −CH₃ → 엽록소 a, 파란 머리·파란 빛 흡수 (모양·개수)
5. 오른쪽 큰 인물, 가슴 포크 = 포밀기 −CHO(포크~포밀) → 엽록소 b, 청록 빛 흡수 (소리)
6. 초록 빛줄기 V(들어와 튕겨 나감) = 녹색광 반사 → 잎이 초록 (모양)
7. 당근 = 카로티노이드(캐롯~카로틴) (소리)
8. 당근 머리잎에 보라·청록 빛 2가닥 = 청자~청록(400~500nm) 흡수 보조색소 (자리·개수)
9. 흰 빛을 망토로 받음 = 과잉 빛 소산, 광보호 (뜻; 약함)
10. 노란 물결선 3개(큰왼→작은왼, 당근→작은왼, 큰오→작은오) = 공명 에너지 전달, 안테나→반응중심 (모양·개수)
11. 작은 인물 2(머리 속 빔, 가슴 Y), 손잡고 그릇 듦 = 반응중심 엽록소 a 특수쌍 (개수)
12. 그릇 속 노란 공 1 = 들뜬 전자 → 1차 전자수용체 (모양)

### 구역4 **흡수·작용 스펙트럼(프리즘, 엥겔만 실험)** — 10개
1. 위의 흰 빛기둥 → 돌받침 위 삼각 프리즘 = 백색광 분산 (모양)
2. 무지개 부채 7색, 보라가 왼쪽 = 가시광 스펙트럼 (개수)
3. 벤치 위 초록 마디 실 1줄 = 사상 녹조류, 엥겔만 재료 (모양·자리)
4. 갈색 알갱이 무더기 = 호기성 세균, 보라-파랑 끝·빨강 끝에 크게, 초록-노랑엔 없음 (자리)
5. 흰 방울(양끝 각 10개 안팎) = O₂ 발생이 많은 곳 (개수)
6. 레일 위 네모 7칸(칠한 3: 보라·파랑·빨강 / 흰 4: 청록·초록·노랑·주황) = 청자·적색 흡수, 녹~주황 약함 (개수)
7. 칠한 칸 구슬은 밝고 흰 칸 구슬은 회색 = 흡수 여부 (모양)
8. 초록 칸 위 초록 V 표시 = 녹색 반사(구역3과 같은 V) (모양)
9. 세균 분포(작용)≈네모 7칸(흡수) = 두 곡선이 겹침 (뜻)
10. 붉은 안개+반투명 유령 2(붉은 머리) = 원적색 영역, 적색 강하·두 광계(에머슨)? (개수; 모름에 가까움)

## ③ 뜻 모를 것 · 어색한 것 · 이어 붙인 흔적
- 망원경·5마디 막대·파란 방울: 외곽선 또렷한 후첨 스프라이트. 마디 수, 흰 마디 2, 끝 고리 뜻 불명.
- 파이프 수(왼 5/오른끝 3)와 갈색 띠 2의 뜻 불명.
- 흰 빛줄기만 흐린 광채(다른 줄은 평평한 막대)이고 망토 안에서 번짐 → 따로 얹은 효과.
- 초록 V 한 줄이 허공에서 끊김(반사인지 입사 2줄인지), 청록 줄 2개가 누구 것인지 헷갈림.
- 큰 왼쪽 인물과 작은 두 인물의 Y 표식이 같고 머리색만 다름.
- 노란 선 3개 질감이 둘은 사각 물결, 하나는 코일형으로 다름.
- 빨강 끝 세균 무더기 왼쪽 가장자리가 직선으로 잘리고 반쪽 방울이 붙음(이음 흔적). 레일·네모·V·초록 실도 후첨 느낌.
- 붉은 안개 속 유령 2의 정체 불명.

## ④ 한 문장
잎의 엽록체 틸라코이드 막에 박힌 엽록소 a·b와 카로티노이드가 청자색·적색 빛을 흡수해 반응중심으로 에너지를 모아 전자를 내보내고(녹색은 반사), 그 흡수·작용 스펙트럼은 엥겔만 실험으로 확인한다.
