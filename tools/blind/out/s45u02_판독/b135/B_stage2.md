# stage2 — 약속 어휘로 다시 읽기 (s45u02)

## 판정
약속표가 결정적으로 푼 것: 구역2 바닥 장면 전부(깔개·스코프·막대·방울), 구역3 기호 셋(메틸·포르밀·포르피린+Mg), 밝은 방울=O₂, 벤치 네모 줄. 약속표 밖이라 1단계 그대로인 것: 잎 조직, 당근·망토, 반응중심 장면(그릇·공), 프리즘·엥겔만, d·f·안개. → 구역2는 크게(추정·모름 4→1), 구역3은 근거만 단단해짐, 구역1·4는 거의 같음. 약속표는 작은 분자·효소 물건에 강하고 큰 구조물·실험 소품은 자연 읽기였다.

## ① 표제어
- **1순위: 광합성의 장소(잎→엽록체)와 광합성 색소·빛 흡수(흡수·작용 스펙트럼)** 65% (그대로)
- ↻ **2순위: 엽록체의 구조와 반응 장소 분업(틸라코이드=명반응·O₂, 스트로마=탄소 고정)** 20% — 루비스코 장면이 풀려 올라옴. 1단계 2순위 「광계 포획」은 8%로 내림.

## ② 구역별

### 구역1 — **잎의 단면(광합성 조직)** · 7개
- 큐티클(맨 위 갈색 막) · 표피(투명 큰 세포 한 줄 약 5칸) · 울타리(기둥 약 10개, 알갱이 빽빽) · 해면(둥글고 성김, 틈) — 1단계와 같음
- ↻ 속 빈 은색 파이프 5개 + 갈색 띠 = 「관+다발」 말놀이 → 관다발. 1단계 모름이던 띠가 풀림(띠 2줄의 개수는 뜻 없음 추정, 약속표엔 없음)
- 맨 아래 투명 세포열 = 하표피. ↻ 공변세포(콩팥 모양 둘 #14)·롤 셔터(#120)가 없다 → 이 판은 기공을 가르치지 않음이 확인됨

### 구역2 — **엽록체 구조·O₂ 방출·스트로마의 탄소 고정** · 13개
- 달걀 겹벽 = 이중막; 두 막 사이 납작한 흰 방울 = O₂(#17 밝은 방울이 좁은 틈에 눌림)
- 초록 방석 더미 6개(좌3·우3) = 그라나(동전이 아니므로 ATP #8 아님), 더미당 7장 = 틸라코이드, 잇는 납작판 = 스트로마 라멜라
- ↻ 원판마다 작은 보라 네모 3개 = 포르피린 고리+Mg(#81)의 축소 = 막에 박힌 엽록소
- 맨 윗 원판의 어두운 빈 곳 + 흰 방울 = 내강에서 나오는 O₂; 방울 3개(내강→막 사이→밖) = 배출 경로
- ↻ 바닥의 양 끝 술 달린 얇은 회색 깔개 = 스트로마(#164). 1단계 「회녹색 속=스트로마」는 정정(스트로마는 바닥 깔개로 그려짐)
- ↻ 깔개 위 루비빛 렌즈 놋쇠 스코프 = 루비스코(#34 확정; 1단계는 소리 추정) → 탄소 고정은 스트로마에서
- ↻ 줄무늬 막대(두 빛깔 5마디) = 탄소 5개 = RuBP(#159); 막대에 붙은 어두운 파란 방울 = CO₂(#16)도 탄소 하나로 셈 → 5+1 = 6탄소 중간체(→3탄소 둘). 막대 끝 고리 = 인산 추정(표 밖)
- ↻ 깔개 위 낱개 원판(보라 네모 3) = 틸라코이드 한 장; 구역3 방석과 같은 꼴이라 확대의 단서(추정, 1단계 모름)

### 구역3 — **광합성 색소(엽록소 a·b, 카로티노이드)와 광계** · 13개
- ↻ 머리 = 자주빛 네모 액자+은빛 구슬 = 포르피린 고리+Mg(#81 확정); 꼬리 = 피톨 꼬리(표 밖)
- ↻ 왼쪽 큰 인물: 가슴 세 갈래 가지(검은 마디·흰 알 셋) = 메틸기 CH₃(#165) → 엽록소 a. 근거가 소리에서 모양으로 바뀜. 창 빨강|파랑
- ↻ 오른쪽 큰 인물: 갈퀴 넷 포크(잔 없이 홀로) = 포르밀기 CHO(#166) → 엽록소 b(푸코잔틴 #56과는 잔 유무로 갈림). 창 주황|청록
- ↻ 빛줄기 8줄 = 각 색의 빛(#125), 창 색과 일치 = 흡수색; 초록 V자 = 녹색 반사
- 당근+망토 = 카로티노이드(표 밖, 소리); 보라·청록 줄기를 잎끝으로 받음; 흰 빔 닿는 망토 = 광보호(불확실)
- ↻ 작은 인물 2명 = 반응중심 엽록소 a(가슴이 메틸기라 a로 확정)
- 노란 물결선 3줄 = 안테나→반응중심 에너지 전달; 그릇+노란 공 = 1차 전자수용체; 바닥 노란 공+점선+김 = 열·형광(불확실)
- 초록 방석 = 틸라코이드 막

### 구역4 — **스펙트럼·엥겔만·원적색 엽록소 d/f** · 12개
- 흰 기둥 빛→프리즘→7색 · 초록 마디 실 = 사상 녹조류 · 갈색 막대 무리(보라·파랑, 빨강에 큰 무리·청록 소수·초록 노랑 없음) = 작용 스펙트럼 · ↻ 흰 방울 = O₂(#17 확정)
- ↻ 벤치 앞 같은 네모 8개, 색만 다름 = 한 가지만 바꾼 대조(#126) → 흡수 스펙트럼(보라·파랑·빨강 칠함, 초록~노랑 빈칸); 당근 아이콘 = 카로티노이드가 청록 틈 메움; 작은 주황 네모+작은 포크(#166) = 엽록소 b의 주황
- 붉은 안개 = 원적색·근적외; 인물 d·f = 엽록소 d·f, f가 더 깊고 선명 = 더 장파장; ↻ 벤치 아래 맨발 두 쌍 = 벤치 뒤에 선 d·f의 발(추정)

## ③ 어색한 것
- 여전히 모름: 바닥 노란 공(열? 형광?), 흰 빔의 정체, 막대 끝 고리, 적색 무리 곁의 작은 초록 막대 한 마리.
- 억지로 끼우지 않은 것: #7 V이음쇠(초록 V는 빔), #8 동전, #9 요(방석은 틸라코이드 확대), #91 삼각 모자(프리즘은 모자 아님), #136 김(독성 맥락), #160 흰 거품(납작한 방울은 O₂).
- 이어 붙인 흔적: 1단계와 같음.

## ④ 한 문장 ↻
틸라코이드 막의 엽록소 a·b와 카로티노이드가 청자색·적색은 흡수하고 녹색은 반사해 반응중심 엽록소 a에 에너지를 모아 O₂를 내고(작용 스펙트럼=흡수 스펙트럼, 엽록소 d·f는 원적색까지), 스트로마에서는 루비스코가 RuBP(5탄소)에 CO₂를 붙인다.
