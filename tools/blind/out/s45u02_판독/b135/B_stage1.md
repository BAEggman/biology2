# stage1 — 생판 (s45u02)

## ① 판 표제어
- **1순위: 광합성의 장소(잎→엽록체)와 광합성 색소·빛 흡수(흡수·작용 스펙트럼)** 65%
- **2순위: 명반응의 빛 포획 — 광계(안테나 색소→반응중심)** 20%
- 그 밖: 엽록체의 구조와 기능 8%, 빛과 식물 색소 7%

## ② 구역별 (4구역)

### 구역1 — **잎의 단면(광합성 조직)** · 7개
- 맨 위 얇은 갈색 막 = 큐티클(자리)
- 투명 큰 세포 한 줄(약 5칸), 알갱이 없음 = 표피(색)
- 기둥 세포 약 10개, 초록 알갱이(엽록체) 빽빽 = 울타리 조직; 해면보다 알갱이가 많음(모양·개수)
- 둥글고 성긴 세포 4~5층, 알갱이 적고 틈 = 해면 조직·공기틈(모양)
- 은색 속 빈 파이프 다발(단면 5개) = 관다발·물관(모양·개수)
- 갈색 띠 2줄 = 모름(유관속초?)
- 맨 아래 투명 세포열 = 하표피, 기공은 안 보임(자리)

### 구역2 — **엽록체 구조와 O₂ 방출·스트로마** · 12개
- 달걀 겹벽 = 이중막(모양) · 두 막 사이 납작한 흰 거품 = 막 사이로 가는 O₂(자리)
- 회녹색 속 = 스트로마 · 동전 더미 6개(좌3·우3) = 그라나, 더미당 7장 안팎 = 틸라코이드(개수)
- 더미를 잇는 납작한 판 = 스트로마 라멜라 · 원판마다 보라 네모 3개 = 막에 박힌 엽록소(광계)
- 맨 윗 원판의 어두운 빈 곳 + 흰 공 = 틸라코이드 내강, 물 분해로 O₂(자리)
- 흰 공 3개(내강→막 사이→밖) = O₂ 배출 경로(개수)
- 바닥 망원경(빨간 렌즈) = 루비스코(루비+스코프, 소리) → 스트로마 칼빈 회로
- 줄무늬 막대 5칸(끝 고리) = RuBP 5탄당(+인산) 추정 · 파란 물방울 = CO₂ 추정(약함)
- 바닥 낱개 원판 = 모름

### 구역3 — **광합성 색소(엽록소 a·b, 카로티노이드)와 광계** · 12개
- 머리 = 보라 네모 틀(포르피린 고리)+은색 공(Mg) · 꼬리 = 피톨 꼬리(모양)
- 왼쪽 큰 인물: 가슴 Y+흰 구슬 3 = 메틸기(-CH₃) → 엽록소 a; 창 빨강|파랑 = 적색·청자색 흡수
- 오른쪽 큰 인물: 가슴 포크 = 포밀(-CHO, 소리) → 엽록소 b; 창 주황|청록 = 주황·청색 흡수
- 초록 빔이 V자로 튕김 = 녹색 반사(비흡수); 빔은 모두 8줄(빨강·파랑 / 흰 / 보라·청록 / 초록·주황·청록)이고 흡수색이 창 색과 일치(개수)
- 당근+망토 = 카로티노이드(보조색소, 소리); 보라·청록 빔을 잎끝으로 받음
- 망토에 닿는 흰 빔 번짐 = 과잉 빛 막기(광보호), 불확실
- 작은 인물 2명(흰 창, Y 가슴) = 반응중심 엽록소 a 특수 쌍(개수)
- 노란 물결선 3줄 = 안테나 색소→반응중심 에너지 전달(개수)
- 둘이 든 그릇+노란 공 = 들뜬 전자를 1차 전자수용체에 넘김(동작)
- 바닥 노란 공+점선+김 = 떨어진 전자, 열·형광 방출(불확실)
- 초록 방석 = 틸라코이드 막(자리)

### 구역4 — **스펙트럼·엥겔만 실험·원적색 엽록소 d/f** · 11개
- 흰 기둥 빛 → 삼각 프리즘 = 백색광 분산 · 무지개 7색(보라→빨강) = 가시광선(개수)
- 벤치 위 초록 마디 실 = 사상 녹조류 · 갈색 막대 무리 = 호기성 세균: 보라·파랑 큰 무리, 청록 소수, 초록·노랑 없음, 빨강 큰 무리 = 작용 스펙트럼(자리)
- 흰 방울(왼 8·청록 3·오른 12쯤) = O₂ 발생
- 벤치 앞 네모 8개: 보라·파랑·빨강 칠함, 초록~노랑 빈칸 = 흡수 스펙트럼(개수)
- 청록 자리 당근 아이콘 = 카로티노이드가 틈 메움 · 주황 작은 네모+작은 포크 = 엽록소 b의 주황 흡수
- 오른쪽 붉은 안개 = 빨강 끝 너머 원적색·근적외선 영역(자리); 맨발 두 쌍은 벤치 뒤에 선 d·f의 발로 추정
- 안개 속 인물 가슴 d·f = 엽록소 d·f(소리); d는 반투명, f는 더 깊고 선명 = f가 더 장파장

## ③ 어색한 것
- 뜻 모름: 망원경·줄무늬 막대·파란 물방울(루비스코 추정), 구역2 바닥 낱개 원판, 갈색 띠 2줄, 바닥 노란 공(열? 형광?), 벤치 아래 맨발 두 쌍.
- 헷갈림: 큰 a·b는 몸이 같고 가슴 기호로만 구별; 작은 인물도 Y라 a와 혼동; 청록 빔이 당근·b 양쪽; 흰 빔이 백색광인지 강광인지.
- 이어 붙인 흔적: 구역3|4 사이 칼날 모서리 흰 기둥(하늘색 갈림); 구역4 수채 안개 질감 이질; 보라 네모·Y·포크·망원경·d/f가 평면 아이콘처럼 얹힘; 망토 위 뭉개진 흰 얼룩; 잎 블록 가운데 세로 접힘선.

## ④ 한 문장
잎 속 엽록체 틸라코이드 막의 엽록소 a·b와 카로티노이드가 청자색·적색은 흡수하고 녹색은 반사하며 그 에너지를 반응중심 엽록소 a로 모아 O₂를 내놓는다(작용 스펙트럼=흡수 스펙트럼, 엽록소 d·f는 원적색까지).
