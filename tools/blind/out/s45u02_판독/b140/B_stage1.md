# 1단계 생판 (s45u02)

## ① 판 전체
- **1순위: 광합성 색소와 빛 흡수** (엽록소 a·b·카로티노이드, 흡수·작용 스펙트럼, 안테나→반응중심) 85%
- **2순위: 광합성 개관 - 장소(잎→엽록체)와 명반응 입구(광계)** 10%
- 흐름: 잎 → 엽록체 → 막 위 색소 → 색소가 먹는 파장으로 줌인.
- 근거: 색소 인물(포르피린 틀·Mg·피톨 꼬리)과 스펙트럼 실험(프리즘·엥겔만)이 중심이고, 캘빈 회로·ATP·NADPH는 거의 없음(루비스코 추정 정도).

## ② 구역별
### 구역1 **잎의 구조(엽육·관다발)** 사실 5
1. 위·아래 납작 투명 세포층 = 표피(엽록체 없음). 위 표피 위 갈색 띠 = 큐티클(위는 두껍고 아래는 얇음).
2. 키 큰 기둥 세포 약 10열, 초록 알갱이 빽빽 = 책상조직(위쪽 자리).
3. 둥근 세포가 성글고 알갱이 적음 = 해면조직(아래쪽 자리).
4. 책상·해면 경계의 파이프 다발, 끝 5개(큰 3+작은 2)에 파란 물 = 관다발의 물관(뜻·개수).
5. 기공·공변세포는 안 그려짐(없음). 파이프를 묶은 갈색 띠 2개, 아래 파이프의 물방울 1은 모름.

### 구역2 **엽록체 구조와 O₂·Rubisco** 사실 7
1. 껍질 2겹, 사이 짙은 초록 = 이중막·막간공간.
2. 원반 더미 6개(왼 3·오 3, 원반 6~7장) = 그라나(개수).
3. 더미를 잇는 납작 선반 5~6개 = 스트로마 라멜라.
4. 원반 막의 보라 틀 점(3열×6줄, 선반엔 없음) = 엽록소 든 광계(보라=포르피린, 뒤 구역 TV 틀과 같은 모양).
5. 맨 위 더미 윗원반의 검은 틈 = 내강.
6. 흰 구슬 3개(내강→막 사이→밖) = 물 분해로 생긴 O₂가 밖으로 나감.
7. 바닥 회색 양탄자 = 스트로마. 루비 렌즈 망원경 = 루비스코(소리 루비+스코프), 5마디 줄무늬 관 = RuBP 5탄당(개수), 회색 물방울 = CO₂(추정).

### 구역3 **엽록소 a·b·카로티노이드, 안테나→반응중심** 사실 8
1. 큰 TV 머리 인물 2 = 엽록소: 보라 틀 = 포르피린 고리, 은색 공 = Mg, 긴 꼬리 = 피톨 꼬리(모양).
2. 왼쪽 가슴의 흰 공 3개 삼지창 = CH₃(H 3개) → 엽록소 a. 7색 빛줄기 중 보라·파랑·빨강만 화면에 닿고 청록·노랑·주황은 사라짐, 초록은 V자로 튕김(반사).
3. 오른쪽 가슴의 포크 = -CHO(소리 포크~포밀) → 엽록소 b. 파랑·청록·주황만 닿음(a와 흡수 위치 다름), 초록 V 반사.
4. 당근 인물 = 카로티노이드(소리 캐럿~카로틴): 보라+청록 두 줄기를 받음, 보조색소.
5. 당근 망토가 흰 빛 기둥을 흐림 = 과잉 빛 방어(광보호).
6. 노란 물결선 3가닥(큰a→작은a, 당근→작은a, 큰b→작은b) = 공명 에너지 전달.
7. 안쪽 작은 인물 2(Y 가슴, 빈 화면, 빛 안 받음) = 반응중심 엽록소 a 한 쌍.
8. 그릇 + 노란 공 1 = 들뜬 전자를 1차 수용체에 넘김.
(추정) 바닥 번쩍이는 공·열 구불 3·점선 = 열·형광 방출. 초록 방석 = 틸라코이드 막.

### 구역4 **흡수·작용 스펙트럼(엥겔만)과 엽록소 d·f** 사실 8
1. 흰 빛 기둥 → 프리즘 → 7색(보라 가장 꺾임, 빨강 가장 덜).
2. 칸막이 실(사상 녹조류) + 갈색 막대 세균: 보라 쪽 큰 덩어리(~40), 빨강 쪽(~20), 초록·노랑 1~3 = 엥겔만 실험.
3. 흰 점 = O₂ 방울(보라·청록·주황·빨강 위).
4. 보라 사각 2줄×7칸(순서 보라·파랑·청록·초록·노랑·주황·빨강). 위줄(Y=a): 보라·파랑·빨강만 켜짐.
5. 아랫줄(포크=b): 파랑·청록·주황만 켜짐.
6. 초록·노랑은 두 줄 다 꺼짐 = 안 먹음.
7. 작은 당근 + 청록 줄 = 카로티노이드는 청록대 흡수.
8. 붉은 안개 속 TV 머리 d, f = 엽록소 d·f: 붉은 끝 너머 원적색 흡수(d 흐림, f 더 깊이).

## ③ 모름·어색·헷갈림·이은 흔적
- 망원경·줄무늬 관·물방울(루비스코 추정 60%), 바닥 공·점선의 뜻.
- 보라 점이 광계인지 ATP 합성효소인지, 갈색 띠 2개, d 글자 속 점은 모름.
- 흰 빛 기둥 2개(프리즘 위·당근 위) 헷갈림.
- 큰 인물 2와 작은 인물 2는 꼬리가 있고 당근은 TV·꼬리가 없음. P680·P700·광계 I/II 글자는 없어 구분은 모름.
- 배경은 수채 한 장, 이음매 없음. 빛줄기·보라 사각·구슬·망원경·파이프는 클립아트 질감으로 얹힌 흔적, 붉은 안개는 따로 번진 층.

## ④ 한 문장
틸라코이드 막의 색소(a·b·카로티노이드)가 파장별로 빛을 나눠 먹고(초록 반사, 작용스펙트럼≈흡수스펙트럼) 안테나에서 반응중심 엽록소 a 한 쌍으로 에너지를 모아 전자를 내보내며 O₂가 나온다.
