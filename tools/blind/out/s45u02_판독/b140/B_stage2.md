# 2단계 약속 덱 (s45u02)

## ① 판 전체
- **1순위: 엽록체와 엽록소 - 빛 흡수에서 반응중심의 들뜬 전자까지** 90% ↻(85→90: 약속 #34·159·164~169가 모두 이 판의 말)
- **2순위: 광합성 색소와 스펙트럼(엥겔만)** 7%
- 판정: 약속으로 더 잘 풀림(1단계 「모름·추정」 6~7개 풀림). 표 밖(당근·꼬리·물결선·프리즘·세균·d f·잎 조직·갈색 띠)은 끼우지 않음.

## ② 구역별 (→ 까닭 = 왜 그 모습인가, 그림 어디서 읽었나)
### 구역1 **잎의 구조(엽육·관다발)**
1. 표피(납작 투명 층). → 까닭: 초록 점이 없음(점 찬 엽육 세포와 견줌) = 엽록체 없음. 맑은 빛깔의 뜻은 모름.
2. 큐티클(위 표피 위 갈색 띠, 위 두껍고 아래 얇음). → 까닭: 위·아래 두께 대비만 읽힘, 이유는 까닭 모름.
3. 책상조직(위, 기둥 약 10열). → 까닭: 점 찬 기둥을 틈 없이 세움 = 엽록체 최다(아래 층과 견줌). 위에 둔 뜻은 모름.
4. 해면조직(아래, 둥근 세포). → 까닭: 성글게 쌓여 틈이 남고 점이 듬성 = 엽록체 적음.
5. 관다발 = 파이프 5(큰 3+작은 2), 파란 물. → 까닭: 속 빈 관+물 가득 = 물길(물관), 두 층 사이 한가운데(자리). 파란 알은 #122(청색광 수용체)가 아니라 관 속 물로 봄. 굵기 둘·갈색 띠 2·물방울 1은 까닭 모름.

### 구역2 **엽록체 구조와 루비스코**
1. 껍질 2겹, 사이 짙은 초록 = 이중막(담=막). → 까닭: 겹 수 2 = 막 수, 사이를 짙게 비움 = 막 사이 공간.
2. ↻ 쿠션 더미 6 = 그라나(#167: 속 빈 납작 쿠션을 팬케이크처럼 포갬; 1단계 「원반」). → 까닭: 같은 쿠션을 포개고 층마다 점 한 줄 = 층 많을수록 엽록소 많음. 6의 뜻은 모름.
3. 더미를 잇는 납작 선반 5~6(표 밖). → 까닭: 한 더미에서 나와 다음 더미에 닿음 = 막이 이어짐. 선반에 점이 없는 까닭은 모름.
4. ↻ 보라 점 3열×6줄 = 엽록소(#81 작은 자주 액자; 1단계 「광계?」 정정, ATP 합성효소는 #116 돌 아치+물레방아라 아님). → 까닭: 같은 점을 같은 간격으로 박음 = 같은 색소가 막에 줄지어 박힘. 3×6 수는 모름.
5. 맨 위 쿠션의 열린 검은 속 = 루멘(#167 텅 빈 속). → 까닭: 그 쿠션만 윗면을 열어 속 빈 것을 보이고 그 속에 방울을 앉힘 = 거기서 O₂가 생김.
6. ↻ 밝은 방울 3 = O₂(#17): 루멘→막 사이→밖. → 까닭: 같은 방울을 한 줄로 놓음 = 가는 길; 막 사이 방울만 납작 = 비집고 지나는 중.
7. ↻ 루비빛 렌즈 스코프 = 루비스코 확정(#34; 1단계 60%). 5마디 막대 = 탄소 5(#159), 어두운 방울 = CO₂(#16). → 까닭: 막대 끝이 렌즈에 걸리고 방울이 렌즈 곁에 붙음 = 한 자리에서 5C+CO₂ 만남(5+1).
8. ↻ 술 달린 회색 깔개 = 스트로마(#164 확정). → 까닭: 담 안 바닥에 깔고 루비스코를 얹음 = 스트로마에서 일어남; 위(그라나·O₂)와 아래(깔개·CO₂) 자리 대비.

### 구역3 **엽록소 a·b·카로티노이드와 안테나→반응중심**
1. ↻ 큰 TV 머리 2 = 엽록소: 자주 액자+은빛 구슬 = 포르피린+Mg(#81), 꼬리 = 피톨(표 밖). → 까닭: 액자 빛깔이 곧 이름(porphyra); 꼬리가 방석 쪽으로 늘어져 닿음(막에 박힘은 추정).
2. ↻ 왼쪽: 삼지창(검은 마디·흰 알 셋 #165) = CH₃ → a, 진한 칸 보라·파랑·빨강. → 까닭: 같은 모습 둘을 세우고 가슴 표식만 바꿈(#126과 같은 꼴) = 곁가지 하나 차이가 먹는 빛을 바꿈.
3. ↻ 오른쪽: 갈퀴 넷 포크(#166) = CHO → b, 진한 칸 파랑·청록·주황. → 까닭: 같은 7색 줄기를 받아도 닿는 줄기가 다름, 겹치는 칸은 파랑뿐(두 화면 견줌). 갈퀴 4의 수는 모름.
4. ↻ 초록 줄기가 액자 윗변에서 V로 되튐(#169) = 덜 받아 돌려보낸 빛 = 잎이 초록인 빛깔. → 까닭: 되튀는 선이 옅고 가늚 = 「조금은 받는다」; 다른 색은 화면으로 드는데 초록만 테두리에서 튕김.
5. 당근 = 카로티노이드(표 밖, 소리), 보라+청록 줄기를 이파리로 받음. → 까닭: TV 머리·꼬리 없는 모양 = 엽록소와 다른 색소; 줄기 둘뿐, 청록은 a가 못 먹는 칸(벤치와 견줌).
6. ↻ 당근 망토가 흰 빛 기둥(#118 햇살; 1단계 「기둥 2개 헷갈림」 정리)을 번지게 흐림 = 과잉 빛 방어(표 밖). → 까닭: 기둥이 망토에 닿는 자리에서 흐려짐(동작); 망토를 a 쪽으로 펼침.
7. 노란 물결선 3(큰a→작은a 아치·당근→작은a·큰b→작은b) = 에너지 전달(표 밖). → 까닭: 모두 작은 인물 머리에서 끝남 = 바깥에서 가운데로 모임. 아치가 당근 위를 넘는 뜻은 모름.
8. 작은 인물 2(Y 가슴, 빈 화면) = 반응중심 a 한 쌍. → 까닭: 화면 줄무늬가 비고 빛줄기가 안 닿음 = 빛을 스스로 안 먹고 받아만 옴; 마주 선 둘 = 한 쌍. 작음은 원근일 수 있어 크기 뜻은 모름.
9. ↻ 노란 공(#168 들뜬 전자) 1을 받침 없는 사발(1차 전자수용체)에 넘김. → 까닭: 한 손은 공 위, 한 손은 사발 밑(동작) = 주고받음; 에너지는 물결(머리), 전자는 공(손)으로 다르게 그림(대비).
10. ↻ 초록 방석 = 틸라코이드 쿠션 확정(#167, 겉천 = 막; 1단계 「막 추정」). → 까닭: 구역2의 쿠션과 같은 소품을 크게 키움 = 확대; 인물이 그 위에 섬 = 막에 박힌 색소.
(추정) 바닥의 번쩍이는 노란 공+점선+김 3+빛살. → 까닭: 같은 노란 공이 사발 밖에, 점선이 사발 자리에서 내려옴(동작); 김·빛살 = 열·빛. 약속표엔 이 장면 없음.

### 구역4 **흡수·작용 스펙트럼(엥겔만)과 엽록소 d·f**
1. ↻ 흰 기둥(#118) → 프리즘 → 7색. → 까닭: 하나가 일곱으로 갈림; 보라 띠가 가장 급히 휘고 빨강이 가장 완만.
2. ↻ 같은 실 한 가닥(사상 녹조류)+갈색 막대 세균(대략 보라~파랑 40, 빨강 20, 청록·주황 4, 초록·노랑 1~3). → 까닭: 같은 실이 모든 색 밑을 지남 = 빛 색만 바꾼 대조(#126); 덩어리 크기가 아래 켜진 칸과 맞음.
3. ↻ 흰 점 = O₂(#17), 덩어리 위로 오름. → 까닭: 덩어리 바로 위 = 세균은 O₂ 나오는 곳에 모임. 점 수는 덩어리 크기와 안 맞음(모름).
4. 보라 액자 2줄×7칸(#81·#126): a(Y) 보라·파랑·빨강, b(포크) 파랑·청록·주황 켜짐. → 까닭: 같은 칸을 나란히 두고 켜지는 색만 바꿈 = 색마다 먹나 안 먹나 견줌; 켜짐은 큰 인물 화면의 진한 칸과 같은 코드.
5. 청록·주황 막대가 흰 a 칸을 지나 켜진 b 칸에 닿음(보라·빨강 열은 반대로 a만 켜짐). → 까닭: 위가 못 먹는 색을 아래가 먹음(비켜 감·위아래 맞섬) = 서로의 빈틈을 메움.
6. 초록·노랑 두 열은 위아래 모두 꺼짐. → 까닭: 통째로 비어 있음 = 안 쓰이는 빛(구역3 초록 V와 같은 말).
7. 작은 당근+청록 막대 = 카로티노이드 청록 흡수(표 밖). → 까닭: a 칸이 꺼진 청록 열에만 서 있음(자리).
8. 붉은 안개 속 d·f(#81 액자·구슬, 글자는 표 밖) = 원적색 흡수. → 까닭: 보라→빨강으로 이어진 줄 끝 너머 어두운 붉음(자리) = 보이는 빛 바깥; d 흐림·f 깊이 선 뜻은 모름.

## ③ 모름·어색·이은 흔적
- 풀림 ↻: 망원경·막대·어두운 방울·깔개·방석·보라 점·흰 방울·초록 V·사발. 새로 본 것: 아랫줄 판자가 떠 있음, 청록 막대가 a 칸 밑으로 이어져 b 칸에 닿음, 쿠션·액자의 확대 관계.
- 여전히 모름: 갈색 띠 2·파이프 물방울, 갈퀴 4, d 글자 속 점, 선반에 점 없음.
- 이은 흔적: 배경은 수채 한 장. 빛줄기·액자·망원경·파이프·아랫줄 판자(양끝이 잘려 떠 있음)는 덧댄 질감, 붉은 안개는 따로 번진 층.

## ④ 한 문장
스트로마에서 루비스코가 5탄당에 CO₂를 붙이고, 쿠션(틸라코이드) 더미의 빈 속에서 O₂가 나가며, 쿠션 천에 박힌 엽록소(a: CH₃, b: CHO)가 파장마다 다른 빛을 먹어 안테나→반응중심 a 한 쌍으로 모은 에너지로 들뜬 전자를 1차 수용체에 넘긴다.

## ⑤ 까닭의 공통 장치 (②의 → 까닭이 쓴 대비)
- 같은 것 나란히·하나만 다름: 큰 인물 둘, 7칸×2줄, 같은 실 → 한 가지가 결과를 가른다.
- 비어 있음: 작은 인물 화면, 초록·노랑 두 열, 청록 열의 흰 a 칸. 비켜 감·맞섬: 막대가 a 칸을 지남, 초록만 V로 튕김, 위(그라나·O₂)↔아래(깔개·CO₂).
- 확대: 구역2 쿠션·작은 보라 점 → 구역3 방석·큰 액자 머리.
