# stage1 생판 (s45u02) — 그림만 보고

## ① 판 전체 표제어
- 1순위 **광합성 — 엽록체와 광합성 색소의 빛 흡수(엽록소 a·b·카로티노이드, 흡수·작용 스펙트럼)** 75%
- 2순위 **명반응 — 광계·반응중심의 빛에너지 포획** 15% (그 밖: 잎·엽록체 구조 단독 5%)
- 흐름: 잎 → 엽록체(확대) → 색소 분자 → 파장(스펙트럼)

## ② 구역 (왼쪽부터 5구역, 5는 4의 오른쪽 위와 겹침)
**구역1 잎의 단면 구조** 6개: 맨 위 갈색 얇은 판=큐티클(자리) / 윗·아랫 표피=납작·투명, 초록 점 없음=엽록체 없음(모양) / 기둥 세포 10개 빽빽·초록 타원 많음=울타리조직(개수·빛 받는 윗자리) / 둥글고 성기며 틈, 초록 타원 적음=해면조직(모양) / 은색 파이프 5개+갈색 띠 2개, 속 파란 구슬=관다발의 물관·물(모양·개수) / 세포 속 초록 타원=엽록체, 바로 옆 달걀로 확대(자리)

**구역2 엽록체 구조** 10개: 달걀+껍질 2겹(사이 짙은 띠)=이중막·막 사이 공간(모양) / 회색 빈 바닥=스트로마 / 초록 동전 더미 6개(왼3·오3, 층 6·6·6·6·7·2)=그라나(모양·개수) / 더미를 잇는 납작한 판=스트로마 라멜라 / 맨 위 동전이 입 벌린 검은 속=틸라코이드 내강 / 막 위 보라 네모 3열=막에 박힌 광계·색소(추정) / 흰 공 3곳(내강·막 사이 납작 덩어리·달걀 밖)=O₂ 생성→방출(추정) / 바닥 양탄자 위 망원경(끝 붉은 보석)=루비스코(소리 ruby+scope)(추정), 5토막 줄무늬 막대=RuBP 5탄당(개수 5)(추정), 회청 물방울=CO₂(약함) → 스트로마=칼빈 회로 자리

**구역3 광합성 색소(엽록소 a·b·카로티노이드)와 반응중심 에너지 전달** 17개: 초록 방석=틸라코이드막(추정), 꼬리가 박힘 / 큰 인물 둘의 보라 네모 머리=포르피린 고리, 은색 공=Mg, 긴 꼬리=피톨 꼬리(모양) / 왼쪽 가슴 Y(흰 점 3)=–CH₃(개수 3)→엽록소 a, 화면 보라·파랑·빨강 켜짐=청자·적색 흡수 / 오른쪽 가슴 포크(4갈래)=–CHO(소리 포크~포밀)→엽록소 b, 화면 파랑·청록·주황 켜짐 / 둘 다 초록 빛이 V자로 튕김=초록 반사 / 당근 인물=카로티노이드(소리 carrot~carotene), 머리에 보라+청록 빛=청자~청록 흡수, 오렌지 망토가 굵은 흰 빛 기둥을 받아 흐려짐=과잉 빛 소산·광보호(추정) / 노란 지그재그 3줄=에너지 전달(개수 3) / 가운데 작은 Y 인물 2명(빛 안 받고 흰 화면에 공)=반응중심 엽록소 a 특수쌍(개수 2) / 사발+노란 공=들뜬 전자→1차 전자수용체 / 점선 따라 바닥에 떨어진 공+김 3줄=바닥상태 복귀·열·형광(추정) / 위 무지개 줄기 둘(각 7색)=백색광

**구역4 흡수·작용 스펙트럼(엥겔만 실험)** 9개: 흰 빛 기둥→프리즘→7색 부채=백색광 분산 / 마디 있는 초록 실=실 모양 조류 / 갈색·올리브 막대=호기성 세균, 산소 많은 곳으로 모임 / 보라-파랑 끝(~45)·빨강 끝(~20)에 빽빽, 초록·노랑엔 2~3=작용 스펙트럼 두 봉우리(개수) / 흰 방울(O₂) 보라-파랑 8·청록 4·노랑 1·주황 4·빨강 ~10 / 윗줄 네모 7(Y표식)=a: 보라·파랑·빨강만 켜짐 / 아랫줄 7(포크표식)=b: 파랑·청록·주황만 켜짐 / 청록 칸 당근 아이콘=카로티노이드 / 초록·노랑 칸 전부 흰색=흡수 안 함

**구역5 원적색 흡수 엽록소 d·f** 4개: 빨강 띠 너머 짙은 붉은 안개=가시광선 밖 원적색 / 가슴 d 인물=엽록소 d / 가슴 f 인물(더 오른쪽)=엽록소 f(더 긴 파장) / 어두운 붉은 화면=원적색 흡수

## ③ 흔적
- 뜻 모름: 막 사이 흰 납작 덩어리, 방석의 정체, 망원경 세트(루비스코 가설), 파이프 갈색 띠 2개, 안개 속 작은 흰 얼룩
- 어색: 기공·공변세포가 없음, 벤치 아랫줄 판자가 다리 앞에 떠 있음
- 헷갈림: Y(a)와 포크(b) / 큰 a(안테나)와 작은 Y 둘(반응중심) / 흰 공(O₂, 가슴 점=H) / 황금색(전자·에너지·d f 글자) / 당근 인물과 벤치 당근 아이콘 / 주황 네모와 당근
- 이은 흔적: 지그재그·빛줄기·네모·표식·d f 글자는 납작한 덧그림 / 두 세균 무리의 그림체가 다름 / 붉은 안개·d f는 윤곽 없는 다른 레이어 / 구역3·4 사이 흰 빛 기둥이 경계 / 망토의 흰 번짐

## ④ 한 문장
엽록체 막의 엽록소 a·b와 카로티노이드가 서로 다른 파장을 흡수하고 초록은 반사하며(엥겔만 실험의 작용 스펙트럼과 일치) 그 에너지는 반응중심 엽록소 a의 들뜬 전자로 모이고, 엽록소 d·f는 원적색까지 흡수한다.
