# 1단계 생판 — 그림만 보고 읽음

## ① 판 전체 표제어
- 1순위 **광합성: 엽록체와 광합성 색소·광계(빛 흡수)** — 60%
- 2순위 **광합성 광반응(명반응)의 도입 — 광계의 빛 포획** — 25%
- 근거: 잎 → 엽록체 → 색소·광계 → 스펙트럼 순으로 "빛을 어디서, 무엇이 잡는가"를 좁혀 간다. 전자전달계·ATP 합성효소·NADPH는 없고(O2 구슬만), 캘빈 회로는 소품 하나뿐.

## ② 구역 (왼쪽부터 4구역)

### 구역1 잎 단면 벽돌 — **잎의 구조: 엽육(울타리·해면)·관다발**
1. 맨 위 얇은 갈색 층 + 점 없는 납작 무색 세포 줄(약 6) = 큐티클·위표피, 엽록체 없음 (모양·색)
2. 세로로 선 기둥꼴 세포 10, 초록 점 빽빽 = 울타리조직, 빛 쪽 위 (모양·개수·자리)
3. 둥글고 느슨히 쌓인 세포 5~6층, 점 적고 사이 틈 = 해면조직, 기체 틈 (모양·자리)
4. 은색 관 5(앞면)에 파란 물 가득 = 관다발의 물관, 물(H2O) 공급 (모양·개수·뜻). 갈색 띠 2는 모름(유관속초?)
5. 맨 아래 납작 무색 세포 줄 = 아래표피. 기공·공변세포는 못 찾음
6. 세포 속 초록 타원 점 = 엽록체는 엽육세포에 있고 울타리에 더 많음 (모양)

### 구역2 달걀 엽록체 — **엽록체 구조: 이중막·그라나·스트로마**
1. 달걀꼴, 껍질 두 겹 = 이중막(바깥막·안막) (모양·개수)
2. 납작 주머니를 동전처럼 쌓은 더미 6(왼3·오른3), 더미당 7~8장 = 그라나(틸라코이드 더미) (모양·개수)
3. 더미 사이 얇은 선반 = 스트로마 라멜라 (모양·자리)
4. 주머니 막에 박힌 보라 네모 점(줄당 3) = 엽록소가 틸라코이드 막에 있음 (구역3 머리와 같은 아이콘)
5. 맨 위 주머니의 검은 속 + 흰 구슬, 껍질 사이 납작 흰 알, 밖의 흰 구슬 = 구슬 3개: 내강에서 물이 분해되어 O2가 밖으로 (자리·개수)
6. 주머니 바깥 빈 공간 = 스트로마(캘빈 회로 자리) (자리)
7. 루비 렌즈 망원경 = RuBisCO(ruby+scope, 소리), 5마디 막대 = 5탄당 RuBP(개수), 회청색 물방울 = CO2(추정)

### 구역3 초록 방석 무대 — **광계: 색소별 빛 흡수, 안테나 → 반응중심**
1. 방석 = 틸라코이드 막, 사람 꼬리가 방석에 꽂힘 = 엽록소의 피톨 꼬리가 막에 박힘 (자리·모양)
2. 사각 보라 머리 + 은구슬 = 포르피린 고리 + Mg (모양)
3. 왼쪽 큰 사람: 머리창 빨강|파랑, 빨강·파랑 광선 받음, 가슴 Y+흰 공 3 = 엽록소 a, 메틸기 CH3 (색·개수)
4. 오른쪽 큰 사람: 창 주황|청록, 주황·청록 받음, 초록 광선은 V자로 튕김, 가슴 포크 = 엽록소 b, 포밀기 CHO (소리 fork≈formyl)
5. 망토 당근 = 카로티노이드(carrot≈carotene), 보라·청록 광선을 받고 망토로 흰 빛을 막음 = 청자색 흡수·광보호 (소리·동작)
6. 노란 물결선 3(큰 왼쪽→작은 왼쪽, 당근→작은 왼쪽, 큰 오른쪽→작은 오른쪽) = 안테나에서 반응중심으로 에너지 이동 (방향·개수)
7. 가운데 작은 두 사람, 창 투명, 가슴 Y = 반응중심 엽록소 a 특수쌍(2분자), 빛을 직접 안 받음 (개수)
8. 둘이 받친 그릇 + 노란 공 = 1차 전자수용체에 들뜬 전자 전달 (동작)
9. 점선 → 땅의 작은 해 + 열줄 3 = 열(또는 형광)로 잃는 에너지 (뜻 약함)
10. 흐릿한 흰 빛기둥 = 백색광 (모양)

### 구역4 프리즘 벤치 — **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 색소 d·f**
1. 삼각 프리즘 + 흰 빛기둥 → 7색 띠, 보라가 가장 꺾임 = 백색광 분산 (개수 7)
2. 벤치 위 가는 초록 마디 실 = 사상 조류 (모양)
3. 갈색 막대 알갱이 = 호기성 세균: 보라~파랑 끝과 빨강 끝에 큰 무더기 2, 청록·주황은 몇 마리, 초록~노랑은 거의 없음 = 작용 스펙트럼 (자리·개수)
4. 흰 방울 약 25 = 세균 위로 오르는 O2 (모양)
5. 벤치 아래 사각 아이콘 10: 보라·파랑·빨강 = 엽록소 a, 청록·주황(+포크) = 엽록소 b, 당근 1 = 카로티노이드, 흰 창 4 = 모름 (자리·개수)
6. 빨강 너머 검붉은 안개 = 원적색·근적외선 구간 (색·자리)
7. 안개 속 d·f 글자 사람 2 = 엽록소 d·f는 원적색 흡수 (글자)

## ③ 모르겠는 것·어색한 것·헷갈리는 것·이은 흔적
- 스트로마 바닥의 회색 해칭 판, 바닥에 홀로 놓인 틸라코이드 1장(점 3): 모름
- 망원경·막대·회청색 방울 풀이는 추정(확신 중간). 벤치 아래 흰 창 4, 점선+작은 해의 뜻도 불확실
- 초록 V 광선이 엽록소 b에만 붙어 있고 노랑 광선은 없음 — 헷갈림
- 선명한 흰 기둥(프리즘)과 흐린 흰 기둥(무대) 두 종류. 광선·물결선·아이콘·d f 글자가 평면 덧칠 느낌. 하늘·지평선은 하나로 이어져 이음선은 못 찾음

## ④ 한 문장
광합성은 잎의 엽육세포 속 엽록체의 틸라코이드 막에서 일어나며, 엽록소 a·b와 카로티노이드가 서로 다른 빛을 흡수해 안테나로 모은 에너지를 반응중심 엽록소 a 쌍에 넘겨 전자를 내보내고, 초록빛은 덜 쓰이며 원적색은 엽록소 d·f가 쓴다.
