# 2단계 — 약속표로 다시 읽기 (↻ = 1단계와 달라진 곳: 해소·확정·추가)

## 판정
약속표는 판 표제어를 뒤집지 않았다. 구역2·3 소품이 확정·해소됐다(루비스코 #34, 스트로마 #164, 마디 막대+어두운 방울 #159·#16, 밝은 방울 #17, 포르피린+Mg #81, 메틸기 #165, 포르밀기 #166). 구역1·4의 주 소품과 당근·그릇·물결선은 약속표 밖이라 1단계 읽기를 유지, #126만 구역4에 보탰다.

## ① 판 표제어
- 1순위 **광합성: 엽록체와 광합성 색소·광계(빛 흡수)** — 60% (유지)
- 2순위 ↻ **광합성 개관(광반응 + 탄소 고정 입문)** — 25% (루비스코·CO₂·5탄소 막대 확정으로 탄소 고정 첫걸음까지 한 판에 듦)

## ② 구역별 사실 (각 사실 아래 ⑤ 까닭)

### 구역1 잎 단면 — **잎의 구조: 엽육(울타리·해면)·관다발**
1. 위표피(약 6칸)+큐티클
→ 까닭: 맨 위 점 없는 무색 칸 ↔ 아래 점 가득한 기둥 = 엽록체 없는 투명 껍질, 갈색 얇은 층이 맨 겉
2. 울타리조직 10칸
→ 까닭: 길쭉·촘촘·점 약 15~25가 하늘 쪽에 몰림 ↔ 아래 둥글고 성긴 세포 = 빛 먼저 닿는 쪽이 광합성 주력
3. 해면조직 5~6층
→ 까닭: 둥근 공이 느슨히 쌓여 사이가 비고 점 약 5~8 = 엽록체보다 기체가 드나드는 빈틈
4. 관다발: 은색 관 5+파란 물+갈색 띠 2
→ 까닭: 관 단면마다 파란 물 가득·끝에 방울, 층 사이 한가운데를 가로지름 = 모든 층에 물 대는 길. 띠 = '다발'. 개수 5·2는 뜻 모름
5. 아래표피, 기공 없음
→ 까닭: 위표피와 같은 무색 줄을 나란히 둠 = 위아래 겉껍질. 기공(#120·#14)은 안 그려짐 — 까닭 모름
6. 엽록체 점
→ 까닭: 같은 초록 타원이 울타리 ≫ 해면(약 3배), 구역2 달걀과 꼴이 같아 그 확대판으로 이어짐

### 구역2 달걀 엽록체 — **엽록체 구조: 이중막·그라나·스트로마**
1. 이중막
→ 까닭: 껍질이 밝은 띠·짙은 띠·밝은 띠로 두껍게 겹침 = 막 둘과 그 사이
2. 그라나 6(왼3·오른3, 더미당 7~8장)+선반(스트로마 라멜라)
→ 까닭: 같은 더미를 엇갈려 나란히 두고 선반이 이음 = 이어진 한 막계. 6의 뜻은 모름
3. ↻ 보라 네모 점(줄당 3) = 엽록소 머리 #81
→ 까닭: 같은 보라 틀이 쌓인 주머니 면에만 박히고 깔개엔 없음(비어 있음) = 색소는 막에 있다. 구역3 머리와 같은 틀
4. ↻ 밝은 방울 #17 = O₂ 3개(맨 위 주머니 속 · 껍질 사이 · 밖)
→ 까닭: 같은 구슬의 자리만 바뀜 = 내강에서 생겨 이중막을 빠져나감. 맨 위 주머니 하나만 속이 열림
5. ↻ 술 달린 회색 깔개 = 스트로마 #164 (1단계 「모름」 해소)
→ 까닭: 담 안 바닥에 얇게 '펴 깔림' + 루비스코가 그 위에 섬 = 탄소 고정 자리는 막이 아닌 기질
6. ↻ 루비빛 렌즈 놋쇠 스코프 = 루비스코 #34
→ 까닭: 막 더미와 떨어져 깔개 위에 홀로 놓임 ↔ 막에 박힌 보라 점 = 일하는 자리가 다름
7. ↻ 막대 5마디(두 빛깔 번갈아)+붙은 어두운 방울 = 5탄소+CO₂ #159·#16 → 탄소 6
→ 까닭: 개수 5+1. 막대 끝이 렌즈 쪽으로 휘고 방울이 그 틈에 붙음 = 효소가 CO₂를 5탄소에 붙임. 3탄소 둘로 갈라짐은 안 그려졌고 끝의 고리는 모름
8. 낱장 틸라코이드 1(점 3)
→ 까닭: 쌓인 더미 곁에 쌓이지 않은 한 장이 깔개 위에 놓임(하나만 다름) = 쌓임 없는 틸라코이드로 추정, 확실한 까닭은 모름

### 구역3 초록 방석 무대 — **광계: 색소별 빛 흡수, 안테나 → 반응중심**
1. 방석 = 틸라코이드 막, 꼬리 = 엽록소 꼬리
→ 까닭: 구역2 납작 주머니와 같은 초록 쿠션 꼴. 꼬리가 모두 방석에 풀뿌리처럼 박히고 머리는 위 = 꼬리는 막 속, 머리는 빛 쪽
2. ↻ 사각 보라 머리+은구슬 = 포르피린+Mg #81
→ 까닭: 머리 여섯(무대 넷+d·f)이 같은 틀·같은 가운데 구슬 = 같은 뼈대, 다른 것은 창 색뿐
3. ↻ 왼쪽 큰 사람 = 엽록소 a, 가슴 Y(검은 마디+흰 알 셋) = 메틸기 CH₃ #165
→ 까닭: 두 큰 사람이 가슴 기호만 다름(Y ↔ 포크) = a·b는 곁가지 하나 차이. 창 빨강|파랑이 내리는 빨강·파랑 줄과 같은 색 짝 = 이 빛을 받음
4. ↻ 오른쪽 큰 사람 = 엽록소 b, 갈퀴 넷 포크 = 포르밀기 CHO #166
→ 까닭: 창 주황|청록은 왼쪽과 다른 색 짝 = 다른 구간을 맡음. 초록 줄이 들어와 V자로 튕기고 창에 초록 칸이 없음(비켜 감) = 초록은 안 씀
5. 망토 당근 = 카로티노이드(약속표 밖, 소리·빛깔), 보라+청록 줄
→ 까닭: 머리·꼬리 없음 = 엽록소 아닌 색소. 흰 빛기둥이 a 곁을 지나 망토에서 멈춰 번지고 망토가 a의 몸 앞을 덮음 = 센 빛을 대신 막음
6. 노란 물결선 3
→ 까닭: a·당근·b에서 하나씩 세 줄이 모두 작은 쌍 머리로만 모이고 쌍엔 색 줄이 없음 = 에너지가 안테나에서 쌍으로 모임(화살표 없어 이 대비로 방향을 읽음)
7. 가운데 작은 두 사람 = 반응중심 엽록소 a 특수쌍(Y 가슴)
→ 까닭: 큰 셋 ↔ 작은 둘, 한가운데·뒤쪽, 창이 흰 빈 칸 = 안테나는 많고 반응중심은 한 쌍이며 빛을 직접 안 받음
8. 그릇+노란 공
→ 까닭: 한 사람은 받치고 한 사람은 공을 넣는 손(동작) = 쌍이 들뜬 전자를 1차 수용체에 건넴. 약속표엔 없고 동전(#8)이 아닌 둥근 구슬
9. 점선+땅 위 작은 해+열줄 3
→ 까닭: 같은 노란 공이 그릇 속·땅 위 둘 + 가는 점선 = 같은 에너지의 곁길(잃는 몫). 열인지 형광인지는 모름

### 구역4 프리즘 벤치 — **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 색소 d·f**
1. 프리즘+흰 기둥 → 7색 띠
→ 까닭: 기둥 하나가 들어가 일곱 띠로 갈라짐(1→7), 보라가 가장 크게 휨 = 백색광은 여러 색의 합
2. ↻ 초록 마디 실 하나가 모든 색 밑을 지나고 같은 머리 아이콘 9+당근 1이 줄지어 창 색만 다름 = #126
→ 까닭: 같은 실·같은 머리를 나란히 두고 빛 색만 바뀜 = 결과 차이의 원인은 빛 색 하나
3. 호기성 세균 무더기
→ 까닭: 큰 무더기가 양 끝(보라~파랑·빨강)에, 청록·주황엔 작은 흔적, 초록~노랑 밑은 빔 = 작용 스펙트럼 양끝 높고 가운데 움푹
4. ↻ 밝은 방울 #17 = O₂ 약 25
→ 까닭: 방울이 무더기 바로 위에 몰리고 큰 무더기일수록 많음 = 세균이 O₂ 나오는 곳으로 모임
5. 아이콘 줄: 보라·파랑·빨강=a, 청록·주황(+포크)=b, 당근(청록 무리)=카로티노이드, 흰 창 4
→ 까닭: 창 색이 바로 위 띠 색과 같고 큰 무더기 밑엔 a 아이콘. 초록~노랑 밑 흰 창은 칸이 빔(흡수 안 됨 추정, 불확실)
6. 빨강 너머 검붉은 안개
→ 까닭: 빨강 끝에서 위·오른쪽으로 짙어짐 = 눈에 안 보이는 더 긴 파장(원적색)
7. d·f 사람 2
→ 까닭: 같은 머리 틀에 창만 검붉음 = 그 빛을 받음. d는 흐리고 왼쪽, f는 또렷하고 더 깊은 안개 쪽 = 파장 d<f 추정(흐림의 까닭은 모름)

## ③ 모르는 것·어색한 것
- 아직 모름: 막대 끝 고리, 낱장 틸라코이드, 점선+작은 해(열/형광), 흰 창 4, 노랑 줄 부재, 기공 부재, 그라나 수 6
- 헷갈릴 뻔함: 초록 방석↔요 #9, 노란 공↔동전 #8, 회색 깔개↔GTP 칩 #101(술 달린 바닥 깔개라 칩 아님)
- 이은 흔적: 하늘·지평선은 이어져 이음선 못 찾음. 광선·물결선·아이콘·글자는 평면 덧칠

## ④ 한 문장
광합성은 잎 엽육의 엽록체에서, 틸라코이드 막의 엽록소(a=CH₃, b=CHO)·카로티노이드가 빛 색을 나눠 받아 에너지를 반응중심 a 쌍에 모아 전자를 넘기고, O₂는 내강에서 밖으로 나가며, 스트로마에서는 루비스코가 CO₂를 5탄소에 붙인다. 작용 스펙트럼은 양끝이 높고 초록이 낮으며 원적색은 d·f가 쓴다.
