# 2단계 약속 적용 판독 (s45u02)

판정: 약속표가 구역2·3·4의 막힌 곳을 풀었다(루비스코·탄소 수·CO₂·스트로마·CH₃/CHO·포르피린 고리·O₂). 구역1(잎)은 해당 약속이 없어 그대로. ATP 동전·NADPH 방패는 이 판에 없다.

## ① 표제어 ↻
- 1순위 **광합성 — 장소(잎→엽록체: 그라나·스트로마)와 광합성 색소(엽록소 a·b·카로티노이드·d·f)·빛 흡수(스펙트럼)** 78% (↻ 70→78: 약속 소품이 색소·구조에만 몰림)
- 2순위 **광계: 안테나 색소→반응중심 엽록소 a 한 쌍** 12%

## ② 사실 → 까닭 (↻ = 1단계와 달라짐)
### 구역1 **잎 단면: 엽육 조직·관다발** (5, 유지)
1. 위 표피: 점 없는 납작 층+얇은 갈색 줄(큐티클 추정)
→ 까닭: [빛깔·대비] 점 가득한 아래 세포와 달리 점 없이 옅게 칠함 = 엽록체 없는 덮개.
2. 책상조직: 키 큰 기둥 약 10개, 점 빽빽
→ 까닭: [크기·자리] 표피 바로 아래에 길고 촘촘히, 점 최다 = 엽록체가 몰린 주력층(아래 둥근 세포와 점 수 견줌).
3. 해면조직: 둥글고 느슨, 점 적음
→ 까닭: [모양·대비] 성기게 쌓아 사이 틈(그늘)이 보임 = 기체 길(추정). 위층의 빽빽함과 견줌.
4. 관다발: 끈으로 묶은 투명 관 5, 속 푸른 물, 끝에 물방울
→ 까닭: [자리·동작] 두 층 사이 한복판, 끝에 물이 맺힘 = 물 나르는 관, 끈 = '다발'(이름). 관 5·끈 2는 까닭 모름. 관 속 푸른 알은 #122와 닮았으나 안 끼움.
5. 아래 표피: 위와 같은 납작·무점 층
→ 까닭: [자리·대비] 위·아래로 마주 서 안쪽을 감쌈. 기공(#120 셔터·#14 콩팥 둘)은 안 그려져 구멍 까닭은 안 읽힘.

### 구역2 **엽록체: 이중막·그라나·스트로마·루비스코** (8)
1. 이중막: 연초록 막 둘+사이 짙은 틈
→ 까닭: [개수·빛깔] 막 둘 사이를 짙게 = 막 사이 공간. 방울이 그 틈에 끼어 틈의 길을 보임.
2. 그라나 6(좌3·우3, 각 5~6장)
→ 까닭: [개수·모양] 같은 접시를 포갠 더미 = 틸라코이드 쌓임. 6의 뜻은 까닭 모름.
3. 더미를 잇는 가로 판 4~5
→ 까닭: [모양·대비] 쌓인 더미↔펴진 판의 대비 = 더미끼리 한 막계로 이어짐.
4. ↻ 보라 네모 점(#81 포르피린 고리+Mg가 작아진 것)
→ 까닭: [자리] 접시에만 박히고 깔개·껍질엔 없음 = 색소는 틸라코이드막에. 구역3 인물 머리와 같은 네모로 이어 읽음.
5. ↻ 흰 진주 3(#17 밝은 방울 = O₂)
→ 까닭: [자리·모양] 열린 더미 입→껍질 틈(납작히 눌림)→바깥(둥글게) 한 길. 입 열린 더미는 6개 중 하나뿐 = O₂ 나오는 곳.
6. ↻ 술 달린 얇은 회색 깔개(#164 스트로마; 1단계 '바닥판' 풀림)
→ 까닭: [자리·두께] 두툼한 초록 더미 밖·아래에 얇게 펴 깔림(stroma = 펴 깐 것). 루비스코가 그 위에 섬.
7. ↻ 루비빛 렌즈 놋쇠 스코프(#34 루비스코)
→ 까닭: [소리·자리] 루비+스코프. 더미 위가 아니라 깔개 위 = 캘빈 회로는 스트로마에서.
8. ↻ 5마디 막대+어두운 방울(#159 마디=탄소 1, #16 CO₂도 1; '푸른 물방울' 풀림)
→ 까닭: [개수·크기] 5마디+방울 1=6탄소. 렌즈가 막대 끝·방울에 닿음 = 루비스코가 5탄당(RuBP)에 CO₂를 붙임.

### 구역3 **광계: 안테나 색소→반응중심** (11)
1. 방석: 초록 납작 쿠션(틸라코이드막 추정; #9 요와 닮았으나 안 끼움)
→ 까닭: [자리] 구역2 초록 접시와 같은 초록·납작, 인물이 그 위에 서고 꼬리가 박힘 = 색소가 막 위에. 방석 약속은 없음.
2. ↻ 자주 네모 머리+은구슬(#81)=포르피린 고리+Mg, 사람=엽록소 분자(큰 2·작은 2)
→ 까닭: [빛깔·대비] 큰 둘은 빛줄기가 꽂혀 창에 색, 작은 둘은 줄기 없이 창이 빔 = 작은 둘은 빛 대신 에너지만 받음.
3. 긴 꼬리 4, 끝이 방석에 박힘
→ 까닭: [크기·자리] 몸만큼 긴 꼬리를 방석에 꽂음 = 긴 사슬로 막에 고정(추정, 약속 없음). 꼬리 없는 당근과 대비.
4. ↻ 왼쪽 큰: 빨강+파랑 창, 가슴 세 갈래+흰 알 셋(#165 CH₃) = 엽록소 a
→ 까닭: [개수·대비] 갈래 셋=수소 셋. 오른쪽과 키·머리·꼬리가 같고 가슴 기호만 다름 = a·b는 곁사슬 하나 차이. 창 색은 흡수색(파란 줄=청색광 #125).
5. ↻ 오른쪽 큰: 주황+청록 창, 가슴 갈퀴 넷 포크(#166 CHO) = 엽록소 b
→ 까닭: [개수·대비] 잔 없이 홀로 선 포크=포르밀기. 하나만 다른 나란한 쌍, 창 색이 달라(주황·청록) a가 못 먹는 색.
6. 초록 광선이 V자로 튕김
→ 까닭: [동작·대비] 다른 광선은 머리에 곧게 꽂히는데 초록만 꺾여 올라감 = 반사, 그래서 잎이 초록.
7. 당근+보라·청록 광선 = 카로티노이드(소리; 약속 없음)
→ 까닭: [개수·빛깔] 청자·청록 두 줄만 꽂히고 빨강·주황 없음 = 청자~청록 담당. 인물들의 광선과 견줌.
8. 망토에 번져 멎는 흰 빛(광보호 추정)
→ 까닭: [동작] 뻗은 팔의 망토가 모든 색 섞인 센 빛을 받아 번져 멎음 = 막아 줌(추정). '소산'은 까닭 모름.
9. 노란 물결선 3(큰a→작은왼, 당근→작은왼, 큰b→작은오)
→ 까닭: [자리·개수] 바깥 셋에서 출발해 가운데 작은 머리로만 끝남 = 에너지가 한가운데로 모임. 왼쪽 2줄·오른쪽 1줄은 까닭 모름.
10. 가운데 작은 둘: Y 둘(a 한 쌍), 손을 맞잡음
→ 까닭: [개수·자리] 같은 몸·같은 기호 둘이 한 그릇을 함께 듦 = 한 쌍이 한 몫(특수 쌍). 작고 낮게 가운데.
11. 그릇의 노란 구슬→점선→방석 위 반짝이는 공
→ 까닭: [동작·순서] 물결선이 닿은 뒤 구슬이 떨어져 반짝임 = 들뜬 전자 방출(추정; 전자 약속 없음). 공 위 김은 까닭 모름(#136 안 끼움).

### 구역4 **스펙트럼: 프리즘·엥겔만 실험·원적색 색소** (9)
1. 흰 기둥→프리즘→7색 부채
→ 까닭: [개수] 한 줄이 한 점에서 일곱 줄로 갈림 = 백색광은 여러 색의 합.
2. 마디진 실(녹조류)이 7색 밑을 가로지름
→ 까닭: [대비] 같은 실을 모든 색 밑에 둠(#126 한 가지만 바꾼 대조) = 결과 차이의 원인은 색 하나.
3. 갈색 막대 덩어리: 보라·파랑 큼, 빨강 큼, 청록·주황 작음, 초록·노랑 없음
→ 까닭: [크기·자리] 덩어리가 색칠 네모 바로 위에 크기대로 모임 = 호기성 세균이 광합성 센 곳에 몰림(작용 스펙트럼이 흡수 스펙트럼과 겹침).
4. ↻ 흰 방울(#17 O₂): 큰 덩어리 위 여럿, 초록·노랑 위 없음
→ 까닭: [개수] 방울 수가 덩어리와 함께 늘고 줆 = O₂ 많은 곳이 광합성 센 곳.
5. ↻ 큰 네모 7: 보라·파랑·빨강 색칠 / 청록·초록·노랑·주황 흰색
→ 까닭: [개수·빛깔] 같은 네모(#81)를 7색마다 하나씩 줄 세워(#126) 색칠=흡수, 흰=비흡수 = 엽록소 a는 청자·적색만(추정).
6. ↻ 작은 네모 2(청록·주황)+작은 포크 = 엽록소 b(1단계 'T' 풀림: #166)
→ 까닭: [크기·자리] a의 흰 칸(청록·주황) 곁에만 작게 덧댐 = b가 a의 빈 곳을 메움. 작은 덩어리도 그 위에 모임.
7. 당근 아이콘 하나(청록~초록 경계)
→ 까닭: [개수·자리] a의 흰 칸 사이에 하나만 = 카로티노이드가 그 틈을 보충하는 보조(추정).
8. 빨강 끝 너머 적갈색 안개
→ 까닭: [자리·빛깔] 7색 줄이 끝난 뒤에만 번지고 방울·덩어리 없음 = 가시광선 밖 원적색(#127 전구는 안 끼움).
9. d(가까움·흐림)·f(더 안쪽)
→ 까닭: [자리·빛깔] 줄이 아닌 안개 속에만 서고 창이 안개처럼 붉음 = 적색 밖 빛 흡수, 안쪽일수록 더 긴 파장(f). 그 밖은 까닭 모름.

## ③ 풀림·남음
- ↻ 풀림: 회색 바닥판=스트로마(#164), 푸른 물방울=CO₂(#16·#159), 포크 4갈래=갈퀴 넷 포크 CHO(#166), 'T'=작은 포크, 흰 진주·방울=O₂(#17).
- 남은 모름: 관 5·끈 2, 그라나 6, 깔개 위 낱장 접시(스트로마 틸라코이드 추정), 막대 아래 끝 고리, 공 위 김, 물결선 줄 수.
- 약속 없어 안 끼움: 당근·프리즘·무지개·벤치·세균·꼬리·그릇·망토·방석·안개.
- 이음: 보라 네모·광선·물결선·d/f·작은 포크는 디지털 도형.

## ④ 한 문장 ↻
빛은 엽록체 틸라코이드막 위 엽록소 a·b·카로티노이드(안테나)에 청자·적색 위주로 흡수돼(초록은 반사) 반응중심 엽록소 a 한 쌍으로 모이고, O₂는 밖으로 나가며, 스트로마의 루비스코가 5탄당에 CO₂를 붙인다 — 스펙트럼 실험이 증거다.
