# stage1 (생판: 그림만 보고)

## ① 판 전체 표제어
- 1순위 **광합성의 장소와 색소: 잎 → 엽록체 → 광합성 색소 → 빛 스펙트럼** (70%)
- 2순위 **광합성 명반응의 시작: 광계(안테나 색소 → 반응중심 에너지 전달)** (20%)
- 근거: 잎 단면 → 달걀형 엽록체 → 색소 인물들 → 프리즘·벤치로 확대·축소가 이어진다. 전자전달계·ATP 합성효소·NADPH는 없고 칼빈회로는 망원경 하나뿐이다.

## ② 구역별 (왼쪽부터 4구역)
### 구역1 **잎의 구조(엽육·관다발)** — 7개
1. 맨 위 얇은 갈색 판 = 큐티클 (자리·색)
2. 그 밑 연한 상자 세포 5칸, 초록 점 없음 = 상표피, 엽록체 없음 (색·개수)
3. 빽빽한 세로 기둥 10개, 초록 점 많음 = 책상조직, 빛 쪽·엽록체 최다 (모양·자리)
4. 아래 둥근 통나무 단면 4~5층, 점 적음 = 해면조직 (모양)
5. 은색 파이프 5개를 갈색 띠 2개로 묶음 = 관다발(다발=묶음 말장난), 파이프=물관 (뜻·개수)
6. 파이프 속 파란 물 + 끝에 물방울 1개 = 물관이 엽육에 물 공급 (색)
7. 맨 아래 연한 상자 5~6칸 = 하표피 (자리). 기공·공변세포는 안 그려짐

### 구역2 **엽록체의 구조** — 8개
1. 달걀 껍질 2겹(점선 든 연한 띠 둘, 사이는 진한 초록) = 외막·내막 이중막과 막 사이 공간 (개수 2)
2. 속을 채운 회색 액체 = 스트로마 (자리)
3. 동전 더미 6개(왼3+오른3), 더미당 3~7장 = 그라나와 틸라코이드 (모양·개수)
4. 더미끼리 잇는 납작한 초록 띠 = 스트로마 라멜라 (모양)
5. 원반 위 보라 네모 점(3열×6~7줄) = 틸라코이드 막에 박힌 엽록소·광계 (자리)
6. 맨 위 원반의 검은 구멍 = 틸라코이드 내강 (모양)
7. 흰 공 3곳(내강 입구 → 두 막 사이에 눌린 납작 공 → 바깥에 뜬 공) = O2, 내강에서 물 광분해로 생겨 이중막을 지나 방출 (자리·개수 3)
8. 바닥 양탄자 위 황동 망원경(통 3마디)+줄무늬 팔(5마디)+루비+회청 물방울 = 스트로마 칼빈회로, 루비≈루비스코, 5C→3C, CO2 고정 (소리·개수; 추정 50%)

### 구역3 **광합성 색소와 광계(안테나 → 반응중심)** — 11개
1. 왼쪽 큰 인물: TV 머리 줄무늬 중 보라·파랑·빨강만 진함, 가슴 Y(흰 점 3) = 엽록소 a(–CH3), 보라-파랑·빨강 흡수 (색·개수 3)
2. 오른쪽 큰 인물: 파랑·청록·주황만 진함, 가슴 포크(4갈래) = 엽록소 b(–CHO, 포크~포밀), 파랑·주황 흡수 (소리·색)
3. 두 머리 모두 초록 빛줄기만 V자로 튕김, 노랑은 흐려짐 = 초록은 반사 (동작)
4. TV 가운데 은색 공 = 중심 Mg, 보라 네모 틀 = 포르피린 고리 (모양·뜻)
5. 큰 인물마다 긴 꼬리 1개가 방석에 꽂힘 = 피톨 꼬리, 방석 = 틸라코이드 막 (모양)
6. 주황 당근 인물 = 카로티노이드, 보라·청록 빛을 받음 = 청~청록 흡수 보조색소 (소리·색)
7. 망토에 닿아 번지는 흰 광선 = 과잉 빛 에너지 소산, 광보호 (동작)
8. 금색 물결선 3줄(큰 둘·당근 → 작은 인물) = 보조색소가 모은 에너지의 공명 전달 (모양)
9. 작은 인물 2명(흰 화면, Y 표식) = 반응중심 엽록소 a 특별쌍 (개수 2)
10. 둘이 든 그릇 + 노란 공 = 들뜬 전자를 1차 전자수용체로 전달 (동작)
11. 모두를 두른 밧줄 고리(매듭 1) = 광계 복합체 (모양)
(땅의 노란 광구 + 열 물결 3줄 + 점선은 모름)

### 구역4 **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 색소 d·f** — 9개
1. 흰 기둥 빛 → 삼각 프리즘 = 백색광 분산 (모양)
2. 부채꼴 7색(보·파·청록·초·노·주·빨), 보라가 가장 가파르게 꺾임 (개수 7)
3. 벤치 위 연두 실(직사각 세포 줄) = 사상 조류 시료 (모양)
4. 올리브 막대 세균(편모)이 보라-파랑 끝과 빨강 끝에 크게 2무더기, 초록·노랑엔 몇 마리 = 호기성 세균, 광합성 많은 파장 = 작용 스펙트럼 (자리·개수)
5. 흰 점 방울 = O2, 세균 몰린 곳 위로 많이 오름 (자리)
6. 벤치 윗줄(Y 표식) 7칸 중 보라·파랑·빨강 3칸만 색 = 엽록소 a 흡수 (개수 3/7)
7. 아랫줄(포크 표식) 7칸 중 파랑·청록·주황 3칸 = 엽록소 b 흡수 (개수 3/7)
8. 당근 아이콘 + 청록 막대 = 카로티노이드가 청록 영역 흡수 (소리·색)
9. 붉은 안개 속 TV 인물 2명, 노란 글자 d·f = 엽록소 d·f, 빨강 너머 원적색(700nm 이상) 흡수, d는 흐리고 f는 뚜렷 (글자·자리)

## ③ 뜻 모를 것·어색한 것·헷갈림·이어 붙인 흔적
- 모름: 망원경(루비스코?), 양탄자 뒤 가장자리의 작은 술 같은 줄 약 10개, 땅의 노란 광구·열 물결·점선(열·형광? ATP?), 밧줄 고리 정체, 작은 인물 화면이 흰색인 이유, d가 흐린 이유, 물관 파이프 오른쪽 끝이 비어 보임, 갈색 띠 2개의 뜻(유관속초?).
- 어색: 잎에 기공이 없음, 스펙트럼이 부채꼴로 휘어짐, 당근에겐 2색 빛만 오고 큰 인물에겐 6색 빛이 옴.
- 헷갈림: 보라 네모가 TV 틀·틸라코이드·벤치 칸에서 같은 기호로 반복됨, Y(a)와 포크(b), 흰 공과 흰 점(둘 다 O2로 읽음), 당근 인물과 당근 아이콘.
- 이어 붙인 흔적: 잎 블록 세로 이음선(모서리), 보라 네모·Y·포크·당근 아이콘·d·f 글자·물결선·점선·색 막대는 납작한 디지털 겹침(손그림 질감과 다름), 흰 공 3개는 렌더 질감, 붉은 안개는 수채 번짐, 규모가 잎 → 엽록체 → 분자 → 실험으로 점프.

## ④ 한 문장
광합성은 잎 엽육세포의 엽록체 틸라코이드 막에서, 엽록소 a·b와 카로티노이드(그리고 원적색의 d·f)가 보라-파랑과 빨강-주황 빛을 흡수하고(초록은 반사) 그 에너지를 반응중심으로 모아 시작되며, 이는 흡수·작용 스펙트럼(엥겔만 실험)으로 확인된다.
