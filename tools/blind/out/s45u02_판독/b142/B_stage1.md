# 1단계 생판 — s45u02 (사전정보 없이 그림만 보고)

## ① 판 표제어
- 1순위 **광합성 색소와 스펙트럼(흡수·작용) — 장소(잎→엽록체)에서 색소·광계·원적색 엽록소까지** 55%
- 2순위 **엽록체 구조와 광계(안테나 색소→반응중심), 명반응의 무대** 25%
- 근거: 중앙·벤치·붉은 구름이 색소·파장 이야기, 앞 2구역은 색소가 사는 곳.

## ② 구역별 (왼→오른, 5구역. 4·5는 한 장면)
### 구역1 **잎 단면(엽육·관다발)** — 8개
1. 3D 블록 = 잎 단면, 광합성 기관(모양)
2. 맨 위 갈색 얇은 띠 = 큐티클(자리)
3. 위·아래 납작·창백한 한 줄, 초록 점 없음 = 표피(엽록체 없음)
4. 위쪽 키 큰 기둥 세포 10개, 초록 타원 빽빽 = 울타리조직(모양·개수)
5. 아래 둥글고 성긴 세포, 엽록체 적고 틈 = 해면조직(공기 틈)
6. 투명 파이프 5개, 단면마다 파란 물 = 관다발의 물관(관+다발, 개수 5)
7. 갈색 띠 2개로 묶음 = 다발(뜻)
8. 파이프 끝 물방울 1 = 물이 엽육으로 공급(약함)

### 구역2 **엽록체 구조와 스트로마의 탄소고정** — 10개
1. 달걀형 두꺼운 벽: 밝은 막 2겹 + 사이 어두운 띠 = 이중막·막간공간(개수 2)
2. 납작 원반 더미 6개(좌3·우3) = 그라나, 지그재그 납작 판 = 스트로마 라멜라
3. 더미마다 보라 사각(흰 점) 3열×6줄(왼쪽 맨 아래만 7줄, 오른쪽 맨 아래만 2줄) = 틸라코이드막의 엽록소·광계
4. 맨 위 더미 윗면이 열려 어두운 속 = 내강(루멘)
5. 그 위 흰 구슬 = O2(내강 물 분해 산소)
6. 흰 구슬 3개(더미 위→막 사이 납작 방울→밖) = O2가 이중막을 빠져나감(개수 3)
7. 바닥 회색 깔개 = 스트로마(stroma=깔개, 소리·뜻)
8. 망원경 + 붉은 보석 렌즈 = ruby+scope = 루비스코(소리)
9. 5마디 줄무늬 막대(갈·흰·갈·흰·갈) = RuBP 5탄당(개수 5)
10. 막대 끝 회청색 방울 = CO2(추정)

### 구역3 **엽록소 a·b·카로티노이드와 광계** — 13개
1. 초록 방석(주머니꼴) 위에 선 인물들 = 틸라코이드막 위 색소(추정, 뜻)
2. 사각 보라 TV 머리 + 은구슬 = 엽록소 고리 머리 + 중심 Mg(모양·색)
3. 인물마다 긴 꼬리가 방석에 닿음 = 피톨 꼬리(막에 박힘); 당근만 꼬리 없음
4. 왼 큰 인물: 가슴 삼지창(끝 흰 구슬 3) = –CH3 = 엽록소 a. 화면 7줄 중 보라·파랑·빨강만 진함 = 청자+적색 흡수
5. 오른 큰 인물: 가슴 포크(4갈래) = –CHO(포크≈포밀, 소리) = 엽록소 b. 진한 줄 파랑·청록·주황
6. 양쪽 초록 빔은 V자로 튕겨 나감 = 초록 반사(개수 2)
7. 주황 당근 = 카로티노이드(소리·색). 머리 잎에 보라+청록 빔 = 청자~청록 흡수
8. 당근 망토에 흰 빔이 닿아 번짐 = 과잉 빛 소산·광보호(뜻, 추정)
9. 가운데 작은 인물 2(작은 삼지창, 화면 흰색) = 반응중심 엽록소 a 한 쌍(개수 2)
10. 둘이 든 그릇 속 노란 구슬 1 = 들뜬 전자 1개 내줌
11. 점선 아래 빛나는 구슬 = 전자수용체로 이동(추정)
12. 금빛 물결선 3줄(a·당근·b → 가운데 쌍) = 안테나→반응중심 에너지 전달(개수 3)
13. 밧줄 고리 + 매듭 = 색소가 묶인 한 광계 / 하늘 빔 4갈래(7색 2, 보라+청록 1, 흰 1)

### 구역4 **프리즘·엥겔만 실험·흡수표** — 8개
1. 흰 기둥빛 → 프리즘 → 7색 띠(보라·파랑·청록·초록·노랑·주황·빨강) = 백색광 분산
2. 벤치 위 초록 칸칸 줄 = 실 모양 녹조류
3. 올리브 막대 무리 = 호기성 세균(O2 쪽으로 모임)
4. 큰 무리 2곳: 보라~파랑, 빨강 = 작용스펙트럼 최대
5. 초록·노랑엔 거의 없음, 청록·주황엔 소수 = 초록 효율 낮음, 보조색소 몫
6. 흰 점 = O2 방울(보라 8, 청록 4, 주황 4, 빨강 10여 개)
7. 벤치 2줄×7칸 표: 윗줄 삼지창(a) 보라·파랑·빨강 3칸 색, 아랫줄 포크(b) 파랑·청록·주황 3칸 색, 나머지 흰 칸 = 흡수스펙트럼
8. 당근 아이콘 + 청록 막대 = 카로티노이드 청록 흡수; 막대가 세균 무리와 이어짐 = 작용≈흡수의 합

### 구역5 **엽록소 d·f — 원적색광** — 5개
1. 빨강 끝 바깥 짙은 적갈 안개 = 원적색(700nm↑)
2. 'd' 인물(흐릿, 안개 얕은 쪽) = 엽록소 d
3. 'f' 인물(더 선명·큰 TV, 안개 깊은 쪽) = 엽록소 f(더 긴 파장)
4. 둘 다 은구슬(Mg) + 짙은 적색 화면 = 같은 엽록소 계열
5. a→d→f 왼→오른 = 흡수 파장 점점 길어짐

## ③ 잔여 메모
- 뜻 모름: 깔개 먼 가장자리 작은 술 10여 개; 매듭에서 늘어진 두 가닥; 노란 구슬 위 물결 3줄; 'd'만 흐린 이유; 흰 기둥 중간 얼룩; 갈색 띠 2개의 정확한 뜻
- 헷갈림: 삼지창(a)↔포크(b); 둥근 구슬 4종(은=Mg, 흰=O2, 노랑=전자, 벤치 흰 점); 보라 사각 3곳(막·TV틀·표); 파란 물방울↔회청색 방울; 청록↔파랑
- 이음 흔적: 납작 아이콘(보라 사각·삼지창·포크·당근·d·f·망원경)과 빔·물결선·점선이 붓칠 위에 덧붙은 느낌; x≈1500에서 하늘이 청회→크림, 흰 기둥이 경계를 가림; 붉은 구름이 무지개와 겹침; 구역 사이 수평선은 매끈

## ④ 한 문장
엽록체 틸라코이드막의 엽록소 a·b·카로티노이드(와 원적색 d·f)는 서로 다른 파장을 흡수해 에너지를 반응중심 a에 모으고, 그 흡수 스펙트럼의 합이 엥겔만 작용스펙트럼(청자·적색 높고 초록 낮음)으로 나타난다.
