# stage2 (약속표 적용 재판독 + 까닭; 숫자 = 약속표 줄, ↻ = 1단계와 달라짐)

## ① 판 전체 표제어
- 1순위 **엽록체 구조와 광합성 색소·광계(빛을 받는 곳과 방법)** (75%) ↻ 70→75 (164·167·81·165·166·168·170이 풀림)
- 2순위 **광합성 명반응의 시작(광계 → 들뜬 전자 → 1차 전자수용체)** (15%)
- 판정: 약속으로 구역2·3의 「모름」(망원경·밧줄·노란 공)이 풀림. 구역1·4는 약속과 거의 무관. 동전·방패·H⁺ 방울이 없어 전자전달·합성은 이 판 몫이 아님.

## ② 구역별 (사실 → 까닭)
### 구역1 **잎의 구조(엽육·관다발)** — 7개 (적용 약속 없음)
1. 큐티클: 맨 위 갈색 띠 → 까닭: 세포 칸막이 없는 한 장이 상표피를 덮고 아래쪽은 더 얇은 회색 띠(위↔아래 견줌). 방수 같은 쓸모는 그림에 없음 → 까닭 모름
2. 상표피 5칸: 연하고 초록 점 없음 → 까닭: 밑 책상조직(점 약 15~18/칸)과 견줘 점 0 = 엽록체 없는 투명 덮개
3. 책상조직 10칸: 길쭉·빽빽 → 까닭: 빛 쪽에 붙고 점이 해면조직(약 4/칸)의 3~4배 = 엽록체를 빛 가까이 몰아 둠
4. 해면조직 4~5층: 둥근 통나무 단면 → 까닭: 틈 없는 위 기둥과 달리 사이에 어두운 삼각 틈이 남음. 틈의 쓸모는 까닭 모름
5. 관다발: 은색 파이프 5 + 갈색 띠 2 → 까닭: 같은 관 5개를 띠로 묶음(다발=묶음), 책상·해면 사이를 가로지름. 띠가 둘인 까닭 모름
6. 물관의 물: 관마다 파란 물(5/5) + 방울 1 → 까닭: 모든 관이 같은 파랑으로 가득 = 물 통로, 방울이 아래 엽육 쪽으로 떨어짐 = 물 공급(H⁺ 방울 119·유리알 122는 아니라 적용 안 함). 오른쪽 끝이 빈 까닭 모름
7. 하표피 5~6칸: 위와 같은 연한 칸 → 까닭: 같은 표피가 엽육을 위아래서 감쌈. 기공(14·120의 물건)이 비어 있음 = 이 판은 기공을 안 다룸(왜 뺐는지 모름)

### 구역2 **엽록체의 구조** — 8개
1. 이중막 2겹 → 까닭: 같은 연한 띠 둘이 나란하고 사이는 좁은 진한 초록 = 막 2장 + 좁은 막 사이(O₂ 방울이 여기서만 납작해짐)
2. ↻ 스트로마 = 바닥에 펴 깐 회색 깔개, 양 끝 술(164; 1단계 「회색 액체」 정정) → 까닭: 틸라코이드 더미와 떨어진 바닥에 깔리고 그 위에 루비스코가 놓임 = 막 밖 바닥 공간
3. ↻ 그라나 6(왼3+오른3) = 팬케이크로 포갠 쿠션 무더기(167), 더미당 3~7장 → 까닭: 높을수록 보라 네모 줄이 늘어남(작은 더미 6개 ↔ 큰 더미 18~21개) = 포갤수록 색소 자리가 늘어남
4. 스트로마 라멜라: 더미를 잇는 납작한 띠 → 까닭: 좌우 더미를 같은 높이 띠가 이어 한 덩어리 막으로 보임. 속이 이어지는지는 까닭 모름
5. ↻ 보라 네모 점 = 엽록소 분자(자주빛 네모 액자 81), 원반마다 3개 → 까닭: 모든 원반에 같은 수로 박힘 = 색소는 막마다 있음
6. ↻ 루멘 = 맨 위 원반의 검은 구멍(167 텅 빈 속) → 까닭: 그 바로 위에 O₂ 방울이 얹힘 = O₂가 루멘 쪽에서 나옴
7. ↻ 밝은 방울(17) 3곳 = O₂: 루멘 입구 → 두 막 사이(납작) → 바깥 → 까닭: 안→틈→밖으로 놓이고 틈에서만 눌림 = 좁은 막 사이를 빠져나가 방출되는 길
8. ↻ 루비스코(34) + 5마디 막대(159 마디=탄소) + 막대 끝 어두운 방울 1(16 CO₂) → 까닭: 5탄소 막대에 방울 1이 렌즈 맞닿은 자리에 붙음 = 루비스코가 5C에 CO₂를 붙임. 위 밝은 방울(나감) ↔ 아래 어두운 방울(붙음)이 위아래로 맞서 명반응(막)·탄소 고정(스트로마)의 자리가 다름. 스코프 통 3마디의 뜻은 모름

### 구역3 **광합성 색소와 광계(안테나 → 반응중심)** — 12개
1. ↻ 엽록소 a = 왼쪽 큰 인물, 가슴 Y = CH₃(165), 진한 줄 3/7(보라·파랑·빨강) → 까닭: 빛줄기가 들어가는 색 = 진한 줄 색. 노랑·주황 줄기는 닿기 전 흐려짐 = 못 받고 지나감(비켜 감)
2. ↻ 엽록소 b = 오른쪽 큰 인물, 갈퀴 넷 포크 = CHO(166), 진한 줄 3/7(파랑·청록·주황) → 까닭: 옆 인물과 키·자세·액자가 같고 가슴 표식과 진한 줄 자리만 다름(하나만 다름) = 곁사슬 하나가 받는 색을 옮김
3. ↻ 두 TV 머리 = 포르피린 고리 + Mg(81 자주빛 액자·은빛 구슬) → 까닭: 둘 다 같은 액자·구슬 = 공통 골격
4. ↻ 초록 V 되튀김(169) → 까닭: 같은 V가 두 액자 윗변에서 튀고 속 초록 줄은 옅음(조금만 받음) = 초록은 돌려보내 초록으로 보임
5. ↻ 방석 = 속 빈 초록 쿠션 = 틸라코이드(167), 인물 4명의 꼬리가 꽂힘 → 까닭: 꼬리는 엽록소 4명(큰 a·b, 작은 둘)에게만 있고 당근엔 없음 = 엽록소만 꼬리로 막에 박힘
6. 당근 인물 = 카로티노이드(표에 없음, 소리·색) → 까닭: 큰 인물엔 6색 줄기가 오는데 당근엔 보라·청록 2줄기뿐 = 짧은 파장 쪽만 받음
7. 망토 + 흰 광선 = 광보호(추정) → 까닭: 강한 흰빛이 엽록소 a 쪽으로 내리는 길목에 망토를 펴 받아 번져 사라짐. 열로 흩는다는 표시는 없음 → 그 부분 까닭 모름
8. 금색 물결선 3줄 = 에너지 전달 → 까닭: 큰 a·당근 → 왼쪽 작은 인물, 큰 b → 오른쪽 작은 인물로 모임(바깥 → 한가운데)
9. 작은 인물 2 = 반응중심 엽록소 a(가슴 Y, 흰 화면) → 까닭: 큰 인물에 둘러싸인 가운데·뒤, 작고 둘뿐, 줄무늬 없는 빈 화면 = 직접 받는 색 없이 전달받는 자리
10. ↻ 사발 + 노란 공 = 1차 전자수용체 + 들뜬 전자(168) → 까닭: 둘이 끈으로 함께 멘 사발(170 한 몸), 왼쪽 손이 공에 닿음 = 건네는 순간, 받침 없음 = 혼자 선 구조가 아님
11. ↻ 밧줄 고리 = 광계(170; 1단계 「모름」) → 까닭: 큰 인물·당근·작은 둘·사발을 한 줄이 모두 둘러 맴 = 떨어지지 않는 한 몸
12. ↻ 땅의 노란 공 + 열 물결 3 + 빛살 + 점선 = 받는 이 없이 떨어진 들뜬 전자(추정; 「모름」에서 부분 풀림) → 까닭: 같은 공이 사발(높음·담김)과 맨 땅(낮음·열 물결)에 따로 있고 점선이 사발 쪽에서 내려옴 = 못 넘기면 열·빛으로 흩음. 표에 없어 확정 못 함

### 구역4 **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 색소 d·f** — 9개
1. 흰 기둥 빛 → 프리즘 → 부채꼴 7색 → 까닭: 굵은 한 줄기가 일곱 갈래로 갈라짐(1→7), 보라가 가장 가파르게 꺾이고 빨강이 가장 덜 꺾임
2. 연두 실 = 사상 조류(직사각 세포 줄) → 까닭: 한 가닥이 모든 색 밑을 지남 = 같은 시료에 색만 바꿈(126 한 가지만 바꾼 대조)
3. 세균(올리브 막대): 보라-파랑 약 55 / 청록 3 / 초록 1 / 노랑 2 / 주황 4 / 빨강 약 25 → 까닭: 양 끝이 크고 가운데가 거의 빔 = 광합성 많은 파장(작용 스펙트럼), 같은 실이라 원인은 색 하나
4. ↻ 밝은 방울(17) = O₂: 보라-파랑 8 · 청록 4 · 초록 1 · 노랑 1 · 주황 4 · 빨강 약 10 → 까닭: 세균 무리와 같은 순서로 많음 = 세균이 O₂ 쪽으로 모임
5. ↻ 윗줄(Y) 엽록소 a 7칸 중 보라·파랑·빨강 3칸만 색 → 까닭: 같은 액자(81) 7개가 나란하고 채움만 다름(126). 큰 인물 a의 진한 줄과 같은 칸 = 같은 사실을 인물과 표로 두 번 보임
6. ↻ 아랫줄(포크) 엽록소 b 3칸(파랑·청록·주황) → 까닭: 윗줄과 위아래로 맞서 a가 비운 청록·주황을 b가 채움, 파랑은 둘 다 칠해짐(공통)
7. 청록·주황 막대가 윗줄 흰 칸을 지나 아랫줄에 닿음 → 까닭: a가 안 받은 빛이 b에 닿음(비켜 감) = 서로 빈자리를 메움
8. 당근 아이콘 + 청록 막대 = 카로티노이드가 청록 흡수 → 까닭: a가 비운 청록 칸 곁에 놓임. 중앙 당근엔 보라도 왔는데 여기선 청록만 → 보라가 빠진 까닭 모름
9. 붉은 안개 + d·f = 엽록소 d·f의 원적색 흡수 → 까닭: 빨강 띠 끝 너머 안개에 섬(보이는 빨강 밖), f가 d보다 크고 선명하고 더 깊이 섬 = 더 긴 파장(추정). d가 흐린 까닭 모름. 원적색 약속(127)은 전구가 없어 적용 안 함

## ③ 남은 것
- 모름: 스코프 통 3마디, 갈색 띠 2개, 파이프 오른쪽 끝, d의 흐림, 점선 출발점, 당근 아이콘의 보라 누락.
- 어색·헷갈림: 잎에 기공 없음, 스펙트럼이 부채꼴로 휘어짐, 당근 2색·큰 인물 6색, 파란 구슬(122 유리알과 닮음), 보라 네모가 TV 틀·틸라코이드·벤치 칸에 같은 기호로 반복.
- 이어 붙인 흔적: 잎 블록 세로 이음선, 보라 네모·Y·포크·당근 아이콘·d·f 글자·물결선·점선은 납작한 겹침, 흰 공은 렌더 질감, 붉은 안개는 수채 번짐.

## ④ 한 문장
엽록체 틸라코이드 막에 박힌 엽록소(a는 CH₃, b는 CHO, 모두 포르피린+Mg)와 카로티노이드가 빛을 받아(초록은 되튕김) 광계 한가운데 엽록소 a 쌍에 모아 들뜬 전자를 1차 전자수용체에 넘기며 광합성이 시작되고, O₂는 루멘에서 밖으로, CO₂는 스트로마에서 루비스코가 붙이며, 받는 색은 엥겔만 실험(작용)과 칸 표(흡수)로 확인한다.
