# 1단계 생판 — s45u02 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **광합성의 장소와 색소: 엽록체·광합성 색소·스펙트럼(빛 흡수)** — 60%
- 2순위 **광합성 명반응의 광계: 안테나 색소 → 반응중심 에너지 포획** — 20%
- 근거: 잎 → 엽록체 → 색소 분자 → 빛 파장으로 왼쪽에서 오른쪽으로 작아지며 "빛을 어디서·무엇이 받나"를 묻는다. 전자전달계·ATP 합성효소·NADPH는 없고 캘빈 회로는 망원경 하나뿐이다.

## ② 구역 (4구역)

### 구역1 (잎 단면) **잎의 구조: 엽육(울타리·해면 조직)과 관다발**
1. 맨 위 갈색 얇은 띠 = 큐티클 [자리·색] 추정
2. 위·아래 표피 = 창백한 직사각 세포(위 6개), 초록 알갱이 없음 = 엽록체 없음 [모양·개수]. 기공은 안 보임
3. 울타리 조직 = 위쪽 길쭉한 기둥 세포 10개, 초록 알갱이 빽빽 = 빛 쪽, 엽록체 최다 [모양·자리·개수]
4. 해면 조직 = 아래쪽 둥근 통나무 같은 세포, 성겨서 빈틈(공기 공간), 알갱이 적음 [모양]
5. 관다발 = 관(파이프) 5개를 띠 2개로 묶음 [소리: 관+다발·개수]. 관 속 파란 물 = 물관, 물 운반 [뜻]
6. 왼쪽 아래 관 끝 물방울 1개 = 잎 세포로 물 공급(추정)
7. 세포 속 초록 타원 알갱이 = 엽록체 [모양]
→ 7개 (확실 5)

### 구역2 (달걀) **엽록체의 구조: 이중막·그라나·스트로마와 O2 방출**
1. 달걀 + 이중 고리 = 외막·내막 2겹 [모양·개수]
2. 두 막 사이 어두운 띠 = 막 사이 공간 [자리]
3. 안쪽 회녹색 바탕·바닥 = 스트로마(기질) [자리]
4. 납작 원반 더미 6개(좌3·우3), 각 6~7장 = 그라나(틸라코이드 더미) [모양·개수]
5. 더미를 잇는 얇은 선반 = 스트로마 라멜라 [모양]
6. 원반 옆면의 보라 네모(층당 3개) = 막에 박힌 색소·광계 [자리·모양]
7. 맨 위 원반의 열린 속(내강)의 흰 공 → 막 사이 납작 흰 방울 → 바깥 흰 공 = 3개, 내강에서 생긴 O2가 밖으로 [자리·개수]
8. 바닥 낱개 원반 1개 = 쌓이지 않은 틸라코이드 — 모름
9. 바닥 망원경 + 빨간 루비 접안 = 루비+스코프 = RuBisCO, 스트로마의 CO2 고정 [소리·자리]
10. 마디 5개 막대 + 회청 물방울 = RuBP(5탄당)·CO2 (추정)
→ 10개 (확실 6)

### 구역3 (방석 위 인물들) **광합성 색소(엽록소 a·b, 카로티노이드)와 안테나 → 반응중심 에너지 전달**
1. 방석 = 틸라코이드막, 색소는 막에 박힘(추정) [자리]
2. 사각 머리틀 + 금속 공 = 엽록소 고리와 중심 Mg [모양]
3. 긴 꼬리 4개가 방석에 닿음 = 피톨 꼬리, 막에 고정 [모양·개수]
4. 왼쪽 큰 인물, 창 빨강|파랑, 광선 2줄 = 엽록소 a, 적색·청자색 흡수, 가슴 Y 기호 [뜻]
5. 오른쪽 큰 인물, 창 주황|청록, 광선 2줄 + 튕기는 초록 V = 엽록소 b, 주황·청색 흡수, 초록 반사, 가슴 포크 [뜻]
6. 당근 영웅 = 카로티노이드 [소리], 보라+청록 광선 = 청자~청록 흡수 [뜻]
7. 망토가 흰 광선을 받아 번짐 = 과잉 빛 소산, 광보호(추정)
8. 노란 물결선 3줄 = 엽록소 a·카로티노이드·엽록소 b → 반응중심 에너지 전달 [개수]
9. 가운데 작은 인물 2명(Y 기호, 창 비었음) = 반응중심 엽록소 a 한 쌍, 빛은 직접 안 받음 [개수]
10. 나무 그릇 + 노란 공 = 1차 전자수용체가 e− 받음. 점선 끝 바닥에서 김 나며 빛나는 공 = e−나 열 — 모름
→ 10개 (확실 6)

### 구역4 (프리즘·긴 의자·붉은 안개) **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 색소 d·f**
1. 흰 기둥 → 삼각 프리즘 → 무지개 7색 = 백색광 분산 [개수]
2. 의자 위 마디 있는 초록 실 = 사상 녹조류 [모양]
3. 갈색 막대 무리(호기성 세균): 보라·파랑과 빨강 쪽에 큰 무리, 청록·주황 쪽 각 5~6마리, 초록·노랑 0 = 작용 스펙트럼 [개수·자리]
4. 흰 방울(O2): 보라·파랑 7, 청록 3, 주황 3, 빨강 약 10 = 광합성 많은 곳에 O2 많음 [개수]
5. 의자 앞 보라 네모 9개의 창색 = 흡수 스펙트럼: 보라·파랑·빨강(a), 청록·주황(b, 작은 포크 표시), 흰 창 4개(초록·노랑 흡수 없음) [개수·뜻]
6. 청록 쪽 당근 아이콘 = 카로티노이드가 청록 흡수 [소리]
7. 오른쪽 짙은 붉은 안개 = 적색 너머 원적색 [자리]
8. 안개 속 'd'(반투명)·'f'(또렷) = 엽록소 d·f, 원적색 흡수 [글자]
→ 8개 (확실 5)

## ③ 뜻 모를 것·헷갈리는 것·이은 흔적
- 모름: Y(3갈래)·포크(4갈래) 기호의 뜻, 빛나는 공, 막대의 5마디, 낱개 원반.
- 헷갈림: 청록 광선이 당근과 오른쪽 큰 인물 둘 다에 들어감. Y가 큰 인물과 작은 2명에게 같이 있어 안테나 a와 반응중심 a 구별 불명. 보라 네모가 막·머리틀·의자 앞에서 다른 뜻으로 쓰임. 흰 구슬은 O2인지 공기방울인지 불명.
- 이은 흔적: 보라 네모·흰 구슬·물결선·망원경·d/f 글자·아이콘은 선이 또렷한 스티커풍, 붉은 안개는 수채 번짐, 가운데 흰 광선은 흐림. 잎 덩어리에 세로 접힘선.

## ④ 한 문장
잎 속 엽록체의 틸라코이드막에서 엽록소 a·b와 카로티노이드가 서로 다른 색(청자색·적색, 초록은 반사)의 빛을 흡수해 에너지를 반응중심으로 모으며, 이는 엥겔만 실험의 작용 스펙트럼으로 확인되고 엽록소 d·f는 원적색까지 흡수한다.
