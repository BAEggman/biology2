# 2단계 — 약속표로 다시 읽기 (s45u02) · ↻ = 1단계와 달라진 곳

## 판정
약속표로 더 잘 풀린다. 풀린 것: 세 갈래 잔가지·갈퀴 포크(모름 → 확정), 스트로마·RuBP·CO₂(추정 → 확정), 루비스코·O₂ 방울·포르피린(확인). 안 풀린 것: 그릇·노란 공 둘·망토·당근·방석·꼬리·낱개 원반. 구역1은 변화 없음. 1단계 큰 틀(4구역·표제어)은 틀린 곳이 없었다. 개수는 1단계와 같은 규칙(번호 항목, 모름 포함).

## ① 판 전체 표제어
- 1순위 **광합성의 개요와 색소: 장소(잎·엽록체의 틸라코이드/스트로마)·엽록소 a/b 구조·스펙트럼** — 70% ↻(60)
- 2순위 **광합성 색소와 광계: 안테나 → 반응중심 에너지 포획** — 15% ↻(20)
- 근거 ↻: 메틸/포르밀(a/b 구별)·스트로마·루비스코 소품이 모두 약속표에 있고, 명반응 산물(동전·방패·물레방아 아치·H⁺ 물방울)은 하나도 없다. 틸라코이드에서 O₂, 스트로마에서 CO₂ 고정이라는 '장소 나누기'가 판의 뼈대.

## ② 구역
### 구역1 (잎 단면) **잎의 구조: 엽육(울타리·해면 조직)과 관다발** — 변화 없음
큐티클(갈색 띠·추정) / 표피 6개, 엽록체 없음, 기공 소품(콩팥 모양 둘·롤 셔터) 없음 / 울타리 기둥 세포 10개, 알갱이 빽빽 / 해면 둥근 성긴 세포·알갱이 적음 / 관 5개를 띠 2개로 묶음 = 관+다발, 파란 물 = 물관 / 관 끝 물방울 1개 = 물 공급(추정) / 알갱이 = 엽록체
→ 7개 (확실 5)

### 구역2 (달걀) **엽록체의 구조: 이중막·그라나·스트로마, O₂ 방출, 루비스코** ↻
1. 달걀 + 이중 고리 = 외막·내막 2겹 / 2. 두 막 사이 띠 = 막 사이 공간
3. ↻ 스트로마 = 뒤·왼쪽 가장자리에 술 달린 회색 깔개, 담 안 바닥 [약속164] (1단계: '회녹색 바탕')
4. 원반 더미 6개(좌3·우3), 각 6~7장 = 그라나 / 5. 더미를 잇는 선반 = 스트로마 라멜라(추정)
6. ↻ 원반 위 자주 네모(층당 3) = 포르피린 고리, 엽록소가 막에 박힘 [81]
7. ↻ 밝은 방울 3개(내강 → 막 사이 → 밖) = O₂ [17]
8. 깔개 위 낱개 원반 1개 = 모름(스트로마 틸라코이드?)
9. ↻ 루비빛 렌즈 놋쇠 스코프 = 루비스코, 스트로마 위 [34] (추정 → 확정)
10. ↻ 두 빛깔 5마디 막대 = 탄소 5 = RuBP [159]
11. ↻ 막대에 붙은 어두운 물방울 = CO₂ 한 탄소 [16·159] → 5+1 = 6C, 루비스코가 CO₂ 를 붙이는 자리
→ 11개 (확실 9; 1단계 10·6)

### 구역3 (방석 위 인물들) **광합성 색소(엽록소 a·b, 카로티노이드)와 안테나 → 반응중심** ↻
1. 방석 = 틸라코이드막(추정) / 2. 자주 네모 액자 + 은빛 구슬 머리 = 포르피린 + Mg, 모두 엽록소 [81] / 3. 꼬리 4개 = 피톨 꼬리(추정)
4. ↻ 왼쪽 큰 인물: 세 갈래 잔가지(끝 흰 알 셋) = 메틸기 → 엽록소 a [165], 빨강|파랑 창 + 파란 빛줄기 = 청색광 [125]
5. ↻ 오른쪽 큰 인물: 갈퀴 넷 포크(잔 없이 홀로) = 포르밀기 → 엽록소 b [166], 주황|청록 창, 초록 V = 반사
6. ↻ 두 인물은 몸·머리틀·꼬리가 같고 곁사슬만 다름 = 한 가지만 바꾼 대조 [126] → a/b 차이는 곁사슬 하나(메틸 ↔ 포르밀), 흡수색이 갈림
7. 당근 = 카로티노이드[소리], 보라+청록 광선 / 8. 망토가 흰 광선 받음 = 광보호(추정)
9. 노란 물결선 3줄 = 안테나 → 반응중심 에너지 전달
10. ↻ 가운데 작은 2명: 메틸 가지 = 엽록소 a 한 쌍(반응중심), 창이 비어 빛을 직접 안 받음
11. 나무 그릇 + 노란 공 = 전자 받이(추정), 점선 끝 김 나는 공 = 모름
→ 11개 (확실 6; 1단계 10·6)

### 구역4 (프리즘·긴 의자·붉은 안개) **흡수·작용 스펙트럼(엥겔만 실험)과 원적색 색소 d·f** ↻
1. 흰 기둥 → 프리즘 → 7색 / 2. 마디 있는 초록 실 = 사상 녹조류 / 3. 세균: 보라·파랑·빨강에 큰 무리, 청록·주황 각 5~6, 초록·노랑 0 = 작용 스펙트럼
4. ↻ 흰 방울 = O₂ [17]: 보라·파랑 7, 청록 3, 주황 3, 빨강 약 10
5. ↻ 의자 앞 자주 네모 9개 = 같은 포르피린 소품이 줄지어 창 색만 다름 = 파장만 바꾼 대조 [81·126] → 보라·파랑·빨강(a)
6. ↻ 청록·주황 네모 곁 작은 포크 2개 = 포르밀기 → 엽록소 b [166]
7. 흰 창 4개 = 초록·노랑 흡수 없음 / 8. 청록 쪽 당근 아이콘 = 카로티노이드
9. 붉은 안개 = 원적색(추정; 약속표의 새까만 전구와 모양이 달라 끼우지 않음) / 10. 안개 속 d·f = 엽록소 d·f(머리틀 = 포르피린)
→ 10개 (확실 8; 1단계 8·5)

## ③ 모름·헷갈림·이은 흔적
- 약속표에 없어 그대로 둔 것: 당근·망토·물결선·꼬리·방석·그릇·빛나는 공·낱개 원반·막대 끝 고리·붉은 안개·관다발 띠.
- 약속표에 있는데 판에 없는 것: 동전·나무 방패·물레방아 아치·H⁺ 물방울·말굽 자석·초승달 → ATP·NADPH·C4·CAM·기공은 이 판 몫이 아님.
- 헷갈림: 청록 광선이 당근과 b 둘 다에 닿음. 관다발의 파란 알은 청색광 수용체 구슬 같으나 물방울이 새어 물로 읽음. 초록 V는 V자 이음쇠가 아니라 반사 광선.
- 이은 흔적: 1단계와 같음(스티커풍 아이콘·붉은 안개 수채·잎 접힘선).

## ④ 한 문장 ↻
잎 속 엽록체에서 틸라코이드의 엽록소(메틸 a·포르밀 b)가 청자색·적색 빛을 받아 O₂ 를 내고 스트로마의 루비스코가 RuBP(5C)에 CO₂ 를 붙이며(6C), 엥겔만 스펙트럼은 초록이 비고 엽록소 d·f 는 원적색까지 간다.
