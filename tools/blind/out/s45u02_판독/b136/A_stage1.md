# 1단계 생판 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **광합성의 장소(잎·엽록체)와 광합성 색소의 빛 흡수·스펙트럼** — 80%
- 2순위 **명반응의 광계: 안테나 색소 → 반응중심 엽록소 a** — 12% (가운데 구역이 이것이라 겹침)
- 나머지 8%: 엽록체 구조 단독 / 광합성 개관

## ② 구역 (왼쪽부터 4구역)

### 구역1 **잎의 단면 구조** — 읽힌 6
1. 맨 위 얇은 갈색 띠 = 큐티클 (자리·색)
2. 그 아래 납작·창백하고 초록 점 없는 세포 줄 = 상표피 (모양)
3. 키 큰 기둥 세포 10개, 초록 점 빽빽 = 울타리조직, 엽록체 최다, 빛 쪽(위) (모양·개수·자리)
4. 아래쪽 통나무 단면처럼 둥글고 느슨히 쌓인 세포, 점 적고 틈 있음 = 해면조직·공기 틈 (모양)
5. 은빛 파이프 5개 묶음(갈색 띠 2), 끝마다 푸른 물, 한 방울 떨어짐 = 관다발(물관)의 물 공급 (모양·개수·뜻)
6. 맨 아래 납작·창백한 세포 줄 = 하표피, 기공은 안 보임 (자리)

### 구역2 **엽록체 구조** — 읽힌 9 (추정 2 포함)
1. 달걀 단면 껍질이 두 겹, 사이에 어두운 틈 = 이중막(외막·내막)·막 사이 공간 (개수 2)
2. 팬케이크 더미 6개(좌3 우3) = 그라나 (모양·개수)
3. 더미를 이루는 납작 원반 = 틸라코이드, 바닥에 낱개 1개 (모양)
4. 더미 사이를 잇는 납작한 띠 = 스트로마 라멜라(그라나 사이 틸라코이드) (모양·자리)
5. 원반마다 보라 네모(흰 점) 3개 = 막에 박힌 엽록소·광계 복합체 (모양·개수)
6. 맨 위 더미의 열린 어두운 틈 = 틸라코이드 내부(루멘). 거기서 흰 공 3개가 막 사이를 지나 밖으로 = O2 방출, 물 분해는 루멘 쪽 (모양·개수·뜻)
7. 바닥의 술 달린 회색 깔개 = 스트로마(그리스어 '깔개') (뜻·자리)
8. 루비 렌즈 달린 망원경 = 루비+스코프 = 루비스코, 칼빈회로 CO2 고정 (소리) 【추정】
9. 5마디 막대(윗끝 회청색 물방울·아랫끝 고리) = RuBP 5탄당 + CO2 (개수) 【추정】

### 구역3 **광합성 색소와 안테나→반응중심 에너지 전달** — 읽힌 15 (추정 3 포함)
1. 네모 고리 머리 + 은빛 구슬 = 엽록소 고리와 중심 Mg (모양) 【추정】
2. 긴 꼬리 = 피톨 꼬리, 막에 박힘 (모양) 【추정】
3. 왼쪽 큰 인물 = 엽록소 a, 가슴 Y(구슬 3) = 메틸기 -CH3 (모양·개수)
4. a의 창 빨강+파랑, 들어오는 빛줄기도 빨강·파랑 = 적색·청색 흡수 (색)
5. 오른쪽 큰 인물 = 엽록소 b, 가슴 포크 = 포르밀기 -CHO (소리)
6. b의 창 주황+청록, 빛줄기 주황·청록 = 그 색 흡수 (색)
7. 초록 빛줄기가 V자로 튕겨 나감 = 초록 반사, 그래서 잎이 초록 (모양)
8. 주황 당근 = 카로티노이드 (소리·모양), 꼬리·고리 없음
9. 당근 머리 위로 보라+청록 빛 = 청자~청록 흡수 (색)
10. 당근 망토가 굵은 흰 빛을 막아 흐려짐 = 광보호, 과잉 에너지 소산 (동작)
11. 금빛 물결선 3줄(큰 a→작은 a, 당근→작은 a, 큰 b→작은 a) = 안테나에서 반응중심으로 에너지 전달 (개수)
12. 가운데 작은 인물 2명, 가슴 Y = 반응중심 엽록소 a 특수쌍 (개수 2·자리)
13. 둘이 함께 든 그릇 + 노란 공 = 들뜬 전자를 1차 전자수용체에 넘김 (동작)
14. 가운데 반응중심, 좌우에 안테나 = 광계의 배치 (자리)
15. 인물들이 선 녹색 방석 = 틸라코이드 막(주머니) (뜻) 【추정】

### 구역4 **스펙트럼 — 흡수·작용 스펙트럼(엥겔만), 원적색 색소** — 읽힌 11
1. 흰 빛기둥 1줄 → 프리즘 → 무지개 = 백색광은 여러 색 혼합 (모양)
2. 7색 띠, 왼쪽 보라 → 오른쪽 빨강 = 짧은 파장→긴 파장 (자리)
3. 벤치 위 마디 있는 초록 실 = 사상 조류 (모양)
4. 갈색 알갱이 = 호기성 세균, 산소 쪽으로 모임 (모양·뜻)
5. 세균 큰 무리는 보라~파랑 쪽과 빨강 쪽, 초록~노랑 쪽은 거의 없음 = 작용 스펙트럼 (자리·개수)
6. 무리 위 흰 방울 = O2, 구역2의 흰 공과 같은 표식 (모양)
7. 벤치 앞 보라 네모 줄: 색 중심 = 흡수, 흰 중심 = 흡수 안 함 → 흡수 스펙트럼, 가운데 비어 있음 (색·자리)
8. 청록·주황 자리 작은 포크 2개 = 엽록소 b가 보충 흡수 (모양)
9. 청록 자리 당근 1개 = 카로티노이드 (모양)
10. 빨강 끝 너머 빨간 안개 = 가시광선 바깥 원적색 (색·자리)
11. 안개 속 인물 d, f(노란 글자) = 엽록소 d·f, 원적색 흡수 (글자)

## ③ 의문점
- 모름: 점선 끝 땅의 빛나는 노란 구슬 + 김 3줄(전자 낙하·열·형광?), 관다발 갈색 띠 2개, 석조 받침대, d만 반투명한 까닭, 흰 빛이 두 가지(프리즘 기둥 / 망토에 닿는 굵은 빛)인 관계, 상표피 위에만 갈색 띠, 깔개의 술.
- 헷갈림: 청록 빛이 b와 당근 둘 다 들어감. 보라 네모가 엽록체·벤치·머리 틀에 같은 모양으로 쓰임. 작은 인물 2명이 특수쌍인지 P680/P700인지. 흰 공이 O2인지 빛인지.
- 이어 붙인 흔적: 하늘·풀밭은 한 장이라 이음매는 안 보임. 덧입힌 듯한 것은 보라 네모, 가슴 표식, 당근 아이콘, 망원경+막대, 금빛 물결선·점선·빛나는 구슬, 반투명 빛줄기, 수채 번짐 같은 빨간 안개.

## ④ 한 문장
잎의 엽록체 틸라코이드 막에서 엽록소 a·b와 카로티노이드가 서로 다른 색 빛을 흡수해 에너지를 반응중심 엽록소 a 한 쌍에 모으고 초록은 반사하며, 이 흡수·작용 스펙트럼은 프리즘·조류·호기성 세균(엥겔만)으로 확인되고 엽록소 d·f는 원적색까지 흡수한다.
