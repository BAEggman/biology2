# 2단계 (약속표로 재판독)

## 판정
약속표는 1단계를 뒤집지 않고 「추정」 여럿을 확정으로 올렸다(↻). 약속표에 없는 물건(당근·망토·꼬리·방석·금빛 물결선·그릇과 노란 공·d/f 글자·프리즘·세균·안개)은 끼우지 않고 1단계 자체 풀이를 유지했다. 약속표에 있는데 이 판에는 없는 것(동전 ATP · 방패 NADPH · 양동이 · 바위 Q · 돌 아치 ATP합성효소 · H⁺ 물방울 · 공변세포)이 비어 있어, 전자전달·ATP 합성 판이 아니라 구조·색소·스펙트럼 판이라는 1순위를 받친다.

## ① 판 전체 표제어
- 1순위 **광합성의 장소(잎·엽록체)와 광합성 색소·빛 흡수 스펙트럼** — 87% ↻(80→87)
- 2순위 **명반응의 광계(안테나 색소→반응중심 엽록소 a)** — 8% ↻(12→8, 전달계 약속물이 없음)
- 나머지 5%: 광합성 개관(명반응·탄소 고정의 장소 분담)

## ② 구역 (4구역)

### 구역1 **잎의 단면 구조** — 읽힌 6 (그대로)
큐티클 / 상표피 / 울타리조직 10개 / 해면조직 / 은빛 파이프 5개 묶음(물) / 하표피. ↻ 콩팥 모양 둘(#14)·롤 셔터(#120)가 없으니 기공 없음 확정. 파이프 끝 파란 알은 #122 파란 유리알과 닮았으나 관 속 물로 읽고 끼우지 않음. 은빛 파이프는 #36 검은 가스 파이프(카스파리대)가 아님.

### 구역2 **엽록체 구조와 스트로마의 루비스코** — 읽힌 10 ↻(9→10)
1. 두 겹 껍질 = 이중막(덱에서 담=막) 2. 더미 6개 = 그라나 3. 낱개 원반 1 = 틸라코이드 4. 잇는 띠 = 스트로마 라멜라
5. ↻ 원반마다 보라 네모 3 = #81 포르피린+Mg의 작은 표지 = 막에 박힌 엽록소 (추정→확정)
6. ↻ 흰 공 3개 = #17 밝은 방울 O₂, 루멘→막 사이→밖으로 (확정)
7. ↻ 술 달린 회색 깔개 = #164 스트로마, 양 끝 술까지 일치 (확정)
8. ↻ 루비빛 렌즈 놋쇠 스코프 = #34 루비스코 (추정→확정)
9. ↻ 5마디 막대 = #159 마디 하나가 탄소 하나 → 5탄소 RuBP
10. ↻ 막대 끝 회청 물방울 = #16 어두운 방울 CO₂, #159대로 탄소 1 → 5+1=6탄소 중간체(→3-PGA 둘). 막대 아랫끝 고리·스코프 끝 곱슬선은 못 풂.

### 구역3 **광합성 색소(엽록소 a·b·카로티노이드)와 안테나→반응중심 에너지 전달** — 읽힌 16 ↻(15→16)
1. ↻ 머리 = 자주 네모 액자+은빛 구슬 = #81 포르피린 고리+Mg (추정→확정, 모자 아님)
2. 꼬리 = 피톨 꼬리 (약속표 없음, 추정 유지)
3. ↻ 왼쪽 큰 인물 가슴 Y = #165 세 갈래 잔가지(검은 마디·흰 알 셋) = 메틸기 → 엽록소 a
4. a의 창·빛줄기 빨강+파랑 (파란 빛줄기 = #125 청색광)
5. ↻ 오른쪽 큰 인물 가슴 포크 = #166 갈퀴 넷 포크(잔 없이 홀로) = 포르밀기 → 엽록소 b (#56 푸코잔틴은 잔에 꽂힌 포크)
6. b의 창·빛줄기 주황+청록
7. 초록 빛줄기가 V자로 튕김 = 초록 반사
8. 주황 당근 = 카로티노이드 (약속표 없음, 소리 풀이 유지)
9. 당근 위 보라+청록 빛
10. 망토가 굵은 흰 빛을 막음 = 광보호 (약속표 없음)
11. 금빛 물결선 3줄 = 안테나→반응중심 에너지 전달
12. ↻ 작은 인물 2명 가슴도 Y = 반응중심 엽록소 a 특수쌍 (a 표식으로 확정)
13. 그릇+노란 공 = 전자를 수용체에 넘김
14. 가운데 반응중심·좌우 안테나 배치
15. 녹색 방석 = 틸라코이드 막 (추정)
16. ↻ 점선 끝 빛나는 구슬+김 3줄 = 그릇에 담기지 못한 에너지가 빛·열로 흩어짐 (모름→추정: #118 햇살은 판의 뜻 그대로, #136 그릇 없이 오르는 김 = 담지 못하고 곧장 흘림)

### 구역4 **흡수·작용 스펙트럼(엥겔만)과 원적색 색소 d·f** — 읽힌 12 ↻(11→12)
1. 흰 빛기둥 1줄→프리즘→무지개 = 백색광은 여러 색의 혼합
2. 7색 띠, 보라(왼)→빨강(오른) = 짧은→긴 파장
3. 마디 초록 실 = 사상 조류
4. 갈색 알갱이(편모 털) = 호기성 세균 (#13 옥수수 알갱이와 색·모양이 달라 끼우지 않음)
5. 큰 무리는 보라~파랑·빨강, 초록~노랑은 없음 = 작용 스펙트럼
6. ↻ 흰 방울 = #17 O₂ (구역2 흰 공과 같은 약속)
7. ↻ 앞면에 같은 보라 네모가 줄지어 색만 다름 = #126 한 가지(파장)만 바꾼 대조
8. ↻ 네모 = #81 엽록소 분자, 색 중심 = 흡수하는 색, 흰 중심 = 흡수 안 함 → 흡수 스펙트럼 (포크 없는 a: 보라·파랑·빨강에서 색, 청록~주황 사이 흰 4개)
9. ↻ 작은 포크 붙은 네모 2개(청록·주황) = #166 포르밀기 = b가 보충 흡수 (포크 갈래 수는 너무 작아 못 셈)
10. 당근 1개(청록 자리) = 카로티노이드
11. 빨간 안개 = 원적색/근적외 영역 (안개는 약속표 없음, #127 새까만 전구 = 근적외광과 같은 뜻으로 읽음)
12. 안개 속 d·f(노란 글자) = 엽록소 d·f 원적색 흡수, 머리 틀은 #81과 같음

## ③ 의문점
- 풀림: 깔개 술, 흰 공=O₂, 보라 네모 재사용, 막대와 방울, Y·포크, 줄지은 네모.
- 아직 모름: 관다발 갈색 띠 2개, 석조 받침대, d만 반투명, 흰 빛 두 가지의 관계, 상표피 위만 있는 갈색 띠, 막대 아랫끝 고리.
- 헷갈림: 작은 인물 둘이 특수쌍인지 P680/P700인지, 청록 빛이 b와 당근 둘 다에 듦.
- 이어 붙인 흔적: 보라 네모·Y·포크·깔개·스코프·막대·흰 공은 덧붙인 듯하나 약속표의 표준 물건이라 약속 부호로 읽힘. 물결선·점선·빛나는 구슬·안개·d/f 글자·당근 아이콘은 약속표 밖 이 판 고유 장치.

## ④ 한 문장
엽록체 틸라코이드 막의 엽록소(포르피린+Mg 머리, a=메틸·b=포르밀)와 카로티노이드가 서로 다른 색 빛을 흡수해 에너지를 반응중심 엽록소 a 한 쌍에 모으고 초록은 반사하며, 이는 프리즘·조류·세균(O₂ 방울)으로 확인되고 d·f는 원적색을 흡수하며, 스트로마에서는 루비스코가 5탄소 RuBP에 CO₂를 붙인다.
