# stage2 — 덱 약속 적용 (s45u02) · ↻ = 1단계와 달라진 곳

## 판정
약속표가 더 잘 풀어 준다(부분적). #16·#17·#34·#81·#125·#126·#159·#164·#165·#166 이 판에 그대로 맞물려 「모름」 3개가 풀리고 「추정」 5개가 확정. 당근·망토·방석·꼬리·그릇·물결선·프리즘·벤치·녹조 줄·세균·붉은 안개는 표에 없어 1단계 읽기 유지(약속에 끼우지 않음).

## ① 판 전체 표제어
- 1순위 **광합성 — 엽록체(틸라코이드·스트로마)와 광합성 색소의 빛 흡수** 70%
- 2순위 **광합성 개요 — 명반응·탄소 고정의 장소와 재료(빛·CO₂·O₂)** 20%
- ↻ 루비스코·RuBP·CO₂·스트로마가 확정돼 「색소만」에서 「장소+색소」로 무게 이동. 기공·C4·CAM·NADPH 소품은 없음. 시선: 잎→엽록체→분자→빛.

## ② 구역별 (5구역)
**구역1 · 잎의 구조** [5]
1. 기둥 세포 10개, 알갱이 빽빽 = 울타리 조직(모양·개수)
2. 둥근 세포, 알갱이 적고 틈 = 해면 조직(모양)
3. 납작 창백층(위 약 6칸), 알갱이 없음 = 표피
4. ↻ 속 빈 은색 관 5개를 갈색 띠 2개로 묶음 = 관다발 「관+다발」(소리·뜻). 띠는 묶음 자체 [모름→추정]
5. 맨 위 갈색 띠 = 큐티클 [추정]
- ↻ 공변세포(#14)·롤 셔터(#120) 없음 → 기공은 이 판 소재 아님

**구역2 · 엽록체** [10]
1. 겹벽 두 겹 = 이중막 / 2. 원반 더미 6개 = 그라나 / 3. 얇은 선반 = 스트로마 라멜라
4. ↻ 보라 네모(은빛 구슬) = 포르피린+Mg(#81) = 막의 엽록소 [확정]
5. ↻ 내강 위 밝은 방울 = O₂(#17), H⁺ 아님
6. 밝은 방울 3개(내강→막 사이→밖) = O₂ 방출 경로
7. ↻ 술 달린 회색 깔개(담 안 바닥) = 스트로마(#164) [모름→확정]
8. ↻ 루비빛 렌즈 놋쇠 스코프 = 루비스코(#34) [추정→확정]
9. ↻ 두 빛깔 마디 막대 5마디 = 탄소 5 = RuBP(#159)
10. ↻ 막대에 붙은 어두운 방울 = CO₂(#16), 탄소 1 → 합 6
- 막대 끝 작은 고리, 망원경 위 곱슬선 = 표에 없음, 모름

**구역3 · 색소와 광계** [13]
1. ↻ 자줏빛 네모 머리+은빛 구슬 = 포르피린+Mg(#81)
2. 방석에 박힌 꼬리 = 피톨 꼬리, 방석 = 막 [표에 없음]
3. ↻ 가슴 잔가지(검은 마디·흰 알 셋) = CH₃(#165) → 엽록소 a
4. ↻ 가슴 포크(홀로, 살 넷) = CHO(#166) → 엽록소 b (소리 가설 폐기)
5. 당근 = 카로티노이드 [표에 없음]
6. 흰 빛이 망토에서 흐려짐 = 광보호 [표에 없음, 추정]
7. ↻ 파란 빛줄기 = 청색광(#125) → a 머리
8. 시안 빔 → b 머리
9. 보라+청록 빔 2 → 당근 머리
10. ↻ 초록 빔이 튕겨 오름(반사 다리가 짧음) = 녹색 반사, V 이음쇠(#7)와 무관
11. 노란 물결선 3줄 = 안테나→반응 중심 에너지 전달 [표에 없음]
12. 작은 둘(가슴 CH₃) = 반응 중심 a 한 쌍
13. 그릇+노란 구슬 = 전자→수용체 [표에 없음, 동전(ATP #8) 아님: 반짝 구슬]

**구역4 · 흡수·작용 스펙트럼** [9]
1. 흰 빔→프리즘→7색 / 2. 초록 마디 줄 = 사상 녹조 [표에 없음] / 3. 갈색 막대 = 호기성 세균 [표에 없음]
4. 더미 자리(보라·파랑, 빨강 큼, 청록 몇, 초록 0) = 작용 스펙트럼
5. ↻ 흰 작은 방울 = O₂(#17) [확정]
6. ↻ 같은 머리 7개, 칸 색만 다름 = 파장만 바꾼 대조 실험(#126), 보라·파랑·빨강 칸만 참 = a 흡수
7. 당근 아이콘 = 카로티노이드 흡수대 / 8. 초록 V표 = 녹색 반사(이음쇠 아님)
9. ↻ 작은 포크+주황 머리 = CHO(#166), b의 주황 흡수 [추정→확정]

**구역5 · 붉은 안개** [3]
1. 붉은 빛줄기 2 = 적색광 / 2. ↻ 흐릿한 두 인물 = 자줏빛 머리(#81) = 엽록소 둘, 가슴 표지 없음 / 3. 붉은 안개 = 장파장·원적색(적색 강하·에머슨) [표로 못 풂, 추정]

## ③ 의문
- 여전히 모름: 안개 속 인물의 정체, 방석 위 희미한 노란 점, 구슬=전자 여부
- ↻ 가짜 친구 기각: 흰 반원(≠초승달 CAM, 잘린 방울), 방석(≠요), 은색 관(≠둥근 관=핏줄)
- 이어 붙인 흔적: 1단계와 같음(흰 빔 경계, x≈1930 세로 절단)

## ④ 한 문장
틸라코이드의 엽록소(포르피린+Mg, a=CH₃·b=CHO)와 카로티노이드가 청자·적색 빛을 흡수해(초록 반사) 반응 중심으로 모으고 O₂를 내며, 스트로마의 루비스코는 RuBP(5C)에 CO₂를 붙인다.
