# stage1 생판 — s45u02 (그림만 보고)

## ① 판 표제어
- 1순위 **광합성 — 엽록체·광합성 색소·광계·스펙트럼 (빛 에너지 포획 단계)** 70%
- 2순위 **명반응 도입 — 광계와 반응중심의 빛 포획** 15%
- 근거: 잎 → 엽록체 → 색소·광계 → 프리즘·벤치로 "빛이 어디서 어떻게 잡히나"를 이음. 전자전달계·ATP 합성효소·캘빈 회로 본판은 없음.

## ② 구역 (왼쪽부터 5구역)
**구역1 · 잎의 단면(엽육 조직)**
1. 맨 위 회갈색 얇은 띠 + 무색 세포 1층 = 큐티클·위표피, 엽록체 없음 (색·자리)
2. 세로로 길고 빽빽한 세포 약 10개 1층, 초록 점 많음 = 울타리 조직 (모양·자리 위)
3. 둥글고 사이가 뜬 세포 약 5층, 점 적음 = 해면 조직, 공기 틈 (모양)
4. 은색 관 5개를 갈색 띠 2개로 묶음, 해면 조직 한가운데 = 관다발 (소리 관+다발·개수). 물관/체관 구분은 모름
5. 맨 아래 무색 세포 1층 = 아래표피. 기공·공변세포는 안 그려짐

**구역2 · 엽록체**
1. 달걀 껍질이 이중 띠(밝은 띠 2 + 사이 짙은 띠) = 외막·내막·막간 공간 (모양·개수 2)
2. 동전 더미 6개(왼 3·오 3)를 납작한 선반이 이음 = 그라나(틸라코이드 더미)·스트로마 라멜라 (모양·개수)
3. 더미 옆면 보라 네모 점(더미당 10여 개) = 막에 박힌 색소·광계 (자리)
4. 흰 구슬 3개: 맨 위 더미의 열린 입(내강) 속 → 껍질 틈 → 바깥 = O2가 내강에서 생겨 이중막을 지나 방출 (개수·자리)
5. 더미 밖 빈 공간·바닥 = 스트로마 (자리). 바닥의 루비 렌즈 망원경 + 5마디 줄무늬 막대 + 물방울 + 회색 깔개는 루비스코(ruby+scope)·RuBP 5탄당·캘빈 회로 추정, 확신 30% (소리)

**구역3 · 광합성 색소와 광계(쿠션 위 무대)**
1. 납작한 초록 쿠션 = 틸라코이드 막, 색소가 놓인 자리 (모양·뜻)
2. 큰 사람 둘의 머리: 정사각 보라 틀 = 포르피린 고리, 은구 = Mg, 땅에 닿는 긴 꼬리 = 피톨 꼬리 (모양)
3. 왼쪽 큰 사람, 가슴에 점 3개 가지 = 메틸(–CH3) = 엽록소 a, 파란 빛줄기 흡수 (모양·색)
4. 오른쪽 큰 사람, 가슴의 포크 = 포밀(–CHO) = 엽록소 b, 청록 빛 흡수 (소리 포크≈포밀)
5. 초록 빛줄기는 머리에서 V로 튕김 = 초록 반사, 그래서 잎이 초록 (모양)
6. 당근 = 카로티노이드 (색), 머리잎에 보라·청록 두 줄 꽂힘 = 짧은 파장 흡수 (자리)
7. 당근 망토가 흰 굵은 빛을 받아 막음(왼쪽 큰 사람 앞) = 과잉 빛 차단·광보호 (자리, 50%)
8. 금빛 물결선 3줄(큰 사람 둘·당근 → 작은 사람) = 안테나 → 반응중심 에너지 전달 (개수 3)
9. 작은 사람 둘(둘 다 메틸), 손잡고 그릇 = 반응중심 엽록소 a 특수쌍 (뜻)
10. 그릇의 노란 공 1 = 들뜬 전자, 그릇 = 1차 전자수용체 (모양·개수)

**구역4 · 프리즘·스펙트럼·벤치(엥겔만 실험)**
1. 흰 빛 기둥 → 유리 프리즘 → 무지개 7색(왼쪽 보라 = 짧은 파장 → 오른쪽 빨강) = 백색광 분산 (모양)
2. 레일 위 상자 7개(+작은 1): 보라·파랑·빨강 상자만 속이 채워짐 = 그 파장 흡수 (색)
3. 초록 칸 위 V = 반사, 노랑 칸은 빈 흰 칸 = 흡수 없음 (모양)
4. 청록 칸 위 당근 = 카로티노이드 흡수 (소리·뜻)
5. 주황 칸 위 포크 + 주황 작은 상자 = 엽록소 b가 주황 흡수 (소리)
6. 초록 마디 실 = 해캄, 막대 세균 더미 2곳(보라-파랑 끝·빨강 끝)이 크고 가운데는 몇 마리 (개수)
7. 흰 방울 = O2 (보라-파랑 쪽 ~7, 빨강 쪽 ~10, 가운데 2), 호기성 세균이 O2 쪽으로 모임 = 엥겔만 실험
8. 그래서 작용 스펙트럼 ≈ 흡수 스펙트럼 (뜻)

**구역5 · 붉은 안개 속 두 사람(적색 강하·에머슨?)**
1. 짙은 붉은 안개, 붉은 빛 두 줄기, 머리 속이 어두운 붉은 흐릿한 두 사람(왼쪽이 더 흐림, 가슴 기호 없음) = 장파장 끝 적색 강하·에머슨 효과(두 광계 협동) 또는 P680·P700 추정, 확신 35%

## ③ 뜻 모를 것 · 어색 · 헷갈림 · 이은 흔적
- 뜻 모름: 망원경 세트, 쿠션 위 희미한 노란 점 1개, 관다발의 갈색 띠 2개, 구역5 두 사람의 정체, 작은 주황 상자의 쌓임
- 어색: 작은 두 사람만 원근으로 작음, 같은 청록 줄기가 당근과 엽록소 b 두 곳에 꽂힘, 흰 빛이 망토에서 번짐
- 헷갈림: a/b 구분은 머리 파랑/청록 차이와 가슴 기호뿐, 레일 상자엔 a/b 기호가 포크 하나뿐이라 보라·파랑·빨강이 a인지 불명. 메틸 vs 포크, 구슬 3(엽록체 O2) vs 방울(벤치 O2)
- 이은 흔적: 오른쪽 세균 더미가 왼쪽에서 수직으로 잘리고 반쪽 방울도 같은 선에서 잘림. 평면 벡터 아이콘(망원경·당근·V·포크·보라 점·빛줄기)이 붓그림 위에 얹힘. 붉은 안개는 무지개·벤치를 덮는 수채 겹침. 구역 사이 하늘과 잔디는 매끈함

## ④ 한 문장
엽록체 틸라코이드 막의 엽록소 a·b와 카로티노이드가 보라·파랑과 빨강 빛은 흡수하고 초록은 반사하며 그 에너지를 반응중심 엽록소 a로 모으고, 같은 파장에서 O2가 가장 많이 나온다.
