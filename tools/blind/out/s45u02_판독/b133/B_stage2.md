## 판정 (약속표 대조)
- 풀린 것: 구역2 망원경 세트 전부(#34·#159·#16·#164), 구역3 머리(#81)·가슴 기호(#165·#166), 밝은 방울 = O₂(#17), 파란 빛줄기 = 청색광(#125), 줄지은 같은 상자(#126). 구역2·3은 약속으로 확정, 구역1·4·5는 거의 그대로.
- 안 풀린 것(약속표에 없음 — 1단계 읽기 유지): 당근·망토·꼬리·금빛 물결선·쿠션·그릇과 노란 공·프리즘·세균 더미·붉은 안개.
- 끼우지 않음: 쿠션 ≠ 요(#9, 초록 쿠션·광합성 판), 노란 공 ≠ 동전(#8, 윤기 나는 공), 초록 V ≠ V자 이음쇠(#7, 빛줄기의 꺾임), 세균 더미 ≠ 자갈·옥수수(#4·#13, 막대 꼴·편모), 방석 더미 ≠ 동전 더미(#8, 둥글지 않은 납작 방석).

## ② 구역 (5구역)
**구역1 · 잎의 단면(엽육 조직)** — 1단계와 같음(약속 물건 없음. 롤 셔터 #120·콩팥 한 쌍 #14이 없어 기공 없음 확정)
1. 회갈색 띠 + 무색 세포 1층 = 큐티클·위표피 2. 세로로 긴 빽빽한 세포 ~10개, 점 많음 = 울타리 3. 둥글고 틈 있는 ~5층, 점 적음 = 해면 4. 은색 관 5개 + 갈색 띠 2개 = 관다발(물관/체관 구분 모름) 5. 아래 무색 세포 1층 = 아래표피

**구역2 · ↻ 엽록체 — 틸라코이드(명반응)와 스트로마(탄소 고정)**
1. 이중 띠(밝은 띠 2 + 짙은 사이) = 외막·내막·막간 공간
2. 납작 방석 더미 6(왼 3·오 3) + 선반 = 그라나 · 스트로마 라멜라
3. ↻ 더미 옆 보라 네모 점 = 엽록소(포르피린 틀 #81 꼴, 막에 박힘) — '광계'에서 좁힘
4. 밝은 방울 3 = O₂(#17): 열린 내강 → 껍질 틈 → 밖
5. ↻ 가장자리에 술 달린 얇은 회색 깔개 = 스트로마(#164) — '빈 바닥'을 정정
6. ↻ 루비빛 렌즈 놋쇠 스코프 = 루비스코(#34) — 추정 30% → 확정
7. ↻ 놋쇠·흰색 번갈아 5마디 막대 = 탄소 5개 RuBP(#159)
8. ↻ 막대 끝 물방울 꼴 어두운 방울 = CO₂ 1개(#16·#124), 렌즈에 맞닿음 = 5+1=6탄소 → 탄소 고정

**구역3 · 광합성 색소와 광계(쿠션 위 무대)**
1. 납작 초록 쿠션 = 틸라코이드 막(추정; 방석 더미와 같은 꼴) 2. 큰 사람 머리 = 포르피린 + Mg(#81) 3. 땅에 닿는 꼬리 = 피톨 꼬리(약속표 없음, 추정) 4. 왼쪽: 세 갈래 가지·흰 알 셋 = 메틸(#165) = 엽록소 a, 파란 줄기(청색광) 흡수 5. 오른쪽: 홀로 선 갈퀴 넷 포크 = 포르밀(#166) = 엽록소 b, 청록 흡수 6. 초록 줄기가 V로 튕김 = 초록 반사 7. 당근 = 카로티노이드, 보라·청록 두 줄 흡수 8. 망토가 흰 굵은 빛을 막음 = 광보호(50%) 9. 금빛 물결선 3 = 안테나 → 반응중심 에너지 전달 10. ↻ 작은 둘(가슴 메틸 확정) = 반응중심 엽록소 a 쌍 11. 노란 공 + 그릇 = 들뜬 전자 → 1차 수용체(추정), 쿠션 위 흐린 점 = 원래 자리(추정)

**구역4 · 흡수 스펙트럼과 작용 스펙트럼(엥겔만 실험)**
1. 흰 빛 기둥 → 프리즘 → 7색 2. ↻ 같은 엽록소 상자 7(+작은 1)이 줄지어 하나씩만 다름(#126) = 파장만 바꾼 비교, 흡수 스펙트럼 3. 보라·파랑·빨강 상자만 색이 참 = 흡수 4. 초록 칸 위 V = 반사, 노랑 칸 흰 칸 = 흡수 없음 5. 청록 칸 위 당근 = 카로티노이드 6. 주황 칸 위 포크(홀로 = 포르밀)와 주황 작은 상자 = 엽록소 b의 주황 흡수 7. 초록 마디 실 = 해캄, 막대 세균 더미 2곳(보라-파랑 끝·빨강 끝)이 큼 8. 흰 방울 = O₂(#17), 보라-파랑 ~7·빨강 ~10·가운데 2 9. 작용 스펙트럼 ≈ 흡수 스펙트럼(위 상자 줄과 아래 세균 더미가 같은 색 칸에서 맞물림)

**구역5 · 붉은 안개 속 두 사람(적색 강하·에머슨?)**
1. ↻ 머리 = 엽록소 분자(#81) 둘이 붉은 빛줄기 둘(적색광)을 받음 — 몸은 등을 보이고 꼬리·가슴 기호가 안 보여 a/b는 모름
2. 짙은 붉은 안개·흐린 몸 = 장파장 끝의 적색 강하·에머슨 효과 추정 35%(안개는 약속표 없음)

## ③ 이상한 것
- 풀림: 망원경 세트, 흰 방울(O₂)과 어두운 방울(CO₂)의 구별
- 여전히 모름: 쿠션 위 흐린 노란 점, 관다발 갈색 띠 2개, 구역5 안개·흐린 몸의 뜻, 작은 주황 상자
- 어색·헷갈림: 쿠션·V·동전이 약속표 물건(#9·#7·#8)으로 오독될 소지, a/b 표지는 가슴 기호·상자 위 포크뿐이라 보라·파랑·빨강 상자가 a인지 불명, 같은 청록 줄기가 당근과 b 두 곳에 꽂힘
- 이은 흔적: 오른쪽 세균 더미와 반쪽 방울이 같은 수직선에서 잘림, 평면 벡터 아이콘(스코프·당근·V·포크)이 붓그림 위에 얹힘, 수채 안개가 무지개·벤치를 덮음

## ④ 한 문장
엽록체 틸라코이드 막의 엽록소 a·b와 카로티노이드가 보라·파랑과 빨강 빛은 흡수하고 초록은 반사해 그 에너지를 반응중심 엽록소 a로 모으며 O₂를 내고(작용 스펙트럼도 같은 파장), 스트로마에서는 루비스코가 RuBP(5탄소)에 CO₂를 붙인다.
