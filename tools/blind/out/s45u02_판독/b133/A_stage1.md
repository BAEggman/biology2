# stage1 — 생판 (s45u02, 그림만 보고)

## ① 판 전체 표제어
- 1순위: **광합성 — 장소(잎·엽록체)와 광합성 색소·광계의 빛 흡수** 확신 70%
- 2순위: **광합성 색소와 흡수·작용 스펙트럼(엥겔만·에머슨)** 확신 20%
- 광합성이라는 큰 틀은 95% 이상. 갈림은 단원 범위(개요형 대 색소·광계형)뿐. 전자전달계·ATP·NADPH·캘빈 회로는 없음 → 명반응 전체 단원은 아님.

## ② 구역별 읽기 (왼쪽부터 5구역)

**구역1 · 잎 단면 — 잎의 구조(광합성 장소)** [읽힌 5]
1. 길쭉한 기둥 세포 10개, 초록 알갱이 빽빽 = 울타리 조직, 엽록체 가장 많음(모양·개수)
2. 둥근 세포, 알갱이 적고 세포 사이 틈 = 해면 조직, 엽록체 적음·기체 교환 틈(모양)
3. 위·아래 납작 창백한 층(위 약 6칸), 알갱이 없음 = 표피, 엽록체 없음(자리)
4. 속 빈 은색 관 5개 묶음 = 관다발(엽맥), 물관=물 공급(뜻: 다발·관)
5. 맨 위 얇은 갈색 띠 = 큐티클(자리) [추정] / 관을 조인 갈색 띠 2개 = 모름

**구역2 · 달걀 단면 — 엽록체 구조와 O2 발생** [읽힌 9]
1. 겹벽 두 겹 = 이중막(외막·내막), 사이 공간(모양)
2. 원반 더미 6개(각 5~7장) = 그라나(개수)
3. 더미를 잇는 얇은 선반 = 스트로마 라멜라(모양)
4. 원반 가장자리 보라 네모 = 막에 박힌 색소·광계(색: 3구역 엽록소 머리와 같은 보라)
5. 맨 윗 원반 어두운 틈 위 흰 구슬 = 틸라코이드 내강, 물 분해→O2(자리) [H+일 수도]
6. 흰 구슬 3개(내강→막 사이에 찌그러짐→밖) = O2가 이중막 통과해 방출(개수·자리)
7. 원반 밖 바닥의 망원경(붉은 렌즈+스코프) = 루비스코(소리), 스트로마(자리)
8. 줄무늬 막대 5마디 = RuBP 5탄당(개수) [추정]
9. 회청색 물방울 = CO2(색) [추정]

**구역3 · 방석 위 인물 — 광합성 색소와 광계** [읽힌 13]
1. 보라 사각 머리+은색 구슬 = 포르피린 고리+Mg(모양·소리: 포르피라=보라)
2. 방석에 박힌 긴 꼬리 = 피톨 꼬리, 방석 = 틸라코이드 막(모양)
3. 가슴 Y+흰 점 3 = CH3 → 엽록소 a(개수)
4. 가슴 포크 = 포밀(CHO) → 엽록소 b(소리: 포크~포밀)
5. 당근 = 카로티노이드(모양)
6. 흰 빔이 당근 망토에서 흐려짐 = 과잉 빛 소산·광보호(뜻) [추정]
7. 파랑 빔1 → a 머리(청자 흡수)
8. 시안 빔1 → b 머리(청색 흡수)
9. 보라+청록 빔 2 → 당근 머리(카로티노이드 400~500nm)(개수)
10. 초록 빔이 V자로 튕김 = 녹색광 반사 → 잎이 초록(모양)
11. 노란 물결선 3줄 = 안테나(a·b·당근)→반응 중심 에너지 전달(개수)
12. 작은 둘(Y 가슴, 흰 머리) = 반응 중심 엽록소 a 한 쌍(개수 2)
13. 그릇 속 노란 구슬 1 = 들뜬 전자→1차 전자 수용체(동작)

**구역4 · 프리즘과 벤치 — 흡수 스펙트럼·작용 스펙트럼(엥겔만)** [읽힌 9]
1. 흰 빔→프리즘→7색 띠 = 백색광 분산(개수 7)
2. 벤치 위 초록 마디 줄 = 사상 녹조(모양)
3. 갈색 막대 알갱이 더미 = 호기성 세균, O2 많은 곳에 모임(뜻)
4. 더미 자리: 보라·파랑 큰 것, 빨강 큰 것, 청록 몇 마리, 초록 0 = 청자·적색에서 광합성 최대(자리)
5. 흰 작은 구슬 = O2 기포
6. 선반 위 상자 7개: 보라·파랑·빨강만 색이 참 = 엽록소 a 흡수대(개수 7), 흰 칸 = 흡수 안 됨
7. 당근 아이콘(청록 자리) = 카로티노이드가 틈을 메움
8. 초록 V표(초록 자리) = 녹색 반사
9. 포크+작은 주황 상자(주황 자리) = 엽록소 b 주황 흡수

**구역5 · 붉은 안개 — 적색 강하·에머슨 효과(추정)** [읽힌 3]
1. 붉은 안개+적색 빔 2 = 원적색(>680nm)에서 효율 급락, 적색 강하(개수 2)
2. 흐릿한 인물 둘 = 광계 II·I 두 개(개수 2) [추정]
3. 머리의 붉은 후광 = 적색광 흡수하나 작동 약함 / 두 빛 함께면 증강 [추정]

## ③ 의문
- 모름: 망원경·막대·물방울 세트의 확정, 회색 격자 판, 관을 조인 갈색 띠 2개, 방석 위 희미한 노란 점, 안개 속 인물 정체
- 헷갈림: 큰 둘(a·b)과 작은 둘(반응 중심), 흰 구슬 O2 대 H+, 노란 구슬 전자 대 광자
- 이어 붙인 흔적: 3·4구역 사이 흰 빔 양옆 하늘색이 갈림, 오른쪽 세균 더미·흰 반원 기포가 x≈1930에서 세로로 잘림, 보라 네모·가슴 표지·상자·물결선은 덧얹은 평면 그림

## ④ 한 문장
엽록체 틸라코이드 막의 엽록소 a·b와 카로티노이드가 청자·적색 빛을 흡수하고(초록은 반사) 에너지를 반응 중심 엽록소 a로 모아 전자를 내보내며, 그 파장대가 곧 O2 발생(작용 스펙트럼)이다.
