# 2단계 — 약속표로 다시 읽음 (↻ = 1단계와 달라진 곳)

## 판정
약속표는 엽록체 속 물건과 분자 표식을 확정했고 「모름」이던 셋(막대·물방울·깔개)을 풀었다. 판 전체 표제어는 거의 그대로다. 잎·당근·빛줄기·프리즘·세균·d/f·붉은 안개는 표에 없어 1단계 읽기를 유지했고 억지로 끼우지 않았다.

## ① 판 전체 표제어
- 1순위: **광합성의 장소와 색소 — 잎·엽록체 구조(틸라코이드·스트로마), 엽록소 a·b·카로티노이드의 빛 흡수, 흡수·작용 스펙트럼** (확신 70%) ↻65→70
- 2순위: ↻ **광합성 두 단계의 자리 구분 — 명반응(틸라코이드·광계)과 CO₂ 고정(스트로마·루비스코)** (확신 15%) — 스트로마 쪽 물건이 확정돼 1단계의 '광계'보다 앞섬

## ② 구역별 (5구역)
**구역1 — 잎의 구조(엽육·관다발)** (변화 없음)
단면(엽록체 든 세포) / 위 표피+큐티클(납작·창백) / 울타리조직(기둥 세포 10개 안팎, 점 빽빽) / 해면조직(둥글고 틈) / 은빛 파이프 5개+띠 2개=관다발 / 아래 표피(기공 없음). 약속표의 검은 가스 파이프(카스파리대)는 은빛이라 무관.

**구역2 — ↻ 엽록체의 구조와 기능(틸라코이드 O₂ 발생 · 스트로마 CO₂ 고정)**
1. 달걀꼴, 벽 두 겹 = 이중막(외막·내막)
2. 원반 더미 6개(각 6~8장) = 그라나, 잇는 판 = 스트로마 라멜라
3. ↻ 원반 위 보라 네모 점 = 엽록소(자주빛 네모 액자+은빛 구슬 = 포르피린+Mg) — 1단계는 모양 추정
4. ↻ 맨 위 더미의 벌어진 틈 + 밝은 방울 = 내강에서 O₂(밝은 방울=O₂) — 방울 3개(내강·막 사이 납작 방울·밖)가 O₂의 나가는 길
5. ↻ 바닥의 술 달린 얇은 회색 깔개 = 스트로마(담 안 바닥) — 1단계 「모름」, 근거: 깔개 양 끝의 술
6. ↻ 루비빛 렌즈 놋쇠 스코프 = 루비스코 — 1단계는 소리 추정, 약속으로 확정
7. ↻ 두 빛깔 마디 막대(마디 5) = 탄소 5개 RuBP (1단계 「모름」)
8. ↻ 막대 끝에 붙은 회청색 물방울 = CO₂(어두운 방울), 탄소 하나로 셈 → 5+1=6탄소 (1단계 「모름」)
(깔개 위 낱개 원반은 여전히 모름)

**구역3 — 광합성 색소와 광에너지 전달(광계)**
1. 초록 방석 = 틸라코이드 막(추정; 약속표의 '요(이불)'는 요소·요산이라 끌어오지 않음)
2. ↻ 보라 사각 머리+은빛 구슬 = 포르피린 고리+Mg(확정), 땅에 닿는 꼬리 = 피톨 꼬리(표 밖)
3. ↻ 왼쪽 큰 사람 = 엽록소 a: 가슴 세 갈래 잔가지(흰 알 셋) = CH₃, 파란 빛줄기 = 청색광 흡수
4. ↻ 오른쪽 큰 사람 = 엽록소 b: 갈퀴 넷 포크 = CHO(포르밀기) — 소리 추정이 약속으로 확정
5. 당근 사람 = 카로티노이드(표 밖·소리), 주황 망토가 굵은 흰 빛을 받음 = 광보호
6. 초록 V자(내려와 튕김) = 초록광 반사 (약속의 V자 이음쇠=ADH는 관에 꽂는 것이라 무관)
7. 빛 7가닥이 사람마다 다르게 닿음 = 색소별 흡수 파장 차이
8. 노란 물결선 3줄 → 가운데 두 작은 사람 = 공명 에너지 전달
9. ↻ 작은 두 사람도 같은 CH₃ 표식 = 반응중심 엽록소 a 쌍(확인)
10. 그릇+금빛 공 = 전자 수용(동전이 아니라 ATP 아님), 점선 낙하·김 = 열 방출(추정)

**구역4 — 흡수·작용 스펙트럼(프리즘·엥겔만 실험)**
1. 프리즘+흰 광선 → 7색(보라가 가장 꺾임)
2. 마디 있는 초록 실 = 사상 녹조류(한 빛깔이라 탄소 막대 아님)
3. 세균 무리가 보라·파랑과 빨강에 몰리고 초록~노랑엔 없음 = 작용 스펙트럼
4. ↻ 흰 방울(왼 7·가운데 3·오른 12) = 밝은 방울 O₂ 확정
5. ↻ 같은 네모 머리 7개가 줄지어 속 색만 다름 = 한 가지(빛 색)만 바꾼 대조, 네모마다 엽록소 — 보라·파랑·빨강은 속이 찼고(흡수) 중간은 흰 속
6. 청록 칸 당근 = 카로티노이드 보충, 초록 칸 ✓ = 초록 반사(추정)
7. ↻ 주황 칸 꼬마 사람: 가슴 표식이 갈색 Y가 아닌 은청색 포크꼴(픽셀 색 비교) → 엽록소 b(≈640nm)로 읽음. 1단계 '피코빌린' 철회, 갈래를 못 세어 확신 낮음

**구역5 — 원적색광과 엽록소 d·f** (변화 없음)
붉은 안개 = 가시광선 너머 원적색, d·f 가슴 글자 = 엽록소 d·f, 어두운 빨강 화면 = 긴 파장 흡수.

## ③ 의문점
- 못 푼 것: 낱개 원반, 막대 아래 끝의 작은 고리, 금빛 공 낙하와 김, ✓, 'd'만 반투명, 널빤지 기둥(표에도 없음).
- 약속표가 헷갈리게 한 것: 초록 V·✓↔V자 이음쇠, 갈색 그릇↔포크 꽂힌 잔(푸코잔틴), 파란 화면 머리↔하늘색 눈알(청색광 수용체), 프리즘↔삼각 격자 우리 → 꼴·맥락이 달라 끌어오지 않음.
- 이어 붙인 흔적은 1단계와 같음.

## ④ 한 문장
잎→엽록체에서 틸라코이드 막의 엽록소(a: CH₃, b: CHO)와 카로티노이드가 청자·적색 빛을 흡수해 O₂를 내고, 스트로마의 루비스코는 5탄소 RuBP에 CO₂를 붙이며, 흡수 파장이 작용 스펙트럼(엥겔만)과 맞는다.
