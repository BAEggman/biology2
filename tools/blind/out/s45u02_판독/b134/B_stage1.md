# 생판 stage1 (s45u02, 그림만 보고)

## ① 판 전체 표제어
- 1순위 **광합성 색소와 빛 흡수(엽록체·색소·광계·스펙트럼)** 55%
- 2순위 **엽록체 구조와 광반응 개관(광합성의 장소·O2 발생)** 25%
- 3순위 **엥겔만 실험·작용스펙트럼** 10%
근거: 잎 → 엽록체 → 색소 분자 → 빛 파장으로 규모가 줄어드는 배열. 오른쪽 3/5가 색소·스펙트럼.

## ② 구역 (왼→오, 5구역) — [ ]는 근거
### 구역1 **잎 단면(엽육·관다발)** — 7개
- 잎 한 토막 단면 블록 = 잎 구조, 광합성 기관 [모양]
- 맨 위 얇은 회갈색 띠 = 큐티클 [자리]
- 그 아래 납작·무색 세포 한 줄(초록 점 없음) = 상표피 [모양]
- 키 큰 기둥 세포 약 10열, 초록 점 빽빽 = 책상(울타리)조직, 엽록체 최다 [모양·개수]
- 아래 둥글고 성긴 세포 5~6층, 점 적음 = 해면조직 [모양]
- 바닥 납작한 칸 = 하표피. 기공은 안 보임 [자리]
- 은색 속 빈 관 5개를 갈색 띠 2개로 묶음 = 관다발(관+다발). 물관·체관 구분은 못 읽음 [소리·개수]

### 구역2 **엽록체 구조와 O2 방출** — 9개
- 달걀 = 엽록체 [모양]
- 껍질 두 겹 + 사이의 짙은 띠 = 외막·내막·막 사이 공간 [개수]
- 안쪽 빈 회녹색 바탕 = 스트로마 [자리]
- 납작 원반 약 7장 쌓은 더미 6개(왼 3·오 3) = 그라나(틸라코이드 더미) [개수]
- 더미끼리 잇는 납작 선반 5개(지그재그) = 스트로마 라멜라 [자리·개수]
- 원반 위 보라 네모 점(왼 더미 줄당 3, 오른 더미 줄당 2) = 막 속 광계·색소 복합체. 3:2의 뜻은 모름 [색·개수]
- 맨 위 왼쪽 더미 윗 원반이 벌어져 어두운 속이 보임 = 틸라코이드 내강 [자리]
- 흰 구슬 3개(내강 위 → 두 겹 사이에 눌림 → 밖 허공) = O2가 내강에서 막을 지나 밖으로 [개수·자리]
- 바닥에 따로 놓인 원반(점 3) = 쌓이지 않은 틸라코이드(추정) [자리]
- 모름: 바닥 회색 깔개 위 황동 망원경 + 줄무늬 막대 + 물방울. 추정 ① 추적(물의 O가 O2로, 망원경=추적·빨간 렌즈=표지·물방울=H2O) 40% ② 원적색·red drop 20%

### 구역3 **광합성 색소와 광계(안테나→반응중심)** — 11개
- 초록 방석 = 틸라코이드 막(납작한 주머니), 꼬리가 박힘 [모양·자리]
- 머리 = 보라 네모 틀 + 가운데 은색 공 = 포르피린 고리 + Mg [모양·뜻]
- 긴 꼬리 = 피톨 꼬리(막에 꽂힘). 당근엔 꼬리 없음 [모양]
- 왼쪽 큰 사람: 가슴 Y(끝 흰 점 3) = -CH3 → 엽록소 a, 파랑 광선 흡수 [모양·개수]
- 오른쪽 큰 사람: 가슴 포크 = 포르밀(-CHO) → 엽록소 b, 청록 광선 흡수, 초록 광선은 V자로 튕김(반사) [소리·모양]
- 당근 = 카로티노이드, 잎줄기에 보라+청록 광선 2줄 = 청자~청록 흡수 [소리·색]
- 당근 망토가 굵은 흰 빔을 막음 = 강광에서 엽록소 보호(광보호) [뜻]
- 금빛 물결선 3개(a→, 당근→, b→ 작은 둘) = 안테나 색소에서 반응중심으로 에너지 전달 [개수·자리]
- 작은 사람 둘(Y, 머리 속 흰색) = 반응중심 엽록소 a 한 쌍 [개수]
- 그릇 속 노란 공 = 1차 전자수용체가 들뜬 전자를 받음 [뜻]
- 점선으로 방석에 떨어져 김 나는 공 = 전자가 제자리로 돌아가며 열·형광 방출 [뜻]

### 구역4 **프리즘·엥겔만 실험·흡수스펙트럼** — 10개
- 위에서 내려오는 흰 기둥 = 백색광 [모양]
- 유리 삼각 프리즘 = 분산 [모양]
- 무지개 7색(보라→빨강) = 가시광선 [개수]
- 벤치 가장자리 초록 마디 막대 = 실 모양 녹조류 [모양]
- 갈색 막대 세균 무더기: 보라·파랑 쪽 크게, 초록 쪽 몇 마리, 빨강 쪽 크게 = 호기성 세균이 O2 많은 청자·적색에 몰림 = 작용스펙트럼 [자리·개수]
- 흰 방울(왼 7·가운데 3·오른 12) = O2 [개수]
- 나무 레일 위 보라 틀 상자 7개 = 파장별 칸: 보라·파랑·빨강은 색 칸(흡수), 나머지는 흰 칸 [개수·색]
- 청록 칸 위 당근 = 카로티노이드가 보충 흡수 [소리]
- 초록 칸 위 V = 초록은 반사 [모양]
- 주황 칸 위 작은 사람(주황 머리, 포크형?) = 엽록소 b의 주황 흡수(추정) [색]

### 구역5 **원적색 엽록소 d·f** — 4개
- 붉은 안개 = 가시광선 밖 원적색광(700 nm 넘음) [색·자리]
- 'd' 사람 = 엽록소 d [글자]
- 'f' 사람 = 엽록소 f [글자]
- 머리 속 어두운 붉은색 = 원적색 흡수(머리 속 색 = 흡수색) [색]

## ③ 걸리는 것
- 뜻 모름: 망원경 세트, 3:2 점, 7상자의 정확한 배정, 레일 다리 2개.
- 어색: 엽록체 안 황동 기구, 껍질 사이 눌린 흰 구슬, 반투명 d·f 몸(벤치 뒤, 다리만 비침).
- 헷갈림: 큰 a/b의 배정(파랑·청록 머리와 Y·포크로만 가름), 청록 광선이 당근과 b 둘 다로 감, 금색 물결선(에너지)과 금색 공(전자), 중앙 흰 빔(번짐)과 오른쪽 흰 기둥(칼선).
- 이음 흔적: 하늘·지평선은 매끈(색차 3 이하). 손그림 바탕 위에 납작한 스티커형 요소(보라 점·망원경·Y/포크/d/f·당근·V·상자·금공)가 얹힘. 붉은 안개는 수채 번짐 덮개로 벤치 아래 풀까지 번짐.

## ④ 한 문장
엽록체 틸라코이드 막에서 엽록소 a·b와 카로티노이드가 파장별로 빛을 모아 반응중심 엽록소 a로 보내며, 청자·적색에서 광합성이 활발하고 초록은 반사된다(남세균 d·f는 원적색까지).
