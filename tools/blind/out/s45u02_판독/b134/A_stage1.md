# 1단계 생판 — s45u02 (그림만 보고 읽음)

## ① 판 전체 표제어
- 1순위: **광합성의 장소와 색소 — 잎·엽록체 구조, 엽록소 a·b·카로티노이드의 빛 흡수(흡수·작용 스펙트럼)** (확신 65%)
- 2순위: **명반응의 빛 포획 — 광계(안테나 색소→반응중심 엽록소 a)와 O₂ 발생** (확신 20%)
- 잎→엽록체→막 위 색소→빛 파장 순의 확대 구성이라 **광합성 개요/장소**일 가능성도 약 10%.

## ② 구역별 (왼쪽부터 5구역)
**구역1 — 잎의 구조(엽육·관다발)**
1. 잎을 직육면체로 잘라 낸 단면, 세포마다 초록 점 = 엽록체 든 엽육세포에서 광합성 (뜻)
2. 맨 윗줄 창백한 납작 세포 + 위의 갈색 얇은 띠 = 위 표피·큐티클, 엽록체 없음 (모양·색)
3. 길쭉한 세로 기둥 세포 10개 안팎, 점 빽빽 = 울타리조직, 엽록체 최다 (모양·개수)
4. 아래쪽 둥근 통나무꼴 4~5층, 점 드묾, 사이 틈 = 해면조직, 공기 틈(기체 교환) (모양)
5. 은빛 파이프 5개를 갈색 띠 2개로 묶어 가로로 = 관다발(엽맥: 물관·체관) (모양·개수)
6. 맨 아래 납작 세포 줄 = 아래 표피(기공은 안 그려짐) (자리)

**구역2 — 엽록체 구조와 O₂ 발생**
1. 달걀꼴 껍질, 벽이 두 겹(사이에 어두운 틈) = 이중막(외막·내막)과 막 사이 공간 (모양·개수 2)
2. 동전 더미 6개(각 6~8장) = 그라나(틸라코이드 더미) (모양·개수)
3. 더미끼리 잇는 납작한 판 = 스트로마 라멜라 (모양)
4. 원반 위 보라 네모 점 = 틸라코이드 막에 박힌 광계·엽록소 (구역3 머리와 같은 모양)
5. 맨 위 더미의 윗 원반이 벌어져 속이 어둡고 흰 구슬이 솟음 = 틸라코이드 내강에서 물 분해→O₂ (자리)
6. 흰 구슬 3개(내강 위·이중막 사이 납작 방울·밖) = O₂가 두 막을 지나 엽록체 밖으로 (개수·자리)
7. 바닥의 황동 망원경 + 붉은 보석 = 루비+스코프 → RuBisCO, 스트로마(바닥)의 CO₂ 고정 (소리, 추정)

**구역3 — 광합성 색소와 광에너지 전달(광계)**
1. 초록 방석 = 틸라코이드 막, 색소가 박힌 자리 (추정)
2. 사람마다 보라 테두리 사각 머리 + 가운데 회색 구슬 = 엽록소의 포르피린 고리와 Mg (모양·뜻)
3. 땅에 닿는 긴 꼬리 = 피톨 꼬리, 막에 고정 (모양)
4. 왼쪽 큰 사람: 파란 화면, 가슴 Y(흰 구슬 3) = CH₃ → 엽록소 a, 파랑 빛 흡수 (개수·모양)
5. 오른쪽 큰 사람: 청록 화면, 가슴 포크(4갈래) = 포크≈포밀(–CHO) → 엽록소 b, 청록 빛 흡수 (소리)
6. 당근 사람: 사각 머리·꼬리 없음, 보라+청록 빛을 머리로 받음 = 카로티노이드(보라~청록 흡수) (소리·뜻)
7. 주황 망토가 굵은 흰 빛을 받아 번짐 = 카로티노이드의 광보호, 과잉 에너지 소산 (동작)
8. 초록 V자(내려와 튕겨 올라감) = 초록광 반사 → 잎이 초록 (모양)
9. 빛 7가닥이 사람마다 다르게 닿음 = 색소마다 흡수 파장이 다름 (개수)
10. 노란 물결선 3줄 → 가운데 두 작은 사람 = 엽록소 b·a·카로티노이드의 공명 에너지 전달 (개수·자리)
11. 가운데 작은 두 사람(Y, 흰 화면) = 반응중심 엽록소 a 쌍 (개수 2)
12. 둘이 든 그릇 + 금빛 공 = 들뜬 전자(e⁻)를 1차 전자수용체에 넘김 (동작)
13. 점선으로 떨어져 김 나는 금빛 공 = 에너지를 잃고 열 방출(추정)

**구역4 — 흡수·작용 스펙트럼(프리즘·엥겔만 실험)**
1. 삼각 프리즘 + 위에서 오는 흰 광선 → 무지개 7색(보라가 가장 꺾임) = 백색광은 여러 파장 혼합 (모양·개수)
2. 벤치를 따라 놓인 마디 있는 초록 실 = 사상 녹조류(엥겔만) (모양)
3. 갈색 막대 무리(세균)가 보라·파랑과 빨강 쪽에 몰리고 초록~노랑엔 없음 = 작용 스펙트럼 (자리)
4. 흰 방울(왼 7·가운데 3·오른 12) = O₂, 몰린 곳이 광합성 최대 (개수)
5. 널빤지 위 사각 머리 7개: 보라·파랑·빨강은 속이 칠해지고 나머지는 흰 속 = 엽록소 흡수 스펙트럼의 초록 틈 (개수)
6. 청록 칸의 당근 그림 = 카로티노이드가 청~청록을 보충
7. 초록 칸의 ✓ = 초록광 반사(추정)
8. 주황 칸 위 꼬마 사람(주황 머리) = 피코빌린?(작다=pico, 추정)

**구역5 — 원적색광과 엽록소 d·f**
1. 붉은 안개 = 가시광선 끝(빨강) 너머 원적색·근적외 빛
2. 'd' 가슴 사람 = 엽록소 d (글자)
3. 'f' 가슴 사람 = 엽록소 f (글자)
4. 안개 속 머리 화면이 짙은 빨강 = 700nm 넘는 긴 파장 흡수 (자리)

## ③ 의문점
- 뜻 모름: 망원경 옆 줄무늬 막대(빨대꼴)와 회청색 물방울, 회색 빗살 깔개, 바닥의 낱개 원반, 널빤지 기둥 2개, 'd'만 반투명한 이유.
- 어색: 달걀(엽록체)이 잎 세포보다 커서 확대 전환; 무지개가 벤치 위 비스듬한 판 모양.
- 헷갈림: 파랑·청록 머리 색 차가 작아 a/b는 가슴 표식으로만 구분; V자와 ✓ 모양 같음; 큰 Y사람과 작은 Y사람은 같은 엽록소 a; 당근이 두 번(사람·그림).
- 이어 붙인 흔적: 사각 머리 둘레 흰 테두리, 빛줄기가 같은 높이에서 끊김, 납작한 벡터풍 아이콘(네모·구슬·✓·망원경)이 수채 그림 위에 얹힘, 가운데 하늘색이 살짝 다름.

## ④ 한 문장
잎→엽록체→틸라코이드 막의 엽록소 a·b와 카로티노이드는 파랑·빨강 빛을 흡수해(초록은 반사) 반응중심 엽록소 a로 에너지를 모으고, 그 흡수 파장이 O₂ 발생(작용 스펙트럼)과 일치하며 일부는 엽록소 d·f로 원적색광까지 쓴다.
