# 1단계 생판

## ① 판 전체
- 1순위: **광합성 — 명반응(광계 I·II, 엽록체 구조, 광화학 반응, 흡수 스펙트럼)** 85%
- 2순위: **엽록체 구조와 광합성 색소/작용 스펙트럼** 10%

## ② 구역
**구역1 잎 단면(엽육·관다발)** — 잎의 울타리조직(길쭉한 세포)·해면조직(둥근 세포, 엽록체 점), 위아래 표피, 가운데 묶인 파이프 다발(물관, 파란 물방울 = 물 수송). 파이프 5~6개 = 물관부(물 공급, 근거: 뜻·모양). 엽록체는 잎 엽육세포에 있음(자리).

**구역2 엽록체(달걀 단면)** — 겉 이중막(두꺼운 테두리), 틸라코이드 쌓임 = 그라나(보라 점 3열 × 여러 층, 스트로마 라멜라로 연결, 근거: 모양), 기질 = 스트로마(그라나 사이 공간), 아래쪽 망원경 = 스트로마에서의 탄소 고정/암반응?(모름, 또는 색소 관찰) 한 방울 물방울 = 틸라코이드 내강의 H+/물 분해, 흰 구슬(O2 기포) 위로 방출(자리: 상층 내부와 막 밖). 그라나 약 6개 스택.

**구역3 광계 무대(방석)** — 사각 머리 = 광계 안테나 복합체(보라 틀 + 은빛 구 = 반응중심 특수 엽록소). 왼쪽 큰 사람(Y 모양 가슴) 과 오른쪽 큰 사람(포크 모양 가슴) = 서로 다른 두 광계(PSII / PSI 추정, 모양 기호 다름). 머리 위 무지개 빔 = 빛 흡수(녹색 선은 반사/투과되는 초록빛). 작은 두 사람(그릇 건네기) = 전자 전달계(플라스토퀴논·시토크롬 등 전달체, 노란 구슬 = 전자 / 에너지), 노란 물결선 = 전자 이동(또는 광자 에너지 공명 전달), 땅의 노란 별 구슬 = ATP(?) 또는 전자 에너지 손실. 당근 사람(망토) = 카로티노이드(보조 색소, 주황색, 근거: 뜻) — 흰 빛 기둥을 망토로 받아 모음(보호/집광). 보라 빛 당근 잎으로 올라감 = 청자색 광 흡수.

**구역4 프리즘과 벤치(스펙트럼)** — 프리즘 = 백색광 분산, 무지개 = 가시광 스펙트럼. 벤치 위 잎 부스러기(색소 조각)와 아래 사각 칸(보라/파랑/…/빨강 점, 2줄)= 흡수 스펙트럼 vs 작용 스펙트럼(위 줄 엽록소 a 기호, 아래 줄 카로티노이드? 포크 기호), 파랑·빨강에서 기포(흰 점, 산소 발생) 많음 = 엥겔만 실험(호기성 세균 / 산소 방출)과 비슷. 빨간 안개 속 두 사람 'd', 'f' = 엽록소 d, f (원적색광 흡수, 근거: 글자), 스펙트럼 끝쪽(빨강 뒤) 자리.

## ③ 어색/헷갈림
- 구역2 망원경: 의미 모름.
- 구역3 노란 물결선의 방향, 땅의 노란 별 구슬 의미 불명.
- 흰 빛 기둥이 흐릿하게 합성된 흔적(번진 흰 기둥), 구역4 벤치 아래줄 사각형 이어붙임 느낌.
- 왼쪽/오른쪽 큰 사람 중 어느 쪽이 PSI/PSII인지 헷갈림.

## ④ 한 문장
식물 잎의 엽록체 안 틸라코이드에서 여러 색소가 빛의 서로 다른 파장을 흡수해 광계 I·II와 전자 전달로 명반응을 일으키고, 그 스펙트럼이 흡수·작용 스펙트럼으로 나타난다.
