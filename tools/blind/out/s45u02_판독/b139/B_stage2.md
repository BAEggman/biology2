# stage2 (약속표 적용)

## 판 표제어
**1순위: 광합성 색소(엽록소 a·b·카로티노이드·d·f)와 틸라코이드 광계 — 흡수 스펙트럼과 에너지 전달** 확신 70% ↻(상승)
**2순위: 엽록체 구조(그라나·스트로마·루멘)와 명반응 개관** 확신 20%
약속으로 더 잘 풀린다: 1단계에서 모르던 세 갈래/포크 기호, 망원경, 사발, 구슬 액자가 모두 풀렸다.

## 구역1 잎 단면
표제어: **잎 — 광합성 장소**(약속 없음, 모양으로 읽음)
- 표피+큐티클, 책상조직(길쭉, 엽록체 촘촘), 해면조직(둥글, 틈), 관다발(은빛 관 5개)
  → 까닭: 위쪽에 길쭉한 세포를 빽빽이, 아래쪽에 둥근 세포를 성기게 견줘 놓았다. 빛 받는 쪽에 엽록체가 몰림. 5개의 까닭 모름(개수 뜻 불확실).
- 엽록체 알갱이(타원): 세포마다 박혀 있음 → 까닭: 같은 알갱이가 모든 세포에 반복돼 엽록체가 광합성 단위임.
- 관 속 파란 알: 약속표에 없음(물관의 물로 읽음). 파란 유리알은 청색광 수용체 약속(#122)과 비슷하나 관 안 물방울이라 억지로 끼우지 않음. → 까닭 모름.

## 구역2 엽록체 ↻
표제어: **엽록체의 구조 — 그라나·루멘·스트로마**
- 팬케이크처럼 포갠 초록 쿠션 더미 = 그라나(#167), 속 빈 쿠션 = 틸라코이드, 맨 윗 더미의 검게 벌어진 속 = 루멘. 더미 4개 + 아래 더미(총 5~6개) ↻
  → 까닭: 쿠션을 쌓아 표면적을 늘리고 속을 비워 H⁺를 가두는 공간으로 보임. 더미 사이 납작판(라멜라)이 잇는 것도 견줘 읽음.
- 더미마다 보라 액자 점 줄(3줄씩) = 포르피린+Mg 색소(#81) ↻ → 까닭: 막 위에 같은 색소가 줄맞춰 박힘 = 광계가 막에 들어 있음.
- 밝은 방울 3개(루멘 속 1, 껍질 틈 1, 밖 1) = O2(#17) ↻ → 까닭: 방울이 루멘에서 껍질 밖으로 한 줄로 올라감 = 물 분해로 생긴 O2가 막 밖으로 나감(자리로 읽음).
- 바닥의 술 달린 회색 깔개 = 스트로마(#164) ↻ → 까닭: 그라나 아래 빈 바닥에 펴 깔아 그라나 밖 기질로 갈림.
- 루비 렌즈 놋쇠 망원경 = 루비스코(#34) ↻, 곁의 마디 막대 = 탄소 수(#159)(마디 5개쯤: RuBP 5탄소로 보이나 아래가 잘려 확신 낮음), 파란 물방울 1개 ↻ → 까닭: 깔개(스트로마) 위에 놓여 캘빈 회로가 스트로마에서 일어남을 자리로 읽음. 막대 개수의 까닭은 불확실. 물방울 뜻 모름.
- 달걀 이중 껍질: 외막·내막 → 까닭: 두 겹으로 그려 막 2겹.

## 구역3 방석 위 광계 무대 ↻
표제어: **광계 — 색소 종류와 에너지 전달**
- 왼쪽 큰 사람 = 엽록소 a ↻: 가슴 세 갈래(끝 흰 알 셋) = 메틸기 CH3(#165) · 머리 액자 보라 = 포르피린+Mg(#81) · 머리 줄무늬 보라·파랑·빨강 위주 = 흡수하는 빛깔 · V로 튕겨 나가는 초록 = 반사한 빛(#169).
  → 까닭: 같은 몸에 기호만 다르게 둬 a와 b의 차이를 곁 사람과 견줌. 초록이 튕기므로 잎이 초록으로 보임.
- 오른쪽 큰 사람 = 엽록소 b ↻: 가슴 네 갈래 포크 = 포르밀기 CHO(#166) · 줄무늬에 청록·주황이 더 있음 · 초록 V 반사.
  → 까닭: 왼쪽 몸과 오른쪽 몸의 줄무늬가 달라 b가 a와 다른 파장(청록·주황)을 더 흡수함을 견줌. 줄무늬가 구역4 벤치 구슬과 같음.
- 주황 당근 영웅 = 카로티노이드(색/소리) · 머리 잎에 보라+청록 빛 · 망토가 하얀 흐릿한 강한 빛줄기를 가림. → 까닭: 청자색~청록을 흡수하고 주황으로 보임(#169). 망토를 빛 쪽으로 펴 강한 빛을 막음 = 광보호. 크기가 작고 사람 사이에 낌 = 보조색소.
- 노란 물결선 3줄(큰 왼쪽→작은 왼쪽 호 1, 당근→작은 왼쪽 1, 큰 오른쪽→작은 오른쪽 1) ↻ → 까닭: 큰 사람과 당근에서 가운데 작은 사람 둘로 모임 = 안테나 색소에서 반응중심으로 에너지 전달. 방향이 모두 가운데를 향함.
- 작은 두 사람 = 반응중심 엽록소 a(가슴 세 갈래 둘, 줄무늬 없는 흰 눈 머리) ↻ → 까닭: 바깥 빛은 안 받고 물결선만 받음, 손을 맞잡음 = 특수 쌍 2개(개수 2).
- 노란 공 = 들뜬 전자, 속 빈 나무 사발 = 1차 전자수용체(#168) ↻ → 까닭: 두 사람이 공을 사발에 넘김 = 전자를 수용체에 넘김.
- 바닥의 빛나는 노란 공 + 점선 + 김 ↻ → 까닭: 약속표에 없음. 잃은 에너지(열)로 읽으나 모름.
- 방석 = 막(자리). 까닭 모름.

## 구역4 프리즘과 벤치 ↻
표제어: **흡수 스펙트럼 · 작용 스펙트럼(엥겔만)**
- 프리즘 → 무지개 → 벤치: 빛을 파장별로 가름 → 까닭: 한 줄 빛이 색으로 갈려 벤치 위치마다 파장이 다름.
- 세균 무리 = 보라 쪽 큰 더미, 빨강 쪽 큰 더미, 청록·주황 쪽 작은 더미, 초록 쪽 거의 없음 + 흰 방울 O2(#17) → 까닭: 방울 많은 곳이 광합성 많은 곳. 초록이 비어 있음 = 초록은 반사돼 쓰이지 않음(작용 스펙트럼).
- 벤치 두 줄 네모(7칸씩): 위줄 세 갈래 기호 = a, 아랫줄 포크 = b ↻. 구슬 빛깔 = 흡수 파장 · 흰 구슬 = 흡수 없음(#126 하나씩만 다른 대조).
  위줄: 파랑·빨강 구슬. 아랫줄: 파랑·청록·주황 구슬. → 까닭: 같은 칸을 나란히 두고 구슬 색만 바꿔 a와 b가 흡수 파장이 어떻게 다른지 견줌(위아래로 맞섬).
- 청록 아래 당근 화살표 = 카로티노이드가 청록(청자~청록) 흡수 ↻ → 까닭: 두 줄 사이 같은 자리에 당근을 둬 a, b 사이 틈을 카로티노이드가 메운다는 뜻으로 읽음.
- 오른쪽 어두운 적색 안개 속 d, f 사람 ↻ → 까닭: 스펙트럼 끝(적색 너머) 자리 = 원적색 흡수 색소 d·f. 안개로 빛이 약한 곳에 있음. 머리는 같은 액자지만 붉은 색조.

## 뜻 모름 / 어색
망원경 곁 파란 물방울과 마디 개수, 바닥의 빛나는 노란 공, 하얀 빛기둥, 방석, 관다발 개수 5, 작은 두 사람의 구체적 위치(PS II/I 구분 없음). 벤치 줄과 구슬 격자는 붙인 흔적.

## 한 문장
엽록소 a·b와 카로티노이드는 서로 다른 파장을 흡수해(초록은 반사) 에너지를 반응중심 엽록소 a로 모으고, 이것이 엥겔만 실험의 작용 스펙트럼으로 확인되며 엽록체에서 일어난다.
