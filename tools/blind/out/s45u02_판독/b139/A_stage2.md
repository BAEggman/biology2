# stage2 (약속표 적용)
## ① 판 전체
**1순위: 엽록소 구조(포르피린+Mg, 곁사슬 CH3/CHO)·광합성 색소의 흡수 스펙트럼** 85% (↻ 구조 쪽으로 무게 이동: 자주빛 액자+은구슬 #81, 메틸기 #165, 포르밀기 #166)
**2순위: 엽록체 안 명반응 위치(틸라코이드·그라나·스트로마)와 O2·들뜬 전자** 65%
## ② 구역과 까닭(→ 까닭)
구역1 잎 단면 — **잎의 구조**
- 위 표피·큐티클(갈색 얇은 띠), 길쭉한 울타리조직, 둥근 해면조직, 아래 표피 (사실 3). → 까닭: 울타리 세포 안 초록 알갱이(엽록체)가 해면보다 빽빽하게 그려짐 = 빛 받는 위쪽에 엽록체가 몰림. 같은 잎 속 두 조직을 나란히 견줘 읽음.
- 은색 관 다발 5개 + 관마다 파란 방울(↻ 파란 방울은 약속표상 물/청색 유리알 아님, 단순 물로 읽음) = 물관. → 까닭: 개수 5는 뜻 불명(까닭 모름), 해면조직 높이에 묶여 있어 잎맥이 해면 쪽에 있다는 자리.
구역2 엽록체 — **엽록체 구조**
- 이중막 달걀 → 까닭: 겹친 두 겹 껍질이 둘레를 두름(이중막).
- 쌓인 쿠션 더미 = 틸라코이드·그라나(#167) 여섯 안팎 → 까닭: 더미 사이를 잇는 납작 선반 = 그라나 사이 연결 틸라코이드, 더미 높이가 서로 달라 개수는 의미 약함. 보라 점 격자(자주빛 액자 점) = 막에 박힌 엽록소.
- 바닥 회색 깔개(술 달림) = 스트로마(↻ #164). → 까닭: 더미 밖 바닥에 펴 깔림 = 막 바깥 빈 자리가 스트로마.
- 루비빛 렌즈 놋쇠 스코프(↻ #34 루비스코) = 스트로마의 루비스코; 곁의 마디 막대(흰·갈색 마디 5개 안팎 = 탄소 수 #159, 5탄소 RuBP로 읽음)+어두운 방울 하나(#16 CO2) → 까닭: 스코프가 마디 막대 끝 쪽을 향하고 어두운 방울이 막대에 붙음 = CO2가 5탄소에 붙는 일(고정). 마디 개수는 확신 낮음.
- 흰 공(O2, #17) 셋: 더미 꼭대기 위(루멘 쪽), 이중막 안쪽 위, 엽록체 밖 위 → 까닭: 위로 솟아 나감 = 물 분해 O2가 막 안→밖으로 빠져나옴(자리의 순서).
구역3 방석 무대 — **엽록소 a·b·카로티노이드와 반응중심**
- 사람 머리 자주빛 액자+은구슬 = 포르피린 고리+Mg(#81) → 까닭: 액자 빛깔이 곧 이름. 머리 속 줄무늬 색 = 그 색소가 먹는 빛(보라·파랑·빨강 / 보라·파랑·청록·주황)이며 두 사람이 다름 = a, b 흡수 차이.
- 왼쪽 인물 가슴 세 갈래 가지+흰 알 셋 = CH3(#165) = 엽록소 a; 오른쪽 인물 가슴 갈퀴 넷 포크 = CHO(#166) = 엽록소 b → 까닭: 둘이 같은 몸에 가슴 표지만 다름(하나만 다름 대비) = 고리는 같고 곁사슬만 다르다.
- 초록 V자 되튀는 빛(#169) = 초록 반사 → 까닭: 초록은 쓰지 않고 튕겨 보내서 잎이 초록으로 보임. 두 머리 모두 V가 초록.
- 당근 + 주황 망토 = 카로티노이드(↻ 약속표 밖, 그림 근거로 유지). → 까닭: 당근에 닿는 빛이 보라·청록 2줄 = 엽록소가 덜 먹는 청록을 보충해 먹음; 망토는 주황 반사. 망토 위 흰 광선이 흐릿하게 지워짐 = 강한 빛을 흡수·완화(광보호, 불확실).
- 주황 물결선 = 에너지 전달(↻ 당근에서 작은 인물 둘로, 큰 인물에서 작은 인물로) → 까닭: 큰 인물들 모두에서 가운데 작은 인물로 모임 = 안테나에서 반응중심으로 집중.
- 가운데 작은 인물 둘, 줄무늬 없는 흰 창 = 반응중심 특수쌍 엽록소 a 둘(가슴 CH3 둘). 맞잡은 사발(#168 받침 없는 나무 사발) 속 노란 공(들뜬 전자) → 까닭: 둘이 한 사발을 같이 받쳐 건넴 = 특수쌍이 전자를 1차 수용체에 넘김; 점선 아래 불꽃 공(열) = 쓰지 못한 에너지는 열로 샘.
- 방석(초록 쿠션) = 틸라코이드막(#167)로 읽음 → 까닭: 인물들이 그 위에 선 채 꼬리는 풀에 꽂힘 = 막에 박힘(꼬리는 피톨 꼬리로 추측, 근거 약함).
구역4 프리즘과 벤치 — **흡수·작용 스펙트럼, 엥겔만 실험, 엽록소 d·f**
- 프리즘이 흰 빛을 무지개로 나눔 + 세균 더미(보라 쪽 큼, 빨강 쪽 큼, 초록 쪽 거의 없음) = 작용스펙트럼 → 까닭: 더미 크기를 위아래 견줌, 가운데 초록은 비어 있음. 흰 방울(O2)이 보라·빨강 위에서 올라옴 = 그곳에서 광합성이 활발.
- 벤치 위줄(세 갈래 가지=a)·아랫줄(포크=b) 사각 액자 칸마다 속 구슬 빛깔: a는 보라·파랑·(흰들)·빨강, b는 파랑·청록·주황 → 까닭: 흰 칸=안 먹는 파장, 색 칸=먹는 파장, 두 줄이 같은 위치에서 다르게 채워짐(a와 b의 흡수 차이, 대비). 청록 칸 곁 당근 화살 = 카로티노이드가 청록 보충.
- 오른쪽 붉은 안개 속 d·f 인물(노란 글자, 가슴 표지 없음, 머리 속 붉음) = 엽록소 d·f, 원적색광 흡수 → 까닭: 붉은 빛 끝 너머 짙은 어둠에 서 있음 = 더 긴 파장; 빛이 흐린 곳에서도 일함. 몸이 흐릿함 = 덜 흔한 색소(추측).
## ③ 헷갈림
↻ 스코프 풀림(루비스코). 남음: 가운데 흰 광선(기둥), 관 다발 5개와 벤치 칸 색의 정밀한 파장 매칭, 방석 꼬리 뜻, 망토의 광보호 해석.
## ④ 한 문장
엽록소는 포르피린+Mg 고리에 곁사슬(a CH3, b CHO)만 달라 흡수하는 빛이 달라지고, 안테나가 모은 에너지를 반응중심이 들뜬 전자로 넘겨 엽록체에서 광합성이 일어난다.
