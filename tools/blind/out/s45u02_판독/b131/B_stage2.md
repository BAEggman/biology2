# 2단계 덱 약속으로 다시 읽기 (s45u02)

## 판정 (정직하게)
약속표가 이 판에서 직접 짚는 소품은 일곱 군데뿐이다: #16 어두운 방울·#17 밝은 방울·#34 루비스코·#81 포르피린+Mg(표에 s45u02라고 적힘)·#125 파란 빛줄기·#126 줄지어 하나만 다른 소품·#159 마디 막대. 이 중 #159가 1단계 「모름」 하나를 풀었고 나머지는 1단계 독해를 확정했다. 당근·물결선·그릇·노란 구슬·프리즘·세균·안개·유령은 표에 없어 1단계 그대로 둔다. 결론: 큰 틀은 안 바뀌고 약속으로 조금 더 잘 풀린다.

## ① 판 전체 표제어
- 1순위 **광합성 색소(엽록소의 구조·종류)와 빛 흡수 — 엽록체·안테나→반응중심·스펙트럼** ↻ 82% (78→82: #81이 이 판에 포르피린 고리+Mg를 박아 둠)
- 2순위 **광합성 명반응의 광계** 10%
- 나머지 8%: 엥겔만·적색 강하 단독 판, 광합성 개요.

## ② 구역 (5칸, 1단계와 같음)
### 구역1 **잎 단면(엽육 구조)** — 8개, 1단계와 같음
블록=잎 단면 / 갈색 띠=큐티클 / 투명·점 없는 납작 세포 6=상부 표피 / 길쭉 빽빽 10·점 15~25=책상조직 / 둥글고 성김·점 4~9=해면조직·세포간극 / 은색 파이프 5+띠 2=관다발 / 맨 밑 납작 세포=하부 표피 / 초록 점=엽록체. 콩팥 모양 둘(#14)·롤 셔터(#120)가 없어 기공은 안 그려진 것으로 일관.

### 구역2 **엽록체 구조(그라나·스트로마·O₂ 방출·루비스코의 CO₂ 고정)** — ↻ 10개 (8→10)
달걀=엽록체 / 테두리 두 겹=이중막 / 방석 더미 6×4장(오른쪽 맨 아래 2)=그라나 / 선반=스트로마 라멜라 / 회색 바탕=스트로마 / ↻ 열린 원반 속 밝은 방울=O₂, 틸라코이드 내강에서 발생(#17로 확정) / ↻ 밝은 방울 3(내강·막 틈·밖)=O₂가 막 둘을 지나 나감(#17) / ↻ 루비빛 렌즈 놋쇠 스코프=루비스코(#34로 확정, 스트로마) / ↻ 풀림: 마디 5개 막대=RuBP 5탄소(#159, 두 빛깔 마디가 번갈아 5) / ↻ 풀림: 막대에 붙은 물방울꼴 어두운 방울=CO₂ 1탄소(#16·#159) → 5+1=6탄소, 루비스코가 RuBP에 CO₂를 붙이는 장면.

### 구역3 **광합성 색소와 안테나–반응중심(엽록소 a·b, 카로티노이드)** — 10개, 수는 같음
방석=틸라코이드막 / ↻ 자주빛 네모 액자+은빛 구슬 4명(큰2·작2)=포르피린 고리+Mg(#81로 확정) / 꼬리 4=피톨 꼬리의 막 고정 / ↻ 왼쪽: 파란 머리·Y·파란 빛줄기=엽록소 a, 파란 빛줄기는 청색광(#125) / 오른쪽: 청록 머리·포크·청록 빛 흡수·초록 V 반사=엽록소 b·녹색 반사 / 당근=카로티노이드(보라+청록 2줄) / 망토=광보호 / 물결선 3=안테나→반응중심 에너지 / 손잡은 둘(흰 머리·Y)=반응중심 엽록소 a 특수쌍 / 구슬 1+그릇=들뜬 전자→1차 수용체(표에 없음. 구슬은 입체라 동전 #8 ATP가 아니고, 그릇은 속이 파여 방패 #114 NADPH가 아님).

### 구역4 **프리즘·벤치: 엥겔만 실험과 흡수/작용 스펙트럼** — 7개
흰 기둥→프리즘→7색=분광 / 초록 줄=녹조류 실 / 올리브 막대=호기성 세균 / 더미 2곳(약 50 보라~파랑, 약 85 빨강)=작용 스펙트럼 / ↻ 밝은 방울 7·10=O₂(#17로 확정) / ↻ 해석 보강: 막대 위 같은 상자(#81) 7개가 나란하고 가운데 색만 다름=파장 하나만 바꾼 대조 실험(#126), 보라·파랑·빨강만 색이라 흡수 스펙트럼 / 초록 체크=녹색은 흡수 안 됨.

### 구역5 **붉은 안개와 유령 둘(적색 강하/에머슨)** — 2개, 약함
안개=원적색 영역에서 광합성 급감 / 유령 2=희미한 포르피린+Mg 틀(#81), 두 광계. 표에 없어 억지로 끼우지 않음.

## ③ 모름·어색함·헷갈림·이어붙임
- ↻ 풀린 것: 5마디 막대+푸른 물방울. 
- 여전히 모름: 회색 깔개(술 빗금이라 #101 네모 칩 아님, #9 요 전용이라 끼우지 않음), 그라나→망원경 고리 가는 줄(줄 위에 동전·방패 없음, #128 끈은 관 졸라맨 끈 한정이라 안 끼움), 흐린 흰 빛줄기.
- ↻ 새 헷갈림: 초록 V·체크는 #7 V자 이음쇠(ADH)와 무관. 포크는 #56(포크 꽂힌 갈색 잔=푸코잔틴)과 달리 잔이 없음. 파란 머리는 #122 흰 눈알이 아니라 틀 안 채색. 달걀형 엽록체·망토에 #49 알·감·베 후크를 끼우지 않음. a/b 배정(Y·파랑 대 포크·청록)은 표로 못 정함.
- 이어붙임 흔적은 1단계와 같음(오른쪽 수채 질감, 흰 테두리 스티커 소품, 흰 빛기둥 경계).

## ④ 한 문장
↻ 잎의 엽록체에서 포르피린 고리(Mg)와 피톨 꼬리를 가진 엽록소 a·b와 카로티노이드가 청자·적색광(녹색은 반사)을 흡수해 에너지를 반응중심 엽록소 a 한 쌍에 모으면 전자가 튀어 나가고(O₂는 내강으로), 스트로마의 루비스코는 5탄소 RuBP에 CO₂를 붙여 6탄소로 만들며, 그 스펙트럼을 엥겔만 실험이 확인한다.
