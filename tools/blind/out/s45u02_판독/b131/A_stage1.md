# 1단계 생판 (그림만 보고)

## ① 판 전체 표제어
- 1순위 **광합성: 장소(잎→엽록체)와 빛 흡수(광합성 색소·스펙트럼·광계)** — 85%
- 2순위 **광합성 명반응의 첫 단계(안테나→반응중심→전자 방출)** — 40%
- 흐름: 잎 단면 → 엽록체 → 막 위 색소 분자 → 프리즘·세균 실험(증거). 점점 확대한 뒤 실험으로 검증.
- 근거: 그라나·엽록소 인물·프리즘+세균이 모두 '빛 포획'. 전자전달·ATP 합성은 안 그려져 2순위.

## ② 구역별 (왼쪽부터 4구역)
### 구역1 **잎의 단면 구조**
- 맨 위 갈색 얇은 띠 = 큐티클(표피 위 방수층) [자리]
- 위·아래 연한 납작 세포(위쪽 5~6개) = 표피, 엽록체 없음, 기공은 안 그려짐 [모양]
- 위쪽 길쭉한 기둥 세포 약 10개, 점 약 20개씩, 빽빽 = 책상(울타리)조직, 빛 쪽·광합성 주력 [모양·자리·개수]
- 아래 둥근 세포 4~5층, 점 3~7개, 사이 어두운 틈 = 해면조직, 엽록체 적고 틈은 기체 통로 [모양]
- 세포 속 초록 타원 점 = 엽록체 [모양]
- 은색 속빈 관 5개 묶음(오른쪽 끝엔 3개 보임) = 관다발(물관·체관), 해면조직 속 [모양·자리]
- 갈색 띠 2개 = 유관속초(추정) [모양]

### 구역2 **엽록체의 구조와 장소**
- 달걀 단면 = 엽록체(타원체) [모양]
- 벽 2겹, 사이 어두운 틈 = 외막·내막 [개수]
- 쿠션 원반 더미 6개(4·4·4·4·4·2, 22장) = 그라나, 원반 = 틸라코이드 [모양·개수]
- 더미를 잇는 납작 판자 6~8개 = 스트로마 라멜라 [모양]
- 회색 바닥·빈 곳 = 스트로마(칼빈 회로 자리) [자리]
- 맨 위 더미의 윗 원반이 입처럼 벌어짐 = 틸라코이드 내강, 물 분해·O2 발생 [모양]
- 흰 구슬 3개(내강 위→막 사이 납작→밖 공중) = O2 방출 경로 [개수·자리]
- 망원경(scope)+빨간 보석(ruby) = RuBisCO, 5마디 막대 = RuBP(5탄당), 푸른 물방울 = CO2(추정) [소리·개수]

### 구역3 **광합성 색소와 광계** (쿠션 위 인물 5: 큰 2·작은 2·당근 1)
- 초록 쿠션 = 틸라코이드 막 [모양·자리]
- 사각 머리+가운데 은구슬 = 엽록소 고리+Mg, 긴 꼬리 4개 = 피톨 꼬리(막에 박힘) [모양·개수]
- Y 표식 큰 인물 = 엽록소 a, 포크 표식 인물 = 엽록소 b(곁사슬 차이, 추정) [모양]
- 당근+망토 = 카로티노이드(보조 색소, 망토는 광보호?), 꼬리 없음 [소리·색]
- 광선: 파랑→a, 보라+청록→당근, 청록→b = 청자색~청록 흡수. 초록은 V로 튕김 = 반사 [색·모양]
- 노란 물결선 3개 = 안테나 색소→반응중심 에너지 전달 [개수]
- 손잡은 작은 쌍 2명(Y, 빛 직접 안 받음) = 반응중심 엽록소 a 쌍 [개수]
- 그릇 = 1차 전자 수용체, 노란 공 1개 = 방출된 전자 [뜻·개수]

### 구역4 **흡수·작용 스펙트럼(엥겔만 실험)**
- 흰 기둥 = 백색광, 프리즘 = 분광, 무지개 7띠 [모양·개수]
- 벤치 위 초록 실 1가닥 = 사상 녹조류, 올리브 막대 = 호기성 세균 [모양]
- 세균 무리 2곳: 보라~파랑(~50), 빨강(~80), 초록~노랑엔 3마리 = 작용 스펙트럼 청자색·적색 최대 [자리·개수]
- 흰 거품 좌 7~8·우 약 10 = O2 [개수]
- 선반 상자 7개: 색 있는 3(보라·파랑·빨강)·흰 4, 초록 ✓ = 흡수 대 비흡수(초록 반사) [개수]
- 붉은 안개 속 희미한 인물 2 = 원적색 한계(red drop) 또는 두 광계? [개수] 확신 낮음
- 돌기둥·벤치·선반 기둥 2 = 받침(뜻 없음으로 봄)

## ③ 이상·모름·헷갈림·이은 흔적
- 모름: 왼쪽 인물 곁 흰 사선 빛줄기(팔·엉덩이를 반투명하게 덮음; 백색광? 안 쓰인 색?), 그라나 밑에서 망원경으로 이어진 가는 실, 관 5·띠 2의 개수 뜻
- 헷갈림: Y가 안테나 a와 반응중심에 똑같이 쓰임(Y 3명 대 포크 1명); 얼굴색(파랑·청록)이 흡수광인지 a/b 구분인지; 초록 V(광선)와 ✓가 같은 뜻인지; 흰 구슬이 O2인지 H+인지
- 이은 흔적: 사각 머리·표식·물결선·노란 공·망원경·7상자·✓·거품은 흰 테두리 달린 덧붙인 아이콘. 하늘은 매끈하고 구역 사이 이음선 없음. 붉은 안개만 화풍이 다른 수채 느낌. 잎 블록 모서리 세로 점선은 3D 모서리. 물관/체관 구분 없음.

## ④ 한 문장
잎 속 엽록체의 틸라코이드막에서 엽록소 a·b·카로티노이드가 청자색·적색광을 흡수(초록은 반사)해 반응중심 엽록소 a로 에너지를 모아 전자를 내보내며, 이는 엥겔만 실험의 세균 분포로 증명된다.
