# s08u01 2단계 (약속표 어휘로 재판독) — ↻ = 1단계와 달라진 곳

## 판정
약속표로 **더 잘 풀림**. 이 판에 걸린 약속 8개(자갈=Ca2+, 사자 문고리=RyR, 청록 스위치 상자+D자 고리=DHP, 동전=ATP, 모듈 쟁반=칼모듈린, 트로피=트로포-, 네온=네불린, 붉은 민 도장=인산화)가 1단계 추정을 모두 확인했고, 틀린 곳 하나(칼모듈린 주체)를 고쳤다. 겹쳐 보여도 끼우지 않은 것: 로봇팔(로봇=안드로겐), 역도 벨트 거구(샅바 장사=APC/C), 은회색 파이프(검은 가스 파이프=카스파리대).

## ① 판 전체 표제어
- **1순위: 근육의 수축 기전 — 골격근·심근·평활근 비교(흥분-수축 연결, Ca2+ 조절)** — 85% ↻(80→85)
- **2순위: 근수축의 Ca2+ 조절 — DHP·RyR·칼모듈린·트로포-** — 45% ↻(표현만 약속 어휘로)

## ② 구역별 (괄호=근거, △=추정)
**구역1 — 골격근: DHP–RyR1 기계적 결합** (7개)
1. 사자 문고리 1개 사물함 = RyR 1형, 사물함 = SR ↻(소리 추정→약속 확정; 개수=아형)
2. 쏟아진 자갈 더미 = SR이 내놓은 Ca2+ ↻
3. 청록 상자의 D자 고리를 당기는 사람 = DHP, 고리에서 자갈이 새지 않음=통로 아닌 전압 감지 ↻
4. 상자~문고리 직결 막대 = 직접 기계적 결합
5. 벽 파이프의 닫힌 밸브에 갇힌 자갈 = 세포외 Ca2+ 불필요 (약속 밖, 자연 읽기)
6. 빈 동전 지갑 + 거미줄 덮여 역기를 쥔 채 굳은 회색 남자, 곁에 자갈 = ATP 없고 Ca2+ 있음 → 사후강직 ↻(보통→높음)
7. 선반 왼쪽 트로피 = 트로포- 계열(트로포닌) 있음 ↻

**구역2 — 심근: plateau와 Ca2+ 유도 Ca2+ 방출** (7개)
1. 모니터의 급상승–긴 평탄–하강 파형 = 심근 활동전위 plateau
2. 청록 상자의 D자 고리 = DHP(L형 칼슘통로), '머그'가 아니라 1구역과 같은 상자 ↻
3. 고리 끝에서 몇 알만 새는 자갈 = 소량의 Ca2+ 유입(plateau 원인)
4. 막대 없이 몇 알이 큰 더미로 이어짐 = 기계적 결합 아닌 CICR
5. 사자 문고리 2개 사물함 = RyR 2형
6. 선반 가운데 트로피 = 트로포- 있음
7. △ 러닝머신 사람 = 지치지 않는 심장(약속표로 안 풀림)

**구역3 — 평활근: Ca2+–칼모듈린–MLCK** (7개)
1. 선반 오른쪽 빈 받침 = 트로포닌 없음
2. 노인이 든 모듈 쟁반 = 칼모듈린(쟁반이 칼모듈린이고 노인은 운반자) ↻(노인=칼모듈린 정정)
3. 쟁반 위 4개 = Ca2+ 4개 결합 ↻
4. 노인이 소년을 떠밂 = Ca2+–칼모듈린이 MLCK 활성화
5. 소년 = MLCK(도장 찍는 쪽, △ 노인=MLCK·소년=경쇄 가능)
6. 붉은 민 도장 = 인산화, 패드의 붉은 번짐 = 찍힌 자국 ↻(모름 해소)
7. 관절 로봇팔 = 미오신(인산화 받는 쪽); '로봇=안드로겐'과 충돌 가능하나 도장 받는 기계 팔이라 유지 ↻

**구역4 — 근절 구조: 네불린·타이틴·활주** (4개)
1. 사람 키보다 큰 코일 스프링(약 10바퀴) = 타이틴 (약속 밖, 모양)
2. 분홍 네온 = 네불린 ↻(○→◎)
3. △ 막대 끝을 덮은 뒤집힌 트로피 = 트로포- 중 덮개(트로포미오신 또는 트로포모듈린) ↻
4. 도해판 긴·짧은 막대(회색 폭 불변) = A대 불변·I대 단축

**구역5 — 근섬유 유형: 지근 vs 속근** (2개)
1. 붉은 옷 마른 선수 = 지근
2. 흰 옷 역도 벨트 거구 = 속근 ↻(샅바 장사=APC/C 후보 기각: 샅바·맨몸이 아님)

## ③ 모름·헷갈림·이음
- 풀린 모름 ↻: 패드의 붉은 호선 = 도장이 눌려 번진 자국(약속 '붉은 민 도장'), 빈 지갑 = 동전 없음(ATP).
- 놓친 물건: 없음(환기창 줄·선반 받침 3개·벤치·스탠드 전선은 뜻 없는 소품으로 봄). 새로 본 것은 D자 고리에서 자갈이 새는지(1구역 안 샘=센서, 2구역 샘=통로)와 쟁반 위 4칸.
- 아직 모름: 네온 중간 L자 받침쇠, 로봇팔 받침의 막대 손잡이, 누운 남자 옆 흰 천(지우개 모양 아님), 모니터 전선.
- 헷갈림: 두 트로피(바로/거꾸로)가 각각 어느 트로포-인지, 노인·소년 중 MLCK, 은회색 파이프(카스파리대 아님), 러닝머신 사람. 이음선 없음(오른쪽 벽색만 변함).

## ④ 한 문장
자갈(Ca2+)이 사자 문고리(RyR)를 열어 쏟아지는데, 골격근은 D자 상자(DHP)가 막대로 직접 당겨 열고, 심근은 같은 상자가 흘린 몇 알이 큰 더미를 부르며, 평활근은 트로포닌 없이 모듈 쟁반(칼모듈린)이 소년(MLCK)을 떠밀어 붉은 도장(인산화)을 찍게 하고, 이 신호는 네불린·타이틴이 잡은 근절에서 A대는 그대로 I대만 줄이는 활주로 이어지며 동전(ATP)이 없으면 굳는다.
