# 생판 stage1 (그림만 보고 읽음)

## ① 판 전체 표제어
- **1순위: 근육 수축의 조절 — 골격근·심근·평활근 비교(흥분-수축 연결, Ca²⁺ 경로)** 확신 75%
- **2순위: 근절 구조·활주설·근섬유 유형(근육의 구조와 수축 기작)** 확신 40%
- 근거: 구슬(=Ca²⁺ 추정)을 쏟는 사물함 둘(사자 1마리/2마리), 위 선반의 트로피 둘+빈 받침, 오른쪽 끝의 근절 도해판·스프링·빨강/하양 선수.

## ② 구역별 (왼쪽부터)
**구역1 골격근 흥분-수축 연결(DHPR–RyR1 직결)** x50~560
- 열린 사물함+쏟아진 구슬 = 근소포체(SR)의 Ca²⁺ 저장·방출 (뜻·자리)
- 사자 문고리 1개 = RyR 1형 (소리 라이언≈리아노딘, 개수 1)
- 문 가장자리와 초록 상자를 잇는 가로 막대 = 센서와 채널이 물리적으로 직접 연결 (모양)
- D자 손잡이 초록 상자 = DHPR, 전압 감지기 (모양 D)
- 손잡이를 당기는 근육질 남자 = 탈분극이 센서를 당겨 채널을 엶 (동작)
- 벽 파이프+닫힌 밸브(구슬이 밸브 위에 갇힘) = 세포 밖 Ca²⁺ 유입 불필요 (뜻, 중간 확신)
- 벤치의 회색 남자(눈 감음·거미줄·흰 천 2조각)+가슴 위 바벨 1+빈 동전지갑 1 = 사후강직: ATP 없어 마이오신이 못 떨어짐 (뜻, 중간)
- 선반 첫 트로피 = 트로포닌(소리 트로피≈트로포) 있음

**구역2 심근 활동전위의 고원** x580~860
- 모니터의 사다리꼴 곡선(급상승-평평-급하강, 시작에 작은 뾰족) = 심근 활동전위 고원 (모양)
- 러닝머신에서 쉬지 않고 달리는 남자 = 지속·반복되는 박동, 유산소 (동작, 낮음)
- 선반 둘째 트로피 = 트로포닌 있음 (자리)

**구역3 심근 Ca²⁺ 유발 Ca²⁺ 방출(CICR)** x860~1150
- 손잡이 달린 머그형 초록 상자에서 구슬이 약 8방울 샘 = 세포 밖 Ca²⁺가 L형 채널로 조금 유입 (모양·개수)
- 사자 문고리 2개 = RyR 2형 (개수 2)
- 구슬이 넘치는 사물함(왼쪽보다 훨씬 많음) = 소량 유입이 대량 방출을 유발, 증폭 (양)
- 구역1과 대비: 이쪽은 세포외 Ca²⁺ 의존

**구역4 평활근 Ca²⁺-칼모듈린-MLCK** x1150~1500
- 차분히 느리게 걷는 노인 = 칼모듈린 (소리 calm, 동작 느림)
- 쟁반 쿠키 4개 = Ca²⁺ 4개 결합 (개수)
- 노인 손이 소년 어깨에 = Ca²⁺-칼모듈린이 MLCK를 활성화 (자리)
- 소년이 빨간 도장을 나무판에 찍음 = 마이오신 경쇄 인산화(인印산화) (동작·소리)
- 관절 로봇팔의 갈색 판 = 마이오신 머리, 인산화되면 작동 (모양)
- 선반의 빈 받침대 = 평활근엔 트로포닌 없음 (자리)

**구역5 근절 구조: 활주설·타이틴** x1560~1930
- 거대한 코일 스프링(약 9~10바퀴) = 타이틴, 탄성·복원 (모양)
- 벽 도해판 두 줄: 위(청록-회색-청록 김)/아래(회색 폭 그대로, 청록만 절반) = 수축 시 A대 불변·I대 단축 (크기)
- 모름: 청록 기둥 위에 거꾸로 씌운 금빛 트로피, 분홍 네온관+벽 브래킷

**구역6 근섬유 유형 지근 vs 속근** x1660~1930
- 마른 빨강 선수 = 지근(적색, 마이오글로빈·미토콘드리아, 지구력) (색·체형)
- 근육질 흰 옷+역도벨트 = 속근(백색, 해당 중심, 순발력·큰 힘) (색·체형)

## ③ 의문·어색함·헷갈림·이어붙임
- 뜻 모를 것: 청록 기둥+거꾸로 트로피(종), 분홍 네온관과 브래킷 팔, 로봇팔 밑동의 갈색 판·크랭크, 모니터의 전선.
- 어색한 것: 파이프가 벽에 떠 있고 사물함과 이어지지 않음. 회색 남자만 탈색. 스프링이 사람보다 훨씬 큼.
- 헷갈리는 것: 두 초록 상자가 같은 물건의 반복인지, 사물함 둘의 차이가 사자 수뿐인지. 러닝머신 남자와 빨강 선수가 둘 다 달리기류. 청록색이 상자·기둥·바지에 두루 쓰여 색 규칙이 흐림.
- 이어 붙인 흔적: 바벨 원판·지갑·파이프·모니터 둘레에 흰 윤곽(오려 붙인 듯). 오른쪽 끝 벽이 x1780부터 더 어둡고 세로 이음선(방 모서리). 사물함 두 개는 같은 틀의 복제.
- 구역별 확신도: 1(70%) 2(60%) 3(65%) 4(60%) 5(55%) 6(60%). 구슬=Ca²⁺, 사자=RyR, 트로피=트로포닌은 모두 소리·모양에서 온 추정이라 약속표 없이는 확정 못 함.
- 대안 읽기: 모니터 곡선은 강축(연축 합산) 기록일 수도. 러닝머신 남자는 심장보다 등척성·지속 수축일 수도. 회색 남자는 사후강직 대신 근위축(불용)·피로일 수도. 거꾸로 트로피는 트로포닌의 구조 변화(뒤집힘)이거나 가는 필라멘트 끝의 캡(트로포모듈린)일 수도. 분홍 관은 Z선·M선·굵은 필라멘트(브래킷 팔=머리)·T세관 중 하나일 수도.

## ④ 한 문장
근육은 골격근(센서-채널 직결), 심근(적은 Ca²⁺가 큰 방출을 유발), 평활근(Ca²⁺-칼모듈린-MLCK)이 Ca²⁺를 다르게 풀어 수축하고, 그 수축은 근절의 활주(A대 불변·I대 단축)이며 섬유 유형에 따라 성능이 갈린다.
