# s08u01 1단계 생판 (그림만 보고)

## ① 판 전체 표제어
- **1순위: 근육의 수축 기전 — 골격근·심근·평활근 비교(흥분-수축 연결, Ca2+ 조절)** — 확신 80%
- **2순위: 흥분-수축 연결(E-C coupling)과 Ca2+ 방출 채널(DHPR·RyR)** — 확신 40%
- 큰 틀: 체육관=근육, 구슬=Ca2+, 사물함=근소포체(SR), 선반 3칸(트로피 2+빈 받침 1)=근육 3종.

## ② 구역별 (왼→오). 괄호는 근거, △는 추정
**구역1 — 골격근: DHPR–RyR1 기계적 결합** (7개)
1. 사자머리 문고리 1개 사물함 = RyR1, 사물함 = SR (소리 사자≈ryanodine, 개수 1)
2. 쏟아진 구슬 더미 = SR이 방출한 Ca2+ (뜻)
3. 초록 상자의 D자 손잡이를 당기는 사람 = DHPR(전압 감지), 탈분극에 구조변화 (모양 D, 동작)
4. 상자와 문고리를 곧장 잇는 쇠막대 = 직접 물리적 결합 (모양, 자리)
5. 벽 파이프의 닫힌 밸브에 구슬이 갇힘 = 세포외 Ca2+ 유입 없이도 수축 (뜻)
6. 거미줄 덮인 회색 남자가 역기를 쥔 채 굳음 + 열린 빈 지갑 = 사후강직, ATP 없으면 교차다리가 안 풀림 (색, 뜻)
7. 선반 왼쪽 트로피 = 트로포닌 있음 (소리 trop-)

**구역2 — 심근: plateau와 Ca2+ 유도 Ca2+ 방출(CICR)** (7개)
1. 모니터의 급상승–긴 평탄–하강 파형 = 심근 활동전위 plateau (모양)
2. 머그 손잡이 모양 초록 상자 = L형 Ca2+ 채널 (모양; 손잡이 고리 끝이 열림)
3. 손잡이 끝에서 몇 방울만 새는 구슬 = 세포 밖에서 들어오는 소량의 Ca2+ (양)
4. 막대 없이 방울이 사물함의 큰 더미로 이어짐 = 기계적 결합이 아니라 CICR (자리, 양)
5. 사자머리 2개 사물함 = RyR2 (개수)
6. 선반 가운데 트로피 = 트로포닌 있음
7. △ 러닝머신 위 달리는 사람 = 쉬지 않는 심장의 지속 수축 (뜻, 낮음)

**구역3 — 평활근: Ca2+–칼모듈린–MLCK** (7개)
1. 선반 오른쪽 빈 받침(트로피 없음) = 트로포닌 없음 (개수, 자리)
2. 노인 = 칼모듈린 (소리 calm-, 동작)
3. 쟁반의 쿠키 4개 = Ca2+ 4개 결합 (개수)
4. 노인이 소년 어깨에 손을 얹어 떠밂 = Ca2+-칼모듈린이 MLCK를 활성화 (동작)
5. 소년 = MLCK(인산화효소) (동작)
6. 소년이 붉은 손잡이를 패드에 끼움 = 미오신 경쇄에 인산(P, 붉은색) 부착 (동작, 색)
7. 관절 달린 로봇팔 = 미오신 머리의 교차다리 운동 (모양)

**구역4 — 근절 구조: 타이틴·네불린·활주** (4개)
1. 사람 키보다 큰 거대한 코일 스프링(약 10바퀴, 바닥~위까지 이어짐) = 타이틴, 거대·탄성 (모양, 크기)
2. 벽의 분홍 네온관 = 네불린 (소리 네온≈네불린, 곧고 긴 자)
3. △ 파란 막대 끝에 거꾸로 씌운 트로피 = 얇은 필라멘트 끝 캡(트로포모듈린 등) (모양, 소리)
4. 벽 도해판의 긴 막대 vs 짧은 막대(회색 폭 같고 청록 폭만 줄어듦) = 활주설, A대 불변·I대 단축 (모양)

**구역5 — 근섬유 유형: 지근 vs 속근** (2개)
1. 붉은 옷의 마른 달리기 선수 = 지근(1형): 적색·산화형·지구력 (색, 복장)
2. 흰 옷에 역도 벨트의 거구 = 속근(2형): 백색·해당형·굵고 세지만 쉽게 지침 (색, 체격)

## ③ 모름·어색·헷갈림·이음
- 모름: 네온관 중간의 L자 받침쇠, 로봇팔 받침의 막대 손잡이와 나무 '의자판'(래치?), 누운 남자 옆 흰 천, 모니터 스탠드의 늘어진 전선, 패드 위 붉은 호선.
- 어색: 누운 남자만 회색(탈색)·거미줄, 선반의 빈 받침, 뒤집힌 트로피, 파이프 밑이 열린 채 비어 있음.
- 헷갈림: 두 초록 상자(D 손잡이 vs 머그 손잡이)가 닮았으나 막대 유무로 역할이 다름. 똑바른 트로피(트로포닌)와 뒤집힌 트로피(캡)가 같은 물건. 사자 1·2마리는 이소형 번호인지 장식인지. 소년이 MLCK인지 경쇄인지. 러닝머신 사람과 구역5 마른 선수.
- 이음: 뚜렷한 이음선은 없음. 오른쪽 끝에서 벽이 따뜻한 색으로 변하고 모서리선이 있어 새 무대처럼 보임. 구역3→4 사이 약 100px 빈 벽.
- 개수 정리: 사자 1+2, 트로피 2+빈 받침 1(선반 받침대 3), 쿠키 4, 사람 7(당기는 이·누운 이·달리는 이·노인·소년·붉은 옷·흰 옷), 도해판 2줄, 초록 상자 2, 사물함 2, 코일 약 10바퀴. 읽힌 사실 합계 27(△ 2 포함).

## ④ 한 문장
Ca2+(구슬)가 근수축의 열쇠여서, 골격근은 DHPR이 RyR1을 직결로 당겨 열고, 심근은 L형 채널로 샌 소량이 RyR2를 열어 불어나며, 평활근은 트로포닌 없이 칼모듈린–MLCK로 경쇄를 인산화해 수축하고, 그 결과는 타이틴·네불린이 지탱하는 근절에서 A대는 그대로 I대만 짧아지는 활주(지근/속근)로 나타난다.
