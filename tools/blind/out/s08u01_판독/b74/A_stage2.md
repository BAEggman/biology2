# 2단계 stage2 (약속표 적용) — ↻=1단계에서 바뀐 곳, ✓=약속표로 확정(내용 불변)

## 판정
약속표로 부분적으로 더 잘 풀렸다. ✓확정: 자갈=Ca²⁺, 놋쇠 사자 문고리=RyR, 청록 스위치상자+D자 고리=DHP, 모듈 쟁반=칼모듈린, 붉은 민 도장=인산화, 트로피=트로포-, 동전=ATP(빈 지갑). ↻새로 풀림: 분홍 네온관=네불린, 거꾸로 트로피=트로포- 계열. 표에 없는 물건(스프링·밸브 파이프·사물함·사람들·로봇팔 밑동)은 끼우지 않고 맥락 추정 그대로 둔다.

## ① 판 전체 표제어
- **1순위: 근육의 구조와 수축 — 필라멘트 단백질(트로포-·네불린·타이틴)과 Ca²⁺ 조절(DHP–RyR·칼모듈린)** 확신 88% ↻(1단계 75%, 근절 단백질까지 넓힘)
- **2순위: 골격근·심근·평활근의 흥분-수축 연결 비교(Ca²⁺ 경로)** 확신 55% ↻(1단계 1순위였음)
- 근거: 읽힌 약속 어휘 7종이 전부 근수축의 단백질·신호다.

## ② 구역별 (왼쪽부터)
**구역1 골격근 흥분-수축 연결(DHP–RyR 직결)** x50~560
- ✓자갈 더미를 쏟는 사물함 = 근소포체의 Ca²⁺ 방출
- ✓놋쇠 사자 1마리 = RyR (1형은 개수로 추정)
- ✓청록 스위치상자+D자 고리 = DHP
- 막대로 상자와 문을 잇고 장사가 D자 고리를 당김 = 탈분극이 DHP를 틀어 RyR을 직접 엶
- 벽 파이프+닫힌 밸브(자갈 갇힘) = 세포외 Ca²⁺ 유입 불필요 (표 밖, 중간)
- ✓회색 남자+빈 동전지갑 = 동전(ATP) 없음 → 사후강직 (65%, 동전=ATP로 보강)
- ↻선반 첫 트로피 = 트로포- 있음 (트로포닌 단정 철회, 닌·미오신 구분 불가)

**구역2 심근 활동전위의 고원** x580~860
- 모니터 사다리꼴 곡선 = 심근 활동전위의 고원 (표 밖)
- 러닝머신 남자 = 지속·반복 박동 (표 밖, 낮음)
- 선반 둘째 트로피 = 트로포- 있음

**구역3 심근 Ca²⁺ 유발 Ca²⁺ 방출(CICR)** x860~1150
- ↻머그 상자는 같은 DHP 물건(상자+D자 고리)의 반복으로 확정, 1단계의 동일물 혼동 해소
- 고리 끝에서 자갈 8알 = Ca²⁺ 소량 유입
- ✓사자 2마리 = RyR (2형은 개수로 추정)
- 자갈이 넘치는 사물함 = 소량 유입이 대량 방출을 유발(증폭)

**구역4 평활근 Ca²⁺-칼모듈린-인산화** x1150~1500
- ↻쟁반이 칼모듈린: 1단계의 노인=calm 말장난보다 쟁반을 우선, 노인은 쟁반 운반자
- 쟁반 위 자갈 4 = Ca²⁺ 4개 결합
- 노인 손이 소년 어깨에 = Ca²⁺-칼모듈린이 키나아제(소년)를 활성화
- ✓소년의 붉은 민 도장 = 인산화, 마이오신 경쇄 인산화
- 관절 기계팔의 나무판 = 마이오신 머리 (표에 마이오신 없음)
- 선반의 빈 받침대 = 트로포- 없음, 평활근 (60%)

**구역5 근절의 거대 단백질·가는 필라멘트** x1560~1930
- ↻분홍 네온관 = 네불린: 가는 필라멘트 길이를 재는 자, 벽(Z선)에 고정
- 스프링(약 10바퀴) = 타이틴, 탄성·복원 (표 밖, 추정)
- 도해판 두 줄 = 수축 시 A대 불변·I대 단축(활주설)
- ↻청록 기둥+거꾸로 씌운 트로피 = 트로포- 계열: 액틴(청록=I대 색)을 덮은 트로포미오신 40%, 끝 캡 트로포모듈린 25%

**구역6 근섬유 유형 지근 vs 속근** x1660~1930 (표 밖, 불변)
- 마른 빨강 선수 = 지근(적색, 마이오글로빈, 지구력)
- 근육질 흰 옷+벨트 = 속근(백색, 해당, 순발력)

## ③ 의문·어색함·헷갈림·이어붙임
- ↻풀린 것: 네온관, 거꾸로 트로피(부분), 두 초록 상자의 동일성. 읽힌 사실 수는 구역1 8·구역2 3·구역3 4·구역4 6·구역5 4·구역6 2로, 1단계 대비 구역5만 2→4.
- ↻폐기: 1단계의 분홍 관 후보(Z선·M선·굵은 필라멘트·T세관)와 거꾸로 트로피의 '구조 변화' 대안.
- 아직 모름: 로봇팔 밑동의 크랭크와 갈색 판(칠판 지우개=탈인산화효소로도 보이나 팔 끝 판과 같은 판이라 25%), 네온관 브래킷 팔, 모니터 전선.
- 표와 헷갈림: 관절 기계팔↔'로봇=안드로겐', 벨트 찬 역도 선수↔'샅바 맨 장사=APC/C', 은색 밸브 파이프↔'검은 가스 파이프=카스파리대'. 전부 모양이 달라 표 뜻으로 읽지 않았다. 노인은 갓이 없어 ABA 아님, 사물함엔 자물쇠가 없어 약물 아님, 심근 구역에 하트가 없는 건 '빨간 하트=Sex'와 일관.
- 어색함: 밸브 파이프가 벽에 떠 있음, 회색 남자만 탈색, 빈 받침대가 선반 위에 따로 있음.
- 이어 붙인 흔적: 바벨 원판·지갑·파이프·모니터 둘레 흰 윤곽, x1780부터 벽 색이 어두워지는 방 모서리 이음선.

## ④ 한 문장
근육은 Ca²⁺ 자갈이 풀려나는 길이 골격근(DHP–RyR 직결)·심근(소량 유입이 대량 방출)·평활근(칼모듈린→인산화)마다 다르고, 이 Ca²⁺가 트로포-·네불린·타이틴이 짜인 근절의 활주(A대 불변·I대 단축)를 일으키며 섬유 유형에 따라 성능이 갈린다. ↻
