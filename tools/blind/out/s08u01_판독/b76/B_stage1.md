# stage1 생판 (s08u01, 그림만 보고)

## ① 판 표제어
- 1순위 **근수축 기전: 골격근·심근·평활근의 흥분-수축 연결(Ca2+) + 활주설·근절 구조** — 약 85%
- 2순위 **근육계 총론: 근육 3종 비교·근섬유 유형(적색/백색)·ATP** — 약 8%
- 근거: 체육관 무대, 락커 속 구슬 더미(=Ca2+ 저장고), 선반 트로피 2개+빈 받침 1개, 근절 도해 패널.

## ② 구역 (왼→오). [근거] 표기, 자신 없으면 추정, 못 읽으면 모름
선반은 구역1~4 위로 이어진 하나의 물건인데, 아래 구역별로 나눠 셈.

**구역1 골격근 흥분-수축 연결 + 사후경직** (9, 확신 상)
1. 사자 머리 1마리 [소리 라이언=리아노딘 수용체 RyR, 개수 1=RyR1]
2. 락커+회색 구슬 더미 [뜻 근소포체=Ca2+ 창고, 쏟아짐=방출]
3. 청록 상자+D자 손잡이 [모양 D=DHPR, T세관 전압감지기]
4. 상자-사자 입을 잇는 막대, 남자가 손잡이를 당김 [동작 전압 변화가 RyR을 기계적으로 직접 열음]
5. 잠긴 밸브 관(위만 구슬, 아래는 빔) [뜻 세포외 Ca2+ 유입 불필요, 추정]
6. 벤치 위 회색 사내+발목 인식표 [뜻 사후경직]
7. 빈 지갑+나방 3마리 [뜻 ATP 고갈, 3의 뜻은 모름]
8. 바벨을 쥔 손+거미줄 [뜻 ATP 없어 미오신 머리가 액틴에서 안 떨어짐=가교 고정]
9. 선반 왼쪽 트로피 [소리 트로피=트로포닌, 골격근에 있음]

**구역2 심근 활동전위(고원)·불응기** (5, 확신 중상)
1. 번개 [뜻 자극]
2. 사다리꼴 파형 화면 [모양 급상승-긴 고원-급하강=심근 AP, 고원은 Ca2+ 유입]
3. 번개가 화면에서 튕겨 나감 [동작 고원 중 불응기라 재자극 무효, 강축 불가]
4. 러닝머신 달리는 사내 [뜻 쉼 없는 규칙적 수축·유산소, 추정]
5. 선반 가운데 트로피 [소리·자리 심근에도 트로포닌, 위치로 추정]
모름: 화면 지지대에 늘어진 전선.

**구역3 심근 Ca2+ 유발 Ca2+ 방출(CICR)** (4, 확신 상)
1. 청록 상자+고리 손잡이(당기는 이 없음)+열린 관에서 구슬 10여 알 [뜻 L형 통로(DHPR)로 소량 Ca2+ 유입]
2. 막대 없음 [자리 기계적 연결 아님, 구역1과 대비]
3. 사자 머리 2마리 [개수 2=RyR2]
4. 가득 찬 락커, 두 사자 입의 구슬 폭포 [뜻 유입 Ca2+가 SR 방출을 증폭]
모름: 사자 밑 문고리 고리.

**구역4 평활근 Ca2+-칼모듈린-MLCK** (7, 확신 상)
1. 평온한 노인 [소리 calm=칼모듈린], 공중에 뜸 [모양 세포질 가용성, 추정]
2. 쟁반 위 회색 덩이 4개 [개수 Ca2+ 4개 결합]
3. 노인 손이 청년 어깨 위 [동작 Ca2+-칼모듈린이 MLCK를 켬]
4. 빨간 옷 청년 [동작 키나아제=MLCK]
5. 청년이 빨간 조각을 나무 머리의 빨간 모자에 얹음 [모양 미오신 경쇄 인산화]
6. 놀란 얼굴의 나무 머리+관절 팔 [모양 미오신 머리+목]
7. 선반 오른쪽 빈 트로피 받침 [개수 평활근엔 트로포닌 없음]
모름: 로봇 받침의 크랭크·나무 좌판.

**구역5 근절 구조·필라멘트·섬유 유형** (6, 그중 4는 추정, 확신 중하)
1. 벽 패널 막대 2개(위 길고 아래 짧음, 회색 중앙 길이 같고 청록 양끝만 줄어듦) [모양 A대 불변·I대 단축=활주설]
2. 거대한 스프링(약 9~10바퀴) [모양 티틴=탄성 거대 단백질]
3. 핑크 형광등+가운데 죔쇠 [추정 굵은 필라멘트(미오신)·M선, 자신 없음]
4. 청록 뱀+뒤집어 쓴 트로피 [추정 가는 필라멘트(트로포미오신)+트로포닌]
5. 마른 빨간 옷 남자 [색 적색근·지근, 지구력, 추정]
6. 큰 흰 옷 근육남 [색·크기 백색근·속근, 큰 힘·빨리 지침, 추정]

## ③ 뜻 모름·어색·헷갈림·이음
- 모름: 핑크 형광등 죔쇠 팔, 뱀 꼬리와 고리, 크랭크, 전선, 나방 수 3, 사자 문고리.
- 어색: 사자 머리가 락커 문에 박힘, 노인이 떠 있음(그림자), 나무 머리의 놀란 표정, 벤치 사내만 탈색, 트로피 뒤집힘.
- 헷갈림: 청록 상자 2개(손잡이 당김 vs 방울 관), 사자 1 vs 2, 청록·빨강이 여러 뜻으로 반복, 트로피(트로포닌)와 노인(칼모듈린)이 둘 다 Ca2+ 결합 단백.
- 이음: 뚜렷한 이음선 없음. 다만 구역4~5 사이가 비어 뱀 하나만 있고, 선반이 구역4 끝에서 끝나며 구역5는 방 모서리 벽(색 톤 변화)에 놓여 별도 도해를 붙인 느낌. 구슬 더미가 구역3→4로 번져 이어짐.

## ④ 한 문장
골격근은 DHPR이 RyR1을 직접 당겨, 심근은 유입 Ca2+가 RyR2를 열어, 평활근은 Ca2+-칼모듈린-MLCK로 수축하고(트로포닌은 골격·심근만), 수축의 실체는 A대 불변·I대 단축의 필라멘트 미끄러짐이며 ATP가 없으면 풀리지 않아 사후경직이 온다.
