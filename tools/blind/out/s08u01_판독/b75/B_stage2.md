# stage2 — 약속표로 다시 읽기 (s08u01)

## 판정
약속표로 **더 잘 풀림**. 확정 8: 사자 문고리=RyR(#44), 청록 상자+D자 고리=DHP(#45), 자갈=Ca²⁺(#4), 동전=ATP(#8), 모듈 쟁반(#22), 트로피(#29), 네온(#30), 붉은 민 도장(#100). 1단계 「모름」 2개가 풀림(네온, 거꾸로 트로피). 정정 ↻ 3, 충돌 2(로봇 #27, 샅바 장사 #82 — 억지로 끼우지 않음). 표에 없는 것(사물함, 파이프·밸브, 모니터·번개, 러닝머신, 벤치·바벨, 노인·소년, 스프링, 보드, 두 남자)은 1단계 읽기 유지.

## ① 판 전체 표제어
- 1순위 **근수축의 기전과 조절(골격근·심근·평활근 + 근절 구성 단백질)** — 92% ↻(85→92)
- 2순위 **근육의 구조와 종류(근절·활주·근섬유 유형)** — 45%
- 근거: 사자·청록 상자·자갈(Ca²⁺ 방출 삼각), 트로피 2+받침 1(트로포닌 유무), 트로포모듈린·네불린(근절 단백질), 모듈 쟁반·붉은 도장(평활근 인산화).

## ② 구역
**구역1 (x50–560) 골격근 흥분-수축 연결: DHP가 RyR을 직접 당김** [90%] — 6개
1. 사자 문고리 1개 = RyR(#44). 고리 대신 막대를 물림 = 직접 연결
2. 청록 상자+D자 고리 = DHP(#45). 막대가 상자를 관통해 사자 입까지
3. 손잡이 당기는 남자 = 전압 변화로 DHP가 RyR을 열어 줌
4. 쏟아진 자갈 더미 = Ca²⁺(#4)
5. 사물함 = SR 창고 [표 밖]
6. 벽 파이프: 자갈은 위쪽만, 밸브 닫힘 = 세포외 Ca²⁺ 불필요 [표 밖]

**구역2 (x190–600, 벤치) 사후강직: ATP 고갈** [85%] — 4개
1. ↻ 입 벌린 빈 동전 지갑 = ATP 없음(#8로 확정)
2. 회색 시신+꼬리표 = 사후 [표 밖]
3. 바벨 쥔 채 굳음 = 미오신–액틴 결합이 안 풀림 [표 밖]
4. 거미줄, 나방 3 = 오래 방치(약함)

**구역3 (x580–1160) 심근: plateau, DHP 소량 유입 → RyR 대량 방출(CICR)** [80%] — 7개
1. 모니터 고원 곡선 = 심근 활동전위 plateau [표 밖]
2. 번개가 고원을 때림 = plateau 중 L형 통로 열림
3. 머그컵꼴 청록 상자+D자 고리 = DHP(#45)
4. 손잡이 끝에서 자갈 약 8알 = 소량 Ca²⁺ 유입
5. 사자 문고리 2개(입에 자갈, 고리 매달림) = RyR(#44). 2개=2형은 추정
6. 쏟아지는 자갈 더미 = 대량 방출·증폭
7. 러닝머신 남자 = 쉼 없는 박동/호기성, 또는 교차다리 「걷기」(약함)

**구역4 (x1160–1520) 평활근: Ca²⁺–칼모듈린–키나아제 → 인산화** [75%] — 6개
1. ↻ 쟁반 = 칼모듈린(#22). 1단계 「노인=calm」 폐기, 노인은 쟁반 운반자
2. 쟁반 위 자갈 무더기 4 = Ca²⁺ 4개 결합
3. 노인 손이 소년 어깨 = Ca²⁺–CaM이 키나아제 활성화 [표 밖]
4. ↻ 소년이 붉은 민 도장을 찍음 = 인산화(#100), 소년=MLCK 추정
5. 도장 맞는 관절 팔 기계(놀란 얼굴) = 미오신 머리(경쇄). ⚠ 로봇(#27 안드로겐)과 겹침 — 줄거리가 끊겨 안드로겐으로 안 읽음, 55%
6. ↻ 선반 오른쪽 받침만 남은 자리 = 트로포닌 없음(#29). 선 트로피 2 = 골격근·심근엔 있음

**구역5 (x1540–1630) ↻ 가는 필라멘트의 끝 캡: 트로포모듈린** [80%] — 2개
1. ↻ 거꾸로 씌운 트로피 = 트로포모듈린(#29). 1단계 「트로포닌·트로포미오신」 폐기
2. 청록 밧줄 = 가는 필라멘트(액틴, #29 「가는 것」)

**구역6 (x1630–1990) 근절 거대단백질·활주·섬유 유형** [65%] — 5개
1. 스프링(약 9~10바퀴) = 타이틴 [표 밖]
2. ↻ 분홍 네온 = 네불린(#30). 1단계 「굵은 필라멘트」 폐기
3. 보드 두 막대: 회색 폭 같고 청록만 줄음 = A대 불변, I대 단축 [표 밖]
4. 마른 붉은 옷 = 적색근 [표 밖]
5. 거구 흰 옷 = 백색근. 역도 벨트라 샅바 장사(#82)로 안 읽음

## ③ 걸리는 것
- 풀린 것: 네온=네불린, 거꾸로 트로피=트로포모듈린. 남은 모름: 로봇꼴 기계의 크랭크·갈색 판·초록 얼룩, 번개 옆 호 2줄, 노인의 공중부양, 네온의 팔 브래킷, 시신 옆 흰 천(소매 자락?).
- 헷갈림: 로봇(안드로겐)·장사(APC/C)와의 충돌, 청록 상자 2개(같은 DHP), 달리는 두 사람, 사자 3·트로피 3(수 일치는 우연).
- 어색: 사자가 고리 대신 막대를 묾(#44의 변형으로 읽음), 아래가 뚫린 파이프.
- 이어 붙인 흔적: 뚜렷한 접합선 없음. 두 번째 사물함 문 오른쪽 반투명 자갈 띠는 사자 입에서 흘러내리는 Ca²⁺의 잔상으로도 읽힘 ↻.

## ④ 한 문장
RyR이 Ca²⁺ 자갈을 쏟아야 근수축이 시작되고(골격근은 DHP가 직접 당기고, 심근은 새어든 소량이 증폭시키고, 평활근은 칼모듈린–키나아제가 미오신에 인산화 도장을 찍는다), 트로포닌·트로포모듈린·네불린·타이틴이 짜 놓은 근절에서 I대만 짧아지며, ATP 동전이 없으면 풀리지 못해 굳는다.
