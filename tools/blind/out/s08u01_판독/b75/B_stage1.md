# stage1 — 생판 (s08u01, 2524×1144)

## ① 판 전체 표제어
- 1순위 **근육 수축의 기전: 골격근·심근·평활근의 흥분-수축 연결(Ca²⁺)** — 85%
- 2순위 **근육의 구조와 종류(근절·활주·근섬유 유형)** — 40%
- 근거: 체육관 무대, 선반 트로피(→트로포닌), 사물함+구슬(Ca²⁺ 창고·방출), 사자(라이언→리아노딘), 스프링·보드(근절). 신경 시냅스·ACh는 없음.
- 선반: 트로피 2 + 컵 없는 받침 1 = 3개, 왼쪽부터 골격근·심근·평활근 자리에 얹힘(추정).

## ② 구역 (왼쪽→오른쪽, 표시좌표 x 0~2000)
**구역1 (x50–560) 골격근 흥분-수축 연결: DHPR–RyR1 기계적 결합** [80%] — 6개
1. 열린 사물함 = SR, Ca²⁺ 창고 [뜻]
2. 쏟아진 회색 구슬 더미(수백) = Ca²⁺ [모양·개수]
3. 문의 사자머리 1개 = RyR1 (라이언≈리아노딘, 1마리=1형, 입=통로) [소리·개수]
4. 사자 입의 막대가 초록 상자(D자 손잡이)까지 곧게 이어짐 = DHPR(T관 전압감지기)과 RyR의 직접 연결 [모양·자리]
5. 손잡이를 당기는 근육질 남자 = 탈분극→DHPR 구조변화가 RyR1을 물리적으로 연다 [동작]
6. 벽 파이프: 위쪽에만 구슬, 밸브 잠김, 아래 빔 = 세포외 Ca²⁺ 유입 불필요 [뜻·자리]

**구역2 (x190–600, 바닥 벤치) 사후강직: ATP 고갈 → 교차다리 고착** [80%] — 4개
1. 회색·눈 감은 남자+발목 꼬리표 = 사후 [모양]
2. 바벨을 쥔 채 굳음 = 미오신 머리가 액틴에 붙은 채 못 풀림 [동작]
3. 입 벌린 빈 지갑 = ATP 소진(분리에 ATP 필요) [뜻]
4. 거미줄, 나방 3마리 = 오래 방치·텅 빔(보조, 약함) [개수]

**구역3 (x580–1160) 심근: 긴 plateau, L형 Ca²⁺ 유입, CICR(RyR2)** [70%] — 7개
1. 모니터 곡선(급상승→평평한 고원→하강) = 심근 활동전위 plateau [모양]
2. 번개가 고원을 때림 = plateau 중 Ca²⁺ 유입 [동작·자리]
3. 러닝머신 남자 = 쉼 없이 반복하는 호기성 박동(약함) [뜻]
4. 머그컵꼴 초록 상자(D 손잡이) = DHPR이 이온통로로 작동 [모양]
5. 손잡이 끝에서 구슬 약 8알만 똑똑 = 소량 Ca²⁺ 유입(방아쇠) [개수]
6. 두 번째 사물함 문의 사자 2개(고리 노커) = RyR2 (2마리=2형, Ca²⁺가 '노크') [개수·소리]
7. 몇 알 → 쏟아지는 구슬 더미 = Ca²⁺ 유발 Ca²⁺ 방출(증폭) [뜻]

**구역4 (x1160–1520) 평활근: Ca²⁺–칼모듈린–MLCK → 미오신 경쇄 인산화** [70%] — 6개
1. 평온한(calm) 노인(old) = 칼모듈린 [소리]
2. 쟁반의 회색 원뿔 4개 = Ca²⁺ 4분자 결합 [개수]
3. 노인 손이 소년 어깨에 = Ca²⁺-CaM이 MLCK 활성화 [동작]
4. 소년(kid≈kinase)이 빨간 도장을 로봇 머리에 찍음 = 인산기 전달 [동작·색]
5. 놀란 로봇(관절 팔·머리) = 인산화로 켜진 미오신 머리 [모양]
6. 선반 맨 오른쪽 컵 없는 받침 = 평활근엔 트로포닌 없음 [자리·개수]

**구역5 (x1540–1630) 가는 필라멘트 조절: 트로포닌·트로포미오신** [40%] — 2개
1. 거꾸로 덮인 금빛 트로피 = 트로포닌 (트로피≈트로포닌) [소리]
2. 아래로 늘어져 바닥에서 똬리 튼 긴 청록 밧줄 = 트로포미오신/액틴 가는 필라멘트 [모양]

**구역6 (x1630–1990) 근절 구조·활주·근섬유 유형** [60%] — 5개
1. 거대한 철제 스프링(약 9~10바퀴) = 타이틴(탄성) [모양]
2. 분홍 네온 막대(+옆으로 튄 팔 1) = 굵은 필라멘트·미오신 머리(약함) [모양]
3. 벽 보드 두 막대(청록-회색-청록): 회색 폭 동일, 청록만 짧아짐 = A대 불변, I대 단축 [개수·모양]
4. 붉은 옷 마른 남자 = 적색근(지근, 미오글로빈·미토콘드리아↑) [색]
5. 흰 옷 거구(역도 벨트) = 백색근(속근, 해당성, 쉽게 지침) [색]

## ③ 걸리는 것
- 뜻 모름: 분홍 네온 막대와 팔 브래킷(M선? 굵은 필라멘트?), 로봇 받침의 크랭크·갈색 판·초록 얼룩, 번개 옆 호 2줄, 시신 옆 흰 천 2점, 노인의 공중부양(아래 멀리 그림자).
- 어색: 사자가 고리 대신 막대를 묾, 아래가 뚫린 벽 파이프, 거미줄이 몸 전체에, 트로피가 뒤집혀 뱀 머리를 덮음.
- 헷갈림: 초록 손잡이 상자(구역1)와 머그컵(구역3)은 같은 물건의 두 모습?; 달리는 두 사람(러닝머신/빨간 옷); 붉은·흰 옷이 적색·백색근인가 경량·중량(경쇄·중쇄)인가; 구슬과 쟁반 원뿔.
- 이어 붙인 흔적: 뚜렷한 접합선 없음(바닥결이 한 소실점). 오른쪽 벽의 색 다른 패널(x≈1780)은 방 모서리이나 스프링이 가로지름. 두 번째 사물함 문 오른쪽에 반투명 구슬 띠(편집 잔상?).

## ④ 한 문장
근육은 SR의 Ca²⁺ 방출(RyR)이 방아쇠여서 골격근은 DHPR이 RyR1을 직접 당겨 열고, 심근은 소량 Ca²⁺ 유입이 RyR2를 열어 증폭하며, 평활근은 칼모듈린–MLCK 인산화로 수축하고, 수축은 필라멘트가 미끄러져 I대만 짧아지는 것이며 ATP가 없으면 풀리지 못해 굳는다.
