# 2단계 약속표로 다시 읽기 (s08u01) — ↻ = 1단계와 달라진 곳

## 판정
약속으로 더 잘 풀린다. 자갈·사자 문고리·청록 상자+D고리·모듈 쟁반·붉은 민 도장·동전·트로피·네온 8종이 확정되어 구역 나눔(골격·심·평활·근절)이 굳었다. 1단계의 오독은 거꾸로 씌운 트로피, 눈금 팔, 노인 근거 3곳이다.

## ① 판 전체 표제어
- 1순위 **근육의 구조와 수축: 골격근·심근·평활근 비교 (Ca²⁺ 조절)** 93% ↻85→93
- 2순위 **흥분-수축 연결과 Ca²⁺ 센서 (트로포닌/칼모듈린)** 5% ↻8→5
- 근거: RyR·DHP·Ca²⁺·칼모듈린·트로포닌·트로포모듈린·네불린이 한 방에 모였고, 선반 받침 3칸(선 트로피 2 + 빈 받침 1 = 「트로포닌 없음」)이 골격·심·평활 순으로 놓였다.

## ② 구역 (4구역 그대로)
### 구역1 **골격근: DHP-RyR 직접 연결·사후강직**
- ↻자갈 = Ca²⁺(약속): 사물함 속과 바닥에 쏟아진 것 = 저장과 방출. 사물함=SR은 자리 추측
- ↻사자 문고리 = RyR(약속). 1마리=RyR1은 개수 추측(M2·M3 손가락 수처럼 개수로 번호를 나르는 관례, 중하)
- ↻청록 상자+D고리 = DHP(약속). 막대로 사자 입과 이어짐 = 직접 기계 연결(모양, 중)
- 남자가 D고리를 당김 = 전압 감지 뒤 구조 변화(동작, 중하)
- 닫힌 밸브 위에 자갈이 갇힌 파이프 = 세포외 Ca²⁺ 불필요(자리, 중하). 'V자 이음쇠'·'검은 가스 파이프'와 모양이 달라 약속 아님
- ↻선반 첫 트로피(받침 위에 섬) = 트로포닌 있음(약속, 하→상)
- 회색 남자+바벨+거미줄+발목 표 = 사후강직(뜻, 중)
- ↻텅 빈 동전지갑 = 동전 없음 = ATP 없음(약속, 중→상)
- 모름: 나방 3마리, 흰 헝겊 2점(주름진 수건이라 '흰 셔츠 칼라(사이토칼라신)' 아님)

### 구역2 **심근: 고원 활동전위·불응기·CICR**
- 사다리꼴 파형 = 긴 고원(모양, 중)
- 번개가 튕김 = 불응기가 길어 강축 없음(동작, 중)
- 러닝머신 달리는 사람 = 쉼 없는 유산소 박동(뜻, 하). 약속 없음
- ↻선반 둘째 트로피 = 트로포닌 있음(약속)
- ↻머그 같은 청록 상자+고리에서 새는 자갈 = DHP로 Ca²⁺ 유입(약속 둘, 중하→상)
- 자갈이 떨어지는 곳 = RyR 사물함 더미 → Ca²⁺ 유발 Ca²⁺ 방출(자리, 중)
- ↻사자 문고리 2개 = RyR2(약속+개수, 하→중하)
- 넘친 사물함 = 대량 방출(뜻, 중)

### 구역3 **평활근: 칼모듈린-MLCK 인산화**
- ↻모듈 쟁반 = 칼모듈린(약속). 1단계는 노인의 평온한 표정(소리 calm)으로 읽었으나 노인 자체는 약속 밖이고 든 쟁반이 근거다
- ↻쟁반 위 자갈 4개 = Ca²⁺ 4개 결합(약속+개수)
- 노인이 소년 어깨를 밂 = Ca-칼모듈린이 MLCK 활성화(동작, 중하). 소년 = MLCK(하)
- ↻붉은 민 도장 = 인산화(약속): 소년이 블록 이마에 찍음 = 미오신 경쇄 인산화
- 얼굴 블록 = 미오신 머리(뜻, 중하). 관절 팔 = 미오신 목·경첩(모양, 하)
- ↻선반의 빈 받침(노인 바로 위) = 트로포닌 없음(약속, 중하→상)

### 구역4 **근절 구조 단백질·근섬유 유형**
- ↻거꾸로 씌운 트로피 = 트로포모듈린, 끝 캡(약속). 1단계 '트로포닌 결합'을 고침
- ↻청록 뱀/밧줄 = 가는 필라멘트 액틴(끝에 캡이 씌워진 점, 중하). '트로포미오신 또는 액틴'에서 좁힘
- ↻분홍 네온관 = 네불린(약속). 가로 팔은 눈금 없는 받침 브래킷이라 '눈금 팔' 읽기를 철회, 모름
- 거대 스프링 = 타이틴(모양, 중). 약속 없음
- 포스터 두 막대 = 이완/수축 근절, A대 불변·I대 반감(모양, 중)
- 빨간 마른 남자 = 지근, 흰 옷 근육질 남자 = 속근(색, 중). 가죽 역도 벨트라 '샅바 맨 장사(APC/C)' 아님

## ③ 의문점
- ↻풀림: 초록 상자 두 개 = 같은 DHP(한쪽은 막대, 한쪽은 자갈이 샘). 소년 손의 빨간 물건과 블록 위 빨간 자국 = 붉은 민 도장과 그 자국. 선반 3칸 = 소단위 T·I·C가 아니라 있음·있음·없음.
- 여전히 모름: 거미줄('끈적한 점액' 아닌 얇은 줄), 나방 3, 흰 헝겊, 번개 옆 점선, 로봇 받침의 크랭크·방석, 노인이 뜬 이유, 네온관 가로 팔.
- ↻약속과 충돌: 로봇 팔은 '로봇=안드로겐 전용'과 겹친다. 칼모듈린 쟁반·인산화 도장과 한 장면이고 안드로겐이 이 판에 이어지지 않아 미오신으로 읽었으나, 약속을 배운 독자는 갈릴 수 있다.
- 약속표에 없는 물건(모양 추측 유지): 스프링, 포스터, 두 남자, 러닝머신, 모니터·번개, 파이프·밸브, 죽은 남자, 사물함, 노인·소년·블록.
- 센 것: 사자 1과 2, 쟁반 자갈 4, 트로피 선 2+빈 받침 1(뱀 끝 1), 나방 3, 사람 7. 이음선은 1단계처럼 없음.

## ④ 한 문장
RyR 사자 사물함의 자갈(Ca²⁺)이 쏟아져 근육이 수축하는데, 골격근은 DHP 상자가 막대로 직접 열고 심근은 DHP로 새어 든 자갈이 열며 평활근은 자갈 4개를 든 칼모듈린이 인산화 도장을 찍게 하고, 트로포닌은 골격·심근에만 있으며 근절은 트로포모듈린·네불린·타이틴이 짠다.
