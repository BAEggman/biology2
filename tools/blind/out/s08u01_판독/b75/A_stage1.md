# 1단계 생판 (s08u01, 그림만 보고)

## ① 판 전체 표제어
- 1순위 **근육의 구조와 수축: 골격근·심근·평활근 비교 (Ca²⁺ 조절)** 85%
- 2순위 **흥분-수축 연결과 Ca²⁺ 센서 (트로포닌/칼모듈린)** 8%
- 근거: 체육관 한 장에 트로피(트로포닌), 거대 스프링(타이틴), 근절 포스터가 모여 있고, 선반 받침 3칸(트로피 2 + 빈 칸 1)이 초록 상자·러닝머신·노인 위에 하나씩 놓여 아래 세 무리와 자리가 맞는다. 사자·사물함·구슬은 Ca²⁺ 방출 장면으로 읽힌다. ATP 대사·운동생리 후보는 5% 이하.

## ② 구역 (왼쪽부터 4구역; 괄호는 근거와 확신)
### 구역1 **골격근: 흥분-수축 연결·사후강직** (x≈50-560)
- 사물함+구슬 = SR에 저장된 Ca²⁺ (뜻, 중)
- 금빛 사자 1마리, 입에 막대 = 라이언≈라이아노딘 수용체 RyR1 (소리+개수, 중)
- 초록 상자+D자 손잡이 = DHPR 전압 센서 (모양, 중)
- 막대 = DHPR-RyR1 직접 기계 연결 (모양, 중)
- 남자가 손잡이를 당김 = 막전위 변화가 구조 변화로 전달 (동작, 중하)
- 닫힌 밸브 위에 구슬이 갇힌 파이프 = 세포외 Ca²⁺ 유입 불필요 (자리, 중)
- 바닥에 쏟아진 구슬 = SR의 Ca²⁺ 방출 (뜻, 중)
- 선반 첫 트로피(상자 바로 위) = 트로포닌 있음 (자리, 하)
- 회색 남자+바벨+거미줄+발목 인식표 = 사후강직 (뜻, 중)
- 빈 지갑 = ATP 고갈 (뜻, 중). 나방 3마리, 흰 헝겊 = 「모름」

### 구역2 **심근: 활동전위 고원·불응기·CICR** (x≈570-1140)
- 사다리꼴 파형 = 활동전위의 긴 고원 (모양, 중)
- 번개가 튕겨 나감 = 불응기가 길어 재자극 무반응, 강축 없음 (동작, 중)
- 러닝머신 달리는 사람 = 쉬지 않는 유산소 활동, 피로 내성 (뜻, 하)
- 선반 둘째 트로피 = 트로포닌 있음 (자리, 하)
- 머그 상자 손잡이에서 똑똑 떨어지는 구슬 = L형(DHPR) 통로로 소량 Ca²⁺ 유입 (모양, 중하)
- 구슬이 사물함 더미 위로 떨어짐 = Ca²⁺ 유발 Ca²⁺ 방출 (자리, 중)
- 사자 2마리 = RyR2 (개수, 하)
- 가득 넘친 사물함 = 대량 방출 (뜻, 중)

### 구역3 **평활근: 칼모듈린-MLCK** (x≈1150-1500)
- 평온한 표정의 노인 = 칼모듈린 (소리 calm, 중하)
- 쟁반 위 덩어리 4개 = Ca²⁺ 4개 결합 (개수, 중)
- 소년 어깨를 미는 손 = Ca-칼모듈린이 MLCK 활성화 (동작, 중하)
- 소년 = MLCK(인산화효소) (뜻, 하)
- 빨간 도장 = 인산기 부착, 미오신 경쇄 인산화 (색+동작, 중하)
- 얼굴 달린 블록 = 미오신 머리 (뜻, 중하)
- 관절 로봇 팔 = 미오신 목·경첩 (모양, 하)
- 선반의 빈 받침(노인 바로 위) = 트로포닌 없음 (자리, 중하)

### 구역4 **근절 구조 단백질·근섬유 유형** (x≈1540-1960)
- 청록 뱀/밧줄 = 트로포미오신 또는 액틴 (모양, 하)
- 거꾸로 씌운 트로피 = 트로포닌 결합 (소리, 중하)
- 거대 스프링(약 10바퀴) = 타이틴 (모양, 중)
- 분홍 네온관+눈금 팔 = 네불린, 분자 자 (소리 neon, 중하)
- 벽 포스터 두 막대 = 이완/수축 근절: 회색(A대) 불변, 청록(I대) 절반 (모양, 중)
- 빨간 마른 남자 = 지근(적색근) (색, 중)
- 흰 옷 근육질 남자 = 속근(백색근) (색, 중)

## ③ 의문점
- 모름: 거미줄, 나방 3마리, 흰 헝겊, 번개 옆 점선 두 줄, 로봇 받침의 크랭크·갈색 방석, 노인이 떠 있는 이유.
- 어색: 노인 그림자만 바닥에 있음, 트로피가 뒤집혀 뱀 머리에 씌워짐, 사자가 문에 박혀 막대를 묾.
- 헷갈림: 초록 상자 두 개(D 손잡이/머그 손잡이)가 같은 물건인지; 소년의 빨간 물건과 블록 위 빨간 캡이 같은지; 막대 당기기가 등척성 수축일 수도 있음; 트로피 3칸이 트로포닌 소단위 T·I·C일 수도 있음; 트로피는 트로포닌/트로포미오신/트로포모둘린이 모두 가능.
- 이어 붙인 흔적: 벽-바닥선과 바닥 색이 전 폭에서 이어져 이음선 없음. 오른쪽 방 모서리만 따로 놓인 느낌이나 증거는 약함.
- 센 것: 사자 1(문 1개)과 2(문 2개), 나방 3, 쟁반 덩어리 4, 선반 트로피 2+빈 받침 1(뱀 위 1개 더), 포스터 막대 2줄, 스프링 약 10-11바퀴, 사물함 2, 초록 상자 2, 사람 7명.

## ④ 한 문장
근육은 SR의 Ca²⁺ 방출로 수축하며, 골격근은 DHPR-RyR1 직접 연결, 심근은 Ca²⁺ 유발 방출, 평활근은 칼모듈린-MLCK로 조절하고, 트로포닌·타이틴·네불린과 섬유 유형이 그 구조 바탕이다.
