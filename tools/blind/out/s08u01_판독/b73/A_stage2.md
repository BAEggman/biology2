# 2단계 (약속표 적용, s08u01) - 「↻」는 1단계와 달라진 곳

## 판정 (#번호 = 약속표 줄 번호)
- 약속표가 확정해 준 것 8개: 자갈=Ca²⁺(#4) · 사자 문고리=RyR(#44) · 청록 스위치 상자+D자 고리=DHP(#45) · 모듈 쟁반=칼모듈린(#22) · 붉은 민 도장=인산화(#100) · 트로피=트로포-(#29) · 네온 불=네불린(#30) · 동전=ATP(#8, 빈 지갑).
- 1단계 뼈대(근육 3종의 Ca²⁺ 조절 비교)는 뒤집히지 않고 굳어짐. 약속은 뼈대보다 어휘를 확정함: 고친 곳 2(노인→쟁반이 칼모듈린, 쿠키→자갈), 모름 중 풀린 것 2(네온 막대, 거꾸로 선 트로피 일부), 나머지 ↻는 추정이 확정으로 오른 곳. 약속 밖 물건(스프링·액자·모니터·적/백 선수·사물함·파이프)은 1단계 읽기를 유지.
- 끼우지 않은 약속: 로봇=안드로겐(#27, 관절 팔은 사람꼴 로봇 아님·근육 맥락 불일치) · 샅바 장사=APC/C(#82, 가죽 역도 벨트) · 검은 가스 파이프=카스파리대(#36, 회색+밸브) · 구슬 쟁반=아미노산(#104, 구슬 아닌 덩이) · 팔을 붙잡은 손=안티트롬빈(#97, 손은 어깨에 얹힘) · 밝은 방울=O₂(#17, 새는 알이 바닥 알과 같아 자갈로 읽음).

## ① 판 전체 표제어
- **1순위: 근수축의 Ca²⁺ 조절 - 골격근·심근·평활근 비교(흥분-수축 연결)** 85% ↻(70에서 상승)
- **2순위: 근육의 미세구조와 근섬유 유형(근절 단백질·적색근/백색근)** 10% ↻(20에서 하락)
- 근거 보강: 자갈 든 사물함, DHP 상자, 모듈 쟁반, 트로- 계열 3개가 모두 근수축 조절 어휘.

## ② 구역
**구역1 - 골격근 흥분-수축 연결(DHP-RyR1 직접 결합)**
1. 사자 문고리 1개 = RyR1 (#44. 개수 1=아형 번호는 약속표에 풀이 없는 내 추정)
2. ↻ 사물함 속·바닥의 자갈 = Ca²⁺ (#4. 구슬 아님, ATP·글리코겐 헷갈림 해소). 사물함=SR 창고는 약속 밖 내 읽기
3. ↻ 청록 스위치 상자+D자 고리 = DHP (#45 확정)
4. 상자-문고리 쇠막대 = DHP가 RyR를 직접(기계적) 연결 (모양)
5. D자 고리를 당기는 남자 = 막 탈분극에 DHP가 움직여 RyR1을 엶 (동작)
6. ↻ 빈 동전지갑 = 동전 없음 = ATP 없음 (#8). 회색 남자·거미줄 = 사후강직(교차다리 못 풀림) 추정이 유력해짐. 자갈이 그 머리 쪽으로 흐름
7. ↻ 선반 왼쪽 트로피 = 트로포닌 (#29 확정)
- 모름 유지: 벽 파이프+밸브

**구역2 - 심근: Ca²⁺ 유발 Ca²⁺ 방출(CICR)·plateau**
1. 모니터 곡선(급상승-고원-급하강, 고원 앞머리에 작은 홈) = 심근 활동전위 plateau (약속 밖)
2. 러닝머신 남자 = 쉬지 않는 율동, 강축 없음 (약속 밖, 약한 추정)
3. ↻ 손잡이(D자 고리)에서 자갈이 새는 청록 상자 = DHP로 세포외 Ca²⁺ 유입 (#45+#4)
4. 사자 2개 = RyR2 (#44, 개수 2)
5. 넘쳐 쌓인 자갈 더미 = 소량 유입이 SR 방출을 증폭 (양)
6. 상자-사물함 사이 막대 없음 = 기계적 연결이 아님 (자리)
7. ↻ 선반 가운데 트로피 = 트로포닌 (#29)

**구역3 - 평활근: Ca²⁺-칼모듈린-인산화효소(MLCK), 트로포닌 없음**
1. ↻ 쟁반 = 칼모듈린 (#22). 노인은 약속표에 없음(갓이 없어 ABA 아님), 쟁반 운반자로만 읽음. 1단계 '노인=칼모듈린' 수정
2. ↻ 쟁반 위 쿠키가 아니라 회색 자갈 4알 = Ca²⁺ 4개 결합 (#4, 개수 4)
3. 노인이 청년 어깨에 손 = Ca²⁺-칼모듈린이 인산화효소를 활성화 (동작)
4. ↻ 청년이 든 붉은 민 도장 = 인산화 (#100 확정). 청년=인산화효소
5. 도장이 찍히는 갈색 패드의 관절 팔 = 표적 미오신(경쇄) (약속 밖, 추정)
6. 선반 오른쪽 빈 받침 = 트로포닌 없음 (자리·빈 칸)

**구역4 - 근절 구조 단백질과 근섬유 유형(titin·nebulin·활주설)**
1. 거대한 코일 스프링(약 10감김) = titin (약속 밖, 모양 추정)
2. 액자 막대 2개: 회색(A대) 일정, 양끝 청록(I대)만 단축 = 활주설 (약속 밖)
3. ↻ 분홍 네온 막대 = 네불린 (#30 확정, 약한 추정에서 상승). 옆으로 뻗은 팔은 고정구, 자 아님
4. 마른 빨간 선수 = 적색근(지근) (약속 밖)
5. 근육질 흰 옷 선수 = 백색근(속근) (약속 밖)
6. ↻ 물병 입구를 덮은 거꾸로 선 트로피 = 트로포- 계열 하나 (#29). 어느 쪽인지·물병 뜻은 미해결 (트로포미오신이 액틴 자리를 덮는다는 추정)

## ③ 모름 · 헷갈림 · 흔적
- 풀림: 구슬·쿠키(자갈), 빨간 막대(붉은 도장), 네온 막대(네불린), 거꾸로 선 트로피(트로포- 계열까지).
- 안 풀림: 벽 파이프+밸브, 흰 천 2장, 물병, 사물함의 정체(SR 추정), 거미줄.
- 헷갈림: 쟁반 위 덩이 4개가 '구슬 쟁반(아미노산)'인지 '모듈 쟁반+자갈'인지 - 덩이 모양과 근육 맥락으로 후자.
- 이어 붙인 흔적: 1단계와 같음(뚜렷한 봉합 없음).
- 읽힌 사실: 구역1 7(↻6에서), 구역2 7, 구역3 6, 구역4 6(↻5에서).

## ④ 한 문장
근육은 모두 Ca²⁺(자갈)로 켜지지만 문 여는 방식이 다르다: 골격근은 DHP가 RyR1을 막대로 직접 당기고, 심근은 DHP로 새어 든 Ca²⁺가 RyR2를 터뜨려 증폭(plateau)하며, 평활근은 Ca²⁺-칼모듈린이 인산화효소를 깨워 인산화한다(트로포닌 없음).
