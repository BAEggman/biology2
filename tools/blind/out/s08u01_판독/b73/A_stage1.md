# 1단계 생판 (s08u01, 그림만 보고)

## ① 판 전체 표제어
- **1순위: 근수축의 Ca²⁺ 조절 - 골격근·심근·평활근 비교(흥분-수축 연결)** 70%
- **2순위: 근육의 미세구조와 근섬유 유형(근절·titin·적색근/백색근)** 20%
- 근거: 배경은 체육관, 사람 7명·사물함 2개·사자 문고리 3개(1+2)·청록 상자 2개·트로피 3개(선반 2+물병 1). 사자(라이언≈리아노딘)가 1개에서 2개로 늘고, 선반 3칸(트로피 2+빈 받침)이 구역1·2·3 위에 하나씩 놓여 근육 3종을 나란히 견주는 구도로 읽힘.

## ② 구역 (왼→오, 4구역)
**구역1 - 골격근 흥분-수축 연결(DHPR-RyR1 기계적 결합)**
1. 사자 문고리 1개 = RyR1 (소리: 라이언≈리아노딘, 개수 1)
2. 사물함+쏟아진 구슬 = 근소포체(SR)의 Ca²⁺ 저장·방출 (뜻·자리; 구슬이 벤치 쪽으로 흘러내림)
3. 문고리에서 청록 상자로 뻗은 쇠막대 1개 = DHPR이 RyR를 직접 당기는 물리적 연결, 외부 Ca²⁺ 불필요 (모양)
4. 청록 상자 손잡이를 당기는 남자 = 막 전압 변화에 DHPR이 움직여 문을 엶 (동작)
5. 벤치의 회색 남자·거미줄·빈 지갑·흰 천 2장 = ATP 고갈로 교차다리가 안 풀림(사후강직)/피로 (색·뜻, 추정)
6. 선반 첫 트로피 = 트로포닌 (소리: 트로피≈트로포-, 자리: 구역 위)
- 모름: 벽 파이프+밸브(금 가고 끝이 열린 채 말라 있음. T세관? 닫힌 외부 Ca²⁺ 통로?)

**구역2 - 심근: Ca²⁺ 유발 Ca²⁺ 방출(CICR)과 plateau 활동전위**
1. 모니터의 급상승-긴 고원-급하강 곡선 = 심근 활동전위 plateau (모양)
2. 러닝머신에서 일정하게 달리는 남자 = 쉬지 않는 율동, 긴 불응기라 강축 없음 (뜻, 추정)
3. 손잡이 끝에서 구슬이 똑똑 새는(약 8알) 청록 머그잔 상자 = L형(오래 지속) Ca²⁺ 채널로 세포외 Ca²⁺ 소량 유입 (모양)
4. 사자 2개 사물함 = RyR2 (개수 2)
5. 문 밖으로 넘쳐 쌓인 구슬 더미 = 소량 유입이 SR의 대량 방출을 증폭 (양)
6. 상자와 사물함 사이 막대 없음 = 기계적 연결 아닌 Ca²⁺ 신호로 유발 (자리)
7. 선반 가운데 트로피 = 트로포닌(심근도 있음)

**구역3 - 평활근: Ca²⁺-칼모듈린-MLCK(트로포닌 없음)**
1. 노인 = 칼모듈린 (소리: calm, 차분한 노인)
2. 쟁반 위 쿠키 4개 = Ca²⁺ 4개 결합 (개수)
3. 청년 어깨에 손을 얹음 = Ca²⁺-CaM이 MLCK를 활성화 (동작)
4. 청년 = MLCK(일하는 키나아제), 빨간 막대를 패드의 빨간 단추에 누름 = 인산(P) 부착 (색·동작)
5. 관절 달린 팔+패드 = 미오신 머리, 경쇄 인산화 후 교차다리 순환 (모양)
6. 선반 오른쪽 빈 받침 = 트로포닌 없음 (자리·빈 칸)

**구역4 - 근절 구조와 근섬유 유형(titin·활주설·적색근/백색근)**
1. 거대한 코일 스프링(약 10감김) = titin, 탄성 용수철 (모양)
2. 액자 속 막대 2개(청록-회색-청록, 위 긴 것·아래 짧은 것): 회색 폭은 거의 같고 양끝 청록만 절반으로 줄어듦 = A대 일정·I대 단축, 활주설 (모양·개수 2)
3. 분홍 네온 막대+옆으로 뻗은 팔 = nebulin? (소리: 네온≈네불린, 자 같은 팔 = 필라멘트 길이 조절; 약한 추정)
4. 마른 빨간 옷 선수 = 적색근(지근): 미오글로빈·미토콘드리아·지구력 (색·체형)
5. 근육질 흰 옷+벨트 선수 = 백색근(속근): 해당·순발력·굵음 (색·체형)
- 모름: 물병 위에 거꾸로 씌운 금 트로피

## ③ 뜻 모를 것 · 헷갈림 · 흔적
- 뜻 모름: 벽 파이프+밸브, 분홍 네온 막대+팔, 거꾸로 선 트로피(선반 빈 받침에서 옮겨 온 듯. 트로포닌 소단위 3개 중 억제 소단위? 마개?).
- 헷갈림: 회색 남자가 사후강직인지 피로인지. 구슬이 Ca²⁺인지 ATP·글리코겐인지. 청록 상자 2개(골격 대 심근)는 막대 유무로만 구분.
- 이어 붙인 흔적: 구역4는 방 모서리(벽 색·원근이 바뀜)이나 바닥과 선은 이어져 뚜렷한 봉합은 없음. 선반은 구역1~3 위에서만 끝남.
- 읽힌 사실 합계: 구역1 6, 구역2 7, 구역3 6, 구역4 5 (모름 3건 별도).

## ④ 한 문장
근육은 모두 Ca²⁺로 켜지지만 문 여는 방식이 다르다: 골격근은 DHPR이 RyR1을 직접 당기고, 심근은 새어 든 Ca²⁺가 RyR2를 터뜨려 증폭(plateau)하며, 평활근은 Ca²⁺-칼모듈린이 MLCK를 깨워 미오신을 인산화한다(트로포닌 없음).
