## 지킬 것
- s2 의 지붕을 뚫고 솟은 근육 팔 + 큰 나무 국자(= 펌프)와 s3 의 지붕 빈 하늘색 소매(= 펌프 없음) 대비: 펌프 수가 세어지는 사건.
- 꿀벌(bee) = b, 황소(ox) = oxidase, 에이스 카드 = a 의 소리 고리(액자를 사건으로 옮길 때도 이름 소리는 잃지 말 것) · 호박 = 호박산.
- s8 · s9 · s10 의 「담장 꼭대기까지 찬 바다 / 마른 앞마당 → 돌 아치 → 물레방아 → 금화 잭팟」: 기울기 → 합성효소 → ATP 의 사건과 맑은 물 그대로 웅덩이로 가는 점.
- s12 의 흰 방울 머리 사람이 노란 공을 두 손으로 받고 그 뒤에는 넘겨줄 사람이 없는 장면(최종 수용체).
- s5 의 둘째 집 레일이 첫째 집 문을 지나지 않고 합류하는 길(I 을 건너뜀)과 둥근 문 대 네모 문의 갈림.

## 과학 의심
없음(s14 의 10H⁺ · 2.5ATP / 6H⁺ · 1.5ATP 는 교재 값이며 판본에 따라 3 · 2 로 적기도 해 판정하지 않았다).

## 총평
이 과의 가장 급한 것은 이름 고리가 하늘의 액자 판 넷에 실려 있어 사건이 이름을 나르지 못하는 점(D1)과, 복합체 I 의 FMN · 플라보단백질 · 철-황 단백질 · Q · FADH₂ 에 이름 고리가 없는 점(N)이다. 이어서 s14 의 H⁺ · ATP 수가 그림에 없는 것(M)과 「물」이 H⁺ · NADH · H₂O 로 세 뜻인 점(C). s10 의 「바퀴 축」은 글만 고치면 된다.
