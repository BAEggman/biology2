- say: 둘째 집의 호박을 보자. 숙신산의 다른 이름인 호박산이다. 첫째 집과 같은 집게가 호박에서 수소를 뗀다. 호박산 탈수소효소, 즉 숙신산 탈수소효소다. 전자를 받는 분자까지 포함한 이름은 숙신산–유비퀴논 산화환원효소다. 시트르산 회로에서 숙신산을 푸마르산으로 바꾸는 효소가 바로 내막의 복합체 II이다. 지붕이 빈 소매인 것은 Q로 전자를 전달하지만 H⁺를 펌프하지 않는다는 뜻이다.

### s4
- obj: 첫째 집의 둥근 은색 양동이와 집게 · 가득 찬 둥근 양동이와 빈 양동이를 든 짐꾼
- fact: I = NADH 탈수소효소(NADH–유비퀴논 산화환원효소)
- hook: 둥근 양동이는 NADH, 수소 풍선을 떼는 집게는 탈수소효소
- say: 첫째 집의 원료인 둥근 양동이는 NADH이다. 집게가 양동이에서 수소를 떼므로 NADH 탈수소효소다. NADH를 산화해 NAD⁺로 돌려보내고, 전자는 유비퀴논 Q에 전달한다. 정식 명칭은 NADH–유비퀴논 산화환원효소다. 지붕 국자는 이 반응에 결합된 H⁺ 펌프다. 그림에는 없는 세부로, 집 안에서 전자는 먼저 FMN, 즉 플라빈 모노뉴클레오타이드 보결분자단에 실린 뒤 철-황 단백질로 이동한다. FMN을 가진 단백질이므로 복합체 I을 플라보단백질이라고도 한다. 둥근 양동이의 경로를 I → Q → III → IV로 연결해 두자.

### s6 (녹음됨)
- obj: 바위 수레의 노란 공 둘 · 셋째 집에 붙은 꿀벌과 수박씨 한 알
- fact: I·II의 전자 → Q/QH₂ → III(유비퀴놀–사이토크롬 c 환원효소, bc₁)
- hook: 두 공을 든 바위는 QH₂, 꿀벌(bee)은 b, 붙박이 씨 한 알은 c₁
- say: 두 입구의 레일이 합쳐지는 곳을 따라가자. 회색 바위 수레는 내막을 이동하는 비단백질 운반체 Q이다. 전자 둘과 H⁺ 둘을 받은 유비퀴놀 QH₂가 셋째 집에 전자를 전달한다. 셋째 집의 꿀벌은 bee이고, 옆에는 씨 한 알이 있다. bee와 씨 하나를 이어 bc₁ 복합체, 즉 복합체 III를 떠올리자. 사이토크롬 b와 c₁은 이 복합체에 붙어 있다. QH₂를 산화하면서 이동성 사이토크롬 c를 환원하므로 유비퀴놀–사이토크롬 c 산화환원효소라고 한다.

### s7 (녹음됨)
- obj: 셋째 집과 넷째 집 사이를 오가는 씨 장식의 나무 수레 · 노란 공 하나
- fact: III의 붙박이 c₁과 이동성 사이토크롬 c를 구별한다. c가 전자를 하나씩 IV에 건넨다.
- hook: 집에 붙은 씨 한 알 = c₁ · 수레에 탄 씨 = 이동성 c · 공 하나 = 전자 1개
- say: 셋째 집에 고정된 씨 한 알은 사이토크롬 c₁이다. 옆의 씨 장식은 움직이는 나무 수레에 달려 있는데, 이 수레는 단백질 운반체 사이토크롬 c이다. 상자 위 공이 하나인 것처럼, 내막의 막간공간 쪽 표면에서 전자를 한 번에 하나씩 III에서 IV로 운반한다. 사이토크롬의 차례는 b → c₁ → c → a → a₃이다. 셋째 집의 b와 c₁, 이동 수레의 c, 넷째 집 카드의 a와 a₃를 이어 보자. 각 사이토크롬에서 전자를 운반하는 자리는 헴의 철이다.

- fact: 화학삼투 — H⁺ 기울기가 ATP 합성효소를 돌려 ATP 를 만든다
- hook: 물레방아 = ATP 합성효소 · 동전 = ATP
- say: 아치에서 나온 물이 큰 나무 물레방아를 돌린다. 바퀴가 돌 때마다 중심축에서 금빛 동전이 잭팟처럼 반짝이며 튀어나와 나무 쟁반에 넘친다. 동전은 ATP이고, 물은 그대로 웅덩이에 떨어진다. 물 자체가 동전으로 바뀌는 것은 아니다. 양성자 기울기의 에너지로 ATP 합성효소가 ATP를 만드는 화학삼투다. 펌프 팔은 물을 퍼 올릴 뿐이며, 동전을 만드는 곳은 물레방아뿐이다. 전자전달이 기울기를 만들고, 그 기울기가 합성효소를 작동시킨다. 세포호흡에서 대부분의 ATP를 합성하는 직접적인 에너지원은 이 기울기다. 엽록체 쿠션 무대 아래 물레방아도 같은 원리를 사용했다.
- 카드 4:
  - B1-148: 전자전달계와 ATP 합성의 짝물림을 한 문장으로 표현하면? → 전자전달이 H+ 기울기를 만들고, 그 기울기가 ATP 합성효소를 돌린다
  - B1-144: 화학삼투(chemiosmosis)란? → 양성자 기울기에 저장된 에너지를 이용해 ATP를 합성하는 과정
  - B1-199: 세포호흡에서 ATP 대부분의 직접 원천은? → 양성자 기울기
  - C0-137: 광합성의 화학삼투와 세포호흡의 화학삼투 공통점은? → 전자전달계가 만든 H+ 기울기로 ATP 합성효소가 ATP를 만든다

### s11 (녹음됨)
- obj: 넷째 집 황소와 문간의 마지막 전자 전달
- fact: IV = 사이토크롬 c 산화효소. heme a를 거쳐 a₃–CuB 중심에서 O₂를 환원한다.
- hook: 씨 수레 + 황소(ox) = cytochrome c oxidase · 에이스와 하트 셋 = a와 a₃
- say: 씨 수레가 전자를 가지고 넷째 집의 황소에게 간다. 황소의 영어 ox를 씨와 이어 cytochrome c oxidase, 사이토크롬 c 산화효소를 떠올리자. 이 효소는 사이토크롬 c를 산화한다. 받은 전자는 복합체 IV 안에서 CuA와 헴 a를 지나 헴 a₃–CuB 중심에 도착하고, 산소가 전자를 받아 물로 환원된다. 황소 위의 첫 카드는 하트 하나인 에이스로 헴 a, 다음 하트 세 개 카드는 헴 a₃이다. 코앞의 산소 방울과 아래 물방울은 최종 반응의 기질과 생성물이다.

### s12 (녹음됨)
- obj: 머리가 통째로 흰 방울인 사람 — 두 손을 오므려 노란 공을 받고 · 그 뒤로는 넘겨줄 사람이 없다
- fact: 최종 전자수용체는 산소(O₂) — 엽록체 전자전달계는 NADP⁺
- hook: 흰 방울 머리 = O₂ · 뒤에 아무도 없음 = 최종
- say: 두 손으로 노란 공을 받는 사람은 머리 전체가 흰 방울이다. 이 덱에서 흰 방울은 언제나 O₂이며, 그 뒤에는 전자를 더 넘겨줄 사람이 없다. 그래서 산소가 최종 전자수용체다. 엽록체 무대의 마지막 둥근 방패는 NADPH였다. 엽록체 전자전달계의 최종 수용체는 NADP⁺, 미토콘드리아에서는 O₂이다. 광합성은 물에서 얻은 전자를 NADPH에 담고, 세포호흡은 유기물에서 얻은 전자를 산소에 전달한다.

### s13
- obj: 산소를 향해 뛰어드는 작은 물방울 둘 · 발치에 붉은 밀랍으로 봉한 물병
- fact: 복합체 IV의 산소 환원 반응은 O₂ + 4e⁻ + 4H⁺(기질) → 2H₂O다.
- hook: 물병 하나당 전자 두 개와 기질의 H⁺ 두 개
- say: 산소 한 분자를 완전히 환원하려면 전자 네 개와 기질 쪽 H⁺ 네 개가 필요하며, 물 두 분자가 만들어진다. 그림은 물병 한 개에 해당하는 몫으로 압축했다. 병 하나의 몫은 산소 원자 하나, 전자 둘, H⁺ 둘이다. 물 생성에 소비되는 H⁺와 넷째 집 국자가 막간공간으로 퍼내는 H⁺는 별도로 세어야 한다.

### s14
- obj: 첫째·둘째 집 문밖에서 합류점까지 이어지는 두 레일 · 그 위에 나란히 놓인 세 국자와 빈 소매

- hook: 합류 전 두 레일에서 출발점을 확인하고 H⁺ 펌프를 센다. NADH 경로는 셋, 숙신산 경로는 둘
