## 지킬 것
- s2 의 털외투 산장지기 배에 달린 열린 무쇠 난로 + 속의 불(내온) ↔ 열등 아래 유리 사육장 도마뱀(외온): 한 물건 두 뜻으로 이어지는 쌍이며 s10 장작 · 꺼진 난로까지 같은 난로로 이어진다.
- s13 의 줄무늬 수면 모자 쓴 고슴도치 + 눈 밑 굴 + 빈 밥그릇(동면 = 겨울잠, 소리 · 글자뜻 겹침).
- s7 의 찡그린 얼음 위 사람(아프게 읽힘, 780 px 에서도 읽힘) · s9 의 유리 장대 다리 거위(역류교환의 뜻 그대로).
- s1 의 큰 온도계 · 초록 띠와 녹는 / 언 버터(큰 틀, 장면의 중심).
- s12 의 느긋한 야크 vs 정신없는 벌새 대비.

## 과학 의심
없음 (11-20 ㄷ 도 의심 0). 다만 s8 의 등산객 머리 둘레 빨간 열 김은 「열 보존」과 반대 방향으로 가르치므로 부호 C 로 따로 적었다.

## 총평
가장 급한 것은 s8 의 반대 신호(열 새는 등산객 = 열 보존)와 혈관 사슬 끊김(C · K), 그리고 s5 의 땀 → 김 이음(T). 이름은 복사 · 대류 · 전도 · BMR/SMR 에 소리 · 글자 고리가 없고(N), s11 의 SMR 다이얼이 780 px 에서 안 보여 BMR/SMR 혼동쌍이 약하다. 그림 전체가 사건 하나로 묶이지 않고 소품이 따로 노는 도해 꼴이라 다음에 다시 그릴 때 사건으로 묶을 일이다.
