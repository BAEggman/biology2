## 지킬 것
- 루비빛 렌즈 스코프 = 루비스코(황동 기둥 · 루비 렌즈 · 두 방에서 같은 방향). 독자가 소리로 맞힌 고리다.
- 칼 = K⁺ 덱 약속과 「칼이 먼저 · 물이 뒤」 순서(s3).
- 풍선처럼 부푼 콩팥 ↔ 쭈글쭈글 붙은 콩팥(팽압 · 공변세포). 독자가 모두 ○ 로 판정.
- 오른쪽 방의 흰 기포 빽빽 ↔ 왼쪽 방의 까만 방울(s7). 두 방 대비가 한눈에 읽힌다.
- 금빛 회중시계 = 생체시계와 갈라진 흙 · 젖은 흙의 두 칸 비교.

## 과학 의심
- s9 · s8 「덥고」: 그림에 열 · 해 표시가 없어 「덥고 건조」 중 「덥고」가 안 나온다(과학 오류는 아님).
- 왼쪽(열림) 방에서 광합성 중이면 O₂ 도 생긴다. 왼쪽 방에 흰 기포가 0 이라 O₂ 가 틈에서 갑자기 나타난다(과학 의심 약함 · s4).

## 총평
가장 급한 것은 s6 의 닫힘 사슬이다. 갓(ABA)이 공변세포와 이어지지 않고 칼이 나가는 방향이 아니라서, 사용자가 앱시스산에 대해 지적한 N 과 사슬 K, 사실과 반대 C 가 한 정거장에 겹친다. 그다음은 s4 증산 M, s5 · s9 빛줄기 수 불일치, s8 발톱 R 이다.
