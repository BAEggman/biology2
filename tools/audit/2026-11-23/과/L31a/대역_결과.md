## 지킬 것
- s1 창의 해 + 당구장 = 해당(소리 고리가 한눈에 읽힘 — ㄱ 도 해 뜨는 · 당구장 ○).
- s2 육각 도장 = 헥소키나아제(헥사)와 s4 열쇠 소품 · 큐 걸이(장소 소품). 덱 약속 빨간 도장 · 동전 · 소금 따위는 s3 · s6 에서 그대로.
- s7 도장 자리에서 솟는 물줄기가 양동이로 떨어지는 사건(같은 자리 연결 ㄷ ○).
- s10 창 가위표 널빤지(산소 안 씀) — 당구는 계속 치는 장면.
- 큐 불꽃 · 선글라스 남자의 한 장면(분위기) 와 s4 의 「ATP 많으면 거절」 손바닥 장면.

## 과학 의심
- s5 도형: 정육면체(면 6) = 탄소 6 · 사각뿔 = 탄소 3 으로 보이나 면 수는 3이 아님(대장 L31a-01 verified). 뜻은 「조각 수」일 뿐이므로 수를 세게 하지 않도록 글로 막을 것.
- s7 물 = NADH: 실제 산물은 NADH 이고 물은 비유(대장 L31a-02). 같은 파란 물이 s12 에서 노폐물 물과 겹침.
- s9 · B1-196: 카드의 「직접 ATP 4」는 해당 순 2 + 시트르산 회로 2(대장 말미)인데 그림 바닥 동전 넷은 해당의 총 회수 4. 같은 숫자 4 가 다른 계산이라 그림이 카드에 맞는 것처럼 읽힘(ㄷ 어긋남).
- s11 · 「산소가 있을 때 피루브산이 미토콘드리아로」: 이동 자체는 산소를 직접 요구하지 않음 — 눈 검사 ㄷ 의 약한 의심과 같음.

## 총평
이름 고리는 해당(해 + 당구) · 헥소키나아제(육각)처럼 첫 음절이 겹치는 것만 살고, 중간 대사물(G3P · BPG · PG · PEP)은 한 종류의 붉은 각뿔이 모두 나르는 데다 이름 고리가 없어 가장 급하다(N + C). 다음은 s12 판(D1)과 s3 · s5 · s9 의 동전 · 각뿔이 사건으로 이어지지 않는 곳(M · K · T).
