### s6
- obj: 막사 지붕 바깥의 두루마리와 보라 짝, 바로 아래 막사 안에서 보이는 색 구슬 사슬.
- fact: SRP가 새 사슬의 소포체 신호서열을 인식 → 리보솜 도킹 → 폴리펩타이드가 막 통로 통과

- say: 대표적인 분비 단백질에서는 N말단의 소수성 신호서열이 먼저 리보솜 밖으로 나온다. 아미노산 스무 개 정도의 신호 펩타이드에 단백질과 RNA로 된 신호인식입자 SRP가 결합한다. SRP는 리보솜을 소포체 막의 SRP 수용체로 안내한다. 리보솜이 트랜스로콘에 자리 잡으면 번역이 이어지며 새 폴리펩타이드가 통로를 지나 내강으로 들어간다. 합성이 끝난 뒤가 아니라 번역 도중 막에 도착한다는 순서를 기억하자. mRNA와 리보솜은 세포질 쪽에 남는다.

### s7
- obj: 막사 안에서 구슬 사슬을 손질하는 손과 붉은 막대사탕, 돌아가는 수레에 찍힌 닻.

- hook: 사슬 손질 → 접힘 · 사탕 → 당화 · 닻 → KDEL · 되돌아오는 수레 → COPI
- say: 내강으로 들어온 분비 단백질은 접히고, 많은 단백질은 N-결합 당화를 받는다. 소기관 안으로 들어온 사슬이 겪는 대표 가공인 이 접힘을 폴딩이라고 한다. 소포체에 남아야 하는 가용성 단백질 일부는 C말단에 KDEL 서열을 갖는다. 골지로 나갔더라도 KDEL 수용체가 이 신호를 인식하면 COPI 소포를 타고 소포체로 회수된다. 닻을 이 회수 과정의 단서로 보자.

### s10
- obj: 골지 쟁반 더미를 따라, 뒤이어 목적지가 다른 수레들로 시선을 옮긴다.
- fact: 시스터나 성숙 모델에서는 화물을 담은 cis 시스터나가 medial·trans 성질을 차례로 얻는다
- hook: 받는 쪽 → 성숙하는 쟁반 → 분류·발송하는 트랜스 골지망
- say: 시스터나 성숙 모델에서는 화물을 담은 초기 시스터나가 점차 중간과 후기 시스터나의 성질을 갖게 된다. 골지 효소는 반대 방향으로 수송되어 구획별 구성이 유지된다. 트랜스 골지망은 화물의 분류 신호를 읽고 목적지에 맞는 운반체에 싣는다. 리소좀 효소의 표지는 그보다 앞쪽 골지에서 형성되기 시작한다.
- 카드 2:
  - A0-75: 시스터나 성숙 모델(cisternal maturation model) 요지? → 시스터나가 시스→트랜스로 이동하며 단백질을 운반·가공
  - A0-76: 골지체 트랜스골지망에서 단백질을 출고할 때 하는 일 두 가지는? → 화물을 목적지별로 분류하고 운반 소낭에 포장한다. 리소좀 효소의 M6P 표지는 시스골지에서 형성이 시작되고, 트랜스골지망에서 수용체에 인식되어 엔도솜행 소낭으로 분류된다.

### s11
- obj: 쟁반의 막사 쪽에서 빨간 도장을 찍는 손과, 붉은 표가 붙은 짐을 삼각 격자 우리에 실은 수레.
- fact: 초기 골지에서 M6P 표지 형성 시작 → 트랜스에서 수용체가 선별 → 엔도솜을 거쳐 리소좀
- hook: 상자 위 붉은 표 → 만노스-6-인산 · 격자 수레 → 클라트린 운반체 · 회색 도착 칸 → 엔도솜
- say: 가용성 리소좀 가수분해효소는 조면소포체에서 만들어진다. 초기 골지의 인산전이효소가 당사슬의 만노스에 표지를 만들기 시작하고, 뒤이어 덮개 당이 제거되면 만노스-6-인산(M6P)이 드러난다. 트랜스 골지망의 M6P 수용체는 표지된 효소를 골라 클라트린 운반체에 싣는다. 엔도솜에서 수용체와 분리된 효소는 리소좀으로 전달된다. 봉입세포병에서는 표지 형성이 손상되어 여러 효소가 세포 밖으로 잘못 분비된다. 리소좀 막 단백질도 조면소포체에서 합성되어 골지를 지나지만 별도의 분류 신호를 사용한다.
- 카드 3:
  - A0-77: 리소좀(lysosome)의 정의? → 가수분해효소가 들어있는 막성 소낭(소화성 소기관)
  - A0-200: 봉입세포병(I-cell disease)의 원인은? → 만노스-6-인산(M6P) 표지 결함 → 효소가 리소좀으로 전달되지 못함
  - A0-81: 가수분해효소와 리소좀 막은 어디서 만들어지는가? → 조면소포체에서 합성 → 골지체에서 가공

### s12
- obj: 물가 울타리의 열린 자리에서 작은 짐이 물 쪽으로 나온다.
- fact: 세포외배출은 소낭막과 세포막의 융합 · 내강 화물이 세포 밖으로 방출되고 소낭막은 세포막에 합류
- hook: 물가로 간 수레 → 분비 소낭 · 울타리 밖으로 나온 짐 → 세포외배출
- say: 분비 소낭의 막이 세포막과 융합하면 소낭 내부가 세포 밖으로 열린다. 가용성 화물은 밖으로 나오고 소낭막은 세포막에 합쳐진다. 이자 베타세포의 인슐린 분비가 대표적이다. 재조합 대장균도 인슐린 원료 단백질을 만들 수 있지만, 소포체와 골지체를 거쳐 소낭으로 분비하는 이 경로는 없다.
- 카드 3:

  - A1-122: 세포외배출작용의 핵심 단계는? → 소낭과 원형질막의 융합

### s13
- obj: 짐을 실은 수레에서 물가 울타리까지 분비 화물의 행선지를 되짚는다.
- fact: 소낭을 쓰는 덩어리 수송 · 세포외배출은 밖으로, 세포내섭취는 세포막이 함입해 안으로
- hook: 분비 경로는 조면소포체 → 운반 소포 → 시스 골지 → 트랜스 골지 → 분비 소낭 → 세포막 융합
- say: 큰 단백질이나 다당류를 내보낼 때는 소낭을 이용한 덩어리 수송을 한다. 반대로 세포막이 바깥 물질을 감싸 내부로 소낭을 만들면 세포내섭취다. 분비 단백질의 경로를 다시 이어 보자. 세포질에서 번역 시작 → 조면소포체 내강 → 운반 소포 → 골지 시스면 → 트랜스 골지망의 분비 경로 → 세포막 융합 → 세포 밖이다.
- 카드 4:
  - A1-118: 덩어리 수송(bulk transport)이 필요한 이유는? → 큰 분자는 확산이나 수송단백질로 막을 통과하기 어렵기 때문
  - A1-119: 덩어리 수송의 두 큰 종류는? → 세포외배출작용(exocytosis) + 세포내섭취작용(endocytosis)
  - A1-123: 단백질과 다당류 같은 큰 분자는 보통 어떻게 이동하는가? → 소낭에 포장되어 덩어리째 이동
  - A1-145: 세포외배출작용 vs 세포내섭취작용의 차이는? → 밖으로 내보냄 vs 안으로 들임
