## 지킬 것
- 와플 + 금색 자물쇠 + 날 박힌 칼 + 번지는 피 웅덩이(s13) — 와파린의 ① 소리 고리와 사건(막힘 → 출혈)이 한 장면이다. ㄴ 독자도 바로 댔다.
- 오렌지 머리 정비사 + C 자 갈고리 + 분홍 세 가닥 땋기(s2) — 「비타민 C = 콜라겐 땋기」가 한눈에 읽히고 땋은 줄이 3중 나선을 나른다.
- 등에 노란 기름방울을 멘 넷(점등원 · 일광욕객 · 소방관 · 요리사) + 우윳빛 흰 길 — 지용성 넷 + 림프 경로가 한 구조로 묶이고 수도 맞다(등에 멘 넷).
- 자갈 = Ca²⁺ · 칼 = K · 금색 자물쇠 = 약물의 덱 약속, O 자 다리 · 갈라진 타일 · 소방관의 E 자 호스 걸이 같은 글자 모양 소품.
- 판 · 화살표 · 말풍선이 없는 사건형 장면(ㄱ 독자 (사) 확인).

## 총평
이름 고리가 가장 급하다: 아스코르브산 · 레티놀 · 비오틴(+ 엽산)이 그림에서 이름으로 가는 길이 없고, 특히 아스코르브산은 눈 검사 독자가 「하는 일로 짐작」으로 맞춘 꼴이라 사용자가 되풀이한 지적에 해당한다. 그다음은 전달이 끊긴 곳(s8 자갈이 문을 지나 안으로 들어가지 않음 · s3 소화기 분사 · s10 호스 · s4 땋은 머리 이음)이고, 정거장 s7 의 간 → 신장 순서와 s11 의 응고 인자 숫자는 글에만 있다. 와플 = 와파린과 기름방울 넷은 잃지 말 것.
