## 지킬 것
- s3 에이스 카드 + 분필 동그라미 · s4 빗자루(비) · s7 프라이팬 + 지팡이 요리사 · s12 라이터 용접공 — 사용자가 11-19 에 「phonetic link 는 마련이 되어있는데」라고 인정한 L11a 의 고리 묶음.
- 지퍼 = 이중나선이 열리는 큰 사건 한 장면(P10)과 오른쪽부터 차례로 선 인물 순서(DnaA → DnaB → SSB → DnaG).
- 아래 띠 못 → 뾰족 판자들과 위 띠 긴 판자 한 장의 선도 · 지연 대비(바뀐 뜻 없이 방향이 갈림).
- 꼬인 지퍼에 스패너 + 분기점 앞쪽 자리 — 위치 사실이 이미 맞다(고리만 얹을 것).

## 과학 의심
- 의심 하: s12 용접 자리. 라이게이스는 이웃한 두 오카자키 절편 사이 닉을 잇는다. 그림은 맨 오른쪽(분기점 쪽, 가장 새) 판자 오른쪽 가장자리에서 불꽃이 튀어 이을 이웃이 보이지 않고, 먼저 만든 왼쪽 토막끼리 이어진다는 시간 방향과도 어긋나 보임. 프라이머 제거 · DNA 대체 걸음은 그림에 없음.
- 그 밖에는 방향(선도 = 분기점 방향 · 지연 = 반대 · 판자 5′ 못 → 3′ 뾰족 · 헬리케이스 진행 방향 · 자이레이스 앞쪽)이 그림에서 맞다고 보았다.

## 총평
이 과의 가장 급한 병은 N: 헬리케이스 · 자이레이스(토포아이소머레이스) · 오카자키 절편이 「하는 일을 하는 인물」만 있고 이름으로 가는 고리가 없다(사용자 지적 그대로), 다음으로 SSB · 활주 클램프의 이름 고리가 글에만 있다. 기존 인물(주황 인부 · 스패너 인부 · 판자 · 쐐기)에 이름을 얹는 방식으로, 붐비게 새 인물을 세우지 않고 풀어야 한다. s3 의 성긴 이빨 · s12 용접 자리는 구역 편집으로 처리 가능.
