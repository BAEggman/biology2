## 정거장(보이는 것 obj · 사실 fact · 고리 hook · 걸린 카드)

### s1
- obj: 열쇠 계주 운동장 — 출발선의 타이 맨 둘에서 결승선 지우개까지 한 줄
- fact: RTK 아래 줄 — 인산화 연쇄(키나아제가 다음 키나아제를 인산화) · Ras · MAP 연쇄는 RTK 하류
- hook: 열쇠(키나아제) 바통을 이어 받는 계주
- say: 열쇠 계주 운동장은 교환국의 타이 창구인 알티케이에서 이어지는 신호 경로다. 열쇠는 키나아제이고, 한 키나아제가 다음 키나아제를 인산화하는 연쇄를 계주로 표현했다. 출발선에서 결승선까지 신호를 따라가 보자. 인산화 연쇄 자체는 뱀 창구 아래에서도 일어나지만, 이 운동장의 쥐 주자인 라스와 지도로 표현한 맵 연쇄는 타이 창구 아래의 경로다.
- 카드 1:
  - X-SG-12: MAPK 연쇄와 Ras는 어느 수용체의 하류인가? → RTK 하류 (← GPCR의 cAMP–PKA 경로와 혼동 주의)

### s2
- obj: 출발선 타이 맨 둘 — 서로 등에 열쇠 도장 · 발밑 금화
- fact: 키나아제는 ATP의 인산기를 단백질(티로신)에 옮긴다 — 도장 = 인산화
- hook: 열쇠 = 키나아제 · 금화 = ATP
- say: 출발선의 흰 셔츠와 타이를 맨 두 사람이 등을 맞대고 서로의 등에 열쇠 도장을 찍는다. 발밑의 금화는 에이티피다. 도장을 찍는 것은 인산화, 찍는 사람은 단백질 인산화효소다. 에이티피의 인산기를 떼어 단백질의 티로신으로 옮긴다. 단계마다 인산화된 단백질의 입체구조가 바뀌면서 신호가 전달된다. RTK는 티로신을 인산화하고, PKA를 비롯한 세포질의 대부분 kinase는 세린·트레오닌을 인산화한다는 차이도 기억하자.
- 카드 5:
  - B0-86: ATP에서 인산기를 떼어 단백질로 옮겨주는 효소의 일반 명칭은? → 단백질 인산화효소(protein kinase)
  - B0-187: RTK 경로에서 ATP의 직접 용도는? → 타이로신 인산화에 인산기 제공
  - B0-81: 각 단계에서 신호는 주로 무엇의 변화로 바뀌는가? → 인산화된 단백질의 입체구조 변화
  - B0-91: RTK의 타이로신 인산화와 일반 세포질 kinase의 차이를 한 문장으로? → RTK는 타이로신을, 일반 세포질 kinase는 주로 세린/트레오닌을 인산화한다
  - X-SG-11: 타이로신을 인산화하는 것은? 세린·트레오닌을 인산화하는 것은? → 타이로신=RTK / 세린·트레오닌=대부분의 세포질 kinase, PKA

### s3 (녹음됨)
- obj: 중계석 아나운서 — 마이크 들고 등의 자국을 노려본다
- fact: 중계단백질 — 인산화된 티로신을 알아보고 붙는다(RTK가 다 켜진 뒤)
- hook: 중계 = 중계단백질
- say: 옆 중계석의 아나운서는 마이크를 든 채 두 사람 등에 찍힌 자국을 살펴보고 있다. 중계를 맡는 중계단백질의 단서다. 알티케이가 활성화되어 인산 도장이 찍힌 뒤, 인산화된 티로신 자국을 알아보고 결합한다.
- 카드 2:
  - B0-63: 완전히 활성화된 RTK(인산화된 티로신)를 알아보고 붙는 것은? → 중계단백질
  - B0-65#4: RTK 신호전달의 핵심 흐름은? → 리간드 결합 → 이합체화 → 타이로신 인산화 → 중계단백질 결합

### s4
- obj: 중계석 앞에서 트랙이 여러 갈래로 갈라진다
- fact: 자국마다 다른 중계단백질이 한 길씩 → 수용체 하나가 여러 경로를 한꺼번에 켠다
- hook: 갈림길
- say: 중계석 앞에서 트랙이 여러 갈래로 나뉜다. 넥타이를 맨 두 사람 등에 찍힌 자국마다 서로 다른 중계단백질이 결합해 각 경로를 맡는 모습이다. 따라서 수용체 하나, 알티케이 한 쌍이 여러 전달 경로를 동시에 활성화해 다양한 세포 반응을 일으킬 수 있다. 인산기가 붙은 티로신 여섯 자리에 여러 중계단백질이 와서 붙는다.
- 카드 2:
  - B0-64: RTK에 결합한 중계단백질의 역할은? → 여러 전달 경로를 활성화해 다양한 세포반응 유도
  - B0-56: RTK는 몇 개의 인산기를 다양한 단백질에 줄 수 있다고 언급되었는가? → 6개(기본서 표현) — 인산기가 붙은 티로신 여섯 자리에 서로 다른 중계단백질이 붙어 여러 경로를 켠다(인산기를 떼어 주는 것이 아님)

### s5 (녹음됨)
- obj: 가운데 길의 쥐 탈 작은 주자 — 네모 칩 뒤집기
- fact: Ras — 작은 G단백질(GDP↔GTP) · RTK 하류
- hook: 쥐(rat) = Ras(rat sarcoma) · 네모 칩 = GTP
- say: 가운데 트랙에서는 쥐 탈을 쓴 작은 주자가 손의 네모 칩을 뒤집으며 달린다. 라스라는 이름은 쥐를 뜻하는 랫과 육종을 뜻하는 사코마에서 왔다. 라스는 작은 지 단백질이며, 칩을 뒤집는 동작은 지디피를 지티피로 교환하는 과정이다. 교환국의 큰 지게꾼과 같은 계열이지만 몸집이 작다. 정상 라스는 타이 창구에서 받은 성장 신호를 아래 단계로 전달한다.
- 카드 2:
  - B0-213: RTK 신호를 중계하는 대표 소형 GTP가수분해효소는? → Ras
  - F1-133: Ras 단백질의 정상 역할은? → 성장 신호 전달

### s6 (녹음됨)
- obj: 긴 발판 위 셋 — 앞의 둘이 지도를 들고 차례로 다음 사람에게 도장
- fact: MAP 인산화효소 연쇄 — 셋이 한 골격단백질(발판) 위에 묶여 차례로 인산화
- hook: 지도 = MAP · 한 발판 = 골격단백질(scaffold = 발판)
- say: 긴 발판 하나 위에 세 사람이 한 줄로 서 있다. 앞의 두 사람은 지도를 들고 차례로 다음 사람에게 도장을 찍는다. 지도, 맵에서 맵 인산화효소 연쇄를 떠올리자. 셋을 한 발판 위에 묶어 두는 것은 골격단백질이다. 영어 스캐폴드는 공사장 발판이라는 뜻이다. 끈적한 세포질에서는 큰 단백질이 저절로 퍼져 서로 만나기 어렵다. 발판이 이들을 한데 모으면 필요한 확산 거리가 줄어 반응이 빨라지고 불필요한 작용도 줄어든다.
- 카드 4:
  - B0-212: RTK 하류의 대표 인산화 연쇄는? → MAP 인산화효소 연쇄(MAPK cascade)
  - B0-195: Scaffold 단백질의 장점과 신호 증폭의 장점을 비교하면? → scaffold는 효율·속도 증가, 증폭은 적은 신호를 큰 반응으로 확대 scaffold는 효율·속도 증가 증폭은 적은 신호를 큰 반응으로 확대
  - B0-141: 골격단백질이 신호전달 효율을 높이는 이유는? → 확산해야 할 단백질들을 한데 묶어 반응을 빠르게 하기 때문
  - B0-142: 점도 높은 세포질에서 scaffold가 유리한 이유는? → 고분자 단백질들이 자유 확산만으로 만나기 어렵기 때문

### s7 (녹음됨)
- obj: 등의 자국이 뒤로 갈수록 는다 — 마지막은 빽빽
- fact: 증폭 — 단을 거칠수록 신호가 커진다 · 단마다 조절할 자리가 생긴다
- hook: 자국 수가 는다
- say: 주자들의 등에 찍힌 자국을 보자. 첫째에는 하나, 둘째에는 몇 개, 마지막에는 빽빽하게 찍혀 있다. 단계를 거칠수록 켜지는 분자가 많아지는 증폭의 비유다. 단계마다 신호를 조절할 자리도 생긴다. 반응을 조절하는 네 요소는 증폭, 각 단계의 조절, 발판의 골격단백질, 결승선의 신호 종결이다. 연쇄는 증폭을 맡고 세포마다 다른 단백질 조합은 특이성을 맡으므로, 증폭과 특이성이 함께 가능하다.
- 카드 3:
  - B0-79: 막수용체 신호전달 경로가 보통 다단계인 이유는? → 여러 분자가 연쇄적으로 참여해 신호를 세포내로 전달하기 때문
  - B0-135: 반응 조절의 4가지는? → 신호의 증폭, 다단계 경로에서의 조절, 골격단백질에 의한 반응효율 증가, 신호의 종결 신호의 증폭 다단계 경로에서의 조절 골격단백질에 의한 반응효율 증가 신호의 종결
  - B0-194: 신호증폭과 특이성은 어떻게 동시에 가능한가? → 증폭은 cascade로, 특이성은 세포별 단백질 조합 차이로 보장된다 증폭은 cascade로 특이성은 세포별 단백질 조합 차이로 보장된다

### s8
- obj: 결승선 심판의 큰 지우개 — 마지막 주자 등을 지운다
- fact: 단백질 탈인산화효소가 인산기를 떼어 끈다 · 종결은 층마다 다르다(칩 되돌림 · 가위 · 지우개)
- hook: 지우개 = 탈인산화
- say: 결승선의 심판이 큰 지우개로 마지막 주자의 등을 지운다. 인산기를 제거해 신호를 끄고 단백질을 다시 사용할 수 있게 하는 단백질 탈인산화효소다. 종료 방식은 단계에 따라 다르다. 지 단백질은 칩을 되돌리고, 씨에이엠피는 가위로 자르며, 인산화된 단백질은 지우개로 지운다. 인산화와 탈인산화가 단백질의 활성을 조절한다. 중계 분자를 비활성화해 기존 신호를 끝내야 세포가 새 신호에 다시 반응할 수 있다. GTP 가수분해는 G단백질을 끄고, 탈인산화효소는 인산화된 단백질을 꺼서 kinase를 다시 쓸 수 있게 한다.
- 카드 7:
  - B0-146: 신호의 종료에서 인산화 단백질 수준의 종료 기작은? → 단백질 탈인산화효소에 의한 탈인산화
  - B0-214: 단백질 탈인산화효소(protein phosphatase)의 역할은? → 인산기를 제거해 신호를 끄고 kinase를 재사용 가능하게 함
  - S-SG-12: 신호 종결 3층(G단백질 / cAMP / 인산화 단백질)은? → GTP 가수분해 / PDE로 AMP 전환 / 탈인산화효소
  - B0-89: 단백질 인산화와 탈인산화는 무엇을 조절하는 데 널리 쓰이는가? → 단백질의 활성
  - B0-90: 인산화의 반대 과정은? → 탈인산화
  - B0-143: 세포가 다시 새 신호에 반응할 수 있게 하려면 무엇이 필요하나? → 중계분자들의 불활성화와 신호 종결
  - X-SG-17: GTP 가수분해가 끄는 것은? 탈인산화효소가 끄는 것은? → G단백질 / 인산화된 단백질(kinase 재사용 가능)

### s9
- obj: 칩이 손에 붙어 뺑뺑이 도는 쥐
- fact: Ras 돌연변이 — GTP 가수분해를 못 해 늘 켜짐 → 멈추지 않는 증식 → 암(인간 암의 약 30%)
- hook: 붙은 칩 = 못 끈다
- say: 앞쪽의 또 다른 쥐는 끈적한 시럽 때문에 칩이 손에 붙어 뒤집지 못한 채 뺑뺑이를 돌고 있다. 라스 돌연변이다. 지티피를 가수분해하지 못해 성장 신호가 없어도 활성 상태를 유지하므로 증식 신호가 멈추지 않고 암으로 이어진다. 변형된 RTK도 신호 분자 없이 활성화되어 여러 경로를 동시에 켤 수 있어 암과 연결된다. 사람 암의 약 삼십 퍼센트에서 라스 돌연변이가 나타난다.
- 카드 2:
  - B0-57: 변형된 RTK가 암과 관련되는 이유는? → 신호분자가 없어도 활성화되어 여러 신호전달 경로를 켤 수 있기 때문
  - F1-134: 돌연변이 Ras가 암을 유발하는 이유는? → 성장 신호가 없어도 계속 활성 상태를 유지할 수 있기 때문
