## 지킬 것
- 진자 시계 = 동방결절의 위치 단서(정수리 관 곁 + 혼자 흔들림 = 자동성 · 덱 약속에서 진자 = 박동). 이름 고리를 얹을 때 시계를 잃지 말 것.
- 노란 반달 문(반달판막)과 날개 셋 / 날개 둘 뚜껑문(삼첨판 / 이첨판) — 글자 뜻이 그대로 보이는 ④ 고리.
- 회청(산소 적음) / 진홍(산소 많음) 두 빛깔 + 지붕의 폐 풍선 + 큰 사람(온몸) — 폐순환 · 체순환 사슬이 끊김 없이 이어짐(ㄷ ○).
- 큰 사람이 높이 든 큰 물병 / 작은 플라스크 — 심박출량 / 일회박출량의 크기 대비 사건(웃는 얼굴 포함).
- 유턴 금지로 역류를 막는 발상은 살리되, 기호(D3)를 사건 속 물건으로 바꾸는 일은 해야 한다.

## 과학 의심
- s3 오른쪽 이첨판의 문짝 둘이 아래로 늘어진 판막 첨(尖)이 아니라 가로 걸쇠의 네모 문짝으로 그려져 있어 방실판막의 모양(심실 쪽으로 늘어진 첨 · 건삭)이 왼쪽 삼첨판과 같은 문법이 아니다.
- s13 네 판막이 동시에 모두 열려 있는 것은 실제 박동과 다르다(그림 안에서 글이 단서를 주나 대장 L46a-01 이 이미 지적함).
- s1 심방이 심실보다 작다는 것은 맞으나 그림의 위 · 아래 방 높이 차가 작아 「심방은 작다」가 약하다(사실 오류는 아님).
- s4 · s7 반달판막이 심실 바깥 옆벽의 문으로 그려져 있다 — 실제로는 심실 위쪽 출구(동맥 기시부)이므로 도해적 단순화.

## 총평
가장 급한 것은 동방결절과 방실결절의 이름 고리 없음(N)이다 — 시계와 신호등은 하는 일만 나른다. 둘째는 판막 사건의 도해화(표지판 · 흰 화살표 D3 와 네 문이 모두 열린 T)이고, 셋째는 s13 · s14 · s6 의 수 · 시간(70 mL · 1분 · 5배 · 결손)이 글에만 있는 M 이다.
