## ㄷ

(ㄴ 표를 다 쓴 뒤 ㄷ 폴더를 열었다. ㄷ 의 그림은 ㄴ 과 같은 파일이다.)

| 정거장 | 사실 낱 | 판정 | 근거 |
|---|---|---|---|
| s1 | 판구조 — 판(땅덩이)이 용암 위에 떠다님 | ○ | 층층 바위 테를 두른 두꺼운 판 조각 셋 이상이 주황 용암 위에 떠 있음 |
| s1 | 판 = 지각 + 맨틀 윗부분 | △ | 두꺼운 층 단면은 보이나 지각과 맨틀 윗부분의 구분은 그림에 없음 |
| s1 | 맨틀 운동 = 대륙이동 | ○ | 판 둘레 용암의 둥근 소용돌이가 판을 움직이는 흐름으로 읽힘(소용돌이 직접 센 수 5 안팎) |
| s2 | 가장자리에 산맥을 두른 거대한 판 하나 | ○ | 한 덩어리 판 둘레에 봉우리 7~8 개가 솟음 |
| s2 | 마른 옛 바다 띠(맞붙은 이음매) → 얕은 바다 소멸 | ○ | 판을 가로지르는 회녹색 띠에 화석이 깔림 · 양옆은 마른 땅 |
| s2 | 내륙 건조(쩍쩍 갈라진 사막) | ○ | 한가운데 베이지색 갈라진 땅 |
| s2 | 비스듬한 긴 금 → 로라시아 · 곤드와나로 갈라짐 | △ | 금은 보이나 두 덩어리의 이름 · 갈라진 뒤의 두 땅은 그림에 없음 |
| s2 | 약 2.5억 년 전 | △ | 수는 그림으로 나르지 못함(그림에 표시 없음) |
| s3 | 옛 바다 띠 바닥의 주검과 뼈(물고기 뼈 · 삼엽충 · 조개 · 소라 · 바랜 산호) | ○ | 물고기 뼈 · 삼엽충 · 소라 · 흰 산호 모두 보임 |
| s3 | 페름기말 대멸종 — 가장 큰 대멸종 | △ | 죽은 바다 생물 무더기는 있으나 「가장 큰」은 그림에 없음 |
| s3 | 해양 동물 약 96 % 멸종 | △ | 수는 그림으로 안 나르어짐 · 살아 있는 바다 생물이 없는 점은 맞음 |
| s4 | 홀로 떨어진 작은 판 위의 캥거루 둘 | ○ | 작은 판 하나에 캥거루 둘(직접 셈 2) |

| s4 | 호주 유대류 vs 다른 대륙 태반류 | △ | 유대류만 있고 맞세울 태반류가 근처에 없음 |
| s5 | 소행성이 불덩이로 떨어짐 → 충돌 구덩이 | ○ | 불꼬리 달린 바위 · 번쩍임 · 구덩이 있음 |
| s5 | 공룡 둘 멸종(목 긴 공룡 · 두 발 공룡) | ○ | 둘 다 × 눈으로 쓰러짐(직접 셈 2) |
