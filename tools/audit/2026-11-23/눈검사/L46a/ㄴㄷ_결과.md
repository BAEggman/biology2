## ㄷ
| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 심방 = 받는 방(위 · 작다) | ○ | 위 두 방이 아래 두 방보다 낮고 작다. 위 왼쪽 방은 정수리 관과 다리 관이 들어오는 방, 위 오른쪽 방은 폐에서 온 진홍 관이 내려오는 방 |
| s1 | 심실 = 내보내는 방(아래 · 크다) | ○ | 아래 두 방이 크고, 아래 왼쪽 방은 반달 문으로 회청 관이, 아래 오른쪽 방은 반달 문으로 진홍 관이 나간다 |
| s1 | 2심방 2심실 | ○ | 직접 센 수: 위 방 2 · 아래 방 2 |
| s2 | 좌심실 벽이 가장 두껍다 | ○ | 오른쪽 아래 방만 갈색 두꺼운 벽, 왼쪽 아래 방은 얇은 연한 벽 |
| s2 | 일회박출량은 좌우가 같다 | ✕ | 좌우 방 크기 · 양 같음을 나르는 물건이 없다 (s13 플라스크는 오른쪽 사람 손에만 하나) |
| s3 | 방실판막 = 심방과 심실 사이 | ○ | 위 방과 아래 방 사이 바닥에 뚜껑문 두 벌 |
| s3 | 심장 오른쪽(그림 왼쪽) 날개 셋 = 삼첨판 | ○ | 직접 센 수: 그림 왼쪽 판자 3 (아래 방 쪽으로 늘어져 열림) |
| s3 | 심장 왼쪽(그림 오른쪽) 날개 둘 = 이첨판(승모판) | ○ | 직접 센 수: 그림 오른쪽 판자 2 |
| s4 | 반달판막 = 심실과 동맥 사이 | ○ | 아래 두 방 바깥벽의 문이 동맥(관)으로 나가는 자리 |
| s4 | 우심실–폐동맥판 | ○ | 왼쪽 문 · 반달 노란 조각(곧은 지름 · 곰보 자국 보임)이 회청 관 출구에 있다 |
| s4 | 좌심실–대동맥판 | ○ | 오른쪽 문 · 반달 노란 조각이 진홍 관 출구에 있다. 직접 센 문 2 · 반달 2 |
| s5 | 판막의 일 = 역류 막기 | ○ | 문 앞 유턴 금지 표지판(빨간 테 · 사선 · 아래로 되돌아오는 화살) |
| s5 | 문 넷 모두 한쪽으로만 열린다 | △ | 표지판은 반달 문 앞 2개뿐. 방실판막(뚜껑문)에는 표지판 · 방향 표시가 없어 「넷」은 그림에서 둘만 나른다 |
| s6 | 통벽으로 좌우가 섞이지 않는다 | ○ | 지붕 밑에서 바닥까지 이어진 세로 벽, 문 없음, 왼쪽 회청 · 오른쪽 진홍 |
| s6 | 오른 → 왼 심장은 폐를 거쳐 | ○ (끊김 없음) | 왼쪽 아래 방 문 → 회청 관 → 지붕 폐 → 진홍 관 → 오른쪽 위 방, 화살 방향 일치 |
| s6 | 왼 → 오른은 온몸을 거쳐 | ○ (끊김 없음) | 오른쪽 아래 문 → 진홍 관 → 사람 → 회청 관(머리 · 다리) → 왼쪽 위 방 (사람 몸 안 연결은 암시) |
| s6 | 벽에 구멍 = 중격 결손 | ✕ | 벽에 구멍이 그려지지 않았고 닫힌 벽만 보인다 (결손을 나르는 물건 없음) |
| s7 | 폐순환 사슬 우심실 → 폐동맥 | ○ | 왼쪽 아래 방 문에서 나가는 회청 관, 화살 ← 후 ↑ |
| s7 | → 폐 (O₂ · CO₂ 교환) | ○ | 관이 왼쪽 폐에 닿고 흰 방울이 들어가며 오른쪽 폐에서 어두운 연기 방울이 나간다 |
| s7 | → 폐정맥 → 좌심방 | ○ | 오른쪽 폐에서 진홍 관이 내려와 오른쪽 위 방 천장으로 열린다. 관이 반달 문 앞을 지난다는 서술은 맞다 |
| s7 | 방향 · 위치 | ○ | 폐는 집 지붕 위, 폐에 들어가는 쪽 회청 · 나오는 쪽 진홍 |
| s8 | 체순환 사슬 좌심실 → 대동맥 | ○ | 오른쪽 아래 문 뒤에서 나온 진홍 관이 사람 가슴에 닿고 문은 우리 쪽으로 열림 |
| s8 | → 온몸(물질 교환) | △ | 사람이 몸을 나타내나 물질 교환 동작은 없다. 가슴에서 진홍 관이 끝나고 머리 · 다리 회청 관으로 이어지는 속은 보이지 않음 |
| s8 | → 대정맥 → 우심방 | ○ | 사람 머리 · 다리 쪽 회청 관이 왼쪽 위 방으로 들어간다 |
| s9 | 상대정맥(머리 · 목 · 팔) → 우심방 | ○ | 정수리에 꽂힌 회청 관이 하늘을 건너 지붕을 뚫고 왼쪽 위 방 천장으로 열림 (팔은 그려지지 않음) |
| s9 | 하대정맥(몸통 · 하체) → 우심방 | ○ | 다리에서 나온 회청 관이 땅 밑 → 왼쪽 벽 위로 → 왼쪽 위 방 벽 창으로 |
| s9 | 둘 다 같은 방으로 | ○ | 직접 센 수: 회청 관 2, 모두 왼쪽 위 방에 닿음 |
| s10 | 동맥 = 나가는 관 | ○ | 반달 문에서 나가는 관 둘(회청 · 진홍) |
| s10 | 정맥 = 들어오는 관 | ○ | 머리 · 다리 관, 폐에서 내려오는 진홍 관 모두 방으로 들어옴 |
| s10 | 폐동맥엔 산소가 적다 | ○ | 폐로 가는 관이 회청 (폐에서 진홍으로 바뀜). 담긴 것과 나오는 것이 같다 |
| s10 | 빛깔이 바뀌는 자리 둘 | ○ | 폐(회청 → 진홍) · 사람(진홍 → 회청) |
| s11 | 동방결절 = 상대정맥이 우심방에 닿는 곳 | ○ | 시계가 정수리 관 입구 바로 곁 |
| s11 | 스스로 박동(자동성) | △ | 태엽 감는 사람이 없다는 것은 그림에서 부재로만 암시. 흔들리는 진자와 소리선은 보임 |
| s11 | 체온 1 ℃↑ → 분당 약 10회↑ | △ | 온도계는 있으나 눈금 · 수 · 증가 표시가 없다 (「약 10회」 보이지 않음) |
| s12 | 방실결절 = 박동 신호를 늦춤 | ○ | 빨간불만 켠 신호등 (정지 · 지연) |
| s12 | 심방 피가 먼저 심실을 채운다 | △ | 신호등 아래 뚜껑문(날개 셋)은 열려 있으나 「먼저 채운다」는 순서 · 피 흐름은 그림에 없다 |
| s12 | 위치 | ○ | 위 왼쪽 방 오른쪽 벽, 아래 왼쪽 방 뚜껑문 위. 신호등이 칸막이(통벽) 아래쪽에 있음 |
| s13 | 일회박출량 = 한 번 수축에 내보내는 피 | ○ | 진홍 관 끝 바로 곁 작은 삼각 플라스크에 진홍 물 (담긴 것과 나오는 것 같음). 눈금은 몇 줄 있으나 수 없음 |
| s13 | 휴식 때 약 70 mL | ✕ | 용량 · 수 표시 없음 (플라스크의 눈금은 숫자 없는 몇 줄) |
| s14 | 심박출량 = 좌심실이 1분에 내보내는 피 | △ | 큰 물병 · 진홍 물 · 반달 문 쪽 손바닥은 보이나 「1분」을 나르는 물건(시계 등)이 없다 |
| s14 | 72회 × 70 mL ≈ 5 L | ✕ | 72도 · 곱셈도 그림에 없다. 물병이 플라스크보다 훨씬 큰 크기 대비만 보인다 |
| s14 | 운동 때 약 5배 | ✕ | 운동 · 배수를 나르는 물건 없음 |
