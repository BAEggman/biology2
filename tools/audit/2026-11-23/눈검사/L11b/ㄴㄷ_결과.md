## ㄷ

모자 등(램프) 수는 직접 센 값: 주황 3 · 노랑 1(통째로 보이는 하나) · 파랑 2. 판의 발 그림은 파란 5발(왼쪽) · 주황 3발(오른쪽).

| 정거장 | 사실 낱 | 판정 | 근거 |
|---|---|---|---|
| s1 | Pol III = 등 셋 주황 인부, 본선, 주 복제 | ○ | 주황 모자 등 3개, 본선 널길에서 작업 |
| s1 | Pol I = 등 하나 노랑 인부, 프라이머 교체 | ○ | 노랑 모자 등 1개, 은못을 뽑고 나무못으로 갈아 끼움 |
| s1 | Pol II = 등 둘 파랑 인부, 손상 대응, 곁길 | ○ | 파랑 모자 등 2개, 휘어진 곁길에서 비뚤어진 붉은 조각을 다룸 |
| s2 | 파란 5발 → 주황 3발 | ○ | 판 위 왼쪽 파란 5발, 오른쪽 주황 3발 직접 셈 |
| s2 | 망치(+) 화살표가 5에서 3 쪽(오른쪽)으로 새 가닥 합성 | ○ | 초록 망치 + 화살표가 파란 5발 아래서 주황 3발 쪽으로 감 |
| s2 | 기존 3′-OH 에 붙임 | △ | 「붙인다」는 망치 + 로 보이나 기존 가닥 끝 · 3′-OH 를 가리키는 물건은 없음 |
| s3 | 은못 = RNA 프라이머 | ○ | 노랑 인부 작업대 오른쪽에 반짝이는 은못 셋(하나는 렌치가 물고 둘은 서 있음) |
| s3 | 노랑 인부의 「집게」 | △ | 은못을 잡은 것은 집게가 아니라 렌치(스패너)로 그려짐 |
| s3 | 프라이메이스가 만든 | ✕ | 못을 만드는 물건 · 동작이 그림에 없음 |
| s3 | DNA 합성 출발 3′-OH 제공 | ✕ | 못이 출발점을 준다는 것을 나르는 물건 없음 |
| s4 | 이미 교체된 나무못이 노랑 인부 왼쪽에 박혀 있음 | ○ | 왼쪽 널판에 나무못이 선 채 박혀 있음 |
| s4 | 손에 든 나무못을 빈 구멍에 끼우려 함 | ○ | 뾰족한 나무못을 쥔 손 아래 빈 구멍(타원) 하나 |
| s4 | 교체 전 = RNA 프라이머 자리, Pol I 이 채움 | △ | 이 정거장 상자 안에는 은못이 없고 오른쪽 s3 에 있음. 빈 구멍이 그 자리라는 연결은 짐작해야 함 |
| s5 | 등 셋 주황 인부(Pol III) | ○ | 모자에 램프 3개 |
| s5 | 곁에 큰 망치 | ○ | 널판 위에 큰 나무자루 쇠망치가 놓여 있음(쓰지는 않고 누워 있음) |
| s5 | 선도 · 지연 가닥 모두 5′→3′ 연장 | △ | 판에 망치 5→3 화살표는 한 줄뿐. 선도 · 지연 두 가닥을 가르는 그림은 없음 |
| s6 | 주황 인부가 집게로 붉은 못을 뽑음 | ○ | 집게가 판자 끝의 붉은 막대(못)를 물고 있음 |
| s6 | 판자 끝에 잘못 끼워진 | △ | 붉은 것이 판자 끝에 있고 색이 달라 눈에는 띄나, 「잘못 들어간 것」이라는 표지는 없음 |
| s6 | 3′→5′ 되짚음(주황 판 아랫줄) | ○ | 판 아랫줄 갈색 화살표가 주황 3발(오른쪽)에서 파란 5발(왼쪽)로, 오른쪽 끝에 집게 + 붉은 조각 아이콘 |
| s7 | 노랑 인부가 은못 대열의 첫 못을 뽑음 | ○ | 렌치가 맨 왼쪽 은못 머리를 물고 들어올림(도구는 렌치) |

| s7 | 노랑 판 맨 아랫줄이 5에서 3 | ○ | 파란 화살표가 오른쪽으로, 은못 + 갈고리 아이콘이 왼쪽 시작에 있음 |
| s7 | 다음 절편 5′ 쪽 프라이머 | △ | 「다음 절편」의 경계 · 5′ 쪽이라는 표시는 없음 |
| s8 | 렌치 바로 왼쪽 손이 나무못을 빈자리에 끼움 | ○ | 한 손은 렌치, 다른 손은 나무못을 빈 구멍 위에 듦 |
| s8 | 노랑 판 맨 위 망치 길 5에서 3 | ○ | 초록 망치 화살표가 파란 5발에서 주황 3발 쪽 |
| s8 | 닉의 위치가 이동 | △ | 닉(틈)이 그려져 있지 않음. 뽑기와 끼우기가 나란한 것으로 암시만 |
| s9 | 한 등 모자 노랑 작업대 | ○ | 노랑 모자 등 하나 |

| s9 | 은못 뽑개 줄 | △ | 아래 줄 아이콘은 은못 둘과 주황 꺾인 막대인데 너무 작아 못뽑개로 바로 읽히지 않음 |
| s9 | 방향: 합성 5→3 · 교정 3→5 · 절제 5→3 | ○ | 화살표가 오른쪽 · 왼쪽 · 오른쪽 |
| s10 | 몸통이 빨간 긴 라이터가 따로 있음 | ○ | 노랑 인부 판 오른쪽 아래에 불꽃 붙은 빨간 긴 라이터 |
| s10 | 확대 그림의 염기가 모두 꽂힘 | ○ | 당 오각형 4개마다 위에 염기 사각형이 하나씩 붙음(4개 모두) |
| s10 | 골격 결합 하나만 끊김 | ○ | 오각형 사이 파란 원(인산) 이음 하나가 끊겨 주황 점선 불꽃이 튐(끊김 1곳) |
| s10 | DNA 라이게이스가 닉을 잇는다 | 어긋남 | 담긴 것은 끊긴 자리에 불꽃을 대는 모양(태움 · 지짐으로 읽힘)이고, 나와야 할 뜻은 이음이라 반대로 읽힘 |
