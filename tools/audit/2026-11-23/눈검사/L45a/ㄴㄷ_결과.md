# L45a 눈 검사 — 독자 ㄴㄷ

## ㄴ
| 용어 | 정거장 | 그림의 무엇이 | 까닭 | 설명 |
|---|---|---|---|---|
| 틸라코이드막 | s6 | 팬케이크 모양 원반 가장자리의 주황 테두리(막처럼 두른 층) | 생김새가 그 글자 | 원반 하나하나를 감싼 얇은 주황 가장자리를 막으로 본다 |
| 글리코젠 | 없음 | 그림에서 이어지는 물건이 보이지 않음 | 모름 | 동물의 저장 다당류 같은 물건이 없다(엽록체 장면이라 가짜로 판단) |
| 수크로스 | s7 | 바닥의 동전(알갱이) 무더기, 밖으로 나가는 바퀴 상자(s10)와 이어 짐작 | 하는 일로 짐작 | 알갱이 더미가 만든 당이고 수레가 밖으로 실어 나르는 것으로 짐작 |
| 스트로마 | s5 | 원반 더미 둘레를 채운 짙은 초록 바탕과 바닥 회색 깔개 | 남은 것이라서 | 원반 더미를 뺀 나머지 안쪽 공간 |
| H2O2 | 없음 | 하얀 물방울(s8)은 보이나 과산화 표시가 될 물건은 없음 | 모름 | 흰 방울은 물처럼 보이고 이 용어로 이어지는 것은 없다 |
| 관다발 | s3 | 빨강 · 파랑 · 노랑 관을 고무줄로 묶은 다발 | 이름의 뜻 그대로 | 관이 다발로 묶여 있어 그대로 읽힌다 |
| 스펙트럼 | s7 | 붉은 렌즈 망원경(빛을 갈라 보는 기구) · 빛기둥 | 하는 일로 짐작 | 렌즈로 빛을 보는 기구라서 짐작. 유리판(s9)일 수도 있다 |
| 틸라코이드 | s6 | 팬케이크처럼 쌓인 납작한 원반 더미 | 생김새가 그 글자 | 납작한 원반이 쌓인 것이 가장 눈에 띈다 |

## ㄷ
| 정거장 | 사실 낱 | 판정 | 근거 |
|---|---|---|---|
| s1 | 빛에너지 → 화학에너지(유기물) | ○ | 하늘의 햇살 기둥이 도시락(샌드위치)에 닿는다 |
| s1 | 잎(엽육세포) → 엽록체로 좁혀 들어간다 | ○ | 왼쪽 잎 널(세포 단면)과 오른쪽 꼬투리(속 단면)가 나란히 있고 크기가 커지는 순서로 읽힌다. 화살표는 없음 |
| s12 | 독립영양 = CO₂ · 무기물로 제 유기물 | △ | 물뿌리개(물=무기물)와 햇살이 도시락으로 들어가고 샌드위치가 담겼다. CO₂ 를 나르는 물건은 없음 |
| s12 | 종속영양 = 남이 만든 유기물을 먹음 | ○ | 빨간 셔츠 남자가 빈 접시를 들고 도시락 샌드위치를 집어 든다 |
| s2 | 광합성 자리 = 엽육세포(엽록체 빽빽) | ○ | 윗층 세포마다 초록 알갱이가 빽빽 |
| s2 | 책상조직(위 · 촘촘) | ○ | 위는 기둥 꼴 세포가 촘촘히 서 있음 |
| s2 | 해면조직(아래 · 공기층) | ○ | 아래는 둥근 세포가 성기게 놓이고 사이가 비어 있음 |
| s3 | 관다발 = 물관 + 체관 · 묶음이 이름 | △ | 빨강 · 파랑 · 노랑 관을 고무줄 둘로 묶은 다발이 보임(묶음 ○). 어느 것이 물관이고 체관인지는 빛깔로 구별되지 않음(파랑 · 빨강 · 노랑 세 빛깔) |
| s4 | 기공(공변세포 둘) | ○ | 콩팥 모양 둘이 마주 보고 가운데 틈 |
| s4 | CO₂ 들고(어두운 방울이 안으로) | ○ | 어두운 방울이 틈 위(잎 안쪽)에 있음. 들어가는 방향은 방울 위치로만 짐작 |
| s4 | O₂ · 수증기 난다(흰 방울) | △ | 흰 방울이 틈 아래 밖에 있다. O₂ 와 수증기를 따로 나누지는 못함 |
| s4 | 주로 아랫면 | ○ | 기공이 잎 널 아랫면에 있음 |
| s5 | 엽록체 이중막 — 외막 · 내막 | ○ | 꼬투리 벽에 담이 둘(바깥 · 안) 겹쳐 있음. 어느 것이 외막 · 내막인지는 위치로만 앎 |
| s6 | 그라나 = 틸라코이드를 쌓은 것 | ○ | 납작한 쿠션(원반)이 무더기로 쌓임. 무더기 4개 |
| s6 | 막을 많이 담아 빛반응 장치를 많이 박는다 | ○ | 쿠션마다 자주 머리가 박힘 |
| s7 | 스트로마 = 담 안 액체(펴 깐 것) | △ | 바닥 회색 깔개가 보이나 액체처럼 보이지 않고 깔개로 읽힘 |
| s7 | 캘빈 회로(루비스코)는 여기서 돈다 | △ | 루비빛 스코프가 깔개 위에 있음(루비스코 말놀이). 회로가 돈다는 동작은 없고 기름방울만 떨어짐 |
| s8 | 루멘 = 틸라코이드 안쪽 빈 공간 | ○ | 맨 위 쿠션이 갈라져 속이 비어 있음 |
| s8 | 물 분해로 난 O₂ 가 막에서 나와 | △ | 흰 방울이 갈라진 쿠션에서 솟아 보임. 물 분해 동작은 없음 |
| s8 | 세포 밖으로(담 둘을 지나 나간다) | ○ | 흰 방울이 쿠션 위 → 담 위 → 꼬투리 벽 바깥 순서로 셋 있음. 담 틈 바깥에 닿음 · 끊기지 않음 |
| s9 | 스트로마 라멜라(무더기를 잇는 낱장) | ○ | 청록 판이 무더기 사이를 이음 |
| s9 | PSI(청록)는 안 쌓인 낱장에 | ○ | 청록 판이 쌓이지 않은 낱장 |
| s9 | PSII(주황)는 쌓인 그라나에 | ○ | 무더기 쿠션 가장자리가 주황 |
| s10 | 산물 G3P 는 엽록체 안에선 전분으로 저장 | △ | 깔개 위 알갱이 더미(곡식 · 동전 같음). 전분인지는 짐작 |
| s10 | 다른 조직으로는 자당(수크로스)으로 수송 | ○ | 바퀴 상자가 꼬투리 밖 문 앞으로 굴러 나감. 상자는 비어 있어 담긴 것은 안 보임(어긋남은 아님) |
| s11 | 자체 원형 DNA | ○ | 제 꼬리를 문 고리 모양 뱀 |
| s11 | 70S 리보솜 · 스스로 분열 | △ | 보라 덩이 둘(큰 알 + 작은 알이 붙은 짝)이 있다. 70S 와 분열은 짝 모양으로만 짐작 |
| s11 | 내부공생의 자취 | ✕ | 내부공생을 나르는 물건이 보이지 않음 |

의심: 없음(s4 어두운 방울 = CO₂ 와 흰 방울 = O₂ + 수증기 구별은 사실이 아니라 그림 문제).
