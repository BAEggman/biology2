## ㄷ

| 정거장 | 사실 낱 | 판정 | 근거 |
|---|---|---|---|
| s1 | 꺾인 뒤 수로가 둑 위 운하로 이어진다 | ○ | 네모 나무 수로가 왼쪽에서 꺾여 돌둑 위로 이어지고 오른쪽 푸른 운하로 닿는다 |
| s1 | 네모 수로 = 오줌길 | ○ | 물이 찬 네모 통 |
| s2 | 둘째 톱니 기계 | △ | 톱니바퀴는 세 개(둘 위 · 하나 아래)인 기계 한 대. 「둘째」 표지는 안 보임 |
| s2 | 자루 하나 · 염소 하나 | ○ | 미끄럼틀에 흰 자루 1 · 흰 염소 1 |
| s2 | 못에 걸린 칼에 가위표 | ○ | 못 아래 칼 한 자루에 나무 X 가 덮여 있음 |
| s2 | NCC — Na⁺-Cl⁻ 1:1 · K⁺ 없음 | △ | 자루:염소 = 1:1 로 센 수는 맞음. K⁺(성냥)가 이 칸에 없음은 맞으나 「없음」은 보이기 어려움 |
| s3 | 자물쇠에 매달린 티백 | ○ | 금빛 자물쇠 끈 끝에 티백 1 |
| s3 | 티아지드가 NCC를 막는다 | ○ | 자물쇠가 톱니 기계 손잡이를 잠금 |
| s3 | 루프 = 굵은 상행지 · 티아지드 = 원위 | ✕ | 루프(굵은 상행지)를 나타내는 물건이 이 그림에 없음. 어긋남은 없음 |
| s4 | 꺾인 뒤도 역청 벽 | △ | 오른쪽 수로 벽이 투명한 판처럼 보임. 역청(검은) 벽은 아님 |
| s4 | 물이 오른쪽으로 갈수록 옅다 | △ | 오른쪽 물이 조금 옅어 보이나 뚜렷한 층차는 아님 |
| s4 | 염은 되찾고 물은 못 나감 → 더 묽어짐 | △ | 앞 칸(s2 · s3)의 염 되찾기와 이어지는 동작이 이 칸 안에는 없음 |
| s5 | 버튼 넷 상자 | ○ | 보라 · 빨강 · 초록 · 하늘 네 단추 |
| s5 | 줄 둘이 나간다 | 어긋남 | 상자에서 오른쪽으로 나가는 줄은 셋(뜰채 · 도르래 둘). 위아래로 내려가는 줄도 있음 |
| s5 | PTH — 한 호르몬 · 두 자리에서 반대로 | △ | 한 상자에서 뜰채(내림)와 바구니(오름) 두 곳으로 줄이 나감. 「반대」는 s6 · s7 로 이어짐 |
| s6 | 왼 줄 — 빈 뜰채가 물 밖에 들린다 | ○ | 줄에 걸린 뜰채가 물 위에서 비어 물방울만 떨어짐 |
| s6 | 성냥이 떠내려간다 | △ | 성냥 6개가 떠 있으나 흘러가는 방향은 안 보임 |
| s6 | 인산 재흡수 ↓ → 오줌으로 | △ | 성냥(인산) 재흡수가 줄었다는 것은 빈 뜰채로 읽히나 근위세뇨관 표지는 없음 |
| s7 | 오른 줄 — 자갈 바구니를 가득 들어 올린다 | ○ | 줄에 매달린 바구니에 회색 돌이 가득 |
| s7 | Ca²⁺ 재흡수 ↑ — 칼슘 올리고 인산 버림 | △ | 바구니가 매달려 올라간 모양은 있으나 자갈이 칼슘인지는 안 보임. 인산 버림은 s6 와 대응 |
| s8 | 첫 칸 · 왕관 주인 · 뜰채로 푸른 운하의 흰 소금 자루를 건진다 | ○ | 왕관 쓴 사람이 그물로 흰 자루를 물에서 올림. 위로 향한 파란 화살표 |
| s8 | 허리에 쇠 열쇠 | ○ | 허리띠에 열쇠 꾸러미 |
| s8 | 알도스테론은 ENaC와 펌프를 늘린다 | △ | 열쇠가 알도스테론을 가리키는지는 그림만으로 알 수 없음. 늘어남(수 · 크기)은 안 보임 |
| s9 | 같은 칸 · 붉은 투구 로마 병사 | ○ | 같은 아치 안 붉은 깃 투구 병사 |
| s9 | 단검을 푸른 운하 쪽으로 겨눈다 | △ | 단검 끝이 아래(바닥 · 운하 쪽)로 향하고 갈색 아래 화살표가 운하로 감. 칼끝에서 K 모양 조각이 떨어짐 |
| s9 | ROMK K⁺ 분비 · 알도스테론 촉진 | △ | 운하로 나가는 방향 화살표는 맞음. 알도스테론 표시 없음 |
| s13 | 액자 — 왕관 주인의 둥근 뜰채에 금색 자물쇠 · 텅 빔 | ○ | 액자 속 왕관 사람의 둥근 뜰채에 금색 자물쇠가 걸리고 안은 빔 |
| s13 | 소금 자루 둘은 밖 물에 떠 있다 | ○ | 흰 자루 2 가 뜰채 밖 물에 떠 있음 |
| s13 | 로마 병사는 칼을 허리에 찬 채 똑바로 서 있다 | ○ | 서서 칼은 허리에 참 |
| s13 | ENaC 차단 → Na⁺ ↓ · K⁺ 분비 ↓ | ○ | 막힌 뜰채와 칼을 안 겨눈 병사로 이어짐 |
| s10 | 둘째 칸 · 깨진 알을 입은 일꾼 | ○ | 금빛 아치 안 알껍질 입은 사람 |
| s10 | 든 손 위 분필 · 붉은 핏줄 | ○ | 손 위로 분필 2 가 오르고 위 띠에 붉은 핏줄 |
| s10 | 발밑 운하에 레몬 | ○ | 레몬 반쪽이 운하 위에 떠 있음 |
| s10 | α 사이세포 H⁺ 관강 분비 · HCO₃⁻ 혈액 쪽 | ○ | 레몬(산)은 아래 운하(관강)로 · 분필은 위 핏줄 쪽으로. 화살표 방향 일치 |
| s11 | 셋째 칸 · 올이 풀린 베옷 | ○ | 보라 아치 안 해진 옷 |
| s11 | 든 손 위 레몬 · 붉은 핏줄 · 발밑 분필 | ○ | 손 위 레몬 2 가 오르고 운하에 분필 2 |
| s11 | β 사이세포 HCO₃⁻ 관강 분비 · H⁺ 혈액 쪽 | ○ | 분필은 아래 운하로 · 레몬은 위로. s10 과 반대로 맞음 |
| s12 | 세 칸 나란히 · 붉은 핏줄 위 · 푸른 운하 아래 | ○ | 왕관 · 알껍질 · 베옷 순 세 아치, 위에 붉은 띠, 아래 운하 |
| s12 | 주세포는 Na⁺·K⁺·물 | △ | 소금 자루(Na⁺) · 병사(K⁺)는 있으나 물을 나르는 물건이 없음 |
| s12 | 알과 베 사이세포는 산·염기 조절 분담 | ○ | 두 칸이 레몬과 분필을 서로 반대로 나름 |
