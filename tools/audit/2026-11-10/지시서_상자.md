# 상자 고침 지시서

## 무엇을 하는가
그림 암기 교재(Sketchy 방식)의 「과(lesson)」는 그림 한 장(2048×1144)과 「정거장」 여러 개다. 정거장마다 `obj`(그림 속 물건)와 그 물건을 가리키는 **상자**(`box` = [x,y,w,h] 또는 그 목록)가 있다.
투어에서는 상자 자리를 밝혀 보여 주고, 시험에서는 상자 자리만 가리킨 채 「이 물건은 무엇을 나르나」를 묻는다. 그래서 상자가 물건을 자르거나(BOX-CUT) · 물건 하나를 빠뜨리거나(BOX-MISS) · 너무 커서 이웃 물건까지 싸면(BOX-LOOSE) 학습자가 틀린 것을 본다.
1차 감사가 상자 지적을 냈다. 너는 지적마다 **그림을 직접 보고** 상자를 고친다. 감사원이 틀렸을 수 있다 — 지금 상자가 괜찮으면 그대로 둔다.

## 읽을 것 (AUD = /tmp/claude-0/-home-claude/adba3dea-fd2a-5075-a226-d8c1b6963879/scratchpad/audit)
- 네 묶음의 지적: `AUD/in/B<번호>.md`.
- 과의 글과 지금 상자: `AUD/pk/<과ID>.txt`(정거장마다 물건 obj · 사실 · 말 · 「상자: [[x,y,w,h],…]」). 정거장 번호는 0부터.
- 상자를 그림 위에 그려 보는 도구(가장자리 눈금 = 원본 좌표 · 파랑 = 지금 상자 · 빨강 = 새 상자 · 회색 + 번호 = 다른 정거장의 상자):
  `cd /tmp/b2 && python3 tools/audit/boxtry.py <과ID> <정거장> --out AUD/out/tmp/B<번호>_<과ID>_<정거장>.png`            ← 지금 상자 보기
  `cd /tmp/b2 && python3 tools/audit/boxtry.py <과ID> <정거장> '[[x,y,w,h],[x,y,w,h]]' --out AUD/out/tmp/B<번호>_<과ID>_<정거장>_n.png`  ← 새 상자 대 보기
  만든 PNG 를 Read 로 연다. 물건이 화면 밖으로 이어지면 `--pad 300` 처럼 여백을 넓힌다.

## 상자 규칙
1. 상자는 그 정거장의 `obj` 가 말하는 물건을 **통째로** 싼다 — 뜻을 나르는 부분(머리 · 손에 든 것 · 표식 · 끝)이 잘리면 안 된다. 여백은 물건 가장자리에서 10~25px.
2. 이웃 정거장의 물건은 되도록 싸지 않는다. 물건이 붙어 있어 조금 겹치는 것은 괜찮다. 다만 이웃 물건의 **답이 되는 표식**(글자 · 숫자 · 색 조각)이 통째로 들어오면 안 된다.
3. `obj` 가 떨어진 물건 둘 이상을 말하면 상자도 그만큼(한 정거장에 많아야 4개). 넓은 빈 바닥을 한 상자로 싸지 말고 물건별로 나눈다.
4. 길게 이어진 것(밧줄 · 관 · 길)은 뜻이 실린 구간만 싼다 — 전체를 다 싸려다 그림의 절반을 덮지 않는다.
5. 「(틀)」 · 「(되짚기)」처럼 그림 전체를 가리키는 정거장은 상자가 없거나 여럿인 것이 정상이다. BOX-MISS 지적이라도 obj 가 특정 물건을 말하지 않으면 그대로 둔다.
6. 상자는 정수 [x,y,w,h], 그림(2048×1144) 안.
7. 지적 목록에 「⚠ 건너뜀」이라고 적힌 지적은 보지 않는다(그림이 바뀔 자리다).

## 일하는 차례 — 지적마다
① `pk` 에서 그 정거장의 obj 를 읽는다 → ② boxtry 로 지금 상자를 본다 → ③ 지적이 맞는지 판정 → ④ 맞으면 새 상자를 정해 boxtry 로 대 보고, 물건이 다 들어오고 이웃이 덜 들어올 때까지 고친다(많아야 3번) → ⑤ 기록.
**새 상자는 반드시 boxtry 그림을 열어 눈으로 확인한 것만 적는다.** 같은 정거장에 지적이 여럿이면 한 번에 풀어 그 정거장의 상자 전체를 다시 적는다.

## 결과 — 파일 둘 (그 밖의 파일은 절대 고치지 않는다 · 과 원본에 직접 쓰지 않는다)
### 1) `AUD/patch/B<번호>.json`
{"set":[ {"lesson":"L01a","sid":"s6","box":[[1320,640,340,420],[1280,200,300,290]]} , … ]}
- `sid` 는 pk 의 「## 정거장 5  (sid s6)」에서 읽는다. `box` 는 그 정거장의 **상자 전체**(고치지 않는 상자도 함께 다시 적는다). 상자 하나면 [x,y,w,h] 하나만 적어도 된다.
- 다 쓴 뒤 검사: `cd /tmp/b2 && python3 tools/lesson_set.py AUD/patch/B<번호>.json --check` — ✕ 가 없을 때까지. **`--check` 없이 돌리지 않는다.**
### 2) `AUD/patch/B<번호>_판정.jsonl` — 지적마다 한 줄
{"id":"V123","lesson":"L01a","stop":5,"verdict":"고침|그대로|건너뜀|못 고침","why":"한 문장","box":[[…]]}
- 「그대로」 = 감사원이 틀렸거나 지금 상자가 규칙에 맞음. 「못 고침」 = 물건이 그림에 없거나 obj 와 그림이 달라 상자로 못 푼다(무엇이 문제인지 적는다).
python 으로 쓰고 줄마다 json.loads 가 되는지 확인한다.
