# L48c
5. 맨 오른쪽 위 외톨이 큰 덩이 — 오른쪽 세로 절단선(x≈1905~1909)의 검은 부스러기를 지우고, 오른쪽을 둥근 검은 윤곽(굵기 3.2px)으로 이어 닫음(보라 채움은 옆 열을 이음, 바닥 그림자는 오른쪽으로 서서히 옅어지게). 달라진 자리 [1896,876,18,42]. 합격 ○.
   오른쪽 풀밭 검은 낙서(x≈1968~1986, y900~912) — 인페인트로 지움(풀색과 거의 구분 안 됨, 아주 옅은 얼룩 가능). 달라진 자리 [1965,898,24,17]. 합격 ○.
   (원본에 있던 덩이 오른쪽의 매우 옅은 점선 타원 유령 자국은 과제 밖이라 건드리지 않음.) 글/상자 변경 없음.
