# L48b ㄷ 그림 판독 (사실 대조)

본 그림: full.jpg 전체, 확대: s3_1(중심립), s4_1(걸쇠), s5(겹친 대롱·화살표), s8(수축환), s10(칸막이), s11_1(비계). 나머지 sN 크롭은 열지 않음.

## full.jpg 직접 센 값
- 집 2채: 왼쪽 분홍 풍선집(허리 잘록, 위아래 홈 2곳), 오른쪽 나무 창고(앞이 잘려 속이 보임).
- 풍선집: 노란 별 2(양 끝에 하나씩). 별마다 속 빈 원통 2개가 L자로 붙음(눕힌 것 1, 세운 것 1). 원통은 총 4개, 쌍은 2개.
- 대롱은 별마다 방사형으로 열 개 남짓(정확히 세기 어려움). 별 둘의 대롱이 한가운데에서 엇갈려 겹치고, 가운데 수평 대롱 하나는 별에서 별까지 이어진 것처럼 보임.
- 풍선집 걸쇠+짚: 위쪽 금빛 2(별마다 1), 아래쪽 초록 2(별마다 1). 합계 4.
- 가운데 줄 1가닥: 꼰 밧줄, 갈색에 붉은 줄무늬. 위아래 홈 안쪽에 매듭으로 묶임. 밖에는 줄 없음.
- 빨간 멜빵 사람 4명(위 1, 가운데 2, 아래 1). 모두 줄을 손으로 잡고 오르는 자세.
- 흰 화살표 6개(위·가운데·아래 각 좌우 한 쌍). 대롱 옆 공중에 떠 있고 대롱 위에 겹치지는 않음.
- 창고: 별·빛 없음. 벽에서 나온 가로 막대 4개(왼 2, 오른 2)에 걸쇠+짚 4(위 금빛 2, 아래 초록 2).
- 창고: 초록 그물 비계 2(칸막이 양옆), 회색 선반 틀 2, 선반 위 널빤지 실은 수레 4(옆마다 2), 바닥 수레 2. 합계 수레 6.
- 창고: 가운데 널빤지 칸막이 1장. 공중에 떠 있고 약간 기울어 보이며 위쪽과 바닥 사이에 틈이 있음.

## 요약
- ○ 중심 구간: s1·s3·s7의 걸쇠·짚 · s8 줄과 홈 · s10 칸막이와 틈 · s11 비계와 수레.
- 약한 곳(△): 당기는 힘·미끄러짐·자라는 방향 같은 동작 전반(s4 당김, s5 늘림, s6 미끄럼, s9 당기는 동작, s10 바깥으로 자람).
- 안 보이는 것(✕): 골지에서 온다(s11).
- 끊김: s11 수레 → 칸막이. 어긋남: s9 등반가는 줄을 타고 오르는 자세이고, s8 줄 색.
