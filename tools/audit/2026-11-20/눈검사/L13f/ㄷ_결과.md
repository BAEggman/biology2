| s2 | 항원에 붙는다 (오른팔) | ○ | 오른 집게는 벌어진 턱, 그 곁 천의 별과 세균 머리의 별이 맞닿음 |
| s2 | 두 세균이 붙들려 발버둥 | ○ | 두 세균이 벽 앞 허공에서 팔을 들고 다리를 참 (2마리). 두 세균은 생김새가 똑같아 「다른 세균」 구별은 없음 |
| s2 | 불변부위 = 무늬 없는 맨 장대 | ○ | 아래쪽은 별 · 천 없는 맨 장대를 큰 벌 둘이 쥠 |
| s2 | 불변부위가 종류와 하는 일을 정한다 | △ | 이 그림엔 맨 장대뿐. 종류 구분은 다른 정거장의 밑동 모양(굽음 · 두 봉우리 등)에 기대야 함 |
| s3 | IgD = D 명찰 | ○ | 곧은 왼쪽 · 둥근 오른쪽의 흰 D 명찰, 아무 글 없음 |
| s3 | B 세포 겉의 수용체 | △ | 명찰이 벌 가슴(겉)에 붙었으나 이 벌이 B 세포라는 표지는 없음 |
| s3 | 효과기능 뚜렷하지 않다 | ○ | 하품, 깃발 없이 팔을 내림, 탑 벽에 기대 있음 |
| s4 | IgG = 굽은 깃대 밑동 | ○ | 벌들이 든 Y 깃발 밑동이 지팡이 손잡이처럼 굽음 |
| s4 | 혈청에 가장 많다 | ○ | 굽은 깃대 벌이 약 9~10마리로 가장 큰 무리 (M 1 · A 2 · E 1 · D 1) |
| s4 | 혈청(피) = 진홍 호스 | ○ | 진홍 호스에 둥근 유리창 셋, 모두 Y 깃발로 가득. 창 속 깃발은 밑동 굽음이 안 보임 |
| s4 | Y 하나로 다니는 단량체 | ○ | 벌 한 마리가 Y 하나씩 |
| s5 | IgG 가 태반을 지나 태아에게 | ○ | 벌이 굽은 손잡이 깃발을 배 유리에 밀어 넣자 유리가 물결치고 아기가 받음 (방향 산모→태아). 아기 손의 것도 작은 노란 깃발 조각이라 담긴 것 = 나오는 것 |
| s5 | IgG 「만」 | △ | 다른 항체가 막히는 장면 없음, 통과하는 것은 하나뿐 |
| s5 | 자연 수동면역 | △ | 아기가 받는 모습은 있으나 「자연」 · 「수동」을 나르는 물건은 없음 |
| s5 | 기억 없음 | ✕ | 기억을 나르는 물건 · 동작 없음 |
| s6 | IgE 가 비만세포에 붙어 있다 | ○ | 뚱보 경비의 배에 Y 3개가 거꾸로 꽂힘 (수 3, 깃대는 배 · 집게는 바깥) |
| s6 | 알레르겐이 둘을 잇는다 | ○ | 위의 집게 두 개가 가시 달린 노란 꽃가루 공 하나를 함께 물음 (세 번째 Y 는 아래에 비어 있음) |
| s6 | 히스타민 방출 | △ · 어긋남 | 불붙은 성냥 약 5개는 경비가 치켜든 주먹에 쥔 것이고 배(세포 속)에서 나온 것이 아님. 담긴 것과 나오는 것이 다름 |
| s7 | IgE 의 정체 | △ | 세 갈래 갈퀴(갈래 3 확인)는 Y 깃발이 아니라 항체 모양이 아님. E 로 읽히는 것은 s14 의 약속에만 의존 |
| s7 | 기생충(연충) | ○ | 금 간 틈에서 몸을 내민 분홍 벌레 |
| s7 | 방어에 나선다 | ○ | 벌이 갈퀴로 벌레를 틈 쪽으로 밀어붙임 (방향 맞음) |
| s8 | IgM = 두 봉우리 장식 별 바퀴 | ○ | 한가운데 검은 쇠 장식 봉우리 2, 아래 나무 바퀴 2, 벌이 밀어붙임 |
| s8 | Y 다섯 5량체 | ○ | 바큇살 5개, 깃대 밑동이 한가운데서 만남 |
| s8 | 결합 자리 10 | ✕ · 어긋남 | 갈래 끝 깃발은 위 셋 바큇살이 각 2 = 6, 아래 둘은 외가닥 깃발 각 1 = 2, 합 8. 10 아님 |
| s8 | 세균을 엉기게(응집) | ○ | 성난 초록 세균 3마리가 위쪽 끝에 한데 몰려 바큇살에 맞닿음 (수 3 일치) |
| s9 | IgM 이 보체 고전경로를 켠다 | △ | 판자(보)가 비스듬히 밀려 물이 넘치나, 판자는 바큇살 앞에 걸쳐 닿았는지 불분명하고 「보체」를 나르는 물건 없음 |
| s9 | (과 IgG) | ✕ | 이 장면에 굽은 깃대 · IgG 표지 없음 |
| s9 | 고전경로 → 막공격복합체 | ✕ · 끊김 | 판자 · 저수지와 세균 사이를 잇는 물건 없고 복합체(고리 · 무리)를 나르는 물건도 없어 걸음이 끊김 |
| s9 | → 구멍 | ○ | 오른쪽 세균 배에 둥근 구멍 하나 |
| s9 | → 용해 | △ · 어긋남 | 물줄기가 구멍에서 아래로 1, 세균 오른쪽에서 위로 1 = 둘 (사실은 구멍 하나 · 줄기 하나). 세균은 멀쩡히 선 채 화난 얼굴 |
| s10 | IgA = A 사다리 | ○ | A 자 접이 사다리, 똑같은 쌍둥이 벌 2 |
| s10 | 분비형 이량체 | ○ | Y 깃발 2개가 깃대 끝끼리 맞붙고 팔이 양쪽 바깥으로 벌어짐 |
| s10 | J 사슬 | ○ | 두 깃대 끝 사이 작은 J 자 쇠고리 |
| s10 | 눈물 | ○ | 우는 아이의 큰 눈물방울 2, 속에 작은 이음(X 꼴) 깃발 각 1 |

| s10 | 점막 분비물 | △ | 돌 샘 줄기 속에 작은 이음 깃발 3~4개. 샘물이 점막 분비물이라는 표지는 약함 |
| s11 | 항체가 병원체 겉을 덮는다 | △ | 작은 집게 Y 약 9개가 덮은 것은 두건 망토의 두 손뿐, 몸 겉 전체가 아님 (집게가 손을 물고 곧은 깃대는 바깥) |
| s11 | 세포에 붙는 것을 막는다 | ○ | 손이 창틀을 못 잡고 어두운 창 안쪽만 짚음 |

| s12 | 항체가 표지한 병원체 | ○ | 세균 둘레에 작은 집게 Y 5개, 곧은 깃대는 바깥 |
