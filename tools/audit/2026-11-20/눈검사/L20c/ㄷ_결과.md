| s4 | 단일식물의 다른 이름이 장야식물 | △ | s3과 s4에서 같은 국화로 대비해 「긴 밤 식물」이라는 뜻은 암시되지만 「다른 이름」이라는 동일시는 그림으로 나르지 않는다. |
| s5 | 광중단 — 밤 한가운데 짧은 빛이 이어진 밤을 끊는다 | ○ | 긴 검은 칸 한가운데(왼 검정 약 165 · 오른 검정 비슷한 길이) 붉은 세로줄이 하나 가로질러 밤을 둘로 가른다. 국화는 꼭대기 봉오리를 닫았다. |
| s5 | 적색광 | ○ | 끊는 줄이 붉은색이다. |
| s5 | (근적외로 취소) | ✕ | 근적외로 취소하는 물건이 이 정거장에 없다(붉은 줄 하나뿐이며 까만 줄 · 까만 전구가 없다). |
| s6 | 장일(단야)식물은 짧은 밤이라야 | △ | 짧은 밤 띠가 따로 없고 긴 검은 칸을 붉은 줄로 쪼갠 띠 하나뿐이며, 분홍 꽃이 활짝 피었다. 「짧은 밤」은 쪼개진 두 토막으로만 읽힌다. |

| s6 | 무 | ✕ | 없다. |

| s7 | 플로리겐(FT 단백질) | ○ | 흰 편지 봉투를 잎이 받쳐 들고 있어 「잎에서 부치는 전갈」로 읽힌다. FT 단백질이라는 이름 · 분자는 그리지 않았다. |
| s7 | 밤을 재는 곳은 잎 | △ | 봉투가 아래 잎 위에 있어 「잎에서 출발」은 맞지만, 잎에서 밤을 재는 모습(모래시계 · 어둠 등)은 이 그림에 없다. |
| s7 | 피는 곳은 꼭대기 | ○ | 화살표 끝이 활짝 핀 꼭대기 꽃 바로 밑에 닿는다. |
| s7 | 체관을 타고 정단으로 | △ 어긋남 | 방향은 위쪽으로 맞다. 그러나 굵은 점선 화살표가 줄기 안(체관)이 아니라 줄기 바깥 허공 곁에 떠 있어 위치가 「체관을 타고」와 다르다. 화살표 꼬리는 봉투 왼쪽 가장자리 곁에서 시작해 거의 닿는다. |
| s8 | 피토크롬 Pr ↔ Pfr | △ | 두 상태를 오가는 토글이지만 Pr · Pfr 둘을 구별하는 표지(글자 · 색)나 분자는 없다. |
| s8 | 빛으로 왔다 갔다 하는 광가역 스위치 | ○ | 크림색 판에 짧은 놋쇠 토글이 붉은 전구와 까만 전구 사이에 있다. 토글과 전구를 잇는 선은 없다. |

| s9 | (생리적 활성형) | △ | 붉은 전구 밑에서 싹이 자란 화분이 「활성」을 암시하나 Pfr라는 형태 자체는 없다. |

| s10 | 눈에 거의 안 보이는 빛이라 까만 전구 | △ | 유리 속이 새까맣고 빛살이 없어 「꺼진 전구」로 읽힐 수 있다. 열 아지랑이 셋(세 줄기)은 빛보다 열을 떠올리게 한다. 「안 보이는 빛」과 「없는 빛」이 구분되지 않는다. |
| s11 | 마지막에 받은 광질이 결과를 정한다 | ○ | 꼬리표를 직접 보면, 싹튼 쪽(왼 화분 밑)은 왼 까망 · 오른 빨강이라 끝이 빨강이고 잠든 쪽(오른 화분 밑)은 왼 빨강 · 오른 까망이라 끝이 까망이다. 두 꼬리표 모두 반쪽 둘이고 화분과 위치가 맞으며 빨강=적색 · 까망=근적외가 s9 · s10과 같다. 왼→오른이 시간순이라는 약속은 그림에 표시가 없다. |
