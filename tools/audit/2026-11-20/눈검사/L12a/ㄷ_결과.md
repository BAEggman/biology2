# L12a ㄷ 그림 판독 결과

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 위샘 세포가 붓고 | ○ | 통 벽에 박힌 인부 둘(기둥 · 벽돌, 직접 센 수 2)이 각각 병 · 항아리에서 쏟아 붓는다. |
| s1 | 위에서 펩신이 자르고 | ○ | 통 속 뗏목의 요리사 1명이 가위를 들고 구슬 사슬 앞에 있다. |
| s1 | 십이지장에서 이자 효소가 마저 자른다 | △ 어긋남 | 작업대 둘(직접 센 수 2)에 가위 든 사람이 각각 있어 「자른다」는 보인다. 그러나 작업대 둘은 가는 관(기름 웅덩이 · 콜리가 있는 관) 속이 아니라 관 위에 올라선 열린 발판(뒤가 베이지색 바깥)에 놓였다. 사실의 「관 속」과 그림의 「관 위」가 위치가 다르다. 통 → 굵은 관 연결 자체는 보인다. |
| s2 | 주세포(아래쪽 인부) | ○ | 통 벽에 박힌 두 인부 중 아래쪽, 하반신이 흰 그리스 기둥(이오니아식 소용돌이 머리 포함), 파란 티셔츠. 1명. |
| s2 | 펩시노겐을 낸다 | ○ | 같은 인부가 병을 기울여 베이지 반죽을 쏟아 낸다. |
| s3 | 비활성형 | ○ | 쏟는 병이 속이 비치는 초록 유리 병이고 반죽도 베이지색이라, s14에서 켜지면 검어지는 병과 색으로 구분된다(초록 = 꺼짐). |
| s3 | 펩시노겐으로 분비된다 | △ 어긋남 | 병 모양(잘록한 탄산 병)은 맞으나 쏟아지는 것은 「반죽」이다. 같은 펩시노겐이 s14에서는 초록 병 여섯으로 나오는데, 반죽은 휘어진 호스 입구로 들어가 점선으로 뗏목 밑까지 이어질 뿐 병 사슬과 닿지 않는다. 같은 물질이 이 정거장에서는 반죽, s14에서는 병이다. |
| s4 | 벽세포 — 염산을 낸다 | ○ | 위쪽 인부(직접 센 수 1), 하반신이 붉은 벽돌, 흙 항아리를 기울여 맑은 물줄기를 쏟는다. |
| s4 | (주세포는 펩시노겐) | ○ | 대비 대상이 바로 아래의 기둥 인부로, 위치(벽세포 위 · 주세포 아래)와 쏟는 것(물 대 반죽)이 갈린다. |
| s5 | 염산 HCl | ○ | 민짜 흙 항아리에서 맑은 물줄기가 거품 위로 떨어진다. |
| s5 | 벽세포가 H⁺와 Cl⁻를 내보낸다 | △ | 내보내는 동작은 보이나 물줄기는 한 줄기뿐이고 두 이온(H⁺ · Cl⁻)을 가르는 표지는 없다. |
| s14 | 염산이 펩시노겐의 활성 부위를 드러내 펩신으로 | ○ | 물줄기가 떨어지는 자리의 첫 병이 검게 바뀌고 빨간 마개가 튀어 날아간다(마개 = 덮개가 벗겨짐). 병 6개(직접 센 수 6): 검은 병 셋, 넷째는 윗부분만 검음, 끝의 초록 병 둘(다섯째는 넷째 아래에 포개짐)로 설명과 일치. |
| s14 | 펩신이 남은 펩시노겐을 켠다 | ○ | 셋째 검은 병 아래끝과 넷째 병 목이 노란 불꽃을 사이에 두고 닿았고, 넷째 마개가 튀고 닿은 위쪽부터 검어진다. 1→2→3→4→5→6 모든 이음이 닿아 있고 끊김 없다(넷째 · 다섯째는 포개져 닿음). |
| s14 | (양성 되먹임) | △ | 사슬은 한 방향 줄이며, 켜진 펩신이 다시 앞의 일을 돕는 되돌이(고리)는 그려져 있지 않다. 「늘어나며 번진다」는 뜻만 읽힌다. |
| s6 | 내인자 | ○ | 벽돌 인부가 항아리 쥐지 않은 다른 손으로 흰 봉투를 내민다. 봉투가 통 위 선반의 사람 손으로 실제 건너간다(두 손이 봉투를 함께 쥠). |
| s6 | 비타민 B12 | ○ | 받는 사람의 코끝만 파랗게 칠했다(코발트 = 코발라민). |
| s6 | 흡수에 필요 | ○ | 봉투(내인자)를 건네받는 사람이 B12 표지를 달고 있어 「B12가 내인자를 받아야 간다」는 관계가 보인다. |
| s6 | 회장에서 | ✕ 어긋남 | 회장을 나타내는 물건이 그림에 없다. 또한 이 사람은 몸 · 얼굴 · 뻗은 팔이 모두 왼쪽(봉투 쪽, 벽돌 인부 쪽)을 향해 달리고 뒷다리가 오른쪽으로 뻗어 있어, 「오른쪽으로 달려 나가려는」과 방향이 반대다. 오른쪽에 있는 관(장)으로 향하지 않는다. |
| s7 | 알칼리성 조조 | ○ | 통 바깥벽 놋쇠 수도꼭지 1개에서 흰 거품이 흘러 나온다. |
| s7 | 산을 낼 때 | △ | 수도꼭지가 벽돌 인부(벽세포) 높이의 벽에 있지만, 그 인부의 쏟는 동작과 꼭지를 잇는 것은 없고 위치만 가깝다. |
| s7 | HCO₃⁻ | △ | 흰 거품 하나뿐이라 HCO₃⁻를 따로 알아볼 표지가 없다. |
| s7 | 혈액으로 간다 | ○ | 거품이 통 밖의 붉은 관으로 흘러 들어가고 관은 통에서 멀어지는 방향(왼쪽 바깥)으로 이어진다. 통 밖으로 나가는 방향이 사실과 맞다. |
| s8 | 레닌(키모신) | △ | 효소 자체를 나르는 물건이 없고 결과(굳은 우유)만 있다. |
| s8 | 어린 포유류 | ○ | 어린 송아지 1마리가 여물통에 입을 대고 있다. |
| s8 | 우유 카세인을 응고 | ○ | 여물통의 우유가 몽글몽글 덩어리로 굳었다. 카세인 자체의 표지는 없으나 응고는 뚜렷하다. |
| s9 | 펩신 | ○ | 요리사(뗏목)가 쳐든 검은 탄산 병. s14의 검은 병(= 켜진 펩신)과 같은 모양이다. |
| s9 | 방향족 아미노산 | ○ | 사슬의 보라 마름모 1개와 그 위로 피어오르는 향 연기(방향). s11의 마름모와 같다. |
| s9 | N 말단 쪽(앞)을 자른다 | △ | 노란 별(절단 자리)이 마름모의 왼쪽에 있어 앞쪽 절단으로 읽힌다(s10 · s11과 같이 왼쪽 = N 쪽 약속). 다만 가위 날은 별에서 약 구슬 두 개 아래로 비껴 있어 사슬에 닿지 않는다. N · C 끝 표지는 없고 약속에 기댄다. |
| s10 | 트립신 | ○ | 빨간 멜빵 인부(직접 센 수 1)가 드립 주전자를 들었다(트립 = 드립). |
| s10 | 라이신 · 아르기닌 | ○ | 쌀밥 공기와 아르헨티나 국기, 표지 둘이 이름이 다른 두 잔기로 나뉘어 있다. 쌀밥 = 라이신은 말놀이 풀이에 기댄다. |
| s10 | C 말단 쪽을 자른다 | ○ | 별 둘이 각각 쌀밥 오른쪽 · 국기 오른쪽에 있다(별 수 2 = 표지 수 2). 가위는 쌀밥 오른쪽에 닿았다. 국기 쪽 절단은 별만 있다. |
| s11 | 키모트립신 | ○ | 기모노 여자 1명이 s10과 같은 드립 주전자를 들었다(기모노 = 키모). |
| s11 | 방향족(Phe · Trp · Tyr) | △ | 마름모 1개와 향 연기로 방향족은 보이나 세 가지 잔기를 가르는 표지는 없다. |
| s11 | C 말단 쪽을 자른다 | ○ | 별이 마름모 오른쪽에 있고 가위 끝이 그 별에 닿았다. |
| s12 | 엔테로펩티데이스가 트립시노겐을 켠다 | ○ | 관 왼쪽 벽 회색 상자에 열쇠가 꽂혀 돌고(진동선), 케이블이 위쪽 꺾쇠(^) 셋을 달고 빨간 멜빵 인부 허리 상자까지 이어진다. 열쇠 → 케이블 → 인부 끊김 없다. |
| s12 | 트립신이 나머지를 켠다 | △ | 인부 허리에서 아래 꺾쇠(v) 셋을 단 둘째 케이블이 기모노 여자 허리 상자로 이어진다(끊김 없음, 방향 아래 맞음). 그러나 「나머지」는 여럿인데 켜지는 대상은 기모노 여자 하나뿐이다. |
| s13 | 지방 소화의 핵심 효소 = 라이페이스 | ○ | 노란 기름 웅덩이(지방)의 가장자리에 큰 쟁반이 담겼다(라이페이스 = 쟁반이라는 말놀이에 기댐). |
| s13 | 콜리페이스가 기름 표면에 붙게 돕는다 | ○ | 콜리(1마리)가 앞발로 쟁반을 밀어 쟁반 가장자리가 기름 표면에 닿아 있다. 콜리가 쟁반 쪽으로 미는 방향과 쟁반이 기름에 닿는 방향이 맞다. |

의심: 없음(생물학적으로 의심스러운 사실 없음).
