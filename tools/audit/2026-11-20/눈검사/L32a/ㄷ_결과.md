# 그림 판독 결과 (L32a / ㄷ)

본 그림에서 직접 센 수: 집 4채(둥근 문 · 네모 문 · 문 둘 열린 집 · 문간 남자 집), 틀 4개, 국자 든 팔 3개(첫째 · 셋째 · 넷째 집, 둘째 집 지붕에는 빈 하늘색 소매), 레일 2줄(첫째 · 둘째 집 문 앞에서 시작해 합류), 합류 뒤 수레 2대(바위 수레 · 씨 장식 나무 수레), 바위 수레 위 노란 공 2 · 나무 수레 위 노란 공 1, 문간 남자 손과 허공의 노란 공 2(머리 흰 사람이 받음), 작은 물방울 2, 봉한 물병 1, 담장 구멍(돌 아치) 1, 물레방아 1, 소용돌이 1, 틀 속 하트 1 + 3 = 4, 방향 화살표(>) 모두 오른쪽.

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 전자전달계는 미토콘드리아 내막 | △ | 붉은 벽돌 담장이 그림을 가로지르나 집들은 담장 앞 마당에 서 있고 팔만 담장 위로 넘어간다. 담장 = 내막이라는 표지는 없다. |
| s1 | 산화적 인산화 = 전자전달 + 화학삼투 | △ | 왼쪽 집 · 레일(전자 쪽)과 오른쪽 아치 · 물레방아(삼투 쪽)가 모두 있으나 둘이 합쳐 한 과정이라는 표지(‘=’, ‘+’)는 없다. |
| s1 | ATP 대부분 | △ | 쟁반에 금화 더미가 있으나 ‘대부분’ 임을 견줄 다른 ATP 원천이 그림에 없다. |
| s2 | 복합체 I · III · IV 가 (셋) | ○ | 국자 든 팔 3개가 첫째 · 셋째 · 넷째 집에서 솟는다. 둘째 집은 빈 소매(국자 없음). |
| s2 | H⁺ 를 퍼낸다(펌프) | ○ | 세 국자 모두 물을 담장 너머 바다로 던져 물보라가 바다에 닿는다. |
| s2 | 기질에서 막간공간으로 | △ · 끊김 | 앞마당 → 담장 너머 바다 방향은 맞다. 그러나 앞마당은 마른 모래라 국자에 물이 담기는 첫걸음(퍼 담는 곳)이 그림에 안 보인다. |
| s3 | II = 숙신산 탈수소효소 | ○ | 둘째 틀의 주황 호박(호박 = 호박산). 둘째 집은 네모 문. 다만 ‘호박산’ 말장난을 알아야 읽힌다. |
| s3 | 숙신산을 푸마르산으로 산화 | ✕ | 호박은 온전한 채 집게와 떨어져 있고(집게는 풍선에 매달려 아무것도 안 집음), 푸마르산이나 변하는 동작이 없다. |
| s3 | H⁺ 를 펌프하지 않는다 | ○ | 둘째 지붕의 소매는 비어 있고 국자 · 물보라 없음(3개 국자와 대비). |
| s4 | I = NADH 탈수소효소 | △ | 첫째 틀의 둥근 은색 양동이 + 집게, 첫째 집은 둥근 문 · 짐꾼의 둥근 양동이. 틀 속 양동이는 빈 것인데 장면의 것은 가득 차 있다. ‘탈수소(수소 떼기)’ 동작은 없음. |
| s4 | NADH → 유비퀴논(산화환원) | △ · 어긋남 | 첫째 집 짐꾼의 가득 찬 둥근 양동이는 집 밖 레일로 가득 찬 채 나가고, 빈 양동이는 다른 사람(왼쪽 끝 뛰는 사람, 왼쪽으로 달아남)이 들고 있어 집 안에서 비워지는 장면이 없다. 또 양동이에는 물이 담겼는데 레일 위 수레에 실린 것은 노란 공이라 담긴 것과 나오는 것이 다르다. |
| s5 | II (숙신산 탈수소효소) | ○ | 네모 양동이를 안은 짐꾼이 네모 문(둘째 집)에 있고, 첫째 집 둥근 문 위에는 네모 양동이에 빨간 가위표 표지가 붙었다(네모는 I에 안 맞는다는 그림). |
| s5 | 결합형 FAD 를 거친 전자 | ✕ · 어긋남 | FAD 를 나타내는 물건이 없다. 짐꾼은 네모 양동이를 안은 채 문밖 레일로 걸어 나온다(‘들어간다’기보다 나오는 모습). 붙박이여야 할 결합형 보조인자가 양동이째 이동하는 것과 맞지 않는다. |
| s5 | I 을 건너뛴다 | ○ | 둘째 집 레일은 첫째 집 문을 지나지 않고 첫째 집 레일과 교차해 합류점으로 간다. |
| s5 | Q 로 간다 | △ · 어긋남 | 합류한 레일이 바위 수레로 이어져 길은 닿는다. 그러나 짐꾼이 나르는 것은 물 양동이이고 수레에 실린 것은 노란 공이라 담긴 것과 나오는 것이 다르다. |
| s6 | I · II 의 전자 | ○ | 첫째 · 둘째 집 레일 2줄이 합류해 바위 수레로 이어진다. |
| s6 | → Q/QH₂ | △ | 바위 수레 + 노란 공 2(전자 한 쌍). Q 와 QH₂ 의 산화 · 환원 상태 구분은 없다. |
| s6 | → III (bc₁) | △ | 바위 수레가 셋째 집 문 앞에 서 있고(끊김 없음) 셋째 틀에 꿀벌 + 수박씨 1알이 있으나, bc₁ 이름과의 대응은 풀이 없이는 읽히지 않는다. |
| s7 | III 의 붙박이 c₁ 과 이동성 사이토크롬 c 의 구별 | △ | 붙박이 집 vs 바퀴 달린 씨 장식 수레로 이동성은 나타난다. 그러나 c₁ 이 셋째 집에 따로 보이지 않고 바위 수레(Q)도 바퀴 달린 이동체라 구별이 겹친다. |
| s7 | c 가 전자를 하나씩 IV 에 건넨다 | ○ | 씨 장식 수레에 노란 공 1개(센 수 1)이고 레일 오른쪽 끝이 넷째 집 문 쪽으로 굽는다. 화살표는 모두 오른쪽 한 방향이라 ‘오가는’ 왕복은 아니다. |
| s8 | 막간공간에 쌓인 H⁺ 기울기 | ○ | 담장 뒤 바다가 담장 꼭대기 높이까지 차고 앞마당은 마른 모래다. 마당에 물이 보이는 곳은 양동이와 물레방아 웅덩이뿐. |
| s8 | = 양성자 구동력(전기화학적 기울기) | △ | 높이 차(농도 쪽 위치에너지)는 보이나 전기적(막전위) 성분을 나타내는 물건은 없다. |
| s9 | H⁺ 가 ATP 합성효소를 통해 | ○ | 담장 구멍은 오른쪽 끝 돌 아치 1개뿐이고 물이 아치를 지나 물레방아에 닿는다. |
| s9 | 막간공간에서 기질로 돌아온다 | ○ | 담장 뒤 바다에서 앞마당 쪽으로 쏟아진다(방향 맞음). 소용돌이는 아치 바로 뒤가 아니라 왼쪽으로 조금 비껴 있다. |
| s9 | ATP 합성을 구동한다 | ○ | 물레방아가 돌아 금화가 나온다(s10 과 이어짐). |
| s10 | H⁺ 기울기가 ATP 합성효소를 돌려 | ○ | 아치의 물이 물레방아를 돌린다(물보라 · 회전). |
| s10 | ATP 를 만든다 | ○ | 금화가 튀어나와 쟁반에 쌓인다. 금화는 바퀴 한가운데 축이 아니라 바퀴 오른쪽 위 가장자리 쪽에서 쏟아진다. |
| s10 | 화학삼투 (H⁺ 는 소모되지 않음) | ○ | 물은 맑은 물 그대로 앞마당 웅덩이로 간다. 들어가는 것(물)과 나오는 것(물 + 금화)이 서로 맞는다. |
| s11 | IV = 사이토크롬 c 산화효소 | ○ | 넷째 틀의 황소(ox = oxidase). 넷째 집 문간 남자. |
| s11 | heme a 를 거쳐 | △ | 틀의 카드 2장(하트 1개, 하트 3개)이 a, a₃ 를 가리킬 수 있으나 단서가 없다. |
| s11 | a₃–CuB 중심 | ✕ | 구리(Cu)를 나타내는 물건이 없다. 하트 3개 카드가 a₃ 일 수 있다는 추정 수준. |
| s11 | O₂ 를 환원 | △ | 황소 코에 흰 공 2개와 물방울 1개가 있어 O₂ → 물을 암시하나, 환원 동작은 s13 에서야 나타난다. |
| s12 | 최종 전자수용체는 산소(O₂) | △ | 머리가 흰 사람이 오므린 두 손으로 노란 공을 받고 그 뒤(오른쪽)에는 물레방아뿐 넘겨줄 사람이 없다(끝자리는 맞음). 그러나 이 사람이 산소라는 표지(O 표시 등)는 없다. |
| s12 | 엽록체 전자전달계는 NADP⁺ | ✕ | 엽록체 · NADP⁺ 를 나타내는 물건이 그림에 전혀 없다. |
| s13 | 복합체 IV 의 산소 환원 반응 | △ | 머리 흰 사람 주위에서 물방울이 뛰고 물병이 서 있다. 산소가 무엇인지는 s12 와 같은 한계. |
| s13 | O₂ + 4e⁻ | ✕ · 어긋남 | 사람에게 가는 노란 공은 센 결과 2개(남자 손에 1, 허공에 1)로 4가 아니다. |
| s13 | + 4H⁺(기질) | ✕ · 어긋남 | 작은 물방울이 센 결과 2개로 4가 아니다. 물방울이 앞마당(기질 쪽)에 있는 위치는 맞다. |
| s13 | → 2H₂O | △ · 어긋남 | 생성물로 읽힐 물건은 발치의 봉한 물병 1개로 2가 아니다. 물방울은 뛰어드는 쪽(반응물)으로 그려졌다. |
| s14 | 전자쌍당 | ○ | 수레 위 노란 공이 정확히 2개(한 쌍). |
| s14 | NADH 경로 | ○ | 첫째 집 문밖에서 시작해 합류점으로 가는 레일(레일 2줄 중 하나). |
| s14 | 약 10H⁺ | ✕ · 어긋남 | 국자 3개는 팔에 쥐인 채 지붕 위에 있지 레일 위에 나란히 놓여 있지 않다. 10 이라는 수를 나타내는 물건도 없다(3 vs 10). |
| s14 | 2.5 ATP | ✕ | 레일 · 수레 위에 금화가 없고 2.5 라는 수도 없다. |
| s14 | 숙신산 경로 | ○ | 둘째 집 문밖에서 시작해 첫째 집 레일과 교차해 합류하는 레일. |
| s14 | 약 6H⁺ | ✕ · 어긋남 | 레일 위에 국자도 빈 소매도 없다(둘째 집 소매는 지붕 위). 둘째 경로 쪽 국자 수(2)도 6 과 다르다. |
| s14 | 1.5 ATP | ✕ | 금화가 레일에 없고 1.5 라는 수 · 절반 표시도 없다. |

의심: 없음(s14 의 약 10H⁺ · 2.5ATP / 6H⁺ · 1.5ATP 는 현행 교재 값이다. 판본에 따라 3 · 2 로 적는 책도 있어 어느 쪽도 판정하지 않았다).
