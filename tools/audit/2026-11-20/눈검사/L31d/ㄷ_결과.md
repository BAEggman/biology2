# 해당과정 그림 판독 (ㄷ) — 읽기 전용 판독 결과

자료: full.jpg · s2~s12 확대(s6_1/2, s7_1/2, s12_1~6 포함) · stops.tsv. 사실 낱 = stops.tsv 3열을 「·」「→」로 끊은 것. 효소 이름 줄은 「이름을 나르는 물건」이 보이는지로 판정. 개수는 모두 확대 그림에서 직접 센 값.

판정: ○ 보임 / △ 일부만·약함 / ✕ 안 보임. 표기: 끊김 = 「→」 걸음에서 물건이 다음 물건에 안 닿음(사이에 딴 물건이 끼거나 형태·수가 바뀌며 이음 없음). 어긋남 = 담긴 것과 나오는 것 불일치, 또는 수·방향·위치 불일치.

## 판독표

| s1 | 투자기 1~5 = 위층 | ○ | 위층 초록 당구대(발코니 난간 있음)에 정거장 5개. 단 번호 표지는 그림에 없고 줄 순서(왼→오른)로만 읽힘. |

| s2 | 1 헥소키나아제 | ○ | 문지기 모자 정면에 가운데 뚫린 은색 육각 너트(헥소), 손에 긴 황금 열쇠(키나아제). 첫 정거장(맨 왼쪽)이라 「1」 위치도 맞음. |
| s2 | 포도당 → 포도당 6-인산 | ○ | 붉은 도장이 포도 블록 윗면에 닿아 있음(윗면에 작은 자국). 도장 1 = 인산 1. 「6」번 자리는 표시 불가(그림에 번호 없음). |
| s2 | ATP 하나를 쓴다 | △ | 앞 금화 1닢(수는 맞음). 그러나 금화가 도장·열쇠와 이어지지 않고 그냥 놓여 있어 「쓴다」 동작·ADP 표시 없음. |
| s3 | 2 포도당인산 이성질화효소 | ○ | 날개가 열린 이삿짐 상자(이사 = 이성질) + 베레모 화가. |
| s3 | 포도당 6-인산 → 과당 6-인산 | △ · 어긋남 | 상자 앞면 포도송이 → 액자 속 사과로 바뀜은 보임. 그러나 s2에서 포도 블록에 찍힌 붉은 도장이 여기 포도·사과 어디에도 없음(도장 0). 인산이 든 채 들어가 인산 없이 나오는 셈. 이 도장은 s4 사과 블록에서 다시 나타남. |
| s3 | 모양만 바꾼다 | ○ | 포도→사과 아이콘만 바뀌고 금화·도장·각뿔의 늘고 줆이 없음. |
| s4 | 3 PFK-1 | ○ | 완두(P) 꼬투리 모자 + 포크(F) 끝이 블록에 닿음 + 포크 손잡이가 열쇠(K). |
| s4 | F6P → F1,6BP | △ · 끊김 · 어긋남 | 포크 끝이 사과 블록 윗면의 붉은 자국에 닿음. 직접 센 붉은 인산 표시 3(윗면 2 + 옆면 장미 도장 1) vs 이인산이면 2. 앞 정거장 사과 액자 → 이 사과 블록은 사이에 금주머니가 끼어 닿지 않음(사과 아이콘 반복으로만 이어짐). |
| s4 | ATP 1 소비 | ✕ · 어긋남 | 소비를 나르는 동작 없음. 금주머니 옆 낱개 금화를 세면 3(왼 2 + 오른 1)이라 「1」과 다름. |
| s4 | ATP 과다 억제 | △ | 가득 찬 금주머니(수북한 금화)는 보임 = ATP 많음. 그러나 그것이 포크를 막거나 누르는 「억제」 동작은 없고 블록 왼쪽에 그냥 놓임. |
| s4 | AMP 활성 | ✕ | 빈 갈색 주머니는 「ATP 없음」으로만 읽히고 AMP를 나르는 물건이 아님. 활성화 동작도 없음(주인의 손바닥이 빈 주머니 쪽으로 펴진 정도). |
| s5 | 4 알도레이스 | ○ | 도끼(알도) + 깨진 알. 재단사는 흰 레이스 옷에 도끼를 양손으로 듦. |
| s5 | 과당 1,6-이인산 → G3P + DHAP | △ · 끊김 · 어긋남 | 알껍데기 사이에 각뿔 2(붉은 큰 것 + 뒤에 파란 것)가 나옴. 그러나 사과 블록(s4) → 알은 갈색 빈 주머니가 사이에 끼어 닿지 않음. 담긴 것은 인산 2인데(s4) 나온 각뿔 2에는 인산 도장이 0. |
| s5 | G3P 하나 + DHAP 하나(서로 다른 3탄당) | ○ | 붉은 1 + 파란 1, 색이 달라 서로 다른 것으로 읽힘. 두 뾰족 끝이 나란히 보이나 파랑이 빨강 뒤에 일부 가려짐. |
| s6 | 5 3탄당인산 이성질화효소 | ○ | 티피 천막(TPI) + 거울(이성질체 = 거울상 느낌). |
| s6 | DHAP → G3P | ○ | 거울 앞 각뿔이 밑 파랑·꼭대기 붉은 자국(전환 중), 바로 오른쪽(아이 옆)에 전체가 붉은 각뿔. 왼→오른 방향도 일관. 알껍데기와 반파랑 각뿔은 거의 붙어 있음. |
| s6 | 이제 G3P 둘 | △ · 어긋남 | 위층~계단의 완전한 붉은 각뿔을 직접 센 값: 알 속 1 + 아이 옆 1 + 계단 2 = 4, 여기에 반쪽(전환 중) 1과 알 속 파랑 1이 더 있음. 「G3P 둘」은 계단의 2개로 읽을 수는 있으나 탁자 위 붉은 것과 겹쳐 셈이 흔들림. |
| s7 | 6 G3P 탈수소효소 | ○ | 후드 지퍼가 V자로 벌어짐(탈의 = 탈수소 암시). 수소 자체는 그림에 없음. |
| s7 | G3P + 무기인산 → 1,3-BPG | △ · 어긋남 | 파란 당구대에 각뿔 2, 각뿔마다 붉은 고리 도장 2(총 4), 낱개 도장 1. 그러나 (1) G3P마다 무기인산 1이 필요한데 낱개 도장은 1뿐(필요 2), (2) 계단에서 내려오는 G3P 각뿔엔 도장 0인데 여기선 각 2로 늘어남. |
| s7 | NAD⁺ → NADH | △ · 끊김 · 어긋남 | 번개 1개(손)와 양동이 2개(발밑)뿐. 번개와 양동이는 서로 이어지지 않고 어느 쪽이 NAD⁺고 NADH인지 구분 표지가 없음. 반응이 2번이면 NADH 2 필요한데 번개 1. 양동이 속은 맑은 물이라 s10의 H₂O와 구별 불가. |
| s8 | 7 인산글리세르산 인산화효소 | ○ | 돼지가 황금 열쇠를 쥠(목에도 열쇠 1개 더 걸림). 오른쪽 돼지가 맞음. |
| s8 | 1,3-BPG → 3-PG | ○ | 앞발이 오른 각뿔 꼭대기의 붉은 도장을 잡음. 각뿔 2개로 s7과 수 일치. 뗐는지 달린 채인지는 구분이 어려움. |
| s8 | ATP 생성(기질수준 인산화) | △ · 끊김 | 앞 금화 2닢에 붉은 점이 붙음(수 일치). 그러나 도장은 앞발에 쥔 채로 금화와 떨어져 있고, 열쇠 끝의 붉은 자국이 왼쪽 금화 쪽으로 가다 끊김. 「직접 옮김」이 안 보임. |
| s9 | 8 인산글리세르산 자리옮김효소 | ○ | 왼쪽 돼지 + 잎 달린 흰 무(무 = mutase의 「무」). |
| s9 | 3-PG → 2-PG | ○ · 어긋남 | 무 끝이 각뿔 옆면의 붉은 고리 자국에 닿음(s8에선 꼭대기 → 여기선 옆면). 그러나 각뿔이 1개뿐이라 s8의 2와 다름(수 1 ≠ 2). |
| s9 | 인산의 자리만 옮긴다 | △ · 어긋남 | 도장이 꼭대기 → 옆면으로 옮겨진 것은 보임. 그러나 탁자 위 무 아래에 낱개 붉은 도장이 2개 떨어져 있어 「자리만」(남는 인산 0)과 어긋남. 무 끝 자체에는 도장이 없고 닿은 각뿔 면 쪽에 자국이 있음. |
| s10 | 9 에놀레이스 | ○ | 튜브 낀 수영복 아이(수영 = 물). |
| s10 | 2-PG → PEP + H₂O | ○ · 어긋남 | 붉은 천(꼬인 붉은 천 꼴, 허용)을 양손으로 비틀어 짬. 그러나 천 1개 = 분자 1개(s11은 각뿔 2). 한 천에서 나온 물은 방울 4개 + 탁자 위 웅덩이 1이라 「분자 2」와 안 맞음. |
| s10 | 물을 빼 | ○ | 물방울이 떨어져 탁자 위 웅덩이, 아이 발밑 바닥에도 웅덩이(탁자 모서리에서 바닥으로 이어지는 흐름은 안 그려짐). |
| s10 | 고에너지 인산 공여체로 | ✕ | 천에 인산 도장이 안 붙어 있음. 옆(파라오 쪽)에 낱개 도장 1이 놓여 있어 오히려 인산이 이미 떨어진 것으로 읽힘. 「고에너지」를 나르는 물건 없음. |
| s11 | 10 피루브산 인산화효소 | ○ | 가로로 긴 피리(피루브산 = 피리) + 황금 열쇠. 피리 끝에 큰 붉은 루비. 맨 왼쪽, 커튼 문 바로 오른쪽. |
| s11 | PEP → 피루브산 | ○ · 끊김 | 도장 없는 붉은 각뿔 2(피루브산, 인산 없음이 맞음). 그러나 수영 아이의 천 1개 → 이 각뿔 2개는 낱개 도장이 놓인 빈 칸이 끼어 닿지 않음. 형태·수가 바뀌는데 잇는 물건이 없음. |
| s11 | ATP 생성(기질수준 인산화) | △ · 끊김 · 어긋남 | 금화 2닢(수 일치). 그러나 붉은 인산 표시를 세면 왼 금화 위 도장 1 + 오른 금화 붉은 점 1 + 낱개 1 = 3이라 2와 다름. 루비는 금화 반대쪽을 향해 있고 루비 → 금화 전달 동작이 없음. |
| s12 | 포도당 1 | ○ | 포도 블록 1개(위층 문지기 앞). |
| s12 | 피루브산 2 | ○ | 파라오 앞 붉은 각뿔 직접 셈 2. 도장 없음. |
| s12 | ATP 생성 4 | ○ | 오른 돼지 앞 금화 2 + 파라오 앞 금화 2 = 4(왼 돼지·후드 앞에는 없음). |
| s12 | ATP 소비 2 | ✕ | 문지기 앞 금화 1 + 과일 주인 앞 낱개 금화 3 = 4라 「한 개씩」과 다름. s4의 어긋남과 같은 원인이라 어긋남 집계는 중복하지 않음. |
| s12 | 순 2 (4 − 2) | △ | 뺄셈을 나르는 동작·물건이 없음. 그림에서 직접 세면 생산 4, 소비 4로 순 0이 됨. |
| s12 | NADH 2 | △ | 양동이 2(수 일치)이나 속이 맑은 물이라 H₂O와 구분 불가. 번개는 1개뿐. s7과 같은 원인이라 어긋남 집계는 중복하지 않음. |
| s12 | H₂O 2 | △ | 웅덩이 2(탁자 위 1 + 바닥 1)로 읽을 수 있으나 양동이 2도 물이라 겹침. 짠 천은 1개. |
| s12 | CO₂ 0 | △ | 기체·거품·연기 같은 CO₂ 물건은 그림 어디에도 없음(부재만 확인). 「0」을 능동적으로 나르는 물건은 없음. |

## 의심 (생물학적으로 의심스러운 사실)

없음. 10반응의 투자기 1~5/회수기 6~10 구분, PFK-1의 ATP 억제·AMP 활성, GAPDH의 무기인산 요구, 3-PG→2-PG 자리옮김, 에놀레이스의 H₂O 제거, 총수지(ATP 4 − 2, NADH 2, H₂O 2, CO₂ 0) 모두 표준 설명과 일치.
