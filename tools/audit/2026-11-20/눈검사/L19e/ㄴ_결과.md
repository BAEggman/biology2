# ㄴ 판독 결과

정거장 번호는 sN.jpg 파일 번호를 따랐다. s2 는 창가 비탈의 시트, s3 은 지퍼, s4 와 s5 는 붉은 콩이 쏟아지는 땅콩 모양 물체, s6 은 일곱 팔 바퀴와 아저씨, s7 은 바닥의 캐스터네츠, s8 은 8점 틈새, s9 는 9점 틈새와 붉은 공 핀, s10 은 3점 틈새, s11 은 아스파라거스와 구슬줄, s12 는 갈고리 걸이에 걸린 캐스터네츠이다. 파일 번호 대로 대지 않은 곳은 아래 각 줄에 그림에서 본 것을 적었다.
