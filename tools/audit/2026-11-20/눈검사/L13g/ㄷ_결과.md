# ㄷ 그림 판독 결과 (L13g)

자료: full.jpg · s1~s11(.jpg, s3_1 · s3_2 · s5_1~s5_3 포함) · stops.tsv. 판정은 그림에 실제로 보이는 것만 근거로 삼음. 「의심」은 그림 판정과 따로 적음.

공통 관찰: Y 깃발은 주황금색 Y 한 가지. 등장인물 거의 전원(벌 · 병정 · 경비 · 의사 · 가족 · 환자)이 붉은 배지(리본)를 달고 있음. 인형 · 꽃가루 공 · 책 · 거북에는 배지 없음.

| s2 | 만들어진 항체를 받는다 | ○ | 조랑말 → 수레(Y 수북) → 흰 옷 경비가 한 아름 떠서 → 침대 환자에게 쏟음. 수레 속 Y와 쏟는 Y가 같은 모양 · 색(담긴 것=나오는 것 일치) |
| s2 | 수동면역 | ○ | 받는 쪽(환자)에 배지는 있으나 깃발을 스스로 든 모습 없음, 전부 외부에서 쏟아짐 |

| s2 | 기억 없음 | ○ | 환자 곁에 벌 0, 책 0(책 든 벌은 수레 경비 머리 위 오른쪽 위에 떨어져 있음). 부재로 표현 |
| s3 | 능동=스스로 생성 · 기억 O | ○ | 책 2권을 안은 벌 1(배지 단 자기) |
| s3 | 수동=받음 · 기억 X | ○ | 깃발만 쏟아진 환자 1, 책 0 · 벌 0. 위(책 벌)와 아래(환자)가 가까이 놓여 한눈에 대비됨 |
| s3 | 예: 백신 · 감염(능동) | △ | 인형은 백신 · 병원체로 읽히나 「감염」을 나타내는 별도 물건 없음 |
| s3 | 예: 모체 항체 · 항독소(수동) | △ | s3 자리 자체엔 없음. 모체 항체는 왼쪽 아래 s4(환자와 멀리 떨어짐)에 있고, 항독소는 s2에서 ✕ |
| s4 | 모체 항체 | ○ | 연두 원피스 엄마 → 숄에 싼 아기. Y 깃발이 숄 위 아기 가슴께에 있음 |
| s4 | IgG는 태반으로 | ✕ | 태반 · 탯줄 없음. 이미 태어난 아기를 안은 모습뿐. 그림의 Y는 하나뿐이라 IgG / IgA 구별 불가 |
| s4 | IgA는 모유로 | ○ | 젖을 물리는 동작 + Y가 아기 입 · 가슴께에 있음(엄마→아기 방향 맞음) |
| s4 | (IgA 이음 = Y 둘이 가운데에서 맞붙음) | (위 ○ 행에 포함, 별도 판정 △) | 직접 본 것: 작은 Y 1개 + 가운데 둥근 매듭. 「Y 둘이 맞붙음」으로는 또렷하지 않음 |
| s4 | 자연 수동면역 | ○ | 엄마가 아기에게 줌, 벌 · 책 없음(기억 없음과 맞음) |
| s5 | 1형(즉시형) | ○ | 성냥이 「확」 타오르는 순간 표현 + 곁 사람이 바로 재채기 |
| s5 | 비만세포 | ○ | 배 불룩한 흰 옷 경비(과립 가득한 세포로 읽힘) |
| s5 | 비만세포에 붙은 IgE | △ | 경비 배 옆(화면 오른쪽)에 집게 팔 2개가 박혀 있음. 그러나 모양이 Y 갈래보다 고리 달린 집게 팔로 보여 s1 · s2 의 Y 깃발과 같은 모양으로 알아보기 약함 |
| s5 | 알레르겐이 IgE를 이음 | ○ | 노란 가시 공 1개를 집게 2개가 함께 물고 있음(공 1 · 집게 2 직접 셈) |
| s5 | 알레르겐 = 꽃가루 | ○ · 끊김 | 꽃 기둥의 꽃(앞쪽 2송이 + 뒤에 가려진 꽃잎) → 꽃가루 구름은 위쪽 벽 앞에 떠 있음. 구름과 배 옆 공 사이는 약 150px 빈 공간이라 「구름→공」 걸음이 이어지지 않음(끊김 1) |
| s5 | 히스타민 방출 | △ · 어긋남 | 방출은 성냥 불꽃이 「확」 올라가는 것으로 표현. 그러나 불꽃은 경비 손에 든 성냥에서 나오고, 담긴 곳(배)에서 나오는 것이 아님. 배 속 내용물(과립)이 안 보여 담긴 것 ≠ 나오는 것(어긋남 1) |
| s5 | 증상(재채기) | ○ | 파란 옷 사람이 입 · 코를 막고 침방울 튀김, 눈 질끈. 눈물과 콧물 구분은 안 됨(침방울 6~7개 직접 셈) |
| s6 | 아나필락시스 쇼크 | ○ | 얼굴 · 입술이 퉁퉁 붓고 입 벌려 헐떡이며 쓰러짐. 경비가 무릎 꿇고 곁에 있음 |
| s6 | 에피네프린 | △ | 쇠 드럼통 뚜껑이 날아가며 노란 섬광이 펑. 약물 · 주사 표지 없고, 경비 손은 환자가 아니라 드럼통에 닿음 |
| s6 | 아드레날린 수용체 작용 | ✕ | 수용체를 나타내는 물건 없음 |
| s6 | 교감 자극 효과 | △ | 환자 눈이 크게 뜨임(번쩍). 그러나 부기 · 호흡 호전 표지는 없고 여전히 헐떡임 |
| s6 | 차단 아님 | △ | 뚜껑이 열려 날아감(막힘이 아님)으로 읽힐 수는 있으나 해석에 의존 |
| s7 | IgG · IgM | △ | 구 속 Y 3개. 모두 같은 Y여서 IgG와 IgM(5량체)의 구별 없음 |
| s7 | 세포 겉 항원에 붙음 | ○ | 구 속 Y 3개가 붉은 원반(적혈구) 조각 위에 물려 있음 |
| s7 | 세포를 부숨(용혈) | ○ | 주머니 속 붉은 원반 5개(온전) → 관을 타고 내려옴 → 둥근 유리 방울 안에서 터져 조각남. 주머니와 방울의 내용이 같은 적혈구(담긴 것=나오는 것 일치), 주머니→관→방울 이어짐 |
| s7 | 부적합 수혈 | △ | 수혈 장비는 있으나 「남의 피」 · 혈액형 불일치를 가리키는 표지는 없음 |
| s8 | 면역복합체(구슬+Y 덩이) | ○ | 거름망 위 금빛 구슬(밝은 것 5 + 옅은 것 2)과 Y(약 3)가 사슬처럼 호(弧)로 엉켜 끼어 있음 |
| s8 | 녹아 떠다니는 항원 | △ | 구슬이 항원으로 읽히나 「녹아 떠다님」은 안 보임. 이미 엉겨 굳은 덩이로만 있음 |
| s8 | 조직에 쌓임 | ○ | 호스 끝 둥근 쇠 거름망에 끼어 걸림(신장 거르개 연상) |
| s8 | 염증 | ○ | 둘레 돌 약 11개가 벌겋게 달아오르고 김이 4줄 오름 |
| s8 | 루푸스 신염 | △ | 거름망이 신장 연상은 되나 「루푸스」 직접 단서는 없음(s10에도 없음) |
| s7→s8 | (사슬: 호스) | 어긋남 | 호스에 실려 오는 것은 터진 붉은 적혈구 파편인데, 망에 끼는 것은 금빛 구슬+Y 덩이. 호스는 이어져 있으나(끊김 아님) 나르는 것과 도착하는 것이 다름(어긋남 1) |
| s9 | 면역관용(반응하지 않음) | ○ | 병정 3명이 차렷으로 서서 한 손 경례, 공격 동작 없음 |
| s9 | 자기 항원 = 배지 · 자기관용 | ○ | 배지 단 가족 3명(아이 · 엄마 · 아빠)이 지나감. 병정 쪽이 오른쪽(가족 쪽)을 향함. 단, 그림 속 거의 모든 인물이 배지를 달고 있어 「가족만의」 자기 표지로는 변별력이 약하고 「배지=자기」 약속으로만 읽힘 |
| s10 | 자가면역(자기를 공격) | ○ | 병정이 배지 단 자기 쪽 사람(사내 · 여자)과 자기 쪽 물건을 공격 |
| s10 | 1형 당뇨 | ○ | 연못 섬(랑게르한스 섬) 위 주사기를 든 흰 가운 사내를 병정 2명이 공격(1명 주먹, 1명 팔 잡아끎). 수 2 = 사실과 일치 |
| s10 | 다발성 경화증 | ○ | 기둥 꼭대기에서 늘어진 검은 줄(전선)에 흰 테이프 토막이 감김, 사다리 위 병정 1명이 기둥 꼭대기의 흰 테이프를 길게 뜯어냄. 병정 → 테이프 → 전선 이어짐 |
| s10 | 류머티스 관절염(관절 부음) | ○ | 앉은 여자의 두 무릎이 대칭으로 벌겋게 부음(2) |
| s10 | 류머티스 관절염(병정이 걷어참) | △ | 병정이 발을 뻗고 있으나 발끝이 무릎보다 낮은 기둥 밑동 · 정강이께를 향해 무릎을 정확히 겨눈 모습은 아님 |
| s10 | 전신홍반루푸스 | ✕ | 나비 모양 얼굴 발진 등 단서 전혀 없음. 4종 중 3종만 그려져 있음 |
| s11 | 4형(지연형) | ○ | 큰 거북이 오른쪽으로 기어 감(고개가 오른쪽), 등에 하품하는 병정 3명. 거북 머리와 사람 팔 사이 아직 간격이 있어 「다가가는 중」으로 읽힘 |
| s11 | 항체 없이 | ○ | 이 구역 어디에도 Y 깃발 0개 |
| s11 | T 세포가 일으킴 | △ | 거북 등의 병정은 s9 · s10 병정과 같은 일반 병정이라 「T 세포」로 따로 읽히지 않음 |
| s11 | 하루 이틀 뒤 | △ | 느림은 보이나 「하루 이틀」을 나타내는 표지 없음 |
| s11 | 접촉성 피부염 | ○ | 덩굴 뻗은 담에 기대 앉은 사람, 두 팔에 오돌토돌 붉은 발진, 가려움 물결선 |

참고(판정 외): s11 에서 증상(발진)이 이미 나 있는데 거북은 아직 도착 전이라 인과 순서가 거꾸로 읽힐 소지가 있으나, 사실 문장의 「다가가는 사람」 설계 그대로여서 어긋남으로는 세지 않음.
