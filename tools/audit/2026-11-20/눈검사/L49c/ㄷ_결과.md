# ㄷ 판독 결과 (L49c/ㄷ)

표기: ○ 보임 · △ 약함/모호 · ✕ 안 보임. 「끊김」 「어긋남」은 해당 칸에 따로 표시. 파일 안에 지시처럼 보이는 글은 없었음.

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 1형 — β 세포가 부서진다 | ○ | 왼쪽 섬의 큰 집: 지붕 한가운데 내려앉고 창 3개(정면 왼·가운데·오른) 모두 판자 가위표, 문 열려 있고 잔해 판자 흩어짐. |
| s1 | 안에 아무도 없고 (만들 주체 없음) | △ | 문 안쪽이 어둡게 비어 보이나 창은 판자로 막혀 내부 전체가 안 보임. 「아무도 없음」을 증명하는 물건(빈 방 등)은 없고 문틈의 어둠뿐. |
| s1 | 인슐린을 거의 만들지 못한다 (잔해 앞 개어 둔 흰 베) | △ · 어긋남 | 흰 베 1장이 잔해 앞 풀밭에 있음(수 1). 그러나 흰 베가 「인슐린」임을 알려 주는 단서가 없고, s3에서 인슐린은 주사기로 그려짐 → 인슐린의 그림이 장면마다 다름(어긋남). 「거의」(전무가 아닌 잔량)도 안 보임: 집이 전파라 「전혀」로 읽힘. |
| s2 | 자가면역 — 제 몸의 면역 | △ | 같은 섬에 같은 갈색 조끼 3명(수 3=사실의 「셋」). 같은 섬 = 제 몸은 읽히나, 이들이 「면역」이라는 표지(옷·소품)는 없음. |
| s2 | 면역이 β 세포를 파괴 | ○ | 3명 모두 큰 망치 1자루씩(망치 3): 가운데 한 명은 문 앞 벽을 내리치고, 양옆 둘은 머리 위로 치켜듦. 먼지구름 · 튀는 파편 · 부서진 판자로 파괴가 보임. (양옆 둘은 아직 집에 닿지 않은 치켜든 동작.) |
| s2 | → 1형은 인슐린 의존성 | ✕ · 끊김 | 「파괴 → 의존성」 사슬이 파괴에서 끊김. 「의존」을 나르는 물건 · 동작(인슐린을 기다리거나 받으려는 손 · 주사기)이 이 섬에 없음. 주사기는 오른쪽 섬(s3)에 있고 물길로 갈라져 서로 닿지 않음. |
| s3 | 2형 — 인슐린은 있다 | ○ · 어긋남 | 오른쪽 섬 멀쩡한 큰 집 창에서 흰 가운 1명이 주사기 1개를 높이 들고 웃음. 다만 「흰 가운 + 주사기」는 의사가 놓는 외부 주사(치료)로 읽혀, 「내 몸이 낸 인슐린」과 담긴 것/나오는 것이 어긋남. |
| s3 | 받는 쪽이 잘 반응하지 않는다(저항성) | △ | 이 장면 안엔 「받는 쪽」이 없음 — 웃으며 손 흔드는 모습뿐. 저항성은 s4 작은 집 문에서만 보이며, 이 섬에서 그쪽으로 향하는 팔 · 길 · 시선이 없음. |
| s3 | 분비도 모자라짐 | ✕ | 집은 멀쩡 · 주사기 1개 · 밝은 표정. 줄어듦 · 바닥남 · 힘없음을 나르는 것이 없음. |
| s4 | 인슐린 수용체 고장 (작은 집 넷, 문마다 손잡이 뜯김) | ○ | 오른쪽 물가에 작은 집 4채, 문 4개 모두 문짝 가장자리에 옅은 판 + 둥근 빈 구멍(손잡이 없음) + 판 위쪽 금. 수 4=4, 위치 오른쪽 물가 맞음. |
| s4 | 손잡이 자리 흔적(자국 판 · 나사 구멍 · 금 · 빈 구멍) | △ | 판 · 금 · 빈 구멍은 4개 문 모두 보임. 「나사 구멍」은 해상도상 판가름 안 됨(작은 점 정도). |
| s4 | 또는 세포 안 반응 경로의 고장 | ✕ | 이를 나르는 물건 없음. 집 안쪽 · 배선 · 관 등이 안 그려지고, 창에 보이는 것은 지방 불꽃(s5)뿐. 「수용체나」 중 한쪽(수용체)만 그려짐. |
| s5 | 포도당이 세포로 못 들어간다 (문마다 포도 수북) | ○ | 문 4개 앞에 포도 더미 4개(문 4=더미 4), 문 닫힘, 더미 주변에 낱알 흩어져 넘침. 같은 포도 아이콘이 수조와 같아 담긴 것 일치. |
| s5 | 혈당이 높다 = 당뇨 | △ | 높은 혈당의 본체는 s6 수조. 문 앞 더미는 모래밭 위에 따로 있어 수조와 이어지지 않음(왼쪽 첫 더미 곁에 수조 물웅덩이가 닿을 듯하나 흐름은 없음). 「혈액 속 높음」이 이 장면에선 약함. |
| s5 | 대신 지방을 많이 쓴다 | ○ | 4채 모두 옆 창에 노란 덩이 위 불꽃 4개, 굴뚝 4개 모두 검은 연기. 같은 집의 문(포도 못 들어감)과 불(지방)이 한 집에 붙어 있어 사슬 끊김 없음. |
| s6 | 혈당이 정상 구간(초록 띠)을 넘었다 | ○ | 유리 수조 한가운데 초록 띠, 물 · 포도가 띠 위로 한참 올라 있고 위쪽에 포도 송이 3개 떠 있음. |
| s6 | 테두리까지 차고 넘쳐 바깥 벽을 타고 흘러내린다 = 고혈당 | ○ | 물이 테두리에 닿아 굵은 한 줄(가운데) + 좌우 가장자리 흐름이 바깥 벽을 타고 내려 바닥 물웅덩이를 이룸. |
| s7 | 넘친 물과 포도가 좁은 돌 도랑으로 모여 그림 밖으로 (포도당이 오줌으로) | ○ | 수조 발치의 돌 도랑에 포도 송이 2 + 낱알 2가 떠 흘러가 그림 아래쪽 밖으로 나감. 수조 → 웅덩이 → 도랑 연결 이어짐(끊김 없음). |
| s7 | 혈당이 재흡수 한계를 넘으면 | △ · 어긋남 | 「한계」가 테두리로 읽힐 수 있으나 s6에선 테두리 넘침이 「정상 구간 초과(고혈당)」로 쓰였음. 그림은 수위가 이미 테두리라 「띠 위·테두리 아래(고혈당이나 요당 없음)」 구간이 안 보여, 고혈당과 요당이 그림으로 구분 안 됨. |
| s7 | 콩팥 · 재흡수 | ✕ | 콩팥을 나르는 물건 없음. 「평소엔 되가져오다 한계에서 샘」의 재흡수 장치(저울 · 펌프 · 거름망)도 없고 도랑뿐. |
| s8 | 두 섬의 큰 나무집 — 왼쪽 부서짐 · 오른쪽 멀쩡 | ○ | 왼쪽 섬 집 폐허(망치 3명), 오른쪽 섬 집 온전(의사 1명) 그대로 보임. 오른쪽 집 고장이 없고 작은 집 문 4개(오른쪽 물가)에 고장이 있음 — 위치 맞음. |
| s8 | 1형은 만들지 못한다(결핍) | ○ | 부서진 큰 집으로 읽힘(s1 재사용). |
| s8 | 2형은 잘 받지 못한다(저항성) — 되짚기 | ○ · 끊김 | 작은 집 문 4개의 뜯긴 손잡이가 보임. 그러나 오른쪽 큰 집 · 주사기에서 작은 집으로 닿는 길 · 팔 · 시선이 없음(물과 섬 사이가 갈림). 「되짚기」는 눈이 아니라 기억으로만 이어짐. |
| s8 | + 분비 부족 | ✕ | s3과 같은 사유 — 오른쪽 집은 멀쩡 · 밝음, 모자람을 나르는 것 없음. |
| s8 | 2형이 흔하다 | ✕ | 두 섬 크기 · 집 수 비슷(각 1채)하고 오른쪽이 더 많다는 단서(집 수 · 크기 · 사람 수)가 없음. 도리어 왼쪽에 사람 3명으로 더 북적임. |
| s8 | 비만과 얽힌다 | ✕ | 비만을 나르는 물건 · 인물 없음(의사는 보통 체형, 지방 불꽃은 s5 장면이며 비만과 이어지지 않음). |

의심(그림 판정과 별개): 없음. 사실 문장들은 교과서 수준에서 생물학적으로 무리 없음(참고: 2형의 「분비도 모자라짐」은 병이 진행되며 생김, 1형 자가면역은 대부분이며 일부 특발성 예외가 있으나 의심할 수준은 아님).
