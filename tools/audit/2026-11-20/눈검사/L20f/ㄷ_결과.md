# L20f ㄷ 그림 판독 결과 (full.jpg · sN.jpg · sN_k.jpg 를 직접 보고 판정)

그림에서 직접 센 것 (전체): 왼쪽 칸 — 창 1개(창살 2칸), 파란 빛줄기 1개, 토분 1개, 큰 줄기 1개, 눈알 1개, 알갱이 띠 1줄(오른쪽 안벽), 창 쪽(왼쪽) 벽 알갱이 0.
오른쪽 칸 — 유리 화분 1개(입구 오른쪽·약간 위), 줄기 1개(끝에 어린 잎 2장, 눈알 없음), 흰 뿌리 1개, 은빛 골무 1개(앞쪽을 잘라 연 모습), 골무 속 짙은 회색 낟알 약 10~12개(서로 겹쳐 정확히는 못 셈), 줄기 아래 가장자리 알갱이 1줄(약 25알), 뿌리 아래 가장자리 알갱이 1줄(약 18알, 위쪽 가장자리 0).
세로 틀선 1개(가운데). 창·빛줄기는 오른쪽 칸에 없다.

## 사슬·담김·수 검사 요약
- 「→」 사슬: s5 한 곳뿐, 이동→신장→굽음 모두 물건이 맞닿음(끊김 0). 다만 첫 걸음(이동)은 결과 위치만 있음.
- 담긴 것 = 나오는 것: 골무 속 낟알 = 녹말체 일치, 노란 알갱이 = 옥신 일치(줄기·뿌리 동일 색) → 어긋남 0.
- 수·방향·위치: 알갱이 띠 1줄/굽음 반대 방향/눈알·창 방향 모두 사실과 일치. 참고: 왼쪽 줄기 아래 20%는 오른쪽으로 기운 곧은 구간.
