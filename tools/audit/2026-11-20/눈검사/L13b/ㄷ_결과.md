| s2 | 흡입(위족으로 감쌈) | ○ | 왼쪽 덩이가 흰 팔 둘(직접 셈 2)로 세균을 감싸 안음. 위족=팔 |
| s2 | → 식포 형성 | ○ | 가운데 덩이 배 속 둥근 유리창 비눗방울에 세균이 갇힘. 1번 덩이와 2번 덩이는 몸이 맞닿음 |
| s2 | → 리소좀 융합 · 분해 | ○ 끊김 | 셋째 덩이 한 주머니에 레몬 조각 뜬 초록 물(리소좀) + × 눈 일그러진 세균이 함께 있음. 다만 2번과 3번 덩이 사이에 가는 틈이 있고 같은 세균이 이어진다는 표시(화살 · 접촉)가 없어 순서는 위치로만 읽힘 |
| s3 | 비만세포 = 뚱뚱한 경비 | ○ | 배가 공처럼 불룩한 경비(「비만」 말장난) |
| s3 | 식균작용을 하지 않는다 | ○ | 눈을 감고 손바닥을 쫙 펴 「멈춰」, 손 곁 작은 초록 세균을 막음. 먹지 않음이 동작으로 보임 |
| s3 | 히스타민 등 매개물질만 분비 | △ | 불붙은 성냥 한 움큼(여럿=「등」)은 보이나 치켜들고만 있고 내보내는(분비) 동작은 없음. 분비는 s4 호스 쪽에서 이어서 읽어야 함 |
| s3 | (사실 자체) 비만세포는 식균 안 함 | 의심 | 교재 서술은 맞으나 비만세포가 약하게나마 식균한다는 보고도 있음(시험 서술로는 문제 없음) |
| s4 | 히스타민(성냥불, 위치) | ○ | 뚱보 경비의 성냥불 바로 위에 호스의 부푼 자리가 있음 |
| s4 | → 혈관 확장 | ○ 끊김 | 호스가 공처럼 부풀음. 그러나 성냥불은 부푼 호스에 닿지 않고 사이가 뜸(물방울 · 김만 오감). 오히려 방울은 호스에서 불 쪽으로 떨어져 방향이 사실(불→호스)과 거꾸로 읽힐 수 있음 |
| s4 | 모세혈관 투과성 증가 | ○ | 부푼 면 앞쪽에 세로 틈 3(직접 센 수 3)에서 방울이 샘 |
| s5 | 히스타민 유리 | ○ | 성냥불(s4와 같음) |
| s5 | → 혈관 이완 · 투과성↑ | ○ 끊김 | 부풀고 새는 호스. 성냥불→부푼 자리는 s4처럼 맞닿지 않음 |
| s5 | → 호중구 도착 | ○ | 호스 똬리 옆구리의 찢어진 구멍에서 상반신을 내밀고 파리채를 든 경비. 호스는 부푼 자리에서 똬리까지 이어짐 |
| s5 | → 고름(농) | ○ 끊김 | 누르스름한 웅덩이에 소용돌이 눈 · 빼문 혀 경비 둘(직접 센 수 2), × 눈 세균 2, 떨어진 파리채 1. 그러나 똬리 아래 노란 웅덩이와 가운데 큰 웅덩이는 서로 떨어져 있고, 나온 경비와 누운 경비도 닿지 않음 |
| s6 | 발적 | ○ | 손가락이 새빨감 |
| s6 | 열감 | ○ | 손가락 위로 김 두 가닥 |
| s6 | 부종 | ○ | 손가락 끝이 둥글게 퉁퉁 부음(가시 박힘) |
| s6 | 통증 | ○ | 눈물이 줄줄 · 우는 얼굴. 징후 넷(붉음 · 김 · 부음 · 눈물)이 직접 셈 4 = 사실 4 |
| s7 | 감염 세포(집)와 바이러스 | ○ | 앞벽을 뗀 집 속에 두루마리를 안은 보라 망토 |
| s7 | 인터페론 분비 | △ 끊김 | 집 오른벽 바깥 인터폰 판 + 수화기를 든 여자로 「분비」를 나르나 인터폰은 집 안(망토)과 이어지는 선이 없고 여자는 집 밖에 서 있음. 바이러스를 가진 집과 분비 주체가 이어지지 않음 |
| s7 | → 이웃이 방어 준비 | ○ | 인터폰 위 전선이 이웃 벽 확성기로 이어지고, 이웃 사람이 의자 위에서 창에 판자를 대고 망치질(방어 준비) |
| s7 | (과 자신) 방어 준비 | ✕ | 감염된 집 쪽은 판자 · 망치 등 방어 준비가 없음. 이웃만 보임 |
| s7 | 바이러스를 직접 부수지 않음 | ○ | 망치는 판자를 향하고 망토는 멀쩡함 |
| s8 | Dicer(깍둑썰기 기계) | ○ | 격자 칼날 상자 + 돌리는 손잡이 |
| s8 | dsRNA 투입(두 겹 띠) | ○ | 망토의 두루마리 끝이 두 겹 종이 띠로 풀려 기계 윗구멍으로 들어감(접촉 있음) |
| s8 | 절단 → 짧은 토막 | ○ | 기계 앞으로 짧은 토막이 쏟아져 탁자 · 바닥에 쌓임 |
| s8 | Argonaute(소용돌이 껍데기 문어) | ○ | 소용돌이 껍데기 진 주황 문어가 토막 하나를 한 다리로 치켜듦. 기계와 문어는 직접 닿지 않으나 토막 더미가 문어 발치까지 쌓임 |
| s8 | 표적 RNA 분해 | ○ | 다른 다리들로 기다란 두루마리 종이를 쥐고 두 쪽으로 찢음(찢긴 가장자리 · 부스러기) |
| s9 | 보체의 세 경로(물길 셋) | ○ | 돌 물길이 직접 센 수 3, 저수지 하나로 모임 |
| s9 | C3에서 합류 | △ | 합류는 보이나 C3를 나르는 표지는 따로 없음. 저수지 자체와 보(판자)의 쓰임이 사실로 번역되지 않음 |
| s9 | 결과 셋(물줄기 셋) | ○ | 왼쪽 가에서 한 줄기로 나와 Y 자로 갈라진 둘 + 앞의 곧은 줄기 1 = 직접 센 수 3 |
| s9 | 염증 증폭 | △ | 바깥의 높은 줄기가 흰 덩이들 발밑을 지나 성냥 쥔 뚱보 경비의 무릎에 철썩. 다만 줄기 양끝에 물보라가 있어 저수지에서 나가는지 저수지로 들어오는지 방향이 헷갈림 |
| s9 | 옵소닌화 | ○ | 안쪽 굵은 줄기가 작은 덩이가 든 세균을 흠뻑 적심(코팅=옵소닌 + 그 덩이가 먹음) |
| s9 | MAC 형성 | ○ | 저수지 앞의 곧은 줄기가 세균 몸의 구멍으로 지남(s10) |
| s10 | MAC가 막에 구멍 | ○ | 곧은 물줄기가 몸을 지나 배 한가운데 둥근 구멍(둘레에 동그란 주름 테 겹겹)으로 빠져나옴. 구멍 수 1 |
| s10 | → 용해 | △ | 물이 통과해 쏟아지나 세균 몸은 온전하고(놀란 「o」 입) 터지거나 쪼그라드는 모습이 없음 |
| s10 | 인터페론이 아니다 | ✕ | 이 칸에는 인터페론 상징(전화 · 확성기)이 없고 부정을 나르는 물건 · 동작이 없음. s7과의 대조는 그림 안에서 이어지지 않음 |
| s11 | 디펜신 = 만년필 · 막에 구멍 | △ | 펜촉이 세균 옆구리를 콕 찌르고 터짐 표시가 있으나 구멍이 난 모습은 없음(찌름 수준) |
| s11 | 무척추동물에도 | ○ | 달팽이가 만년필로 세균 왼쪽 아래를 찌름 |
| s11 | 식물에도 | ○ | 화분 분홍 튤립이 초록 팔로 만년필을 쥐고 같은 세균의 위 오른쪽(반대쪽)을 찌름. 만년필 수 2 · 세균 1 · 양쪽 반대편 위치 맞음 |
| s11 | 척추동물만이 아니라(척추동물에도 있음) | △ | 척추동물이 펜을 든 모습이 없음. 비척추 · 식물 둘만 보임 |
