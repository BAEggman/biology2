# L07d ㄷ 그림 판독 결과

전체 구도(full.jpg에서 직접 확인): 앞벽 없는 4칸 건물(맨 위 3칸 = 피질, 맨 아래 칸 = 지하). 옥상에 멜론 · 시계(오른쪽 옆구리에 태엽 열쇠) · X 팻말. 해는 옥상이 아니라 오른쪽 하늘에 있다. 초록 호스는 오른쪽 바깥, 검은 케이블은 왼쪽 바깥.

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 부신피질 세 층 | ○ | 옥상 아래 칸이 위에서부터 3개(소금·포도 · 다발·코르크 · 그물·로봇)로 세어진다. 지하 칸이 하나 더 있어 피질 3 + 수질 1로 맞다. |
| s1 | 스테로이드 호르몬을 만든다 | △ | 칸마다 호르몬을 상징하는 물건이 쌓여 있으나 「만든다」는 동작(합성·생산)이나 스테로이드(콜레스테롤 계열)를 나타내는 표지는 없다. |
| s1 | 수질 = 지하 | ○ | 맨 아래 칸이 지하로 그려져 있고 위치(가장 안쪽 · 아래)도 맞다. |
| s1 | 수질은 교감신경을 직접 받는다 | △ | 왼쪽 바깥 검은 케이블이 지하로 들어가는 것은 보인다(방향 맞음). 다만 케이블이 지붕 소켓(멜론 바로 옆)에서 출발해 구불거린다(s6 참조). 「교감」임을 알려 주는 표지는 없다. |
| s2 | 알도스테론(자극받는 쪽) | △ | 레버 끝의 망치 머리가 쓰러진 소금통 옆에 놓여 있어 소금통이 알도스테론 쪽으로 읽히나, 호르몬 자체를 나타내는 물건은 따로 없다. 「작업대」도 별도 작업대 없이 칸 바닥뿐이다. |
| s2 | 혈중 K⁺ 상승 | ○ | 바나나 한 송이(네댓 개)가 구부러진 갈색 관으로 레버 몸체(망치 달린 축)에 연결된다. 바나나 → 관 → 레버로 닿아 있다(끊김 없음). |
| s2 | 안지오텐신 II (두 사슬 고리의 종) | ○ | 큰 고리 2개(사이에 작은 연결 고리, 맨 위는 천장에 잘림)로 이어진 사슬 끝에 종이 달리고, 레버가 아래쪽 고리를 관통해 걸린다. 사슬 → 레버로 닿는다. |
| s2 | 「주로」 자극 = 굵은 레버 | ○ | 바나나와 사슬이 같은 갈색 이중 관 레버에 합류하며, 이 관이 초록 가는 관보다 굵다. 초록 호스의 굵은 관은 중간 · 안쪽 두 칸으로 뻗는다(직접 센 수 2)는 점도 맞다. |
| s2 | ACTH도 일시적으로 자극 | △ | 호스 → 수도꼭지(좁은 밸브) → 얇은 초록 관이 바닥을 따라 종 밑을 지나 망치 뿌리까지 이어져 닿는다(좁고 가늘다 = 약함은 맞음). 「일시적」(시간)은 표현되지 않는다. |
| s3 | 사구대(피질 가장 바깥) | ○ | 맨 위 칸 왼쪽에 둥근 세포 뭉치 한 송이가 1개 있다(수 · 위치 사실과 일치). 맨 위 = 가장 바깥으로 읽힌다. |
| s3 | → 알도스테론 | △ 끊김 | 세포 뭉치(왼쪽)와 소금통 · 망치(오른쪽) 사이에 인부와 소금 자루가 끼어 있고 이어 주는 선 · 관이 없다. 뭉치 → 호르몬 걸음이 이어지지 않는다. |
| s3 | 신장 Na⁺ 재흡수 | ○ | 인부가 쏟아진 소금을 삽으로 떠 도로 자루에 담는 동작이 재흡수로 읽힌다. 담긴 것(소금)과 나오는 것(소금)이 같다. |
| s3 | 「신장」이라는 장소 | △ | 이 칸에 콩팥이 없고 인부 · 자루만 있다. 콩팥은 s10에서 혈류 감소 장기로만 나온다. |
| s3 | K⁺ 분비 촉진 | ✕ | K⁺를 내보내는 물건 · 동작이 없다. 바나나는 s2 쪽 레버에 붙어 있고 인부는 소금만 다룬다. |
| s4 | 코르티솔 | △ | 코르크 마개(소리 연상) 하나가 서 있다. 코르크는 「억제」의 마개로도 읽혀 한 물건이 두 사실을 겸한다. |
| s4 | 다발대 | ○ | 가운데 칸에 세로 막대를 빨간 끈으로 묶은 다발이 2개 있다. 「다발」을 직접 나른다. |
| s4 | 당질코르티코이드 | ○ | 그릇에 담긴 포도(포도당 연상)가 있다. |
| s4 | 혈당 ↑ | △ | 포도 그릇을 작은 탁자 위에 올려놓은 것뿐이다. 늘어나거나 올라가는 동작 · 화살표는 없다. |
| s4 | 면역 억제 | ✕ | 면역을 뜻하는 물건이 없고, 코르크는 아무것도 막고 있지 않으며 그냥 서 있다. |
| s5 | 안드로겐 | ○ | 양철 로봇(android 소리 연상)이 안쪽 칸 오른쪽에 있다. |
| s5 | DHEA | ✕ | 이름 · 기능을 나르는 물건이 없다. |
| s5 | 망상대 | ○ | 안쪽 칸(지하 바로 위)에 잔줄이 서로 교차하는 그물이 있다. 위치도 맞다. |
| s5 | 약한 남성호르몬 | △ | 작은 장난감 로봇이 「약함」으로 읽히나 「남성호르몬」이라는 뜻은 소리 연상뿐이다. |
| s5 | (Sex) | △ | 빨간 하트가 있다. 큰 하트가 로봇보다 두드러져 「약한」과 무게가 어긋나 보인다. s10의 장기 심장과 모양이 달라 혼동 여지가 있다. |
| s6 | 부신수질 = 지하 | ○ | 케이블 끝이 지하 칸으로 들어가 인부 손에 쥐어진다. |
| s6 | 신경(교감) 자극을 받는다 | △ | 굵은 검은 케이블이 있으나 신경 · 교감임을 알려 주는 표지(신호 · 가지)는 없다. 케이블이 옥상 소켓에서 시작해 멜론 바로 옆에서 올라오므로 출처가 송과선 쪽으로도 읽힌다. |
| s6 | 직접 | ○ | 케이블이 세 층 벽 바깥 왼쪽을 지나 어느 층에도 닿지 않고 지하로 들어간다. 호스 같은 중계 구간이 없다. |
| s6 | 세 층 옆을 곧게 지나 직통 | △ | 3층 구간 왼쪽 바깥은 세로로 곧으나, 지붕에서 아치로 올라와 땅 밑에서 S자로 굽어 지하로 들어간다. 「곧게」와 완전히 맞지 않는다. |
| s6 | 즉각 | ✕ | 속도를 나타내는 표지가 이 정거장에는 없다(s7의 홱 잡아당김에 있다). |
| s7 | 즉시 분비 (줄을 홱 잡아당김 → 뚜껑이 터짐) | △ 끊김 | 인부가 줄을 당기는 모습과 뚜껑이 날아가는 모습은 있다. 그러나 줄 끝은 바닥에 늘어져 드럼통에 닿지 않고 사이가 한 통 폭쯤 비어, 줄 → 드럼통이 이어지지 않는다. |
| s7 | 에피네프린 · 노르에피네프린(둘) | △ 어긋남 | 드럼통 4개를 직접 셌고 뚜껑 2개가 날고 연기 2개가 오른다. 호르몬은 2개인데 통은 4개다. 통 속 내용물은 그려져 있지 않다. |
| s7 | 혈당 · 혈압 · 심박 ↑ | ✕ | 이 정거장에는 세 가지를 나타내는 물건이 없다(s10의 빛나는 장기에만 있음). |
| s7 | 투쟁-도피 | △ | 놀란 표정으로 확 당기는 몸짓이 갑작스런 반응으로 읽히나 투쟁이나 도피 동작은 아니다. |
| s8 | 송과선 | △ | 시계 · 멜론이 옥상에 놓여 있으나 「송과(솔방울)」를 나르는 물건은 없다. |
| s8 | 뇌하수체 조절을 받지 않는다 | ○ | 시계에는 호스가 물려 있지 않다. 초록 호스는 오른쪽 옥상 소켓에서 시작해 아래 두 칸 쪽으로만 간다. |
| s8 | 빛을 따른다 | △ 끊김 | 해는 오른쪽 하늘 멀리 있고 햇살이 시계로 향하지 않는다(해 → 시계 이음 없음). 사이에 X 팻말 · 호스가 있다. |
| s8 | 생체리듬 | ○ | 큰 시계가 직접 나른다. |
| s9 | 멜라토닌 | ○ | 그물무늬 멜론 1개가 시계 왼쪽에 있다(위치 · 수 일치). 멜론은 시계 가장자리에 걸쳐 닿는다. |
| s9 | 생체리듬 | △ | 멜론이 시계 옆에 붙어 있어 시계(s8)에 의존한다. 멜론 자체는 리듬을 나르지 않는다. |
| s9 | 수면 조절 | ✕ | 침대 · 잠 · 눈 감김 같은 물건이 없다. |
| s9 | 밤에 분비가 는다 | ✕ 어긋남 | 그림은 해가 쨍쨍한 낮 하늘이고 달 · 별 · 어둠이 없다. 「밤」과 반대 장면이다. |
| s10 | 카테콜아민(드럼통 → 바람) | △ 끊김 | 터진 드럼통에서 오른쪽으로 바람이 나가는 구도는 맞다. 그러나 바람이 지하 오른쪽 벽 바깥에서 시작하고 통에서 바람으로 이어지는 선이 없다. 바깥 호스 끝(노즐)이 바람 옆에 걸려 호스 물줄기로 오해될 여지도 있다. |
| s10 | 티로신 유래 아민 | ✕ | 티로신 · 아미노산을 나타내는 물건이 없다. |
| s10 | 심장 · 뇌 · 골격근 | ○ 의심 | 빛나는 심장 · 뇌 · 알통 팔 3개를 직접 셌고, 바람이 오른쪽으로 불어 세 개 쪽에 닿는다(수 · 방향 맞음). 의심은 사실 쪽이다. 카테콜아민이 뇌 혈류를 크게 늘린다는 것은 뇌 자동조절 때문에 약하다. 교재 분류를 따른 것이라 경미하다. |
| s10 | 혈류 ↑ | △ | 바람 · 반짝임이 혈류 증가로 읽히나 혈관 · 피는 그려져 있지 않다. |
| s10 | 피부 | ✕ 어긋남 | 사실은 피부 · 소화기 · 신장 3개인데 그림에는 위와 콩팥 2개뿐이다. 피부 상징이 없다. |
| s10 | 소화기(위) · 신장(콩팥) | ○ | 위와 콩팥을 직접 셌고(2개) 각각 관 끝에 집게로 조여 있다(집게 2개). 흙 속 오른쪽 아래에 있다. |
| s10 | 혈류 ↓ (불지 않음) | ○ | 바람 줄기가 위 · 콩팥 위치(오른쪽 아래)까지 닿지 않고 집게로 조여 있어, 혈류 감소 · 차단이 맞게 읽힌다. |
| s11 | 시교차상핵(SCN) | ○ | X자 갈림길 팻말(교차)이 시계 오른쪽에 있고(위치 일치) 한가운데에서 손이 나온다. |
| s11 | 시상하부 | ✕ | 시상하부를 나르는 물건이 없다. 팻말은 그냥 옥상에 서 있다. |
| s11 | 멜라토닌 분비의 상위 중추 = 송과선의 시계를 감는다 | ○ | 팻말 한가운데에서 나온 손이 시계 옆구리의 태엽 열쇠를 쥔다. 팻말 → 손 → 열쇠 → 시계로 닿는다(끊김 없음). 열쇠가 돌아가는 동작 표지(화살표)는 없다. |
| s11 | 멜라토닌 분비를 지배(시계 → 멜론) | △ | 감기는 대상은 시계이고, 멜론(멜라토닌)은 시계에 걸쳐 놓인 것뿐이라 직접 구동 관계는 약하다. |
