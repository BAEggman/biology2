# L50b ㄷ 그림 판독 결과 (체온조절 산장)

본 자료: full.jpg, s1~s13(+ 확대 조각), stops.tsv. 판정은 그림에 실제로 보이는 것만 근거로 했다. 수는 직접 센 값.
공통 관찰: 방 셋(왼쪽: 벽난로·온도계·버터선반 / 가운데: 도마뱀·열대어 선반 + 침대 / 오른쪽: 사우나) 구분은 맞다. 산장지기(s2·s10), 박쥐(s3·s13), 도마뱀(s2·s11), 사우나 사람(s5·s8), 등산객(s6·s8)은 한 개체가 두 정거장 몫을 겸한다.

| s1 | 체온조절 = 체온을 정상 범위 안에 유지 | ○ | 왼쪽 방 벽에 큰 온도계 1개. 빨간 기둥 끝이 초록 띠(띠 높이 약 65px) 안쪽 아랫부분에서 멈춤. 다만 벽 온도계라 「몸」이 아니라 방 온도로도 읽힘(체온이라는 뜻은 설명에 의존). |

| s3 | 내온/외온과 항온/변온은 다른 축 | △ | 어항·박쥐 두 물건이 서로 어긋난 짝(외온인데 항온, 내온인데 변온)이라는 표지는 없음. 「두 축」을 드러내는 장치(십자표 등)는 그림에 없음. |
| s3 | 열대어는 외온 | ○ | 어항 1개에 주황 물고기 1마리, 몸 밖 열원인 검은 히터 1개가 어항 안에 보임. 물고기는 금붕어 모양(열대어는 아님)이나 주황색이라 판독엔 지장 없음. |
| s3 | 열대어는 항온 | △ | 히터 1개는 보이나 「일정함」을 보이는 온도계·다이얼은 이 어항에 없음. 같은 선반 도마뱀 사육장의 다이얼(s11)을 끌어와야 함. |
| s3 | 휴면 박쥐는 내온 | △ | 박쥐 1마리(왼쪽 처마 밑, 거꾸로 매달려 눈 감음, 서리·고드름). 「내온동물임」을 나르는 표지(자기 열을 내는 모습)가 없음. |
| s3 | 휴면 박쥐는 변온 | ○ | 몸에 서리가 덮이고 주변에 고드름·물방울: 체온이 바깥 추위를 따라 내려간 상태로 읽힘. |
| s4 | 복사 = 닿지 않고 | ○ | 스웨터 사람 1명이 의자(나무 의자 1)에 앉아 손바닥 2개를 편 채 내밀었고 불꽃과 손 사이 틈이 있음(가깝긴 하나 닿지 않음). |
| s4 | 전자기파로 열을 주고받음(주황 물결이 손바닥에 닿음) | △ · 끊김 | 주황 물결선을 세어 보니 4줄(위쪽 3줄 + 아래쪽 1줄). 위 3줄은 손바닥보다 위쪽 높이에서 얼굴·가슴 쪽으로 가고, 아래 1줄은 손 아래로 지나감. 어느 줄도 손바닥 위에 끝나지 않아 「불→손바닥」 사슬이 손바닥 앞에서 끊김. 한 방향(불→사람)뿐이고 「주고받음」은 없음. 몸에서 나가는 선도 없음. |
| s4 | 열이 드나드는 길은 복사·증발·대류·전도(4갈래) | △ | 그림에 난로 손(복사)·사우나 땀(증발)·바람 등산객(대류)·얼음(전도) 4곳이 있어 수 4 = 4로 맞음. 그러나 s4 물건은 복사 하나뿐이고, 4갈래가 한 묶음임을 보이는 표지는 없음. |
| s5 | 땀(액체)이 살갗에 | ○ | 사우나 사람 1명. 이마·뺨에 굵은 방울 약 2~3개, 머리 둘레에 튀는 방울 약 5개(합 약 7). 몸통·팔 피부에는 방울이 없고 이마·얼굴 위주. |
| s5 | 액체가 기체가 된다(땀 → 김) | △ · 끊김 · 어긋남 | 흰 김 물결은 3줄(굵은 것 2 + 작은 것 1)이 머리 위 벽 앞에 떠 있고 머리·피부와 닿지 않음 → 땀방울에서 김으로 이어지는 사슬이 끊김. 사우나라는 장소 때문에 이 김은 땀이 증발한 것이 아니라 사우나 증기로 읽힘(담긴 것: 땀 ≠ 나온 것으로 읽히는 것: 방 증기). |
| s5 | 열을 많이 빼앗는다 | △ | 파란 바람결 5줄 정도가 시원함을 암시하나 「몸에서 열이 빠져나가는」 표지(열선·화살)가 없음. 사람은 새빨갛게 웃고 있어 열을 받는 모습으로 읽힘. |
| s5 | 땀샘은 증발 냉각으로 식힌다 | ✕ | 땀샘(땀구멍·샘 그림)이 없고 방울만 있음. 식은 결과(몸 색 변화)도 없음. |
| s6 | 대류 = 몸 표면을 지나는 공기의 흐름 | ○ | 등산객 1명의 목도리가 옆으로 날리고, 흰 바람 곡선이 약 8줄 소용돌이침. (「공기나 물」 중 물의 흐름은 없으나 「~나」라 공기만으로 충분.) |
| s6 | 열을 실어 감 | △ | 머리 둘레에 연한 분홍 물결 약 7줄(머리 위 왼쪽 3, 목 왼쪽 2, 얼굴 오른쪽 2). 색이 연하고 일부는 바람 앞쪽(오른쪽)에도 있어 「바람에 실려 멀어지는」 방향이 뚜렷하지 않음. |
| s7 | 전도 = 맞닿은 물체 사이 | ○ | 사람 1명이 투명한 파란 얼음덩이 1개에 걸터앉고 손도 얼음을 짚음. 접촉이 분명. |
| s7 | 분자 충돌로 | ✕ | 분자·입자·부딪침을 나르는 물건이 없음. |
| s7 | 열이 옮겨 감 | ○ | 엉덩이·허벅지에서 얼음 앞면으로 빨간 화살 3개가 아래로 향함(몸 → 얼음 방향 맞음). 밑에 녹은 물 웅덩이가 있어 얼음이 열을 받았음이 보이고 얼굴 찡그림도 있음. |
| s8 | 피부 혈관 확장 | ○ | 사우나 사람의 양팔에 붉은 핏줄이 가지처럼 불거짐(팔 2개 모두). |
| s8 | → 피부 혈류 ↑ | ○ | 온몸 살갗이 새빨강. 핏줄 → 붉은 피부로 같은 몸 위에서 이어짐. |
| s8 | → 열 방출 ↑ | ✕ · 끊김 · 어긋남 | 몸에서 열이 빠져나가는 표지가 없음. 사우나(뜨거운 방, 김·땀)는 열을 받는 환경이라 열 방출이 커진다는 뜻과 맞지 않음. 담긴 것(방출↑) ≠ 나오는 것(열 흡수 환경). |
| s8 | 혈관 수축 | ✕ | 등산객에게 혈관 그림이 없고 창백한 얼굴색만 있음. 수축 자체를 나르는 물건 없음. |
| s8 | → 혈류 ↓ | ○ | 등산객 얼굴이 창백한 청백색(단, 두 뺨에는 분홍 홍조 동그라미가 있어 완전한 창백은 아님). |
| s8 | → 열 보존 | ✕ · 끊김 · 어긋남 | 같은 등산객 머리 둘레에 빨간 열선 약 7줄이 바깥으로 흩날림(s6) → 그림은 열이 새는 모습이라 「보존」과 반대. 목도리·움츠린 어깨가 보존으로 읽힐 여지는 있으나 혈관과 이어지지 않음. |
| s9 | 다리로 내려가는 동맥피 | ○ | 흰 거위 1마리, 유리처럼 투명한 긴 다리 2개. 각 다리마다 빨간 관 1줄에 아래쪽 화살(합 2줄). |
| s9 | 올라오는 정맥피 | ○ | 각 다리 빨간 관 바로 오른쪽에 파란 관 1줄, 위쪽 화살(합 2줄). 위치·방향 사실과 일치. |
| s9 | → 열을 넘긴다 | ○ | 각 다리 두 관 사이에 작은 빨간 화살 3개씩 오른쪽(빨강 → 파랑)으로 건너뜀(다리당 3, 합 6). 「셋」은 다리 하나 기준으로 맞음. 두 관이 맞닿아 있어 사슬이 이어짐. |
| s9 | → 열 손실을 줄인다 | △ | 결과 표지가 없음. 빨간 관은 발끝까지 같은 빨강, 파란 관은 위까지 같은 파랑이라 「내려오며 식고 올라오며 데워지는」 온도 변화가 안 보임. 언 연못·눈은 찬 환경으로만 보임. |
| s10 | 갚아야 한다 → 대사율 ↑(장작을 난로에 밀어 넣음) | ○ | 산장지기 1명이 작은 삽 1개로 장작 1개를 배의 난로 입구(문 열림, 불 활활)에 밀어 넣음. 연료가 난로로 들어가는 방향. |
| s10 | 행동 | ✕ | 이 정거장 그림에서 행동으로 열을 갚는 모습(웅크림·이동 등)을 나르는 물건이 없음. 벽난로 사람(s4)은 다른 정거장 몫. |
| s10 | 형태 조절 | △ | 털외투가 단열로 읽히나 「몸 형태」가 아니라 옷이고, 갚음의 한 수단으로 표시된 것은 아님. |
| s10 | 못 갚으면 저체온 | ○ | 눈밭에 웅크린 사람 1명: 푸르스름한 살갗, 서리, 떠는 선, 배의 난로 문은 열렸고 속이 검게 꺼져 있음. 산장지기 난로(불 있음)와 짝으로 대비됨. (연못은 왼쪽 가장자리에 조금만 보임.) |
| s11 (기초대사율) | 쉬고(안정) | ○ | 좁은 침대에 반듯이 누운 사람 1명, 팔다리 늘어짐. 움직임 표지 없음. |
| s11 | 깨어 있음 | ○ | 눈이 떠져 위를 보고 있음(눈동자 보임). 측정 대상 깨어 있음 사실과 맞음. |
| s11 | 굶고(공복) | △ · 어긋남 | 침대 곁 바닥에 빈 접시 1개. 「굶어서 비었다」와 「다 먹어 비었다」 두 읽기가 다 가능하고, 접시가 바닥에 놓여 식사 직후로도 읽힘. 먹는 중이 아님은 맞음. |
| s11 | 편안(적온) | △ | 담요 없이 얇은 옷으로 누웠고 표정은 무덤덤. 이 방에 온도 표지가 없어 「편안한 온도」를 나르는 물건이 없음. (온도계는 왼쪽 방.) |
| s11 | 자라지 않는 | △ | 콧수염 난 어른이라 성장기가 아님을 약하게 암시. 직접 표지는 없음. |
| s11 | 내온동물 | ○ | 대상이 사람. 코에서 관이 벽의 둥근 계기판 1개로 이어짐(관 1줄, 한쪽 끝은 코 밑, 다른 쪽은 계기판 아래). 측정 장치가 이어져 있음. |
| s11 | 표준대사율 = 외온동물 | ○ | 위 선반 사육장의 도마뱀 1마리가 엎드려 쉼. 먹이 없음. 사람 위쪽 선반이라 짝으로 읽힘. |
| s11 | 정한 온도 | ○ | 사육장 옆(오른쪽 위 패널)에 온도 조절 다이얼 1개, 열등 1개. 같은 선반의 어항 히터(s3)와 섞일 수 있으나 도마뱀 쪽 다이얼은 분명. |
| s11 | (측정 관 → 계기판 연결 확인) | (위 내온동물 행에 포함) | 코 → 관 → 계기판 사슬이 끊김 없이 이어짐. |
| s12 | 작을수록(작은 벌새·큰 야크) | ○ | 큰 야크 1마리(폭 약 230px)와 작은 벌새 1마리(약 40px)의 크기 대비가 뚜렷. 야크는 오른쪽 눈밭, 벌새는 오른쪽 처마 모이통(맞음). |
| s12 | 부피에 비해 표면적이 크다 | ✕ | 표면적·부피를 나르는 물건(상자 비교·표면 표시 등)이 없음. |
| s12 | 열을 빨리 잃는다 | ✕ | 벌새에게 열이 새는 표지(열선·서리·떨림 선 외의 것)가 없음. 날개 떨림 선은 움직임이지 열 손실이 아님. |
| s12 | → 체중당 대사율이 높다 | ○ · 끊김 | 벌새가 날개를 떨며 빨간 모이통에 부리를 꽂고 빨아 먹음 vs 야크는 누워 건초(입에서 늘어진 풀 두 가닥)를 천천히 씹음 → 속도 대비로 「높은 대사」는 읽힘. 그러나 앞 두 걸음(표면적·열 손실)이 그림에 없어 「→」 사슬이 중간에서 끊김. |
| s13 | 휴면 = 활동·대사가 줄어든 | △ | 고슴도치 1마리 눈 감고 웅크려 자고, 박쥐 1마리(왼쪽 처마, s3과 같은 개체)도 잠. 「잠」은 보이나 대사 저하 표지는 없음. |
| s13 | 짧은 | ✕ | 시간 길이를 나르는 물건(달력·시계·쌓인 눈 두께 비교 등)이 없음. 고슴도치와 박쥐가 길이 대비로 짝지어 보이지 않음. |

## 기초대사율(s11) 측정 대상 상태 따로 정리
- 깨어 있는가: 눈 뜸, 위를 봄. 맞음.
- 쉬는가: 반듯이 누워 팔다리 늘어뜨림. 맞음.
- 공복인가: 빈 접시는 있으나 「굶음」과 「다 먹음」이 갈림. 약함(△·어긋남).
- 편안한 온도인가: 이 방에는 온도 표지 없음. 약함(△).
- 자라지 않는가: 콧수염 어른으로만 암시(△).
- 표준대사율 쪽(도마뱀): 엎드려 쉬고 먹이 없고 다이얼 있음. 대체로 맞음.

## 의심 (사실 자체, 그림 판정과 분리)
- s11 「기초대사율 = 쉬고 굶고 편안하고 자라지 않는 내온동물」: 기초대사율은 그런 상태 동물의 「대사 속도」이지 동물 자체가 아님. 표준대사율도 같음. 내용은 맞고 표현이 느슨한 경미한 문제. 다른 사실(s1·s3~s10·s12·s13)은 생물학적으로 의심할 점 못 찾음.
- (참고, 사실이 아니라 그림) s3의 어항 물고기는 금붕어 모양으로 열대어가 아님. s5의 사우나는 습한 열이라 증발 냉각의 예시로는 환경이 어색함.
