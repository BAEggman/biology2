| s4 | 닿지 않고 | ○ | 두 손바닥을 편 채 불꽃과 손 사이에 빈 공기 틈. 불에 닿지 않음. |
| s4 | 전자기파로 열을 주고받음 | △ | 주황 물결선 약 5개(위 3, 아래 2). 선이 손바닥 위치부터 손 너머 얼굴·몸쪽에 걸쳐 있고 불꽃~손바닥 사이 틈엔 거의 없음. 한쪽 방향뿐이라 「주고받음」도 약함. |
| s4 | 열이 드나드는 길 4가지 | △ | 복사는 이 정거장, 증발·대류·전도는 s5·s6·s7에 따로 있음. 한데 묶는 물건 없음. |
| s5 | 증발 = 액체→기체 | △ · 끊김 | 땀방울 약 8개(이마 2, 머리 둘레 6)와 흰 김 3줄. 김은 머리 위 허공에서 시작해 땀방울·살갗과 안 닿음. |
| s5 | 열을 많이 빼앗는다 | △ | 파란 바람결 5줄이 시원함은 알리나 사람 왼쪽 벽 쪽에 있고 몸에 안 닿음. 열이 빠져나가는 화살 없음. 바람 때문에 s6 대류와 헷갈림. |
| s5 | 땀샘은 증발 냉각 | ✕ | 땀샘 그림 없음. 땀방울뿐. |
| s6 | 몸 표면을 지나는 공기 흐름 | ○ | 흰 바람 곡선 약 6줄, 목도리가 왼쪽으로 수평으로 날림. 왼쪽 위 비탈. |
| s6 | 열을 실어 감 | △ | 빨간 열 김 약 6개(머리 왼쪽 3, 뺨 왼쪽 1, 오른쪽 2). 바람 가는 쪽으로만 흐르지 않고 양쪽에 흩어짐. 흰 선은 오른쪽 끝이 말린 모양이라 방향이 애매(목도리는 왼쪽). |
| s7 | 맞닿은 물체 | ○ | 사람이 파란 얼음덩이(1개) 위에 앉음. 접촉면 있음. |
| s7 | 열이 옮겨 감 | ○ | 빨간 화살 3개가 허벅지·엉덩이 쪽에서 얼음 속으로 아래를 향함. 밑에 녹은 물웅덩이. 얼굴 찡그림. 방향(몸→얼음) 사실과 맞음. |
