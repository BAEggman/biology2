# ㄷ 판독 결과 (그림 판독자, 읽기 전용)

판정 기호: ○ 그림에서 뚜렷이 나름 · △ 부분적/모호 · ✕ 그림에 없음. 끊김 = 사슬 걸음이 이어지지 않음. 어긋남 = 담긴 것과 나오는 것, 또는 수·방향·위치가 사실과 다름.
전체 배치: 가운데 기둥이 그림을 둘로 가름. 왼쪽 = 위층/아래층 두 층(창살문 둘, 계단), 오른쪽 = 열쇠구멍판 + 긴 복도.

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 같은 아세틸콜린(=같은 열쇠) | ○ | 열쇠 2개를 직접 셈: 왼쪽 창살문 자물쇠에 1(주먹이 쥠), 오른쪽 벽 열쇠구멍판에 1. 둘 다 둥근 고리 머리의 놋쇠 열쇠로 모양 동일. |
| s1 | 양쪽: 왼쪽 창살문 · 오른쪽 맨 벽 | ○ | 기둥 왼쪽 = 창살문의 열쇠구멍, 기둥 오른쪽 = 문 없는 벽에 붙은 놋쇠판. 열쇠구멍 위치 맞음. |
| s1 | 결과가 갈린다 | △ | 왼쪽은 문이 열리고 소금이 쏟아지나, 오른쪽은 아무 일도 안 일어남(변화 없음). '갈림'은 읽히나 오른쪽 '결과'가 그려진 게 없어 비대칭. |
| s1 | 흥분 · 억제를 정하는 것은 수용체 | ✕ | '흥분'과 '억제'를 나르는 물건이 없음. 열쇠 같음 / 구멍 다름만 보이고 흥분·억제 표지(예: 열림 vs 잠김)는 s1 그림에 없음. |
| s2 | 니코틴성 nAChR(열린 담뱃갑) | ○ | 왼쪽 위층 바닥에 열린 담뱃갑, 담배 약 6~7개 쏟아짐. |
| s2 | 리간드개폐 이온통로 직결(열쇠구멍이 문에 바로 박힘) | ○ | 열쇠구멍 달린 자물쇠판이 창살문 가장자리에 붙어 있고 열쇠가 그대로 꽂힘. 문 = 통로, 열쇠 = 리간드로 직결. |
| s2 | 주먹이 열쇠를 돌리자 그 자리에서 열림 · 즉각 | △ | 열쇠 쥔 주먹 1개, 문은 비스듬히 열려 있음(○). 그러나 '돌림' 동작 표시(회전선·화살표)는 없고 '즉각'을 보이는 시간 표지도 없어 열린 상태만 보임. |
| s2 | 바깥 소금 자루에서 소금이 쏟아져 듦 | △ | 파란 하늘이 보이는 바깥 쪽 문간의 자루에서 소금이 흘러 안쪽 바닥에 쌓임(방향 안쪽, ○). 그러나 열리는 창살문과 소금이 들어오는 문간은 서로 옆의 다른 개구부로 그려져, 열린 문을 소금이 통과하지 않음 → 열림→유입 걸음이 약하게 이어짐. 끊김. |
| s2 | Na⁺ 유입으로 탈분극 | △ | 소금 = Na⁺ 유입(자루 1, 소금 더미 1)은 ○. '탈분극'(막전위가 올라감)을 나르는 물건은 없음. 소금은 NaCl이라 Cl⁻도 함께 읽힐 수 있음. |
| s3 | 골격근 신경근접합부 | △ | 근육 팔 1개가 위층 벽을 뚫고 나옴. 신경근접합부(신경 말단 + 근섬유 사이 시냅스)를 나르는 물건은 없고 팔만 있음. |
| s3 | 수용체는 니코틴성 | △ | 팔은 위층 창살문 · 소금 자루 오른쪽 벽에 가까이 있어 '곁에 있음'으로만 니코틴 문(담뱃갑 · 열쇠)과 묶임. 팔 자체에는 열쇠 · 열쇠구멍 없음(빈 주먹이라 열쇠를 안 쥔 것은 ○). 위치(위층, 기둥 왼쪽) 맞음. |
| s3 | 골격근 수축 | ○ | 팔이 굽혀져 알통이 불끈 솟고 주먹 쥠. 벽이 부서지는 파편 표시. |
| s4 | 근육 팔은 없고, 아래층 창살문 | ○ | 아래층 구역엔 팔 없음, 창살문 1개 있음(위층 팔과 층이 다름, 위치 맞음). |
| s4 | 회색 재킷 사람이 위층과 똑같은 열쇠로 문을 연다 | ○ | 사람 1명, 회색 재킷, 똑같은 둥근 놋쇠 열쇠를 자물쇠에 꽂고 문은 비스듬히 열림. |
| s4 | 절전 뉴런의 ACh가 절후 뉴런의 니코틴 수용체를 연다 | △ | '열쇠 쥔 사람 → 문'의 한 걸음은 ○. 그러나 '절전 뉴런' 표지(사람=절전)가 따로 없고 '절후 뉴런'(문 뒤 누군가)도 없음. 문 앞 바닥에 소금 흔적이 있어 Na⁺ 유입과는 맞음. 위층 문의 주먹 소매도 회색이라 위층/아래층 사람 구분이 흐림 → 어긋남(사람 표지 겹침). |
| s4 | 자율신경절(장소) | ✕ | 신경절을 나르는 물건 없음. 단지 아래층이라는 위치뿐. |
| s5 | 맨 벽에 열쇠구멍판만 홀로, 뒤에 문 없음 | ○ | 열쇠가 꽂힌 놋쇠판이 무늬 없는 벽에 붙어 있고 문이나 창살 없음. 오른쪽 위치 맞음. |
| s5 | 무스카린성(붉은 갓 흰 점 버섯) | ○ | 버섯 1개, 붉은 갓에 흰 점 약 11개. 판 아래쪽 바닥(복도 벽 모서리)에 있어 '그 앞 바닥'은 대체로 맞음. |
| s5 | G단백질 연결 수용체(GPCR) | △ | '문 없음 = 이온통로 아님'은 읽히나 G단백질을 나르는 물건은 s5에 없음(s6에 나옴). |
| s5 | 느리고 길게 작용 | ✕ | 느림 · 오래감을 나르는 표지 없음. 열쇠만 꽂혀 있음. |
| s6 | 열쇠구멍 곁에서 시작하는 긴 복도 | △ | 열쇠구멍판은 복도 왼쪽 벽 중간 높이에 걸려 있고, 복도는 그 옆에서 안쪽으로 뻗음. 시작 위치는 근접하나 맞닿지 않음. |
| s6 | 나무 지게를 진 지게꾼이 짙은 회색 칩을 쳐들고 달림 | ○ | 사람 1명, 등에 나무 사다리꼴 지게, 오른손에 짙은 회색 사각 칩을 쳐들고 달리는 자세. |
| s6 | 무스카린성 수용체는 G단백질에 신호를 건넨다 | △ · 끊김 | 지게꾼은 열쇠구멍에서 떨어져 등을 돌리고 복도 안쪽으로 달아남. 열쇠구멍 → 지게꾼의 접촉 · 건네받는 장면이 없고, 지게꾼도 칩을 누구에게 건네지 않고 혼자 쥠. 수용체 → G단백질 걸음 끊김. |
| s6 | 복도 끝이 위층 계단과 아래층 복도로 갈라짐 | △ · 끊김 | 복도 끝에 계단이 위로 오르고(칸 약 15~17개) 그 위에 선반과 시계, 복도는 바닥에서 오른쪽 문들로 이어짐. 갈래는 읽히나, 아래층 갈래의 피자 · 물자루(s8)는 지게꾼보다 화면 앞쪽(복도 입구 쪽) 바닥에 있어 지게꾼이 달려가는 방향(복도 끝)과 반대. 지게꾼 → 아래 갈래 걸음 끊김. |
| s6 | 심장의 M₂는 Gi/o, 샘과 평활근의 M₃는 Gq | ✕ · 어긋남 | Gi/o와 Gq를 구분하는 물건이 s6에 없음. 칩 1개, 지게꾼 1명이 두 갈래(M₂, M₃)에 동시에 해당해 서로 다른 두 G단백질이 하나로 그려짐(담긴 것 1 / 나오는 것 2). |
| s6 | (참고) 지게꾼 모양 | 어긋남 | 지게꾼은 갈색 머리 · 회색 재킷으로 s4의 회색 재킷 사람(절전 뉴런 자리)과 같은 모습이라 서로 다른 역할이 같은 인물로 읽힘. |
| s7 | M₂ → Gi/o(위층 갈래) | ✕ · 끊김 | 위층 갈래 위치(계단 끝)만 있음. Gi/o 표지 없고 지게꾼은 위층에 도착하지 않음. M₂/Gi/o → 이후 걸음 이어짐 없음. |
| s7 | AC 억제(압착기 + 수평 손잡이에 걸린 자물쇠) | ○ | 놋쇠 압착기 1대, 손잡이에 자물쇠 1개가 걸려 손잡이를 막음. 자물쇠 구멍도 열쇠구멍 모양. |
| s7 | cAMP↓(빈 받침) | ○ | 압착기 옆 받침(사각 접시) 1개가 비어 있음. '감소'보다 '없음'에 가까움. |
| s7 | AC 억제 → cAMP↓ | ○ | 잠긴 압착기와 바로 곁의 빈 받침이 한 선반 위에 붙어 있어 걸음 이어짐. |
| s7 | 심박수↓(두 손가락이 시계 진자를 늦춤) | △ | 손가락은 곧게 편 2개(집게 · 가운데) + 접힌 2개 + 엄지. 진자 추는 엄지와 손바닥 사이에 잡혀 있고 편 두 손가락은 추에 닿지 않음. 추 주변 흔들림선으로 '늦춤'이 읽히나 두 손가락이 직접 늦추는 모습은 아님. 시계 바늘은 평범(10시 8분쯤). |
| s7 | cAMP↓ → 심박수↓ | ✕ · 끊김 | 압착기(왼쪽 선반)와 시계 · 손(계단 오른쪽)은 떨어져 있고 잇는 선 · 물건이 없음. 빈 받침 → 진자 걸음 끊김. 또 지게꾼 칩이 압착기에 닿는 장면 없어 Gi/o → AC도 끊김. |
| s8 | M₃ → Gq(아래층 갈래) | ✕ · 끊김 | Gq 표지 없음. 지게꾼이 아래 갈래에 닿지 않고 피자 · 물자루는 지게꾼 뒤(앞쪽 바닥). |
| s8 | PLC가 PIP₂를 IP₃·DAG로 절단(피자 커터가 원판을 둘로 가름) | ○ | 피자 원판 1개가 지름선으로 잘려 2조각, 가운데에 커터 1개(바퀴 1). 두 조각이 같은 모양이라 IP₃와 DAG를 구분하지는 못함(△ 성분 있음). |
| s8 | IP₃ → Ca²⁺ 방출(세 손가락이 가죽 물자루를 짜서 물방울이 떨어짐) | ○ · 끊김 | 물자루 1개, 물방울 3개(직접 셈). 손: 말아 쥔 손가락 3개(손톱 3개) + 엄지로 쥐어 '셋' 맞음. 그러나 피자 조각 → 손 · 자루 사이 접촉이 없고 서로 떨어져 있어 IP₃ 조각 → 방출 걸음 끊김. |
| s8 | 평활근 수축 | △ | 가죽 자루를 쥐어 짜 구겨짐 = 수축으로 읽을 수는 있으나 '평활근'을 나르는 물건 아님. |
| s8 | 샘 분비 | ✕ · 어긋남 | 물방울(3개)은 Ca²⁺ 방출에도 쓰이고 샘 분비도 겸함. 샘(분비샘)을 나르는 별도 물건이 없음. Ca²⁺이 나오는 것과 샘이 분비하는 것이 같은 물방울로 뭉개짐. |
| s8 | DAG | ✕ | 반쪽 조각 하나가 DAG인지 표지가 없고 이후 쓰임도 없음(사실 문장은 DAG를 '절단 산물'로만 언급하므로 경미). |

## 사슬 점검 요약
- s2 열림→소금 유입: 문과 소금 문간이 서로 다른 개구부라 약하게 이어짐 (끊김 1로 셈).
- s6 열쇠구멍 → 지게꾼 → 두 갈래: 접촉 없음 (끊김 1 + 갈래 끊김 1).
- s7 G단백질 도착 → 압착기 → 받침 → 진자: 받침 → 진자 구간 끊김 (끊김 1, Gi/o → AC도 끊김 1로 따로 셈).
- s8 G단백질 → 커터 → 피자 → 손: 지게꾼 → 커터 끊김 1, 피자 → 손 끊김 1.

## 의심 (그림 판정과 따로)
- 없음. 참고만: s7 '심박수↓'는 cAMP↓ 외에 Gβγ → GIRK(K⁺ 유출 · 과분극) 경로도 주경로로 알려져 있어 사실 문장은 단순화되어 있음(오류는 아님). s5 붉은 갓 버섯(광대버섯)은 이름 유래용 소재이며 실제 무스카린 함량은 매우 적음(소재 선택일 뿐 사실 문장과 무관).
