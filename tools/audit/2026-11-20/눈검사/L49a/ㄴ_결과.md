# ㄴ 판독 결과 (L49a)

주의: 폴더에 정거장 번호 안내가 없어 sN 파일명은 「그 물건이 가장 잘 보이는 파일」 기준으로 적었다 (s2/s3/s12_1~2 = 섬의 집 네 채, s4 = 헛간, s7 = 수조, s8 = 홈통·국자, s9/s12_3 = 코르크·근육남, s10/s12_4 = 달리기, s11/s12_5 = 통, s5 = 모자 쓴 사람, s6 = 사슬 집).
공통 장면: 섬에 집 네 채(왼쪽부터 방망이+알 / 주사기 의사 / 원뿔 모자+줄 / 사슬) = 췌장 섬 세포 네 종류로 보임. 포도 = 혈당(포도당), 수조 = 혈액.

## 남은 물건 (어느 용어에도 못 이음)
전선에 걸린 방망이와 주사기, 지붕 위 못, 창턱의 천, 통나무, 오른쪽 돔 건물, 손수레와 체크무늬 천, 홈통 물방울, 수조 속 초록 띠, 포도 쟁반을 든 아이.
