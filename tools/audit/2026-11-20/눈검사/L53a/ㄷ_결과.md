# ㄷ 그림 판독 결과 (L53a/ㄷ)

판정: ○ = 그림에 보임 / △ = 약하거나 간접 / ✕ = 안 보임. 센 수는 full.jpg · sN 조각에서 직접 센 것.
stops.tsv 사실 칸에 「→」 사슬은 없다. 그래서 물건끼리 닿는지는 그림 속 연결(물건 → 물건)로 따로 검사했고, 끊긴 곳은 없다.
- 봉투 → 우편함 → 기둥 → 등
- 천장 → 집게 → 사탕
- 천장 → 기둥 → 대갈못 → 기둥
- 그물 → 매듭 → 기둥 → 살구 구슬줄
- 머리 → 사슬 → 구슬 덩이
- 기둥 끝 → 작업대 → 일꾼

## 의심 (그림 판정과 별개)
- s3: 「플립플롭은 드묾」(자발적)과 「플립페이스가 옮겨」(ATP로 능동 수송)는 별개 현상인데 한 사실로 묶여 있다. 플립페이스의 작용은 드물지 않다.
- s5: 소기름 = 스테아르산 · 돼지기름 = 팔미트산은 단순화다. 실제로는 둘 다 올레산이 가장 많고 스테아르산 · 팔미트산을 함께 포함한다.
- s9: 「소수성 부분 = α나선」은 단순화다. 막관통 부분이 β통(포린)인 단백질도 있다.
- s11: 식별 표지의 예로 면역글로불린은 느슨하다. 세포 표면 식별 표지는 보통 MHC 당단백질이나 ABO 당지질을 든다.
