# L04a ㄷ 그림 판독 결과

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 동물 발생 | ○ | 빵집 작업대 한 장면에 큰 반죽 공 · 벽 조리법 카드 · 쟁반 둘이 한꺼번에 놓여 발생 한 판을 이룸 |
| s1 | 낭배 | ○ | 왼쪽 큰 반죽 공 1개를 손가락이 눌러 굴이 난 모습 + 카드 끝 칸 |
| s1 | 세 배엽 | ○ | 큰 공의 잘린 면의 겹을 직접 세니 파랑 · 빨강 · 노랑 3겹 |
| s1 | 선구 vs 후구의 세 짝 | ○ | 왼쪽 쟁반: 어긋난 피라미드 · 덩어리 · 붉은 금 덩이 = 3, 오른쪽 쟁반: 곧은 탑 · 공 · 주머니 = 3, 짝 3개가 같은 줄에 마주 놓임. 달팽이는 왼쪽 · 불가사리는 오른쪽 |
| s2 | 접합자 | ○ | 카드 첫 칸 매끈한 덩이 1개 |
| s2 | → 난할 | ○ | 둘째 칸 십자 금(선 2줄로 4구획), 첫 칸에서 화살표로 이어짐 |
| s2 | → 포배 | ○ | 셋째 칸 반쪽이 잘려 속이 빈 껍질, 화살표로 이어짐 |
| s2 | → 낭배 | ○ | 넷째 칸 껍질 속이 눌려 들어간 굴, 화살표로 이어짐(화살표 3개로 4칸 이어짐, 끊김 없음) |
| s2 | 난할은 쪼개질 뿐 커지지 않는다 | ○ | 네 공의 폭이 거의 같음(대략 145 · 140 · 140 · 145). 다만 금만 그어졌을 뿐 실제로 떨어진 조각은 없음 |
| s3 | 포배 한쪽이 안으로 밀려 | △ | 거대한 손가락이 큰 공 오른 옆구리를 누르는 동작은 뚜렷함. 그러나 큰 공은 속이 찬 반죽 덩이라 속 빈 포배가 아님(포배는 카드에만 있음) |
| s3 | 굴(원장)이 되고 | ○ | 잘린 면 안쪽에 갈색 굴 통로 1개가 입구에서 왼쪽 안으로 이어짐(손가락은 오른쪽에서 누르고 굴은 왼쪽 안으로 향해 방향 맞음) |
| s3 | 입구가 원구 | △ | 둥글고 어두운 원반 1개가 굴 입구에 있고 손가락 끝이 닿음. 다만 구멍이라기보다 표면에 얹힌 단추 · 뚜껑처럼 보임 |
| s4 | 세 배엽 | ○ | 잘린 면 겹 3개 |
| s4 | 바깥 외 | ○ | 가장 바깥 겹이 파랑 |
| s4 | 가운데 중 | ○ | 가운데 겹이 빨강 |
| s4 | 안 내 | ○ | 가장 안쪽 겹이 노랑 |
| s4 | 겹의 자리가 곧 이름 | ○ | 바깥 → 안 순서가 파랑 → 빨강 → 노랑으로 외 · 중 · 내 자리와 맞음 |
| s5 | 외배엽 = 외피 | △ 끊김 | 선반 위 가죽 조각이 외피를 떠올리게 함. 그러나 파란 끈은 대롱 입구로만 들어가고 가죽에는 닿지 않음 |
| s5 | 중추신경 | ○ | 파란 끈이 닿는 선반 위 속 뚫린 대롱 1개 |
| s5 | 신경관 | ○ | 한쪽 끝이 뚫린 관이고 끈이 그 입구로 들어감 |
| s5 | 뇌 | △ | 대롱 몸통에 둥근 혹 2개가 붙어 있으나 뇌로 읽을 단서가 약함 |
| s5 | 겉 겹이 접혀 관이 된다 | ✕ | 접히는 동작이 없음. 이미 완성된 관이 선반에 있고 파란 끈만 이어질 뿐 파란 겹이 접히는 장면이 없음 |
| s6 | 중배엽 = 근육 | ○ | 빨간 끈 끝이 작업대 위 팔뚝(알통 1개) 잘린 단면에 닿음 |
| s6 | 대부분의 기관 | △ 끊김 | 연장 상자(망치 · 펜치 · 렌치)로 여러 기관을 떠올릴 수는 있으나 빨간 끈은 팔뚝에서 끝나고 상자에는 닿지 않음. 상자는 세워진 채이고 쏟아지지 않음(렌치 1개만 밖) |
| s6 | 뼈 | ✕ | 뼈 모양 물건 없음(망치 · 펜치 · 렌치뿐) |
| s6 | 심장 | ✕ | 심장 모양 물건 없음 |
| s6 | 콩팥 | ✕ | 콩팥 모양 물건 없음 |
| s6 | 생식샘 | ✕ | 생식샘을 나타내는 물건 없음 |
| s7 | 내배엽 = 소화관 내벽 | ○ | 노란 끈 2가닥이 노란 겹(가장 안)에서 나와 굴로 되돌아감. 한 가닥은 굴 갈색 벽을 따라 원반까지 이어짐 |
| s7 | 폐 | △ | 굴 안에 잎사귀 1개와 주머니 1개가 있고, 잎사귀 줄기 끝에 노란 끈이 닿음. 폐 · 간 두 가지를 이 두 물건 중 어느 쪽이 맡는지 그림만으로 정해지지 않음 |
| s7 | 간 | △ | 위와 같음. 간을 가리키는 별도 물건 없음 |
| s7 | 굴 벽에서 부푼 곁주머니 | △ 어긋남 | 주머니 1개는 끈 가닥에 묶여 입구 원반 아래에 처져 매달려 있음. 굴 벽에서 부풀어 나온 것이 아니라 끈으로만 이어지고 벽과 닿지 않음(위치 어긋남) |
| s8 | 2배엽 | ○ | 맨 왼쪽 의자 위 작은 공 1개, 잘린 면 겹 2개(파랑 · 노랑) |
| s8 | 자포 | ✕ | 해파리 · 말미잘 등 자포동물 물건 없음 |
| s8 | 유즐 | ✕ 의심 | 빗해파리 물건 없음. 사실 쪽 의심: 유즐동물은 젤리층에 근육세포가 있어 일부 분류에서는 3배엽성으로 보기도 함 |
| s8 | 중배엽 없음 | ○ | 빨강 겹 0개(작은 공에는 파랑과 노랑뿐) |
| s8 | 중배엽에서 나오는 근육층 | △ | 팔뚝이 없다는 부재만 간접으로 읽힘. 빠진 근육을 보여 주는 물건은 없음 |
| s8 | 기관계를 못 갖춤 | △ | 연장 상자가 없다는 부재만 간접으로 읽힘 |
| s8 | 신경망은 있다 | ✕ | 신경망을 나타내는 물건 · 그물 무늬 없음(두 겹과 가운데 선뿐) |
| s9 | 나선난할 | ○ | 왼쪽 쟁반 공 10개(1+2+3+4 줄)가 위 줄 공이 아래 두 공 틈에 얹힌 어긋난 피라미드 |
| s9 | 선구 | ○ | 왼쪽 쟁반 = 선구 쪽(달팽이는 왼쪽 쟁반 귀퉁이, 전체 그림에서 확인) |

| s9 | 후구 | ○ | 오른쪽 쟁반 = 후구 쪽(불가사리는 오른쪽 쟁반 귀퉁이) |
