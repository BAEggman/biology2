# ㄷ 그림 판독 결과 (아폽토시스 vs 괴사)

판독 대상: full.jpg · s2~s12(· s6_1 · s6_2 · s9_1 · s9_2) · stops.tsv. 왼쪽 칸 = 아폽토시스, 오른쪽 칸 = 괴사.
그림에서 직접 센 것: 잎 1장(수포 5개), 왼쪽 땅의 자루 4개(땅 3 + 식세포 입 안 1), 유리병 3개(마개 3), 줄기 토막 왼쪽 5 / 오른쪽 6~7, 괴사 자루 덩어리의 묶은 목 5개 · 찢긴 구멍 2개, 오른쪽 마개 5개.

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 아폽토시스 = 단일세포 | ○ | 왼쪽 칸에 잎이 딱 1장 떨어지고 가지의 다른 잎은 멀쩡. 가운데 어두운 세로 구분선으로 두 칸이 갈림. |
| s1 | 괴사 = 세포군 | ○ | 오른쪽은 묶은 목 5개가 달린 자루들이 한 덩어리로 붙음(구멍 2개). 「여럿 한 덩어리」가 보임. |
| s1 | (전체) 자루가 무엇인가 | △ · 어긋남 | 왼쪽 땅의 자루는 「소체(세포 조각)」인데 오른쪽 자루는 「세포」. 같은 자루 그림이 두 칸에서 다른 것을 뜻함. 왼쪽 칸의 세포는 잎이다. |
| s2 | 아폽토시스 = 떨어져 나감 | ○ | 잎이 가지에서 떨어져 내려오고 왼쪽에 떨어지는 속도선 2줄. 가지는 멀쩡. |
| s2 | 괴사는 밖에서 당해 터진다 | △ | 자루가 찢겨 터진 것은 보이나 밖에서 때리는 것(충격 · 가해자)은 그림에 없음. 「당해」가 안 나르어짐. |
| s3 | ATP가 드는 능동 | △ | 금빛 태엽 손잡이가 잎 한가운데 꽂힘(1개). 에너지 · 감기의 느낌은 있으나 「ATP」 자체를 가리키는 단서는 없음. |
| s3 | 조절 과정 | △ | 태엽이 「정해진 기계 동작」을 암시할 뿐 「조절」을 나르는 별도 물건 없음. |
| s3 | 전형적 괴사 = ATP 없는 수동 손상 | ○ | 오른쪽 칸 어디에도 태엽 없음(전체 그림에서 확인). 찢긴 자루만 있어 「수동」으로 읽힘. |
| s4 | 수포(blebbing) | ○ | 잎 가장자리에 광택 있는 물집 모양 둥근 혹 5개(위 1 · 왼쪽 2 · 아래 1 · 오른쪽 1). |
| s4 | 터지지 않고 불거진다 | ○ | 5개 모두 매끈하게 닫혀 있고 터진 것 없음. |
| s5 | 막으로 싸인 소낭(소체)으로 나뉜다 (부푼 자리에서 떨어진 주머니) | △ · 끊김 | 주머니 4개(땅 3 + 입 안 1)는 있으나 잎의 수포 5개가 떨어져 나와 주머니가 되는 장면은 없음. 수포(초록 물방울)와 주머니(베 자루)는 모양 · 재질이 달라 닿는 고리가 안 보임. 수포 5 ≠ 주머니 4. |
| s5 | 다 닫혀 있다 · 새지 않는다 | ○ | 땅의 주머니 3개와 입 안의 1개 모두 목이 묶여 있고 주변에 흘린 것 없음. |
| s6 | 효소가 새어 나오지 않는다 (주머니 쪽 바닥 깨끗) | ○ | 왼쪽 땅은 연두색 그대로 얼룩 없음. 오른쪽은 구멍 2곳에서 올리브색 진흙이 흘러 웅덩이를 이룸. 담긴 것(병 속 올리브색 액) = 나오는 것(올리브 갈색 진흙)으로 어긋남 없음. |
| s6 | 주변 세포를 다치게 하지 않는다 | △ | 왼쪽에서 이웃 주머니가 멀쩡한 것은 보이나 「다치지 않음」을 따로 나르는 물건은 없음(오른쪽의 상한 줄기 토막으로 대비는 됨). |
| s7 | 식균 — 식세포가 주머니를 삼킴 | ○ | 왼쪽 아래에 입 벌린 큰 자루 모양 몸통이 있고 주머니 1개가 입에 물려 들어감. |
| s7 | 오른쪽엔 없다 | ○ | 오른쪽 칸에 입 벌린 식세포 없음. |
| s7 | 재빨리 삼켜 흔적 없이 사라진다 | △ | 삼키는 장면은 있으나 「재빨리」를 나르는 단서(속도선 등) 없음. 삼키는 중인 주머니는 아직 보이고 땅에 다른 주머니 3개가 그대로라 「흔적 없이」가 약함. |
| s8 | 터진 자루들 둘레가 붉다 | ○ | 구멍 2곳 아래 · 둘레에 붉은 얼룩이 크게 번짐. |
| s8 | 잎 쪽은 없다 | ○ | 왼쪽 땅에는 붉은 얼룩 없음. 붉은 것은 점무늬 안감 한 조각뿐(s12의 것, 얼룩 아님). |
| s8 | 새어 나온 것 때문 | △ | 붉은 얼룩이 진흙 아래에서 시작하긴 하나 진흙 밖(줄기 토막 둘레 · 칸 가장자리)까지 퍼져서 「새어 나온 것 → 붉음」 인과가 닿는지 불분명. |
| s9 | 주머니 창 너머 성한 유리병 셋(마개) | ○ | 창 안에 병 3개, 마개 3개, 액이 차 있음. 셋째 병은 점무늬 안감에 아래쪽이 가려짐. 창이 있는 주머니는 1개뿐(다른 주머니 속은 안 보임). |
| s9 | 터진 자루 속의 병은 깨짐 | ○ | 구멍 안과 진흙 속에 유리 파편 다수와 마개 5개(왼쪽 구멍 3 · 오른쪽 2), 온전한 병은 없음. 마개 5 ≠ 병 3이나 서로 다른 자루라 사실과는 충돌하지 않음. |
| s9 | 리소좀이 아폽토시스에서 안 깨지고 괴사에서 깨진다 | ○ | 왼쪽 병 성함 · 오른쪽 병 깨짐의 좌우 대비가 분명. |
| s9 | 바닥이 깨끗한 까닭 | ○ | 사슬: 병 깨짐 → 내용물이 구멍으로 흘러나옴 → 바닥 흥건(진흙이 구멍에서 땅으로 이어짐). 왼쪽은 병이 성해 바닥 깨끗. 끊김 없음. |
| s10 | 똑같은 길이 다섯 토막 | △ | 수는 5개로 맞음. 길이는 화면에서 약 170 · 145 · 130 · 120 · 160px로 서로 최대 1.4배 차이(거의 같으나 「똑같음」은 아님). |
| s10 | 일정한 자리마다 끊긴다(래더) | ○ | 토막 사이 간격이 고르고 자른 면이 매끈한 원통. 위치는 땅 위(잎 아래 앞쪽)로, 「잎 앞」으로 읽힘. |
| s11 | 오른쪽 줄기 제각각 너덜너덜 | ○ | 6~7토막(겹친 갈래 1개 포함), 길이 · 방향이 제각각이고 끝이 톱니처럼 찢겨 있음. 왼쪽 5토막 고른 것과 대비됨. |
| s11 | 괴사엔 분획 없음 | △ | 그림은 조각이 여러 개라 「분획이 있다」로 읽힘. 「없음」이 아니라 「무질서한 조각」을 나름. 「고르냐 제각각이냐」 문구로 풀어 읽어야 맞음. |
| s11 | 고르냐 제각각이냐가 실험실의 표 | △ | 좌우 대비는 되지만 「실험실의 표」(겔 · 표)를 나르는 물건은 그림에 없음. |
| s12 | 주머니 하나의 귀퉁이가 뒤집혀 점무늬 안감이 겉으로 | ○ | 창 달린 가운데 주머니의 오른쪽 아래 귀퉁이가 접혀 붉은 바탕에 흰 점(약 15개)의 안감이 드러남. 1개뿐. |
| s12 | PS 바깥 노출 = 「나를 먹어라」 표 | △ | 안감이 겉으로 나온 것은 보이나 「먹어라」를 나르는 표지(글 · 화살표 · 손짓)는 없음. 붉은색은 s8의 「염증」 붉은색과 겹쳐 색이 헷갈림. |
| s12 | 식균의 까닭 (표 → 식세포) | ✕ · 끊김 | 안감이 뒤집힌 주머니는 가운데에 있고, 식세포가 삼키는 주머니는 안감이 없는 다른 주머니. 뒤집힌 귀퉁이는 오른쪽 아래(식세포와 반대쪽)를 향함. 표 → 먹힘의 고리가 닿지 않음. |

## 의심 (그림 판정과 별개, 사실 자체)
- s9 「리소좀이 안 깨지는 것이 바닥이 깨끗한 까닭」: 바닥이 깨끗한 것은 소체의 막이 닫혀 있고 식세포가 빨리 치우기 때문이기도 하여 리소좀 하나만을 까닭으로 세우는 것은 단순화(인과가 과함). 나머지 사실(단일세포 · 세포군, 수포, 소체, 식균, 염증, 래더 · 분획 없음, PS 노출, ATP 능동 · 수동)은 일반 교재 설명과 모순 없음.
