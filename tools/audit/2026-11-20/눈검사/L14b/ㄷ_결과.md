# ㄷ 그림 판독 결과 (s1 ~ s18)

| 정거장 | 사실 낱 | ○△✕ · 끊김 · 어긋남 | 근거 |
|---|---|---|---|
| s1 | 세포골격 = 세포 안 단백질 섬유 그물 | ○ | 앞벽을 잘라 속이 보이는 분홍 놀이성 안에 대롱 · 줄 · 구슬 줄이 그물처럼 얽혀 있고, 오른쪽 창고도 같은 줄들로 채워짐. |
| s1 | 미세소관 · 미세섬유 · 중간섬유 세 종류 | ○ | 놀이성 안에서 대나무 대롱 · 노란 꼰 줄 · 살구색 구슬 줄 세 가지를 직접 확인. 굵기가 서로 다름. |
| s1 | 모양 지지 + 운동 | △ | 아이들이 대롱을 타고 오르내리고 줄을 당겨 운동은 보임. 줄이 풍선 모양을 받친다는 장면은 약함(풍선은 부풀어 있고 줄은 벽 안쪽에 걸려 있을 뿐). |
| s2 | 미세소관 25 nm (가장 굵음) | ○ | 왼쪽 안 벽가 세로 3줄 중 가장 왼쪽 대나무 대롱이 가장 굵음(crop 폭 약 55px). |
| s2 | 중간섬유 8~12 nm (가운데 굵기) | ○ | 가운데 노란 꼰 줄(약 35px), 대롱보다 가늘고 구슬 줄보다 굵음. 대롱 > 노란 줄 > 구슬 줄 순서가 사실의 부등호와 일치. |
| s2 | 미세섬유 7 nm (가장 가늘음) | ○ | 오른쪽 살구색 구슬 줄이 가장 가늘음(약 17px). 세 줄이 위아래로 나란히 선 것도 확인. |
| s3 | 미세소관 = 속 빈 관 | ○ | 왼쪽 아래 대롱 끝이 열려 동그란 구멍 속이 비어 보임(s3_2 확대). 꼭지에서 대롱 7개가 사방으로 뻗음. |
| s3 | 소단위체 = α · β 튜불린 이합체 | △ | 오른쪽 위 대롱 끝에 흰 알 1 + 흰 베 1이 한 벌로 얹힘(둘로 된 한 벌 = 이합체는 맞음). 어느 쪽이 α이고 β인지는 구별되지 않음. |
| s3 | GTP 로 중합 | ✕ | GTP를 나타내는 물건 · 동작이 그림에 없음. |
| s4 | + 끝(바깥)은 빨리 붙음 | ○ | 오른쪽 위 대롱의 바깥 끝(벽 쪽)에 흰 알 + 흰 베 한 벌이 얹혀 붙는 중. |
| s4 | + 끝(바깥)은 빨리 떨어짐 | ○ · 어긋남 | 오른쪽 아래 대롱 바깥 끝에서 흰 알 + 흰 베 한 벌이 떨어지고, 그 아래 흰 알이 하나 더 따로 굴러떨어짐. 사실 설명은 알 1 · 베 1인데 그림은 알 2 · 베 1(수 어긋남). 같은 끝에 작은 살구색 공(얼굴 같은 줄)도 있는데 사실에 없는 물건. |
| s4 | − 끝은 꼭지에 고정 | △ | 대롱들이 꼭지(허브)에서 모이고 꼭지 쪽에서는 알 · 베가 떨어지지 않음. 고정을 나타내는 별도 물건은 없음. |
| s4 | 키네신 → + | ○ | 통짜 굽 키높이 신발 + 투명 방울 가방(꽃 · 분홍 담김)을 멘 아이가 왼쪽 위 대롱을 꼭지에서 바깥 벽 쪽(왼쪽 위)으로 오름. 신발이 대롱에 닿고 가는 방향이 + 끝(바깥)과 일치. |
| s4 | 다이닌 → − | △ · 끊김 | 오른쪽 위 대롱의 아이는 머리와 손이 꼭지 쪽을 향해 내려와 방향은 − 끝과 맞음. 그러나 다이닌을 뜻하는 다이아몬드는 아이 몸에 닿지 않고 그 아래 공중에 떨어지는 줄 모양이라 아이와 다이아가 이어지지 않음. |
| s5 | 중심체(막 없음) | ○ | 대롱이 뻗는 꼭지 둘레에 막이 없이 열려 있음. |
| s5 | 핵 근처 | ○ | 크림색 공(핵)이 꼭지 바로 왼쪽에 붙어 있음. |
| s5 | 동물세포에서 미세소관이 뻗어 나오는 곳 | ○ | 꼭지에서 대롱 7개가 방사형으로 뻗음. |
| s5 | 중심립 2개 | ○ | 꼭지 아래 짧고 굵은 원통 2개를 직접 셈: 하나는 서고 하나는 누워 직각. |
| s6 | 중심립 · 기저체 = 삼중 미세소관 9개 (9×3) | ○ | 연두 냅킨 고리 앞면에 작은 관 3개씩 묶인 묶음을 9개 셈(위 · 위왼 · 왼 위 · 왼 아래 · 아래왼 · 아래 · 아래오른 · 오른 · 위오른). 고리를 눈에 댄 아이는 물놀이 통 왼쪽. |
| s6 | 가운데 없음 (9+0) | ○ | 고리 가운데가 비어 아이 눈이 보임. |
| s6 | 기저체가 섬모 · 편모 고정 | ✕ | 고리(기저체)와 섬모 대롱(s7)은 서로 다른 두 아이가 각각 들고 있을 뿐 서로 붙어 있지 않아 고정 장면이 없음. |
| s7 | 바깥 이중관 9 | ○ | 크림색 나팔 끝면에 관 둘씩 묶인 묶음을 9개 셈. 묶음 사이 하늘색 다이아몬드도 9개 셈. 눈에 댄 아이는 물놀이 통 오른쪽. |
| s7 | 가운데 2 | ○ | 끝면 가운데에 관 둘(원 2개). 9+2 일치. |
| s7 | 다이닌 팔이 미끄러뜨려 휜다 | △ | 묶음 사이 다이아몬드(s4의 다이아와 같은 하늘색 모양)로 다이닌 팔은 보이나, 미끄러짐 · 휨은 정지 그림이라 보이지 않음(나팔이 벌어진 정도뿐). |
| s8 | 섬모 짧고 많음 | ○ | 놀이성 왼쪽 바깥벽에 짧은 털이 수십 개 빽빽이 덮임. |
| s8 | 노 젓기 | ○ | 털들이 한쪽(왼쪽 아래)으로 휘어 있고 바깥에 회색 먼지 뭉치가 흩어져 날림. |
| s8 | 기관 점액을 밖으로 | △ | 쓸려 나가는 것은 먼지 뭉치이고 점액 · 기관을 나타내는 물건이 없음. 바깥 방향은 맞음. |
| s8 | 편모 길고 적음 | ○ | 물놀이 통 헤엄꾼에 긴 꼬리 단 1개(뾰족 모자 · 금빛 목걸이도 확인). 섬모 수십 개 대 편모 1개로 대비됨. |
| s8 | 물결 | ○ | 꼬리가 S자로 크게 물결치고 물에 잔물결 선. |
| s8 | 안테나 = 비운동성 섬모 | ○ | 지붕 한가운데에 가늘고 긴 살구빛 털 1개가 곧게 서 있고 움직임 선이 없음(지붕 가운데 위치 맞음). |
| s9 | 미세섬유 = 액틴 두 가닥 나선 | ✕ · 어긋남 | 뒷벽과 오른쪽 벽 그물의 살구색 줄은 구슬이 한 줄로만 이어진 외줄(1가닥). 사실은 두 가닥 나선인데 s14 · s16 · s18의 작업대 줄은 두 가닥이라 같은 미세섬유가 정거장마다 가닥 수가 다름. |
| s9 | 장력(당기는 힘)에 버팀 | △ | 구슬 줄이 팽팽한 그물로 걸림. 당기는 힘을 받는 장면은 이 정거장에는 없음(s10에서 나옴). |
| s9 | 3차원 그물로 모양 지지 | △ | 뒷벽과 오른쪽 벽 두 면에 그물이 걸려 입체적으로 보이나 풍선 모양을 받치는 모습은 아님. |
| s10 | 근수축(+ 마이오신): 근수축 | △ | 빨간 멜빵 아이가 오른쪽 벽 안쪽 구슬 줄을 두 손으로(위아래로 겹쳐 쥐고) 당김. 근육 맥락(근섬유)은 없음. |
| s10 | 마이오신 | ✕ | 마이오신을 나타내는 별도 물건이 없음. 아이 손이 그 역할이라 해도 표시가 없음. |
| s10 | 아메바 운동(위족) | ○ · 어긋남 | 놀이성 오른쪽 벽이 구슬 줄 여러 가닥(약 4~5줄)을 품은 긴 팔처럼 불룩 뻗고 주변에 움직임 선. 오른쪽으로 뻗음. 그런데 아이가 구슬 줄을 당기는 쪽은 몸쪽(왼쪽 아래)이라 기어가는 방향(오른쪽)과 반대로 읽힘(방향 어긋남). |
| s10 | 식물 세포질 유동 | ○ | 오른쪽 창고 안 살구색 구슬 고리 위에 초록 구슬 12개, 화살표 3개가 모두 같은 방향(시계 방향)으로 돎. 창고가 놀이성 오른쪽에 있어 위치 맞음. |
| s10 | 세포질분열 | ✕ | 세포가 둘로 갈라지는 장면 · 물건이 없음. |
| s10 | 모양 | △ | 위족 불룩이 모양 변화를 보이긴 하나 모양 유지 장면은 따로 없음. |
| s11 | 미세융모 — 액틴 미세섬유가 심 | ○ | 지붕에 손가락 모양 작은 탑 12개: 앞줄 7개마다 가운데 살구색 구슬 줄 심, 뒷줄 5개는 심 없음(어두운 색). |
| s11 | 세포 표면적을 넓혀 흡수 | △ | 손가락 탑이 많아 가장자리가 넓어 보이나 흡수되는 것(들어오는 물건)은 없음. |
| s11 | 물질대사에 유리 | ✕ | 물질대사를 나타내는 물건 · 동작이 없음. |
| s12 | 케이블처럼 꼰 섬유 단백질 | ○ | 굵은 노란 꼬불꼬불 꼰 줄이 해먹처럼 크림색 공을 받침. 줄 끝이 왼쪽 위 벽 쇠 고리판에 걸림. |
| s12 | 케라틴 등 세포마다 다름 | ✕ | 줄이 하나뿐이고 종류 차이를 나타내는 물건이 없음. |
| s12 | 장력 | ○ | 줄이 공 무게로 팽팽히 당겨져 처짐. |
| s12 | 오래가는 받침 | ○ | 이 줄에는 타는 아이가 없음(오르내림 없이 공만 받침). |
| s13 | 중간섬유는 척추동물 등 일부 동물에만 | △ | 동물(놀이성)에는 노란 줄이 있고 창고에는 없어 동물 대 식물 대비는 보임. 척추동물 등 일부라는 제한은 그림에 없음. |
| s13 | 식물세포는 미세섬유 + 미세소관뿐 | ○ | 창고 안 대나무 대롱 4개(3개 서고 1개 누움) + 살구색 구슬 고리 1개, 노란 꼰 줄 0개. |
| s13 | 각질 = 케라틴 | ✕ | 각질 · 케라틴을 나타내는 물건이 없음. |
| s14 | 왼쪽 미세소관 | ○ | 왼쪽 열 두 칸에 속 빈 연두 대롱 각 1개(위 · 아래 합 2개). 위쪽 대롱은 주둥이가 사선으로 열려 속이 보임. |
| s14 | 오른쪽 액틴 미세섬유 | ○ | 오른쪽 열 두 칸에 살구색 구슬이 두 가닥으로 꼬인 줄 각 1개(합 2개). |
| s14 | 위는 중합 억제 | ○ | 위쪽 두 칸은 줄 밖에 재료(연두 두 토막 2쌍 / 낱구슬 2개)가 떨어져 줄에 붙지 못함. |
| s14 | 아래는 탈중합 억제 | ○ | 아래쪽 두 칸은 완성된 줄이 포장끈 / 독버섯으로 묶여 있고 떨어진 재료가 없음. |
| s15 | 콜히친 → 튜불린에 결합 | ○ · 어긋남 | 꼬불선 달린 나무 전화기가 연두 두 토막 부품을 코드로 붙들고, 주둥이가 사선으로 열린 대롱 앞에 서 있음. 전화기-부품 사이는 닿음. 다만 튜불린이 s3 · s4에서는 흰 알 + 흰 베 한 벌이었는데 여기서는 연두 두 토막이라 같은 튜불린이 정거장마다 다른 물건으로 나옴. |
| s15 | 미세소관 중합 · 신장 억제 | ○ | 붙들린 부품과 대롱 끝 사이가 점선만큼 벌어져 못 붙고, 뒤에 같은 부품 한 쌍(합 2쌍)이 더 대기. |
| s16 | 사이토칼라신 → 액틴 미세섬유 | ○ | 흰 셔츠 칼라(앞단추 · 뾰족한 옷깃 2장 · 둥근 목둘레)가 두 가닥 구슬 줄 오른쪽 끝을 실제로 덮음. 칼라 = 사이토칼라신 이름 연상. |
| s16 | 빠른 성장 말단(+)을 덮음 | △ | 칼라는 줄 오른쪽 끝(낱구슬이 기다리는 쪽)에 있어 성장 쪽 끝으로 읽히나, + 끝이라는 표시는 없음. |
| s16 | 중합 억제 | ○ | 칼라 바깥 낱구슬 2개가 줄과 떨어져 있어 붙지 못함. |
| s17 | 택솔 → 조립된 미세소관 | ○ | 택배 상자(택솔 이름 연상)에서 내려온 굵은 포장끈이 양 끝이 이미 완성된 대나무 대롱 한가운데를 감싸고 이웃 마디 사이에서 X로 교차. 상자-끈-대롱이 모두 닿음. |
| s17 | 안정화 → 탈중합 억제 | ○ | 끈이 대롱을 묶어 쪼개지지 않게 잡아 두는 모양. |
| s18 | 팔로이딘(독버섯) → F-액틴에 결합 | ○ | 작업대 오른쪽 아래 칸의 흰 갓 독버섯 3개(사실 설명의 셋과 일치)가 이어진 두 가닥 구슬 줄 위에 서서 작은 팔로 이웃한 구슬 사이를 끌어안음. |
| s18 | 미세섬유 안정화 → 탈중합 억제 | ○ | 줄이 끊김 없이 이어지고 떨어진 구슬이 없으며 팔이 구슬들을 묶어 둠. |

## 의심 (사실 자체)
의심으로 적을 항목 없음. 확인한 것: 지름 25 / 8~12 / 7 nm, 튜불린 GTP 중합, 9+0 · 9+2, 안테나(일차섬모) 비운동성, 미세융모 액틴 심, 콜히친 · 사이토칼라신 · 택솔 · 팔로이딘 기전, 중간섬유가 식물에 없다는 서술(캠벨 교재 서술과 일치). 모두 통상 교재 내용과 맞음.
