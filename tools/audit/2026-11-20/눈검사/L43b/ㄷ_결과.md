# ㄷ 그림 판독 결과 (판 L43b)

본 자료: full.jpg · s2~s13(+ s8_1 · s8_2 · s11_1~4 · s13_1~3) · stops.tsv 만 열람. 읽기 전용.
기호: ○ 실제로 보임 · △ 암시만/약함 · ✕ 안 보임. 수는 그림에서 직접 센 값(가위·겹침으로 가려진 곳은 「약」).

## 직접 센 값
- 작업대 띠: 청록 약 5~6칸(가위 아래 한 칸은 가려져 확정 불가) · 회색 4칸. 왼끝 모자 · 오른끝 술.
- 술(작업대 오른끝): 매달린 것 약 7~8 + 일꾼이 손에 쥔 1 = 약 8~9가닥.
- 일꾼(어깨동무): 5명. 가위는 1자루(실제로 쥔 손은 분홍 옷 일꾼 + 옆 일꾼 정도, 나머지는 어깨동무).
- 통 속 회색 토막: 위로 보이는 리본형 고리 약 7~8 + 통 옆으로 늘어진 올가미 3 = 고리 약 10. 모자·술 달린 토막 없음, 청록 없음.
- 구멍 속 띠: 가로 마디선 약 9~10칸, 전부 청록(회색 없음). 앞끝(왼) 작은 모자 · 뒤끝(오른) 술 약 2~3다발.
- 선반: 3단. 맨 위 = 감긴 띠 통 + 청록·회색 교대 띠(청록 약 6 · 회색 약 5) + 가위 1. 가운데 = ○ △ ☆ 판 3장 + 둥근 손잡이 곧은 쇠 날. 아래 = ○ □ ☆ 판 3장 + 같은 둥근 손잡이 쇠 용수철. 연장은 위: 손잡이가 판 쪽 · 날이 바깥, 아래: 용수철이 판 쪽 · 손잡이가 바깥(방향 반대).
- 5′→3′ 방향: 작업대 띠도 구멍 속 띠도 모자 왼쪽 · 술 오른쪽으로 같다(방향 일치).

## 의심(생물학적 사실 자체)
없음. 모든 사실이 교과서 수준(Campbell 포함)에서 통상 서술과 일치. (참고: s7 「ex- / in-」 는 말장난 기억법이며 어원 주장이 아니다. exon = expressed, intron = intervening/intragenic.)

## 요약 메모
- 가장 큰 구멍: 「나르는 사슬」이 곳곳에서 끊김(작업대 → 통, 작업대 → 구멍, 원본 → 산물 둘). 정작 가위는 띠를 자르지 않은 채 걸쳐 있음.
- 수 어긋남: 청록 5~6칸 → 구멍 띠 9~10칸, 술 8~9가닥 → 2~3다발.
- 산물(○△□☆ 무늬판)과 원본(무늬 없는 띠)이 서로 다른 약속이라 선택적 스플라이싱이 그림으로 안 닿음.
- 개념 설명류(분해 막음 · 번역 돕기 · 안정성 · UTR · 단백질+snRNA)는 그림으로 나르지 못함 → 글/구술에 의존.
