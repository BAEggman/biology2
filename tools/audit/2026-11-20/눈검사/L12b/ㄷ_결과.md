| s3 | 중화한다 | ○ | 흰 거품이 초록 웅덩이 오른쪽 가장자리를 덮으며 번진다(분수는 초록 쏟아지는 곳에서 오른쪽으로 약 1/3 지점). 초록은 계속 쏟아져 「다 덮음」은 아니나 덮어 가는 동작이 보인다. |
| s4 | 파네트세포 | △ | 벽 속 비탈 감실에 웅크린 사람 셋(직접 센 수 3). 세포 이름을 나르는 물건은 없고 하는 일(분무)만 있다. |
| s4 | 움 바닥 | △ | 감실이 계단식으로 내려가 아래쪽에 앉은 사람이 바닥 쪽이다. 움(음와)이라는 구조 단서는 없다. |
| s4 | 라이소자임(세포벽 공격) | △ | 초록 액 분무기로 세균에 분사한다. 분무와 세균은 보이나 「세포벽」이 무너지는 모습은 없다. |
| s4 | 디펜신 | △ | 감실 아래 그물망 속 대파 한 단뿐이다. 「대파」와 「디펜신」의 소리 연결이 약하고 분무 동작과 이어지지 않는다. |
| s4 | 세균 감시 | ○ | 초록 세균이 분무 쪽에 직접 센 수 5(첫째 사람 앞 2 · 셋째 사람 앞 3). 사람 셋이 세균 쪽으로 분무한다. |

| s5 | 항원 | ○ | 창 앞에 떠 있는 주황 점박이 가시 공 하나(직접 센 수 1). |

| s5 | 넘긴다 | △ 끊김 | 오른쪽 경비가 손에 흰 물건을 쥐고 있으나 갈고리 공과 닿지 않고, 받는 쪽(면역세포)도 없다. |
| s6 | 카할 간질세포 | △ | 벽 속 아치 방의 북 치는 사람. 이름 단서 없음. |
| s6 | 박동원(페이스메이커) | ○ | 북채 든 북 치는 사람이 박자를 낸다. |

| s7 | 담즙은 간에서 만든다 | △ | 곳간 벽 밑에서 시작한 초록 관이 운하 왼쪽에 초록 방울을 붓는다(관이 곳간 벽 모서리에 닿음). 곳간 안에서 담즙을 「만드는」 동작은 없다. |
| s7 | 담즙산염은 회장에서 재흡수 | ○ | 오른쪽 끝 큰 노란 스펀지가 운하를 가로막고(스펀지 오른쪽엔 물이 비스듬히 빠짐) 초록 방울이 날아와 닿고 스펀지 면에 초록 점이 박혀 있다. 직접 센 날아드는 방울 약 12. |

| s7 | → 간으로 | ○ | 관이 위로 올라가 곳간 오른쪽 위 벽으로 들어가고 관에 위쪽 화살표(↑)가 있어 방향이 사실과 맞다. |
| s7 | (장간순환) | ○ | 곳간 → 초록 관 → 운하 → 스펀지 → 초록 관 → 곳간으로 닫힌 고리가 그림에서 직접 이어진다. |
| s11 | 담즙산염 = 지방 유화 | ○ | 운하 물 위 노란 기름 덩이에 초록 방울이 튀고 덩이가 금 가며(금은 오른쪽 끝) 초록 테 두른 작은 노란 방울로 흩어진다. 담긴 것(기름)과 나온 것(노란 방울)이 같다. 방울 맞닿는 곳은 왼쪽인데 깨지는 곳은 오른쪽이다. 의도된 설명이라 어긋남으로는 안 쳤다. |

| s11 | 담즙 색소가 쌓이면 | ○ | 곳간 벽에서 나온 초록 호스에 매듭이 하나(직접 센 수 1) 있고, 벽 쪽 호스만 불룩 부풀어 막혀 쌓인 모양이다. 호스 색이 담즙과 같은 초록이라 「색소」만 따로 구별되지는 않는다. |
| s11 | 황달 | ○ | 호스를 든 일꾼의 피부와 눈 흰자위가 누렇고 표정이 아프다. |
| s12 | 상피 표면 효소가 마무리 소화 | △ | 일꾼 둘이 앞벽 윗전 구멍에 허리까지 박혀 있어 「표면에 박힌」 것은 읽힌다. 「효소」「마무리」는 동작으로 구별되지 않는다. |
| s12 | 아미노(펩티데이스) | ○ | 왼쪽 일꾼이 긴 구슬 사슬(직접 센 구슬 14)의 왼쪽 끝 바깥에서 구슬 1개를 들었다. 아미노 말단(왼쪽 끝)과 맞다. |
| s12 | 디펩티데이스 | △ | 가운데 일꾼이 두 손에 구슬 하나씩 들고 손 둘레에 짧은 초록 선이 있다. 붙어 있던 짝이 보이지 않아 「짝을 떼었다」가 확실하지 않고, 긴 사슬의 오른쪽 끝 바로 옆이라 카복시 쪽으로도 읽힐 수 있다. |

| s12 | 뉴클레이스 | ○ | 뗏목 위 다른 일꾼이 색 네모가 줄지은 흰 종이띠를 가위로 자르고 물 위에 낱장 네모가 떠 있다(직접 센 낱장 약 3). |
