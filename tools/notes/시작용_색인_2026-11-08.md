## 세션 절차(늘 같은 것)
- Gemini(Argon · 3.1 Pro 예비 · Flash 안 씀)는 Claude in Chrome 으로 자동화 — 도우미 `tools/gemini_helpers_0928.js` 와 세션 scratchpad 의 `helpers_inject.js`(첨부는 노출한 file input + paste 이벤트). 받은 그림은 기기 `~/Downloads` → `device_stage_files`.
- 커밋은 세션마다(귀속 줄 자동) · 푸시는 **사용자가** `~/Downloads/push_b2.command` 로(번들 `b2_hNN.bundle` 을 `push_b2.sh` BUNDLES 에 적어 둔다). **Claude 는 토큰을 쓰지 않는다** — 토큰은 파일 · 명령줄 · 저장소 어디에도 두지 않는다.
- 보고는 늘 **「다음에 할 일」 표**로 끝낸다 · 생물 사실은 검수 두 번 · bizarreness(이상함이 곧 사실) · 사용자가 전에 실망한 자리(그림이 직관적이지 않음 · 글이 그림을 대신함)를 늘 떠올린다.
