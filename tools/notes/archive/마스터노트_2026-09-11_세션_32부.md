## Gemini 자동화 — 이번에 새로 배운 것 (tools/fetch_gemini.md 에 반영)
1. **다운로드 버튼을 아예 안 쓴다.** blob URL 을 `<a download>` 로 직접 받으면 한 번에 되고 이름도 내가 정한다. 버튼 클릭은 씹히고, 「옵션 더보기」 메뉴를 여는 순간 렌더러가 얼어붙었다(그림 8장 대화).
2. **업로드 메뉴가 DOM 에 file input 을 만들려면 리페인트가 필요하다.** JS 로 이벤트 열 개를 쏜 뒤 **`computer screenshot` 을 한 번 끼워 넣어야** `input[type=file]` 세 개가 생긴다. 스크린샷 없이 바로 세면 0 개다.
3. **편집 프롬프트는 첫 줄이 명령이어야 한다.** 「keep everything as it is」로 시작하면 모델이 원본을 그대로 돌려준다(s45p03 v1). 「You returned the picture unchanged. Do it now.」처럼 못 박아야 먹힌다.
4. **한 번에 한 가지만 고친다.** v2 에서 받침대, v3 에서 홈 — 나눠야 둘 다 남는다.
5. 대화당 그림 **8장**이 한계. 판마다 새 대화를 판다.
