## 5. Gemini 자동화 — 첨부가 사라지던 것을 고쳤다

★ **증상.** `file_upload` 는 ref 가 있어야 하고 ref 는 `find` 로만 얻는데,
`find` 가 접근성 스냅숏을 뜨는 순간 **Material 메뉴 overlay 가 통째로 지워져**
`input[type=file]` 이 사라진다 → `Element is no longer in the document`.

★ **고침 — input 을 `document.body` 로 옮겨 놓고 `find` 를 부른다.**
노드를 옮겨도 리스너는 따라가므로 업로드가 그대로 먹고, 메뉴가 닫혀도 살아남는다.

```js
document.body.appendChild(i);   // ← 이 한 줄이 핵심이다
i.id='__imgup';
i.style.cssText='position:fixed;left:12px;top:12px;width:240px;height:48px;'
              +'opacity:1;z-index:2147483647;display:block;visibility:visible';
```

같이 적은 둘:

- **`aria-label` 은 정확히 일치로 찾아라** — `/업로드/` 같은 부분 일치는 사이드바 단추를 집는다.
- ⚠⚠ **숨은 탭에서 `setTimeout` 루프를 돌리지 마라.** 크롬이 배경 탭 타이머를 분 단위로 늦춰서
  `await setTimeout(500)` × 16 이 **CDP 45초 시간초과**로 죽는다. 기다림은 **호출을 나눠서** 한다.
- **같은 그림이 두 번 붙을 수 있다** — 보내기 전 `첨부파일 닫기` 단추 수가 **1인지** 확인한다.
