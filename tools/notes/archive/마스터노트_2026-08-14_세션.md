## 2. ⚠ 보안 — PAT 취급 (원문 보존)

사용자가 GitHub PAT를 직접 준다. **취소 권고는 명시적으로 거부됐다**:
「**pat 토큰은 별 상관없어, 계속 커밋해야해**」 → 취소를 권하지 말고 계속 커밋한다.

현재 토큰: `github_pat_<지움>`
(앞 토큰은 세션 중 만료됐다. 401이 나면 사용자에게 새 것을 요청한다.)

**푸시할 때마다 이 절차 그대로** — 토큰은 `~/.dep/.tk`(600)에만, `GIT_ASKPASS`로만 전달,
`.git/config`·명령줄·환경변수에 **절대** 넣지 않는다. 출력은 전부 `sed`로 가린다.
푸시 뒤 즉시 삭제하고 `ls -a ~/.dep`로 확인한다.

```bash
cd /tmp/b2 && git fetch origin
mkdir -p ~/.dep && chmod 700 ~/.dep
printf '%s' '<TOKEN>' > ~/.dep/.tk && chmod 600 ~/.dep/.tk
printf '%s\n' '#!/bin/sh' 'case "$1" in Username*) echo BAEggman;; Password*) cat ~/.dep/.tk;; esac' > ~/.dep/askpass.sh
chmod 700 ~/.dep/askpass.sh
timeout 600 env -u https_proxy -u HTTPS_PROXY -u http_proxy -u HTTP_PROXY \
  -u GIT_CONFIG_COUNT GIT_ASKPASS=$HOME/.dep/askpass.sh GIT_TERMINAL_PROMPT=0 \
  git push origin main 2>&1 | sed "s|$(cat ~/.dep/.tk)|<TOKEN>|g"
rm -f ~/.dep/.tk ~/.dep/askpass.sh; ls -a ~/.dep
```

## 3. 방법론 — 이 덱의 규칙

### ★ 최상위 원칙 — 그린 것만 건다
그림에 없으면 **사실표를 고친다.** 그림에 있는 척하지 않는다.
「원래 이렇게 그리려 했다」는 근거가 못 된다.

### 7가지 점검표 (`생물Sketchy_사용자실망패턴_점검표.md`)
① **기출 축이 그림에 있는가** — 걸린 카드가 무엇을 묻는지 세어, 최빈 축이 물체로 없으면 실패
② **유령** — 똑같은 것이 여럿인데 「여럿임」이 사실이 아니면 실패. 복수형이 신호
③ **단서가 위치뿐인가** — 「왼쪽이 A」로만 갈리면 실패. 이름→형태로 뽑는다
④ **하나의 상징은 하나의 사실인가** — ★ **2026-08-14 확장: 형제 패널이 아니라 「같은 게이트 전체」**
⑤ **셀 수 있는 것이 정확한가** — 눈으로 세지 말고 **픽셀로** 센다
⑥ **그림과 요약(br)·사실표·bx가 어긋나지 않는가**
⑦ **구별 가능한 수를 넘지 않는가** — 같은 종류가 여섯을 넘으면 안 갈린다

### ★ ④를 어긴 사례 — 이번 세션에 내가 만들었다
`s11p04#3`이 「**나무못은 DNA, 쇠못은 RNA 프라이머**」로 재질 문법을 명시해 놨는데,
`s38p01`을 그리면서 확인하지 않고 **쇠못 = 인산이에스터**로 썼다. 둘 다 게이트 E다.
`s39p03`의 구슬 = 뉴클레오타이드도 `s38p01`의 구슬 = 인산과 부딪친다.

→ **새 패널 설계 첫 단계: 쓰려는 소품 낱말을 게이트 전체 사실표에서 grep 한다.**

## 4. 자료 구조와 도구

### 데이터 모델
- `sketchy.html` 안 `const DATA = [scenes]`
- 장면 `{id,t,gate,unit,panels[]}` · 패널 `{id,pc,t,br,bx,f}` 또는 `{id,t,svg,br,bx,f}`
- 사실표 행 `["소품","사실"]` 또는 `["소품","사실",["카드ID"]]` — **행 단위 카드 ID는 큰따옴표**
- ★ **CARDS는 `index.html`에만** (`<script id="CARDS">`). `build.js`는 읽기만 한다
- 패널 id가 `d`로 시작하면 **도해** — webp가 없고 `svg:` 필드에 인라인 SVG가 들어간다.
  도해 SVG는 `sketchy.html`에만 들어간다(`index.html`은 도해 SVG를 안 넣는다)
- ★ **DATA를 재직렬화하지 않는다.** 괄호 스캐너로 자리를 찾아 문자열로 끼워 넣고,
  넣은 뒤 다시 파싱해 확인한다

## 5. ★ Gemini 파이프라인 — 오늘 확정한 것

### ① 무조건 한 줄 검사부터
```
Reply with just the word OK.
```
- 답이 오면 → 계정 정상. 그림 작업으로.
- **답이 안 오면 → 계정 쪽이다. 프롬프트를 아무리 고쳐도 소용없다.** 도해 쪽으로 돌린다.

오늘 이걸 몰라서 프롬프트 네 판을 헛되이 고쳤다. 그러고 나서야 28자짜리 검사를 했고,
**그것도 빈 응답**이라 계정 문제임을 알았다. 네트워크를 떠 보니 `StreamGenerate`가
**200**을 준다 — 인증도 한도도 서버 오류도 아니고 **스트리밍 렌더링이 멈춘 것**이다.

### ② 전송하는 법 — `execCommand`는 안 된다
DOM에는 글자가 들어가는데 Angular가 몰라 **보내기 버튼이 아예 안 생긴다.** 키보드 타이핑도 같다.
```js
const ed=document.querySelector('.ql-editor');
ed.focus();
while(ed.firstChild) ed.removeChild(ed.firstChild);
for(const line of txt.split('\n')){ const p=document.createElement('p'); p.textContent=line; ed.appendChild(p); }
ed.classList.remove('ql-blank');
ed.dispatchEvent(new InputEvent('beforeinput',{bubbles:true,cancelable:true,inputType:'insertText',data:txt}));
ed.dispatchEvent(new InputEvent('input',{bubbles:true,cancelable:false,inputType:'insertText',data:txt}));
// 이제 aria-label "메시지 보내기" 버튼이 나타난다
```
- `innerHTML`은 **TrustedHTML 정책에 막힌다** — 노드를 만들어 `appendChild` 해야 한다
- **보내기 전 `aria-label`이 「…현재 Pro …」인지 확인한다.** 새 대화는 Flash로 초기화된다
- 모드 버튼은 `/app`에서도 **뜨는 데 몇 초 걸린다** — 최대 15초 폴링. 한 번 보고 없다고 하지 마라
- 모드를 바꾸면 보내기 버튼 참조가 갈리므로 **바꾼 뒤 다시 찾아서** 누른다
- 전송 성공 판정은 `.ql-editor` 길이가 아니라 **정지 버튼(「대답 생성 중지」)이 떴는지**
- 응답이 죽으면 정지 버튼이 안 사라져 **다음 전송이 막힌다** → 탭 새로고침

### ③ 그림 받아오는 법
```js
const b=[...document.querySelectorAll('img')].filter(i=>i.src.startsWith('blob'));
const last=b[b.length-1];
let d=document.getElementById('__cap'); if(d) d.remove();
d=document.createElement('div'); d.id='__cap';
d.style.cssText='position:fixed;left:0;top:0;width:512px;height:512px;z-index:2147483647;background:#fff;overflow:hidden';
const g=document.createElement('img'); g.src=last.src;
g.style.cssText='position:absolute;left:0;top:0;width:512px;height:512px;display:block';
d.appendChild(g); document.body.appendChild(d);
```
그다음 `computer zoom` + `save_to_disk:true`. **영역은 `512 × (screenshot_width / innerWidth)`**,
창 크기가 바뀌면 값도 바뀐다. 넉넉히 잡고 어두운 화소로 경계를 찾아 잘라 낸다.
새로고침해도 blob이 `naturalWidth 0`이면 **새 탭으로 같은 대화를 연다.**

### ④ 프롬프트 규칙 (효과가 확인된 것)
1. **개수는 물체마다 문장 하나씩 따로 못 박는다.** 이걸 지킨 뒤로 대체로 첫 판에 맞는다
2. **쌍으로 존재하는 것이 기본형인 소품은 쓰지 말 것**(코트 주머니는 세 판을 더 지시해도 둘로 나왔다)
3. **구도가 비면 가구를 바꾼다**(가로 작업대 5.22% → 세로 선반 15.03%)
4. **차이는 색으로 준다.** 한 색은 한 뜻에만 쓰고 프롬프트에 「이 색은 여기 말고 어디에도 없다」를 넣는다
5. Gemini가 못 하는 것: 짝 있는 소품 하나 없애기 · 복제 습관 고치기 · 화면 밖 구도 당겨오기 · 빈 구도 채우기
   → **말로 안 되면 어포던스를 바꾸거나 PIL로 고친다**

## 6. ★ PIL 후보정 — 되는 조건과 마스크 만드는 법

되는 조건 셋. 하나라도 빠지면 재생성이 싸다.
1. **옮길 것이 같은 그림 안에 이미 있다**
2. **목적지가 단색이거나 질감이 단순하다**
3. **원본을 지울 필요가 없다**(복사이지 이동이 아니다)

### 마스크 — 색으로만 뜨면 배경이 사각형으로 딸려 온다 (오늘 한 번 실패했다)
```
① 옮길 물체 안쪽 한 점을 씨앗으로 (잉크가 아닌 곳 — 휘도를 찍어 확인)
② ~ink 를 라벨링해 씨앗이 든 성분 = 물체 내부
③ 내부를 4회 팽창 ∩ ink = 물체를 감싼 윤곽선
④ 내부에 닿은 잉크 성분 중 작은 것(걸쇠·손잡이)만 붙인다 — 큰 것은 배경 윤곽이다
⑤ binary_fill_holes → binary_closing
⑥ 「물체 색도 잉크도 아닌 화소」를 알파에서 한 번 더 뺀다
```
붙인 뒤 **세 자리를 세서 확인한다** — 목적지(늘었나)·원본(그대로인가)·엉뚱한 이웃(안 건드렸나).
가장자리는 알파로 섞고 **실측 잡음(std 2.3~2.8)**을 얹어 붓질처럼 만든다.

## 7. 도해(SVG) 만드는 법 — Gemini 없이 가는 길

**E0처럼 「두 배치를 견주는」 단원은 그림보다 격자가 낫다.** 그리고 도해는 이미지가 필요 없다.
