# E0(연관·성유전) — 그림이 아니라 도해로 간다

## 왜 도해인가

E0 **193장이 전부 미연결**인데 **훑을 그림이 하나도 없다.** 감수분열·멘델을 그린 장면이
덱에 아예 없다는 것을 확인했다. `d01p01`(감수분열 3열 대조)은 분열 기전이지 연관이 아니라,
거기 걸면 점검표 ②(유령)에 걸린다.

그런데 이 단원의 기출은 「소품을 떠올려라」가 아니라 **「두 배치를 견주어라」**다.
상인과 상반은 유전자형이 둘 다 AaBb로 같은데 배치 하나가 배우자와 표현형비를 통째로 바꾼다.
이런 것은 그림보다 격자가 낫다 — `d02p01`(멘델 예외 격자)과 같은 자리다.

★ **그리고 도해는 이미지가 필요 없다.** Gemini가 막힌 동안에도 진도가 나간다.

## 완료 — d05p01 「상인과 상반」 (커밋 `737dc1d`, E0 16장)

장면 `d05` 「연관과 성유전 도해」 (게이트 E) 신설.

| 문법 | 뜻 |
|---|---|
| 막대 하나 | 염색체 하나 |
| 채운 원 / 빈 원 | 우성 / 열성 |
| 청록 / 주황 | A·a 유전자좌 / B·b 유전자좌 |

★ **배우자는 막대를 통째로 물려받는다** — 그래서 막대에 적힌 그대로가 배우자다.

- 상인: 한 막대에 채운 원끼리 → 배우자 AB·ab → **3 : 1**
- 상반: 막대마다 하나씩 엇갈려 → 배우자 Ab·aB → **1 : 2 : 1**
- 아래 띠: 교차 없음 → 배우자 둘(완전연관) / 감수 1분열 전기 교차 → 넷인데 **수가 같지 않다**

E0-8 · E0-8#1~#3 · E0-9 · E0-9#1~#3

## ★ SVG는 손으로 쓰지 않는다

좌표와 개수가 곧 사실인 도해라 손으로 적으면 반드시 어긋난다.
`tools/gen_d05p01_svg.py` 가 막대 하나·원 하나까지 계산해서 찍는다.

작업 순서:

1. `python3 tools/gen_d05p01_svg.py` → `tools/_d05p01.svg`
2. `cairosvg`로 PNG를 떠서 **눈으로 배치를 본다** (한글은 네모로 나온다 — 컨테이너에 한글 폰트가
   없어서고, 허브에서는 페이지 폰트로 정상이다. 볼 것은 글자가 아니라 **겹침과 여백**이다.)
   이번에도 범례가 상반 열 막대와 겹쳐서 아래 왼쪽으로 옮겼다.
3. `python3 tools/inject_d05p01.py` → `npm run build` → `npm test` → 래칫 → 배포

주입 뒤에는 **DATA를 다시 파싱해 svg가 디스크 원본과 바이트 동일한지** 확인한다(태그 균형도).
통과가 아니라 결과로 본다.

⚠ SVG 안에 **백틱·역슬래시가 들어가면 주입이 깨진다** — 생성기가 assert로 막는다.
⚠ 도해 SVG는 **`sketchy.html`에만** 들어간다. `index.html`(SRS)은 도해 SVG를 넣지 않는다 —
기존 도해 11장도 전부 그렇다. 안 들어갔다고 놀랄 것 없다.

## 남은 E0 도해 — 설계 초안

| 패널 | 무엇을 견주나 | 대상 카드 | 대략 |
