## 무엇을 그릴 것인가

★ **저울 둘은 둘 다 수평인데 담긴 개수가 서로 다르다** — 그것이 샤가프의 전부다.

| 자리 | 소품 | 사실 |
|---|---|---|
| 왼쪽 저울 | 갈고리 **둘**짜리 조각이 접시마다 **둘**, 저울대 수평 | A = T |
| 오른쪽 저울 | 갈고리 **셋**짜리 조각이 접시마다 **넷**, 저울대 수평 | G = C |
| 두 저울 대비 | 담긴 **개수가 다르다** | A+T ≠ G+C — 종마다 다르다 |
| 가운데 | 검은 카드에 흐릿한 **X자 십자** | 프랭클린의 X선 회절 사진 |
| 작업대 전체 | 놓인 것은 사진과 저울, **그 둘뿐** | 왓슨·크릭의 근거는 그 둘 |
| 오각판 왼쪽 | 꼭짓점마다 고리, **넷 다 있다** | 리보스 |
| 오각판 오른쪽 | 칸 조각 **바로 다음 자리만** 맨숭맨숭, 고리 셋 | 디옥시리보스 |
| 그 빈 자리 | 칸 조각이 붙는 자리가 1번이므로 **바로 다음이 2번** | 2′-OH → -H |

갈고리 둘/셋은 **s38p01의 수소결합 2개/3개 표시를 그대로 잇는다** — 새 기호를 만들지 않았다.

## ★ 이번 세션에서 새로 알아낸 전송 방법 (규칙에 넣을 것)

`document.execCommand('insertText')`로 넣으면 **DOM에는 글자가 들어가지만 Angular가 모른다** —
「메시지 보내기」 버튼이 아예 안 생긴다. 키보드로 직접 타이핑해도 마찬가지였다.

```js
const ed = document.querySelector('.ql-editor');
ed.focus();
while (ed.firstChild) ed.removeChild(ed.firstChild);
for (const line of txt.split('\n')) {
  const p = document.createElement('p'); p.textContent = line; ed.appendChild(p);
}
ed.classList.remove('ql-blank');
ed.dispatchEvent(new InputEvent('beforeinput', {bubbles:true, cancelable:true,
                 inputType:'insertText', data:txt}));
ed.dispatchEvent(new InputEvent('input', {bubbles:true, cancelable:false,
                 inputType:'insertText', data:txt}));
// 이제 aria-label "메시지 보내기" 버튼이 나타난다
```

- `innerHTML`은 **TrustedHTML 정책에 막힌다** — 노드를 만들어 `appendChild` 해야 한다.
- 보내기 전 `aria-label`이 「…현재 **Pro** 모드 사용 중」인지 확인한다.
  단, **새 채팅(`/app`) 화면에는 이 버튼이 안 뜰 때가 있다** — 그럴 땐 기존 대화 URL로 들어간다.
- 전송 성공 판정은 **정지 버튼(「대답 생성 중지」)이 떴는지**로 한다.
- 스크린샷이 「Script injection timed out」으로 죽어도 `javascript_tool`은 살아 있다 —
  좌표가 필요 없는 일은 전부 JS로 하면 된다.
- **응답이 죽으면 정지 버튼이 안 사라져 다음 전송이 막힌다.** 정지를 눌러도 안 풀리면
  탭을 새로고침해야 작성란이 다시 살아난다.
