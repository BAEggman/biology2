### ⛔ s14p02 는 보내지 않는다 (커밋 `2f09c30`)

프롬프트를 다 써 놓고 **보류로 확정**했다. 오늘 배운 규칙에 스스로 걸렸다.

> 이 판의 #5·#6 이 「가운데가 빈 원판 — **아홉** 다발이 각각 **셋**씩」(중심체 9×3, 4장)과
> 「바깥 **아홉** 다발이 각각 **둘**씩 + 가운데 둘」(섬모 9+2, 3장)이다.
> **아홉을 정확히 세야 하는 소품인데 지금 그림은 그것을 맞게 그려 놓았다.**
> 재생성하면 여덟이나 열로 바뀌어 **이미 맞은 7장을 깨뜨릴 위험**이 α·β 2장을 얻는 값보다 크다.

덱의 규칙 그대로다 — 「2장을 위해 7행을 걸지 않는다」.
언제 하나: 이 판을 **다른 이유로** 재생성할 때, 또는 9×3·9+2 원판만 떼어
**작은 도해 판으로 신설**해 본 판의 부담을 덜었을 때.

## ★ 자동화 결함 둘을 더 찾았다 (커밋 `921c1f4`)

**(10) 새 대화를 열면 모델이 `Flash Extended` 로 되돌아가 있을 때가 있다.**
「Extended 가 켜져 있으면 건너뛴다」는 검사가 그것을 통과시킨다.
**Pro 와 Extended 를 따로** 봐야 하고, 되돌리려면 알약을 **두 번** 연다
(먼저 3.1 Pro, 다시 열어 확장된 사고). 끝나고 `aria-label` 로 확인한다.

**(11) 키보드는 보이는 탭에만 닿는다 — 송신뿐 아니라 타이핑도.**

| | hidden |
|---|---|
| JS 실행 · `fire()` · `el.focus()` | ✅ |
| 좌표 클릭 | ✅ |
| **`type` (실제 키 입력)** | ❌ 아무 데도 안 들어간다 |
| **`key "Return"` (송신)** | ❌ 조용히 실패 |

⚠ 다만 **보이는 상태에서 치기 시작하면** 도중에 창이 뒤로 가도 글은 끝까지 들어간다.
순서: **visible 확인 → 클릭 → 타이핑 → 길이 검증 → 다시 visible 확인 → Enter.**
