## 2. ★ 왜 도해 판에서만 생기나 — 만든 순서가 반대였다

| | 만든 순서 | 결과 |
|---|---|---|
| **그림 판 (`s` 계열)** | 사실표를 **먼저** 쓰고 → 그림을 맞춰 그린다 | 소품 칸이 처음부터 **그린 물건**을 부른다 |
| **도해 판 (`d` 계열)** | 그림(svg)을 **먼저** 만들고 → 사실표를 **요약만** 달았다 | 소품 칸이 **물건이 아니라 뜻**을 적는다 |

d01p03 의 옛 소품 칸 여섯:

> 「먼저 작동하는 광계」 · 「전자의 출발점」 · 「최종 전자수용체」 · 「순환적 경로」 · 「명반응 장소」 · 「캘빈회로 장소」

전부 **물건이 아니다**. 소품 칸 훑기가 이름 붙인 **갈래 ①**(소품 칸이 물건을 제 이름으로 안 부른다)인데, 그림 판에서는 **예외**였던 것이 도해 판에서는 **기본값**이었다.

고친 뒤:

> 「왼쪽 아래 **주황 상자**, 그 아래에 **「먼저 작동」**이라 적혔다」
> 「사슬의 맨 아래 왼쪽 **H₂O 상자**에서 선이 올라와 주황 상자로 들어간다 · 그 곁에 **「광분해 → O₂」**가 적혔다」
> 「**Fd** 에서 나와 도식 위를 크게 돌아 **PQ** 로 되돌아가는 **회색 점선** · 그 점선 위에 **빗금 친 O₂**와 **「O₂ 없음」**이 붙었다」

## 3. ★ 방법 — 도해를 눈으로 여는 법 (다음 세션이 바로 쓸 것)

```python
# ① svg 를 뽑는다
i = s.find("{id:'d01p03'"); j = s.find("f:[", i)
m = re.search(r"svg:`", s[i:j]); a = m.end(); b = s[i:j].find('`', a)
open('/tmp/d01p03.svg','w').write(s[i:j][a:b])

# ② png 로 만든다 (cairosvg 가 컨테이너에 이미 있다)
import cairosvg
cairosvg.svg2png(url='/tmp/d01p03.svg', write_to='/tmp/d01p03.png',
                 output_width=1320, background_color='#fdf8ef')

# ③ 위·아래로 잘라 Read 로 본다
```

⚠ **한글 글리프가 네모로 깨져 나온다.** 그래도 **구조와 로마자 이름표는 그대로 보이므로** 판정에는 넉넉하다. 깨진 한글은 `<text>` 를 따로 뽑아 읽으면 된다.
