# ★ 편집도 소품을 증발시킨다 — 편집 뒤 검수표 (2026-08-15)

마스터노트에는 「**편집 요청은 아주 잘 듣는다 — 그대로 두고 딱 한 곳만이 나머지를 하나도
안 건드렸다**」로 적혀 있었다. **이번에 반례가 나왔다.**

## 사례 — s11p01에 소품 둘을 더했더니 하나가 사라졌다

프롬프트는 「기존 것을 하나도 바꾸지 말고 둘만 더하라」였고, 지키지 말라는 것을
**이름까지 열거**했다(지퍼·띠·판자·못·용접공·요리사·쐐기 두 사람·스패너 든 사람).

| | 결과 |
|---|---|
| 분필 동그라미 + 성긴 이빨 구간 | ✅ 완벽 |
| 도르래 + 띠를 감은 줄 | ✅ 완벽 (줄이 띠를 감아 **고리**를 이룬 것이 오히려 더 나았다 — 활주 클램프가 실제로 DNA를 둘러싸는 고리다) |
| **꼬여 뭉친 띠 (자이레이스)** | ❌ **평평해졌다.** 스패너 든 인부는 남았는데 **무는 대상이 사라져** 허공에 스패너를 들고 서 있다 |

★ 「스패너 든 사람」은 지키라고 이름을 댔지만, **그가 물고 있던 「꼬임」은 이름을 안 댔다.**
Gemini는 **사람은 지키고 그 사람이 상호작용하던 구조는 평탄화**했다.

## 그래서 규칙을 이렇게 고친다

### 편집 프롬프트에는 「사람」이 아니라 「사람 + 그가 물고 있는 것」을 함께 못 박는다
- ✗ `the man with the wrench`
- ✅ `the man whose wrench is clamped onto the twisted, overwound stretch of the band`

**동사와 목적어까지 적는다.** 명사만 적으면 명사만 남고 관계는 사라진다.

### 편집 뒤에는 반드시 「사라진 것」을 먼저 센다
새로 들어온 것을 확인하기 **전에** 기존 소품을 하나씩 대조한다. 새것이 잘 나오면
기분이 좋아져서 없어진 것을 놓친다 — 실제로 이번에 그럴 뻔했다.

```
□ 사실표의 모든 행을 꺼내 소품 낱말을 목록으로 만든다
□ 그림에서 하나씩 찾는다 (있다/없다만 적는다)
□ 없는 것이 하나라도 있으면 → 그 행의 카드가 유령이 된다 → 배포하지 않는다
□ 다 있으면 → 그다음에 새 소품을 검증한다
```

### 유령이 생기는 편집은 배포하지 않는다
이번에 두 카드(E1-119#1·E1-118)를 얻자고 배포했으면 **E1-69(자이레이스)가 유령**이 된다.
얻는 것보다 잃는 것이 크다. **한 판 더 돌리는 쪽이 언제나 싸다.**
