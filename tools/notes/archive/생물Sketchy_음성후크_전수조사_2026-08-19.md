## 3. ★ 후크의 세 형태 — 하나라도 있으면 후크다

전수조사를 돌리고 나서야 갈렸다. 「소리」만이 후크가 아니다.

| 형태 | 뜻 | 덱에 이미 있는 예 |
|---|---|---|
| **① 소리** | 소품의 한국어 이름이 라벨과 비슷하게 들린다 | 파치니 → **양파** · 프라이메이스 → **프라이팬**(s11p01) |
| **② 글자 모양** | 소품의 생김새가 그 글자다 | CXC → **편자 둘 사이에 X**(s02p01) · CC → **편자 둘이 딱 붙음** |
| **③ 머리글자 낱말** | 소품 이름의 첫 글자가 라벨이다 | **S**alt·**S**ugar·**S**ex → 소금통·케이크·하트(s07p04) · Mut**S** = **S**earch(돋보기) · Mut**L** = **L**ink(사슬) |

셋 다 없으면 위반이다. 그리고 —

> ★★ **후크가 작으면 후크가 아니다.**
> 2026-08-19 사용자가 `s19p01` v2를 보고 「여전히 phonetic connection 이 전혀 안보이네」라고 했다.
> 그림에는 루비·앰프·자전거·CD·완장이 **다 들어 있었다.** 다만 목걸이 장식·구석 상자 크기였다.
> Sketchy는 Salmonella에 **연어 한 마리**를 그리지 연어 뱃지를 그리지 않는다.
> **후크는 화면의 주인공 크기여야 한다.**

★ 그라운딩(원칙 8)과 헷갈리지 말 것.
**그라운딩은 「사실」에 적용되는 규칙이지 「인출 단서」에 적용되는 규칙이 아니다.**
루비가 Rb 단백질과 아무 관계 없어도 된다 — 후크는 이름을 꺼내는 손잡이지 사실이 아니다.

## 4. 후크 사전

전부 덱 전체 grep으로 충돌을 확인했다.

### 4-1 원소·이온 어휘 (재사용 · 한국어라서 가능한 것들)

| 라벨 | 소품 | 근거 |
|---|---|---|
| Na | **소금 자루** | 나트륨=소금 |
| K | **칼** | 칼륨의 「칼」 |
| Cl | **염소(동물)** | 鹽素 = 염소(goat) 동음 — 한국어에서만 되는 후크 |
| Ca | **분필** | 칼슘=탄산칼슘=분필. K의 「칼」과 갈린다 |

→ **NKCC2** = 소금 자루 1 · 칼 1 · **염소 두 마리**. 이름이 그대로 그림이 된다.
→ **ENaC** = 상피 문에 놓인 **소금 자루**. → **ROMK** = **로마 병정 투구 + 칼**.

### 4-2 세포주기 (`s19p01`) — ✅ 그림 완성

| 라벨 | 소품 | 소리 |
|---|---|---|
| Rb | **사람 머리만 한 붉은 루비** | Rb = 루비듐 원소기호 |
| E2F | 조끼 앞을 채운 **숫자 2** + 키 높이 **F자 장대** | 이-2-F (② 글자 모양) |
| MPF | 사람 키만 한 **앰프** | 엠피에프 ≈ 앰프 |
| Cdk1 | 레버에 끼운 **접시만 한 음반 한 장** | CD + 1 |
| 사이클린 B | **자전거** | 사이클 |
| Wee1 | **어깨띠 두른 위원장** | 위원 |
| Cdc25 | **음반 다섯 장을 부채처럼 쥔 사람** | Cdk와 같은 CD 계열 |

### 4-3 감각 소체 (`s27p01` · 인명 넷 · 13장) — ✅ 그림 완성

| 라벨 | 소품 | 겹치는 것 |
|---|---|---|
| 마이스너 | **거대한 마이크** | 소리(마이) + 가벼운 것을 잡는다 |
| 메르켈 | **거대한 납작 메달** | 소리(메) + **납작한 원반**이라 형태까지 맞는다 |
| 파치니 | **양파** (이미 있음) | 소리(파) + 겹겹 층 |
| 루피니 | **늘린 고무 루프** | 소리(루) + 신전 감지라 기능까지 맞는다 |

### 4-4 속씨식물 생식 (`s34`) — ★ 이 덱에서 가장 깨끗한 한국어 후크

| 라벨 | 소품 | |
|---|---|---|
| **대포자**(모세포) | **대포** | 대포 넷 중 **하나만 장전**돼 있다 = 대포자 4개 중 1개만 생존 |
| **소포자**(모세포) | **소포(택배 상자)** | 소포 **넷이 다 성하다** = 소포자 4개가 다 산다 |

지금은 「꼬투리 넷」이다. 사용자 지적: 「왜 콩 꼬투리에 연결했는지는 모르겠지만」 — 맞다,
꼬투리는 아무 이름도 안 나른다. **대포 ↔ 소포**로 갈면 위층·아래층 대비까지 같이 산다.

### 4-5 비타민 B군 (`s12p04` · `s12p05` · 21장)

시험은 「B1」이 아니라 **티아민·리보플라빈**을 묻는다. 이름 후크면 충분하다.

| 라벨 | 소품 | 상태 |
|---|---|---|
| B1 티아민 | **넥타이** | 설계 |
| B2 리보플라빈 | **리본** | 설계(리본 3건 사용 중 — 색·자리로 갈라야 함) |
| B3 나이아신 | **신발** | 설계 |
| B5 판토텐산 | **널빤지 + 텐트** | 설계 |
| B6 피리독신 | **피리** | ✅ **이미 있다** |
| B7 비오틴 | **비 오는 양철 지붕** | 설계 |
| B9 엽산 | **잎** | ✅ **이미 있다** |
| B12 코발라민 | **코발트빛 코** | 설계 |

### 4-6 이차 전령 (`s16p02` · `s16p02b` · 13장)

| 라벨 | 소품 |
|---|---|
| cAMP | **캠프 텐트의 고리** (씨-앰프 ≈ 캠프) |
| PKA | **피켓** |

| `s11p03` | Mut**S**=돋보기로 **찾고**(Search) · Mut**L**=사슬로 **잇고**(Link) · **B**ER=벽돌(**B**ase) 한 장 · **N**ER=판째(**N**ucleotide 여럿) — 동작이 글자를 나른다 |
| `s07p04` | **S**alt·**S**ugar·**S**ex = 소금통·케이크·하트 |

| `s17p02` | AQP1 = 아쿠아(물)가 뿜어 나온다 |
| `s37p01` | H1이 **밖에 하나** — 개수가 곧 번호 |
