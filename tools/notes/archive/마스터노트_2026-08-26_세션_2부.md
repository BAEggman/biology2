## s08p02 RyR2 — 한 번에 통과

**창고 문 한가운데의 놋쇠 사자 머리 문고리.** s08p01(골격근)의 RyR1 과 **같은 물건**이고,
**1 과 2 는 판이 가른다** — 스위치와 문이 쇠막대로 **직결**된 방이 RyR1,
사이가 **텅 비어** 바깥에서 들어온 물방울이 대신 여는 방이 RyR2 다.

준비돼 있던 v1 프롬프트에 **두 가지를 더해** v2 로 보냈고 한 번에 됐다.

1. **스위치 상자를 s08p01 과 같은 물건으로 맞췄다** — 청록 상자 + **D자 고리**(DHP 예약 심볼).
   v1 은 회색 상자에 빨간 레버라 옆 판과 다른 물건이었다. **같은 물건이라야
   「안쪽 면이 맨판이다」가 비교로 선다.**
2. **「무엇이 있으면 안 되는가」 절을 새로 넣었다** — 상자와 문을 잇는 막대·전선·선반·**그림자**까지.

결과: 상자가 **벽을 뚫고 들어와 안쪽 면이 맨판**이고(급소), 문까지 벽이 완전히 비었고,
사자는 갈기까지 크게 읽히고, 밸브에서 물방울 하나가 떨어져 바닥에 튀고, 그래프의
평평한 가운데가 가장 길다. **다섯 요구가 전부 한 번에 나왔다.**
옛 그림은 상자가 문틀 뒤에 겹쳐 「사이가 비었다」가 **아예 읽히지 않았다.**

## ★★ [재정정] Enter 는 **역시 보이는 탭에만** 닿는다

1부에 「hidden 이어도 Return 이 두 번 다 먹었다」고 적은 것은 **틀렸다.**
s08p02 를 보낼 때 hidden 상태로 **네 번 눌러 네 번 다 배달되지 않았다**
(`edLen` 도 `blocks` 도 그대로였다 — 키 이벤트가 아예 안 온 것이다).
1부의 두 번은 그 순간 창이 실제로 앞에 있었던 것으로 본다.

- `resize_window` 는 `document.hasFocus()` 만 true 로 만들 뿐 **가시성을 못 바꾼다**
- 송신 단추 `fire()` 는 execCommand 로 넣은 글에는 **역시 안 먹는다** (8-25 기록이 맞다)
- → **Enter 말고는 길이 없고, Enter 는 보이는 탭에만 닿는다.**
  hidden 이면 **글은 컴포저에 안전하게 남으니** 사용자에게 창을 앞으로 꺼내 달라고 말한다.

## ★★ 줄바꿈 있는 프롬프트는 **정규화 해시**로 검증한다

`execCommand` 는 줄바꿈을 살려 넣는데 Quill 이 각 줄을 `<p>` 로 만들며 빈 줄을 더한다.
그래서 **글자 수가 안 맞는다**(3,383 → 3,425). 여기서 「match:false 니 보내지 마라」로 멈추면
멀쩡한 프롬프트를 버린다. **공백을 뭉개고 djb2 해시를 양쪽에서 견주면** 정확히 대조된다.

```js  // 브라우저
const norm=s=>s.replace(/ /g,' ').replace(/\s+/g,' ').trim();
const n=norm(document.querySelector('.ql-editor').innerText);
let h=5381; for(let i=0;i<n.length;i++){h=((h*33)^n.charCodeAt(i))>>>0;}
```
```python  # 컨테이너
n=re.sub(r'\s+',' ', t.replace(' ',' ')).strip()
h=5381
for ch in n: h=((h*33) ^ ord(ch)) & 0xFFFFFFFF
```
