## ★ 배운 것 — PIL 수술이 되는 조건

s10p02가 된 이유를 일반화하면 셋이다.

1. **옮길 것이 같은 그림 안에 이미 있다** (새로 그릴 필요가 없다)
2. **목적지가 단색이거나 질감이 단순하다** (겹친 것을 복원할 필요가 없다)
3. **원본을 지우지 않아도 된다** (복사이지 이동이 아니다)

셋 중 하나라도 빠지면 재생성이 싸다. s01p05·s31p02는 2·3을 다 어긴다.

## ★ 마스크 만드는 법 — s10p02에서 확정

금색·잉크 같은 **색으로만 뜨면 뒤 배경이 사각형으로 딸려 온다**(한 번 그렇게 실패했다).

```
① 옮길 물체 안쪽 한 점을 씨앗으로 잡는다 (잉크가 아닌 곳이어야 한다 — 휘도를 찍어 확인)
② ~ink 를 라벨링해 씨앗이 든 성분 = 물체 내부
③ 내부를 4회 팽창시켜 ink 와 교집합 = 물체를 감싼 윤곽선
④ 내부에 닿은 잉크 성분 중 작은 것(걸쇠·손잡이 등)만 붙인다 — 큰 것은 배경 윤곽이다
⑤ binary_fill_holes → binary_closing
⑥ 마지막으로 「물체 색도 잉크도 아닌 화소」를 알파에서 한 번 더 뺀다
```

붙인 뒤에는 반드시 **세 자리를 세서 확인한다** — 목적지(늘었나) · 원본(그대로인가) ·
엉뚱한 이웃(안 건드렸나). s10p02에서는 4 → 3,985 / 8,437 유지 / 1,377 유지였다.
