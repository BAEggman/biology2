## 무엇을 그리려 했나

광주리 둘은 **크기도 모양도 같다**. 다른 것은 **틈·색·깃발** 셋뿐이다.

| | 왼쪽 광주리 | 오른쪽 광주리 |
|---|---|---|
| 틈 | 성겨서 **팔이 어깨까지** 들어간다 | 빈틈없어 **손바닥이 막힌다** |
| 색 | 연한 하늘색 | 진한 남색 |
| 깃발 | 감긴 자리마다 **꽂혀** 있다 | **뽑혀 바닥에** 흩어져 있다 |
| 뜻 | **진정염색질** — 덜 응축·발현 잘 됨·밝게 염색 | **이질염색질** — 더 응축·접근성 낮음·진하게 염색 |
| | **아세틸화 = 느슨 = 촉진** | **탈아세틸화 = 응축 = 억제** |

**옆 탁자** — 실패가 하나도 없는 맨 실이 **끝 없는 고리** 하나(세균: 히스톤 없음·원형) /
실패에 감긴 실은 **양 끝이 드러남**(사람: 선형). 둘 다 DNA+단백질·슈퍼코일인 것은 같다.

★ **깃발이 꽂힌 쪽이 성기다** — 아세틸화의 방향이 그림에 붙어 있다.
