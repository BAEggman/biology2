## 사실표 포맷 — 8/8 세션에서 고친 것 (`f7f6e52`)

사실표만 `esc()`를 통과해 `<b>리보솜</b>` 같은 태그가 **글자 그대로** 화면에 나오고 있었다.
요약(PBR)·본문(bx)은 강조가 먹는데 사실표만 안 먹던 것이다. 822행 중 **155행**이 영향받았다.

```
rich(s) = esc(s) 로 전부 이스케이프한 뒤 허용 태그만 되살린다
허용 = b i em strong u sub sup
```
- `index.html` : `function rich(s)` — 복구 화면의 `esc(r[0])`·`esc(r[1])` 두 곳을 `rich(...)`로
- `sketchy.html` : `const rich = s =>` + `RICH_OK` 정규식
- 같이 고친 것 : 짝 없는 `</p>` 13건(`</span></p>` 패턴) · `&plus;` 3건

**★ 검증은 「빌드·테스트 통과」로 하지 않는다.** 치환식이 깨져도 문법과 테스트는 다 통과한 적이
있다. 두 판의 `rich()`를 **실제로 실행해** 5케이스씩 대조했다 —
`<b>` 살아남음 / `n>1` 안전 / `Ca<sup>2+</sup>` 살아남음 / `<script>` 이스케이프됨 / `&` 이스케이프됨.

## 병합 — bundle로 넘어온 작업을 얹는 법

다른 대화가 프록시에 막혀 push를 못 할 때 `git bundle`로 넘어온다.
`git fetch <파일> HEAD` → `git merge FETCH_HEAD`. 부딪히는 셋은 **전부 생성물이거나 파생물**이다.

| 파일 | 푸는 법 |
|---|---|
| `index.html` | BUILD 구간을 뺀 차이가 몇 줄인지부터 센다(내 쪽이 0줄이면 안전). 확인 후 `--theirs`, 이어서 `npm run build`가 BUILD 구간을 병합된 사실표에서 다시 만든다 |
| `links_report.md` | 순수 생성물 — 아무 쪽으로 풀고 재생성 |
| `test/baseline.json` | 내 쪽 계수를 바닥에 깔고 `pmapMoved`만 합친다. **계수는 `npm run check` 출력에서 읽어 넣는다 — 손으로 적지 않는다** |
