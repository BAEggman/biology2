# 훑기 도구 — `tools/suggest_cards.js` (2026-08-15)

「이미 그렸는데 안 걸린 카드」를 찾는 일이 이 덱에서 **가장 값싼 카드**다.
d05p02에서 15장, s11에서 8장, 텔로미어·세포주기에서 8장이 그렇게 나왔다.
손으로 패널을 하나씩 열어 보던 것을 도구로 바꿨다.

```bash
node tools/suggest_cards.js <게이트|*> [최소점수]
node tools/suggest_cards.js E 4
```

## 무엇을 하나

- 게이트 안의 모든 패널에서 제목·요약·bx·사실표를 모아 토큰화한다(한글 2~5글자 부분문자열 + 영문)
- 미연결 카드의 질문+답을 같은 방식으로 토큰화한다
- **idf 가중**(패널 여럿에 흔한 낱말은 값을 깎는다)으로 겹침 점수를 매겨 최고 패널을 붙인다
- 그 게이트에 **이미 쓰인 접두어**의 카드만 후보로 본다(엉뚱한 단원이 딸려 오지 않게)

## ★ 도구를 믿지 않는다 — 판정은 그림을 보고 한다

점수는 **낱말**이 겹치는 정도이지 **그림에 있는지**가 아니다. 실제로 걸러 낸 것:

| 점수 | 카드 | 왜 안 걸었나 |
|---|---|---|
| 28.0 | F0-44 RNA 중합효소가 푸는 범위 | s11p03은 **수복**이지 전사가 아니다. 낱말만 겹쳤다 |
| 23.9 | C1-129 MCM 헬리케이스 | 「S기 한 번만」을 막는 소품이 그림에 없다 |
| 22.9 | I1-21 PCR | 시험관 장면이 덱에 아예 없다 |
| — | E1-116#1 DNA+단백질·**슈퍼코일** | 실(DNA)과 실패(단백질)는 s37에 있지만 **슈퍼코일이 없다**. 셋 중 둘만 그려져 있으면 걸지 않는다 |

**순서**: 도구로 후보를 뽑는다 → 패널 사실표를 읽는다 → **그림을 연다** → 그림에 있는 것만 건다.

★ d01p02는 **SVG 안의 글자**를 뽑아서 확인했다 — `G₁ · S · G₂ · DNA만 2배 (4→8)`가
실제로 들어 있어서 걸 수 있었다. 도해 패널은 이렇게 확인한다.

```js
const svg = s.slice(i).match(/svg:`([\s\S]*?)`/)[1];
[...svg.matchAll(/>([^<>]+)</g)].map(x => x[1].trim()).filter(Boolean)
```
