## 규칙 15 — ★ Gemini는 **구조물 삭제**를 못 한다. 인물 편집은 한 번에 된다

`s34p03`에서 「관이 벽을 뚫고 지나간다」를 고쳐 달라고 **네 번** 요청했고 네 번 다 실패했다.
표현을 바꿔도(구멍을 파라 / 돌을 지워라 / 아치를 뚫어라 / 터널로 이어라) 결과가 같았다.
Gemini는 매번 **구멍을 옆에 새로 그려 놓고 관은 그대로 돌을 통과**시켰다. 한 번은 스스로
「관을 문 옆에 그렸다」고 자백까지 했다.

반면 **같은 채팅에서 인물 편집은 한 번에 통과했다**:

| 요청 | 결과 |
|---|---|
| 사람 하나를 완전히 지워라 | ✅ 1회 |
| 사람을 바구니 **안으로** 내려 앉혀라 | ✅ 1회 |
| 자루 넷 중 하나를 지워라 | ✅ 1회 |
| 접시처럼 보이는 것을 떡으로 다시 그려라 | ✅ 1회(2차 시도) |
| 벽에 구멍을 뚫어라 | ❌ 4회 |

**결론: 인물·소품은 Gemini에, 벽·기둥·바닥 같은 배경 구조물은 직접 픽셀로.**
구조물 수정을 세 번 이상 요청하고 있다면 그건 도구를 잘못 고른 것이다.

## 규칙 16 — 한 번에 넷을 시키면 둘만 먹는다

`s34p03` 편집에서 네 가지를 한 번에 요청했더니 **정확히 둘만** 반영됐다.
반영된 둘은 인물 관련(사람 삭제·바구니 안으로), 안 된 둘은 배경 관련(벽 구멍·인물 삭제 후 잔상).
`s34p04`에서도 둘을 요청해 하나만 됐다.

**둘씩 끊어 보낸다.** 그리고 매번 **유지할 것을 전부 다시 나열한다**(마스터노트 보조규칙 그대로 —
안 그러면 딴 것이 사라진다).

## 규칙 17 — ★ 국소 도상을 아무리 고쳐도 **구조**가 틀리면 안 낫는다

`s34p04`가 이 규칙을 만들었다. v1에서 적대적 검수가 최상 3건을 잡았고 전부 고쳤다.
v2에서 그 다섯 개가 실제로 고쳐진 것을 픽셀로 확인했는데, **v2가 v1보다 더 큰 결함으로 실격**했다.

> v1·v2의 진짜 문제는 소품이 아니라 **「창고를 그렸지 종자를 안 갈라 봤다」**는 것이었다.
> 아기·죽·가죽이 화면에 **따로** 놓여 있어서 「종자 = 배 + 배젖 + 종피」라는
> **포함관계 자체가 그림에 없었다.** 소품을 하나씩 고치는 동안 그건 손도 안 댔다.

v3에서 껍질을 조개처럼 갈라 열고 그 **안에** 아기·떡·자루를 앉히자 한 번에 해결됐다.

**배포 전 자문에 네 번째 줄을 추가한다:**

> ① 그림에 있는 모든 것이 사실표에 있나
> ② 사실표의 모든 소품이 그림에 있나
> ③ 세라고 시킨 것을 실제로 세면 그 수가 나오나
> ④ **가르치려는 관계(안/밖 · 앞/뒤 · 포함 · 순서)가 배치로 나타나 있나**

## 규칙 18 — 그릇의 안팎이 곧 사실이다. 용기 밖으로 나온 사람은 이름을 잃는다

이 덱은 이미 **사람을 용기 안에 넣는 것**으로 정체를 나른다 —
`s34p01` 서랍 안(소포자) · 껍질 안(수배우체) / `s34p02`·`p03` 바구니 안(중앙세포) / `s34p04` 껍질 안(배).
`s34p04` v2에서 아이를 작업대 **위**에 앉혔더니 「이 아이가 무엇의 내용물인지」가 사라졌고,
검수자가 정확히 그 지점을 짚었다.

**사람을 그릴 때는 「무엇 안에 있는가」를 먼저 정한다.** 안에 없으면 그 사람은 엑스트라다.

## 규칙 19 — 색을 **장면 전체에서** 의미로 고정하면 오답 차단기가 된다

`s34p03`을 그리고 나서야 `s34p02` 바구니의 두 사람이 **청록 + 붉은색**인 것이 문제가 됐다.
p03에서 붉은 옷을 **정자**로 쓰는데, p02를 먼저 본 사람은 바구니 속 붉은 옷을 **극핵**으로
매칭한다 — 3n 구성이 통째로 무너진다. 적대적 검수가 **단독 실격**으로 잡았다.

**이미 배포된 그림의 색은 고칠 수 있다.** HSV에서 **색상(H)만 바꾸고 명도(V)는 유지**하면
워터컬러 질감이 안 깨진다. 마스크는 bbox + 색 범위로 좁힌다(피부·머리색이 같이 안 잡히게).

```python
r,g,b = sub[:,:,0], sub[:,:,1], sub[:,:,2]
mask = (r>120)&(r<245)&((r-g)>40)&((r-b)>45)&(g>55)      # 붉은 옷만
h,s,v = colorsys.rgb_to_hsv(R,G,B)
nr,ng,nb = colorsys.hsv_to_rgb(0.108, min(1, s*(0.60/0.30)), v)   # 겨자색으로
```

지금 씨앗 공방의 색 규칙: **붉은 옷 = 정자 / 겨자색 = 극핵 → 배젖 / 청록 = 난세포·조세포·반족세포.**
`s34p04`의 아이는 **청록 윗도리 + 붉은 바지** — 그 자체가 「접합자 = 난세포 + 정자 = 2n」이다.

# Gemini 운용 — 이번에 걸린 것

## ① 「대답 생성 중지」 버튼을 누르면 이미지가 사라진다

이미지 생성이 끝나도 전송 버튼이 ■(중지)로 굳어 다음 메시지를 못 보내는 일이 잦다.
**중지를 누르면 방금 나온 이미지가 DOM에서 통째로 사라진다.**
정답은 **누르지 말고 페이지를 새로고침**하는 것이다. 대화는 서버에 있으므로 이미지가 돌아온다.
(새로고침하면 입력창 내용은 날아가므로 프롬프트는 다시 넣는다.)

## ② 파일 다운로드가 막히면 페이지에서 직접 캡처한다 — 원본과 동등하다

디바이스 브리지가 끊기면 다운로드 폴더를 못 읽는다. 그때는 이렇게 한다:

```js
const im = [...document.querySelectorAll('img')].filter(i=>i.naturalWidth>500).pop();
const d = document.createElement('div');
d.style.cssText='position:fixed;inset:0;background:#fff;z-index:2147483647';
const n = document.createElement('img'); n.src = im.src;
n.style.cssText='position:absolute;left:0;top:0;width:512px;height:512px';  // DPR 2 → 실제 1024
d.appendChild(n); document.body.appendChild(d);
```

그 다음 `computer` 도구의 `zoom` 을 `region:[0,0,482,482]`(512 CSS px × 0.941 스케일),
`save_to_disk:true` 로 부르면 **정확히 1024×1024** 파일이 컨테이너에 떨어진다.
Gemini 원본이 1024이므로 **손실이 없다**. (2048 원본일 때는 `width:1024px`로 띄운다.)

⚠ `innerHTML` 대입은 Gemini의 TrustedHTML 정책에 막힌다 — `createElement`로 만들어 붙인다.

## ③ 프롬프트 삽입

입력창은 Quill이라 `value` 대입이 안 먹는다. `document.execCommand('insertText', false, TEXT)` 를 쓴다.
줄바꿈이 그대로 들어가고 전송도 안 된다.

# 후보정(픽셀) 기법 — 규칙 15가 걸렸을 때

## 벽에 개구부 파기 (`s34p03`)

1. **개구부의 x 범위**를 행 프로파일로 실측한다. 돌은 `R-B > 42`, 배경은 `R-B ≈ 23`, 잉크는 `lum < 120`.
2. 관을 남기고 위아래만 지운다. **관의 외곽선 y는 벽 바깥·방 안쪽처럼 배경 위에 있는 구간에서 재서
   선형 보간**한다. 벽 위에서 재려 하면 줄눈에 걸려 잔치아가 남는다(실제로 두 번 남았다).
3. 인방·문지방·문설주를 잉크색 `(40,34,30)` 직선으로 긋는다. 관이 지나는 구간에서는 문설주를 끊는다.
4. 인방 밑에 **12~18px 그늘 띠**를 넣으면 「지운 자국」이 「깊이 있는 구멍」이 된다.

## 배경 구조물 지우기 — 옆에서 복사해 붙인다

장식 아치를 지울 때 **같은 y의 왼쪽 평범한 돌기둥을 통째로 복사해 붙였다.**
같은 y에서 가져오므로 **줄눈이 자동으로 맞는다.** 손으로 다시 그리는 것보다 훨씬 자연스럽다.

```python
src = im.crop((216, 995, 296, 1305))          # 평범한 블록 기둥
for dx in (300, 380): canvas.paste(src, (dx, 995))
```

## 액자 테두리 제거

Gemini가 「테두리 그리지 말라」를 자주 어긴다. 행·열별 최소 휘도로 테두리 선을 찾아 그 안쪽을
잘라 내고 1024로 다시 키운다. 이쪽이 다시 돌리는 것보다 싸고 확실하다.
