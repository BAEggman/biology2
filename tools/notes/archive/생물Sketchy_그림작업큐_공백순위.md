# 그림 작업 큐 — 「그릴 것」 공백 순위 (2026-08-08)

> 훑기의 **탈락 요약**은 그 자체로 「이 패널이 무엇을 안 그리는가」의 목록이다.
> 그것을 **미연결 카드 수로 계량**해 순위를 매겼다. 이 문서가 다음에 무엇을 그릴지의 근거다.

## 세는 방법 — 키워드 말고 **카드 ID 대역**

처음에 탈락 사유를 키워드 정규식으로 셌는데 오탐이 심했다
(「전기」가 전기영동을, 「CAM」이 세포부착분자를 잡는 식). **버렸다.**

카드 ID 는 단원별로 연속이므로 **20장 단위 대역마다 (걸림 : 미연결)** 을 세면 정확하다.

```js
const B=20;                       // 대역 폭
for(const c of CARDS){
  const {pre,num}=parse(c.id);
  const k=pre+'|'+Math.floor(num/B);
  PMAP[c.id] ? bucket[k].map++ : bucket[k].un++;
}
// 「미연결 - 걸림×2」 내림차순 = 그림이 아예 없는 대역이 위로 온다
```

## 1위를 어떻게 그렸나 — `s03p04` (참고 사례)

**표를 그리지 마라. 표에서 기출이 무엇을 묻는지를 그려라.**

A0-175~188 은 「~를 3영역으로 비교하면?」 형식의 표 14줄이다. 표를 그대로 그리면
3 × 14 = 42칸이 되어 아무도 못 읽는다. 그런데 **기출은 표를 통째로 묻지 않는다** —
A0-186·187 이 「고세균이 어느 쪽을 닮았나」를 묻는다. 그래서 그림의 본체를
**가운데 가게의 양다리**로 잡고 항목을 여섯으로 줄였다.

| 소품 | 왼쪽(세균) | 가운데(고세균) | 오른쪽(진핵) |
|---|---|---|---|
| 칸막이 | 없음 | **없음** | 작은 방들 + 가운데 큰 방 |
| 저울 | 작다 | **작다** | 크다 |
| 소시지 | 한 줄에 꿴 것 | **한 줄에 꿴 것** | 낱개로 따로 |
| 실패 | 실이 엉킨 채 | **실패** | 실패 |
| 차양 줄무늬 | 곧다 | **가지를 친다** | 곧다 |
| 모자 | 납작모자 | **맨머리** | 맨머리 |

넷은 왼쪽과 같고, 하나는 오른쪽과 같고, 하나는 자기 것이다.
「고세균만의 특징 하나」를 묻는 자리는 차양의 가지 하나로 끝난다.

**한 패널이 31장을 진다** — 지금까지 만든 패널 중 최고 밀도다.

그리지 않은 것(세포벽·인트론·RNA 중합효소)은 걸지 않고 bx 에 「표에서 내린 것」으로 적었다.
