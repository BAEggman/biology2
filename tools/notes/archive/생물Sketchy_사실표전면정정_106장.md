작업일 **2026-08-04** · 커밋 `b29938b` · 앞선 전면감사 문서: `claude/생물Sketchy_그림전면감사_106장.md`

## 무엇을 왜 했나

전면감사에서 결함 **547건**이 나왔다. 그중 **432건이 사실표에 관한 것**(A 대조·B 1:1)이었다.
그림을 새로 그리는 일은 비싸고 느리므로 **이번에는 그림을 건드리지 않고 표만 고쳤다.**

## 판정 규칙 넷

| 판정 | 언제 | 결과 |
|---|---|---|
| **DROP** | 사실은 맞는데 **대응 소품이 그림에 없다** | 표에서 뺀다. 살릴 것은 bx로 내린다 |
| **ADD** | **그림에 있는데 표에 없는** 소품 | 행을 추가한다 |
| **EDIT** | 문구가 그림보다 세거나 소품 서술이 어긋난다 | 문구만 고친다 |
| **KEEP+IMG** | **표가 옳고 그림이 틀렸다**(수·방향·위치가 반대) | **표는 그대로 둔다.** 그림 큐로 넘긴다 |

> **KEEP+IMG가 이 작업의 핵심이다.** 감사에서 나온 「높음」 상당수가 이 유형이었다 —
> `s17p02` 직세혈관 방향, `s33p03` 요소회로 위치, `s31p02` 피루브산 산화 장소,
> `s14p02` 다발 9→8, `s13p01` IgM 5→8.
> **표를 그림에 맞췄다면 시험에서 그대로 틀린다.** 그래서 표는 안 고치고 그림 큐로 보냈다.

## 방식

106패널을 8배치로 나눠 각 배치마다 작업자를 붙였다. **작업자는 감사 기록을 믿지 않고 `png`를 직접 열었고**,
개수·방향·위치가 걸린 자리는 잘라 확대해 픽셀로 실측했다. 감사자가 틀렸다고 판단하면 기각하게 했다.

## 도구

`tools/apply_table.js` 신설 — 정정된 사실표를 `sketchy.html`에 주입한다.

```bash
node tools/apply_table.js <표.json> --check   # 쓰지 않고 검사만
node tools/apply_table.js <표.json>           # 주입 (.bak 남긴다)
```

입력: `{ "s01p01": { "f": [["소품","사실"], ["소품","사실",["카드ID"]]], "bxAdd": "표에서 내린 내용" } }`

**중단 조건 — 하나라도 걸리면 원본을 안 건드린다:**

1. 덱에 없는 카드 ID
2. **원래 f에 있던 카드 ID가 새 f에서 사라짐** (링크 유실 금지)
3. 행이 2~3원소가 아니거나 빈 칸
4. bx 추가문에 **백틱·`${`** 잔류 — v17에서 실제로 걸렸다. 작업자가 쓴 마크다운 `` `s18p02` ``의 백틱이 템플릿 리터럴을 닫아 DATA 전체가 깨졌다. `mdToHtml()`로 변환하고 잔류를 검사한다
5. **고친 결과가 다시 파싱되지 않음** — 한 글자만 새도 14MB DATA가 통째로 죽으므로 쓰기 전에 재파싱한다

`f`만 괄호 스캐너로 잘라 바꾸고 나머지 서식은 손대지 않는다(§2 「큰 파일 고치는 법」).

## 배운 것

**1. 감사 기록은 2차 자료다.** 8배치 전부가 원본 그림을 직접 열었고 **21건을 기각**했다.
그림을 안 열고 감사 기록만으로 표를 고쳤다면 그 21건은 잘못된 방향으로 고쳐졌을 것이다.

**2. 「표와 그림이 어긋난다」에는 방향이 있다.** §8 그라운딩은 「대응 소품이 없는 행은 뺀다」고만 적혀 있는데,
그대로 적용하면 **그림이 틀린 경우에 옳은 표를 지운다.** 그래서 판정에 KEEP+IMG를 넣었고, 결과적으로 **184건이 여기로 갔다** —
DROP(65)의 세 배다. **표보다 그림이 더 많이 틀렸다.**

**3. 형제 패널은 나란히 놓아야 보인다.** `s31p02`의 담장 안팎, `s15p02`의 통·문 불일치, `s12p02a/b`의 모자 충돌,
`s11`의 프라이머 심볼 분열 — 넷 다 **한 장만 보면 안 보이고 형제와 대조해야 보이는 결함**이다.

**4. 픽셀로 재면 말싸움이 끝난다.** `s31p04`의 「한복판」(실측 3px vs 100px), `s27p01`의 부채 길이(70 vs 80),
`s12p01`의 인부 수(3:6), `d03p02`의 반비례(곱이 11,100~19,600으로 1.8배 흔들림) — 전부 실측으로 판정됐다.
