- **글을 고쳐야만 풀리는 오독**(받침 · 표기 때문에 사전 줄로도 두 번 틀림): Sonnet 은 say 를 고치지 않는다 — HOLD 로 두고 `tools/audio/batches/` 의 묶음 기록과 보고에 「Opus 에게: <과> <구간> · 틀린 낱말 · 시도한 사전 줄」을 적는다. 사용자가 글 고침을 승인하면 Opus 가 고치고 다시 잠근다.
- **동시에 돌리지 않는다.** 두 세션 모두 번들을 만들고 `push_b2.sh` 를 고치므로 겹치면 엉킨다. 차례: Opus 가 번들을 냄 → 사용자가 `push_b2.command` → (Opus 세션이 멈춰 있을 때) Sonnet 이 fetch 해서 녹음 → 번들 → 사용자가 `push_b2.command` → Opus 가 이어 감. Opus 가 묶음 가를 끝까지 한 뒤 Sonnet 을 한 번에 돌려도 되고, Opus 의 번들이 올라갈 때마다 사이에 돌려도 된다.
- Sonnet 은 세션을 열 때 `git fetch` 로 GitHub main 이 Opus 의 마지막 번들을 담고 있는지(보고에 적힌 커밋) 먼저 확인한다. 없으면 녹음을 시작하지 않고 「push_b2.command 가 아직 안 눌렸다」고 알린다.
- Sonnet 의 보고: 만든 수 · AI 검수 통과 · 공개 확인 · HOLD(사유) · 사람 청취 0 을 따로 · manifest 수 · 남은 「잠겼는데 녹음 없는 구간」 · 청취표 파일 이름 · 다음 일의 예상 시간.
