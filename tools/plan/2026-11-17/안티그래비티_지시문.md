## 4. Sketchy 원칙 · 지켜야 할 것
- **한 과 = 한 그림 = 한 장면 · 한 사건**(누가 누구에게 무엇을 하는 한 순간). 사실은 그 사건 속의 행동 · 소품. 따로 노는 소품 전시 · 교과서 도해 금지 — 인과의 끈(줄 · 물줄기 · 손에서 손)으로 잇는다.
- **물건 하나 = 사실 하나** · 기묘함(bizarreness)을 꼭 넣는다(사람을 통째로 삼키는 손님 · 일하는 그루터기 · 눈 달린 새싹 같은).
- **덱 약속을 이어 쓴다**(같은 물건 = 같은 뜻 — 예: 칼 = K⁺ · 자갈 = Ca²⁺ · 은빛 구슬 = Mg · 빨간 머리 성냥 = 인 · 흰 방울 = O₂ · 어두운 방울 = CO₂ · 돔 천막 = 핵 · 초록 꼬투리 = 엽록체 · 청록 관 = 물관 · 분홍 관 = 체관 · 붉은 원반 = 적혈구 · 금색 자물쇠 = 약 · 가위표 친 널빤지 = 없음 · 사람이 멘 자루 개수 = 배수성 · 빨간 하트 = 성).
- **예약(`tools/hooks.json` 의 `_심볼예약` · 738개)과 부딪치지 않게** — 소품을 고르기 전에 낱말로 찾는다:
  ```sh
  python3 - <<'PY'
  import json; R=json.load(open('/tmp/b2/tools/hooks.json',encoding='utf-8'))['_심볼예약']
  for w in ['파라솔','우산','바늘','우유']:
      print(w, [k[:60] for k in R if w in k])
  PY
  ```
  다른 뜻으로 예약된 물건은 쓰지 않는다(예: 파라솔 = 파라믹소 · 배턴 = 소마토스타틴 / GH · 우유병 = 알로락토스 · 캥거루 = 대륙이동 · 수면 모자 = 잠 · 망토 두른 이 = 바이러스). 설계서의 「피할 것」이 고른 **대안도 다시 찾는다**(배운 것 92).
- 그림 안에 **글자 · 숫자 · 기호(+, −, ?) 금지** · 알려진 캐릭터 · 실존 인물 금지 · 아기에게 양복 · 넥타이 금지.
- 글(`obj`)은 **그림에 보이는 것만** — 그림에 없는 것을 글에 남기지 않는다. `fact` ≤ 60자 · `say` ≤ 560자.

6. **PIL**: 개수 · 자리 · 옮기기 · 지우기 · 빛깔(Gemini 는 「옮기기」를 하면 틀을 다시 짜고, 작은 것 여럿의 자리를 못 바꾼다 — 배운 것 94). `tools/prompts/deckfill.py`(평면 채우기) · `L22e_tubes.py`(자리로 빛깔 바꾸기) · `s13_lib.py` 가 본보기.

9. **블라인드 테스트**(§8) ✕ 0 까지 + 끝 그림 · 끝 글로 한 번 더.
10. **예약** `tools/prompts/reserve_<ID>.py`(새 물건을 `_심볼예약` 에 · 본보기 `reserve_L22e.py`) →

## 7. Gemini 카본으로 그리기
- **어디서**: 사용자의 Chrome 에 로그인된 `gemini.google.com`(Antigravity 의 브라우저 기능으로 몬다). 입력창 아래 모델 알약이 **「카본」 · 생각 「높음」** 인지 매번 확인 — 아니면 고른다. (Antigravity 안에서 같은 모델로 「첨부 그림 편집」이 되는 이미지 도구가 있으면 그것도 된다.)
- **그림 한 장**: 새 채팅 → 그림 파일 올리기(S1 은 `cast_ref`, 구역 편집은 `z/up_<NAME>.png`) → 프롬프트 붙여 넣기 → 보내기 → 30 ~ 90초 → 결과 그림 내려받기 → `z/gem_<NAME><탭><회>.png`(예: `gem_ZAA1.png`) 로 옮김.
- **같은 채팅에서 고치기**: 「Very good. One more change to this last picture: … Keep everything else exactly the same. Same image size and framing. No text anywhere.」 — 새로 올리지 않는다.
- **두 탭에 같이** 보내 둘 중 나은 것을 고르면 빠르다(배운 것 90).
- **받은 그림은 반드시 눈으로**(grid.py 로 키워서): 글자 · 숫자 · 손가락 · 팔다리 개수 · 겹침 · 시킨 것만 바뀌었나 · 금지 소품(파라솔 · 넥타이 …)이 끼었나. Gemini 는 「No text」 「no buttons」 같은 금지를 자주 어긴다.
- **로그인 · 약관 · 동의 · CAPTCHA 창**이 뜨면 멈추고 사용자에게 알린다(풀지 · 우회하지 않는다).
- **프롬프트 뼈대**(영어가 잘 듣는다):
  - S1: `The attached picture shows the cast of a clean medical mnemonic cartoon (bold black ink outlines, flat bright colors, big clear shapes, cute and funny): <출연진>. Draw ONE wide 16:9 cartoon SCENE in exactly the same drawing style with these SAME kinds of characters. It must look like one lively, funny moment in a story — NOT like a diagram, NOT like characters standing in a row: figures overlap at different depths and everyone is busy doing something. PLACE: … WHAT HAPPENS (one connected story — …): 1. … No text, letters or numbers anywhere.` (본보기 `L06a_prompt_scene.txt`)
  - 구역 편집: `Edit the attached picture. Keep exactly the same drawing style (bold black ink outlines, flat bright colors) and keep <그대로 둘 것 낱낱이> exactly as they are, with only this change: <바꿀 것 하나>. Same image size and the same framing. No text, letters or numbers anywhere.`
- 배운 것 몇: 더하는 편집(얼굴 · 몸짓 · 물보라)은 잘 지키고 옮기는 편집은 틀을 다시 짠다 → 옮기기 · 개수는 PIL · 「물이 들어간다」 그릇 겉에 흘러내리는 물을 두지 않는다(새는 것으로 읽힘 · 96) · 털은 갈라지지 않게(95) · 작은 표지는 크게.

## 8. 블라인드 테스트(일치 검사) — 그릴 때마다
1. 판 만들기: `python3 tools/prompts/mkcheck2.py <ID> /tmp/chk_<ID>_<회> s1,s2,…` → `full.jpg` · `sN.jpg` · `sN_k.jpg` · `stops.tsv`.
2. **새 에이전트 대화**(Antigravity 의 새 대화 · 이 과의 사실 · 설계를 본 적 없는 것)를 열어 `tools/kit/일치검사_프롬프트.md` 의 「독자에게 주는 글」을 그대로(〈 〉만 채워) 준다 — 폴더 경로 · 정거장 수 · 3단계 물음(이 그림에서 개수 · 방향 · 누가 누구에게 · 빛깔이 뜻인 것). **fact · hook · say 는 주지 않는다.** 회마다 새 대화.
3. 결과: ✕ = 반드시 고친다 · △ = 뜻이 흔들리면 그림을, 글이 더 말했으면 글을 그림에 맞춘다. 고치는 차례: 사건 자체를 그림으로(구역 편집) → 개수 · 자리는 PIL → 그래도 남는 것만 글. (마) 「도해처럼 따로따로」가 나오면 끝난 것이 아니다.
4. ✕ 0 이면 끝 그림 · 끝 글로 한 번 더 · 회차표(회 | ○ · △ · ✕ | 나온 것 → 고친 것)와 끝 회 첫인상 한 줄을 `<ID>_설계.md` 에. 덧붙임 +정거장은 보탠 정거장만 · 2회 안.
