## 1. 먼저 알 것
1. **고리는 이미 정해졌다.** 사용자가 직접 고른 고리는 제안 단계가 없다(`tools/cue/README.md` §0). 심판(opus · effort 가장 높게) 하나가 넷만 확인한다 — 카드 사실 · 예약 기호 · 보존과 잠금 · 자리와 크기 — 그리고 그리기 명세를 쓴다. 글은 `tools/cue/jobs/심판_사용자고름_글.md`. 점수로 퇴짜 놓지 않는다. 부딪치면 그리지 않고 사용자에게 돌려준다.
2. **기록하는 법이 생겼다(이번 커밋).** 고르기 일감 폴더에 과마다 `확인_<과>.md` 를 남긴 뒤 `node tools/cue/jobs/record.js <고르기 일감> <과|sid …>`. 확인 기록이 없는 과의 hook · obj 를 바꾸면 `test/verify_standing.js` 가 막는다. 앞서는 6 + 1 을 돌린 폴더만 받아 주어서, 고르기 일감으로는 기록할 길이 없었다.
3. **고른 것이 적힌 곳**: `tools/cue/jobs/1126_고르기/picks.json` · `1127_고르기/picks.json` · `1128_고리v2/picks.json`(물건) · `tools/cue/names/장부.md` 의 「처방」 칸(구간 · 주의할 것) · `tools/hooks.json` 의 `_심볼예약`(이미 올라 있다 — 실물과 문구가 달라지면 고친다).
4. **플라스토시아닌은 그림 그대로**다(베이지색 옛 데스크톱 PC). L45c 에서 컴퓨터 · 여왕 카드 · 플로피에 손대지 않는다.
5. **HIV 약 셋은 넣을 자리가 없다.** 새 과에는 약 정거장이 없다(L01c s8 ~ s12 가 레트로바이러스의 걸음 · L01d s8 이 HIV). 소품은 정해졌지만 자리와 사건은 새로 짓는 것이라 조각 H 는 6 + 1(보통 일감 — 가 · 다 · 라 + 심판)을 돈다.
6. **여러 과에 걸친 기호**는 먼저 그리는 조각이 꼴을 정하고, 그 조각 그림을 레시피(`tools/prompts/<ID>_src/`)에 남겨 뒤 조각이 참조 그림으로 쓴다.

## 4. 과 하나의 흐름 (조각마다 과 단위로 되풀이)
1. **꾸러미** — `tools/cue/jobs/<고르기 일감>/` 아래 그 과의 것: 고른 묶음(picks.json) · 장부의 처방 · 걸린 카드(`node tools/kit/cardfull.js`) · 그림 전체와 조각(`tools/cue/mkpacket.js` · `tools/prompts/mkcheck2.py`). 한 과의 묶음이 두 일감에 걸쳐 있는 것은 L15a 뿐이다(트랜스형 = 1126 · 나머지 셋 = 1128) — 꾸러미와 확인 기록은 `1128_고리v2` 에 하나로 만들고, 트랜스형 줄 머리에 「1126 에서 고름」이라고 적는다.
2. **심판 확인** — 독립 에이전트(opus · effort 가장 높게) 하나에 `심판_사용자고름_글.md` 를 준다 → `확인_<과>.md`. 본 세션은 예약과 사실을 제 손으로 한 번 더 본다(README §9). 「부딪침」이 난 묶음은 그리지 않고 보고에 적는다.
3. **그리기** — 통과한 묶음을 명세대로. Gemini 웹 구역 편집 → `zone3.py` 붙임 → 필요하면 PIL. 레시피(`tools/prompts/<ID>_src/recipe.json` + `zbuild.py`)를 남긴다(11-20 지시서 §26). 글자 · 숫자 · 상표 · 아는 캐릭터 · 실존 인물 없음. 고리 물건은 짧은 변 110 px 이상 — 자리가 작으면 바꿔 넣기.
4. **글** — obj · hook 을 실물대로, say 에 이름을 잇는 한 문장(40자 안쪽 · say 560자 한도 · 반말 서술체 · `verify_saytext`). fact 는 그대로. 그림에 없는 것을 말하지 않는다.
5. **눈 검사 셋** — README §8. 독자 ㄱ 이 그 물건을 고른 이름으로 부르는가 · 독자 ㄴ 이 맞는 구간 + 설계한 종류로 꺼내는가(「하는 일로 짐작」은 통과가 아니다) · 독자 ㄷ 이 사실이 보인다고 하는가.
6. **세 번 그려도 안 되면** 공개 그림을 바꾸지 않고 보류한다. 까닭을 `확인_<과>.md` 끝과 보고에 적는다. 다른 물건으로 바꾸지 않는다 — 고리는 사용자가 골랐다.
7. **기록** — `record.js`(hook · obj 를 바꾼 구간) · `hooks.json`(사전의 낱말 → 소품 · `_심볼예약` 문구) · 장부(`python3 tools/cue/names/setrow.py` — 상태를 「그림 반영 〈날짜〉 · 눈 검사 통과」로. `장부.json` 을 직접 고치지 않는다) · 문 1 · 2 · 3 의 기준선 · 넘은 구간 잠금(`tools/audio/locked.json`).
8. **녹음** — 닿은 구간에 녹음이 있으면 「다시 녹음」 목록에 적는다(§5). 녹음은 하지 않는다. 글이 안 바뀌고 그림만 바뀐 녹음 구간은 11-20 지시서 §16 대로 픽셀 차를 재어 적는다.
9. `node test/all.js` → **과마다 커밋** → 다음 과.
