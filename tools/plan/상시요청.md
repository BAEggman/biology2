## 2. 사용자의 말(원문 · 날짜)
1. (2026-11-19 · 11-23 다시) 「각 그림 칸 오른쪽에 쓰고 지울수 있는 별표 표시 … 다음 그림으로 자동 넘김 기능을 토글로 … 각 그림 칸 왼쪽에는 썸네일 … 반복재생 기능도 넣어줘, 구간 및 전체 반복재생 설정가능하게.」
2. (2026-11-19 · 11-23 다시) 「새로운 그림에는 phonetic cue, 나 link 가 부족한 경우가 많아, 감사를 다시 해보고 cue 가 그림에 표현되게 그림을 그려줘야 해.」
3. (2026-11-19 · 11-23 다시) 「전체 덱에서 자매염색분체와 상동염색체 표현이 일관되게 그림 사이에서 유지되지 않아서 혼동쌍 문제에 취약해.」
4. (2026-11-19 · 11-23 다시) 「다음 소품, 상황 만들기, 이외의 sketchy 요소 및 그림간 연결 and 고치기 부터는 독립 에이전트 6개를 실행한 다음 어떤 phonetic cue, mnemonic cue 를 생각해 보았는지 보고하고, 마지막 7번째의 에이전트로 하여금 이때까지 너에게 가르쳐주었고, 다른 문제가 없었던 mnemonic cue, phonetic cue 에서 왜 이런 cue 들이 적합했는지 생각한 다음 채점을 해서 … 그리기 결정을 하도록 하자.」
5. (2026-11-19 · 11-23 다시 · 가장 중요) 「내가 제공했던 피드백을 바탕으로 학습해서, 학습결과를 바탕으로 다른 그림들에서도 문제들을 찾아보고 알아서 고치는 계획을 짜봐. 지금 지적한 문제들은 표면적인 문제일 뿐이고, 지적하지 못한 문제들도 많은 그림에 산재해 있어.」
4-1. (2026-11-23 · 6+1 돌리는 법 바꿈) 「보통 일감(과 하나의 이름 고리 · 소품)은 제안자 셋만 따로 돌려 — 가(우리말 소리 · 없으면 학생이 아는 영어 낱말이나 글자 모양) · 다(사건 연출) = opus, 라(기호 재사용 · 그림 간 연결) = sonnet — 심판(opus)이 채점해. 혼동쌍 · 자리와 크기 · 붐빔은 제안 양식의 칸으로 셋 모두 채우게 해. 여러 과에 퍼지는 기호 일감(염색체 문법 등)만 여섯 모두 돌려. 재공모는 한 번만. 그래도 합격안이 없으면 그 낱말을 「사용자에게」 목록에 올리고 넘어가. 내가 직접 정해 준 고리는 제안 단계 없이 심판의 확인(사실 · 예약 기호 충돌)만 거쳐 써.」
