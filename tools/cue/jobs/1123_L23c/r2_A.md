### 〈L23c · 정거장 2~5 (s3 α₂ 방) · 노르에피네프린〉 — 안 1

- 길: 그림
- 물건: 노르웨이 연어 한 마리. 이미 바닥에 떨어져 있는 확성기(L13b 이웃 외침 릴레이와 같은 「내보내는 기구」)의 입에서 반쯤 튀어나와 끼어 있다. 새 인물은 없음.
- 사건: 손님(NE 신경 끝)이 확성기로 곧장 쏟아내려던 연어가 입에 끼어 반쯤만 나온다. 방 이름 α₂(분비 억제)와 같은 방향의 장면이라, 「신경 끝에서 표적으로 직접 내보냄」이 확성기 입이라는 한 점에서 읽힌다.
- 고리: ① 소리. 연어 → 노르웨이 → 노르(에피네프린). 첫 음절 겹침은 두 걸음(연어→노르웨이)이라 간접적이다.
- 낭독에 넣을 한 문장: 확성기에서 튀는 노르웨이 연어, 노르에피네프린이다. (29자)
- 자리와 크기: s3 확성기 위. bbox ≈ 440–540 × 580–700 (≈100×120 → 146×176@2048). 110px@2048 최소(75px@1400)는 충족. 빈 구역 Z(435–610 × 435–665, 폭 175)에 들어가고, 확성기 bbox(437–531 × 697–760)와 겹치지 않고 입 위에 얹히게 한다.
- 그림에서 바뀌는 것 · 그대로 두는 것: 바뀜 = 연어 하나 추가. 그대로 = 손님(NE) 정본, 드럼통 = 에피네프린 = 혈액 쪽 정본, 입 막은 손, 알 개수(α = 알), 눌림틀.
- 예약 확인: 연어 → 없음. 노르웨이 → 없음. 확성기 → L13a/L13b 인터폰 계열만 걸림(같은 「내보냄」 뜻이라 충돌 아님, 재사용). 노 / 노래 / 노란 → 각각 산화질소(노) · 오페론(오페라) · 플라빈(노랑)에 걸려 쓰지 않음. 물고기류는 「이유 없는 동물」 쪽 위험이 있으나 연어는 노르웨이로 이유가 있음.
- 혼동쌍: 에피네프린(드럼통). 손님 쪽에 소리를 붙여 정본은 뒤집지 않음.
- 붐빔: s3 이 이미 눌림틀 + 확성기 + 손 + 회색 드럼으로 빽빽하다. 연어 하나가 더해지면 Z 의 폭이 거의 다 찬다(ACh 안 1 과 한 구역을 나눔).
- 오독 위험과 스스로 본 약점: (1) 780px 에서 연어로 알아보기 어려울 수 있음(분홍 몸통 + 은빛 배가 필요). (2) 연어 → 노르웨이 → 노르 두 걸음. (3) 확성기 안의 물건이 「들어옴」으로 읽히면 수용체로 오독될 수 있어, 반쯤 나오는 방향과 튀는 물방울을 그려야 한다.

### 〈L23c · s3 (α₂ 방) · 아세틸콜린 · ACh〉 — 안 1

- 길: 그림
- 물건: 솜 마개를 꽂은 아세톤 병 하나(작은 병, 솜은 병 주둥이에서 삐져나옴). 병 하나로 이름을 나르고, 라벨 글자는 없음.
- 사건: 확성기 옆에 서 있고 솜이 확성기 쪽으로 기울어, 신경 끝의 분비가 부교감 쪽 ACh 로도 눌릴 수 있음을 비춘다(L23b#6 이 M₂ 와 α₂ 가 같은 Gi 눌림틀이라 했으므로 이 방과 이어짐). 쏟아지는 병이 아니라 서 있는 병이므로 「쏟아짐 = 분비」 반대 읽기를 피한다. 표적이 부교감 입력(심장 M₂, 기관지)도 받는다는 사실은 부정하지 않는다.
- 고리: ① 소리. 아세톤 → 아세(틸콜린), 첫 음절 두 글자 겹침.
- 낭독에 넣을 한 문장: 옆에 선 아세톤 병, 솜마개의 아세틸콜린이다. (24자)
- 자리와 크기: s3 확성기 오른쪽 바닥, 벽·바닥 경계에 걸침. bbox ≈ 545–615 × 645–765 (70×120 → 102×176@2048). 구역 Z 오른쪽 끝(610)을 5px 넘는다. 폭은 780px 에서 약 39px 로 경계선. 병은 짙은 청색, 솜은 흰색이어야 크림색 바닥에서 읽힌다. 연어(안 1)와 가로로 맞닿지만 겹치지 않음.
- 그림에서 바뀌는 것 · 그대로 두는 것: 바뀜 = 병 하나 추가. 그대로 = L23b 의 열쇠구멍에 꽂힌 놋쇠 열쇠(리간드)는 건드리지 않는다. 이 방에는 열쇠를 그리지 않는다(걸린 열쇠는 키나아제로 읽히고 L23b 와 결투가 된다). 이름만 나른다.
- 예약 확인: 아세톤 → 없음. 솜 → 없음(면봉 · 휴지는 쓰지 않음). 병 → 걸린 항목이 있으나 이 병과 뜻이 다름. 놋쇠 열쇠 → L23b ACh(둥근 놋쇠 열쇠)가 임자라 새로 그리지 않고 이름만 이어 씀. 매니큐어 → 없음(대안). 콜 → 콜히친(전화), 콜리페이스(콜리), 콜라에 걸려 안 씀.
- 혼동쌍: L23b 의 ACh 열쇠(같은 이름, 다른 물건) · 아드레날린 수용체 α₂(같은 방).
- 붐빔: s3 오른쪽이 연어와 병으로 꽉 찬다. 이 방의 그림은 이미 많아서 둘 중 하나만 쓰는 것이 낫다.
- 오독 위험과 스스로 본 약점: 이 낱말의 소리가 가장 약하다. 아세톤 → 아세틸까지는 소리가 맞지만 병과 콜린(「콜」 계열이 모두 예약됨)은 이어지지 않아 절반만 푼다. 병이 선반 위의 물건처럼 보이면 수용체 상점으로 오독된다. 칸 크기가 모자라면 이 안을 접는다.

- 낭독에 넣을 한 문장: 눌림틀은 열쇠로 연 M₂ 시계의 것과 같다. (24자)
- 자리와 크기: 변경 없음. 눌림틀은 s3 에 이미 있음.
- 그림에서 바뀌는 것 · 그대로 두는 것: 바뀜 없음. 모두 그대로.

- 혼동쌍: 없음(이름 고리가 아니므로).
- 붐빔: 없음.
- 오독 위험과 스스로 본 약점: 소리 고리가 아님을 솔직히 인정한다. L23b 쪽에서 이미 푼 이름에 기대는 이음일 뿐이라, 이 문서 목적(이름 역방향 회상)에는 거의 도움이 안 된다. 심장 M₂ 가 시계에 걸리는 것과 부교감 입력이 따로 있다는 사실과는 충돌하지 않는다.

### 〈L23c · s4 (β₁ 방) · 글리코젠〉 — 안 1

- 길: 그림 (새 소리 물건 없음, 정본만)
- 물건: 정본 가지 친 포도송이(L16b#7 정본) 한 송이를 벽 나무못에 건다. 줄기에 금반지(cAMP)를 하나 끼워 걸이로 삼는다. 또 s4 에만 빠진 뚜껑 날아간 드럼통(에피네프린 정본)을 바닥에 둔다.
- 사건: 에피네프린 드럼통이 뚜껑을 날리고, 그 위쪽 벽에 걸린 포도송이 줄기를 금반지가 잡는다. 「혈액으로 온 에피네프린 → 간에서 글리코젠(포도송이)을 푼다」와 「신경 끝에서 온 손님 → 심장 시계」가 같은 방 안에서 갈라져, 카드가 대비시키는 간 = 분해 / 심장 = 심박이 지워지지 않는다. 간 정본(붉은 벽돌 곳간)은 붐비므로 새로 그리지 않고 낭독으로만 잇는다.
- 고리: 기존 기호 재사용(정본 포도송이 + 금반지 + 드럼통). 소리 고리 아님. 분류하면 ④ 정도이며 낱말이 한글 소리로 풀리지 않는 것이 약점.
- 낭독에 넣을 한 문장: 금반지가 잡은 포도송이는 간에서 풀리는 글리코젠이다. (30자)
- 자리와 크기: s4 왼쪽 옆벽 띠. 포도송이 bbox ≈ 712–795 × 150–262 (≈83×112 → 121×164@2048). 110@2048 충족. 드럼통과 날아간 뚜껑은 띠 바닥 ≈ 715–790 × 320–378. 이 띠(x 705–777, 뒷벽 777–796)는 픽셀 색으로 비어 있음을 확인했다(옆벽 ≈(236,223,170), 뒷벽 (251,242,187), 벽 모서리 선만 다름). 눌림틀 상자 왼쪽 가장자리 x≈795, 선반 797–940 × 105–145 와 겹치지 않는다.
- 그림에서 바뀌는 것 · 그대로 두는 것: 바뀜 = 벽 나무못 + 포도송이 + 금반지 하나 + 바닥 드럼통과 뚜껑. 그대로 = 눌림틀, 시계, 추, 크랭크, 금반지 서랍 등 β₁ 정본 전부.
- 예약 확인: 포도송이 → L16b 정본(가지 친 포도송이, 극 걸이 송이 정본 허용). 포도알 → 별도 낱말로 예약돼 있어 낭독에 쓰지 않음. 드럼통 → 에피네프린 정본(뚜껑이 날아간 모습). 지렛대 → GA₃ 에 예약, 안 씀. 못 → 히스톤(놋쇠 못)이 임자인데 이것은 나무못이라 색 · 재질이 다름. 벽돌집 → 간 정본(여기서는 그리지 않음).
- 혼동쌍: 포도송이를 심장 쪽 시계에 걸면 「심장 = 글리코젠 분해」로 읽혀 대비가 사라진다 → 시계가 아닌 왼쪽 옆벽에 둔다. 걸이 금반지(cAMP)와 PKA 천막 + 열쇠(L16b)는 서로 다른 기호.
- 붐빔: s4 의 이 띠는 비어 있어 부담이 작다. 반면 금반지 사슬(눌림틀 아래 반지 860–945 × 275–350 → 이 포도송이)은 약 100px 이상 떨어져 이어진 사슬로 안 보인다. 서랍(900–960 × 330–375)과 선반 β 천을 피하느라 생기는 거리이므로 사슬이 끊겨 보인다는 한계를 숨기지 않는다. 지렛대 끝에 거는 대안은 송이가 약 70px 폭(102@2048)으로 8px 모자라 버림. s5 오른쪽 빈 곳 P(≈1065–1175 × 432–545, 110×113)는 폭이 맞지만 심장 방이 아니라서 글리코젠 비중이 다른 방에 놓임.
- 오독 위험과 스스로 본 약점: (1) 포도송이가 「가지 친」 모양으로 읽혀야 하는데 벽에 걸린 포도로만 보일 위험. (2) 글리코젠 이름의 소리 고리는 없음(§7 이 새 소리 물건 금지). (3) 심장 근육에도 글리코젠이 있고 β₁ 신호로 분해된다는 사실이 있어 「심장은 분해가 아님」으로 읽히지 않게 낭독이 간 얘기임을 분명히 해야 한다 — 카드가 심장 쪽 분해를 어떻게 다루는지는 모름.

### 〈L23c · s4 · 글리코젠〉 — 안 2

- 낭독에 넣을 한 문장: 금반지가 L16b 의 포도송이를 간 곳간에서 푼다. (24자)
- 자리와 크기: 변경 없음.
- 그림에서 바뀌는 것 · 그대로 두는 것: 바뀜 없음. 모두 그대로. s4 에 드럼통이 빠진 사실(안 1 의 이유)은 이 안에서 건드리지 않는다.

### 과 전체

- 한 사건: 혈액으로 온 뚜껑 날린 드럼통(에피네프린)은 벽의 포도송이(글리코젠)를 풀게 하고, 신경 끝 손님(노르에피네프린)은 확성기로 곧장 연어를 내보내 시계를 움직인다.
- 이웃과 이음: 확성기는 L13b 외침 릴레이와 같은 뜻, 포도송이 + 금반지는 L16b 정본, 놋쇠 열쇠는 L23b 에 남겨 두고 이름만 잇는다.
- 사용 가능성: 노르에피네프린 안 1 과 아세틸콜린 안 1 은 같은 s3 구역을 나눠 쓰므로 둘 중 하나만 그리고, 다른 하나는 낭독으로만 둔다.
- 정직한 판정: 아세틸콜린은 소리가 가장 약하고, 글리코젠은 소리 없이 정본 재사용으로만 풀었다.
