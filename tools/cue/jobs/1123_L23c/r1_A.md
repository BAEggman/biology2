- 고리: ④ — 「글리코젠은 가지가 갈라지고 또 갈라져 끝마다 포도가 붙은 덩이」라는 이름 뜻 그대로(덱 약속: 가지에 붙어 있으면 글리코젠 · 떨어져 구르면 포도당). 사실 쪽: cAMP(금빛 고리)가 닿자 글리코젠이 포도당으로 헐린다.
- 낭독에 넣을 한 문장: 금빛 고리가 들이받자 글리코젠 송이에서 포도가 떨어진다.
- 자리와 크기: s4 압착기 받침 상자 앞 바닥(약 x880–975, y330–380) — 송이 높이 ≈ 70 px(1400) ≈ 100–110 px(2048), 굴러간 포도 둘셋은 시계 받침 쪽으로.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀜 — 포도송이 하나(잔가지가 보이게) · 떨어진 포도 몇 알 · 상자에서 굴러 나온 금빛 고리 하나(이미 있는 고리의 자리만 옮김). 그대로 — 압착기 · 베 하나 · 시계 · 손님.
- 예약 확인: `포도송이` → 「가지가 거듭 갈라진 나무에 붙은 포도 = 글리코젠 전용 · 장대에 매단 포도송이(L16b#7 — 꼭지에서 잔가지가 갈라진 송이 · 알이 후두둑)도 글리코젠으로 읽어 맞다」 · 「동글동글한 포도 = 포도당 · 붙었느냐 떨어졌느냐가 갈림 · 『포도알』이라고 쓰지 마라(알 = α)」 · 「쓰러진 빈 포도 그릇에서 쏟아진 금 고리 = 포도당 낮음 → cAMP 높음(L25a) — 그릇의 포도는 낱알로」 · 「분홍 풍선 송이 = 폐포」(L46f). `곤봉` 글루카곤 — 곤봉은 그리지 않는다. `글리코` 위와 같음. ⚠ 낭독에서 「포도알」이라 부르지 말 것(알 = α 아형과 부딪힘 — 이 과는 선반의 알이 α다!).
- 혼동쌍: L25a 의 「빈 포도 그릇 + 금 고리」(포도당 낮음 → cAMP 높음)와 물건 짝(포도 + 금 고리)이 같다 — 여기는 **그릇 없이 가지 친 송이**이고 고리가 송이를 **들이받는** 방향이라 갈린다. 포도알과 선반의 흰 알(α)은 빛깔(보라 대 흰)과 자리(바닥 대 선반)로 갈린다.
- 붐빔: 새 물건 1(송이) — 금빛 고리는 이미 있는 것을 굴린다.
- 오독 위험과 스스로 본 약점: ① 사실은 「간의 글리코젠 분해」인데 s4 는 심장(β₁) 방이다 — 고리가 송이를 치는 것이 「β₁ → 글리코젠 분해」로 읽힐 수 있다(심근도 에피네프린에 글리코젠을 헐지만, 카드 답은 간이다 — 낭독 「에피네프린은 간에서 글리코젠 분해를 촉진하는 β₂에도 작용한다」에 기대야 함). 덜 위험한 자리는 s5(β₂ 방, 베 둘) 압착기 앞 — s5 의 바닥 드럼통 곁에 두면 「에피네프린 → β₂ → 고리 → 송이가 헐림」이 한 줄 소동으로 더 바르게 선다. 정거장 표가 s4 에 걸었으므로 s4 를 먼저 적고 s5 를 대안 자리로 적는다. ② 포도가 굴러 시계 쪽으로 가면 「포도 = 진자 연료」로 읽힐 수 있다 — 반대쪽(방 왼쪽 벽)으로 굴린다.

### 〈L23c · s4 · 글리코젠〉 — 안 2
- 길(글 / 그림): 글 — **쓸 만한 빈 소품이 없다고 판단**(정직하게 적는다)
- 물건: (후보였던 것) 압착기 받침 상자 · 괘종시계 몸통 · 진자추
- 사건: —
- 고리: 없음. 상자는 금빛 고리(cAMP) 그릇이고, 진자추는 심박, 괘종시계 몸통은 시계 약속(진자 = 심박) 아래에 있다 — 셋 다 이미 뜻을 나른다. 「글리-」 소리가 나는 일상 물건(글러브)은 가죽 글러브 = 글로메로균 예약이라 못 쓴다.
- 낭독에 넣을 한 문장: (쓰지 않음)
- 예약 확인: `가죽` → 「가죽 글러브 = 글로메로균(L05a)」 확인.
- 오독 위험: 억지로 진자추를 「포도알 같은 추」로 부르면 진자(심박) 뜻을 빼앗고 「알 = α」와도 부딪힌다 — 그래서 글 길은 내지 않고 안 1(그림)만 권한다.

## 과 전체 — 한 장면으로 엮으면
1. 왼쪽 위: **노**가 터진 드럼통을 퍼 올려 튄 물이 조인 관 허리에 철썩 — 노르에피네프린이 α₁ 혈관에 닿는다(노 + 에피네프린 통).
2. 왼쪽 아래: 손님이 입을 막아 확성기 「노래」가 끊긴다 — α₂ 가 NE 분비를 줄인다(글 길).
3. 오른쪽 위: 미친 듯 돈 진자가 **아세톤 병**을 쳐내 쏟아진다 — 아세틸콜린(부교감) 브레이크가 빠지고 손님은 「**에이씨**(ACh)!」.
4. 같은 방(또는 오른쪽 아래 β₂ 방)에서 압착기가 뱉은 금빛 고리가 굴러 **가지 친 포도송이**를 들이받아 포도가 떨어진다 — cAMP 가 글리코젠을 헌다.
5. 한 줄 소동: 노 → 물줄기 → 관 / 크랭크 → 진자 → 병 → 웅덩이 / 압착기 → 고리 → 송이 → 구르는 포도 — 매 걸음 물건이 다음 물건에 닿는다.
