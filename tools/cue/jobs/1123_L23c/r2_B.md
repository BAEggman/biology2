### 〈L23c · s1 (낭독 s1 · 그림 s3 방) · 노르에피네프린〉 — 안 1
- 길: 그림 (있는 소품을 알아보게 키움)
- 물건: 노르웨이 국기 — 바닥에 굴러 있는 빨간 확성기 손잡이에 끈으로 매단 작은 손깃발(빨강 바탕 · 흰 테 두른 파란 십자)
- 사건: 빨간 운동복 손님(노르웨이 선수)이 제 응원 확성기를 입에 대고 표적에게 바로 외치던 참인데, 왼쪽 아래 방에서는 손으로 제 입을 막고 노르웨이 깃발 달린 확성기를 떨궜다.
- 고리: ① 「노르에피네프린의 노르는 노르웨이의 노르처럼 들린다.」 빨간 운동복 = 노르웨이 대표팀 빛깔이라 손님(정본 NE)과 저절로 한 몸이 된다. 확성기 = 입에서 앞사람에게 직접 대고 내보내는 도구(문 · 구멍이 아니라 내보냄의 연장).
- 낭독에 넣을 한 문장: 확성기의 노르웨이 깃발 — 손님이 내뿜는 건 노르에피네프린이다. (36자)
- 자리와 크기: 지금 확성기 = x 435–535, y 688–762 (100×74 → 2048 에서 146×108). 깃발은 손잡이(x≈455–475, y≈735)에서 짧은 막대로 오른쪽 위 빈 벽 x 470–575, y 600–676 에 편다 = 105×76 → 2048 에서 154×111 (짧은 변 111 ≥ 110 ✓) · 780 px 에서 58×42. 이 칸(x 440–690, y 400–685)은 손님 오른쪽의 빈 뒷벽이라 겹치는 소품 없음(손님 다리 x 330–420 · 알 선반 x 95–245 와 떨어짐). 확성기 자체도 짧은 변 74 → 2048 에서 108 이라 키울 때 ×1.05 쯤 키워 110 을 넘긴다.
- 그림에서 바뀌는 것 / 그대로: 깃발 하나(구역 편집 1회, 확성기 둘레) / 손님 · 입 막은 손 · 압착기 · 알 둘 · 드럼통 · 확성기의 꼴과 방향은 그대로.
- 예약 확인: `reserved.py 노르웨이` 임자 없음 · `국기` 임자 없음 · `노르딕` 임자 없음 · `메가폰` 임자 없음 · `확성기` — 인터페론(L13b 이웃 집 확성기 · 인터폰과 함께 쓰는 사슬)에 걸림 → 그쪽은 「집 · 전선 · 인터폰 · 판자 창」이 함께인 사슬이라 이 방의 맨 확성기와 갈린다. 다만 확성기는 이미 이 그림에서 「전달물질 분비」를 나르므로 깃발은 그 분비되는 것의 이름만 보탠다(뜻 둘이 아니라 한 뜻의 이름표). `깃발` — IgG 연대 깃발 · 노란 깃발(플라비) · 황토빛 깃발(항체) · 응원단(폼폼만) 예약 있음 → 빛깔(빨강 + 흰 테 파란 십자)과 놓인 곳(확성기 손잡이)으로 가른다. 노란색 쓰지 말 것.
- 혼동쌍: 드럼통(에피네프린 = 혈액) ↔ 깃발 단 확성기(노르에피네프린 = 신경 끝이 직접) — 통은 터져 흩어지는 것, 확성기는 한 사람이 앞으로 겨누는 것으로 갈린다. 덴마크 국기(빨강 + 흰 십자)와 헷갈리면 이름을 못 부르므로 파란 십자 · 흰 테를 굵게.
- 붐빔: +1 (작은 깃발). 이미 있는 확성기에 얹음.
- 오독 위험과 약점: ① 노르웨이 국기를 780 px 에서 「북유럽 국기 / 덴마크 / 아이슬란드」로 부를 수 있다 — 「북유럽 = 노르딕」으로도 노르가 살아남지만 덴마크로 부르면 끊긴다. ② 확성기가 떨어져 있는 α₂ 방이라 s1 에서 「NE 분비 = 줄어든 장면」만 보인다 — 낭독이 「다른 방에선 늘 외친다」를 받쳐야 한다. ③ 노래 · 가수로 읽히지 않게 음표 금지(노래하는 사람은 오페론 예약).

- 혼동쌍: 드럼통(에피) ↔ 손님(노르에피) — 통 · 사람으로 갈림.

- 오독 위험과 약점: 그림에 노르웨이를 알리는 것이 없어 글을 안 받은 독자는 여전히 못 꺼낸다(지난 N 의 까닭 그대로). 안 1 의 깃발이 그림 쪽 받침이 되면 이 문장이 비로소 산다. 「직접 내보냄」은 손님이 표적에 손을 대는 것으로만 보여 약하다.

### 〈L23c · s1 · 아세틸콜린 · ACh (한 물건)〉 — 안 1
- 길: 그림 (작은 새 소품 하나)
- 물건: 스탠드 에어컨(키 큰 흰 세로 몸통 · 앞면 가로 바람살 · 푸르스름한 찬바람 줄 셋)
- 사건: 오른쪽 위 심장 방 구석의 에어컨이 땀 흘리며 크랭크를 돌리는 손님과 괘종시계 쪽으로 찬바람을 불어 「식혀라, 늦춰라」 한다 — 손님이 아직 이기고 있다(진자는 빠르다).
- 고리: ③ + ① 「ACh 의 A·C 는 에어컨(A/C — 자동차 단추에 찍힌 그 A/C)이다 · 에이씨 = 에어(컨)처럼 들린다.」 식히면 심박이 내려간다(덱: 체온 1 ℃ → 심박 약 10회 ↑ 의 거꾸로) = 부교감 ACh 가 M₂ 로 심박을 늦춤 — 표적이 부교감도 받는다는 사실을 그대로 그린다.
- 낭독에 넣을 한 문장: 구석 에어컨(A/C)은 아세틸콜린, 심장을 식혀 늦춘다. (29자)
- 자리와 크기: 심장 방 오른쪽 옆벽 띠 x 1310–1388, y 150–370 (78×220 → 2048 에서 114×322, 짧은 변 114 ≥ 110 ✓ · 780 px 에서 43×123). 손님 뒷발(x≈1255–1300, y 345–375) · 땀방울(x 1270–1310, y 70–110)보다 오른쪽 · 아래. 찬바람 줄은 손님 등 쪽으로 x 1240–1310, y 160–220 에 짧게(손님 몸을 가리지 않게 등 뒤로만).
- 그림에서 바뀌는 것 / 그대로: 에어컨 하나 + 바람 줄(구역 편집 1회, 오른쪽 띠) / 괘종시계 · 진자 · 크랭크 · 압착기 · 금빛 고리 · 베 하나 그대로.
- 예약 확인: `에어컨` 임자 없음 · `찬바람` 임자 없음 · `리모컨` 임자 없음 · `바람` — 건조 스트레스(마른 바람) · L50b 「열이 드나드는 네 길」의 바람 = 대류에 걸림 → 이쪽은 기계에서 나오는 찬바람이고 다른 과라 겹치지 않으나 L50b 와 「바람 = 열 빼앗기」 결이 같아 거스르지 않음. `ACh` — nAChR = 열린 담뱃갑 · mAChR = 흰 점 빨간 버섯(L23b s23p02 바닥) → 에어컨은 수용체가 아니라 전달물질 이름이라 겹치지 않음. `열쇠` — L23b 「열쇠구멍에 꽂혀 돌아가는 놋쇠 열쇠 = 수용체에 붙는 리간드(ACh)」.
- L23b 놋쇠 열쇠와의 짜임: 열쇠 = 「ACh 분자가 수용체에 꽂힌다」(붙는 꼴) · 에어컨 = 「ACh 라는 이름 + 부교감이 심장을 늦춘다」(이름표). 에어컨은 아무 구멍에도 꽂히지 않고 손에 들리지도 않는다 → 둘째 리간드 기호가 아니다. L23b 낭독에 「그 놋쇠 열쇠의 이름은 A/C — 에어컨」 한 문장을 보태면 두 물건이 한 이름을 나눠 갖는 대신 열쇠 = 결합, 에어컨 = 이름으로 일을 가른다.
- 혼동쌍: 크랭크 돌리는 손님(NE · β₁ · 빠르게) ↔ 찬바람 에어컨(ACh · M₂ · 늦게) — 사람과 기계, 빨강과 하양 · 파랑으로 갈림. 진자를 세우는 손가락 둘(L23b M₂)과도 손이 없어 안 겹침.
- 붐빔: +1 (에어컨 · 바람 줄은 그 몸에 딸림). 심장 방에서 손이 닿지 않는 마지막 빈 띠를 쓴다.
- 오독 위험과 약점: ① 아세틸콜린(전체 이름)과는 첫 음절이 겹치지 않는다(아 ≠ 에) — ACh 글자로만 이어지므로 「ACh → 아세틸콜린」 한 걸음을 학습자가 해야 한다. ② 심장 방에 늦추는 힘이 함께 있어 s4 「β₁ = 빠르게」가 흐려질 수 있다 — 진자의 빠름 줄은 그대로 두고 바람은 손님 등에만 닿게(진자에는 안 닿게). ③ 「에어컨 = 냉방 = 땀 = 체온조절」로 새면 L50b 쪽으로 끌린다.

### 〈L23c · s1 · 아세틸콜린 · ACh〉 — 안 2
- 길: 그림 (작은 새 소품 하나)
- 물건: 아세톤 병 + 빨갛게 물든 솜(매니큐어 지우는 그것)
- 사건: 심장 방 오른쪽 띠의 낮은 받침 위에서 아세톤 솜이 손님 운동복 소매 끝에 묻은 빨간 칠을 지워 하얗게 만든다 — 빨강(교감)을 거두는 쪽.
- 고리: ① 「아세틸콜린은 아세톤처럼 들린다(아세-).」 아세톤 = 빨간 매니큐어 지우개 = 교감의 빨강을 거둠 = 부교감의 맞섬.
- 낭독에 넣을 한 문장: 빨강을 지우는 아세톤 — 아세틸콜린, 부교감의 맞수다. (28자)
- 자리와 크기: 안 1 과 같은 띠 x 1310–1388, y 260–370 (병 78×110 → 2048 에서 114×161 ✓). 솜은 병 곁 손님 소매 끝(x≈1290–1310, y≈200) 쪽.
- 그림에서 바뀌는 것 / 그대로: 병 + 솜 / 나머지 그대로.
- 예약 확인: `아세톤` 임자 없음 · `매니큐어` 임자 없음 · `리무버` 임자 없음 · `손톱` 임자 없음 · `솜` — 짚끈 · 구슬 등 다른 뜻에 「솜」 낱말이 섞여 걸렸을 뿐 솜뭉치 예약 없음 · `아세틸콜린` 임자 없음.
- 혼동쌍: 금색 자물쇠(약 · 독) ↔ 병 — 병에는 자물쇠 · 금빛 없이 맑은 액체. 탄산 병(콜라 · 펩시 예약)과 갈리게 거품 · 왕관 마개 없이 펌프 뚜껑의 납작한 화장품 병으로.
- 붐빔: +2 (병 · 솜). 안 1 보다 붐빔.
- 오독 위험과 약점: ① 라벨 없는 병은 780 px 에서 「약병 · 화장품」으로 불릴 수 있다 — 빨간 솜이 있어야 「아세톤」이 나온다. ② 「지운다」가 「분해한다(효소)」로 읽혀 거꾸로 끌 수 있다(ACh 가 NE 를 분해하는 것이 아님). ③ 사람이 없는데 솜이 소매를 닦는 짓이 어색하다 — 사건이 약하다. 그래서 안 1 을 먼저 둔다.

### 〈L23c · s1 · 아세틸콜린 · ACh〉 — (글) 길

### 〈L23c · s4 (그림은 s5 방에) · 글리코젠〉 — 안 1
- 길: 그림 (정본 물건 — 가지 친 포도송이, 새 소리 물건 없음)
- 물건: 붉은 벽돌 곳간(간 정본 · 앞을 터서 안이 보임) 처마에 매단 가지 친 포도송이
- 사건: 오른쪽 아래 β₂ 방의 압착기가 뱉은 금빛 고리 하나가 바닥을 굴러 왼쪽 벽돌 곳간에 닿자, 곳간에 매단 가지 친 포도송이에서 포도가 후두둑 떨어져 바닥을 구른다.
- 고리: ④ 이름 뜻 그대로 — 가지 친 포도송이 = 글리코젠(정본) · 떨어져 구르는 포도 = 포도당 · 벽돌 곳간 = 간(정본). 사슬: 드럼통(에피네프린, 이 방에 이미 있음) → 압착기(Gs · AC) → 금빛 고리(cAMP) → 곳간의 송이가 헐림. 심장 방(위)이 아니라 β₂ 방에 두어 「간 = 글리코젠 분해 / 심장 = 심박」의 갈림을 방 자체로 지킨다(낭독의 「간에서 글리코젠 분해를 촉진하는 β₂」와 맞음).
- 낭독에 넣을 한 문장: 아래 방 벽돌 곳간은 간, 고리 닿은 송이가 헐린다. (27자) — s4 낭독 끝에 「심장은 진자, 간은 아래 방 곳간」으로 이어 부른다.
- 자리와 크기: β₂ 방 왼쪽 옆벽 앞 x 705–805, y 560–745 (100×185 → 2048 에서 146×271). 송이는 곳간 트인 앞에서 75×85 → 2048 에서 110×124 (짧은 변 110 ✓ · 780 px 에서 42×47). 고리가 구르는 길은 압착기 받침 아래 바닥 x 790–875, y 740–775(지금 빈 바닥 — 드럼통 x 875–945 · 뚜껑 x 945–1000 은 오른쪽). 압착기 몸체(x 810–985, y 520–735)의 왼쪽 가장자리와 붙되 겹치지 않게, 베 둘 선반(x 795–975, y 465–530)보다 아래(y 560 부터).
- 그림에서 바뀌는 것 / 그대로: 곳간 + 송이 + 구르는 고리 하나 + 떨어진 포도 두셋(구역 편집 1회, 왼쪽 아래 구석) / 숨관 · 벌리개 · 바람 · 압착기 · 드럼통 · 베 둘 · 손님 그대로.
- 예약 확인: `포도송이` — 가지가 거듭 갈라진 나무에 붙은 포도 = 글리코젠 전용(송이 자체도 맞음) · 동글동글한 포도 = 포도당(떨어져 구르면) · 「포도알」이라 쓰지 말 것(α 알과 충돌) → 낭독에 「포도」만. `벽돌집` — 지붕 · 문이 있는 붉은 벽돌 건물 · 곳간 = 간(담장은 막 · 미토콘드리아 — 담장으로 그리지 말 것). `포도` — 쓰러진 빈 포도 그릇 + 금 고리 = 포도당 낮음 → cAMP 높음(L25a) → 이쪽은 그릇이 아니라 송이 · 곳간이라 갈림. 분홍 풍선 송이(폐포)와는 숨관 바로 곁이라 특히 갈려야 함 → 보라 포도 · 초록 꼭지 · 갈색 잔가지로.
- 혼동쌍: 금빛 고리(cAMP)가 송이에 「닿기」만 — 고리가 송이에 걸려 송이 일부로 보이면 안 된다. 분홍 숨관(기관지) ↔ 보라 송이(글리코젠) — 빛깔로. 위층 심장 방의 압착기 고리와는 방이 달라 「심장에선 고리가 진자로, 간에선 송이로」가 된다.
- 붐빔: +1 덩이(곳간 + 송이 한 묶음). 있는 소품에 얹을 수 없음(정본이 그림에 없음).
- 오독 위험과 약점: ① β₂ 방에 숨관과 간이 함께 있어 「한 방 = 한 조직」 문법이 깨진다 — 「방 = 수용체 β₂, 그 수용체를 가진 두 조직」으로 낭독이 받쳐야 한다. ② 고리 · 송이 사슬이 짧은 거리(80 px)라 780 px 에서 「굴러가 닿음」이 안 보일 수 있다 — 고리를 곳간 문턱에 반쯤 걸치게. ③ 사람 간 β₂ 이외 α₁ 도 관여한다는 세부는 이 판에 넣지 않는다(카드 밖).

## 과 전체
네 칸 방의 빨간 운동복 손님은 노르웨이 대표팀(노르에피네프린)이고, 노르웨이 깃발 단 응원 확성기로 표적에게 바로 외친다 — 왼쪽 아래 α₂ 방에서만 제 입을 막고 그 확성기를 떨궜다.
오른쪽 위 심장 방에서는 손님이 땀 흘리며 진자를 빨리 돌리는데, 구석의 스탠드 에어컨(A/C = ACh · 부교감)이 등에 찬바람을 불어 늦추려 한다 — 심장은 둘 다 받는다.
오른쪽 아래 β₂ 방에서는 압착기가 뱉은 금빛 고리 하나가 바닥을 굴러 붉은 벽돌 곳간(간)에 닿고, 처마의 가지 친 포도송이에서 포도가 후두둑 떨어진다 — 심장은 진자, 간은 송이.
드럼통(에피네프린 · 혈액)은 방마다 그대로 두어, 「신경 끝이 직접 외치는 확성기」와 「피로 퍼지는 터진 통」이 갈린다.
