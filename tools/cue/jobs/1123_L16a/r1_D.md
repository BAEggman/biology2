> 먼저 밝힐 것 다섯 —
> 1. **글 길은 이 그림 안에 알아볼 소품이 없는 낱말이 많다.** 그럴 때는 억지로 지게 · 자판기 · 종 같은 임자 있는 소품에 뜻을 얹지 않고, 덱 정본이 이미 그려 둔 **이웃 그림의 소품을 낭독 한 문장으로 가리키는 길**(L07c · L16b · L16d — 그림은 그대로, 비용 0)을 냈다. 그 이웃 그림에서 독자가 그 소품을 알아봤는지는 **모름**(이 꾸러미에 없다).
> 2. **s7 의 지게(나무 A 자 틀)는 독자가 「사다리」로 읽는다**(표의 독자 답: 사다리 멘 남자 · 나무 의자 진 남자). 덱의 글자사전에서 A 자 접이 사다리 = A(PKA · 사이클린 A · CENP-A · IgA)다. 지금은 지게 = G 가 임자라 PKA 에 못 얹지만, **독자가 PKA 로 읽을 위험**이 있다(아래 PKA 안 · 「과 전체」).
> 3. AC 는 표에서 s2 에 걸렸으나 s2 의 카드 아홉 장에 AC 가 없고, s2 낭독엔 ACh 만 있다(「ACh」의 앞 두 글자가 갈려 걸린 것으로 보이나 **모름**). AC 효소는 s7 의 오른쪽 끝 기계라 안은 s7 기계에 둔다.
> 4. 이웃 정본이 있는 낱말(에피네프린 = 터진 드럼통 · 글리코겐 = 가지 갈라진 포도 · PDE = 가위 · PLC = C 자 크랭크 · PKA = A 자 + 열쇠 · 스테로이드 골격 = 금빛 고리 넷)은 **내 렌즈의 새 안을 내지 않았다.** 한 개념 = 한 기호(P7)를 깨기 때문이다. 대신 내 렌즈에서만 나온 안(갑상선호르몬 · 스테로이드 이름 · ACh · AC)을 냈다.
> 5. 고리 물건 크기 기준(2048 px 에서 짧은 변 110 px)은 full.jpg(1400 px) 로 옮기면 약 **75 px**다. 안마다 이 수에 맞춰 크기를 적었다.

### 〈s1 · 갑상선호르몬〉 — 안 1

- 물건(일상 낱말 하나): 티셔츠
- 사건(누가 무엇에게 무엇을 한다 — 한 문장): 기름을 뒤집어쓴 손님이 반팔 티셔츠 바람으로 서류 캐비닛 서랍을 연다.

- 낭독에 넣을 한 문장(40자 안쪽): 손님의 티셔츠 — 티셔츠의 티가 티록신, 갑상선호르몬이다.
- 자리와 크기(지금 그림의 어디 · 무엇을 대신하거나 무엇 곁에 · 어림 크기): s11 기름 손님의 웃옷(그림 x≈420–600, y≈500–680). 새 물건이 아니라 **지금 입은 긴소매 웃옷을 반팔로 바꾼다**. 몸통이 이미 170 px 라 크기 문제 없음.

- 예약 확인: `티셔츠` → L25 문지기 둘(lac 억제자 = 검은 티셔츠 대머리 · trp 억제자 = 초록 티셔츠 뾰족머리)이 **입은 옷**일 뿐 티셔츠 자체의 임자는 없음 · `셔츠` → 흰 셔츠 + 타이 둘(티로신) · 사이토칼라신 칼라 · `반팔` 임자 없음 · `나비` 파필로마 예약(쓰지 않음) · `갑상선` 부갑상선 버튼 상자 · 나비 판(TSH). 정본: L07c 는 결정 넷 코트 = T₄ · 코트 벗은 망치 인부 = T₃.
- 혼동쌍(무엇과 어떻게 갈리나): ① 티로신(흰 셔츠 + **타이**, s9 · s10) — 둘 다 「티」로 시작하고 둘 다 옷이다. 타이는 목에 매는 것 · 티셔츠는 몸통이고 타이 맨은 안(교환원) · 티셔츠는 밖에서 온 기름 손님이라 자리로도 갈리나 **옷끼리라 약하다**. ② L07c 의 「코트 벗은 인부 = T₃(활성형)」 — 티셔츠를 「코트 벗음」으로 읽으면 T₃ 로 샌다. 이 정거장은 T₃ · T₄ 를 가르지 않고 「갑상선호르몬」 한 덩이만 묻는다.
- 붐빔(새로 느는 물건 수 · 이미 있는 소품에 얹을 수 있는가): 새 물건 0(옷만 바꿈). 단 기름 손님 한 사람에 안 2 스테로이드의 스테이크가 같이 붙으면 「손님이 둘을 든다」가 된다(아래 · 둘 다 지용성 대표라 뜻은 맞다).
- 오독 위험과 스스로 본 약점: (1) 티셔츠가 「티」 소리만 나르고 **갑상선**이라는 이름은 안 나른다(T = thyroid 를 아는 학생에게만 풀림 — 티록신 · T₃ · T₄ 를 이미 아는 학생은 풀린다). (2) 점액에 젖은 옷이라 반팔로 안 읽힐 수 있다 — 흰 옷 + 맨 팔뚝이 보이게. (3) 티록신 · 티로신 · 티아민 · 티아지드(티백)로 **「티」 가족이 넷**이 된다 — 덱이 이미 티로신(타이) · 티아민(혼자 맨 넥타이) · 티아지드(티백)에 쓴 소리라 가장 큰 약점. 심판이 이 소리 붐빔을 크게 보면 버릴 안.

### 〈s2 · ACh〉 — 안 1
- 길(글 / 그림): **그림**(몸짓 하나 — 새 물건 없음)
- 물건(일상 낱말 하나): 쑤시는 어깨(ache)
- 사건(누가 무엇에게 무엇을 한다 — 한 문장): 담배를 투입구에 넣던 손님이 다른 손으로 어깨를 움켜쥐고 얼굴을 찡그린다.
- 고리(종류 ①②③④ + 한 문장): ② 철자 — ACh 는 영어 ache(쑤심 · 근육통)에서 끝의 e 만 뺀 꼴이다(철자 A · C · h 가 그대로 앞에 있다). 이 손님의 담배 = 니코틴이 붙는 수용체가 바로 근육에서 일하는 니코틴성 ACh 수용체라 「근육이 쑤신다」는 뜻이 사실과도 어긋나지 않는다(모름이 아님: 골격근 신경근접합부의 전달물질이 ACh 다).
- 낭독에 넣을 한 문장(40자 안쪽): 쑤신다는 ache 에서 e 를 빼면 ACh — 아세틸콜린이다.
- 자리와 크기: 그림 x≈150–270, y≈100–215의 담배 손님. 비어 있는 왼팔(지금은 벽 위에 올려 둠)을 올려 **오른쪽 어깨를 움켜쥔** 손 + 눈썹 찌푸림. 몸 전체가 이미 120 px 라 크기 문제는 없으나 얼굴 표정이 작아 **780 px 에서 약해진다**.
- 그림에서 바뀌는 것 / 그대로 두는 것: 손님의 왼팔 자세와 표정. / 담배 · 투입구 · 자판기 · 캔 · 연기는 그대로.
- 예약 확인: `근육통` 임자 없음 · `어깨` → 어깨띠(Wee1) · 어깨에 멘 크레인(RdRp) · 키스하는 남자의 어깨(EBV)는 **물건**이고 이 안은 몸짓이라 겹치지 않음 · `파스` → **Fas 전용**이라 근육통 파스를 못 쓴다(그래서 몸짓만) · `ACh` · `니코틴` → 사전: nAChR = 열린 담뱃갑(L23).
- 혼동쌍: ACh ↔ AC(교환대, s7) — 철자 앞 두 글자가 같아 **가장 큰 혼동쌍**. 이 안(자판기 · 쑤시는 어깨)과 AC 안(교환대 · 교류)은 장면이 다르다.

- 낭독에 넣을 한 문장(40자 안쪽): 글리코겐은 다음 그림에서 가지 갈라진 포도송이다.
- 자리와 크기: 그림 그대로.
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부.
- 예약 확인: `포도` → 글리코젠 전용(가지에 붙은 것) · 포도당(떨어져 구르는 것) · 곤봉(글루카곤) · `글리코` 같은 예약 · `새총` 임자 없음.
- 혼동쌍: 글리코겐(가지에 붙은 포도) ↔ 포도당(떨어져 구르는 낱알) — 붙었느냐 떨어졌느냐.
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: 이 그림만 본 독자에게는 소품이 없다. L16b 의 송이를 알아봤는지 모름. ⚠ 낭독에 「포도알」이라는 낱말을 쓰지 말 것(α 의 「알」과 부딪침).

### 〈s7 · 글리코겐〉 — 안 2
- 길(글 / 그림): **그림** — **안 없음(권하지 않음)**
- 까닭: 내 렌즈에서 나온 새 안(glyco- = 단 · -gen = 낳는 → 꿀단지 · 발전기 · Y 자 갈래)은 모두 **포도 정본과 같은 개념에 둘째 기호**를 세운다(P7). 게다가 노란 점액 손님을 독자 셋이 「꿀」로 읽어 꿀단지는 점액과 샌다. 정본을 s7 에 옮기려면 기계 위에 포도송이 하나를 얹는 방법(새 물건 1 · 폭 80 px)이 있으나 s7 이 AC · G 단백질 이야기라 장면에서 겉돈다.

### 〈s7 · PLC〉 — 안 1
- 길(글 / 그림): **글**(이웃 그림 가리킴)
- 물건(일상 낱말 하나): 옆구리에 큰 C 자 크랭크가 달린, 피자를 삼키는 기계(L16b s16p02b)
- 사건(누가 무엇에게 무엇을 한다 — 한 문장): (L16b 에서) 기계가 피자(PIP₂ = 인지질)를 통째로 삼킨다.
- 고리(종류 ①②③④ + 한 문장): ②(정본) — 큰 C 자 크랭크의 C 가 PLC 의 C · PL = 인지질을 자르는 기계.
- 낭독에 넣을 한 문장(40자 안쪽): PLC 는 피자를 삼키는, C 자 크랭크 달린 기계다.
- 자리와 크기: 그림 그대로.
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부.
- 예약 확인: `C자` → PKC = C 자 굽은 열쇠(L16b#10) · PLC = C 자 · 크랭크가 큰 C 자 ② · `크랭크` → Na⁺-K⁺ 펌프(동전 투입구) · lac 인쇄 기계 등 **갈리는 물건**.
- 혼동쌍: PLC(C 자 크랭크 기계) ↔ AC(이 그림의 교환대) — 둘 다 「기계」라 샐 수 있다. 크랭크 · 피자가 갈림.
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: 위 PKA 안 1 과 같다. ⚠ s7 의 기계는 수화기 두 개가 달린 **C 자 꼴 손잡이**가 있어 C 자로 읽힐 수 있다 — **PLC 와 AC 가 같은 기계 위에서 부딪칠 수 있다.** 안 1 의 AC(교환대 전체 = 교류)와 PLC(수화기 C)를 **같이 쓰지 않는다.**

### 〈s7 · PLC〉 — 안 2
- 길(글 / 그림): **그림** — **안 없음**
- 까닭: 내 렌즈(PL + C · 글자 모양 C)의 새 물건은 결국 C 자 손잡이 달린 기계 하나이고, 이미 정본이 있다. 둘째 기계를 새로 들이면 s7 오른쪽 구석이 AC · 지게꾼 · 칩으로 이미 차 있어 붐빈다(새 물건 둘 이상).

### 〈s7 · PDE〉 — 안 1
- 길(글 / 그림): **글**(이웃 그림 가리킴)
- 물건(일상 낱말 하나): 회색 고리를 자르는 가위(L16b#5 · L15a#8)
- 사건(누가 무엇에게 무엇을 한다 — 한 문장): (L16b 에서) 가위가 회색 고리를 잘라 끊는다.
- 고리(종류 ①②③④ + 한 문장): ③(정본) — 가위는 자르는 동작이고 이름은 자르는 대상(고리)이 나른다. 고리를 자르는 것 = cAMP 를 분해하는 PDE.
- 낭독에 넣을 한 문장(40자 안쪽): PDE 는 다음 그림에서 회색 고리를 자르는 가위다.
- 자리와 크기: 그림 그대로.
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부.
- 예약 확인: `가위` → 절단 일반 · PDE(회색 고리) · 제한효소(빨간 조끼 경비) · Cas9(전지가위) · 탈카복실 등 **자르는 대상으로 가름** · `펜치` → 사전 PDE 안(고리를 펴는 s16p02).
- 혼동쌍: PDE(회색 고리를 자르는 가위) ↔ 제한효소(경비의 가위) · Cas9(전지가위) — 대상이 가름.
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: 이 그림만 본 독자에게는 소품이 없다. ⚠ 정본은 **회색 고리**를 자른다 — 이 그림의 지게꾼 칩이 짙은 회색 네모(GTP)라 「회색」이 겹칠 수 있다(고리와 네모로 갈리나 색은 같다).

### 〈s7 · PDE〉 — 안 2
- 길(글 / 그림): **그림** — **안 없음**
- 까닭: 내 렌즈(PD + E · 디에스터)의 후보는 이스터 달걀(알 = α 예약과 부딪침) · 프로듀서(헤드셋 · 클립보드에 글자 필요)뿐이고 둘 다 버렸다. 정본(가위 + 회색 고리 = 새 물건 둘)을 s7 에 들이는 것은 붐빔이라 권하지 않는다.

## 과 전체

1. 밖에서 온 기름 손님이 흰 티셔츠 바람으로 발치에 스테이크 접시를 두고(스테이크 = 스테로이드, 티셔츠 = 티록신) 서류 캐비닛 서랍을 연다 — 이 장면에서 지용성 호르몬 둘(스테로이드 · 갑상선호르몬)이 한 사람의 몸에 실린다.
2. 담배 손님은 한 손으로 어깨를 움켜쥔 채(ache → ACh) 투입구에 담배를 넣는다 — 이 안은 약해서, 안 되면 s2 는 「ACh 는 소리 고리 없음」으로 남긴다.
3. 뱀 창구 위 바깥에는 터진 드럼통이 하나 더 서서(에피네프린) 등불 · 향수와 함께 줄을 선다.
4. 안에서는 지게꾼이 교류로 도는 교환대 기계로 달려가고(AC), 발치에는 머리가 A 자인 열쇠가 놓인다(PKA — 단, 지게의 A 자 꼴과 겹치니 지게를 지게답게 고칠 것).
5. PLC · PDE · 글리코겐은 이 그림에 새 물건을 들이지 않고 L16b 의 정본(C 자 크랭크 기계 · 가위와 회색 고리 · 포도송이)을 낭독 한 문장으로 가리킨다 — 안 1 둘을 쓴다면 s7 오른쪽 구석에 새 물건은 열쇠 하나뿐이다.

내가 고르는 순서: 에피네프린 안 1(값싼 고침) > AC 안 1 > 스테로이드 안 1 > 갑상선호르몬 안 1 · PKA 안 1 > 나머지. ACh 는 내 안이 약하니 다른 제안자의 안을 먼저 볼 것을 권한다.
