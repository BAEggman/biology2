- 고리(① + ④ — 「아데닐산은 아대처럼 들린다」(아데 = 아대 · 요즘 말에서 소리가 같다) · 아대가 둥근 고리라 「고리화」 효소의 고리 뜻까지 그대로):

- 오독 위험과 스스로 본 약점: 「인지」 ≈ 「인절」 은 둘째 음절이 다르다. 「C」는 못 나른다. 시험 카드가 「PLC」 글자로 묻기 때문에 인절미 → 인지질분해효소 → PLC 로 한 번 더 옮겨야 한다. 음식이 또 는다.

### 〈s7 · PLC〉 — 안 2
- 길(글): 이미 그려진 소품에 이름만 잇기
- 물건: 기계 옆 수화기에서 늘어진 꼬불 줄 — 「C」자로 휜 부분
- 사건: 지게꾼이 달려가는 기계의 수화기 줄이 큰 C 자로 휘어 있다.
- 고리(② — 「PLC 의 C 는 C 자로 휜 줄처럼 생겼다」 · 사전 C자 그대로): 
- 낭독에 넣을 한 문장: C 자로 휜 수화기 줄, 피엘시다.
- 자리와 크기: s7 기계 수화기 그대로.
- 그림에서 바뀌는 것 / 그대로 두는 것: 그림 그대로.
- 예약 확인: `reserved.py 수화기` → 【나무 전화기 = 콜히친】 · 【회색 인터폰(수화기 · 꼬불 줄) = 인터페론】 — ⚠ 꼬불 줄 달린 수화기가 인터페론 예약이다.
- 혼동쌍: 인터페론 인터폰과 정면 충돌. PKC(C자 열쇠)와도 C 가 겹친다.
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: 예약 충돌 + 기계(AC)에 뜻을 하나 더 얹음 — 쓰지 않기를 권한다. 내 렌즈(우리말 소리)로는 글 길 안이 나오지 않았다.

### 〈s7 · PDE(포스포다이에스터레이스)〉 — 안 1
- 길(그림): 작은 새 소품 하나(작은 인물)
- 물건: 피디(방송 PD — 야구모자 · 손에 흑백 줄무늬 슬레이트)
- 사건: 기계 곁에 선 피디가 슬레이트를 「딱」 쳐서 한 장면을 끝낸다 — 켜진 신호를 끊는다.
- 고리(③ + ① — 「PDE 는 피디(PD)처럼 들린다」 · 우리말에서 흔한 「피디」가 앞 두 글자를 그대로 읽힌다. 「컷!」으로 끝내는 이 = cAMP 를 깨서 신호를 끝내는 효소): 
- 낭독에 넣을 한 문장: 슬레이트 쳐 끝내는 피디, PDE 다.
- 자리와 크기: s7 기계 왼쪽 앞 · 인물 반신 + 슬레이트 약 120×110 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 작은 인물 하나. 지게꾼 · 칩 · 기계 그대로.
- 예약 확인: `reserved.py 피디` → (임자 없음). `reserved.py 슬레이트` → 슬레이트 예약 없음(붉은 벽돌 건물 줄은 무관). `reserved.py 메가폰` → (임자 없음) · `reserved.py 확성기` → 인터페론 예약이라 확성기는 들리지 않는다. `reserved.py PDE` → [고리] 펜치 · 관을 끊는 가위(③) · 【가위 — 회색 고리를 자르는 가위 = PDE】.
- 혼동쌍: 사전의 가위(PDE)와 같은 뜻의 다른 손잡이 — 두 손잡이가 생긴다. 「끝내는 사람」은 s8 주저앉은 지게꾼(스스로 꺼짐 · GTP 가수분해)과 뜻이 비슷해 「신호 종료」가 둘로 보일 수 있다 — 피디는 지게꾼이 아니라 기계(AC 산물) 쪽을 끊는다.
- 붐빔: +1 인물(크다).
- 오독 위험과 스스로 본 약점: 슬레이트는 「판」이라 그림 조건(판 · 글자 없음)에 걸릴 수 있다 — 글자 없는 흑백 사선 줄무늬만. 독자가 「감독」이라 부르면 「피디」가 안 나온다. 사실 쪽: 「Gt 는 PDE 를 켠다」(시각)와 「PDE 가 cAMP 를 끊는다」 둘 다 끊는 쪽이라 반대로 끌지는 않는다.

## 과 전체
전화 교환국 오른쪽 끝: 지게꾼이 칩을 뒤집으며 아대 낀 기계로 달려가고, 기계 곁 피디가 슬레이트를 쳐 「컷」을 외치며, 바닥에서는 교환원이 인절미를 둘로 끊는다.
왼쪽 벽에선 담배 꽂는 아저씨(아세틸콜린) 옆으로 캔이 쏟아지고, 뱀 창구 셋째 칸에는 에이프런 요리사가 몸을 내민다.
뒷방에서는 스테이크를 든 기름 손님이 벽을 미끄러져 들어와 서랍을 열자 서랍 속 갑티슈가 보인다(스테로이드는 손 = 세포질, 갑상선은 서랍 = 핵).
종이 울리면 글라이더에 매단 포도송이가 홀 위로 후두둑 쏟아진다(글리코겐 분해).
약점 정리: 에피네프린 · 글리코겐 · PLC · PDE 의 글 길은 이 그림에 빈 소품이 없어 정직하게 「없음」에 가깝다. 붐빔이 6 이상 늘므로 고를 때 스테이크 · 갑티슈 · 아대 · 피디 넷을 먼저 권한다.
