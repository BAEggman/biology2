> 읽은 것: packet.md · img/full.jpg · s2 · s4 · s7 · s9 · s11. 저장소 파일은 건드리지 않았다. 아래 「예약 확인」은 `python3 tools/cue/reserved.py 낱말` 로 직접 찾은 결과다.

## 0. 렌즈 메모 — 먼저 적는 혼동쌍과 막아야 할 소리 친구

| 쌍(시험이 바꿔 내는 것) | 한 가지 차이 | 막을 소리 친구 · 충돌 |
|---|---|---|
| 스테로이드호르몬 ↔ 갑상선호르몬 (A1-47 · B0-190 · 지용성 쌍둥이) | 같은 기름 손님 · 같은 벽 통과 — 든 물건 하나(스테이크 ↔ 갑옷)만 다르게 | 스테이크 → 고기 → 단백질 → 펩타이드(수용성)로 끄는 소리. 비계 기름을 크게 그려 막는다 |
| 갑상선호르몬 ↔ 부갑상선호르몬 (G0-136 · G0-137) | 갑옷 / 나비 ↔ 2×2 버튼 넷 상자(예약) | 「부」를 빼고 읽는 실수 |
| 에피네프린 ↔ 스테로이드 (G0-120 ↔ G0-121 · 수용성 ↔ 지용성) | 같은 「통」 모양 손님인데 통 속이 맑은 물 보라냐 기름이냐 | 드럼통 = 기름통 → 지용성으로 끌 위험(4절에서 막는다) |
| ACh ↔ 에피네프린 (S-SG-1) | 창구가 자판기(이온통로)냐 뱀 창구(GPCR)냐 | 손님이 다 「밖에서 온 것」이라 섞임 |
| ACh ↔ AC ↔ ACE · ACTH | 글자 둘이 같고 ACh 는 h 하나 더 | 에이스 카드 = DnaA · ACE(예약) / 층층 케이크 = ACTH · 부신피질(예약) — 둘 다 쓰지 않는다 |
| AC ↔ PLC ↔ PDE ↔ PKA (S-SG-8 한 카드가 Gs=AC · Gi=AC 억제 · Gq=PLC · Gt=PDE 를 한꺼번에 바꿔 냄) | AC 는 고리를 만들고 PDE 는 자르고 PKA 는 고리를 받는다 | 피엘씨 ↔ 피케이씨(PKC)가 거의 같은 소리 · 사다리 = A(글자사전)가 이 그림의 지게와 충돌(아래) |
| 글리코겐 ↔ 글루카곤 ↔ 포도당 | 포도가 가지에 붙었나(글리코겐) / 떨어졌나(포도당) / 곤봉(글루카곤) | 글리코(상표) · 글루건 — 쓰지 않는다 |

**이 그림에서 새로 찾은 위험(과 전체에 걸린 것)**
1. **지게꾼의 사다리 = 글자 A.** 글자사전에서 A자 접이 사다리는 PKA · IgA · CENP-A · 사이클린 A 의 소품이고, 독자도 s7 에서 「사다리 멘 남자」라 불렀다. 이 그림에서는 지게 = G 를 나른다. 그래서 PKA 에 사다리를 쓰면 안 되고, AC · PKA · ACh 에 「A」 소리가 새어 들 수 있다. 사다리를 지게(G)로 읽히게 할 지게끈 · 등짐 모양을 더 키우는 것도 따로 따져 볼 만하다.
2. **s2 의 AC 걸림은 가짜일 가능성이 크다.** s2 카드는 B0-70 하나(Na⁺ · Ca²⁺)뿐이다. AC 의 진짜 카드는 S-SG-8(Gs=AC 활성 / Gi=AC 억제 / Gq=PLC / Gt=PDE)과 G0-134(ATP를 써서 cAMP 를 만드는 효소 = 아데닐산 고리화효소)로 s7 쪽이다. 그래서 AC 는 낱말은 s2 표에 있지만 자리는 s7 기계로 잡았다.
3. **s7 의 기계는 독자가 「컴퓨터」라고도 부른다.** 컴퓨터 = PC(플라스토시아닌, L45c) 예약이다. 기계를 AC 로 부르는 글에서 「컴퓨터」라는 말은 쓰지 않는다.
4. **콜 = 전화기 = 콜히친(예약).** 교환국이라 전화 말이 쉽게 나오지만 「콜린 = 콜」 소리는 쓰면 안 된다.
5. **타이 = 티로신 · 티아민(예약).** 티록신(갑상선호르몬)에 「타이」를 쓰면 s9 · s10 의 넥타이 맨과 섞인다. 나비넥타이도 쓰지 않는다.
6. **포도 낱알은 「알」(α) 소리가 새어 든다.** 글에서 「포도알」이라 쓰지 않는다(reserved.py 포도의 경고).
7. **「크랭크」는 Na⁺-K⁺ 펌프(예약)가 쓴다.** PLC 의 C자 크랭크는 반드시 C자 모양이 읽혀야 한다.

## 1. 갑상선호르몬 (정거장 s1 낱말 · 거는 자리는 s11)

### 〈s1 · 갑상선호르몬〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 갑옷
- 사건: 지금 뒤에 번진 노란 유령 실루엣을 둘째 기름 손님으로 또렷이 그리고, 그가 목에 쇠 갑옷 목받이를 두른 채 앞 손님 뒤에서 벽을 미끄러져 서류 캐비닛 쪽으로 들어온다.
- 고리(④): 갑상선(甲狀腺)은 「갑옷(甲) 꼴 샘」이라는 이름 뜻 그대로다 — 갑상선호르몬은 갑옷 입은 손님이다. 갑옷의 「갑」은 갑상선의 「갑」과 같은 한자다.
- 낭독에 넣을 한 문장: 뒤 손님의 쇠 갑옷은 갑상선, 갑옷 꼴 샘이라는 뜻이다.
- 자리와 크기: s11 앞 손님 바로 뒤(원본 1400 px 에서 x 440–620 · y 410–520 쯤)의 노란 실루엣 자리를 사람으로 고쳐 그린다. 갑옷 목받이는 목 둘레만이 아니라 가슴까지 덮는 크기(2048 px 기준 짧은 변 110 px 이상)로 둔다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 실루엣이 둘째 기름 손님(기름 범벅 · 같은 노란색)이 된다. 그대로 = 앞 손님 · 캐비닛 · 서랍 · 기름 · 종 · 웅덩이.
- 예약 확인: `reserved.py 갑옷` → 곤충 판(L04d)의 「애벌레 갑옷」 · 절지 갑옷 가게(키틴) 언급만 있고 갑옷 소품 단독 예약은 없다(L16a 는 다른 세계). `reserved.py 갑상선` → 부갑상선 = 2×2 정사각 버튼 넷 상자 전용 · 나비는 파필로마 예약이되 「납작한 나비 모양 판 = 갑상선」은 예외. `reserved.py 목도리` → 갑상샘기능저하(L07f) 전용이라 목도리는 쓰지 않는다. `reserved.py 방패` → NADPH 전용이라 방패는 쓰지 않는다(갑옷이지 방패가 아니게).
- 혼동쌍: 스테로이드호르몬(앞 손님의 스테이크)과는 같은 기름 · 같은 벽 통과인데 든/입은 것 하나로 갈린다. 부갑상선호르몬(버튼 넷 상자)과는 갑옷이냐 버튼이냐로 갈린다.
- 붐빔(새로 느는 물건 수 · 얹을 수 있는가): 새 소품 1(갑옷) + 실루엣 재작화 1. 기존 소품에 뜻을 얹지 않는다.
- 오독 위험과 스스로 본 약점: 갑옷 = 방어 → 코르티솔(스트레스 · 스테로이드)로 끌 수 있다. 곤충 판의 갑옷(키틴)으로 오독할 수도 있다. 한자(甲)를 아는 학습자에게만 곧바로 풀린다(한의학 공부자에겐 맞지만 일반 학습자에겐 약함). 이름 뜻은 맞지만 「호르몬」 쪽에는 고리가 없다.

### 〈s1 · 갑상선호르몬〉 — 안 2
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 나비 접시
- 사건: 안 1 의 둘째 기름 손님이 갑옷 대신(또는 갑옷 곁) 납작한 나비 꼴 접시를 받쳐 들고 캐비닛 쪽으로 내민다.
- 고리(②): 갑상선은 나비 꼴 샘이다 — 덱의 약속 「나비 모양 판 = 갑상선」(L07b#2 · L07e#2 · L07f)을 같은 뜻으로 다시 쓴다.
- 낭독에 넣을 한 문장: 뒤 손님이 든 나비 접시는 갑상선, 나비 꼴 샘이다.
- 자리와 크기: 안 1 과 같은 둘째 손님의 손(쟁반 폭은 손바닥 두 개, 2048 px 기준 짧은 변 110 px 이상).
- 그림에서 바뀌는 것 / 그대로 두는 것: 안 1 과 같다.
- 예약 확인: `reserved.py 나비` → 「납작하게 펼친 나비 모양 판 = 갑상선」은 예외로 허용(산 나비는 파필로마 전용이라 금지). `reserved.py 쟁반` → 모듈 쟁반(칼모듈린) · 구슬 쟁반(아미노산)이 따로 있으니 구슬을 담지 않는다. `reserved.py 접시` → 우유 접시(lacZ)와 겹치지 않게 나비 날개 꼴로 그린다.
- 혼동쌍: 부갑상선(네모 버튼 넷)과 나비 꼴 대 네모 꼴. 스테로이드 손님과 접시 대 스테이크.
- 붐빔: 새 소품 1. 안 1 과 둘 다 넣을 필요는 없다(하나만).
- 오독 위험과 스스로 본 약점: 나비가 「판」(간판)으로 읽히면 그림 조건 위반 — 입체 접시로 그린다. 나비가 이름 소리와 무관해 (다른 과의 약속을 봐야 아는) 약한 고리이고 L07 을 거치지 않은 독자에겐 안 풀린다. **글 길은 낼 수 없다**: s11 의 그려진 소품(기름 · 캐비닛 · 서랍 · 종)에 갑상선 소리나 꼴이 걸리는 것이 없어 억지가 된다(모름).

## 2. 스테로이드호르몬 (정거장 s1) · 스테로이드 (정거장 s11) — 같은 소품을 쓰고 s1 낭독에서 예고한다

### 〈s11 · 스테로이드〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 스테이크
- 사건: 기름 범벅 손님이 비계 두른 스테이크(뼈 붙은 고깃덩이)를 한 손에 쥔 채 벽을 미끄러져 들어오고, 거기서 기름이 뚝뚝 떨어져 온몸이 번들거린다.
- 고리(①): 스테로이드는 스테이크처럼 들린다(스테 · 두 음절이 먼저 겹친다). 스테이크 비계 = 콜레스테롤이고 스테로이드는 콜레스테롤에서 만든다는 사실과도 거스르지 않는다.
- 낭독에 넣을 한 문장: 기름 뚝뚝 스테이크를 쥔 손님, 스테이크는 스테로이드다.
- 자리와 크기: s11 앞 손님의 늘어진 쪽 손(왼쪽 아래 노란 웅덩이 위). 스테이크는 손바닥 두 배 폭(2048 px 기준 짧은 변 110 px 이상)이고 비계 테가 번들거려야 한다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 쥔 손에 스테이크 하나. 그대로 = 기름 · 캐비닛 · 서랍 · 종 · 둘째 손님.
- 예약 확인: `reserved.py 스테이크` → 임자 없음. `reserved.py 고기` → 호랑이의 티본 고깃덩이(L51 육식) · 레디의 고기 단지(자연발생설) 가 있으니 티본이 아닌 비계 두른 등심 꼴로 그린다. `reserved.py 포크` → 네 갈퀴 포크 = 포르밀 전용이라 포크를 쓰지 않고 손으로 쥔다. `reserved.py 기름` → 「노란 기름방울 = 지방 · 지용성」(같은 방향이라 충돌 없음). `reserved.py 스테로이드` → 금빛 고리 넷 덩이(골격)가 L16d · L53 에 있으니 이 그림에서는 고리 넷을 그리지 않는다.
- 혼동쌍: 갑상선호르몬(갑옷 손님)과 한 가지(손에 든 물건)만 다르다. 에피네프린(맑은 물 보라)과 기름 대 물로 갈린다.
- 붐빔: 새 소품 1. 기름 소품에 새 뜻을 얹지 않는다(기름 = 지용성 그대로 두고 스테이크가 이름을 진다).
- 오독 위험과 스스로 본 약점: 스테이크 → 고기 → 단백질 → 수용성 펩타이드 호르몬으로 끌 수 있다(틀린 소리 친구). 비계 기름이 번들거리게 크게 그려야 막힌다. 호랑이 티본(L51 육식)으로 오독할 수 있다. 「스테이크 = 스테로이드」는 소리가 앞 두 음절만 겹쳐 라이터 = 라이게이스만큼 선명하지는 않다.

### 〈s11 · 스테로이드〉 — 안 2
- 길(글 / 그림): 글
- 물건(일상 낱말 하나): 기름(앞 손님이 뒤집어쓴 노란 점액)
- 사건: 앞 손님은 스테이크 기름을 뒤집어쓰고 벽을 미끄러져 들어온다 — 독자가 이미 알아본 「기름」에 스테이크 소리를 잇는다.
- 고리(①): 스테로이드는 스테이크처럼 들린다 — 그림은 그대로 두고 글만 보탠다.
- 낭독에 넣을 한 문장: 손님을 덮은 기름은 스테이크 기름, 스테이크는 스테로이드다.
- 자리와 크기: 앞 손님의 온몸 노란 점액(이미 크게 그려져 있다).
- 그림에서 바뀌는 것 / 그대로 두는 것: 그림은 하나도 바뀌지 않는다.
- 예약 확인: 안 1 과 같다.
- 혼동쌍: 뒤 손님(갑상선)도 같은 기름이라 둘이 같은 이름으로 읽힌다 — 그래서 이 안은 앞 손님만 가리키게 한 문장으로 못 박아야 한다.
- 붐빔: 새 물건 0. 다만 기름은 이미 「지용성」을 나르므로 같은 소품에 뜻이 하나 더 얹히는 경계다(지용성 ⊃ 스테로이드라 방향은 같다).
- 오독 위험과 스스로 본 약점: 독자는 이 점액을 꿀 · 기름 · 치즈로 불렀다 — 스테이크 기름으로는 읽히지 않는다(그림에 고기가 없으므로 글만 믿어야 한다). 안 1 보다 약하다.

### 〈s1 · 스테로이드호르몬〉 — 안 1
- 길(글 / 그림): 글(s11 의 스테로이드 안 1 · 2 와 같은 소품을 s1 낭독에서 예고)
- 물건(일상 낱말 하나): 스테이크
- 사건: s1 의 전경 낭독 끝(「후자의 대표는 스테로이드 호르몬과 갑상선 호르몬이다」)에서 기름 손님 앞은 스테이크, 뒤는 갑옷이라고 미리 부른다.
- 고리(①): 스테로이드호르몬은 스테이크 손님처럼 들린다 — 「호르몬」은 흰 봉투(L16d 의 호르몬 약속)로 굳이 잇지 않고 「손님」으로 둔다.
- 낭독에 넣을 한 문장: 지용성 손님은 둘이다. 스테이크 손님은 스테로이드다.
- 자리와 크기: 새 그림 없음(s11 의 스테이크가 있어야 서는 글이다).
- 그림에서 바뀌는 것 / 그대로 두는 것: s1 그림은 그대로.
- 예약 확인: 스테로이드 안 1 과 같다. `reserved.py 스테로이드호르몬` → 임자 없음.
- 혼동쌍: 갑상선호르몬(같은 문장 안에서 둘째 손님으로 부른다).
- 붐빔: 새 물건 0 — 단 s11 안이 서야 쓸 수 있다.
- 오독 위험과 스스로 본 약점: s1 에서는 두 손님이 보이지 않으므로(전경만) 글이 허공에 뜬다. 독자가 안 보이는 것을 외우게 되는 약점 — 이 안은 s11 안이 채택될 때만 의미가 있다.

## 3. ACh · AC (정거장 s2 낱말)

### 〈s2 · ACh〉 — 안 1
- 길(글 / 그림): 글
- 물건(일상 낱말 하나): 팔걸이 의자(암체어) — 벽 위에 팔을 얹고 기댄 손님의 팔
- 사건: 손님이 벽 위 턱에 팔을 얹고 기대어 선 채 담배를 투입구에 꽂는다 — 그림 속 「팔」을 팔걸이로 보이게 하는 글이다.
- 고리(③): ACh 는 Arm·Chair 의 머리글자(A · Ch)처럼 쓴다 — Ch 의 h 가 ACh 끝의 소문자 h 다.
- 낭독에 넣을 한 문장: 손님이 벽에 팔을 얹었다. 팔걸이 의자, 암체어는 에이씨에이치다.
- 자리와 크기: s2 손님의 팔(이미 있음).
- 그림에서 바뀌는 것 / 그대로 두는 것: 그림은 그대로. 담배(니코틴) · 자판기(이온통로) · 캔 그대로.
- 예약 확인: `reserved.py 의자` → 유아 의자(L12g) · 휴식 조직 의자(L46g) 정도만 있고 팔걸이 의자는 임자 없음. `reserved.py 안락의자` · `reserved.py 팔걸이` → 임자 없음. `reserved.py ACh` → nAChR = 열린 담뱃갑(니코틴) · mAChR = 광대버섯. 담배는 이미 니코틴성(n)을 나르므로 담배에는 ACh 를 얹지 않는다.
- 혼동쌍: ACh ↔ AC(에어컨) · ACE(에이스 카드) · ACTH(층층 케이크) — 이 안은 케이크와 에이스를 쓰지 않아 막는다.
- 붐빔: 새 물건 0.
- 오독 위험과 스스로 본 약점: **약하다.** 암체어 → ACh 는 소리 고리가 아니라 철자 요령이고 「h」가 Chair 의 둘째 글자라는 설명이 필요하다. 팔 얹은 자세가 의자로 안 읽힌다. 더 나은 소리 친구(아세틸콜린 · 콜린 · 에이씨에이치에 첫 음절이 겹치는 일상 낱말)는 못 찾았다(모름). 「콜」 소리는 콜히친 = 전화기와 충돌해서 쓰지 못한다. 「에취(재채기)」는 알레르기 · 히스타민으로 끄는 틀린 소리 친구라 버렸다.

### 〈s2 · ACh〉 — 안 2
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 팔걸이 의자(안락의자)
- 사건: 쏟아진 캔 더미 오른쪽의 빈 타일에 팔걸이 의자 하나가 서 있고 구른 캔이 그 다리에 부딪혀 멈춘다.
- 고리(③): 안 1 과 같다 — Arm·Chair → A·Ch.
- 낭독에 넣을 한 문장: 캔 곁 팔걸이 의자는 암체어, 에이씨에이치의 머리글자다.
- 자리와 크기: 캔 더미 오른쪽 아래 빈 타일(원본 1400 px 에서 x 250–400 · y 560–720 쯤). 의자는 2048 px 기준 가로 150 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 빈 타일에 의자 하나. 그대로 = 자판기 · 손님 · 캔 · 덧문 자판기 · 기름 손님.
- 예약 확인: 안 1 과 같다.
- 혼동쌍: AC 의 에어컨과 같은 「A 로 시작하는 가구 한 쌍」으로 갈린다 — 의자 = ACh(밖에서 온 손님 쪽 · 왼쪽) / 에어컨 = AC(홀 안 기계 쪽 · 오른쪽).
- 붐빔: 새 소품 1.
- 오독 위험과 스스로 본 약점: 의자가 자판기와 무슨 사건으로 이어지는지 약하다. 이 안의 가치는 안 1 보다 작고 안 1 과 함께는 쓰지 않는다.

### 〈s2 · AC〉 — 안 1 (자리는 s7 기계)
- 길(글 / 그림): 글
- 물건(일상 낱말 하나): 에어컨 통풍구(교환기 윗면의 큰 검은 격자)
- 사건: 지게꾼이 달려가 닿는 오른쪽 끝 기계가 격자에서 바람을 내뿜듯 일한다 — 독자가 「교환기」라 부르는 기계의 격자를 에어컨 바람구멍으로 읽게 하는 글이다.
- 고리(③): AC 는 에어컨(A/C, 자동차 에이씨 단추)의 머리글자 그대로다.
- 낭독에 넣을 한 문장: 기계 위 격자는 에어컨 바람구멍, 에어컨은 에이씨다.
- 자리와 크기: s7 기계 윗면의 큰 격자(이미 크게 있다).
- 그림에서 바뀌는 것 / 그대로 두는 것: 그림은 그대로.
- 예약 확인: `reserved.py 에어컨` · `reserved.py 통풍구` → 에어컨은 임자 없음, 통풍구는 UCP 놋쇠 환기구(L32b)가 있으니 놋쇠 환기구로 읽히지 않게 검은 격자 그대로 둔다. `reserved.py AC` → 걸리는 단독 예약 없음(열쇠 · 케이크 · 객차는 다른 낱말).
- 혼동쌍: ACh 와 에이씨 소리가 같다 — AC 는 홀 안의 기계(에어컨), ACh 는 밖에서 온 손님이라 갈린다. ACE(에이스 카드 예약)와 PLC(큰 C자)도 이 한 문장에서 같은 기계를 두고 갈린다.
- 붐빔: 새 물건 0. 기계는 이미 AC 효소(「오른쪽 끝 기계」)를 나르므로 같은 뜻만 얹는다.
- 오독 위험과 스스로 본 약점: 격자가 스피커 · 건반으로 보일 수 있어 에어컨으로 안 읽힐 수 있다(절반의 도박). 「컴퓨터」(PC 예약)라 부르지 않는다. 컴퓨터로 읽는 독자에게는 이 글이 통하지 않는다.

### 〈s2 · AC〉 — 안 2 (자리는 s7 기계)
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 금 고리(반지)
- 사건: 지게꾼이 칩을 던지자 기계 배출구에서 금빛 고리 하나가 굴러 나온다 — 이름 뜻 그대로 「고리를 만드는 효소」다.
- 고리(④): 아데닐산 「고리화」효소는 고리를 만드는 효소라는 이름 뜻 그대로를 크게 그린 것이다.
- 낭독에 넣을 한 문장: 기계가 금 고리를 뱉는다. 고리를 만드는 기계, 에이씨다.
- 자리와 크기: 기계 아래쪽 배출구 앞 바닥(원본 1400 px 에서 x 1290–1370 · y 700–760 쯤). 고리는 2048 px 기준 지름 110 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 고리 하나. 그대로 = 지게꾼 · 칩 · 기계.
- 예약 확인: `reserved.py 고리` · `reserved.py 반지` → 금 고리(금화를 구부린 것)는 cAMP 전용(L16b 약속) — 같은 뜻으로만 쓴다. 회색 고리는 cGMP 라 쓰지 않는다. 금색 자물쇠(약물)와 헷갈리지 않게 구멍 뚫린 둥근 고리로 그린다.
- 혼동쌍: AC(고리를 만든다) ↔ PDE(고리를 자른다 — 안 PDE 1 에서 같은 고리를 가위가 문다) ↔ PKA(같은 고리에 열쇠가 꿰인다). 한 고리의 세 운명이 한눈에 갈린다.
- 붐빔: 새 소품 1(고리 — PDE · PKA 안과 하나를 나눠 쓴다).
- 오독 위험과 스스로 본 약점: 「AC」라는 약어에는 이어지지 않고 한국어 풀이 이름(아데닐산 고리화효소)에만 이어진다. 금 고리가 금화(동전 = ATP)로 읽힐 수 있다 — 구멍이 보이게 그린다. cAMP 약속을 L16b 보다 먼저 꺼내는 점은 약점이자 장점(앞당겨 예고).

## 4. 에피네프린 (정거장 s4)

### 〈s4 · 에피네프린〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 뚜껑이 터진 드럼통
- 사건: 등불 · 향수병 손님 곁, 첫 뱀 창구 위의 빈 벽 턱에서 셋째 손님이 쇠 드럼통에 두 팔을 얹고 있는데 뚜껑이 퍽 터져 날아가고 맑은 물 보라가 솟는다.
- 고리(④): 에피네프린은 급할 때 한꺼번에 터뜨려 쏟아 내는 호르몬이라 「뚜껑이 터진 드럼통」이 이름 뜻 그대로다(고리 사전 에피네프린 항목 · s16p01c 의 GPCR 대표 손님 그대로).
- 낭독에 넣을 한 문장: 셋째 손님의 드럼통은 뚜껑이 터졌다. 에피네프린이다.
- 자리와 크기: 첫 뱀 창구(몸 고리 일곱) 위 빈 벽 턱 · 담배 손님과 등불 손님 사이(원본 1400 px 에서 x 420–600 · y 95–205 쯤). 드럼통은 2048 px 기준 짧은 변 110 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 손님 하나와 드럼통 하나가 늘어 빛 · 냄새 · 에피네프린 「셋」이 된다(fact 가 이 셋이다). 그대로 = 뱀 창구 셋 · 등불 · 향수병 · 묘목.
- 예약 확인: `reserved.py 드럼통` → 「뚜껑이 터진 드럼통 = 에피네프린 전용」(뚜껑이 반드시 터져 날아가 있어야 한다 · 아나필락시스 쇼크에는 노란 섬광) — 같은 뜻이라 허용. `reserved.py 에피네프린` → 금빛 고리 하나(꼬리 달린 아민 표지)는 L16d 몫이라 여기서 그리지 않는다.
- 혼동쌍: 스테로이드(기름 손님)와 → 통 속이 맑은 물이냐 기름이냐로 갈려 수용성(창구) ↔ 지용성(벽 통과)이 한 가지 차이로 보인다. ACh(자판기 담배 손님)와 → 창구가 자판기냐 뱀 창구냐.
- 붐빔: 새 소품 2(손님 · 드럼통)지만 사실의 「셋」을 채운다. 기존 소품에는 뜻을 얹지 않는다.
- 오독 위험과 스스로 본 약점: **드럼통 = 기름통 → 지용성 → 스테로이드로 끄는 틀린 소리 친구.** 터져 나오는 것을 맑은 물보라(노란 기름 아님)로 그려 막고, 앞 손님의 노란 점액과 빛깔을 달리 한다. 낭독이 이미 다음 그림의 드럼통을 가리키는 문장을 갖고 있으니 그것과 이어지게(같은 통) 한다.

### 〈s4 · 에피네프린〉 — 안 2
- 길(글 / 그림): 글
- 물건(일상 낱말 하나): (없음)
- 사건: 이 그림에 그려진 소품(등불 · 향수병 · 뱀 · 몸 고리 일곱 · 창 · 묘목)에 에피네프린 소리나 꼴이 걸리는 것이 없다.
- 고리(종류): 후보 없음(모름). 지어내면 억지다.
- 낭독에 넣을 한 문장: (현 낭독의 「다음 그림 … 드럼통이 바로 그 손님이다」를 그대로 둔다 — 독자는 그 그림에서 드럼통을 만나게 된다.)
- 자리와 크기: —
- 그림에서 바뀌는 것 / 그대로 두는 것: —
- 예약 확인: `reserved.py 에피네프린` 위와 같다. `reserved.py 아드레날린` → 임자 없음.
- 혼동쌍: —
- 붐빔: —
- 오독 위험과 스스로 본 약점: 글 길로는 이 낱말을 이 정거장에서 꺼낼 수 없다. 드럼통이 다음 그림에만 있는 한 N′ 는 남는다.

## 5. s7 — PKA · 글리코겐 · PLC · PDE (AC 는 3절에서 같이 다뤘다)

> s7 사실(G단백질이 켜져 효소를 찾아간다)과 무관한 낱말이 둘이다(PKA · 글리코겐은 cAMP 아래 단계로 L16b 몫이다). 새 소품을 모두 넣으면 오른쪽 끝이 붐비므로 **PLC · PDE 를 먼저 쓰고 PKA · 글리코겐은 「유지 — 붐빔」 또는 낭독 예고**를 권한다. 아래 안은 다 넣을 때의 모양이다.

### 〈s7 · PDE〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 가위
- 사건: 기계가 뱉은 금 고리를 큰 가위가 싹둑 자른다 — AC 가 만든 고리를 PDE 가 끊는다.
- 고리(③): 고리를 펴서 되돌리는 연장이라 덱의 PDE 항목(펜치 · 관을 끊는 가위)을 같은 뜻으로 다시 쓴다. 가위는 이름이 없고 「무엇을 자르느냐」가 이름을 나른다(reserved.py 가위: 회색 고리 · 금 고리를 자르는 가위 = PDE).
- 낭독에 넣을 한 문장: 금 고리를 싹둑 자르는 가위는 피디이, 고리를 끊는 효소다.
- 자리와 크기: 기계 배출구 앞 바닥의 금 고리 곁(원본 1400 px 에서 x 1230–1330 · y 690–760 쯤). 가위는 2048 px 기준 폭 150 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 금 고리(AC 안 2 와 공유) + 가위. 그대로 = 지게꾼 · 칩 · 기계 · 쓰러진 지게꾼(s8).
- 예약 확인: `reserved.py 가위` → 회색 고리를 자르는 가위 = PDE(L15a#8 · L16b#5) 같은 뜻. `reserved.py PDE` → 트랜스듀신 트램펄린(Gt)은 L15a 몫이라 쓰지 않는다. 산울타리를 손으로 뽑는 칸(L05b)은 가위를 쓰지 않는 약속이라 상관없다.
- 혼동쌍: AC(같은 고리를 만든다) ↔ PDE(자른다) ↔ PKA(받는다). 시험은 Gs · Gi · Gq · Gt 의 표적을 바꿔 묻는다(S-SG-8).
- 붐빔: 새 소품 2(가위 · 고리). 고리는 AC 안 2 와 한 개를 나눠 쓴다.
- 오독 위험과 스스로 본 약점: 가위가 제한효소(빨간 조끼 경비) · Cas9(전지가위)로 오독될 수 있다 — 자르는 대상이 금 고리라야 갈린다. 「피디이」라는 약어에 이어지는 소리 고리가 아니다(펜치도 마찬가지). **글 길은 없다**: 이 그림에 가위 · 고리가 없다.

### 〈s7 · PLC〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 큰 C자 크랭크 · 피자
- 사건: 기계 왼쪽의 작은 둘째 기계가 피자 한 판을 통째로 삼키고 옆구리의 C자 크랭크가 돈다 — 덱의 PLC 항목 그대로다.
- 고리(②): P·L 은 피자를 삼켜 두 조각으로 나누는 기계, C 는 옆구리의 C자 크랭크 손잡이다(고리 사전 PLC 항목 · 피자 = PIP₂).
- 낭독에 넣을 한 문장: 둘째 기계는 피자를 삼키고 C자 크랭크를 돌린다. 피엘씨다.
- 자리와 크기: 지게꾼이 달려오는 길 위쪽 벽 아래, 기계 왼쪽(원본 1400 px 에서 x 1180–1280 · y 600–740 쯤). 기계 높이의 절반, C자 손잡이는 2048 px 기준 짧은 변 110 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 둘째 작은 기계 + 피자 한 판. 그대로 = 지게꾼 · 칩 · 첫 기계.
- 예약 확인: `reserved.py PLC` → 고리 사전 항목(C자 크랭크). `reserved.py 크랭크` → 동전 투입구 크랭크 펌프(Na⁺-K⁺ 펌프) · 놋쇠 펌프 기계(L53c) 예약이 있으니 크랭크가 아니라 「C자」 모양이 읽혀야 한다. `reserved.py 피자` → PIP₂ 전용(「피자 = PIP₂」). 포도 · 동전 · 열쇠는 쓰지 않는다.
- 혼동쌍: PKC(C자 갈고리 열쇠 — 소리가 거의 같다)와 PLC(C자 크랭크 기계)는 열쇠냐 기계냐, 곁의 피자가 있느냐로 갈린다. AC(금 고리를 만든다)와도 갈린다.
- 붐빔: 새 소품 2(기계 · 피자). 이 정거장에서는 가장 무거운 안이라 PKA · 글리코겐과 함께 쓰지 않는다.
- 오독 위험과 스스로 본 약점: 둘째 기계가 첫 기계(AC)와 같은 기계로 읽히면 효소 둘이 한 이름을 지게 된다. 피자가 음식(와플 · 케이크)과 헷갈릴 수 있다. 크랭크가 Na⁺-K⁺ 펌프(동전 · 소금)로 읽히지 않게 동전을 곁에 두지 않는다. **글 길은 없다**(기계의 수화기가 C 꼴이지만 기계는 AC 라 뜻이 둘이 된다).

### 〈s7 · PKA〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 열쇠 — 머리가 A자
- 사건: 기계가 뱉은 금 고리에 머리가 A 꼴(삼각 지붕 꼴)인 열쇠 하나가 꿰여 덜렁인다 — 고리가 열쇠를 깨운다.
- 고리(②): 열쇠(키 = 키나아제)에 머리가 A 모양이라 PKA 다 — 덱의 PKA(A자 텐트 꼭대기의 열쇠 · L16b#3) · PKC(C자로 굽은 열쇠 · L16b#10)와 같은 문법이다.
- 낭독에 넣을 한 문장: 금 고리에 꿴 열쇠는 키나아제, 머리가 A자라 피케이에이다.
- 자리와 크기: 금 고리(AC 안 2)에 꿰여 기계 곁에 늘어짐(원본 1400 px 에서 x 1250–1340 · y 640–760 쯤). 열쇠는 2048 px 기준 길이 150 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 열쇠 하나(고리를 나눠 씀). 그대로 = 지게꾼 · 칩 · 기계.
- 예약 확인: `reserved.py 열쇠` → 키나아제 전용(소리 「키」) · A자 텐트 꼭대기의 열쇠 = PKA(L16b#3) · 같은 뜻이라 허용. 금색 자물쇠(약물) · 놋쇠 열쇠(리간드 · 아세틸콜린 L23b)와는 머리 모양(A자)과 열쇠고리(금 고리)로 갈린다. `reserved.py 사다리` → A자 접이 사다리 = A(PKA · IgA · CENP-A)이지만 **이 그림의 사다리는 지게(G)를 지고 있다 — 사다리에는 PKA 를 얹지 않는다.**
- 혼동쌍: PKC(머리가 C자) · PKA(머리가 A자) · AC(고리를 만든다)가 모두 A 를 끼고 있어 시험이 바꿔 낸다. 같은 열쇠에 머리 글자 하나만 다르게 그린다.
- 붐빔: 새 소품 1(열쇠).
- 오독 위험과 스스로 본 약점: 열쇠가 리간드(ACh) 열쇠(L23b)로 읽힐 수 있다 — 꽂는 열쇠구멍이 없고 고리에 걸린 열쇠라 갈린다. 머리 A 모양이 작아 780 px 에서 안 읽힐 수 있다. 이 안은 L16b 가 책임질 몫을 앞당긴 것이라 붐빔이면 버려도 된다. **글 길은 없다**: s7 에는 열쇠 · A 꼴이 없고 있는 A 꼴(사다리)은 G 의 것이다.

### 〈s7 · 글리코겐〉 — 안 1
- 길(글 / 그림): 그림
- 물건(일상 낱말 하나): 가지 친 포도송이
- 사건: 지게꾼이 던진 칩이 기계에 맞아 튀자, 기계 곁 못에 걸린 포도송이(꼭지에서 잔가지가 갈라진 송이)에서 포도가 후두둑 떨어져 구른다.
- 고리(④): 글리코겐은 가지가 거듭 갈라진 포도 송이(붙어 있으면 글리코겐, 떨어지면 포도당)를 이름 뜻 그대로 그린 것이다 — 덱의 글리코겐 약속 그대로(L16b#7 장대 송이).
- 낭독에 넣을 한 문장: 가지 친 포도송이는 글리코겐, 떨어져 구르면 포도당이다.
- 자리와 크기: 기계 위쪽 벽 못(원본 1400 px 에서 x 1290–1380 · y 380–470 쯤). 송이는 2048 px 기준 짧은 변 110 px 이상.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 = 송이 하나. 그대로 = 나머지 전부.
- 예약 확인: `reserved.py 포도` → 가지가 거듭 갈라진 나무에 붙은 포도 = 글리코젠 전용(장대 가로대에 매단 송이도 같은 뜻으로 허용) · 동글동글한 낱 포도 = 포도당(떨어진 것만) · 「포도알」은 α 소리가 새므로 글에 쓰지 않는다 · 곤봉은 글루카곤이라 같이 그리지 않는다. `reserved.py 글리코젠` → 같은 내용.
- 혼동쌍: 글루카곤(곤봉 + 포도 포대)과 포도당(떨어진 포도)과 글리코겐(붙은 포도)이 포도 하나로 갈린다.
- 붐빔: 새 소품 1. s7 사실(G단백질 켜짐)과 무관해 「유지 — 붐빔」 판정이 정당할 수 있다.
- 오독 위험과 스스로 본 약점: 송이의 가지가 작으면 단순 포도로 읽혀 포도당이 된다. 효소 사슬의 맨 끝(분해)을 s7 에서 보여 주는 것은 순서가 앞서간다. **글 길은 없다**: s7 에 포도 · 가지 소품이 없다.

## 6. 과 전체 — 네 안을 한 사건으로 엮으면

1. 교환국 벽 너머 손님 넷: 담배 손님은 팔걸이 의자 곁(ACh, 안락의자 안을 쓰면), 등불 · 향수병 · 터진 드럼통 손님(에피네프린)이 뱀 창구 셋 위에 나란히 선다.
2. 벽 쪽 기름 손님은 둘로 늘어 앞은 비계 스테이크를 쥐고(스테로이드) 뒤는 쇠 갑옷을 입고(갑상선호르몬) 벽을 미끄러져 같은 캐비닛을 연다 — 같은 기름에서 든 물건 하나로만 갈린다.
3. 지게꾼이 칩을 뒤집으며 홀 안을 달려 기계(에어컨 격자)로 가면 기계가 금 고리를 뱉는다(AC).
4. 그 고리 한쪽엔 A자 머리 열쇠가 꿰이고(PKA) 다른 쪽에선 가위가 싹둑 문다(PDE), 둘째 작은 기계가 피자를 삼키고 C자 크랭크를 돌리며(PLC) 기계 곁 포도송이에서는 포도가 후두둑 떨어진다(글리코겐).
5. 뒷기둥의 종이 울린다(s12 그대로).
(s7 은 안이 많아 붐빈다 — PLC · PDE 만 넣고 PKA · 글리코겐은 L16b 로 넘기는 편이 안전하다.)
