# r1_마 — 렌즈 마(혼동쌍) · 일감 1122_L07b

## 먼저: 혼동쌍과 예약 사실
- 혼동쌍: T3 ↔ T4 · TRH ↔ GnRH(↔ CRH) · TSH ↔ TRH · FSH ↔ LH. 덧붙여 전엽 ↔ 후엽 · ACTH ↔ CRH(↔ ADH).
- 틀린 소리 친구: 테스토스테론 ↔ 알도스테론 · 프로게스테론(모두 「-스테론」) · T3/T4/TSH/TRH(모두 「티」로 시작) · ACTH ↔ ADH(둘 다 A_H).
- 예약 사실(reserved.py 로 찾음, 읽기 전용): 「흰 낙하산 + 짐 = 앞 글자」는 방출호르몬(-RH) 전용(L07e — 짐: 나비 TRH · 층층 케이크 CRH …). 낙하산을 L07b 에 들이는 것은 이 덱 약속을 이어 쓰는 것이다. 이 약속이 곧 마 렌즈 그대로다(같은 낙하산 · 짐만 다름). 층층 케이크 = 부신피질(L07b#3 ACTH · L07e#3 CRH 낙하산 — C = 케이크 = cortex). 나비는 「뱃전 난간의 큰 나비 = 파필로마(L01a)」 · 「나비 날개 = HPV(L01d)」 예약이 있으나 이 과의 나비 판(TSH)은 이미 쓰인 것. 쟁반은 「모듈 쟁반 · 구슬 쟁반」 예약이 많아 쓰지 않는다. 티셔츠 · 티백(티아지드) · 포크(포르밀) · 노른자(알 α · SCNT) · 앞치마 · 주전자(드립 = 트립신) · 키재기 · 막대 · 장대 · 매트는 예약이 걸려 피했다.
- 임자 없음으로 확인한 것: 토스트 · 토스터 · 테스트 · 찻잔 · 찻주전자 · 티포트 · 티팟 · 각설탕 · 앞니 · 신발닦개 · 현관 · 어린이 · 아이스.

### 〈s1 · ACTH〉 — 안 1 (글)
- 물건: 케이크(이미 둘째 창구원이 든 층층 케이크)
- 사건: 둘째 창구원이 케이크를 들고 아래로 내려보낸다 — 케이크의 「C」가 ACTH 한가운데 C.
- 고리: ③ 케이크(Cake)는 C 로 시작하고 ACTH 의 C 는 코티코(cortico = 피질)이니, 케이크 든 창구원이 곧 A-C-T-H 의 C 다. 층 셋 = 피질 셋은 이미 이 케이크가 나른다(같은 소품이 뜻을 늘리는 것이 아니라 같은 뜻의 C 에 소리를 하나 보탤 뿐).
- 낭독에 넣을 한 문장: 「케이크는 영어로 케이크, C 로 시작한다 — A·C·T·H 의 가운데 C 가 피질이고, 피질은 케이크 층처럼 쌓여 있다.」
- 자리와 크기: 둘째 창구, 그림 그대로.
- 바뀌는 것 / 그대로: 그대로(낭독만).
- 예약 확인: reserved.py ACTH · 케이크 — 층층 케이크 = 부신피질 전용(L07b#3). 같은 뜻으로만.
- 혼동쌍: ACTH ↔ CRH — 같은 케이크인데 창구원 손에 있으면 ACTH, 낙하산에 달려 내려오면 CRH(L07e#3). ACTH ↔ ADH 는 「전엽 창구에 케이크」 대 「후엽 — 이 그림에 없음」으로 가른다.
- 붐빔: 새 물건 0.
- 오독 위험 / 약점: 소리 겹침이 아니라 글자(머리글자) 고리라 약하다. 「케이크 = 부신피질」이 이미 있어 새로 얻는 것은 C 하나뿐. 「ACTH 를 ACT = 행동으로 읽는」 길은 억지라 접었다. 이 낱말은 내 렌즈에서 안 하나만 낸다.

### 〈s1 · TSH〉 — 안 1 (글)
- 물건: 나비(첫째 창구원이 든 나비 판)
- 사건: 첫째 창구원이 직접 나비를 든다 = 전엽이 손수 내놓는 TSH. (TRH 는 같은 나비가 위에서 낙하산으로 내려오는 것 — 아래 TRH 안과 한 쌍.)
- 고리: ④ 나비 모양 = 갑상선의 모양이고, 「손에 직접 든 나비」 대 「낙하산에 달린 나비」로 TSH 와 TRH 가 한 가지(낙하산 유무)만 다르게 갈린다.
- 낭독에 넣을 한 문장: 「손에 든 나비는 TSH, 위에서 낙하산에 매달려 내려오는 같은 나비는 TRH — 낙하산이 달리면 방출호르몬이다.」
- 자리와 크기: 첫째 창구, 그림 그대로.
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: reserved.py TSH · 나비 — 나비 판 = 갑상선 축(그레이브스 · 갑상샘종 전령 등에서 이미 쓰는 같은 뜻). 뜻을 갑상선 축으로만 쓴다.
- 혼동쌍: TSH ↔ TRH — 같은 나비, 낙하산이 있나 없나. TSH ↔ T3/T4 — 나비는 축을 가리킬 뿐 호르몬 둘 가운데 하나를 가리키지 않는다고 낭독에서 못 박는다(T3·T4 는 아래 찻그릇이 나른다).
- 붐빔: 새 물건 0.
- 오독 위험 / 약점: 글만이면 독자가 낙하산을 그림에서 못 본다 — 그림 길(TRH 안 1)과 함께 가야 선다. 소리 고리는 없다.

### 〈s1 · TSH〉 — 안 2 (그림)
- 물건: 찻잔(티컵) 하나 — 나비 창구원 곁 창턱에
- 사건: 나비 창구원 창턱에 찻잔이 놓여 있다(T = Tea = Thyroid 의 T 머리글자, 「티」 소리).
- 고리: ③ T 로 시작하는 아는 낱말 Tea. 단 T3·T4·TRH 도 모두 T 라 갈림이 약해, 안 2 는 「갑상선 계열 전체」의 표시로만 쓰고 개별 낱말은 낙하산(R) · 포트(4) · 잔(3)으로 가른다.
- 낭독에 넣을 한 문장: 「나비 창구 곁 찻잔 — 티, 갑상선 호르몬 집안의 T.」
- 자리와 크기: 첫째 창 창턱 오른쪽, 어림 짧은 변 120 px(2048 기준).
- 바뀌는 것 / 그대로: 찻잔 하나 추가 / 나머지 그대로.
- 예약 확인: reserved.py 찻잔 → 임자 없음. 티백은 티아지드 예약이라 티백은 쓰지 않는다(찻잔만).
- 혼동쌍: 계열 표시라 TSH 하나를 가르지 못한다.
- 붐빔: 새 물건 1(T3 안 2 의 찻잔과 같은 물건).
- 오독 위험 / 약점: 약한 안. 「티셔츠」는 예약(문지기 티셔츠 · PYY)이라 버렸다.

### 〈s3 · TRH〉 — 안 1 (그림)
- 물건: 흰 낙하산에 매달린 나비 모양 짐
- 사건: 첫째 창 위 유리에서 흰 낙하산에 달린 나비가 창구원 쪽으로 내려온다 — 위에서 TSH 를 내놓으라 시킨다.
- 고리: ④ 이름 뜻 그대로 — 방출(releasing) = 위에서 내려보냄, 짐의 모양이 앞 글자(나비 = 갑상선 T…). L07e 의 「짐 = 앞 글자」 약속을 그대로 잇는다.
- 낭독에 넣을 한 문장: 「나비 창구 위로 같은 나비가 낙하산을 타고 내려온다 — 이것은 TRH, 위에서 내려보내는 방출호르몬이고, 창구원 손의 나비 TSH 를 내놓게 한다.」
- 자리와 크기: 첫째 창 유리 위쪽 가운데, 낙하산 + 짐 높이 어림 짧은 변 150 px(2048 기준).
- 바뀌는 것 / 그대로: 낙하산 하나 추가 / 창구원 · 손의 나비는 그대로.
- 예약 확인: reserved.py 낙하산 · 방출 — 흰 낙하산 = 방출호르몬(-RH) 전용(L07e#1 약속, 짐 = 나비 TRH). 같은 뜻으로 이어 쓴다. 나비는 L01 에서 다른 뜻이 있으나 갑상선 판 안에서는 이미 쓰는 짐이다.
- 혼동쌍: TRH ↔ TSH — 같은 나비, 낙하산 유무 하나만 다르다. TRH ↔ GnRH(↔ CRH) — 같은 낙하산, 짐만 나비 / 달걀 둘 / 케이크.
- 붐빔: 새 물건 1(낙하산, 짐은 이미 있는 나비를 닮음). 창구 위 유리의 빈 자리를 쓴다.
- 오독 위험 / 약점: 두 나비를 같은 물건으로 읽을 수 있다 — 낙하산의 흰 갓과 줄이 분명해야 한다. 낙하산이 「하늘에서 오는 것」 정도로만 읽히면 TRH 라는 이름 자체는 못 꺼낸다(소리 고리 아님, 뜻 고리).

### 〈s3 · TRH〉 — 안 2 (글)
- 물건: 나비(이미 있는 것)
- 사건: 창구원이 든 나비를 가리키며, 이 나비를 내놓으라고 위에서 시킨 이가 TRH 라고 말해 준다.
- 고리: ③ T-R-H 에서 R 은 Releasing, 「내놓으라(릴리스)」 — 「TSH 는 S = 자극(Stimulating)해서 쏘는 것, TRH 는 R = 풀어 내려보내는 것」으로 글자 하나(S ↔ R)만 갈라 외운다.
- 낭독에 넣을 한 문장: 「TSH 와 TRH 는 글자 하나 차이 — 가운데가 S 면 전엽이 갑상선을 자극하고, R 이면 위에서 전엽에게 내놓으라고 시킨다.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: reserved.py TSH · 방출 — 위 안과 같다.
- 혼동쌍: TSH ↔ TRH.
- 붐빔: 새 물건 0.
- 오독 위험 / 약점: 영어 약어를 풀어 쓰는 길이라 소리 고리가 아니다. 안 1 의 보조용.

### 〈s3 · T3〉 — 안 1 (그림)
- 물건: 찻잔(티컵) + 곁에 각설탕 셋
- 사건: 나비 창구 곁 창턱에서 찻잔 곁 각설탕 세 알 — 바로 마시는 한 잔.
- 고리: ② 개수 = 이름의 숫자(이름 뜻 그대로 ④도 겸함): T3 = 요오드 셋 = 각설탕 셋. 찻잔은 「바로 마시는 것」이라 세포에서 직접 작용하는 활성형 T3 에 걸린다.
- 낭독에 넣을 한 문장: 「찻잔에 각설탕 셋 — T3 는 요오드가 셋이고, 잔을 바로 비우듯 세포에 바로 듣는 활성형이다.」
- 자리와 크기: 첫째 창 창턱, 찻잔 어림 짧은 변 120 px · 각설탕 한 알 40 px 이상(2048 기준 — 셋이 한 덩이로 읽히게 모아 둔다).
- 바뀌는 것 / 그대로: 찻잔 + 각설탕 셋 추가 / 나머지 그대로.
- 예약 확인: reserved.py 찻잔 · 각설탕 · 티백 → 찻잔 · 각설탕 임자 없음, 티백 = 티아지드 예약이라 안 쓴다. 설탕은 「설탕 자루(정자의 길)」 예약이 있어 낱개 각설탕으로만.
- 혼동쌍: T3 ↔ T4 — 같은 각설탕, 셋 대 넷(그릇이 잔 대 포트로도 갈림).
- 붐빔: 새 물건 2(찻잔 · 각설탕). 
- 오독 위험 / 약점: 개수 셈 고리는 「덱 약속」(알/베 · 단추 개수)과 닮아 다른 판의 개수 약속과 섞일 수 있다. 활성형이라는 사실 연결은 억지가 조금 있다(찻잔 = 바로 마심). 사실은 틀리지 않다.

### 〈s3 · T3〉 — 안 2 (글)
- 물건: 나비 날개(이미 그려진 나비의 날개)
- 사건: 나비 날개는 네 장 — 이 중 한 장이 떨어진 나비가 T3(요오드를 하나 뗀 활성형).
- 고리: ④ 이름 뜻 그대로 — T4 에서 요오드 하나가 떨어져 T3 가 된다(탈요오드화, 사실). 날개 네 장 → 셋.
- 낭독에 넣을 한 문장: 「나비 날개는 네 장 — T4 는 네 장 온전한 나비, 한 장 뗀 것이 T3.」
- 자리와 크기: 그림 그대로(날개 네 장은 이미 보인다).
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: reserved.py 날개 · 나비 — 나비 날개 = HPV(L01d) 예약이 있어 다른 과 장면과 닿는다. 또 나비 판은 이미 TSH/갑상선 뜻을 나르므로 「같은 소품에 뜻을 둘 얹지 않는다」에 걸린다.
- 혼동쌍: T3 ↔ T4(날개 수 한 가지).
- 붐빔: 새 물건 0.
- 오독 위험 / 약점: 규칙에 걸린다(나비가 이미 갑상선 뜻). 기록용으로 낸다 — 채택하려면 안 1 이 낫다.

### 〈s3 · T4〉 — 안 1 (그림)
- 물건: 티포트(찻주전자) + 곁에 각설탕 넷
- 사건: 찻잔 곁에 놓인 큰 포트와 각설탕 네 알 — 많이 만들어 두는 저장 · 운반용.
- 고리: ① 「T4 = 티포(트)」: 티 + 포(4)가 첫 두 음절에서 소리가 겹친다 / ② 각설탕 넷.
- 낭독에 넣을 한 문장: 「티포 — 티포트다. 각설탕 넷, 갑상선이 주로 내놓는 큰 주전자 T4 는 세포에 가서 요오드 하나를 떼고 T3 잔이 된다.」
- 자리와 크기: 첫째 창 창턱 찻잔 옆, 포트 어림 짧은 변 130 px(2048 기준).
- 바뀌는 것 / 그대로: 포트 + 각설탕 넷 추가(찻잔 · 설탕은 T3 안과 같은 물건).
- 예약 확인: reserved.py 티포트 · 티팟 · 찻주전자 → 임자 없음. 「드립 주전자 = 트립신」 예약이 있어 포트는 뚱뚱한 둥근 배 · 뚜껑 · 굵은 손잡이로 그려 긴 주둥이 드립 주전자와 갈라야 한다.
- 혼동쌍: T4 ↔ T3 — 포트(넷, 많이 · 저장) 대 잔(셋, 바로 마심). 한 쟁반 위 한 세트에 개수와 그릇만 다르다.
- 붐빔: 새 물건 2(포트 · 각설탕 넷).
- 오독 위험 / 약점: 드립 주전자(트립신)와 섞일 수 있다. 「주된 분비형 = 큰 주전자」라는 연결은 사실에 맞으나 소리(티포)가 약간 영어 읽기에 기대고 있다.

### 〈s3 · T4〉 — 안 2 (글)
- 물건: 나비(이미 있는 것)의 날개 네 장
- 사건: 날개가 모두 붙은 온전한 나비 = T4.
- 고리: ④ 숫자 뜻 그대로(날개 4).
- 낭독에 넣을 한 문장: 「이 나비의 날개를 세어 보면 넷 — T4.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: T3 안 2 와 같다 — 나비에 뜻이 둘 얹히는 규칙 위반 소지.
- 혼동쌍: T3 ↔ T4.
- 붐빔: 0.
- 오독 위험 / 약점: 위와 같다. 채택하지 않는 쪽을 권한다.

### 〈s5 · 테스토스테론〉 — 안 1 (그림)
- 물건: 토스트 한 조각(넷째 창구 창턱, 달걀 곁)
- 사건: 넷째 창구원(LH)의 에그컵 곁 창턱에 토스트 한 조각이 놓여 있다 — 아침 한 쌍(달걀 + 토스트).
- 고리: ① 테스토스테론의 「테스토스」가 「토스트」의 토스와 소리가 겹친다(테스-토스-테론). 「토스트」는 첫 음절이 아니라 가운데에서 겹치는 점이 약점. 달걀(정소 쪽 생식샘)과 짝지은 아침이라 남성 호르몬 자리도 떠오른다.
- 낭독에 넣을 한 문장: 「넷째 창구원의 달걀 곁에 토스트 — 테스토스테론, LH 가 정소를 시켜 만들게 하는 남성 호르몬이다.」
- 자리와 크기: 넷째 창 창턱 오른쪽, 어림 짧은 변 120 px(2048 기준).
- 바뀌는 것 / 그대로: 토스트 하나 추가 / 달걀 · 컵 그대로.
- 예약 확인: reserved.py 토스트 · 토스터 · 테스트 → 모두 임자 없음. 에그/달걀은 「알 α」 · 초파리 알 · SCNT 예약이 있으나 이 과의 에그컵 달걀은 이미 쓴 것(곁에 토스트를 얹을 뿐).
- 혼동쌍: 테스토스테론 ↔ 알도스테론 · 프로게스테론 — 「토스트」는 「알도」 · 「프로게」와 소리가 달라 틀린 친구로 끌지 않는다. 달걀 둘 가운데 LH 쪽(넷째)에만 놓아 FSH ↔ LH 도 가른다(LH → 테스토스테론, 카드 Q1-20#2). FSH 는 토스트 없는 셋째.
- 붐빔: 새 물건 1.
- 오독 위험 / 약점: 달걀 두 개가 FSH · LH 라는 대응(셋째 = FSH · 넷째 = LH)이 낭독 순서에만 기대고 있다. 토스트가 「아침 식사」로만 읽히면 호르몬 이름으로 안 간다. 「FSH 는 정자형성」은 카드가 「FSH + 테스토스테론」이라 토스트와 함께 가는 뜻은 따로 챙긴다(모름은 아님, 카드 근거).

### 〈s5 · 테스토스테론〉 — 안 2 (글)
- 물건: 에그컵 속 삶은 달걀(이미 있는 것)
- 사건: 달걀이 익었는지 돌려 보는 「테스트」 — 이 창구원이 달걀을 돌려 시험해 본다.
- 고리: ① 테스토스테론의 첫 두 음절 「테스」 = 테스트(시험).
- 낭독에 넣을 한 문장: 「달걀이 제대로 익었나 돌려 시험해 본다 — 테스트, 테스토스테론.」
- 자리와 크기: 그림 그대로(동작은 낭독만).
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: reserved.py 테스트 → 임자 없음. 시험관은 L38b · L52a 예약이 많아 쓰지 않는다.
- 혼동쌍: 위와 같다.
- 붐빔: 0.
- 오독 위험 / 약점: 그림에 돌리는 동작이 없어 낭독 한 줄에만 걸린다. 「테스트」가 시험 · 시험지 연상으로 가면 글자 있는 그림으로 번질 위험은 없지만 호르몬과 연결이 약하다.

### 〈s5 · GnRH〉 — 안 1 (그림)
- 물건: 흰 낙하산에 묶여 내려오는 달걀 둘
- 사건: 셋째 · 넷째 창 위 유리에서 흰 낙하산에 나란히 묶인 달걀 둘이 내려온다 — 위에서 전엽에게 달걀을 내놓으라 시킨다.
- 고리: ④ 이름 뜻 그대로 — 달걀 = 생식샘(알), 낙하산 = 방출(RH). L07e 「짐 = 앞 글자」 약속(Gn = 생식샘 = 알)을 그대로 잇는다.
- 낭독에 넣을 한 문장: 「셋째 · 넷째 창 위로 달걀 둘이 낙하산을 타고 내려온다 — GnRH, 위에서 내려보내는 생식샘 방출호르몬이고, 창구원 손의 달걀 FSH · LH 를 내놓게 한다.」
- 자리와 크기: 셋째와 넷째 창 사이 위 유리, 낙하산 + 짐 어림 짧은 변 150 px(2048 기준).
- 바뀌는 것 / 그대로: 낙하산 하나 추가 / 창구원 · 달걀 · 컵 그대로.
- 예약 확인: reserved.py GnRH · 낙하산 · 방출 — 흰 낙하산 = -RH 전용, GnRH 고리 = 달걀 둘 묶임(사전)과 같은 뜻.
- 혼동쌍: GnRH ↔ TRH ↔ CRH — 같은 낙하산 한 줄에 짐만 나비 / 달걀 둘 / 케이크(CRH 는 L07e#3). GnRH ↔ FSH · LH — 같은 달걀, 낙하산 유무 한 가지.
- 붐빔: 새 물건 1(TRH 안의 낙하산과 같은 약속).
- 오독 위험 / 약점: 달걀을 두 손의 FSH · LH 와 같은 물건으로 읽을 수 있다 — 낙하산 때문에 갈린다. 소리 고리가 없다(뜻 고리). 「G = 지」에서 낱말을 꺼내는 길은 못 찾았다(지니 램프는 아는 캐릭터 조건에 걸려 접음).

### 〈s5 · GnRH〉 — 안 2 (글)
- 물건: 에그컵 달걀 둘(이미 있는 것)
- 사건: 이 두 달걀이 낙하산 없이 손에 있으면 FSH · LH, 낙하산에 달려 내려오는 같은 달걀은 GnRH.
- 고리: ④ 달걀 = 생식샘(알), 방출 = 낙하산.
- 낭독에 넣을 한 문장: 「달걀이 손에 있으면 FSH 와 LH, 같은 달걀이 낙하산을 타고 내려오면 GnRH — 위에서 내려보내는 방출호르몬이다.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: 위와 같다.
- 혼동쌍: 위와 같다.
- 붐빔: 0.
- 오독 위험 / 약점: 그림에 낙하산이 없어 독자가 못 본다. 그림 길과 함께 가야 선다.

### 〈s6 · IGF〉 — 안 1 (그림)
- 물건: 장대 한 줄에 감은 무지개 띠
- 사건: 오른쪽 아래 소년의 긴 장대에, 주자가 든 짧은 배턴과 같은 무지개 줄무늬를 감는다 — 같은 막대가 간을 거쳐 길어졌다.
- 고리: ④ 이름 뜻 그대로 — 배턴(GH)의 색이 장대(IGF)에 이어지니 「GH 가 간을 거쳐 길어진 것」이 IGF.
- 낭독에 넣을 한 문장: 「주자의 짧은 배턴과 소년의 긴 장대는 같은 무지개 막대 — 짧으면 GH, 간을 거쳐 길어진 것이 IGF 다.」
- 자리와 크기: 오른쪽 아래 소년의 장대 전체에 줄무늬(길이는 그대로), 줄무늬 폭 어림 20 px(2048 기준).
- 바뀌는 것 / 그대로: 장대의 빛깔만 / 소년 · 벽돌 · 간장 집 그대로.
- 예약 확인: reserved.py 배턴 · 장대 · 막대 — GH: 짧은 배턴 · IGF 긴 장대 고리는 사전에 이미 있다(같은 뜻). 장대 예약은 「F 자로 짠 나무 장대(F 인자) · 유리 장대 다리 거위」 — 곧은 막대 장대에 줄무늬를 두르면 F 장대와 꼴로 갈린다.
- 혼동쌍: GH ↔ IGF — 같은 막대 꼴, 길이(짧음 대 김)와 간을 거쳤는지 한 가지만 다르다.
- 붐빔: 새 물건 0(빛깔만 바꿈).
- 오독 위험 / 약점: 소리 고리가 아니라 연결 고리라 낱말 「IGF」 자체는 꺼내 주지 못한다. 무지개 띠가 「그냥 무늬 장대」로 읽히면 효과가 없다.

### 〈s6 · IGF〉 — 안 2 (글)
- 물건: 긴 장대를 든 소년(이미 있는 것)
- 사건: 장대로 벽돌을 쌓는 이 아이가 자라는 뼈를 대신한다 — 아이(I)가 쑥쑥 크는 인자(IGF).
- 고리: ① 「IGF」의 첫 글자 I 를 「아이」로 읽으면 장대 든 소년의 아이와 소리가 겹친다 / ④ Growth Factor = 키 자라는 것.
- 낭독에 넣을 한 문장: 「장대를 든 아이 — 아이(I)·지(G)·에프(F), 아이 키를 쑥쑥 자라게 하는 성장 인자다.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 그대로.
- 예약 확인: reserved.py 아이 · 어린이 · 아이스 → 어린이 · 아이스 임자 없음, 「아이」 낱말에는 직접 예약 없음.
- 혼동쌍: IGF ↔ GH — 아이가 든 긴 장대(IGF) 대 주자의 짧은 배턴(GH).
- 붐빔: 새 물건 0.
- 오독 위험 / 약점: 소년이 아이로 읽히는지 그림을 확인하지 못했다(청년으로 읽힐 수 있음 — 모름). 아이(I) 소리는 영어 알파벳 읽기에 기댄다.

## 과 전체 (한 사건)
1. 일곱 창구 건물 앞면(앞 = 전엽)에서 창구원마다 물건을 들고 아래를 가리킨다.
2. 첫째 창 위에서 나비를 매단 흰 낙하산이 내려오고(TRH), 셋째 · 넷째 창 위에서는 달걀 둘을 묶은 낙하산이 내려온다(GnRH) — 손에 든 같은 물건(TSH · FSH · LH)과 낙하산 하나만 다르다.
3. 첫째 창턱의 찻잔(각설탕 셋 = T3)과 포트(넷 = T4), 넷째 창턱 달걀 곁의 토스트(테스토스테론)가 아래 효과를 나른다.
4. 둘째 창구원의 케이크는 C = cortex 로 ACTH, 낙하산이 매달리면 CRH(L07e).
5. 아래 오른쪽에서 소년의 장대에 주자 배턴과 같은 무지개 줄무늬 — 짧은 배턴 GH 가 간을 거쳐 긴 장대 IGF 가 된다.

(모름: FSH ↔ LH 를 달걀 둘 사이에서 소리로 가르는 고리 — 포크(포르밀) · 노른자(알 α) 가 예약이라 새 안을 내지 못했다. 셋째 = FSH · 넷째 = LH 대응은 교재 순서 가정이다.)
