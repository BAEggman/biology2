# r1_가 — 렌즈: 우리말 소리 (첫 음절부터 겹치는 일상 낱말)

소리 내어 읽은 꼴: GPCR = 「지피씨알」 · 트랜스형 = 「트랜스형」 · DAG = 「다그 / 닥」 · Ca²⁺ = 「칼슘」 · IP₃ = 「아이피 쓰리」.
먼저 지운 소리 후보(예약에 걸림): 지퍼(DNA 전용) · 짚이[지피](짚 = DNA 짚 세계) · 지팡이(DnaG) · 피리(B6 피리독신) · 칼(K⁺) · 연(꼬리 달린 연 = 프랭클린) · 코트(T4 「결정 넷 박힌 코트」 — 아래에서 가른다).

### 〈L15a · s7 · GPCR〉 — 안 1
- 길: 그림
- 물건: 피뢰침 (지붕 위)
- 사건: 지붕 꼭대기에 선 피뢰침 곁에서 접시 안테나가 햇살을 받는다 — 지붕 + 피뢰침이 접시와 한 몸처럼 붙어 선다.
- 고리: ① — 「**지**붕 **피**뢰침 = 지피 → GPCR」. 지붕의 지 + 피뢰침의 피가 「지피」로 들린다(이 덱이 이미 쓰는 「로프의 로 + 도르래의 도 = 로돕신」과 같은 두 낱말 머리 잇기 꼴). 피뢰침도 하늘에서 오는 것을 받는 물건이라 「수용체」 쪽으로 끌고 갈 뿐 사실과 반대로 끌지 않는다.
- 낭독에 넣을 한 문장: 지붕 피뢰침, 지피 — 접시는 GPCR이다. (21자)
- 자리와 크기: 오른 칸(낮) 지붕 용마루, 접시 안테나 받침 바로 왼쪽. 접시와 같은 높이까지 솟는 곧은 쇠막대 + 끝의 뾰족한 촉, 받침에 감긴 굵은 접지선 한 가닥. 높이 약 200 px · 막대 굵기는 가늘어도 촉과 받침이 합쳐 짧은 변 110 px 이상(2048 기준). 같은 건물이라 왼 칸(밤) 지붕에도 똑같이 하나 — 밤에도 수용체는 있다(쉬고 있을 뿐).
- 그림에서 바뀌는 것 / 그대로 두는 것: 지붕 용마루에 피뢰침 하나 더함(두 칸 같은 자리). 접시 · 로프 · 도르래 · 트램펄린 · 지게꾼 · 칩은 그대로.
- 예약 확인: `reserved.py 피뢰침` → (임자 없음). `reserved.py 지붕` → 지붕 자체에 걸린 예약 없음(지붕 위 멜론 = 멜라토닌은 s07p04 의 「그물무늬 멜론」 — 피뢰침과 안 겹침). `reserved.py 안테나` → 「GPCR 의 표지 — 뒤따르는 지게꾼과 짙은 회색 네모 칩」 · 「지붕 한가운데 홀로 솟은 가늘고 긴 털 하나 = 1차 섬모(L14b s8)」.
- 혼동쌍: L14b 의 「지붕 한가운데 홀로 솟은 가늘고 긴 털」(1차 섬모 = 신호 안테나)과 꼴이 가깝다 — 이쪽은 쇠 막대 + 뾰족한 촉 + 접지선이 달린 연장이고 털이 아니다. 촉 · 접지선을 꼭 그려 「피뢰침」으로 불리게 한다. 접시 안테나(수용체 몸 = 로돕신)와는 「피뢰침은 이름 · 접시는 몸」으로 나뉜다.
- 붐빔: 새 물건 +1(두 칸에 같은 것 하나씩). 있는 소품에 얹지 않는다 — 접시는 이미 로돕신(로프 · 도르래와 함께) · 수용체를 나르고 있어 셋째 뜻을 얹으면 안 된다.
- 오독 위험과 약점: 피뢰침 → 「번개 · 전기 → 탈분극」으로 읽힐 위험(이 과의 낮 칸은 과분극). 번개 · 불꽃은 그리지 않고 막대만 둔다. 「지피」 두 음절만 나르고 「씨알」은 못 나른다(GPCR 을 머리글자로 아는 학습자에겐 지피 → GPCR 로 충분하다고 본다). 피뢰침 → 프랭클린(꼬리 달린 연 예약, L38) 연상 우려는 작다고 보지만 다른 판의 연 · 프랭클린과 같은 판에 두지 말 것.

### 〈L15a · s7 · GPCR〉 — 안 2
- 길: 글
- 물건: (이미 있는) 접시 안테나 + 로프 끝의 지게꾼 — 독자가 「위성 안테나(접시)」라 부른 것
- 사건: 접시 안테나가 로프로 지게꾼과 이어져(연결돼) 있다.
- 고리: ④ + ① — 이름 뜻 그대로: G단백질 「연결」 수용체 = 지게(G)와 연결된 접시. 「지게」의 지가 G 로 들린다(덱 약속: 지게꾼 = G단백질).
- 낭독에 넣을 한 문장: 지게꾼과 이어진 접시, 지게 연결 수용체 GPCR. (24자)
- 자리와 크기: 그림 그대로.
- 그림에서 바뀌는 것 / 그대로 두는 것: 그림 그대로 — 낭독 한 문장만.
- 예약 확인: `reserved.py 지게` · `reserved.py 연결` → 「GPCR 의 표지 — 뒤따르는 지게꾼과 짙은 회색 네모 칩 — 수용체의 꼴은 과마다 이름을 나르는 물건이다(… 햇살 받는 접시 안테나 + 로프 · 도르래 = 로돕신 L15a …)」. 덱 규칙과 같은 뜻으로 쓴다(새 뜻 아님). 로프에 새 뜻을 얹지 않는다 — 「이어져 있다」는 관계만 말한다.
- 혼동쌍: 지게꾼 혼자 = G단백질(트랜스듀신의 G) / 접시 + 지게꾼의 짝 = GPCR. 「지게」 소리가 G 단백질과 GPCR 둘에 다 걸려 헷갈릴 수 있다 — 「짝이면 GPCR, 혼자면 Gt」로 낭독에서 갈라 준다.
- 붐빔: 0.
- 오독 위험과 약점: 내 렌즈(첫 음절 소리)로는 「지」 하나만 겹쳐 약하다. 독자가 이미 이 짝을 보고도 GPCR 을 못 꺼냈으니 글만으로는 다시 흘릴 수 있다 — 안 1 과 함께 쓰면 낫다.

### 〈L15a · s7 · 트랜스형〉 — 안 1
- 길: 그림
- 물건: 트렌치코트 (옷걸이에 걸린 것)
- 사건: 낮 칸 — 접시 안테나 앞 팔(급전 팔)에 옷걸이로 걸린 트렌치코트가 햇살을 받자 두 소매까지 쭉 펴져 곧게 늘어진다 / 밤 칸 — 같은 코트가 한쪽 소매가 팔꿈치에서 꺾여 접힌 채 걸려 있다.
- 고리: ① — 「**트렌**치코트는 **트랜**스형처럼 들린다」(렌 · 랜은 오늘 우리말 소리로 같다). 빛을 받아 꺾였던 소매가 펴진다 = 시스(굽음) → 트랜스(펴짐). 레티날이 로돕신 안에 있듯 코트는 접시에 걸려 있다.
- 낭독에 넣을 한 문장: 트렌치코트 소매가 펴진다, 시스에서 트랜스형으로. (26자)
- 자리와 크기: 두 칸 같은 자리 — 접시 안테나 앞으로 뻗은 급전 팔 끝(로프가 묶인 고리 바로 아래)에 옷걸이. 코트 길이 약 220 px · 폭 약 130 px(2048 기준). 접시보다 작게, 그러나 780 px 에서 「코트」로 불릴 크기. 베이지 · 허리끈 · 견장 · 겹여밈 단추 두 줄로 「트렌치」임을 세운다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 두 칸에 코트 하나씩 더함(밤 = 꺾인 소매 · 낮 = 펴진 소매). 접시 · 로프 · 도르래는 그대로 — 로프에 걸지 않고 접시 팔에 건다(로프는 로돕신 이름 전용).
- 예약 확인: `reserved.py 트렌치코트` → (임자 없음). `reserved.py 옷걸이` → (임자 없음). `reserved.py 코트` → [고리] T4: 「코트엔 결정 넷」(② · 코트에 박힌 결정이 넷). `reserved.py 소매` → 「흰 털 소매(외생균근)」 · 「민소매 거인(골격근)」 등 — 옷의 소매 자체엔 예약 없음. `reserved.py 트랜스형` · `레티날` · `시스형` → (임자 없음).
- 혼동쌍: T4 의 「결정 넷 박힌 코트」와 가른다 — 이쪽은 결정 · 보석 없이 맨 베이지 트렌치코트, 사람이 입지 않고 걸려 있다. 트램펄린(트 = 트랜스듀신)과는 「트」가 겹친다 — 트램펄린은 「트-램」, 코트는 「트-렌」 두 음절째로 갈린다. 낭독에서 「트렌」까지 소리 내어 준다.
- 붐빔: 새 물건 +1(두 칸 각 하나). 기존 소품에 얹지 않는다.
- 오독 위험과 약점: 지붕 위가 접시 · 로프 · 도르래 · (안 1 이면) 피뢰침 · 코트로 붐빈다 — 피뢰침과 코트를 다 넣으면 지붕 위 새 물건 둘. 「T4 코트」 오독 가능성이 남는다. 「11-시스」의 11 은 못 나른다.

### 〈L15a · s10 · DAG〉 — 안 1
- 길: 그림
- 물건: 닭 (덱 고리 사전에 이미 있는 「닭」을 되살림)
- 사건: 낮 칸 선반, 거의 빈 유리 통 오른쪽 곁에 닭 한 마리가 선반 판에 납작 눌러앉아 있다.
- 고리: ① — 「DAG(다그)는 닭처럼 들린다」. 눌러앉음 = 막에 남는다(사전 고리 그대로).
- 낭독에 넣을 한 문장: 통 곁에 눌러앉은 닭, DAG다. (16자)
- 자리와 크기: 오른 칸 벽 선반, 유리 통 오른쪽(선반을 통 오른쪽으로 한 뼘 늘림). 닭 높이 약 140 px. 흰 닭 · 빨간 볏으로 780 px 에서도 닭.
- 그림에서 바뀌는 것 / 그대로 두는 것: 선반 오른쪽 연장 + 닭. 유리 통 · 회색 고리 · 검은 선 그대로. 닭이 통 안을 쪼지 않게(쪼면 「닭이 cGMP 를 줄였다」로 읽힘) 고개는 앞을 본다.
- 예약 확인: `reserved.py 닭` → [고리] DAG: 닭(① · 다그 ≈ 닭. 눌러앉은 것이 「막에 남는다」) — 같은 뜻으로 되살림. 닭 물건 예약 충돌 없음. 알(α 예약)은 그리지 않는다.
- 혼동쌍: 이 과의 북극곰(쌍극세포)과 동물끼리 — 자리(선반 위 · 작음)와 소리로 갈린다. 알을 품게 그리면 α 와 엉키니 알 없음.
- 붐빔: +1. 기존 소품에 얹을 곳 없음.
- 오독 위험과 약점: 이 과의 이야기(광전환)에 DAG 는 끼지 않는다 — 「다섯 2차 전달자 진열」이라는 뜻을 낭독이 꼭 붙잡아야 한다. 「닭이 빛 경로에 낀다」로 오해할 위험.

### 〈L15a · s10 · DAG〉 — 안 2
- 길: 글
- 물건: (이미 있는) 선반 받침 — 목수 말로 「까치발」
- 사건: 유리 통을 받친 선반 밑 받침 두 개.
- 고리: ① 약함 — 「까치발」에서 새 발 → 닭발 → 닭 → DAG. 소리 겹침이 아니라 두 다리 건너는 연상이라 약하다.
- 낭독에 넣을 한 문장: 선반 받침은 닭발, DAG다. (14자)
- 자리와 크기 / 그림에서 바뀌는 것: 그림 그대로.
- 예약 확인: `reserved.py 까치발` → (임자 없음). `reserved.py 닭발` → (임자 없음).
- 혼동쌍: 밤 칸 선반 받침도 같은 꼴이라 「어느 칸이냐」가 흐려진다.
- 붐빔: 0.
- 오독 위험과 약점: 독자는 받침을 「까치발」로 부르지 않을 가능성이 크다(일상 낱말이긴 하나 목수 말에 가깝다). 안 1 이 훨씬 낫다.

### 〈L15a · s10 · Ca²⁺〉 — 안 1
- 길: 그림
- 물건: 자갈 (덱 약속 그대로)
- 사건: 낮 칸 선반, 닭 발치(또는 유리 통 왼쪽 곁)에 회색 자갈 한 줌이 소복이 쌓였다.
- 고리: 덱 약속 — 자갈 = Ca²⁺. 내 렌즈의 소리 후보 「칼슘 → 칼」은 K⁺ 예약이라 쓸 수 없어 덱 약속을 따른다(새 물건을 세우지 않는다).
- 낭독에 넣을 한 문장: 자갈 한 줌은 칼슘 이온, 셋째 전달자다. (20자)
- 자리와 크기: 오른 칸 선반, 통 왼쪽 곁 작은 자갈 더미 약 120 × 80 px. 둥글고 거친 돌 — 동전 · 와셔와 갈리게 납작하지 않게.
- 그림에서 바뀌는 것 / 그대로 두는 것: 자갈 더미 하나 더함.
- 예약 확인: `reserved.py 자갈` → 「자갈 — Ca²⁺ 전용 (s16p02b · L46e · L08a …)」 — 같은 뜻.
- 혼동쌍: 통 안의 회색 고리(cGMP · 납작 · 가운데 구멍)와 빛깔이 비슷하다 — 자갈은 갈색 섞인 둥근 덩이 · 구멍 없음으로 가른다. 바깥 소금 더미(Na⁺, 흰 가루)와도 빛깔 · 결로 갈린다.
- 붐빔: +1.
- 오독 위험과 약점: 독자가 이미 통 안 고리를 「동전 · 와셔」라 불렀다 — 회색 자갈을 통 바로 곁에 두면 「고리가 쏟아졌다」로 읽힐 수 있다. 통 안이 아니라 선반 판 위, 통과 손가락 한 마디 띄운다.

### 〈L15a · s10 · IP₃〉 — 안 1
- 길: 그림
- 물건: 구멍 셋 뚫린 피자 한 조각 (덱 L16b 「구멍 셋 피자 조각 = IP₃」 그대로)
- 사건: 낮 칸 선반, 유리 통 앞 판에 구멍 셋 난 피자 한 조각이 기대 세워져 있다.
- 고리: ① + ② — 「아이**피** → **피**자」(PIP₂ = 피자 한 판에서 떨어진 조각) · 구멍 셋 = 아래 첨자 3. 덱이 이미 세운 것이라 같은 뜻으로만 쓴다.
- 낭독에 넣을 한 문장: 구멍 셋 피자 조각, IP 쓰리다. (16자)
- 자리와 크기: 통 앞 판 오른쪽 아래, 닭 왼쪽. 조각 약 130 × 110 px. 구멍 셋이 780 px 에서 셀 수 있게 크게.
- 그림에서 바뀌는 것 / 그대로 두는 것: 조각 하나 더함.
- 예약 확인: `reserved.py IP3` → [고리] IP3: 구멍 셋(② · 조각에 뚫린 구멍이 셋인 것이 아래 첨자 3). `reserved.py IP₃` → 「뚜껑에 나무 돌기 셋이 선 끈 묶은 소포 상자 — 소포체 · L16b#11 · 구멍 셋 피자 조각(IP₃)이 꽂히면 … 자갈(Ca²⁺)이 쏟아진다」. `reserved.py 피자` → [고리] PIP / PIP2: 피자 · 「격자무늬 와플 — 덱의 유일한 음식 — 다른 판에서 음식을 그리지 마라」 경고가 있으나 피자 조각은 이미 L16b 에서 IP₃ 로 쓰이고 있어 같은 뜻 재사용으로 본다(판정은 진행자에게).
- 혼동쌍: 온 피자 한 판 = PIP₂ / 조각 = IP₃ — 조각으로만 그린다. 「아이 + 피리」 소리 안은 피리가 B6 예약이라 버렸다.
- 붐빔: +1. s10 에 닭 · 자갈 · 피자 조각을 다 넣으면 +3 — 아래 「과 전체」 참고.
- 오독 위험과 약점: 음식 금지 경고와 부딪칠 수 있다. 이 과 이야기에 IP₃ 는 끼지 않으므로 「진열」 뜻을 낭독이 붙잡아야 한다.

### 〈L15a · s10 · IP₃〉 — 안 2
- 길: 글
- 물건: 없음 — 「아이피」와 첫 음절이 겹치는 일상 이름을 독자가 이 조각에서 부르지 않았다(통 · 고리 · 와셔). 통 안 회색 고리에 구멍이 있으나 cGMP 전용이라 얹을 수 없다. 글 길 막힘.

## 과 전체
- 낮 칸 지붕: 피뢰침(지붕 피 = 지피 = GPCR) 곁의 접시 안테나가 햇살을 받자, 접시 팔에 걸린 트렌치코트의 꺾인 소매가 쭉 펴지고(트렌 = 트랜스형), 로프 · 도르래가 지게꾼을 당긴다.
- 밤 칸 지붕: 같은 피뢰침 · 같은 코트, 그러나 소매는 꺾인 채(시스).
- 낮 칸 선반: 거의 빈 회색 고리 통 곁에 「2차 전달자 진열」 — 자갈 한 줌(Ca²⁺) · 구멍 셋 피자 조각(IP₃) · 눌러앉은 닭(DAG). 빈 통과 나란히 놓여 「cGMP 는 다섯 가운데 하나」를 보인다.
- 붐빔이 부담이면 차례: 지붕은 피뢰침 > 코트, 선반은 닭 > 피자 조각 > 자갈(자갈은 덱에 이미 널리 쓰여 글로도 떠올리기 쉽다).
