## 먼저 — §7 「모자란 점」 세 가지에 대한 내 답

1. 빈자리 크기 계획: 접시 · 지붕 · 사람은 키우지 않는다. 낮 칸 **접시 왼쪽 하늘의 햇살 띠 자리**를 쓴다(full.jpg 1400 px 기준 x 900 ~ 1040 · y 60 ~ 165, 약 140×105 px 의 빈 하늘 — 노란 빛줄기만 지나가고 아무 소품도 없다). 새 물건은 소품 하나(라디오 + 안테나), 새 사람 0. 상자 몸통 약 80×58 + 안테나가 서는 높이를 합친 범위가 90×110 px(1400 기준) = 2048 px 기준 짧은 변 약 130 px 로 110 px 를 넘고, 780 px 로 줄여도 약 72 px 라 「상자 + 가는 막대」 꼴이 읽힌다. 구역 편집 한 번(낮 칸의 위 왼쪽 하늘 한 군데).
2. 모양이 바뀌고 그 바뀜이 다음 걸음을 일으킨다: 안테나가 **한 군데 꺾인 팔꿈치(ㄱ 자)에서 곧게 펴진다** — 레티날의 11-시스(C11=C12 에서 한 번 꺾임) → 모두-트랜스(곧게 폄) 와 같은 모양 사건이다. 곧게 선 안테나 끝이 접시 아랫단을 받쳐 올려 접시가 로프 쪽으로 당겨지는 그림으로 잇는다(끝만 닿는다 — 로프 · 접시에는 아무것도 얹지 않는다).
3. 「트-」 소품과의 관계: 같은 앞소리 「트랜」을 쓰되 **한눈에 갈린다** — 트램펄린은 방 안 선반 위의 둥근 파란 원반, 라디오는 지붕 밖 하늘 자리의 네모 상자 + 가는 막대. 갈리는 방법은 아래 혼동쌍에 적었다.

### 〈L15a · s7 · 트랜스형〉 — 안 1

- 길(글 / 그림): 그림 (새 소품 하나 — 있는 소품에는 아무것도 얹지 않음)
- 물건(일상 낱말 하나): **트랜지스터 라디오** (진한 남색 몸통 · 크림색 둥근 스피커 가로줄 무늬는 점 없이 단순 줄 · 은빛 안테나 하나 · 숫자 · 눈금 없음)
- 사건(누가 무엇에게 무엇을 한다 — 한 문장): 햇살이 라디오에 닿자 한 군데 꺾여 접혀 있던 안테나가 쭉 곧게 펴지며 끝으로 접시 아랫단을 받쳐 올린다.
- 고리(종류 ①④ + 한 문장): 「트랜지스터 라디오는 트랜스형처럼 들린다(트랜- 두 음절이 같다)」 + 「곧게 펴진 안테나는 트랜스형(펴진 모양) 이름 뜻 그대로다」. 트랜지스터는 영어 transfer + resistor 에서 온 말이라 transform 의 그 trans 와 같은 뿌리다(이 연결은 학생이 낱말로 알 만한 수준 — 전문 지식 필요 없음). 셋째 음절 「지」와 「스」는 다르다 — 이것이 약점이고 아래에 적었다.
- 낭독에 넣을 한 문장(반말 서술체, 40자 안쪽): 「트랜지스터 라디오 안테나가 쭉 펴진다. 트랜스형.」 (28자)
  — 이어지는 기존 문장(「정확한 작동은 내부의 레티날이 … 트랜스형으로 바뀌며 …」) 바로 앞에 두면 사슬이 「꺾임 → 곧음 → 로프」 순서로 읽힌다.
- 자리와 크기(지금 그림의 어디 · 무엇을 대신하거나 무엇 곁에 · 어림 크기): 낮 칸 **접시 왼쪽의 햇살 띠 속 하늘**(지붕 왼 비탈 위 · 접시 받침대 왼쪽에 기대 세움). 아무것도 대신하지 않는다 — 비어 있는 하늘이다. 상자 몸통 약 80×58 px(1400 기준) · 안테나는 상자 오른쪽 위 모서리에서 접시 아랫단 쪽으로 비스듬히 곧게 서서 끝이 접시 가장자리 바로 밑에 닿는다. 전체 약 90×110 px.
- 그림에서 바뀌는 것 / 그대로 두는 것:
  - 바뀌는 것: 낮 칸 위 왼쪽 하늘에 라디오 하나 추가(구역 편집 1회). 안테나 뿌리에 「방금 펴졌다」는 짧은 움직임 호 두 가닥(화살표 아님 — 지게꾼 곁의 짧은 호와 같은 문법).
  - 선택(편집 1회 더): 밤 칸의 같은 자리(접시 왼쪽 어두운 하늘)에 같은 라디오를 안테나가 팔꿈치에서 꺾여 누운 모양으로 — 「꺾임 = 11-시스 / 곧음 = 트랜스」 대조가 한 그림에서 서는 것은 이쪽이 있을 때다. 없어도 낮 칸의 움직임 호로 「방금 펴졌다」는 읽힌다.
  - 그대로: 접시 · 접시 가운데 막대 · 로프 · 도르래 · 지붕 구멍 · 트램펄린 · 지게꾼 · 칩 · 가위 · 통 · 문 · 곰 · 지휘자 · 햇살 방향 전부.
- 예약 확인(찾아본 낱말과 결과 — `python3 tools/cue/reserved.py 낱말`):
  - 라디오 → 임자 없음 / 트랜지스터 → 임자 없음 / 음악 → 임자 없음.
  - 안테나 → 접시 안테나 + 로프 · 도르래 = 로돕신(예약) · 지붕 한가운데 털 하나 = 1차 섬모(L14b) · 상자 초파리 더듬이(L43e). → 라디오의 안테나는 **접시와 짝을 이루는 곁 소품**일 뿐 접시 · 로프 · 도르래에는 닿는 일 외에 뜻을 얹지 않는다. 지붕 한가운데 털(1차 섬모)과는 장소(L14b 와 다른 판) · 꼴(라디오 상자에 달림)로 갈린다.
  - 스피커 → 회색 인터폰(인터페론 · L13a) → 인터폰이 아니도록 **벽에 걸지 않고 수화기 · 꼬불줄 없음**, 라디오 스피커는 단순 가로줄.
  - 막대 · 마디 → **마디 진 막대 = 탄소 수 전용**(L45b) → 안테나는 **마디 없는 매끈한 가는 막대 + 팔꿈치 한 군데만**(마디가 줄지으면 탄소 수로 읽힌다 · 망원 안테나 식 여러 마디는 금지).
  - 사다리 · 지팡이 → A 자 접이 사다리(PKA · IgA) · 지팡이(DnaG · IgG) → 안테나 끝에 가로대 · 갈고리 손잡이를 달지 않는다(끝은 작은 은빛 공 하나).
  - 시계 → 호스 없는 큰 옥상 시계 = 빛 · 하루 → 지붕에 시계 모양을 만들지 않는다(둥근 다이얼도 그리지 않고 가로줄 스피커 + 작은 막대 손잡이 눈금 없음).
  - 구름 · 굴뚝 · 지붕 → 이 자리에 걸린 예약 없음(L14b 털 · L46f 유리 돔 · L46h 지붕 동물은 다른 판).
  - 빛깔: 빨간 도장(인산화) · 빨간 말굽 자석 · 금색(cAMP · 자물쇠) · 회색 고리(cGMP) · 짙은 회색 네모 칩(GTP) 과 겹치지 않게 **남색 몸통 + 은빛 안테나**.
- 혼동쌍(무엇과 어떻게 갈리나):
  - 트랜스형 ↔ 트랜스듀신: 둘 다 「트랜-」이다. 갈림 = ① 자리(방 안 선반 위 vs 지붕 밖 하늘) ② 꼴(둥근 파란 원반 vs 네모 상자 + 가는 막대) ③ 동작(튀어 오르는 지게꾼 vs 꺾임이 펴지는 안테나) ④ 카드가 묻는 것(트랜스형 = 「레티날의 모양」 → 펴짐 / 트랜스듀신 = 「G 단백질」). 낭독에서도 라디오 문장은 레티날 문장 곁에, 트램펄린 문장은 로프 끝에 있어 순서로도 갈린다.
  - 트랜스형 ↔ 시스형: 안테나가 꺾였나(시스) 곧은가(트랜스). 낮 칸이 곧음이고 밤 칸(선택 편집)이 꺾임 — 카드 T0-415 의 「11-시스형 → 트랜스형(펴진다)」 순서가 그대로 그림의 밤 → 낮이다.
- 붐빔(새로 느는 물건 수 · 이미 있는 소품에 얹을 수 있는가): 새 물건 1(라디오 + 안테나 한 벌 · 사람 0). 이미 있는 소품에는 얹지 않는다(접시 · 로프 · 도르래 · 지게꾼 · 칩 모두 그대로). 지붕이 아니라 지붕 왼쪽 위의 빈 하늘을 쓰므로 지붕 위 소품 수(접시 · 도르래)는 그대로이고 새로 붐비는 곳은 없다. 이 칸에서 하늘은 지금 햇살 띠만 있다.
- 오독 위험과 스스로 본 약점:
  1. **소리 겹침이 두 음절**: 트랜지스터는 「트랜-지스터」, 정답은 「트랜-스형」 — 첫 두 음절은 같지만 셋째가 다르다. ① 종류로는 「첫 음절부터 겹친다」를 충족하나 「통째 겹침」은 아니다. 라디오가 곧 트랜스형 소리로 바로 나오기보다 「트랜지스터!」가 먼저 나오고 낭독의 한 문장이 「트랜스형」으로 이어 준다. 일상 낱말 순위로는 전봇대 「트랜스」(변압기)가 더 통째로 겹치지만 그 물건은 모양이 바뀌지 않아 기능(모자란 점 2)에서 탈락해 버렸다(아래 「버린 안」).
  2. **라디오 → 음악 · 청각**: 이 과는 시각인데 라디오가 소리 쪽으로 읽힐 수 있다 → 음표 · 소리 파동을 그리지 않는다(그림 조건상 글자 · 화살표도 없다). 안테나 쪽만 크게 읽히게 한다.
  3. **라디오 = 둘째 수용체 · 접시 둘로 읽힘**: 접시가 수용체(GPCR · 합격으로 닫힘)라 안테나 달린 라디오가 「수용체가 하나 더」로 읽힐 수 있다 → 라디오는 접시보다 작고 어둡게(남색), 안테나 끝만 접시에 닿게 한다. 학생이 「수용체」라고 읽어도 사실에는 해롭지 않다(로돕신이 수용체이므로).
  4. **끝이 닿는 연결은 약하다**: 안테나가 접시 아랫단을 받쳐 올린다는 것은 비유 연결이다. 실제 레티날은 옵신 주머니 안에서 모양이 바뀌어 옵신이 활성화되는 것이다 — 라디오는 접시의 「곁」이지 「안」이 아니다. 접시를 키우지 않기 위해 이 타협을 했다. 「안」을 원하면 접시를 키워야 하므로(모자란 점 1이 막은 길) 이 안은 일부러 곁에 둔다.
  5. **Gemini 가 안테나에 마디를 줄지어 그릴 위험**(마디 진 막대 = 탄소 수) · 다이얼 숫자를 적어 넣을 위험 → 구역 편집 문장에 「마디 없는 한 가닥 막대 · 팔꿈치 한 군데 · 숫자 눈금 없음」을 못박는다.
  6. 사실 한 줄: 11-시스 레티날은 C11=C12 에서 꺾이고 모두-트랜스는 곧게 펴진다 — 이 말은 확실하다(학생 카드 T0-415 와 같다). 접시를 「밀어 올린다」는 부분은 사실이 아니라 소리 · 모양 손잡이를 위한 그림 연출이다.

### 〈L15a · s7 · 트랜스형〉 — 안 2

- 길(글 / 그림): 글 (새 소품 없음 · 그림은 그대로 · 낭독 한 문장만 보탬)
- 물건(일상 낱말 하나): 없음 — **덱의 다른 그림(L48d 골지체 「박공 둘 맞붙은 건물」)에서 이미 외운 「시스 → 트랜스」 한 쌍**을 불러온다. 이 그림에는 새 소품도 이름도 얹지 않는다.
- 사건(누가 무엇에게 무엇을 한다 — 한 문장): 학생이 골지체에서 외운 시스 → 트랜스 순서를 레티날의 모양 바뀜(시스 → 트랜스)에 그대로 겹쳐 읽는다.
- 고리(종류 + 한 문장): ④에 가까운 연결 고리 — 「골지체의 시스 → 트랜스처럼 레티날도 시스에서 트랜스로 간다」. 소리가 아니라 **이미 아는 쌍의 순서**를 재사용한다. 덱의 예약(박공 둘 건물 · 왼쪽 = 시스 · 오른쪽 = 트랜스)과 **같은 뜻**(시스가 먼저, 트랜스가 나중) 이라 충돌이 없다.
- 낭독에 넣을 한 문장(반말 서술체, 40자 안쪽): 「골지체에서 시스 다음이 트랜스였듯 레티날도 시스에서 트랜스로 펴진다.」 (39자)
- 자리와 크기: 해당 없음(그림에 아무것도 넣지 않는다). 낭독에서 레티날 문장 바로 뒤.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 없음 · 전부 그대로.
- 예약 확인: 시스 → 골지체 · 시스터나(시스 → 트랜스) 전용(L48d s9 · s10) · 앱시스산(갓 쓴 늙은 아비) · 시냅시스 · 트랜스 → 같은 골지 예약과 트램펄린(트랜스듀신). 이 안은 새 물건을 안 그리므로 예약 충돌이 없다.
- 혼동쌍: 트랜스형 ↔ 트랜스듀신 — 이 안에서는 갈리는 물건이 없다. 「트랜스」라는 소리가 트램펄린(트랜스듀신)에도 걸려 있어 오히려 섞일 수 있다.
- 붐빔: 새 물건 0 · 얹는 소품 0.
- 오독 위험과 스스로 본 약점: **소리 손잡이가 아니라 순서 손잡이다.** 이 낱말은 그림에서 꺼낼 물건이 없다는 것이 이번 재공모의 출발점이었고(독자가 그림만 보고 못 꺼냄) 이 안은 그것을 풀지 못한다 — 글을 받은 학생이 L48d 를 기억해야만 선다. 기능 점수(모자란 점 2: 로돕신 안에서 모양이 바뀌고 다음 걸음을 일으킴)도 못 채운다. 그래서 단독안이 아니라 **안 1 과 함께 쓰는 보강 문장**(안 1 이 「트랜지스터」까지 데려오면 이 문장이 「시스 → 트랜스」 순서를 잇는다)으로 두기를 권한다. 한의학 비유가 아니라 기억 연결일 뿐이므로 다른 해석의 충돌은 없다.

### 검토하고 버린 안 (다음 사람이 다시 만들지 않게)

- **전봇대 트랜스(변압기 통)**: 소리는 통째로 겹쳐 가장 좋지만 모양이 바뀌지 않아 모자란 점 2 에서 탈락. 도르래 받침 기둥 위에 얹으면 도르래(「도」)에 뜻을 얹는 것이 된다.
- **노란 기름방울 + 꼬리가 펴짐(트랜스지방)**: 덱 문법상 곧은 선 꼬리는 「빨대 꽂은 공 · 숟가락 · 올챙이」로 읽혔고(L12g 지방 예약 기록) 곧음 = 포화로 읽혀 「불포화 → 포화」로 거꾸로 끌고 간다.
- **C 자 갈고리 → 곧은 T 막대**(덱의 글자 모양 사전 C): 덱 문법 재사용으로는 가장 순수하지만 cGMP 의 c 와 섞이고 C 갈고리가 PKC · 비타민 C · CCA 로 이미 읽혀 이 칸에서 뜻이 셋 더 얹힌다.
- **로프의 늘어짐 → 팽팽함을 「꺾임 → 곧음」으로 읽기**: 이미 로(로돕신)의 이름을 나르는 소품이라 얹을 수 없다.
- **변신 로봇 · 장난감**: 로봇 = 안드로겐 전용, 장난감 병정 · 벌 = T · B 세포 예약.
- **해바라기**: 소리가 없다 · L53b 에 꼿꼿한 해바라기 예약.

### 과 전체 (이번 재공모는 트랜스형 한 낱말이므로 한 장면만)

1. 낮 칸 지붕 위: 햇살 띠가 지나는 하늘 자리에 남색 트랜지스터 라디오가 접시 받침대에 기대 서 있고, 밤에는 팔꿈치에서 꺾여 누웠던 은빛 안테나가 낮에는 쭉 곧게 선다.
2. 곧게 선 안테나 끝이 접시 아랫단을 받쳐 올리면 접시가 로프를 당기고, 로프가 도르래를 돌아 지붕 구멍으로 내려가 트램펄린 테를 잡아끈다.
3. 트램펄린에서 지게꾼이 칩을 뒤집으며 튀어 오른다(트랜스듀신) — 같은 「트랜-」이지만 이쪽은 방 안의 둥근 원반, 위쪽은 지붕 밖의 상자 + 가는 막대.
4. 읽는 순서: 꺾인 안테나(시스) → 곧은 안테나(트랜스형) → 로프 → 트램펄린(트랜스듀신) → 가위 → 빈 통 → 닫힌 문.
5. 보강 낭독(안 2): 골지체에서 외운 「시스 → 트랜스」 순서가 이 한 장면의 안테나 꺾임 → 펴짐에 겹친다.
