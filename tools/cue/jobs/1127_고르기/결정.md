# 1127_고르기 — 사용자가 낸 연상 여섯 낱말 (2026-11-27)
- 사용자가 직접 낸 연상(아카심 · 선분/후장 · 마컨 · 아재 · 프로)과 물음(miRNA · siRNA)을, Claude 의 보완안(사실 · 예약 확인) · 옛 그림판의 고리와 나란히 고르기 화면에 올렸다 → `후보.json`.
- **결정: 사용자 고르기 대기.** 고르면 장부 · `hooks.json` 「_심볼예약」 · 이 파일에 적는다(1126_고르기 와 같은 차례).
- 확인한 사실: 아포플라스트 → 카스파리대 → 심플라스트는 층이 아니라 물이 지나는 차례 · 후구는 원구가 항문(선구는 입) · 마라비록은 숙주 수용체 CCR5 에 붙음 · AZT 는 역전사 차단 · 프로테아제는 바이러스의 절단 효소이고 약은 그것을 막음 · miRNA 는 제 헤어핀 전구체, siRNA 는 긴 이중가닥에서.
- 새 과(lessons/)에는 HIV 약 자리가 없다(옛 판 s02p01 ~ p04 에만: 고추 = 마라 · 아지트 = AZT · 자물쇠 잠근 가위) — 고른 뒤 L01c · L01d 가운데 자리를 정한다.
