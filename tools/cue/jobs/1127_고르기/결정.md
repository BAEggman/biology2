# 1127_고르기 — 사용자가 낸 연상 여섯 낱말 (2026-11-27)
- 사용자가 직접 낸 연상(아카심 · 선분/후장 · 마컨 · 아재 · 프로)과 물음(miRNA · siRNA)을, Claude 의 보완안(사실 · 예약 확인) · 옛 그림판의 고리와 나란히 고르기 화면에 올렸다 → `후보.json`.
- **결정(2026-11-28 · 사용자 · 고르기 화면): 여섯 모두 고름** — 다섯은 사용자가 낸 안 그대로, miRNA · siRNA 는 Claude 의 첫째 안. 원본 `picks.json`.
  - 아포플라스트 → 카스파리대 → 심플라스트(차례) = 아카시아 나무를 심는 사람
  - 선구 = 분열체강 · 후구 = 장체강(짝) = 엉덩이 쪽으로 들어가는 선분
  - 마라비록 = 마컨(마인드 컨트롤)당한 문지기 · AZT = 복사기 앞에서 둘이 되려는 아재를 막는다 · 프로테아제 억제제 = 마지막 관문을 막아선 프로 선수
  - miRNA · siRNA = 「내 거(my)」 하고 가슴을 가리키는 공장 일꾼 / 깃 세운 스파이 망토
- 적은 곳: `hooks.json` 「_심볼예약」 새 물건 여섯(그릴 때의 조건 함께 — 게임 아이콘 · 실존 선수는 그리지 않음) · 장부는 줄이 있는 L22b 아포플라스트 · 심플라스트 둘(`가름.json` → 「㉲ 합격안 대기(이름 4) — 사용자 고름」). 나머지 낱말은 장부에 줄이 없다(카드의 짝 · 차례를 묻는 것이라 낱말 줄이 아님).
- 확인한 사실: 아포플라스트 → 카스파리대 → 심플라스트는 층이 아니라 물이 지나는 차례 · 후구는 원구가 항문(선구는 입) · 마라비록은 숙주 수용체 CCR5 에 붙음 · AZT 는 역전사 차단 · 프로테아제는 바이러스의 절단 효소이고 약은 그것을 막음 · miRNA 는 제 헤어핀 전구체, siRNA 는 긴 이중가닥에서.
- 새 과(lessons/)에는 HIV 약 자리가 없다(옛 판 s02p01 ~ p04 에만: 고추 = 마라 · 아지트 = AZT · 자물쇠 잠근 가위) — 고른 뒤 L01c · L01d 가운데 자리를 정한다.
