- 카드 Q1-12: 세르톨리세포(Sertoli cell)의 역할은? → 정자형성에 영양 공급
- 카드 Q1-21: 남성에서 FSH를 억제하는 물질은? → 세르톨리세포의 인히빈(inhibin)
- 카드 X-AN-24: 인히빈을 분비하는 세포와 억제 대상 호르몬은? → 세르톨리세포가 분비 → FSH 억제
- 지금 낭독(say): 큰 방의 앞치마 유모들을 보자. 젖병을 안고 헤엄꾼 곁에 선 유모는 자라는 정자에 영양을 공급하는 세르톨리 세포다. 다른 유모는 빨간 멈춤 팻말을 높이 들었다. 위에서 내려오는 관에는 에그컵의 달걀이 미끄러져 내려온다. 본사 창구에서 본 에그컵 달걀은 FSH이다. 세르톨리 세포가 인히빈을 분비해 FSH를 억제한다는 관계를 연결하자.
- **FSH** — 쪼개기: F S H · 걸린 카드(답) 1
  - 지금 고리와 안 된 까닭: 글을 받지 않은 독자가 그림만 보고 이 낱말을 이 정거장에서 꺼내지 못했다(N′ — 사전엔 고리가 있는데 이 과에서 흘림). 독자의 답: 없음 | - | - | 이어지는 물건이 안 보임
  - 고리 사전(hooks.json)에 이미 있는 것 — 되살릴 수 있는 안: 달걀 둘 (③)
  - 글을 안 본 독자가 이 조각의 물건을 부른 이름: 멈춤 팻말 든 아주머니 (메이드 / 하녀 / 급식 아주머니) · 팻말 (정지 표지판 / 손바닥 팻말 / 금지 표지) · 관 속 달걀 (에그컵 달걀 / 삶은 달걀 / 알) · 흰 통을 든 아주머니 (우유통 든 메이드 / 컵 / 통) | 팻말을 들어 막는 시늉. 달걀이 관을 타고 내려온다

## 4. 임자 있는 기호
- 덱 약속(같은 뜻으로만 다시 쓴다): 칼 = K⁺ · 소금 자루 = Na⁺ · 염소 = Cl⁻ · 자갈 = Ca²⁺ · 금색 자물쇠 = 약물 · 독 · 빨간 도장 = 인산화 · 동전 = ATP · 짙은 회색 네모 칩 = GTP · 알/베의 개수 = α₁ · α₂ / β₁ · β₂ · 레몬 = H⁺ · 분필 = HCO₃⁻.
- 예약 기호 전체 목록은 길다 — 쓰려는 물건 · 소리마다 `python3 tools/cue/reserved.py <낱말>` 로 직접 찾아 그 결과를 안에 적는다(예: `reserved.py 사다리` · `reserved.py 모자`). 찾지 않은 물건은 쓰지 마라.
