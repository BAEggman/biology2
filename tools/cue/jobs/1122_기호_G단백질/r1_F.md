# r1_라 — 렌즈 라: 기호 재사용 · 그림 간 연결 (일감 1122_기호_G단백질)

## 0. 먼저 본 것 (덱에 이미 있는 것 — 이 안들의 뼈대)

예약 확인은 `reserved.py` 와 hooks.json 직접 검색으로 했다. 아래 묶음 중 "찾아본 낱말"은 각 안의 「예약 확인」에 다시 적는다.

1. 이 덱의 G 갈래 문법은 이미 하나 있다: **지게꾼(G) + 곁의 소리 소품 = 갈래 이름.** 예약에 「작은 둥근 트램펄린 — 트랜스듀신 전용 — 지게꾼(G단백질 · L16a)과 짝」이 있다. 트램펄린이 Gt 의 이름을 나르고 지게꾼이 G 를 나른다. 나머지 셋(Gs · Gi · Gq)에게 같은 문법을 이어 주는 것이 내 안의 중심이다.
2. 효소는 과마다 같은 소품이 이미 나른다: **압착기 = 아데닐산 고리화효소(AC; 금빛 고리 = cAMP 가 나오는 곳)** · **피자 + 피자 커터 = PIP₂ + PLC(L23b s8 · L23c s2)** · **가위 + 회색 고리 = PDE(L15a)**. 갈래 이름 소품은 이 효소 소품 곁에만 둔다 — 새 효소 소품은 짓지 않는다.
3. 글자 모양(②)은 덱의 전통이다: PLC = 큰 C자 크랭크 · PKC = C자 갈고리 · PKA = A자 사다리 · DHP = D자 · 힐 계수 = S자 언덕. 글자를 적어 넣는 게 아니라 소품 생김새가 글자다. 그러니 Gq = Q 꼴 커터는 같은 전통이다.
4. **짙은 회색 네모 칩 = GTP** (효소 소품에 칩이 붙으면 "G 가 붙었다"). 갈래가 갈리는 것은 칩이 아니라 이름 소품이다 — 칩과 자리만으로는 고리가 아니다(규칙).

### 그림 사이에서 찾은 어긋남 (정본을 정해야 한다)

- **A. 멈춘 압착기가 두 꼴이다.** L23b s7 은 손잡이에 금색 자물쇠를 걸었고, L23c s3 은 빈 받침 + 내려앉은 손잡이다. 그런데 금색 자물쇠는 덱에서 **약물 · 독물 전용**(예약)이다. L23b s7 의 자물쇠는 "약이 막았다"로 읽힌다 — M₂ 는 약이 아니라 Gi 다. **정본: 멈춘 압착기 = 빈 받침(금빛 고리가 안 나옴), 자물쇠 없음.** 낭독의 「α₂ 방과 같은 도구」가 이미 이 연결을 말한다.
- **B. 지게 = 사다리 오독.** 독자 셋 다 첫 이름이 「사다리 멘 남자」다. 덱에는 PKA = A자 사다리 · DNA 사다리가 있다. 지게꾼이 "사다리 멘" 사람으로 읽히면 G 가 PKA 와 섞인다. 이 일감 밖의 일이지만 모든 안의 전제라 적는다. 지게 위에 짐 보퉁이 하나를 얹는 쪽이 나을 듯하나 효과는 **모름**.
- **C. PLC 가 두 꼴이다.** 예약의 PLC 고리는 「피자를 삼키는 기계의 큰 C자 크랭크」(L16b)이고, L23 은 피자 커터다. L16b 가 지금도 C자 크랭크 기계인지는 이 꾸러미로 **모름**. **정본 제안: PLC = 피자 + 피자 커터**(과 둘에 있음). C 와 Q 는 꼬리 하나 차이라, L16b 가 C자 기계로 남아도 "C 에 꼬리가 달리면 Q = Gq" 로 이어진다.
- **D. 로돕신 칸(L15a s7)의 Gt 이름은 s8 에 있다.** 로프가 지붕 도르래를 돌아 s8 트램펄린으로 이어지는 선이 이미 그려져 있다 — 이 선이 Gt 연결의 정본이다.

### 정본 표 (한 기호 = 한 꼴)

| 갈래 | 이름 소품 | 어디에 두나 | 종류 |
|---|---|---|---|
| Gt | 트램펄린(기존) | 지게꾼 · 로프 곁(L15a) | ① 트램→트랜 |
| Gq | 둥근 날 + 비스듬히 뻗은 손잡이 = Q 꼴 피자 커터 | 피자 곁(L23b s8 · L23c s2 · L16b) | ② 글자 모양 |
| Gi | 입 막은 손(입 = ip 의 i) / 굵은 쇠 핀 | 막은 입(L23c s3) / 압착기 손잡이 | ③ / ② |
| Gs | S자 갈고리(압착기 손잡이에 걸려 아래로 당김) / 스쿠터 | 압착기(L23c s4 · s5) | ② / ① |

## L16a — 전화 교환국의 창구 셋 — 수용체

### 〈L16a · s7 · Gs〉 — 안 1 (그림)
- 물건(일상 낱말 하나): S자 갈고리(정육점 갈고리)
- 사건: 지게꾼이 달려 닿는 오른쪽 끝에서, S자 갈고리가 작은 압착기의 손잡이를 아래로 당겨 금빛 고리가 쏟아진다.
- 고리(②): S 갈고리는 S 처럼 생겼다 — Gs 의 s. 압착기는 이웃 과(L23c · L15a)에서 쓰는 AC 와 같은 물건이다.
- 낭독에 넣을 한 문장: 「교환대 발치의 작은 압착기에 걸린 S자 갈고리가 Gs다 — 당기면 고리(cAMP)가 쏟아진다.」
- 자리와 크기: 오른쪽 끝 교환대 발치 바닥. 압착기 높이 약 330 px(2048 기준) + S 갈고리 약 150×100 px. 교환대를 가리지 않는다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 작은 압착기 한 대와 갈고리를 더한다. 지게꾼 · 칩 · 교환대 · 주저앉은 지게꾼은 그대로.
- 예약 확인: `갈고리`(PKC 의 C자 갈고리 · 수소결합 쇠갈고리 · 방추체 검은 쇠고리만 — S 갈고리 없음) · `S자`(세포주기의 「S자 쇠 한 칸」 · 힐 계수 「S자 언덕」 — 둘 다 다른 과, 모양이 다름) · `압착기`(다이서의 「종이 파쇄기」 첫인상만 — 이름 아님) · `고리화효소`(cGMP 회색 고리 항목만).
- 혼동쌍: Gi(핀이 손잡이를 막음 ↔ 갈고리가 손잡이를 당김) · Gt(트램펄린 · PDE 쪽).
- 붐빔: 새 물건 둘(압착기 · 갈고리). 이미 있는 소품에 얹을 수 없다 — 이 과에는 압착기가 없다.
- 오독 위험과 스스로 본 약점: 교환대 · 전화기와 섞여 「기계 둘」로 읽힐 수 있다. 갈고리가 작으면 안 보인다. S 갈고리가 세포주기의 S자 쇠와 모양이 겹친다 — 곁의 압착기로 갈린다고 믿을 뿐 검증 못 함. 신호전달 3단계 그림에 과한 짐일 수 있다.

### 〈L16a · s7 · Gs〉 — 안 2 (글)
- 물건: 없음 — 이 과에 Gs 를 나를 소품이 없다. 「글 길 없음」이 정직하다. 가장 가까운 대안은 이웃 과의 S 갈고리를 낭독으로 불러오는 것이다.
- 사건: 지게꾼이 가는 곳은 과마다 다른 압착기다 — 이웃 아드레날린 방 오른쪽 위에서 S 갈고리가 그 압착기를 당긴다.
- 고리(②): S 갈고리 = Gs(L23c 에서 만든 것을 되가리킨다).
- 낭독에 넣을 한 문장: 「Gs 는 아드레날린 방에서 S자 갈고리로 압착기를 당기는 쪽이다.」
- 자리와 크기: 그림 변화 없음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 모두 그대로.
- 예약 확인: 안 1 과 같음.
- 혼동쌍: 위와 같음.
- 붐빔: 새 물건 0. 하지만 독자가 L16a 에서 S 갈고리를 본 적이 없다 — 이 안은 L23c 를 먼저 본 독자에게만 선다.
- 오독 위험과 스스로 본 약점: 글을 받지 않은 독자가 그림만 보고 꺼내는 시험(N)은 통과하지 못한다. 연결 안내일 뿐이다.

### 〈L16a · s7 · Gi〉 — 안 1 (글)
- 물건: 입 막은 손(이웃 과 L23c s3 의 그 사람 · 같은 동작)
- 사건: 지게꾼 중 칩을 쥔 쪽이 제 손으로 제 입을 막으면 압착기가 멎는다 — L23c 의 손님과 같은 동작이다.
- 고리(③): 입은 i 로 시작한다(입 = ip). 입 막기 = 억제.
- 낭독에 넣을 한 문장: 「입을 막으면 Gi — 입의 i, 막는 쪽이다. 아드레날린 방에서 입을 틀어막던 손님을 떠올리자.」
- 자리와 크기: 그림 변화 없음(이웃 과 L23c s3 가 정본). L16a 는 낭독으로만 되가리킨다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 모두 그대로.
- 예약 확인: `입 막`(없음) · `막은 입`(없음) · `확성기`(응원단의 「주지 않는다」 목록만) · `입을 막`(면역 중화의 설명 문장만) · 괄약근의 「막은 빨간 입술」은 소리 · 꼴이 달라 가름.
- 혼동쌍: Gs · Gq(입 막기는 끄는 쪽에만 쓴다).
- 붐빔: 새 물건 0.
- 오독 위험과 스스로 본 약점: L16a 에서는 그림이 없어 N 시험을 못 넘긴다. 「입 = i」는 로마자 첫 글자가 필요해 ③ 이 헐겁다. 입 막은 이유가 α₂ 의 억제인지 Gi 의 억제인지 독자가 가를 수 있는지 **모름**.

### 〈L16a · s7 · Gi〉 — 안 2 (그림)
- 물건: 굵은 쇠 핀(머리 둥근 걸쇠 핀)
- 사건: 작은 압착기의 손잡이 구멍에 굵은 핀이 가로로 꿰여 손잡이가 움직이지 않는다.
- 고리(②): 곧게 선 핀과 둥근 머리는 i(막대 + 점)처럼 생겼다. 막아 세우니 끄는 쪽.
- 낭독에 넣을 한 문장: 「손잡이를 꿰어 막는 핀은 i처럼 생겼다 — Gi, 끄는 쪽이다.」
- 자리와 크기: 안 1(그림)의 압착기 손잡이 위. 핀 굵기 110 px 이상으로 키워야 하는데 그러면 손잡이보다 굵어진다(약점).
- 그림에서 바뀌는 것 / 그대로 두는 것: 안 1 의 압착기에 핀 하나만 더한다.
- 예약 확인: `빗장`(루비 박힌 빗장 = Rb, L19d — 보석이 없으면 가름) · `핀`(헤어핀 = 헤파린, U자 — 곧은 핀이라 가름) · `못`(히스톤 H1 의 「못이 하나」 — 통 밖 집게의 놋쇠 못, 가름) · `쐐기`(SSB 의 쐐기 — 단일가닥 붙잡는 쐐기라 자리가 다름).
- 혼동쌍: Gs 의 갈고리(당김 ↔ 막음).
- 붐빔: 새 물건 하나(핀) — 압착기 곁 한 군데에 갈고리와 핀이 함께 서면 붐빈다. 한 장면에 둘을 나란히 두지 않는다.
- 오독 위험과 스스로 본 약점: 「못 · 막대 · 빗장 · 열쇠」로 읽힐 수 있고, 열쇠는 키나아제 예약이다. 점 달린 i 를 보고 글자를 떠올리는 것은 전문 지식 쪽에 가깝다. 이 안은 약하다.

### 〈L16a · s7 · Gq〉 — 안 1 (글)
- 물건: 피자 커터(이웃 과 L23b s8 · L23c s2 의 것)
- 사건: 지게꾼이 칩을 쥐고 가면 이웃 과에서 둥근 날의 피자 커터가 피자를 둘로 가른다.
- 고리(②): 피자 커터는 Q 처럼 생겼다 — 둥근 날에 비스듬한 꼬리 손잡이.
- 낭독에 넣을 한 문장: 「Gq 는 피자 커터 — 둥근 날에 꼬리 손잡이가 달린 Q 꼴이고, PLC 가 피자(PIP₂)를 가른다.」
- 자리와 크기: 그림 변화 없음. 이웃 과를 가리킨다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 모두 그대로.
- 예약 확인: `피자`(PIP₂ = 피자 고리 · 와플 · 소포체 상자의 「피자 조각(IP₃)」) · `커터`(볼트 커터 = 코헤신 · 이 이름과 다름 — 피자 커터 자체는 예약 없음) · `PLC`(C자 크랭크 기계 고리 — 어긋남 C 참고) · `Q `(티록신의 「9 · Q · 올챙이 로도 읽힌다」 경고뿐).
- 혼동쌍: Gs · Gi(피자 곁 = Gq 라는 자리 + Q 꼴로 갈린다).
- 붐빔: 새 물건 0.
- 오독 위험과 스스로 본 약점: L16a 에서 N 시험을 못 넘긴다. 커터가 PLC 의 몸이기도 해서 「같은 소품에 뜻 둘」이다 — PLC 이름은 커터가 나르고 Q 는 갈래의 이름이다. 둘이 한 몸이라 사실도 같이 외워지지만 규칙은 위반에 가깝다(L23c 안 1 의 약점 참고).

### 〈L16a · s7 · Gq〉 — 안 2 (그림)
- 물건: Q 꼴 피자 커터와 피자 한 판(작게)
- 사건: 오른쪽 끝 교환대 곁에서 커터가 피자를 둘로 가른다.
- 고리(②): 안 1 과 같다 — Q 꼴.
- 낭독에 넣을 한 문장: 「교환대 곁 피자를 가르는 Q 꼴 커터가 Gq 의 갈래다.」
- 자리와 크기: 교환대 발치 오른쪽 모서리. 커터 약 220 px · 피자 약 300 px — 이미 붐비는 구역이다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 피자 · 커터 추가. 나머지 그대로.
- 예약 확인: 안 1 과 같다.
- 혼동쌍: 압착기(AC 쪽)와 한 구역에 서면 Gs · Gi · Gq 가 한 장면에 모인다 — 갈래 대조는 쉬우나 붐빔.
- 붐빔: 새 물건 둘 — 압착기 · 피자 · 갈고리 · 핀 · 커터까지 합치면 다섯. 권하지 않는다.
- 오독 위험과 스스로 본 약점: 수용체 총론에 갈래 셋을 다 얹는 짐이 크다.

## L23b — 똑같은 열쇠 둘 — 아세틸콜린 수용체

### 〈L23b · s6 · Gi〉 — 안 1 (글)
- 물건: 입 막은 손(L23c s3)
- 사건: 위층 갈래 끝 압착기가 멎은 것을 입 막은 손님의 억제와 같은 일로 잇는다.
- 고리(③): 안 L16a Gi 안 1 과 같다 — 입의 i.
- 낭독에 넣을 한 문장: 「위층 갈래는 Gi — 입을 틀어막던 아드레날린 방 손님처럼 끄는 쪽이다.」
- 자리와 크기: 그림 변화 없음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 모두 그대로. 단 정본 A 에 따라 s7 의 자물쇠는 별도 일감으로 빈 받침 꼴로 바꾸기를 권한다.
- 예약 확인: L16a Gi 안 1 과 같다.
- 혼동쌍: Gq(아래 갈래).
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: s6 그림에는 입 막은 사람이 없다. 이웃 과 지시라서 N 시험은 못 넘긴다. 이 과의 지게꾼은 문장 없이 위층 계단으로 달려 올라가는 방향성에 기대야 한다.

### 〈L23b · s6 · Gi〉 — 안 2 (그림)
- 물건: 굵은 쇠 핀(압착기 손잡이)

## L23c — 네 칸 방의 빨간 운동복 손님 — 아드레날린 수용체

### 〈L23c · s2 · Gq〉 — 안 1 (글)

## L15a — 같은 극장의 두 때 — 간상세포 광전환

### 〈L15a · s7 · Gt〉 — 안 1 (글)
- 물건: 안테나에서 도르래를 돌아 지붕 구멍을 지나 s8 트램펄린으로 이어지는 로프(**이미 그려져 있다**)
- 사건: 햇살이 접시에 닿고 로프가 팽팽해지면 그 끝이 선반 트램펄린을 매단 테를 당겨 지게꾼이 튄다.
- 고리(①): 트램펄린 → 트랜스듀신, 트램 → 트랜(예약된 기존 고리). 같은 로프가 로돕신과 Gt 를 잇는다.
- 낭독에 넣을 한 문장: 「이 로프 끝에 매인 선반의 트램펄린이 Gt, 트랜스듀신이다 — 로돕신이 줄을 당기면 트램펄린이 지게꾼을 튕긴다.」
- 자리와 크기: 그림 그대로. 로프가 이어지는 지붕 구멍 아래를 알아보기 쉽게 굵게(선택).
- 그림에서 바뀌는 것 / 그대로 두는 것: 그대로.
- 예약 확인: `트램펄린`(트랜스듀신 전용 · 지게꾼과 짝 · L15a 갈아엎기 덱에서 이미 지게꾼과 묶임) · `지게`(GPCR 표지 예약) · `도르래`(로돕신 예약 — 같은 로프) · `PDE`(회색 고리를 자르는 가위).
- 혼동쌍: Gs(압착기 · AC) — s8 의 대조.
- 붐빔: 새 물건 0 · 이미 있는 소품.
- 오독 위험과 스스로 본 약점: 독자가 s7 한 조각만 볼 때 트램펄린이 안 보인다. 로프가 s8 로 이어지는 것을 알아보는지가 관건. 낭독이 길어진다.

### 〈L15a · s7 · Gt〉 — 안 2 (그림)
- 물건: s7 지붕 구멍 아래로 내려오는 로프 끝에 작은 트램펄린 가장자리가 보이게
- 사건: 도르래 로프가 지붕을 뚫고 내려와 트램펄린 테에 매인 모습이 s7 조각 안에 함께 들어온다.
- 고리(①): 안 1 과 같다.
- 낭독에 넣을 한 문장: 「로프 끝의 트램펄린이 Gt — 트램, 트랜스듀신.」
- 자리와 크기: s7 조각을 아래로 넓혀 지붕 구멍 + 트램펄린 윗부분 포함(약 300×200 px).
- 그림에서 바뀌는 것 / 그대로 두는 것: 그림 변화 없음 — 조각(크롭) 범위만 바뀐다.
- 예약 확인: 안 1 과 같다.
- 혼동쌍: 같다.
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: s7 · s8 이 한 사건이라는 사실을 크롭이 드러낼 뿐 고리가 새로 늘지는 않는다.

### 〈L15a · s8 · Gs〉 — 안 1 (글)
- 물건: 이웃 L23c 의 S 갈고리 압착기(낭독으로 되가리킴) — 이 장면의 그림은 그대로
- 사건: 지게꾼이 트램펄린에서 튀는 이 장면은 Gt 이고, Gs 는 같은 지게꾼이 아드레날린 방에서 S 갈고리로 압착기를 당기는 쪽이다.
- 고리(②): S 갈고리 = Gs. 이 칸의 트램펄린 = Gt(예약 기존). 둘 다 지게꾼의 곁 소품이라는 문법이 같다.
- 낭독에 넣을 한 문장: 「Gs 는 아드레날린 방에서 S 갈고리로 압착기를 당기는 쪽이고, 여기 트램펄린은 Gt, PDE 를 켠다 — 같은 지게꾼, 다른 곁 소품이다.」
- 자리와 크기: 그림 변화 없음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 모두 그대로.
- 예약 확인: `스쿠터`(임자 없음) · `S자`(위 L23c 와 같음) · `트램펄린`(트랜스듀신 전용).
- 혼동쌍: Gt — 한 낭독 안에서 두 곁 소품을 함께 말한다.
- 붐빔: 0.
- 오독 위험과 스스로 본 약점: 이 칸에서는 Gs 가 대조용 낱말(카드 S-SG-10 · S-SG-9)이라 그림에 있을 필요가 작다. 독자가 L23c 를 보지 않았으면 이어지지 않는다.

### 〈L15a · s8 · Gs〉 — 안 2 (그림)
- 물건: 선반의 트램펄린 곁에 작은 압착기 + S 갈고리
- 사건: 같은 선반에서 지게꾼은 트램펄린에서 튀고 곁의 압착기는 S 갈고리가 당긴다 — 갈래 둘이 한 장면에서 만난다.
- 고리(②): S 갈고리 = Gs. 트램펄린 = Gt.
- 낭독에 넣을 한 문장: 「선반 곁의 S 갈고리 압착기가 Gs, 트램펄린이 Gt — 같은 GPCR 인데 켜는 효소가 다르다.」
- 자리와 크기: 선반 오른쪽 빈 자리. 압착기 약 280 px + 갈고리 약 150 px.
- 그림에서 바뀌는 것 / 그대로 두는 것: 압착기 + 갈고리 추가. 지게꾼 · 트램펄린 · 로프 · 밤낮 구조는 그대로.
- 예약 확인: 안 1 과 같다. 추가로 `압착기`는 AC 로 이미 이웃 과 정본.
- 혼동쌍: Gt — 카드 S-SG-10(고리화효소 ↔ PDE)을 한 장면에서 바로 대조한다.
- 붐빔: 새 물건 둘. 로돕신 칸에 AC 를 가져오면 PDE · 가위와 함께 효소 소품이 셋이 되어 붐비고, cGMP 와 cAMP 의 금빛 · 회색 고리도 섞인다.
- 오독 위험과 스스로 본 약점: 시각 과의 핵심은 PDE 와 cGMP 감소이므로 AC 소품이 주의를 빼앗는다. 이 안은 권하지 않는다.

## 과 전체 — 네 과를 한 사건으로 엮으면

1. 지게꾼(G)은 L16a 교환국에서 칩(GTP)을 뒤집고, 그가 가는 곳이 과마다 효소 소품이다: 아드레날린 방의 압착기 · 피자 · 시각 칸의 가위.
2. 같은 압착기에 S 갈고리가 걸려 아래로 당겨지면 Gs(β 방 · L16a 끝 교환대), 같은 압착기에 핀이 꿰이거나 손님이 입을 틀어막으면 Gi(α₂ 방 · M₂ 의 위층 갈래), 압착기가 멎는다.
3. 피자 곁의 Q 꼴 커터는 어느 과에서나 Gq 다(α₁ 방 · 무스카린 아래층 갈래 · L16a 낭독), 시각 칸에서는 같은 로프가 트램펄린으로 가서 지게꾼이 튀면 Gt, 가위가 회색 고리를 자른다.
4. 정본은 둘이다 — 멈춘 압착기는 자물쇠 없이 빈 받침(금색 자물쇠는 약물 전용이므로 L23b s7 의 자물쇠를 핀으로 바꾸거나 없앤다), PLC 는 피자 커터(L16b 가 C자 크랭크로 남아 있으면 C → Q 의 꼬리로 잇는다).
5. 과 사이 연결은 낭독 한 문장씩이라 비용이 작고, 새 물건 순증은 정본대로면 s4 · s5 갈고리 둘 · s3 핀 하나로 끝난다. 다만 Gs · Gi 의 이름 고리는 약하고(스쿠터는 한 음절 · 핀은 i 읽기가 헐거움), 가장 단단한 것은 Q 꼴 커터와 기존 트램펄린이다.
