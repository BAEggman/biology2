# r1_다 — 렌즈 다(사건 연출) · 일감 1122_기호_G단백질

## 덱 기호 하나(네 과 공통) — 「지게꾼이 무엇을 지고 오나」
- 지게꾼(G · 덱 예약 그대로) + **지고 온 것 · 올라탄 것의 첫소리 = 둘째 글자**. 지게꾼이 그것을 효소에 **직접 갖다 대는 동작**이 그 갈래가 하는 일이다.
  - **Gs = 에스프레소 잔** — 압착기(아데닐산 고리화효소)에 부어 넣으면 압착기가 쿵쿵 돌아 금빛 고리(cAMP)를 뱉는다(켬).
  - **Gi = 지게에 앉아 온 아이** — 뛰어내려 압착기 누름판 밑에 나무 굄목을 괴어 멈춘다(끔 · 【억제의 문법】 「붙어서 괴는 억제 단백질 = 굄목」을 그대로 씀).
  - **Gq = 당구 큐** — 피자 탁자를 당구대처럼 엎드려 큐로 피자 커터(PLC)를 '탁' 치면 커터가 굴러 피자(PIP₂)를 둘로 가른다(IP₃ · DAG).
  - **Gt = 트램펄린**(이미 있는 예약) — 지게꾼이 올라타 튄다 → 가위(PDE).
- 네 물건 모두 손의 **짙은 회색 네모 칩(GTP)** 은 그대로 든다. 짐만 갈아 끼운다.

### 〈L16a · s7 · Gs〉 — 안 1 (그림)
- 물건(일상 낱말 하나): 에스프레소 잔(작은 흰 잔 + 받침 · 위에 갈색 크레마 · 김)
- 사건: 달리는 지게꾼의 지게 위 칸에 얹힌 에스프레소 잔이 출렁이며 김을 뿜고, 그는 그것을 오른쪽 기계(이 과에서 AC 자리)에 부어 넣으러 달려간다.
- 고리: ① 「Gs 의 에스(s)는 **에스**프레소처럼 들린다」 — 에스프레소 한 잔이 기계를 깨운다 = 자극(stimulatory). 덤: 에스프레소는 압력으로 내린 커피 → 압착기(L23b · L23c)에 붓는 그림과 맞물린다. 카페인이 cAMP 를 올리는 쪽(PDE 억제)이라 사실과 같은 쪽으로 끈다.
- 낭독에 넣을 한 문장: 「지게 위에서 출렁이는 작은 잔은 에스프레소 — 에스, 곧 Gs다. 에스프레소 한 잔이 기계를 깨우듯 Gs는 아데닐산 고리화효소를 켠다.」
- 자리와 크기: s7 지게꾼 등의 지게 위 칸(어깨 높이 · 사다리 가로대 둘째 칸 위) · 2048 px 기준 짧은 변 120~140 px(잔 + 김 포함).
- 그림에서 바뀌는 것 / 그대로 두는 것: 지게 위에 잔 하나를 더함 · 지게꾼 자세 · 칩 · 기계 · 바닥 칩은 그대로.
- 예약 확인: 에스프레소 → 임자 없음 · 커피 → 임자 없음 · 커피잔 → 임자 없음 · 카페인 → 임자 없음 · 「잔」 → 【포크가 꽂힌 갈색 잔】(푸코잔틴 — 포크 + 민짜 갈색 잔) · 【트로피】(받침 위 잔) 가 걸림 → 흰 사기 잔 + 받침 접시 + 손잡이 + 크레마로 갈린다. 지게꾼 → 【GPCR 의 표지】 예약 — 같은 뜻(G단백질)으로만 씀.
- 혼동쌍: Gs(에스프레소 = 켬) ↔ Gi(아이 = 괴어 멈춤) — 「마시면 깬다 / 아이가 막는다」로 방향이 반대. Gs ↔ Gt: Gs 는 지고 오고, Gt 는 올라탄다.
- 붐빔: +1(작은 잔). 기존 소품(지게)에 얹는다.
- 오독 위험과 약점: 780 px 에서 「커피잔」으로만 불리면 「에스」가 안 나온다 — 받침 접시 위 아주 작은 잔 · 크레마 거품이 보여야 「에스프레소」로 불린다. 지게가 「사다리 · 의자」로 읽히는 문제(독자 보고)는 남는다 — 다만 지게 위에 짐이 얹히면 「짐 나르는 틀」로 읽힐 몫이 는다.

### 〈L23b · s6 · Gq〉 — 안 1 (그림)
- 물건: 당구 큐
- 사건: 아래층 복도 바닥에서 둘째 지게꾼이 당구 치듯 엎드려 큐를 내지르고, 큐 끝이 피자 커터 손잡이를 '탁' 쳐 커터가 굴러 피자를 둘로 가른다.
- 고리: ① 「Gq 의 q 는 당구 **큐**처럼 들린다」 + ② 둥근 피자 가장자리에 비스듬히 닿은 큐 = 대문자 Q 꼴.
- 낭독에 넣을 한 문장: 「아래층 지게꾼은 지게에서 당구 큐를 뽑아 피자 커터를 친다 — 지-큐, Gq. 맞은 커터(PLC)가 굴러 피자(PIP₂)를 IP₃ 와 DAG 두 쪽으로 가른다.」
- 자리와 크기: s8 피자 왼쪽 앞(그림 아래 가운데 · 붉은 버섯과 피자 사이) · 지게꾼은 허리 위만(엎드린 자세) · 큐 길이 피자 지름의 1.5배 · 굵은 끝 짙은 밤색 · 가는 끝 파란 초크 팁.
- 그림에서 바뀌는 것 / 그대로 두는 것: 엎드린 지게꾼 + 큐 더함 · 커터에 「굴러 가는」 움직임 줄 / 피자 · 커터 · 물자루 · 세 손가락 그대로.
- 예약 확인: 큐 → 임자 없음 · 큐대 → 임자 없음 · 당구 → 당구장 세계(L31) — 당구대 · 공 없이 큐만. 피자 커터 → 임자 없음(이 과 안에서 PLC — 같은 뜻으로 닿기만 함). 지팡이 → DnaG — 엎드려 겨누는 자세로 지팡이와 갈린다. 붉은 갓 흰 점 버섯(무스카린)에 큐가 닿지 않게.
- 혼동쌍: 위층 Gi(아이 + 굄목 → 압착기)와 짐 · 닿는 효소가 다 다르다. 피자 커터를 「큐가 아니라 커터가 PLC」라고 낭독이 한 번 갈라 줘야 한다.
- 붐빔: +2(엎드린 지게꾼 · 큐). 아래층 바닥에 빈자리는 있으나 버섯 · 피자 · 물자루 사이라 좁다.
- 오독 위험과 약점: 지게꾼 둘이 「같은 사람」으로 읽힐 수 있다 — 위층 지게꾼은 아이를 태우고, 아래층 지게꾼은 큐를 든다는 짐 차이로만 갈린다. 엎드린 사람의 지게가 등에 보여야 G 가 산다.

- 사건: 위층 선반에서 압착기에 부어지려던 에스프레소 잔이 엎어져 커피가 선반 끝으로 흘러내리고, 압착기 누름판 밑엔 아이가 괴어 둔 굄목이 박혀 금빛 고리가 안 나온다.

- 자리와 크기: s7 위층 선반 · 압착기와 빈 받침 사이 · 잔 짧은 변 110~120 px · 흘러내린 갈색 줄 하나.
- 그림에서 바뀌는 것 / 그대로 두는 것: 엎어진 잔 더함 · (권함) 손잡이의 쇠 자물쇠를 누름판 밑 굄목으로 바꿈 / 시계 · 두 손가락 · 빈 받침 · 계단 그대로.
- 예약 확인: 에스프레소 · 커피 · 커피잔 → 임자 없음. 자물쇠 → 【억제의 문법】 「억제성 인산화 = 검은 쇠 자물쇠」 · 「금색 자물쇠 = 약 · 독」 — **지금 L23b 압착기 손잡이의 짙은 회색 자물쇠는 이 문법과 어긋난다**(Gi 는 인산화로 막지 않는다). 굄목으로 바꾸면 「붙어서 괴는 억제 단백질」로 문법과 맞는다.
- 혼동쌍: Gs(잔) ↔ Gi(아이 · 굄목) — 같은 압착기를 두고 켬 / 끔. 엎어진 잔 = 「여기엔 Gs 가 일하지 않는다」.
- 붐빔: +1(잔) · 자물쇠 → 굄목 바꿈은 0.
- 오독 위험과 약점: 엎어진 잔이 「M₂ 가 Gs 를 쓴다」로 거꾸로 읽힐 위험 — 낭독이 「쏟아졌다 = 안 쓴다」를 꼭 말해야 한다. 자물쇠를 바꾸면 L23c s3(그대로 둘 것)의 멈춘 압착기와 꼴을 맞출 일이 생긴다(L23c s3 압착기엔 지금 자물쇠가 없다 — 낭독 「α₂ 방과 같은 도구」와도 이미 어긋남).

### 〈L15a · s7 · Gt〉 — 안 1 (글)
- 물건: 트램펄린(이미 있음 · 독자가 s8 에서 트램펄린으로 부름) — s7 로프가 바로 이 트램펄린 테에 묶여 있다.
- 사건: 햇살이 접시를 때리자 로프가 도르래를 돌아 팽팽해지고, 그 끝에 묶인 트램펄린 테가 홱 들려 지게꾼이 튀어 오른다(지금 그림의 줄 그대로).
- 고리: ① 「지게의 **지** + **트**램펄린의 트 = 지-트, Gt」 — 트랜스듀신의 「트」도 같은 소리라 한 물건이 둘을 함께 끈다(덱 예약 【트램펄린 = 트랜스듀신】과 같은 뜻 · Gt 는 트랜스듀신의 다른 이름이므로 뜻이 하나).
- 낭독에 넣을 한 문장: 「로프 끝은 트램펄린에 묶였다 — 지게꾼의 지, 트램펄린의 트, 지-트 Gt, 곧 트랜스듀신이다.」
- 자리와 크기: 바뀜 없음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음.
- 예약 확인: 트램펄린 → 【작은 둥근 트램펄린 — 트랜스듀신 전용】(지게꾼과 짝) — 같은 뜻 · 로프 · 도르래 → 로돕신(같은 뜻 · 건드리지 않음).
- 혼동쌍: Gs(에스프레소 — 지고 감) ↔ Gt(트램펄린 — 올라탐). Gt → 가위(PDE) / Gs → 압착기(AC).

- 오독 위험과 약점: 트램펄린이 s8 정거장 물건이라 s7 에서 부르려면 로프 줄을 따라가야 한다 — 그것이 곧 이 렌즈의 「닿는 줄」이라 오히려 맞다. 이 과의 덱 기호 중 가장 안전.

### 〈L15a · s7 · Gt〉 — 안 2 (그림)
- 물건: T 자 몸(지게꾼 자세)

### 〈L15a · s8 · Gs〉 — 안 1 (글)

### 〈L15a · s8 · Gs〉 — 안 2 (그림)

- 사건: 지게꾼이 튀어 오르는 서슬에 트램펄린 선반 끝에 놓였던 에스프레소 잔이 튕겨 떨어져 커피가 쏟아진다 — 이 극장에선 Gs 가 일하지 않는다.

## 과 전체
1. 한 사건(네 과를 잇는 줄): 지게꾼(G)은 늘 GTP 칩을 들고 달리고, **지게에 무엇을 지고 오느냐**로 갈래가 정해진다 — 에스프레소(Gs)는 압착기에 부어 금빛 고리를 쏟게 하고, 지게에 탄 아이(Gi)는 뛰어내려 압착기를 굄목으로 괴고, 당구 큐(Gq)는 피자 커터를 쳐 피자를 가르고, 트램펄린을 탄 지게꾼(Gt)은 튀어 올라 가위꾼에게 간다.
2. L16a(총론): 달리는 지게꾼 지게에 에스프레소 한 잔(Gs) — 기계를 켜러 감 · 아이 · 큐는 낭독으로만 미리 부름.
3. L23b(아세틸콜린): 복도 지게꾼 지게에 아이(Gi) → 위층 압착기 굄목 · 곁에 엎어진 에스프레소(Gs 아님) / 아래층엔 큐 지게꾼(Gq) → 피자 커터.
4. L23c(아드레날린): 첫 방 큐(Gq) · 둘째 방 아이 굄목(Gi) · 오른쪽 두 방 에스프레소(Gs) — 「알 하나 큐 · 알 둘 아이 · 베는 둘 다 에스프레소」. L15a(빛): 트램펄린(Gt) — 짐 대신 올라탄다.
5. 내가 본 걸림: (가) L23b 압착기의 짙은 회색 자물쇠는 【억제의 문법】(검은 쇠 자물쇠 = 억제성 인산화)과 어긋난다 — Gi 굄목으로 바꾸길 권함 · L23c s3 멈춘 압착기엔 자물쇠가 없어 두 과 「같은 도구」 낭독과도 지금 어긋남. (나) 효소 물건이 L16a 는 「교환 기계」, L23b · L23c 는 「압착기」로 다르다 — 에스프레소 잔이 두 물건에 다 붓게 되면 AC 기호가 둘임이 드러난다(모름: 어느 쪽을 정본으로 할지는 내 몫 밖). (다) 독자가 지게를 「사다리 · 의자」로 먼저 부른다 — 짐(아이 · 잔)이 얹히면 「지게」로 불릴 몫이 커지리라 보지만 검수로 확인해야 한다.
