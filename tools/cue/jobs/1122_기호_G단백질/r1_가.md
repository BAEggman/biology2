# r1_가 — 렌즈 가(우리말 소리) · 1122_기호_G단백질

## 0. 기호 한 벌 (네 과 공통 — 덱 전체 한 개념 = 한 기호)

G 는 이미 「지게(꾼)」의 **지**가 나른다(예약: 지게꾼 = G단백질). 나는 **둘째 글자만** 지게꾼이 「지고 · 쥐고 · 입은 것」의 첫 음절로 싣는다. 소리 내어 읽으면 —

| 낱말 | 읽는 소리 | 기호(지게꾼 + 물건) | 소리 | 사건(하는 일과 같은 방향) |
|---|---|---|---|---|
| Gs | 지-**에스** | 김 나는 흰 **에스프레소** 잔을 털어 넣는 지게꾼 | ① 에스 = 에스 | 에스프레소 안에 **프레스**가 들었다 → 금색 압착기(= 프레스, 고리화효소)를 돌리러 달린다 |
| Gi | 지-**아이** | 작은 지게를 진 **아이**(꼬마 지게꾼) | ① 아이 = 아이 | 아이가 압착기(프레스) 손잡이에 매달려 못 내리게 붙든다 = 고리화효소를 끈다 |
| Gq | 지-**큐** | 지겟작대기 대신 당구 **큐**대를 짚은 지게꾼 | ① 큐 = 큐 | 큐대 끝으로 피자 커터(PLC)를 툭 쳐 굴린다 → 피자(PIP₂)가 갈린다 |
| Gt | 지-**티** | 흰 반팔 **티**셔츠 지게꾼 + 트램펄린 | ① 티 = 티 (트램펄린의 「트」도 t) | 트램펄린에서 튀어 가위(PDE) 쪽으로 |

- 가장 센 짝: **에스프레소 ↔ 프레스**. 「에스 + 프레스」 한 낱말 안에 Gs 와 그 표적(압착기 = 고리화효소)이 같이 들었다. 그래서 L23b · L23c 의 금색 압착기를 「프레스」라 한 번 불러 주기만 해도(글 길) Gs 가 떠오른다.
- Gi 의 「아이」는 압착기를 **붙드는** 쪽, Gs 의 「에스프레소」는 압착기를 **돌리는** 쪽 — 같은 압착기를 두고 켜기 / 끄기가 갈린다.
- 사람 없는 방(L23c)에서는 지게꾼 없이 **물건만**(잔 · 아이 · 큐대) 표적 도구에 닿게 둔다 — 칼 = K⁺ 처럼 물건이 기호다. 지게꾼이 나오는 판(L16a · L23b · L15a)에서는 지게꾼에게 붙인다.
- 예약 확인(이 표 전체): `reserved.py 에스프레소` → 임자 없음 · `커피` → 임자 없음 · `어린이` → 임자 없음 · `아이` → 아기·아이 예약 여럿(기저귀 아기 HbF · 포대기 손주 · 히히 아기 · 크레용 아기 · 갈색 담요 아기 · 횃불 아기 · 배 속 새싹 아기 · 잎채소 든 아이) — 모두 「지게를 진 아이」와 꼴이 다름 · `꼬마` → 꼬마 일꾼(뉴런 L16d · 펌프 L08a · 꽃 도장 L43 · 형성층 꼬마) 있음 → **반드시 작은 나무 지게를 지게 한다**가 갈림 · `큐대` · `큐` · `지큐` · `지티` · `지에스` → 임자 없음 · `당구` → 당구장 세계(L31a 해당과정) · `당구대` → 세포호흡 안내판 · `작대기` → 임자 없음 · `지팡이` → DnaG(「지」= G 선례 — 같은 소리 쓰임이라 오히려 받쳐 줌) · `지게` → G단백질 예약(같은 뜻) · `트램펄린` → 트랜스듀신 예약(같은 뜻) · `티셔츠` → 문지기 옷빛(lac 검정 · trp 초록 · PYY 노랑) — 흰 반팔이면 갈림 · `티` → 티백 = 티아지드(티백은 안 씀) · `잔` → 포크 꽂힌 갈색 민짜 잔(푸코잔틴) · 받침 위 잔 = 트로피 · `손가락` → **M₂ · M₃ 손가락 개수 예약 — 새 인물의 손가락을 펴 세지 않게** · `쉿` → 세크레틴 요원 예약(아이에게 「쉿」 시키지 않는다) · `에스컬레이터` → Ca²⁺ 회수 예약(Gs 에 쓰지 않음) · `스위치` → DHP 청록 스위치 상자 · 그레이브스 초인종(둘째 안에서 버림) · `수화기` · `전화` → 인터폰 = 인터페론 · 나무 전화기 = 콜히친(L16a 기계 수화기는 건드리지 않는다).

## L16a — 전화 교환국

### 〈L16a · s7 · Gs〉 — 안 1 (그림)
- 물건(일상 낱말 하나): 에스프레소(김 나는 손잡이 달린 작은 흰 잔)
- 사건: 칩을 뒤집으며 달리는 지게꾼이 다른 손으로 에스프레소 한 잔을 입에 탁 털어 넣고, 신이 나서 기계로 뛰어간다.
- 고리: ① — 「Gs(지-에스)는 지게의 지 + **에스**프레소의 에스처럼 들린다」. 덤: 에스프레소 안의 「프레스」 = 다음 과들의 금색 압착기(고리화효소) — 켜러 가는 쪽.
- 낭독에 넣을 한 문장: 「지게꾼이 에스프레소를 털어 넣고 기계로 달린다 — 지게의 지, 에스프레소의 에스, 고리화효소를 켜는 Gs 다.」
- 자리와 크기: s7 지게꾼의 멜빵 잡은 왼손 자리 — 손을 들어 입가로. 잔 + 김 + 손을 합쳐 짧은 변 110 px 이상(2048 기준). 잔은 실제보다 크게.
- 그림에서 바뀌는 것 / 그대로 두는 것: 왼손 자세와 잔만 바뀜 / 지게 · 칩 뒤집기 · 달리는 방향 · 기계는 그대로.
- 예약 확인: 에스프레소 · 커피 → 임자 없음 · 잔 → 갈색 민짜 잔(푸코잔틴) · 받침 위 잔(트로피) → 흰 도자기 · 손잡이 · **받침 접시 없이 손에 든** 잔으로 갈림.
- 혼동쌍: Gi(아이) · Gq(큐대) — 지게꾼이 「무엇을 들었나」로 갈림. 잔 = 「마신다 · 켠다」, 아이 = 「붙든다 · 끈다」.
- 붐빔: 새 물건 +1(잔). 이미 있는 지게꾼에 얹는다.
- 오독 위험과 약점: 그림만 보면 「커피」라 부를 것 — 커피에는 소리가 없다. 「에스프레소」라는 이름은 낭독이 한 번 붙여 줘야 선다. 작은 잔을 키우면 「머그」로 읽힐 위험.

### 〈L16a · s7 · Gs〉 — 안 2 (글)
- 물건: 지게꾼의 전력 질주(스프린트)
- 사건: 지게꾼이 칩을 뒤집으며 기계까지 내달린다(지금 그림 그대로).
- 고리: ① 은 못 되고 둘째 — 「Gs 의 에스(s)는 기계로 **스**프린트하는 지게꾼」(끝소리 스만 겹침). 하는 일(켜러 달려감)과 방향은 맞다.
- 낭독 한 문장: 「웃으며 기계로 스프린트하는 이 지게꾼이 고리화효소를 켜는 Gs, 지-에스다.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 없음 / 전부.
- 예약 확인: 스프린트 — 찾지 않음(그림에 물건이 생기지 않으므로); 스위치는 DHP 예약이라 버림.
- 혼동쌍: s8 주저앉은 지게꾼(GTP 가수분해) — 달리는 쪽만 Gs.
- 붐빔: 0.
- 오독 위험과 약점: 약하다. 「달린다」는 하는 일만 그린 것에 가깝고 독자가 「스프린트」라는 낱말을 떠올리지 않는다. 안 1 을 먼저.

### 〈L16a · s7 · Gi〉 — 안 1 (글)
- 물건: 지게(독자가 「의자」라 부른 그것)
- 사건: (그림 그대로) — 낭독이 갈래를 말할 때 「아이가 진 작은 지게」를 다음 과에서 만나라고 예고.
- 고리: ① — 「Gi(지-아이)는 지게 진 **아이**, 꼬마 지게꾼처럼 들린다」.
- 낭독 한 문장: 「갈래가 하나 더 있다 — 지게를 진 아이, 지-아이 Gi 는 기계를 켜는 게 아니라 매달려 붙들어 끈다. 아세틸콜린 · 아드레날린 방에서 만난다.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 없음 / 전부.
- 예약 확인: 어린이 → 임자 없음 · 아이 → 아기류 예약 여럿(지게 없는 아기들).
- 혼동쌍: Gs 에스프레소 지게꾼 — 어른 / 아이 · 켬 / 붙듦.
- 붐빔: 0.
- 오독 위험과 약점: 이 판에서는 그림에 기댈 물건이 없다 — 낭독 예고뿐. L16a 는 총론이라 갈래 셋을 한 지게꾼에 얹으면 「켜면서 끄는」 꼴이 되어 사실과 어긋나므로, 이 판은 글로만 두는 쪽이 맞다고 본다.

### 〈L16a · s7 · Gi〉 — 안 2 (그림)
- 물건: 아이(작은 나무 지게를 진 꼬마 지게꾼)
- 사건: 기계 오른쪽 옆구리에서 꼬마 지게꾼이 기계 앞판의 큰 손잡이에 매달려 아래로 붙든다 — 어른 지게꾼이 켜러 오는 기계를 꼬마는 붙들어 멈춘다.
- 고리: ① — 「지-아이는 지게 진 아이처럼 들린다」.
- 낭독 한 문장: 「기계에 매달린 꼬마 지게꾼은 지-아이, Gi — 고리화효소를 끄는 갈래다.」
- 자리와 크기: s7 오른쪽 끝 기계 옆구리(수화기에서 떨어진 아래쪽) · 아이 키 = 어른 지게꾼의 절반 · 짧은 변 130 px 안팎.
- 바뀌는 것 / 그대로: 아이 +1 / 기계 · 수화기 · 지게꾼 그대로.
- 예약 확인: 위 표. 수화기 → 인터폰(인터페론) · 나무 전화기(콜히친) 예약 — 아이가 **수화기를 만지지 않게**.
- 혼동쌍: s8 주저앉은 지게꾼(스스로 꺼짐 = GTP 가수분해)과 — 「꺼짐」이 둘이 되어 섞일 수 있음. 아이는 **효소를** 붙들고, 주저앉은 이는 **제 칩을** 튕긴다.
- 붐빔: +1 사람. 오른쪽 아래가 이미 붐빈다(주저앉은 지게꾼 · 칩 · 접힌 의자).
- 오독 위험과 약점: 한 기계에 켜는 이와 끄는 이가 함께 있으면 「같은 G 가 켜고 끈다」로 읽힌다. 권하지 않는 쪽.

### 〈L16a · s7 · Gq〉 — 안 1 (글)
- 물건: 지게(지겟작대기 자리)
- 사건: (그림 그대로) — 낭독이 「지겟작대기 대신 큐대를 짚는 지게꾼」을 다음 과에서 만나라고 예고.
- 고리: ① — 「Gq(지-큐)는 지게 + 당구 **큐**대」.
- 낭독 한 문장: 「지겟작대기 대신 당구 큐대를 짚은 지게꾼, 지-큐 Gq 는 피자 커터 PLC 를 친다.」
- 자리와 크기: 그림 그대로.
- 바뀌는 것 / 그대로: 없음 / 전부.
- 예약 확인: 큐대 · 큐 · 지큐 → 임자 없음 · 작대기 → 임자 없음.
- 혼동쌍: Gs(잔) · Gi(아이).
- 붐빔: 0.
- 오독 위험과 약점: L16a 에는 피자 커터가 없어 사건이 서지 않는다 — 예고뿐.

### 〈L16a · s7 · Gq〉 — 안 2 (그림)
- 물건: 큐대(당구 큐)
- 사건: 지게꾼의 지게 옆구리에 지겟작대기처럼 큐대 한 자루가 꽂혀 있다.
- 고리: ① — 「지-큐는 지게에 꽂은 큐대처럼 들린다」.
- 낭독 한 문장: 「지게에 꽂힌 큐대 — 지-큐, Gq 갈래도 있다.」
- 자리와 크기: 지게 오른쪽 기둥을 따라 비스듬히 · 길이는 지게보다 조금 길게 · 짧은 변(굵기)은 가늘어서 110 px 조건을 못 채움 → 큐대 끝의 흰 팁과 굵은 손잡이 쪽을 크게.
- 바뀌는 것 / 그대로: 큐대 +1 / 나머지 그대로.
- 예약 확인: 위와 같음. 당구 → 당구장 세계(해당과정) — 큐대 하나만, 당구공 · 초록 당구대는 그리지 않는다.
- 혼동쌍: 안 1 의 에스프레소와 한 지게꾼에 겹치면 Gs 이자 Gq 가 됨 — **둘 중 하나만**.
- 붐빔: +1.
- 오독 위험과 약점: 독자가 이미 지게를 「사다리」로 보는데 막대를 하나 더 붙이면 사다리 느낌이 더 세진다(DNA 사다리 예약과 섞일 위험). 권하지 않음.

## L23b — 똑같은 열쇠 둘(무스카린성)

### 〈L23b · s6 · Gi〉 — 안 1 (그림)
- 물건: 아이(작은 나무 지게를 진 꼬마 지게꾼)
- 사건: 갈림길에서 꼬마 지게꾼이 위층 계단을 깡충깡충 올라 자물쇠 걸린 압착기 쪽으로 간다 — 어른 지게꾼(G 총칭)은 그대로 달려오고, 위층 갈래를 맡는 것은 꼬마다.
- 고리: ① — 「Gi(지-아이)는 지게 진 아이처럼 들린다」.
- 낭독 한 문장: 「위층 계단을 오르는 꼬마 지게꾼이 지-아이, Gi 다 — 위층 프레스를 붙들어 멈추러 간다.」
- 자리와 크기: s6 오른쪽 계단 중턱(지금 빈 계단) · 짧은 변 120 px 이상 · 등 뒤 작은 지게가 또렷해야 함.
- 바뀌는 것 / 그대로: 계단 위 아이 +1 / 지게꾼 · 칩 · 복도 · 계단 · 압착기 그대로.
- 예약 확인: 어린이 · 아이 · 꼬마(위 표) · 손가락 → M₂ 두 손가락 예약 바로 곁이므로 **아이의 손은 주먹이나 계단 손잡이를 쥔 꼴로, 손가락을 펴지 않는다**.
- 혼동쌍: Gq(아래 복도의 큐대). 위 = 아이, 아래 = 큐대 — 「자리만으로 가른 것」이 아니라 물건이 다르다.
- 붐빔: +1 사람. 계단은 지금 비어 있어 자리는 있다.
- 오독 위험과 약점: 작게 그리면 「아이」로만 보이고 지게가 안 보여 지 소리가 빠진다. M₂ 「두 손가락」 손이 바로 옆이라 아이 손과 섞이지 않게.

### 〈L23b · s6 · Gi〉 — 안 2 (글)
- 물건: 지게(독자 이름: 「의자」)
- 사건: (그림 그대로) 어른 지게꾼이 갈림길로 달린다.
- 고리: 둘째 — 「지게를 의자로 본 독자에게: 의자의 『의』 → 이(i)」. 첫 음절이 「의」라 「이」와 소리 겹침이 어설프다.

- 고리: ① + ② — 「지-티는 지게꾼의 **티**셔츠, 펼친 반팔 셔츠는 생김도 T 자」.
- 낭독 한 문장: 「흰 티셔츠 지게꾼이 트램펄린에서 튄다 — 지-티, Gt 트랜스듀신.」
- 자리와 크기: s8 공중의 지게꾼 몸통 · 셔츠 짧은 변 110 px 이상(지금 몸통 크기 그대로면 모자람 → 지게꾼을 조금 키움).
- 바뀌는 것 / 그대로: 웃옷 빛깔 · 소매 / 지게 · 칩 뒤집기 · 트램펄린 · 로프 매듭 그대로.
- 예약 확인: 티셔츠 → lac 문지기 검정 · trp 문지기 초록 · PYY 쌍둥이 노랑 — **흰 반팔**은 비어 있음 · 티 → 티백(티아지드)은 쓰지 않음 · 반팔 → 임자 없음.
- 혼동쌍: PYY(두 팔을 위로 = Y) — 팔은 **수평**으로 뻗어 T. L16a · L23b 지게꾼은 긴팔로 남겨 갈래를 가른다.
- 붐빔: 0(옷만 바뀜).
- 오독 위험과 약점: 옷은 독자가 이름 부를 「물건」으로 잘 안 잡힌다 — 「남자」라고만 말할 위험. 대머리 + 흰 반팔이 lac 문지기(검은 티셔츠 대머리)와 닮아 보일 수 있다 → 머리카락을 그리는 쪽이 안전.

### 〈L15a · s8 · Gs〉 — 안 1 (글)
- 물건: 지게꾼의 빈손(잔이 없음) + 가위(s9, 지금 그림)
- 사건: (그림 그대로) 트램펄린 지게꾼은 칩만 쥐고, 그 아래 일꾼이 가위로 회색 고리를 자른다.
- 고리: ① 짝 — 「에스프레소 지게꾼(Gs)은 프레스(금색 압착기)로 가고, 이 티셔츠 · 트램펄린 지게꾼(Gt)은 가위로 간다」.
- 낭독 한 문장: 「이 지게꾼 손엔 에스프레소가 없다 — 프레스를 돌려 cAMP 를 늘리는 Gs 가 아니라, 가위로 cGMP 를 자르는 Gt 다.」
- 자리 / 바뀌는 것: 없음.
- 예약 확인: 가위 · 회색 고리 → 이 판에서 PDE · cGMP(같은 뜻, 건드리지 않음).
- 혼동쌍: 금빛 고리(cAMP · 압착기가 뱉음) ↔ 회색 고리(cGMP · 가위가 자름) — 이미 빛깔과 연장으로 갈려 있다.
- 붐빔: 0.
- 오독 위험과 약점: 「없는 물건」으로 떠올리는 대조라 그림만으로는 안 나온다. 카드 S-SG-9 · S-SG-10 의 물음(왜 갈리나)에는 맞는 꼴.

### 〈L15a · s8 · Gs〉 — 안 2 (그림)
- 물건: 에스프레소 잔(엎어진 것)
- 사건: 트램펄린 선반 끝에 에스프레소 잔이 엎어져 식어 있다(김 없음) — 이 극장에서는 에스프레소(Gs)가 안 쓰인다.
- 고리: ① — 「에스프레소 = Gs」, 엎어짐 = 「여기서는 아니다」.
- 낭독 한 문장: 「선반 끝에 엎어진 에스프레소 — Gs 는 이 극장 몫이 아니다, 여기선 트램펄린 Gt.」
- 자리와 크기: s8 선반 오른쪽 끝 · 짧은 변 110 px.
- 바뀌는 것 / 그대로: 잔 +1 / 트램펄린 · 지게꾼 · 로프 그대로.
- 예약 확인: 에스프레소 → 임자 없음 · 「여기서는 안 쓴다」는 덱에서 **못에 걸고 널빤지 가위표**가 예약 — 엎어진 잔은 그 약속과 다른 꼴이라 문법이 둘이 된다.
- 혼동쌍: 회색 고리 통(s3 · s10)과 가까우면 「잔 = 통」으로 섞임.
- 붐빔: +1.
- 오독 위험과 약점: 그림에 Gs 물건이 있으면 「Gs 가 관여한다」로 읽힐 수 있다 — 사실과 반대로 끌 위험이 있어 **권하지 않음**. 써야 한다면 덱의 「못 + 널빤지 가위표」 꼴로 거는 편이 일관된다(그 경우도 붐빔 +2).

## 과 전체 — 한 사건으로 엮으면

1. 지게꾼(지 = G)이 무엇을 지니느냐가 둘째 글자다: **에스프레소 = Gs · 아이 = Gi · 큐대 = Gq · 티셔츠 + 트램펄린 = Gt** — 네 과 어디서나 같은 물건 · 같은 꼴.
2. L16a(총론): 에스프레소를 털어 넣은 지게꾼이 기계로 달린다(Gs 한 그림) · 아이와 큐대는 낭독 예고만 — 한 지게꾼에 갈래 셋을 얹지 않는다.
3. L23b: 갈림길에서 꼬마 지게꾼(Gi)이 위층으로 올라 자물쇠 프레스에 매달리고, 아래 복도엔 큐대(Gq)가 피자 커터를 친다.
4. L23c: α₁ 방 큐대가 커터를 치고(Gq) · α₂ 방 프레스엔 꼬마가 앉고(Gi) · β 방 프레스 곁엔 에스프레소(Gs) — 「에스 + 프레스 = 에스프레소」라 Gs 는 늘 프레스(고리화효소) 곁에만 선다.
5. L15a: 흰 티셔츠 지게꾼이 트램펄린(트)에서 튀어 가위(PDE) 쪽으로 — 에스프레소가 없으니 프레스가 아니라 가위.
