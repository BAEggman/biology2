# r2_라 — 렌즈: 기호 재사용 · 그림 간 연결 (일감 1123_내분비_이름 · 재공모)

> 방침: 덱에 이미 있는 문법을 같은 뜻으로 다시 쓴다. 새로 쓴 문법은 하나도 없다 — ① 흰 낙하산 = -RH(짐 = 표적) ② T = 「티」(티백 · 티셔츠) ③ 글자 소품 = 글자사전(A 사다리 · C 갈고리) ④ 에그컵 달걀 = FSH · 달걀 둘 = 생식샘 ⑤ 양철 로봇 = 테스토스테론(몸 그대로).
> reserved.py 로 찾다가 **막힌 길**(다른 안이 같은 길로 가지 않도록 먼저 적는다): 에이스 카드(DnaA 전용 · 「다른 판에서 새로 쓰지 말 것」 → ACTH 불가) · 지게 · 지게꾼(= G단백질/GPCR 전용 → GnRH 불가) · 지팡이(DnaG) · 지프(GIP) · 지휘자(L15a 등 사용) · 진자(= 심장 박동, 시계 예약) · 크레인(RdRp) · 왕관(코로나 · AUG 황제 · IgM 금지) · 코르크 마개(코르티솔) · 에스컬레이터(근소포체 Ca²⁺ 회수) · 시험지(= 산성 H⁺) · F 꼴 장대(F 인자 · E2F 둘뿐).

### 〈L07b s1 · L07d s2 · ACTH〉 — 안 1
- 길(글 / 그림): 그림 — 작은 새 소품 하나(덱의 A 문법 재사용)
- 물건(일상 낱말 하나): A자 접이 사다리
- 사건: 에이(A) 사다리가 층층 케이크(부신피질)를 딛고 올라 맨 위 층 가장자리에 닿는다 — 피질을 타고 올라가 키운다.
- 고리(종류): ② 「A 는 A자로 벌어진 접이 사다리처럼 생겼다」 — 덱의 글자사전 A(PKA · IgA · CENP-A · 비타민 A …)와 같은 꼴. 소리 ① 은 못 낸다(독자가 부르는 이름은 「사다리」). 이름 뜻 ④ 는 케이크(= 부신피질 · 기존 ③)가 맡는다.
- 낭독에 넣을 한 문장: 케이크를 타고 오르는 A 사다리 — 에이, ACTH 다.
- 자리와 크기: L07b 창2 — 케이크 접시 위, 케이크 뒤에 기대 세운다(윗부분이 케이크 위 빈 유리 칸으로 솟음). 밑폭 ≥ 75 px@1400(= 110 px@2048), 높이 어림 100 px@1400. 창구원 · 케이크 · 손가락은 그대로. L07d s2 — 오른쪽 벽 밖 초록 호스의 두 번째 굽이 위에 딛고 서서 맨 위층 가는 관 쪽으로 기댄다(호스 = ACTH 이므로 같은 개념에 이름만 얹는다 · 옥상 X 팻말과 멀리, 오른쪽 아래 바람과도 멀리).
- 그림에서 바뀌는 것 / 그대로 두는 것: 사다리 한 개 추가 / 케이크 · 창구원 · 호스 · 가는 관 · 굵은 관 전부 그대로.
- 예약 확인(찾은 낱말과 결과): 「에이스」 → 에이스 카드 = DnaA 전용 · 「다른 판에서 새로 쓰지 말 것」(ACE 가 이미 한 번 빌림) → 안 씀. 「사다리」 → 글자사전 A = A자 접이 사다리, 일곱 곳(전화국 바닥 · 벽 셋째 자리 · 짚 꿴 통 위 · 가로등 · 인형집 지붕 · 매달린 갈고리 밑 · 샘가). 같은 글자라 같은 꼴을 쓰고, 「딛고 선 것」이 가른다 → 이번 것은 「케이크 접시/호스」. 「에어 · 에이프런 · 에이드 · 액트 · 에이포 · 에이컵」 → 임자 없음이나 에어컨류는 식힘(반대 방향)이고 나머지는 독자가 그 소리로 못 부른다. 「케이크」 → 층층 케이크 = 부신피질 전용(L07b#3 · L07e#3) — 같은 뜻으로만 쓴다.
- 혼동쌍: CRH(C 갈고리가 걸린 낙하산 케이크)와 글자(A/C)와 자리(창 안/낙하산)로 갈린다. 코르티솔(L07d 코르크 마개)과는 케이크 대 코르크로 갈린다.
- 붐빔(새로 느는 물건 수 · 이미 있는 소품에 얹을 수 있는가): 두 정거장에 각 +1. 기존 소품에 뜻을 얹지 않는다(새 소품).
- 오독 위험과 스스로 본 약점: ① 「에이」로 곧장 불리는 물건이 아니다 — 심판이 말한 ① 에는 못 닿는다. 에이스 카드가 막혀 있어 그 길은 포기했다. ② 「사다리 = 올라간다」는 읽히지만 「키운다」까지는 낭독이 시켜야 한다. ③ 창2 의 좌우에 빈 자리가 없어 케이크 뒤 · 위로 솟게 해야 한다.

### 〈L07b s1 · L07d s2 · ACTH〉 — 안 2
- 길: 글 — **내 렌즈에서는 낼 안이 없다.** 이미 그려져 있고 독자가 부른 이름(바나나 · 놋쇠 종 · 수도꼭지 · 초록 호스 · 정원 호스 · 케이크)에 「에이」로 시작하는 것이 없다. 호스를 H(호스)로 읽어도 ACTH 의 마지막 글자뿐이다.
- 물건 · 사건 · 고리: 해당 없음. (참고로만: 기존 고리 「층층 케이크(③)」는 그대로 둔다.)
- 오독 위험과 스스로 본 약점: 지어낸 안을 억지로 내지 않았다.

### 〈L07b s3 · L07c s4 · L07e s1 · TRH〉 — 안 1
- 길(글 / 그림): 그림 — 작은 새 소품 하나 + 기존 낙하산 문법
- 물건: 티아라(은빛 작은 아치 · 뾰족 셋 · 보석 하나. 머리에 쓰지 않고 매달리거나 놓인다)
- 사건: 위에서 흰 낙하산이 티아라를 매달고 내려와 티셔츠 창구원의 창턱에 내려앉는다 — 위(시상하부, 「머리」)에서 전엽으로 내려보낸다.
- 고리: ① 「티아라는 티알(TR)처럼 들린다」 — T 는 덱의 「티」(티백 · 티셔츠)와 같은 문법이고, 아라 ≈ R. 낙하산 = R(방출 · 위에서 아래로)은 덱 정본 그대로. 티아라 = 머리 장식 = 「머리 = 시상하부」.
- 낭독에 넣을 한 문장: 낙하산이 티아라를 내려보낸다 — 티아라, TRH 다.
- 자리와 크기: L07b 창1 — 창턱의 나비 판 곁(창구원 입은 흰 티셔츠는 TSH 정본 그대로). 낙하산 지붕은 흰색 40 px, 티아라 폭 80 · 높이 75 px@1400(≥ 110 px@2048 짧은 변). 창1 의 물건 = 나비 판 · 티셔츠 · 티아라 낙하산, 셋 이내. 나비는 더 그리지 않는다. L07e s1 — 첫 낙하산 짐 = 나비 판 위에 같은 티아라를 얹는다(나비 판은 기존 갑상샘 뜻, 티아라가 이름). **짐을 키우는 법**: 지금 짐은 짧은 변이 ~58 px@2048 이라 이미 모자라다. 유리 관 구간을 아래로 40 px@1400 늘리고(점원 머리와 겹치는 가운데 구간은 좁게) 낙하산 지붕을 줄여 짐 짧은 변 ≥ 75 px@1400 로 맞춘다. L07c s4 — 그림 변경 없이 낭독에서만 L07b 의 티아라를 부른다.
- 그림에서 바뀌는 것 / 그대로 두는 것: 티아라 두 곳 + L07b 낙하산 한 개 / 나비 판 · 티셔츠 · 손가락질 · 관 · 붉은 관 전부 그대로.
- 예약 확인: 「티아라」 → 임자 없음. 「모자」 → 5′캡 전용이라 머리에 씌우지 않는다. 「왕관」 → 금빛 왕관(코로나) · 월계관(AUG) · IgM 왕관 금지 → 은빛 · 작은 아치 · 보석으로 갈린다. 「티백」 → 티아지드, 「티셔츠」 → TSH 정본(같은 T = 티 문법, 다른 물건 · 다른 둘째 음절). 「낙하산」 → -RH 전용, 짐은 앞 글자 — 같은 뜻. 「나비」 → 갑상샘 판만 허용 — 새 나비 없음.
- 혼동쌍: TSH(입은 흰 티셔츠)와 「입은 것 / 내려오는 것」으로 갈린다. T3 · T4(L07c)와는 코트 · 결정 개수로 갈린다.
- 붐빔: +1(L07b), 낙하산 지붕은 기존 문법. 기존 소품에 뜻을 얹지 않는다.
- 오독 위험과 스스로 본 약점: 티아라 = 걸그룹 이름이 연상될 수 있어 그림에 표시를 일절 달지 않고 낭독도 일반명사로만 쓴다. 「티」 소리가 TSH 와 같아 헷갈릴 수 있다. L51a 유모의 흰 머리띠와 같은 정거장 안이 아니라 괜찮지만 은빛 아치로 갈라 둔다. 판정: TRH 는 새 물건이 없어도 되는 낱말이 아니라고 보지만 붐빔 값(창1)이 크다.

### 〈L07e s1 · CRH〉 — 안 1
- 길: 그림 — 작은 새 소품 하나(덱의 C 문법 재사용)
- 물건: C자 갈고리(놋쇠 · 큰 C 한 개)
- 사건: 낙하산 줄 끝의 큰 C 갈고리가 층층 케이크 접시 테두리를 걸어 아래로 내려보낸다 — 방출(R) + 케이크(피질).
- 고리: ② 「C 는 C자로 굽은 갈고리처럼 생겼다」(글자사전 C: PKC · 비타민 C · C형 간염 · CCA). 케이크 = C = cortex(기존 ③).
- 낭독에 넣을 한 문장: C 갈고리에 걸려 내려온 케이크 — 씨, CRH 다.
- 자리와 크기: L07e 둘째(가운데) 낙하산 — 줄 아래 케이크 사이. 갈고리 높이 75 px@1400(= 110 px@2048), 놋쇠색이라 흰 낙하산 · 하늘색 관 안에서 구별된다. 관 키우기는 TRH 안 1 과 같다(한 번의 구역 편집으로 셋 모두).
- 그림에서 바뀌는 것 / 그대로 두는 것: 갈고리 한 개 / 케이크 · 낙하산 · 점원 · 카운터 케이크 그대로.
- 예약 확인: 「C자/갈고리」 → 글자사전 C 와 같은 꼴(딛고 선 곳/걸린 것이 가름: 이번엔 낙하산 줄 끝 + 케이크 접시). 「코르크」 → 코르티솔 전용이라 안 씀. 「케이크」 → 부신피질 전용(같은 뜻). 「크레인」 → RdRp 전용이라 팔 · 도르래 없이 갈고리만. 「크림 · 시리얼」 → 음식은 심판 ③ 에 걸려 안 씀. 「씨알 · 시소 · 크라운」 → 시소 · 크라운은 임자 없으나 소리가 「씨알」이 아니고, 크라운은 왕관 예약과 겹친다.
- 혼동쌍: ACTH(A 사다리)와 글자로, 비타민 C 정비사(L12e)와 자리로 갈린다.
- 붐빔: +1.
- 오독 위험과 스스로 본 약점: 심판이 말한 「철자로만 C-R 인 것은 낮다」에 정확히 걸린다 — 독자가 부르는 이름은 「갈고리」다. 「씨알」로 곧장 불리는 일상 물건은 이 덱에서 찾지 못했다(시리얼은 음식, 크라운은 왕관 예약).

### 〈L07b s5 · L07e s1 · GnRH〉 — 안 1
- 길: 그림 — 작은 새 소품 하나
- 물건: 지구본(탁상용 작은 것)
- 사건: 흰 낙하산 하나가 지구본을 매달고 내려오고, 리본 맨 달걀 둘이 그 양옆에 한 짝으로 매달려 있다 — 한 지시가 둘을 함께 나른다.
- 고리: ① 「지구본은 지(G)로 시작한다」 — 덱의 「지 = G」 문법(지팡이 = DnaG · 지프 = GIP)과 같은 읽기. 둘째 음절 이하는 못 낸다.

## 과 전체 — 네 안들을 한 사건으로 엮으면 (≤ 5줄)
1. 시설 옥상 관제탑이 파이프로 낙하산 셋을 내려보낸다: 티아라 얹은 나비 · C 갈고리에 걸린 케이크 · 지구본 곁의 리본 단 달걀 둘.
2. 첫 낙하산(티아라)은 L07b 창1 에도 내려앉아 티셔츠 창구원 앞에 닿는다 — TRH → TSH 가 한 장면으로 이어진다.
3. 창2 의 케이크에는 A 사다리가 올라타고(ACTH), 창3 · 창4 에는 퍼스트 달걀(FSH)과 엘리베이터 칸에 탄 달걀(LH)이 서로 갈린다.
4. 아래 방에서는 액자 낙서 대신 실물 로봇이 테스터를 물고 서고, 같은 테스터가 L51a 조립대 로봇에도 물려 있다 — 로봇 = 테스토스테론이 두 과에서 같은 꼴.
5. 이 렌즈의 한계: 소리 ① 으로 닿은 것은 티아라 · 테스터 · 엘리베이터뿐이고, ACTH · CRH · GnRH 는 글자 소품(②) 또는 약한 소리 손잡이에 머문다.
