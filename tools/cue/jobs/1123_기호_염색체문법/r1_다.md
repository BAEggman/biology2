# r1_다 — 염색체 그림 문법 · 렌즈: 사건 연출(동작을 하는 물건 + 단계마다 한 줄 소동)

## 0. 그림에서 직접 본 병(열한 과 full.jpg + L48a s6 · s9 · L48b s4 · L48f s10 · s11 · L48g s5 · L19c s7)
1. **빛깔이 과마다 다른 뜻을 나른다.** L48a · L48b 는 금빛 ↔ 초록 = 「서로 다른 염색체 둘(부모 구분 없음)」(L48a 낭독 · hooks 예약 주석 그대로)인데, L48f · L48g 는 남색 ↔ 하늘색 = 「아버지 쪽 ↔ 어머니 쪽(상동)」이고 다른 염색체는 **키**로 가른다. 독자는 L48a 의 금 · 초록을 상동 한 쌍으로도, 다른 염색체 둘로도 읽을 수 있다.
2. **체세포분열 중기(L48a s6)와 감수 2분열 중기가 똑같이 생겼다.** L48a 셋째 칸 = 점선 위 X 둘(서로 다른 염색체) 세로 한 줄 · 양쪽 밧줄. 감수 2분열(L48g s4 → s5)도 X 둘(키가 다른 것 하나씩) → 한 줄 → 자매 분리. 2n 세포를 그린 L48a 가 사실상 n=2 세포처럼 생겨서 시험의 제일 큰 혼동쌍(체세포 중기 ↔ 감수 II 중기)이 그림에서 갈리지 않는다.
3. **밧줄이 매이는 자리가 과마다 다르다.** L19h 는 쇠판 + 바깥으로 휜 걸쇠(동원체)에만 밧줄 · 「짚에는 아무 데도 감기지 않았다」. 그런데 L48f s10 · s11 · L48g s5 는 밧줄이 짚단 **허리를 감은 고리**에 매이고, 그 허리 고리가 동시에 「남은 코헤신」 뜻도 진다(한 물건에 뜻 둘). L48a s6 은 짚 끈 감김 + 작은 고리. L48a s9 · L48b 는 걸쇠.
4. **코헤신이 어떤 과에선 있고 어떤 과에선 없다.** L19c · L19h · L48f s11 · L48g s5 = 은빛 C 고리. L48a(중기 · 후기 모두)엔 은빛 고리가 없고 허리를 밧줄로 묶었다(예약 주석도 「L48a 짚단 허리는 밧줄로 묶였다」). L37a s10 의 X 도 짚끈으로 동여맴.
5. **재질이 다르다.** L19c 바닥의 자매 두 다발은 짚이 아니라 **갈색 나무 막대 다발**. 짚 세계 밖으로 나간다.
6. **외다발(염색분체 하나)의 꼴이 둘.** L48a s9 · L48b = 가운데가 꺾인 V. L48g s5 = 곧은 다발 허리 묶음. (꼴은 달라도 「다발 하나」로 세면 되게 문법을 짠다 — 아래 셈 규칙.)
7. 맞게 된 것: L48f · L48g 의 남색 모자 / 하늘색 면사포(상동) · 큰 쌍 / 작은 쌍(서로 다른 염색체) · 중매쟁이 띠(접합) · 은빛 C 조각(코헤신 분해) · L19h 의 허리 · 쇠판 · 걸쇠 · L35c s16 「끈으로 묶인 자루 둘 + 홀로 하나」(짝지은 상동 + 짝 없음) · L36b 「자루 하나 = n」 · L05b 「천막 = 핵」. → 이것들을 **문법의 뼈대**로 삼고, 어긋난 L48a · L48b · L19c · L48f 허리 · L48g 허리를 그쪽으로 끌어온다.

## 1. 사건 사전 — 동작이 곧 뜻(이 렌즈의 핵심)
「하는 일만 그린 것은 고리가 아니다」는 이름 고리의 잣대다. 이 문법에서 **사건(동작)은 이름 고리가 아니라 혼동쌍을 가르는 칼**이다. 이름 고리는 따로(표의 「부르는 말」 · §6) 물건에 단다. 사건은 셋뿐이고, 셋이 덱 어디서나 같은 동작이다.

| 사건 | 하는 물건 · 동작 | 무엇이 갈라지나 | 어디서 |
|---|---|---|---|
| **① 혼례(짝 묶기)** | 중매쟁이가 **천 띠**로 같은 키의 남색 · 하늘색 짚단을 칭칭 감아 한 덩이로 | 상동끼리 짝(접합 · 접합사) | 감수 I 전기에만(L48f s3 · s4). 체세포분열 · 감수 II 에는 **혼례가 없다** |
| **② 이혼 줄다리기(부부 째로 끌려감)** | 짚단마다 **한쪽 벽 밧줄 하나** · 부부가 통째로 반대쪽으로 끌려가고 **팔의 은빛 고리만 팅** · 허리 고리는 남아 가랑이는 멀쩡 | 상동 분리(환원 · 2n → n · 복제된 채) | 감수 I 후기에만(L48f s11) |
| **③ 다리 찢기(가랑이가 찢어짐)** | X 짚단 하나가 **양쪽 벽 밧줄 둘**에 허리를 잡혀 · 마지막 허리 은빛 고리가 「팅」 튀며 두 다발이 **외다발 둘**로 쪼개져 반대쪽으로 | 자매 분리(동형 · 수 그대로) | 체세포분열 후기(L48a s9) **와** 감수 II 후기(L48g s5) — 같은 소동 = 시험의 「공통점」(C1-100~101) |

곁 사건(문법 보조):
- **동여매기 ↔ 풀어헤치기**: 천막(핵막)이 찢어지면 가는 실(염색질)이 허둥지둥 허리를 동여매 짚단(염색체)이 되고, 새 천막 밑에 들어가면 다시 가는 실로 풀린다(L48a s2 → s10 · L48f s2 · L48g s2 · s6 이미 그렇다).
- **분신(복제 · S기)**: 한 다발이 제 곁에 똑같은 다발을 하나 꼬아 내고 둘을 **은빛 고리 하나**에 꿴다 → 다발 하나가 X 로. 이 사건을 그린 그림은 덱에 지금 없다(L19a 는 반죽 덩이 세계) — 글로만 부르고, 그림은 §4 L19a 선택 안.

**줄 규칙(한 줄로 외움)**: 「줄이 **양쪽**에서 오면 가랑이가 찢기고(자매), **한쪽**에서만 오면 부부가 갈린다(상동).」 — 생물학: 체세포 · 감수 II 는 자매 동원체가 양극을 봄(양극 부착) · 감수 I 은 자매 동원체가 같은 극을 봄(단극 부착).

## 2. 문법 표 — 뜻 | 꼴 | 부르는 말

| 뜻 | 꼴(물건 · 빛깔 · 크기 · 수) | 부르는 말(낭독에서 한 번) |
|---|---|---|
| **DNA · 염색질(풀린 상태)** | 금빛 짚끈 / 국수 가락처럼 가는 짚 실 — 묶이지 않고 흩어짐 · 늘 **천막(핵) 안이나 천막이 막 생기는 밑** | 「풀린 실 = 염색질」 |
| **염색체(응축)** | 허리가 잘록한 **짚단** — 천막이 찢어진 뒤에만 보인다 | 「동여맨 짚단 = 염색체」 |
| **복제 전 염색체(염색분체 하나)** | **외다발** — 다발 하나 · 허리 하나(끌려가는 중엔 V 로 꺾여도 다발 하나) · 은빛 고리 없음 | 「외다발 = 한 가닥」 |
| **복제된 염색체(염색분체 둘)** | **X 짚단** — 같은 빛깔 · 같은 키의 다발 둘이 허리에서 엇걸리고 허리 바로 아래 **은빛 C 고리 하나**에 꿰임 | 「X = 두 가닥 · 염색체는 하나」(C1-69) |
| **자매염색분체** | 한 X 의 **두 다발** — 빛깔 · 키 · 모자(면사포)가 같다(한 부모) · 은빛 쇠 고리로 엮임 | 「한 고리에 꿴 같은 옷 두 다발 = 자매(같은 부모에게서 난 똑같은 둘)」(C1-94) |
| **상동염색체** | **같은 키 · 같은 허리 자리**의 남색(검은 실크해트 · 아버지 쪽) 짚단과 하늘색(흰 면사포 · 어머니 쪽) 짚단 한 쌍 — 엮일 때는 쇠 고리가 아니라 **천 띠**로(접합 때만) | 「키 같은 부부 = 상동(서로 같은 꼴 · 다른 집안)」(D0-14~16) |
| **서로 다른 염색체(비상동)** | **키**가 다르다 — 큰 쌍 / 작은 쌍(빛깔로 가르지 않는다) | 「키가 다르면 남남」 |
| **아버지 쪽 / 어머니 쪽** | 빛깔 남색 / 하늘색(주) + 실크해트 / 면사포(사람 꼴로 그린 곳 · 크기가 되는 곳) — 외다발이 되어도 제 빛깔 · 제 모자 | 「모자는 아빠 · 면사포는 엄마」 |
| **중심절(DNA 부위)** | 짚 **자체가 서로 꼬여** 잘록해진 허리 — 덧붙인 물건 없음(짚 = DNA) | 「허리의 꼬임 = 중심절 · 짚이니 DNA」(C1-11) |
| **동원체(단백질 복합체)** | 허리 바깥 면에 볼트로 박은 **납작한 쇠판 + 바깥으로 휜 걸쇠** — 밧줄은 **여기에만** 매인다. 체세포 · 감수 II 의 X 는 쇠판 둘(양쪽) · 감수 I 의 X 는 자기 벽 쪽 걸쇠에만 밧줄 | 「쇠판 = 동원체 · 쇠니 단백질 · 밧줄이 매이는 곳」(C1-11) |
| **코헤신** | 두 자매 다발을 한데 꿴 **은빛 C 자 쇠 고리**(허리 바로 아래 · 감수 I 전엔 팔에도) · 끊기면 C 조각이 「팅」 튄다 · 허리 고리는 넓은 갓 돌 수호신(슈고신)이 감수 I 내내 지킨다 | 「은빛 고리 = 코헤신 · 끊기면 자매가 갈린다」(C1-26) |
| **방추사 · 극** | 삼밧줄(금빛 아님) · 벽에 박힌 **검은** 쇠고리(L48b 에서만 가까이 본 대나무 대롱) | 「검은 고리에서 삼밧줄」 |
| **한 벌(n)** | 짚 세계: **큰 것 하나 · 작은 것 하나**(모든 키가 한 번씩) / 다른 세계: **사람이 멘 자루 하나** | 「키마다 하나씩 = 한 벌 = 자루 하나」(D0-20) |
| **2n · 3n · 4n(배수체)** | 짚 세계: 키마다 둘(남색 + 하늘색) = 2n / 사람 세계: 자루 개수(L35c · L36b · L36a 그대로) · 끈으로 묶인 자루 둘 = 짝지은 상동 · 홀로 하나 = 짝 없음 | 「자루 수 = 몇 벌」 |
| **염색체 수** | **허리(중심절) 수**를 센다 — X 도 외다발도 허리 하나 = 하나 | 「허리를 세면 염색체 수」 |
| **DNA 양(상대량)** | **다발 수**를 센다 — X = 2 · 외다발 = 1 | 「다발을 세면 DNA 양」 |
| **핵 · 핵막** | 빨강 · 흰 줄 돔 천막(찢어짐 = 핵막 붕괴 · 기운 새 천막 = 재형성) · L05b 의 단색 돔 천막도 같은 「천막 = 핵」 | — |

## 3. 혼동쌍이 한눈에 — 같은 「중기」 세 장면(+ 바로 다음 한 줄 소동)

**장면 A · 체세포분열 중기 = 「따로 줄 선 넷 — 차렷, 찰칵」(L48a s6 고친 뒤)**
- 흰 점선 위 **세로 한 줄**에 X 넷: 큰 남색(작은 실크해트) · 큰 하늘색(작은 면사포) · 작은 남색 · 작은 하늘색. **부부가 옆에 서지 않는다** — 큰 남색과 큰 하늘색 사이에 다른 짚단이 끼어 서로 모르는 척.
- X 마다 허리 양쪽 쇠판 걸쇠에 **양쪽 벽**에서 온 삼밧줄 둘 · 허리 아래 은빛 고리 하나.
- 다음 소동(s9): **다리 찢기** — 넷이 한꺼번에 가랑이가 찢어지며 은빛 C 조각이 점선 위로 튀고, 벽마다 외다발 **넷**(남 · 하늘 × 큰 · 작은)이 날아가 붙는다 = 두 벌 그대로(2n → 2n).
- 셈: 허리 4 · 다발 8 → 벽마다 허리 4 · 다발 4.

**장면 B · 감수 1분열 중기 = 「점선을 사이에 둔 부부 맞선 — 줄다리기 직전」(L48f s10 그대로 + 허리만 고침)**
- 점선을 **사이에 두고** 부부가 **짝째로** 마주 선다: 큰 쌍 · 작은 쌍 둘. 점선 위에 선 짚단은 하나도 없다.
- X 마다 **자기 쪽 벽 밧줄 하나**(자기 쪽 걸쇠 하나) — 반대쪽 쇠판엔 밧줄이 없다.
- 끝(X 의 바깥 위 다발)에 짝의 빛깔이 꽂혀 있다(이발사가 한 교차의 흔적 · 비자매 사이).
- 다음 소동(s11): **이혼 줄다리기** — 부부가 통째로 반대쪽으로 끌려가고 팔의 은빛 고리만 튀며 허리 고리(수호신이 지킴)는 남아 **가랑이는 안 찢어진다** = 2n → n · 아직 X.
- 셈: 허리 4 · 다발 8 → 방마다 허리 2 · 다발 4.
- 장면 A 와 **셈이 똑같다**(허리 4 · 다발 8) — 다른 것은 「옆에 짝이 있나」 · 「줄이 한쪽인가 양쪽인가」뿐. 시험 함정(중기 체세포 ↔ 중기 I 염색체 수 · DNA 양 같음)을 그림이 그대로 말한다.

**장면 C · 감수 2분열 중기 = 「홀몸 둘이 한 줄 — 짝은 어디 갔나」(L48g 왼쪽 · 오른쪽 방)**
- 점선 위 세로 한 줄에 X **둘뿐**: 큰 것 하나 · 작은 것 하나(빛깔은 쌍마다 따로 — 하나는 남색 실크해트, 하나는 하늘색 면사포 = 독립 분리의 결과). 같은 키의 짝이 **방 안에 없다**.
- 양쪽 벽 밧줄 둘(장면 A 와 같은 줄 규칙) · 허리 은빛 고리 하나.
- 두 다발 중 하나의 끝에 짝의 빛깔이 섞였다 — 그래서 **이제 자매가 완전히 똑같지는 않다**(교차 뒤).
- 다음 소동(s5): **다리 찢기**(장면 A 와 같은 동작) — 허리 고리가 팅 · 외다발 넷이 벽마다 **둘**(큰 하나 · 작은 하나).
- 셈: 허리 2 · 다발 4 → 방마다 허리 2 · 다발 2.

**세 장면을 한 줄로**: A = 한 줄에 **넷**(짝이 있는데 모른 척) · 양쪽 줄 → 가랑이 찢기 / B = 점선 사이에 **부부** · 한쪽 줄 → 이혼 / C = 한 줄에 **둘**(짝이 없음) · 양쪽 줄 → 가랑이 찢기.

## 6. 혼동쌍 · 자리와 크기 · 붐빔 · 오독 위험 · 스스로 본 약점
**혼동쌍이 갈리는 칼(무엇으로 가르나)**
- 자매 ↔ 상동: **은빛 쇠 고리**(자매) ↔ **천 띠**(상동 · 접합 때만) · **같은 빛깔**(자매) ↔ **남색 · 하늘색**(상동) · 한 X 안(자매) ↔ 따로 선 두 X(상동). 셋이 겹으로 가른다 — 빛깔 하나에만 기대지 않음.
- 복제 전 ↔ 복제 뒤: 외다발 ↔ X(다발 수).
- 염색체 수 ↔ DNA 양: 허리 수 ↔ 다발 수(셈표).
- 체세포 ↔ 감수 I ↔ 감수 II: 줄 규칙(양쪽 / 한쪽 / 양쪽) + 한 줄의 수(넷 / 부부 / 둘) + 소동(가랑이 찢기 / 이혼 / 가랑이 찢기).
- 중심절 ↔ 동원체 ↔ 코헤신: **재질** — 짚의 꼬임(DNA) ↔ 잿빛 쇠판 걸쇠(단백질 · 밧줄 매는 곳) ↔ 은빛 C 고리(단백질 · 자매를 꿰는 곳). 「짚이면 DNA, 쇠면 단백질」.
- 염색질 ↔ 염색체: 천막 안의 가는 실 ↔ 천막 밖의 동여맨 짚단.
- 반수체 ↔ 배수체: 키마다 하나 ↔ 키마다 둘(짚) · 자루 하나 ↔ 여럿(사람).

**자리와 크기**: L48a 셋째 칸이 좁다 — X 넷을 세로로 넣으면 짚단마다 약 150 px(2048 기준), 작은 모자 · 면사포는 110 px 에 못 미칠 수 있다 → 모자 · 면사포는 보조, 빛깔 + 키가 주. 780 px 로 줄이면 작은 쌍의 남 · 하가 붙어 보일 수 있음 — 남색은 짙게, 하늘색은 거의 흰빛으로 대비를 키운다(L48f 처럼).

**붐빔**: L48a 의 짚단이 칸마다 둘 → 넷. 다섯 칸 모두 늘면 헛간이 짚 투성이가 된다. 줄이려면 s3 · s5 · s10 은 넷 중 앞의 둘만 또렷이, 뒤 둘은 반쯤 가려도 된다(셈이 시험에 걸리는 s6 · s9 만 넷을 다 또렷이).

**오독 위험**
1. L48a 중기(넷 한 줄)를 「상동이 짝지었다」로 읽을 위험 — 남 · 하 · 남 · 하 로 **섞어 세워** 같은 키끼리 붙지 않게 하고, 점선을 짚단 가운데로 지나게(L48f 는 점선이 부부 **사이**로).
2. 감수 II(장면 C)를 체세포(장면 A)로 읽을 위험 — 수(둘 ↔ 넷)와 「같은 키의 짝이 방에 없음」이 칼. L48g 는 방이 둘로 나뉘어 있어 「방 하나 = 반쪽 세포」가 이미 읽힌다.
3. L48b 는 별마다 남 · 하 하나씩(같은 키)만 보여 2n = 2 처럼 보인다 — 장면이 방추체 이야기라 셈을 묻지 않는 자리지만, 덱 셈(2n = 4)과 어긋난다는 약점. 대롱이 더 들어갈 자리가 없어 그대로 둠.
4. 「다리 찢기」 비유가 「찢어져 망가짐(DNA 손상)」으로 읽힐 위험 — 낭독에서 「찢어지는 것은 가랑이(고리)뿐, 다발은 멀쩡히 둘」로 한 번 말한다.
5. 금빛 짚(L19h · L37a · L19c)이 「부모 셋째 빛깔」로 읽힐 위험 — 규칙: **금빛 = 부모를 묻지 않는 자리**(복제 · 포장 · 검문소 이야기). 부모를 묻는 자리(L48 줄기)에서는 금빛을 쓰지 않는다. 금빛 짚단과 남색 · 하늘색 짚단이 한 그림에 같이 나오는 곳이 없어야 한다(지금 없음 · 고친 뒤도 없음).

**스스로 본 약점**
- 비용이 L48a 에 몰린다(구역 5 또는 전체 다시 그림). 이 과는 녹음이 없어 지금이 고칠 때이지만 일이 가장 크다.
- 사건(이혼 · 가랑이 찢기)은 혼동쌍을 가르는 문법이지 **이름 고리가 아니다** — 「자매」 · 「상동」의 이름 고리는 글자 뜻(④)에 기댄다: 자매 = 같은 부모의 같은 옷 둘(같은 모자) · 상동(相同) = 서로 같은 꼴(같은 키 · 같은 허리 자리). 소리 고리(①)는 이 안에 없다 — 다른 렌즈의 안이 소리 고리를 주면 그것을 이 문법의 물건(은빛 고리 · 모자 · 면사포)에 얹으면 된다.
- L19a 은빛 고리 안은 반죽 덩이(L19a s13 · s14 에선 「세포」)를 「염색분체」로 다시 읽게 해서 덩이의 뜻이 둘이 된다 — 그래서 선택으로만 냄.
- 「줄이 한쪽에서만」(감수 I 단극 부착)은 L48f s10 에 이미 그렇게 그려졌지만, 쇠판을 **양쪽 다** 그리고 한쪽만 비워 두면 L19h s9 의 「빈 걸쇠 = 검문소가 멈춤」과 헷갈린다 → 감수 I X 에는 **자기 벽 쪽 쇠판 하나만** 그리고 반대쪽엔 쇠판 자체를 두지 않는다(빈 걸쇠를 만들지 않는다). 생물학적으로는 자매 동원체 둘이 한 극을 보는 것 — 「쇠판이 한쪽으로 몰렸다」로 맞음.

## 안 2(짧게) — 2n = 2 로 줄이는 싼 길
L48a 를 X 넷이 아니라 **같은 키의 남색 · 하늘색 X 둘**(상동 한 쌍)로 바꾼다 — 빛깔 바꾸기 + 모자 · 면사포 + 키 맞추기만, 구역 2–3 번, 짚단 수는 그대로. 체세포 중기 = 「부부가 같은 줄에 앞뒤로(짝짓지 않음)」 → 감수 I = 「부부가 점선 사이에 나란히」의 대비는 살아난다. 약점: L48f · L48g 가 2n = 4 라 감수 II(X 둘)가 체세포(X 둘)와 **수가 같아져** 장면 A ↔ C 를 수로 못 가른다 — 남는 칼은 「같은 키의 짝이 있느냐」뿐. 그래서 본안(2n = 4)을 먼저 민다.

## 덱 전체 — 다섯 줄
1. 짚은 DNA, 쇠는 단백질: 짚이 꼬인 허리가 중심절, 그 허리에 박은 잿빛 쇠판 걸쇠가 동원체, 두 다발을 꿴 은빛 C 고리가 코헤신이다.
2. 한 은빛 고리에 꿴 같은 빛깔 두 다발이 자매(X 하나 = 염색체 하나 · 가닥 둘), 키가 같은 남색(실크해트) · 하늘색(면사포) 두 짚단이 상동 부부, 키가 다르면 남남이다.
3. 혼례(천 띠로 부부를 칭칭)는 감수 I 에만 있고, 그때 줄은 한쪽에서만 와서 부부가 통째로 갈리는 이혼 줄다리기가 된다 — 2n 에서 n, 그래도 아직 X.
4. 체세포분열과 감수 II 에서는 줄이 양쪽에서 와 X 의 가랑이가 찢어지고 은빛 고리가 팅 튄다 — 체세포는 한 줄에 넷, 감수 II 는 짝 없는 둘.
5. 허리를 세면 염색체 수, 다발을 세면 DNA 양, 키마다 하나면 한 벌(사람 세계에선 자루 하나) — 천막 안에 들어가면 모두 가는 실로 풀린다.
