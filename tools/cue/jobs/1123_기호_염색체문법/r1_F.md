# r1_가 — 염색체 그림 문법 (렌즈: 우리말 소리)

> 낱말을 소리 내어 읽어 첫 음절이 겹치는 일상 우리말 물건을 찾았다: **코**헤신 → **코**뚜레 · **동**원체 → **동**(銅)판 · 중심**절** → **중**…**절**모처럼 가운데가 접힌 허리 · 염색**질** → **질**질 끌리는 짚 실 · **염색**체 → **염색**(물들인) 짚단 · 염색**분**체 → **분**신 · **상동** → 서식 칸의 「**상동**(위와 같음)」. 새 물건을 거의 늘리지 않고, 이미 그려진 짚 · 은빛 고리 · 쇠판 · 모자 · 면사포 · 자루 · 천막을 **이름 소리로 다시 부르고 빛깔과 꼴을 한 문법으로 맞추는** 안이다.

## 1. 문법 표

> 셈 규칙 하나를 덱 전체에 건다: **「허리를 세면 염색체, 다발을 세면 DNA」** — 허리(잘록한 중심절 + 동판 한 쌍) 하나 = 염색체 하나 · 짚 다발 하나 = 염색분체(DNA 이중나선) 하나.

| 뜻 | 꼴(물건 · 빛깔 · 크기 · 수) | 부르는 말(낭독에서 한 번) |
|---|---|---|
| DNA 일반(어느 부모 것인지 묻지 않는 장면) | **물 안 들인 금빛 짚 / 짚끈**(L37a · L19h · L19c) | 「물 안 들인 맨 짚 = DNA」 |
| 염색질(풀린 상태) | 묶이지 않은 **가는 짚 실이 바닥에 질질** 늘어짐(L48a s10 · L48f s2 · L48g s2 · s6) · 통에 감긴 채면 L37a | 「짚이 실로 풀려 **질질** 끌린다 — 염색**질**」 |
| 염색체(응축) | **허리를 꽉 조인 짧고 굵은 짚단**(물든 것은 남색 · 하늘색) | 「**물들인**(염색) 짚단 = 염색체 — 염색해야 보이는 몸」 |
| 염색분체 | 짚단을 이루는 **한 다발** | 「X 의 한 다발은 다른 다발의 **분**신 — 염색**분**체」 |
| 복제 전 염색체(염색분체 1) | **한 다발** 짚단(I 자) · 허리 하나 | 「한 다발 = 아직 한 벌 사본」 |
| 복제된 염색체(염색분체 2) | **같은 빛깔 두 다발**이 허리에서 은빛 코뚜레로 꿰인 **X** · 허리 하나 | 「다발 둘 · 허리 하나 = 염색체 하나에 분신 둘」 |
| 자매염색분체 | 한 X 의 두 다발 — **빛깔 같고, 머리 표지도 같다**(모자면 둘 다 모자 쪽 · 면사포면 둘 다 면사포 쪽). 둘 사이에만 **은빛 코뚜레** | 「한 집 딸 둘 — 자매. **코뚜레**로 꿴 것은 언제나 같은 빛깔 사이」 |
| 상동염색체 | **남색 + 검은 실크해트**(아버지 쪽) ↔ **하늘색 + 흰 면사포**(어머니 쪽) · **같은 키 · 같은 허리 높이 · 같은 자리에 짙게 물든 띠 두 줄**(염색 양상) | 「키 · 허리 · 띠가 **상동**(위와 같음) — 서식 칸에 '상동'이라 적듯 꼴은 같고 집안(빛깔 · 머리 표지)만 다른 부부」 |
| 서로 다른 염색체 | **키가 다른** 짚단(키 큰 쌍 · 작은 쌍 — L48f 그대로) | 「키가 다르면 남남」 |
| 한 벌(n) | **자루 하나** = 키 다른 짚단 한 개씩이 든 묶음(L36b · L35c 자루 그대로 · 자루 아가리로 짚 끝이 보이게) | 「자루 하나 = 한 벌 · 짚단 하나 ≠ 한 벌」 |
| n · 2n · 3n · 4n | 사람이 멘 **자루 개수**(L36b · L35c 예약 그대로) · 세포 안이면 **같은 키 짚단이 몇 개씩**인가 | 「자루를 세면 n 의 몇 배」 |
| 1n 이라도 복제됨 | 짝 없는(키 다른 것끼리만) **X** | 「짝 없는 X = n 인데 다발 둘」 |

| 접합(상동끼리 붙음) | 남색 · 하늘색 사이를 감는 **엮은 짚 띠**(L48f 중매쟁이 띠) — 코뚜레와 재료 · 꼴이 다르다 | 「부부를 감는 띠, 자매를 꿰는 고리」 |

## 2. 혼동쌍이 한눈에 갈리는 장면 셋 — 같은 「중기」

1. **체세포분열 중기(L48a 셋째 칸)** — 흰 점선 위에 **같은 빛깔 X 가 하나씩 세로 한 줄**(남색 X · 하늘색 X 가 위아래로 따로). X 마다 양쪽 동판에서 **양쪽 벽**으로 밧줄 둘. 남색과 하늘색 사이에 띠도 엇걸림도 없다 → 「짝이 있어도 짝짓지 않는다 · 자매가 갈라질 준비」.
2. **감수 1분열 중기(L48f 춤판)** — 점선을 사이에 두고 **남색 X 와 하늘색 X 가 짝째 마주** 선다(같은 키끼리). 한 X 의 두 동판이 **같은 쪽 벽**으로만 밧줄 하나(두 다발이 한 몸으로 같은 극). X 끝에 짝의 빛깔(교차) → 「짝째 서고, 갈리는 것은 부부(상동)」.
3. **감수 2분열 중기(L48g 아래층)** — 점선 위에 X 가 하나씩인데 **키가 서로 다르다**(키 큰 것 하나 · 작은 것 하나 — 짝 없음). X 끝이 두 빛깔(교차의 흔적). 양쪽 동판에서 **양쪽 벽**으로 밧줄 → 「1 과 꼴은 같은데 짝이 없다 = n · 갈리는 것은 자매(분신)」.

→ 1 과 3 을 가르는 단서는 **「점선 위 X 들의 키가 같은 쌍인가(2n) · 저마다 다른가(n)」** 와 **X 끝 두 빛깔(교차 흔적)** 이다. 1 과 2 를 가르는 단서는 **「하나씩 줄 · 짝째 마주」 + 「밧줄이 양쪽 · 한쪽」**.

## 4. 예약 확인(`python3 tools/cue/reserved.py`)

- **코뚜레** — 임자 없음. 「코」 소리는 코르크 마개(코르티솔) · 코발트빛 파란 코(B12) · 코사크(코작)에 있으나 물건이 다르다(둥근 쇠고리 · 사람 코 아님). 은빛 쇠 고리 = 코헤신 예약과 **같은 물건 · 같은 뜻** — 이름 소리만 보탬.
- **동판 · 구릿빛** — 임자 없음. 「구리」는 구리 왕복관(바사 렉타) · 구리 냄비 달팽이(헤모시아닌)가 쓰고, 「동」은 **동전 = ATP** — 그래서 **네모 · 볼트 박힘 · 걸쇠 달림**으로만 그린다(둥글게 그리면 동전). 쇠판 = 동원체 예약(L19h)과 같은 물건 — 빛깔만 바꿈.
- **모자 · 면사포** — 남색 실크해트 · 흰 면사포 = 상동의 아버지 · 어머니 쪽(L48f) 예약 그대로. 「모자」 = 5′ 캡(띠 앞머리 중산모)은 사람 · 짚단이 쓴 모자와 다르다고 장부가 적음.
- **중절모** — 장부: 「사람이 쓴 중절모는 뜻이 없다」. 그래서 **그리지 않고 글에서 비유로만** 쓴다(안 2 참고).
- **질질 · 분신 · 커플룩 · 초례상** — 임자 없음(초례상은 안 씀 — 아래).
- **혼례상** — L35c 에서 종 개념 · 생식 장벽의 「가운데 금」. 그래서 「상동」을 혼례**상**으로 잇지 **않았다**(한 물건 두 뜻).
- **쌍둥이** — PYY(Y 자 쌍둥이) · IgA(쌍둥이 벌 깃발)가 씀 → 자매를 「쌍둥이」로 부르지 않는다.
- **자루** — 배수성 전용 예약 그대로. ⚠ 「**자**루」와 「**자**매」가 첫 음절이 같다 → 자매에는 「자」 소리 물건을 쓰지 않았다(아래 약점).
- **띠** — 어깨띠 = Wee1. 짚단에 칠한 「짙은 띠 두 줄」은 몸에 두르는 띠가 아니라 짚 자체의 물든 무늬 — 접합의 엮은 짚 띠와도 꼴이 다르다(아래 오독 위험).
- **가위표** — 「여기서는 안 쓴다」 예약 · 수문. 염색체 X 는 짚단 꼴이라 겹치지 않으나 글에서 「가위표 짚단」 대신 「X 짚단」으로 부르길 권함.

## 5. 혼동쌍 · 자리와 크기 · 붐빔 · 오독 위험 · 스스로 본 약점

- **자매 ↔ 상동**: 「코뚜레는 같은 빛깔 사이에만 · 짚 띠는 두 빛깔 사이에만」 — 고리 재료(은빛 쇠 ↔ 엮은 짚)와 빛깔 둘이 함께 가른다. 빛깔만이 아니라 **머리 표지(모자 ↔ 면사포)** 라는 물건이 갈라 준다.
- **복제 전 ↔ 후**: 다발 하나 ↔ 둘. **허리 수 = 염색체 수**를 덱 셈 규칙으로 걸어 「후기에 염색체 수가 두 배」를 그림으로 센다.
- **중심절 ↔ 동원체 ↔ 코헤신**: 잘록한 **짚 자체**(DNA) ↔ 덧댄 **구릿빛 동판**(단백질) ↔ 꿴 **은빛 코뚜레**(단백질 고리) — 재료 셋 · 빛깔 셋 · 꼴 셋.
- **크기**: L48a · L48f · L48g 의 X 는 짧은 변이 110 px 를 넘지만 동판 · 코뚜레는 그 안의 부품이라 작다 — 이 과들에서 이름을 나르는 곳은 L19h(가까이 본 것)이고, 나머지는 **꼴을 맞추는 반복**이다. 780 px 에서 동판의 구릿빛이 갈색 밧줄과 섞일 수 있다 → 동판에 볼트 두 점을 꼭.
- **붐빔**: 새 종류 0 · 반복 물건만. L48a s6 에 모자 · 면사포를 얹으면 셋째 칸이 조금 붐빈다(사진기 · 점선과 겹치지 않게 짚 위쪽 끝에).
- **오독 위험**: ① 짙은 띠 두 줄이 「접합 띠」로 읽힐 수 있다 → 띠는 짚 위에 **칠한 줄**(두께 없음)로. ② 쌍덩이(L19a)가 「땅콩 · 눈사람」으로 읽힘 → 코뚜레가 보이게. ③ 구릿빛 동판이 「동전」으로 → 네모 꼴 엄수. ④ L48a 의 2n = 2(한 쌍)와 L48f 의 2n = 4(두 쌍)가 다르다 — 그대로 두면 「체세포 중기 X 둘 ↔ 감수 2 중기 X 둘」이 **허리 수 · 다발 수까지 같아진다** → 가르는 단서는 오직 「같은 키 쌍인가 · 키가 다른가」와 끝 빛깔. L48a 를 두 쌍으로 늘리는 것은 크다(안 하지 않고 적어 둔다).
- **스스로 본 약점**: 「자매」에는 내 렌즈(소리)에서 좋은 물건을 못 찾았다 — 「자」로 시작하는 일상 물건(자 · 자루 · 자물쇠 · 자갈)이 모두 임자가 있거나 「자루 = n」과 부딪친다. 그래서 자매는 ④(낱말 뜻 — 한 집 딸 둘 · 같은 머리 표지)와 「분신」(염색**분**체)으로 버틴다. 「상동」도 서식의 「상동(위와 같음)」은 나이 든 독자에겐 익지만 젊은 독자에겐 낯설 수 있다 — 낭독에서 「표의 '위와 같음' 칸」이라고 풀어 말해야 산다.

### 안 2 (짧게)
중심절에 **진짜 중절모**를 쓴다 — 가운데가 접힌 모자 꼭대기를 X 허리 높이 곁에 둔다. 소리(중 · 절)와 꼴(가운데 접힘)이 다 맞지만, 짚단의 실크해트(아버지 쪽)와 모자가 둘이 되어 「모자 = 부모 표지」 문법을 흐린다 → 본안은 글의 비유로만.

## 덱 전체 — 한 사건으로 읽히는 다섯 줄
1. 맨 금빛 짚끈은 DNA, 풀려 바닥에 **질질** 끌리면 염색**질**, 허리를 조여 **물들이면** 염색체 짚단.
2. S기에 짚 다발이 제 **분**신을 하나 더 만들어 같은 빛깔 두 다발이 되고, 소 **코**뚜레 같은 은빛 고리(**코**헤신)가 둘을 꿰어 X 하나 — 허리는 여전히 하나, 다발만 둘.
3. 가운데가 **중**절모처럼 **접힌** 허리(중심절)에 구릿빛 **동**판(**동**원체)을 박아 삼밧줄은 거기에만 건다 — 허리를 세면 염색체, 다발을 세면 DNA.
4. 남색 · 모자 신랑과 하늘색 · 면사포 신부는 키 · 허리 · 띠가 「**상동**(위와 같음)」인 부부 — 체세포분열에선 저마다 줄 서서 자매가 갈리고, 감수 1에선 짚 띠로 짝째 서서 부부가 갈리고, 감수 2에선 키 다른 X 하나씩 남아 자매가 갈린다.
5. 그렇게 나온 한 벌이 **자루 하나**(n) — 자루 둘이 만나면 2n, 셋 · 넷 · 여섯이면 배수체, 균류의 천막 둘(n+n)은 지퍼로 하나 되어야 2n.
