# r1_바 — 염색체 그림 문법 안 (렌즈: 그리기 · 자리 · 수)

> 한 줄: **「허리 · 다발 · 키」 문법** — 짚 세계의 기존 물건(다발 · 허리 · 은빛 고리 · 흰 점선 · 밧줄 · 사람이 멘 자루)을 그대로 쓰고, 빛깔이 아니라 **꼴(허리 밑 다발이 하나냐 둘이냐) · 수(허리를 세고 다발을 센다) · 크기(같은 키는 짝, 다른 키는 다른 염색체) · 자리(점선이 허리를 지나느냐 허리와 허리 사이를 지나느냐)** 로 자매 ↔ 상동을 가른다. **새로 느는 물건 0.** 고치는 것은 열한 과 중 L48g 두 곳(필수)과 L48f 한 곳(권장)이 중심이다.

**재서 얻은 핵심 셋**
1. 같은 짚단이 과마다 **다른 것**을 뜻한다. ⓐ L48a · L48b 의 금 · 초록은 예약 글에 「서로 다른 염색체 둘」인데, 키가 같아 눈으로는 **한 쌍(상동)**으로 읽힌다. ⓑ L48g 후기 II 칸은 남색 둘 · 하늘색 둘이 **같은 키**라 감수 II 세포가 「상동 짝을 아직 가진」 것으로 읽힌다(감수 II 에 짝이 없다는 급소를 그림이 뒤집는다). ⓒ L48f s7 의 **X 는 상동 둘의 엇걸림**인데 다른 과의 X 는 **자매 둘**이다.
2. 통짜 한 다발이 두 뜻이다: L48f 전기 I 의 곧게 선 굵은 다발(복제됨 · 속에 자매 둘)과 L48g 후기 II 의 한 다발(복제 전 · 분체 하나)이 겉으로 같다.
3. 수를 나르는 물건이 셋으로 갈려 있다: 짚단(L48) · 자루(L35c · L36b) · 천막(L05b). 서로 이어 주는 한 줄이 없다.

## 1. 문법 표 — 센 것은 다섯, 나머지는 꼴 규칙

**센 것 다섯**: ① **허리 수** ② **허리 밑 다발 수** ③ **같은 키 짝이 있나** ④ **갈림의 자리**(흰 점선이 허리를 지나나 허리 사이를 지나나 + 한 허리에 매인 밧줄이 몇 가닥 · 어느 쪽) ⑤ **자루 수**.
빛깔 · 은빛 고리 · 풀린 실 · 모자 · 면사포는 세는 것이 아니라 **보조 표지**다.

| 뜻 | 꼴(물건 · 빛깔 · 크기 · 수) | 부르는 말(낭독에서 한 번) |
|---|---|---|
| **염색분체 하나**(DNA 한 분자) | **한 다발** — 짚 한 묶음. 굵기는 어느 과에서나 한 다발이 같은 굵기 | 「한 다발」 |
| **복제 전 염색체**(분체 하나) | **허리 하나 + 다발 하나** — 틈 없는 통짜(I) 또는 한 가닥이 꺾인 V(끌려가는 중) | 「허리 하나에 다발 하나 — 아직 복사 전」 |
| **복제된 염색체**(분체 둘) | **허리 하나 + 다발 둘** — 허리는 잘록, 위 · 아래 끝은 두 갈래. 벌어지면 X, 곧게 설 땐 **가운데 틈 한 줄**이 보여 둘로 센다(통짜 한 덩이로 그리지 않는다 · 잘록한 꼴을 가리키며 모래시계 물건은 그리지 않는다 — 예약) | 「허리 하나에 다발 둘 — 복사 뒤」 |
| **자매염색분체** | 위 다발 둘 — **같은 빛깔 · 완전히 같은 키 · 한 허리를 나눠 쓴다** · 은빛 고리 하나가 둘을 한꺼번에 낀다 | 「허리를 나눠 쓰는 두 다발이 자매」 |
| **상동염색체**(부계 · 모계) | **허리가 둘(따로) · 같은 키 · 같은 허리 높이 · 빛깔이 다름**(남색 = 아버지 · 하늘색 = 어머니. L48a · b 의 금 · 초록도 서로 다른 빛깔 한 쌍). 은빛 고리가 둘 **사이에는 없다**. 닿는 곳은 접합 띠(전기 I)와 팔의 엇걸림뿐 | 「허리가 따로, 키가 같다 — 상동」 |
| **서로 다른 염색체** | **키가 다르다**(큰 것 : 작은 것 ≈ 1.5 : 1 — L48f 에서 잰 값과 같게) | 「키가 다르면 다른 염색체」 |
| **염색체 수**(n · 2n) | **허리를 센다** | 「허리 수가 염색체 수」 |
| **DNA 양** | **다발을 센다**(한 다발 = 1) | 「다발 수가 DNA 양」 |
| **n 이라도 복제 여부** | n = 같은 키가 **하나씩**(짝 없음). 그런데 허리 밑이 둘이면 DNA 는 두 배 | 「키마다 하나뿐이면 n — 다발이 둘이면 아직 복제된 채」 |
| **반수체 ↔ 배수체**(n · 2n · 3n · 4n) | 같은 키가 **한 개 · 둘 · 셋 · 넷** · 사람이 멘 **자루 개수**(이미 있는 덱 규칙) | 「자루 하나 = 한 벌」 |
| **한 벌(n) ↔ 염색체 한 개** | 자루 하나 = 한 벌(**안에 키가 다른 허리들이 하나씩**) / 허리 하나 = 염색체 한 개 | 「자루는 벌을 세고 허리는 염색체를 센다」 |
| **염색질 ↔ 염색체** | 허리 없이 **풀린 실 · 끈**(묶이지 않음) = 염색질 / **허리가 생겨 묶인 단** = 염색체 | 「풀린 실에는 허리가 없다」 |
| **중심절**(DNA 부위) | **허리** — 잘록한 한 곳(꼬임 또는 끈) | 「허리가 중심절」 |
| **동원체**(단백질 복합체) | 허리 양면에 붙은 **납작한 쇠판 · 밧줄이 매인 매듭** | 「밧줄 맨 허리의 쇠판이 동원체」 |
| **코헤신** | 두 자매 다발을 한꺼번에 끼운 **은빛 고리**(자매 사이에만). 끊기면 C 자로 튄다 | 「은빛 고리는 자매 사이에만」 |
| **갈림의 자리**(체세포 · 감수 II ↔ 감수 I) | **점선이 허리를 지나면** X 가 둘로 갈린다(자매) · **점선이 허리와 허리 사이를 지나면** 짝이 통째로 간다(상동). 밧줄: 한 허리에 **양쪽 두 가닥**이면 자매가 갈리고, **같은 쪽 한 가닥**이면 X 째로 간다 | 「점선이 허리를 가르면 자매 · 허리 사이를 가르면 상동」 |
| **교차**(비자매 사이) | 상동 둘의 **팔 끝**(허리 아닌 곳)에서 끝 한 줌씩 바꿈 · 허리 쪽에는 엇걸림 끈을 두지 않는다 | 「엇걸림은 팔에서 — 허리에서가 아니다」 |
| **극에 닿은 묶음**(환원 · 동형) | 체세포 후기: 한 극에 **같은 키 짝이 있다**(2n) / 감수 II 후기: 한 극에 **같은 키 없다**(n) | 「한 극에 같은 키가 둘이면 2n · 하나씩이면 n」 |

### 1-1. 수 표(이 덱의 그림으로 세는 값 — 허리 / 다발)

| 단계 | 그려진 곳 | 한 세포의 허리 / 다발 |
|---|---|---|
| 체세포 중기(2n=2 약식) | L48a 셋째 칸 | 2 / 4 |
| 체세포 후기 · 한 극 | L48a 넷째 칸 · L48b | 2 / 2 |
| 감수 I 중기(2n=4) | L48f s10 | 4 / 8 |
| 감수 I 뒤 한 세포 | L48g 계단 X | 2 / 4 (n 이지만 복제된 채) |

## 2. 혼동쌍이 한눈에 갈리는 장면 셋 (같은 단계 = 중기)

| | ① 체세포분열 중기 | ② 감수 1분열 중기 | ③ 감수 2분열 중기 |
|---|---|---|---|
| 그려진 곳 | L48a 셋째 칸(s6 · s7) | L48f s10 | L48g — 중기는 안 그려져 있다. 계단 도착 X 둘(s4)과 후기 II(s5)를 한 사건으로 읽는다 |
| 점선 자리 | **허리 위**를 지난다 | **허리와 허리 사이**를 지난다 | **허리 위**(후기 II 에서 은빛 C 조각이 점선 위로 튄다) |
| 밧줄 / 허리 | 허리마다 **양쪽 두 가닥**(다이아몬드 꼴) | 허리마다 **같은 쪽 한 가닥** | 허리마다 양쪽 두 가닥 |
| 같은 키 짝 | **있다**(금 · 초록이 같은 키) — 그러나 짝짓지 않고 위아래로 따로 선다 | **있다** — 점선 건너편에 마주 선다 | **없다**(키가 모두 다르다) |
| 허리 / 다발 | 2 / 4 | 4 / 8 | 2 / 4 |

→ ①과 ③은 수가 같다(2 / 4). 가르는 것은 **같은 키 짝의 유무**뿐이라 L48g 의 크기 고침이 필수다. ①과 ②는 점선 자리와 밧줄 수로 갈린다.
→ 자매와 상동은 한 문장으로 갈린다: 「**허리를 나눠 쓰면 자매 · 허리가 따로이고 키가 같으면 상동**」.

| L05b s1 · s5 | 「천막 한 채 = 핵 하나 · 두 채 나란히 n+n · 한 채에 두 빛깔 줄무늬 = 한 핵에 두 벌 2n」 | 없음 | 0 | 0 |

**합계**: 필수 구역 편집 **2**(L48g) · 권장 **1~2**(L48f) · 선택 **1**(L19c). 새 물건 **0**. 글은 과마다 덧붙임 한 문장씩.

(안에서 더 찾을 과: L48c · L46c 의 핵막 천막, L34b 씨 속 자루 3n, L36a · L42 의 자루 — 예약 글로만 알고 그림은 보지 않았다 → 「모름」. 자루 · 천막 규칙은 그대로 두면 된다.)

## 4. 예약 확인 · 혼동쌍 · 자리와 크기 · 붐빔 · 오독 위험 · 스스로 본 약점

**예약**(`reserved.py` 로 직접 찾음)
- 짚단 · 다발 계열: 금빛 짚끈 = DNA · 남색 · 하늘색 짚단 = 상동의 아버지 · 어머니 · 삼밧줄 = 방추사 · 은빛 쇠 고리 = 코헤신 · 검은 쇠고리 = 극 · 돔 천막 = 핵 · 사람이 멘 자루 개수 = 배수성 — **모두 같은 뜻으로만 쓴다. 새 이름을 얹지 않는다.**
- **모래시계는 예약**(시계탑 광주기) → 「허리 잘록한 꼴」은 짚 모양일 뿐 모래시계 물건을 그리지 않는다. **「쌍둥이」** 는 L12f(PYY) · L13(IgA)가 쓰는 낱말이라 부르는 말에서 쓰지 않았다(「같은 키」 · 「짝」).
- 고쳐 적을 예약 글: ⓐ 남색 · 하늘색 짚단 항목의 「⚠ L48a 의 금 · 초록 짚단은 서로 다른 염색체 둘」 → 「같은 키 한 쌍」(금 · 초록도 서로 다른 빛깔 둘 = 상동). ⓑ 계단 X 둘 · 후기 II 항목에 「한 세포 안 남색 · 하늘색은 키가 다르다」 덧붙임.

**혼동쌍**: 이 문법이 직접 막는 것은 (a) 자매 ↔ 상동 (허리 하나 vs 둘) (b) 복제 전 ↔ 후 (다발 하나 vs 둘) (c) 염색체 수 ↔ DNA 양 (허리 vs 다발) (d) 체세포 ↔ 감수 II (같은 키 짝 유무) (e) 감수 I ↔ II (점선 자리) (f) 한 벌 ↔ 염색체 한 개 (자루 vs 허리) (g) 중심절 ↔ 동원체 ↔ 코헤신 (허리 · 쇠판 · 은빛 고리).

**자리와 크기**: 고칠 곳이 아래층 두 방이라 여유가 있다. 다만 **L48g 계단 X 는 2048 기준 67×114 로 이미 110 px 아래** — 남색을 1.3배 키워 ≈87×148 이 되게 하고, 하늘색(≈66×107)은 그대로 둔다. 780 px 로 줄이면 하늘색 ≈25×41 px — X 꼴은 알아보지만 아슬아슬하다.

**붐빔**: 새 물건이 없어 붐비지 않는다. 다만 L48f 천막 구역 편집은 사람 · 띠 · 수레가 한 구역에 있어 다발만 바뀌도록 마스크를 좁게 잡아야 한다.

**오독 위험 · 스스로 본 약점**
1. **키 비 1.5 하나에 기댄다.** 780 px 에서 큰 쌍 ≈95 : 작은 쌍 ≈64 px 라 약하다. → 안 2 가 모양(허리 높이)으로 한 겹 더 건다.
2. L48a(2n=2) · L48f(2n=4) 절대 수가 다르다(§1-1).
3. 금 · 초록과 남색 · 하늘색 두 짝 팔레트가 그대로다. 「같은 빛깔 = 자매 · 다른 빛깔 = 상동」 규칙은 둘 다 맞지만 어버이 표지(남색 = 아버지)는 L48f · g 에서만 켜진다. 빛깔은 보조라서 일부러 안 건드렸다.
4. 감수 II 중기가 그려져 있지 않아 장면 ③ 은 후기 II 에서 거꾸로 읽는다.
5. L48f 전기 I 의 「틈 한 줄」은 생성 편집이 다발을 다시 통짜로 뭉갤 수 있다 → 안 되면 (글)만으로 두고 「L48f 천막 안 통짜는 모두 복사된 것」이라고 한 번 말한다.
6. 만족한 그림(lock.json) · 녹음 manifest 는 이 일감 규칙상 읽지 못했다 → L48f s3–s7 · L48g s4 · s5 가 lock 이면 (글)만 하고 심판에게 넘긴다.

**안 2(대안, 짧게)**: 크기 대신 **허리 높이**로 종류를 가른다 — 한 쌍은 허리가 한가운데(대칭 X), 다른 쌍은 허리가 위로 치우쳐 한쪽 팔이 길다(비대칭 X). 780 px 에서도 꼴로 읽히고 「상동 = 같은 동원체 위치」(D0-14)를 그대로 담는다. 값은 L48f 춤판 작은 쌍 둘의 허리를 위로 올리는 **구역 편집 1**(x 970–1290, y 440–600) 과 L48g 두 곳에 비대칭 X 를 쓰는 것. 대가: 키 규칙(L48g 크기 고침)과 겹쳐 고칠 곳이 늘고, L19h · L37a(한 종류)와 이어 주는 말이 길어진다.
**안 3(대안)**: L48a 를 2n=4(X 넷)로 늘려 L48f 와 절대 수를 맞춘다 — 구역 편집 4(1~4칸)라 비싸서 권하지 않는다.

## 5. 덱 전체 — 이 문법이 한 사건으로 읽히는 다섯 줄

1. 짚 세계의 **짚단 하나는 허리를 한 곳 가진다** — 허리 밑에 다발이 하나면 아직 복사 전, 둘이면 복사 뒤이고 **그 둘은 한 허리를 나눠 쓰는 자매**다(허리 수 = 염색체 수 · 다발 수 = DNA 양).
2. **상동은 허리를 따로 가진 같은 키의 짝**이다 — 남색 신랑과 하늘색 신부처럼 둘 사이엔 은빛 고리가 없고, 중기의 점선이 **둘 사이**를 지나면 짝이 헤어지고(감수 I) **허리 위**를 지나면 자매가 헤어진다(체세포 · 감수 II).
3. 한 세포 안에서 **같은 키가 둘이면 두 벌(2n) · 하나씩이면 한 벌(n)** — 체세포 극에는 같은 키 둘이 있고 감수 II 의 극에는 키가 모두 다르다.
4. **풀린 실에는 허리가 없고** 허리가 생겨 묶이면 염색체다 — 말기에 다시 풀린 짚이 천막 안에 흩어진다.
5. **자루는 벌을 세고(하나 = n · 둘 = 2n · 여섯 = 6n) 허리는 염색체를 센다** — 두 셈이 서로 다른 물건이라 한 벌과 염색체 한 개가 섞이지 않는다.
