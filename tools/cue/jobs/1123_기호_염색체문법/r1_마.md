## 0. 안의 이름 — 「허리 · 다발 · 자루 셋만 센다 + 점선이 지나는 자리」

내 렌즈의 규칙: **혼동쌍의 두 짝은 그림에서 모든 것이 같고 딱 한 가지만 다르다.** 그 한 가지는 그림의 같은 자리에서 보이는 물건이어야 하고(빛깔은 보조), 시험이 문장에서 바꿔 내는 바로 그 낱말에 걸려야 한다. 덱이 이미 가진 배우(남색 · 하늘색 · 금빛 짚단 · 은빛 고리 · 삼밧줄 · 점선 · 자루)만 쓰고 새 물건은 거의 늘리지 않는다.

## 1. 혼동쌍 먼저 — 시험이 바꿔 내는 방식 · 지금 덱이 무너지는 자리 · 갈라 줄 「한 가지」

| # | 혼동쌍 | 시험이 바꿔 내는 문장(기출 · 카드) | 지금 덱에서 무너지는 자리(그림에서 직접 봄) | 같은 것 / **다른 한 가지** |
|---|---|---|---|---|
| 1 | 자매염색분체 ↔ 상동염색체 | 「제1 감수분열 후기에 자매염색분체가 두 딸세포로 분리」(X · BM상-0334) · 「교차는 자매염색분체 사이」(X · 0319 · 0335) · C1-94 자매는 정보 동일 | ① L48a·L48b 는 금빛 X + 초록 X(키 같음)인데 해설은 「서로 다른 염색체」 — 같은 키 · 다른 빛깔은 L48f 에서는 **상동**이라 그렇게 읽힌다. ② 후기에 양 극이 「금 + 초록」씩(L48a s9 · L48b s4)인 것이 L48g s5 의 「남색 + 하늘색」씩과 같은 꼴이다. ③ L19h 「가위표 짚단 한 쌍」 · L19c 갈색 막대 다발 · L37a 금빛 — 같은 개념이 세 재료 · 세 빛깔 | 같은 것: 같은 키의 두 짚 묶음. **다른 것: 허리를 같이 쓰는가** — 한 허리에 낀 두 다발 = 자매(한 빛깔), 허리가 따로인 두 X = 상동(두 빛깔) |

| 3 | n ↔ 2n ↔ DNA 양 (감수 II 중기 = n · 복제됨 ↔ 체세포 G1 = 2n · 복제 전) | D0-43 환원분열 2n → n · 동형분열 n → n · DNA 상대량 그래프 | 한 장면에서 세 숫자를 「짚단 몇 개」 하나로 센다 — L36b 는 자루 · L48 은 짚단 · L05b 는 천막 · L19a 는 덩이로 세는 물건이 과마다 다르다 | **DNA 양은 같고 염색체 수는 다른 쌍**이 핵심(예 2n = 2 의 G1: 허리 2 · 다발 2 / n = 1 의 중기 II: 허리 1 · 다발 2). 같은 것: 다발 수. **다른 것: 허리 수** |

## 2. 문법 표 — 뜻 | 꼴 | 부르는 말 (낭독에서 한 번)

세는 것은 **세 물건**이다: 허리(염색체) · 다발(염색분체 · DNA) · 자루(한 벌 · 배수성). 이 셋은 한 장면에서 서로 대신하지 않는다.

| 뜻 | 꼴 (물건 · 빛깔 · 크기 · 수) | 부르는 말 |
|---|---|---|
| 염색분체 하나 = DNA 한 분자 | 짚 **한 다발**(한 번 묶인 한 묶음). 꺾여도(V) 직선이어도 한 다발 | 「다발」 |
| 염색체 하나 | **허리 하나**(짚이 한 곳에서만 잘록하게 꼬인 자리. 허리 수 = 염색체 수) | 「허리 하나가 염색체 하나」 |
| 복제 전 염색체 | 한 허리 · **한 다발**(I) · 은빛 띠 없음 | 「한 다발」 |
| 복제된 염색체(중기 염색체) | 한 허리 · **두 다발**(X) · 허리에 은빛 띠 한 바퀴 · **한 빛깔** | 「한 허리에 두 다발」 |
| 자매염색분체 | 한 X 의 두 다발 — **같은 빛깔 · 같은 키 · 같은 허리** | 「한 허리의 두 다발」 (쌍둥이 · 짝 같은 말은 쓰지 않는다 — 아래 §3) |
| 상동염색체 | **허리가 따로인 같은 키 짚단 둘**, 남색(검은 모자 = 아버지 쪽) + 하늘색(흰 면사포 = 어머니 쪽) · 마주 선다 | 「서로(相) 같은(同) 키로 마주 선 부부」 |
| 비상동(다른 번호 염색체) | **키가 다르다**(큰 쌍 · 작은 쌍). 빛깔은 같아도 된다 | 「키가 다르면 다른 염색체」 |
| 부계 · 모계 · 부모 표지 없음 | 남색 + 모자 · 하늘색 + 면사포 / **금빛(노랑) = 부모 표지가 없는 한 염색체를 가까이 본 것**(L19c · L19h · L37a) | 「남색 아버지 · 하늘색 어머니」 |
| 염색질(풀림) ↔ 염색체(응축) | 가는 짚 **실 · 끈 · 뭉치** / 묶인 짚**단** | 「실」 ↔ 「단」 |
| 중심절 | 허리의 **짚 그 자체**(잘록 · 꼬임 · 덧댄 것 없음 = DNA 부위) | 「허리 = 중심절」 |
| 동원체 | 허리 옆구리에 **박힌 쇠**(큰 그림 L19h: 쇠판 + 걸쇠 · 작은 그림: 작은 쇠 고리) — **밧줄은 오직 여기에만 매인다** | 「밧줄이 매이는 쇠 = 동원체」 |
| 코헤신 | 두 다발을 한데 끼운 **은빛 띠 · 고리** — 밧줄이 안 걸린다 · 풀릴 때는 **C 자로 끊겨 튄다** · 자리를 지키는 수호신 | 「두 다발을 끼운 은빛 고리 = 코헤신」 |
| 염색체 수(n · 2n = 46) | **허리를 센다** | 「허리를 세면 염색체」 |
| DNA 양 | **다발을 센다** | 「다발을 세면 DNA」 |
| 한 벌(n) | 사람이 멘 누런 삼베 **자루 하나**(L36b · L35c) — 자루에는 키가 다른 염색체가 한 개씩 든다 | 「자루 하나 = 한 벌」 |
| 반수체 · 2배체 · 배수체 | 자루 **1 · 2 · 3 이상**. 반(半)수체도 자루는 한 개 **가득**(반쪽 자루 없음) | 「자루를 세면 몇 배체」 (배수체가 2n 을 포함하는가는 교재마다 — 모름) |
| 어느 분열인가 | 점선(분열면)이 **허리를 지나면** 자매를 가르는 분열(체세포 · 감수 II) · **부부 사이를 지나면** 상동을 가르는 분열(감수 I). 밧줄: 허리마다 **양쪽에서 두 가닥**(체세포 · II) / 허리마다 **한쪽에서 한 가닥**(I) | 「점선이 허리를 지나나, 부부 사이를 지나나」 |
| 분리된 뒤 한 다발 | **허리가 앞서고 팔이 뒤로 처진다**(V 또는 직선) · 밧줄 하나 · **은빛 띠 없음** | 「허리가 앞장선다」 |
| 키아즈마 | 두 빛깔 짚단이 **팔 끝에서** X 로 엇걸림(허리 띠 없음 · 아래는 A 자로 벌어짐) | 「두 빛깔이 팔 끝에서 엇걸림」 |

낱말마다 두 길(packet 요구):

| 낱말 | (글) 있는 소품의 일상 이름에 잇기 — 그림은 그대로 | (그림) 작은 새 소품 · 키우기 |
|---|---|---|
| 자매염색분체 | 「한 허리에서 갈라 나온 두 다발」 — 소리 고리는 안 만든다(누구나 아는 낱말 · RUBRIC §3-2). 쌍둥이는 예약(PYY) | 새 물건 없음 — 이미 X |
| 상동염색체 | ④ 글자 뜻 **相同 = 서로 같다** — 같은 키로 **마주 선** 짚단(L48f 큰 쌍 · 작은 쌍이 이미 그렇다) | 모자 · 면사포를 작은 장면에도(선택 · §5) |
| 동원체 | ④ 動原體 = 끌려가는 힘이 걸리는 자리(이미 hooks) — 「밧줄이 매이는 쇠」 | L48f 춤판의 밧줄 끝을 은빛 고리가 아니라 허리 옆구리의 작은 쇠 고리로(§5) |
| 중심절 | ④ 中心節 = 한가운데의 마디 → 「잘록한 허리」(이미 hooks) | 없음 |
| 코헤신 | 「끼워 붙임」(이미 hooks ④) | L48a 허리 끈을 은빛 띠로(색만 바꿈 · §5) |
| 염색분체 · 염색체 | 「다발」 · 「허리」로 센다 | 없음 |
| 반수체 · 배수체 | 「자루 개수」 | 없음 |

## 3. 틀린 소리 친구 막기 — 시험이 바꿔 내는 말과 이 문법의 낱말이 부딪치는 자리

| 부딪침 | 왜 위험한가 | 막는 법 |
|---|---|---|
| **자루 ↔ 자매** (첫 음절 「자」) | 「자매 = 자루 둘」 또는 「자루 둘이면 자매」로 읽혀 **한 벌(2n)** 과 **자매(두 다발)** 가 섞인다 | 자루는 L36b · L35c 에만. L48 계열에는 자루를 그리지 않는다. 낭독에서 자매를 설명할 때 자루를 입에 올리지 않고 「한 허리의 두 다발」이라고만 한다 |
| **신부(여) ↔ 자매(sister)** | 하늘색 신부 = 어머니 쪽 상동인데 「자매 = 여자 = 신부」로 끌려갈 수 있다. 신랑 · 신부는 성 구별이 아니라 **부모 쪽** | 자매염색분체 곁에는 사람(특히 여인)을 두지 않는다. 자매를 설명하는 말에 신부 · 신랑을 쓰지 않는다. 남색 · 하늘색에 X · Y 성염색체 뜻을 얹지 않는다 |
| **중심절 · 중심체 · 중심립 ↔ 「중심」** | L48b 별(성상체) 꼭지의 원통 둘 = 중심체 · 중심립, L19h 허리 = 중심절 — 「중심」 단독으로 말하면 둘이 섞인다. L48b s3(중심체) 는 녹음됨 | 낭독은 「중심절」 · 「중심체」를 늘 통째로 부른다. 허리 쪽(L19h s1)에 「별 꼭지의 중심체와 다르다」 한 줄(글 · 녹음 없음) |
| **모자 ↔ 5′ 캡**(모자는 캡 예약) | 남색 신랑의 모자를 「아버지 염색체에 캡」으로 읽을 위험(이미 있는 예외) | 모자를 이 덱에서 더 늘리지 않는다. 면사포는 모자가 아니다. 새 장면에 모자를 달 때는 남색 짚단 머리에만 |
| **상동 ↔ 상(床)** | 「혼례상」을 그리면 소리 고리처럼 보임 | 혼례상 · 상 위 물건을 그리지 않는다(뜻은 相同 의 글자 뜻으로만) |
| **반수체 ↔ 반(半)** | 반쪽 자루 · 반쯤 빈 자루로 그리면 n 이 「반 벌」로 읽힌다 | 자루는 늘 가득. 반수체 = 한 벌 = 자루 하나 |
| **코헤신 ↔ 콘덴신**(응축 고리) | 은빛 고리를 응축에 쓰면 코헤신과 섞인다(콘덴신은 덱에 아직 없다 — 모름) | 은빛 고리는 코헤신 전용(이미 예약). 콘덴신이 새로 필요하면 L37a 가로대 고리(굵은 밧줄 고리)와 잇고 은빛은 피한다 |
| **동원체 ↔ 「동원」(사람)** | 줄다리기 사내(L48f)를 동원체로 읽을 수 있다 | 사내는 방추장치(극)다. 동원체는 쇠 고리 · 쇠판. 낭독에서 사내를 「극에서 당기는 쪽」이라 부른다 |
| **영어 sister ↔ 시스터나(골지)** | 시스터나(L48d 팬케이크 쟁반) 와 소리 겹침 — 한국어 낭독에서는 「자매」만 쓰면 안전 | 낭독에서 sister 를 영어로 말하지 않는다 |

## 4. 혼동쌍이 한눈에 갈리는 장면 셋 — 같은 배우, 점선 하나가 다르다

배우: **큰 남색(모자) · 큰 하늘색(면사포) · 작은 남색 · 작은 하늘색**(L48f 춤판 그대로). 체세포 장면은 한 쌍만 써도 된다(§5 의 안 1) — 쌍이 하나여도 문법은 같다.

1. **체세포 중기** (L48a 셋째 칸 · 점선이 칸 한가운데를 위아래로) — 남색 X 와 하늘색 X 가 **서로 닿지 않고 한 줄**로 선다. **점선이 두 허리를 꿰뚫는다.** 허리마다 은빛 띠 한 바퀴 · 밧줄이 **양쪽 극에서 한 가닥씩**(마름모). 보는 법: 「점선이 허리를 지난다 → 한 허리의 두 다발을 가른다. 부부는 짝짓지 않았다.」
2. **감수 I 중기** (L48f 춤판) — 같은 키의 남색 X · 하늘색 X 가 **점선 양옆에 나란히 마주**. **점선이 부부 사이를 지난다.** 허리마다 밧줄 **한 가닥 · 같은 쪽**(남색 → 왼쪽 극 · 하늘색 → 오른쪽 극). 은빛 띠는 허리에 그대로. 보는 법: 「점선이 부부 사이 → 상동을 가른다. X 째로 끌려간다.」
3. **감수 II 중기 · 후기** (L48g 아래층 한 방) — 한 방에 X 가 **둘뿐이고 키가 다르다**(왼쪽 방 큰 남색 + 작은 하늘색 · 오른쪽 방 큰 하늘색 + 작은 남색 — L48f 말기 I 글과 같음). **같은 키 짝이 없다**(상동은 위층에서 이미 갈렸다). 점선이 허리를 지나고 밧줄이 양쪽 두 가닥 · 은빛 띠가 C 자로 끊겨 튄다. 보는 법: 「같은 키 둘이 없다 → 상동은 갈린 뒤. 점선이 허리 → 자매를 가른다.」

세 장면의 **한 가지**: 점선이 지나는 자리(허리 / 부부 사이 / 허리), 그리고 같은 키 짝이 있느냐(없다 / 있다 / 없다).

덤 — **도치쌍**(DNA 양은 같고 염색체 수는 다르다): 중기 II 세포(허리 1 · 다발 2)와 G1 세포(허리 2 · 다발 1 씩 둘)는 **짚 다발 수가 둘로 같다**. 이 쌍은 낭독 한 줄(「다발은 둘이지만 허리는 하나」)로만 잇는다 — 그림에서 두 세포를 한 장면에 놓지 않는다.

## 7. 예약 확인 · 자리와 크기 · 붐빔 · 오독 위험 · 스스로 본 약점

- **예약 확인**(`reserved.py` 로 직접): 모자 = 5′ 캡 전용이나 「남색 짚단(검은 실크해트) · 하늘색 짚단(면사포) = 상동의 아버지 · 어머니 쪽」은 이미 예약된 예외 — 같은 뜻으로만 다시 쓴다 · 짚 · 짚끈 = DNA · 염색체(재료 부호: 짚 = DNA · 덧댄 쇠 · 나무 = 단백질) · 은빛 쇠 고리 = 코헤신 전용 · 검은 쇠고리(벽) = 극 · 삼밧줄 = 방추사 · 돔 천막 = 핵 · 사람이 멘 자루 개수 = 배수성 · **쌍둥이 = PYY 전용**(그림 · 말 모두 안 쓴다) · 허리 · 걸쇠 · 쇠판 · 점선 = 짚 세계 안의 뜻만 있음. 새로 쓰는 물건은 「작은 쇠 고리」 하나뿐이고 L48a 에 이미 있는 꼴이다. 찾지 않은 물건은 쓰지 않았다.
- **자리와 크기**: 문법 부호는 이미 그려진 것의 색과 밧줄 끝 자리만 바꾼다. 작은 쇠 고리는 780 px 에서 작아 이름 고리(110 px)는 못 된다 — 이름은 L19h 의 큰 쇠판 · 걸쇠가 맡고 작은 고리는 「같은 물건」으로만 읽히게 한다(약점).
- **붐빔**: 새 물건이 사실상 없고 빛깔 · 키 · 밧줄 자리만 바꾼다. 선택 8 은 붐비면 버린다.
- **오독 위험**: (a) 한 쌍(L48a)을 남색 · 하늘색으로 바꾸면 체세포가 「부부 한 쌍뿐인 세포(2n = 2)」로 읽힌다 — 문법은 같고 쌍 수만 다르니 낭독에 「이 칸은 쌍이 하나」 한 줄. (b) 사람이 안 메고 짚단이 걷는 L48g 는 자루와 섞이지 않는다. (c) 금빛(L19c · L19h · L37a)이 「부모 없음」인지 「자매」인지 — 금빛은 한 X 를 클로즈업한 것으로만. (d) X · V · 직선의 다발 수를 780 px 에서 세는 일: X = 두 다발 · V · 직선 = 한 다발이라고 낭독이 한 번 말해 준다.
- **스스로 본 약점**: ① 색치환(금 · 초록 → 남색 · 하늘색)이 Gemini 구역 편집에서 모자 · 키가 번질 수 있음 — 모름(해 봐야). ② 감수 II 중기 장면이 L48g 에 따로 없다(s4 → s5 로 건너뜀) — 안 1 은 s4 · s5 로 읽게 한다. ③ 도치쌍(DNA 같고 염색체 수 다름)은 그림이 아니라 말로만 간다. ④ 자루 ↔ 짚단 연결(자루에 키가 다른 염색체가 든다)은 그림에 없고 표에만 있다 — L36b 는 녹음이 끝나 손댈 수 없다.

## 8. 안 2 — 「같은 네 사람」 풀 판 (비용이 큰 대안)

L48a 를 한 쌍이 아니라 **L48f 와 같은 네 짚단**(큰 남색 · 큰 하늘색 · 작은 남색 · 작은 하늘색)으로 다시 그린다. 그러면 체세포(L48a) · 감수 I(L48f) · 감수 II(L48g) 가 **정확히 같은 배우**여서, 체세포 중기 = 네 X 가 닿지 않고 한 줄 · 후기 = 양 극이 네 가지씩(큰 · 작은 × 남 · 하) 받는 것까지 감수와 한눈에 갈린다. 비용: L48a 둘째 ~ 넷째 칸 전부 다시(구역 편집이 아니라 칸 재작성 3) · L48b 도 같은 수로 · 새 물건 0 이지만 칸이 좁아 붐빈다. 안 1 로 쌍 하나가 안 읽히는 독자 시험이 나올 때만 쓴다.

## 9. 덱 전체 — 이 문법이 한 사건으로 읽히는 다섯 줄

1. 한 집안의 짚단 네 개(큰 · 작은 × 남색 아버지 · 하늘색 어머니)가 헛간의 앞칸 · 위층 · 아래층에서 분열마다 다른 줄에 선다.

3. 세는 것은 셋이다 — 허리는 염색체 · 다발은 DNA · 자루는 한 벌 — 허리 하나에 다발 둘이면 X(복제됨).
