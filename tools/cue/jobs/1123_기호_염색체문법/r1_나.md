# r1_나 — 「허리는 글자, 다발은 획」: 짚단을 한자처럼 읽는 염색체 문법 (렌즈: 영어 · 어원 · 글자)

## 한 줄 안
새 소품 없이, 이미 그려진 짚단을 **글자처럼 센다** — 허리(은빛 고리 한 개) 하나 = 글자 하나 = 염색체 하나, 다발 하나 = 획 하나 = 염색분체 하나 = DNA 한 단위. 「한 허리에 두 다발」이면 자매, 「허리가 둘이고 같은 키에 남색 · 하늘 한 쌍」이면 상동. 빛깔 두 벌(금 · 초록 / 남색 · 하늘)을 한 벌(남색 · 하늘)로 합치는 구역 편집 8번이 그림의 전부이고, 나머지는 어원 · 글자 풀이를 이미 있는 소품의 낭독에 한 문장씩 얹는 글 길이다.

## 0. 읽는 규칙 다섯 (이 안의 뼈대)
1. **한 허리 = 한 글자 = 염색체 1개**(중심절 1곳). 염색체 수는 허리를 센다. 후기에 허리가 둘로 쪼개지면 글자가 두 배.
2. **한 다발 = 한 획 = 염색분체 1개 = DNA 1단위**. DNA 양은 다발(획)을 센다. 한자의 글자 수와 획수가 따로이듯 **염색체 수와 DNA 양은 따로 센다** — n · 2n 이라도 X 인지 I 인지가 갈린다.
3. **자매 = 같은 허리를 쓰는 두 획**(한 빛깔 · 같은 굵기 · 은빛 고리 하나에 함께 끼움). **상동 = 허리가 따로인 같은 글자 둘**(같은 키 · 남색 하나 + 하늘 하나). 묻는 말은 하나: 「허리가 하나냐 둘이냐」(꼴 · 수) — 빛깔은 보조.
4. **한 벌 = 자루**(기존 배수성 약속 — L35c · L36b). 자루 안에는 키가 다른 짚단이 종류마다 하나씩. n 은 「종류 수」이고 허리(글자) 수와 같다. 자루가 둘이면 같은 키가 둘씩.
5. **부모 표지는 덱에 하나**: 남색(+검은 모자) = 아버지 쪽, 하늘색(+면사포 · 머릿수건) = 어머니 쪽. 금빛 한 가지 짚(L19h · L37a)은 「누구 것인지 묻지 않는 염색체」. 금 · 초록 같은 제3의 짝 빛깔은 쓰지 않는다.

## 1. 문법 표
(부르는 말 = 낭독에서 한 번만 말해 줄 낱말. 글 길 = 이미 있는 소품 · 정거장에 한 문장. 그림 길 = 그림에서 하는 일.)

| 뜻 | 꼴(물건 · 빛깔 · 크기 · 수) | 부르는 말 |
|---|---|---|
| 염색분체 1개 | 곧은 짚 한 다발. 허리 한 곳이 잘록 | 「한 다발 = 한 획」 |
| 복제 전 염색체 | 한 다발짜리 짚단. 허리에 은빛 고리 **없음**(끼울 짝이 아직 없다). 풀린 맨 짚끈과는 허리가 있는 것으로 가른다 | 「한 허리 한 다발 — 아직 안 복제」 |
| 복제된 염색체(중기 염색체 1개 = 염색분체 2개) | 같은 빛깔 · 같은 굵기 두 다발이 **한 허리에서 은빛 고리 하나**에 끼워져 가위표 꼴. 허리 1곳 | 「한 허리 두 다발」 |
| 자매염색분체(같은 어버이 · 복제 사본 · 유전 정보 동일) | 위 두 다발 **한 빛깔**. 쓰개가 있으면 두 다발 사이 꼭대기 틈에 얹거나 두 다발 모두에 | 「한 글자의 두 획 — 자매」 |
| 상동염색체(짝 · 부계/모계 · 같은 길이 · 같은 허리 높이) | **허리가 따로 둘**, 키 · 허리 높이가 같고 **남색 하나 + 하늘색 하나**. 서로 은빛 고리를 나눠 갖지 않음 | 「같은 글자 둘 — 아버지 판 · 어머니 판, 상동」 |
| 자매 ↔ 상동 가르는 질문 | 허리 1(고리 공유) → 자매 / 허리 2(키 같음 · 빛깔 둘) → 상동 / 키가 다르면 서로 다른 염색체 | 「허리가 하나냐 둘이냐」 |
| 염색체 수 | 허리 수 | 「글자 수」 |
| DNA 양 · 염색분체 수 | 다발 수 | 「획 수」 |
| 후기에 염색체 수 2배 | 허리 고리가 끊겨 꺾인 짚 두 개(허리 걸쇠가 앞장). 허리 수가 늘었을 뿐 다발 수는 그대로 | 「글자가 둘로」 |
| n(한 벌) · 반수체 | 자루 1개 = 키 다른 짚단 종류마다 하나(큰 것 · 작은 것) | 「한 벌 = 자루 하나. 짚단 한 개가 아니다」 |
| 2n(이배체) | 자루 2개(아버지 · 어머니 한 벌씩) = 같은 키가 둘씩 | 「두 겹」 |
| 3n · 4n · 6n(배수체) | 자루 3 · 4 · 6 개(기존 L35c) | 「세 겹 · 네 겹 · 여섯 겹」 |
| 염색질(풀린 상태) | **허리 없는** 맨 짚끈 · 가는 실 · 통에 감긴 끈 | 「질(質) = 풀린 바탕」 |
| 염색체(응축) | **허리가 생긴** 묶인 짚단 | 「체(體) = 묶인 몸」 |
| 중심절(DNA 부위) | 짚 가닥 자체가 꼬여 잘록한 허리 | 「절(節) = 마디, 짚 자체」 |
| 동원체(단백질 복합체) | 허리 양 바깥에 볼트로 박은 납작한 쇠판(다발마다 하나 · 등짐). 쇠판이 안 그려진 과는 밧줄 고리가 매인 허리 띠를 동원체 자리로 읽는다 | 「체(體) = 덧댄 쇠판」 |
| 코헤신 | 두 다발을 한데 끼운 은빛 쇠 고리(기존 예약). 허리와 후기 전 팔에 | 「-in = 붙임 고리」 |
| 교차(비자매 사이) | 남색 · 하늘 사이에서만 끝 한 줌을 바꿈(기존 이발사). 결과 = 한 팔 끝만 짝 빛깔 | 「부부 사이에서만」 |
| 점선이 갈라 놓는 것 | 점선이 **허리 위**를 지나면 자매가, **글자 사이**를 지나면 상동이 갈라진다 | 「점선이 지나는 자리」 |

## 2. 혼동쌍이 한눈에 — 중기 장면 셋 (한 세포 · 2n = 4 기준, L48f 의 큰 쌍 · 작은 쌍)
- **① 체세포분열 중기**(L48a s6 · s7): 같은 키 짚단이 점선 위에 **한 줄로 따로따로**(남색 · 하늘 — 짝지어 서지 않음). 짚단마다 허리에 고리 하나, 양쪽 쇠고리에서 온 밧줄 둘. **점선이 각 짚단의 허리(두 다발 사이)를 지난다.** → 「글자는 그대로 서 있고 갈라질 것은 획」.
- **② 감수 1분열 중기**(L48f s10): 같은 키 남색 · 하늘이 **점선을 사이에 두고 마주**(짝째). **점선이 두 글자 사이를 지난다.** 짚단 하나에 밧줄은 제 쪽 한 가닥. → 「갈라질 것은 글자(상동)」.
- **③ 감수 2분열 중기**(L48g s4 → s5): 점선 위에 **짝 없는 짚단**(키가 다른 큰 것 하나 · 작은 것 하나). **점선이 허리를 지나고 밧줄은 양쪽.** → ①과 같은 모습인데 **같은 키 둘이 안 보인다**(글자가 반 = n). 「갈라질 것은 획, 그러나 한 벌뿐」.
- 한 번에 읽는 법: 점선이 허리 위 + 같은 키 둘 있음 = 체세포 / 점선이 글자 사이 = 감수 I / 점선이 허리 위 + 같은 키 없음 = 감수 II. C1-100~101(감수 II 와 체세포분열의 공통점 = 자매 분리)도 같은 「점선이 허리 위」로 읽힌다.

글자 · 획 세기(2n = 4 · 큰 쌍 + 작은 쌍 · 글자 = 허리, 획 = 다발):

| 단계 | 글자 | 획 | 꼴 |
|---|---|---|---|
| G1(체세포) | 4 | 4 | 한 다발 넷 |
| G2 ~ 중기(체세포) | 4 | 8 | 한 허리 두 다발 넷 |
| 체세포 후기 | **8** | 8 | 꺾인 짚 여덟 |
| 체세포 딸세포 하나 | 4 | 4 | 한 다발 넷 |
| 감수 I 중기 | 4(짝 둘) | 8 | 짝지은 둘씩 |
| 감수 I 끝(딸세포 하나) | **2(= n)** | **4** | 한 허리 두 다발 둘 — 「n 인데 아직 복제된 채」 |
| 감수 II 중기 | 2 | 4 | 한 허리 두 다발 둘 |
| 감수 II 후기 | 4 | 4 | 꺾인 짚 넷 |
| 감수 II 끝(딸세포 하나) | 2(= n) | 2 | 한 다발 둘 — 비복제 |

## 4. 영어 · 어원 · 글자 길 (글 길 문장 초안 — 낭독용 한글 표기)
(영어는 낭독에서 한글로 쓴다. 뿌리가 확실하지 않은 것은 「모름」.)
- **자매 / 상동 (L48f s10 · L19h s2)**: 「한 허리에 두 다발이면 자매, 같은 어머니의 딸 둘이다. 허리가 둘이고 키가 같으면 상동이다. 호모는 그리스말로 같은, 호모님(동음이의어)의 호모다 — 같은 이름이지 같은 몸이 아니다. 아버지 판과 어머니 판.」 → 「자매 = 같은 몸(복사), 상동 = 같은 이름(다른 몸)」으로 갈림.
- **염색질 / 염색체 (L37a s3 · s10, L48a s3)**: 「질(質)은 바탕, 체(體)는 몸. 영어도 크로마틴의 인(-in)은 물질, 크로모솜의 솜(-some)은 몸 — 리보솜 · 리소좀의 솜이다.」 크로마(색)는 둘 다 같다.
- **중심절 / 동원체 / 코헤신 (L19h s2 · s3 · s7)**: 「중심절의 절(節)은 마디, 센터(중심) + 메로스(부분)로 가운데 마디. 동원체의 체(體)는 덩어리, 덧댄 쇠판. 코헤신은 코(함께) + 붙다 — 접착제(어드히시브)의 헤스와 같은 계통.」 키네토(움직임)는 키네틱(운동)의 키네토. 키네토코어의 뒷부분(-chore)의 뿌리는 모름.
- **n · 2n · 배수체 (L35c s15)**: 「한 벌은 자루 하나. 배수성의 플로이드는 -겹(two-fold · three-fold)이라는 뜻의 그리스말. 하플로 = 홑, 디플로 = 겹 — 졸업장(디플로마)은 두 겹으로 접은 종이라는 뜻이다.」(ply · 합판과 뿌리가 같은지는 모름 — 쓰지 않는다)
- **환원 / 동형 (L48f s11 · L48g s5)**: 「감수 1분열은 리듀스(줄인다) — 글자 수가 절반. 감수 2분열은 이퀄(같다) — 글자 수 그대로. 감수(減數)라는 이름도 줄어드는 수.」
- **2가 · 테트라 (L48f s4)**: 「칭칭 감겨 한 덩이가 된 부부는 2가(바이밸런트) 염색체 — 글자 둘, 획 넷. 테트라는 4(테트라포드 · 네발동물의 테트라).」
- **복사기 · 태사기의 絲**: 이미 덱에 있는 뜻 그대로(가는 실 · 굵은 실 · 겹실) — 絲 = 한 가닥. 이 안의 「획」과 같은 층이라 따로 보태지 않는다.

버린 것(렌즈가 만든 함정):
- 「2n = 트윈(쌍둥이)」: 트윈 = 자매(복사)라서 2n 이 자매로 읽힌다 — 거꾸로다.
- 「키네토코어의 코어 = 춤판」: L48f 의 춤판 = 중기판(예약)과 겹친다. 동원체를 춤판이라 부르지 않는다.
- 「크롬 = 은빛」: 은빛은 코헤신 예약.
- 「호모 사피엔스」: 라틴 호모(사람)와 그리스 호모(같은)가 섞인다 — 호모님(동음이의어)만 쓴다.
- 졸업장 두루마리를 그림에 넣기: 두루마리 예약(알 · 감 · 베 / mRNA)과 겹치고 붐빈다 — 글에서만.

## 5. 예약 확인 (`python3 tools/cue/reserved.py …` 로 직접 찾은 결과)
- **짚단 · 면사포 · 모자**: 임자 있음 — 남색 짚단(검은 실크해트 신랑) · 하늘색 짚단(면사포 신부) = 상동의 아버지 · 어머니 쪽(L48f · L48g · 같은 두 빛깔). 모자 = 5′ 캡이 본래 임자이고 이 짚단 쓰개만 예외. 이 안은 **새 모자 · 새 면사포를 만들지 않는다.**
- **자루**: 배수성 전용(L36b · L35c · s42p01) — 이 안은 두 과의 자루에 천 빛깔만 보태고 **다른 과에 자루를 새로 그리지 않는다.**
- **코헤신(은빛 쇠 고리)**: 예약됨(L19c · L19h · L48f · L48g). L48a 에는 「고리가 그려지지 않았다」고 예약문이 스스로 적었다 — 이 안이 그 빠진 곳을 메운다. 헛간 벽 검은 쇠고리(극)와는 색 · 자리(벽 · 밧줄이 나옴)로 가른다.
- **금빛 짚끈 · DNA 세계별 물건**: 금빛 = DNA 짚. 이 안은 금빛을 「중립 짚」으로만 남기고 L48a 의 금 · 초록 **짝 빛깔**을 거둔다(예약문 「서로 다른 염색체 둘 · 부모 구분 없음」 결정을 뒤집는다 — 아래 약점 ①).
- **X · V · 사다리**: X = 키아즈마(L48f s7 예약, 키아즈마와 크로모솜이 둘 다 그리스 문자 Χ 에서 온다) — **X 를 「복제된 염색체」의 이름으로 쓰지 않는다**(복제된 것은 「한 허리 두 다발」, 키아즈마는 「엇걸림」으로 부른다). V = V자 이음쇠(ADH) — 후기 꺾인 짚은 「꺾인 짚」이라 부르고 V 에 뜻을 주지 않는다. 사다리 = A(CENP-A · PKA) — 안 쓴다.
- **졸업장 · 휴지 · 합판 · 하프 · 수녀**: 임자 없음 — 글로만 씀(그림에 넣지 않는다).

## 6. 혼동쌍 · 자리와 크기 · 붐빔 · 오독 위험 · 스스로 본 약점
- **혼동쌍**: 자매 ↔ 상동(허리 하나냐 둘이냐 · 꼴), 복제 전 ↔ 후(한 다발 ↔ 한 허리 두 다발), 염색체 수 ↔ DNA 양(글자 ↔ 획), 질 ↔ 체, 절 ↔ 체 ↔ in, 체세포 중기 ↔ 감수 I ↔ 감수 II(점선 자리 + 같은 키 유무).
- **자리와 크기**: 새 소품 0 이라 크기 문제는 L48a 의 허리 은빛 고리(짧은 변 110 px 이상 · 2048 px 기준 — L19h 의 고리 크기를 본보기로)뿐이다. L48a 허리 띠는 이미 크게 그려져 있으니 재질만 바꾸는 구역 편집 한 번씩으로 된다.
- **붐빔**: 물건이 늘지 않는다(고리 3개는 있던 띠의 재질 교체).
- **오독 위험**:
  1. 「글자 · 획」은 읽는 규칙이지 그려진 물건이 아니다 — 설명으로 읽히면 고리가 아니다. 그림이 받치는 것은 허리 고리 수 · 다발 수 · 점선 자리다.
  2. L48f 의 모자가 X 의 한쪽 팔 위에만 앉아 「자매가 서로 다르다」로 읽힐 수 있다(재조합 얼룩과도 섞임). 선택 보정: 모자 · 면사포를 두 다발 사이 꼭대기 틈으로(L48f s10 한 구역).
  3. L48g s4 의 두 X(모자 남색 · 면사포 하늘)가 빛깔 때문에 상동 부부로 읽힐 수 있다 — 키가 다름(큰 하나 · 작은 하나)을 낭독이 짚는다.
  4. L48a 를 2n = 2 로 읽게 하면 L48f(2n = 4)와 한 세포가 아니다 — 두 과가 같은 세포라는 주장은 하지 않는다(키 같음 · 빛깔 둘의 문법만 같다).
  5. L05b 의 파랑 · 노랑(교배형)이 하늘 · 남색(부모)과 비슷해 보일 수 있다 — 다른 생물의 두 계통이라 문법 밖이다.
- **약점 ①**: L48a 의 「부모 구분 없는 서로 다른 염색체 둘」 결정을 뒤집는다. 이유는 체세포 중기를 감수 I 과 견줄 때 상동이 존재하되 짝짓지 않음을 보여 줄 수 없기 때문(안 2 가 되돌리는 길).
- **약점 ②**: 렌즈가 글 길 중심이라 L19a · L19c · L36b · L05b 에서는 문법이 낭독 · 기존 그림에 기대고, 새 그림 단서가 거의 없다. L36b 천 빛깔은 색만으로 가르는 약한 보조다(꼴 · 수는 자루 개수가 맡는다).
- **약점 ③**: 「획」 비유가 한자 획수에 익숙해야 즉시 읽힌다(이 독자는 한의학 · 한자에 익숙한 독자로 가정). 그렇지 않으면 「다발 수」로 읽어도 문법은 선다.
- **약점 ④**: 어원 풀이 몇 개(-id · -chore · ply 와 -ploid 의 계통)는 확실하지 않아 안에서 뺐거나 「모름」으로 적었다.

## 7. 안 2 (짧게 — L48a 의 결정을 지키는 쪽)
- L48a 의 금 · 초록을 그대로 두고(구역 편집 0) 「서로 다른 염색체 둘」로 둔다. 대신 L48a s6 낭독에 「여기에는 짝(같은 키의 상동)을 그리지 않았다 — 짝은 L48f」 한 문장. 체세포 ↔ 감수 I 의 비교는 ① · ③ 의 「점선이 허리 위」 규칙으로만 한다.
- 장단: 그림 손이 가장 적고 예약 결정과 충돌하지 않으나, 체세포 중기에 상동이 있다는 사실이 그림에 없어 「체세포분열은 상동끼리 짝짓지 않는다」를 그림이 말하지 못한다.
- 선택 보정(안 1 · 안 2 공통): L19c 의 갈색 막대 다발을 금빛 짚으로(구역 편집 1 · 새 물건 0), L36b s5 · s6 자루 주둥이에 키 다른 짚 끝 둘을 삐죽(새 물건 4 · 110 px 한계라 비추천).

## 8. 덱 전체 — 이 문법이 한 사건으로 읽히는 다섯 줄
1. 한 짚단은 세포 안에서 한 글자다: 풀린 맨 짚끈(질)이 묶여 허리가 생기면(체) 한 글자, 허리가 은빛 고리 하나로 두 다발을 끼우면 복제된 한 글자(X) — 획은 둘.
2. 같은 키의 남색 글자와 하늘 글자는 아버지 판과 어머니 판의 같은 이름(상동): 서로 허리가 따로이니 고리를 나눠 갖지 않는다.
3. 점선(중기판)이 글자의 허리를 지나면 획이 갈리고(체세포 · 감수 II), 글자 사이를 지나면 글자가 갈린다(감수 I) — 그래서 감수 I 은 글자가 줄고(reduce), 감수 II 는 글자가 그대로다(equal).
4. 자루는 한 벌의 글자 종류를 담는다: 하나면 n, 둘이면 2n(아버지 · 어머니), 셋 · 넷이면 세 겹 · 네 겹 — 글자를 세는 것(허리)과 획을 세는 것(다발)은 별개다.
5. 이 규칙을 L19c · L19h(고리 · 쇠판) → L37a(질 → 체) → L48a(체세포) → L48f(감수 I) → L48g(감수 II) → L36b · L35c · L05b(자루 · 천막)가 같은 방식으로 읽게 한다: 새 물건은 없고, 같은 허리 · 같은 다발 · 같은 두 빛깔뿐.
