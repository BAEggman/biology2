## 0. 렌즈 — 혼동쌍을 먼저 적는다
| # | 쌍 | 시험이 바꿔 내는 말 | 지금 덱에서 섞이는 곳(직접 본 것) | 짝이 같은 꼴에서 달라지는 **한 가지** |
|---|---|---|---|---|
| 1 | 자매 ↔ 상동 | 「같은 어버이 · 복제 사본」 ↔ 「짝 · 부계 / 모계」 · 비자매 사이 교차 | **X 꼴 하나가 두 뜻**: L48f s10 · s11 의 X = 같은 빛깔 두 다발(자매) / L48f s5 · s6 · s7 의 X = 남색 다발 + 하늘색 다발(상동 둘의 키아즈마). 같은 실루엣 · 빛깔만 다르다 | **빛깔**(같다 ↔ 다르다)을 1차로 · **묶는 물건**(은빛 고리 ↔ 짚 띠)을 2차로 못 박는다 |
| 2 | 복제 전 ↔ 후 | 「염색분체 하나 ↔ 둘」 · 감수 I 이 끝나도 복제된 채 | L48f s3 ~ s8 의 상동 하나가 **한 다발**(전기 I 인데 복제 전 꼴) · L48g s2 말기 I 천막 밑 **한 다발**(복제된 채여야) | **은빛 고리가 끼었나**(같은 빛깔 두 다발 + 고리 = 복제됨 · 한 다발 · 고리 없음 = 복제 전) |
| 3 | n ↔ 2n ↔ DNA 양 | 염색체 수와 DNA 양이 단계마다 | 체세포 중기(L48a 칸 3 = X 둘) 와 감수 II(L48g = X 둘)가 **같은 수**; L48b 극마다 V 둘 = 이 모형(2n = 4)으로 읽으면 반수 | 염색체 수 = 서 있는 **덩어리(X 또는 한 다발) 수** · DNA 양 = **다발 수** · 한 벌(n) = **자루**(L36b · L35c) |
| 4 | 체세포 중기 ↔ 감수 II 중기 | 「X 가 줄에 선다 · 밧줄 양쪽」은 둘이 같고 수 · 짝만 다르다 | L48a 칸 3 = 금 X + 초록 X 같은 키 / L48g s4 = 남색 X + 하늘색 X 같은 키 — **둘이 사실상 같은 그림** | 줄 위 **X 의 수**: 넷 ↔ 둘 (보조: 같은 키 짝이 있다 ↔ 없다) |
| 5 | 중심절 ↔ 동원체 ↔ 코헤신 | 「DNA 부위 ↔ 단백질 복합체 ↔ 고리」 | L48f s10 · s11 · L48g s5: 밧줄이 **은빛 허리 고리에 직접** 매임 → 동원체와 코헤신이 한 물건 / L48a: 밧줄이 갈색 허리 묶음에 매임 | 허리 한 자리의 **세 물건을 자리로 가른다**: 꼬임(짚 자체) · 고리(짚 둘레) · 쇠판 걸쇠(짚 옆구리, 밧줄은 여기만) |
| 6 | 염색질 ↔ 염색체 | 풀림 ↔ 응축 | 이미 갈린다(흩어진 가는 짚 실 ↔ 묶인 짚단: L48a 칸 1 · 5 · L48f s2 · L37a) | — (그대로) |
| 7 | 반수체 ↔ 배수체(2n · 3n · 4n …) | 개수 | L36b · L35c: **자루 개수**(메든 들든 개수만) | — (그대로, 다만 자루 = 한 벌 이라 못 박는다) |

## 1. 문법 표 (뜻 | 꼴 | 부르는 말)
모형 하나: **2n = 4** — 큰 쌍 하나(남색 + 하늘색, 키 100) + 작은 쌍 하나(남색 + 하늘색, 키 약 60). 한 벌(n) = 큰 것 하나 + 작은 것 하나. L48f 의 지금 그림이 이미 이 모형이다(큰 쌍 · 작은 쌍).

| 뜻 | 꼴(물건 · 빛깔 · 크기 · 수) | 부르는 말(낭독에서 한 번) |
|---|---|---|
| **염색분체 한 개** | 짚 **한 다발**. 다발은 허리에서 잘록하다 | 「다발 하나가 염색분체 하나」 |
| **염색체 한 개** | **짚단 하나** = 다발 하나(복제 전) 또는 같은 빛깔 두 다발이 허리에서 엇걸린 **X**(복제 후). 낱말 약속: **짚단 = 염색체 · 다발 = 염색분체** (L48g s1 글이 이미 「한 짚단의 두 다발」) | 「짚단은 염색체, 다발은 염색분체」 |
| **복제 전** | 다발 하나 · **은빛 고리 없음** · 점선도 밧줄도 아직 없다 | 「고리 없는 한 다발 — 복제 전」 |
| **복제 후** | 같은 빛깔 두 다발이 허리에서 한 점으로 꼬이고(X) **은빛 고리 하나**가 둘을 한꺼번에 끼운다. 전기 I 처럼 아직 모여 선 때는 두 다발이 나란히 겹쳐 「II」로 서고 고리는 같다 | 「고리에 낀 두 다발 — 복제된 염색체」 |
| **자매염색분체** | 한 X 안의 두 다발: **같은 빛깔 · 같은 키 · 은빛 고리 하나 · 맞붙음** | 「한 고리에 함께 낀 같은 빛깔 두 다발이 자매염색분체」 |
| **상동염색체** | 따로 선 **짚단(X) 둘**: **같은 키 · 다른 빛깔**(남색 = 아버지 · 하늘색 = 어머니, 모자 · 면사포는 혼례 이야기의 보조). 둘을 묶는 것은 짚 띠(접합기)뿐이고 **은빛 고리는 둘 사이에 없다** | 「키가 같고 빛깔만 다른 둘 — 신랑 신부, 상동 한 쌍」 |
| **비상동(다른 염색체)** | **키가 다르다**(큰 쌍 ↔ 작은 쌍) | 「키가 다르면 서로 다른 염색체」 |
| **교차** | 이발사 가위는 **서로 다른 빛깔 두 다발 사이**(안쪽 다발끼리)에서만 — 같은 빛깔 다발끼리는 바꾸지 않는다 | 「자매끼리가 아니라 남색 다발과 하늘색 다발이 맞바꾼다」 |
| **한 벌(n)** | 큰 짚단 하나 + 작은 짚단 하나 = **자루 한 개**(L36b 글 「한 벌의 염색체 수가 엔」과 그대로 이어진다) | 「한 벌이 엔 — 자루 한 개」 |
| **2n** | 큰 쌍 + 작은 쌍 = 짚단 **넷** = 자루 둘 | 「같은 키 짝이 다 있으면 2n」 |
| **염색체 수** | 서 있는 덩어리(X 또는 한 다발)의 **수**. 복제해도 안 변한다 | 「덩어리를 센다」 |
| **DNA 양** | **다발의 수**(X 는 둘). 복제하면 두 배 · 후기 · 감수 I 끝 · 감수 II 끝에서 줄어든다 | 「다발을 센다」 |
| **염색질(풀림)** | 흩어진 가는 짚 실 · 금빛 짚끈(L37a). 풀려도 어버이 빛깔은 남는다 | 「풀리면 실, 묶이면 짚단」 |
| **중심절** | 두 다발이 **짚 자체로 서로 꼬여 한 몸**이 된 잘록한 허리(L19h s2 본). 덧댄 물건이 아니다 | 「짚이 꼬인 허리가 중심절」 |
| **동원체** | 허리 **옆구리**(바깥 면)에 박은 **회색 쇠판 + 걸쇠**. 가까이 본 그림(L19h)은 판 + 걸쇠, 먼 그림(L48a · L48f · L48g)은 **걸쇠 하나가 삐죽**. **방추사 밧줄은 오직 여기에만** 걸린다 | 「밧줄은 쇠판 걸쇠에만 — 사내들을 총동원해 당기는 줄이 걸리는 판, 동원체」 |
| **코헤신** | 허리를 둘러 두 다발을 한꺼번에 끼운 **은빛 고리**. 끊기면 **은빛 C 조각**이 튄다. 밧줄은 여기 매지 않는다 | 「응집시키는 은빛 고리, 코헤신」 |
| **방추사 · 극** | 방추사 = 삼밧줄(L48b 가까이 = 속 빈 대나무 대롱) · 극 = 벽에 박힌 **검은 쇠고리**. 은빛(코헤신) · 회색(걸쇠) · 검정(극)이 쇠 물건 셋 — **자리**(허리 둘레 · 허리 옆 · 벽)와 꼴(O 고리 · J 걸쇠 · 벽 고리)로 가른다 | 「검은 건 벽, 회색은 짚 옆, 은빛은 짚 둘레」 |
| **빛깔 규칙** | **금빛 · 노랑 = 어버이를 가르지 않는 확대 그림**(L19h · L37a · L19c 이후). **남색 · 하늘색 = 아버지 · 어머니**(L48a · L48b 도 이 빛깔로 통일). 자루의 빛깔(L35c = 어느 종) · 천막의 빛깔(L05b = 어느 짝짓기형)은 **물건이 다르므로 따로 읽는다** | 「짚단의 남색 · 하늘색은 어버이」 |
| **중기 읽기** | ① 줄(흰 점선) **위**에 X 가 한 줄 + 밧줄 **두 면** = 체세포 / 감수 II ② 줄을 **가로질러 짝지어** + 밧줄 **한 면** = 감수 I. 그 안에서 **X 넷이면 체세포 · 둘이면 감수 II** | 「넷이면 2n · 둘이면 n」 |

색 · 키는 보조일 뿐 아니라 물건이 받친다: 자매 = **고리**(O) · 상동 = **띠**(접합기에 짚 띠가 길이 전체를 감는 것 = L48f s4) · 둘 다 L35c s16 의 「끈으로 묶인 둘 = 짝 · 홀로 = 짝 없음(3n)」과 같은 말버릇이다.

## 2. 혼동쌍이 한눈에 갈리는 장면 셋 — 같은 도구(점선 · X · 걸쇠 · 밧줄)로 짠 같은 틀
| | ① 체세포 중기 | ② 감수 I 중기 | ③ 감수 II 중기 |
|---|---|---|---|
| 그림 자리 | **L48a 칸 3(s6)**: 칸 가운데 점선 한 줄 | **L48f s10**(지금 그림 그대로) | **L48g 왼쪽 방 s4 편집**: 왼쪽 방 점선 위 |
| 줄 위 X | **넷**(큰 남색 · 작은 하늘색 · 큰 하늘색 · 작은 남색, 짝끼리 이웃하지 않게 섞음) 한 줄 | **넷**, 줄을 **가로질러 짝지어**(큰 쌍 남|하 · 작은 쌍 하|남) | **둘**(큰 남색 · 작은 하늘색), 같은 키 짝 없음 |
| 밧줄 | X 마다 왼쪽 쇠고리 · 오른쪽 쇠고리에서 **둘**(마름모) | X 마다 **자기 쪽 벽 하나**(걸쇠도 한 면) | X 마다 **둘**(마름모) |
| 허리 | 은빛 고리 넷 + 걸쇠 여덟 | 은빛 고리 넷 + 걸쇠 넷 | 은빛 고리 둘 + 걸쇠 넷 |
| 다발 수(DNA) | 여덟 | 여덟 | **넷** |
- **780 px 에서 한눈에 보이는 한 가지 차이 = 줄 위 X 의 수(넷 ↔ 둘).** 큰 X 가 780 px 에서 약 85 px · 작은 X 약 50 px(L48f s10 비를 그대로)라 **센다**. 키 비에는 기대지 않는다 — 키는 「같은 키 짝이 있다 ↔ 없다」 보조 단서일 뿐이다.
- ① ↔ ②: 넷으로 수가 같으니 **줄 위 한 줄 ↔ 줄 가로질러 짝지어, 밧줄 두 면 ↔ 한 면**. ② ↔ ③: **넷 짝지어 ↔ 둘 외톨이**.
- 계기: L48a 칸 3 바닥의 옛 사진기(핵형 · s8)가 이제 **키 두 가지 X 넷**을 겨눈다 — 「수와 형태를 비교」가 그림으로 서고 상동 짝(같은 키 둘씩)이 사진에서 보인다.
- 왼쪽 방(③)의 사실: 지금 L48g 에는 감수 II **중기**가 그려진 곳이 없다(s4 = 걸어 내려옴 · s5 = 이미 후기). s4 편집 때 두 X 를 점선 위에 세우고 s3 에서 이미 건너가 있는 삼밧줄에 걸쇠로 걸어 주면 그 칸이 된다(s3 글의 「짚단엔 아직 안 매임」은 전기 II 로 남는다).

## 8. 예약 확인 · 혼동 · 자리와 크기 · 붐빔 · 오독 위험과 스스로 본 약점
- **예약에 걸리는 것과 처리**: ① 【가위표】 = 「여기서는 안 쓴다」(L35c 수문 정본은 그대로) — 짚단에는 「X 꼴」. ② 【모자】 = 5′ 캡 전용 — **새 모자를 달지 않는다**(남색 짚단 예외 항목에 한정: L48f 춤판 · L48g s4 · s5 에서만, L48a · L48b 에는 모자 · 면사포를 더하지 않고 빛깔로 읽는다). ③ 【짚 다발을 끼운 은빛 쇠 고리】 = 코헤신 전용 — 새 고리를 다른 뜻으로 쓰지 않는다. ④ 【헛간 벽에 박힌 검은 쇠고리】 = 극 — 걸쇠(회색)와 색 · 자리로 가름. ⑤ 【돔 천막】 = 핵 전용 — 짚 소품에 천막 안 씀. ⑥ 【사람이 멘 자루 개수】 = 배수성 — 짚 쪽에 자루를 더하지 않는다(한 벌 = 자루는 글로만 잇는다). ⑦ 【깔때기】 = 감수분열(주둥이 넷) 그대로. ⑧ 【지퍼】 = DNA — 쓰지 않는다(L05b s5 는 별건). ⑨ 【줄자 · 키 재기 막대】 = L35c · L22e 임자 — **키는 잣대 없이 견준다**. ⑩ 【빨간 도장】 = 인산화 — 짚에 도장을 찍지 않는다.

## 덱 전체 — 이 문법이 한 사건으로 읽히는 다섯 줄
1. 한 집안의 짚단(염색체)은 **한 다발에서 시작해 은빛 고리에 낀 두 다발(X)이 되고**, 고리가 끊길 때 다시 한 다발씩 갈라진다 — 체세포분열 후기 · 감수 II 후기가 같은 은빛 C 조각으로 닮고, 감수 I 후기만 **고리가 허리에 남은 채 X 째로** 간다.
2. **자매는 같은 빛깔이 한 고리에 낀 둘 · 상동은 같은 키에 빛깔이 다르고 서로 끼지 않은 X 둘**(남색 아버지 · 하늘색 어머니) — 둘이 묶일 때는 고리가 아니라 **짚 띠**(접합기)이고 교차는 **빛깔이 다른 다발끼리**만 맞바꾼다.
3. **한 벌(n) = 큰 짚단 하나 + 작은 짚단 하나 = 자루 한 개**(L36b · L35c 의 자루가 그대로 이어진다): 2n 은 넷, n 은 둘, **염색체 수는 덩어리를 · DNA 양은 다발을 센다**.
4. 줄(흰 점선) 위에서 **밧줄 양쪽 + X 넷 = 체세포 · X 가 줄을 가로질러 짝짓고 밧줄 한쪽 = 감수 I · 밧줄 양쪽 + X 둘(짝 없음) = 감수 II** — 세 장면이 같은 도구로 짠 한 틀이다.
5. 허리의 세 물건은 어느 과에서나 **꼬임(짚) · 은빛 고리 · 회색 쇠판 걸쇠** — 밧줄은 걸쇠에만 걸리고, 코헤신이 끊겨야 갈라지며, 중심절은 짚 그 자체다.
