## 0. 요지 (한 문단)
짚 세계의 물건 다섯이 **사건 다섯**을 한다: ① **S기에 한 다발 곁에 똑같은 다발이 하나 더 꼬여 은빛 코뚜레 고리로 꿰인다(복제 → 자매)** ② **중매쟁이가 같은 키의 남색 신랑 · 하늘색 신부를 띠로 감는다(짝짓기 → 상동)** ③ **이발사가 부부의 팔 끝을 맞바꾼다(교차)** ④ **밧줄은 허리의 쇠판 걸쇠에만 걸려 당긴다(동원체)** ⑤ **은빛 고리가 C 자로 끊겨 튀면 무엇이 갈라지는가로 분열을 가른다 — 팔 고리만 끊기면 부부가 갈라지고(감수 I), 허리 고리까지 끊기면 자매가 갈라진다(체세포 · 감수 II)**. 셈은 짚 세계의 모든 세포 방에서 **2n = 4(큰 부부 한 쌍 + 작은 부부 한 쌍)** 하나로 맞춘다. 그러면 세 중기는 「점선 **위** 한 줄에 두 다발 짚단 **넷**(체세포) / 점선을 **사이에 두고** 부부 둘(감수 I) / 점선 **위** 한 줄에 **둘**(감수 II)」로 한눈에 갈린다.

## 1. 문법 표

| 뜻 | 꼴(물건 · 빛깔 · 크기 · 수) | 부르는 말(낭독에서 한 번) |
|---|---|---|
| DNA 한 가닥(분자 하나) | 짚 한 가닥 · 짚끈(L37a · L43e 와 같음) | 「짚끈 한 가닥 = DNA 한 분자」 |
| 염색질(풀린 상태) | 묶이지 않고 바닥에 흩어진 **가는 짚 실**(L48a s10 · L48f s2 · L48g s2 · s6) | 「풀린 짚 실 = 염색질」 |
| 염색체(응축) | **묶인 짚단**(실 → 다발로 굵어짐). 짚단 하나 = 염색체 하나 | 「묶인 짚단 = 염색체 하나」 |
| 복제 전 염색체 = 염색분체 하나 | **한 다발**(가운데 틈 없음 · 은빛 고리 없음 · 허리에 쇠판 하나) | 「한 다발」 |
| 복제된 염색체 = 염색분체 둘 | **두 다발 짚단**: 같은 빛깔 · 같은 키의 다발 둘이 잘록한 허리에서 꼬여 붙고 **은빛 고리**로 꿰였다. 전기 초엔 두 다발이 나란히(가운데 세로 틈이 보임), 응축 · 중기엔 X 꼴 | 「두 다발 짚단 — 다발 하나가 염색분체 하나」 |
| 자매염색분체 | 한 짚단 안의 두 다발 = **같은 빛깔**(한 집안) + 은빛 고리로 꿰임. 교차 뒤엔 한 팔 끝만 짝 빛깔 | 「한 집 두 다발 = 자매」 |
| 상동염색체 | **같은 키 · 다른 빛깔**의 짚단 둘 = 남색(검은 실크해트 신랑 = 아버지 쪽) · 하늘색(흰 면사포 신부 = 어머니 쪽). 감수 I 전기에만 중매쟁이 띠로 감겨 나란히 | 「같은 키 두 집안 = 부부 = 상동」 |
| 서로 다른(비상동) 염색체 | **키가 다른** 짚단(큰 쌍 · 작은 쌍) | 「키가 다르면 다른 염색체」 |
| 어버이를 따지지 않는 염색체 | **금빛 짚 홀로**(짝 빛깔 없이) — L19h · L19c · L37a · L43e | 「금빛 홀로 = 아무 염색체 하나」 |
| 중심절(DNA 부위) | 두 다발의 짚 **자체가 꼬여 잘록한 허리 마디**(L19h s2) — 덧댄 것 없음 | 「꼬인 허리 마디 = 중심절」 |
| 동원체(단백질 복합체) | 허리 **바깥 면에 볼트로 박은 쇠판 + 걸쇠** — 다발마다 하나(두 다발 짚단엔 둘 · 등을 맞댐) | 「허리에 박은 쇠판 걸쇠 = 동원체」 |
| 코헤신(고리) | 두 다발을 한데 꿴 **은빛 고리**(허리 바로 아래 하나 + 감수 I 의 팔에 작은 것). 끊기면 **C 자 조각**으로 튄다 | 「은빛 코뚜레 고리 = 코헤신」 |
| 방추사 | **삼밧줄** — 벽의 검은 쇠고리(극)에서 나와 **쇠판 걸쇠에만** 매듭(짚 · 은빛 고리에 감기지 않음) | 「밧줄은 걸쇠에만」 |
| 키아즈마 | **다른 빛깔** 두 짚단의 **팔 끝**이 엇걸린 X(허리가 아님) | 「팔 끝의 엇걸림 = 키아즈마」 |
| 교차 · 재조합 염색분체 | 이발사가 바꾼 끝 — 다발 하나의 끝만 짝 빛깔 | 「끝이 짝 빛깔인 다발」 |
| 염색체 수 | 방(세포) 안의 **짚단 수**(두 다발 짚단도 하나 · 갈라진 한 다발도 하나) | 「짚단을 센다」 |
| DNA 양 | 방 안의 **다발 수** | 「다발을 센다」 |
| 2n · n(세포 안) | **같은 키 짝이 다 있으면 2n · 키마다 하나뿐이면 n**. 짚 세계 세포 방은 2n = 4(큰 남 · 큰 하늘 · 작은 남 · 작은 하늘) | 「짝이 다 있나」 |
| 한 벌(n) ↔ 염색체 한 개 | **자루 하나 = 한 벌**(L36b · L35c · L34b) ↔ **짚단 하나 = 염색체 하나**. 짚 세계에서 한 벌 = 큰 것 하나 + 작은 것 하나 | 「자루 하나에 짚단 둘(큰 · 작은)이 한 벌」 |
| 반수체 ↔ 배수체(2n · 3n · 4n · 6n) | **자루 수**(L36b · L35c 그대로) | 「자루를 센다」 |
| 핵 · 핵막 | 돔 천막(L48a · L48f · L48g · L37a · L05b 그대로) | — |
| 모자 · 면사포 | **두 다발 짚단(염색체 하나) 하나에 하나**. 자매가 갈라진 한 다발에는 씌우지 않는다(빛깔로만 읽음) | — |

**셈의 세 차례**(어느 과에서나): ① 다발을 센다 = DNA 양 ② 짚단을 센다 = 염색체 수 ③ 같은 키 짝이 다 있나 = 2n / n. 덧붙여 ④ 은빛 고리가 있나 = 복제됨.

## 2. 셈 모형과 단계마다 한 줄 소동 (2n = 4 · 짚 세계의 모든 세포 방)

| 단계 | 방 안(짚단 · 다발) | 염색체 수 · DNA | 한 줄 소동(사건) |
|---|---|---|---|
| G1 | 한 다발 넷(풀린 실) | 4 · 2C | 실이 흩어져 쉰다 |
| S | 다발 곁에 똑같은 다발이 꼬여 붙고 은빛 고리가 꿰임 | 4 · 2C → 4C | **꼬아 붙이고 고리를 꿴다**(복제 = 자매 탄생) |
| G2 | 두 다발 짚단 넷 | 4 · 4C | 돋보기로 검사 |
| 체 전기 · 전중기 | 천막이 찢기고 무너짐 · 두 다발 짚단 넷 · 밧줄이 걸쇠를 낚음 | 4 · 4C | 천막이 무너지고 밧줄이 걸쇠를 낚는다 |
| **체 중기** | 점선 **위** 한 줄에 두 다발 짚단 넷 · 짚단마다 양쪽 밧줄 | 4 · 4C | 넷이 **혼자씩** 양쪽에서 당겨져 줄 선다 |
| 체 후기 | 허리 고리 C 조각이 튀고 한 다발 여덟이 양 벽으로(벽마다 큰 남 · 큰 하늘 · 작은 남 · 작은 하늘) | 8 · 4C | **허리 고리가 튀고 자매가 갈라진다** |
| 체 말기 | 새 천막 둘 · 풀린 실 넷씩 | 각 4 · 2C | 천막을 기워 세운다 |
| 감 I 전기 | 두 다발 짚단 넷 → 중매쟁이 띠(같은 키 남 · 하늘) → 이발사 → 팔 끝 엇걸림 → 수레 | 4 · 4C | **띠로 부부를 감고 · 끝을 맞바꾼다** |
| **감 I 중기** | 부부 둘이 점선을 **사이에 두고** 마주 · 짝의 안쪽 팔 끝이 점선 위에서 엇걸림 · 짚단마다 **바깥쪽 밧줄 하나** | 4 · 4C | 부부가 **손(팔 끝)을 걸고** 서로 반대쪽에 매인다 |
| 감 I 후기 | 팔의 작은 고리만 C 로 튐 · 허리 고리는 남음 · 부부가 반대 벽으로 | 4 · 4C | **팔 고리가 튀고 부부가 갈라진다**(자매는 붙은 채) |
| 감 I 말기 | 칸막이 · 방마다 두 다발 짚단 둘(큰 하나 · 작은 하나) | 각 2 · 2C(n · 복제됨) | 목수가 칸막이를 박는다 |
| 감 II 전기 | 천막 찢기 · 두 다발 짚단 둘이 계단을 내려옴 | 2 · 2C | 짝 없이 둘만 내려온다 |
| **감 II 중기** | 점선 **위** 한 줄에 두 다발 짚단 **둘**(큰 · 작은) · 양쪽 밧줄 · 한 팔 끝이 짝 빛깔 | 2 · 2C | 둘이 **혼자씩** 양쪽에서 당겨져 줄 선다 |
| 감 II 후기 | 허리 고리 C 조각 · 한 다발 넷이 양 벽으로(벽마다 큰 하나 · 작은 하나) | 4 · 2C | **허리 고리가 튀고 자매가 갈라진다** |
| 감 II 말기 | 작은 천막 · 한 다발 둘씩 풀림 | 각 2 · 1C | 작은 천막을 친다 |

→ 「**무엇이 C 로 튀는가**」가 사건의 열쇠: 허리 고리 = 자매 분리(체세포 후기 · 감 II 후기 — C1-100 공통점) / 팔 고리 = 상동 분리(감 I 후기).

## 3. 혼동쌍이 한눈에 갈리는 장면 셋 (같은 단계 = 중기)

| | A 체세포분열 중기 — **L48a 셋째 칸** | B 감수 1분열 중기 — **L48f 춤판 앞 쌍** | C 감수 2분열 중기 — **L48g 왼쪽 방 가운데** |
|---|---|---|---|
| 점선과의 자리 | 점선 **위** 세로 한 줄 | 점선을 **사이에 두고** 짝째 마주 | 점선 **위** 세로 한 줄 |
| 줄 선 짚단 수 | **넷**(큰 남 · 큰 하늘 · 작은 남 · 작은 하늘) | 넷(부부 둘) | **둘**(큰 남색 하나 · 작은 하늘색 하나) |
| 밧줄 | 짚단마다 양쪽 둘(쇠판 둘) | 짚단마다 **바깥쪽 하나**(쇠판이 바깥 한 면만) | 짚단마다 양쪽 둘 |
| 팔 끝 | 제 빛깔뿐(교차 없음) | 짝 쪽 팔 끝이 엇걸림(키아즈마) | 한 다발 끝이 짝 빛깔(교차 흔적) |
| 한 줄 소동 | 넷이 혼자씩 줄다리기 한가운데 | 부부가 팔 끝을 건 채 서로 반대 편에 매임 | 둘이 혼자씩 줄다리기 한가운데 |

**한눈에 보이는 한 가지 차이**
- A ↔ C: **점선 위 줄의 짚단 수 — 넷 ↔ 둘**. 키 비교가 아니라 셈이다. 780 px 에서 L48a 한 칸이 약 140 px 폭 × 360 px 높이 — X 넷이 위아래로 꽉 찬 줄과 반만 찬 줄은 세지 않아도 길이로 보인다. 보조 둘: A 는 같은 키 짝이 다 있다(모자 둘 · 면사포 둘이 아니라 빛깔 짝) · C 는 한 팔 끝이 얼룩(이발사가 다녀간 흔적 — 감수 II 에만).
- A · C ↔ B: **점선 위 한 줄이냐, 점선을 사이에 둔 짝이냐**(+ 밧줄이 양쪽이냐 한쪽이냐).

**셈 모형을 맞추는 비용(이 차이를 쓰려면)**
| 무엇 | 비용 |
|---|---|
| L48a 를 2n = 4 · 남색 / 하늘색으로 | 다시 그리기 1(또는 칸마다 구역 편집 5) · 새로 느는 물건: 짚단 +2 × 4칸(전기 · 전중기 · 중기 · 말기 실) + 후기 한 다발 +4 + C 조각 한 줌 · 녹음 없음 · 잠금 없음 · 글 8구간(녹음 안 됨) |
| L48g 왼쪽 방에 중기 II 를 세움(s3 · s4) | 구역 편집 1 · 새 물건 0(있는 X 둘을 옮기고 키만 바꿈 · 쇠판 걸쇠 4 · 밧줄은 s3 에 이미 있음) · 녹음 · 잠금 없음 |
| L48f 앞 쌍을 중기 I 로(팔 끝 엇걸림 · 발 땅에) | 구역 편집 1 · 새 물건 0 |
| L48b(잠김) | **안 1 = 그대로**(비용 0 — §4 참조, 반대로 읽히지 않음) · 안 2 = 다시 칠함(§8) |
| 합 | 다시 그리기 1 + 구역 편집 2 · 녹음 0 · 잠긴 그림 해시 0 |

## 6. 예약 확인 (직접 돌린 결과 요약)
- `가위표` — 「못에 걸고 널빤지 둘로 가위표 = 여기서는 안 쓴다 · 막힘」 예약 → 염색체 이름으로 쓰지 않는다(F6). 새 부르는 말 **「두 다발 짚단」**.
- `X자` — **키아즈마 = X자(② chi)** 예약이 이미 있다 → 염색체를 「X 짚단」으로 부르면 키아즈마와 같은 글자 꼴이 둘. 그래서 부르는 말은 「두 다발 짚단」으로 하고, 그림에서 키아즈마 X 는 **다른 빛깔 · 팔 끝**, 염색체 X 는 **같은 빛깔 · 허리**로 가른다(§7 약점 1).
- `짚 다발을 끼운 은빛 쇠 고리` — 코헤신 전용(이 문법 그대로). 예약 주석의 「L48a 짚단 허리는 밧줄로 묶였다」는 이 안으로 사라진다(예약 글 고칠 것).
- `남색 짚단 · 하늘색 짚단` — 상동의 아버지 · 어머니 전용 · 「같은 키 한 쌍 = 상동 · 키 큰 쌍 / 작은 쌍 = 다른 염색체」 — 이 안이 그대로 이어받아 L48a 까지 넓힌다(예약 글 「⚠ L48a 의 금빛 · 초록」 줄을 L48b 만으로 좁힘).
- `헛간 벽 검은 쇠고리` = 극 · `삼밧줄` = 방추사(동원체 걸쇠에 맴) — 그대로.
- `사람이 멘 자루 개수` = 배수성(한 개 n · 두 개 2n) — 「한 벌」 줄이 그대로 씀. ⚠ 예약이 「다른 판에서 자루를 셀 수 있게 그리지 마라」 → 이 안의 1 안은 짚 세계에 자루를 **새로 넣지 않는다**(안 2 만 넣음).
- `돔 천막` = 핵 — 그대로. `붉은 천 눈가리개` = 무작위 — L48g s8 그대로.
- 새 낱말: `코뚜레` · `동판` · `자매품` · `동갑` · `빈 자루` · `자루 한 개` — 모두 임자 없음.
- `모자` 예약(5′ 캡 = 띠 앞머리의 중산모 · 「사람이 쓰고 있는 모자는 뜻이 없다」)과 실크해트 신랑은 이미 따로 예약됨 — 이 안은 「짚단(염색체 하나)에 하나 · 갈라진 한 다발엔 없음」만 보탬.

## 7. 혼동쌍 · 자리 · 크기 · 붐빔 · 오독 위험 · 스스로 본 약점
1. **X 꼴 둘**(염색체의 허리 X ↔ 키아즈마의 팔 끝 X): L48f s7 · 장면 B 에서 둘이 한 그림에 같이 나온다. 가름: 허리 X = 같은 빛깔 + 은빛 고리 + 쇠판 / 키아즈마 = 다른 빛깔 + 팔 끝 + 고리 없음. 780 px 에서 팔 끝 엇걸림이 작다 → 앞 쌍 편집 때 엇걸린 끝을 짚단 폭의 절반 이상으로.
2. **자매 ↔ 상동이 빛깔에 기댄다**: 빛깔만으로 가르면 약하다는 덱 규칙이 있다. 그래서 빛깔 + **꼴**(자매 = 한 짚단 안 · 은빛 고리로 꿰임 / 상동 = 떨어진 두 짚단 · 같은 키 · 띠) + **수**(2n 방엔 짝 둘)를 겹쳤다. 빛깔을 못 가르는 독자에겐 「한 짚단 안인가 밖인가」가 남는다.
3. **장면 A ↔ C 의 한 가지 차이(넷 ↔ 둘)**는 L48a 를 다시 그려야만 선다. 다시 그리기에서 짚단 수가 틀리기 쉽다(바탕 모형이 셈을 자주 틀림) → 검수에서 칸마다 짚단 · 다발 수를 센다(중기 4 · 후기 벽마다 4 · 말기 천막마다 4).
4. **L48a 칸 폭**: 780 px 에서 한 칸 ≈ 140 px. 짚단 넷이 위아래 한 줄이면 하나 ≈ 60 px 높이 — 알아보는 데 걸림 없음. 2048 px 기준 110 px 하한은 짚단마다 넘는다(≈ 160 px). 후기 칸의 V 넷 × 2 는 빽빽 — 벽 쪽에 바짝 붙이고 가운데를 비운다(가운데 C 조각).
5. **L48g 왼쪽 방에 시점이 셋**(말기 I 천막 · 전기 II 찢기 · 중기 II 줄): 셈할 때 같은 순간끼리 세야 한다. s2 를 「두 다발 짚단 둘」로 고치면 방 안에 X 가 넷 보여 「n = 4?」로 셀 위험 → s2 의 둘은 **실로 많이 풀려 반쯤 흐린** 꼴로, 중기 줄의 둘은 또렷하게. 글에 「방 앞은 앞선 순간」 한 마디.
6. **L48b 줄임판**: 셈 2 가 장면 C(감 II)의 셈 2 와 같다. 가르는 것은 「같은 키 두 빛깔이 극마다 다 있다 = 2n」 — 키 비교에 기댄다. 안 2 로 지울 수 있다.
7. **금빛의 두 뜻**: 「금빛 홀로 = 아무 염색체」(L19 · L37 · L43) ↔ L48b 의 「금빛 + 초록 = 부모 짝」. 반대로 읽히지는 않으나 P7 에 덜 맞는다(안 2).
8. **L48g s7 짚 제비 · s10 짚더미**: 짚 = DNA 세계에서 「뽑기 짚」 · 「쌓인 짚」은 염색체로 셀 수 있다. 셀 이유가 없는 자리(마당)라 그대로 두되 글에 한 마디.
9. **L19a 에 짚이 들어오며** 덩이(세포)와 짚(염색체) 두 물건이 겹친다 — 짚은 덩이 **위에 얹은 작은 것**으로만(덩이 안에 박지 않음).
10. 사실 확인: 감수 I 중기의 자매 동원체가 한쪽만 보는 것(쇠판이 바깥 한 면) · 팔 코헤신이 후기 I 에 잘리고 중심절 코헤신은 슈고신이 지킴 · 감수 I 과 II 사이 S 기 없음 · 체세포 후기 염색체 수 두 배 — 모두 교재 수준 사실. 감수 I 말기의 풀림 정도는 종마다 다르다(글 id1 이 이미 그렇게 말함).

## 덱 전체 — 한 사건으로 읽히는 다섯 줄
1. 풀린 짚 실이 묶여 짚단이 된다 — 짚단 하나가 염색체 하나, 다발 하나가 DNA 한 가닥.
2. S 기에 한 다발 곁에 똑같은 다발이 꼬여 붙고 은빛 코뚜레 고리가 꿴다 — 한 집 두 다발이 자매다.
3. 감수 I 에만 중매쟁이가 같은 키의 남색 신랑과 하늘색 신부를 띠로 감고 이발사가 끝을 바꾼다 — 두 집 한 쌍이 상동이다.
4. 밧줄은 허리의 쇠판 걸쇠에만 걸린다 — 양쪽에서 당기면 혼자씩 점선 위에(체세포 · 감수 II), 한쪽만 당기면 부부가 점선을 사이에 두고(감수 I).
5. 팔 고리가 튀면 부부가 갈라져 짝이 사라지고(2n → n, 아직 두 다발), 허리 고리가 튀면 자매가 갈라진다(체세포 · 감수 II) — 자루를 세면 벌, 짚단을 세면 염색체, 다발을 세면 DNA.
