# r1_마 — L45c 고리 제안 (렌즈: 혼동쌍)

먼저 적는 혼동쌍(시험이 바꿔 내는 짝)
- P680 ↔ P700 (숫자는 왼쪽→오른쪽 커지는데 광계 번호는 II→I 로 거꾸로 — 이 그림에서 가장 잘 뒤집히는 짝)
- 광계 II ↔ 광계 I (물 분해·O₂ 쪽 ↔ NADPH 쪽)
- 카로티노이드 ↔ 엽록소 (엽록소 = 엽(잎)·초록 → 「잎」 손잡이가 이미 엽록소 쪽에 있다. 카로티노이드에 잎을 달면 엽록소와 섞인다)
- 스트로마 ↔ 루멘 (바깥 ↔ 속), 스트로마 ↔ 스토마(기공) (글자 하나 차이)
- G3P ↔ 3-PGA (둘 다 탄소 3 — 마디 셋 막대만으로는 못 가른다. 다른 점은 ATP·NADPH 를 먹었느냐)

틀린 소리 친구(막은 것)
- 스트로마 → 스트로(빨대): 빨대는 에스트로겐 · 스트라메노파일 전용이라 못 쓴다(reserved.py 빨대·스트로). 쓰면 에스트로겐으로 끌려간다.
- P700 → 「피칠」 = 페인트칠: 붓(MSH) · 페인트 롤러(시토키닌) · 솔(브라시노스테로이드)이 모두 예약이라 페인트 물건은 못 쓴다. 옻칠(칠기 광택)로 바꿨다.
- G3P → 각설탕: 정육면체 블록 = 6탄소 포도당 예약이라 각설탕(정육면체)은 6탄소로 읽힌다. 못 쓴다.
- 카로티노이드 → 당근 잎: 잎이 엽(葉)이라 엽록소로 읽힌다. 뿌리 쪽 당근을 크게.

### 〈s5 · P680〉 — 안 1 (글)
- 물건(일상 낱말 하나): 피륙(짠 천 한 폭) — 주황 원(이미 그려진 주황 깔판)
- 사건: 쌍둥이가 짠 천 한 폭 위에 서서 도끼로 쪼갠 물에서 전자를 채운다.
- 고리(①): P680 「피육」은 「피륙」처럼 들린다 — 피-륙 두 음절이 겹치고, 주황 원이 올 짠 천(피륙)으로 읽힌다.
- 낭독에 넣을 한 문장: 「주황 원은 올이 짜인 천, 피륙 한 폭 — 피륙은 피육백팔십, 도끼가 있는 먼저의 광계 이이다.」 (낭독에서 주황·청록 원은 「깔개」라 부르지 말고 「원」·「천」이라 한다 — 아래 스트로마의 깔개와 겹치지 않게)
- 자리와 크기: 왼쪽 주황 원 전체(그림 그대로) · 새 물건 없음
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 없음 / 전부 그대로
- 예약 확인: reserved.py 피륙 → 임자 없음 · P680 → 임자 없음 · 천 → 요소 · 키틴 등 다른 뜻의 천뿐(주황 원을 천으로 부르는 것과는 무관)
- 혼동쌍(무엇과 어떻게 갈리나): P700 「피칠」(옻칠 광택 판)과 — 같은 둥근 자리 · 같은 쌍둥이, 천 짜임 ↔ 칠 광택 한 가지만 다르다.
- 붐빔: 새 물건 0 · 이미 있는 소품(주황 원)에 얹음
- 오독 위험과 약점: 「피륙」은 요즘 낱말이 아니다. 낭독에서 뜻(천)을 같이 말해 줘야 한다. 색만으로 갈린다고 읽힐 위험 — 소리(피륙)가 주 손잡이이고 색은 부수.

### 〈s5 · P680〉 — 안 2 (그림)
- 물건: 올이 보이게 짠 천 무늬 + 풀린 올 한두 가닥(주황 원 가장자리)
- 사건: 주황 원의 가장자리 올이 풀려 나온다(천임을 알아보게 함).
- 고리(④ 이름 뜻 그대로): 피륙 = 짠 천. 천 원 = P680.
- 낭독에 넣을 한 문장: 안 1과 같음.
- 자리와 크기: 주황 원 테두리 한 바퀴 안쪽 · 올 무늬 띠 폭 약 110 px(2048 기준)
- 그림에서 바뀌는 것 / 그대로 두는 것: 원 표면에 직조 무늬·풀린 올 / 쌍둥이 · 사발 · 밧줄 · 물통 그대로
- 예약 확인: 직조 · 베틀 → 임자 없음 · 무늬 → 다른 뜻의 무늬(요 · 방울 · 궤짝) 있으나 원 무늬와 겹치지 않음
- 혼동쌍: 안 1과 같음
- 붐빔: 새 물건 0 (무늬만)
- 약점: 780 px 로 줄이면 올 무늬가 뭉개진다 · 안 1(글)이 낫다.

### 〈s5 · P700〉 — 안 1 (글)
- 물건: 옻칠한 판(칠기 쟁반처럼 윤나는 판) — 청록 원
- 사건: 쌍둥이가 윤 나게 칠한 판 위에 서서 올라온 전자를 플로피 쪽으로 넘긴다.
- 고리(①): P700 「피칠백」의 칠이 「옻칠」의 칠로 들린다 — 칠 소리가 그대로 겹친다.
- 낭독에 넣을 한 문장: 「청록 원은 옻칠로 반들반들한 판 — 칠 — 피칠백, 플로피와 방패가 있는 뒤의 광계 일이다.」
- 자리와 크기: 오른쪽 청록 원 전체 · 새 물건 없음
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부 그대로
- 예약 확인: 옻칠 → 임자 없음 · 칠 → 금색 자물쇠 · 알도스테론 등 잡음 일치뿐(옻칠 물건은 예약 없음) · 붓 · 페인트 · 솔 → MSH · 시토키닌(초록 롤러) · 브라시노스테로이드 전용이라 안 씀
- 혼동쌍: P680 「피륙」(천) — 육/칠 소리가 각각 천/칠로 갈린다. 번호 역전(II=680)은 낭독으로 「육은 먼저, 칠은 나중」을 한 번 더.
- 붐빔: 새 물건 0
- 약점: 칠 소리는 「칠하다」 쪽으로 끌려 페인트(예약 물건)를 떠올릴 수 있다 — 낭독에서 「옻」을 붙여 반들거리는 칠기로 못 박는다.

### 〈s5 · P700〉 — 안 2 (그림)
- 물건: 거울처럼 번들거리는 하이라이트 줄(청록 원 표면)
- 사건: 청록 원 위에 빛이 번쩍 비쳐 윤이 난다.
- 고리(④): 옻칠 = 윤 나는 판. 천(주황) ↔ 윤(청록) 한 가지만 다르다.
- 낭독에 넣을 한 문장: 안 1과 같음.
- 자리와 크기: 청록 원 윗면 · 번쩍 줄 길이 약 300 px · 폭 110 px(2048 기준)
- 그림에서 바뀌는 것 / 그대로 두는 것: 원 표면의 광택 / 나머지 그대로
- 예약 확인: 거울 · 윤 → 임자 없음 또는 무관(lac 오페론의 「윤」은 글자 일치뿐)
- 혼동쌍: 안 1과 같음
- 붐빔: 새 물건 0
- 약점: 광택은 단순 색 변화로 읽혀 「빛깔만으로 가른 것」이 될 위험 — 안 1(글) + 안 2의 쌍으로만 쓴다.

(광계 II ↔ 광계 I 는 위 두 낱말 쌍에 같이 얹힌다: 도끼 · 물통이 있는 천 원 = 먼저·II, 플로피 · 방패가 있는 칠 원 = 나중·I. 번호 거꾸로 문제는 「육(6)은 천, 칠(7)은 칠」 소리로만 풀고, 번호 II/I 는 기존 낭독 그대로.)

### 〈s1 · 스트로마〉 — 안 1 (글)
- 물건: 쿠션 바깥에 펼쳐진 술 달린 회색 깔개(이미 그려져 있음 — s14 · 오른쪽 아래, 루비스코 놓인 곳)
- 사건: 쿠션 속에서 나온 금화와 방패가 쿠션 바깥 깔개 위로 옮겨져 쓰인다.
- 고리(④): 스트로마는 이름 뜻 그대로 「펴 깐 것 = 깔개」다. 쿠션 바깥에 깔린 것이 곧 스트로마.
- 낭독에 넣을 한 문장: 「무대 바깥에 펴 깐 술 달린 회색 깔개가 스트로마다 — 쿠션 속은 루멘, 쿠션 바깥에 깐 것이 스트로마.」
- 자리와 크기: 그림 오른쪽 아래 회색 깔개 · 새로 만들 것 없음
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부 그대로
- 예약 확인: reserved.py 깔개 → 고리 사전 「스트로마: 깔개」(s45u02 술 달린 회색 깔개 · 루비스코가 그 위) 있음 · 스트로 · 빨대 → 에스트로겐 · 스트라메노파일 전용이라 스트로(빨대)는 쓰지 않는다
- 혼동쌍: 루멘(쿠션 속) · 기공(스토마). 쿠션 속 ↔ 쿠션 바깥 깔개. 스토마는 「입」, 스트로마는 「깐 것」으로 갈린다.
- 붐빔: 새 물건 0 · 이미 있는 소품
- 약점: 주황·청록 원도 「깔개」처럼 보인다(사전에서 이미 흘렀던 까닭일 수 있음). 그래서 위 P680/P700 낭독에서 그 둘을 「원 · 천」으로 불러 「깔개」 낱말을 회색에만 남긴다. 그림 속 회색 깔개가 s1 조각에서 작게 보일 수 있다.

### 〈s1 · 스트로마〉 — 안 2 (그림)
- 물건: 회색 깔개를 쿠션 아래까지 넓힌 것(쿠션이 깔개 위에 놓임)
- 사건: 쿠션이 깔개 위에 놓여 있고 금화가 그 깔개 위로 쏟아진다.
- 고리(④): 깔개 = 스트로마(펴 깐 것). 쿠션을 받쳐 둘러싼 깔린 것.
- 낭독에 넣을 한 문장: 「쿠션 아래와 둘레에 깔린 회색 깔개가 스트로마다.」
- 자리와 크기: 쿠션 아래 · 물레방아 아래쪽 금화가 떨어지는 곳까지 · 폭 약 400 px 이상(2048 기준)
- 그림에서 바뀌는 것 / 그대로 두는 것: 회색 깔개를 왼쪽으로 넓혀 쿠션 밑까지 · 그대로: 쿠션 · 루비스코 · 소년 · 방패
- 예약 확인: 안 1과 같음
- 혼동쌍: 안 1과 같음
- 붐빔: 새 물건 0 · 크기만 변경(큰 구역 편집 — 한 번에 안 들어갈 수 있음)
- 약점: 큰 편집이다. 루멘 · 스트로마의 안팎이 더 선명해지는 대신 쿠션 모양이 가릴 수 있다.

### 〈s2 · 스펙트럼〉 — 안 1 (그림)
- 물건: 유리 프리즘 + 무지개 부채
- 사건: 위에서 내리는 햇살이 유리 프리즘을 지나 무지개 부채꼴로 갈라져 액자 머리 사람들에게 닿는다.
- 고리(④ 이름 뜻 그대로): 스펙트럼 = 빛이 갈라져 펼쳐진 색 띠. 프리즘이 햇살을 무지개로 펼친다.
- 낭독에 넣을 한 문장: 「햇살이 유리 프리즘을 지나 무지개로 펼쳐진다 — 이 펼쳐진 색 띠가 스펙트럼이고, 카로티노이드는 이 띠를 더 넓게 쓰게 해 준다.」
- 자리와 크기: 액자 사람 무리 위쪽, 기존 노란 빛살 한 줄 자리를 대신 · 프리즘 밑변 약 140 px · 무지개 부채 폭 약 400 px(2048 기준)
- 그림에서 바뀌는 것 / 그대로 두는 것: 빛살 한 줄이 프리즘 + 무지개로 / 액자 사람 · 물결 · 반원 그대로
- 예약 확인: 프리즘 · 무지개 · 스펙트럼 → 모두 임자 없음 · 삼각 → 삼각 모자(δ) · 삼각 격자 우리(클라트린) 예약이라, 프리즘은 투명한 유리 기둥(모자도 우리도 아님)으로 그린다
- 혼동쌍: 스펙트럼(펼쳐진 띠 전체) ↔ 흡수하는 한 색. 카로티노이드는 「색 한 줄」이 아니라 「띠를 넓힘」 — 무지개 폭을 넓히는 쪽을 낭독에 못 박는다.
- 붐빔: 새 물건 1(프리즘; 기존 빛살 한 줄과 교체)
- 약점: 무지개 일곱 색 줄이 「범례 · 색 칸」으로 읽히면 안 된다 — 부채꼴 빛살로 그린다. 보조 색소 설명과 겹쳐 낭독이 길어진다.

### 〈s2 · 스펙트럼〉 — 안 2 (글)
- 물건: 액자 머리 위의 노란 빛살 여러 줄(이미 그려져 있음)

- 고리(④): 빛살 한 줄 = 무지개의 한 칸, 여러 줄 = 스펙트럼.

- 자리와 크기: 기존 빛살 · 변경 없음
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부
- 예약 확인: 스펙트럼 → 임자 없음
- 혼동쌍: 위와 같음
- 붐빔: 새 물건 0
- 약점: 약하다 — 그림에 무지개가 없어 글만 받은 독자는 이미지를 못 꺼낸다(N 이 그대로 날 가능성). 안 1이 낫다.

### 〈s2 · 카로티노이드〉 — 안 1 (그림)
- 물건: 당근(주황 뿌리 한 개, 굵게)
- 사건: 액자 머리 사람 하나가 굵은 당근을 껴안고 센 빛을 받아 낸다.
- 고리(④ 사전 그대로): carota = 당근 — 카로티노이드 = 당근을 든 사람. 잎은 달지 않고 뿌리만(잎은 엽록소의 「엽」과 섞인다).
- 낭독에 넣을 한 문장: 「굵은 당근을 안은 사람이 카로티노이드 — 엽록소 에이가 놓치는 파장을 맡는 보조 색소다.」
- 자리와 크기: 왼쪽 무리 맨 왼쪽 사람(갈색·붉은 몸) 가슴 앞 · 당근 길이 약 300 px · 굵은 쪽 폭 약 115 px(2048 기준)
- 그림에서 바뀌는 것 / 그대로 두는 것: 그 사람이 당근을 안음(몸 · 액자는 그대로) / 나머지 세 사람 · 물결 · 빛살 그대로
- 예약 확인: 당근 → 「당근빛 사람(머리에 당근 잎) — 카로티노이드 전용(s45u02)」 있음 — 같은 뜻으로만 되살리며 잎을 뿌리로 바꿔 쓴다 · 카레 · 캐럿 → 임자 없음(안 썼다)
- 혼동쌍: 카로티노이드(당근 뿌리) ↔ 엽록소(잎). 같은 액자 머리 사람이고 한 가지만 다르다 — 든 것이 당근이냐 잎이냐.
- 붐빔: 새 물건 1(당근) · 사람은 그대로
- 약점: 당근 잎을 안 달면 사전의 「당근빛 사람 · 당근 잎」과 모양이 달라진다 — 같은 뜻이라 허용될 것으로 본다(사전 갱신 필요 여부는 검수자 판단). 사람이 안으면 광호흡 · 다른 판의 물건 든 사람과 섞일 수 있다.

### 〈s2 · 카로티노이드〉 — 안 2 (글)
- 물건: 오른쪽 무리 맨 왼쪽의 주황 몸 사람(full 그림 x≈860 · 이미 그려져 있음)
- 사건: 주황 몸 사람이 다른 액자 사람들 곁에서 빛을 받아 넘긴다.
- 고리(④): 당근빛 몸 = 카로티노이드(carota = 당근).
- 낭독에 넣을 한 문장: 「당근빛 주황 몸의 사람이 카로티노이드, 초록 옷 사람이 엽록소다.」
- 자리와 크기: 기존 · 변경 없음
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부
- 예약 확인: 당근 → 위와 같음
- 혼동쌍: 엽록소(초록 몸) ↔ 카로티노이드(주황 몸)
- 붐빔: 새 물건 0
- 약점: 몸 빛깔만으로 가른 것이라 「고리가 아닌」 쪽에 가깝다 — 소리 연결은 「당근」 낭독뿐. 약하다. 안 1이 낫다.

### 〈s14 · G3P〉 — 안 1 (그림)
- 물건: 마디 셋 막대(탄소 셋 — s45u01 문법 그대로)
- 사건: 소년이 금화와 방패를 깔개 위 막대에 갖다 대자 마디 셋 막대가 나온다(금화·방패를 먹은 막대 = G3P).
- 고리(④ 이름 뜻): G3P 의 3 = 탄소 셋 = 마디 셋. 금화(ATP)·방패(NADPH)를 쓰고 난 뒤의 막대가 G3P 라는 짝 구조.
- 낭독에 넣을 한 문장: 「소년이 금화와 방패를 깔개의 작업장에 내려놓으면 마디 셋 막대, 지삼피가 나온다 — 에이티피와 엔에이디피에이치를 먹고 난 삼탄소 당이다.」
- 자리와 크기: 회색 깔개 위, 루비스코 곁 · 막대 길이 약 250 px · 폭 110 px(2048 기준)
- 그림에서 바뀌는 것 / 그대로 두는 것: 깔개에 마디 셋 막대 하나 추가 / 소년 · 금화 · 방패 · 루비스코 그대로
- 예약 확인: G3P → 해당과정 장의 NAD 양동이 예약뿐(별개) · 마디 → 마디 진 막대 = 탄소 수(마디 셋 = 3-PGA/G3P) 전용 · 각설탕 · 큐브 → 안 썼다(정육면체 블록 = 6탄소 포도당 예약) · 포도 → 포도당 예약이라 안 썼다 · 사탕 → 당 사슬(L48d) 예약이라 안 썼다
- 혼동쌍: 3-PGA ↔ G3P — 같은 마디 셋 막대. 갈리는 한 가지 = 금화와 방패를 먹었느냐(먹기 전 = 3-PGA, 먹은 뒤 = G3P). 사전의 막대는 둘이 같이 쓰여 이 갈림이 안 보인다 — 이 안이 그 틈을 채운다.
- 붐빔: 새 물건 1(막대) · 소년 · 금화 · 방패의 의미는 그대로
- 약점: 막대의 마디(탄소 수)는 알아도 「지삼피」 소리와는 안 이어진다(글자 모양·소리 고리는 없다). 「먹은 막대」는 금화·방패를 붙이는 장면이 그림 한 장에서 다 읽히는지 의문 — 모름.

### 〈s14 · G3P〉 — 안 2 (글)
- 맞는 소품 없음. 이 정거장의 기존 소품은 소년(에너지 심부름) · 금화(ATP) · 방패(NADPH) · 루비스코(예약)뿐이고, 3 · 당을 나르는 것이 없다. 낭독만 얹으면 독자가 꺼낼 물건이 없어 N 이 그대로다. (지어내지 않고 「없음」으로 둔다.)

## 과 전체 (한 사건)
1. 햇살이 유리 프리즘을 지나 무지개로 펼쳐져(스펙트럼) 액자 머리 사람들에게 닿고, 굵은 당근을 안은 사람(카로티노이드)이 센 빛을 맡는다.
2. 쿠션 위 주황 원은 올 짠 천(피륙 = P680) — 도끼로 쪼갠 물통이 있는 먼저의 광계 이이. 오른쪽 청록 원은 옻칠로 반들거리는 판(칠 = P700) — 플로피 · 방패가 있는 나중의 광계 일.
3. 쿠션 속은 붉은 구슬(루멘) · 쿠션 바깥에 펴 깐 술 달린 회색 깔개가 스트로마다.
4. 물레방아에서 쏟아진 금화와 방패를 소년이 회색 깔개 작업장에 내려놓으면, 마디 셋 막대(G3P)가 나온다.
5. 혼동 막이: 빨대(스트로) · 페인트 붓 · 각설탕 · 당근 잎은 예약·엽록소 충돌 때문에 일부러 뺐다.
