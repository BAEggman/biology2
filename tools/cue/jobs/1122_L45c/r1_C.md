먼저 버린 것(찾아보고 막힌 것):
- 빨대 → 스트로마: reserved.py 빨대 = 털 돋은 빨대(스트라메노파일) · 에스트로겐(스트로 = 빨대) 이미 임자 있음. 버림.

- 피자 조각 → G3P(삼 · 피): reserved.py 피자 = PIP · IP₃ 전용. 버림.

## 스트로마 (s1)

### 〈s1 · 스트로마〉 — 안 1 (글)
- 물건(일상 낱말 하나): 깔개 (s14 쿠션 밖 오른쪽 아래의 회색 깔개 — 루비스코 망원경이 놓인 그 깔개)

- 고리(④ 이름 뜻 그대로): 스트로마는 그리스말로 「펴 깐 것 · 깔개」라 이름 뜻 그대로다 (hooks.json 의 스트로마: 깔개 되살림).
- 낭독에 넣을 한 문장: 「쿠션 바깥 바닥에 펴 깐 회색 깔개가 스트로마다 — 이름이 깔개라는 뜻이고, 캘빈 회로는 이 깔개 위에서 일한다.」
- 자리와 크기: 지금 그림 오른쪽 아래 회색 깔개(1400 px 기준 약 210×150) 그대로. 손대지 않음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 바뀌는 것 없음 / 전부 그대로.
- 예약 확인: reserved.py 회색 깔개 → 임자 없음. reserved.py 깔개 → 와플 · 짚끈 · 바둑판 깔개(L50a) 등이 걸리나 모두 다른 물건. 사전 「스트로마: 깔개(④)」가 같은 뜻.
- 혼동쌍: 주황 · 청록 깔개(PSII · PSI 자리)와 같은 낱말이라 흐릴 수 있다 — 낭독에서 「쿠션 위의 두 깔개는 광계 자리, 쿠션 밖 회색 깔개가 스트로마」로 위치 한 번 가른다.
- 붐빔: 새 물건 0. 이미 있는 소품에 얹음 — 단 회색 깔개는 지금 낭독에서 「루비스코 망원경이 놓인 곳」 정도만 나르므로 뜻이 겹치지 않는다(망원경 = 루비스코, 깔개 = 장소).
- 오독 위험과 약점: 독자가 s14 에서 깔개를 못 짚었음(망원경 · 소년만 봄). 낭독이 없으면 안 된다. 주황 · 청록 깔개와 헷갈림.

## 카로티노이드 (s2)

- 고리(④ 이름 뜻): 카로티노이드는 당근(carrot)에서 온 이름이라 이름 뜻 그대로다. 사전의 「당근빛 사람 · 당근 잎」을 액자 사람과 부딪히지 않게 당근 하나로 되살림.
- 낭독에 넣을 한 문장: 「노란 옷의 사람 곁에 서 있는 당근 — 카로티노이드는 당근빛 보조 색소다.」

- 혼동쌍: 엽록소 b · 에이를 나타내는 초록 옷 사람과는 주황 당근 + 잎이 곁에 있느냐로 가름.

## P680 (s5)

### 〈s5 · P680〉 — 안 1 (그림)
- 물건: 훌라후프 (왼쪽 주황 깔개 바깥 끝에 한 개)
- 사건: 주황 깔개 곁에 훌라후프 하나가 기대 세워져 있다 — 이름 속 0(공 · 동그라미)이 한 개.
- 고리(② 글자 모양): 680 의 0 은 동그라미 하나 — 훌라후프 하나. 700 은 0 이 둘 — 훌라후프 둘(P700 안 1).
- 낭독에 넣을 한 문장: 「주황 깔개 곁에 훌라후프가 하나 — 육백팔십에는 동그라미 0 이 하나다. 청록 깔개 곁에는 둘 — 칠백에는 0 이 둘이다.」
- 자리와 크기: 왼쪽 주황 깔개 왼쪽 바깥 가장자리(1400 px 기준 x 약 170~230, y 약 470~540). 지름 약 80(2048 기준 약 115).
- 그림에서 바뀌는 것 / 그대로 두는 것: 훌라후프 추가(구역 편집 — 왼쪽 아래 한 곳 + 오른쪽 아래 한 곳, 총 두 곳) / 사람 · 공 · 밧줄 · 사발 그대로.
- 예약 확인: reserved.py 훌라후프 → 임자 없음. reserved.py 반지 · 바퀴 → 옥가락지(옥시토신) · 로프 도르래(로돕신) 걸리나 훌라후프와는 다른 물건. reserved.py 노란 공 → 1차 전자수용체 전용이라 공 개수는 안 씀.
- 혼동쌍: 680 / 700 의 갈림은 숫자가 아니라 0 의 개수(하나 / 둘)로 가른다. 광계 번호(II / I)는 낭독의 기존 문장이 맡음.
- 붐빔: 새 물건 1(오른쪽 P700 까지 합 3 개 = 1 + 2). 쿠션 바깥 가장자리가 비어 있어 가림 없음.
- 오독 위험과 약점: 훌라후프가 밧줄 고리(계)와 둥근 모양으로 겹친다 — 색(분홍 · 빨강)과 서 있는 자세로 갈라야 한다. 숫자 6 · 8 · 7 은 연결하지 못한다(0 의 개수만). 「훌라후프 = 0」이 전문 지식 없이 풀리는지는 낭독 문장에 의존 — 소리 손잡이가 아니라 모양 손잡이이므로 중간 이하.

### 〈s5 · P680〉 — 안 2 (글)
- 물건: 쌍둥이 (가운데 나란히 선 둘)
- 사건: 밧줄 속에서 사발을 맞들고 선 한 쌍이 전자를 내놓는다.
- 고리(③ 머리글자): P = Pair(한 쌍) — 쌍둥이 한 쌍이 곧 P, 주황 깔개의 쌍둥이가 P680.
- 낭독에 넣을 한 문장: 「P 는 짝(Pair)의 P — 이 쌍둥이 한 쌍이 P이고, 주황 깔개 쪽은 육백팔십이다.」
- 자리와 크기: 변화 없음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부.
- 예약 확인: reserved.py 쌍둥이 → PYY(Y 자 쌍둥이) 예약 있음. 이 판의 쌍둥이는 팔을 내린 보통 서 있는 쌍둥이(s3 특수 엽록소 쌍)라 모양이 다르나 낱말이 같으므로 「쌍둥이 둘」로만 쓸 것.
- 혼동쌍: P680 / P700 은 이 안으로 가르지 못한다(같은 쌍둥이). 숫자는 기존 낭독.
- 붐빔: 0.
- 오독 위험과 약점: P = Pigment(색소)가 교과서 풀이라 「Pair」는 학습 편의일 뿐 사실이 아니다(고리는 사실이 아니어도 됨). 680 vs 700 은 못 가름.

## P700 (s5)

### 〈s5 · P700〉 — 안 1 (그림)
- 물건: 훌라후프 (오른쪽 청록 깔개 바깥 끝에 두 개)
- 사건: 청록 깔개 곁에 훌라후프 둘이 겹쳐 기대 서 있다 — 700 의 0 이 둘.
- 고리(② 글자 모양): 700 은 7 + 0 0 — 동그라미 둘, 훌라후프 둘.
- 낭독에 넣을 한 문장: P680 안 1 과 같은 문장(왼쪽 하나 · 오른쪽 둘).
- 자리와 크기: 오른쪽 청록 깔개 오른쪽 바깥 가장자리(1400 px 기준 x 약 1180~1260, y 약 480~560). 지름 약 80 두 개가 겹침(2048 기준 약 115).
- 그림에서 바뀌는 것 / 그대로 두는 것: 훌라후프 둘 추가 / 나머지 그대로.
- 예약 확인: 훌라후프 임자 없음(위).
- 혼동쌍: P680 의 하나 대 둘. 낭독에서 「왼쪽 하나 · 오른쪽 둘 = 숫자도 커진다」로 이어 두 쪽이 한 쌍이 된다.
- 붐빔: 새 물건 2. 오른쪽 청록 깔개 곁은 플로피 · 방패와 떨어져 있어 가림 없음.
- 오독 위험과 약점: P680 과 같음. 훌라후프 둘 겹침이 780 px 에서 「링 하나」로 뭉칠 수 있음 — 약간 어긋나게 세울 것.

## G3P (s14)

### 〈s14 · G3P〉 — 안 1 (그림)
- 물건: 삼각김밥 (회색 깔개 위, 망원경 곁에 하나)
- 사건: 소년이 가져온 금화 · 방패로 회색 깔개 작업장에서 삼각김밥 하나가 만들어져 놓여 있다 — 삼 모서리 = 3탄소, 밥 = 당.
- 고리(① + ④): 「삼」각김밥의 첫 음절이 G3P 의 3(삼 · 삼탄당)과 겹치고, 모서리 셋이 3탄소를 크게 그린 것이며 밥은 당(캘빈 회로의 산물)이다.
- 낭독에 넣을 한 문장: 「깔개 위에 삼각김밥이 하나 놓였다 — 삼각이 삼탄당 G3P, 캘빈 회로가 만든 당이다.」
- 자리와 크기: 회색 깔개 왼쪽 위 빈 곳(1400 px 기준 x 약 1250~1330, y 약 620~690). 약 75×70(2048 기준 약 110×105).
- 그림에서 바뀌는 것 / 그대로 두는 것: 삼각김밥 하나 추가(구역 편집 한 번) / 소년 · 금화 · 방패 · 망원경 · 깔개 그대로.
- 예약 확인: reserved.py 삼각김밥 → 임자 없음. reserved.py 삼각 → 삼각 모자(δ) · 삼각 격자 우리(클라트린) 예약 — 「삼각」 소리가 이미 다른 데서 쓰이므로 이 정거장 안에서만 쓰고 다른 판에 퍼뜨리지 말 것. reserved.py 피자 → 걸려서 버림(위).
- 혼동쌍: 놋쇠 망원경(루비스코)과 위치로 갈림 — 망원경은 깔개 오른쪽 · 삼각김밥은 왼쪽. 다른 당 소품(포도 = 포도당)과는 모양으로 가름.
- 붐빔: 새 물건 1. 깔개 가장자리가 그림 오른쪽 끝에 잘려 있어 자리가 좁다.
- 오독 위험과 약점: 780 px 에서 약 40 px 라 하얀 삼각형 + 검은 띠가 간신히 읽힘 — 김 띠를 크게. 「삼각김밥」을 「주먹밥 · 삼각형」으로 부를 수 있다(낭독이 잡아 줌). 「3」을 삼각의 모서리 수로 보는 건 학습자 몫이라 소리 고리로는 중간.

### 〈s14 · G3P〉 — 안 2 (글)
- 물건: 소년 (금화 · 방패를 들고 걷는 소년)
- 사건: 소년이 금화와 방패, 자신까지 셋이 한 줄로 깔개로 간다(세 가지 = 삼).
- 고리(②/③ 억지): 소년 + 금화 + 방패 = 세 가지, G3P 의 3. 소리 · 뜻 고리가 약해 「세어 보는」 손잡이일 뿐.
- 낭독에 넣을 한 문장: 「소년과 금화와 방패, 셋이 깔개로 가서 삼탄당 G3P 를 만든다.」
- 자리와 크기: 변화 없음.
- 그림에서 바뀌는 것 / 그대로 두는 것: 없음 / 전부.
- 예약 확인: 새 물건 없음 — 금화(ATP) · 방패(NADPH) 약속 그대로.
- 혼동쌍: 금화 = ATP 와 겹치지 않게 「세 가지」로만 말함.
- 붐빔: 0.
- 오독 위험과 약점: 금화 · 방패가 이미 다른 뜻을 나르는 소품 — 그 위에 「3」을 얹는 꼴이라 규칙 위반에 가깝다. 사실상 안 1 이 막힐 때의 보충. 좋은 글 쪽 안을 못 찾음(모름).

## 과 전체
쿠션 무대 밖 회색 깔개(스트로마 = 깔개)가 쿠션 아랫변까지 이어지고, 그 위에서 소년이 삼각김밥(G3P)을 내려놓는다.
왼쪽 무리 곁에는 당근 한 개(카로티노이드)가 서 있고 가장 왼쪽 빛살만 무지개 띠(스펙트럼)로 내려온다.
주황 깔개 곁에 훌라후프 하나(P680), 청록 깔개 곁에 둘(P700)이 세워져 있다.
새 물건은 당근 1 + 훌라후프 3 + 삼각김밥 1 = 5, 나머지(깔개 키우기 · 빛살 칠하기)는 있는 소품 손질이다.
약점: 훌라후프 3 개가 밧줄 고리와 둥글게 겹치므로 P680/P700 는 가장 불안한 안이다.
