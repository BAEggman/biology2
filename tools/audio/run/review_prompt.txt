첨부 ZIP의 MP3 {N}개를 독립 검사해 줘. 이 대화에는 원문 대본이 없다. ZIP을 실제로 풀고 각 MP3의 실제 재생 길이·sample rate·채널·파일 SHA256을 도구로 측정한 뒤, 가능한 검수 방법을 정직하게 구분해 줘.
1. 실제 오디오를 모델이 듣는 도구가 있다면 사용해서 발음·누락·끝 잘림·잡음·음색 일관성을 판단해. 사용한 오디오 청취 도구 이름과 반환 형식이 실제 음성인지 자동전사 텍스트인지 명시해.
2. 각 파일의 전체 내용을 처음부터 끝까지 한국어로 받아 적어 줘. 들린 그대로 적고, 오류처럼 보여도 과학 지식으로 임의 교정하지 마. 알파벳 약어처럼 들리는 곳은 들린 한글 소리로 적어(예: '씨 디'). 알아듣기 어려운 낱말은 [불명확: 들린 소리]로 남겨.
3. ASR 전사만 가능하면 청취 완료라고 말하지 말고, 그 결과를 그대로 제공해. 사람이 듣지 않은 파일을 사람이 청취했다고 쓰지 마.
4. 결과는 JSON 보고서 하나로 만들어 다운로드 가능하게 해 줘. 파일마다 filename, sha256, duration_sec, verbatim_text, unclear_segments, pronunciation_anomalies(heard_form, context), end_truncation, extra_utterances 키를 꼭 넣어. 타임스탬프는 실제 도구가 제공할 때만 쓰고 텍스트 길이로 추정하지 마.
중요: 원문은 일부러 주지 않았으므로 '원문과 일치'라고 판정하지 마. 내가 결과를 대조할 거야. 새 음성 생성은 필요 없어.
