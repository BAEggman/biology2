# 녹음 제작 및 등록

Gemini 앱에서 확정한 SID별 say를 그대로 읽어 파일로 저장한다. 동일 목소리와 속도를 유지하고 숫자·방향·니모닉을 청취 대조한다. 내용 검토 보류 구간은 먼저 검토한다. 기존 say를 바꿔 분량을 줄이지 않는다.

lesson/audio/manifest.json의 lessons[lessonId][sid]에 src, text, status: ready를 등록한다. text는 정확한 say 원문이며, 한 글자라도 달라지면 플레이어는 낡은 녹음을 건너뛰고 기기 음성을 사용한다. 새 파일명으로 버전을 올리고 src를 갱신한다. src에는 같은 저장소 상대 경로나 지속적인 HTTPS 오디오 주소를 사용할 수 있다. 임시 Gemini 다운로드 주소는 사용하지 않는다.

파일이 없거나 로딩에 실패하면 기기 음성으로 전환한다. 자동 시작은 브라우저 정책에 따라 첫 클릭이 필요할 수 있다. 실패하면 현재 문단에 멈춰 시작 버튼을 보여 준다. 다음/이전/멈춤/모드 변경 시 이전 음성을 취소한다.

현재 L03a s2·s3 두 구간만 Gemini 녹음이다. 46.44초 원본의 22.47225~23.18850초 무음 내부인 22.83초에서 나누어 MP3로 압축했다. 원본 음절을 잘라내지 않았다. 나머지는 녹음 제작 전이다. 페이지의 완전한 사실·그림 무결성 승인을 뜻하지 않는다.
